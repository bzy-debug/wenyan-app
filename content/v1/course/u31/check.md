# 检查：他们说的事，已经发生了吗 {#check.31}

## 原文：教学例句 {#p.check.31.a}
> 村人将凿渠，约曰：“若泉自石下出，便引之入田；否则罢役。”次日方试掘。
译文：村人将挖水渠，约定若石下有泉就引入田中，否则停工。第二天才试着挖。

## 单选：村人约定挖渠的当日，还有哪件事必须等试掘才知道？ {#q.check.31.1}
考点：skill.syntax.7.1
语境：p.check.31.a

- [ ] 没有泉时应怎样处置
  理由：“否则罢役”说得很清楚：若无泉，便停工。
- [x] 石下究竟有没有泉
- [ ] 村人是否订了约定
  理由：“约曰”已写出约定。

提示：看看“若”后面是什么，再读“次日方试掘”。
解析：怎么做已经约定了：有泉就引水，无泉就停工。有没有泉，还须实际挖开看。

## 原文：教学例句 {#p.check.31.b}
> 使者辞车曰：“苟得一马，今日可至县。”主人入厩求之。
译文：使者谢绝车子说，只要得到一匹马，今天就能到县里。主人进马厩里寻找。

## 找原文证据：使者说“今日可至县”。这句话要成真，他还缺什么？请找原话。 {#q.check.31.2}
考点：skill.syntax.7.2
语境：p.check.31.b

- [ ] 主人入厩
  理由：进厩是主人动身去找，这时使者还没得到坐骑。
- [x] 得一马
- [ ] 辞车
  理由：“辞车”是使者刚做过的事。他还缺的是后面向主人提到的东西。

提示：他说“苟”时，把哪件尚未到手的东西算进去了？
解析：“得一马”才可以今天到县。主人进厩去找，也说明马还没有交到使者手中。

## 原文：教学例句 {#p.check.31.c}
> 客见竹桥窄而犹坚，曰：“桥虽窄，一人徐过无妨。”乃使众相次而度。
译文：客人见竹桥虽窄，还很结实，说：“桥窄归窄，一个人慢慢走过去，倒不妨事。”于是让众人一个接一个过桥。

## 单选：竹桥窄，客人为什么还说能过？他叫众人怎样走？ {#q.check.31.3}
考点：skill.syntax.8.1
语境：p.check.31.c

- [x] 限制过桥方式，每人慢慢走
- [ ] 众人并行就不会拥挤
  理由：“相次”是一个接着一个。
- [ ] 桥窄，所以谁也不能上桥
  理由：“一人徐过无妨”仍许通行。

提示：把“虽窄”接到“一人徐过”上，再读“相次”。
解析：桥窄是事实，办法是一次一人，慢慢过去。所以下句叫大家一个接一个走。

## 原文：教学例句 {#p.check.31.d}
> 牧人失羊，欲入林。邻人曰：“纵循迹至林口，夜黑，亦难辨群羊。”
译文：牧人丢了羊想进林子。邻人说，即使顺着踪迹到林口，天黑了也难辨清羊群。

## 单选：邻人说“纵循迹至林口”时，人当真已到林口了吗？ {#q.check.31.4}
考点：skill.syntax.8.2
语境：p.check.31.d

- [ ] 已经回来了，正讲述经过
  理由：“纵循迹至林口”是“即使找到了林口”，并未说人已经从那里回来。
- [x] 文中只提出这种设想，没有交代已到达
- [ ] 已经到了，所以能数清所有羊
  理由：“难辨”与数清相反。

提示：先听“纵”怎样设想，再听“亦难辨”担心什么。
解析：邻人只是说，就算能追到林口，天黑也辨不清羊。他没有说自己已走到那里。

## 原文：教学例句 {#p.check.31.e}
> 主簿欲今日发粟。吏曰：“仓固满，然籍未定，且受粟者未集，宜少待。”
译文：主簿想今天发粮。官吏说：“仓里的粮固然充足，可名册还没定，领粮的人也没来齐，还是稍等一下。”

## 单选：官吏主张晚一点发粟。名册还没定之外，又有什么不便？ {#q.check.31.5}
考点：skill.syntax.9.1
语境：p.check.31.e

- [ ] 主簿决定取消发放
  理由：“宜少待”只是主张推迟。
- [x] 领粮人尚未到齐
- [ ] 仓里已经没有粮食
  理由：开头说“仓固满”。

提示：他先用“然”谈名册，再用哪个字添了一条？
解析：“且受粟者未集”是第二个理由：要领粟的人也还没有来齐。

## 原文：教学例句 {#p.check.31.f}
> 邑人疑坏堤者为水獭。夜伏而候，乃群牛争饮，践土使崩。
译文：当地人疑是水獭破坏河堤。夜里埋伏等候，才发现原来是牛群争饮，踩踏泥土使堤岸崩落。

## 找原文证据：水獭果真弄坏了堤吗？当地人守了一夜，哪几个字写他们看见了什么？ {#q.check.31.6}
考点：skill.syntax.9.4
语境：p.check.31.f

- [ ] 夜伏而候
  理由：夜伏是他们怎样守候。要说清查到了什么，还需读他们看见的事。
- [ ] 邑人疑
  理由：那是起初猜水獭所为，没说他们后来亲眼见到了什么。
- [x] 群牛争饮，践土使崩

提示：“疑”只说起初怎么猜；看看“乃”后面是谁在做什么。
解析：他们看见的是牛群争饮，践土而崩，才知道错怪了水獭。
