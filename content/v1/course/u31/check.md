# 检查：依语境分清假定、让步与结论 {#check.31}

## 原文：教学例句 {#p.check.31.a}
> 村人将凿渠，约曰：“若泉自石下出，便引之入田；否则罢役。”次日方试掘。
译文：村人将挖水渠，约定若石下有泉就引入田中，否则停工。第二天才试着挖。

## 单选：在试掘以前，哪件事仍未明？ {#q.check.31.1}
考点：skill.syntax.7.1
语境：p.check.31.a

- [ ] 没有泉时应怎样处置
  理由：“否则罢役”已经说明。
- [x] 石下究竟有没有泉
- [ ] 村人是否订了约定
  理由：“约曰”已写出约定。

提示：把计划和待检验的前提分开。
解析：两个方案都已提出，掘地才知道走哪一个。

## 原文：教学例句 {#p.check.31.b}
> 使者辞车曰：“苟得一马，今日可至县。”主人入厩求之。
译文：使者谢绝车子说，只要得到一匹马，今天就能到县里。主人进马厩里寻找。

## 找原文证据：哪处是使者作出“今日可至县”判断所凭的假定？ {#q.check.31.2}
考点：skill.syntax.7.2
语境：p.check.31.b

- [ ] 主人入厩
  理由：这是主人听完以后的动作。
- [x] 得一马
- [ ] 辞车
  理由：这是已经发生的行动。

提示：“可至”以前，他说还需要什么？
解析：“苟”标出取得坐骑这个条件。

## 原文：教学例句 {#p.check.31.c}
> 客见竹桥窄而犹坚，曰：“桥虽窄，一人徐过无妨。”乃使众相次而度。
译文：客人看见竹桥窄却还结实，说桥虽然窄，一人慢慢过并无妨碍。于是让众人依次过桥。

## 单选：说话人既承认桥窄，又主张怎样？ {#q.check.31.3}
考点：skill.syntax.8.1
语境：p.check.31.c

- [x] 限制过桥方式，每人慢慢走
- [ ] 众人并行就不会拥挤
  理由：“相次”是一个接着一个。
- [ ] 桥窄，所以谁也不能上桥
  理由：“一人徐过无妨”仍许通行。

提示：比较“虽窄”和“一人徐过”。
解析：承认窄，保留在限定条件下可过的判断。

## 原文：教学例句 {#p.check.31.d}
> 牧人失羊，欲入林。邻人曰：“纵循迹至林口，夜黑，亦难辨群羊。”
译文：牧人丢了羊想进林子。邻人说，即使顺着踪迹到林口，天黑了也难辨清羊群。

## 单选：邻人是否已经跟到林口？ {#q.check.31.4}
考点：skill.syntax.8.2
语境：p.check.31.d

- [ ] 已经回来了，正讲述经过
  理由：“纵”引出的是设想中的一步。
- [x] 文中只提出这种设想，没有交代已到达
- [ ] 已经到了，所以能数清所有羊
  理由：“难辨”与数清相反。

提示：看“亦难辨”之前让出了什么可能。
解析：邻人把追到林口作为有利设想，仍指出黑夜的限制。

## 原文：教学例句 {#p.check.31.e}
> 主簿欲今日发粟。吏曰：“仓固满，然籍未定，且受粟者未集，宜少待。”
译文：主簿想今天发粮。官吏说，仓里固然满，但是名册未定，况且领粮的人还没到齐，应该稍等。

## 单选：名册问题之外，吏又补充哪条理由？ {#q.check.31.5}
考点：skill.syntax.9.1
语境：p.check.31.e

- [ ] 主簿决定取消发放
  理由：“宜少待”只是主张推迟。
- [x] 领粮人尚未到齐
- [ ] 仓里已经没有粮食
  理由：开头说“仓固满”。

提示：找“且”后另提的情况。
解析：“然”转向实际困难，“且”又列出第二个等待的理由。

## 原文：教学例句 {#p.check.31.f}
> 邑人疑坏堤者为水獭。夜伏而候，乃群牛争饮，践土使崩。
译文：当地人疑是水獭破坏河堤。夜里埋伏等候，才发现原来是牛群争饮，踩踏泥土使堤岸崩落。

## 找原文证据：找出澄清先前猜测的行为证据。 {#q.check.31.6}
考点：skill.syntax.9.4
语境：p.check.31.f

- [ ] 夜伏而候
  理由：这是取得证据的方法。
- [ ] 邑人疑
  理由：怀疑并非查明。
- [x] 群牛争饮，践土使崩

提示：看“乃”引出的真实过程。
解析：观察到群牛争饮并踩崩堤岸，才排除先前对水獭的怀疑。
