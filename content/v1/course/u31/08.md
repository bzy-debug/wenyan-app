# 课文：虽与纵：承认一件事，仍坚持什么 {#syntax.8}
简介：辨清说话人承认的事实、暂且接受的说法和始终不改的结论。

## 正文

### 让步保留了哪一句
读“道虽远，吾必往”，最有用的动作是把“道远”和“必往”分列。前者看来足以劝退人，后者却仍然成立。“虽”可以承认眼前的事实，也可以暂且接过别人的说法；不能只凭一个“虽”就断言事情实有。

“纵”引出让步时，可以把设想推进一步：“纵添一舟，亦不足载众。”并没有交代船已经添来。找“亦”“犹”“必”等字，看哪个判断不因前件而变。

## 知识点：虽 {#skill.syntax.8.1}
义项：让出一层再申明判断
领域：虚词
要诀：找保留下来的后件
讲解：承认一个情况或说法，随后指出仍成立的事实、决定或评价。
例句：p.syntax.8.a

## 知识点：纵 {#skill.syntax.8.2}
义项：即使出现所设想的情形
领域：虚词
要诀：设想更进一步仍如何
讲解：“纵”放在假设性让步前件，后面表达即使如此也不变的结论。
例句：p.syntax.8.c

## 原文：古籍引文 {#p.syntax.8.a}
> 与朋友交，言而有信。虽曰未学，吾必谓之学矣。
译文：和朋友交往，说话守信用。即使说此人没有学过，我也一定说他已经学过了。
出处：《论语·学而》一之七节选

## 单选：“虽曰未学”在这段评价中有什么作用？ {#q.syntax.8.1}
考点：skill.syntax.8.1
语境：p.syntax.8.a

- [x] 暂且承认“未学”的说法，再给出自己的评价
- [ ] 确认对方从未读过书并表示同意
  理由：后面“吾必谓之学矣”另作评价。
- [ ] 说明先前不守信的原因
  理由：开头说“言而有信”。

提示：比较“曰”的说法和“吾必谓”的判断。
解析：“虽”让出别人可能提出的一层，子夏仍从行为来评判。

## 找原文证据：找出说话人最终坚持的判断。 {#q.syntax.8.2}
考点：skill.syntax.8.1
语境：p.syntax.8.a

- [ ] 虽曰未学
  理由：这里暂且接过一种说法。
- [ ] 言而有信
  理由：守信是给出这个评价的依据之一。
- [x] 吾必谓之学矣

提示：注意带有“必”的话。
解析：“必谓之学”才是评价落点。

## 原文：教学例句 {#p.syntax.8.b}
> 使者至城下，道虽远，所持书犹完。吏取而验其封。
译文：使者来到城下。道路虽远，他带的信仍完好。官吏接过来检验封口。

## 单选：让步之后作者特别指出什么？ {#q.syntax.8.3}
考点：skill.syntax.8.1
语境：p.syntax.8.b

- [ ] 只要走远，信件就会完好
  理由：远路不是保存信件的条件。
- [ ] 因为道路长，信件已毁
  理由：“犹完”与毁坏相反。
- [x] 经历长途，信件仍完好

提示：把“犹”读成“仍然”。
解析：路远带来损坏的可能，作者特写实物仍完好。

## 找原文证据：哪一处是本句已承认的困难？ {#q.syntax.8.4}
考点：skill.syntax.8.1
语境：p.syntax.8.b

- [ ] 犹完
  理由：这是不受困难改变的结果。
- [ ] 使者至城下
  理由：到城下是已经达到的地点。
- [x] 道虽远

提示：“虽”标出前件。
解析：旅途遥远是已经历的困难，并未损坏信件。

## 原文：教学例句 {#p.syntax.8.c}
> 客欲夜发。舟人指水曰：“纵月复明，水急亦不可渡。”客乃止。
译文：客人想夜里出发。船夫说，即便月亮重新明亮，水流湍急也不能渡河。客人才停下。

## 单选：船夫的论证允许哪种设想？ {#q.syntax.8.5}
考点：skill.syntax.8.2
语境：p.syntax.8.c

- [x] 即使照明改善，急流仍阻渡
- [ ] 水势已缓，月亮才明
  理由：原文仍说“水急”。
- [ ] 月亮已出来，所以可以渡
  理由：“纵”是假设，“不可渡”才是结论。

提示：哪个问题即使月明也没有解决？
解析：船夫把月明当作有利假设，指出水急这个困难仍在。

## 找原文证据：排除天色因素后，不能渡河的直接依据是哪两个字？ {#q.syntax.8.6}
考点：skill.syntax.8.2
语境：p.syntax.8.c

- [x] 水急
- [ ] 客乃止
  理由：停下是听劝的结果。
- [ ] 月复明
  理由：月明是让步中设想的有利条件。

提示：找客观水势。
解析：水流过急不会随月色立即改变。

## 原文：教学例句 {#p.syntax.8.d}
> 仓吏计粟曰：“纵明日又得十斛，犹不足供三月。”乃请先省宴饮。
译文：仓吏计算存粮，说即使明天再得十斛，仍不够三个月用。于是请求先节省宴饮开支。

## 单选：校核账簿时，能否把十斛列为已经入仓？ {#q.syntax.8.7}
考点：skill.syntax.8.2
语境：p.syntax.8.d

- [ ] 不能，因为官吏拒收粮食
  理由：原文是估算，不是拒绝收粮。
- [ ] 能，“又得”说明昨日已经收到
  理由：“纵明日”明确是假设将来的收入。
- [x] 不能，这是为估算所作的有利假设

提示：“纵”要连着哪一天读？
解析：“纵明日又得”还没有发生；仓吏故意把收入估得有利一些。

## 排序：按仓吏说明为何应节省的思路排列。 {#q.syntax.8.8}
考点：skill.syntax.8.2
语境：p.syntax.8.d

- [3] 提出节省宴饮
- [1] 假设明日多得十斛
- [2] 估算仍难供三月

提示：先看“纵”，再看“犹”和“乃”。
解析：假设收入增加仍不足，由此提出节用。
