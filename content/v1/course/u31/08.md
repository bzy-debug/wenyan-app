# 课文：虽与纵：承认一件事，仍坚持什么 {#syntax.8}
简介：“虽远，必往”里的路可以当真很远；“纵添一舟”里的船，却还未必添到了。

## 正文

### 路远，为什么还要去？

“道虽远，吾必往。”路远是足以劝人回头的理由，说话人先承认这一点，仍然决定去。换个场合，“虽”后面也可以只是把别人可能说的话姑且接过来。是不是真有那件事，还得问上下文。

“纵添一舟，亦不足载众。”船还没添，说话人不妨把事情往好处想一步：就算多一条，也装不下。在这种句子里找“亦”“犹”“必”，往往就能读出他始终坚持哪一句。

## 知识点：虽 {#skill.syntax.8.1}
义项：虽然；即使别人这样说
领域：虚词
要诀：先读“虽”，再找说者自己要坚持哪句话
讲解：“虽”可承认眼前的事实，也可姑且接过一种说法。说者真正要下的判断，常在它之后。
例句：p.syntax.8.a

## 知识点：纵 {#skill.syntax.8.2}
义项：纵使，即便
领域：虚词
要诀：就算事情往好处走，什么仍旧不变？
讲解：“纵添一舟”先让你想象有了船。是不是已经来船了，还得看后面写的事。
例句：p.syntax.8.c

## 原文：古籍引文 {#p.syntax.8.a}
> 与朋友交，言而有信。虽曰未学，吾必谓之学矣。
译文：与朋友交往，说过的话能算数。就是有人说这样的人没学过，我也一定说他学过了。

## 单选：子夏说“虽曰未学”，是真的同意别人对这个人的评价吗？ {#q.syntax.8.1}
考点：skill.syntax.8.1
语境：p.syntax.8.a

- [x] 暂且承认“未学”的说法，再给出自己的评价
- [ ] 确认对方从未读过书并表示同意
  理由：后面“吾必谓之学矣”另作评价。
- [ ] 说明先前不守信的原因
  理由：开头说“言而有信”。

提示：把“虽曰”里别人的话，同“吾必谓”里子夏自己的话分开。
解析：就算有人说此人没学过，子夏看他待朋友守信，仍要说他学过。这里先接过一种说法，再发自己的议论。

## 找原文证据：子夏最后认定这个人怎样？请找出他自己的原话。 {#q.syntax.8.2}
考点：skill.syntax.8.1
语境：p.syntax.8.a

- [ ] 虽曰未学
  理由：“虽曰”是说，就算有人这样讲。子夏自己的判断在后面。
- [ ] 言而有信
  理由：守信是给出这个评价的依据之一。
- [x] 吾必谓之学矣

提示：哪一句的主语是“吾”？
解析：“吾必谓之学矣”是子夏坚持的看法，前面的守信是他这样评价的根据。

## 原文：教学例句 {#p.syntax.8.b}
> 使者至城下，道虽远，所持书犹完。吏取而验其封。
译文：使者来到城下。道路虽远，他带的信仍完好。官吏接过来检验封口。

## 单选：走了很长的路以后，使者手里的信怎样了？ {#q.syntax.8.3}
考点：skill.syntax.8.1
语境：p.syntax.8.b

- [ ] 只要走远，信件就会完好
  理由：远路不是保存信件的条件。
- [ ] 因为道路长，信件已毁
  理由：“完”是完好，“犹”又加了一层“仍旧”，不能读成毁了。
- [x] 经历长途，信件仍完好

提示：“犹”可试着讲“还”。
解析：路远本会叫人担心封书有损；到城下时，它却仍旧完好。

## 找原文证据：这一路使者经历了什么不便？哪几个字先承认了这一点？ {#q.syntax.8.4}
考点：skill.syntax.8.1
语境：p.syntax.8.b

- [ ] 犹完
  理由：“犹完”写的是信件如今怎样，前面才写来路有多远。
- [ ] 使者至城下
  理由：城下是使者抵达的地方，路好不好走要看接下来的“道”。
- [x] 道虽远

提示：先读到“虽”，暂且别看写封书情形的后半句。
解析：“道虽远”说的是旅途。使者真走过这段远路，信也确实安全到了。

## 原文：教学例句 {#p.syntax.8.c}
> 客欲夜发。舟人指水曰：“纵月复明，水急亦不可渡。”客乃止。
译文：客人想趁夜出发。船夫指着水说：“哪怕月亮又照亮了，水这么急，还是渡不得。”客人这才作罢。

## 单选：船夫说，就算什么情况好转，今晚还是不能渡？ {#q.syntax.8.5}
考点：skill.syntax.8.2
语境：p.syntax.8.c

- [x] 即使照明改善，急流仍阻渡
- [ ] 水势已缓，月亮才明
  理由：原文仍说“水急”。
- [ ] 月亮已出来，所以可以渡
  理由：“纵”是假设，“不可渡”才是结论。

提示：天上与水面各有一件事，哪一件才在“纵”后？
解析：“纵月复明”姑且设想月色转好，江水却还很急，所以船夫不肯渡。

## 找原文证据：假定月亮恢复明亮，还有什么拦着船？请找两个字。 {#q.syntax.8.6}
考点：skill.syntax.8.2
语境：p.syntax.8.c

- [x] 水急
- [ ] 客乃止
  理由：“客乃止”说船夫讲完以后客人怎样做，还没有点出渡不得的缘由。
- [ ] 月复明
  理由：“纵月复明”是先假设月色变好了。船夫真正顾虑的在水上。

提示：留在船夫的话里，找写水势的地方。
解析：“水急”才是即使月明也解不了的难处，“客乃止”已经是客人听劝的结果。

## 原文：教学例句 {#p.syntax.8.d}
> 仓吏计粟曰：“纵明日又得十斛，犹不足供三月。”乃请先省宴饮。
译文：仓吏计算存粮，说即使明天再得十斛，仍不够三个月用。于是请求先节省宴饮开支。

## 单选：记今天的仓账，能把明天可能得到的十斛算进去吗？ {#q.syntax.8.7}
考点：skill.syntax.8.2
语境：p.syntax.8.d

- [ ] 不能，因为官吏拒收粮食
  理由：仓吏是在把明天可能多进的粮也算在内，可没说有粮也不收。
- [ ] 能，“又得”说明昨日已经收到
  理由：“纵明日”明确是假设将来的收入。
- [x] 不能，这是为估算所作的有利假设

提示：“纵”跟哪一天连着？
解析：仓吏把账往宽处算：纵使明天再得十斛，也供不了三个月。多出的十斛还没有入仓。

## 排序：从估量存粮到请求节用，仓吏的话分几步说？ {#q.syntax.8.8}
考点：skill.syntax.8.2
语境：p.syntax.8.d

- [3] 提出节省宴饮
- [1] 假设明日多得十斛
- [2] 估算仍难供三月

提示：“纵”领出设想，“犹”说是否够用，最后才有“乃请”。
解析：先算上可能多得的十斛，三个月仍然不够，因此才请求在宴饮上省些。
