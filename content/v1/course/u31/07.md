# 课文：若与苟：事情已经发生了吗 {#syntax.7}
简介：一句承诺可以很肯定，前提却未必已经实现。

## 正文

### 把前后两件事分开
守渡的人说“若水落，当渡客”。他承诺的是**水落以后渡客**。客人今天是否已渡河、明天河水是否一定会退，这句话都没有交代。把前件记在“待核实”一栏，结果记在“前件成立后”一栏。

“苟”也可引出假设，特别是说话人认为**只要这一点成立，后面就说得通**时。读“苟正其身矣”，要把从政的议论接在“能端正自己”的条件之后。注意“苟安”的“苟”（姑且、草率地）另有用法。

## 知识点：若 {#skill.syntax.7.1}
义项：提出尚待核实的条件
领域：虚词
要诀：先问“要是怎样”
讲解：“若”带出一件假定的事，后句才交代在这种情况下会怎样。
例句：p.syntax.7.a

## 知识点：苟 {#skill.syntax.7.2}
义项：假定足以支持结论的条件
领域：虚词
要诀：试读为“如果确能……”
讲解：说话人把一项条件提出来，再推出自己的判断。不必据此断言条件已经成立。
例句：p.syntax.7.b

## 原文：教学例句 {#p.syntax.7.a}
> 守津者与客约曰：“若明旦水落，吾乃济君。”客宿津旁。
译文：守渡的人和客人约好，如果明早水退了，才送他过河。客人在渡口旁住下。

## 单选：当晚已经可以确定哪一件事？ {#q.syntax.7.1}
考点：skill.syntax.7.1
语境：p.syntax.7.a

- [ ] 明早河水必定下降
  理由：“若”把水落放在假设中。
- [ ] 客人已于当晚渡河
  理由：末句说他宿在渡口旁。
- [x] 双方约定了送渡的条件

提示：分清“约定”和“约定的条件已经实现”。
解析：双方已经立约；水落与送渡都尚在以后。

## 找原文证据：指出明早是否开船所取决的条件。 {#q.syntax.7.2}
考点：skill.syntax.7.1
语境：p.syntax.7.a

- [ ] 客宿津旁
  理由：这是当晚客人的去处。
- [ ] 吾乃济君
  理由：这是条件成立后的安排。
- [x] 明旦水落

提示：找“若”所带的那部分。
解析：开船要看明早水是否退下。

## 原文：古籍引文 {#p.syntax.7.b}
> 苟正其身矣，于从政乎何有？不能正其身，如正人何？
译文：如果自己真正端正了，从政还有什么困难？不能端正自己，又怎样端正别人？

## 单选：开头的“苟”要求先具备什么？ {#q.syntax.7.3}
考点：skill.syntax.7.2
语境：p.syntax.7.b

- [ ] 官职已经确定
  理由：“从政”是下文议论的事。
- [x] 自身言行能够端正
- [ ] 众人已经听从政令
  理由：此处先谈自己。

提示：看“其身”是谁的身体和行为。
解析：“苟正其身矣”提出条件，后文才议论为政。

## 单选：有人把第一句改成“此人已经端正了自己”。少了什么？ {#q.syntax.7.4}
考点：skill.syntax.7.2
语境：p.syntax.7.b

- [ ] 百姓变化的经过
  理由：原文没有叙述百姓如何改变。
- [ ] 具体任职的年月
  理由：原文没有任职年月。
- [x] 由假设引出议论的关系

提示：后句是在讲一个道理，还是记一件已经发生的事？
解析：“苟”让读者先假定自正，再考虑为政之难易。

## 原文：教学例句 {#p.syntax.7.c}
> 匠谓徒曰：“若石足，则砌岸；若不足，姑以木御水。”徒往数石。
译文：工匠说，如果石料足就砌岸，不足就暂且用木料挡水。徒弟去清点石料。

## 单选：徒弟清点石料，是要决定什么？ {#q.syntax.7.5}
考点：skill.syntax.7.1
语境：p.syntax.7.c

- [ ] 谁来代替师傅
  理由：句中没有更换工匠的安排。
- [x] 采用师傅所说的哪一种办法
- [ ] 石料究竟运往哪座城
  理由：两种安排都围绕岸边。

提示：把两个“若”后的情况并排看。
解析：“足”和“不足”各接一套安排，数过才知道用哪套。

## 排序：按石料不足时的处置逻辑排列。 {#q.syntax.7.6}
考点：skill.syntax.7.1
语境：p.syntax.7.c

- [3] 暂用木料
- [1] 清点石料
- [2] 判明不足

提示：想到“若不足”是分支，而不是最终办法。
解析：先清点，再判断是否足够，若不足才用木挡水。

## 原文：教学例句 {#p.syntax.7.d}
> 圃人谓主人曰：“苟此沟通，积水可泄。”主人使人疏沟，未竟而日暮。
译文：园丁说，只要这条沟畅通，积水就能排掉。主人派人疏沟，尚未做完天就黑了。

## 找原文证据：园丁认为积水能排走，凭什么条件？ {#q.syntax.7.7}
考点：skill.syntax.7.2
语境：p.syntax.7.d

- [ ] 主人使人
  理由：这是主人采取的行动。
- [x] 此沟通
- [ ] 日暮
  理由：天黑只交代时间。

提示：从“苟”后找让积水有出口的状态。
解析：园丁把沟渠畅通当成积水可排的条件。

## 单选：截至日暮，原文支持哪种判断？ {#q.syntax.7.8}
考点：skill.syntax.7.2
语境：p.syntax.7.d

- [ ] 园丁已经宣布积水排尽
  理由：“可泄”说的是可行。
- [x] 已开始疏沟，积水是否排尽还不知道
- [ ] 主人断定这条沟永远不通
  理由：他已派人疏沟。

提示：“未竟”限制了读者可以断定的事。
解析：疏沟尚未完工，不能把“苟……可……”当作排水的实录。
