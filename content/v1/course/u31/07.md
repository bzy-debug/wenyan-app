# 课文：若与苟：事情已经发生了吗 {#syntax.7}
简介：读出“等水退了我送你”这一类许诺：渡口边已说定什么，还在等什么？

## 正文

### 船夫答应了，客人渡河了吗？

守渡的人说“若水落，当渡客”。他已经答应送客，河水却未必已经退下。把“若”读成“要是”，就听得出说话人留着一个条件：要是水退了，才有后面的渡客。至于明早的水会怎样，要到明早才知道。

“苟正其身矣”也请人先想一想：假如能端正自己，从政又有什么难处？句中是“只要”的意思。遇到另一个词“苟安”，那里的“苟”是姑且或草率，又该另讲。

## 知识点：若 {#skill.syntax.7.1}
义项：要是，如果
领域：虚词
要诀：“若”之后，哪件事还说不准？
讲解：“若水落”先说水退这个条件，后面才说水退了准备怎么做。
例句：p.syntax.7.a

## 知识点：苟 {#skill.syntax.7.2}
义项：如果确能如此，只要
领域：虚词
要诀：接着“苟”读出说者要先假定的事
讲解：“苟正其身”请人先假定能端正自己。就算后面的结论说得很肯定，这个条件仍是暂且假定的。
例句：p.syntax.7.b

## 原文：教学例句 {#p.syntax.7.a}
> 守津者与客约曰：“若明旦水落，吾乃济君。”客宿津旁。
译文：船夫跟客人约定：“明早水要是退了，我就送你过河。”客人留宿在渡口旁。

## 单选：客人当晚睡在津旁。到这时，两人已经说定了什么？ {#q.syntax.7.1}
考点：skill.syntax.7.1
语境：p.syntax.7.a

- [ ] 明早河水必定下降
  理由：船夫用的是“若”，没有说河水明早一定会退。
- [ ] 客人已于当晚渡河
  理由：末句说他宿在渡口旁。
- [x] 双方约定了送渡的条件

提示：回看守渡者的话，哪件事还要等到“若明旦”才知道？
解析：立约在当晚。明早是否水落，落了是否送客过河，还都在后头。

## 找原文证据：舟人明早要看什么才决定开船？请找出原话。 {#q.syntax.7.2}
考点：skill.syntax.7.1
语境：p.syntax.7.a

- [ ] 客宿津旁
  理由：“客宿津旁”只能告诉你他晚上住在哪儿。
- [ ] 吾乃济君
  理由：这是船夫预备怎么做。哪件事得先发生，还要往前读。
- [x] 明旦水落

提示：从“若”往下读，先别读到“吾乃”。
解析：“明旦水落”是要等的条件，“吾乃济君”才是条件满足后的安排。

## 原文：古籍引文 {#p.syntax.7.b}
> 苟正其身矣，于从政乎何有？不能正其身，如正人何？
译文：如果自己真正端正了，从政还有什么困难？不能端正自己，又怎样端正别人？

## 单选：把“苟”念成“如果”，孔子请人先想哪一个条件？ {#q.syntax.7.3}
考点：skill.syntax.7.2
语境：p.syntax.7.b

- [ ] 官职已经确定
  理由：读完“苟正其身”才谈到从政，不是已有官职才来端正自己。
- [x] 自身言行能够端正
- [ ] 众人已经听从政令
  理由：“其身”指为政者本人，众人如何还没有谈到。

提示：“其身”指自己还是别人？
解析：能端正自己，再来谈从政。下句反过来问，自己都不能端正，要怎样端正别人？

## 单选：若改成“此人已经端正了自己”，便把孔子的话读成什么了？原句少了哪一层？ {#q.syntax.7.4}
考点：skill.syntax.7.2
语境：p.syntax.7.b

- [ ] 百姓变化的经过
  理由：原文没有叙述百姓如何改变。
- [ ] 具体任职的年月
  理由：原文没有任职年月。
- [x] 由假设引出议论的关系

提示：读读后面的发问：是在记一件往事，还是在推想一个道理？
解析：原句请人假定能端正自己，再往下想从政难不难。写成“已经”便把假设当成了事实。

## 原文：教学例句 {#p.syntax.7.c}
> 匠谓徒曰：“若石足，则砌岸；若不足，姑以木御水。”徒往数石。
译文：师傅告诉徒弟：“石料够，就砌河岸；要是不够，先用木料挡水。”徒弟便去清点石头。

## 单选：师傅说完，徒弟为什么还要去数石头？ {#q.syntax.7.5}
考点：skill.syntax.7.1
语境：p.syntax.7.c

- [ ] 谁来代替师傅
  理由：师傅让徒弟数石，是为定用什么挡水，未说要另换工匠。
- [x] 采用师傅所说的哪一种办法
- [ ] 石料究竟运往哪座城
  理由：无论用木还是用石，都是在说眼前这道岸怎样修。

提示：石料足与不足，各预备了什么办法？
解析：石够就砌岸，不够就先用木料。石头数过，才知道选哪一种。

## 排序：假如石料不够，从徒弟去清点到挡水，要依次怎样做？ {#q.syntax.7.6}
考点：skill.syntax.7.1
语境：p.syntax.7.c

- [3] 暂用木料
- [1] 清点石料
- [2] 判明不足

提示：得先弄清哪件事，才用上师傅的第二种办法？
解析：先数，再判断足不足。数出来不够，才暂用木料挡水。

## 原文：教学例句 {#p.syntax.7.d}
> 圃人谓主人曰：“苟此沟通，积水可泄。”主人使人疏沟，未竟而日暮。
译文：园丁说，只要这条沟畅通，积水就能排掉。主人派人疏沟，尚未做完天就黑了。

## 找原文证据：园丁说，积水能不能泄出去，要看哪一件事？ {#q.syntax.7.7}
考点：skill.syntax.7.2
语境：p.syntax.7.d

- [ ] 主人使人
  理由：这是主人采取的行动。
- [x] 此沟通
- [ ] 日暮
  理由：天黑只交代时间。

提示：“苟”后写沟得变成什么样？
解析：要“此沟通”，积水才有去路。派人疏沟是在设法让这个条件成真。

## 单选：天黑时，读者能说准什么？ {#q.syntax.7.8}
考点：skill.syntax.7.2
语境：p.syntax.7.d

- [ ] 园丁已经宣布积水排尽
  理由：“可泄”是水有望排掉，还没说已经排尽。
- [x] 已开始疏沟，积水是否排尽还不知道
- [ ] 主人断定这条沟永远不通
  理由：他已派人疏沟。

提示：“未竟”是说已经做完了，还是还在做？
解析：主人已叫人疏沟，可是天黑尚未完工。“可泄”也只说通了就能排水。
