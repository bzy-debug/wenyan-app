# 课文：“且”“然”“则”“乃”怎样连接两句话 {#syntax.9}
简介：同一个“且”能说“天快黑了”，也能再添一条理由。遇到且、然、则、乃，再听听下半句。

## 正文

### 这一字过后，话往哪里走？

“天且暮”的“且”说快要天黑；“路阻，且粮乏”是在路不通之外又添一层难处。“闻之以为然”的“然”是觉得对；要是接着有人说“然不可行”，这个“然”便把话转了个弯。

同样试读“水涨则舟浮”：前一句说水涨，后一句才说船怎样。有时事情依次发生，“乃”可以讲“接着”；有时先是“疑”，近前一看才知道猜错，“乃”就要用“原来是”的口气读。

## 知识点：且 {#skill.syntax.9.1}
义项：况且，又添一个理由
领域：虚词
要诀：除了先说的难处，后面还说了什么？
讲解：两个理由都能说明为什么要这样办，第二个理由前的“且”可读成“况且”。
例句：p.syntax.9.a

## 知识点：然 {#skill.syntax.9.2}
义项：可是，转过来说另一层情况
领域：虚词
要诀：听一听“然”后面有没有叫事情为难之处
讲解：乡人可以先承认北路很近，再用“然”说桥已坏。前面说的距离仍算数，走法却不能照旧。
例句：p.syntax.9.b

## 知识点：则 {#skill.syntax.9.3}
义项：就，由前面那种情形说到相应的结果
领域：虚词
要诀：读“则”时向前看，它接的是哪件事？
讲解：“则”把一种情况和一种结果接上；两句都有“则”，就各找各的前半句。
例句：p.syntax.9.c

## 知识点：乃 {#skill.syntax.9.4}
义项：原来是，查明时才发现
领域：虚词
要诀：先看“疑”什么，再看后来亲眼见到什么
讲解：本来以为是甲，拿灯或走近一看却是乙，这时“乃”写的是“原来是乙”。
例句：p.syntax.9.d

## 原文：教学例句 {#p.syntax.9.a}
> 吏议移仓。父老曰：“旧仓近市，且地高不水，何遽移之？”
译文：官吏商议搬仓。父老说：“旧仓离集市近，地势又高，不易遭水淹，何必急着搬呢？”

## 单选：父老不愿急着迁仓。说完靠近集市，“且”又给了什么理由？ {#q.syntax.9.1}
考点：skill.syntax.9.1
语境：p.syntax.9.a

- [ ] 指出靠近集市反而必受淹
  理由：父老说地势高，正是要说旧仓不易被淹。
- [x] 在靠近集市之外，再补充不易受淹的好处
- [ ] 预告仓房即将升高
  理由：“地高”说的是已有地势。

提示：靠近集市和不受水淹，都是留仓的好处吗？
解析：旧仓一近市，二处高地，不受水淹。“且”是在替不急迁仓再添一条理由。

## 原文：教学例句 {#p.syntax.9.b}
> 客言北径甚近。乡人曰：“诚近，然溪桥昨坏，今须由南。”
译文：客人说北路很近。乡人说，确实近，可是溪桥昨天坏了，今天得走南边。

## 找原文证据：乡人也承认北路近，究竟哪几个字使这条近路今天走不通？ {#q.syntax.9.2}
考点：skill.syntax.9.2
语境：p.syntax.9.b

- [ ] 今须由南
  理由：“今须由南”是决定绕行。找为什么绕，还须往前读一句。
- [ ] 诚近
  理由：乡人先承认近。
- [x] 溪桥昨坏

提示：“诚近”之后，乡人接着用“然”补了什么消息？
解析：“溪桥昨坏”是眼前的难处。近仍是近，只是今天要绕道走。

## 原文：古籍引文 {#p.syntax.9.c}
> 学而不思则罔，思而不学则殆。
译文：只学而不思考就会迷惘，只思考而不学习就会有危险。

## 单选：“学而不思”“思而不学”各会怎样？把“罔”和“殆”分别接上。 {#q.syntax.9.3}
考点：skill.syntax.9.3
语境：p.syntax.9.c

- [ ] 罔承接思而不学，殆承接学而不思
  理由：原文先说“学而不思”，紧接的是“则罔”；“则殆”在下一句。
- [ ] 罔和殆都是思考之后的两个步骤
  理由：一句讲只学不思，另一句讲只思不学。不能都说成思考后的步骤。
- [x] 罔承接学而不思，殆承接思而不学

提示：遇到每一个“则”，就在它左边找相应的那半句。
解析：“学而不思”接“罔”，“思而不学”接“殆”。两种情形各有相应的结果。

## 原文：教学例句 {#p.syntax.9.d}
> 吏夜闻院中有声，疑盗入。持灯视之，乃老犬曳断索过庭。
译文：官吏夜里听见院中有声，以为进了贼。拿灯一看，原来是老狗拖着断绳穿过院子。

## 单选：官吏拿灯一照，这句“乃老犬曳断索过庭”的“乃”是什么口气？ {#q.syntax.9.4}
考点：skill.syntax.9.4
语境：p.syntax.9.d

- [x] 原来是老狗经过
- [ ] 于是盗贼放出了老狗
  理由：“疑盗入”只是猜。灯下实际看见的，是老狗拖着断绳。
- [ ] 只有老狗能够看见盗贼
  理由：看的是拿灯的官吏。

提示：刚才只听到什么？现在又看清了什么？
解析：先疑心是贼，照见的却是拖着断绳的老狗，读作“原来是”最贴切。

## 原文：教学例句 {#p.syntax.9.e}
> 父谓子曰：“日且暮，且山中多雾，宜早返。”
译文：父亲说，天快黑了，况且山中多雾，应该早些回来。

## 单选：父亲一句话用了两次“且”，能都讲成“快要”吗？ {#q.syntax.9.5}
考点：skill.syntax.9.1
语境：p.syntax.9.e

- [ ] 两处都表示天色将暗
  理由：第二处引出的是山中多雾。
- [ ] 前一处表示转折，后一处说才起雾
  理由：父亲给出两个支持早归的理由。
- [x] 前一处说将要天黑，后一处另添多雾的理由

提示：分别念“日且暮”和“且山中多雾”。
解析：天快要黑了，是第一个“且”；山中又多雾，是第二个“且”。两个理由合起来，都劝孩子早归。

## 原文：教学例句 {#p.syntax.9.f}
> 徒曰：“此石可为碑。”师以为然，然石有罅，不堪久立。
译文：徒弟说这石头能做碑。师傅也觉得在理，只是石头有裂缝，立不了多久。

## 单选：“师以为然，然石有罅”里的两个“然”各怎样讲？ {#q.syntax.9.6}
考点：skill.syntax.9.2
语境：p.syntax.9.f

- [ ] 都表示“对”，师傅完全没有保留
  理由：师傅虽认为有理，也看出了石上的罅隙，所以才说不能久立。
- [x] 以为对；可是石头有裂缝
- [ ] 然而如此；于是裂缝消失
  理由：后句明确说“有罅”。

提示：前一处是师傅听了想法怎样评价，后一处要说石头有什么不足。
解析：师傅先说想法对，接着话锋一转：可是石头有裂缝。想法虽好，这块石头却不能久立。

## 原文：教学例句 {#p.syntax.9.g}
> 守堰者教徒曰：“水及朱线，则举闸；线犹露，则勿动。”徒视石，朱线尚明。
译文：看堰的人教徒弟，水到红线就提闸，线还露着就别动。徒弟看石头，红线还清楚可见。

## 单选：红线还看得清，徒弟现在该动闸门吗？ {#q.syntax.9.7}
考点：skill.syntax.9.3
语境：p.syntax.9.g

- [ ] 先提闸再画红线
  理由：红线本已画在石上。
- [ ] 立即提闸
  理由：提闸的条件是水淹到红线。
- [x] 保持闸门不动

提示：“尚明”更接近“水及朱线”，还是“线犹露”？
解析：石上的红线还露着，应照第二句“则勿动”去做。

## 原文：教学例句 {#p.syntax.9.h}
> 客初以山麓白者为积雪，近观之，乃一畦梨花也。
译文：客人起初把山脚的白色当作积雪，走近一看，原来是一畦梨花。

## 找原文证据：客人走近，才认出山脚那片白色究竟是什么。请指出原话。 {#q.syntax.9.8}
考点：skill.syntax.9.4
语境：p.syntax.9.h

- [ ] 山麓
  理由：山麓只是山脚这个地方。要找的是那里那片白色究竟是什么。
- [ ] 积雪
  理由：“积雪”是远望时的猜想，近看以后才发现看错了。
- [x] 一畦梨花

提示：先前以为是雪。再从“乃……也”中找他实际看见的。
解析：“一畦梨花”才是走近后的发现。“山麓”只说地点，“积雪”只是远望时的猜测。
