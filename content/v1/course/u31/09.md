# 课文：且、然、则、乃：给相邻两句接上线 {#syntax.9}
简介：从第二句回看第一句，判断是在补充理由、转向、推论，还是修正原来的猜测。

## 正文

### 先读两句的关系，再选现代说法
“天且暮”的“且”关乎时间；“路阻，且粮乏”的“且”另补理由。“闻之以为然”的“然”是“对”，“然不可行”放在反面的判断前则可译“可是”。

“水涨则舟浮”给出条件与结果。至于“乃”，既可以连接相继而起的动作，也可在“原以为……看清才知……”的语境中揭示与预料不同的事实。试把“接着”“原来”代入，核对是谁在何时才知道答案。

## 知识点：且 {#skill.syntax.9.1}
义项：追加同一方向的理由
领域：虚词
要诀：第二个理由能否单独支持结论
讲解：前后两项共同支持一个判断时，“且”可译作“况且、又”。
例句：p.syntax.9.a

## 知识点：然 {#skill.syntax.9.2}
义项：另提与前文相反或相限的事实
领域：虚词
要诀：转折前后分别成立什么
讲解：“然”放在后一分句的开头，可引出相反的情况，或指出前一建议的局限。
例句：p.syntax.9.b

## 知识点：则 {#skill.syntax.9.3}
义项：承接前提推出相应结果
领域：虚词
要诀：配对两边的条件和后果
讲解：前面给出做法或情形，后面的“则”引出与之对应的判断。
例句：p.syntax.9.c

## 知识点：乃 {#skill.syntax.9.4}
义项：在查明之后揭示与预料不同的事实
领域：虚词
要诀：比较先前所疑与后来所见
讲解：和“初疑”“近视”等线索连用时，可用“原来是”说出后来查明的情况。
例句：p.syntax.9.d

## 原文：教学例句 {#p.syntax.9.a}
> 吏议移仓。父老曰：“旧仓近市，且地高不水，何遽移之？”
译文：官吏议论迁仓。父老说，旧仓靠近集市，况且地势高不受水淹，何必急着搬？

## 单选：“且”后面的话怎样支持父老的意见？ {#q.syntax.9.1}
考点：skill.syntax.9.1
语境：p.syntax.9.a

- [ ] 指出靠近集市反而必受淹
  理由：这里说的是“不水”。
- [x] 在靠近集市之外，再补充不易受淹的好处
- [ ] 预告仓房即将升高
  理由：“地高”说的是已有地势。

提示：两个优点是否都在支持保留旧仓？
解析：“近市”便于交易，“地高”有利存粮，是同一主张的两条理由。

## 原文：教学例句 {#p.syntax.9.b}
> 客言北径甚近。乡人曰：“诚近，然溪桥昨坏，今须由南。”
译文：客人说北路很近。乡人说，确实近，可是溪桥昨天坏了，今天得走南边。

## 找原文证据：哪句话给“走近路”的建议加上了实际限制？ {#q.syntax.9.2}
考点：skill.syntax.9.2
语境：p.syntax.9.b

- [ ] 今须由南
  理由：这是考虑桥坏后提出的走法。
- [ ] 诚近
  理由：乡人先承认近。
- [x] 溪桥昨坏

提示：找出“然”带来的新情况。
解析：桥坏使北路眼下难以通行，距离近仍是事实。

## 原文：古籍引文 {#p.syntax.9.c}
> 学而不思则罔，思而不学则殆。
译文：只学而不思考就会迷惘，只思考而不学习就会有危险。

## 单选：“罔”和“殆”该怎样同前文配对？ {#q.syntax.9.3}
考点：skill.syntax.9.3
语境：p.syntax.9.c

- [ ] 罔承接思而不学，殆承接学而不思
  理由：两处“则”的后项被对调了。
- [ ] 罔和殆都是思考之后的两个步骤
  理由：两项各有独立前件。
- [x] 罔承接学而不思，殆承接思而不学

提示：每个“则”都先向左找它紧接的条件。
解析：两句并列，各自说明一类学思失衡会导致的结果。

## 原文：教学例句 {#p.syntax.9.d}
> 吏夜闻院中有声，疑盗入。持灯视之，乃老犬曳断索过庭。
译文：官吏夜里听见院中有声，以为进了贼。拿灯一看，原来是老狗拖着断绳穿过院子。

## 单选：“乃”在这里最适合怎么读？ {#q.syntax.9.4}
考点：skill.syntax.9.4
语境：p.syntax.9.d

- [x] 原来是老狗经过
- [ ] 于是盗贼放出了老狗
  理由：查明的事实取代了“盗入”的猜测。
- [ ] 只有老狗能够看见盗贼
  理由：看的是拿灯的官吏。

提示：注意“疑”和“视之”之间的信息差。
解析：先听声而疑盗，后照看才知道声源。

## 原文：教学例句 {#p.syntax.9.e}
> 父谓子曰：“日且暮，且山中多雾，宜早返。”
译文：父亲说，天快黑了，况且山中多雾，应该早些回来。

## 单选：两处“且”分别起什么作用？ {#q.syntax.9.5}
考点：skill.syntax.9.1
语境：p.syntax.9.e

- [ ] 两处都表示天色将暗
  理由：第二处引出的是山中多雾。
- [ ] 前一处表示转折，后一处说才起雾
  理由：父亲给出两个支持早归的理由。
- [x] 前一处说将要天黑，后一处另添多雾的理由

提示：逐个读“日……暮”和“……山中多雾”。
解析：同一个字先标示临近的时间，又连接并列的理由。

## 原文：教学例句 {#p.syntax.9.f}
> 徒曰：“此石可为碑。”师以为然，然石有罅，不堪久立。
译文：徒弟说这块石头可做碑。师傅认为这个想法有道理，可是石头有裂缝，不能久立。

## 单选：把两个“然”放回各自位置，怎样才通？ {#q.syntax.9.6}
考点：skill.syntax.9.2
语境：p.syntax.9.f

- [ ] 都表示“对”，师傅完全没有保留
  理由：“不堪久立”说明实际限制。
- [x] 以为对；可是石头有裂缝
- [ ] 然而如此；于是裂缝消失
  理由：后句明确说“有罅”。

提示：前一个在“以为”后，后一个带出新的不利情况。
解析：“以为然”评价想法，“然石有罅”把读者转向材料的缺陷。

## 原文：教学例句 {#p.syntax.9.g}
> 守堰者教徒曰：“水及朱线，则举闸；线犹露，则勿动。”徒视石，朱线尚明。
译文：看堰的人教徒弟，水到红线就提闸，线还露着就别动。徒弟看石头，红线还清楚可见。

## 单选：按照教给徒弟的办法，此刻该怎样？ {#q.syntax.9.7}
考点：skill.syntax.9.3
语境：p.syntax.9.g

- [ ] 先提闸再画红线
  理由：红线本已画在石上。
- [ ] 立即提闸
  理由：提闸的条件是水淹到红线。
- [x] 保持闸门不动

提示：把所见“尚明”与两种条件相配。
解析：红线尚露，对应“勿动”一支；“则”在两支中分别接出办法。

## 原文：教学例句 {#p.syntax.9.h}
> 客初以山麓白者为积雪，近观之，乃一畦梨花也。
译文：客人起初把山脚的白色当作积雪，走近一看，原来是一畦梨花。

## 找原文证据：点出走近之后查明的实物。 {#q.syntax.9.8}
考点：skill.syntax.9.4
语境：p.syntax.9.h

- [ ] 山麓
  理由：这是事物所在的位置。
- [ ] 积雪
  理由：这是起初的推测。
- [x] 一畦梨花

提示：把先前“以为”的东西和“乃……也”里的东西分开。
解析：“乃……也”揭示白色来自梨花。
