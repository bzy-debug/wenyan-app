# 课文：还珠与售椟：用一句话讲清故事与议论 {#l3.12}

简介：先分清买、卖、还的对象，再检查对故事的概括是谁作的。

## 正文

买卖故事中同时出现**珠**与**椟**。用两条线记去向：郑人留下什么？交还什么？“鬻”仍是卖，田鸠说“善卖椟”“未可谓善鬻珠”，故意以前后两个宾语划开实际效果与原来目的。

这段摘自田鸠答楚王的话。读到“今世之谈也”，他从货品移到言谈。概括可写为两句：先说买家做了什么，再说田鸠借此说明什么。别把说理者的评价写成郑人的自白。

## 知识点：还其珠 {#skill.l3.12.1}
义项：用买与还的相反方向识别买卖两方和物品去向
领域：实词
要诀：把每一件物品的起点和终点记下来
讲解：“还其珠”是郑人把珠归还给卖珠人。两个宾语分别是椟和珠，不能因合成一个典故而省略其去向。
例句：p.l3.12.a

## 知识点：此可谓 {#skill.l3.12.2}
义项：从评断句和话题切换区分故事人物与说理者
领域：篇章
要诀：先标出谁在讲故事，再找评语改说了什么
讲解：“此可谓”开始衡量卖物的实际效果，“今世之谈也”把议题转到言谈的文辞与用处。
例句：p.l3.12.a

## 原文：古籍引文 {#p.l3.12.a}
> 楚人有卖其珠于郑者，为木兰之柜，薰桂椒之椟，缀以珠玉，饰以玫瑰，辑以羽翠。郑人买其椟而还其珠。此可谓善卖椟矣，未可谓善鬻珠也。今世之谈也，皆道辩说文辞之言，人主览其文而忘有用。
译文：有个楚人到郑地卖珠。他制成木兰木的匣，用桂椒熏香，以珠玉、美石和翠羽装饰。郑人买下匣子，却把珠还了。田鸠评论说，这可算善卖匣子，算不得善卖珠子；当时的言谈喜欢讲究辞采，人主看重文辞而忘了有用的内容。

## 单选：“买其椟而还其珠”后，郑人留下的是哪一件？ {#q.l3.12.1}
考点：skill.l3.12.1
语境：p.l3.12.a

- [ ] 原要出售的那颗珠
  理由：“还其珠”将珠交回。
- [ ] 一块没有加工的木材
  理由：木材已被做成匣并加以装饰。
- [x] 用香料和珠玉等装饰的匣子

提示：分别给“买”“还”各找一个宾语。
解析：保留的是买来的椟，未保留的是卖方本想出售的珠。

## 找原文证据：哪一处先交代了楚人起初想卖什么？ {#q.l3.12.2}
考点：skill.l3.12.1
语境：p.l3.12.a

- [ ] 缀以珠玉
  理由：这是点缀匣子用的工艺。
- [ ] 为木兰之柜
  理由：这是制作容器。
- [x] 卖其珠于郑

提示：比较开头的目的和后来为目的作的准备。
解析：“卖其珠”早于制匣的细节，能与最后“还其珠”直接对照。

## 单选：在田鸠答楚王、讲买椟故事的这段话里，“未可谓善鬻珠也”属于哪一层？ {#q.l3.12.3}
考点：skill.l3.12.2
语境：p.l3.12.a

- [ ] 楚人事先告诉郑人不要买珠
  理由：楚人原想出售珠子。
- [ ] 郑人当场报出匣子的价钱
  理由：这一句没有价格，也没有引入郑人的话。
- [x] 田鸠衡量故事中卖珠人的成效

提示：看“可谓”是在做动作，还是在评价动作。
解析：说理者以实际成交的物品衡量成效，随后转到文辞与用处的关系。

## 单选：田鸠说“人主览其文而忘有用”，与买匣还珠怎样对应？ {#q.l3.12.4}
考点：skill.l3.12.2
语境：p.l3.12.a

- [ ] 凡用匣装珠都不准出售
  理由：评语没有提出商品规定。
- [ ] 君主把装饰珠玉全部退还给百姓
  理由：君主在另一个话题中，是听言者。
- [x] 只留意言辞之美而忽略其用，如同留下华匣却归还珠子

提示：找两边各自吸引眼光的外在一面。
解析：转入“今世之谈”后，田鸠已从交易说到听言，借先前故事作说明。

## 原文：教学例句 {#p.l3.12.b}
> 鲁人鬻历，绘四时花鸟于首。客悦其画，取画而还历。弟子曰：“市人争来，可谓善售矣。”师曰：“来者观画，历日无人问，何善之有？”
译文：有个鲁人卖历书，在卷首画了四时的花鸟。客人喜欢画，取画而把历书退回。弟子说市上的人争相前来，可以称得上善卖了。老师说来的人看画，历日无人过问，有什么善卖可言？

## 排序：按原文次序排出售物与退物的过程。 {#q.l3.12.5}
考点：skill.l3.12.1
语境：p.l3.12.b

- [1] 卖者给历书绘上花鸟
  理由：绘画是招来客人的前提。
- [3] 客人留下画并交还历书
  理由：所还的正是卖者本来要卖的东西。
- [2] 客人喜欢卷首的画
  理由：“悦其画”是随后行为的原因。

提示：先分清“历”与“画”各在谁手。
解析：先绘画，再悦画，最后取画还历；“还历”并不表示客人把画也一并还回。

## 单选：说“来者众，所以历书售出甚多”，缺了哪项信息？ {#q.l3.12.6}
考点：skill.l3.12.1
语境：p.l3.12.b

- [ ] 卖历者出自哪一国
  理由：开头已说鲁人，国别不能证明销量。
- [x] 买家是否实际留下历书
- [ ] 画上是不是花鸟
  理由：原文明说绘花鸟，画面不能证明历书成交。

提示：来观、取画、留下历书是不同动作。
解析：来者数与所售物不同；这里有取画还历的事例，老师又说历日无人问。

## 找原文证据：哪一处明确是弟子对售卖结果所下的判断？ {#q.l3.12.7}
考点：skill.l3.12.2
语境：p.l3.12.b

- [ ] 历日无人问
  理由：这是老师反驳时提出的情况。
- [x] 可谓善售矣
- [ ] 取画而还历
  理由：这是客人的行为。

提示：按“弟子曰”“师曰”区分说话人。
解析：弟子以人多为根据说善售，老师衡量的是原想卖的历书有没有人问。

## 单选：哪一句合适作既交代故事又保留评者分歧的摘要？ {#q.l3.12.8}
考点：skill.l3.12.2
语境：p.l3.12.b

- [ ] 众人都买了历书，师徒一致称赞卖者
  理由：两位评者意见不同，历也被退还。
- [ ] 画工责备客人毁坏了书，并赔了钱
  理由：没有损坏或赔钱的情节。
- [x] 客取画还历，弟子以人多称善，师则以历日无人问反驳

提示：摘要保留客人的动作及两名评者各自所据。
解析：短篇有物品去向和两种评价。若只写“生意很好”，便不知是谁持什么标准。
