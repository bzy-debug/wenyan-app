# 课文：还珠与售椟：用一句话讲清故事与议论 {#l3.12}

简介：郑人到底花钱买下了什么？讲清楚珠子和匣子各到了谁手里，再听田鸠为什么要把这个故事讲给楚王。

## 正文

楚人想卖珠子，为此精心装饰了匣子，也就是“椟”。到“买其椟而还其珠”，分两步读就很清楚：郑人买下的是匣子，交还卖家的才是珠子。同是“卖”，田鸠却分开评论“善卖椟”和“未可谓善鬻珠”。

这段话是田鸠在回答楚王。“今世之谈也”一起头，话题便从珍珠匣子转到言谈：听的人只顾文辞漂亮，却忘了话里有什么用处。把故事讲给别人时，先说郑人买了什么、还了什么，再说田鸠从中看出了什么。

## 知识点：还其珠 {#skill.l3.12.1}
义项：分清买下与交还的各是哪件东西、最后到了谁手里
领域：实词
要诀：读“买”和“还”时，各带上后面那件东西。
讲解：郑人原是买家。“买其椟”是把匣子留下，“还其珠”是把珠子交还给楚人。别只记得人来买珠，却没留心他带走的是什么。
例句：p.l3.12.a

## 知识点：此可谓 {#skill.l3.12.2}
义项：辨清哪些是故事里的人做的事，哪些是讲故事的人说的评语
领域：篇章
要诀：“此可谓”是谁在评说刚讲完的事？
讲解：田鸠先问算不算善卖珠子，接着说到“今世之谈”。从货物转到文辞的，始终是这位讲故事的人。
例句：p.l3.12.a

## 原文：古籍引文 {#p.l3.12.a}
> 楚人有卖其珠于郑者，为木兰之柜，薰桂椒之椟，缀以珠玉，饰以玫瑰，辑以羽翠。郑人买其椟而还其珠。此可谓善卖椟矣，未可谓善鬻珠也。今世之谈也，皆道辩说文辞之言，人主览其文而忘有用。
译文：有个楚人到郑地卖珠。他制成木兰木的匣，用桂椒熏香，以珠玉、美石和翠羽装饰。郑人买下匣子，却把珠还了。田鸠评论说，这可算善卖匣子，算不得善卖珠子；当时的言谈喜欢讲究辞采，人主看重文辞而忘了有用的内容。

## 单选：“买其椟而还其珠”后，郑人留下的是哪一件？ {#q.l3.12.1}
考点：skill.l3.12.1
语境：p.l3.12.a

- [ ] 原要出售的那颗珠
  理由：“还其珠”将珠交回。
- [ ] 一块没有加工的木材
  理由：木材已被做成匣并加以装饰。
- [x] 用香料和珠玉等装饰的匣子

提示：分别给“买”“还”各找一个宾语。
解析：“买其椟”留下匣子，“还其珠”归还珍珠。卖家原指望卖出去的那颗珠子，又回到了自己手中。

## 找原文证据：楚人刚出场时，哪几个字点明了他本想卖的东西？ {#q.l3.12.2}
考点：skill.l3.12.1
语境：p.l3.12.a

- [ ] 缀以珠玉
  理由：这是点缀匣子用的工艺。
- [ ] 为木兰之柜
  理由：这是制作容器。
- [x] 卖其珠于郑

提示：先来郑地卖什么，后来才想起做个漂亮匣子？
解析：先说“卖其珠于郑”，再写做匣子、饰匣子。原来为卖珠而备的匣子，最后倒成了郑人带走的东西。

## 单选：“未可谓善鬻珠也”是谁在评论什么？ {#q.l3.12.3}
考点：skill.l3.12.2
语境：p.l3.12.a

- [ ] 楚人事先告诉郑人不要买珠
  理由：楚人原想出售珠子。
- [ ] 郑人当场报出匣子的价钱
  理由：“善鬻珠”谈的是楚人会不会卖珠，没提价钱。
- [x] 田鸠衡量故事中卖珠人的成效

提示：楚人做了生意，谁在给楚王讲这笔生意？
解析：田鸠说楚人会卖匣子却算不得会卖珠子，评的是这笔买卖的结果。下面他才借这件事谈听人说话。

## 单选：田鸠说“人主览其文而忘有用”，与买匣还珠怎样对应？ {#q.l3.12.4}
考点：skill.l3.12.2
语境：p.l3.12.a

- [ ] 凡用匣装珠都不准出售
  理由：田鸠谈的是听话的人容易受漂亮文辞吸引，没有禁止用匣子装珠。
- [ ] 君主把装饰珠玉全部退还给百姓
  理由：这里的君主在听人进言，并没有拿珠玉同百姓做买卖。
- [x] 只留意言辞之美而忽略其用，如同留下华匣却归还珠子

提示：匣子吸引了买珠人的目光，漂亮的文辞又吸引了谁？
解析：郑人被好看的匣子吸引，留下匣子还了珠。田鸠借此说君主听言也可能只顾文辞好看，忘了话中有用的东西。

## 原文：教学例句 {#p.l3.12.b}
> 鲁人鬻历，绘四时花鸟于首。客悦其画，取画而还历。弟子曰：“市人争来，可谓善售矣。”师曰：“来者观画，历日无人问，何善之有？”
译文：有个鲁人卖历书，在卷首画了四时的花鸟。客人喜欢那幅画，留下画，把历书还了。弟子说：“市上的人都争着过来，可算是会卖了。”老师却说：“来客只看画，历书上的日子没人问，这怎么叫会卖？”

## 排序：从鲁人作画到客人交还历书，中间的事该怎么排？ {#q.l3.12.5}
考点：skill.l3.12.1
语境：p.l3.12.b

- [1] 卖者给历书绘上花鸟
  理由：绘画是招来客人的前提。
- [3] 客人留下画并交还历书
  理由：所还的正是卖者本来要卖的东西。
- [2] 客人喜欢卷首的画
  理由：“悦其画”是随后行为的原因。

提示：先找画是谁画的，再看谁被画吸引。
解析：卖家先在卷首画花鸟，客人看了喜欢，最后留下画却交还历书。还回去的只有历书。

## 单选：来的人多，为什么还不能说历书卖得多？ {#q.l3.12.6}
考点：skill.l3.12.1
语境：p.l3.12.b

- [ ] 卖历者出自哪一国
  理由：开头已说鲁人，国别不能证明销量。
- [x] 买家是否实际留下历书
- [ ] 画上是不是花鸟
  理由：原文明说绘花鸟，画面不能证明历书成交。

提示：来观、取画、留下历书是不同动作。
解析：客人可能只是来看画。至少眼前这位，拿走画却还了历书；老师还说“历日无人问”。

## 找原文证据：弟子觉得卖得好，原文里他是怎么说的？ {#q.l3.12.7}
考点：skill.l3.12.2
语境：p.l3.12.b

- [ ] 历日无人问
  理由：这是老师反驳时提出的情况。
- [x] 可谓善售矣
- [ ] 取画而还历
  理由：这是客人的行为。

提示：按“弟子曰”“师曰”区分说话人。
解析：“可谓善售矣”是弟子的话，他看重的是来人多。老师问的却是：真正要卖的历书，有人问吗？

## 单选：怎样简短地讲完这件事，还能听出师徒两人的分歧？ {#q.l3.12.8}
考点：skill.l3.12.2
语境：p.l3.12.b

- [ ] 众人都买了历书，师徒一致称赞卖者
  理由：两位评者意见不同，历也被退还。
- [ ] 画工责备客人毁坏了书，并赔了钱
  理由：没有损坏或赔钱的情节。
- [x] 客取画还历，弟子以人多称善，师则以历日无人问反驳

提示：先说客人拿走了什么，再把师徒各自的理由带上。
解析：客人只要画，弟子觉得来客多就是卖得好，老师却问历书有没有人要。若只说“生意很好”，就把师徒的分歧抹去了。
