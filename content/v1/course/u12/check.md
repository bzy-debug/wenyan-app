# 检查：从故事读到议论综合检查 {#check.12}

## 原文：教学例句 {#p.story.check.12.a}
> 邻有良医，病者千里来。医死，有人请其弟诊脉，曰：“兄能之，弟宜亦能。”弟谢曰：“吾业织，虽与兄同居，岂尝学脉哉？”病者乃别求医。
译文：邻地有良医，病人从千里外来。医生去世，有人请他的弟弟诊脉，说哥哥能做弟弟也应会。弟弟辞谢说自己以织布为业，虽与哥哥同住，却何曾学过诊脉。病人另求医生。
词注：诊脉：通过切脉察看病情。
  谢：辞谢，弟弟婉言推掉看病的请求。
  业织：以织布为业。

## 单选：“弟宜亦能”是谁的判断？ {#q.story.check.12.1}
考点：skill.story.l3.10.1
语境：p.story.check.12.a

- [ ] 从千里来的良医
  理由：医生已经去世。
- [x] 请弟弟诊脉的人
  理由：那个人依据兄弟关系作出判断，不是作者给弟弟作的介绍。
- [ ] 织布的弟弟
  理由：他恰好在辞谢，不肯妄称会诊脉。

提示：“有人请其弟”后面是谁在解释？
解析：那个人依据兄弟关系作出判断，不是作者给弟弟作的介绍。

## 单选：弟弟先说“虽与兄同居”，随即反问“岂尝学脉哉”。他承认哪件事，又拒绝别人拿它证明什么？ {#q.story.check.12.2}
考点：skill.story.l3.12.1
语境：p.story.check.12.a

- [x] 承认曾与哥哥一起生活，否认因此就学过诊脉
- [ ] 承认曾一起生活，也答应自己一定学过诊脉
  理由：后一句是反问，驳的是“住在一起就跟着学过”的推断。
- [ ] 否认曾经同住，想请病者替他找当年的老师
  理由：“虽”已让出同住这一层；反问针对学脉，没提寻找师傅。

提示：先给“虽”后的话打个勾，再读“岂……哉”驳掉哪一步。
解析：共同生活是弟弟亲自承认的事实。他用反问截断由“同居”推到“学脉”的想法，病者这才另求医生。

## 单选：按这段材料，能下怎样的判断？ {#q.story.check.12.3}
考点：skill.story.l3.12.2
语境：p.story.check.12.a

- [x] 弟弟自称未学诊脉，病人因此另寻医生
  理由：弟弟明言未学，结尾写另求，已经足够交代转折。
- [ ] 弟弟替病人看过，没能治好
  理由：他辞谢了，未写看诊。
- [ ] 医术绝不能由兄弟相传
  理由：一个人的经历不能推出这种通则。

提示：只收进有行动或答话作依据的内容。
解析：弟弟明言未学，结尾写另求，已经足够交代转折。

## 原文：教学例句 {#p.story.check.12.b}
> 山民治竹为笠，客劝鬻于海滨，曰：“彼多雨，笠当有售。”山民未往。记者曰：“售与不售，犹未可必。凡言利者，亦当察其地。”
译文：山民以竹制斗笠，客人劝他到海边卖，说那里多雨，斗笠应当有销路。山民还没去。记事人说卖不卖得掉尚不能断定，凡谈收益也应考察当地。
词注：治竹：加工竹料，此处是用来编斗笠。
  鬻：读 yù，卖。
  犹：还，记事人说目前还不能断定能否卖掉。

## 找原文证据：客人判断斗笠好卖，先提出什么当地情形？ {#q.story.check.12.4}
考点：skill.story.l3.11.1
语境：p.story.check.12.b

- [x] 彼多雨
  理由：客人认为雨多便需要斗笠，从这种需求推测销路。
- [ ] 山民治竹为笠
  理由：这说的是手艺。
- [ ] 山民未往
  理由：这是叙述者交代后来的情况。

提示：找客人谈当地的一句。
解析：客人认为雨多便需要斗笠，从这种需求推测销路。

## 单选：“笠当有售”写的是什么？ {#q.story.check.12.5}
考点：skill.story.l3.11.2
语境：p.story.check.12.b

- [ ] 记事人已经查得的实情
  理由：记事人反说还不能断定。
- [x] 客人对销路的预计
  理由：客人觉得应有销路，结尾仍为实际结果留了余地。
- [ ] 山民卖完斗笠的报告
  理由：“未往”说明还没到海滨。

提示：看“当”和“犹未可必”。
解析：客人觉得应有销路，结尾仍为实际结果留了余地。

## 找原文证据：哪里将一个卖笠的故事引向较一般的意见？ {#q.story.check.12.6}
考点：skill.story.l3.10.2
语境：p.story.check.12.b

- [ ] 山民未往
  理由：这只交代这一次的进展。
- [x] 凡言利者，亦当察其地
  理由：“凡”与“亦”把话推到一般谈收益的人，主张先察当地。
- [ ] 客劝鬻于海滨
  理由：这只是一人这一回的建议。

提示：谁不再只对山民的这一批笠说话？
解析：“凡”与“亦”把话推到一般谈收益的人，主张先察当地。
