# 检查：讲故事的人想说什么 {#check.12}

## 原文：古籍引文 {#p.check.12.a}
> 荆人有遗弓者，而不肯索，曰：“荆人遗之，荆人得之，又何索焉？”孔子闻之，曰：“去其荆而可矣。”老聃闻之，曰：“去其人而可矣。”故老聃则至公矣。
译文：有个荆人丢了弓，却不肯寻找，说荆人失去、荆人得到，何必去找？孔子听了说，去掉“荆”字就可以。老聃听说后又说，去掉“人”字就可以。讲故事的人因此赞叹，老聃真是公正到了极点。

## 单选：荆人说“荆人得之”，原文能确定什么？ {#q.check.12.1}
考点：skill.l3.12.1
语境：p.check.12.a

- [ ] 已记下拾弓人的姓名
  理由：这段没有具体的拾弓者。
- [x] 他认为即使别的荆人拾得也不必追索
- [ ] 孔子亲手将弓还给了失主
  理由：孔子听说这件事，评论的是荆人的话，没去拾弓。

提示：把弓的去向与失主设想的去向分开。
解析：丢弓是真的，失主不去找也是真的。他说别的荆人捡到又何妨，是在解释自己的打算；没说弓已经落入谁手。

## 找原文证据：三个人都说完后，哪一句是讲故事的人加上的评语？ {#q.check.12.2}
考点：skill.l3.12.2
语境：p.check.12.a

- [ ] 又何索焉
  理由：这是遗弓者自己给的理由。
- [ ] 去其荆而可矣
  理由：说“去其荆”的是孔子，后面还有老聃的说法。
- [x] 故老聃则至公矣

提示：读到三个“曰”结束之后再找。
解析：从“故”开始，是讲故事的人开口了。他说老聃“至公”，赞的是老聃的看法。

## 原文：教学例句 {#p.check.12.b}
> 乡人治陂，去岁小雨，水不逾堤。今年霖雨，仍守旧堤，水遂溢。童子破竹为管，测水所至，众始知水高几许。父初责其毁竹，见所记甚明，曰：“竹可更种，此记可传后来者。守堤不察水，犹医病不察疾而守故方也。”
译文：乡人修池塘，去年雨小，水没漫过堤岸。今年久雨仍沿用旧堤，水于是漫出。孩子剖竹制管，测量水到了哪里，众人才知道水有多高。父亲原来责怪他损坏竹子，看到记录清晰，便说竹子可以再种，测量记录可以留给后来的人。守堤不看水势，正像医病不问病情而沿用旧方。

## 单选：父亲把守堤和医病放在一起说，医者“不察疾”对应哪件事？ {#q.check.12.3}
考点：skill.l3.10.2
语境：p.check.12.b

- [ ] 孩子已经测得水有多高
  理由：测水正是察看情形。
- [x] 乡人沿用旧堤，却未按连雨后的水势作调整
- [ ] 父亲当初不知道孩子割竹
  理由：父亲最初怪孩子用竹，与他拿水势比病情是两件事。

提示：医病得先看病情，守堤得先看什么？
解析：乡人不看新的水势，仍守旧堤；医生不看眼前的病情，仍用老药方。父亲把两件事并在一起，提醒人先看情形再决定怎么办。

## 单选：同一堤岸为何去年可守、今年却溢？ {#q.check.12.4}
考点：skill.l3.10.1
语境：p.check.12.b

- [x] 雨势从小雨变为连绵的雨，而堤仍旧
- [ ] 孩子先毁堤引发水患
  理由：水溢在孩子取竹之前，破的是竹。
- [ ] 去年水已经漫过堤岸
  理由：“不逾堤”表示没越过。

提示：对照“去岁”和“今年”所带的天气。
解析：去年只下小雨，水没漫过堤；今年雨下个不停，堤还是那道旧堤，水便溢出来了。

## 找原文证据：哪句话写出用竹管测过以后，乡亲们终于弄清了什么？ {#q.check.12.5}
考点：skill.l3.11.1
语境：p.check.12.b

- [ ] 竹可更种
  理由：竹子可以重种，是父亲说损失还补得回来。
- [ ] 仍守旧堤
  理由：使用旧堤发生在制竹管前。
- [x] 众始知水高几许

提示：找制成竹管以后，众人知道的那件事。
解析：孩子把竹子制成管子，用它测水。“众始知水高几许”交代了结果：大家这才知道水究竟有多高。

## 单选：父亲改口的转折点是什么？ {#q.check.12.6}
考点：skill.l3.11.2
语境：p.check.12.b

- [x] 看见孩子的记录清楚，可以留下作参考
- [ ] 发现竹子本来就是坏的
  理由：原文说可以再种，没有否认损坏。
- [ ] 知道旧堤不用修了
  理由：水已溢出，父亲也没有评价堤是否安全。

提示：父亲原先只见竹子被毁，后来又看到了什么？
解析：父亲起初只看见竹子被剖开了，后来又见孩子把水位记得很清楚。他说竹子可以再种，这份记录却能留给以后的人用。
