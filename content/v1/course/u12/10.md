# 课文：循表涉水：故事在哪里变成了议论？ {#l3.10}

简介：水里设了渡河的标记，为什么仍然出了事？读明白这场水难，再看作者为什么要讲给治国的人听。

## 正文

“使人先表澭水”说派人先在水里设标记。等到“循表而夜涉”，“表”已经指设好的标记。要紧的是中间那句“澭水暴益”：河水猛涨，荆人却不知道，夜里还沿着旧标记渡河。“千有余人”就是一千多人，文中只给了约数。

接下来读“向其先表之时”。设标记的时候，标记原本可以指路；等到河水涨了，旧标记就靠不住了。看清水在什么时候变了，就知道作者为什么先肯定设标有用，后面又讲它怎样招致失败。

到了“今世之主”，作者谈起了治国。水情变了还循旧标，时代变了还照搬旧法，“有似于此”说的正是这一点相像。后面老园丁谈种田、说药方时，也可以问问哪些事已经变了，哪些做法还照旧。

## 知识点：向……今…… {#skill.l3.10.1}
义项：比较先前和如今的情形，说明同一做法为何有时管用、有时失灵
领域：篇章
要诀：“向”是先前，先前和如今有什么不同？
讲解：标记还是原来那块标记，水已经涨了。把设标时和渡水时分开，就知道办法为何一时管用、一时又不管用。
例句：p.l3.10.a

## 知识点：有似于此 {#skill.l3.10.2}
义项：辨明讲故事的人拿哪两件事作比，它们相似在哪里
领域：阅读技能
要诀：看说话人把哪两件事放到一块儿说。
讲解：“此”指上文说的整件事。君主沿用旧法，荆人沿用旧标，两边相像的是情形已经变了，办法还没改。
例句：p.l3.10.a

## 原文：古籍引文 {#p.l3.10.a}
> 向其先表之时，可导也。今水已变而益多矣，荆人尚犹循表而导之，此其所以败也。今世之主法先王之法也，有似于此。
译文：先前设置标记时，它可以用来引导渡水。如今水情已变，水量更多，荆人却仍依原来的标记渡水，这是他们失败的原因。当今的君主照着先王的法度办事，就有些像这样。

> 荆人欲袭宋，使人先表澭水。澭水暴益，荆人弗知，循表而夜涉，溺死者千有余人。

## 排序：荆人设标、河水上涨、夜里渡河，三件事怎样排？ {#q.l3.10.1}
考点：skill.l3.10.1
语境：p.l3.10.before

- [2] 河水突涨
  理由：“暴益”是水突然涨了，发生在设标以后、夜渡以前。
- [3] 依标夜渡
  理由：荆人不知道水已经上涨。
- [1] 派人设标
  理由：设标发生在涨水前。

提示：“先”“暴”“而夜涉”分别落在哪一步？
解析：标记设在涨水之前，夜渡却在涨水之后。问题出在水已变，荆人还照旧标走，并非一开始就不能设标。

## 单选：“可导也”与“所以败也”为什么不矛盾？ {#q.l3.10.2}
考点：skill.l3.10.1
语境：p.l3.10.a

- [ ] 荆人第二次已经另设过新标
  理由：“尚犹循表”表明仍依原标。
- [x] 前句以设标时为条件，后句说水涨以后仍沿旧标
- [ ] 两句写两支互不相关的队伍
  理由：荆人沿用的正是本军先设之标。

提示：注意“向”与“今”各自管到哪里。
解析：“向”说的是当初，标记能给人指路。“今”说的却是水已上涨以后；这时还要照着原标记走，才有了水难。

## 找原文证据：从哪一句起，作者讲的不再是荆人渡河，而是君主治国？ {#q.l3.10.3}
考点：skill.l3.10.2
语境：p.l3.10.a

- [ ] 向其先表之时
  理由：仍在回顾设标。
- [x] 今世之主法先王之法也
- [ ] 荆人尚犹循表而导之
  理由：仍在说渡水。

提示：注意主语在何处不再是荆人。
解析：前面一直在说水和标记。“今世之主”一出场，谈的已经是今天的君主怎样对待先王的法度了。

## 单选：旧标好比旧制度，那么已经上涨的河水好比什么？ {#q.l3.10.4}
考点：skill.l3.10.2
语境：p.l3.10.a

- [x] 君主要治理的时代处境发生变化
- [ ] 君主必须到河边另立木牌
  理由：作者拿渡河的事作比，并未安排君主也去河边设标。
- [ ] 先王一定命荆人入宋
  理由：作者拿先王的法度作比，并没说袭宋是谁下的命令。

提示：先想在水变了以后，哪样东西还照旧。
解析：水情变了还用旧标记，正好比时代变了还用旧制度。这才是“有似”的地方。

## 原文：教学例句 {#p.l3.10.b}
> 山北旧寒，农人五月而种。数年山麓渐暖，或犹待五月，苗未实而秋风至。老圃曰：“昔之候，非今之候也。治病者执一方以应众疾，亦犹是耳。”
译文：山北原来寒冷，农人在五月播种。几年间山脚渐暖，有人仍等五月才种，到秋风来时禾苗还没结实。老园丁说，旧日时令和今日情况不同；治病的人若拿一张方子应付种种病，也有类似之处。

## 找原文证据：原文用哪几个字说明山脚下比过去暖和了？ {#q.l3.10.5}
考点：skill.l3.10.1
语境：p.l3.10.b

- [x] 山麓渐暖
- [ ] 农人五月而种
  理由：这写过去的做法。
- [ ] 苗未实
  理由：没有结出谷实，是照旧在五月下种以后才看到的。

提示：以前“山北旧寒”，后来山脚下又怎样？
解析：从“旧寒”到“渐暖”，变化的是山里的气候。仍等五月才下种的人，沿用的却是从前的做法。

## 单选：老圃为何把“昔之候”和“今之候”分开说？ {#q.l3.10.6}
考点：skill.l3.10.1
语境：p.l3.10.b

- [ ] “候”指两个不同官职
  理由：这里讨论的是农时。
- [ ] 五月从此不再是月份
  理由：五月还是五月，山脚下却比从前暖了。
- [x] 同在山北，也要比较今年与过去的时令

提示：前面说到山里从前冷、后来暖，老园丁接着在说什么？
解析：前面说山北从前冷，后来山脚逐年转暖。因此“昔之候，非今之候”是提醒农人，眼下的时令已和从前不同。

## 单选：把医生和农人的事情对着读。“一方”相当于农人沿用的什么？ {#q.l3.10.7}
考点：skill.l3.10.2
语境：p.l3.10.b

- [ ] 今年变暖的山麓
  理由：“一方”是医者施用的办法。
- [x] 不论条件一直沿用的播种时间
- [ ] 秋风到来时的果实
  理由：果实是结果，并非处理办法。

提示：一边总用同一张药方，另一边总在什么时候播种？
解析：医生不看病情，总用同一张药方；农人不看天候，总等到五月。两人守着不变的，都是自己的做法。

## 单选：“亦犹是耳”是老园丁在做什么？ {#q.l3.10.8}
考点：skill.l3.10.2
语境：p.l3.10.b

- [x] 老圃从农事转说医事，借两者的关系申明看法
- [ ] 叙事者报告有人因错服药死亡
  理由：治病是老圃提出的比方，没有病人的结局。
- [ ] 农人在播种前向医生求方
  理由：没有医生与农人会面的事。

提示：说这话的是谁？前面可真有个病人找过医生？
解析：老园丁先说农时，再拿医生用药作比。田里误了收成，是前面讲过的事；医病只出现在老园丁的比方里。
