# 课文：循表涉水：故事在哪里变成了议论？ {#l3.10}

简介：辨清标记何时有效，再把故事里的关系移到治国的讨论中。

## 正文

“表”先作动词，指在渡口设标记；“循表”的“表”是设好的标记。“益”写水涨。要解释失败，分两个时点回答：**设标时**水怎样？**夜涉时**水又怎样？

荆人先派人在澭水设标，涨水后却仍趁夜循标渡水。读过这一经过，再读“向其先表之时”开头的解释。作者先解释“所以败”，再以“有似于此”把旧时制度和旧标记相提并论。判断类比时，要能说出两边对应的**关系**。第三个语境换到山田，试着自己找出变化的条件。

“荆人弗知”省去了不知的内容：河水在设标后猛涨。“溺死者千有余人”中的“千有余”给出超过一千的约数，修饰“人”。作者没有报出准确人数，读者却已能从这个后果理解他为何追问失败的原因。

## 知识点：向……今…… {#skill.l3.10.1}
义项：对照早先和眼下的条件以解释同一做法的不同后果
领域：篇章
要诀：先区分设法之时和用法之时
讲解：向指先前。办法原来可用，条件改变后是否仍可用，需要对照两处事实。
例句：p.l3.10.a

## 知识点：有似于此 {#skill.l3.10.2}
义项：从叙事转入议论时找类比的对应关系
领域：阅读技能
要诀：把两边各自不变的做法和已变的条件分列
讲解：此回指前面整个处境。类比比较关系，不能把两个对象的所有性质都互换。
例句：p.l3.10.a

## 原文：古籍引文 {#p.l3.10.a}
> 向其先表之时，可导也。今水已变而益多矣，荆人尚犹循表而导之，此其所以败也。今世之主法先王之法也，有似于此。
译文：先前设置标记时，它可以用来引导渡水。如今水情已变，水量更多，荆人却仍依原来的标记渡水，这是他们失败的原因。如今的君主仿效先王的制度，也有与此相似之处。

> 荆人欲袭宋，使人先表澭水。澭水暴益，荆人弗知，循表而夜涉，溺死者千有余人。

## 排序：按水情和荆人行动发生的次序排列。 {#q.l3.10.1}
考点：skill.l3.10.1
语境：p.l3.10.before

- [2] 河水突涨
  理由：“暴益”是两次到河边之间的新情况。
- [3] 依标夜渡
  理由：荆人不知道水已经上涨。
- [1] 派人设标
  理由：设标发生在涨水前。

提示：“先”“暴”“而夜涉”分别落在哪一步？
解析：设标时与渡河时处在不同的水情，如不分两时，容易误以为故事批评一开始就不该标水。

## 单选：“可导也”与“所以败也”为什么不矛盾？ {#q.l3.10.2}
考点：skill.l3.10.1
语境：p.l3.10.a

- [ ] 荆人第二次已经另设过新标
  理由：“尚犹循表”表明仍依原标。
- [x] 前句以设标时为条件，后句说水涨以后仍沿旧标
- [ ] 两句写两支互不相关的队伍
  理由：荆人沿用的正是本军先设之标。

提示：注意“向”与“今”各自管到哪里。
解析：读条件带来的变化，才能既承认早先设标有用，又解释后来的失败。

## 找原文证据：哪一处文字表明作者已转向君主的做法？ {#q.l3.10.3}
考点：skill.l3.10.2
语境：p.l3.10.a

- [ ] 向其先表之时
  理由：仍在回顾设标。
- [x] 今世之主法先王之法也
- [ ] 荆人尚犹循表而导之
  理由：仍在说渡水。

提示：注意主语在何处不再是荆人。
解析：从“今世之主”开始，话题移到政治，下一句才点明两件事“有似”。

## 单选：若把旧标记与旧制度相对应，河水变化对应什么？ {#q.l3.10.4}
考点：skill.l3.10.2
语境：p.l3.10.a

- [x] 君主要治理的时代处境发生变化
- [ ] 君主必须到河边另立木牌
  理由：类比取的是“条件已变”的关系。
- [ ] 先王一定命荆人入宋
  理由：文中没有建立这种因果。

提示：给两个例子各写“原有办法”和“施用环境”。
解析：水情与时代都是办法发挥作用的条件；两边的对象并不需要字面相同。

## 原文：教学例句 {#p.l3.10.b}
> 山北旧寒，农人五月而种。数年山麓渐暖，或犹待五月，苗未实而秋风至。老圃曰：“昔之候，非今之候也。治病者执一方以应众疾，亦犹是耳。”
译文：山北原来寒冷，农人在五月播种。几年间山脚渐暖，有人仍等五月才种，到秋风来时禾苗还没结实。老园丁说，旧日时令和今日情况不同；治病的人若拿一张方子应付种种病，也有类似之处。

## 找原文证据：哪处明说播种时的环境已有变化？ {#q.l3.10.5}
考点：skill.l3.10.1
语境：p.l3.10.b

- [x] 山麓渐暖
- [ ] 农人五月而种
  理由：这写过去的做法。
- [ ] 苗未实
  理由：这是后一年的结果。

提示：找直接报告气候的信息。
解析：山脚转暖是条件变化；播种月份没有跟着变，老圃据此回看旧做法。

## 单选：老圃为何把“昔之候”和“今之候”分开说？ {#q.l3.10.6}
考点：skill.l3.10.1
语境：p.l3.10.b

- [ ] “候”指两个不同官职
  理由：这里讨论的是农时。
- [ ] 五月从此不再是月份
  理由：历月名称并未消失，变化的是气候。
- [x] 同在山北，也要比较今年与过去的时令

提示：从叙事中的冷暖寻找“候”的含义。
解析：把“候”读作时令，才能接上前面的旧寒和渐暖。

## 单选：医者“一方”在前面的故事中相当于什么？ {#q.l3.10.7}
考点：skill.l3.10.2
语境：p.l3.10.b

- [ ] 今年变暖的山麓
  理由：“一方”是医者施用的办法。
- [x] 不论条件一直沿用的播种时间
- [ ] 秋风到来时的果实
  理由：果实是结果，并非处理办法。

提示：将两个场景都拆为办法和适用条件。
解析：固定月份与固定方子都在“办法”一侧；需要分别考虑的是气候和病情。

## 单选：“亦犹是耳”由谁说，用来做什么？ {#q.l3.10.8}
考点：skill.l3.10.2
语境：p.l3.10.b

- [x] 老圃从农事转说医事，借两者的关系申明看法
- [ ] 叙事者报告有人因错服药死亡
  理由：治病是老圃提出的比方，没有病人的结局。
- [ ] 农人在播种前向医生求方
  理由：没有医生与农人会面的事。

提示：先找“曰”的说者，再分实际事情和例子。
解析：农事写实际事件，医事在老圃的话里作为比喻，不应据此续写新的病案。
