# 课文：煮饭成糜：父亲真正关心什么？ {#l3.11}

简介：从炊具和成品弄懂事情的来龙去脉，再解释末句如何改换评价。

## 正文

读到陌生器物，不必一开始就逐字查字典。先排出本段的操作链：**忘箸箄 → 饭落釜中 → 饭今成糜**。“箸”在此是放置，“箄”指蒸饭的箅子，“釜”是锅。知道这个差别，就能解释同是粮食，为什么做成了不同的饭食。

陈太丘先问饭为何没蒸好，随后问儿子记得多少谈话。留意两次问题之间的变化，再看“何必饭也”评价的究竟是什么。“识”“志”在此都与记住谈话有关。

## 知识点：忘箸箄 {#skill.l3.11.1}
义项：通过工具与成品之间的关系复原省去的操作
领域：文化背景
要诀：找漏掉哪道手续以及材料去了哪里
讲解：箄能让饭在水上蒸；未放箄而落入釜中，故成糜。辨器物须拿前后动作和结果相互印证。
例句：p.l3.11.a

## 知识点：何必饭也 {#skill.l3.11.2}
义项：从先问失误到后许其所得辨出评价重心
领域：篇章
要诀：把人物最后一句同中间的新证据相连
讲解：末句以反问放宽先前要求。询问是否记得、二子能够复述，解释了父亲为何接受糜。
例句：p.l3.11.a

## 原文：古籍引文 {#p.l3.11.a}
> 宾客诣陈太丘宿，太丘使元方、季方炊。客与太丘论议，二人进火，俱委而窃听。炊忘箸箄，饭落釜中。太丘问：“炊何不馏？”元方、季方长跪曰：“大人与客语，乃俱窃听，炊忘箸箄，饭今成糜。”太丘曰：“尔颇有所识不？”对曰：“仿佛志之。”二子俱说，更相易夺，言无遗失。太丘曰：“如此，但糜自可，何必饭也？”
译文：宾客来陈太丘家住宿，他命两个儿子做饭。他与客人议论，两个孩子添火后都搁下活儿偷听，忘了放蒸饭的箅子，饭落进锅中。父亲问饭怎么没蒸好，兄弟跪直了身子解释，说饭成了粥。父亲问他们可曾记得谈话，他们说大致记得。两人一道复述，互相订正，所谈无所遗漏。父亲说，既然如此，粥也就可以，何必一定要蒸成饭呢？

## 排序：依原文还原饭食改变的因果次序。 {#q.l3.11.1}
考点：skill.l3.11.1
语境：p.l3.11.a

- [3] 饭食变成糜
  理由：成糜是两兄弟报告的成品状况。
- [2] 饭落入釜中
  理由：这是没放箅子后的直接结果。
- [1] 做饭时忘放箅子
  理由：先缺了一道手续。

提示：从少了的器具开始。
解析：箅子把米与釜中的水隔开。少了它，米落锅中，才有“饭今成糜”的解释。

## 单选：在“炊忘箸箄”中，把“箸”读作“筷子”会丢掉什么？ {#q.l3.11.2}
考点：skill.l3.11.1
语境：p.l3.11.a

- [ ] 二人没有听父子说话
  理由：他们听的是父亲与客人。
- [x] 忘记做的是放置箅子这一步
- [ ] 饭烧焦的气味
  理由：没有气味或焦糊的叙述。

提示：看“忘”后面能否接上一件动作。
解析：“箸箄”是放箅子，后文说饭落进釜中，由缺器具产生的后果也能反证。

## 找原文证据：哪段直接表明两个儿子虽误了炊事，确实记住了所听？ {#q.l3.11.3}
考点：skill.l3.11.2
语境：p.l3.11.a

- [x] 言无遗失
- [ ] 二人进火
  理由：添火不能证明记住谈话。
- [ ] 元方、季方长跪
  理由：姿势不能证明复述完整。

提示：找发生在他们开口复述之后的说明。
解析：“仿佛志之”是自述，后来的“言无遗失”具体写出复述的结果。

## 单选：“如此，但糜自可”中“如此”最直接承接什么？ {#q.l3.11.4}
考点：skill.l3.11.2
语境：p.l3.11.a

- [ ] 父亲原本要求孩子煮粥
  理由：父亲先问饭为什么没蒸好。
- [ ] 来客已经离家不吃饭了
  理由：没有客人离开的情节。
- [x] 孩子复述论议时相互订正，没有遗漏

提示：把“如此”接到紧邻的叙述。
解析：两人实际学到了谈话，这是父亲改变对这一餐要求的背景。

## 原文：教学例句 {#p.l3.11.b}
> 匠使徒以筛择沙。客过，问桥柱所以深立者，徒舍筛往听。少顷，沙与石俱入筐。匠怒而问之。徒画地言水势，皆中其理。匠曰：“沙可复择，得此说亦足矣。”
译文：工匠让学徒用筛子筛沙。来客问桥柱为什么要深埋，学徒放下筛子去听。不久沙石一起进了筐。工匠生气询问，学徒在地上画图讲水势，所讲都合于道理。工匠说沙还能重筛，学到这番道理也值得。

## 找原文证据：哪几个字说明沙石混在一起之前少了什么操作？ {#q.l3.11.5}
考点：skill.l3.11.1
语境：p.l3.11.b

- [ ] 徒画地言水势
  理由：这是解释之后发生的事。
- [ ] 客过
  理由：来客经过不直接造成沙石混杂。
- [x] 徒舍筛往听

提示：找与原先“以筛择沙”相反的动作。
解析：舍下筛子，便没有执行分开粗细的操作；后面“俱入筐”与此衔接。

## 单选：哪一情节最能解释工匠从怒到宽解？ {#q.l3.11.6}
考点：skill.l3.11.2
语境：p.l3.11.b

- [ ] 客人替学徒重新筛完沙
  理由：没有写客人动手。
- [ ] 工匠发现筐里从来没有石头
  理由：“沙与石俱入筐”是已叙事实。
- [x] 学徒能画图说明水势而且合乎道理

提示：注意态度变化前多了哪件能看见的事。
解析：“皆中其理”使“得此说”落到可观察的学习结果上。

## 单选：单凭“沙可复择”，能推出什么？ {#q.l3.11.7}
考点：skill.l3.11.1
语境：p.l3.11.b

- [ ] 学徒先前一直在用筛
  理由：“舍筛”表明他一度停了手。
- [x] 眼下混杂的沙石还有重新分拣的机会
- [ ] 桥柱现在已经全部修成
  理由：故事没有交代修桥完成。

提示：把“可”同“已”分开。
解析：“可复”表示尚能补做，而原任务有没有按时做好，前文另有交代。

## 单选：怎样概括结尾会保留工匠判断的限度？ {#q.l3.11.8}
