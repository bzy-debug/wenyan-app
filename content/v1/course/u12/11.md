# 课文：煮饭成糜：父亲真正关心什么？ {#l3.11}

简介：原要蒸饭，怎么成了粥？陈太丘听两个儿子说完，又为什么肯吃这锅粥？

## 正文

“箄”是蒸饭用的箅子，搁在锅里，把米和水隔开。“箸箄”的“箸”在这里是放的意思。两兄弟听入了神，竟忘记放箅子，米便落进锅里的水里。读到“饭今成糜”，就知道为什么没蒸成饭，倒煮成了粥。

父亲起初问“炊何不馏”，想知道饭怎么没蒸好。等儿子承认去偷听了，他却问还记不记得谈话：“识”和“志”在这里都是记住的意思。听完二人复述，再读“何必饭也”，想想父亲此刻看重的是什么。

## 知识点：忘箸箄 {#skill.l3.11.1}
义项：看米落进锅里煮成粥，明白先前漏放了什么
领域：文化背景
要诀：少了哪样炊具，米才会落进水里？
讲解：“忘箸箄”说的是忘了放箅子。下一句饭落釜中，再下一句成了糜，顺着结果就能看懂箅子的用处。
例句：p.l3.11.a

## 知识点：何必饭也 {#skill.l3.11.2}
义项：从原先问饭到后来肯吃粥，读出父亲此时看重什么
领域：篇章
要诀：从问饭到问谈话，中间父亲听到了什么？
讲解：儿子误了蒸饭，却把客人和父亲的话复述得没有遗漏。父亲这才宽下心来说，这一顿吃粥也可以。
例句：p.l3.11.a

## 原文：古籍引文 {#p.l3.11.a}
> 宾客诣陈太丘宿，太丘使元方、季方炊。客与太丘论议，二人进火，俱委而窃听。炊忘箸箄，饭落釜中。太丘问：“炊何不馏？”元方、季方长跪曰：“大人与客语，乃俱窃听，炊忘箸箄，饭今成糜。”太丘曰：“尔颇有所识不？”对曰：“仿佛志之。”二子俱说，更相易夺，言无遗失。太丘曰：“如此，但糜自可，何必饭也？”
译文：宾客来陈太丘家住宿，他命两个儿子做饭。他与客人议论，两个孩子添火后都搁下活儿偷听，忘了放蒸饭的箅子，饭落进锅中。父亲问饭怎么没蒸好，兄弟跪直了身子解释，说饭成了粥。父亲问：“你们可还记得些什么？”两人答：“大致还记得。”兄弟俩一道复述，彼此订正，没有漏掉什么。父亲说，既然如此，粥也就可以，何必一定要蒸成饭呢？

## 排序：原来要蒸的饭为什么变成了粥？请把经过排出来。 {#q.l3.11.1}
考点：skill.l3.11.1
语境：p.l3.11.a

- [3] 饭食变成糜
  理由：“饭今成糜”是孩子们最后看到的光景。
- [2] 饭落入釜中
  理由：这是没放箅子后的直接结果。
- [1] 做饭时忘放箅子
  理由：他们先把蒸饭用的箅子忘了。

提示：从少了的器具开始。
解析：先忘了放箅子，米才落进锅里的水中，最后煮成了糜。这里的“糜”是粥。

## 单选：“炊忘箸箄”为什么不能把“箸”讲成筷子？ {#q.l3.11.2}
考点：skill.l3.11.1
语境：p.l3.11.a

- [ ] 二人没有听父子说话
  理由：他们听的是父亲与客人。
- [x] 忘记做的是放置箅子这一步
- [ ] 饭烧焦的气味
  理由：没有气味或焦糊的叙述。

提示：看“忘”后面能否接上一件动作。
解析：“忘”的是一个本该做的动作，即“箸箄”，放好箅子。少了这一步，米才会落进锅里去。

## 找原文证据：哪四个字说兄弟俩确实把听来的谈话记全了？ {#q.l3.11.3}
考点：skill.l3.11.2
语境：p.l3.11.a

- [x] 言无遗失
- [ ] 二人进火
  理由：添火不能证明记住谈话。
- [ ] 元方、季方长跪
  理由：姿势不能证明复述完整。

提示：找发生在他们开口复述之后的说明。
解析：“仿佛志之”只是孩子们自己说大致记得。他们开口复述以后，作者才说“言无遗失”，也就是一句没漏。

## 单选：父亲说“如此”，指的是刚看见、听见的哪件事？ {#q.l3.11.4}
考点：skill.l3.11.2
语境：p.l3.11.a

- [ ] 父亲原本要求孩子煮粥
  理由：父亲先问饭为什么没蒸好。
- [ ] 来客已经离家不吃饭了
  理由：没有客人离开的情节。
- [x] 孩子复述论议时相互订正，没有遗漏

提示：父亲刚听完两个儿子的复述，他们记得怎样？
解析：两个儿子把听来的话说给父亲，一边说一边互相订正，竟没有遗漏。父亲知道他们确有所得，这才接受煮成的粥。

## 原文：教学例句 {#p.l3.11.b}
> 匠使徒以筛择沙。客过，问桥柱所以深立者，徒舍筛往听。少顷，沙与石俱入筐。匠怒而问之。徒画地言水势，皆中其理。匠曰：“沙可复择，得此说亦足矣。”
译文：工匠让学徒用筛子筛沙。来客问桥柱为什么要深埋，学徒放下筛子去听。不久沙石一起进了筐。工匠生气询问，学徒在地上画图讲水势，所讲都合于道理。工匠说沙还能重筛，学到这番道理也值得。

## 找原文证据：哪几个字说学徒放下了本该用来分开沙石的东西？ {#q.l3.11.5}
考点：skill.l3.11.1
语境：p.l3.11.b

- [ ] 徒画地言水势
  理由：画地讲水势已经是在沙石混在一起以后。
- [ ] 客过
  理由：来客经过不直接造成沙石混杂。
- [x] 徒舍筛往听

提示：找与原先“以筛择沙”相反的动作。
解析：师傅原让他“以筛择沙”，他却“舍筛往听”。没人再筛，沙和石子便一齐进了筐。

## 单选：工匠起初生气，后来为什么觉得学徒也有所得？ {#q.l3.11.6}
考点：skill.l3.11.2
语境：p.l3.11.b

- [ ] 客人替学徒重新筛完沙
  理由：没有写客人动手。
- [ ] 工匠发现筐里从来没有石头
  理由：“俱入筐”明说沙和石都进了筐。
- [x] 学徒能画图说明水势而且合乎道理

提示：学徒在地上画了什么，说得对不对？
解析：学徒能画图说明水势，又说得“皆中其理”。师傅这才知道，他放下筛子去听，确实听懂了桥柱为什么要深埋。

## 单选：单凭“沙可复择”，能推出什么？ {#q.l3.11.7}
考点：skill.l3.11.1
语境：p.l3.11.b

- [ ] 学徒先前一直在用筛
  理由：“舍筛”表明他一度停了手。
- [x] 眼下混杂的沙石还有重新分拣的机会
- [ ] 桥柱现在已经全部修成
  理由：故事没有交代修桥完成。

提示：把“可”同“已”分开。
解析：“可复择”是还可以把沙石挑开。师傅只说这次失误补得回来，没有说此刻已经重筛完了。

## 单选：工匠最后的话说到什么程度？ {#q.l3.11.8}
考点：skill.l3.11.2
语境：p.l3.11.b

- [ ] 工匠宣布此后谁都不必再筛沙
  理由：只说这一次“可复择”。
- [ ] 工匠认为听一次谈话总比做活重要
  理由：原文评价这一次的具体得失。
- [x] 这次失误可补，他也看重学徒当场表现出的所学

提示：他谈的是这回错过的活儿和这回听到的道理。
解析：沙石可以重筛，学徒当场讲清的水势却也是收获。师傅评的是眼下这一次，没有说往后谁都可以不做活。
