# 课文：名词之后的限定语与数量 {#l2.8}
简介：辨清先提一类对象、后从中选取的读法，再读名词后补出的数量。

## 正文

“客之善书者”先给出“客”这一类，再限定为其中善写字的那些人。用现代汉语可说“善写字的客人”。普通的“客之书”却可读成“客人的信”；能否在后面找出限定条件以及收尾的“者”，会改变整组的边界。

古文也常先写物或人，再列数量：“取简三枚”。核对量词所能计算的对象。若写“登山三次”，算的却是动作次数，不能仅凭数字的位置作决定。

## 知识点：名词之……者 {#l2.skill.post-nominal}
义项：将后置条件还原成对前项的限制
领域：句法
要诀：将后置条件还原成对前项的限制
讲解：找出整个集合，再点出真正符合条件的成员，注意后面的行动只涉及哪些人或物。
例句：l2.ex.post-nominal

## 原文：教学例句 {#l2.ex.post-nominal}
> 择木之直者以为梁。
译文：挑选笔直的木料做房梁。

## 知识点：名词后列数量 {#l2.skill.post-count}
义项：给前面的名词补出数量
领域：句法
要诀：给前面的名词补出数量
讲解：把“物名＋数量”换说为“数量＋物名”，用量词、后文余数或领取记录核对。
例句：l2.ex.post-count

## 原文：教学例句 {#l2.ex.post-count}
> 匠取竹三竿。
译文：工匠取了三根竹子。

## 原文：古籍引文 {#l2.8.p.swim}
> 冠者五六人，童子六七人，浴乎沂。
译文：五六位成年人，六七个少年，到沂水中沐浴。

## 单选：哪种复述保留了两项人数？ {#l2.8.q1}
考点：l2.skill.post-count
语境：l2.8.p.swim

- [x] 成年人五六位，少年六七个
- [ ] 少年五六个，成年人六七位
  理由：将数量各自连回前面的身份。
- [ ] 每个人沐浴五六次
  理由：“人”是人数单位。

提示：每一小组都以“人”收住。
解析：两处数量都放在所属群体后面。浴是共同的活动，并非被计数的对象。

## 找原文证据：哪一组数量属于童子？ {#l2.8.q2}
考点：l2.skill.post-count
语境：l2.8.p.swim

- [x] 六七人
- [ ] 五六人
  理由：这紧跟在“冠者”之后。
- [ ] 沂
  理由：这是水名。

提示：先读“童子”后面的词。
解析：“童子六七人”是一组，“六七人”是后置的数量说明。

## 原文：教学例句 {#l2.8.p.reeds}
> 吏集舟之可载粟者，泊于东岸。舟之漏者，皆留西岸。
译文：官吏集合能装运粮食的船，停在东岸；漏水的船都留在西岸。

## 单选：东岸停的是哪一部分船？ {#l2.8.q3}
考点：l2.skill.post-nominal
语境：l2.8.p.reeds

- [ ] 只装着水的船
  理由：漏水的船有另外的去处。
- [ ] 所有来到渡口的船
  理由：西岸还留下哪一批？
- [x] 能装运粮食的船

提示：以两处“舟之……者”分别分组。
解析：“可载粟”限定东岸所集之舟，“漏”限定留在西岸的一组。

## 找原文证据：哪一个字说明西岸那批船的毛病？ {#l2.8.q4}
考点：l2.skill.post-nominal
语境：l2.8.p.reeds

- [ ] 舟
  第几处：1
  理由：这是全部对象的类别。
- [ ] 东岸
  理由：这是另一批船所在处。
- [x] 漏

提示：看第二个“者”前面的条件。
解析：“舟之漏者”专指其中漏水的船。

## 原文：教学例句 {#l2.8.p.count}
> 库有帛十匹。吏出帛三匹，以给冬衣。余帛封而藏之。
译文：仓库有丝帛十匹。官吏拿出三匹，用来供制冬衣，剩下的封存。

## 单选：“出帛三匹”中的“三匹”与什么相连？ {#l2.8.q5}
考点：l2.skill.post-count
语境：l2.8.p.count

- [ ] 出库三次
  理由：“匹”在数帛，不在数取的次数。
- [ ] 每一套冬衣
  理由：句中未说每套衣服用料多少。
- [x] 这次取出的帛

提示：看数量的单位。
解析：“三匹”限定本次所出丝帛的数量。

## 单选：封存部分能由文意算出多少？ {#l2.8.q6}
考点：l2.skill.post-count
语境：l2.8.p.count

- [ ] 三匹
  理由：三匹是已取出的。
- [x] 七匹
- [ ] 十匹
  理由：十匹是取用之前的总数。

提示：把库存和此次支出的单位对齐。
解析：同一批十匹中取三匹，未写别次出入，因此余七匹。

## 原文：教学例句 {#l2.8.p.students}
> 生之能诵者先出，未能者留。师授留者以简，令习之。
译文：学生中能背诵的先出去，尚不能的留下。老师给留下的人竹简，让他们练习。

## 单选：“生之能诵者先出”若只译为“学生先出”，损失了什么？ {#l2.8.q7}
考点：l2.skill.post-nominal
语境：l2.8.p.students

- [ ] 把老师写成学生
  理由：句子并未这样换人。
- [x] 先出去的人须满足能诵的条件
- [ ] 所有人都留下
  理由：“先出”与“留”有分别。

提示：注意“未能者”另有去向。
解析：前项先点出学生这个集合，后置条件限制先出去的那一部分。

## 原文：教学例句 {#l2.8.p.trees}
> 园有梨树五株。翁灌其新植者；根深者不灌。
译文：园里有五棵梨树。老人浇灌其中新栽的，根深的没有浇。

## 单选：根据现有信息，能确定哪一项？ {#l2.8.q8}
考点：l2.skill.post-nominal
语境：l2.8.p.trees

- [ ] 五株全被浇过
  理由：“根深者不灌”作了限制。
- [ ] 恰好浇了两株
  理由：“五株”是总数，未说各组数量。
- [x] 只浇新栽者，未给出浇了几株

提示：分清全园的数量与实际灌溉的范围。
解析：“其新植者”在整体中取一部分；总数不等于这部分的数量。
