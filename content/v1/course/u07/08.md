# 课文：名词之后的限定语与数量 {#l2.8}
简介：先说“舟”，又加一句“可载粟者”，这才知道指哪些船。人数和物件的数量也常放在名词后面。

## 正文

“客之善书者”说的是哪些人？先读“客”，再读“善书者”，合起来就是“那些善于写字的客人”。若只读“客之书”，倒可能是“客人的信”。要把“之”后面的词读完，才知道该怎样分组。

“取简三枚”就是说“拿三枚竹简”。遇见数字，不妨问一句“数的是什么”。“登山三次”数的是登山的次数，当然不能读成三座山。

## 知识点：名词之……者 {#l2.skill.post-nominal}
义项：先说哪一类人或东西，再说其中符合什么条件的那些
领域：句法
要诀：读到“者”，回头看是哪一类人或物。
讲解：“择木之直者”要从木料中挑选，能选中的还有一个条件：木料得直。
例句：l2.ex.post-nominal

## 原文：教学例句 {#l2.ex.post-nominal}
> 择木之直者以为梁。
译文：挑选笔直的木料做房梁。

## 知识点：名词后列数量 {#l2.skill.post-count}
义项：看名词后面的数量，知道人或东西有多少
领域：句法
要诀：看量词数的是人、东西还是动作。
讲解：“取竹三竿”是取三根竹子。遇到总数和余数，可以对照一下取走的到底有多少。
例句：l2.ex.post-count

## 原文：教学例句 {#l2.ex.post-count}
> 匠取竹三竿。
译文：工匠取了三根竹子。

## 单选：跟曾皙一起到沂水去的，两拨人各有多少？ {#l2.8.q1}
考点：l2.skill.post-count
语境：l2.8.p.swim

- [x] 成年人五六位，少年六七个
- [ ] 少年五六个，成年人六七位
  理由：把“五六人”连着它前面的“冠者”一起读。
- [ ] 每个人沐浴五六次
  理由：“五六人”数的是几个人。“浴”前没有写洗了几次。

提示：每处人数前面紧挨着什么称呼？
解析：“冠者”后是“五六人”，“童子”后是“六七人”。两拨人都去沐浴，这两个数说的是人头。

## 找原文证据：原文写少年有多少人？ {#l2.8.q2}
考点：l2.skill.post-count
语境：l2.8.p.swim

- [x] 六七人
- [ ] 五六人
  理由：这紧跟在“冠者”之后。
- [ ] 沂
  理由：“沂”是水名，说的是他们去哪里沐浴。

提示：先读“童子”后面的词。
解析：“童子六七人”合起来就是六七个少年。前面的“五六人”另数成年人。

## 原文：教学例句 {#l2.8.p.reeds}
> 吏集舟之可载粟者，泊于东岸。舟之漏者，皆留西岸。
译文：官吏集合能装运粮食的船，停在东岸；漏水的船都留在西岸。

## 单选：东岸停的是哪一部分船？ {#l2.8.q3}
考点：l2.skill.post-nominal
语境：l2.8.p.reeds

- [ ] 只装着水的船
  理由：漏水的船有另外的去处。
- [ ] 所有来到渡口的船
  理由：漏水的船还留在西岸。
- [x] 能装运粮食的船

提示：拿东岸的船和留在西岸的船比一比。
解析：东岸的要能“载粟”，西岸留下的是漏水的船。这两个“者”各说一批。

## 找原文证据：原文用哪个字说西岸的船出了什么问题？ {#l2.8.q4}
考点：l2.skill.post-nominal
语境：l2.8.p.reeds

- [ ] 舟
  第几处：1
  理由：“舟”只能看出是船，看不出毛病。
- [ ] 东岸
  理由：这是另一批船所在处。
- [x] 漏

提示：留在西岸的船哪里出了问题？找“者”前面的字。
解析：“漏”紧跟在“舟之”后面，说的是这批船会漏水。

## 原文：教学例句 {#l2.8.p.count}
> 库有帛十匹。吏出帛三匹，以给冬衣。余帛封而藏之。
译文：仓里有十匹丝帛。官吏拿出三匹做冬衣，把剩下的封存起来。

## 单选：这三匹数的是哪一样东西？ {#l2.8.q5}
考点：l2.skill.post-count
语境：l2.8.p.count

- [ ] 出库三次
  理由：“匹”是帛的单位。要说出库几回，不能拿“匹”来数。
- [ ] 每一套冬衣
  理由：句中未说每套衣服用料多少。
- [x] 这次取出的帛

提示：“匹”能用来数丝帛，还是数出库的次数？
解析：官吏取的是帛。“出帛三匹”就是“取出三匹帛”，“匹”是帛的量词。

## 单选：官吏封存了多少帛？ {#l2.8.q6}
考点：l2.skill.post-count
语境：l2.8.p.count

- [ ] 三匹
  理由：三匹是已取出的。
- [x] 七匹
- [ ] 十匹
  理由：十匹是取用之前的总数。

提示：原有多少？取去做冬衣的有多少？
解析：原有十匹，用掉三匹，余下七匹。最后收起来的是“余帛”。

## 原文：教学例句 {#l2.8.p.students}
> 生之能诵者先出，未能者留。师授留者以简，令习之。
译文：学生中能背诵的先出去，尚不能的留下。老师给留下的人竹简，让他们练习。

## 单选：只说“学生先出去”，漏掉了什么？ {#l2.8.q7}
考点：l2.skill.post-nominal
语境：l2.8.p.students

- [ ] 把老师写成学生
  理由：开头说的是“生”。少译的是哪些学生能先走。
- [x] 先出去的人须满足能诵的条件
- [ ] 所有人都留下
  理由：文中写了两批学生，有的先出去，有的留下。

提示：注意“未能者”另有去向。
解析：有的学生“先出”，有的“留”。“能诵”是两拨人的分别，只能把会背的人算在先出去的那一拨。

## 原文：教学例句 {#l2.8.p.trees}
> 园有梨树五株。翁灌其新植者；根深者不灌。
译文：园里有五棵梨树。老人浇灌其中新栽的，根深的没有浇。

## 单选：读完能知道老人给哪些树浇了水吗？ {#l2.8.q8}
考点：l2.skill.post-nominal
语境：l2.8.p.trees

- [ ] 五株全被浇过
  理由：遇到根扎得深的树，老人就不浇水。
- [ ] 恰好浇了两株
  理由：“五株”是总数，未说各组数量。
- [x] 只浇新栽者，未给出浇了几株

提示：五株是全园的树，还是新栽的树？
解析：园里总共有五株，只知道老人浇了新栽的。新栽的到底占几株，文中没有说。
