# 检查：同师学弈，临河修桥 {#check.7}

## 原文：古籍引文 {#check.7.p.chess}
> 今夫弈之为数，小数也。不专心致志，则不得也。弈秋，通国之善弈者也。使弈秋诲二人弈，其一人专心致志，惟弈秋之为听。一人虽听之，一心以为有鸿鹄将至，思援弓缴而射之。虽与之俱学，弗若之矣。
译文：说到下棋这门技艺，虽只是小技艺，不专心也学不会。弈秋是全国善于下棋的人。让他教两个人学棋，一个集中精神，只听弈秋讲。另一个也听，却总想着会有大鸟飞来，想拿弓和系绳的箭去射。尽管他同前一人一起学习，学得却不如人家。
词注：弈：下棋。
  数：在开头“弈之为数”中读 shù，指技艺。
  诲：教导。
  鸿鹄：大鸟。
  缴：读 zhuó，系在箭上的丝绳，此处连同弓箭一起说。
出处：《孟子·告子上》弈秋诲二人章节录

## 单选：“通国之善弈者也”先认定一个人的身份，后面怎样用到了这层身份？ {#check.7.q1}
考点：l2.skill.actor-zhe
语境：check.7.p.chess

- [x] 他善弈，才让他教两个人下棋
- [ ] 举国的人都成了弈秋的学生
  理由：“通国之善弈者”说弈秋棋艺出众，真正从学的写作“二人”。
- [ ] 他是两名学生中后来分心的那个
  理由：“使弈秋诲二人”把教者与两名学生分开。

提示：顺着“弈秋”读到“诲二人”，谁在教？
解析：“善弈者”是以本领称人的说法，指已经提名的弈秋。下面才有两位学生听他教。

## 找原文证据：开头说不专心“则不得”，后文哪处具体写出了一个学生为什么分心？ {#check.7.q2}
考点：l2.skill.condition-ze
语境：check.7.p.chess

- [x] 思援弓缴而射之
- [ ] 惟弈秋之为听
  理由：这是另一名学生一心听讲。
- [ ] 与之俱学
  理由：同学只说明一同受教，不能单独说明为何学得不同。

提示：找他坐着听棋时心里却想做的那件事。
解析：“则不得”说学艺的条件。想着拿弓去射大鸟，是后来那名学生没有专注的具体情形。

## 单选：末句的“与之俱学”已经给出哪一个相同点？还不能由此推出什么？ {#check.7.q3}
考点：l2.skill.companion-yu
语境：check.7.p.chess

- [x] 两人同从弈秋学，不能推出二人所学一样好
- [ ] 弈秋也在和两人一起学，所以三人不分高下
  理由：弈秋的身份是教者，末句又明说“弗若”。
- [ ] 二人都在想射鸟，所以都没听见弈秋
  理由：专心的一人“惟弈秋之为听”。

提示：回到“诲二人”，分清教师与一同学习的伙伴。
解析：“与之”把第二人同首名学生连起来，“俱”落在学，“弗若”却说表现不及；同学和同样学得好是两回事。

## 原文：教学例句 {#check.7.p.bridge}
> 西桥低于东桥。春水至，西桥没。匠以水急，闭其桥，惟东桥可行。水退，匠与其徒下视，见一柱折。徒为匠持灯，匠以绳引新柱就其处。柱既定，乃开西桥。
译文：西桥比东桥低。春水到来，西桥被淹。工匠因为水流急而封了西桥，只有东桥还可通行。退水后，工匠和徒弟下去查看，见一根桥柱折了。徒弟替工匠举灯，工匠用绳牵引新柱就位。桥柱安稳后，才重新开放西桥。
词注：没：读 mò，淹没。
  惟：只有，说当时还可通行的桥。
  就：到，这里是让新柱到安放之处。

## 单选：两座桥究竟哪座被封了？哪种解释能兼顾开头的比较和后面的安排？ {#check.7.q4}
考点：l2.skill.compare-yu
语境：check.7.p.bridge

- [ ] “低于东桥”说西桥建在东桥下面，工匠须两座一起封
  理由：这里比高低，后文还留一座桥通行。
- [ ] 东桥更低，所以人们只走西桥
  理由：“惟东桥可行”明指还能通行的是东桥。
- [x] 西桥较低，涨水后被淹，水急时先关闭它

提示：先用“比”读“于”，再回头核对“其桥”是哪一座。
解析：西桥低于东桥，春水也确实漫没西桥。比较本身不能证明一定会封桥，后文“水急”才交代工匠当时的决定。

## 单选：“以水急”和“以绳引新柱”各自补上原文哪一层意思？ {#check.7.q5}
考点：l2.skill.reason-yi
语境：check.7.p.bridge

- [ ] 两处都在报工匠此时能用的材料
  理由：水急是已出现的水势，正文写工匠因此闭桥。
- [x] 先交代封桥缘由，后交代安柱所用工具
- [ ] 先说用急流冲倒旧柱，后说绳索引起退水
  理由：封桥在退水前，绳用在退水后的修桥。

提示：把两处“以”放回各自紧挨着的主要动作。
解析：水急能回答“为何闭桥”，绳能回答“怎样引新柱”。两次“以”联结的事情不同。

## 排序：从水退到重新通桥，哪几件事有明确先后？ {#check.7.q6}
考点：l2.skill.then-nai
语境：check.7.p.bridge

- [3] 桥柱安稳后再开西桥
  理由：“既定，乃开”给复通添了一项实际条件。
- [2] 徒弟执灯，工匠把新柱安放到位
  理由：发现旧柱断折才动手替换。
- [1] 师徒同去察看，发现断柱
  理由：“水退”只让人能下去查，并没有立刻开桥。

提示：没有了急流，就一定马上能通行吗？读到“既定”再判断。
解析：“与其徒”是同去察看，“为匠持灯”是帮忙。修好柱子才解除封闭，这便是“乃”不能提前的原因。
