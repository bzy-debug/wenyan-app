# 检查：谁做了什么，话里又省了什么 {#check.7}

## 原文：教学例句 {#check.7.p.trust}
> 吾数告之，众终不我信。事验，众始谢。
译文：我多次告诉他们，众人始终不信我；后来事情应验了，众人才向我道歉。

## 单选：谁原先没有相信谁？ {#check.7.q1}
考点：l2.skill.negative-object
语境：check.7.p.trust

- [x] 众人不相信我
- [ ] 众人不相信自己
  理由：“我”是说话人。
- [ ] 我不相信众人
  理由：后文致歉的是谁？

提示：读成“众终不信……”试试看。
解析：“众”放在句首，是众人不信。“我”虽然在“信”前面，仍然是他们当初不信的那个人。

## 原文：教学例句 {#check.7.p.find}
> 舟人失篙，问童：“汝何见？”童指浅滩之木。
译文：船夫丢了篙，问孩子：“你看见什么？”孩子指向浅滩的木头。

## 单选：船夫想问孩子什么？ {#check.7.q2}
考点：l2.skill.question-object
语境：check.7.p.find

- [x] 孩子看见的东西
- [ ] 是谁看见了孩子
  理由：“汝”是船夫面对的孩子，由他来说自己看见了什么。
- [ ] 孩子在哪里见船夫
  理由：孩子指的是浅滩上的木头，没指船夫所在的地方。

提示：把“汝何见”读成“你看见了什么”试试。
解析：“汝何见”读成“汝见何”就好懂了。孩子指向浅滩的木头，正是在说自己看见了什么。

## 原文：教学例句 {#check.7.p.stones}
> 匠取石之平者为阶，其锐者弃之。
译文：工匠取平坦的石头做台阶，尖锐的便弃置。

## 找原文证据：工匠挑什么样的石头做台阶？找出那个字。 {#check.7.q3}
考点：l2.skill.post-nominal
语境：check.7.p.stones

- [x] 平
- [ ] 阶
  理由：“阶”是石头要做成的东西。
- [ ] 匠
  理由：工匠作决定。

提示：做成台阶的石头，和丢掉的尖石哪里不同？
解析：工匠在石头里挑“平者”，尖的就扔掉。“平”正是他看中的地方。

## 原文：教学例句 {#check.7.p.coins}
> 商遗钱七枚。童得五枚，以还商。
译文：商人丢了七枚钱，孩子拾得五枚，归还给他。

## 单选：“七枚”和“五枚”各指什么？ {#check.7.q4}
考点：l2.skill.post-count
语境：check.7.p.coins

- [ ] 商人与孩子的年龄
  理由：商人丢了钱，孩子捡了钱，两个数都是在数钱。
- [ ] 遗失的时间与寻找的次数
  理由：枚是物品的量词。
- [x] 遗失数与找回数

提示：“遗”说商人丢了多少，“得”又是谁捡到的？
解析：“遗钱七枚”说商人丢了多少，“得五枚”说孩子捡回多少。七枚里只写到这五枚的下落。

## 原文：教学例句 {#check.7.p.stone}
> 客题名于石，童问于客：“何名也？”
译文：客人把名字题在石上，孩子向客人问：“这是什么名字？”

## 单选：两个“于”各引出什么？ {#check.7.q5}
考点：l2.skill.post-pp
语境：check.7.p.stone

- [ ] 两处都是实施者
  理由：题字的是客人，石头只是他写字的地方。
- [x] 题写的位置；提问的对象
- [ ] 两个都是地点
  理由：客是能回答的人。

提示：分别试问“把字写在哪里”“向谁开口问”。
解析：名字题在石头上，孩子向客人发问。第一个“于”后面是位置，第二个“于”后面是能回答的人。

## 原文：教学例句 {#check.7.p.lamp}
> 客举灯照壁，置案上，复读壁书。
译文：客人举灯照墙，把灯放在桌上，又读墙上的文字。

## 单选：“置案上”省了什么？怎样补全才通顺？ {#check.7.q6}
考点：l2.skill.ellipsis-object
语境：check.7.p.lamp

- [x] 把灯放在桌上
- [ ] 把墙移上桌
  理由：可移动且刚在手里的是什么？
- [ ] 把壁上文字抄到桌面
  理由：原文没有抄写动作。

提示：客人刚才手里举着什么？
解析：客人手里刚举起的是灯，放到案上的自然也是灯。墙上的字留在原处，客人还要接着读。
