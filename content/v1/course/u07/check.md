# 检查：还原语序与叙事成分 {#check.7}

## 原文：教学例句 {#check.7.p.trust}
> 吾数告之，众终不我信。事验，众始谢。
译文：我多次告诉他们，众人始终不信我；事情得到验证，众人才致歉。

## 单选：谁原先没有相信谁？ {#check.7.q1}
考点：l2.skill.negative-object
语境：check.7.p.trust

- [x] 众人不相信我
- [ ] 众人不相信自己
  理由：“我”是说话人。
- [ ] 我不相信众人
  理由：后文致歉的是谁？

提示：将“不我信”暂排成“不信……”。
解析：“我”在否定词与动词间作宾语，主语是众。

## 原文：教学例句 {#check.7.p.find}
> 舟人失篙，问童：“汝何见？”童指浅滩之木。
译文：船夫丢了篙，问孩子：“你看见什么？”孩子指向浅滩的木头。

## 单选：问句让孩子补充哪项信息？ {#check.7.q2}
考点：l2.skill.question-object
语境：check.7.p.find

- [x] 孩子看见的东西
- [ ] 是谁看见了孩子
  理由：“汝”是被问要作观察报告的人。
- [ ] 孩子在哪里见船夫
  理由：答话动作指向物件。

提示：把“何”放回“见”的对象位置。
解析：问句可展开为“汝见何”。

## 原文：教学例句 {#check.7.p.stones}
> 匠取石之平者为阶，其锐者弃之。
译文：工匠取平坦的石头做台阶，尖锐的便弃置。

## 找原文证据：哪一个字提出选石作台阶的条件？ {#check.7.q3}
考点：l2.skill.post-nominal
语境：check.7.p.stones

- [x] 平
- [ ] 阶
  理由：这是用途。
- [ ] 匠
  理由：工匠作决定。

提示：在“石之……者”里找限制词。
解析：“石之平者”是在石头中选表面平坦者。

## 原文：教学例句 {#check.7.p.coins}
> 商遗钱七枚。童得五枚，以还商。
译文：商人丢了七枚钱，孩子拾得五枚，归还给他。

## 单选：“七枚”和“五枚”各指什么？ {#check.7.q4}
考点：l2.skill.post-count
语境：check.7.p.coins

- [ ] 商人与孩子的年龄
  理由：数目跟在钱与所得之物后。
- [ ] 遗失的时间与寻找的次数
  理由：枚是物品的量词。
- [x] 遗失数与找回数

提示：注意“遗”与“得”是两个环节。
解析：七枚限定所失，五枚限定所得，不能据此说七枚全找回。

## 原文：教学例句 {#check.7.p.stone}
> 客题名于石，童问于客：“何名也？”
译文：客人把名字题在石上，孩子向客人问：“这是什么名字？”

## 单选：两个“于”各引出什么？ {#check.7.q5}
考点：l2.skill.post-pp
语境：check.7.p.stone

- [ ] 两处都是实施者
  理由：石头并没有做题写动作。
- [x] 题写的位置；提问的对象
- [ ] 两个都是地点
  理由：客是能回答的人。

提示：分别问“写在哪里”和“向谁问”。
解析：第一个介宾限定题名地点，第二个限定问话面向的人。

## 原文：教学例句 {#check.7.p.lamp}
> 客举灯照壁，置案上，复读壁书。
译文：客人举灯照墙，把灯放在桌上，又读墙上的文字。

## 单选：“置案上”可补成什么？ {#check.7.q6}
考点：l2.skill.ellipsis-object
语境：check.7.p.lamp

- [x] 把灯放在桌上
- [ ] 把墙移上桌
  理由：可移动且刚在手里的是什么？
- [ ] 把壁上文字抄到桌面
  理由：原文没有抄写动作。

提示：沿着举起又放下的物件阅读。
解析：前句手持灯，案上是放灯的位置。
