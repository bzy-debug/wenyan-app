# 课文：宾语前置：不我知与何求 {#l2.7}
简介：“不我知”是谁不了解谁？“何以取鱼”是在问鱼还是问用具？试着用答话把原句读通。

## 正文

读“不我知”，可以先在心里把它念成“不知我”：不了解的是别人，别人不了解的是“我”。在否定句里，“我”“之”这样的宾语有时会提前，放在“不”“未”和动词之间。碰到别的否定句，仍要看谁做了什么。

“何求”问“求什么”，“何以书之”则问“用什么来写它”。后一问的“何”跟“以”相连，回答时可以说“用笔”。“谁”在动词前却未必是宾语：“谁买”完全可能是在问买东西的人。

## 知识点：否定句中的代词宾语 {#l2.skill.negative-object}
义项：在否定句里，认出放到动词前面的“我”“之”等宾语
领域：句法
要诀：先试读成“不知我”“未救之”。
讲解：如“众不之信”，不相信的是众人，他们不信的是客人说的话。“之”虽在“信”前，仍是“信”的宾语。
例句：l2.ex.negative-object

## 原文：教学例句 {#l2.ex.negative-object}
> 客言有急，众不之信。
译文：客人说有急事，众人不相信他的话。

## 知识点：疑问宾语前置 {#l2.skill.question-object}
义项：看清“何”“谁”问的是动词或介词后本该接的什么
领域：句法
要诀：用一句完整的话回答“何”或“谁”。
讲解：“吾何取”可以答“我取书”，书正好接在“取”后。“何以取”则问“用什么取”，答话要能接在“以”后。
例句：l2.ex.question-object

## 原文：教学例句 {#l2.ex.question-object}
> 客执空囊，问：“吾何取？”
译文：客人拿着空袋，问：“我取什么呢？”

## 原文：古籍引文 {#l2.7.p.known}
> 莫我知也夫！
译文：没有人了解我呀！

## 单选：把“莫我知”换个语序，哪句话还是孔子的意思？ {#l2.7.q1}
考点：l2.skill.negative-object
语境：l2.7.p.known

- [ ] 我无所知
  理由：孔子说的是别人不了解他，没有说自己一无所知。
- [x] 莫知我
- [ ] 我莫知人
  理由：这样便成了“我不了解别人”，把孔子的意思倒过来了。

提示：试把“我”放回“知”后。
解析：孔子叹的是“没有人了解我”。把“知”同“我”合起来读作“知我”，就不会读成“我不了解别人”。

## 找原文证据：原句中哪一个字指被了解的人？ {#l2.7.q2}
考点：l2.skill.negative-object
语境：l2.7.p.known

- [ ] 知
  理由：“知”是了解。要找被了解的人，还得问“了解谁”。
- [x] 我
- [ ] 莫
  理由：“莫”是“没有谁”，不是孔子说自己时用的那个字。

提示：孔子觉得，旁人不了解谁？
解析：“知”是了解，“莫”是没有人。那个希望被了解的人，用一个“我”字点了出来。

## 原文：教学例句 {#l2.7.p.request}
> 生见医，问曰：“此药何服？”医问：“子何苦？”对曰：“苦寒。”
译文：学生去见医生，问：“这药怎么服？”医生问：“你哪里难受？”学生答：“冷得难受。”

## 单选：医生和学生各问了一句话。“寒”答的是哪一问？ {#l2.7.q3}
考点：l2.skill.question-object
语境：l2.7.p.request

- [ ] “此药何服”的“何”
  理由：学生在问药怎么服。“寒”说的是病人的感受。
- [x] “子何苦”的“何”
- [ ] 两处都问用药温度
  理由：“苦寒”说的是人受寒难受，没有说药是凉的。

提示：把第二问试读成“子苦何”。
解析：学生想知道怎样服药，医生问的是他苦于什么。答“寒”，说的是哪里不舒服。

## 原文：教学例句 {#l2.7.p.sell}
> 客持布至市，问商曰：“吾布谁买？”商指舟人曰：“彼欲买之。”
译文：客人拿布去市场，问商人：“谁买我的布？”商人指船夫说：“他想买。”

## 单选：“吾布谁买”是在打听谁？ {#l2.7.q4}
考点：l2.skill.question-object
语境：l2.7.p.sell

- [ ] 量布的工具
  理由：商人指着船夫，答的是谁想买布。
- [x] 买布的行动者
- [ ] 被买的物品
  理由：要卖的东西开头就说了，是“吾布”。

提示：商人指着船夫，说他想做什么？
解析：商人说“彼欲买之”——船夫想买布。“谁”问的正是这个买主，放在“买”前应作主语。

## 原文：教学例句 {#l2.7.p.net}
> 渔人问童：“汝何以取鱼？”童举网。渔人笑曰：“非徒有网足也。”
译文：渔人问孩子：“你用什么捕鱼？”孩子举起网。渔人笑着说：“仅有网还不够。”

## 找原文证据：孩子拿什么回答“何以取鱼”？请从原文找出来。 {#l2.7.q5}
考点：l2.skill.question-object
语境：l2.7.p.net

- [x] 网
  第几处：1
- [ ] 渔人
  第几处：1
  理由：渔人提出问题。
- [ ] 鱼
  理由：鱼是要捕取的对象。

提示：看孩子举起什么作为回答。
解析：孩子举起网，等于回答“我用网捕鱼”。所以“何以”问的是“用什么”。

## 单选：若直接把“何以取鱼”读为“取什么鱼”，漏掉了什么？ {#l2.7.q6}
考点：l2.skill.question-object
语境：l2.7.p.net

- [ ] 渔人是否会笑
  理由：笑发生在答问之后。
- [x] “以”在询问凭借的工具
- [ ] 童子打了几条鱼
  理由：渔人只问用什么取鱼，没有问捕了几条。

提示：已经知道要“取鱼”，还缺哪一层意思？
解析：“取”的对象已经明说是鱼。把“何以”读成“以何”，就知道渔人想问用哪样工具去取。

## 原文：教学例句 {#l2.7.p.guest}
> 客困道中，呼人告急。里人疑其诳，未之救。及知其病，乃舁归。
译文：客人困在路上，喊人求救。村人疑他骗人，还没有救他。知道他生病后，才抬他回去。

## 单选：“未之救”用今天的话怎么说？ {#l2.7.q7}
考点：l2.skill.negative-object
语境：l2.7.p.guest

- [ ] 他还没救村人
  理由：呼人告急的是客人，来救人的是村人。
- [ ] 他没有救人的办法
  理由：“未”说当时还没去救，没有说村人想不出救法。
- [x] 村人还没有救他

提示：沿用“里人”作主语。
解析：“里人疑其诳”，起疑的是村人。接下来的“未之救”还是说他们：他们还没救那个求助的客人。

## 原文：教学例句 {#l2.7.p.letter}
> 兄远游，久无信。母问儿曰：“汝不我告，何也？”儿乃以兄书进。
译文：哥哥远游，许久没有消息。母亲问儿子：“你不告诉我，为什么？”儿子才把哥哥的信呈上。

## 单选：母亲抱怨哪件事？ {#l2.7.q8}
考点：l2.skill.negative-object
语境：l2.7.p.letter

- [ ] 自己没有告诉儿子
  理由：“汝”是母亲当面叫的儿子，应当是儿子告诉母亲。
- [ ] 哥哥拒绝回家
  理由：母亲问儿子为什么没告诉她，没有问哥哥愿不愿意回家。
- [x] 儿子没有告诉她消息

提示：把“不我告”展开为“不告……”。
解析：母亲说“汝不我告”，也就是“你不告诉我”。儿子拿出哥哥的信，正好接上她追问的消息。
