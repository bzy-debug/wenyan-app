# 课文：宾语前置：不我知与何求 {#l2.7}
简介：比较否定句中的代词和疑问句中的问词，读清实际动作方向。

## 正文

取一句现代语序的“他不了解我”，要读“不我知”，可以先按意思暂排作“不知我”。“我”仍是被了解的一方。否定句中的代词宾语常可提前；这条线索不能反过来证明每个否定句都必须前置。

疑问句中“谁欺”“何求”可试读成“欺谁”“求什么”。介词的对象也可能提前，例如“何以书之”可还原为“以何书之”。先找正在提问的空位，再判断说话人想知道人物、物品还是工具。

## 知识点：否定句中的代词宾语 {#l2.skill.negative-object}
义项：把否定词后的代词读回动词的对象
领域：句法
要诀：把否定词后的代词读回动词的对象
讲解：检查谁是动作发出者。若在否定词与动词之间的代词是受事，可先调回动词后试读。
例句：l2.ex.negative-object

## 原文：教学例句 {#l2.ex.negative-object}
> 客言有急，众不之信。
译文：客人说有急事，众人不相信他的话。

## 知识点：疑问宾语前置 {#l2.skill.question-object}
义项：用动词或介词还原问题的空位
领域：句法
要诀：用动词或介词还原问题的空位
讲解：将“何”“谁”放到有联系的动词或介词之后，看看应由什么类型的答案填入。
例句：l2.ex.question-object

## 原文：教学例句 {#l2.ex.question-object}
> 客执空囊，问：“吾何取？”
译文：客人拿着空袋，问：“我取什么呢？”

## 单选：哪种换序保留“我”的作用？ {#l2.7.q1}
考点：l2.skill.negative-object
语境：l2.7.p.known

- [ ] 我无所知
  理由：这里感叹无人了解自己，并非自称没有知识。
- [x] 莫知我
- [ ] 我莫知人
  理由：这样“我”成了了解别人的一方。

提示：试把“我”放回“知”后。
解析：“莫”表示没有人，“我”是“知”的对象，否定环境中代词在动词前。

## 找原文证据：原句中哪一个字指被了解的人？ {#l2.7.q2}
考点：l2.skill.negative-object
语境：l2.7.p.known

- [ ] 知
  理由：“知”是动作。
- [x] 我
- [ ] 莫
  理由：“莫”表示没有人做这个动作。

提示：问“知谁”。
解析：说话人把自己作为“知”的宾语。

## 原文：教学例句 {#l2.7.p.request}
> 生见医，问曰：“此药何服？”医问：“子何苦？”对曰：“苦寒。”
译文：学生见医生，问：“这药怎样服用？”医生问：“你苦于什么？”回答说：“苦于寒冷。”

## 单选：哪一个“何”能由“寒”来回答？ {#l2.7.q3}
考点：l2.skill.question-object
语境：l2.7.p.request

- [ ] “此药何服”的“何”
  理由：这句问服药方法，寒并非服药方法。
- [x] “子何苦”的“何”
- [ ] 两处都问用药温度
  理由：答语明说“苦寒”。

提示：把第二问试读成“子苦何”。
解析：第二问要补痛苦的对象。第一问要补方式，两种“何”不能硬套同一分析。

## 原文：教学例句 {#l2.7.p.sell}
> 客持布至市，问商曰：“吾布谁买？”商指舟人曰：“彼欲买之。”
译文：客人拿布去市场，问商人：“谁买我的布？”商人指船夫说：“他想买。”

## 单选：“吾布谁买”里的“谁”承担哪种角色？ {#l2.7.q4}
考点：l2.skill.question-object
语境：l2.7.p.sell

- [ ] 量布的工具
  理由：回答“舟人”给出的是人。
- [x] 买布的行动者
- [ ] 被买的物品
  理由：物品在话题“吾布”里已经交代。

提示：看看商人以什么身份的人回答。
解析：“吾布”是话题，答语中的“彼”作“欲买”的主语。疑问词在动词前也可能本来就是主语。

## 原文：教学例句 {#l2.7.p.net}
> 渔人问童：“汝何以取鱼？”童举网。渔人笑曰：“非徒有网足也。”
译文：渔人问孩子：“你用什么捕鱼？”孩子举起网。渔人笑着说：“仅有网还不够。”

## 找原文证据：哪一处写出问题里“何”要问的工具？ {#l2.7.q5}
考点：l2.skill.question-object
语境：l2.7.p.net

- [x] 网
  第几处：1
- [ ] 渔人
  第几处：1
  理由：渔人提出问题。
- [ ] 鱼
  理由：鱼是要捕取的对象。

提示：看孩子举起什么作为回答。
解析：“何以”可读成“以何”。举网示意工具，和问句的空位相合。

## 单选：若直接把“何以取鱼”读为“取什么鱼”，漏掉了什么？ {#l2.7.q6}
考点：l2.skill.question-object
语境：l2.7.p.net

- [ ] 渔人是否会笑
  理由：笑发生在答问之后。
- [x] “以”在询问凭借的工具
- [ ] 童子打了几条鱼
  理由：数目从未被问起。

提示：找与“何”连用的介词。
解析：“鱼”已经是“取”的对象。“何”对应的是“以”的空位，不是“取”的空位。

## 原文：教学例句 {#l2.7.p.guest}
> 客困道中，呼人告急。里人疑其诳，未之救。及知其病，乃舁归。
译文：客人困在路上，喊人求救。村人疑他骗人，还没有救他。知道他生病后，才抬他回去。

## 单选：“未之救”补成现代语序应怎样说？ {#l2.7.q7}
考点：l2.skill.negative-object
语境：l2.7.p.guest

- [ ] 他还没救村人
  理由：求救的人是谁？
- [ ] 他没有救人的办法
  理由：下句抬走病者，指向具体救助行为。
- [x] 村人还没有救他

提示：沿用“里人”作主语。
解析：“未”否定“救”，“之”指求救的客人，宾语提前。

## 原文：教学例句 {#l2.7.p.letter}
> 兄远游，久无信。母问儿曰：“汝不我告，何也？”儿乃以兄书进。
译文：哥哥远游，许久没有消息。母亲问儿子：“你不告诉我，为什么？”儿子才把哥哥的信呈上。

## 单选：母亲抱怨哪件事？ {#l2.7.q8}
考点：l2.skill.negative-object
语境：l2.7.p.letter

- [ ] 自己没有告诉儿子
  理由：“汝”直接点出发出告知动作的一方。
- [ ] 哥哥拒绝回家
  理由：原句问的是谁没有相告。
- [x] 儿子没有告诉她消息

提示：把“不我告”展开为“不告……”。
解析：“我”处在否定词与“告”之间，指本该接收消息的母亲。
