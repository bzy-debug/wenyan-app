# 课文：递钥匙的人接到哪道嘱咐 {#fword.48.1}
简介：同一句里有“吾”有“尔”；轮到对方回话，“我”又换了主人。小店的这串钥匙到底交给谁？

## 正文

交班的人说“吾守西扉，尔守东扉”，接班的人答“我当先验其钥”。前一句自称的是师傅，后一句自称的成了弟子。在每句旁边写上发话人的名字，再把“吾／我”“尔／汝”换成人名，责任才不会分错。

如果说“或告师曰”，要补一个不具名的报信人；如果说“夜雨或至”，夜雨已是主语，暂时拿不准的是会不会来。后者是较晚文献中可以见到的用法。“独西扉未闭”仍须有人去关门，“但验东钥”却只限定查钥匙这一项差事；读“只”，还要问它管到哪儿。

## 知识点：“吾／我”随开口的人换指 {#fword.s.speaker}
义项：第一人称可以由不同的说话人先后使用
领域：虚词
要诀：遇见另一人“曰”，重找本句说话人。
讲解：师傅说“吾守西扉”，徒弟答“我当先验其钥”。在师傅那句填师傅，在徒弟那句填徒弟，不能从头到尾用一个名字替“我”。
例句：fword.p.keys

## 知识点：“尔／汝”指本次说话的听者 {#fword.s.hearer}
义项：第二人称指向当面受话的人
领域：虚词
要诀：问谁被点名去做事，再看“汝”或“尔”能换成谁。
讲解：父亲在屋上说“汝以绳授我”，受嘱咐的是屋下的女儿；绳该从女儿手中递到父亲手中。
例句：fword.p.roof

## 知识点：“或”修饰尚难断定的事 {#fword.s.possible}
义项：也许、或许，不指一个无名的人
领域：虚词
要诀：主语已经明白时，试读成“未必，一种可能是……”。
讲解：“或告师”要补报信人；“夜雨或至”本有可能降下的雨。两个“或”连在一回传话里，只有前一个占了人的位置。
例句：fword.p.keys

## 知识点：“独”“但”限定对象或动作 {#fword.s.limit}
义项：唯独一个、只做一事
领域：虚词
要诀：圈出“只”管住的是人、物，还是整项行动。
讲解：“但取绳”不许顺手去搬梯；“独女留”则只剩女儿一人没有避雨。前者限要做的事，后者限留下的人。
例句：fword.p.roof

## 原文：教学例句 {#fword.p.keys}
> 师谓徒曰：“吾守西扉，尔守东扉。”徒曰：“我当先验其钥，师可安坐。”或告师曰：“夜雨或至。”师曰：“但验东钥，西钥吾自收之。”及暮，诸扉皆闭，独西扉未闭。
译文：师傅向徒弟分派任务，自己守西门，让徒弟守东门。徒弟答应先查钥匙，请师傅坐下休息。有人来报信，说夜里也许下雨。师傅让徒弟只验东门的钥匙，自己收西门的。傍晚各处门都关上了，唯独西门还没关。
词注：扉：门。
  验：查验。

## 原文：教学例句 {#fword.p.roof}
> 父登屋，谓女曰：“吾葺其漏处，汝以绳授我。”女曰：“吾手有泥，父少待。”或闻雷而走告邻人，父曰：“雨或自北来，未可知也。但取绳，勿取梯。”邻人皆避，独女留。
译文：父亲爬上房顶，告诉女儿自己补漏，要她把绳子递给自己。女儿说自己手上有泥，请父亲稍等。有人听到雷声赶去告诉邻居。父亲说雨也许从北边来，还说不准；只让取绳，不要取梯。邻居都去躲雨，唯独女儿留下。
词注：葺：修补。
  授：递给。

## 单选：把师徒的“吾守西扉”“我当先验其钥”记成两项差事，该给谁记哪项？ {#fword.q.48.1.1}
考点：fword.s.speaker
语境：fword.p.keys

- [ ] 师傅独自守门、验钥，徒弟坐下
  理由：第二句话已经换成“徒曰”，请师傅坐下的正是徒弟。
- [ ] 徒弟守西门，师傅验钥匙
  理由：这把两句自称的话都安到了听话人身上。
- [x] 师傅守西门，徒弟验钥匙

提示：先换人名读“师谓徒”，再换人名读“徒曰”。
解析：师傅和徒弟都能自称“我”，称呼相同不等于领受差事的是同一人。

## 单选：父亲说“汝以绳授我”，绳子应当怎样传？ {#fword.q.48.1.2}
考点：fword.s.hearer
语境：fword.p.roof

- [x] 由女儿交给屋顶的父亲
- [ ] 由父亲交给屋下的女儿
  理由：句中“汝”是被叫来递绳的人；“我”是想接到绳的父亲。
- [ ] 由邻人交给女儿
  理由：父女已经交谈，邻人到听雷时才提及。

提示：先把“汝”“我”都换成当面两人的称呼。
解析：父亲开口时，“汝”指听话的女儿。是她递，他接。

## 单选：哪种记法能保留“或告师曰：‘夜雨或至。’”原有的把握？ {#fword.q.48.1.3}
考点：fword.s.possible
语境：fword.p.keys

- [ ] 师傅已确认夜间下过雨
  理由：报来的只是可能的天气，不是见过雨的记录。
- [x] 有人报说，夜间也许有雨
- [ ] 有两个人到来，其中一个已经淋了雨
  理由：头一“或”才占了报信人的位置，第二个在“夜雨”之后。

提示：一个“或”后面是谁在说话，另一个前面已经有谁或什么？
解析：“或告”里的“或”代人；夜雨本已是后句的主语，“或”说的是还拿不准。

## 找原文证据：若要说明父亲当时只许女儿拿一种东西，哪句话约束的是她手里的差事？ {#fword.q.48.1.4}
考点：fword.s.limit
语境：fword.p.roof

- [ ] 独女留
  理由：这是说到最后谁没有走，不是父亲如何限定取物。
- [ ] 父少待
  理由：这句是女儿请父亲稍等，没有说该取哪样东西。
- [x] 但取绳，勿取梯

提示：“只”后面若是“取”，它主要限定哪件事？
解析：“但”收窄到取绳，后面的“勿取梯”把另一样排除；“独女留”才是在众人中排出女儿。

## 单选：若两处“吾”都记作父亲，哪一件事就记错了人？ {#fword.q.48.1.5}
考点：fword.s.speaker
语境：fword.p.roof

- [x] 手上有泥的是女儿
- [ ] 在屋上修漏的是女儿
  理由：这正是父亲发话时自己承担的事。
- [ ] 听雷去报信的人一定是女儿
  理由：报信只说“或”，没有把这事放在女儿口中。

提示：只在“女曰”处换一次发话人。
解析：“吾葺”是父亲自称，“吾手有泥”是女儿自称；两个“吾”各随一句话走。

## 单选：若给西门和东门各挂一个当值人的名牌，“尔守东扉”该挂谁的？ {#fword.q.48.1.6}
考点：fword.s.hearer
语境：fword.p.keys

- [ ] 来报雨的人，只有他是新来者
  理由：报雨还在后头，师傅交代的是眼前的徒弟。
- [x] 徒弟的，师傅正向他派差
- [ ] 师傅的，因为这四个字是师傅说的
  理由：开口的人自称“吾”，“尔”称被他说话的人。

提示：“师谓徒”的“谓”把话送向哪一人？
解析：即使是师傅说的，“尔”也不随书写者或讲述者走，它指此刻被吩咐的徒弟。

## 单选：父亲听到雷，为什么仍可以说“雨或自北来，未可知也”？ {#fword.q.48.1.7}
考点：fword.s.possible
语境：fword.p.roof

- [ ] “或”指一个走来的邻人，姓雨
  理由：“自北来”前已说“雨”，父亲又明说不能确定。
- [ ] 父亲断定大雨已从北面下到屋顶
  理由：如果已确认，不必接“未可知也”。
- [x] 雷声有人听到，雨从北面来却还只是推测

提示：分出前一句所听的声音和后一句要判断的方向。
解析：同一段中“或闻雷”指有人听到雷声；父亲把“或”放在“雨”后，是给判断留余地。

## 单选：傍晚点数门扇，“独西扉未闭”要怎样填表？ {#fword.q.48.1.8}
考点：fword.s.limit
语境：fword.p.keys

- [x] 西门一处尚开，其余已关
- [ ] 只有师傅一个人曾经关过门
  理由：“独”所限定的是西门，不是关门的人。
- [ ] 只许西门的人去验钥匙
  理由：验哪把钥匙是先前的嘱咐，当前一句在记门的开闭。

提示：看“独”紧贴着西门，还是紧贴着师傅。
解析：句首先概说众门已闭，再以“独”提出例外，不能把某一扇门的状态扩大到所有门。
