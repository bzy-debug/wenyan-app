# 检查：山亭交班与石桥开放 {#check.48}

## 原文：教学例句 {#fword.p.check-torch}
> 兄付炬于弟曰：“我守桥，汝但送火至亭。”弟曰：“吾送火，尔留桥上。”或指西云曰：“雪或夜至。”众皆归，独兄不去。
译文：哥哥把火把交给弟弟，说自己守桥，只让弟弟送火到亭子。弟弟答应自己去送火，让哥哥留在桥上。有人指着西边的云，说雪也许夜里才到。众人都已回去，唯独哥哥没走。
词注：炬：火把。
  亭：歇脚的亭子。

## 原文：教学例句 {#fword.p.check-port}
> 吏告众：“毋举帆，勿发。”客顾舟中无货，问其故。舟人曰：“此送客之舟，非载货之舟也。”风未定，有人请发，舟人弗许，仍不举帆。
译文：官吏告诫众人，不要扬帆，不要出发。客人看船里没有货，询问原因。船夫说这是载客的船，不是货船。风势没稳定，有人请求开船，船夫没答应，仍旧没扬帆。
词注：顾：回头看。
  举帆：升起船帆。

## 原文：教学例句 {#fword.p.check-weir}
> 客问守堰者：“水已至西田欤？”曰：“至东田耳，未至西田。”客指西渠曰：“渠犹闭乎？”守者颔之。客见父老相与开渠，水遂西流，叹曰：“美哉，此渠！两田皆得灌，不亦善乎？”
译文：客人问看守水坝的人，水是否已经引至西田。对方答只到了东田，还没到西田。客人指着西渠，问是否仍然堵塞，守堰人点头。客人见乡亲们一同开渠，水终于向西流，便赞叹渠道修得好，两块田都能灌溉，实在是好事。
词注：堰：拦水、引水的堤坝。
  灌：灌溉。

## 单选：“吾送火，尔留桥上”是哪一个人的复述？哥哥的“但”和末句的“独”把差事和留下的人怎样分开？ {#fword.q.48.check.1}
考点：fword.s.speaker
语境：fword.p.check-torch

- [x] 弟弟说自己只管送火，“尔”是哥哥；最后只有哥哥没走
- [ ] 弟弟口中的“吾”指哥哥，所以弟弟留桥
  理由：换成弟弟说话以后，自称随弟弟走。
- [ ] 弟弟除了送火还须替哥哥守桥，两人都留守
  理由：“汝但送火”只委托送火；最后“独兄不去”更明说留下的只有哥哥。

提示：先标弟弟是这次发话人，再核对先前委托的差事。
解析：谁开口谁可自称“我”。“汝但送火”限定弟弟的任务，最后说“独兄不去”也跟二人的分工一致。

## 单选：“或指西云曰：‘雪或夜至。’”后能确认哪一件，哪一件仍不能确认？ {#fword.q.48.check.2}
考点：fword.s.possible
语境：fword.p.check-torch

- [ ] 所有人都指着云，人人都断定夜里会下雪
  理由：“或”没有概括全体，也没保证后面的天气。
- [x] 有个人已指出云，雪是否夜里到还没定
- [ ] 云也许有人去指，但雪已经到了
  理由：前一个“或”是未具名的指云人，后一个才把到雪说成可能。

提示：能画出一个人指云，能否据此画成地上已有雪？
解析：别把无定代词同表示可能的副词换位。消息确实有人说，所说的情形却仍待证。

## 单选：从“毋举帆，勿发”到“弗许，仍不举帆”，哪种记法区别了禁令和实际行为？ {#fword.q.48.check.3}
考点：fword.s.ban
语境：fword.p.check-port

- [ ] 官吏只报告以前没开船，船夫后来又命令官吏停下
  理由：前两句是官吏对众人发令；“弗许”写船夫如何回应请求。
- [ ] 两段都只是禁令，无法知道最终究竟动没动帆
  理由：叙述者在后面明确说“仍不举帆”。
- [x] 官吏先禁扬帆出发，船夫后来没答应请求，也没扬帆

提示：注意说话人先后变化，也注意后半已经离开引号。
解析：“毋、勿”引导人别做；“弗、不”在这段叙述中报告决定和动作。后两句才是禁令得到遵从的根据。

## 单选：“舟中无货”和“非载货之舟也”分开说清了什么？ {#fword.q.48.check.4}
考点：fword.s.no-have
语境：fword.p.check-port

- [x] 前一句说船上没有货物，后一句说这条船不属于货船
- [ ] 两句都说港中根本没有能运货的船
  理由：两句都只谈眼前一条船，且后一项说类别。
- [ ] 前一句指船只类别，后一句只说这次恰好空载
  理由：这把陈述次序倒转了：“无”接的是“货”，“非”否认它是载货之舟。

提示：问一次“里面有什么”，再问一次“它算哪一种”。
解析：眼前没货，一艘货船也可能空载。要知道这是客船，还得看主持者所作的身份判断。

## 单选：“水已至西田欤”“渠犹闭乎”都要对方怎样答？开渠前的实情又是什么？ {#fword.q.48.check.5}
考点：fword.s.yes-no
语境：fword.p.check-weir

- [ ] 两句都要核实情况，答复却是两田已经得水
  理由：“至东田耳”把到水范围限在东田，此时西渠尚未开通。
- [x] 都要核实情况；水只到东田，西渠确实还堵着
- [ ] 第一句委婉询问，第二句却赞渠道修得好；水只到东田
  理由：守者点头确认“犹闭”，赞美渠道还在疏通之后。

提示：先读给水划范围的“耳”，再看点头确认了什么。
解析：“欤”与“乎”在这两处都要事实答复。守者以“耳”限在东田，又点头确认西渠尚堵；说到水遂西流，情况才改变。

## 单选：最后两句话，一句有“哉”，一句有“不亦……乎”。它们还会向守堰者索取什么答复吗？ {#fword.q.48.check.6}
考点：fword.s.acclaim
语境：fword.p.check-weir

- [ ] 前句赞渠，后句又追问西田究竟得水没有
  理由：“水遂西流”已是眼见，“两田皆得灌”是评价的理由。
- [ ] 前句仍问渠修得美不美，后句却在禁止灌田
  理由：“美哉”是赞叹，“善乎”肯定两田得益。
- [x] 先赞渠道，再以反问肯定两田得灌是好事；都无须再报水到哪儿

提示：分别把两句换成“真好啊”与“不也是好事吗”，再读前面的实情。
解析：赞叹说出感受，反问邀人认同评价。若要找真正求新消息的问句，得回到段首。
