# 课文：等一句实答，还是听一声赞叹 {#fword.48.3}
简介：哪句话要报数，哪句话只盼别人认同？看看语气与眼前事实能否合在一起。
回读：g26.skill.er fword.p.tray

## 正文

客人问“今日设二席欤”，席数须由主人报明。客人若亲见两人合力抬起病者，再说“不亦善乎”，他已经作出了称许，用反问请旁人想想是不是如此。

“善哉”可以只是喝彩，也不需另请人拿出证据。再遇“余二枚耳”，句末是在收紧数目，不是赞两枚钱多好。把要查证的事、已经有的评价和说到哪里为止分开读，句末几个字便能听清。

## 知识点：“乎／欤”请听者判定是或否 {#fword.s.yes-no}
义项：真正发问，要求听者确认一项情况
领域：虚词
要诀：看看答话有没有新报出的事实，也可给出一句明确的否定。
讲解：“今日设二席欤”，主人若答一席，正好纠正客人猜的数量；这位客人还没看清席数，并不是在赞美席多。
例句：fword.p.tray

## 知识点：“不亦……乎”邀人认同一项已有判断 {#fword.s.delight}
义项：用反问加重肯定或评价
领域：虚词
要诀：先还原成陈述，再找讲话人已拿在手里的理由。
讲解：孟子先说明百姓也能进文王的苑囿，才说“不亦宜乎”。他明明认为百姓的想法合理，不是在索取一个未知的园地尺寸。
例句：fword.p.park

## 知识点：“哉”着重已有的赞叹 {#fword.s.acclaim}
义项：一句感叹给人或事物加上评价
领域：虚词
要诀：再问一遍能不能靠报出事实来作答；不能时先听说话人的感情。
讲解：旅人已经见到泉水，才叹“清哉，斯泉”。这里对水表示赞美，若译成“不知道泉清不清”，反倒把亲眼所见抹掉了。
例句：fword.p.spring

## 原文：教学例句 {#fword.p.tray}
> 客入席，问：“今日设二席欤？”主曰：“一席耳。”客见父子相扶举一病者，安之席上，曰：“同力救人，不亦善乎！厚哉，父子之心！”
译文：客人入座，问今天是否备了两张席子。主人答只有一张。客人见父子合力抬病者，安顿在席上，感叹两人同心救人做得好，并赞他们心地厚道。
词注：席：铺来坐卧的席子。
  厚：宽厚。

## 原文：教学例句 {#fword.p.spring}
> 行者问：“泉在岭南乎？”樵者指岭北。行者至，见泉新通，曰：“清哉，斯泉！”汲少许，为同行病者留之，曰：“今得水以济人，不亦幸乎？”
译文：行路人问泉是否在岭南，樵夫指给他看在岭北。他到泉边，见泉刚疏通，赞叹泉水清澈。他取了些水留给同行病人，说今天能有水救人，不也是幸运吗？
词注：汲：打水。
  济：救助。

## 原文：古籍引文 {#fword.p.park}
> 曰：“文王之囿方七十里，刍荛者往焉，雉兔者往焉，与民同之。民以为小，不亦宜乎？”
译文：孟子说，文王的苑囿每边长七十里，割草打柴的人可以去，捕野鸡野兔的人也可以去，和百姓同享。百姓觉得地方还小，这不也合乎情理吗？
词注：囿：苑囿，养禽兽等的园地。
  刍荛：割草、砍柴。
  宜：合乎情理。

## 单选：若主人误把“今日设二席欤”当成称赞，只说“承让”，他还欠客人什么？ {#fword.q.48.3.1}
考点：fword.s.yes-no
语境：fword.p.tray

- [x] 今天究竟是不是两张席子的实答
- [ ] 对两父子品格的评价
  理由：此刻客人还没见到父子救人。
- [ ] 病者为什么需要有人抬
  理由：这也是后来才发生的事情，不是当前问题。

提示：哪一句给出了客人原来不知道的数目？
解析：“欤”把二席作为待确认的判断，主人的“一席耳”给出实际数目，也纠正了客人的猜测。

## 单选：孟子说“民以为小，不亦宜乎”，希望齐王承认什么？ {#fword.q.48.3.2}
考点：fword.s.delight
语境：fword.p.park

- [ ] 百姓不得捕猎，因此要求把园子缩小
  理由：“往焉”“与民同之”都表示可以进入、可以共享。
- [x] 百姓也能进苑谋生，觉得七十里的苑还小，是有道理的
- [ ] 先找人重测苑地，孟子还不知道它有多大
  理由：方七十里早在开头说过，末句评的是百姓看法是否合理。

提示：末句能换成哪句有理由的肯定话？
解析：先写百姓如何从苑中受益，再以反问加重“宜”的判断。问句在这里并不索要一个新的面积。

## 单选：“清哉，斯泉”同开头问泉的位置相比，语气怎样变了？ {#fword.q.48.3.3}
考点：fword.s.acclaim
语境：fword.p.spring

- [ ] 两处都等樵者指出泉在南还是北
  理由：第二句行者已经到了，说的是水质。
- [ ] 此前赞地方好，现在问水清不清
  理由：“至，见泉新通”让第二句有了亲眼所见的对象。
- [x] 此前要问路，现在亲见清泉而称赞

提示：试把“清哉”换成“真清啊”，还合不合眼前情景？
解析：“哉”把对眼前泉水的赞叹说足，没有让樵者再报一次地点。

## 单选：“一席耳”里，主人给客人设下什么数目界线？ {#fword.q.48.3.4}
考点：g26.skill.er
语境：fword.p.tray

- [x] 席子只有一张，不能算两张
- [ ] 一张已经铺好，接下来必然铺第二张
  理由：“耳”把回答限为一张，没许诺添铺。
- [ ] 主人只是听到席上有人说话
  理由：“耳”在此附在数目后，与听觉无关。

提示：若略去“耳”，“一席”的回答少强调了什么？
解析：“耳”有止于此数之意，客人原猜两席，主人将数目收回到一张。

## 单选：行者起初说“泉在岭南乎”，樵者只指岭北，为什么也算回答？ {#fword.q.48.3.5}
考点：fword.s.yes-no
语境：fword.p.spring

- [ ] 行者本来已经断定泉在岭南
  理由：真已断定就无需问路；樵者也用另一方向纠正他。
- [x] 手指北面已经否认“在岭南”并指出去向
- [ ] 他想证明那里的水清甜
  理由：方向不说明水质，行者得亲自走到泉边才见到。

提示：问句里究竟等待确认哪一项事实？
解析：“乎”在这处是真问。一个否定动作也能回复，不必照搬书面的“否”字。

## 单选：已为同行病者留下泉水，行者为什么还问“不亦幸乎”？ {#fword.q.48.3.6}
考点：fword.s.delight
语境：fword.p.spring

- [ ] 担心自己完全没打到水，仍在问泉哪里有
  理由：他已经汲水，还留给同行者。
- [ ] 发令禁止生病的人喝水
  理由：“幸”是在评际遇，未出现禁令。
- [x] 要人认同今天能得水济人确实幸运

提示：若拿掉反问的外形，行者已经有哪项判断？
解析：水已到手，能帮助病人。这个“乎”托住反问的肯定语气，不要求补报取了几升。

## 找原文证据：哪一句直接称许父子的心地，而不是询问席数？ {#fword.q.48.3.7}
考点：fword.s.acclaim
语境：fword.p.tray

- [x] 厚哉，父子之心
- [ ] 今日设二席欤
  理由：还等主人告知的是席数。
- [ ] 安之席上
  理由：这是把病者安顿到哪里，没有表示说话者的称赞。

提示：看看哪个形容词加“哉”，后面又点明在说谁。
解析：“厚”指宽厚，“哉”带出赞叹。听者已经知道被赞的父子是谁，不必把它另凑成一问一答。

## 单选：“同力救人，不亦善乎”若改成只叙述一件已经看到的事，会漏了什么？ {#fword.q.48.3.8}
考点：fword.s.delight
语境：fword.p.tray

- [ ] 主人另备两张席子的事实
  理由：前面答的恰是只有一席。
- [x] 客人赞成他们救人的评价，以及盼人也认同的口气
- [ ] 客人仍不知他们究竟抬没抬病人
  理由：客人已经“见父子……举一病者”，行动是亲见。

提示：试分开“他们抬了人”和“这么做真好”。
解析：“同力救人”已交代动作；“不亦善乎”加的是客人有根据的评价。
