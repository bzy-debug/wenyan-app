# 课文：门上无锁，能不能推门 {#fword.48.2}
简介：从一段守仓人的口供里，区分没做、没有、不是以及不要做。
回读：l2.skill.negative-fei fword.p.warehouse

## 正文

守仓人说“西门无锁。吾见封，弗启”，前一句说少了一样东西，后一句才交代他没有动手开门。有人从“无锁”推出“门必开了”，正好把没有东西与没有动作混为一谈。

“毋启”或“勿启”是在吩咐人别开门；“守者不启”才报告行为。“此非开仓之令”更不是催人开关，只是说这道文书算不上开仓令。从这几种话里得出的事实各有边界。

## 知识点：“不／弗”否定实际动作 {#fword.s.act-neg}
义项：叙述一方没有做某事
领域：虚词
要诀：从后面的动词取回没做的事，别当成对另一人下令。
讲解：仓丁“见封，弗启”。封条在那里，他没开门。这里在报告他的决定，告诫他“毋启”的命令却来自前一句仓吏。
例句：fword.p.warehouse

## 知识点：“无”否定事物存在 {#fword.s.no-have}
义项：某处没有某物或某人没拥有某物
领域：虚词
要诀：把“无”后的东西找出来，再看句子限定在哪一处。
讲解：“舟中无篙”只说船上没有竹竿。下文明说岸上有篙，不能推成世上没有，也不能推成船夫已经把竿扔掉。
例句：fword.p.sail

## 知识点：“毋／勿”告诫听者不要行动 {#fword.s.ban}
义项：用禁止句要求听者停止或避免某事
领域：虚词
要诀：有命令就找受命的人；要证明他确实没做还须另找一句。
讲解：“勿解缆”是船师嘱咐；接着“子不解”才是儿子照办。头一句单独出现时，不能预知儿子听从与否。
例句：fword.p.sail

## 原文：教学例句 {#fword.p.warehouse}
> 仓吏告守者曰：“未得令，毋启西门。”又指门封曰：“莫坏之。”暮有客至，门无锁而有封。守者见封，弗启。客出关书曰：“此行旅之券也，非开仓之令。”乃宿门外。
译文：仓吏嘱咐守仓人，没接到命令不要开西门。又指着门上的封条，叫他别损坏。傍晚有客人来，门上没有锁，贴着封条；守仓人看见封条，没有开门。客人拿出通行文书，说这是旅人的凭证，不是开仓命令，便在门外过夜。
词注：封：封条。
  券：凭证。

## 原文：教学例句 {#fword.p.sail}
> 船师命子：“风急，勿解缆。”子不解。客曰：“舟中无篙，能行乎？”子曰：“此系舟之索，非篙也。”指岸上竹篙，请客取之。
译文：船老大让儿子在风大时不要解缆，儿子没有去解。客人说船里没篙，还能开船吗？孩子说这是系船的绳子，不是篙，又指着岸上的竹篙，请客人去拿。
词注：缆：系船的绳索。
  篙：撑船的长竿。

## 单选：若要写一笔守仓人确实没有做什么，从“弗启”能写下哪件事？ {#fword.q.48.2.1}
考点：fword.s.act-neg
语境：fword.p.warehouse

- [ ] 客人决定不用打开自己的旅券
  理由：“启”接在看见门封后，主语还是守仓人。
- [x] 他看见封条，没有把门打开
- [ ] 仓吏从未交代能不能开门
  理由：仓吏已明说“毋启”，但发令和守者办不办是两件事。

提示：这两个字落在客人到来以前还是以后？
解析：命令下达在先，客来见封在后；“弗”把后一个开门动作否定。

## 单选：“舟中无篙”当时能排除哪种情况？ {#fword.q.48.2.2}
考点：fword.s.no-have
语境：fword.p.sail

- [ ] 岸边有一根竹竿
  理由：后文孩子所指的竹篙恰在岸上。
- [ ] 客人知道怎样找竹竿
  理由：“无”说的是舟中存有什么，没有判断客人会不会找。
- [x] 撑船的竹竿就在这条船内

提示：把“无”的东西和“无”的地点一起读。
解析：缺篙的是这条船。船中没有并不等于岸上也没有。

## 单选：吏先说“毋启”，又指封说“莫坏之”。听到这两句时能确认什么？ {#fword.q.48.2.3}
考点：fword.s.ban
语境：fword.p.warehouse

- [x] 他告诫守者别开门、别损坏封条；守者是否照做还待下文
- [ ] 第一句是禁开门，第二句是报告此前一直无人损坏封条
  理由：吏指着门封直接交代守者，“莫坏之”仍是向人发出的禁令。
- [ ] 两句都是守者事后报告自己做过什么
  理由：“告守者”“又指门封曰”都出自仓吏，指向守者以后该怎么做。

提示：两句话的听者有没有换？这时开门和损坏封条可曾发生？
解析：“莫”在“莫知”中可以指无人；此处承接吏对守者的嘱咐，同“毋”一样劝止行动。见封未启才是守者照办的记录。

## 单选：孩子说“非篙也”，他为什么仍指得出一根竹篙？ {#fword.q.48.2.4}
考点：l2.skill.negative-fei
语境：fword.p.sail

- [ ] 索与篙本是同一物，只是换一种称呼
  理由：孩子把船上的索与岸上的竹竿分开指明。
- [x] 只否认眼前系舟索算篙，岸上另有真篙
- [ ] 断定岸边什么木竹都没有
  理由：“非”否定的是眼前物的类别，随后明说岸上有篙。

提示：先把“非”前面被谈的那件物填出来。
解析：有系舟索是事实；它不是撑船竹竿也是事实。“非”否认后一种分类，没把所有竹竿都否掉。

## 找原文证据：船师发话以后，哪处能直接证明儿子当时怎么做的？ {#fword.q.48.2.5}
考点：fword.s.act-neg
语境：fword.p.sail

- [ ] 勿解缆
  理由：这是船师的命令，尚不能证明儿子执行。
- [ ] 舟中无篙
  理由：这是客人见到船内少了什么。
- [x] 子不解

提示：找叙述儿子行动的句子，暂且跳过引号。
解析：“子不解”是行为记录。“不”否定解缆，和父亲口中的“勿”担任的工作不同。

## 单选：“门无锁而有封”若读成门已经敞开，为何站不住？ {#fword.q.48.2.6}
考点：fword.s.no-have
语境：fword.p.warehouse

- [x] 没有的是锁，门上仍有封条，守者也没有开门
- [ ] 因为“无锁”说明钥匙一定在仓吏手中
  理由：文中未说钥匙由谁收存。
- [ ] 因为“有封”是说今天已有开门的命令
  理由：封是门上的封条；客人所持的也不是开仓令。

提示：“无”直接连着哪个东西？动作“启”另写在哪里？
解析：“无”否定一种东西的存在。少锁不等于有人已推开这扇门。

## 单选：要在儿子采取行动以前记下父亲给的那条规矩，该选哪种表述？ {#fword.q.48.2.7}
考点：fword.s.ban
语境：fword.p.sail

- [ ] 船上没有缆绳可解
  理由：后文孩子还指给客人看系舟的绳子。
- [x] 风急，不许去解缆
- [ ] 船师已经替儿子解了缆
  理由：“勿”是禁止，没报告有人代为动手。

提示：想想“勿解”若只读成“没解”，会删掉哪一层？
解析：船师直接命令孩子避免解缆。后一句“子不解”才说他真的没有做。

## 单选：旅人出示文书后说“非开仓之令”，这会推翻哪一种想法？ {#fword.q.48.2.8}
考点：l2.skill.negative-fei
语境：fword.p.warehouse

- [ ] 他手上有一份通行凭证
  理由：文中“此行旅之券也”正面承认了这一点。
- [ ] 他本人确实到了仓门外
  理由：他的来意和身份并不因文书类别的否定而消失。
- [x] 这份文书可以授权打开仓门

提示：“非”从“开仓之令”上撤掉的是什么身份？
解析：他出示的是旅券，不能把它认作开仓令；“非”不会把已经拿出的文书变成没有。
