# 检查：两回问答：牛棚与留宿 {#check.3}

## 原文：教学例句 {#p.check.3.r1}
> 夜雨，牧人闭牛牢。旦，主人问牧人：“昨何失？”对曰：“未失牛，失一绳耳。”主人取绳，授牧人，使系门。
译文：夜里下雨，牧人关上牛栏。清早主人问他：“昨晚丢了什么？”他答：“牛没丢，只丢了一根绳子。”主人取来绳子，交给牧人，叫他拴门。
词注：牢：圈养牲口的地方，此处是牛栏。
  旦：天亮、早晨。
  耳：罢了，把所失的东西限定为一根绳。

## 原文：古籍引文 {#p.check.3.r2}
> 止子路宿，杀鸡为黍而食之。
译文：老人留下子路过夜，杀鸡，煮小米饭，拿来给子路吃。
词注：止：挽留，是留子路在家过夜。
  黍：一种谷物，“为黍”是煮黍饭。
  食：读 sì，给人东西吃，这里是拿饭招待子路。

## 单选：“昨何失”期待的回答应当说明什么？ {#q.check.3.1}
考点：skill.interrogative-object
语境：p.check.3.r1

- [ ] 牛栏在哪个地方 {#q.check.3.1.o1}
  理由：“昨”已标出时间，提问的是“失”的对象。
- [ ] 牧人为什么失职 {#q.check.3.1.o2}
  理由：原文问“何失”，并没有先责问缘由。
- [x] 失掉的是哪件东西 {#q.check.3.1.o3}
  理由：答语报出一根绳；前句“何”所问的就是遗失的东西。

提示：把“失一绳”接到问句下面。
解析：答语报出一根绳；前句“何”所问的就是遗失的东西。

## 单选：“对曰”前不写人名，由谁说这句话才答得上？ {#q.check.3.2}
考点：skill.respondent
语境：p.check.3.r1

- [ ] 清早来发问的主人 {#q.check.3.2.o1}
  理由：主人刚问过牧人，如今在等他回话。
- [ ] 夜里来偷绳的人 {#q.check.3.2.o2}
  理由：原文只说少了绳，没有说有人来偷。
- [x] 昨夜闭牛栏的牧人 {#q.check.3.2.o3}
  理由：主人直接问牧人，“对曰”把话头递给被问的人。

提示：回头找“主人问……”后面的人。
解析：主人直接问牧人，“对曰”把话头递给被问的人。

## 找原文证据：主人问起时，牧人确认哪一项损失还没有发生？ {#q.check.3.3}
考点：skill.not-yet
语境：p.check.3.r1

- [x] 失牛 {#q.check.3.3.o1}
  理由：“未失牛”说明截至当时牛没丢，后半句另说确实丢了一根绳。
- [ ] 失一绳 {#q.check.3.3.o2}
  理由：绳是确实少了一根，“未”没有管到这一小句。
- [ ] 系门 {#q.check.3.3.o3}
  理由：这是主人随后吩咐的动作，与失物不同。

提示：“未”紧挨哪件事？
解析：“未失牛”说明截至当时牛没丢，后半句另说确实丢了一根绳。

## 单选：主人从自己拿着绳变为牧人拿着绳，是哪个动作起的作用？ {#q.check.3.4}
考点：skill.action-verb
语境：p.check.3.r1

- [x] 授 {#q.check.3.4.o1}
  理由：“授牧人”是把绳递给牧人，这个动作完成了交接。
- [ ] 闭 {#q.check.3.4.o2}
  理由：“闭牛牢”是昨夜牧人的动作。
- [ ] 取 {#q.check.3.4.o3}
  理由：“取”只说主人拿到绳，还没交给牧人。

提示：物件换了持有的人。
解析：“授牧人”是把绳递给牧人，这个动作完成了交接。

## 单选：留客、杀鸡、煮饭这三件事，原文怎样交代做事的人？ {#q.check.3.5}
考点：skill.subject-continuity
语境：p.check.3.r2

- [x] 主人留客，接着也是主人备饭 {#q.check.3.5.o1}
  理由：被留的是子路，留客的人接着备饭款待他。后面的动词可以沿用先前的主语。
- [ ] 前两步主人做，煮饭忽然换成子路 {#q.check.3.5.o2}
  理由：连续叙述备饭，没有出现换人的字样。
- [ ] 子路留下主人，主人再备饭 {#q.check.3.5.o3}
  理由：“止子路宿”是挽留子路，不是子路挽留别人。

提示：先定“止子路宿”中谁是被挽留的人。
解析：被留的是子路，留客的人接着备饭款待他。后面的动词可以沿用先前的主语。

## 找原文证据：主人要准备饭菜，动手杀了什么？ {#q.check.3.6}
考点：skill.direct-object
语境：p.check.3.r2

- [x] 鸡 {#q.check.3.6.o1}
  理由：“杀鸡”和“为黍”各有各的对象；备好的饭菜给子路吃。
- [ ] 子路 {#q.check.3.6.o2}
  理由：子路是被招待的客人。
- [ ] 黍 {#q.check.3.6.o3}
  理由：黍是煮饭用的小米。

提示：在“杀”后面找，再跟“为黍”分开。
解析：“杀鸡”和“为黍”各有各的对象；备好的饭菜给子路吃。
