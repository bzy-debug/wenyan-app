## 原文：教学例句 {#p.check.3.cobbler}
> 工缀履于檐下。
译文：工匠在屋檐下缝补鞋子。

## 选段：点选缝补这一动作。 {#q.check.3.1}
考点：skill.action-verb
语境：p.check.3.cobbler

- [ ] 工 {#q.check.3.1.o1}
  理由：工匠做这个动作。
- [ ] 履 {#q.check.3.1.o2}
  理由：鞋子是缝补的对象。
- [x] 缀 {#q.check.3.1.o3}

提示：哪一个字能回答“做了什么”？
解析：“工／缀履／于檐下”依次交代行事者、动作和对象、地点。

## 单选：“食之”中，哪一个词所指的人接受饭食？ {#q.check.3.2}
考点：skill.direct-object
语境：p.check.3.carve

- [ ] “之”指鸡，丈人喂鸡 {#q.check.3.2.o1}
  理由：鸡在“杀鸡”里是被宰的对象，已用来待客。
- [ ] “之”指丈人，子路做饭给他 {#q.check.3.2.o2}
  理由：“止子路宿”先说主人留客，接下来的准备饭食沿用丈人为主语。
- [x] “之”指子路，他是受招待的人 {#q.check.3.2.o3}

提示：先找被留下过夜的客人，再读最后的动作。
解析：“止子路宿”交代客人。后面杀鸡、为黍都是主人的动作，“食之”表示给子路吃。

## 原文：教学例句 {#p.check.3.lamp}
> 客取火，燃灯以照书。
译文：旅客取来火种，点灯照着书本。

## 单选：“燃灯”的主语怎样补足？ {#q.check.3.3}
考点：skill.subject-continuity
语境：p.check.3.lamp

- [x] 取火的旅客 {#q.check.3.3.o1}
- [ ] 灯 {#q.check.3.3.o2}
  理由：灯是被点燃的物件。
- [ ] 著书的人 {#q.check.3.3.o3}
  理由：原句没有提到著书人。

提示：前后两个动作是否组成一件事？
解析：取火是点灯的前一步，前句的“客”仍然是点灯者。

## 原文：教学例句 {#p.check.3.west-road}
> 客问樵者曰：“西径通村乎？”对曰：“通。”
译文：旅客问樵夫：“西边的小路通到村子吗？”樵夫回答：“通。”

## 选段：点选第二个“通”是谁说的。 {#q.check.3.4}
考点：skill.respondent
语境：p.check.3.west-road

- [x] 樵者 {#q.check.3.4.o1}
- [ ] 客 {#q.check.3.4.o2}
  理由：旅客问路，尚不知道答案。
- [ ] 西径 {#q.check.3.4.o3}
  理由：西边小路是谈论的对象。

提示：先辨出“问”的对象。
解析：问答之间换了说话人。“对曰”的主语承接被问的樵夫。

## 原文：教学例句 {#p.check.3.drum}
> 众已集，鼓未鸣。
译文：众人已经集合，鼓还没响。

## 单选：在叙述的这个时刻，哪项理解正确？ {#q.check.3.5}
考点：skill.not-yet
语境：p.check.3.drum

- [x] 人已集合，鼓声还没响起 {#q.check.3.5.o1}
- [ ] 从此不会再击鼓 {#q.check.3.5.o2}
  理由：“未”不足以判断将来。
- [ ] 人还未到，鼓已响过 {#q.check.3.5.o3}
  理由：“已”和“未”对应的动作被调换了。

提示：分别指出“已”和“未”后面的词。
解析：“已”修饰“集”，“未”修饰“鸣”。两者对照交代当时情形。

## 原文：教学例句 {#p.check.3.tribute}
> 吏见车至，问曰：“车中载何物？”
译文：官吏看见车来了，问：“车里装着什么？”

## 单选：哪一个答语切中问题？ {#q.check.3.6}
考点：skill.interrogative-object
语境：p.check.3.tribute

- [x] 车上装的是木材 {#q.check.3.6.o1}
- [ ] 车夫傍晚动身 {#q.check.3.6.o2}
  理由：“何物”没有问时间。
- [ ] 车是从南门来的 {#q.check.3.6.o3}
  理由：“何物”没有问来处。

提示：“载”的对象才是要回答的信息。
解析：“载何物”的答案要给出被运载的事物，木材符合。
