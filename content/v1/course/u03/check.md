# 检查：谁做了什么，又问了什么 {#check.3}

## 原文：教学例句 {#p.check.3.cobbler}
> 工缀履于檐下。
译文：工匠在屋檐下缝补鞋子。

## 找原文证据：工匠正在补鞋。哪个字表示“缝补”？ {#q.check.3.1}
考点：skill.action-verb
语境：p.check.3.cobbler

- [ ] 工 {#q.check.3.1.o1}
  理由：工是做事的人。用哪个字说他正在做什么？
- [ ] 履 {#q.check.3.1.o2}
  理由：履是被修补的东西。修的动作在哪里？
- [x] 缀 {#q.check.3.1.o3}

提示：哪一个字能回答“做了什么”？
解析：“履”是鞋，“于檐下”是屋檐下，工匠手上在做的事落在“缀”字上。

## 原文：古籍引文 {#p.check.3.carve}
> 止子路宿，杀鸡为黍而食之。
译文：（丈人）留下子路过夜，杀鸡做黍饭给他吃。“食”在“食之”中读 sì，意为给人吃。

## 单选：“食之”读作“给他吃”。谁得到了款待？ {#q.check.3.2}
考点：skill.direct-object
语境：p.check.3.carve

- [ ] “之”指鸡，丈人喂鸡 {#q.check.3.2.o1}
  理由：鸡在句里是备下的食物，还是受款待的客人？
- [ ] “之”指丈人，子路做饭给他 {#q.check.3.2.o2}
  理由：谁留客，谁投宿？把两人角色分开。
- [x] “之”指子路，他是受招待的人 {#q.check.3.2.o3}

提示：先找被留下过夜的客人，再读最后的动作。
解析：开头先说丈人留子路过夜。后来杀鸡、做黍饭的都是主人，给饭吃的客人便是子路。

## 原文：教学例句 {#p.check.3.lamp}
> 客取火，燃灯以照书。
译文：旅客取来火种，点灯照着书本。

## 单选：是谁用取来的火点了灯？ {#q.check.3.3}
考点：skill.subject-continuity
语境：p.check.3.lamp

- [x] 取火的旅客 {#q.check.3.3.o1}
- [ ] 灯 {#q.check.3.3.o2}
  理由：灯是被点燃的。谁已把火拿来？
- [ ] 著书的人 {#q.check.3.3.o3}
  理由：文中提到书，是否也交代了写书的人？

提示：前后两个动作是否组成一件事？
解析：客人取来火种，接着用它点灯照书。到“燃灯”时，做事的人仍是客人。

## 原文：教学例句 {#p.check.3.west-road}
> 客问樵者曰：“西径通村乎？”对曰：“通。”
译文：旅客问樵夫：“西边的小路通到村子吗？”樵夫回答：“通。”

## 找原文证据：谁回答西边的小路能通村子？ {#q.check.3.4}
考点：skill.respondent
语境：p.check.3.west-road

- [x] 樵者 {#q.check.3.4.o1}
- [ ] 客 {#q.check.3.4.o2}
  理由：客先问了路。再问自己：谁在回答客人？
- [ ] 西径 {#q.check.3.4.o3}
  理由：西径是谈论的对象。找出能答话的人。

提示：客人遇到了谁，才问起去村子的路？
解析：开头是客人问樵夫，接着答“通”的是听见这个问题的樵夫。

## 原文：教学例句 {#p.check.3.drum}
> 众已集，鼓未鸣。
译文：众人已经集合，鼓还没响。

## 单选：众人和鼓，这会儿各是什么情形？ {#q.check.3.5}
考点：skill.not-yet
语境：p.check.3.drum

- [x] 人已集合，鼓声还没响起 {#q.check.3.5.o1}
- [ ] 从此不会再击鼓 {#q.check.3.5.o2}
  理由：这一刻还没发生，就能断定以后也不发生吗？
- [ ] 人还未到，鼓已响过 {#q.check.3.5.o3}
  理由：把“已”“未”各自连回后一个字。

提示：分别指出“已”和“未”后面的词。
解析：“已集”是人已经到齐，“未鸣”是鼓还没有响。把两句停在同一个时刻读。

## 原文：教学例句 {#p.check.3.tribute}
> 吏见车至，问曰：“车中载何物？”
译文：官吏看见车来了，问：“车里装着什么？”

## 单选：怎样答，官吏才知道他想问的事？ {#q.check.3.6}
考点：skill.interrogative-object
语境：p.check.3.tribute

- [x] 车上装的是木材 {#q.check.3.6.o1}
- [ ] 车夫傍晚动身 {#q.check.3.6.o2}
  理由：发车时刻能说明车里装的物品吗？
- [ ] 车是从南门来的 {#q.check.3.6.o3}
  理由：来路回答“从哪儿来”。这次问的是什么？

提示：假如把车上的东西卸下来，会看到什么？
解析：官吏问车上装了什么。说出所载的是木材，就答到了“何物”。
