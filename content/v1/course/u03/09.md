# 课文：否定与疑问 {#l1.9}
简介：看清谓语前的“未”限定到什么时间，再看“何”要问哪一件事物。

## 正文

“未”给一个动作设下时间界线。读“客未至”，能确定的只是**到叙述的这一刻，他还没有到**。若要判断明天会不会到，还须找后文。自编对比“客复不至”写又一次没来，“客将至”才是将要到来。

### 找到被“未”管着的部分

《论语·先进》有“未能事人，焉能事鬼？”先读出“未〔能事人〕”，再看“焉能”怎样承接前句。孔子借问题把注意力带回眼前的事。“未”不能单独当成对将来的预言。[核对原文](https://github.com/kanripo/KR1h0004/blob/89b65734d4386e2478179c77741a968bfc627abb/KR1h0004_011.txt#L104-L108)

### 把疑问词换成一个可能的答案

自编例句“客何求？”试答“求舟”，便能看出“何”占的是“求”的对象位置。再读“何人求舟？”试答“客求舟”，这里空出的才是找船的人。两句都有“何”和“求”，所问内容却不同。

**读问句有两步**。先用“某人、某物、某处”等替换疑问词，找出空位；再结合上下文看说话者是在索取消息，还是借问题表达态度。能找出空位，并不保证对方真在等待回答。

## 知识点：未 {#skill.not-yet}
义项：说明到某时动作尚未发生
领域：句法
要诀：判断否定的动作和时间界线
讲解：“未”放在谓语前，表示到叙述的时间还没有发生该动作。单凭“未”不能推断以后是否会发生。
例句：p.ex.not-yet

## 知识点：何 {#skill.interrogative-object}
义项：询问事物或内容
领域：句法
要诀：读清疑问词所问的对象
讲解：“何”在“有何物”一类结构中询问是什么；在“何求”中，也可放在动词前，读作“求什么”。根据动词和答语确定提问目标。
例句：p.ex.interrogative-object

## 原文：古籍引文 {#p.ex.not-yet}
> 季路问事鬼神。子曰：“未能事人，焉能事鬼？”
译文：季路询问怎样事奉鬼神。孔子说：“连事奉人还没有做到，怎么能事奉鬼呢？”“焉能”有反问语气。

## 原文：教学例句 {#p.ex.interrogative-object}
> 客曰：“子何求？”答曰：“求书。”
译文：客人说：“你求什么？”对方答道：“求书。”

## 原文：教学例句 {#p.l1.9.shutter}
> 夜半雨止，客未寝。
译文：半夜雨停了，旅客还没有睡。

## 单选：可以从“客未寝”确定什么？ {#q.l1.9.1}
考点：skill.not-yet
语境：p.l1.9.shutter

- [ ] 客人整夜一定不睡 {#q.l1.9.1.o1}
  理由：“未”只说明当时的情况。
- [x] 到雨停时客人还没睡 {#q.l1.9.1.o2}
- [ ] 客人已睡醒 {#q.l1.9.1.o3}
  理由：“未寝”不能读成“睡醒”。

提示：只说在文中那个时刻能确定的事。
解析：“未”否定“寝”，以半夜雨停时为观察点。

## 原文：教学例句 {#p.l1.9.parcel}
> 童携一囊，母问曰：“囊中有何物？”
译文：孩子带着一个袋子，母亲问：“袋里有什么？”

## 单选：哪句话能直接回答母亲？ {#q.l1.9.2}
考点：skill.interrogative-object
语境：p.l1.9.parcel

- [x] 袋里装着豆子 {#q.l1.9.2.o1}
- [ ] 袋子是昨天缝的 {#q.l1.9.2.o2}
  理由：这是在回答制袋时间。
- [ ] 袋子放在车上 {#q.l1.9.2.o3}
  理由：这是在回答袋子的位置。

提示：留意“何”后面的“物”。
解析：“何物”问的是袋中物品的种类，说明装的东西即可。

## 原文：教学例句 {#p.l1.9.water}
> 井已成，水未至。
译文：井已经挖好，水还没有涌来。

## 选段：点选仍未发生的事所对应的动词。 {#q.l1.9.3}
考点：skill.not-yet
语境：p.l1.9.water

- [ ] 水 {#q.l1.9.3.o1}
  理由：水是尚未涌来的事物，题目问动词。
- [ ] 成 {#q.l1.9.3.o2}
  理由：“已成”说明井已经挖好。
- [x] 至 {#q.l1.9.3.o3}

提示：分清“已”与“未”各修饰哪个动作。
解析：“未”紧接在“至”前面，否定到达，并不否定挖井这件事已经完成。

## 原文：教学例句 {#p.l1.9.lesson}
> 师问生曰：“今读何书？”
译文：老师问学生：“今天读什么书？”

## 单选：教师要学生说明什么？ {#q.l1.9.4}
考点：skill.interrogative-object
语境：p.l1.9.lesson

- [ ] 坐在哪里读书 {#q.l1.9.4.o1}
  理由：“何”与“书”相连，不是询问地点。
- [x] 所读的书是哪一本 {#q.l1.9.4.o2}
- [ ] 何时开始读书 {#q.l1.9.4.o3}
  理由：时间“今”已经给出。

提示：把“读”的对象找出来。
解析：“何书”是“读”的对象，应报出书名或说明所读之书。

## 原文：教学例句 {#p.l1.9.return}
> 使者未归，家人方候于门。
译文：使者还没回来，家人正在门口等候。

## 单选：关于使者归来，哪项有原文依据？ {#q.l1.9.5}
考点：skill.not-yet
语境：p.l1.9.return

- [ ] 使者已在家中歇息 {#q.l1.9.5.o1}
  理由：“未归”说明此时尚未归来。
- [x] 家人在门口等候时，使者还未回来 {#q.l1.9.5.o2}
- [ ] 使者将永远不归 {#q.l1.9.5.o3}
  理由：“未”没有断定以后的情形。

提示：看作者写的是眼下，还是一生。
解析：“方候”点明当下情境。“未归”只确定这个时刻前还没回来。

## 原文：教学例句 {#p.l1.9.river}
> 叟执竿临水。童问曰：“翁何求？”叟指水中鱼。
译文：老人持竿来到水边。孩子问：“您想得到什么？”老人指向水中的鱼。

## 选段：点选能补出“求”的对象的字。 {#q.l1.9.6}
考点：skill.interrogative-object
语境：p.l1.9.river

- [ ] 竿 {#q.l1.9.6.o1}
  理由：竿是老人已经拿着的用具。
- [ ] 童 {#q.l1.9.6.o2}
  理由：孩子是发问者。
- [x] 鱼 {#q.l1.9.6.o3}

提示：看老人用手指向什么。
解析：“何求”是在问求什么。老人指鱼，以动作表明要得到鱼。

## 原文：教学例句 {#p.l1.9.bridge}
> 桥未成，行者仍乘舟。
译文：桥还没建好，过路人仍坐船。

## 单选：“未成”解释了哪一情形？ {#q.l1.9.7}
考点：skill.not-yet
语境：p.l1.9.bridge

- [ ] 船还没有造好 {#q.l1.9.7.o1}
  理由：“未成”的主语是桥。
- [ ] 行者永远只能坐船 {#q.l1.9.7.o2}
  理由：文中只写桥成之前。
- [x] 桥尚未建好，所以过路人仍坐船 {#q.l1.9.7.o3}

提示：找出“未成”前面的主语。
解析：“未成”说的是桥目前的状态，后半句写人在此时怎样过河。

## 原文：古籍引文 {#p.l1.9.planting}
> 无臣而为有臣。吾谁欺？欺天乎！
译文：本来没有家臣，却装作有家臣。我是在欺骗谁？欺骗上天吗！这是孔子责备佯设家臣之举时说的话。

## 单选：“吾谁欺”追问的是“欺”这一动作的哪一项？ {#q.l1.9.8}
考点：skill.interrogative-object
语境：p.l1.9.planting

- [ ] 做出欺骗行为的人 {#q.l1.9.8.o1}
  理由：“吾”已经明说出发问者所指的行事者。
- [ ] 欺骗发生的时间 {#q.l1.9.8.o2}
  理由：下文用“天”接着发问，“天”是可能的对象，未指明时刻。
- [x] 受到欺骗的对象 {#q.l1.9.8.o3}

提示：把“欺天”的“天”换成问词，再比较前一问。
解析：“吾”是主语，“谁”是提前的疑问宾语，“欺”是谓语。用“我欺骗谁”补出今天常用的顺序就能看清。
