# 课文：否定与疑问 {#l1.9}
简介：“客未至”，能说他明天也不会来吗？再听听古人怎样问“谁”“什么”。

## 正文

“客未至”只说客人到这会儿还没来。再读两句教学例句：“客复不至”，是又一次没来；“客将至”，才是说快来了。

《论语·先进》里，孔子反问：“未能事人，焉能事鬼？”把“未能事人”整句读完，再读“焉能”：眼前事奉人的事还没做好，怎么谈得上事奉鬼神？[核对原文](https://github.com/kanripo/KR1h0004/blob/89b65734d4386e2478179c77741a968bfc627abb/KR1h0004_011.txt#L104-L108)

要明白“何”究竟问什么，一个办法是试着答一句。看这两句教学例句：“客何求？”可以答“求舟”；“何人求舟？”却要答“客求舟”。前一句问客人想要什么，后一句问的是哪一个人。有些问句和孔子的话一样，还须听一听说话人的语气。

## 知识点：未 {#skill.not-yet}
义项：说明到某时动作尚未发生
领域：句法
要诀：到哪一刻还没发生？
讲解：“未”说眼下还没有。至于以后会不会有，还得往下读。
例句：p.ex.not-yet

## 知识点：何 {#skill.interrogative-object}
义项：询问事物或内容
领域：句法
要诀：如果回答他，要说出什么？
讲解：“囊中有何物”问袋里装什么，“何求”问想得到什么。用一样具体的东西试答，问的意思就清楚了。
例句：p.ex.interrogative-object

## 原文：古籍引文 {#p.ex.not-yet}
> 季路问事鬼神。子曰：“未能事人，焉能事鬼？”
译文：季路询问怎样事奉鬼神。孔子说：“连事奉人还没有做到，怎么能事奉鬼呢？”“焉能”有反问语气。

## 原文：教学例句 {#p.ex.interrogative-object}
> 客曰：“子何求？”答曰：“求书。”
译文：客人说：“你求什么？”对方答道：“求书。”

## 原文：教学例句 {#p.l1.9.shutter}
> 夜半雨止，客未寝。
译文：半夜雨停了，旅客还没有睡。

## 单选：可以从“客未寝”确定什么？ {#q.l1.9.1}
考点：skill.not-yet
语境：p.l1.9.shutter

- [ ] 客人整夜一定不睡 {#q.l1.9.1.o1}
  理由：原文只写雨停时的事，之后的事有交代吗？
- [x] 到雨停时客人还没睡 {#q.l1.9.1.o2}
- [ ] 客人已睡醒 {#q.l1.9.1.o3}
  理由：睡醒之前先要睡着，这和“未寝”合得上吗？

提示：读到雨停的那一刻就好。
解析：雨是半夜停的。到那时客人还没睡，后来什么时候睡，文中没写。

## 原文：教学例句 {#p.l1.9.parcel}
> 童携一囊，母问曰：“囊中有何物？”
译文：孩子带着一个袋子，母亲问：“袋里有什么？”

## 单选：哪句话能直接回答母亲？ {#q.l1.9.2}
考点：skill.interrogative-object
语境：p.l1.9.parcel

- [x] 袋里装着豆子 {#q.l1.9.2.o1}
- [ ] 袋子是昨天缝的 {#q.l1.9.2.o2}
  理由：缝袋子的时间能回答“何物”吗？
- [ ] 袋子放在车上 {#q.l1.9.2.o3}
  理由：回答袋子的位置，母亲就知道里面装什么了吗？

提示：留意“何”后面的“物”。
解析：母亲问袋里装什么，告诉她一件袋里的东西便答得上。

## 原文：教学例句 {#p.l1.9.water}
> 井已成，水未至。
译文：井挖好了，水还没有涌出来。

## 找原文证据：井已经挖好了，水还没怎样？找出写这个动作的字。 {#q.l1.9.3}
考点：skill.not-yet
语境：p.l1.9.water

- [ ] 水 {#q.l1.9.3.o1}
  理由：“水未至”已经点出了水。接下来读它还没有怎样。
- [ ] 成 {#q.l1.9.3.o2}
  理由：“成”前面是“已”还是“未”？
- [x] 至 {#q.l1.9.3.o3}

提示：一件事已经做完，另一件还没发生。各是哪件？
解析：“井已成”和“水未至”要分开读。挖井已经完工，尚未到来的是水。

## 原文：教学例句 {#p.l1.9.lesson}
> 师问生曰：“今读何书？”
译文：老师问学生：“今天读什么书？”

## 单选：老师问“今读何书”，学生该告诉老师什么？ {#q.l1.9.4}
考点：skill.interrogative-object
语境：p.l1.9.lesson

- [ ] 坐在哪里读书 {#q.l1.9.4.o1}
  理由：“何”紧挨着“书”，哪里问到了坐的位置？
- [x] 所读的书是哪一本 {#q.l1.9.4.o2}
- [ ] 何时开始读书 {#q.l1.9.4.o3}
  理由：句首“今”已交代时间，再看“何”后面的字。

提示：把“读”的对象找出来。
解析：老师已经说了“今”，问的是“何书”。答书名或说清所读的是哪本书就好。

## 原文：教学例句 {#p.l1.9.return}
> 使者未归，家人方候于门。
译文：使者还没回来，家人正在门口等候。

## 单选：关于使者归来，哪项有原文依据？ {#q.l1.9.5}
考点：skill.not-yet
语境：p.l1.9.return

- [ ] 使者已在家中歇息 {#q.l1.9.5.o1}
  理由：家人还在门前等，和已经在家休息相合吗？
- [x] 家人在门口等候时，使者还未回来 {#q.l1.9.5.o2}
- [ ] 使者将永远不归 {#q.l1.9.5.o3}
  理由：“未”能让你断定以后也绝不会发生吗？

提示：使者家里的人眼下正在做什么？
解析：家人还在门口等，说明使者到这时还没回来。再往后的事，他们也还不知道。

## 原文：教学例句 {#p.l1.9.river}
> 叟执竿临水。童问曰：“翁何求？”叟指水中鱼。
译文：老人持竿来到水边。孩子问：“您想得到什么？”老人指向水中的鱼。

## 找原文证据：老人想得到什么？找出他伸手指的东西。 {#q.l1.9.6}
考点：skill.interrogative-object
语境：p.l1.9.river

- [ ] 竿 {#q.l1.9.6.o1}
  理由：老人已经拿着竿。还要求的是手里的工具吗？
- [ ] 童 {#q.l1.9.6.o2}
  理由：童是提问的人。老人的手指向什么？
- [x] 鱼 {#q.l1.9.6.o3}

提示：看老人用手指向什么。
解析：“翁何求”是问老人想要什么。他没开口，指向水里的鱼，孩子便能明白。

## 原文：教学例句 {#p.l1.9.bridge}
> 桥未成，行者仍乘舟。
译文：桥还没建好，过路人仍坐船。

## 单选：桥还没修好，过路人怎样过河？ {#q.l1.9.7}
考点：skill.not-yet
语境：p.l1.9.bridge

- [ ] 船还没有造好 {#q.l1.9.7.o1}
  理由：“未成”前的主语是船吗？
- [ ] 行者永远只能坐船 {#q.l1.9.7.o2}
  理由：当前的通行方式能推到永远吗？
- [x] 桥尚未建好，所以过路人仍坐船 {#q.l1.9.7.o3}

提示：行人为什么还得坐船？
解析：桥眼下不能走，行人仍得乘船。“仍”也说明坐船这个办法还在用。

## 原文：古籍引文 {#p.l1.9.planting}
> 无臣而为有臣。吾谁欺？欺天乎！
译文：本来没有家臣，却装作有家臣。我是在欺骗谁？欺骗上天吗！这是孔子责备佯设家臣之举时说的话。

## 单选：“吾谁欺”里，说话人究竟问什么？ {#q.l1.9.8}
考点：skill.interrogative-object
语境：p.l1.9.planting

- [ ] 做出欺骗行为的人 {#q.l1.9.8.o1}
  理由：“吾”已说明谁在做，剩下哪个位置需要发问？
- [ ] 欺骗发生的时间 {#q.l1.9.8.o2}
  理由：疑问词“谁”是在问何时吗？
- [x] 受到欺骗的对象 {#q.l1.9.8.o3}

提示：把“欺天”的“天”换成问词，再比较前一问。
解析：按今天的习惯说，就是“我欺骗谁”。“吾”是我，“谁”是可能被欺骗的人。
