# 课文：回话里的“未”与问话里的“何” {#l1.9}
简介：账目还没算完，缺的究竟是什么？读出否定管到哪一步、问题要谁填上。

## 正文

“未发”是到说话时还没启程。它让此刻与将来有了分别，却不保证过一会儿就一定会发。

“何求”口语常说成“求什么”。若答“求一纸”，问答恰好合在一起：答句里的“一纸”占了问句里“何”的位置。另一种问法“何时发”则是问时间；只知道“何”能发问，还不够。

## 知识点：未 {#skill.not-yet}
义项：还没有，到当时为止事情尚未发生或完成
领域：虚词
要诀：划定说话的时刻，找是哪件事尚未完成。
讲解：“已收而未读”里两件事进度不同：东西已经到手，阅读还没有开始或完成。
例句：p.l1.9.r1

## 知识点：何 {#skill.interrogative-object}
义项：作动词的对象，问“什么”
领域：句法
要诀：看答句里是哪件东西补上了空缺。
讲解：“何求”问求什么，“何见”问看见什么。疑问的对象可以出现在动词前面。
例句：p.l1.9.r2

## 原文：教学例句 {#p.l1.9.r1}
> 客问舟人：“舟发乎？”曰：“未发，尚待一客。”顷之，客至，舟乃发。
译文：旅客问船夫：“开船了吗？”船夫说：“还没开，还在等一名客人。”过了一会儿，那名客人到了，船才开。
词注：尚：还，船夫仍在等人。
  顷之：过了一小会儿。
  发：出发，主语是船。

## 原文：教学例句 {#p.l1.9.r2}
> 商人问吏：“子何求？”吏曰：“求昨日之账。”商人启匣，账已在，然未校也。
译文：商人问小吏：“您要找什么？”小吏说：“要昨天的账。”商人打开匣子，账已经在里面，只是还没有核对。
词注：求：寻找、索取，问的是小吏要什么东西。
  然：可是，引出与“已在”不同的一面。
  校：读 jiào，核对账目是否相符。

## 原文：古籍引文 {#p.l1.9.r3}
> 季路问事鬼神。子曰：“未能事人，焉能事鬼？”
译文：季路问该怎样侍奉鬼神。孔子说：“还不能好好侍奉人，又怎么能侍奉鬼呢？”
词注：事：侍奉；可以说侍奉人，也可以说侍奉鬼神。
  焉：怎么，出现在“能事鬼”之前，语气带有反问。

## 原文：教学例句 {#p.l1.9.r4}
> 客登台而望。主人问：“何见？”客曰：“见白帆二。”
译文：客人登台眺望。主人问：“你看见了什么？”客人说：“看见两张白帆。”
词注：望：向远处看，客人登台是为了看得远。
  白帆二：两张白帆，数目放在物名之后。

## 单选：船夫说“未发”时，哪项状态已经可以确定？ {#q.l1.9.1}
考点：skill.not-yet
语境：p.l1.9.r1

- [ ] 当天无论如何都不开船 {#q.l1.9.1.o1}
  理由：后面那位客人到了，船便开出。
- [x] 船此刻还在等人 {#q.l1.9.1.o2}
  理由：“未发”说的是问话时还未开船。后面的“乃发”写状态后来变了。
- [ ] 先前已开过船又折回 {#q.l1.9.1.o3}
  理由：原文一直写等齐旅客，没有写折返。

提示：把船夫回答的那一刻与“顷之”分开。
解析：“未发”说的是问话时还未开船。后面的“乃发”写状态后来变了。

## 找原文证据：哪几个字说明迟迟不开船的原因？ {#q.l1.9.2}
考点：skill.not-yet
语境：p.l1.9.r1

- [x] 尚待一客 {#q.l1.9.2.o1}
  理由：“尚”是还，“待”是等。船夫正等着另一位旅客到来。
- [ ] 舟发乎 {#q.l1.9.2.o2}
  理由：客人只问是否已经开船，还不知原因。
- [ ] 顷之 {#q.l1.9.2.o3}
  理由：这是交代过了一会儿，没说在等什么。

提示：接着船夫的话继续读。
解析：“尚”是还，“待”是等。船夫正等着另一位旅客到来。

## 单选：“子何求”若换成白话，商人究竟想问什么？ {#q.l1.9.3}
考点：skill.interrogative-object
语境：p.l1.9.r2

- [ ] 您想什么时候来取东西？ {#q.l1.9.3.o1}
  理由：答话给出的是“昨日之账”这件东西，没有约取件的时辰。
- [ ] 您为什么一定要找那本账？ {#q.l1.9.3.o2}
  理由：在小吏答话前，商人甚至还不知道要找账。
- [x] 您想要找什么东西？ {#q.l1.9.3.o3}
  理由：小吏答“昨日之账”，对准商人话里的“何”。“何求”是求什么。

提示：把“求昨日之账”的对象换成一个问词。
解析：小吏答“昨日之账”，对准商人话里的“何”。“何求”是求什么。

## 单选：“账已在，然未校”里，哪件事还需要做？ {#q.l1.9.4}
考点：skill.not-yet
语境：p.l1.9.r2

- [ ] 重抄一整年的账 {#q.l1.9.4.o1}
  理由：问到的是昨天的账，原文也没有说需要重抄。
- [x] 核对账目 {#q.l1.9.4.o2}
  理由：账已收在匣里，“未校”说的是内容还没有核对。
- [ ] 找回遗失的账匣 {#q.l1.9.4.o3}
  理由：“账已在”，商人打开匣子已能看到。

提示：“已”与“未”各自只管哪件事？
解析：账已收在匣里，“未校”说的是内容还没有核对。

## 找原文证据：小吏的话中，哪几个字正好能填到“求____”里？ {#q.l1.9.5}
考点：skill.interrogative-object
语境：p.l1.9.r2

- [ ] 启匣 {#q.l1.9.5.o1}
  理由：这是小吏作答之后商人动手的事。
- [x] 昨日之账 {#q.l1.9.5.o2}
  理由：“求昨日之账”把含糊的“何”换成了具体的一本账。
- [ ] 问吏 {#q.l1.9.5.o3}
  理由：这是商人开口向谁发问。

提示：找答话中的物件全名。
解析：“求昨日之账”把含糊的“何”换成了具体的一本账。

## 单选：孔子说“未能事人”，哪种理解合乎这个“未”？ {#q.l1.9.6}
考点：skill.not-yet
语境：p.l1.9.r3

- [ ] 这个人一生都绝不肯侍奉别人 {#q.l1.9.6.o1}
  理由：“未能”说能力尚未达到，不是给一生下结论。
- [ ] 鬼神已经能被他侍奉好 {#q.l1.9.6.o2}
  理由：下句是追问怎能侍奉鬼，没说他已做到了。
- [x] 就眼下来说，侍奉人还做不好 {#q.l1.9.6.o3}
  理由：“未”限定问话当时，“能”指能不能做到。孔子先把问题放回眼前的人事。

提示：看“能”而非“愿”，并把判断放回问答当时。
解析：“未”限定问话当时，“能”指能不能做到。孔子先把问题放回眼前的人事。

## 单选：若主人只想问“你看见没有”，客人答个“见”即可。原问还要他说明什么？ {#q.l1.9.7}
考点：skill.interrogative-object
语境：p.l1.9.r4

- [ ] 台子距河多远 {#q.l1.9.7.o1}
  理由：客人答白帆两张，没有报距离。
- [ ] 是谁先登台 {#q.l1.9.7.o2}
  理由：是谁登台在首句已交代，回答也没有另报人名。
- [x] 看见的具体东西 {#q.l1.9.7.o3}
  理由：多出来的“白帆二”回答看见了什么。“何”在这里占的是被看见的对象的位置。

提示：留意答句除了“见”还多什么。
解析：多出来的“白帆二”回答看见了什么。“何”在这里占的是被看见的对象的位置。

## 排序：登台之后的问答，怎样读才知道“何”所问？ {#q.l1.9.8}
考点：skill.interrogative-object
语境：p.l1.9.r4

- [2] 主人询问眼中所见 {#q.l1.9.8.o1}
  理由：主人问“何见”，得先有人在看。
- [3] 客人回答看见两张白帆 {#q.l1.9.8.o2}
  理由：“客曰”是对主人问话的回应。
- [1] 客人上台向远处看 {#q.l1.9.8.o3}
  理由：客人看，主人问，客人再说出所见。最后的白帆补明了问句的对象。

提示：先分清望的人和问的人。
解析：客人看，主人问，客人再说出所见。最后的白帆补明了问句的对象。
