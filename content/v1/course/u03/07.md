# 课文：一把仓钥：谁动手，动了什么 {#l1.7}
简介：动词找到以后，再看它带着什么东西一起动。

## 正文

同一间仓房，主人授钥，看守受钥。“授”和“受”读音一样，伸出的两只手却方向相反。

读教学短文，不妨在纸上记两行：“主人——钥”，“看守——门”。只有补上动词，才知道主人把钥匙交出去，看守把门关起来。语法上说的“宾语”，就是这些句子里交出去、接过来或关起来的对象。

## 知识点：找动作 {#skill.action-verb}
义项：从一句叙事里认出人物做的事
领域：句法
要诀：把人物名字拿开，再看发生了什么变化。
讲解：“吏封门”中，人是吏，东西是门，把门封上的动作才是“封”。
例句：p.l1.7.r1

## 知识点：找对象 {#skill.direct-object}
义项：找出动作直接针对的人或事物
领域：句法
要诀：在动词后面试问“什么”或“谁”。
讲解：“与客钥”同时提到人和物，若问交出了什么，要找钥匙；问交给谁，则要找客人。
例句：p.l1.7.r2

## 原文：教学例句 {#p.l1.7.r1}
> 谷尽入仓，主人授守者钥。守者受钥，闭门。明旦客至，守者以钥启门，客入视谷。
译文：谷子都进了仓，主人把钥匙交给看守。看守接过钥匙，把门关了。次日早上有客人来，看守用钥匙开门，客人进去看谷子。
词注：授：交给，是递出东西那一方的动作。
  受：接过，是收到东西那一方的动作。
  明旦：第二天早上。

## 原文：古籍引文 {#p.l1.7.r2}
> 以杖叩其胫。
译文：用手杖敲他的小腿。
词注：以：用，后面的“杖”是手中的工具。
  胫：小腿，读 jìng。

## 原文：教学例句 {#p.l1.7.r3}
> 妇汲水，儿负薪。至灶前，妇注水于釜，儿置薪于灶下。
译文：妇人打水，孩子背柴。来到灶前，妇人把水倒进锅里，孩子把柴放进灶下。
词注：汲：从井里打水，读 jí。
  薪：柴火。
  釜：锅，读 fǔ。

## 单选：主人伸手，看守也伸手。“授”与“受”怎样配给两个人？ {#q.l1.7.1}
考点：skill.action-verb
语境：p.l1.7.r1

- [ ] 主人接过，看守交出 {#q.l1.7.1.o1}
  理由：“授守者钥”中，看守是接收的人。
- [x] 主人交出，看守接过 {#q.l1.7.1.o2}
  理由：“授”是给，“受”是接。从相对两方写出同一次交接。
- [ ] 两人先后各交出了一把钥匙 {#q.l1.7.1.o3}
  理由：后文用来开门的钥匙正是主人给的那把，文中没有第二把。

提示：留心授字的提手旁，想象递钥匙的手。
解析：“授”是给，“受”是接。从相对两方写出同一次交接。

## 找原文证据：客人进仓要查看的东西，原文怎样叫？ {#q.l1.7.2}
考点：skill.direct-object
语境：p.l1.7.r1

- [ ] 钥 {#q.l1.7.2.o1}
  第几处：1
  理由：钥匙是看守用来开门的工具。
- [ ] 客至 {#q.l1.7.2.o2}
  理由：这两个字说有客来到，没说他看什么。
- [x] 谷 {#q.l1.7.2.o3}
  第几处：2
  理由：“客入视谷”中的“谷”是“视”的对象，正是开头入仓的那批粮食。

提示：找“客入视……”中被看的东西。
解析：“客入视谷”中的“谷”是“视”的对象，正是开头入仓的那批粮食。

## 单选：门从关闭变成打开，是哪个动作造成的？ {#q.l1.7.3}
考点：skill.action-verb
语境：p.l1.7.r1

- [ ] 至 {#q.l1.7.3.o1}
  理由：“至”的是客人。人到达，门还得由看守动手。
- [x] 启 {#q.l1.7.3.o2}
  理由：“闭”是关，“启”是开。“以钥”说明用什么工具开。
- [ ] 视 {#q.l1.7.3.o3}
  理由：“视”是看谷子，这时门已经开了。

提示：把前一晚的“闭”跟第二天的动作配起来。
解析：“闭”是关，“启”是开。“以钥”说明用什么工具开。

## 排序：按原文排出看守办的三件事。 {#q.l1.7.4}
考点：skill.action-verb
语境：p.l1.7.r1

- [2] 把仓门关上 {#q.l1.7.4.o1}
  理由：“受钥”之后紧跟“闭门”。
- [1] 承接主人交来的钥匙 {#q.l1.7.4.o2}
  理由：看守先受钥、闭门，到了第二天早晨才用这把钥匙开门。
- [3] 次晨把门打开 {#q.l1.7.4.o3}
  理由：“明旦”把这次开门移到了次日。

提示：先分清当天和明早。
解析：看守先受钥、闭门，到了第二天早晨才用这把钥匙开门。

## 单选：“以杖叩其胫”中，被敲到的是哪一处？ {#q.l1.7.5}
考点：skill.direct-object
语境：p.l1.7.r2

- [x] 那个人的小腿 {#q.l1.7.5.o1}
  理由：杖是工具，小腿才是敲击的对象。这两样东西都在一句里。
- [ ] 拿在手里的杖 {#q.l1.7.5.o2}
  理由：“以杖”是用杖，告诉你拿什么敲。
- [ ] 拿杖人的手 {#q.l1.7.5.o3}
  理由：这是拿工具的部位，原句没有说手被敲。

提示：“胫”指小腿。“叩什么”和“拿什么叩”各有答案。
解析：杖是工具，小腿才是敲击的对象。这两样东西都在一句里。

## 找原文证据：在“儿负薪”里，写孩子怎样把柴带过来的是哪个字？ {#q.l1.7.6}
考点：skill.action-verb
语境：p.l1.7.r3

- [ ] 薪 {#q.l1.7.6.o1}
  第几处：1
  理由：“薪”是柴火，指背上的东西。
- [ ] 汲 {#q.l1.7.6.o2}
  理由：这是妇人打水的动作。
- [x] 负 {#q.l1.7.6.o3}
  理由：“负”是背在背上。“负薪”说孩子背着柴来到灶前。

提示：想象柴背在什么地方。
解析：“负”是背在背上。“负薪”说孩子背着柴来到灶前。

## 单选：“注水于釜”要分清哪两件东西？ {#q.l1.7.7}
考点：skill.direct-object
语境：p.l1.7.r3

- [ ] 倒进去的是锅，接着锅的是水 {#q.l1.7.7.o1}
  理由：“釜”是锅，“于釜”标出水倒到哪里。
- [ ] 水和锅一起被放到灶下面 {#q.l1.7.7.o2}
  理由：灶下放的是柴；妇人的动作是倒水。
- [x] 倒进去的是水，接着水的是锅 {#q.l1.7.7.o3}
  理由：“注水”点出倒水，“于釜”点出目的地。地点和被倒的东西有不同用处。

提示：问“注什么”，再问“注到哪里”。
解析：“注水”点出倒水，“于釜”点出目的地。地点和被倒的东西有不同用处。

## 找原文证据：“置薪于灶下”里，孩子放下的东西是什么？ {#q.l1.7.8}
考点：skill.direct-object
语境：p.l1.7.r3

- [ ] 灶下 {#q.l1.7.8.o1}
  理由：柴是“置”的对象，“灶下”是放柴的地方。锅里的水和灶下的柴没有放混。
- [x] 薪 {#q.l1.7.8.o2}
  第几处：2
  理由：薪是柴火，孩子一路背来的就是它。
- [ ] 釜 {#q.l1.7.8.o3}
  理由：妇人把水倒在釜里，随后才换孩子动手。

提示：用白话补一句：“他把____放在灶下。”
解析：柴是“置”的对象，“灶下”是放柴的地方。锅里的水和灶下的柴没有放混。
