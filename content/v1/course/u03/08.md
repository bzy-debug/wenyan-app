# 课文：“对曰”是谁开口：从问话找答话人 {#l1.8}
简介：人名有时只写一次，有时一句答话就换了人。

## 正文

“王见之，曰”两件事可以由同一人做：王见到有人牵牛，王开口询问。再往下读到“对曰”，若仍当作王自己说话，就成了他明明知道还自问自答。堂上坐的是王，堂下牵牛的那位，才知道牛要去哪里。

“对曰”是“回答说”。在一段问答里，先留意谁在问、问的是谁；若只见同一个人低头、举物、出门，中间也许压根没有换人。

## 知识点：承前省主 {#skill.subject-continuity}
义项：前面的人继续做事，人名可以省去
领域：句法
要诀：试着把最近明确做事的人补在动作前。
讲解：一个人见物、俯身、捡起，若中间没有换人的信号，几个动作可以由同一个人完成。
例句：p.l1.8.r2

## 知识点：对曰 {#skill.respondent}
义项：回答说，答话的人可根据前面的问话补出
领域：句法
要诀：找谁在发问，再找在场能回答的人。
讲解：上一个说话的若是问话人，读到“对曰”通常需要换到被问的一方。
例句：p.l1.8.r1

## 原文：古籍引文 {#p.l1.8.r1}
> 王坐于堂上，有牵牛而过堂下者。王见之，曰：“牛何之？”对曰：“将以衅钟。”
译文：王坐在堂上，有个人牵着牛从堂下走过。王看到了，问：“牛往哪里去？”那人答：“要用它的血来祭钟。”
词注：何之：往哪里去，此处“之”是前往的意思。
  衅钟：古代用牲畜的血涂在钟上举行祭礼，“衅”读 xìn。

## 原文：教学例句 {#p.l1.8.r2}
> 市人见囊遗于地，俯而拾之。吏问市人曰：“囊中何物？”对曰：“未启，不知也。”
译文：市上一人看见地上落了个口袋，低头捡起。小吏问他：“口袋里是什么？”他答道：“还没打开，不知道。”
词注：市人：集市上的人。
  囊：口袋。
  启：打开，拾到的人尚未打开口袋。

## 原文：教学例句 {#p.l1.8.r3}
> 母召女，问曰：“汝兄安在？”对曰：“方汲于井。”母取瓮，出候之。
译文：母亲叫来女儿问：“你哥哥在哪里？”女儿答：“正在井边打水。”母亲拿起瓮，出门去等他。
词注：汝：你；母亲是在对女儿说话。
  安在：在哪里，这里问人的去处。
  方：正在，哥哥此刻正打着水。
  瓮：大腹的陶器，读 wèng。

## 单选：“牛何之？”是王问的。“将以衅钟”是谁回答的？ {#q.l1.8.1}
考点：skill.respondent
语境：p.l1.8.r1

- [ ] 牵着牛的下一位来客 {#q.l1.8.1.o1}
  理由：原文只交代一位牵牛从堂下经过的人。
- [ ] 堂上坐着的王 {#q.l1.8.1.o2}
  理由：“对曰”承接王的问话，王在等别人答他。
- [x] 堂下牵牛的人 {#q.l1.8.1.o3}
  理由：牵牛人被王问及去处，答的是他此行的用途。“对”把说话人换到了堂下。

提示：谁正在办这件差事，知道牛的去处？
解析：牵牛人被王问及去处，答的是他此行的用途。“对”把说话人换到了堂下。

## 单选：“王见之，曰”如果把省掉的人名补上，怎样讲？ {#q.l1.8.2}
考点：skill.subject-continuity
语境：p.l1.8.r1

- [x] 王看见这件事，王便开口问 {#q.l1.8.2.o1}
  理由：“王”领起看见和发问两个动作，到了“对曰”才换人。
- [ ] 牵牛人看见王，王便回答 {#q.l1.8.2.o2}
  理由：原文点明“王见之”，先看见的是王。
- [ ] 王看见有人牵牛，牵牛人便开口问 {#q.l1.8.2.o3}
  理由：“见之，曰”连在同一个“王”之后。牵牛人在后面“对曰”时才发言。

提示：“见”和“曰”之间有没有新的人出场？
解析：“王”领起看见和发问两个动作，到了“对曰”才换人。

## 找原文证据：哪几个字是答话人的原话？ {#q.l1.8.3}
考点：skill.respondent
语境：p.l1.8.r1

- [ ] 牛何之 {#q.l1.8.3.o1}
  理由：这是王先提出的问题。
- [x] 将以衅钟 {#q.l1.8.3.o2}
  理由：“将以衅钟”回答牛要被用来做什么。“将”说的是接下来的打算。
- [ ] 牵牛而过堂下 {#q.l1.8.3.o3}
  理由：这是叙述者介绍王看到了什么。

提示：顺着“对曰”往引号里找。
解析：“将以衅钟”回答牛要被用来做什么。“将”说的是接下来的打算。

## 单选：谁俯身拾起落在地上的口袋？ {#q.l1.8.4}
考点：skill.subject-continuity
语境：p.l1.8.r2

- [ ] 丢口袋的原主人 {#q.l1.8.4.o1}
  理由：原文没有交代失主已经回来。
- [ ] 后来盘问的小吏 {#q.l1.8.4.o2}
  理由：“吏问”在拾到口袋之后才引进小吏。
- [x] 最先看见口袋的市人 {#q.l1.8.4.o3}
  理由：市人先见囊，随后就是他低头拾囊。新的人名在下句才出现。

提示：把“俯而拾之”接在第一句的“市人”后。
解析：市人先见囊，随后就是他低头拾囊。新的人名在下句才出现。

## 找原文证据：答话人用什么理由说明自己不知道里面是什么？ {#q.l1.8.5}
考点：skill.respondent
语境：p.l1.8.r2

- [ ] 何物 {#q.l1.8.5.o1}
  理由：这是小吏问什么，不是拾物者给的理由。
- [ ] 俯而拾之 {#q.l1.8.5.o2}
  理由：这是他捡起口袋，并不能表明打开看过。
- [x] 未启 {#q.l1.8.5.o3}
  理由：“未启”是还没打开。拾到袋子和知道里面装什么，并不是同一件事。

提示：在“对曰”的引语里找先于“不知”的两字。
解析：“未启”是还没打开。拾到袋子和知道里面装什么，并不是同一件事。

## 单选：按照“汝兄”来认人，回答“方汲于井”的是谁？ {#q.l1.8.6}
考点：skill.respondent
语境：p.l1.8.r3

- [x] 刚被母亲叫来的女儿 {#q.l1.8.6.o1}
  理由：母亲问女儿，女儿才能用哥哥正在何处来作答。
- [ ] 开口召人的母亲 {#q.l1.8.6.o2}
  理由：说“汝兄”的人是母亲，接着等女儿回答。
- [ ] 正在井旁的哥哥 {#q.l1.8.6.o3}
  理由：哥哥不在场，母亲问的是他的去处。

提示：把“汝”读成“你”：母亲当面对谁说“你哥哥”？
解析：母亲问女儿，女儿才能用哥哥正在何处来作答。

## 单选：末句谁带着瓮出去等人？ {#q.l1.8.7}
考点：skill.subject-continuity
语境：p.l1.8.r3

- [x] 母亲 {#q.l1.8.7.o1}
  理由：“母取瓮，出候之”是一人连做两事。第二个动作前不必再写一遍“母”。
- [ ] 哥哥 {#q.l1.8.7.o2}
  理由：哥哥在井旁打水，没有回到这一幕中取瓮。
- [ ] 女儿 {#q.l1.8.7.o3}
  理由：女儿刚答完，叙述者已重新写出“母取瓮”。

提示：是谁“取瓮”？两个动作之间有没有换主语？
解析：“母取瓮，出候之”是一人连做两事。第二个动作前不必再写一遍“母”。

## 排序：拾囊到答话，按发生的经过排一排。 {#q.l1.8.8}
考点：skill.subject-continuity
语境：p.l1.8.r2

- [2] 小吏追问袋里有什么 {#q.l1.8.8.o1}
  理由：问题指着已被拾起的囊。
- [1] 市人弯腰拾起口袋 {#q.l1.8.8.o2}
  理由：开头的动作都属市人，中间小吏发问，最后答话的又是市人。
- [3] 市人答说还没打开 {#q.l1.8.8.o3}
  理由：“对曰”是对刚刚那句话的回答。

提示：留意“吏问”与“对曰”两次换人。
解析：开头的动作都属市人，中间小吏发问，最后答话的又是市人。
