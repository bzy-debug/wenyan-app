# 课文：午时那场约会：两个人的时间表 {#l1.10}
简介：两个人不在同一时刻到场。把约定、离开和迟到放回各自的位置。

## 正文

陈太丘与朋友相约同行。开头两个“期”，头一个说相约，后一个点出约在几时。“日中”即正午。读到“去后乃至”，不要急着把“去”和“至”安在同一个人身上：一个已等不下去，另一个才赶来。

教学短文另写了一回交棒。问自己两次：东西如今在谁手里？时间已经从昨晚走到今早了吗？只要这两点没丢，复述时用自己的话也能说清。

## 知识点：分清人物 {#skill.track-actors}
义项：把动作归到当时做事的人身上
领域：篇章
要诀：先标出两个人各自所在的位置。
讲解：同一句中，离开的人与赶到的人有时不同。若接下来有人问去者何在，就能看出谁来迟了。
例句：p.l1.10.r1

## 知识点：分清先后 {#skill.time-links}
义项：借前后、早晚、才等线索排列实事
领域：篇章
要诀：有人说的是约好的时辰，有人做的事才实际发生。
讲解：“明旦”若在引语里，是预告明天；叙述者后来写“旦”，才到了次日早上。
例句：p.l1.10.r2

## 原文：古籍引文 {#p.l1.10.r1}
> 陈太丘与友期行，期日中。过中不至，太丘舍去，去后乃至。元方时年七岁，门外戏。客问元方：“尊君在不？”答曰：“待君久不至，已去。”
译文：陈太丘和朋友约在正午一起出行。过了中午朋友还没到，太丘不再等，离开了，朋友在他走后才到。太丘的儿子元方当时七岁，在门外玩。朋友问元方：“你父亲在吗？”元方答：“他等您许久，您没来，他已经走了。”
词注：期：相约；第二个“期”后面说约在什么时辰。
  舍去：不再等候，离开。
  尊君：对别人父亲的尊称。
  在不：在不在，“不”同“否”。

## 原文：教学例句 {#p.l1.10.r2}
> 昏，甲卒授乙卒木牌，曰：“明旦持至东门。”乙藏之。旦，甲犹守西门，乙已持牌至东门。
译文：傍晚，甲卒把木牌交给乙卒，说：“明早带到东门去。”乙收起了木牌。早晨，甲还守着西门，乙已带牌到了东门。
词注：昏：傍晚，与下文的“旦”相对。
  卒：兵士，这段话里有甲、乙两人。
  持：拿着、带着。

## 原文：教学例句 {#p.l1.10.r3}
> 渔父约子日入收网。子先至，系舟以待。父至，父子共引网，乃载鱼归。
译文：渔夫和儿子约好日落时收网。儿子先到，拴好船等候。父亲到了，父子一起拉网，这才装鱼回家。
词注：渔父：以捕鱼为业的男子，“父”读 fǔ。
  日入：太阳下山。
  引：拉，是父子合力拉网的动作。

## 单选：“期日中”里的正午，究竟是哪一种时间？ {#q.l1.10.1}
考点：skill.time-links
语境：p.l1.10.r1

- [x] 两人约好一起出发的时间 {#q.l1.10.1.o1}
  理由：约的是正午；在场者照约来没来，要看后一句。
- [ ] 朋友实际赶到太丘家的时间 {#q.l1.10.1.o2}
  理由：朋友到时太丘已经走了，晚于正午。
- [ ] 元方告诉客人父亲去处的时间 {#q.l1.10.1.o3}
  理由：问答发生在客人迟到之后，原文没给它报时。

提示：留意“期”是约定，再看“过中”。
解析：约的是正午；在场者照约来没来，要看后一句。

## 单选：“去后乃至”如果把人名补齐，怎样读？ {#q.l1.10.2}
考点：skill.track-actors
语境：p.l1.10.r1

- [ ] 元方走后，两人都到 {#q.l1.10.2.o1}
  理由：元方正在门外，还要与刚到的客人说话。
- [ ] 朋友走后，太丘才到 {#q.l1.10.2.o2}
  理由：前句已写“太丘舍去”，离开者有明确姓名。
- [x] 太丘走后，朋友才到 {#q.l1.10.2.o3}
  理由：友人来时只见元方，才问其父何在。去的是太丘，来的是友人。

提示：客人接着问“尊君在不”，是在找谁？
解析：友人来时只见元方，才问其父何在。去的是太丘，来的是友人。

## 找原文证据：哪一句是孩子站在门外所说的话？ {#q.l1.10.3}
考点：skill.track-actors
语境：p.l1.10.r1

- [x] 待君久不至，已去 {#q.l1.10.3.o1}
  理由：元方对来客说“君”，交代父亲一度等他、后来离开的经过。
- [ ] 门外戏 {#q.l1.10.3.o2}
  理由：这是叙述者交代孩子在哪里做什么。
- [ ] 尊君在不 {#q.l1.10.3.o3}
  理由：客人称对方的父亲为“尊君”。

提示：找“答曰”后的原话。
解析：元方对来客说“君”，交代父亲一度等他、后来离开的经过。

## 排序：约时、离开、见到孩子，这三件事实怎样排列？ {#q.l1.10.4}
考点：skill.time-links
语境：p.l1.10.r1

- [1] 两人约在中午同行 {#q.l1.10.4.o1}
  理由：先定约，再有太丘独自离开，来迟的朋友最后见到的是元方。
- [3] 朋友到来，在门外问元方 {#q.l1.10.4.o2}
  理由：“去后乃至”把朋友到来放在太丘离开之后。
- [2] 太丘等过了中午便离开 {#q.l1.10.4.o3}
  理由：他因对方过时没到才不再等。

提示：“约在正午”不等于“正午都到了”。
解析：先定约，再有太丘独自离开，来迟的朋友最后见到的是元方。

## 单选：甲说“明旦持至东门”时，牌已到东门了吗？ {#q.l1.10.5}
考点：skill.time-links
语境：p.l1.10.r2

- [ ] 已经到了，“至”写的是刚发生的事 {#q.l1.10.5.o1}
  理由：这句话放在引号里，且前面有“明旦”。
- [ ] 那晚就丢在了东门外 {#q.l1.10.5.o2}
  理由：“乙藏之”说明乙收好木牌。
- [x] 还没有，这是他对次晨的交代 {#q.l1.10.5.o3}
  理由：傍晚说的是安排，第二天“已持牌至东门”才是办成的事。

提示：分清人物嘴里的“明旦”和叙述里真的到了“旦”。
解析：傍晚说的是安排，第二天“已持牌至东门”才是办成的事。

## 找原文证据：次日“犹守西门”的是哪位兵卒？在末句里选出他。 {#q.l1.10.6}
考点：skill.track-actors
语境：p.l1.10.r2

- [x] 甲 {#q.l1.10.6.o1}
  第几处：2
  理由：甲还在西门，乙已到东门，各人有各人的所在。
- [ ] 东门 {#q.l1.10.6.o2}
  第几处：2
  理由：这是送牌的目的地，题目问的是人。
- [ ] 乙已持牌 {#q.l1.10.6.o3}
  理由：这位带牌去了东门。

提示：对照“甲犹……”和“乙已……”。
解析：甲还在西门，乙已到东门，各人有各人的所在。

## 单选：谁真正动手拉了网？ {#q.l1.10.7}
考点：skill.track-actors
语境：p.l1.10.r3

- [ ] 父亲一人，儿子只负责划船 {#q.l1.10.7.o1}
  理由：“父子共引网”的“共”把两个人都算进去。
- [ ] 先到的儿子独自拉网 {#q.l1.10.7.o2}
  理由：他先到时做的是“系舟以待”，还在等人。
- [x] 父子两人 {#q.l1.10.7.o3}
  理由：先到的人、后到的人，最终一起收网。先到不等于先收。

提示：找“引网”前面的称呼。
解析：先到的人、后到的人，最终一起收网。先到不等于先收。

## 排序：把日落前后的实事排好。 {#q.l1.10.8}
考点：skill.time-links
语境：p.l1.10.r3

- [3] 父子装上鱼回家 {#q.l1.10.8.o1}
  理由：“乃”说明鱼已收上来，才谈得上载鱼回去。
- [2] 父亲来到，两人拉网 {#q.l1.10.8.o2}
  理由：父至以后才写“共引网”。
- [1] 儿子拴船等人 {#q.l1.10.8.o3}
  理由：真正发生的动作从儿子先到开始，等到父亲后才收网、载鱼归家。

提示：看到“约”时，留意那是计划。
解析：真正发生的动作从儿子先到开始，等到父亲后才收网、载鱼归家。
