# 课文：等兔的人：意外如何成了主意 {#l1.11}
简介：看清一次意外、人心中的期待和最后的结果，才知道弯转在哪里。

## 正文

“株”是树桩，“耒”（lěi）是耕具。第一次得兔，用不着耕者动手：疾跑的兔子自己撞上了树桩。他后来“释其耒”，是放下耕具，专等下次好运。读到这里，先别替他说“又得一兔”；“冀”只表示心里盼着。

再看等东西的另一个人。原文若真要说他的办法奏效，会写他又得到了什么。写的是“不可复得”，恰恰是盼望落了空。

## 知识点：找缘由 {#skill.causal-link}
义项：指出原文中促使一个人采取行动的事
领域：篇章
要诀：从人物改变做法的地方往回看。
讲解：有人原本耕田，忽然改为等待。要问为什么改变，就读他此前遇到的事情。
例句：p.l1.11.r1

## 知识点：分愿望与结果 {#skill.contrast-expectation}
义项：辨认原本期待的事与最后发生的事
领域：篇章
要诀：别把“冀、欲、以为”后面的话直接当作结局。
讲解：“以为晴”只写人的判断，若后面真的下起雨来，判断本身不能改变事实。
例句：p.l1.11.r2

## 原文：古籍引文 {#p.l1.11.r1}
> 宋人有耕田者，田中有株，兔走触株，折颈而死。因释其耒而守株，冀复得兔。兔不可复得，而身为宋国笑。
译文：宋国有个人耕田，田里有个树桩。一只兔子奔来撞上树桩，摔断脖子死了。他于是放下农具守住树桩，希望再得到兔子。兔子再没等到，他自己倒被宋国人笑话。
词注：株：露在地面上的树桩。
  释：放下，耕者放下了手中的农具。
  耒：古代的耕具，读 lěi。
  冀：希望，还没有第二只兔子出现。

## 原文：教学例句 {#p.l1.11.r2}
> 客欲渡溪，见远山无云，以为雨止，乃留盖于舍。至溪，雨复作，衣尽湿。
译文：客人打算过溪，见远山上没有云，以为雨已经停了，便把伞留在屋里。走到溪边，雨又下起来，衣服全湿了。
词注：以为：认为，后面是客人自己对天气的判断。
  盖：遮雨用的伞。
  作：兴起，雨又下了起来。

## 原文：教学例句 {#p.l1.11.r3}
> 匠见邻舍失火，恐火及其屋，急撤屋旁积薪。风转，火不至，薪犹在庭。
译文：工匠看见邻家起火，担心蔓延到自己家，赶紧移开房旁堆的柴。风向变了，火没有烧来，移开的柴仍在庭院里。
词注：及：到、延及，担心火烧到自己的屋舍。
  积薪：堆在一起的柴。
  庭：屋前的院子。

## 找原文证据：耕者为什么突然觉得，留在树桩旁就可能得兔？哪段是他见到的意外？ {#q.l1.11.1}
考点：skill.causal-link
语境：p.l1.11.r1

- [x] 兔走触株，折颈而死 {#q.l1.11.1.o1}
  理由：兔子撞死在树桩上，给了他一次不劳而获的经验；这才有守株的打算。
- [ ] 冀复得兔 {#q.l1.11.1.o2}
  理由：这是他在意外之后生出的盼头。
- [ ] 而身为宋国笑 {#q.l1.11.1.o3}
  理由：这是后来落到他身上的结果。

提示：先看耕者放下耒以前出了什么事。
解析：兔子撞死在树桩上，给了他一次不劳而获的经验；这才有守株的打算。

## 单选：“因释其耒”里的“因”把哪两件事连了起来？ {#q.l1.11.2}
考点：skill.causal-link
语境：p.l1.11.r1

- [ ] 宋人先笑他，他才想证明守株有用 {#q.l1.11.2.o1}
  理由：别人取笑他在末尾，是等不到兔的发展。
- [x] 白得一兔，于是放下耕具去等 {#q.l1.11.2.o2}
  理由：“因”是于是，前面是触发它的意外，后面才是耕者改变做法。
- [ ] 放下耕具，于是兔子撞桩 {#q.l1.11.2.o3}
  理由：兔先撞死，人在那之后才放下手里的东西。

提示：沿着“因”前后各读一句。
解析：“因”是于是，前面是触发它的意外，后面才是耕者改变做法。

## 单选：若给讲述者留两行：“他想____；后来____”，怎样填？ {#q.l1.11.3}
考点：skill.contrast-expectation
语境：p.l1.11.r1

- [ ] 兔子别再撞树；成功护住了兔子 {#q.l1.11.3.o1}
  理由：“冀复得兔”明说他所希望的是得兔。
- [x] 再得一只兔；没再得到 {#q.l1.11.3.o2}
  理由：“冀”领出愿望，“不可复得”写结局，一个人的盼头不能充当已经发生的事。
- [ ] 宋人佩服他；大家果然来学他 {#q.l1.11.3.o3}
  理由：末尾“为宋国笑”是被人取笑。

提示：分别找“冀”和“不可”。
解析：“冀”领出愿望，“不可复得”写结局，一个人的盼头不能充当已经发生的事。

## 排序：三幅图怎样排，才能看见希望落空的地方？ {#q.l1.11.4}
考点：skill.contrast-expectation
语境：p.l1.11.r1

- [2] 耕者守桩盼再得兔 {#q.l1.11.4.o1}
  理由：只在第一次撞兔后，他才有复得的盼头。
- [1] 兔子撞桩而死 {#q.l1.11.4.o2}
  理由：先是偶得，再是有意等候，最后等待落空。前后两次得兔只有一次成了事实。
- [3] 耕者没等到兔，还被人笑 {#q.l1.11.4.o3}
  理由：“不可复得”给等待画上了句号。

提示：“复”是再，须先有第一次。
解析：先是偶得，再是有意等候，最后等待落空。前后两次得兔只有一次成了事实。

## 单选：客人把伞留在屋里，是依据什么作了判断？ {#q.l1.11.5}
考点：skill.causal-link
语境：p.l1.11.r2

- [ ] 他亲眼见到溪边一直天晴 {#q.l1.11.5.o1}
  理由：他那时还没到溪边。
- [x] 他望见远山上没有云 {#q.l1.11.5.o2}
  理由：他看见了远山无云，由此以为雨停了。“以为”提醒人，这是他的推断。
- [ ] 他的衣服已经全湿了 {#q.l1.11.5.o3}
  理由：衣湿发生在路上又下雨之后。

提示：“乃留盖”之前有一件看见的事和一个推测。
解析：他看见了远山无云，由此以为雨停了。“以为”提醒人，这是他的推断。

## 找原文证据：客人把伞留下以后，原文哪一处写天气又变了？ {#q.l1.11.6}
考点：skill.contrast-expectation
语境：p.l1.11.r2

- [ ] 客欲渡溪 {#q.l1.11.6.o1}
  理由：这是出门前的打算，还没有说赶到溪边时天气怎样。
- [ ] 衣尽湿 {#q.l1.11.6.o2}
  理由：衣服湿了是淋雨的结果。再往前看，天气本身起了什么变化？
- [x] 雨复作 {#q.l1.11.6.o3}
  理由：“复作”是雨又下起来。客人原以为路上用不着伞，到了溪边却淋湿了。

提示：“作”在这里是兴起、下起来。
解析：“复作”是雨又下起来。客人原以为路上用不着伞，到了溪边却淋湿了。

## 单选：匠人为什么急着搬柴？ {#q.l1.11.7}
考点：skill.causal-link
语境：p.l1.11.r3

- [x] 怕邻火蔓延，烧到自家 {#q.l1.11.7.o1}
  理由：邻舍失火是已发生的事，担忧祸及自己才促使他撤薪。
- [ ] 想趁着风转把柴晾干 {#q.l1.11.7.o2}
  理由：风转是搬柴以后才来的变化。
- [ ] 看到他家的房子已经烧着 {#q.l1.11.7.o3}
  理由：“恐火及其屋”说的是怕将要发生的事。

提示：“恐”后面的事，是已发生还是担心发生？
解析：邻舍失火是已发生的事，担忧祸及自己才促使他撤薪。

## 单选：原文把“火不至”紧接在哪一件事后面？ {#q.l1.11.8}
考点：skill.contrast-expectation
语境：p.l1.11.r3

- [x] 风向转了 {#q.l1.11.8.o1}
  理由：“风转，火不至”点出风向变化。原文没有把不受火灾全归功于搬柴。
- [ ] 邻舍把火彻底扑灭 {#q.l1.11.8.o2}
  理由：文中未交代邻舍如何救火。
- [ ] 匠人把屋顶拆下来了 {#q.l1.11.8.o3}
  理由：他移开的是屋旁积薪。

提示：别只看人做了什么，再留心天候怎样变了。
解析：“风转，火不至”点出风向变化。原文没有把不受火灾全归功于搬柴。
