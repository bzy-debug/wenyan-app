# 课文：因果与转折 {#l1.11}
简介：从一句行动回看它的缘由，再辨认与预期相反的结果。

## 正文

同一段话可以同时写**先后、原因、愿望和结果**。读者容易在“先后发生”的两件事中自行补进一个“所以”。先把原文仅读作“接下来”，再问它是否给了相连的理由。

### 区分原因与线索

自编例句“舟人见水涨，故系舟于岸。少顷，有客至。”涨水是船夫系船的缘由，“故”把判断说出来。旅客到来在系舟之后；仅凭“少顷”，还说不出旅客是因为船系住了才来的。判断题中若多出人物未说的动机，应回到原文查证。

### 从人物所想走到实际所见

自编例句“童以为门启，趋而前，门犹闭。”先把“以为”后面的内容放进“儿童所想”一栏，把“犹闭”放进“实际所见”一栏。“门启”属于人物原先的判断，不能当成门真正开过一次。

进入练习后，留心“冀”所引的是人希望发生的事。对照后来发生的事，指出它从哪一点违背了人物的期待。讲因果时找具体事实，讲转折时说清被打破的是谁的什么预期。

## 知识点：缘由 {#skill.causal-link}
义项：用原文事实解释行动或结果
领域：篇章
要诀：找出证据能支持的原因
讲解：先说明要解释的是哪一个动作，再回读与它有关的处境、话语或事实。“故”“以……故”等常明示因由；两个动作先后相接，本身还不足以断定因果。
例句：p.ex.causal-link

## 知识点：转折 {#skill.contrast-expectation}
义项：辨认实际结果与原先预期的落差
领域：篇章
要诀：抓住前后的差别
讲解：先概括人物原先的判断或愿望，再找后文实际发生的情况。“然”“而”等有时连接相反或出乎预料的内容。须由前后两意确认关系。
例句：p.ex.contrast-expectation

## 原文：教学例句 {#p.ex.causal-link}
> 昨夜雨，板桥没于水。客以桥没故，循高岸行。
译文：昨夜下雨，木板桥被水淹没。客人因为桥被淹没，沿高处的岸走。

## 原文：教学例句 {#p.ex.contrast-expectation}
> 客谓雨将止，欲即行。出户视之，雨反益急。
译文：客人以为雨快停了，想马上出行。出门一看，雨反而更急了。

## 原文：古籍引文 {#p.l1.11.ford}
> 宋人有耕田者，田中有株，兔走触株，折颈而死。因释其耒而守株，冀复得兔。兔不可复得，而身为宋国笑。
译文：宋国有个种田人，田里有树桩。一只兔子奔跑撞上树桩，折颈而死。农人于是放下农具守着树桩，希望再得到兔子。兔子没能再得到，他自己却被宋人取笑。耒是耕作工具。

## 单选：根据这一段，农人为什么放下农具去守树桩？ {#q.l1.11.1}
考点：skill.causal-link
语境：p.l1.11.ford

- [x] 曾有兔子撞死在树桩上，他盼这种事重现 {#q.l1.11.1.o1}
- [ ] 兔子每天定时来此 {#q.l1.11.1.o2}
  理由：文字只交代一次撞桩，不能据此推成每天如此。
- [ ] 他已被宋人嘲笑，想证明自己 {#q.l1.11.1.o3}
  理由：“为宋国笑”是结尾写的结果，发生在守株之后。

提示：把“因”向前接到一次偶发事件，再向后读“冀”。
解析：“因”承接兔子撞死一事，“冀复得兔”交代农人的打算。前件是起因，“复得”是他想要的结果。

## 单选：从“冀”读到“而”，哪项把预期与结果分别说清？ {#q.l1.11.2}
考点：skill.contrast-expectation
语境：p.l1.11.ford

- [ ] 农人原来希望兔子逃走，后来兔子果然逃走 {#q.l1.11.2.o1}
  理由：“冀复得兔”的“得”表明他想再次得到兔子。
- [x] 原想再得兔子，结果一无所得，还被取笑 {#q.l1.11.2.o2}
- [ ] 农人本想继续耕田，因为没人笑他才守株 {#q.l1.11.2.o3}
  理由：“释其耒”已经写出放下农具，受嘲笑则在末句。

提示：“冀”后是愿望；哪一句回答愿望有没有实现？
解析：“兔不可复得”直接否定愿望；“而身为宋国笑”又加上一个出乎农人意料的结果。

## 原文：教学例句 {#p.l1.11.light}
> 客夜读，见窗纸忽明，意月出也。开户视之，则邻人执炬寻牛。既失牛，故举火遍求。
译文：客人夜里读书，见窗纸忽然亮了，以为是月亮升起。开门一看，原来是邻居举着火把找牛。因为丢了牛，所以举火到处寻找。

## 选段：点选原文明示邻人持火遍寻的起因。 {#q.l1.11.3}
考点：skill.causal-link
语境：p.l1.11.light

- [ ] 窗纸忽明 {#q.l1.11.3.o1}
  理由：这是客人看到的现象。
- [x] 既失牛 {#q.l1.11.3.o2}
- [ ] 开户视之 {#q.l1.11.3.o3}
  理由：这是客人的查证动作。

提示：找到“故”前面解释邻人行为的一句。
解析：“既失牛，故举火遍求”前半说明失牛，后半写出因之而有的行动。

## 单选：客人最初的推测和后来所见有何不同？ {#q.l1.11.4}
考点：skill.contrast-expectation
语境：p.l1.11.light

- [ ] 原以为是日光，后来看到月光 {#q.l1.11.4.o1}
  理由：客人说的是“月出”，没有提太阳。
- [x] 原以为是月光，实际是火把的光 {#q.l1.11.4.o2}
- [ ] 原以为邻人失火，后来发现走失了牛 {#q.l1.11.4.o3}
  理由：客人最初推测的是月亮升起。

提示：读“意”与“则”各自领起的内容。
解析：“意”引出推测，“则”引出实际所见。照亮窗纸的是邻人手中的火把。

## 原文：教学例句 {#p.l1.11.basket}
> 樵者携二筐入山。将归，恐薪重，留一筐于石下。既负薪而行，然道滑，数步辄止。
译文：樵夫带着两筐进山。准备回去时，他怕柴重，留下一筐在石下。背着柴行走时，路却很滑，走几步就得停。

## 单选：樵夫留下一筐与走几步就停，各有何因？ {#q.l1.11.5}
考点：skill.causal-link
语境：p.l1.11.basket

- [ ] 留筐因为路滑，频停因为迷路 {#q.l1.11.5.o1}
  理由：前文写的是“恐薪重”，全文没有迷路。
- [x] 留筐因为怕柴重，频停因为路滑 {#q.l1.11.5.o2}
- [ ] 两件事都是为了等同伴 {#q.l1.11.5.o3}
  理由：文中没有等人的情节。

提示：给“留”和“止”各找附近的理由。
解析：“恐薪重”紧接留筐；“道滑”紧接频停。两种困难分别解释不同动作。

## 选段：哪处写出减了负担后仍然走不顺的表现？ {#q.l1.11.6}
考点：skill.contrast-expectation
语境：p.l1.11.basket

- [ ] 留一筐 {#q.l1.11.6.o1}
  理由：留下筐是减轻负担的办法。
- [ ] 入山 {#q.l1.11.6.o2}
  理由：入山是之前的行动。
- [x] 数步辄止 {#q.l1.11.6.o3}

提示：找“然”之后表示行动停顿的短语。
解析：“然”后写路滑，“数步辄止”呈现仍难行的结果。

## 原文：教学例句 {#p.l1.11.field}
> 农人引水入田，以为一夕可遍。明旦往视，田半犹干。循沟察之，乃有土块塞水。去其土，水始通。
译文：农人引水入田，以为一夜就能灌遍。次日清早去看，一半田地还干着。沿沟察看，原来有土块堵住水。去掉泥土后，水才畅通。

## 单选：从哪件事可以验证水不畅通的原因？ {#q.l1.11.7}
考点：skill.causal-link
语境：p.l1.11.field

- [x] 去掉土块后水才通 {#q.l1.11.7.o1}
- [ ] 农人以为一夜就够 {#q.l1.11.7.o2}
  理由：估计所需时间没有揭示原因。
- [ ] 农人次日清早去田里 {#q.l1.11.7.o3}
  理由：去查看本身不能说明哪里出了问题。

提示：看移走土块前后的变化。
解析：“土块塞水”指出阻碍；“去其土，水始通”用后续变化印证了原因。

## 单选：“田半犹干”与哪一处预期相对？ {#q.l1.11.8}
考点：skill.contrast-expectation
语境：p.l1.11.field

- [x] 以为一夕可遍 {#q.l1.11.8.o1}
- [ ] 循沟察之 {#q.l1.11.8.o2}
  理由：循沟是发现问题后的调查。
- [ ] 水始通 {#q.l1.11.8.o3}
  理由：这是清沟后的结果。

提示：回读农人最初怎样估计灌溉的结果。
解析：本来以为能灌遍整田，次日却还有半田干着。“犹”表示实际仍未达到预期。
