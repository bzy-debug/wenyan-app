# 课文：因果与转折 {#l1.11}
简介：先发生的事未必是后事的原因；人物心里盼的，也未必真会发生。

## 正文

看一个人系船，再看客人来了，这两件事怎么连？教学例句这样写：“舟人见水涨，故系舟于岸。少顷，有客至。”“故”说清水涨是系船的缘由。“少顷”只说过了一会儿；客人为什么来，还不知道。

再读一句教学例句：“童以为门启，趋而前，门犹闭。”孩子以为门开了，读到“犹闭”，才晓得门一直还关着。倘若照着“以为”就说门开过一次，便把孩子所想当成了眼前发生的事。

“冀”是盼望。读守株待兔的故事，别急着替农人做判断，看看他等的是什么，后来又得到了什么。

## 知识点：缘由 {#skill.causal-link}
义项：用原文事实解释行动或结果
领域：篇章
要诀：他为什么要这样做？
讲解：想解释一个动作，往附近找景况或人物原话。“故”有时已经替我们指出了缘由。
例句：p.ex.causal-link

## 知识点：转折 {#skill.contrast-expectation}
义项：辨认实际结果与原先预期的落差
领域：篇章
要诀：原来怎么想，后来又怎样？
讲解：门本以为开着，走近却发现还关着。把人所想和后来真正看到的分开，转折就容易读出。
例句：p.ex.contrast-expectation

## 原文：教学例句 {#p.ex.causal-link}
> 昨夜雨，板桥没于水。客以桥没故，循高岸行。
译文：昨夜下雨，木板桥被水淹没。客人因为桥被淹没，沿高处的岸走。

## 原文：教学例句 {#p.ex.contrast-expectation}
> 客谓雨将止，欲即行。出户视之，雨反益急。
译文：客人以为雨快停了，想马上出行。出门一看，雨反而更急了。

## 原文：古籍引文 {#p.l1.11.ford}
> 宋人有耕田者，田中有株，兔走触株，折颈而死。因释其耒而守株，冀复得兔。兔不可复得，而身为宋国笑。
译文：宋国有个种田人，田里有树桩。一只兔子奔跑撞上树桩，折颈而死。农人于是放下农具守着树桩，希望再得到兔子。他再没等来兔子，自己倒成了宋人的笑柄。耒是耕作工具。

## 单选：农人为什么放下农具，等在树桩旁？ {#q.l1.11.1}
考点：skill.causal-link
语境：p.l1.11.ford

- [x] 曾有兔子撞死在树桩上，他盼这种事重现 {#q.l1.11.1.o1}
- [ ] 兔子每天定时来此 {#q.l1.11.1.o2}
  理由：原文只写遇兔一次，哪里说每天都会来？
- [ ] 他已被宋人嘲笑，想证明自己 {#q.l1.11.1.o3}
  理由：受到嘲笑是在守株之前还是之后？

提示：农人先捡到了什么？“冀”写他还盼着什么？
解析：兔子碰上树桩死了，农人便盼着再捡一只。“冀复得兔”写他为什么守在这里。

## 单选：农人盼来的是什么？末句写的又是什么？ {#q.l1.11.2}
考点：skill.contrast-expectation
语境：p.l1.11.ford

- [ ] 农人原来希望兔子逃走，后来兔子果然逃走 {#q.l1.11.2.o1}
  理由：“冀复得兔”的“得”和“逃走”意思相合吗？
- [x] 原想再得兔子，结果一无所得，还被取笑 {#q.l1.11.2.o2}
- [ ] 农人本想继续耕田，因为没人笑他才守株 {#q.l1.11.2.o3}
  理由：“冀”后面说的是怕被人笑，还是想得到东西？

提示：“冀”后是愿望；哪一句回答愿望有没有实现？
解析：“冀”是盼。农人没能再得兔子，反倒成了宋人的笑柄，“而”后面还多了一层结果。

## 原文：教学例句 {#p.l1.11.light}
> 客夜读，见窗纸忽明，意月出也。开户视之，则邻人执炬寻牛。既失牛，故举火遍求。
译文：客人夜里读书，见窗纸忽然亮了，以为是月亮升起。开门一看，原来是邻居举着火把找牛。因为丢了牛，所以举火到处寻找。

## 找原文证据：邻人举着火把四处找，先前发生了什么事？ {#q.l1.11.3}
考点：skill.causal-link
语境：p.l1.11.light

- [ ] 窗纸忽明 {#q.l1.11.3.o1}
  理由：窗纸亮是客人看到的现象。邻人先前遇到了什么事？
- [x] 既失牛 {#q.l1.11.3.o2}
- [ ] 开户视之 {#q.l1.11.3.o3}
  理由：开门看动静的是读书的客人；举火寻找的是邻人。

提示：找到“故”前面解释邻人行为的一句。
解析：邻人先丢了牛，于是举火遍寻。“故”前面的“失牛”就是原因。

## 单选：客人最初的推测和后来所见有何不同？ {#q.l1.11.4}
考点：skill.contrast-expectation
语境：p.l1.11.light

- [ ] 原以为是日光，后来看到月光 {#q.l1.11.4.o1}
  理由：“意月出也”说他以为月亮升起来了。
- [x] 原以为是月光，实际是火把的光 {#q.l1.11.4.o2}
- [ ] 原以为邻人失火，后来发现走失了牛 {#q.l1.11.4.o3}
  理由：“举炬”是拿火把。哪里写房屋失火了？

提示：读“意”与“则”各自领起的内容。
解析：窗纸亮了，客人以为是月出；推开门，才看见邻人在举火寻牛。

## 原文：教学例句 {#p.l1.11.basket}
> 樵者携二筐入山。将归，恐薪重，留一筐于石下。既负薪而行，然道滑，数步辄止。
译文：樵夫带着两筐进山。准备回去时，他怕柴重，留下一筐在石下。背着柴行走时，路却很滑，走几步就得停。

## 单选：樵夫为何留下一筐柴，后来又为何走几步就停？ {#q.l1.11.5}
考点：skill.causal-link
语境：p.l1.11.basket

- [ ] 留筐因为路滑，频停因为迷路 {#q.l1.11.5.o1}
  理由：分别找留筐和停步之前紧挨着的原因。
- [x] 留筐因为怕柴重，频停因为路滑 {#q.l1.11.5.o2}
- [ ] 两件事都是为了等同伴 {#q.l1.11.5.o3}
  理由：原文介绍了哪位同伴？

提示：给“留”和“止”各找附近的理由。
解析：一开始“恐薪重”，所以少背一筐；上路以后却因“道滑”频频停步。各有各的缘由。

## 找原文证据：留下一筐柴以后，他走得顺利吗？找出写脚步的字。 {#q.l1.11.6}
考点：skill.contrast-expectation
语境：p.l1.11.basket

- [ ] 留一筐 {#q.l1.11.6.o1}
  理由：留筐是上路前减负。结果他走得顺利吗？
- [ ] 入山 {#q.l1.11.6.o2}
  理由：入山是先前的行动，减负后发生了什么？
- [x] 数步辄止 {#q.l1.11.6.o3}

提示：找“然”之后表示行动停顿的短语。
解析：“数步辄止”说走上几步就停下来。少背了一筐，他还是没能走得顺畅。

## 原文：教学例句 {#p.l1.11.field}
> 农人引水入田，以为一夕可遍。明旦往视，田半犹干。循沟察之，乃有土块塞水。去其土，水始通。
译文：农人引水入田，以为一夜就能灌遍。次日清早去看，一半田地还干着。沿沟察看，原来有土块堵住水。去掉泥土后，水才畅通。

## 单选：怎样知道堵水的真是那块土？ {#q.l1.11.7}
考点：skill.causal-link
语境：p.l1.11.field

- [x] 去掉土块后水才通 {#q.l1.11.7.o1}
- [ ] 农人以为一夜就够 {#q.l1.11.7.o2}
  理由：“以为”引出预想，田里的实情何时才明白？
- [ ] 农人次日清早去田里 {#q.l1.11.7.o3}
  理由：去查看只能发现问题。哪一步真正改变了水流？

提示：看移走土块前后的变化。
解析：沿沟能看见土块，拿开它以后水才流通。这个前后变化，正好说明水原先为什么过不去。

## 单选：农人原来怎么估计，第二天却看到了“田半犹干”？ {#q.l1.11.8}
考点：skill.contrast-expectation
语境：p.l1.11.field

- [x] 以为一夕可遍 {#q.l1.11.8.o1}
- [ ] 循沟察之 {#q.l1.11.8.o2}
  理由：沿沟察看发生在发现半田仍干之前还是之后？
- [ ] 水始通 {#q.l1.11.8.o3}
  理由：这是清沟之后的事；农人头天晚上所想，还得往前找。

提示：回读农人最初怎样估计灌溉的结果。
解析：他以为一夜便能灌遍田地，到清早却还有一半田干着。“犹”是仍然，水还没有到这里。
