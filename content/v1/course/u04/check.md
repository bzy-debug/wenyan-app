# 检查：鞋市已经散了：再读一篇陌生短文 {#check.4}

## 原文：古籍引文 {#p.check.4.r1}
> 郑人有且置履者，先自度其足，而置之其坐。至之市而忘操之。已得履，乃曰：“吾忘持度。”反归取之。及反，市罢，遂不得履。
译文：有个郑国人准备买鞋，先量了自己的脚，把量好的尺码放在座位上。到市上去时却忘了带。拿到鞋后才说：“我忘了带尺码。”便回家去取。等他再来，集市已经散了，终于没能买到鞋。
词注：且：将要，那人还没动身买鞋。
  履：鞋。
  操：拿，指把量好的尺码随身带上。
  市罢：集市散了，买卖已经结束。

## 原文：教学例句 {#p.check.4.r2}
> 村南有津。客将渡，见舟中一席空，喜而趋前。舟子曰：“彼席已许负药者。”顷之，负药者至。客让其先渡，自候次舟。
译文：村南有个渡口。旅客要过河，见船上空着一个位子，高高兴兴赶上前。船夫说，那位子已经答应给背药的人。不久背药人到了，旅客让他先过，自己等下一条船。
词注：席：座位，船上的空位已经有人预订。
  趋：快步前往。
  许：答应、应允，此处是答应给人留位。

## 排序：郑人去买鞋，哪件事在出门前，哪件事已是回头以后？ {#q.check.4.1}
考点：skill.time-links
语境：p.check.4.r1

- [3] 回家取尺码，再来时集市已散 {#q.check.4.1.o1}
  理由：“及反”点明这是返回后的情形。
- [2] 到了市上想起没带尺码 {#q.check.4.1.o2}
  理由：“已得履，乃曰”表明人在市上见到了鞋才想起来。
- [1] 在家量自己的脚 {#q.check.4.1.o3}
  理由：先量脚却没随身带尺码，到市上才想到，来回取了一趟，终于错过集市。

提示：“度其足”是量脚，“度”有时也指量好的尺码。
解析：先量脚却没随身带尺码，到市上才想到，来回取了一趟，终于错过集市。

## 找原文证据：郑人已经见到鞋，为什么还要回家？用他自己的话回答。 {#q.check.4.2}
考点：skill.causal-link
语境：p.check.4.r1

- [ ] 先自度其足 {#q.check.4.2.o1}
  理由：他事前量过脚，问题是没把量好的东西带来。
- [x] 吾忘持度 {#q.check.4.2.o2}
  理由：“吾忘持度”说自己忘记携带尺码。他的回程直接由这次遗忘引起。
- [ ] 市罢 {#q.check.4.2.o3}
  理由：这是往返之后才有的结果，不是回家前已知道的消息。

提示：从“乃曰”后的直接引语里找。
解析：“吾忘持度”说自己忘记携带尺码。他的回程直接由这次遗忘引起。

## 单选：与“买鞋没买成”直接相连的完整经过是哪一个？ {#q.check.4.3}
考点：skill.mainline
语境：p.check.4.r1

- [ ] 鞋太小，回家换钱，再来时鞋已卖掉 {#q.check.4.3.o1}
  理由：原文没有说鞋的大小不合，也没谈带钱。
- [ ] 先在集市量脚，再拿鞋回家比较 {#q.check.4.3.o2}
  理由：他出门之前已经量过脚，最后“不得履”。
- [x] 忘带尺码，折返去取，再来时集市已散 {#q.check.4.3.o3}
  理由：取尺码花掉了市场还开着的那段时间，错过集市才使他没买到鞋。

提示：只保留能解释“遂不得履”的经过。
解析：取尺码花掉了市场还开着的那段时间，错过集市才使他没买到鞋。

## 单选：“村南有津”让我们先知道什么？ {#q.check.4.4}
考点：skill.ferry-custom
语境：p.check.4.r2

- [ ] 背药人住在村南 {#q.check.4.4.o1}
  理由：村南说的是津的位置，没说背药人家在哪里。
- [ ] 下一条船一定很快就来 {#q.check.4.4.o2}
  理由：“津”交代地点，并不保证班次。
- [x] 村子南边有个可以渡水的地方 {#q.check.4.4.o3}
  理由：旅客要过水，船只停靠载人的地方正是渡口。

提示：“将渡”和“舟”说明这是哪类地点。
解析：旅客要过水，船只停靠载人的地方正是渡口。

## 单选：旅客刚见空位时的判断，后来哪一点需要改过来？ {#q.check.4.5}
考点：skill.contrast-expectation
语境：p.check.4.r2

- [x] 位子眼下空着，却已经留给别人 {#q.check.4.5.o1}
  理由：空着是真，有人预留也是真。旅客高兴趋前时只知道前一件事。
- [ ] 船上原来并没有空位 {#q.check.4.5.o2}
  理由：旅客确实看见“一席空”，船夫没有否认这一点。
- [ ] 背药人不打算渡河了 {#q.check.4.5.o3}
  理由：背药人随后到来，还先渡了河。

提示：分别问“有没有人坐”和“已经答应给谁”。
解析：空着是真，有人预留也是真。旅客高兴趋前时只知道前一件事。

## 找原文证据：谁最后留在岸上等下一班船？请选择指明他身份的字。 {#q.check.4.6}
考点：skill.track-actors
语境：p.check.4.r2

- [x] 客 {#q.check.4.6.o1}
  第几处：2
  理由：让人先渡和留下等船的都是客；先渡的一方才是背药人。
- [ ] 负药者 {#q.check.4.6.o2}
  第几处：2
  理由：背药人到来后，旅客让他先渡。
- [ ] 舟子 {#q.check.4.6.o3}
  理由：船夫解释位子留给谁，没说他留在岸上候船。

提示：末句“客让其先渡，自候次舟”中，“自”承接谁？
解析：让人先渡和留下等船的都是客；先渡的一方才是背药人。
