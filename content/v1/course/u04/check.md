# 检查：把几件事的来龙去脉讲清楚 {#check.4}

## 原文：教学例句 {#p.check.4.slips}
> 司书者晨失一简。先是，小儿拾简于庭，置之案上。司书者遍索于庭，归室，始见案上之简。
译文：掌管书简的人清早找不到一枚简。在这之前，小孩子在庭院拾起简，放到了案上。掌管书简的人在庭院遍寻，回屋才看见案上的简。

## 排序：把拾简、寻找和发现的经过按先后排一排。 {#q.check.4.1}
考点：skill.time-links
语境：p.check.4.slips

- [3] 掌书简者回屋看见简 {#q.check.4.1.o1}
  理由：回到屋里才“始见”。他先去哪里找过？
- [2] 掌书简者遍寻庭院 {#q.check.4.1.o2}
  理由：庭院里遍寻时，小儿是否已经把简收起？
- [1] 孩子拾简并放在案上 {#q.check.4.1.o3}
  理由：“先是”把童子的行动放到什么时候？

提示：把“先是”后写的事摆回时间线上。
解析：“先是”把话倒回去讲。小儿先把简捡起来放在案上，管书简的人后来才到庭里找，最后回屋看见。

## 原文：教学例句 {#p.check.4.jar}
> 父出，嘱子守瓮。邻人来借水，子以瓢酌而与之。父归，见水少，子具言其故。
译文：父亲出门，嘱咐儿子看守水瓮。邻人来借水，儿子便用瓢舀水给他。父亲回来见瓮里的水少了，儿子把经过告诉了他。

## 单选：谁舀了水，舀给谁？ {#q.check.4.2}
考点：skill.track-actors
语境：p.check.4.jar

- [ ] 父亲给水，邻人受水 {#q.check.4.2.o1}
  理由：父亲当时已经出门，他在什么时候才归来？
- [x] 儿子舀水，邻人受水 {#q.check.4.2.o2}
- [ ] 邻人舀水，儿子受水 {#q.check.4.2.o3}
  理由：“以瓢酌”前是谁？再找前来借水的人。

提示：读清“来借”与“酌而与”前面的人物。
解析：“子以瓢酌”说儿子舀水；邻人先前来借水，后来接水的就是他。

## 原文：古籍引文 {#p.check.4.gate}
> 郑人有且置履者，先自度其足，而置之其坐。至之市而忘操之。已得履，乃曰：“吾忘持度。”反归取之。及反，市罢，遂不得履。
译文：郑国有人要买鞋，先量了脚，把量得的尺码放在座位上。到了集市才发觉忘记带尺码。他已经拿到鞋，却说忘拿尺码，回家去取。再回来时集市已散，终究没买成。前一“度”指量，后一“度”指量得的尺码。

## 单选：郑人为什么最终没买成鞋？ {#q.check.4.3}
考点：skill.causal-link
语境：p.check.4.gate

- [ ] 他根本没量脚，所以找不到合脚的鞋 {#q.check.4.3.o1}
  理由：“先自度其足”说明他此前做过哪一步？
- [ ] 集市一直没有鞋，所以他才回家 {#q.check.4.3.o2}
  理由：他第一次离开集市前，市场已经散了吗？
- [x] 回家取尺码，回来时市场已散，错过买鞋 {#q.check.4.3.o3}

提示：分别找离开集市的理由与返回时市场的状态。
解析：他忘了带尺码，回家去取。等他回到市上，“市罢”了，所以鞋没买成。

## 原文：教学例句 {#p.check.4.rain}
> 暮云合，农人喜曰：“今夜必雨。”旦起视庭，土犹干。问邻翁，翁曰：“夜半风起，云已散矣。”
译文：傍晚云聚，农人高兴地说今夜一定下雨。清早他起来看院子，土还干着。他问邻家老人，老人说半夜起风，云已散了。

## 找原文证据：农人第二天早上看到了什么？选出他亲眼所见的景象。 {#q.check.4.4}
考点：skill.contrast-expectation
语境：p.check.4.rain

- [ ] 暮云合 {#q.check.4.4.o1}
  理由：“暮”是前一天傍晚，农人看院子已经是第二天一早。
- [ ] 云已散矣 {#q.check.4.4.o2}
  理由：云散是谁告诉农人的？与他亲眼所见分开。
- [x] 土犹干 {#q.check.4.4.o3}

提示：题目问清早亲见，区分农人的眼见和邻翁的话。
解析：“旦起视庭”写他清早亲自查看，“土犹干”才是他当时看到的景象。

## 原文：教学例句 {#p.check.4.shore}
> 妇携子至津，舟尚系岸。妇先登，以手引子。母子既坐，舟子始解缆。
译文：妇人带孩子到渡口，船还系在岸边。妇人先上船，伸手拉孩子。母子坐好以后，船夫才解缆。

## 单选：船夫哪一刻才准备离岸？ {#q.check.4.5}
考点：skill.ferry-custom
语境：p.check.4.shore

- [x] 母子已经坐好之后 {#q.check.4.5.o1}
- [ ] 母子刚到渡口时 {#q.check.4.5.o2}
  理由：刚到渡口时，缆绳正处于什么状态？
- [ ] 妇人刚伸手拉孩子时 {#q.check.4.5.o3}
  理由：“既坐”写在“始解缆”的前面还是后面？

提示：把“系岸”和“解缆”分开读。
解析：“既坐”说母子都已坐定，“始解缆”才轮到船夫准备划走。

## 原文：教学例句 {#p.check.4.bridge}
> 村桥一板折。牧童见行者将至，立桥头呼止之。行者察桥，乃从旁径过。童暮归，告里人修桥。
译文：村桥断了一块板。牧童看见有人快走过来，站在桥头喊他停下。行人查看桥面，便从旁边的小路经过。牧童傍晚回去，告诉乡人要修桥。

## 单选：读到结尾，哪些事情确已发生？ {#q.check.4.6}
考点：skill.mainline
语境：p.check.4.bridge

- [x] 牧童提醒行人避开断桥，并告诉乡人要修桥 {#q.check.4.6.o1}
- [ ] 行人当场修好桥，乡人都从桥上过 {#q.check.4.6.o2}
  理由：“告里人修桥”能证明修桥已经完成了吗？
- [ ] 牧童与行人一同掉下桥，乡人来救 {#q.check.4.6.o3}
  理由：行者后来走的是桥面，还是旁径？

提示：把已经发生的事与人物建议要做的事区分开。
解析：行人已听了劝阻，绕旁路过去；牧童傍晚也告诉乡人该修桥了。有没有人动手修，故事还没讲到。
