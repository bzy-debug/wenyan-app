# 课文：诸葛亮劝刘禅听谁的话 {#l4.10}
简介：读诸葛亮的表，分清“先帝”“陛下”各指谁，再看旧恩和两汉往事怎样引出眼前的劝告。

## 正文

“先帝”是已经去世的刘备，“陛下”是继位的刘禅，上表的是诸葛亮。开头接连说创业未半、天下三分、益州疲敝，到“然”字却转了过来：朝廷内外还有人肯尽力。他们念的是刘备昔日的知遇，今天却要把这份心报答在刘禅身上。有这样的人肯进言，君主就该让他们说得进来。“开张圣听”的来由，在这里。

后来谈到先汉和后汉，再看几组字的位置。亲贤臣、远小人，和亲小人、远贤士，用人取舍恰好颠倒，兴衰也跟着相反。诸葛亮随后列出眼前的官员，才向刘禅说“愿陛下亲之、信之”。讲两汉旧史，是为这两个能马上去做的动作作准备。

## 知识点：看臣下为什么这样进言 {#skill.l4.10.a}
义项：从眼前的形势或过去的事例，读出臣下在“宜”“愿”后请君主做什么
领域：篇章
要诀：前面讲的处境，为什么会引出这句“宜”或“愿”？
讲解：内外臣士仍愿报恩，进谏才有人可听。读到“开张圣听”，把它接回前面的“志士”，便懂诸葛亮为什么在此时劝刘禅广听忠言。
例句：p.l4.10.a

## 知识点：写给谁看，拿谁作例 {#skill.l4.10.b}
义项：从“先帝”“臣”“陛下”等称谓，弄清臣下借谁的旧事说话、劝的是谁
领域：文化背景
要诀：旧恩是谁给的，眼前的话又是对谁说的？
讲解：“先帝”刘备已经去世，“陛下”刘禅正在受表。诸葛亮提先帝的旧恩和旧日议论，是给在位的刘禅作参考。
例句：p.l4.10.b

## 原文：古籍引文 {#p.l4.10.a}
> 先帝创业未半而中道崩徂，今天下三分，益州罢弊，此诚危急存亡之秋也。然侍卫之臣不懈于内，忠志之士亡身于外者，盖追先帝之遇，欲报之于陛下也。诚宜开张圣听，以光先帝遗德，恢志士之气；不宜妄自菲薄，引喻失义，以塞忠谏之路也。
译文：先帝开创事业尚未完成一半就中途去世，现在天下三分，益州疲敝，确是危急存亡的关头。然而内外臣士仍尽心忘身，大约是追念先帝的知遇，想报答在陛下身上。陛下应广泛听取意见，发扬先帝留下的美德，振起志士的心气；不宜随意看轻自己、说话失当，堵住忠言进谏之路。

## 原文：古籍引文 {#p.l4.10.b}
> 亲贤臣，远小人，此先汉所以兴隆也；亲小人，远贤士，此后汉所以倾颓也。先帝在时，每与臣论此事，未尝不叹息痛恨于桓、灵也。侍中、尚书、长史、参军，此悉贞亮死节之臣也。愿陛下亲之、信之，则汉室之隆，可计日而待也。
译文：亲近贤臣、疏远小人，是前汉兴盛的原因；反过来，则是后汉衰落的原因。先帝生前每次与我谈论此事，总为桓帝、灵帝叹息痛惜。这里列举的几位官员都是忠正、肯为节义献身的臣子。希望陛下亲近并信任他们，这样汉室的振兴便可指日而待。

## 找原文证据：说完局势与人心，诸葛亮在哪一句开口请刘禅做一件事？ {#q.l4.10.1}
考点：skill.l4.10.a
语境：p.l4.10.a

- [x] 诚宜开张圣听 {#q.l4.10.1.o1}
- [ ] 此诚危急存亡之秋也 {#q.l4.10.1.o2}
  理由：“存亡之秋”判断局势危急。要找的是诸葛亮随后请君主做的事。
- [ ] 欲报之于陛下也 {#q.l4.10.1.o3}
  理由：“欲报之”的是臣士。诸葛亮给刘禅的建议要从“宜”字读起。

提示：找“宜”后面可由君主实施的动作。
解析：“危急存亡之秋”说形势，“欲报之于陛下”说臣心；到“诚宜开张圣听”，才明确请眼前的君主广听意见。

## 单选：内外臣士受过谁的知遇？如今又想向谁报恩？ {#q.l4.10.2}
考点：skill.l4.10.b
语境：p.l4.10.a

- [ ] 外地臣士要先帝回朝听谏 {#q.l4.10.2.o1}
  理由：先帝已“中道崩徂”。
- [x] 臣士曾受先帝知遇，想在继位者身上报答 {#q.l4.10.2.o2}
- [ ] 刘禅曾经知遇刘备，现在要向父亲报恩 {#q.l4.10.2.o3}
  理由：“追”“欲报”的主语仍是内外臣士。

提示：分别给“先帝”和“陛下”填上名字，再读是谁报恩。
解析：臣士曾受刘备的知遇，如今愿在他的继承者刘禅身上报恩。两个称谓分清，谁的旧恩、向谁尽力就不会读反。

## 单选：如果删掉“然”以下至“欲报之于陛下”，哪一环会缺失？ {#q.l4.10.3}
考点：skill.l4.10.a
语境：p.l4.10.a

- [x] 在危急时仍可倚重哪些人，以及为什么要听他们说话 {#q.l4.10.3.o1}
- [ ] 天下是否三分 {#q.l4.10.3.o2}
  理由：形势列在“然”之前。
- [ ] 先帝是否已去世 {#q.l4.10.3.o3}
  理由：首句已明说崩徂。

提示：删去这一段，还能看出朝廷里外有哪些人肯尽心吗？
解析：若删去这一层，只剩下益州疲敝和广开言路。读者将看不见还有哪些人肯为朝廷尽力，也就少了广纳忠言的具体缘由。

## 单选：“以塞忠谏之路”的后果是谁的行为可能造成的？ {#q.l4.10.4}
考点：skill.l4.10.b
语境：p.l4.10.a

- [x] 当下受表君主若妄自菲薄、言语失当 {#q.l4.10.4.o1}
- [ ] 侍卫之臣若不懈于内 {#q.l4.10.4.o2}
  理由：“不懈”是作者所肯定的表现。
- [ ] 先帝若在世继续重用忠臣 {#q.l4.10.4.o3}
  理由：先帝是追念的依据，已非受劝者。

提示：把“不宜”后两动作补上主语。
解析：“不宜”后面虽省了主语，听话的仍是刘禅。诸葛亮提醒他，若自轻、说话失当，可能把愿意进谏的人挡在门外。

## 单选：哪一项最贴近后段的实际劝告？ {#q.l4.10.5}
考点：skill.l4.10.a
语境：p.l4.10.b

- [ ] 请读者凭两句对偶还原两汉全部制度 {#q.l4.10.5.o1}
  理由：本文写给在位君主，结尾落实为用人建议。
- [ ] 请刘禅立刻裁撤所有侍中、尚书 {#q.l4.10.5.o2}
  理由：作者肯定所举诸臣的品行。
- [x] 请刘禅亲近并信任段中列举的忠臣 {#q.l4.10.5.o3}

提示：由两汉对举读到“愿陛下”。
解析：“愿陛下亲之、信之”紧接列举的几位官员。“之”指他们，所请的事便是刘禅亲近并信任这些忠臣。

## 找原文证据：哪一处显示作者与先帝曾共同讨论相关历史？ {#q.l4.10.6}
考点：skill.l4.10.b
语境：p.l4.10.b

- [ ] 亲小人，远贤士 {#q.l4.10.6.o1}
  理由：这里还在讲后汉为什么衰落。先帝与诸葛亮一同讨论这段历史，在下一句。
- [ ] 愿陛下亲之、信之 {#q.l4.10.6.o2}
  理由：这是作者对当前君主的请求。
- [x] 每与臣论此事 {#q.l4.10.6.o3}

提示：找“臣”出现在过去哪段对话中。
解析：“先帝在时”把时间放在过去，“每与臣论此事”说明刘备曾屡次与诸葛亮谈论这个问题。

## 排序：依后段的说服步骤排列。 {#q.l4.10.7}
考点：skill.l4.10.a
语境：p.l4.10.b

- [1] 用先汉、后汉的用人差异说明兴衰 {#q.l4.10.7.o1}
  理由：两汉往事先说明用人与兴衰有关。
- [3] 请求陛下亲近信任这些人 {#q.l4.10.7.o2}
  理由：“愿陛下”才将先例转成明确请求。
- [2] 引先帝的痛惜，继而点出现有忠臣 {#q.l4.10.7.o3}
  理由：“先帝在时”和当朝官名把历史拉回眼前。

提示：从历史判断走到眼前具体的人。
解析：先由两汉说明用人的后果，再举先帝的惋惜和眼前的忠臣，最后落在请求刘禅怎么做。

## 单选：诸葛亮为什么在劝刘禅用人时提到桓帝、灵帝？ {#q.l4.10.8}
考点：skill.l4.10.b
语境：p.l4.10.b

- [x] 作为先帝痛惜的后汉君主，给继位者作警戒 {#q.l4.10.8.o1}
- [ ] 作为诸葛亮请陛下任命的两位现任官员 {#q.l4.10.8.o2}
  理由：当下官员在下一句另列。
- [ ] 作为亲自向刘禅投递表章的作者 {#q.l4.10.8.o3}
  理由：上表者自称“臣”，是诸葛亮。

提示：观察这两个名字紧跟在哪种情感之后。
解析：桓、灵是先帝谈后汉衰落时曾为之痛惜的两位君主。有了这段旧史，今天劝刘禅慎选亲信就多了一层依据。
