# 课文：出师表如何把话说给君主 {#l4.10}
简介：从危局、旧恩和两汉兴衰，辨认臣下怎样提出行动要求。

## 正文

“先帝”是刘备，“陛下”是继位的刘禅，作者诸葛亮以臣下身份上表。开篇的转折很要紧：局势危急，可仍有内外忠臣效力。先交代他们为什么肯效力，才说君主为何要让意见进得来。读表章时，把“形势如此”与“所以请您这样做”分开。

后一段以先汉、后汉为历史镜子。它不是给两汉列完整兴亡史，而是从中选出亲近哪类人这个政治选择。归到“愿陛下亲之信之”，历史叙述才落到受表者今天能采取的行动。

## 知识点：以情势推出进言 {#skill.l4.10.a}
义项：从危局或史例复原“宜”“愿”后面的行动请求
领域：篇章
要诀：先找依据，再补“因此请陛下……”
讲解：留意前面的人物、条件和后面真正可以执行的动词。
例句：p.l4.10.a

## 知识点：表章中的受言人与先例 {#skill.l4.10.b}
义项：循先帝、臣、陛下等称谓辨认劝告的授权与对象
领域：文化背景
要诀：给旧事中的人和当下受言者分别署名
讲解：臣下借先帝知遇或历史经验进言，真正被要求采取行动的是在位君主。
例句：p.l4.10.b

## 原文：古籍引文 {#p.l4.10.a}
> 先帝创业未半而中道崩徂，今天下三分，益州罢弊，此诚危急存亡之秋也。然侍卫之臣不懈于内，忠志之士亡身于外者，盖追先帝之遇，欲报之于陛下也。诚宜开张圣听，以光先帝遗德，恢志士之气；不宜妄自菲薄，引喻失义，以塞忠谏之路也。
译文：先帝开创事业尚未完成一半就中途去世，现在天下三分，益州疲敝，确是危急存亡的关头。然而内外臣士仍尽心忘身，大约是追念先帝的知遇，想报答在陛下身上。陛下应广泛听取意见，发扬先帝留下的美德，振起志士的心气；不宜随意看轻自己、说话失当，堵住忠言进谏之路。

## 原文：古籍引文 {#p.l4.10.b}
> 亲贤臣，远小人，此先汉所以兴隆也；亲小人，远贤士，此后汉所以倾颓也。先帝在时，每与臣论此事，未尝不叹息痛恨于桓、灵也。侍中、尚书、长史、参军，此悉贞亮死节之臣也。愿陛下亲之、信之，则汉室之隆，可计日而待也。
译文：亲近贤臣、疏远小人，是前汉兴盛的原因；反过来，则是后汉衰落的原因。先帝生前每次与我谈论此事，总为桓帝、灵帝叹息痛惜。这里列举的几位官员都是忠正、肯为节义献身的臣子。希望陛下亲近并信任他们，这样汉室的振兴便可指日而待。

## 找原文证据：由危局与忠臣之心转成对君主的正面请求，是哪一句？ {#q.l4.10.1}
考点：skill.l4.10.a
语境：p.l4.10.a

- [x] 诚宜开张圣听 {#q.l4.10.1.o1}
- [ ] 此诚危急存亡之秋也 {#q.l4.10.1.o2}
  理由：这是对形势的判断。
- [ ] 欲报之于陛下也 {#q.l4.10.1.o3}
  理由：这是说忠臣的意愿。

提示：找“宜”后面可由君主实施的动作。
解析：“开张圣听”要求给进言留路；前面的形势与人心为此作铺垫。

## 单选：“追先帝之遇，欲报之于陛下”涉及怎样的两代关系？ {#q.l4.10.2}
考点：skill.l4.10.b
语境：p.l4.10.a

- [ ] 外地臣士要先帝回朝听谏 {#q.l4.10.2.o1}
  理由：先帝已“中道崩徂”。
- [x] 臣士曾受先帝知遇，想在继位者身上报答 {#q.l4.10.2.o2}
- [ ] 刘禅曾经知遇刘备，现在要向父亲报恩 {#q.l4.10.2.o3}
  理由：“追”“欲报”的主语仍是内外臣士。

提示：给“遇”的施予者和“报”的承受者分别署名。
解析：先帝的旧恩被引作效力当下君主的理由，也将两代事业联结起来。

## 单选：如果删掉“然”以下至“欲报之于陛下”，哪一环会缺失？ {#q.l4.10.3}
考点：skill.l4.10.a
语境：p.l4.10.a

- [x] 在危急时仍可倚重哪些人，以及为什么要听他们说话 {#q.l4.10.3.o1}
- [ ] 天下是否三分 {#q.l4.10.3.o2}
  理由：形势列在“然”之前。
- [ ] 先帝是否已去世 {#q.l4.10.3.o3}
  理由：首句已明说崩徂。

提示：比较删后“益州罢弊”与“开张圣听”之间的距离。
解析：中间的臣士与忠心使开言路的劝告不止是一条孤立口号。

## 单选：“以塞忠谏之路”的后果是谁的行为可能造成的？ {#q.l4.10.4}
考点：skill.l4.10.b
语境：p.l4.10.a

- [x] 当下受表君主若妄自菲薄、言语失当 {#q.l4.10.4.o1}
- [ ] 侍卫之臣若不懈于内 {#q.l4.10.4.o2}
  理由：“不懈”是作者所肯定的表现。
- [ ] 先帝若在世继续重用忠臣 {#q.l4.10.4.o3}
  理由：先帝是追念的依据，已非受劝者。

提示：把“不宜”后两动作补上主语。
解析：表章省去受言者作主语，前面的“陛下”可以补回。

## 找原文证据：哪一处显示作者与先帝曾共同讨论相关历史？ {#q.l4.10.6}
考点：skill.l4.10.b
语境：p.l4.10.b

- [ ] 亲小人，远贤士 {#q.l4.10.6.o1}
  理由：这是后汉衰颓的一项解释。
- [ ] 愿陛下亲之、信之 {#q.l4.10.6.o2}
