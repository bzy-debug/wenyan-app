# 课文：臣子给刘禅写表，怎样把先帝的话说到今天？ {#l4.10}
简介：看清哪位君主已经去世、哪位君主正读此表，才能听出诸葛亮给谁提出了什么请求。

## 正文

一边是“先帝”，刘备立业未竟而亡；一边是“陛下”，读表的是刘禅。初读若把这两个尊称都替作“皇帝”，就会说不清楚侍卫与臣士要把谁的恩报答给谁。请把两个称呼原样放回“追先帝之遇，欲报之于陛下”再读。

困疲的益州和仍肯尽力的人同时摆在眼前。“然”引出转机，“诚宜”“不宜”才成为对策。广开听言之门是让忠心有出路，妄自轻贱、谈论失当则会让谏言说不进来。这不是对一位性格内向者作宽慰，而是在危急中提醒一位君主怎样对进言者作反应。

再看第二处。先用两汉相反的用人选择解释兴衰，再追忆刘备论桓、灵，终于列出朝中可托的官员。常识提示：桓、灵是东汉后期的两位皇帝；“痛恨”在这里是痛心、遗憾。说到“愿陛下亲之、信之”，古人的成败才落实到刘禅眼前可以做的事情上。

## 知识点：重建表章从局势到建议的中间理由 {#skill.l4.10.a}
义项：找出陈情或进言所凭的处境，说明这一请求为何在此时提出
领域：篇章
要诀：遇到“然”，看看危局中还有何人可以依靠。
讲解：先帝已逝而人心愿报旧恩，使得“开张圣听”有可用的人作根据；这一层不能用泛泛的天命替代。
例句：p.l4.10.a

## 知识点：辨清收表人、施恩者与历史榜样 {#skill.l4.10.b}
义项：把臣子的建议、引述的前朝人事和在位者的责任分开
领域：文化背景
要诀：分头问“这是谁曾做的事”“现在谁能照着做”。
讲解：诸葛亮引先帝谈旧史，并未让亡者再出面施政。真正能从身边亲贤远小、接受劝告的人，是收表的刘禅。
例句：p.l4.10.b

## 原文：古籍引文 {#p.l4.10.a}
> 先帝创业未半而中道崩徂，今天下三分，益州罢弊，此诚危急存亡之秋也。然侍卫之臣不懈于内，忠志之士亡身于外者，盖追先帝之遇，欲报之于陛下也。诚宜开张圣听，以光先帝遗德，恢志士之气；不宜妄自菲薄，引喻失义，以塞忠谏之路也。
译文：先帝开创事业还没到一半就中途去世。今日天下三分，益州疲惫困乏，真是危急存亡的时刻。可是宫中侍卫未曾松懈，在外的忠义之士也肯舍身，想来是念及先帝的知遇，要在陛下身上报答。陛下实在应当广听意见，以发扬先帝留下的德行、振起志士的精神；不应无端轻视自己，陈说譬喻失当，以致挡住尽忠进谏的来路。
词注：秋：关头、时刻。
  遇：先帝给予臣下的知遇。
  开张：扩大、广开。

## 原文：古籍引文 {#p.l4.10.b}
> 亲贤臣，远小人，此先汉所以兴隆也；亲小人，远贤士，此后汉所以倾颓也。先帝在时，每与臣论此事，未尝不叹息痛恨于桓、灵也。侍中、尚书、长史、参军，此悉贞亮死节之臣也。愿陛下亲之、信之，则汉室之隆，可计日而待也。
译文：亲近贤臣、疏远小人，是前汉兴盛的缘故；亲近小人、疏远贤士，是后汉倾颓的缘故。先帝在世时，每逢与我谈这些事，无不为桓帝、灵帝叹息痛心。侍中、尚书、长史、参军都是坚贞诚实、可舍身守节的臣子。愿陛下亲近、信任他们，那样汉室的振兴便指日可待了。
词注：所以：在“所以兴隆”里指兴盛的原因。
  痛恨：痛心和遗憾。
  愿：臣下向皇帝陈述自己的愿望。

## 找原文证据：天下三分、益州疲弊之后，诸葛亮用哪一处把笔锋转向仍在尽心的人？ {#q.l4.10.1}
考点：skill.l4.10.a
语境：p.l4.10.a

- [x] 然侍卫之臣不懈于内 {#q.l4.10.1.o1}
- [ ] 先帝创业未半 {#q.l4.10.1.o2}
  理由：这是危局的由来。
- [ ] 以塞忠谏之路也 {#q.l4.10.1.o3}
  理由：这是末尾提醒君主避免的后果。

提示：读第一个“然”，不妨换成“不过”。
解析：“然”没有抹去危局，只在危局中指出还可依靠内外臣士。下文的劝告因此有了着力处。

## 单选：“欲报之于陛下”中的“陛下”和“先帝”能否交换？ {#q.l4.10.2}
考点：skill.l4.10.b
语境：p.l4.10.a

- [ ] 能；表章中两个称呼都只指同一位君主 {#q.l4.10.2.o1}
  理由：先帝已“崩徂”，陛下是正在读表的人。
- [x] 不能；当年给予知遇的是先帝，如今接受报效的是在位者 {#q.l4.10.2.o2}
- [ ] 能；“报恩”既是同一件事，接受知遇和接受报效的人也应相同 {#q.l4.10.2.o3}
  理由：接受知遇的是臣士，给予知遇的是先帝，今日承受报效的是陛下。

提示：一边找“遇”来自谁，一边找“报”落向谁。
解析：旧恩通向今日尽忠，这才使两代君主同时出现在进言里。混作一人，整段的时间和对象都会错。

## 单选：若把“然……欲报之于陛下也”这一层删去，开篇接“诚宜开张圣听”会少什么？ {#q.l4.10.3}
考点：skill.l4.10.a
语境：p.l4.10.a

- [x] 从国势危急到应广听意见之间，少了确有忠臣可听的理由 {#q.l4.10.3.o1}
- [ ] 蜀汉兵少、各方分立的形势本身 {#q.l4.10.3.o2}
  理由：“今天下三分，益州罢弊”仍在。
- [ ] 先帝已去世的时间标志 {#q.l4.10.3.o3}
  理由：“中道崩徂”在最前。

提示：先想危急何以必然推出“听”，中间还要有谁？
解析：危难可以推出许多办法。先写愿意尽力的臣士，扩大听言的途径才显得有针对性。

## 单选：“不宜妄自菲薄”为什么在这里不是一句孤立的性格劝告？ {#q.l4.10.4}
考点：skill.l4.10.b
语境：p.l4.10.a

- [x] 因为引喻失当、自我轻贱会堵塞别人进忠言的路 {#q.l4.10.4.o1}
- [ ] 因为诸葛亮表示自己没有资格向皇帝说话 {#q.l4.10.4.o2}
  理由：被劝“不宜”的是陛下，写表的人还在进言。
- [ ] 因为先帝生前从来不允许群臣说话 {#q.l4.10.4.o3}
  理由：这段没有把先帝列作闭塞言路的反例。

提示：读“不宜”后的末一个“以”，它引向什么后果？
解析：高低评价自己，牵涉在位者怎样回应进谏。把内心态度同言路的后果连起来，才符合此处劝谏的对象。

## 单选：先汉、后汉被简写成兴与衰，有什么直接的劝说作用？ {#q.l4.10.5}
考点：skill.l4.10.a
语境：p.l4.10.b

- [ ] 按朝代断定先汉人人贤、后汉人人奸 {#q.l4.10.5.o1}
  理由：作者比较的是亲近谁、疏远谁。
- [ ] 替刘禅证明本朝自称继汉，兴盛便可自然承继 {#q.l4.10.5.o2}
  理由：后人怎么选择贤士才是历史比较的落点，不会因继承名号就自动兴盛。
- [x] 让刘禅面对两种亲疏安排，看到不同取向可能导致的国运 {#q.l4.10.5.o3}

提示：调换两句中“亲”“远”后的宾语。
解析：相似的结构把不同选择摆到一起，历史的远例随后才落到眼前“亲之、信之”。

## 找原文证据：由两汉兴亡转到践行建议，哪句直接要求刘禅改变自己怎样对待眼前人？ {#q.l4.10.6}
考点：skill.l4.10.b
语境：p.l4.10.b

- [ ] 先帝在时，每与臣论此事 {#q.l4.10.6.o1}
  理由：这是先帝谈史的记忆。
- [ ] 此先汉所以兴隆也 {#q.l4.10.6.o2}
  理由：这是分析前汉兴盛的缘由。
- [x] 愿陛下亲之、信之 {#q.l4.10.6.o3}

提示：先找“愿”字，再看后面是谁要做什么。
解析：“之”就近接侍中、尚书、长史、参军。愿句给这个读表的人布置了可以实行的动作。

## 排序：依原文排出诸葛亮从谈古到荐人的三步。 {#q.l4.10.7}
考点：skill.l4.10.a
语境：p.l4.10.b

- [1] 拿亲贤与亲小人的相反后果作对照 {#q.l4.10.7.o1}
  理由：段首先并写两汉。
- [3] 列现有官员，向陛下请托以信任 {#q.l4.10.7.o2}
  理由：“此悉……”之后才有“愿陛下”。
- [2] 回忆先帝与自己谈桓、灵时的态度 {#q.l4.10.7.o3}
  理由：“先帝在时”把国史接到刘禅熟悉的人。

提示：看朝代名、先帝、眼前的官称依次出现在哪里。
解析：同一劝告有三种根据：前代兴亡、父辈意见、现成可托之人。它一步步逼近这位收表的君主。

## 单选：“可计日而待也”里的期待，承接了哪项尚需做到的事？ {#q.l4.10.8}
考点：skill.l4.10.b
语境：p.l4.10.b

- [x] 陛下亲近并信任方才举出的贤臣 {#q.l4.10.8.o1}
- [ ] 臣下只需怀念先帝，即便不被新君信任也足以中兴 {#q.l4.10.8.o2}
  理由：“则”之前的“愿陛下”尚有接纳贤臣这一要求。
- [ ] 汉室已确凿中兴，只是日期需要查历 {#q.l4.10.8.o3}
  理由：“愿……则……”先交代条件才展望结果。

提示：把“则”前的愿望接到“则”后的前景。
解析：结语有鼓励之意，但它依附于用人的选择；这封表里没有给出一个现成日期。
