# 课文：李密为什么请求先奉养祖母 {#l4.11}
简介：一边是年迈的祖母，一边是朝廷的任命。李密列出两人的年龄，究竟想向君主请求什么？

## 正文

李密上表，希望先留在家中奉养祖母。婴儿时失去父亲，四岁时母亲离家，接过孩子亲自抚养的是祖母刘氏。“九岁不行”紧跟“少多疾病”，说的是他九岁还不能走路。“至于成立”才把这一段从幼年写到长大成人。

再读两人的年龄：“臣密今年四十有四”，祖母却已经九十六岁。李密能在将来奉职的日子还长，眼下能陪伴、奉养祖母的时日却短。他列出年岁，是为了说清先要照料谁，以及想留到什么时候。“愿乞终养”里的“终”字，尤其值得细读。

## 知识点：陈情时怎样说明非己不可 {#skill.l4.11.a}
义项：从家人的处境，读出写表的人为什么请求亲自承担这件事
领域：篇章
要诀：小时候是谁养他长大？如今家里又有哪些人能接手？
讲解：“躬亲抚养”交代祖母的旧恩，“既无伯叔，终鲜兄弟”交代可分担的人手很少。李密为何请求自己留下，这两处都用得上。
例句：p.l4.11.a

## 知识点：请求从何时起、到何时为止 {#skill.l4.11.b}
义项：从年龄、时日和期限，弄清臣下请求何时做什么
领域：文化背景
要诀：留意请愿中表示长短、先后的词。
讲解：“日长”说将来尚能尽忠，“日短”说祖母已年迈。“终养”把所请的期限落在奉养祖母至终。
例句：p.l4.11.b

## 原文：古籍引文 {#p.l4.11.a}
> 臣以险衅，夙遭闵凶。生孩六月，慈父见背；行年四岁，舅夺母志。祖母刘愍臣孤弱，躬亲抚养。臣少多疾病，九岁不行，零丁孤苦，至于成立。既无伯叔，终鲜兄弟，门衰祚薄，晚有儿息。
译文：我命途艰险，很早就遇上不幸。出生六个月父亲就去世，四岁时舅父迫使母亲改嫁。祖母刘氏怜我孤弱，亲自抚养。我幼时多病，九岁还不能走路，孤单困苦，一直到长大成人。没有伯叔，也缺少兄弟，家族人丁衰少，很晚才有孩子。

## 原文：古籍引文 {#p.l4.11.b}
> 臣密今年四十有四，祖母刘今年九十有六，是臣尽节于陛下之日长，报养刘之日短也。乌鸟私情，愿乞终养。臣之辛苦，非独蜀之人士及二州牧伯所见明知，皇天后土，实所共鉴。

## 找原文证据：哪四个字说祖母亲手把李密养大？ {#q.l4.11.1}
考点：skill.l4.11.a
语境：p.l4.11.a

- [ ] 舅夺母志 {#q.l4.11.1.o1}
  理由：“舅夺母志”说母亲为何离家，还没写祖母后来怎样照料李密。
- [ ] 晚有儿息 {#q.l4.11.1.o2}
  理由：“晚有儿息”说李密自己很晚才有孩子，此时已离开他幼年受养那一段。
- [x] 躬亲抚养 {#q.l4.11.1.o3}

提示：找“祖母刘”之后的动作。
解析：“躬亲”是亲自。李密自幼体弱，是祖母一手把他养大。如今祖母老了，他也想亲自照料她。

## 单选：“九岁不行”在这一段人生次序中指什么？ {#q.l4.11.2}
考点：skill.l4.11.b
语境：p.l4.11.a

- [x] 因幼年多病，九岁还不能行走 {#q.l4.11.2.o1}
- [ ] 到九岁已经长大成家 {#q.l4.11.2.o2}
  理由：下文“至于成立”才概括后来的成人。
- [ ] 九岁不肯去朝廷做官 {#q.l4.11.2.o3}
  理由：说的是童年疾病，并未谈到征召。

提示：把这一句紧接“臣少多疾病”来读。
解析：“九岁不行”紧接李密幼年多病，说的是不能行走。把它读作不肯任职，就把后来受征召的事提前了。

## 单选：请求留下奉养祖母时，李密为什么要数家中的伯叔、兄弟？ {#q.l4.11.3}
考点：skill.l4.11.a
语境：p.l4.11.a

- [ ] 证明祖母没有亲自养大他 {#q.l4.11.3.o1}
  理由：前文明确“躬亲抚养”。
- [x] 说明可分担家庭照护的近亲很少 {#q.l4.11.3.o2}
- [ ] 表示所有蜀地人士都与他绝交 {#q.l4.11.3.o3}
  理由：列的是家中近亲，不是社会交往。

提示：祖母需要人照料时，前后说到的亲属有谁能来分担？
解析：没有伯叔，也少兄弟，眼下能分担照护的亲人很少。这串亲属称谓都与李密为何必须自己留下有关。

## 排序：依原文所述的李密人生先后排列。 {#q.l4.11.4}
考点：skill.l4.11.b
语境：p.l4.11.a

- [2] 四岁母亲离家，祖母亲养 {#q.l4.11.4.o1}
  理由：“行年四岁”接在父亡以后，交代母离与祖母抚养。
- [1] 婴儿时父亲去世 {#q.l4.11.4.o2}
  理由：“生孩六月”比四岁早。
- [3] 幼时多病，孤苦长大 {#q.l4.11.4.o3}
  理由：“至于成立”将时间从童年推到成人。

提示：年龄词可确定前后，“至于成立”是较晚的回顾。
解析：父亡时李密才六个月。四岁时母亲离家，他由祖母抚养；“至于成立”再把读者带到他长大成人。

## 单选：“乌鸟私情”放在两个人的年龄之后，主要补出哪层关系？ {#q.l4.11.5}
考点：skill.l4.11.a
语境：p.l4.11.b

- [ ] 李密请求替所有亲族谋取官职 {#q.l4.11.5.o1}
  理由：“愿乞”所接的是“终养”。
- [ ] 祖母侍奉朝廷的日期已经确定 {#q.l4.11.5.o2}
  理由：请愿对象是陛下，祖母并非受命为官者。
- [x] 自己曾被抚养，如今愿趁祖母尚在奉养她 {#q.l4.11.5.o3}

提示：联系“报养刘”中的“报”。
解析：过去祖母亲自养育他，如今他愿意回过头来养祖母。“报养”的“报”和乌鸟反哺的比喻相照应。

## 找原文证据：李密想留在祖母身边到什么时候？找出他的原话。 {#q.l4.11.6}
考点：skill.l4.11.b
语境：p.l4.11.b

- [ ] 尽节于陛下之日长 {#q.l4.11.6.o1}
  理由：还能有很长的日子为君主尽忠，所以他敢请求暂缓；要缓到何时，得看“终养”。
- [ ] 皇天后土 {#q.l4.11.6.o2}
  理由：李密请天地作证，是表明心意真切。期限还要从他向君主“乞”的事情里找。
- [x] 愿乞终养 {#q.l4.11.6.o3}

提示：找“愿乞”所接的具体动作。
解析：所求是“终养”，即奉养祖母到她生命终了。这样说，既能叫人知道眼前所急，也说清推迟奉职到什么时候。

## 单选：李密说蜀地人士和二州长官都知情，是想请他们说明什么？ {#q.l4.11.7}
考点：skill.l4.11.a
语境：p.l4.11.b

- [ ] 代替陛下决定此表是否批准的人 {#q.l4.11.7.o1}
  理由：李密仍向陛下陈情。
- [x] 能够知道他实际处境的旁证 {#q.l4.11.7.o2}
- [ ] 已经承诺接班照护祖母的家人 {#q.l4.11.7.o3}
  理由：“所见明知”说知情，不是接手照护。

提示：分清知道苦衷与能替代照护。
解析：李密请蜀中人士和两州长官作知情的人，说明自己的苦处确实为人所知。知道这番苦处，并不等于能够替他照料祖母。

## 单选：若将请愿改述为“我选四十四年尽孝，九十六年尽忠”，错在哪里？ {#q.l4.11.8}
考点：skill.l4.11.b
语境：p.l4.11.b

- [x] 把当下年龄错当成预计的服务期限 {#q.l4.11.8.o1}
- [ ] 把李密称作一位臣子 {#q.l4.11.8.o2}
  理由：李密正以“臣”上表。
- [ ] 提到奉养和尽忠两种责任 {#q.l4.11.8.o3}
  理由：这两种责任确实都在原文。

提示：先用“今年几岁”问这两个数字，再看“日长”“日短”说的又是什么。
解析：两个数字都在“今年”之后，是两人当前的年龄。它们说明报养比将来尽忠更急迫，不能直接当作余下的年数。
