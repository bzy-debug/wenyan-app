# 课文：李密并列两个人的年纪，是要争取多少时间？ {#l4.11}
简介：祖母曾把他养大，眼下又无人代为照料。读完这些家事，再回到表文真正向皇帝提出的请求。

## 正文

“慈父见背”很委婉：李密才六个月，父亲已经去世。四岁时遇到另一桩事，母亲被舅父迫使改嫁。两处年龄对应不同的变故。祖母刘氏随后“躬亲抚养”，这一笔写明李密小时候是谁在尽力。再说伯叔、兄弟、儿子，才指出今天他要离家的难处。

读第二段前先替收表人问一句：受征召的人总说家庭困难，是否要永远拒绝出仕？李密把一老一少的年纪并到一句话里，一边是可尽忠的日子还长，一边是能报养的日子已短。他没有把九十六岁当成可推算死亡日期的根据，他想安排两种责任在何时做才可能两全。

“乌鸟”用乌鸦反哺的传统说法比自己的孝亲愿望。“愿乞终养”才是真正的请求。后面举蜀中人士、地方长官，再呼皇天后土，是替这番家事求取信任；皇帝能批准的仍只是前面那一句。遇上陈情文字，有用的办法是分清陈述的难处、可作证的人和所请之事。

## 知识点：从身世中辨出请愿所需的证据 {#skill.l4.11.a}
义项：区分身世的叙述、证明与收件人能批准的事项
领域：篇章
要诀：“祖母……抚养”同“无伯叔”“鲜兄弟”分头解决哪一个疑问？
讲解：祖母抚育在先，李密应当报恩；可以分担的人少，解释他此时何以非留下不可。两条理由得从不同句子里取。
例句：p.l4.11.a

## 知识点：从期限辨请愿的分寸 {#skill.l4.11.b}
义项：辨识眼下、此后一段时间与终身，不把推迟一事读成永久拒绝
领域：文化背景
要诀：用“何时能做”读两个“日”，再找“愿乞”之后的界限。
讲解：祖母年高、自己尚壮，能说明报养的机会比事君来得紧迫。“终养”给眼下的请求划了边，既没有规定日期，也没许诺永不出仕。
例句：p.l4.11.b

## 原文：古籍引文 {#p.l4.11.a}
> 臣以险衅，夙遭闵凶。生孩六月，慈父见背；行年四岁，舅夺母志。祖母刘愍臣孤弱，躬亲抚养。臣少多疾病，九岁不行，零丁孤苦，至于成立。既无伯叔，终鲜兄弟，门衰祚薄，晚有儿息。
译文：臣命运坎坷，自幼便遇上不幸。生下才六月，父亲就离世；四岁那年，舅父强使母亲改嫁。祖母刘氏怜我孤弱，亲手将我养大。我幼时常病，九岁还不能走，一直孤苦地长到成人。既无伯父叔父，也少有兄弟帮衬；家门衰薄，很晚才有儿子。
词注：见背：父亲离我而去，是说父亲亡故。
  成立：长大成人、自立。

## 原文：古籍引文 {#p.l4.11.b}
> 臣密今年四十有四，祖母刘今年九十有六，是臣尽节于陛下之日长，报养刘之日短也。乌鸟私情，愿乞终养。臣之辛苦，非独蜀之人士及二州牧伯所见明知，皇天后土，实所共鉴。

## 找原文证据：李密讲幼年的处境，哪一句明确说谁实际承担了抚育他的事？ {#q.l4.11.1}
考点：skill.l4.11.a
语境：p.l4.11.a

- [ ] 零丁孤苦，至于成立 {#q.l4.11.1.o1}
  理由：这概述他从幼小到成人的处境，未交代是谁照顾他。
- [ ] 既无伯叔，终鲜兄弟 {#q.l4.11.1.o2}
  理由：这是亲属单薄，不能代替直接的抚养事实。
- [x] 祖母刘愍臣孤弱，躬亲抚养 {#q.l4.11.1.o3}

提示：留心“躬亲”，是谁亲自做的？
解析：幼年失去父母照拂，本可以只说明可怜；明写祖母亲自抚养，又为今日谁应反过来照料她留下依据。

## 单选：“行年四岁，舅夺母志”之后才写祖母，能否据此写成“李密父母都在他四岁时去世”？ {#q.l4.11.2}
考点：skill.l4.11.b
语境：p.l4.11.a

- [x] 不能；父亲早亡与母亲被迫改嫁是两件不同的事 {#q.l4.11.2.o1}
- [ ] 能；“见背”和“夺母志”是对同一次丧事的复说 {#q.l4.11.2.o2}
  理由：前者指父亲去世，后者交代母亲处境。
- [ ] 能；“行年四岁”追补说明前面的“生孩六月” {#q.l4.11.2.o3}
  理由：两种年龄标记着不同遭遇。

提示：先把六月与四岁各归还给它后面那件事。
解析：若把两件事写成同时双亡，祖母接手照顾的具体来由就被改了。读自述先尊重作者给的年月。

## 单选：“晚有儿息”好像说明也有孩子，为什么不能拿来直接否定“家中难有替手”？ {#q.l4.11.3}
考点：skill.l4.11.a
语境：p.l4.11.a

- [ ] 只要尚有伯叔在，孩子再小也能由伯叔承担 {#q.l4.11.3.o1}
  理由：“既无伯叔”已经排除了这一层替手。
- [x] 孩子来得晚，结合无伯叔兄弟，不能推成已有成年亲属可接手 {#q.l4.11.3.o2}
- [ ] “晚有”表示根本没有孩子 {#q.l4.11.3.o3}
  理由：李密明说有，困难在于能否替代照顾。

提示：篇中先列上一辈、同辈，再顺着读下一辈。
解析：他逐层交代可指望的家人。既不能凭空添一个壮年的帮手，也不能把“有儿息”删成没有。

## 排序：把李密请求留家之前的家世交代，按各句讲述的先后复述。 {#q.l4.11.4}
考点：skill.l4.11.b
语境：p.l4.11.a

- [2] 祖母养大体弱多病的孩子 {#q.l4.11.4.o1}
  理由：接下来写抚养与九岁仍不能行。
- [1] 婴幼时丧父，母亲后来被迫改嫁 {#q.l4.11.4.o2}
  理由：先是六月，再是四岁。
- [3] 成年后再点出亲属稀少、晚得儿子 {#q.l4.11.4.o3}
  理由：“至于成立”以后转谈家门现状。

提示：留意两处年龄和“至于成立”，后者指长大成人。
解析：早年的依靠与今天的无替手分处前后，把两段一接，才看出这段往事为何是请求的理由。

## 单选：李密把两个人的年龄并列，主要想请陛下考虑什么？ {#q.l4.11.5}
考点：skill.l4.11.a
语境：p.l4.11.b

- [ ] 按年龄算出祖母一定会在哪一年去世 {#q.l4.11.5.o1}
  理由：数字已知，余寿却没有精确预告。
- [ ] 按长幼证明照顾祖母比事君永远优先 {#q.l4.11.5.o2}
  理由：“日长、日短”争的是眼下先后，不立一切时候的规矩。
- [x] 奉养祖母可用的时间已经很短，自己尽忠尚可能有来日 {#q.l4.11.5.o3}

提示：比较结论用的是“长短”还是“轻重高下”。
解析：四十四和九十六把两个义务放在长短不同的时间里。有人肯答应暂缓，就不必让两项永远冲突。

## 找原文证据：哪几个字明确界定李密想把奉养持续到什么时候？ {#q.l4.11.6}
考点：skill.l4.11.b
语境：p.l4.11.b

- [ ] 臣密今年四十有四 {#q.l4.11.6.o1}
  理由：年龄说明为什么能作这种安排，却没有提出请求。
- [ ] 皇天后土，实所共鉴 {#q.l4.11.6.o2}
  理由：这是为实情作证，没交代期限。
- [x] 愿乞终养 {#q.l4.11.6.o3}

提示：“终”落在哪件要向陛下请求的事上？
解析：终养指奉养祖母到她去世。不是说李密从此终身不再出仕，也没有指定某个日期。

## 单选：在表里提蜀中人士与二州牧伯，最能回答皇帝怎样的疑虑？ {#q.l4.11.7}
考点：skill.l4.11.a
语境：p.l4.11.b

- [ ] 哪个地方官已批准他不必奉诏 {#q.l4.11.7.o1}
  理由：“所见明知”是知道实情，不是有权允准。
- [x] 这番为难究竟只是他自己的说辞，还是当地人也知情 {#q.l4.11.7.o2}
- [ ] 两州都需要他任职，所以皇帝应从中选一处 {#q.l4.11.7.o3}
  理由：这是列见证者，没有列求职志愿。

提示：这些人后面接的是“知”还是“许”？
解析：皇帝不在他家中，李密便援引家乡与官员所知，使家中状况有公开可核的根据。

## 单选：有人替李密写结论：“陛下和祖母只能选一位，我永远选祖母。”哪个地方最不合他的说法？ {#q.l4.11.8}
考点：skill.l4.11.b
语境：p.l4.11.b

- [x] 抹去“尽节……日长”，把他争取的先后变成永久弃此取彼 {#q.l4.11.8.o1}
- [ ] 漏了“皇天后土”，没有交代究竟由谁批准终养 {#q.l4.11.8.o2}
  理由：天地是他呼唤的见证，皇帝才是收表人；这不触及“永远”违背原文的地方。
- [ ] 把祖母的抚育说成小时候的事 {#q.l4.11.8.o3}
  理由：祖母确是从李密幼年开始抚养。

提示：再读一遍紧邻“报养刘之日短”的前一句。
解析：李密先保留日后报国的可能，再请准眼前终养。两种责任并排，正是这封表能向君主开口的理由。
