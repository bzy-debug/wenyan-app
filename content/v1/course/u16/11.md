# 课文：李密怎样说明所请有期 {#l4.11}
简介：从照护关系、两代人的年龄和时间对举，还原陈情表所请求的实际安排。

## 正文

李密向晋朝君主陈情，希望先留在家中照护祖母。第一段看似列身世，其实在处理一个现实问题：祖母养大了谁，如今又有谁能接替照护。读到“不行”应联系九岁与疾病，理解作不能行走；读到“成立”则已长成人。

后段不把孝与侍奉朝廷说成永远二选一，而是列出自己与祖母的年岁，将两种责任放在长短不同的时间里。年龄计算能说明他的请求为什么急切、有期限，却不能保证任何人的确切寿数。

## 知识点：陈情材料与不可替代性 {#skill.l4.11.a}
义项：由亲属处境说明请求中特定行动为何须由本人承担
领域：篇章
要诀：辨认过去抚养者和今天照护者
讲解：亲属关系、可接替的人手、对方的处境共同决定请求的理由。
例句：p.l4.11.a

## 知识点：表请中的时间界限 {#skill.l4.11.b}
义项：结合年龄及时间限定读出请愿的具体范围
领域：文化背景
要诀：区分已尽的责任、眼前急务与将来打算
讲解：用当事人所说的期限约束推论，避免将暂缓某事读成永久拒绝。
例句：p.l4.11.b

## 原文：古籍引文 {#p.l4.11.a}
> 臣以险衅，夙遭闵凶。生孩六月，慈父见背；行年四岁，舅夺母志。祖母刘愍臣孤弱，躬亲抚养。臣少多疾病，九岁不行，零丁孤苦，至于成立。既无伯叔，终鲜兄弟，门衰祚薄，晚有儿息。
译文：我命途艰险，很早就遇上不幸。出生六个月父亲就去世，四岁时舅父迫使母亲改嫁。祖母刘氏怜我孤弱，亲自抚养。我幼时多病，九岁还不能走路，孤单困苦，一直到长大成人。没有伯叔，也缺少兄弟，家族人丁衰少，很晚才有孩子。

## 原文：古籍引文 {#p.l4.11.b}
> 臣密今年四十有四，祖母刘今年九十有六，是臣尽节于陛下之日长，报养刘之日短也。乌鸟私情，愿乞终养。臣之辛苦，非独蜀之人士及二州牧伯所见明知，皇天后土，实所共鉴。
译文：我李密今年四十四岁，祖母刘氏九十六岁，因此我能为陛下尽忠的日子长，能回报奉养祖母的日子短。我怀着乌鸟反哺一般的私情，乞求准许我为她养老送终。我的辛酸苦处不独蜀中人士和两州长官明白，天地也可共同见证。

## 找原文证据：哪处直接说明李密幼年孤弱时，祖母亲自承担了什么？ {#q.l4.11.1}
考点：skill.l4.11.a
语境：p.l4.11.a

- [ ] 舅夺母志 {#q.l4.11.1.o1}
  理由：这是导致家庭处境改变的前事。
- [ ] 晚有儿息 {#q.l4.11.1.o2}
  理由：这是后来说到家中人手的情况。
- [x] 躬亲抚养 {#q.l4.11.1.o3}

提示：找“祖母刘”之后的动作。
解析：亲自把孩子养大，为后来由他报养祖母建立具体的情义根据。

## 单选：“九岁不行”在这一段人生次序中指什么？ {#q.l4.11.2}
考点：skill.l4.11.b
语境：p.l4.11.a

- [x] 因幼年多病，九岁还不能行走 {#q.l4.11.2.o1}
- [ ] 到九岁已经长大成家 {#q.l4.11.2.o2}
  理由：下文“至于成立”才概括后来的成人。
- [ ] 九岁不肯去朝廷做官 {#q.l4.11.2.o3}
  理由：说的是童年疾病，并未谈到征召。

提示：把这一句紧接“臣少多疾病”来读。
解析：年龄与疾病限定了“不行”的所指，不能提前代入他成年后的请愿。

## 单选：“既无伯叔，终鲜兄弟”如何服务于上表？ {#q.l4.11.3}
考点：skill.l4.11.a
语境：p.l4.11.a

- [ ] 证明祖母没有亲自养大他 {#q.l4.11.3.o1}
  理由：前文明确“躬亲抚养”。
- [x] 说明可分担家庭照护的近亲很少 {#q.l4.11.3.o2}
- [ ] 表示所有蜀地人士都与他绝交 {#q.l4.11.3.o3}
  理由：列的是家中近亲，不是社会交往。

提示：把亲属名单看作解决照护问题的条件。
解析：交代家中人手，使由李密本人报养的请求更具体。

## 排序：依原文所述的李密人生先后排列。 {#q.l4.11.4}
考点：skill.l4.11.b
语境：p.l4.11.a

- [2] 四岁母亲离家，祖母亲养 {#q.l4.11.4.o1}
  理由：“行年四岁”接在父亡以后，交代母离与祖母抚养。
- [1] 婴儿时父亲去世 {#q.l4.11.4.o2}
  理由：“生孩六月”比四岁早。
- [3] 幼时多病，孤苦长大 {#q.l4.11.4.o3}
  理由：“至于成立”将时间从童年推到成人。

提示：年龄词可确定前后，“至于成立”是较晚的回顾。
解析：按六月、四岁、幼年以至成人排列，分清童年受养与长成年后的责任。

## 单选：“乌鸟私情”放在两个人的年龄之后，主要补出哪层关系？ {#q.l4.11.5}
考点：skill.l4.11.a
语境：p.l4.11.b

- [ ] 李密请求替所有亲族谋取官职 {#q.l4.11.5.o1}
  理由：“愿乞”所接的是“终养”。
- [ ] 祖母侍奉朝廷的日期已经确定 {#q.l4.11.5.o2}
  理由：请愿对象是陛下，祖母并非受命为官者。
- [x] 自己曾被抚养，如今愿趁祖母尚在奉养她 {#q.l4.11.5.o3}

提示：联系“报养刘”中的“报”。
解析：乌鸟反哺的比喻将曾受照护、今欲回报的关系写得更切身。

## 找原文证据：哪一句最精确地给所请求的延缓设下边界？ {#q.l4.11.6}
考点：skill.l4.11.b
语境：p.l4.11.b

- [ ] 尽节于陛下之日长 {#q.l4.11.6.o1}
  理由：这是说明延期可行的理由。
- [ ] 皇天后土 {#q.l4.11.6.o2}
  理由：这里引天地为证，没有说延缓到何时。
- [x] 愿乞终养 {#q.l4.11.6.o3}

提示：找“愿乞”所接的具体动作。
解析：希望奉养祖母至生命终了；这个界限定在祖母身上，没有说永远不仕。

## 单选：蜀地人士和二州牧伯被列出来，承担什么角色？ {#q.l4.11.7}
考点：skill.l4.11.a
语境：p.l4.11.b

- [ ] 代替陛下决定此表是否批准的人 {#q.l4.11.7.o1}
  理由：李密仍向陛下陈情。
- [x] 能够知道他实际处境的旁证 {#q.l4.11.7.o2}
- [ ] 已经承诺接班照护祖母的家人 {#q.l4.11.7.o3}
  理由：“所见明知”说知情，不是接手照护。

提示：分清知道苦衷与能替代照护。
解析：列知情者增强陈述可信度，不改变照护责任的承担者。

## 单选：若将请愿改述为“我选四十四年尽孝，九十六年尽忠”，错在哪里？ {#q.l4.11.8}
考点：skill.l4.11.b
语境：p.l4.11.b

- [x] 把当下年龄错当成预计的服务期限 {#q.l4.11.8.o1}
- [ ] 把李密称作一位臣子 {#q.l4.11.8.o2}
  理由：李密正以“臣”上表。
- [ ] 提到奉养和尽忠两种责任 {#q.l4.11.8.o3}
  理由：这两种责任确实都在原文。

提示：“今年”管辖两个数词，后面才推“日长”“日短”。
解析：年岁是比较所据的现状，由它只能推相对急缓，不能得出实际剩余年数。
