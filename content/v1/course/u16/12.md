# 课文：游人走后谁还在乐？从山路读到太守 {#l4.12}
简介：远处一座山用眼睛看，近处一眼泉先听到水声。等游人散去，笔下的山林又换了一批主人。

## 正文

起初要辨的是地方：滁州四周群山，到西南群峰，再到其中深秀的琅琊。注意“山行六七里，渐闻水声”，已不是拿着地名站在原地指点。等泉从两峰间泻出，山路一转，才能看见像鸟展翅一样临于泉上的亭。每个地名都被放在一段观察之后，读者自己也经历了一次找路。

接连问谁造亭、谁命名，答案是智仙与太守两个不同的人。初读可以在旁边记住这位太守，先别急着替他报名姓。等到文章最后说“醒能述以文者”，才知道把滁州这番出游留给后世读者的，正是同一位太守。

夕阳下游人归去，人声让位给上下鸟鸣。文中“乐”在禽鸟、游人、太守之间接连换主人，每换一次，还要问他乐的是哪件事。“太守之乐其乐”的两个“乐”不宜读成一句自我欣赏：太守的快乐正以别人的快乐为对象。末句再请读者认识写文章的欧阳修，已经在此基础上多走了一层。

## 知识点：依据行止和感官次序读写景 {#skill.l4.12.a}
义项：辨识取景人的站位、走向和见闻次序，而非只列景物
领域：篇章
要诀：从远望走到“渐闻”，再到转过山路后的亭子。
讲解：山、泉、亭的名称都能背下，仍未必看清这条路。先听见水，再见两峰间的泉，表明读者也跟着行人接近了地方。
例句：p.l4.12.a

## 知识点：给反复出现的词找主体和对象 {#skill.l4.12.b}
义项：逐句找出谁乐、乐什么、谁又不能知别人的乐
领域：阅读技能
要诀：把“禽鸟乐”“人乐”“太守乐其乐”各写成主语完整的一句。
讲解：人知道自己跟随太守出游很快乐，却未必理解太守以同游者的乐为乐。结尾点出写作者，使随众出游与留文记游相接。
例句：p.l4.12.b

## 原文：古籍引文 {#p.l4.12.a}
> 环滁皆山也。其西南诸峰，林壑尤美，望之蔚然而深秀者，琅琊也。山行六七里，渐闻水声潺潺，而泻出于两峰之间者，酿泉也。峰回路转，有亭翼然临于泉上者，醉翁亭也。作亭者谁？山之僧曰智仙也。名之者谁？太守自谓也。
译文：滁州四面环山。西南那几座峰的林木山谷尤其好看，望去草木茂盛、幽深秀丽的是琅琊山。沿山路走六七里，渐听泉水淙淙；在两峰间流泻而出的是酿泉。峰势回转，路也绕过来，有座亭子如鸟展翅临在泉上，便是醉翁亭。谁造了亭？山僧智仙。谁为亭取名？太守用自己的称号为它命名。
词注：壑：山谷。
  翼然：像鸟展翅的样子。
  名之：给这亭子取名。

## 原文：古籍引文 {#p.l4.12.b}
> 已而夕阳在山，人影散乱，太守归而宾客从也。树林阴翳，鸣声上下，游人去而禽鸟乐也。然而禽鸟知山林之乐，而不知人之乐；人知从太守游而乐，而不知太守之乐其乐也。醉能同其乐，醒能述以文者，太守也。太守谓谁？庐陵欧阳修也。
译文：不一会儿夕阳倚山，人影散乱，太守回去，宾客跟着。树林浓荫遮蔽，上下传来鸟鸣；游人离去，禽鸟乐起来了。鸟只知山林的快乐，不知人的快乐；人们知道随太守出游很快乐，却不知太守正以他们的快乐为乐。醉时能同他们一道快乐，醒来能将这一切写成文章的，是太守。太守是谁？庐陵人欧阳修。
词注：阴翳：树木枝叶遮蔽。
  从：在“宾客从也”里指跟随。
  述：记述，把见闻写下来。

## 排序：从“环滁”读到醉翁亭，按读者跟着行人逐渐靠近的次序排列。 {#q.l4.12.1}
考点：skill.l4.12.a
语境：p.l4.12.a

- [3] 山路转弯，才见泉上如张翼的亭子 {#q.l4.12.1.o1}
  理由：“峰回路转”后首次点出亭名。
- [1] 从群山认出西南特别深秀的琅琊 {#q.l4.12.1.o2}
  理由：“望之”还在远观。
- [2] 沿山走几里，寻水声看到酿泉 {#q.l4.12.1.o3}
  理由：行路和听声把人引入山间。

提示：顺着“望”“渐闻”“路转”走一趟。
解析：“也”一次次把所见配上名字，地点由大收小；声音是从远望转为置身其间的一道线索。

## 单选：同样问“谁”，作亭和为亭命名的是不是一人？ {#q.l4.12.2}
考点：skill.l4.12.b
语境：p.l4.12.a

- [ ] 两件事都由智仙做，因为他先于太守出场 {#q.l4.12.2.o1}
  理由：“名之者谁”重新发问，不是沿用上一个答案。
- [x] 造亭的僧人是智仙，给予名字的是太守 {#q.l4.12.2.o2}
- [ ] 两件事都由太守做，因为最后文章点明欧阳修 {#q.l4.12.2.o3}
  理由：末尾认领文章的名字，不能代替造亭人的名字。

提示：给两句“……者谁”各配紧跟在它后面的回答。
解析：一地可留下不同人的行动。这里把造亭、命名分列，又让“太守”留到篇末再揭姓名。

## 找原文证据：除了“望”，原文哪处感官变化让人感觉脚步已经靠近泉水？ {#q.l4.12.3}
考点：skill.l4.12.a
语境：p.l4.12.a

- [ ] 望之蔚然而深秀者 {#q.l4.12.3.o1}
  理由：这还是从远处望山的眼力，并未改用听觉。
- [ ] 有亭翼然临于泉上者 {#q.l4.12.3.o2}
  理由：这写看见亭的样子，已经走过寻找泉水的一步。
- [x] 渐闻水声潺潺 {#q.l4.12.3.o3}

提示：找一个不必用眼睛也能知道的信号。
解析：水声由远及近，有了听觉的线索，泉才从山中的远景变成行人眼前可辨的水流。

## 单选：每次先写外观，再说“琅琊也”“酿泉也”，这样的次序让读者怎么认识地方？ {#q.l4.12.4}
考点：skill.l4.12.b
语境：p.l4.12.a

- [ ] 先背地名，再按地图逐一核对经纬 {#q.l4.12.4.o1}
  理由：景物特征都在名称之前。
- [x] 先随行人辨认景物，再得到名称 {#q.l4.12.4.o2}
- [ ] 先由造亭人开口指路，再将他的指点按地点抄下 {#q.l4.12.4.o3}
  理由：提到智仙时亭已经找到，文中也没有引他作向导。

提示：把“望之蔚然而深秀者，琅琊也”换一次顺序试读。
解析：若直接说“这里有琅琊山”，寻找和辨认的过程便少了一层。句末点名正接住之前描写的那个对象。

## 单选：人影散去后“鸣声上下”才入耳，这一层同开头“渐闻水声”最可相比之处是什么？ {#q.l4.12.5}
考点：skill.l4.12.a
语境：p.l4.12.b

- [x] 声音都随人的行止出现，帮助读者换一个立足处看山林 {#q.l4.12.5.o1}
- [ ] 两声都准确标示同一座泉的名字 {#q.l4.12.5.o2}
  理由：晚归时所写的鸣声来自禽鸟。
- [ ] 两声都证明山中无人，水声鸟鸣才听得见 {#q.l4.12.5.o3}
  理由：初次听泉时行人正在趋近；傍晚鸟鸣才接在游人离去之后。

提示：一次在走近，一次在游人离去；分别是谁的声音入了文章？
解析：白日行至山中，水声引出泉；游人散后，鸟鸣让原有人群的山林转到另一种生活。景物都由次序组织。

## 找原文证据：“人知从太守游而乐”之后，哪几个字说太守的乐还以别人的乐为对象？ {#q.l4.12.6}
考点：skill.l4.12.b
语境：p.l4.12.b

- [x] 太守之乐其乐也 {#q.l4.12.6.o1}
- [ ] 而不知人之乐 {#q.l4.12.6.o2}
  理由：这说禽鸟所不知道的那一层。
- [ ] 游人去而禽鸟乐也 {#q.l4.12.6.o3}
  理由：这里是游人离开后的鸟之乐。

提示：找两个“乐”挨得特别近的一处，分别问谁在乐。
解析：“乐其乐”前一“乐”是以……为乐，后面的“其乐”是游人的快乐。同游并不表示彼此都看见了这一层。

## 单选：末尾才说“庐陵欧阳修也”，为什么这时点姓名格外有用？ {#q.l4.12.7}
考点：skill.l4.12.a
语境：p.l4.12.b

- [x] 前面那个能同游、酒醒还能写这篇文章的太守，至此同执笔人相合 {#q.l4.12.7.o1}
- [ ] 开头给亭子取名的人到篇末才首次以“太守”身份登场 {#q.l4.12.7.o2}
  理由：开头已经以“太守”回答命名者，这次才揭出姓名和执笔人的身份。
- [ ] 先前的太守是智仙，到这里才换欧阳修接任 {#q.l4.12.7.o3}
  理由：智仙是造亭的山僧，文中没有官员更替。

提示：留意点姓名之前的“醒能述以文”。
解析：文章先让读者认得太守在做什么，才交代是谁把这些事写下来。结尾的自报名姓也交代了叙述来自哪里。

## 单选：“禽鸟不知人之乐，人不知太守之乐”是否在把同游者判成不快乐？ {#q.l4.12.8}
考点：skill.l4.12.b
语境：p.l4.12.b

- [ ] 是；人不懂太守便不能从同游中得乐 {#q.l4.12.8.o1}
  理由：前文已经肯定“人知从太守游而乐”。
- [x] 没有；游人确实快乐，只是未必知道太守为什么快乐 {#q.l4.12.8.o2}
- [ ] 是；最后的“醉”一字取消了众人的快乐 {#q.l4.12.8.o3}
  理由：“醉能同其乐”反而写能共享。

提示：在三种“知／不知”后分别补出所知的对象。
解析：知道自己的快乐和理解别人的快乐是两件事。层层递进，最后才容得下能共享又能记述的太守。
