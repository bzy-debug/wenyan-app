# 课文：《醉翁亭记》里，太守以什么为乐 {#l4.12}
简介：先循着水声找到亭子，再顺着游人归去读到太守。两个“乐”字连在一起，各说的是谁？

## 正文

先站远些看：滁州四面都是山，西南诸峰里有琅琊山。再沿山路走，泉还没有出现在眼前，水声已渐渐传来。直到峰回路转，才见翼然临泉的一座亭子。两个“谁”紧跟上来：亭是智仙建的，命名的却是太守。这样，笔从山泉走到亭，又从亭走到了人。

篇末，游人散了，树林里听得见鸟鸣。鸟有山林之乐，人有随太守出游之乐。还有一层是游人自己不知道的：“太守之乐其乐”，前一个“乐”是以什么为乐，后一个“乐”指游人的快乐。太守以众人的欢喜为欢喜，醉时和大家同乐，醒后还能把这番同游写下来。到这里，写《记》的人也有了名字。

## 知识点：跟着游人的目光读写景 {#skill.l4.12.a}
义项：顺着谁在看、谁在听、到了哪里，读清游记先写什么、后写什么
领域：篇章
要诀：先问谁在看、听到了什么，再跟着动作往下走。
讲解：到醉翁亭之前，读者先远望山林，继而在山路听泉声；到了傍晚，人影散去，树林里又响起禽鸟的鸣声。景物之间，各有耳目可循。
例句：p.l4.12.a

## 知识点：同一个词，前后各指谁 {#skill.l4.12.b}
义项：同一个词前后出现时，分清每一处说的是谁、指的又是什么
领域：阅读技能
要诀：两个“乐”是不是同一个人在快乐？
讲解：“人知从太守游而乐”写游人自己的快乐。问太守以什么为乐，再读“乐其乐”，末尾的“乐”便有了来处。
例句：p.l4.12.b

## 原文：古籍引文 {#p.l4.12.a}
> 环滁皆山也。其西南诸峰，林壑尤美，望之蔚然而深秀者，琅琊也。山行六七里，渐闻水声潺潺，而泻出于两峰之间者，酿泉也。峰回路转，有亭翼然临于泉上者，醉翁亭也。作亭者谁？山之僧曰智仙也。名之者谁？太守自谓也。
译文：滁州四面都是山。西南诸峰林谷格外秀美，远望草木繁盛幽深的是琅琊山。沿山路走六七里，渐听见流水潺潺，从两峰间倾泻而出的是酿泉。山势回环、道路转折，一座像鸟张开双翼般临着泉水的亭子，就是醉翁亭。建亭的是谁？山僧智仙。给它命名的呢？是太守用自己的别号命名。

## 原文：古籍引文 {#p.l4.12.b}
> 已而夕阳在山，人影散乱，太守归而宾客从也。树林阴翳，鸣声上下，游人去而禽鸟乐也。然而禽鸟知山林之乐，而不知人之乐；人知从太守游而乐，而不知太守之乐其乐也。醉能同其乐，醒能述以文者，太守也。太守谓谁？庐陵欧阳修也。
译文：不久夕阳照山，人影散开，太守回去，宾客随行。树林浓荫遮蔽，上下都是鸟鸣，游人走了，禽鸟得其乐。然而鸟知道山林的快乐，不知道人的快乐；人知道跟从太守游玩很快活，却不知道太守以他们的快乐为快乐。醉时能够和大家同乐，醒时能用文章记下的，是太守。太守是谁？庐陵的欧阳修。

## 排序：循着文中的山路，按先后排出一路所见所闻。 {#q.l4.12.1}
考点：skill.l4.12.a
语境：p.l4.12.a

- [3] 转过峰路见亭临泉 {#q.l4.12.1.o1}
  理由：经过峰回路转，泉上之亭方进入画面。
- [1] 远望西南峰林 {#q.l4.12.1.o2}
  理由：“望之”时仍在看远处的西南山林。
- [2] 沿山路听到泉水 {#q.l4.12.1.o3}
  理由：“山行六七里”以后才逐渐听见流水。

提示：区分“望”“闻”和峰回路转后的所见。
解析：先“望”琅琊山，再“山行”并“渐闻水声”，最后“峰回路转”才见醉翁亭。山、泉、亭都由行路时的耳目相接。

## 单选：“作亭者”与“名之者”分别是谁？ {#q.l4.12.2}
考点：skill.l4.12.b
语境：p.l4.12.a

- [ ] 太守建亭，智仙给太守起号 {#q.l4.12.2.o1}
  理由：问答顺序恰好相反。
- [x] 山僧智仙建亭，太守给亭命名 {#q.l4.12.2.o2}
- [ ] 两件事都是酿泉的发现者所作 {#q.l4.12.2.o3}
  理由：文中并无一个被称为发现酿泉的人。

提示：两次“谁”各自就近寻找答句。
解析：作亭者是智仙，名亭者是太守。两个“谁”分问两件事，都有就近的答句。

## 找原文证据：哪句最清楚写出见亭前行进路线的改变？ {#q.l4.12.3}
考点：skill.l4.12.a
语境：p.l4.12.a

- [ ] 林壑尤美 {#q.l4.12.3.o1}
  理由：“林壑尤美”说西南诸峰美在哪里，还没有走到要转弯的那段路。
- [ ] 环滁皆山也 {#q.l4.12.3.o2}
  理由：“环滁皆山也”一下子写了整个滁州周围的山，还没写眼前山路怎样转。
- [x] 峰回路转 {#q.l4.12.3.o3}

提示：找既涉及山势又涉及道路的四个字。
解析：“峰回路转”把山势和人的路线都写了进去。道路这一转，泉上的亭子才出现在眼前。

## 单选：“名之者谁”里的“之”沿前文回指什么？ {#q.l4.12.4}
考点：skill.l4.12.b
语境：p.l4.12.a

- [ ] 山僧智仙原本的姓名 {#q.l4.12.4.o1}
  理由：上一问给出建亭者，正在取名的是亭。
- [x] 刚由两峰间的泉水引出的醉翁亭 {#q.l4.12.4.o2}
- [ ] 整个滁州的行政名称 {#q.l4.12.4.o3}
  理由：叙述已由滁州范围收至一亭。

提示：看两个问句共享的对象。
解析：前问谁造亭，后问谁“名之”，还是在问这座醉翁亭。两问换了做事的人，没换被建造、被命名的对象。

## 单选：宾客跟着太守归去之后，作者又让人听到了什么？ {#q.l4.12.5}
考点：skill.l4.12.a
语境：p.l4.12.b

- [x] 人的队伍离开，注意力转回林中仍活动的禽鸟 {#q.l4.12.5.o1}
- [ ] 作者回到清晨重写第一次登山 {#q.l4.12.5.o2}
  理由：“已而夕阳在山”仍是同一天傍晚。
- [ ] 鸟群护送太守入城 {#q.l4.12.5.o3}
  理由：鸣声属林中，游人已经离开。

提示：对读“游人去”与“禽鸟乐”。
解析：前一刻看见散乱的人影，随后听见树林上下的鸣声。游人已经离开，在山林中活动的禽鸟这才进入人的注意。

## 找原文证据：哪一句写太守把游人的快乐当作自己的快乐？ {#q.l4.12.6}
考点：skill.l4.12.b
语境：p.l4.12.b

- [x] 太守之乐其乐也 {#q.l4.12.6.o1}
- [ ] 禽鸟知山林之乐 {#q.l4.12.6.o2}
  理由：这里写的是禽鸟在山林里的快乐。
- [ ] 人知从太守游而乐 {#q.l4.12.6.o3}
  理由：这里只说随太守出游的人觉得快乐。太守因他们快乐而高兴，还要往下读。

提示：找句中“乐”前后各出现一次的地方。
解析：“太守之乐其乐”里，太守自己所乐的是游人随游所得的快乐。前一个“乐”有“以……为乐”的意思。

## 单选：写到“醒能述以文”，太守除了同游，还有什么身份？ {#q.l4.12.7}
考点：skill.l4.12.a
语境：p.l4.12.b

- [x] 游赏中的太守又成为回顾并写下此游的作者 {#q.l4.12.7.o1}
- [ ] 旅客记录太守却始终不知其名 {#q.l4.12.7.o2}
  理由：最后一句已经署出欧阳修。
- [ ] 山鸟开始以人的文字记事 {#q.l4.12.7.o3}
  理由：此句的主语由“太守也”揭出。

提示：把“述”与这篇《记》本身相联系。
解析：这位太守参加了出游，也把同游的快乐写成了文章。读到“述以文”，眼前的游人与落笔记事的欧阳修就合成了一个人。

## 单选：游人知道什么，又没看出太守的哪一层用心？ {#q.l4.12.8}
考点：skill.l4.12.b
语境：p.l4.12.b

- [ ] 游人并不知道自己身在山中 {#q.l4.12.8.o1}
  理由：“知从太守游而乐”明确写他们知道自己的感受。
- [x] 知道自己随游的快乐，未必知道太守所乐正是他们快乐 {#q.l4.12.8.o2}
- [ ] 游人已经理解太守的一切用心 {#q.l4.12.8.o3}
  理由：后一个“不知”明示仍有未察觉的一层。

提示：分别补出“游人知道……”和“游人不知道……”。
解析：游人知道跟太守出游很快乐，却不一定明白，太守最喜欢的正是看见大家快乐。两个“知”的内容在这里分开。
