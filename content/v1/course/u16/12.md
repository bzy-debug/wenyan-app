# 课文：醉翁亭记的视线与乐意 {#l4.12}
简介：从山泉亭的近景到太守看游人之乐，读懂两个“乐”各属于谁。

## 正文

开头沿行路人的感觉前进：先远望诸峰，再行山路闻泉，转过峰路才见亭。连问“作亭者谁”“名之者谁”，视角便从物移到人。把作亭、命名配给不同的人，才能读懂太守为何会在一篇游记里成为中心。

篇末的阴翳树林还有鸟声，游人已归。作者一层层区分鸟知道的乐、游人知道的乐和太守所乐。“太守之乐其乐”里，前一个“乐”是以某事为乐，后一个“乐”要回接游人从游的快乐。同乐之外还能“述以文”，于是写记的人也进入了画面。

## 知识点：景物铺陈的视线转移 {#skill.l4.12.a}
义项：跟随感官、主体与空间变换重建记的组织
领域：篇章
要诀：标出看见、听见以及是谁在感受
讲解：在连续画面间找过渡的动作或主体，解释景物如何引出人的活动。
例句：p.l4.12.a

## 知识点：同词复现时的主体归属 {#skill.l4.12.b}
义项：辨析相同字词在相邻句中各属于谁、指向什么
领域：阅读技能
要诀：给每一次命名、知道或快乐补主语
讲解：在问答与转述中逐次核对角色，同一词的重复不意味着同一人和同一对象。
例句：p.l4.12.b

## 原文：古籍引文 {#p.l4.12.a}
> 环滁皆山也。其西南诸峰，林壑尤美，望之蔚然而深秀者，琅琊也。山行六七里，渐闻水声潺潺，而泻出于两峰之间者，酿泉也。峰回路转，有亭翼然临于泉上者，醉翁亭也。作亭者谁？山之僧曰智仙也。名之者谁？太守自谓也。
译文：滁州四面都是山。西南诸峰林谷格外秀美，远望草木繁盛幽深的是琅琊山。沿山路走六七里，渐听见流水潺潺，从两峰间倾泻而出的是酿泉。山势回环、道路转折，一座像鸟张开双翼般临着泉水的亭子，就是醉翁亭。建亭的是谁？山僧智仙。给它命名的呢？是太守用自己的别号命名。

## 原文：古籍引文 {#p.l4.12.b}
> 已而夕阳在山，人影散乱，太守归而宾客从也。树林阴翳，鸣声上下，游人去而禽鸟乐也。然而禽鸟知山林之乐，而不知人之乐；人知从太守游而乐，而不知太守之乐其乐也。醉能同其乐，醒能述以文者，太守也。太守谓谁？庐陵欧阳修也。
译文：不久夕阳照山，人影散开，太守回去，宾客随行。树林浓荫遮蔽，上下都是鸟鸣，游人走了，禽鸟得其乐。然而鸟知道山林的快乐，不知道人的快乐；人知道跟从太守游玩很快活，却不知道太守以他们的快乐为快乐。醉时能够和大家同乐，醒时能用文章记下的，是太守。太守是谁？庐陵的欧阳修。

## 排序：按文章的感官行程排列。 {#q.l4.12.1}
考点：skill.l4.12.a
语境：p.l4.12.a

- [3] 转过峰路见亭临泉 {#q.l4.12.1.o1}
  理由：经过峰回路转，泉上之亭方进入画面。
- [1] 远望西南峰林 {#q.l4.12.1.o2}
  理由：“望之”时仍在看远处的西南山林。
- [2] 沿山路听到泉水 {#q.l4.12.1.o3}
  理由：“山行六七里”以后才逐渐听见流水。

提示：区分“望”“闻”和峰回路转后的所见。
解析：先给出远景，再以水声引入泉，最后到达亭前。

## 单选：“作亭者”与“名之者”分别是谁？ {#q.l4.12.2}
考点：skill.l4.12.b
语境：p.l4.12.a

- [ ] 太守建亭，智仙给太守起号 {#q.l4.12.2.o1}
  理由：问答顺序恰好相反。
- [x] 山僧智仙建亭，太守给亭命名 {#q.l4.12.2.o2}
- [ ] 两件事都是酿泉的发现者所作 {#q.l4.12.2.o3}
  理由：文中并无一个被称为发现酿泉的人。

提示：两次“谁”各自就近寻找答句。
解析：前一问对应山僧，后一问对应太守；两个动作也须保留。

## 找原文证据：哪句最清楚写出见亭前行进路线的改变？ {#q.l4.12.3}
考点：skill.l4.12.a
语境：p.l4.12.a

- [ ] 林壑尤美 {#q.l4.12.3.o1}
  理由：这是对林谷的判断。
- [ ] 环滁皆山也 {#q.l4.12.3.o2}
  理由：这是总写地域。
- [x] 峰回路转 {#q.l4.12.3.o3}

提示：找既涉及山势又涉及道路的四个字。
解析：山势与道路一转，临泉之亭随即出现，画面获得具体转折点。

## 单选：“名之者谁”里的“之”沿前文回指什么？ {#q.l4.12.4}
考点：skill.l4.12.b
语境：p.l4.12.a

- [ ] 山僧智仙原本的姓名 {#q.l4.12.4.o1}
  理由：上一问给出建亭者，正在取名的是亭。
- [x] 刚由两峰间的泉水引出的醉翁亭 {#q.l4.12.4.o2}
- [ ] 整个滁州的行政名称 {#q.l4.12.4.o3}
  理由：叙述已由滁州范围收至一亭。

提示：看两个问句共享的对象。
解析：前问谁“作亭”，后问谁“名之”；行动者变了，受事仍是亭。

## 单选：由宾客随太守归去转写“鸣声上下”，发生了怎样的视线变化？ {#q.l4.12.5}
考点：skill.l4.12.a
语境：p.l4.12.b

- [x] 人的队伍离开，注意力转回林中仍活动的禽鸟 {#q.l4.12.5.o1}
- [ ] 作者回到清晨重写第一次登山 {#q.l4.12.5.o2}
  理由：“已而夕阳在山”仍是同一天傍晚。
- [ ] 鸟群护送太守入城 {#q.l4.12.5.o3}
  理由：鸣声属林中，游人已经离开。

提示：对读“游人去”与“禽鸟乐”。
解析：空间仍在山林，感知中心由散去的人影转成树间的鸣声。

## 找原文证据：哪一句写太守把游人的快乐当作自己的快乐？ {#q.l4.12.6}
考点：skill.l4.12.b
语境：p.l4.12.b

- [x] 太守之乐其乐也 {#q.l4.12.6.o1}
- [ ] 禽鸟知山林之乐 {#q.l4.12.6.o2}
  理由：主体为鸟，对象为山林。
- [ ] 人知从太守游而乐 {#q.l4.12.6.o3}
  理由：这是游人知道自己游玩的快乐。

提示：找句中“乐”前后各出现一次的地方。
解析：前“乐”是以之为乐，后“乐”指上文游人的快乐。

## 单选：“醒能述以文”给篇末多添了一层什么视角？ {#q.l4.12.7}
考点：skill.l4.12.a
语境：p.l4.12.b

- [x] 游赏中的太守又成为回顾并写下此游的作者 {#q.l4.12.7.o1}
- [ ] 旅客记录太守却始终不知其名 {#q.l4.12.7.o2}
  理由：最后一句已经署出欧阳修。
- [ ] 山鸟开始以人的文字记事 {#q.l4.12.7.o3}
  理由：此句的主语由“太守也”揭出。

提示：把“述”与这篇《记》本身相联系。
解析：太守不仅参加同游，还能将所见所思整理为文，文章在这里点出叙述者。

## 单选：“人知……而不知……”限定了游人认识的哪一层？ {#q.l4.12.8}
考点：skill.l4.12.b
语境：p.l4.12.b

- [ ] 游人并不知道自己身在山中 {#q.l4.12.8.o1}
  理由：“知从太守游而乐”明确写他们知道自己的感受。
- [x] 知道自己随游的快乐，未必知道太守所乐正是他们快乐 {#q.l4.12.8.o2}
- [ ] 游人已经理解太守的一切用心 {#q.l4.12.8.o3}
  理由：后一个“不知”明示仍有未察觉的一层。

提示：给两个“知”的宾语分别补全。
解析：同一个“人”可以知道自己的快乐，同时并不理解太守的深一层用心。
