# 检查：《石钟山记》与《求通亲亲表》：一句结语写给谁？ {#check.16}

## 原文：古籍引文 {#p.check.16.a}
> 余方心动欲还，而大声发于水上，噌吰如钟鼓不绝。舟人大恐。徐而察之，则山下皆石穴罅，不知其浅深，微波入焉，涵澹澎湃而为此也。
译文：我心里刚一惊，想要往回走，水上便起了巨响，像钟鼓齐鸣，绵延不断。船工大为恐惧。慢慢察看，原来山脚下尽是石洞裂缝，深浅不知；细小的水波涌进去，激荡吞吐，这才发出这样的声响。
词注：徐：缓缓地。
  罅：读 xià，缝隙。
  焉：在“微波入焉”中相当于进入那里。

## 原文：古籍引文 {#p.check.16.b}
> 事不目见耳闻，而臆断其有无，可乎？郦元之所见闻，殆与余同，而言之不详；士大夫终不肯以小舟夜泊绝壁之下，故莫能知；而渔工水师虽知而不能言，此世所以不传也。而陋者乃以斧斤考击而求之，自以为得其实。余是以记之，盖叹郦元之简，而笑李渤之陋也。
译文：一件事不亲眼看、亲耳听，却凭臆测判它有无，这可以吗？郦道元的见闻大概同我相近，只是说得不详。士大夫终究不肯坐小船夜泊绝壁之下，所以无从得知；渔人、船师虽知，却不能形诸言辞，这就是世间未曾传开的缘故。浅陋者倒拿斧子去敲击探寻，自以为弄明白了。我因此写下这篇记，感叹郦道元说得简略，也讥笑李渤见识浅陋。
词注：臆断：凭主观猜测判断。
  殆：大概。
  考击：敲击石头。

## 原文：古籍引文 {#p.check.16.c}
> 今臣以一切之制，永无朝觐之望。至于注心皇极，结情紫闼，神明知之矣。然天实为之，谓之何哉！退省诸王，常有戚戚具尔之心。愿陛下沛然垂诏，使诸国庆问，四节得展，以叙骨肉之欢恩，全怡怡之笃义。妃妾之家，膏沐之遗，岁得再通，齐义于贵宗，等惠于百司。
译文：如今臣受这权行一时的制度所限，长久没有入朝觐见的希望。对朝廷的向往，寄在宫门的情意，神明自知；既然情形如此，又能怎么办？退而顾念诸王，心中常有兄弟相亲的情意。愿陛下广施恩泽降诏，让诸国的庆贺问候得以在四时节日表达，以叙骨肉之欢，全手足和睦之谊。又愿妃妾娘家间的膏沐馈赠，一年能往来两次，使宗室与贵戚、百官同样蒙受恩惠。
词注：朝觐：臣下朝见君主。
  遗：读 wèi，馈赠。
  再：这里指两次。
出处：《文选·求通亲亲表》节录

## 排序：苏轼听水上巨声时，先后怎样从不安走到有解释可提？ {#q.check.16.1}
考点：skill.l4.12.a
语境：p.check.16.a

- [3] 把水波进穴后的激荡同听到的声音联系起来 {#q.check.16.1.o1}
  理由：“微波入焉……为此”解释此前所闻。
- [2] 慢慢察看，发现山下石上有穴缝 {#q.check.16.1.o2}
  理由：“徐而察之”让惊恐转成观察。
- [1] 巨大声响在水上发出，同行人惊恐 {#q.check.16.1.o3}
  理由：“余方心动欲还”接着写巨声、船人恐。

提示：分别找“发”“徐而察”“为此”。
解析：害怕是真实反应，解释却要等到察看之后。苏轼把这一段由耳闻、目见串到推断的路程写给读者。

## 单选：曹植把“诸国庆问”和“妃妾之家”具体写出来，求诏的对象为何不能只概括成“想家”？ {#q.check.16.2}
考点：skill.l4.11.a
语境：p.check.16.c

- [x] 他在替不同亲属关系请求可获准的往来，把感情写成能颁布的事 {#q.check.16.2.o1}
- [ ] 因为这只是一篇描写诸王如何彼此庆问的回忆 {#q.check.16.2.o2}
  理由：“愿陛下……使”表明相关往来还有待获准。
- [ ] 因为他请皇帝把兄弟一律召回同住宫中 {#q.check.16.2.o3}
  理由：请求中还分节候、年次，并未要求同居。

提示：看看“愿陛下……使……”后有哪两种人和哪两种联络。
解析：表章有明确收件人。诸王的问候、与姻亲的馈赠都涉及制度，因而要把私人牵挂说成君主可以批复的请求。

## 找原文证据：曹植从陈说心意直接转为请求皇帝下令，转折点在哪一句？ {#q.check.16.3}
考点：skill.l4.10.a
语境：p.check.16.c

- [ ] 神明知之矣 {#q.check.16.3.o1}
  理由：这是说有人可知自己的心，并未要求下令。
- [x] 愿陛下沛然垂诏 {#q.check.16.3.o2}
- [ ] 退省诸王 {#q.check.16.3.o3}
  理由：这里还在思量诸王的亲情。

提示：找“愿”后面收表的人能够亲自做的事。
解析：“垂诏”是向下发布诏令。后面的“四节得展”“岁得再通”才是请求诏令允许的具体事项。

## 单选：“莫能知”写谁不去察看，“虽知而不能言”又写谁？两处“知”合起来解释了什么？ {#q.check.16.4}
考点：skill.l4.12.b
语境：p.check.16.b

- [ ] 认定渔工从未到过水边，而士大夫天天亲临绝壁 {#q.check.16.4.o1}
  理由：原文把两者的处境恰好说在相反方向。
- [x] 士大夫不肯亲去，渔工水师亲知却不能著述；所见和传下来的记载便可能分离 {#q.check.16.4.o2}
- [ ] 认定所有写得简略的著作都没有亲历根据 {#q.check.16.4.o3}
  理由：作者对郦元还说其见闻可能与己相同。

提示：对照“终不肯以小舟夜泊”和“虽知而不能言”。
解析：有文字能力的人未必到场，到场的人知道却未必留下可传之言。苏轼以“记”试着跨过这层隔阂。

## 单选：曹植说“愿陛下沛然垂诏，使诸国庆问”。若把这道请求转交有权答复的人，三方应怎样区分？ {#q.check.16.5}
考点：skill.l4.10.b
语境：p.check.16.c

- [x] 上表的是曹植，能下诏的是皇帝，希望获准通问的是诸王之家 {#q.check.16.5.o1}
- [ ] 下诏的是曹植，皇帝只代他把家书传给诸王 {#q.check.16.5.o2}
  理由：“愿陛下……垂诏”出自向上的请求，曹植自己不能以诏令准许此事。
- [ ] 妃妾之家已下令通问，现在由皇帝请求曹植照办 {#q.check.16.5.o3}
  理由：家属也是拟受恩惠的人；“愿”字以后的话是曹植所求，还没有谁照办。

提示：从“臣”读到“陛下”，再看“使”字会给谁带来改变。
解析：曹植为诸王及亲属之间的往来请命。低头称臣、受表发诏、奉诏相通问，各有其人；不能因为都属亲族便抹平这一层君臣关系。

## 单选：曹植请“四节得展”，又请“岁得再通”。给皇帝拟批复记录，哪一句最准确？ {#q.check.16.6}
考点：skill.l4.11.b
语境：p.check.16.c

- [x] 诸国节候问候和姻亲一年两度馈送，应分作两项准请 {#q.check.16.6.o1}
- [ ] 一切探亲从此不受次数拘束 {#q.check.16.6.o2}
  理由：原文“两度”的“再”及“四节”都是具体界限。
- [ ] 每年四次赠送膏沐，另许诸国每年两次问候 {#q.check.16.6.o3}
  理由：把两种往来所属的次数调换了。

提示：分别在“四节”和“岁”前，找与它相连的话。
解析：一项接“使诸国庆问”，一项接“妃妾之家，膏沐之遗”。同是诉亲情，所请的事与频率各有归属。
