# 检查：在另一页读懂“北辰”、异本和句界 {#check.18}

## 原文：古籍引文 {#p.check.18.a}
> 北极谓之北辰。北辰常居其所而不移，故众星共尊之。
译文：北极称作北辰。北辰常在本位不动，所以众星都环拱尊奉它。
词注：北辰：古人对天北极附近星辰的称呼，这里引用的是疏家的说法。
  故：所以，引出解释的后半。

## 单选：若只摘“北极谓之北辰”，经文中的哪个名称受解释？ {#q.check.18.1}
考点：s.l5.glossdirection
语境：p.check.18.a

- [ ] 北极 {#q.check.18.1.o2}
  理由：经文说“譬如北辰”。“北极”是疏家用来说明“北辰”的词。
- [x] 北辰 {#q.check.18.1.o1}
- [ ] 众星 {#q.check.18.1.o3}
  理由：众星在下一句出现，这里只释北辰。

提示：看“谓之”之后的两个字。
解析：疏以“北极”说明经文中的名称“北辰”。

## 找原文证据：按疏的说法，北辰何以能用作居位的比方？ {#q.check.18.2}
考点：s.l5.glossdirection
语境：p.check.18.a

- [ ] 众星 {#q.check.18.2.o3}
  理由：仅说众星，不能说明北辰自身的特点。
- [ ] 北极谓之北辰 {#q.check.18.2.o2}
  理由：这是解释名称，未说明星的位置变化。
- [x] 常居其所而不移 {#q.check.18.2.o1}

提示：找“故”之前所说的情形。
解析：疏先讲它不移，才讲众星拱尊；比方所取的特点由此可见。

## 原文：古籍引文 {#p.check.18.b}
> 共，求用反。郑作拱，俱勇反，拱手也。
译文：“共”用“求用”反切。郑氏本写作“拱”，用“俱勇”反切，指拱手。
词注：郑作：郑氏所用的本子写作。
  俱勇反：用“俱”的声母、“勇”的韵和调为“拱”注音。

## 单选：这条音义把哪一个反切配给郑本的写法？ {#q.check.18.3}
考点：s.l5.soundnote
语境：p.check.18.b

- [x] 拱——俱勇反 {#q.check.18.3.o1}
- [ ] 郑——俱勇反 {#q.check.18.3.o3}
  理由：“郑”是指出另一家读本，不是要反切的字。
- [ ] 拱——求用反 {#q.check.18.3.o2}
  理由：“求用反”跟在“共”后。

提示：先对准“郑作”之后的字。
解析：郑本写“拱”，继而注它的音和义。

## 单选：古注说“郑作拱”，读者引用自己所据的“共”本时怎样交代？ {#q.check.18.4}
考点：s.l5.soundnote
语境：p.check.18.b

- [ ] 把所有本都写作“拱” {#q.check.18.4.o2}
  理由：这条注专门区分了两种写法。
- [x] 照抄“共”，旁注郑本作“拱” {#q.check.18.4.o1}
- [ ] 删“拱手也”，说两者毫无意义差别 {#q.check.18.4.o3}
  理由：这会漏掉注书人给郑本写法配的解释。

提示：分别记下正文和所引异本。
解析：此处同时记录异字、异读及一条释义，三样都能帮助比较。

> 君子欲讷于言而敏于行

## 单选：要把言行两面各自读完整，哪种停法合适？ {#q.check.18.5}
考点：s.l5.clauses
语境：p.check.18.c

- [ ] 君子欲讷／于言而敏于／行 {#q.check.18.5.o3}
  理由：这拆散了两个相配的“于……”短语。
- [ ] 君子欲讷于／言而敏于行 {#q.check.18.5.o2}
  理由：“于”引所及方面，不宜断在“言”前。
- [x] 君子欲讷于言／而敏于行 {#q.check.18.5.o1}

提示：留意两个“于”后各有一个字。
解析：“讷于言”和“敏于行”成对，“而”把两面联起来。

## 单选：若给后半补出省去的意思，应怎样讲？ {#q.check.18.6}
考点：s.l5.clauses
语境：p.check.18.c

- [x] 君子还希望行动敏捷 {#q.check.18.6.o1}
- [ ] 另一位刚出场的人要快走 {#q.check.18.6.o3}
  理由：原文没换主语，“君子欲”管到后半。
- [ ] 言语本身行动得快 {#q.check.18.6.o2}
  理由：“言”是前半所及，“行”才是后半所及。

提示：看看“而”后有没有另起一个主语。
解析：一个“欲”领两种表现，这也能验证句界。
