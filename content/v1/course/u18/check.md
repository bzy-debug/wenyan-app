# 检查：读隐公元年的事和齐景公的问话 {#check.18}

## 原文：古籍引文 {#p.check.18.a}
> 元年春王正月。三月，公及邾仪父盟于蔑。夏五月，郑伯克段于鄢。秋七月，天王使宰咺来归惠公、仲子之赗。
译文：鲁隐公元年春季王历正月。三月，鲁隐公与邾仪父在蔑结盟。夏季五月，郑伯在鄢击败段。秋季七月，周王派宰咺来给惠公、仲子送助丧之物。

## 单选：记录蔑地的盟会，年、月、日能写到哪一步？ {#q.check.18.1}
考点：skill.l5.4
语境：p.check.18.a

- [ ] 鲁隐公元年正月初一 {#q.check.18.1.o2}
  理由：“三月”已经把盟会与开头正月分开。
- [x] 鲁隐公元年三月，日子未载 {#q.check.18.1.o1}
- [ ] 郑伯元年五月，日子未载 {#q.check.18.1.o3}
  理由：这是鲁隐公的元年。郑伯到夏五月那条才出现。

提示：“元年”要回篇题看是谁的元年；盟会前最近的月份是哪一个？
解析：这是鲁隐公元年三月的事，日子没有记下来。

## 单选：“天王使宰咺来归……之赗”，谁派谁来，所为何事？ {#q.check.18.2}
考点：skill.l5.5
语境：p.check.18.a

- [ ] 鲁君任命惠公为宰 {#q.check.18.2.o3}
  理由：惠公在“赗”这一层里。看看“使”后面紧跟的是谁。
- [ ] 来送丧礼后，咺才被封为天王 {#q.check.18.2.o2}
  理由：“天王”是派遣者的称号。
- [x] 周王派遣宰咺来送助丧物 {#q.check.18.2.o1}

提示：“使”前后各是谁？“赗”与什么礼有关？
解析：周王吩咐宰咺来送助丧物。这一次写的是派遣，未说谁新得了官职。

## 单选：“公及邾仪父盟于蔑”，这个没冠上国名的“公”指哪位？ {#q.check.18.3}
考点：skill.l5.6
语境：p.check.18.a

- [x] 结合篇题和鲁国编年的叙事立场，指鲁隐公 {#q.check.18.3.o1}
- [ ] 指本条以后的郑伯 {#q.check.18.3.o3}
  理由：郑伯在另一个月份的事件中才出现。
- [ ] 指邾仪父，他与自己结盟 {#q.check.18.3.o2}
  理由：“及”连接的是两方。

提示：篇题以谁的元年纪事？“及”又把哪两方连起来？
解析：鲁史称本国国君为“公”。在隐公元年的经文中，便是鲁隐公与邾仪父结盟。

## 原文：古籍引文 {#p.check.18.b}
> 齐景公问政于孔子。孔子对曰：“君君，臣臣，父父，子子。”公曰：“善哉！信如君不君，臣不臣，父不父，子不子，虽有粟，吾得而食诸？”
译文：齐景公向孔子问为政的道理。孔子回答：“做君主、臣下、父亲、儿子的，各尽各的本分。”景公说：“好啊！倘若各人果真都不尽本分，即便有粮，我还能吃得到吗？”

## 单选：“吾得而食诸”的“吾”指的是谁？ {#q.check.18.4}
考点：skill.l5.6
语境：p.check.18.b

- [ ] 孔子，因为开头有“孔子对曰” {#q.check.18.4.o2}
  理由：中间“公曰”已经更换说话人。
- [x] 齐景公，接着自己的“善哉”说下去 {#q.check.18.4.o1}
- [ ] 臣下，因为前句有“臣不臣” {#q.check.18.4.o3}
  理由：这里的“臣”是景公设想的身份之一。引语并没有换一个臣下来讲。

提示：从末句往回找，引语最近一次换人在哪里？
解析：问话前是“公曰”，从“善哉”到“吾得而食诸”都是齐景公在说。

## 单选：想把齐景公的这次问政记在日历上，原文给了足够的日期吗？ {#q.check.18.5}
考点：skill.l5.4
语境：p.check.18.b

- [ ] “景公”二字就能确定问政的具体日子 {#q.check.18.5.o3}
  理由：称号可缩小历史范围，无法单独给事件定日。
- [ ] “虽有粟”表明一定是某一年的秋分 {#q.check.18.5.o2}
  理由：“虽有粟”是说即使有粮，也不能用来推算问话的日子。
- [x] 有人物与事件，没有明确的年次、月份或干支 {#q.check.18.5.o1}

提示：文章把问答双方交代得很清楚，有没有也交代年次或日名？
解析：这里有问政的人和事，却没有年月干支。查问政的年代，还要另找史料。

## 单选：齐景公问政时答了“臣臣”。这两个字是在谈臣子的本分，还是在授官？ {#q.check.18.6}
考点：skill.l5.5
语境：p.check.18.b

- [x] 孔子谈为臣者应尽本分，没有写某人当场获授官职 {#q.check.18.6.o1}
- [ ] 文中列出两位都名叫“臣”的官员 {#q.check.18.6.o3}
  理由：“君君、父父、子子”显示相同的表达格式。
- [ ] 齐景公在句中任命孔子为新的臣属 {#q.check.18.6.o2}
  理由：“对曰”只是孔子在答问。经文没有写景公拜他为什么官。

提示：与“君君”“父父”并排读，两次出现的字各起什么作用？
解析：“臣臣”是说做臣子的要尽臣子的本分，文中没记任何人当场受职。
