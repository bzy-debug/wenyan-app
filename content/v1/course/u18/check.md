# 检查：在编年记录和问答之间辨身份 {#check.18}

## 原文：古籍引文 {#p.check.18.a}
> 元年春王正月。三月，公及邾仪父盟于蔑。夏五月，郑伯克段于鄢。秋七月，天王使宰咺来归惠公、仲子之赗。
译文：鲁隐公元年春季王历正月。三月，鲁隐公与邾仪父在蔑结盟。夏季五月，郑伯在鄢击败段。秋季七月，周王派宰咺来给惠公、仲子送助丧之物。

## 单选：做纪年卡时，盟于蔑一事能准确登记到哪一级？ {#q.check.18.1}
考点：skill.l5.4
语境：p.check.18.a

- [ ] 鲁隐公元年正月初一 {#q.check.18.1.o2}
  理由：“三月”已经把盟会与开头正月分开。
- [x] 鲁隐公元年三月，日子未载 {#q.check.18.1.o1}
- [ ] 郑伯元年五月，日子未载 {#q.check.18.1.o3}
  理由：此篇以鲁为纪年中心，五月写的是另一件事。

提示：看最近一个月名，检索本条是否有日名。
解析：经文逐月记事；这条只提供元年和三月，没有明确日期。

## 单选：“天王使宰咺来归……之赗”中，哪项是这条记录本身写出的职务关系？ {#q.check.18.2}
考点：skill.l5.5
语境：p.check.18.a

- [ ] 鲁君任命惠公为宰 {#q.check.18.2.o3}
  理由：惠公是赗所涉及的人，不是“使”的受任者。
- [ ] 来送丧礼后，咺才被封为天王 {#q.check.18.2.o2}
  理由：“天王”是派遣者的称号。
- [x] 周王派遣宰咺来送助丧物 {#q.check.18.2.o1}

提示：拆出派遣者、被派者、任务。
解析：“宰咺”是被派遣者的称呼；这条记遣使和丧礼，不是在叙述拜官。

## 单选：“公及邾仪父盟于蔑”没有先写“鲁”。应怎样判断“公”？ {#q.check.18.3}
考点：skill.l5.6
语境：p.check.18.a

- [x] 结合篇题和鲁国编年的叙事立场，指鲁隐公 {#q.check.18.3.o1}
- [ ] 指本条以后的郑伯 {#q.check.18.3.o3}
  理由：郑伯在另一个月份的事件中才出现。
- [ ] 指邾仪父，他与自己结盟 {#q.check.18.3.o2}
  理由：“及”连接的是两方。

提示：留意经文以哪一国君的元年纪年。
解析：“公”是鲁史叙述中对本国君主的称呼，与邾仪父是盟会双方。

## 原文：古籍引文 {#p.check.18.b}
> 齐景公问政于孔子。孔子对曰：“君君，臣臣，父父，子子。”公曰：“善哉！信如君不君，臣不臣，父不父，子不子，虽有粟，吾得而食诸？”
译文：齐景公向孔子问政。孔子说，人主、臣下、父亲、儿子各要尽各的职责。景公说，确实如此，如果各不尽职，即使有粮，我还能吃到吗？

## 单选：“吾得而食诸”的“吾”该记作谁？ {#q.check.18.4}
考点：skill.l5.6
语境：p.check.18.b

- [ ] 孔子，因为开头有“孔子对曰” {#q.check.18.4.o2}
  理由：中间“公曰”已经更换说话人。
- [x] 齐景公，接着自己的“善哉”说下去 {#q.check.18.4.o1}
- [ ] 臣下，因为前句有“臣不臣” {#q.check.18.4.o3}
  理由：这只是条件句里的一个角色。

提示：从末句逆读，找最近的发言标识。
解析：这一整段是“公曰”的引语，故“吾”指齐景公。

## 单选：要给齐景公这次问政换算公历年月，这段提供的时间资料如何？ {#q.check.18.5}
考点：skill.l5.4
语境：p.check.18.b

- [ ] “景公”二字就能确定问政的具体日子 {#q.check.18.5.o3}
  理由：称号可缩小历史范围，无法单独给事件定日。
- [ ] “虽有粟”表明一定是某一年的秋分 {#q.check.18.5.o2}
  理由：有粮是条件设想，不是日期记录。
- [x] 有人物与事件，没有明确的年次、月份或干支 {#q.check.18.5.o1}

提示：寻找明确的时间标识，别以话题代替纪日。
解析：可从外部材料研究年代，本段直接给出的是问答关系。

## 单选：“臣臣”在此次问政中能证明哪种关系？ {#q.check.18.6}
考点：skill.l5.5
语境：p.check.18.b

- [x] 孔子谈为臣者应尽本分，没有写某人当场获授官职 {#q.check.18.6.o1}
- [ ] 文中列出两位都名叫“臣”的官员 {#q.check.18.6.o3}
  理由：“君君、父父、子子”显示相同的表达格式。
- [ ] 齐景公在句中任命孔子为新的臣属 {#q.check.18.6.o2}
  理由：“对曰”说明发言，没有“拜”“命”一类任命叙事。

提示：分开职位名称和授予职位的动作。
解析：第一个“臣”指身份，后一个说明应合乎此身份的责任。它不是一次人事任命。
