# 课文：没加标点，怎样认出一句话到哪里 {#l5.6}
简介：试在两小段原文上停一停，先听相称的词组，再核对句意。

## 正文

古书的字句和今人添的句读要分开看。这里练习的两段保留底本文字，暂去标点。先自己读，再看给出的几种停法。只判断会改变句意的大边界；在相同意思之下，逗号、分号等整理习惯可以有别。

读到连续的“见……如……”不妨等到两边都说完再停；读到“则”，要看是前面条件没有说完，还是后面的结果还缺动作。

## 知识点：凭相称句式和话意判断句界 {#s.l5.clauses}
义项：凭相称句式和话意判断句界
领域：句法
要诀：保全搭配，再试两边能否各自说通
讲解：更换语气、动作主语或成对的句式都可能提示停顿。先寻找不宜从中切开的词组，再看两边是否各自成意。
例句：p.l5.6.example
复习题：q.l5.6.1 q.l5.6.3 q.l5.6.5 q.l5.6.7

## 原文：教学例句 {#p.l5.6.example}
> 见雨则归见晴则出。
译文：见雨则归，见晴则出。两边都把条件和相应的动作连在一起。

## 原文：古籍引文 {#p.l5.6.a}
> 见善如不及见不善如探汤吾见其人矣吾闻其语矣
译文：看见善行像怕赶不上，看见不善像把手伸进热水。这样的人我见过，这样的话我也听过。
词注：及：赶上。
  探汤：把手伸入热水。“汤”在这里指热水。

## 单选：要读出对待善与不善的两种态度，先在哪里停？ {#q.l5.6.1}
考点：s.l5.clauses
语境：p.l5.6.a

- [x] 见善如不及／见不善如探汤 {#q.l5.6.1.o1}
- [ ] 见善如不及见／不善如探汤 {#q.l5.6.1.o3}
  理由：第二个“见”带“不善”，拆开便打乱成对的说法。
- [ ] 见善如不／及见不善如探汤 {#q.l5.6.1.o2}
  理由：“不及”说赶不上，不能把“不”丢给前一半。

提示：两半各以哪个动作开始？
解析：两边都是“见……如……”，比较的对象分别是善与不善。

## 单选：“探汤”怎样理解才不该从中强断？ {#q.l5.6.2}
考点：s.l5.clauses
语境：p.l5.6.a

- [ ] 探听是谁煮汤，说话人开始问菜肴 {#q.l5.6.2.o2}
  理由：这里用身体怕烫比喻避恶。
- [x] 伸手碰热水，是一个比方 {#q.l5.6.2.o1}
- [ ] “探”结束前句，汤是下一位发言人 {#q.l5.6.2.o3}
  理由：没有引出名为“汤”的人，后面说“吾”。

提示：先和前面的“不及”一同放回“如”后。
解析：“探汤”连读，接在“如”后成比喻。

## 单选：“吾见其人矣吾闻其语矣”怎样读？ {#q.l5.6.3}
考点：s.l5.clauses
语境：p.l5.6.a

- [ ] 吾见其人矣吾／闻其语矣 {#q.l5.6.3.o3}
  理由：第二个“吾”要领“闻”，不能拖到前句。
- [ ] 吾见／其人矣吾闻其语矣 {#q.l5.6.3.o2}
  理由：这把“见”和对象隔开，还使两处“吾”失去对称。
- [x] 吾见其人矣／吾闻其语矣 {#q.l5.6.3.o1}

提示：留意两个“吾”和两个“矣”。
解析：两边各有主语、动词、对象和收尾的“矣”。

## 单选：哪一条释义最能检验刚才两处停顿？ {#q.l5.6.4}
考点：s.l5.clauses
语境：p.l5.6.a

- [x] 先说两种行止，再说我见过这样的人、听过这样的话 {#q.l5.6.4.o1}
- [ ] 先否定行善，再否定自己听过这些话 {#q.l5.6.4.o3}
  理由：“不”在前两种态度的表述里，未否定后面的见闻。
- [ ] 先说看见两个人互相交谈，再说他们去烧水 {#q.l5.6.4.o2}
  理由：原文把“人”和“语”分作见、闻的对象。

提示：停好后，试分别说每半句是谁在做什么。
解析：能交代“见”“闻”各带什么，才算断句有了意思上的根据。

## 原文：古籍引文 {#p.l5.6.b}
> 不愤不启不悱不发举一隅不以三隅反则不复也
译文：学生没有想弄明白却想不通，我不去开导；没有想说却说不出，我不去启发。指出一个角而不能由此推回另外三个角，我就不再反复教。
词注：悱：读 fěi，想把意思说出来却还表达不好。
  隅：读 yú，角落。此处用四个角比学习时举一反三。

## 单选：前八个字如何分，才能读出两种施教时机？ {#q.l5.6.5}
考点：s.l5.clauses
语境：p.l5.6.b

- [ ] 不愤不／启不悱不发 {#q.l5.6.5.o2}
  理由：“启”是对“愤”这种处境的回应。
- [x] 不愤不启／不悱不发 {#q.l5.6.5.o1}
- [ ] 不愤不启不悱／不发 {#q.l5.6.5.o3}
  理由：这把第二组中成对的条件与回应拆散了。

提示：看“愤、悱”和“启、发”怎样成双。
解析：每半先说学生的状态，再说教师是否开导。

## 单选：在“举一隅不以三隅反则不复也”里，“则”领什么？ {#q.l5.6.6}
考点：s.l5.clauses
语境：p.l5.6.b

- [ ] 老师举三个角后自己返回 {#q.l5.6.6.o3}
  理由：“一隅”是已经举出的，三隅留给学生。
- [ ] “反则”是一条要反对的法则 {#q.l5.6.6.o2}
  理由：“则”在此连接条件和后果。
- [x] 老师就不再重复指教 {#q.l5.6.6.o1}

提示：“则”之前说学生能不能推，之后说老师怎么办。
解析：“不以三隅反”是条件，“则不复也”才是处理办法。

## 找原文证据：哪个字组必须保留在一起，才知道老师起初指出多少？ {#q.l5.6.7}
考点：s.l5.clauses
语境：p.l5.6.b

- [x] 举一隅 {#q.l5.6.7.o1}
- [ ] 三隅反 {#q.l5.6.7.o3}
  理由：“三隅”写待学生推知的部分。
- [ ] 不悱 {#q.l5.6.7.o2}
  理由：这写学生尚未处于想说难言的状态。

提示：找“举”紧接的数量和对象。
解析：“举一隅”合起来说明被指出的是一个角。

## 单选：“复”查到重复、回复两义。照你的断句，该怎样读结尾？ {#q.l5.6.8}
考点：s.l5.clauses
语境：p.l5.6.b

- [ ] 学生当场复述了四个角 {#q.l5.6.8.o2}
  理由：有“不”，也没说学生复述成功。
- [x] 老师不再重复指教 {#q.l5.6.8.o1}
- [ ] 一个角自己回到原处 {#q.l5.6.8.o3}
  理由：“不复”承接的是师生授受，不是物体位移。

提示：看“则”后面说的是教学怎样继续。
解析：一隅不能反三，老师便不再重复；这样前提、结果能接上。
