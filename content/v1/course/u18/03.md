# 课文：“寡人”和“臣”各是谁 {#l5.6}
简介：古人开口自称“寡人”或“臣”，先认说话的人，再看这个称呼说明了什么。

## 正文

### 把引号里的“我”换回人名

“寡人”是谁，往前看开口的是哪位国君；读到“对曰”，通常换人答话了。遇到接连几个没写姓名的“曰”，试给一问一答各补一个名字，看看还说得通吗。

“臣”有时是面对尊者的谦称。要知道那人有没有受官、在席上受什么礼遇，还得看叙事。比如谁特意留座，谁坐了上去，最后是谁执辔驾车？“辔”就是控马的缰绳。

查字时可直接翻到这里。[轡](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E8%BD%A1)

## 知识点：自称与对称 {#skill.l5.6}
义项：在对话中辨认自称所指的人
领域：文化背景
要诀：从“曰”向前找谁开口
讲解：君主可以自称“寡人”，向尊者说话的人可以自称“臣”。谦称和宾主礼节能看出说话的姿态，有无正式官职还要另找记载。
例句：p.l5.6.example
复习题：q.l5.6.1 q.l5.6.3 q.l5.6.5 q.l5.6.6

## 原文：教学例句 {#p.l5.6.example}
> 君问渔父：“子知津乎？”对曰：“臣世居此，愿导君。”
译文：国君问渔人：“你认得渡口吗？”渔人答：“我家世代住在这里，愿给您带路。”渔人自称“臣”是说话时的谦称，文中没说他受过什么官。

## 原文：古籍引文 {#p.l5.6.a}
> 梁惠王曰：“寡人愿安承教。”孟子对曰：“杀人以梃与刃，有以异乎？”曰：“无以异也。”“以刃与政，有以异乎？”曰：“无以异也。”
译文：梁惠王说：“我愿安心听您教诲。”孟子问：“用木杖打死人和用刀杀人，有分别吗？”王答：“没分别。”“用刀杀人和用政事害人，有分别吗？”王仍答：“没分别。”

## 单选：“寡人愿安承教”是谁向谁说的？ {#q.l5.6.1}
考点：skill.l5.6
语境：p.l5.6.a

- [x] 梁惠王愿听孟子指教 {#q.l5.6.1.o1}
- [ ] 两个未具名的听众互相请教 {#q.l5.6.1.o3}
  理由：头一句点名梁惠王，下一句点名孟子，不用另添两位来客。
- [ ] 孟子愿听梁惠王指教 {#q.l5.6.1.o2}
  理由：“寡人”在梁惠王的引语中。

解析：“梁惠王曰”领起这句谦辞，接着孟子“对曰”，是梁惠王愿听孟子教诲。

## 找原文证据：哪几个字明白写出这回换孟子开口？ {#q.l5.6.2}

## 单选：两处“无以异也”都没写人名。这两次回答是谁的话？ {#q.l5.6.3}
考点：skill.l5.6
语境：p.l5.6.a

- [ ] 两位持杖者各回答一次 {#q.l5.6.3.o3}
  理由：梃是问句里举出的器物，没有引入两位新人物。
- [ ] 孟子，因为最后一次写出的姓名是孟子 {#q.l5.6.3.o2}
  理由：把疑问句给孟子，再读答句：每次都是王答“无以异也”。
- [x] 梁惠王，在回应孟子的两个问句 {#q.l5.6.3.o1}

提示：试把问句交给孟子，再看对面的答话该由谁说。
解析：孟子先问梃与刃，再问刃与政。两次答“没有分别”的都是梁惠王。

## 单选：从“梃与刃”问到“刃与政”，孟子把话转到了什么事上？ {#q.l5.6.4}
考点：skill.l5.6
语境：p.l5.6.a

- [x] 用政者也需面对政事害人的后果 {#q.l5.6.4.o1}
- [ ] 王的谦称证明他已经做到了仁政 {#q.l5.6.4.o3}
  理由：王愿意听孟子说，是他说话时的态度。治理是否已经做到，文中还没说。
- [ ] 王应在两种器物中挑一件 {#q.l5.6.4.o2}
  理由：第二次不再只比两件器械，“以刃与政”已经问到执政。

提示：第一问的两样东西都是器械，第二问多了什么？
解析：孟子先让王承认两种器械害人没有分别，再追问用政治害人，由此把后果推到用政者面前。

## 原文：古籍引文 {#p.l5.6.b}
> 公子从车骑，虚左，自迎夷门侯生。侯生摄敝衣冠，直上载公子上坐，不让，欲以观公子。公子执辔愈恭。侯生又谓公子曰：“臣有客在市屠中，愿枉车骑过之。”公子引车入市。
译文：公子带着车马，空出左边的尊位，亲自去迎侯生。侯生整一整破旧衣帽，径直上车坐了尊位，也不推让，想看看公子的反应。公子握着缰绳，越发恭敬。侯生又说：“我有个朋友在市上的屠户中，想请您屈驾去看看他。”公子便驾车入市。侯生说“我”时，自称为“臣”。

## 单选：“臣有客在市屠中”，这个自称“臣”的人是谁？ {#q.l5.6.5}
考点：skill.l5.6
语境：p.l5.6.b

- [ ] 公子，因为车骑归他所有 {#q.l5.6.5.o2}
  理由：车是公子的，向他请求绕路的却是侯生。
- [x] 侯生，正在向公子提出请求 {#q.l5.6.5.o1}
- [ ] 市里的朋友，因为紧接着写“客” {#q.l5.6.5.o3}
  理由：“客”是“臣”要探访的另一个人。

提示：是谁“谓公子曰”？
解析：对公子开口的是侯生。他想探望的朋友是“客”，开口自称的是“臣”。

## 单选：侯生自称“臣”，这段究竟写出了他和公子怎样的关系？ {#q.l5.6.6}
考点：skill.l5.6
语境：p.l5.6.b

- [ ] 侯生自称臣，所以他没坐尊位 {#q.l5.6.6.o3}
  理由：前文已经明写他“上坐，不让”。
- [ ] 侯生被任命为御者，因为他自称“臣” {#q.l5.6.6.o2}
  理由：握缰驾车的恰是公子。
- [x] 侯生说话用谦称“臣”，本文未交代他获公子封官 {#q.l5.6.6.o1}

提示：称呼是一条线索；要说公子任命了他，原文还该有怎样的话？
解析：侯生对公子说话用谦称。文中详写公子如何迎宾，却没有说公子授给他什么官职。

## 找原文证据：侯生径直坐上尊位之后，哪几个字写公子怎样待他？ {#q.l5.6.7}
考点：skill.l5.6

- [x] 执辔愈恭 {#q.l5.6.7.o1}
- [ ] 直上载公子上坐 {#q.l5.6.7.o3}
  理由：这是侯生已经登座的动作。

解析：“执辔愈恭”写公子握着缰绳，态度比先前更恭敬。
