# 课文：翻到“音义”：两个反切字怎样用 {#l5.5}
简介：一条音注可以管到下章，也可能保留另一种读法。

## 正文

经注本的“音义”往往紧挨着注文。遇到“好呼报反”，要圈的是“好”。“呼”“报”配合注音，不能当三个意思连译。遇到“下章……同”，再看看古人特意把读法延伸到哪个词。

“又如字”很值得留意。同一部书可以并存两种读法，抄作“只许如此读”便把底本提供的信息丢掉了。

## 知识点：读懂反切、直音和音注的适用范围 {#s.l5.soundnote}
义项：读懂反切、直音和音注的适用范围
领域：阅读技能
要诀：先圈目标字，再看注音方式和附记
讲解：“甲乙反”取甲的声母、乙的韵和声调。古今语音会变，不宜硬拿普通话拼出古音。“音某”以同音字提示，“如字”则照通常读法。
例句：p.l5.5.example
复习题：q.l5.5.1 q.l5.5.3 q.l5.5.5 q.l5.5.7

## 原文：教学例句 {#p.l5.5.example}
> 邑，音悒。
译文：这则教学音注只说“邑”与“悒”音同，没有说城邑是一种忧愁。

## 原文：古籍引文 {#p.l5.5.a}
> 夏，户雅反。好，呼报反，下章好学同。尽，津刃反，下注同。
译文：“夏”用“户雅”反切。“好”用“呼报”反切，下章“好学”的“好”同读。“尽”用“津刃”反切，下面注文中的这个字也同读。
词注：反：反切注音的标记写在两个切音用字之后。
  下章：后面相应的一章。

## 单选：“呼报反”是给哪个字注音？ {#q.l5.5.1}
考点：s.l5.soundnote
语境：p.l5.5.a

- [x] 好 {#q.l5.5.1.o1}
- [ ] 学 {#q.l5.5.1.o3}
  理由：“好学”提示下章用例，这里没有为“学”单独反切。
- [ ] 报 {#q.l5.5.1.o2}
  理由：“报”是配合切音的第二个字。

提示：看反切前单列的字。
解析：“好”是目标字；读者借“呼”“报”两字所代表的音来读它。

## 单选：在“呼报反”中，从第二个字取什么？ {#q.l5.5.2}
考点：s.l5.soundnote
语境：p.l5.5.a

- [ ] 整个现代普通话音节 {#q.l5.5.2.o2}
  理由：上下两字分工，且古今语音并非全同。
- [x] 韵和声调 {#q.l5.5.2.o1}
- [ ] “告诉”的意思 {#q.l5.5.2.o3}
  理由：反切在注音，不用“报”的词义。

提示：上字供声母，下字还要供什么？
解析：“报”是反切下字，供韵和调；不能据此说“好”古音就是今天的 bào。

## 找原文证据：哪几个字明确把“好”的音注用到别的地方？ {#q.l5.5.3}
考点：s.l5.soundnote
语境：p.l5.5.a

- [ ] 津刃反 {#q.l5.5.3.o3}
  理由：这是“尽”的反切。
- [ ] 户雅反 {#q.l5.5.3.o2}
  理由：这三个字给“夏”注音。
- [x] 下章好学同 {#q.l5.5.3.o1}

提示：找提到另一章的短语。
解析：“下章好学同”连词、位置一并指出，不能随便套给所有“好”字。

## 单选：抄“尽，津刃反，下注同”时把最后三字删掉，漏了什么？ {#q.l5.5.4}
考点：s.l5.soundnote
语境：p.l5.5.a

- [x] 下文注文中的“尽”也按此读 {#q.l5.5.4.o1}
- [ ] 下注的人叫津刃 {#q.l5.5.4.o3}
  理由：“津刃”是反切用字。
- [ ] 整章所有字都要用这一反切 {#q.l5.5.4.o2}
  理由：“同”只对相应被注字说。

提示：“下”后写的是“章”还是“注”？
解析：这次音注照顾的是下面的注，不同于上一条指向下章。

## 原文：古籍引文 {#p.l5.5.b}
> 近，附近之近，下及注同，又如字。覆，芳服反，下同。远，于万反。
译文：“近”照“附近”的“近”读，下面正文和注的相应字也如此；又可照常读。“覆”用“芳服”反切，下面相同。“远”用“于万”反切。
词注：如字：依这个字通常的读法来读。前加“又”，表明还可如此读。
  下同：下文相应的用字也按此读。

## 单选：“附近之近”是怎样给读者帮忙的？ {#q.l5.5.5}
考点：s.l5.soundnote
语境：p.l5.5.b

- [ ] 给“近”下一个严密的地理定义 {#q.l5.5.5.o2}
  理由：此处位在音义，重点是怎样读。
- [x] 举读者熟悉的词，把目标字的读法指出来 {#q.l5.5.5.o1}
- [ ] 教人把“附”“近”作反切上下字 {#q.l5.5.5.o3}

## 单选：如需给“远”抄一条反切，应摘哪一组？ {#q.l5.5.7}

## 单选：有人见“近”有“又如字”，便在“远”的音注也加上它，问题在哪里？ {#q.l5.5.8}
考点：s.l5.soundnote
语境：p.l5.5.b

- [ ] “如字”意思是原字抄错 {#q.l5.5.8.o2}
  理由：“如字”说读法，不是校正字形。
- [x] 该附记写在“近”条内，不能移给“远” {#q.l5.5.8.o1}
- [ ] 一条音义不能出现两个反切 {#q.l5.5.8.o3}
  理由：不同目标字完全可以各有反切。

提示：逐条划开“近、覆、远”。
解析：音注的适用对象和范围都要按原书记录。
