# 课文：蔺相如拜上卿，谁的位次在前 {#l5.5}
简介：赵王两次任用蔺相如。先读新授的官名，再听廉颇怎么说自己的位次。

## 正文

### “拜相如”是向相如行礼吗？

读到“拜相如”，且多读三个字：“为上大夫”。一接官名，就看出是谁在任命谁。再遇上只写“拜为上卿”的句子，回头找刚说到谁立了功，受任的人便能补出来。

两段文字分别记完璧归赵后和渑池会后的任命。大夫、卿的位次，要就当时当地来读。比如“右”在哪一边更尊贵？这一回，廉颇自己就换了个说法，留心他怎样讲“上”和“下”。

查字时可直接翻到这里。[拜](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%8B%9C)

## 知识点：拜为某官 {#skill.l5.5}
义项：由授官的句子读出人的职位和高下
领域：文化背景
要诀：问“谁任命谁做什么官”
讲解：“拜甲为乙”，可以是任命甲担任乙职。省去人名时，可从前一句的功劳和后面同僚的反应找回受任的人。
例句：p.l5.5.example
复习题：q.l5.5.1 q.l5.5.2 q.l5.5.5 q.l5.5.6

## 原文：教学例句 {#p.l5.5.example}
> 君召邑吏，拜之为令。吏受命而出。
译文：国君召来地方上的一名小吏，任命他为县令。小吏领命出去了。

## 原文：古籍引文 {#p.l5.5.a}
> 相如既归，赵王以为贤大夫使不辱于诸侯，拜相如为上大夫。秦亦不以城予赵，赵亦终不予秦璧。
译文：蔺相如回国后，赵王认为他是出使诸侯而没有受辱的贤才，任命他为上大夫。秦国没有把城交给赵国，赵国最终也没有把璧交给秦国。

## 单选：读“拜相如为上大夫”，是谁任命谁，任什么官？ {#q.l5.5.1}
考点：skill.l5.5
语境：p.l5.5.a

- [x] 赵王—相如—上大夫 {#q.l5.5.1.o1}
- [ ] 秦王—相如—诸侯 {#q.l5.5.1.o3}
  理由：“诸侯”还在说相如出使一事。新得的官名要到“拜”之后找。
- [ ] 相如—赵王—上大夫 {#q.l5.5.1.o2}
  理由：“拜相如”的宾语是受任者，相如没有任命赵王。

提示：“拜”之后是谁？“为”之后又是什么？
解析：赵王任命蔺相如，受任的新职是上大夫。

## 找原文证据：写出相如受任后是什么官的，是原文哪几个字？ {#q.l5.5.2}
考点：skill.l5.5
语境：p.l5.5.a

- [ ] 不辱于诸侯 {#q.l5.5.2.o2}
  理由：这是出使的表现，也是受到任用的理由。
- [x] 为上大夫 {#q.l5.5.2.o1}
- [ ] 不以城予赵 {#q.l5.5.2.o3}
  理由：说不给城的是秦国。相如回国得了什么官，要往前找。

提示：找“拜相如”后面接上的话。
解析：“为上大夫”点明官职。前文说出使不辱，是解释他为何受任。

## 单选：赵王为什么在相如归来后任用他？“使不辱于诸侯”说了哪一点？ {#q.l5.5.3}
考点：skill.l5.5
语境：p.l5.5.a

- [ ] 相如只有得到秦城后才能任官 {#q.l5.5.3.o3}
  理由：末句说秦没有交城，任命仍已发生。
- [ ] 诸侯已经联合授予相如官职 {#q.l5.5.3.o2}
  理由：从“赵王以为”往下读，接着下令授官的就是赵王。
- [x] 赵王以相如出使表现为任用依据 {#q.l5.5.3.o1}

提示：读读“赵王以为”后面的话，这是赵王怎样看相如？
解析：赵王看重相如出使时维护国体；这次提拔并不以秦国交出城池为条件。

## 单选：人事和城璧交换，分别有了什么结果？ {#q.l5.5.4}
考点：skill.l5.5
语境：p.l5.5.a

- [x] 相如升任上大夫，璧没有给秦 {#q.l5.5.4.o1}
- [ ] 秦因授官而立即献城 {#q.l5.5.4.o3}
  理由：“秦亦不以城予赵”已说明没有交城。
- [ ] 上大夫等于后来各朝的宰相 {#q.l5.5.4.o2}
  理由：这里只给战国赵国的职位，不能跨时代等同。

提示：先读授职的一句，再读两处“不予”。
解析：相如得授上大夫。秦没给城，赵也没有把璧交给秦。

## 原文：古籍引文 {#p.l5.5.b}
> 既罢归国，以相如功大，拜为上卿，位在廉颇之右。廉颇曰：“我为赵将，有攻城野战之大功，而蔺相如徒以口舌为劳，而位居我上，且相如素贱人，吾羞，不忍为之下。”
译文：会后回国，赵王因蔺相如功大，任他为上卿，位在廉颇之上。廉颇说：“我做赵国的将领，攻城野战立过大功；蔺相如只凭几句话立功，职位却比我高。况且他从前地位卑微，我觉得羞耻，不甘心屈居他之下。”

- [ ] 廉颇，下句一开头就是廉颇 {#q.l5.5.5.o2}
  理由：“廉颇曰”是同僚听说相如受任后的话，还不是先前受任的人。
- [x] 相如，因前文刚说明他的功劳 {#q.l5.5.5.o1}
- [ ] 赵王，因为他是授官人 {#q.l5.5.5.o3}
  理由：赵王是决定给官的人。现在要补的是谁得了这个官。

提示：任命前，先交代了谁的功劳？
解析：既说“以相如功大”，受任的便是相如。下一句才转到廉颇。

## 找原文证据：相如在廉颇“之右”。廉颇自己用哪几个字说出了两人的高下？ {#q.l5.5.6}
考点：skill.l5.5
语境：p.l5.5.b

- [ ] 相如素贱人 {#q.l5.5.6.o3}
  理由：这是廉颇谈相如过去的社会身份。
- [ ] 我为赵将 {#q.l5.5.6.o2}
  理由：这是廉颇的职务，不能直接比较两人等级。
- [x] 位居我上 {#q.l5.5.6.o1}

提示：在廉颇的话里找他最在意的位次。
解析：廉颇说相如“位居我上”，可见本段的“右”指居上。

## 单选：说相如“徒以口舌为劳”的是谁？这话该算在谁的看法里？ {#q.l5.5.7}
考点：skill.l5.5
语境：p.l5.5.b

- [x] 列为廉颇对相如的评价，和授官事实区分 {#q.l5.5.7.o1}
- [ ] 据此改写“功大”为“无功” {#q.l5.5.7.o3}
  理由：廉颇心里不服，史家却已明写“以相如功大”。不能拿一句气话抹掉授官理由。
- [ ] 当作赵王任命书的原文 {#q.l5.5.7.o2}
  理由：这句话在“廉颇曰”之后。

提示：退回引语开头，看看谁在开口。
解析：“廉颇曰”以后是他自己的委屈；叙述者此前交代拜相如为上卿，是因为他“功大”。

## 单选：凭这段能把“右”解释到哪一步？ {#q.l5.5.8}
考点：skill.l5.5
语境：p.l5.5.b

- [ ] 所有朝代和仪式一概尊右 {#q.l5.5.8.o2}
  理由：赵国这一回“居右”的意思说清了。换到另一朝的朝仪，还得另查。
- [x] 本次任命中，“右”据下文可释为居上 {#q.l5.5.8.o1}
- [ ] 写“右”仅表示廉颇向右走一步 {#q.l5.5.8.o3}
  理由：“位”“居我上”“为之下”都在比较地位。

提示：这里除了“右”，还明说了“上”“下”；其他朝代也在这段里吗？
解析：本次任命后相如居廉颇之上，有本人说的话作证。其他朝代和场合的尊位，得查各自的制度。
