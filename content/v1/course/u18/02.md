# 课文：列传里的授官和位次 {#l5.5}
简介：用“拜……为……”认出受任者，再从当事人的话复核相对地位。

## 正文

### “拜”后若跟一个职位

读史传可在页边记一行“谁任命｜任命谁｜担任何职”。主语有时是国君，有时承前省略；判断前后是否授受一致，比见“拜”就译“叩头”更有用。

大夫、卿在各国各时的官制中不尽相同。听到“居右”“居上”，先问同一篇的当事人怎样解释这次位次变化，再决定是否要另查制度史。下面两段分别记完璧归赵后和渑池会后的任命。

查阅《重编国语辞典修订本》的字头。[拜](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%8B%9C)

## 知识点：拜为某官 {#skill.l5.5}
义项：从授任句和位次判断人物的官职变化
领域：文化背景
要诀：找授者、受者、官名
讲解：“拜甲为乙”可表示任命甲担任乙职。职位先后及同僚的反应也能解释省略的任命和相对班次。
例句：p.l5.5.example
复习题：q.l5.5.1 q.l5.5.2 q.l5.5.5 q.l5.5.6

## 原文：教学例句 {#p.l5.5.example}
> 君召邑吏，拜之为令。吏受命而出。
译文：国君召见地方小吏，任命他为县令，小吏领命出去。由“为令”可知这次“拜”是授职。

## 原文：古籍引文 {#p.l5.5.a}
> 相如既归，赵王以为贤大夫使不辱于诸侯，拜相如为上大夫。秦亦不以城予赵，赵亦终不予秦璧。
译文：蔺相如回国后，赵王认为他是出使诸侯而没有受辱的贤才，任命他为上大夫。秦国没有把城交给赵国，赵国最终也没有把璧交给秦国。

## 单选：若以“授者—受者—官职”登记，应当怎样写？ {#q.l5.5.1}
考点：skill.l5.5
语境：p.l5.5.a

- [x] 赵王—相如—上大夫 {#q.l5.5.1.o1}
- [ ] 秦王—相如—诸侯 {#q.l5.5.1.o3}
  理由：“诸侯”是前面出使活动所涉及的对象。
- [ ] 相如—赵王—上大夫 {#q.l5.5.1.o2}
  理由：“拜相如”的宾语是受任者，相如没有任命赵王。

提示：从“拜……为……”前后找人名和官名。
解析：赵王是任命者，“相如”接在“拜”后，“上大夫”接在“为”后。

## 找原文证据：哪一短语直接记录授官的结果？ {#q.l5.5.2}
考点：skill.l5.5
语境：p.l5.5.a

- [ ] 不辱于诸侯 {#q.l5.5.2.o2}
  理由：这是出使的表现，也是受到任用的理由。
- [x] 为上大夫 {#q.l5.5.2.o1}
- [ ] 不以城予赵 {#q.l5.5.2.o3}
  理由：这是事情的外交结果，未写官职。

提示：找“拜”之后表示新身份的部分。
解析：“为上大夫”指出相如受拜后担任的职位。

## 单选：“使不辱于诸侯”与授官有什么关系？ {#q.l5.5.3}
考点：skill.l5.5
语境：p.l5.5.a

- [ ] 相如只有得到秦城后才能任官 {#q.l5.5.3.o3}
  理由：末句说秦没有交城，任命仍已发生。
- [ ] 诸侯已经联合授予相如官职 {#q.l5.5.3.o2}
  理由：授官动作由赵王发出。
- [x] 赵王以相如出使表现为任用依据 {#q.l5.5.3.o1}

提示：读“以为”所领的判断。
解析：赵王看重的是使者维护国体的表现，并非实际取得多少城。

## 单选：只从这段能确认哪一项结果？ {#q.l5.5.4}
考点：skill.l5.5
语境：p.l5.5.a

- [x] 相如升任上大夫，璧没有给秦 {#q.l5.5.4.o1}
- [ ] 秦因授官而立即献城 {#q.l5.5.4.o3}
  理由：“秦亦不以城予赵”已说明没有交城。
- [ ] 上大夫等于后来各朝的宰相 {#q.l5.5.4.o2}
  理由：这里只给战国赵国的职位，不能跨时代等同。

提示：把人事任命与秦赵实物交割分两行记。
解析：任命明确发生，双方交换并未完成。两类结果不要混成因果。

## 原文：古籍引文 {#p.l5.5.b}
> 既罢归国，以相如功大，拜为上卿，位在廉颇之右。廉颇曰：“我为赵将，有攻城野战之大功，而蔺相如徒以口舌为劳，而位居我上，且相如素贱人，吾羞，不忍为之下。”
译文：会后回国，因蔺相如功大，任命他为上卿，位次高于廉颇。廉颇说，自己为赵将立有战功，而相如仅凭言辞立功却居自己之上，何况相如出身卑微，自己羞于居其下。

## 单选：第二次“拜为上卿”省去受任者姓名，宜补谁？ {#q.l5.5.5}
考点：skill.l5.5
语境：p.l5.5.b

- [ ] 廉颇，下句一开头就是廉颇 {#q.l5.5.5.o2}
  理由：“廉颇曰”已转入同僚的反应。
- [x] 相如，因前文刚说明他的功劳 {#q.l5.5.5.o1}
- [ ] 赵王，因为他是授官人 {#q.l5.5.5.o3}
  理由：国君授官与臣子受任是不同角色。

提示：看看“以……功大”承接谁。
解析：“以相如功大”交代授职对象得任的原因，故省去的受者为相如。

## 找原文证据：廉颇的哪句话帮读者复核本段“右”的地位含义？ {#q.l5.5.6}
考点：skill.l5.5
语境：p.l5.5.b

- [ ] 相如素贱人 {#q.l5.5.6.o3}
  理由：这是廉颇谈相如过去的社会身份。
- [ ] 我为赵将 {#q.l5.5.6.o2}
  理由：这是廉颇的职务，不能直接比较两人等级。
- [x] 位居我上 {#q.l5.5.6.o1}

提示：找说话人自己表述相对位置的短语。
解析：“位居我上”与叙述者“位在廉颇之右”相互印证。

## 单选：如何处理“徒以口舌为劳”这句材料？ {#q.l5.5.7}
考点：skill.l5.5
语境：p.l5.5.b

- [x] 列为廉颇对相如的评价，和授官事实区分 {#q.l5.5.7.o1}
- [ ] 据此改写“功大”为“无功” {#q.l5.5.7.o3}
  理由：廉颇的轻视不能替代叙述中明写的授任理由。
- [ ] 当作赵王任命书的原文 {#q.l5.5.7.o2}
  理由：这句话在“廉颇曰”之后。

提示：先标明引语边界与发言者。
解析：一段内同时有任命事实和带情绪的个人评说。词义应结合话语层次解释。

## 单选：要把“右”释作尊位，哪种范围最稳妥？ {#q.l5.5.8}
考点：skill.l5.5
语境：p.l5.5.b

- [ ] 所有朝代和仪式一概尊右 {#q.l5.5.8.o2}
  理由：单篇记载无法证明跨制度的普遍规则。
- [x] 本次任命中，“右”据下文可释为居上 {#q.l5.5.8.o1}
- [ ] 写“右”仅表示廉颇向右走一步 {#q.l5.5.8.o3}
  理由：“位”“居我上”“为之下”都在比较地位。

提示：区分本段证据与跨朝代概括。
解析：廉颇的话坐实本处位次，推广到别的制度需另查文献。
