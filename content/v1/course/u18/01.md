# 课文：古注里“谓”和“谓之”的方向 {#l5.4}
简介：读邢昺的疏，看看哪边是要讲的词，哪边是解释。

## 正文

古书的正文叫经文，解释经文的文字常称为注；再讲经、注的文字可以叫疏。它们刊在一页，声音却不同。《论语》写“慎终”，疏接着问这里的“终”究竟指什么。另一处经文列“温良恭俭让”，疏把各字展开，又都收在“谓之某”上。

可以拿一张纸对折。左边抄正文里的单字，右边抄古注解释的情形。若“谓”“谓之”两种写法最后都能回填这两栏，就读顺了。

## 知识点：从“谓”“谓之”认出被释的词 {#s.l5.glossdirection}
义项：从“谓”“谓之”认出被释的词
领域：阅读技能
要诀：把古注改写成“某词，这里指……”
讲解：“甲谓乙”常以乙说明甲在这里指什么；“甲谓之乙”则说甲这种情形被叫作乙。读清两头，才能把解释写回正文。
例句：p.l5.4.example
复习题：q.l5.4.1 q.l5.4.3 q.l5.4.5 q.l5.4.7

## 原文：教学例句 {#p.l5.4.example}
> 谨其言谓之慎。
译文：说话小心，叫作“慎”。要解释的是“慎”，前面四字说什么样才算慎。

## 原文：古籍引文 {#p.l5.4.a}
> 慎终者，终谓父母之丧也。以死者人之终，故谓之终。
译文：讲“慎终”，“终”在这里指父母的丧事。死是一个人生命的终结，所以称为“终”。
词注：谓：这里说一个字在经文中具体指什么。
  丧：这里读 sāng，父母去世后的丧事。

## 单选：“终谓父母之丧也”应写进笔记的哪一栏？ {#q.l5.4.1}
考点：s.l5.glossdirection
语境：p.l5.4.a

- [x] 终——在这句中指父母的丧事 {#q.l5.4.1.o1}
- [ ] 丧——指父母活着时的教诲 {#q.l5.4.1.o3}
  理由：原句明写“死者人之终”。
- [ ] 父母——在古书中指一切终结 {#q.l5.4.1.o2}
  理由：“父母”只是解释“终”的短语的一部分。

提示：留意“谓”前的那个单字。
解析：“谓”后给出所指，解释的是“慎终”的“终”。

## 找原文证据：疏中哪几个字说明为什么用“终”来称这件事？ {#q.l5.4.2}
考点：s.l5.glossdirection
语境：p.l5.4.a

- [ ] 慎终者 {#q.l5.4.2.o2}
  理由：这是回提经文，还没说明称名的缘故。
- [x] 死者人之终 {#q.l5.4.2.o1}
- [ ] 父母之丧也 {#q.l5.4.2.o3}
  理由：这给出此处所指，下一句才说明命名的缘由。

提示：找“故”前面的缘故。
解析：生命至死为终，这才接得上“故谓之终”。

## 单选：读了这条疏，能否说“终”在任何场合都指父母的丧事？ {#q.l5.4.3}
考点：s.l5.glossdirection
语境：p.l5.4.a

- [ ] 可以，“人之终”专指读书结束 {#q.l5.4.3.o3}
  理由：后一句明用了“死者”。
- [ ] 可以，“谓”后面总是字的唯一解释 {#q.l5.4.3.o2}
  理由：古注在说明眼前经文，未遍举字义。
- [x] 只能确认这句“慎终”的所指 {#q.l5.4.3.o1}

提示：辨认疏起首重提的经文。
解析：“慎终者”限定了正在解释的用例，别处仍须另读。

## 单选：后人复述这条“终谓父母之丧也”，怎样署明是谁在说？ {#q.l5.4.4}
考点：s.l5.glossdirection
语境：p.l5.4.a

- [x] 写成邢昺等的疏对“慎终”的解释 {#q.l5.4.4.o1}
- [ ] 写成现代编者自创的释义 {#q.l5.4.4.o3}
  理由：古注原文有底本，不应抹掉出处。
- [ ] 把整句引作曾子亲口的话 {#q.l5.4.4.o2}
  理由：疏是在讲曾子的话，二者年代和文字层次不同。

提示：正文之外，篇名还标有“疏”。
解析：可以援疏解释经文，但引号里的话是谁的要分清。

## 原文：古籍引文 {#p.l5.4.b}
> 敦柔润泽谓之温，行不犯物谓之良，和从不逆谓之恭，去奢从约谓之俭，先人后己谓之让。
译文：敦厚温和叫温，行为不侵害别人叫良，和顺不违逆叫恭，去奢从简叫俭，把别人放在自己前头叫让。
词注：约：俭省。
  物：这里指他人，“不犯物”说不侵扰别人。

## 单选：“先人后己谓之让”，要给哪个字配解释？ {#q.l5.4.5}
考点：s.l5.glossdirection
语境：p.l5.4.b

- [ ] 人 {#q.l5.4.5.o2}
  理由：“人”是先照顾谁，未作这条训释的词头。
- [x] 让 {#q.l5.4.5.o1}
- [ ] 先 {#q.l5.4.5.o3}
  理由：“先”和“后”一块说明怎样对待别人和自己。

提示：找“谓之”后收束的一字。
解析：疏用“先人后己”展开经文的“让”。

## 找原文证据：若要说明“俭”，只应从这段抄哪四个字？ {#q.l5.4.6}
考点：s.l5.glossdirection
语境：p.l5.4.b

- [ ] 行不犯物 {#q.l5.4.6.o3}
  理由：这组词解释“良”。
- [ ] 和从不逆 {#q.l5.4.6.o2}
  理由：这组词解释“恭”。
- [x] 去奢从约 {#q.l5.4.6.o1}

提示：对齐反复出现的“谓之”，不串到前一条。
解析：“去奢从约”紧接“谓之俭”，两边是一组。

## 单选：“行不犯物谓之良”和“终谓父母之丧”如何分别填卡片？ {#q.l5.4.7}
考点：s.l5.glossdirection
语境：p.l5.4.b

- [x] 良：行不犯物；终：父母之丧 {#q.l5.4.7.o1}
- [ ] 行：良；父母：终 {#q.l5.4.7.o3}
  理由：这样会把一种品德名安到“行”字，并把“终”错当父母之义。
- [ ] 良：谓；终：也 {#q.l5.4.7.o2}
  理由：把古注连词、语气词误当义项。

提示：先找出经文中要查的是哪两个单字。
解析：“谓之良”把名称放在末尾，“终谓”则从被释的字说起。

## 单选：若把“先人后己”抄到“恭”下，哪条古注可立刻校正？ {#q.l5.4.8}
考点：s.l5.glossdirection
语境：p.l5.4.b

- [ ] 敦柔润泽谓之温 {#q.l5.4.8.o2}
  理由：这一条让人核对的是“温”。
- [x] 和从不逆谓之恭 {#q.l5.4.8.o1}
- [ ] 去奢从约谓之俭 {#q.l5.4.8.o3}
  理由：这一条讲节俭，未说“恭”的所指。

提示：找明确以“恭”收尾的一条。
解析：疏中五项各有归属。“恭”与“让”不能只因都属德行就混填。
