# 课文：《春秋》把日食记在哪一天 {#l5.4}
简介：把日食、会面、去世各系到自己的日子上，看经文是记到月，还是记到了某一天。

## 正文

### “三年”是谁的三年？

《春秋》按鲁国国君的在位年次记事。篇题是“隐公三年”，往下看“春王二月”，这才是时令和月份。紧跟着的“己巳”说这一日叫什么。读到下一月，先前那个日名便不能带过来。

可在纸上给每件事记一行：哪位国君的第几年、哪个月、哪一天、出了什么事。“朔”又能告诉你当日是初一，“晦”指月末最后一天。干支六十天一轮，月有自己的起止；单凭“己巳”两字，还查不出是哪一年哪一月的公历日子。

查字时可直接翻到这里。[朔](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%9C%94) · [晦](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%99%A6)

## 知识点：干支纪日 {#skill.l5.4}
义项：分清君年、月份、干支日名和朔日
领域：文化背景
要诀：每件事单独记下月份和日子
讲解：“三年”按鲁君在位算，“己巳”是六十日轮回的一个日名，“朔”才说明这天是初一。若要换成公历日期，还得查清年代、核对历表。
例句：p.l5.4.example
复习题：q.l5.4.1 q.l5.4.3 q.l5.4.5 q.l5.4.8

## 原文：教学例句 {#p.l5.4.example}
> 某公五年秋七月甲子，河水溢。越月，水退。
译文：某位国君在位第五年，秋七月甲子日河水漫溢，过了一个月才退。这是仿编年体的例句；单凭“甲子”，还不能说那天是初一。

## 原文：古籍引文 {#p.l5.4.a}
> 三年春王二月，己巳，日有食之。三月庚戌，天王崩。夏四月辛卯，君氏卒。
译文：（鲁隐公）三年春季王历二月己巳日，发生日食。三月庚戌日，周天子去世。夏季四月辛卯日，君氏去世。

## 单选：日食这一条，鲁隐公在位第几年？当日的干支是什么？ {#q.l5.4.1}
考点：skill.l5.4
语境：p.l5.4.a

- [x] 三年；己巳 {#q.l5.4.1.o1}
- [ ] 二年；日食 {#q.l5.4.1.o3}
  理由：二月说一年中哪个月，日食说出了什么事，两者都不能填到日名那一栏。
- [ ] 三月；己巳 {#q.l5.4.1.o2}
  理由：“三月”已另起第二件事。

提示：把年次、月名、日名依次认出来。
解析：“三年”承篇题说隐公，“己巳”才是二月里那一天的日名。

## 找原文证据：天王去世，是在原文记的哪一个干支日？ {#q.l5.4.2}
考点：skill.l5.4
语境：p.l5.4.a

- [ ] 己巳 {#q.l5.4.2.o2}
  理由：己巳对应前面的日食。
- [x] 庚戌 {#q.l5.4.2.o1}
- [ ] 辛卯 {#q.l5.4.2.o3}
  理由：辛卯对应后面的君氏卒。

提示：从“天王崩”往前读，别越过前一个月名。
解析：“三月庚戌，天王崩”，月份和干支一起交代了去世的日子。

## 单选：只有“己巳”这两个字，能知道日期到什么程度？ {#q.l5.4.3}
考点：skill.l5.4
语境：p.l5.4.a

- [ ] 它必定是公历某年二月的同一日 {#q.l5.4.3.o3}
  理由：过六十天还会有“己巳”。要换成公历，须先查这是哪一年、哪个月。
- [ ] 它必定是二月初一 {#q.l5.4.3.o2}
  理由：本条并没有在日名后写“朔”。
- [x] 它是循环中的一个干支日名 {#q.l5.4.3.o1}

提示：“己巳”多久会再出现一次？这两个字说了初几吗？
解析：“己巳”在六十日的轮回中有定位。离开年、月和相应的历表，还换不成一个公历日期。

## 排序：按二月、三月、四月的顺序，排好经文记的三件事。 {#q.l5.4.4}
考点：skill.l5.4
语境：p.l5.4.a

- [1] 日食 {#q.l5.4.4.o1}
- [3] 君氏卒 {#q.l5.4.4.o3}
- [2] 天王崩 {#q.l5.4.4.o2}

提示：一换月，看看经文接下来记了什么。
解析：二月日食，三月天王崩，夏四月君氏卒。三个日名各归它所在的月份。

## 单选：“壬辰朔”里，壬辰和朔为什么能指同一天？ {#q.l5.4.5}
考点：skill.l5.4
语境：p.l5.4.b

- [ ] 一个年号和一个国号 {#q.l5.4.5.o2}
  理由：“秋七月”之后才写“壬辰朔”，这两个词都还在讲哪一天。
- [x] 干支日名和月内首日 {#q.l5.4.5.o1}
- [ ] 上月的最后一天和本月的第二天 {#q.l5.4.5.o3}
  理由：“朔”就是初一。“壬辰朔”合在一起只记这一天。

提示：一个按六十日循环数，一个按本月第几日数。
解析：“壬辰”是干支日名，“朔”说明这一天恰好是月首。

## 找原文证据：若要引用一个字说明日食在七月初一，该引哪个字？ {#q.l5.4.6}
考点：skill.l5.4
语境：p.l5.4.b

- [ ] 秋 {#q.l5.4.6.o3}
  理由：“秋”只给季节，不能确定月内哪一日。
- [ ] 既 {#q.l5.4.6.o2}
  理由：“既”承接日食，说明食尽。
- [x] 朔 {#q.l5.4.6.o1}

提示：经文除了“七月”和“壬辰”，还记了什么？
解析：“朔”指月首。有了这个字，才能说是七月初一。

## 单选：“既”可以讲“已经”，也可以讲“尽”。接在日食之后，这个字补说了什么？ {#q.l5.4.7}
考点：skill.l5.4
语境：p.l5.4.b

- [x] “既”在此指食尽，太阳被全部遮蔽 {#q.l5.4.7.o1}
- [ ] “既”把七月变成闰月 {#q.l5.4.7.o3}
  理由：是否闰月不能靠句末“既”判断。
- [ ] 太阳从六月起一直被遮蔽 {#q.l5.4.7.o2}
  理由：六月写诸侯会面，日食发生在七月。

提示：月日已经写在前面，看看末尾还可以补哪一种消息。
解析：“日有食之，既”，说的是太阳被全部遮蔽。这个“既”写日食到了什么程度。

## 单选：六月会见杞侯，能沿用下文日食的“壬辰朔”作会见日期吗？ {#q.l5.4.8}
考点：skill.l5.4
语境：p.l5.4.b

- [ ] 可以，经文以同一个日名概括两事 {#q.l5.4.8.o2}
  理由：从“六月”走到“秋七月”，已经是下一条记载。
- [x] 不能，壬辰朔只限定七月这一条 {#q.l5.4.8.o1}
- [ ] 可以，“公会”说明是在日食现场会见 {#q.l5.4.8.o3}
  理由：文本给会面的地点是郕，没有把会面同日食相连。

提示：两个事件之间又出现了哪个月名？
解析：会面在六月，只记到月。“秋七月”已另起一条，壬辰朔记的是日食。
