# 课文：年、月、干支怎样落在同一件事上 {#l5.4}
简介：沿着鲁国纪年读《春秋》日食条目，判断每个时间词所能提供的信息。

## 正文

### 先确定是谁的几年

《春秋》以鲁君为纪年中心。篇题“隐公三年”给出君名和年次，正文的“春王二月”继续交代时令和月份。“己巳”在此处是一个干支日名。不要把每个地支都当成生肖年。

试作四栏笔记：**君年｜季节、月序｜日名、朔晦｜事件**。“朔”是农历初一，“晦”是月末一日。干支的循环和朔望月的循环并不相同。经文若只给出干支，先如实记下，再决定是否需要找年表。

查阅《重编国语辞典修订本》的字头。[朔](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%9C%94) · [晦](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%99%A6)

## 知识点：干支纪日 {#skill.l5.4}
义项：区分年次、月序、干支日名和月首
领域：文化背景
要诀：从大到小拆出时间层次
讲解：经文依国君在位年次排列。干支日名六十日循环，朔是月首。换算绝对日期还需要年代和历表。
例句：p.l5.4.example
复习题：q.l5.4.1 q.l5.4.3 q.l5.4.5 q.l5.4.8

## 原文：教学例句 {#p.l5.4.example}
> 某公五年秋七月甲子，河水溢。越月，水退。
译文：假设某国君五年秋七月甲子日发生水患，一个月后水退。此句仿编年体；甲子并没有自动说明是初一。

## 原文：古籍引文 {#p.l5.4.a}

## 单选：表格有“鲁君年次”和“日名”两栏，第一件事应怎样填写？ {#q.l5.4.1}
考点：skill.l5.4
语境：p.l5.4.a

- [x] 三年；己巳 {#q.l5.4.1.o1}
- [ ] 二年；日食 {#q.l5.4.1.o3}
  理由：“二月”是月序，“日食”是事件。
- [ ] 三月；己巳 {#q.l5.4.1.o2}
  理由：“三月”已另起第二件事。

提示：从第一个月名往前后分别找年和日。
解析：篇题补足鲁隐公，“三年”是年次，“己巳”是二月之内的日名。

## 单选：仅凭“己巳”二字可以确定什么？ {#q.l5.4.3}

- [ ] 它必定是二月初一 {#q.l5.4.3.o2}

解析：六十干支循环，不能脱离篇年、月序等信息直接换成公历日期。

## 单选：“壬辰朔”给同一天加了哪两种标识？ {#q.l5.4.5}
考点：skill.l5.4
语境：p.l5.4.b

- [ ] 一个年号和一个国号 {#q.l5.4.5.o2}
  理由：这里紧接“七月”，两项都限定日子。
- [x] 干支日名和月内首日 {#q.l5.4.5.o1}
- [ ] 上月的最后一天和本月的第二天 {#q.l5.4.5.o3}
  理由：“朔”指新月月首，且原文记的是一日。

提示：分别查“壬辰”和“朔”。
解析：壬辰在六十日循环中定名，朔说明这是该月第一天。

## 找原文证据：要说明该次日食发生在七月初一，须引用哪一个字？ {#q.l5.4.6}
考点：skill.l5.4
语境：p.l5.4.b

- [ ] 秋 {#q.l5.4.6.o3}
  理由：“秋”只给季节，不能确定月内哪一日。
- [ ] 既 {#q.l5.4.6.o2}
  理由：“既”承接日食，说明食尽。
- [x] 朔 {#q.l5.4.6.o1}

提示：寻找直接说明月首的字。
解析：证据是“朔”；“七月”和“壬辰”各提供另一层时间信息。

## 单选：字书列“既”为已经、尽。末句如何注才能补上经文所记的现象？ {#q.l5.4.7}
考点：skill.l5.4
语境：p.l5.4.b

- [x] “既”在此指食尽，太阳被全部遮蔽 {#q.l5.4.7.o1}
- [ ] “既”把七月变成闰月 {#q.l5.4.7.o3}
  理由：是否闰月不能靠句末“既”判断。
- [ ] 太阳从六月起一直被遮蔽 {#q.l5.4.7.o2}
  理由：六月写诸侯会面，日食发生在七月。

提示：看“既”承接的是“日有食之”还是“秋七月”。
解析：这里“既”说明日食程度。日期在前，现象和程度在后。

## 单选：能否把“公会杞侯”和“日有食之”都记到壬辰朔？ {#q.l5.4.8}
考点：skill.l5.4
语境：p.l5.4.b

- [ ] 可以，经文以同一个日名概括两事 {#q.l5.4.8.o2}
  理由：六月和七月之间已经改换月份。
- [x] 不能，壬辰朔只限定七月这一条 {#q.l5.4.8.o1}
- [ ] 可以，“公会”说明是在日食现场会见 {#q.l5.4.8.o3}
  理由：文本给会面的地点是郕，没有把会面同日食相连。

提示：先标月份，再给事件系日期。
解析：六月之会只有月份；后条有新的月份和日名，不能向上补作六月之日。
