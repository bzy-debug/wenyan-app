# 课文：不知“楫”读什么，能查到它吗？ {#d32.1}
简介：先翻部首，再数余下的笔画；到了同一栏还得看字形。

## 正文

读到“舟人失楫”，不必先猜字音。“楫”左边是木；把这一边遮住，右边是口三画、耳六画，合计九画。按下面这份小索引查，先到木部，再到九画栏，最后在同栏的字里找右边是“咠”的那个。本课行号为教学排印的地址，原辞书并没有这些行号。

| 部首 | 部外笔画 | 本页所列字头及条号 |
| --- | --- | --- |
| 木 | 七 | 梧①、桴② |
| 木 | 八 | 棹③ |
| 木 | 九 | 楫④、楓⑤ |
| 舟 | 四 | 舫⑥ |
| 舟 | 五 | 舷⑦、舸⑧ |

翻到④才见“楫，jí，划船的桨”。若选了②，字条说“桴”可指屋梁、鼓槌、竹木筏；是哪一义，单靠木部回答不了。下面保留一段《论语》，可以拿这个条目试读。部首、部外画按教育部《重编国语辞典修订本》；同栏只列本课用字，不作全表。[查“楫”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=楫)

## 知识点：部首与部外笔画 {#skill.d32.radical}
义项：从部首和余画找到字头所在栏，再核对整字
领域：阅读技能
要诀：只数部首以外的部分；同栏可能有几个字。
讲解：木部九画不是全字九画。翻到这一栏还要认出目标字的另一半。
例句：p.d32.1.r1

## 知识点：从索引到字条 {#skill.d32.apply}
义项：翻到对应条目，再用本句的动作筛选解释
领域：阅读技能
要诀：索引给地址，字条才给读音、词义。
讲解：木部的字可能指船桨、树木、屋梁。用它划船还是拿它造屋，得看原句。
例句：p.d32.1.r3

## 原文：教学例句 {#p.d32.1.r1}
> 待查句：舟人失楫，舟隨流下。
> 检字表：木部七画，梧①、桴②；八画，棹③；九画，楫④、楓⑤。
> 字条：②竹木筏，亦可指屋梁。④划水的桨，读 jí。⑤一种树。
译文：船夫失了船桨，船随水漂了下去。④这一条讲得通船为什么随流而下。小表和字条是本课整理的练习材料。
词注：隨：随，顺着。

## 原文：教学例句 {#p.d32.1.r2}
> 待查句：大舸至，客倚舷而望。
> 检字表：舟部四画，舫⑥；五画，舷⑦、舸⑧。
> 字条：⑥船。⑦船侧的边沿。⑧大船，读 gě。
译文：大船到了，客人靠在船边眺望。舸和舷都在舟部五画，却得翻到不同的字条。
词注：倚：靠着。

## 原文：古籍引文 {#p.d32.1.r3}
> 子曰：「道不行，乘桴浮于海。」
译文：孔子说：“我的主张行不通，我便乘筏到海上漂游。”
词注：乘：搭乘。
  浮：漂行在水面。
出处：《论语·公冶长》5.7，节至“浮于海”

## 单选：不知道“楫”的读音，用表中的哪一条路能找到它？ {#q.d32.1.1}
考点：skill.d32.radical
语境：p.d32.1.r1

- [ ] 舟部→部外九画，找船上用品 {#q.d32.1.1.o1}
  理由：它在船上用，写这个字却用木旁；本表据字形归部。
- [x] 木部→部外九画→④ {#q.d32.1.1.o2}
  理由：木是部首，口三画、耳六画。九画栏里右边有口和耳的字标④。
- [ ] 木部→全字十三画，再翻部外十三画栏 {#q.d32.1.1.o3}
  理由：十三是连木旁一并数出的总画数，小表各栏列的是余画。

提示：遮住“木”，看看口和耳共多少画。
解析：木是部首，口三画、耳六画。九画栏里右边有口和耳的字标④。

## 找原文证据：已经翻到木部九画栏，下一步该点哪个字头？ {#q.d32.1.2}
考点：skill.d32.radical
语境：p.d32.1.r1

- [x] 楫④ {#q.d32.1.2.o1}
  理由：“楫④”字形相合，④是从这一栏通往正文的条号。
- [ ] 棹③ {#q.d32.1.2.o2}
  理由：它也可指桨，但在另一笔画栏；原句用字没有“卓”。
- [ ] 楓⑤ {#q.d32.1.2.o3}
  理由：这一项也在九画栏，右边却是“風”。

提示：把原句的字和候选字从左到右对一遍。
解析：“楫④”字形相合，④是从这一栏通往正文的条号。

## 单选：若只记下“树木”，原句“舟隨流下”的缘由还能说清吗？ {#q.d32.1.3}
考点：skill.d32.apply
语境：p.d32.1.r1

- [ ] 应选②，竹筏就是这条船掉在水里的东西 {#q.d32.1.3.o1}
  理由：“舟”仍在顺流走，船夫丢掉的是楫；②的字头是桴。
- [x] 要改查④，船夫失了划水用的桨 {#q.d32.1.3.o2}
  理由：他少了控制船行的桨。“随流下”的动作支持④的解释。
- [ ] 可以，所有木部字在船边都指造船的树 {#q.d32.1.3.o3}
  理由：同一张表就有船桨和树，木部没有给出这个字的义项。

提示：问“失楫”以后，舟人少了什么用具。
解析：他少了控制船行的桨。“随流下”的动作支持④的解释。

## 排序：只看“舸”的外形，把这趟检字过程排好。 {#q.d32.1.4}
考点：skill.d32.radical
语境：p.d32.1.r2

- [3] 在“舷、舸”中核对右半，翻⑧ {#q.d32.1.4.o1}
  理由：锁定“可”才知道应翻哪一个条号。
- [1] 找舟部 {#q.d32.1.4.o2}
  理由：部首先把范围缩到舟部，五画再缩小一层，最后用字形确定⑧。
- [2] 在余下的“可”上数得五画，找五画栏 {#q.d32.1.4.o3}
  理由：这一栏须在舟部内找，不能先在整部辞书随意翻五画。

提示：“舷”和“舸”在本表同一栏。
解析：部首先把范围缩到舟部，五画再缩小一层，最后用字形确定⑧。

## 单选：有人抄成“客倚大船而望”，认为“舷”和“舸”可以共用一条释义。问题在哪？ {#q.d32.1.5}
考点：skill.d32.apply
语境：p.d32.1.r2

- [ ] “舸”才是船边，“舷”是整条大船 {#q.d32.1.5.o1}
  理由：⑦、⑧分别标出船边和大船，正好相反。
- [x] “舷”指可以倚靠的船边，两字同栏仍须分条 {#q.d32.1.5.o2}
  理由：大的东西是舸，靠着的部位是舷。相同部首、余画只说明检索位置相邻。
- [ ] “倚”字已经说明客人站在另一条小船上 {#q.d32.1.5.o3}
  理由：原句没有另写一条小船，不能用它解释字义。

提示：看看两个条号各给的是整物还是一部分。
解析：大的东西是舸，靠着的部位是舷。相同部首、余画只说明检索位置相邻。

## 单选：查原句的“桴”。木部小表为“七画：梧①、桴②；八画：棹③；九画：楫④”。该翻哪里？ {#q.d32.1.6}
考点：skill.d32.radical
语境：p.d32.1.r3

- [x] 七画栏的② {#q.d32.1.6.o1}
  理由：“桴”的右边是“孚”，在所列七画字中应翻②。
- [ ] 七画栏的① {#q.d32.1.6.o2}
  理由：两字同栏；①的右边是“吾”。
- [ ] 九画栏的④ {#q.d32.1.6.o3}
  理由：④是“楫”；划水用桨与乘筏都能过水，却是两个不同字头。

提示：读原字右边的形状，别只认左边的木旁。
解析：“桴”的右边是“孚”，在所列七画字中应翻②。

## 单选：桴条简列“屋梁、鼓槌、竹木筏”。用哪一种能读通孔子所设想的出路？ {#q.d32.1.7}
考点：skill.d32.apply
语境：p.d32.1.r3

- [x] 竹木筏，可以乘它漂到海上 {#q.d32.1.7.o1}
  理由：“乘桴”把桴当交通工具，“浮于海”把场景限在水上，两处都合的是筏。
- [ ] 鼓槌，可以敲响招人出船 {#q.d32.1.7.o2}
  理由：这段没有鼓和击鼓的动作；孔子要“乘”的就是桴。
- [ ] 屋梁，指海边准备搭建的屋子 {#q.d32.1.7.o3}
  理由：句中没有建屋，“浮于海”说它在水面的用途。

提示：同时满足“乘”和“浮”的是哪一项？
解析：“乘桴”把桴当交通工具，“浮于海”把场景限在水上，两处都合的是筏。

## 找原文证据：哪一处除了“乘”之外，还能让你在桴条里舍去“屋梁”一义？ {#q.d32.1.8}
考点：skill.d32.apply
语境：p.d32.1.r3

- [ ] 道不行 {#q.d32.1.8.o1}
  理由：这是他作此设想的缘故，尚未说他将怎样走。
- [x] 浮于海 {#q.d32.1.8.o2}
  理由：“浮于海”说在海上漂行；能载人漂行的是辞条所列的筏。
- [ ] 子曰 {#q.d32.1.8.o3}
  理由：这只交代话由谁说，与桴为何物无关。

提示：沿着“乘桴”往后读，找所在与动作。
解析：“浮于海”说在海上漂行；能载人漂行的是辞条所列的筏。
