# 检查：从众人的说法里读出各自的意思 {#check.32}

## 原文：教学例句 {#p.check.32.a}
> 县人役毕不散。或问故，里正曰：“众所以留者，欲共校役簿，恐漏一人也。”
译文：乡人服完役还留着。有人问缘故，里正说：“大伙儿想一起核对役簿，生怕漏记谁，所以没散。”

## 单选：乡人服役已完还不散去。要问“所以留”的缘故，应当弄清什么？ {#q.check.32.1}
考点：skill.syntax.10.1
语境：p.check.32.a

- [x] 大家是否还得一同核对役簿
- [ ] 大家使用什么办法登记服役人数
  理由：“或问故”是在问完工后为什么还不走。簿册怎样登记，里正并没有讲。
- [ ] 服役在哪一天开始
  理由：这是前事，不能说明结束后为什么还留。

提示：谁先“问故”？里正答的是留下做什么，还是怎样登记人数？
解析：怕漏掉一人，所以大家想一起核对役簿。这才解释了人为什么没有散。

## 原文：教学例句 {#p.check.32.b}
> 水忽涨。园中无舟，守者解门扉，以为筏，载书渡沟。
译文：水忽然上涨。园中没有船，看守人卸下门板，用作筏子，载着书渡过沟。

## 找原文证据：守者拆下门扇，“以为筏”。原文哪一处说明他真把门板派上了这个用场？ {#q.check.32.2}
考点：skill.syntax.10.4
语境：p.check.32.b

- [x] 载书渡沟
- [ ] 水忽涨
  理由：水涨是先前的难处，门板是不是真派上用场，还要看后来怎样渡沟。
- [ ] 园中无舟
  理由：没船让守者想到别的办法，还没写出他真用门板载了什么。

提示：找他拿门板去做的一件实事。
解析：“载书渡沟”要有东西托住书过水。把“以为筏”补成“以之为筏”，那块门板便有了着落。

## 原文：教学例句 {#p.check.32.c}
> 商将雇车，问主者：“新车与旧车，孰任重？”主者各载一石，旧车轴曲，新车独行如常。
译文：商人要雇车，问车主新旧两辆哪辆能承重。车主让两车各载一石，旧车车轴弯曲，新车照常行驶。

## 单选：哪一番比较真正试出了新旧车谁能负重？ {#q.check.32.3}
考点：skill.syntax.11.1
语境：p.check.32.c

- [ ] 只比较车漆的新旧
  理由：新旧用来指认两车，标准是承重。
- [ ] 比较车主与商人谁更有力
  理由：“孰任重”接在“新车与旧车”后，问的是车的本领。
- [x] 同载一石，看两车是否还能行走

提示：两车装了多少，试过以后各成什么样？
解析：一车各载一石，旧车轴弯了，新车仍能行驶。两车担了同样的重量，才好作此比较。

## 原文：教学例句 {#p.check.32.d}
> 乡人争古桥之年，诸说不一。生曰：“与其各道所闻，孰若同观桥碑？”众从之，碑果有年月。
译文：乡人争论古桥的建造年代，众说不一。读书人说，与其各讲听闻，何不一道看桥碑？大家听从他的建议，碑上果然刻着年月。

## 单选：众人为古桥的年代各说各话。读书人劝他们到哪里去找答案？ {#q.check.32.4}
考点：skill.syntax.11.2
语境：p.check.32.d

- [x] 一起查验碑上有无年月
- [ ] 在旧桥旁立一块新碑
  理由：“同观桥碑”指现有的碑。
- [ ] 把不同传闻都认作建桥年代
  理由：众人的传闻互有出入，读书人这才请大家一起去看桥碑。

提示：听完“孰若”这句话，众人去看了什么？
解析：他劝众人一道看桥碑，碑上果然刻着年月。“众从之”正说大家听取了这个建议。

## 原文：教学例句 {#p.check.32.e}
> 驿吏候信，过午未至，问来客曰：“得无道有积雪乎？”客曰：“山道晴，信使伤足，止前亭矣。”
译文：驿吏等信，过了中午还没等着，便问来客：“莫不是路上有积雪？”来客说：“山路天晴，是信使伤了脚，停在前面的亭子里了。”

## 单选：驿吏和来客各有一种说法，怎样写才说清信为什么迟了？ {#q.check.32.5}
考点：skill.syntax.12.2
语境：p.check.32.e

- [ ] 驿吏没有等过中午
  理由：开头写“过午未至”。
- [ ] 驿吏猜测道路被积雪阻断
  理由：积雪是驿吏担心的事。来客却说“山道晴”，还说了信使在哪儿。
- [x] 来客说明信使受伤停下

提示：谁是在猜？谁见到了信使怎样了？
解析：积雪只是驿吏问到的一种可能。来客带来的消息是信使伤了脚，停在前亭。

## 原文：教学例句 {#p.check.32.f}
> 众人欲刈禾，见水漫田。长者问：“如积水何？”少年指旧沟曰：“启此可泄。”长者即命治沟。
译文：众人要割稻，看到水漫过田。长者问，积水该怎么办？少年指着旧沟说，打开这里便能排水。长者马上叫人疏沟。

## 排序：长者怎样求教排水，少年怎样答，众人又怎样做？按事情发生的先后排好。 {#q.check.32.6}
考点：skill.syntax.12.4
语境：p.check.32.f

- [2] 少年指出旧沟可供排水
- [1] 长者提出如何处置积水
- [3] 长者命人疏通沟渠

提示：从看到积水，读到少年指的旧沟，再读到最后的命令。
解析：先问怎样处置积水，少年就指出旧沟可用；长者随即命人疏沟，果然照这个主意办了。
