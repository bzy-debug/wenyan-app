# 检查：在比较、猜测和问句中还原立场 {#check.32}

## 原文：教学例句 {#p.check.32.a}
> 县人役毕不散。或问故，里正曰：“众所以留者，欲共校役簿，恐漏一人也。”
译文：县里的人服役完毕还没有散去。有人问缘故，里正说，大家留下来是想一起核对服役簿，唯恐遗漏一个人。

## 单选：求证“所以留”的原因，应查哪一项？ {#q.check.32.1}
考点：skill.syntax.10.1
语境：p.check.32.a

- [x] 大家是否还得一同核对役簿
- [ ] 大家使用什么办法登记服役人数
  理由：“或问故”问的是为什么服役完还没散；簿册的登记方法没有展开。
- [ ] 服役在哪一天开始
  理由：这是前事，不能说明结束后为什么还留。

提示：看“或问故”要的是什么答案。
解析：“所以留者”接着解释众人想避免漏记，因而留下核簿。

## 原文：教学例句 {#p.check.32.b}
> 水忽涨。园中无舟，守者解门扉，以为筏，载书渡沟。
译文：水忽然上涨。园中没有船，看守人卸下门板，用作筏子，载着书渡过沟。

## 找原文证据：从哪里能验证“以为筏”已经实际做到了？ {#q.check.32.2}
考点：skill.syntax.10.4
语境：p.check.32.b

- [x] 载书渡沟
- [ ] 水忽涨
  理由：这是事情起因。
- [ ] 园中无舟
  理由：这是另寻渡具的缘由。

提示：找出门板充当筏子的具体结果。
解析：门板被用来运书过沟，“以为”可补作“以之为”，并非仅仅猜它像筏子。

## 原文：教学例句 {#p.check.32.c}
> 商将雇车，问主者：“新车与旧车，孰任重？”主者各载一石，旧车轴曲，新车独行如常。
译文：商人要雇车，问车主新旧两辆哪辆能承重。车主让两车各载一石，旧车车轴弯曲，新车照常行驶。

## 单选：哪一次比较真正回答商人的问题？ {#q.check.32.3}
考点：skill.syntax.11.1
语境：p.check.32.c

- [ ] 只比较车漆的新旧
  理由：新旧用来指认两车，标准是承重。
- [ ] 比较车主与商人谁更有力
  理由：两者并不是“孰任重”的对象。
- [x] 同载一石，看两车是否还能行走

提示：找出两车受到的相同考验。
解析：在相同载荷下观察到不同表现，新车本次表现更好。

## 原文：教学例句 {#p.check.32.d}
> 乡人争古桥之年，诸说不一。生曰：“与其各道所闻，孰若同观桥碑？”众从之，碑果有年月。
译文：乡人争论古桥的建造年代，众说不一。读书人说，与其各讲听闻，何不一道看桥碑？大家听从他的建议，碑上果然刻着年月。

## 单选：读书人为解决分歧推荐哪一种做法？ {#q.check.32.4}
考点：skill.syntax.11.2
语境：p.check.32.d

- [x] 一起查验碑上有无年月
- [ ] 在旧桥旁立一块新碑
  理由：“同观桥碑”指现有的碑。
- [ ] 把不同传闻都认作建桥年代
  理由：传闻相异才促使他提出别的途径。

提示：看哪一项紧随“孰若”，以及众人随后的去向。
解析：查碑可取得众人共同核验的材料，“众从之”表明他们采用了后一办法。

## 原文：教学例句 {#p.check.32.e}
> 驿吏候信，过午未至，问来客曰：“得无道有积雪乎？”客曰：“山道晴，信使伤足，止前亭矣。”
译文：驿吏等信，过了中午还没等到，便问来客，莫非路上有积雪？客人说山路晴好，送信人伤了脚，停在前一座亭里了。

## 单选：若要写出信迟的原因，应采用哪一条？ {#q.check.32.5}
考点：skill.syntax.12.2
语境：p.check.32.e

- [ ] 驿吏没有等过中午
  理由：开头写“过午未至”。
- [ ] 驿吏猜测道路被积雪阻断
  理由：“得无”把猜测交给来客核实，来客并未认可。
- [x] 来客说明信使受伤停下

提示：分别标出谁在猜，谁在提供新消息。
解析：伤足停亭是答话提供的缘故，积雪是问话中待确认的可能。

## 原文：教学例句 {#p.check.32.f}
> 众人欲刈禾，见水漫田。长者问：“如积水何？”少年指旧沟曰：“启此可泄。”长者即命治沟。
译文：众人要割稻，看到水漫过田。长者问，积水该怎么办？少年指着旧沟说，打开这里便能排水。长者马上叫人疏沟。

## 排序：依真正请求办法后事情的发展排序。 {#q.check.32.6}
考点：skill.syntax.12.4
语境：p.check.32.f

- [2] 少年指出旧沟可供排水
- [1] 长者提出如何处置积水
- [3] 长者命人疏通沟渠

提示：把问题、回答和采用办法的行动分开。
解析：少年的回答受到采用，表明“如积水何”是在索取切实办法。
