# 课文：孰与、与其……孰若：比较中的取舍 {#syntax.11}
简介：读发问人给出的标准，也读对方有没有真的被要求评个高下。

## 正文

### 三个空格：甲、乙、在哪一点上比
“甲孰与乙近？”把两者放到**远近**这把尺上；“甲与乙，孰近？”也可询问哪个近。两者都出现，并不意味着问者已经赞成其中一方。阅读时先留好空格，由后文的回答补上比较结果。

“与其舍近而求远，孰若即此问津？”也给出两种办法，但问句本身常在**推荐后者**。把两项分别代入当时的难处，再看有没有“从之”“遂……”等行动证据。《论语》用“与其……宁……”明说偏好；同是排列两个选项，口气却与请教高下不同。

## 知识点：孰与 {#skill.syntax.11.1}
义项：比较两项在特定方面的高下
领域：句法
要诀：谁和谁，按什么比
讲解：“我孰与某……”可问我与某人相比怎样；倒过来用“甲与乙孰……”也可请人评判。若无答案和其他证据，勿代问者下结论。
例句：p.syntax.11.a

## 知识点：与其……孰若…… {#skill.syntax.11.2}
义项：并列备选做法，倾向于后一项
领域：句法
要诀：后者解决了眼前哪个困难
讲解：“与其……孰若……”常把赞成的办法置于后一端。“与其……宁……”则用“宁”直接标明偏好。辨别是否真在征询答案，要读理由与回应。
例句：p.syntax.11.b

## 原文：教学例句 {#p.syntax.11.a}
> 客将载粟入城，问舟子：“水道孰与陆道近？”对曰：“陆道近三里，然雨后泥深，不利车。”
译文：客人将运粮进城，问船夫水路和陆路哪条近。船夫回答，陆路近三里，不过雨后泥深，不便行车。

## 单选：“孰与”这一问直接要比较的是哪一点？ {#q.syntax.11.1}
考点：skill.syntax.11.1
语境：p.syntax.11.a

- [ ] 客人与船夫谁更能吃苦
  理由：发问的人与答话的人不是两个被比较的对象。
- [x] 水路和陆路的路程长短
- [ ] 车与船所能载的谷物多少
  理由：“近”已指定比较标准。

提示：先圈两种路线，再读问句最后一个字。
解析：两项是水道与陆道，标准是远近；路泥深是对方答后补充的限制。

## 找原文证据：船夫哪一句直接回答了远近问题？ {#q.syntax.11.2}
考点：skill.syntax.11.1
语境：p.syntax.11.a

- [ ] 雨后泥深
  理由：这是路况。
- [x] 陆道近三里
- [ ] 不利车
  理由：这是泥深对车辆的影响。

提示：只截取给出比较结果的一小句。
解析：“陆道近三里”直接比较里程；后半句能影响如何走，却未改里程。

## 单选：在“奢、俭”两项之间，哪一个字把偏好说得最明确？ {#q.syntax.11.3}
考点：skill.syntax.11.2
语境：p.syntax.11.b

- [ ] 其
  理由：“与其”带起拿来比较的第一项。
- [x] 宁
- [ ] 礼
  理由：“礼”限定议论的对象。

提示：看哪一个字可以换成“宁可”。
解析：这里明说在所举两端之间宁愿取俭，不是在请听者猜选项。

## 原文：教学例句 {#p.syntax.11.c}
> 两匠各献一弓。将试之，问曰：“此弓孰与彼弓强？”射者引之，曰：“彼弓强，然非弱士所能满也。”
译文：两名工匠各献一张弓。将领试弓，问这张弓与那张相比哪张更强。射手把弓拉开，说那张强，但力弱的人没法把它拉满。

## 单选：读完答话，可以确认什么？ {#q.syntax.11.4}
考点：skill.syntax.11.1
语境：p.syntax.11.c

- [x] 彼弓较强，但强并不一定适合每个射手
- [ ] 此弓肯定强，因为问句把它列在前面
  理由：先提哪一张不能决定结果。
- [ ] 试弓者认为两张都没有用
  理由：“非弱士所能满”只说明强弓的使用条件。

提示：用答话补全结果，再读“然”引出的限制。
解析：比较对象的顺序不等于高下顺序；“彼弓强”才提供答案。

## 原文：教学例句 {#p.syntax.11.d}
> 里有二井，客问：“东井与西井，孰甘？”妪曰：“未之尝也。”乃各汲一瓢以进。
译文：村里有两口井，客人问东井与西井的水哪口更甘。老妇说自己没尝过，于是各打一瓢水给他。

## 单选：就本段所载，能否决定哪口井的水更甘？ {#q.syntax.11.5}
考点：skill.syntax.11.1
语境：p.syntax.11.d

- [ ] 能，水更深的西井必定更甘
  理由：文中也没比较井的深浅。
- [x] 还不能，答者说没尝过，只取来两瓢供比较
- [ ] 能，先汲的东井必定更甘
  理由：原文没有给品尝结果。

提示：把发问、提供样品和实际尝味区分开。
解析：“孰甘”指出要比甘美程度；“各汲一瓢”在准备比较而非宣布结果。

## 原文：教学例句 {#p.syntax.11.e}
> 行者迷津，欲复返城求图。友指渔舟曰：“与其返城，孰若问诸舟人？”遂趋水际。
译文：行路人找不到渡口，要回城找地图。友人指着渔舟说，与其回城，何不向船上的人问问？于是他们快步走到水边。

## 单选：友人实际上建议先做哪件事？ {#q.syntax.11.6}
考点：skill.syntax.11.2
语境：p.syntax.11.e

- [ ] 回城画一张新的地图
  理由：回城只是权衡时提出的第一方案。
- [ ] 在渔舟与城门之间丈量距离
  理由：“问诸舟人”是获取消息的办法。
- [x] 到水边向船上的人询问

提示：结合“孰若”后的动作和最后一句。
解析：渔舟近在眼前，后面赶往水边的动作与问船人的建议一致。

## 找原文证据：哪处行动说明行者采纳了友人的主张？ {#q.syntax.11.7}
考点：skill.syntax.11.2
语境：p.syntax.11.e

- [ ] 友指渔舟
  理由：这是友人的示意。
- [ ] 欲复返城
  理由：这是友人劝说之前原拟的办法。
- [x] 遂趋水际

提示：找问句之后已经发生的事。
解析：“趋水际”朝着船人所在的地方去，显示原拟返城的做法改变了。

## 原文：教学例句 {#p.syntax.11.f}
> 雨坏南墙，众议刻石记费。匠曰：“与其先刻石，孰若先葺墙？雨又将至矣。”主者命取土。
译文：雨水损坏南墙，众人议论刻石记下费用。工匠说，与其先刻石，何不先修墙？雨又快来了。主持者下令取土。

## 排序：还原匠人改变眼前办事次序的思路。 {#q.syntax.11.8}
考点：skill.syntax.11.2
语境：p.syntax.11.f

- [2] 建议把修墙放在前面
- [1] 说出众人原想先办的刻石之事
- [3] 以雨快到来说明修墙急迫

提示：找出“与其”前项、“孰若”后项及紧随其后的理由。
解析：先把原议带入权衡，再推荐优先补墙，最后点明雨将至的理由。
