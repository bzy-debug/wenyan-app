# 课文：孰与、与其……孰若：比较中的取舍 {#syntax.11}
简介：问“两口井哪口甜”得等人回答；问“与其回城，何不问问船夫”却已含着建议。

## 正文

### 两种东西摆出来，究竟是在发问还是劝人？

“甲孰与乙近？”“甲与乙，孰近？”问的都是甲乙谁近。先找两边比的是什么，再等下文的回答。别因为甲写在前面，就认定甲一定较近。

“与其舍近而求远，孰若即此问津？”也摆出两条路，说话的人心里却更愿就近问渡口。下文若接“从之”“遂……”，就看看大家照哪个办法去做。《论语》说“与其……宁……”，“宁”字更把愿意选哪一面说得明白。

## 知识点：孰与 {#skill.syntax.11.1}
义项：与另一项相比，哪一个更……
领域：句法
要诀：谁跟谁比，比的是哪一点？
讲解：“我孰与某……”是问我跟他比起来怎样。也能把两人并排写作“甲与乙孰……”。问句只提出比较，答案要到后面去找。
例句：p.syntax.11.a

## 知识点：与其……孰若…… {#skill.syntax.11.2}
义项：与其这样，不如那样
领域：句法
要诀：说者更愿意哪一种，下文的人往哪里去？
讲解：把两种办法并说时，“孰若”后面常跟说者倾向的那一种。“宁”字更明白地表态。是不是请人评高下，还要听上下文的口气。
例句：p.syntax.11.b

## 原文：教学例句 {#p.syntax.11.a}
> 客将载粟入城，问舟子：“水道孰与陆道近？”对曰：“陆道近三里，然雨后泥深，不利车。”
译文：客人将运粮进城，问船夫水路和陆路哪条近。船夫回答，陆路近三里，不过雨后泥深，不便行车。

## 单选：“水道孰与陆道近？”客人想知道两条路的哪一点？ {#q.syntax.11.1}
考点：skill.syntax.11.1
语境：p.syntax.11.a

- [ ] 客人与船夫谁更能吃苦
  理由：客人请舟子分辨长短，两种走法才是拿来比较的东西。
- [x] 水路和陆路的路程长短
- [ ] 车与船所能载的谷物多少
  理由：客人问“近”，只问程途；载多少粮是另一个问题。

提示：先认水路和陆路，再读问话的最后一个字。
解析：“近”字定下了要比的是路程。雨后泥深，是船夫答完远近又补说的事。

## 找原文证据：船夫哪一句正面回答了客人“哪条路近”的问题？ {#q.syntax.11.2}
考点：skill.syntax.11.1
语境：p.syntax.11.a

- [ ] 雨后泥深
  理由：泥深说明陆路难走，没说它比水路长还是短。
- [x] 陆道近三里
- [ ] 不利车
  理由：这是泥深对车辆的影响。

提示：哪一句实实在在说出了相差多少里？
解析：“陆道近三里”已经回答远近。泥深会影响怎样走，却没改两条路的长短。

## 原文：古籍引文 {#p.syntax.11.b}
> 礼，与其奢也，宁俭。
译文：谈到礼，与其奢侈，宁可节俭。

## 单选：孔子谈礼，在“奢”和“俭”之间，哪个字明白说出他愿意选哪一个？ {#q.syntax.11.3}
考点：skill.syntax.11.2
语境：p.syntax.11.b

- [ ] 其
  理由：念到“与其奢也”，两条路只摆出头一条，还不知道说者要选谁。
- [x] 宁
- [ ] 礼
  理由：“礼”限定议论的对象。

提示：从“俭”往前读一个字。
解析：“宁俭”就是宁可节俭。两种做法都说了，孔子自己的选择也说了。

## 原文：教学例句 {#p.syntax.11.c}
> 两匠各献一弓。将试之，问曰：“此弓孰与彼弓强？”射者引之，曰：“彼弓强，然非弱士所能满也。”
译文：两名工匠各献一张弓。将领试弓，问这张弓与那张相比哪张更强。射手把弓拉开，说那张强，但力弱的人没法把它拉满。

## 单选：试完两张弓以后，射手怎样回答“孰强”？这句话还有什么保留？ {#q.syntax.11.4}
考点：skill.syntax.11.1
语境：p.syntax.11.c

- [x] 彼弓较强，但强并不一定适合每个射手
- [ ] 此弓肯定强，因为问句把它列在前面
  理由：问话先提此弓，射手的回答却明说“彼弓强”。
- [ ] 试弓者认为两张都没有用
  理由：力弱的人拉不满那张强弓，不能由此说两张弓都没用。

提示：先听他挑哪一张，再听“然”后补了什么。
解析：“彼弓强”已经有了高下；力弱的人却拉不满。较强是比较所得，合不合用还要看人。

## 原文：教学例句 {#p.syntax.11.d}
> 里有二井，客问：“东井与西井，孰甘？”妪曰：“未之尝也。”乃各汲一瓢以进。
译文：村里有两口井，客人问东井与西井的水哪口更甘。老妇说自己没尝过，于是各打一瓢水给他。

## 单选：老妇各取一瓢井水。这时能说哪口井更甘甜了吗？ {#q.syntax.11.5}
考点：skill.syntax.11.1
语境：p.syntax.11.d

- [ ] 能，水更深的西井必定更甘
  理由：老妇只去打水，既没量西井深浅，也没尝出西井的水更甜。
- [x] 还不能，答者说没尝过，只取来两瓢供比较
- [ ] 能，先汲的东井必定更甘
  理由：原文没有给品尝结果。

提示：她只说“未之尝也”。有人接着把尝水的结果说出来了吗？
解析：两瓢水已经取来，还等着比较。文中没有写出品尝的结果。

## 原文：教学例句 {#p.syntax.11.e}
> 行者迷津，欲复返城求图。友指渔舟曰：“与其返城，孰若问诸舟人？”遂趋水际。
译文：赶路的人找不到渡口，想回城找张图。友人指着渔舟说：“与其回城去，何不问问船上的人？”于是快步往水边去了。

## 单选：行者原想回城找图，友人指了指渔舟，劝他怎么做？ {#q.syntax.11.6}
考点：skill.syntax.11.2
语境：p.syntax.11.e

- [ ] 回城画一张新的地图
  理由：返城是行者原来想做的，正是友人请他先放下的办法。
- [ ] 在渔舟与城门之间丈量距离
  理由：友人要问船上的人渡口在哪儿，没有叫人量距离。
- [x] 到水边向船上的人询问

提示：看听完这句话，两人朝哪一边去了。
解析：就近找船人问路，省得折返。问句里的两条路，友人更愿取后面那条。

## 找原文证据：哪几个字说明他们当真照友人的话，向渔舟那边走了？ {#q.syntax.11.7}
考点：skill.syntax.11.2
语境：p.syntax.11.e

- [ ] 友指渔舟
  理由：这是友人的示意。
- [ ] 欲复返城
  理由：“欲复返城”只是原先想回去，接下来还会不会回城，要看听劝后的脚步。
- [x] 遂趋水际

提示：只看友人说完以后已经发生的动作。
解析：“遂趋水际”是赶到水边。行动接上“问诸舟人”，原来打算回城的路也就改了。

## 原文：教学例句 {#p.syntax.11.f}
> 雨坏南墙，众议刻石记费。匠曰：“与其先刻石，孰若先葺墙？雨又将至矣。”主者命取土。
译文：雨水冲坏了南墙，众人在商量刻石记下这笔费用。工匠说：“与其先刻石，何不先把墙修好？雨又要来了。”主事的人便叫人取土。

## 排序：匠人为什么劝众人先修墙？把他说话的次序排好。 {#q.syntax.11.8}
考点：skill.syntax.11.2
语境：p.syntax.11.f

- [2] 建议把修墙放在前面
- [1] 说出众人原想先办的刻石之事
- [3] 以雨快到来说明修墙急迫

提示：先听“与其”所说的刻石，再找“孰若”要先做什么；雨是在什么时候提到的？
解析：他先提众人想办的刻石，再主张先补墙，末了才说雨又要来，不能耽搁。
