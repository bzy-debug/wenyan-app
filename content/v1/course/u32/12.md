# 课文：无乃、得无、何……为、如……何：听懂发问的用意 {#syntax.12}
简介：有的问句期待一个办法，有的带着一项推测，还有的借问句表达明确判断。

## 正文

### 不凭末尾的问号作决定
先找**发问前已知什么**。说话人提出一串理由后仍问“何以伐为”，可能是在表明出兵没有道理。若来人不知水深，问“如这条河何”，接下来派人测水、讨论怎样过，读作真心请教办法才与上下文相合。

“无乃……乎（与）”常含“恐怕……吧”的推断或委婉责问；“得无……乎”也可带着担忧揣测。两者的语气有相交之处。留意答者是在提供消息、纠正猜测，还是被要求面对已经摆明的理由。不要把每个反问都解释成生气。

## 知识点：无乃……乎 {#skill.syntax.12.1}
义项：用推测口吻提出规劝或责问
领域：句法
要诀：话里已给出哪些判断依据
讲解：常可读为“恐怕……吧”，口气委婉，内容却可能是明确批评。不同语境也可只是表示忧虑。
例句：p.syntax.12.a

## 知识点：得无……乎 {#skill.syntax.12.2}
义项：带着一种担忧或猜测向人求证
领域：句法
要诀：所担心的事有无证据
讲解：提出一种可能情况让对方确认或否认，不能只凭问句认定那件事真的发生。
例句：p.syntax.12.b

## 知识点：何……为 {#skill.syntax.12.3}
义项：以问句质疑某事的必要性
领域：句法
要诀：在这段理由之后还要这么做吗
讲解：“何以伐为”在列出的理由之后反诘为何要攻打。是否反问要靠上下文，不能见到“何为”两字就套用。
例句：p.syntax.12.a

## 知识点：如……何 {#skill.syntax.12.4}
义项：询问处置办法或以问句表达无能为力
领域：句法
要诀：是期待办法，还是已排除可行办法
讲解：“如……何”把要对付的人或事情放在中间，可问“拿它怎么办”。答复、实际行动与上下文限制会改变语气。
例句：p.syntax.12.c

## 原文：古籍引文 {#p.syntax.12.a}
> 求！无乃尔是过与？夫颛臾，昔者先王以为东蒙主，且在邦域之中矣，是社稷之臣也。何以伐为？
译文：求啊，恐怕该责备你吧？颛臾，从前先王让它主持东蒙山的祭祀，而且它在本国疆域之内，是本国的臣属，为什么还要攻打它呢？

## 单选：孔子用“无乃尔是过与”开口，接着列举颛臾的情况，是在做什么？ {#q.syntax.12.1}
考点：skill.syntax.12.1
语境：p.syntax.12.a

- [x] 用推断口吻批评冉求，并给反对攻伐的理由
- [ ] 单纯打听谁叫作“求”
  理由：“求！”已直接称呼听话人。
- [ ] 已经接受出兵，只询问颛臾的位置
  理由：后文反问为何要攻打，显出反对态度。

提示：留心问句接下来的整段理由。
解析：“尔是过”可读为“责备你”，无乃……与使责问带着“恐怕……吧”的口吻。

## 单选：读到“何以伐为”，应怎样理解孔子的立场？ {#q.syntax.12.2}
考点：skill.syntax.12.3
语境：p.syntax.12.a

- [x] 既然颛臾本是臣属，何必攻打它呢
- [ ] 邀请冉求选择出兵的吉日
  理由：前面的身份和境域都在质疑出兵本身。
- [ ] 请冉求列出攻城器械
  理由：上文列的是不该攻打的理由，没有讨论武器。

提示：结合“且在邦域之中”“是社稷之臣”。
解析：反问承接已经摆明的理由，表达出兵缺乏正当理由。

## 原文：教学例句 {#p.syntax.12.b}
> 暮，牧童独归。母不见小犊，问曰：“得无失其犊乎？”童指篱外曰：“方就草耳。”
译文：傍晚，牧童独自回来。母亲没看见小牛，问莫非把小牛弄丢了？孩子指着篱笆外说，它正在吃草罢了。

## 单选：母亲的话能否成为“小牛已丢”的证据？ {#q.syntax.12.3}
考点：skill.syntax.12.2
语境：p.syntax.12.b

- [ ] 能，“得无”明说已经找到失牛
  理由：“得无……乎”提出的是疑问。
- [x] 不能，那是由眼前未见而生的担心，孩子随后作了回答
- [ ] 能，孩子也说正在寻找
  理由：“就草”说明小牛在吃草。

提示：比较母亲所见的范围与篱外的情况。
解析：没有看见使母亲产生了猜测；答者提供了母亲原先不知道的信息。

## 原文：教学例句 {#p.syntax.12.c}
> 堰坏，水将入田。农问匠曰：“如决口何？”匠量其广，教先下木桩，次实以石。
译文：堰坏了，水快要流进田里。农夫问工匠，缺口该怎么办？工匠量了宽度，教他先下木桩，再用石头填实。

## 单选：农夫是请教具体办法，哪条后文最能验证这点？ {#q.syntax.12.4}
考点：skill.syntax.12.4
语境：p.syntax.12.c

- [x] 工匠量缺口，提出木桩和石料的施工次序
- [ ] 水可能要入田
  理由：这只说明情势紧急。
- [ ] 决口已经出现
  理由：提出问题的背景本身不能决定发问语气。

提示：看对话是否真的给出了一个可操作的回答。
解析：工匠照题意提供了修堰办法，说明农夫的问句有待补足的信息。

## 原文：教学例句 {#p.syntax.12.d}
> 众约凿井，未量地势便争井栏之饰。长者曰：“水尚不知所在，今遽饰其栏，无乃早乎？”众乃持绳相地。
译文：众人约好挖井，还没勘察地势便争着商议井栏的装饰。长者说，水还不知在哪里，现在就忙着装饰井栏，恐怕早了吧。众人这才拿绳索勘察地势。

## 找原文证据：长者批评“早”的依据是什么？ {#q.syntax.12.5}
考点：skill.syntax.12.1
语境：p.syntax.12.d

- [ ] 今遽饰其栏
  理由：这是他认为过早的行动。
- [x] 水尚不知所在
- [ ] 众乃持绳相地
  理由：这是众人受劝后的行动。

提示：找出本应先解决、实际还不知道的事。
解析：井水所在未定，此时讲究井栏装饰就颠倒了次序。

## 原文：教学例句 {#p.syntax.12.e}
> 医至病者之家，见碗中药如故，问曰：“得无苦而未饮乎？”病者曰：“已饮一碗，此新煎者也。”
译文：医生来到病人家，见碗里的药像没动过，就问莫非是药苦还没喝？病人答，已经喝了一碗，这是新煎的。

## 单选：病人的回答改变了医生的哪一项猜测？ {#q.syntax.12.6}
考点：skill.syntax.12.2
语境：p.syntax.12.e

- [ ] 已经有人通知医生药要换方
  理由：对话只讨论是否服过。
- [x] 药满碗可能是因为嫌苦未喝
- [ ] 药碗根本不在病人家
  理由：医生亲眼见到药碗。

提示：区别“眼前药满”和“因此从未喝过”。
解析：“得无”试探一个解释；病人用新煎的一碗说明同一现象另有缘故。

## 原文：教学例句 {#p.syntax.12.f}
> 使者持空牍来。吏曰：“书一字未具，印之何为？”遂还其牍，俟书成乃印。
译文：使者拿着空文书来。吏员说，一个字都没有写，盖印做什么？于是把文书还回，等写好才盖印。

## 找原文证据：哪一个动作最直接表明此刻的问句是否定盖印的必要？ {#q.syntax.12.7}
考点：skill.syntax.12.3
语境：p.syntax.12.f

- [ ] 俟书成乃印
  理由：这是写好以后的处理方式。
- [x] 遂还其牍
- [ ] 持空牍来
  理由：这是使者来时的举动。

提示：看问完当下怎样处置空文书。
解析：他把空文书退还，借问句表达“眼下盖印没有用”。

## 原文：教学例句 {#p.syntax.12.g}
> 炬尽，崖路绝，无舟可济。导者叹曰：“吾欲即往，如此水何！”众乃宿岸上。
译文：火把用尽，崖路断绝，也没有船可以渡水。向导叹道，我想马上过去，可拿这条河怎么办！大家就在岸上过夜。

## 单选：与求教工匠“如决口何”相比，向导此处更接近什么口气？ {#q.syntax.12.8}
考点：skill.syntax.12.4
语境：p.syntax.12.g

- [x] 眼下无计可施，只能感叹
- [ ] 已决定游过，问众人谁先下水
  理由：“众乃宿岸上”没有开始过河。
- [ ] 询问河流正式的名字
  理由：上下文在说如何通过。

提示：把“路绝”“无舟”和留宿放在一起。
解析：路与船都不可用，又以叹息、留宿收束，所表达的是暂且无法渡河。
