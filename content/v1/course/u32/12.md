# 课文：无乃、得无、何……为、如……何：听懂发问的用意 {#syntax.12}
简介：问“该怎么办”，有人等你出个主意；有时说话人已知道无计可施，只剩一声叹息。

## 正文

### 听到问句，再听听有没有人在等答话

孔子已列出颛臾的身份和位置，再问“何以伐为”，冉求此时该回答怎样出兵吗？联系前面的理由，就听得出这是在质疑出兵本身。换个情形，若来人不知水深，问“如这条河何”，后面又实际测水商量渡法，倒真是在求个办法。

“无乃……乎（与）”有“恐怕……吧”的口气，可以是担忧，也可以是婉转的批评。“得无……乎”也常是心里有一个猜想，还要问个明白。留心答者是在补消息、解误会，还是一句话便听出了劝意。反问也有平静的说法，不能见了问号就一律读成发怒。

## 知识点：无乃……乎 {#skill.syntax.12.1}
义项：恐怕……吧，委婉地规劝或责问
领域：句法
要诀：听说者已经摆出了什么道理
讲解：“无乃……乎”语气可以很婉，意思却可能是批评。若只是担心一件未明的事，也可读作推测。
例句：p.syntax.12.a

## 知识点：得无……乎 {#skill.syntax.12.2}
义项：莫非……吗，带着担心向人核实
领域：句法
要诀：他说的是亲见的事，还是自己担心的事？
讲解：“得无……乎”把心里想到的可能问出来。答案可能证实猜测，也可能告诉他另有缘故。
例句：p.syntax.12.b

## 知识点：何……为 {#skill.syntax.12.3}
义项：何必……呢，以问句质疑有无必要
领域：句法
要诀：前面说到这里，事情还值得做吗？
讲解：“何以伐为”之前已说足不该攻打的理由，所以要读出反问的口气。换一段话，究竟是不是反问仍要看前后。
例句：p.syntax.12.a

## 知识点：如……何 {#skill.syntax.12.4}
义项：拿……怎么办，有时也用来表示没有办法
领域：句法
要诀：听完“怎么办”，接着有人出主意吗？
讲解：“如”与“何”中间说要对付的事。有人真来讨办法，也有人眼前无路可走而感叹，看对话怎样接、大家后来怎样做。
例句：p.syntax.12.c

## 原文：古籍引文 {#p.syntax.12.a}
> 求！无乃尔是过与？夫颛臾，昔者先王以为东蒙主，且在邦域之中矣，是社稷之臣也。何以伐为？
译文：求啊，恐怕该责备你吧？颛臾，从前先王让它主持东蒙山的祭祀，而且它在本国疆域之内，是本国的臣属，为什么还要攻打它呢？

## 单选：孔子问“无乃尔是过与”，接着讲颛臾的地位。他要冉求想一想什么？ {#q.syntax.12.1}
考点：skill.syntax.12.1
语境：p.syntax.12.a

- [x] 用推断口吻批评冉求，并给反对攻伐的理由
- [ ] 单纯打听谁叫作“求”
  理由：“求！”已直接称呼听话人。
- [ ] 已经接受出兵，只询问颛臾的位置
  理由：后文反问为何要攻打，显出反对态度。

提示：“求！”已叫了姓名。下面的几句话为什么都在说明不该出兵？
解析：“尔是过”是指责冉求。“无乃……与”把责问说得委婉，随后的理由却表明孔子确实不赞成攻伐。

## 单选：“何以伐为”换成今天的话，怎样才能读出孔子的意思？ {#q.syntax.12.2}
考点：skill.syntax.12.3
语境：p.syntax.12.a

- [x] 既然颛臾本是臣属，何必攻打它呢
- [ ] 邀请冉求选择出兵的吉日
  理由：孔子已说颛臾在邦内、是社稷之臣，追问的是为何要伐，没在挑日子。
- [ ] 请冉求列出攻城器械
  理由：上文列的是不该攻打的理由，没有讨论武器。

提示：颛臾既在邦内，又是什么身份？
解析：已经是社稷之臣，又何必去攻打？孔子把反对的意思放进这一问里。

## 原文：教学例句 {#p.syntax.12.b}
> 暮，牧童独归。母不见小犊，问曰：“得无失其犊乎？”童指篱外曰：“方就草耳。”
译文：傍晚，牧童独自回来。母亲没看见小牛，问莫非把小牛弄丢了？孩子指着篱笆外说，它正在吃草罢了。

## 单选：母亲没见到小牛，问“得无失其犊乎”。这就能说牛丢了吗？ {#q.syntax.12.3}
考点：skill.syntax.12.2
语境：p.syntax.12.b

- [ ] 能，“得无”明说已经找到失牛
  理由：母亲怕小牛丢了，才这样问。她还没有看见小牛，也没有说已经找到。
- [x] 不能，那是由眼前未见而生的担心，孩子随后作了回答
- [ ] 能，孩子也说正在寻找
  理由：“就草”说明小牛在吃草。

提示：听一听孩子指着篱外怎样答她。
解析：母亲只见牧童独归，所以担心。篱外的小牛正吃草，孩子的回答解开了误会。

## 原文：教学例句 {#p.syntax.12.c}
> 堰坏，水将入田。农问匠曰：“如决口何？”匠量其广，教先下木桩，次实以石。
译文：堰塌了，水快漫进田里。农夫问工匠：“这道口子怎么办？”工匠量过缺口的宽度，教他先打木桩，再拿石头填实。

## 单选：农夫问“如决口何”，哪件事看得出他真想讨一个办法？ {#q.syntax.12.4}
考点：skill.syntax.12.4
语境：p.syntax.12.c

- [x] 工匠量缺口，提出木桩和石料的施工次序
- [ ] 水可能要入田
  理由：水将入田分明很急，但这还不能告诉你农夫问过以后，工匠答了什么。
- [ ] 决口已经出现
  理由：人人都看得见堰坏。要看农夫是在感叹还是求教，听工匠怎样答最清楚。

提示：工匠听过以后，是在感叹，还是在安排怎样修？
解析：工匠量过决口，交代先下木桩、再填石头。答的是怎样动手修，也就照应了农夫的求教。

## 原文：教学例句 {#p.syntax.12.d}
> 众约凿井，未量地势便争井栏之饰。长者曰：“水尚不知所在，今遽饰其栏，无乃早乎？”众乃持绳相地。
译文：众人约好挖井，还没勘察地势便争着商议井栏的装饰。长者说，水还不知在哪里，现在就忙着装饰井栏，恐怕早了吧。众人这才拿绳索勘察地势。

## 找原文证据：长者说装饰井栏还早，究竟是哪一件要紧事还没弄清？ {#q.syntax.12.5}
考点：skill.syntax.12.1
语境：p.syntax.12.d

- [ ] 今遽饰其栏
  理由：抢着装饰井栏，是长者批评的那件事。为什么嫌早，上一句已讲。
- [x] 水尚不知所在
- [ ] 众乃持绳相地
  理由：这是众人受劝后的行动。

提示：找一找，开井的人现在连什么都还不知道。
解析：连哪里有水都没有弄清，先争井栏怎么装饰自然太早。后来众人持绳相地，才去办头一件事。

## 原文：教学例句 {#p.syntax.12.e}
> 医至病者之家，见碗中药如故，问曰：“得无苦而未饮乎？”病者曰：“已饮一碗，此新煎者也。”
译文：医生到了病人家里，见碗里的药像没动过，便问：“莫不是嫌苦还没喝？”病人说：“我已经喝了一碗，这是新煎的。”

## 单选：医生看着满碗的药，原先以为怎么回事？病人怎样使他明白了？ {#q.syntax.12.6}
考点：skill.syntax.12.2
语境：p.syntax.12.e

- [ ] 已经有人通知医生药要换方
  理由：病人解释哪一碗已经喝了，并没有同医生商量药方。
- [x] 药满碗可能是因为嫌苦未喝
- [ ] 药碗根本不在病人家
  理由：医生亲眼见到药碗。

提示：同样是满碗，原先的一碗与眼前的一碗是同一碗吗？
解析：医生以为药苦没喝。病人说已喝过一碗，这是新煎的，满碗的原因便另有解释。

## 原文：教学例句 {#p.syntax.12.f}
> 使者持空牍来。吏曰：“书一字未具，印之何为？”遂还其牍，俟书成乃印。
译文：使者拿着空文书来。吏员说，一个字都没有写，盖印做什么？于是把文书还回，等写好才盖印。

## 找原文证据：官吏问“印之何为”，哪一个紧接的动作表示他眼下不肯盖印？ {#q.syntax.12.7}
考点：skill.syntax.12.3
语境：p.syntax.12.f

- [ ] 俟书成乃印
  理由：“俟书成”还得等。官吏此刻做的动作在它前面。
- [x] 遂还其牍
- [ ] 持空牍来
  理由：这是使者来时的举动。

提示：留意他把空文书怎样处置了。
解析：说完便退回空牍，等写好才盖印。“盖它做什么”其实是说现在盖了也无用。

## 原文：教学例句 {#p.syntax.12.g}
> 炬尽，崖路绝，无舟可济。导者叹曰：“吾欲即往，如此水何！”众乃宿岸上。
译文：火把用尽，崖路断绝，也没有船可以渡水。向导叹道，我想马上过去，可拿这条河怎么办！大家就在岸上过夜。

## 单选：向导叹“如此水何”，与农夫求教“如决口何”有什么不同？ {#q.syntax.12.8}
考点：skill.syntax.12.4
语境：p.syntax.12.g

- [x] 眼下无计可施，只能感叹
- [ ] 已决定游过，问众人谁先下水
  理由：“众乃宿岸上”没有开始过河。
- [ ] 询问河流正式的名字
  理由：就算知道这条河叫什么，眼下还是无舟可渡。向导叹的是过不去。

提示：看看火把、山路和渡船都怎样了，众人后来又在哪里过夜。
解析：崖路不通，又没船，向导的话只剩无奈。众人只得岸上留宿，和工匠当即说出修堰办法不同。
