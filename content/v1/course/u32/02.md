# 课文：同样的“阝”该翻哪一部？ {#d32.2}
简介：右边的阝通常入邑部，左边的阝通常入阜部。遇到地名，还需翻回原句确认。

## 正文

临摹旧地名时，“郢”和“隅”里的折笔很像。试用这一份教学索引。凡例按《重编国语辞典修订本》所列部首缩编，括号里的数是部首以外的笔画。这里的“阝”已经是邑或阜写进整字时的形状，不必把“邑”“阜”再写一次凑笔画。

| 索引部 | 本页只列这些字头 |
| --- | --- |
| 邑部，形在右 | 郊（六）、郡（七）、郢（七）、郭（八） |
| 阜部，形在左 | 限（六）、陌（六）、陳（八）、陵（八）、隅（九） |

在“郢”里把右旁遮起来，剩一个“呈”。找到“邑部七画”还不能立刻合书，那一栏有“郡”也有“郢”。“陳”恰在另一部。是地名还是“陈列”的动作，需要再查字条与原句。[查“郢”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=郢)

## 知识点：左阜右邑 {#skill.d32.shape}
义项：按阝在字中的位置选阜部或邑部，再核对余形
领域：阅读技能
要诀：先看折耳是在左边还是右边。
讲解：郢的折耳在右，查邑部；陳的折耳在左，查阜部。两字都能写地名，不能据此归为同一部。
例句：p.d32.2.r1

## 知识点：从候选字中取义 {#skill.d32.head}
义项：核对候选字的完整形体，再把地名或普通词义放回原句
领域：阅读技能
要诀：同栏不保证同义，同一个字头也可能兼有别的身份。
讲解：郢是楚都名，郡是行政区；读“在陳”还要在“陈列”和“陈国”之间选择。
例句：p.d32.2.r2

## 原文：教学例句 {#p.d32.2.r1}
> 待查句：使者自郢來，出郭乃見車馬。
> 教学索引：邑部六画郊；七画郢、郡；八画郭。
> 字条：郢，楚都名；郡，行政区名；郭，外城。
译文：使者从郢地来，出了外城才看见车马。郢与郡的笔画栏相同，字头与所指不同。
词注：使者：受命出行的人。
  乃：才。

## 原文：教学例句 {#p.d32.2.r2}
> 待查句：客登陵，見城東隅有塔。
> 教学索引：阜部八画陳、陵；九画隅、階。
> 字条：陵，大土山；隅，角落；階，台阶。
译文：旅客登上土山，看到城东的一角有座塔。城隅落在城的一角，不是登山时脚下的台阶。
词注：登：由低往高处上。
  塔：高耸的建筑。

## 原文：古籍引文 {#p.d32.2.r3}
> 在陳絕糧，從者病，莫能興。
译文：在陈国时断了粮，跟从孔子的人病倒，没人能起身。
词注：絕糧：断了粮。
  興：起来。

## 单选：抄到“郢”不知音。看清哪一边，便能决定先翻哪部？ {#q.d32.2.1}
考点：skill.d32.shape
语境：p.d32.2.r1

- [ ] 右边的阝，把书翻到阜部 {#q.d32.2.1.o1}
  理由：阜在这组字里写在左边，可与“陵”对照。
- [ ] 左边的口，把书翻到口部七画栏 {#q.d32.2.1.o2}
  理由：本表的“郢”列在邑部；左边整个“呈”用于数余画。
- [x] 右边的阝，把书翻到邑部 {#q.d32.2.1.o3}
  理由：右阝是这里的邑旁，先翻邑部，再核对左边是不是“呈”。

提示：把目标字和范例“郊”对一对。
解析：右阝是这里的邑旁，先翻邑部，再核对左边是不是“呈”。

## 找原文证据：使者从哪里来？请在索引后面的字条中选出与原句相符的释条。 {#q.d32.2.2}
考点：skill.d32.head
语境：p.d32.2.r1

- [ ] 郡，行政区名 {#q.d32.2.2.o1}
  理由：同在七画栏，左边却为“君”，原句为“呈”。
- [ ] 郭，外城 {#q.d32.2.2.o2}
  理由：外城属于“出郭”那个动作，原句的起点在“自”之后。
- [x] 郢，楚都名 {#q.d32.2.2.o3}
  理由：“自郢”指从郢地来。查到七画栏后要分清郢、郡，不能用一个泛称换掉具体地名。

提示：观察“自”和“出”各带哪个字。
解析：“自郢”指从郢地来。查到七画栏后要分清郢、郡，不能用一个泛称换掉具体地名。

## 单选：查“隅”时面前有“邑部九画”和“阜部九画”两页，翻哪一页？ {#q.d32.2.3}
考点：skill.d32.shape
语境：p.d32.2.r2

- [x] 阜部九画，阝在左 {#q.d32.2.3.o1}
  理由：入阜部九画，再与同栏的“階”核字，才找到“隅”。
- [ ] 邑部九画，因为所说地点在城内 {#q.d32.2.3.o2}
  理由：用处是处所，不等于字形入邑部；“隅”的折耳在左。
- [ ] 任选一页，两个部只是不同字体 {#q.d32.2.3.o3}
  理由：在这份辞书中它们有各自独立的部首和字目。

提示：把“隅”与“郢”的折耳位置比一比。
解析：入阜部九画，再与同栏的“階”核字，才找到“隅”。

## 单选：“城東隅有塔”较可信的读法是哪一个？ {#q.d32.2.4}
考点：skill.d32.head
语境：p.d32.2.r2

- [ ] 塔在一座叫陳的城里 {#q.d32.2.4.o1}
  理由：“陳”属于阜部八画，并且原文没提到陈国。
- [ ] 塔在城东的台阶上 {#q.d32.2.4.o2}
  理由：“階”和“隅”同栏；原字右边是“禺”，不是“皆”。
- [x] 塔在城东一角 {#q.d32.2.4.o3}
  理由：“隅”条的角落义能和城东相接。把同栏的另一个字认进来，就给原文添了一段台阶。

提示：看看“东”给哪种位置定了方向。
解析：“隅”条的角落义能和城东相接。把同栏的另一个字认进来，就给原文添了一段台阶。

## 排序：查“陳”，依本课索引排好实际操作。 {#q.d32.2.5}
考点：skill.d32.shape
语境：p.d32.2.r3

- [3] 对照“陳、陵”二形选中陳条 {#q.d32.2.5.o1}
  理由：同栏后还要以右半辨认字头。
- [1] 看见阝在左，翻阜部 {#q.d32.2.5.o2}
  理由：依序从阜部到八画，再核对阜旁加“東”的陳字。
- [2] 数右边“東”八画，进八画栏 {#q.d32.2.5.o3}
  理由：数的是部首之外的“東”；八画栏须在阜部里找。

提示：部首的位置、部外画数、条目字形各用一次。
解析：依序从阜部到八画，再核对阜旁加“東”的陳字。

## 单选：陳字条简列“排列；陈说；古国名”。这里该取哪一项？ {#q.d32.2.6}
考点：skill.d32.head
语境：p.d32.2.r3

- [ ] 陈说，孔子在讲怎么节省粮食 {#q.d32.2.6.o1}
  理由：“在陳”给事情一个地点，后面接的是随从的遭遇。
- [ ] 排列，粮食已整齐摆开 {#q.d32.2.6.o2}
  理由：“絕糧”是断粮，不是陈列粮食。
- [x] 古国名，在那里断了粮 {#q.d32.2.6.o3}
  理由：陈国是断粮发生的所在；在古文中遇到这个字，查到“排列”还得往下看。

提示：先读“在____”，再读随从当时的处境。
解析：陈国是断粮发生的所在；在古文中遇到这个字，查到“排列”还得往下看。

## 单选：如果把“出郭”译成“离开郊野”，检字记录里最该复查哪一步？ {#q.d32.2.7}
考点：skill.d32.head
语境：p.d32.2.r1

- [ ] 是否应该改找阜部，郭的阝在左 {#q.d32.2.7.o1}
  理由：郭的阝在右，邑部这一步没有错。
- [x] 原字是八画栏的郭，还是六画栏的郊 {#q.d32.2.7.o2}
  理由：郭的左边与郊不同，索引也分列两栏。字条给“郭”的释义是外城。
- [ ] 有没有把“自”字抄成“出” {#q.d32.2.7.o3}
  理由：要分的是外城和郊野，先看“出”后的那个字。

提示：两个候选字都有邑旁，错可以出在下一层。
解析：郭的左边与郊不同，索引也分列两栏。字条给“郭”的释义是外城。

## 找原文证据：旅客登高后看见一座塔。他先登上的究竟是什么？用条目中的释义作答。 {#q.d32.2.8}
考点：skill.d32.head
语境：p.d32.2.r2

- [x] 大土山 {#q.d32.2.8.o1}
  理由：“陵”在这个字条里指大土山。两处同带左耳的字在句中各有位置。
- [ ] 台阶 {#q.d32.2.8.o2}
  理由：这是階的解释，待查句写“登陵”。
- [ ] 角落 {#q.d32.2.8.o3}
  理由：东隅是他望见塔的所在，不是先前登上的东西。

提示：一个字由“登”带着，另一个由“城东”限定。
解析：“陵”在这个字条里指大土山。两处同带左耳的字在句中各有位置。
