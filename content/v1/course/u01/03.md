# 课文：根据上下文判断词义 {#l1.3}
简介：从对象、结果和并列结构中提出词义，再用原句检查自己的推断。

## 正文

### 遇见生词时，先留下一个空位

教学例句：“童汲水，满瓮而归。”假如不认识“汲”，先保留“孩子对水做了某件事”。再问：结果为什么是“满瓮”？这个动作应当能让水进入容器。从水源取水就能解释这个变化。把它理解成“喝水”，得到的结果就不对。

| 证据来自哪里 | 能帮助回答什么 |
| --- | --- |
| 动词支配的物件 | 这个动作作用于谁或什么？ |
| 后句交代的新状态 | 什么变化已经发生？ |
| 两个结构相近的小句 | 已知的一句能约束另一句的哪个位置？ |

**试着反证。** 试读教学例句“引索，桶乃升”。把“引”先试成“放开”，再试成“拉动”。桶升上来支持“拉动”的读法；这条线索加上“索”（绳）作为工具，才让推断变得具体。练习中若只看见一个熟悉字就选定答案，可以回头问：我还有哪半句没用上？

本课还会用一对先秦短句练习平行结构。即使逐字都很陌生，也可以先配对两个动作和两种结果。

## 知识点：搭配 {#skill.object-clue}
义项：从动作对象辨义
领域：阅读技能
要诀：动作和对象相互限定
讲解：“取火”与“取书”对象不同。遇到多义词，把它和所支配的对象连起来读，再检验全句是否通顺。
例句：p.ex.object-clue

## 知识点：下文 {#skill.result-clue}
义项：用后果验证词义
领域：阅读技能
要诀：把候选义代回前后句
讲解：下句写出的状态或动作结果可以排除不合语境的解释。先说出发生了什么变化，再代回词义。
例句：p.ex.result-clue

## 原文：教学例句 {#p.ex.object-clue}
> 童举石，置之于案。
译文：孩子举起石头，把它放在桌上。

## 原文：教学例句 {#p.ex.result-clue}
> 樵者释担，肩乃轻。
译文：砍柴人放下担子，肩上才轻松了。

## 原文：教学例句 {#p.l1.3.water}
> 童汲井水，注之于瓮。
译文：孩子打了井水，把水倒进大瓮里。

## 单选：“注之于瓮”的“注”是哪种动作？ {#q.l1.3.1}
考点：skill.object-clue
语境：p.l1.3.water

- [x] 倒入 {#q.l1.3.1.o1}
- [ ] 注解 {#q.l1.3.1.o2}
  理由：“之”指井水，井水能加注解吗？
- [ ] 注视 {#q.l1.3.1.o3}
  理由：光靠看，能把井水装进瓮里吗？

提示：先确定“之”指什么。
解析：“之”指井水，瓮是容器，“注”只能是把水倒入。

## 原文：教学例句 {#p.l1.3.untie}
> 舟人解缆，舟乃离岸。
译文：船夫解开缆绳，船才离开岸边。

## 找原文证据：解开缆绳后，船怎么样了？找出写这一变化的话。 {#q.l1.3.2}
考点：skill.result-clue
语境：p.l1.3.untie

- [x] 舟乃离岸 {#q.l1.3.2.o1}
- [ ] 缆 {#q.l1.3.2.o2}
  理由：缆是船绳。题目问船后来怎么样了。
- [ ] 舟人 {#q.l1.3.2.o3}
  理由：舟人是解缆的人；要找的是后来的变化。

提示：找“乃”引出的变化。
解析：船能离岸说明原先的系缚已被解除。

## 原文：教学例句 {#p.l1.3.door}
> 父启户，月光入室。
译文：父亲打开门，月光照进室内。

## 单选：由下句推知，“启户”是怎样做？ {#q.l1.3.3}
考点：skill.result-clue
语境：p.l1.3.door

- [x] 打开门 {#q.l1.3.3.o1}
- [ ] 关上门 {#q.l1.3.3.o2}
  理由：关上门和月光进屋，这两件事相合吗？
- [ ] 修补门 {#q.l1.3.3.o3}
  理由：前文有没有交代门坏了？

提示：比较门开与关各有什么结果。
解析：“月光入室”支持打开门的理解。

## 原文：教学例句 {#p.l1.3.weave}
> 妇持针，穿线于针孔。
译文：女子拿着针，把线穿过针孔。

## 单选：这里的“穿”该如何解释？ {#q.l1.3.4}
考点：skill.object-clue
语境：p.l1.3.weave

- [x] 使线通过小孔 {#q.l1.3.4.o1}
- [ ] 凿开岩石 {#q.l1.3.4.o2}
  理由：针孔已经存在，还要凿开什么？
- [ ] 穿上衣服 {#q.l1.3.4.o3}
  理由：找一找：穿过针孔的究竟是哪样东西？

提示：把“穿”和紧接的名词连读。
解析：“线”是移动的东西，“针孔”是它通过的位置。

## 单选：如果暂时不认识“权”，用两句的对称关系可以怎样推断？ {#q.l1.3.5}
考点：skill.result-clue
语境：p.l1.3.ice

- [ ] “权”是掌权，因为可以决定物品贵贱 {#q.l1.3.5.o1}
  理由：“轻重”相应的是物的重量还是贵贱？
- [ ] “权”是量长度，因为后面有“长短” {#q.l1.3.5.o2}
  理由：“权”与“度”各接哪一个“然后知”？
- [x] “权”是称量，因为它的结果是知道轻重 {#q.l1.3.5.o3}
  理由：“权”与“度”位置对应，轻重与长短分别检验前一动作。

提示：两次“然后知”像两条分界线。分别找线前的动作和线后的结果。
解析：先将两小句上下对齐。“度”通向长短，“权”通向轻重，因此“权”表示称量。即便没记过这个义项，也能由句式和结果验证。

## 原文：教学例句 {#p.l1.3.net}
> 渔者举网，网中有鱼。
译文：渔人提起渔网，网里面有鱼。

## 找原文证据：渔人举起了什么？选出“举”后表示物件的字。 {#q.l1.3.6}
考点：skill.object-clue
语境：p.l1.3.net

- [ ] 鱼 {#q.l1.3.6.o1}
  理由：鱼在网里。渔人直接提起的是哪件东西？
- [x] 网 {#q.l1.3.6.o2}
  第几处：1
- [ ] 渔者 {#q.l1.3.6.o3}
  理由：渔者是提东西的人。看他手中之物。

提示：找动词后面直接相接的物件。
解析：“举网”的宾语是网，因此“举”是提起。

## 原文：教学例句 {#p.l1.3.fuel}
> 薪尽火灭，室复暗。
译文：柴烧尽，火熄了，屋里又暗下来。

## 单选：后文哪种现象印证“灭”的意思？ {#q.l1.3.7}
考点：skill.result-clue
语境：p.l1.3.fuel

- [ ] 柴还有很多 {#q.l1.3.7.o1}
  理由：“尽”说明柴是多了还是少了？
- [ ] 屋里亮起来 {#q.l1.3.7.o2}
  理由：“复暗”中的“暗”形容怎样的光线？
- [x] 屋里暗下来 {#q.l1.3.7.o3}

提示：看火的变化给屋内带来什么结果。
解析：失去光亮印证“灭”是火熄了。

## 原文：教学例句 {#p.l1.3.ink}
> 生磨墨，濡笔而书。
译文：学生磨墨，把笔蘸湿后写字。

## 单选：“濡笔”的“濡”在这里应指什么？ {#q.l1.3.8}
考点：skill.object-clue
语境：p.l1.3.ink

- [ ] 折断笔 {#q.l1.3.8.o1}
  理由：把笔折断，还能接着“书”吗？
- [x] 把笔蘸湿 {#q.l1.3.8.o2}
- [ ] 晾干笔 {#q.l1.3.8.o3}
  理由：磨墨和写字之间为什么还要处理笔尖？

提示：联系前面的墨和后面的书写。
解析：笔是对象，墨已备好，又将书写，可以判断是在蘸湿笔尖。
