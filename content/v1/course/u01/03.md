# 课文：秤与尺：不认识的字也能往下读 {#l1.3}
简介：看动作碰到什么，再看动作之后发生什么。

## 正文

古人拿一件东西放上秤，才知道它轻不轻；拿尺子量，才知道它长不长。《孟子》把这两件事写成两句，连着读，比单查一个“权”字容易懂。

再试一句教学自编的话：“客发匣，见旧书。”如果“发”指寄出，客人怎样会马上看见匣中的信？读到一个熟字，先让两种可能的意思都留着，到后一句看看哪种讲得通。

## 知识点：看动作碰到什么 {#skill.object-clue}
义项：借动作的对象判断词义
领域：阅读技能
要诀：把动词和它后面的人或物一起读。
讲解：动词可以有好几个意思，所接的是信、箱子还是车船，往往能排除其中几种。
例句：p.l1.3.r2

## 知识点：看事情的结果 {#skill.result-clue}
义项：用后文发生的事检验词义
领域：阅读技能
要诀：如果这个词这样读，后面那件事还会发生吗？
讲解：原文指出长短已经分明，就要找一种能得出长短的办法。
例句：p.l1.3.r1

## 原文：古籍引文 {#p.l1.3.r1}
> 权，然后知轻重；度，然后知长短。
译文：用秤称过才知道轻重，用尺量过才知道长短。
词注：权：用秤称量。
  度：读 duó，用尺等量长短。
  然后：这样以后，先动手量，才有后面的判断。

## 原文：教学例句 {#p.l1.3.r2}
> 客发木匣，中有故人书。读毕，仍置匣中，合而藏之。
译文：客人打开木匣，里面有老友的信。他读完仍把信放回匣中，合上收藏起来。
词注：发：打开，这里被打开的是一只木匣。
  故人：旧日的朋友。
  毕：完，读毕便是读完。

## 原文：教学例句 {#p.l1.3.r3}
> 舟横溪上，以绳系岸。樵者解其绳，舟乃离岸。既渡，复系之。
译文：船横在溪上，用绳子系在岸边。打柴人解开绳索，船才离岸。过溪后，他又把船拴好。
词注：樵者：打柴的人，“樵”读 qiáo。
  乃：才，船拴着时还不能离岸。
  复：再一次，船过溪后要重新系好。

## 单选：这里的“权”，是哪种可以见到结果的动作？ {#q.l1.3.1}
考点：skill.result-clue
语境：p.l1.3.r1

- [x] 拿东西称一称 {#q.l1.3.1.o1}
  理由：跟“轻重”对应的动作是称量，这里“权”用作动词。
- [ ] 估量事情的重要与否 {#q.l1.3.1.o2}
  理由：“轻重”也能打比方，但与下句量长短并排读，两句说的都是实测。
- [ ] 用尺量一件东西的尺寸 {#q.l1.3.1.o3}
  理由：尺寸与下一句的“长短”相合，“权”的结果却是知道轻重。

提示：每句的“然后知”后面都点出了结果。
解析：跟“轻重”对应的动作是称量，这里“权”用作动词。

## 找原文证据：暂且不查“度”，下文哪一处能帮助你读懂它？ {#q.l1.3.2}
考点：skill.result-clue
语境：p.l1.3.r1

- [x] 长短 {#q.l1.3.2.o1}
  理由：看出长短要经过测量，所以这里“度”读 duó，是量一量。
- [ ] 权 {#q.l1.3.2.o2}
  理由：“权”领起前半句的动作；要读懂“度”，还得看后半句给出的结果。
- [ ] 知轻重 {#q.l1.3.2.o3}
  理由：知道轻重，是称量以后的收获。后面换了“度”，收获也随之换了。

提示：读“度”所在的后半句。
解析：看出长短要经过测量，所以这里“度”读 duó，是量一量。

## 单选：“发木匣”的“发”，在这段话里是什么动作？ {#q.l1.3.3}
考点：skill.object-clue
语境：p.l1.3.r2

- [x] 打开 {#q.l1.3.3.o1}
  理由：匣子先打开，随后合上。这对动作把“发”的意思限定为打开。
- [ ] 寄出 {#q.l1.3.3.o2}
  理由：寄走木匣，客人就没法随即取信读了。
- [ ] 把里面的信分发给众人 {#q.l1.3.3.o3}
  理由：紧跟“发”的是木匣；信读完就放回原处，并没分给旁人。

提示：木匣的下一次动作是“合”。
解析：匣子先打开，随后合上。这对动作把“发”的意思限定为打开。

## 找原文证据：如果要补出“发”的对象，原文该选哪一处？ {#q.l1.3.4}
考点：skill.object-clue
语境：p.l1.3.r2

- [x] 木匣 {#q.l1.3.4.o1}
  理由：“木匣”是装信的容器。“发木匣”和下文“合”说的是同一只匣子。
- [ ] 中有 {#q.l1.3.4.o2}
  理由：这是接下来说里面有什么，还没有给物件取名。
- [ ] 故人 {#q.l1.3.4.o3}
  理由：“故人”说明信来自老朋友，并非被打开的物件。

提示：看“发”的后面。
解析：“木匣”是装信的容器。“发木匣”和下文“合”说的是同一只匣子。

## 单选：若读成“把匣子送走”，后面哪一动作最先讲不通？ {#q.l1.3.5}
考点：skill.result-clue
语境：p.l1.3.r2

- [ ] 老朋友的信收在匣里 {#q.l1.3.5.o1}
  理由：信也能跟匣子一起寄出。真正说不通的是匣子离手后，客人还能做什么。
- [ ] 客人遇到了这只木匣 {#q.l1.3.5.o2}
  理由：这与送不送走并没有冲突。看看原文接着写客人如何对待里面的信。
- [x] 客人随即读了匣中的来信 {#q.l1.3.5.o3}
  理由：信就在匣里。原文中间没有收信或追回匣子的动作，他应当是打开了它。

提示：要“读毕”，得先拿到什么？
解析：信就在匣里。原文中间没有收信或追回匣子的动作，他应当是打开了它。

## 单选：樵者“解”的是什么，又为什么要解？ {#q.l1.3.6}
考点：skill.object-clue
语境：p.l1.3.r3

- [ ] 把船系得更紧，等过溪再解 {#q.l1.3.6.o1}
  理由：“舟乃离岸”紧跟在“解”后，船已经可以走；重新系紧是在渡完以后。
- [x] 解开拴船的绳，让船能走 {#q.l1.3.6.o2}
  理由：被解开的东西是绳子。它原来拴着船，绳松了船才离岸。
- [ ] 叫岸上的人替他松绳 {#q.l1.3.6.o3}
  理由：句首写出“樵者”，解绳的就是他；没有写他吩咐旁人。

提示：在“解”后找手里能碰到的东西。
解析：被解开的东西是绳子。它原来拴着船，绳松了船才离岸。

## 找原文证据：哪一处是绳子已经解开的直接结果？ {#q.l1.3.7}
考点：skill.result-clue
语境：p.l1.3.r3

- [ ] 舟横溪上 {#q.l1.3.7.o1}
  理由：开头写的是还没出发时船停在溪上的样子。
- [ ] 复系之 {#q.l1.3.7.o2}
  理由：这是已经过溪之后，又把船拴好。
- [x] 舟乃离岸 {#q.l1.3.7.o3}
  理由：“舟乃离岸”写解绳带来的结果，说明原先是绳子把船留在岸边。

提示：“乃”在这里是“这才”。
解析：“舟乃离岸”写解绳带来的结果，说明原先是绳子把船留在岸边。

## 排序：从停船到渡过溪，樵者先后怎样做？ {#q.l1.3.8}
考点：skill.object-clue
语境：p.l1.3.r3

- [3] 过溪后把船重新拴住 {#q.l1.3.8.o1}
  理由：“既渡”说明人和船已经到了另一侧。
- [1] 解开系船的绳 {#q.l1.3.8.o2}
  理由：绳先松开，船才能离岸，渡完再拴好。前后两个系绳的位置不同。
- [2] 离岸渡溪 {#q.l1.3.8.o3}
  理由：“乃”表明离岸在解绳以后。

提示：开头那根绳连着船与岸。
解析：绳先松开，船才能离岸，渡完再拴好。前后两个系绳的位置不同。
