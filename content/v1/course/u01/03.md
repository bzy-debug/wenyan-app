# 课文：根据上下文判断词义 {#l1.3}
简介：字有不认识的，可以往下多读半句：装满的水瓮、升上来的木桶，都能帮你读懂前面的动作。

## 正文

试读这句教学例句：“童汲水，满瓮而归。”即使不认识“汲”，也知道孩子回家时水瓮已经满了。往前看，他对水做了什么才能装满一瓮？“打水”说得通，“喝水”就难解释。

再试一句教学例句：“引索，桶乃升。”“索”是绳子。桶升上来了，那人是松手，还是在拉绳？用后半句读懂前半句，比单记一个“引”字更容易记住。

有时，相邻两句话还会互相帮忙。《孟子》把轻重和长短并排来写。先从你认得的一边读起，再去认另一边的动作。

## 知识点：搭配 {#skill.object-clue}
义项：从动作对象辨义
领域：阅读技能
要诀：先看手上拿的是什么。
讲解：“童举石，置之于案”，孩子后来把石头放上桌。连着手里的石头读，“举”就能读成举起。
例句：p.ex.object-clue

## 知识点：下文 {#skill.result-clue}
义项：用后果验证词义
领域：阅读技能
要诀：往后读一句，看发生了什么。
讲解：“樵者释担，肩乃轻”，砍柴人肩头一轻，你便知道他把担子放下来了。
例句：p.ex.result-clue

## 原文：教学例句 {#p.ex.object-clue}
> 童举石，置之于案。
译文：孩子举起石头，把它放在桌上。

## 原文：教学例句 {#p.ex.result-clue}
> 樵者释担，肩乃轻。
译文：砍柴人放下担子，肩上才轻松了。

## 原文：教学例句 {#p.l1.3.water}
> 童汲井水，注之于瓮。
译文：孩子打了井水，把水倒进大瓮里。

## 单选：“注之于瓮”的“注”是哪种动作？ {#q.l1.3.1}
考点：skill.object-clue
语境：p.l1.3.water

- [x] 倒入 {#q.l1.3.1.o1}
- [ ] 注解 {#q.l1.3.1.o2}
  理由：“之”指井水，井水能加注解吗？
- [ ] 注视 {#q.l1.3.1.o3}
  理由：光靠看，能把井水装进瓮里吗？

提示：这里的“之”指井水。水怎样才能进瓮？
解析：孩子先打水，接着把井水倒进瓮里。“注”的意思要连着水和装水的瓮来读。

## 原文：教学例句 {#p.l1.3.untie}
> 舟人解缆，舟乃离岸。
译文：船夫解开缆绳，船才离岸。

## 找原文证据：解缆之后，船怎么样了？ {#q.l1.3.2}
考点：skill.result-clue
语境：p.l1.3.untie

- [x] 舟乃离岸 {#q.l1.3.2.o1}
- [ ] 缆 {#q.l1.3.2.o2}
  理由：缆是系船的绳子。解开以后，再看船的位置。
- [ ] 舟人 {#q.l1.3.2.o3}
  理由：舟人是解缆的人；要找的是后来的变化。

提示：找“乃”引出的变化。
解析：缆绳解开，船这才能离开岸边。“乃”把先后两件事接在一起。

## 原文：教学例句 {#p.l1.3.door}
> 父启户，月光入室。
译文：父亲打开门，月光照进室内。

## 单选：月光照进屋以前，父亲对门做了什么？ {#q.l1.3.3}
考点：skill.result-clue
语境：p.l1.3.door

- [x] 打开门 {#q.l1.3.3.o1}
- [ ] 关上门 {#q.l1.3.3.o2}
  理由：关上门和月光进屋，这两件事相合吗？
- [ ] 修补门 {#q.l1.3.3.o3}
  理由：前文有没有交代门坏了？

提示：月光随后照了进来，门是开了还是关了？
解析：门一开，月光才照进屋。“启户”就是开门。

## 原文：教学例句 {#p.l1.3.weave}
> 妇持针，穿线于针孔。
译文：女子拿着针，把线穿过针孔。

## 单选：这里的“穿”该如何解释？ {#q.l1.3.4}
考点：skill.object-clue
语境：p.l1.3.weave

- [x] 使线通过小孔 {#q.l1.3.4.o1}
- [ ] 凿开岩石 {#q.l1.3.4.o2}
  理由：针孔已经存在，还要凿开什么？
- [ ] 穿上衣服 {#q.l1.3.4.o3}
  理由：找一找：穿过针孔的究竟是哪样东西？

提示：把“穿”和紧接的名词连读。
解析：女子手上有针，让线从针孔里穿了过去。“穿”的东西是线。

## 单选：“度”能知长短。照后半句的读法，前面的“权”该怎样讲？ {#q.l1.3.5}
考点：skill.result-clue
语境：p.l1.3.ice

- [ ] “权”是掌权，因为可以决定物品贵贱 {#q.l1.3.5.o1}
  理由：“轻重”相应的是物的重量还是贵贱？
- [ ] “权”是量长度，因为后面有“长短” {#q.l1.3.5.o2}
  理由：“权”与“度”各接哪一个“然后知”？
- [x] “权”是称量，因为它的结果是知道轻重 {#q.l1.3.5.o3}
  理由：“权”与“度”位置对应，轻重与长短分别检验前一动作。

提示：把“轻重”和“长短”分别放回前面的小句里。
解析：量过才知道长短，称过才知道轻重。“权”正好对着“轻重”，说的是称量。

## 原文：教学例句 {#p.l1.3.net}
> 渔者举网，网中有鱼。
译文：渔人提起渔网，网里面有鱼。

## 找原文证据：渔人举起了什么？ {#q.l1.3.6}
考点：skill.object-clue
语境：p.l1.3.net

- [ ] 鱼 {#q.l1.3.6.o1}
  理由：鱼在网里。渔人直接提起的是哪件东西？
- [x] 网 {#q.l1.3.6.o2}
  第几处：1
- [ ] 渔者 {#q.l1.3.6.o3}
  理由：渔者是提东西的人。看他手中之物。

提示：顺着渔人的手想：他先提起什么，才看见鱼？
解析：先提起的是网，鱼在网里。“网”直接接在“举”后。

## 原文：教学例句 {#p.l1.3.fuel}
> 薪尽火灭，室复暗。
译文：柴烧尽，火熄了，屋里又暗下来。

## 单选：火“灭”了，从屋里能看到什么变化？ {#q.l1.3.7}
考点：skill.result-clue
语境：p.l1.3.fuel

- [ ] 柴还有很多 {#q.l1.3.7.o1}
  理由：“尽”说明柴是多了还是少了？
- [ ] 屋里亮起来 {#q.l1.3.7.o2}
  理由：“复暗”中的“暗”形容怎样的光线？
- [x] 屋里暗下来 {#q.l1.3.7.o3}

提示：看火的变化给屋内带来什么结果。
解析：屋里又暗下来，说明方才的火光已经消失了。

## 原文：教学例句 {#p.l1.3.ink}
> 生磨墨，濡笔而书。
译文：学生磨墨，把笔蘸湿后写字。

## 单选：“濡笔”的“濡”在这里应指什么？ {#q.l1.3.8}
考点：skill.object-clue
语境：p.l1.3.ink

- [ ] 折断笔 {#q.l1.3.8.o1}
  理由：把笔折断，还能接着“书”吗？
- [x] 把笔蘸湿 {#q.l1.3.8.o2}
- [ ] 晾干笔 {#q.l1.3.8.o3}
  理由：磨墨和写字之间为什么还要处理笔尖？

提示：联系前面的墨和后面的书写。
解析：先磨墨，后写字，中间还得让笔尖蘸上墨。“濡笔”就写了这一步。
