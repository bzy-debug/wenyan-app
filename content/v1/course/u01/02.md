# 课文：一字两用：是动作，还是东西？ {#l1.2}
简介：送信、分饭、走山路，同一个字换个位置，就可能要换个意思读。

## 正文

看教学短文里的一双手：旅客把“一书”交给驿吏，驿吏“书客名于册”。第一处的“书”可以拿在手里，第二处的“书”却是提笔记下。若都读成“信”，就解释不了姓名是怎么进册的。

换成别的字也可以这样试。我们今天说“饭来了”和“吃饭了”，一个是端来的东西，一个是人做的事。古文有时用同一个“食”来讲这两件不同的事。读到后面的“道”和“衣”，先把它们放回句中，问问是人做了什么，还是地上、手中有件什么。

## 知识点：动作与名物 {#skill.word-role}
义项：从句中位置辨认一个字指东西还是写动作
领域：阅读技能
要诀：看它能否被拿在手里，或能否接上做事的对象。
讲解：“一书”的“书”可以计数。“书客名”里姓名已经是所记的事物，“书”就要读成落笔记录。
例句：p.l1.2.r1

## 知识点：同字换义 {#skill.sense-evidence}
义项：从搭配或上下句找出同一个字需要换义的依据
领域：阅读技能
要诀：若两处都用同一个意思，哪一处先读不通？
讲解：“低头看道”说的是脚下有路，“道其故”后面却跟着可以开口说明的原因。
例句：p.l1.2.r4

## 原文：教学例句 {#p.l1.2.r1}
> 客以一书付吏。吏书客名于册，使卒持书行。
译文：旅客把一封信交给驿吏。驿吏在册子上记下旅客的姓名，派驿卒带信上路。
词注：付：交给。
  册：用来登记姓名的簿册。

## 原文：古籍引文 {#p.l1.2.r2}
> 一箪食，一瓢饮，在陋巷。人不堪其忧，回也不改其乐。
译文：一竹筐饭，一瓢水，住在简陋的巷子里。旁人受不了那种清苦，颜回依旧不改自己的乐趣。
词注：箪：读 dān，盛饭的竹器。
  堪：受得住。
  陋巷：简陋的街巷，此处指住处清贫。

## 原文：教学例句 {#p.l1.2.r3}
> 庖人出食，客取一饼食之，余以与童子。
译文：厨师端出食物，客人拿一张饼吃了，其余的给孩子。
词注：庖人：厨师，“庖”读 páo。
  余：剩下的，指客人取饼以后余下的食物。

## 原文：教学例句 {#p.l1.2.r4}
> 雨后山崩，石塞山道。客不得行，归而道其故。乡人闻之，相与除石。
译文：雨后山体崩塌，石块堵住山路。旅客走不过去，回来说明缘故。乡人听说后，一同去搬石头。
词注：塞：堵住。“石塞山道”是石块把路堵住了。
  其故：其中的缘故，指眼前这条路为什么走不通。
  相与：一同，乡人一起去搬石块。

## 原文：教学例句 {#p.l1.2.r5}
> 雪暮不止。客衣短裘而来。既入室，解衣近火，衣上雪乃消。
译文：到了傍晚，雪还是不停。客人穿着短皮衣前来。进屋后，他脱下衣服靠近火，衣上的雪这才化了。
词注：裘：皮衣，读 qiú。
  既：已经，“既入室”是进屋以后。

## 单选：驿卒动身以后，驿站里留下了什么记录？ {#q.l1.2.1}
考点：skill.word-role
语境：p.l1.2.r1

- [x] 簿册上写着旅客的姓名 {#q.l1.2.1.o1}
  理由：“书”在这里指写下，“客名”是留下的内容。随后送走的是信。
- [ ] 旅客自己写的一张收信凭证 {#q.l1.2.1.o2}
  理由：“吏书”写的是驿吏动笔，旅客只交了一封信。
- [ ] 簿册上抄着信里的原话 {#q.l1.2.1.o3}
  理由：“书客名”写明所记的是人名，没有说抄信。

提示：把“书客名”读成某个人做的一件事。
解析：“书”在这里指写下，“客名”是留下的内容。随后送走的是信。

## 找原文证据：哪处“书”连着前面的字一起读，明明白白是一件可以计数的东西？ {#q.l1.2.2}
考点：skill.sense-evidence
语境：p.l1.2.r1

- [ ] 持书行 {#q.l1.2.2.o1}
  理由：这也能读出手中拿着信，不过这处交代的是携带，并没有数它。
- [ ] 吏书客名 {#q.l1.2.2.o2}
  理由：吏后面的“书”说他提笔记录，紧跟其后的是姓名。
- [x] 一书 {#q.l1.2.2.o3}
  理由：“一书”就是一封信。换到“书客名”中，这个字所处的位置与意思都变了。

提示：原文哪里直接给出了数量？
解析：“一书”就是一封信。换到“书客名”中，这个字所处的位置与意思都变了。

## 单选：把“一箪食”和“一瓢饮”并排读，颜回眼前有什么？ {#q.l1.2.3}
考点：skill.sense-evidence
语境：p.l1.2.r2

- [x] 竹筐里的饭，瓢里的水 {#q.l1.2.3.o1}
  理由：两项各有容器，配起来是少量饭和水。此处的“食”是饭食，古文也能用它写吃的动作。
- [ ] 他先吃了一次，再喝了一次 {#q.l1.2.3.o2}
  理由：“箪”和“瓢”是容器，两句一同交代日常所有。
- [ ] 他天天都要挨饿，一口粮食也没有 {#q.l1.2.3.o3}
  理由：住处和饮食确实清贫，可“一箪食”仍说他有一竹筐饭。

提示：“箪”是竹器，“瓢”是舀水的用具。
解析：两项各有容器，配起来是少量饭和水。此处的“食”是饭食，古文也能用它写吃的动作。

## 单选：同一顿饭里，厨师“出食”，客人“食之”。两人各做了什么？ {#q.l1.2.4}
考点：skill.word-role
语境：p.l1.2.r3

- [x] 厨师端出食物，客人拿饼来吃 {#q.l1.2.4.o1}
  理由：前一个“食”能被厨师端出来；后一个“食”后面接“之”，指客人吃下手中的饼。
- [ ] 厨师出门吃饭，客人拿饼给厨师吃 {#q.l1.2.4.o2}
  理由：后半说客人自己取饼，“余”才给了孩子。
- [ ] 厨师已经吃过，客人只把饼递给孩子 {#q.l1.2.4.o3}
  理由：“食之”在“余以与童子”以前；给孩子的是余下的。

提示：谁端出东西，谁“取一饼”？
解析：前一个“食”能被厨师端出来；后一个“食”后面接“之”，指客人吃下手中的饼。

## 单选：石块堵住了什么？“归而道其故”的客人又做了什么？ {#q.l1.2.5}
考点：skill.word-role
语境：p.l1.2.r4

- [ ] 堵住山路；客人沿原路折返 {#q.l1.2.5.o1}
  理由：“归”已经说了返回。接在“道”后面的是缘故，不是另一段路。
- [x] 堵住山路；客人回去说明缘故 {#q.l1.2.5.o2}
  理由：“山道”就是山路；“道其故”是讲出为什么走不过去。同样的字，有时是路，有时是开口说。
- [ ] 挡住客人说话；客人回去寻找山路 {#q.l1.2.5.o3}
  理由：“不得行”说明受阻的是行路，“乡人闻之”才涉及说与听。

提示：两处“道”，一处紧接“山”，一处后面跟“其故”。
解析：“山道”就是山路；“道其故”是讲出为什么走不过去。同样的字，有时是路，有时是开口说。

## 找原文证据：就算暂时不懂“道其故”，哪一处能说明旅客已经把事情说了出来？ {#q.l1.2.6}
考点：skill.sense-evidence
语境：p.l1.2.r4

- [ ] 客不得行 {#q.l1.2.6.o1}
  理由：这是旅客受阻，还没人知道他回去会做什么。
- [x] 乡人闻之 {#q.l1.2.6.o2}
  理由：乡人后来听说此事，说明客人回去作了讲述。“道”在此处不能还当作一条路。
- [ ] 石塞山道 {#q.l1.2.6.o3}
  理由：这里点明路不通的原因，还没写乡人得到消息。

提示：找发话后听话一方的反应。
解析：乡人后来听说此事，说明客人回去作了讲述。“道”在此处不能还当作一条路。

## 单选：客人“衣短裘而来”。从这句话能画出怎样一个人？ {#q.l1.2.7}
考点：skill.word-role
语境：p.l1.2.r5

- [ ] 他把皮衣抱在怀里带来 {#q.l1.2.7.o1}
  理由：后文写他进屋后“解衣”，可见这件皮衣是穿在身上的。
- [x] 他身上穿着一件短皮衣 {#q.l1.2.7.o2}
  理由：第一个“衣”读 yì，意思是穿着。后文他进屋脱下的正是身上的衣物。
- [ ] 他到屋里才换上短皮衣 {#q.l1.2.7.o3}
  理由：“而来”说的就是前来时的情形；“既入室”在后。

提示：短裘是件衣物，它前面的“衣”得读成人的动作。
解析：第一个“衣”读 yì，意思是穿着。后文他进屋脱下的正是身上的衣物。

## 找原文证据：开头的“衣”是穿着，后来哪一处明说衣服上还覆着东西？ {#q.l1.2.8}
考点：skill.sense-evidence
语境：p.l1.2.r5

- [ ] 短裘 {#q.l1.2.8.o1}
  理由：这个名称只说明衣物长短和材质。
- [ ] 解衣 {#q.l1.2.8.o2}
  理由：这是脱下衣物的动作，尚未说明衣上有什么。
- [x] 衣上雪 {#q.l1.2.8.o3}
  理由：“衣上雪”是衣服上的雪。“衣”在这里读 yī，指能落上雪的那件衣物。

提示：找写雪最后在哪里融化的一句。
解析：“衣上雪”是衣服上的雪。“衣”在这里读 yī，指能落上雪的那件衣物。
