# 检查：把熟字放回句子里 {#check.1}

## 原文：教学例句 {#p.check.1.news}
> 夜半闻叩门声，主人披衣出。
译文：半夜听见敲门声，主人披上衣服出门。

## 单选：主人为何披衣出门？ {#q.check.1.1}
考点：skill.hear
语境：p.check.1.news

- [ ] 闻到门外气味 {#q.check.1.1.o1}
  理由：原句点出的是敲门的声音。
- [x] 听到有人敲门 {#q.check.1.1.o2}
- [ ] 收到一封书信 {#q.check.1.1.o3}
  理由：主人是听到动静，还是看到有人递信？

提示：看看“闻”所接的名词。
解析：“叩门声”是敲门的响声。半夜听到这声音，主人才披衣出去。

## 找原文证据：士卒丢盔弃甲后逃跑了。哪个字表示“逃跑”？ {#q.check.1.2}
考点：skill.run
语境：p.check.1.field

- [x] 走 {#q.check.1.2.o1}
  理由：“走”与下文不等的逃跑距离相照应。
- [ ] 曳 {#q.check.1.2.o2}
  理由：“曳”的对象是兵器。哪个字写士卒奔逃？
- [ ] 止 {#q.check.1.2.o3}
  理由：“止”写的是停下。往前找停下之前的动作。
  第几处：1

提示：先读“弃甲”“曳兵”，再看士卒自己怎样逃开。
解析：兵是手里拖着的兵器，“曳”写怎样带着它。“走”写人逃跑。后面两句才分别说跑了多远。

## 原文：教学例句 {#p.check.1.inn}
> 客去驿，驿吏独守空舍。
译文：旅客离开驿站，驿吏独守空屋。

## 单选：由“空舍”推断，“去驿”指什么？ {#q.check.1.3}
考点：skill.leave
语境：p.check.1.inn

- [ ] 修建驿站 {#q.check.1.3.o1}
  理由：原文里有没有动工修建的迹象？
- [x] 离开驿站 {#q.check.1.3.o2}
- [ ] 前往驿站 {#q.check.1.3.o3}
  理由：旅客若正在进驿，屋里怎么空了？

提示：看驿吏身旁是否还有旅客。
解析：只剩驿吏守着空屋，可见旅客已经离开驿站。

## 原文：教学例句 {#p.check.1.sign}
> 主人削木为牌，书价于其上。
译文：主人削木做牌，把价格写在上面。

## 单选：读“书价于其上”，其中的“书”指物件，还是写东西的动作？ {#q.check.1.4}
考点：skill.write
语境：p.check.1.sign

- [ ] 名词，图书 {#q.check.1.4.o1}
  理由：“价”在牌上。把“书”读成书本试试看。
- [x] 动词，表示写上 {#q.check.1.4.o2}
- [ ] 名词，信函 {#q.check.1.4.o3}
  理由：这里交代了收信人，还是写价格的位置？

提示：读“价”与“其上”。
解析：“价”是落笔写下的字，“其上”是木牌上。“书价”就是写上价钱。

## 原文：教学例句 {#p.check.1.letter}
> 子书至，母启而读之，乃知子安。
译文：儿子的信到了，母亲拆开阅读，才知道儿子平安。

## 排序：儿子的消息怎样传到母亲这里？按先后排列。 {#q.check.1.5}
考点：skill.letter
语境：p.check.1.letter

- [2] 打开并阅读 {#q.check.1.5.o1}
  理由：母亲启读的是怎样到她手里的？
- [1] 收到儿子的信 {#q.check.1.5.o2}
  理由：“至”说信到了，此时母亲已经读过了吗？
- [3] 得知儿子平安 {#q.check.1.5.o3}
  理由：母亲是凭哪项消息才知道儿子平安的？

提示：“乃知”表示最后得知的事情。
解析：信到了，母亲才拆信来读；“乃知”接着写她读信后得知儿子平安。

## 原文：教学例句 {#p.check.1.window}
> 童掩窗，风不复入。
译文：孩子关上窗，风不再吹进来。

## 找原文证据：孩子掩窗后发生了什么？找出能说明窗已关上的话。 {#q.check.1.6}
考点：skill.result-clue
语境：p.check.1.window

- [ ] 童 {#q.check.1.6.o1}
  理由：孩子是掩窗的人，关窗后发生了什么？
- [x] 风不复入 {#q.check.1.6.o2}
- [ ] 窗 {#q.check.1.6.o3}
  理由：窗是动作对象。再看关窗的结果。

提示：找发生在掩窗之后的变化。
解析：窗关上以后，风就吹不进屋了。“不复入”写的正是这个变化。
