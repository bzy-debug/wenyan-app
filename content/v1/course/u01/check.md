# 检查：古今词义综合检查 {#check.1}

## 原文：教学例句 {#p.check.1.news}
> 夜半闻叩门声，主人披衣出。
译文：半夜听见敲门声，主人披上衣服出门。

## 单选：主人为何起身出门？ {#q.check.1.1}
考点：skill.hear
语境：p.check.1.news

- [ ] 闻到门外气味 {#q.check.1.1.o1}
  理由：“叩门声”是听觉对象。
- [x] 听到有人敲门 {#q.check.1.1.o2}
- [ ] 收到一封书信 {#q.check.1.1.o3}
  理由：句中没有信件或送信人。

提示：看看“闻”所接的名词。
解析：“闻”以敲门的声音为对象，应解为听见。

## 选段：士卒丢盔弃甲，跑出几十步才停。点选原文直接表示奔逃的字。 {#q.check.1.2}
考点：skill.run
语境：p.check.1.field

- [x] 走 {#q.check.1.2.o1}
  理由：“走”与下文不等的逃跑距离相照应。
- [ ] 曳 {#q.check.1.2.o2}
  理由：“曳兵”是拖着兵器，它写移动兵器的方式。
- [ ] 止 {#q.check.1.2.o3}
  第几处：1
  理由：“止”是奔逃结束时的动作。

提示：把先前所带的装备与人所做的位移动作分开。
解析：“弃甲”写丢下盔甲，“曳兵”写拖着兵器；“走”才是逃跑。两种距离不同，逃跑这一动作相同。

## 原文：教学例句 {#p.check.1.inn}
> 客去驿，驿吏独守空舍。
译文：旅客离开驿站，驿吏独守空屋。

## 单选：由“空舍”推断，“去驿”指什么？ {#q.check.1.3}
考点：skill.leave
语境：p.check.1.inn

- [ ] 修建驿站 {#q.check.1.3.o1}
  理由：句中没有工匠和营建过程。
- [x] 离开驿站 {#q.check.1.3.o2}
- [ ] 前往驿站 {#q.check.1.3.o3}
  理由：若正进入，便与留下空屋的结果不合。

提示：看驿吏身旁是否还有旅客。
解析：“独守空舍”说明旅客已经离开。

## 原文：教学例句 {#p.check.1.sign}
> 主人削木为牌，书价于其上。
译文：主人削木做牌，把价格写在上面。

## 单选：“书价”中“书”起什么作用？ {#q.check.1.4}
考点：skill.write
语境：p.check.1.sign

- [ ] 名词，图书 {#q.check.1.4.o1}
  理由：“于其上”说明把价格写在牌上。
- [x] 动词，表示写上 {#q.check.1.4.o2}
- [ ] 名词，信函 {#q.check.1.4.o3}
  理由：这里记的是价格，没有寄信的双方。

提示：读“价”与“其上”。
解析：价是写下的内容，木牌是书写位置。

## 原文：教学例句 {#p.check.1.letter}
> 子书至，母启而读之，乃知子安。
译文：儿子的信到了，母亲拆开阅读，才知道儿子平安。

## 排序：按情节排列事件。 {#q.check.1.5}
考点：skill.letter
语境：p.check.1.letter

- [2] 打开并阅读 {#q.check.1.5.o1}
- [1] 收到儿子的信 {#q.check.1.5.o2}
- [3] 得知儿子平安 {#q.check.1.5.o3}

提示：“乃知”表示最后得知的事情。
解析：先是信到，接着启读，才由信的内容得知近况。

## 原文：教学例句 {#p.check.1.window}
> 童掩窗，风不复入。
译文：孩子关上窗，风不再吹进来。

## 选段：哪处结果让你能确定“掩”是关上？ {#q.check.1.6}
考点：skill.result-clue
语境：p.check.1.window

- [ ] 童 {#q.check.1.6.o1}
  理由：这是关窗的人。
- [x] 风不复入 {#q.check.1.6.o2}
- [ ] 窗 {#q.check.1.6.o3}
  理由：这是关的对象。

提示：找发生在掩窗之后的变化。
解析：风不再进来，说明窗被关上了。
