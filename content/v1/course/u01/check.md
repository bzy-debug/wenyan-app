# 检查：夜间一封信，战场两段路 {#check.1}

## 原文：教学例句 {#p.check.1.r1}
> 吏守驿门，闻马嘶，启门。有使者至，出一书，曰：“请速送县。”吏书其至时于册，乃遣人走送之。
译文：小吏守着驿门，听见马叫，便开门。一位使者到了，取出一封信，请他赶紧送到县里。小吏在簿册上记下使者到达的时间，才派人跑去送信。
词注：嘶：马叫。
  使者：受人派遣来传达事情的人。
  遣：派人去办事。

## 原文：古籍引文 {#p.check.1.r2}
> 弃甲曳兵而走。或百步而后止，或五十步而后止。
译文：士兵丢掉铠甲，拖着兵器逃跑。有的跑了一百步才停，有的跑了五十步才停。
词注：甲：护身用的铠甲。
  曳：拖着，读 yè。
  兵：兵器，指逃跑时手里拖的东西。
  或：有的人；两处“或”说的是两批士兵。

## 找原文证据：什么声音把守门小吏引到门边？ {#q.check.1.1}
考点：skill.hear
语境：p.check.1.r1

- [ ] 使者至 {#q.check.1.1.o1}
  理由：这是门开时到达的人。
- [x] 马嘶 {#q.check.1.1.o2}
  理由：“嘶”指马叫。听到马叫在前，开门见到使者在后。
- [ ] 速送县 {#q.check.1.1.o3}
  理由：这是使者开口提出的要求，门已经打开了。

提示：从“闻”读到“启门”。
解析：“嘶”指马叫。听到马叫在前，开门见到使者在后。

## 单选：同一段里还写到簿册，怎么知道使者拿出的是另一件东西？ {#q.check.1.2}
考点：skill.sense-evidence
语境：p.check.1.r1

- [x] “一书”是使者交来要送往县里的 {#q.check.1.2.o1}
  理由：使者先交信，小吏再派人传送。一路传送的是一封书信。
- [ ] 簿册是使者交给驿站留底的 {#q.check.1.2.o2}
  理由：簿册在后文，是小吏记时用的。
- [ ] 送往县里的，是小吏刚写下的到达时刻 {#q.check.1.2.o3}
  理由：小吏还没登记，使者已经把“一书”拿了出来，送的是信。

提示：跟踪“请速送县”所说的东西。
解析：使者先交信，小吏再派人传送。一路传送的是一封书信。

## 找原文证据：小吏在册上写下了哪项内容？ {#q.check.1.3}
考点：skill.word-role
语境：p.check.1.r1

- [ ] 一书 {#q.check.1.3.o1}
  理由：信要送走，小吏另用簿册登记。
- [x] 其至时 {#q.check.1.3.o2}
  理由：“其至时”指使者到达的时间。“书”后面的这项内容就是记录的对象。
- [ ] 驿门 {#q.check.1.3.o3}
  理由：驿门是值守的地方，不是记入册里的内容。

提示：找“书……于册”中间那几字。
解析：“其至时”指使者到达的时间。“书”后面的这项内容就是记录的对象。

## 排序：把信与簿册分开看，小吏怎样办理这件事？ {#q.check.1.4}
考点：skill.object-clue
语境：p.check.1.r1

- [2] 在簿册登记到达时间 {#q.check.1.4.o1}
  理由：小吏得先见到来人，才有到达时间可记。
- [1] 开门迎来使者 {#q.check.1.4.o2}
  理由：使者到站，小吏先登记时间，信随后由专人送走。
- [3] 派人把信送往县里 {#q.check.1.4.o3}
  理由：“乃”说明派人发生在登记之后。

提示：哪些文字留下，哪件东西送走？
解析：使者到站，小吏先登记时间，信随后由专人送走。

## 单选：“而走”的士兵当时怎样离开战场？ {#q.check.1.5}
考点：skill.run
语境：p.check.1.r2

- [ ] 整队缓慢前进 {#q.check.1.5.o1}
  理由：“弃甲曳兵”写的是慌忙逃跑时的样子。
- [x] 扔下铠甲奔逃 {#q.check.1.5.o2}
  理由：丢盔、拖兵器、奔出几十步，连在一起，读得出“走”的急迫。
- [ ] 丢下武器后原地休息 {#q.check.1.5.o3}
  理由：“曳兵”是拖着兵器；他们还跑出了不同距离。

提示：后文把这段路按步数算了出来。
解析：丢盔、拖兵器、奔出几十步，连在一起，读得出“走”的急迫。

## 单选：哪一点足以看出第二批人与第一批人做的是同一件事？ {#q.check.1.6}
考点：skill.result-clue
语境：p.check.1.r2

- [ ] 两批人跑的步数相等 {#q.check.1.6.o1}
  理由：一处是百步，一处是五十步。
- [x] 两批人都是逃出一段路才停 {#q.check.1.6.o2}
  理由：两批人都走而后止。数字只改变逃的距离，没有改变奔逃这件事。
- [ ] 两批人都当场留下了兵器 {#q.check.1.6.o3}
  理由：开头说拖着兵器，没说把兵器也丢在原地。

提示：把两处“而后止”并排读一遍。
解析：两批人都走而后止。数字只改变逃的距离，没有改变奔逃这件事。
