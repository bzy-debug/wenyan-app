# 课文：驿卒夜巡：闻、走、去 {#l1.1}
简介：听见、跑、离开，三个动词带你走过一座快要塌掉的桥。

## 正文

夜里桥头只站着一个驿卒（替驿站办事的人）。读教学短文时，先听他听见的动静，再跟着他走一遍：他赶去告诉谁？最后谁离开了桥？

| 原文 | 当时发生的事 |
| --- | --- |
| 闻水声 | 耳朵先察觉水有动静 |
| 走告里人 | 跑去告诉附近的居民 |
| 众皆去桥 | 大家离开原来的地点 |

今天说“去桥上”，桥通常是目的地。可是这段话接着写桥塌了，人一个也没伤着。读“去桥”时，可以站到桥上想一想：要平安，人该往哪个方向走？

## 知识点：闻 {#skill.hear}
义项：听见声音
领域：实词
要诀：看耳朵听见了什么。
讲解：声音能叫人停步、起身或出门。把“闻”后面的声音和随后的反应连起来。
例句：p.l1.1.r1

## 知识点：走 {#skill.run}
义项：跑
领域：实词
要诀：找找有什么事情让人赶时间。
讲解：“走告”是跑去报信。另有些人“竞走”，彼此争快，未必是为了逃命。
例句：p.l1.1.r2

## 知识点：去 {#skill.leave}
义项：离开原处
领域：实词
要诀：找出人原来站在哪里。
讲解：若下文说那地方空了，或说人已经到了别处，“去”常是离开的意思。
例句：p.l1.1.r3

## 原文：教学例句 {#p.l1.1.r1}
> 夜半，驿卒守桥，闻水声甚急，走告里人。众皆去桥。俄而桥坏，无一人伤。
译文：半夜，驿卒守桥，听见水声很急，跑去告诉附近居民。大家都离开了桥。不一会儿桥塌了，没有人受伤。
词注：驿卒：在驿站当差的人。
  里人：附近的居民。
  俄而：过了不久。

## 原文：古籍引文 {#p.l1.1.r2}
> 王戎七岁，尝与诸小儿游。看道边李树多子折枝，诸儿竞走取之，唯戎不动。人问之，答曰：“树在道边而多子，此必苦李。”取之，信然。
译文：王戎七岁时同一群孩子出游。路边李树果子多得压弯了枝条，孩子们争着跑去摘，只有王戎不动。有人问他，他答说：“树长在路边，竟然还结着这么多果子，一定是苦李。”摘来一尝，果真如此。
词注：诸：众、各个，后面跟的是结伴出游的孩子。
  子：树上结的果实。
  信然：果真如此；尝了李子，才证实先前的判断。

## 原文：教学例句 {#p.l1.1.r3}
> 舟将发，客犹在岸。闻舟子呼，客解所系马，去岸登舟。
译文：船快开了，旅客还在岸上。他听见船夫招呼，解开拴着的马，离开岸边上船。
词注：犹：还，船快开了，旅客仍在岸上。
  舟子：操舟的人，此处是在呼唤旅客的船夫。
  系：拴住，读 jì。

## 找原文证据：守桥的驿卒先听见了什么？ {#q.1}
考点：skill.hear
语境：p.l1.1.r1

- [ ] 夜半 {#q.1.o1}
  理由：“夜半”是当时的时刻，深夜里响起了什么？
- [x] 水声 {#q.1.o2}
  理由：先是水声变急，后来桥才塌。驿卒靠耳朵察觉了危险。
- [ ] 桥坏 {#q.1.o3}
  理由：桥是“俄而”才坏的。驿卒在塌桥以前就跑去报信了。

提示：看“闻”后面紧接的两个字。
解析：先是水声变急，后来桥才塌。驿卒靠耳朵察觉了危险。

## 单选：“走告里人”写谁去报信，又是怎么去的？ {#q.2}
考点：skill.run
语境：p.l1.1.r1

- [x] 跑去给附近的人报信 {#q.2.o1}
  理由：水已经涨急，驿卒奔跑报信，居民这才来得及撤开。
- [ ] 步行去通知附近的居民 {#q.2.o2}
  理由：“水声甚急”，桥眼看就要塌。这里的“走”是跑，不能照今天“走过去”的意思读。
- [ ] 居民跑来给守桥的驿卒报信 {#q.2.o3}
  理由：“闻水声”的是驿卒，接下来“走告”的还是他；“里人”是听他报信的人。

提示：把“走告”和末尾“无一人伤”连起来。
解析：水已经涨急，驿卒奔跑报信，居民这才来得及撤开。

## 单选：第二天问起桥塌时的情形，哪句话与原文相合？ {#q.3}
考点：skill.leave
语境：p.l1.1.r1

- [ ] 大家正在往桥上赶 {#q.3.o1}
  理由：桥坏在“众皆去桥”之后，文末还特意点明无人受伤。
- [x] 大家已经离开桥面 {#q.3.o2}
  理由：“去”是离开。众人先离开，桥随后才坏。
- [ ] 驿卒走了，居民仍在桥上 {#q.3.o3}
  理由：“众皆”说的是众人全都这样做了。

提示：“去桥”前的“众皆”指多少人？
解析：“去”是离开。众人先离开，桥随后才坏。

## 单选：“诸儿竞走取之”写的是什么情景？ {#q.4}
考点：skill.run
语境：p.l1.1.r2

- [ ] 孩子们和王戎赛跑，看谁先到树下 {#q.4.o1}
  理由：“唯戎不动”独把王戎留在原地，奔跑的人里没有他。
- [x] 抢先跑到树下摘李子 {#q.4.o2}
  理由：树上的李子吸引了孩子们，他们争着跑过去取果子。
- [ ] 孩子们拿了李子才沿路赛跑 {#q.4.o3}
  理由：先有“竞走”再说“取之”，他们奔向树是为了摘李子。

提示：“竞走”后面的“取之”说出了目的。
解析：树上的李子吸引了孩子们，他们争着跑过去取果子。

## 找原文证据：哪一处写出与孩子们奔跑相反的举动？ {#q.5}
考点：skill.run
语境：p.l1.1.r2

- [ ] 道边李树 {#q.5.o1}
  理由：这里介绍树长在什么地方，没有写谁动谁不动。
- [ ] 此必苦李 {#q.5.o2}
  理由：这是王戎对果子的判断。找他用动作表态的地方。
- [x] 唯戎不动 {#q.5.o3}
  理由：别人争先，唯独王戎留在原处。“不动”把两种反应分开。

提示：沿着“诸儿竞走取之”往下读一小句。
解析：别人争先，唯独王戎留在原处。“不动”把两种反应分开。

## 单选：谁发出了客人听见的声音？ {#q.6}
考点：skill.hear
语境：p.l1.1.r3

- [ ] 岸上的马 {#q.6.o1}
  理由：马是“系”着的；“呼”的人另有其人。
- [x] 船夫 {#q.6.o2}
  理由：“舟子”是船夫。是他在船上招呼，岸上的客人听见了。
- [ ] 客人 {#q.6.o3}
  理由：“客”先在岸上，听到呼唤后他才解马。

提示：“闻舟子呼”中，谁在“呼”？
解析：“舟子”是船夫。是他在船上招呼，岸上的客人听见了。

## 找原文证据：哪一处交代了客人离岸后做的下一件事？ {#q.7}
考点：skill.leave
语境：p.l1.1.r3

- [ ] 将发 {#q.7.o1}
  理由：“将发”只说船快要开了，客人这时还在岸上。
- [x] 登舟 {#q.7.o2}
  理由：登舟就是上船。“去岸”的岸是离开的地方，船才是接下来到的地方。
- [ ] 解所系马 {#q.7.o3}
  理由：解马是上船之前的准备。

提示：从“去岸”的下一步往回看。
解析：登舟就是上船。“去岸”的岸是离开的地方，船才是接下来到的地方。

## 排序：客人赶船，三件事怎样接在一起？ {#q.8}
考点：skill.hear
语境：p.l1.1.r3

- [2] 解开岸上拴着的马 {#q.8.o1}
  理由：“闻”后才写“解”，先有呼声，再有准备。
- [3] 离岸上船 {#q.8.o2}
  理由：“去岸登舟”排在“解所系马”之后，原文先写解马再写离岸。
- [1] 听到船夫招呼 {#q.8.o3}
  理由：客人起先还在岸上，听到呼声才解马、登舟。

提示：“犹在岸”提醒你，他最初还没登船。
解析：客人起先还在岸上，听到呼声才解马、登舟。
