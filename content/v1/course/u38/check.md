# 检查：用地点与后果核验词义 {#check.38}

## 原文：教学例句 {#check.38.p.market}
> 使者自鲁适齐，越境已三日，今始至国门。守门者导之入市。
译文：使者从鲁前往齐，越过国境已有三天，今天才到国都的城门。守门人领他进了街市。

## 单选：根据这段行程，“国门”最合适指哪里？ {#check.38.q1}
考点：words.skill.guo-capital
语境：check.38.p.market

- [x] 齐国都城的城门
- [ ] 鲁齐两国的国境关卡
  理由：三天前便已越境。
- [ ] 市中某家商铺的门
  理由：过门以后才被领进市中。

提示：分别标出“越境”和“至国门”的时间。
解析：两地相隔数日行程，入门又通街市，所以此处落在都城。

## 原文：教学例句 {#check.38.p.news}
> 盗起东鄙，越界而走。守边之卒逐至界石，不敢复前。
译文：东部边地发生盗事，盗贼越过国界逃走。守边士卒追到界石，不敢再往前。

## 找原文证据：哪一样东西标明追赶已经到了边界？ {#check.38.q2}
考点：words.skill.bi-border
语境：check.38.p.news

- [x] 界石
- [ ] 东鄙
  理由：这是起事的地区名称。
- [ ] 守边之卒
  理由：这是追赶者，并非标记。

提示：找一件可以立在两地交界处的实物。
解析：界石明确标出分界，与“东鄙”的边地含义相互印证。

## 原文：教学例句 {#check.38.p.granary}
> 道闻群盗将至。尉令二卒守东门，非持符者不得入。二卒终夜在门。
译文：路上传来群盗将到的消息。县尉命两名士卒守东门，没有凭符的人不许进。两人整夜在门边。

## 单选：“守东门”这项差事需要他们怎样做？ {#check.38.q3}
考点：words.skill.shou-guard
语境：check.38.p.granary

- [ ] 追出城外捕尽所有盗贼
  理由：士卒整夜在门，任务有明确处所。
- [x] 值守门口并查验进入的人
- [ ] 替无符的人借一面符
  理由：规矩是无符不得入。

提示：找“非持符者”后对出入的要求。
解析：查验与夜间值守是守卫门户的具体内容。

## 原文：教学例句 {#check.38.p.refuge}
> 民避乱于山，寇平，乡里复定。父老遣人招之，避者乃归。
译文：百姓为躲避动乱进了山。盗寇被平定，乡里重新安定。父老派人招呼，避难的人才回来。

## 单选：“乡里复定”怎样解释避难者后来的行动？ {#check.38.q4}
考点：words.skill.ding-settle
语境：check.38.p.refuge

- [x] 家乡安定了，他们才敢回来
- [ ] 山中确定了新住处，所以留下
  理由：末句说“乃归”。
- [ ] 父老为每家定了田界
  理由：文中写的是避乱、寇平和返乡。

提示：找进山时的原因是否已经消除。
解析：乡里从动乱转为安定，使归家成为可能。

## 原文：教学例句 {#check.38.p.rain}
> 父闻子修堤有功，戒曰：“乡人自知之，汝毋伐也。”子默然，未尝言己劳。
译文：父亲听说儿子修堤有功，告诫说：“乡亲自然知道，你不要夸耀。”儿子沉默，从不提自己的辛劳。

## 单选：“毋伐”叫儿子收住什么？ {#check.38.q5}
考点：words.skill.fa-boast
语境：check.38.p.rain

- [ ] 对敌军发起进攻
  理由：原文写修堤与言己劳，并未出现战争。
- [ ] 继续维修堤坝的行动
  理由：父亲说乡人已经知道的是他的功劳。
- [x] 夸说自己修堤的功劳

提示：用“未尝言己劳”验证父亲要求的行为。
解析：“伐”指自夸，儿子不再谈自己的劳绩，回应了告诫。

## 原文：教学例句 {#check.38.p.money}
> 客去年假钱十，今还其六。主人但责所余四钱，客如数偿之。
译文：客人去年借钱十枚，现在还了六枚。主人只索要剩下的四枚，客人如数还清。

## 单选：“责所余四钱”对应哪一个实际动作？ {#check.38.q6}
考点：words.skill.ze-demand
语境：check.38.p.money

- [x] 向客人索还四枚欠钱
- [ ] 因为客人只有四枚钱而斥责他
  理由：“所余”承接十减六的欠额，后文如数偿还。
- [ ] 重新给客人借出四枚钱
  理由：“偿之”写还债，流向是还给主人。

提示：先作十减六，再看“偿”由谁来做。
解析：应还余额和实际偿还数相同，说明“责”是在索取欠款。
