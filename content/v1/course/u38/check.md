# 检查：留种、择竿与孔子论尧 {#check.38}

## 原文：教学例句 {#syn38.0.p.seed}
> 秋，圃人藏瓜子数囊。子之饱满者，别封以待春；瘪者弃之。邻儿攫一囊欲食，圃人曰：“此来岁之种也。”
译文：秋天，种园人收了几袋瓜子。颗粒饱满的，另行封存留到春天；干瘪的便扔掉。邻家的孩子抓起一袋想吃，种园人说：“这是来年留的种子。”
词注：圃人：种园人。
  子：这里指瓜子。
  别封：另外封存。

## 单选：春天要播的瓜子，种园人秋天挑选时先看的是什么？ {#syn38.0.q1}
考点：syn38.s.class
语境：syn38.0.p.seed

- [ ] 是否已装在另一只封好的袋里
  理由：另封是挑好以后采取的办法。
- [x] 颗粒是否饱满
- [ ] 邻家孩子爱不爱吃
  理由：孩子想吃是种园人收好瓜子以后发生的事。

提示：先读“子之……者”，那时种园人还没动手封袋。
解析：“饱满”限定要保留的那类瓜子；“瘪者弃之”从另一面验证了这个标准。

## 找原文证据：原文哪一处已经讲到选定瓜子后怎样处置它们？ {#syn38.0.q2}
考点：syn38.s.statement
语境：syn38.0.p.seed

- [ ] 子之饱满者
  理由：这里挑出具备条件的瓜子，尚未说怎样处理。
- [ ] 此来岁之种也
  理由：这是种园人向孩子说明瓜子的用途，没写封存这一步。
- [x] 别封以待春

提示：“者”收住种子的特点，接下来哪个动作是种园人做的？
解析：“别封”是另行封存，“以待春”说明要等到何时。“者”之前是所选之子，这一层才是处置办法。

## 原文：教学例句 {#syn38.0.p.pole}
> 竹有曲直，舟师欲得直者。其徒题壁曰：“手拣长竿直，心期远客还。”舟师取竿试水。至暮，来舟犹未见。
译文：竹子有曲有直，船师要选直的。徒弟在壁上题道：“手拣笔直的长竿，心里盼着远客回来。”船师取竿试水。到傍晚，还看不见归来的船。
词注：舟师：驾船的人。
  期：期待，盼望。

## 单选：徒弟写“手拣长竿直”。船师拿去试水的竹竿是怎样得来的？ {#syn38.0.q3}
考点：syn38.s.attribute
语境：syn38.0.p.pole

- [x] 从长竿中选出了原本就直的一根
- [ ] 选中一根弯竿，下水后才把它拉直
  理由：船师要的是直竿，试水时已经拿到，没有矫直的动作。
- [ ] 要等远客带直竿回来，眼下只拿到弯竿
  理由：末句人未回来，但船师已经取竿试水。

提示：看“拣”以前，竹子是不是已经有曲直之分。
解析：“直”说所拣长竿的形状。把它连到竿上，才接得上“欲得直者”。

## 单选：若有人题一行小记“远客是日晚归”，根据这段文字应怎样改？ {#syn38.0.q4}
考点：syn38.s.wish
语境：syn38.0.p.pole

- [ ] 远客天亮就归来，题壁时还没开船
  理由：原文未记归来的时刻。
- [x] 徒弟盼远客归来，直到傍晚还没看见来船
- [ ] 远客明日一定归来，今天只是改了行期
  理由：“犹未见”没有交代明天的行程。

提示：“心期”以后装进的是一件心中之事；再到末句查它有无兑现。
解析：“远客还”三个字读在“期”里面，才是徒弟所盼。末句记人还没看见船，不能把愿望写成当日已发生的事。

## 原文：古籍引文 {#syn38.0.p.yao}
> 子曰：“大哉，尧之为君也！巍巍乎！唯天为大，唯尧则之。”
译文：孔子说：“尧作为君主真伟大啊！何等崇高！只有天如此广大，只有尧能够效法它。”

## 找原文证据：读“大哉”，原文随即用哪一处说明孔子头一句在称颂什么？ {#syn38.0.q5}
考点：syn38.s.subject
语境：syn38.0.p.yao

- [ ] 唯天为大
  理由：这是稍后用来说明评价的参照。
- [ ] 唯尧则之
  理由：这里写尧怎样效法天，已经是在说明缘由。
- [x] 尧之为君也

提示：先找到最初那声称颂，再取紧跟在它后面的事。
解析：“大”所评的是尧为君这件事。说完这一层，孔子才以天来说明评价有多高。

## 单选：若把孔子开头的话听成“尧做君主伟大吗”，后文的口气会被读错在哪里？ {#syn38.0.q6}
考点：syn38.s.tone
语境：syn38.0.p.yao

- [x] 他已经在称颂，并接连用“巍巍”和效法天来说明这声赞叹
- [ ] 他在问谁得到君位，还不知道那人叫尧
  理由：开头已经有“尧之为君”。
- [ ] 他正在请尧本人回答怎样效法天
  理由：从开头到“唯尧则之”都是孔子说话，没有出现尧的回答。

提示：听“巍巍乎”接在前面，是等待答案，还是又说了一层赞美的话？
解析：“大哉”先给出评价；“尧之为君也”点出所论之事。孔子顺着这层意思继续赞叹，全段并未把疑问交给听者。
