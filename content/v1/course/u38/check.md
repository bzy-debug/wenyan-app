# 检查：从城门读到边界 {#check.38}

## 原文：教学例句 {#check.38.p.market}
> 使者自鲁适齐，越境已三日，今始至国门。守门者导之入市。
译文：使者从鲁前往齐，越过国境已有三天，今天才到国都的城门。守门人领他进了街市。

## 单选：三天前使者已经越过国境。眼下他来到的“国门”又是哪道门？ {#check.38.q1}
考点：words.skill.guo-capital
语境：check.38.p.market

- [x] 齐国都城的城门
- [ ] 鲁齐两国的国境关卡
  理由：三天前便已越境。
- [ ] 市中某家商铺的门
  理由：过门以后才被领进市中。

提示：入门后，守门人把使者带进了哪里？
解析：越境在先，到城门在后，一进门便通往街市。眼前这道门是齐国都城的城门。

## 原文：教学例句 {#check.38.p.news}
> 盗起东鄙，越界而走。守边之卒逐至界石，不敢复前。
译文：东部边地闹了盗贼，盗贼越过国界逃走。守边士卒追到界石，不敢再往前。

## 找原文证据：士卒追到什么东西跟前，就知道再走要越过国界了？ {#check.38.q2}
考点：words.skill.bi-border
语境：check.38.p.news

- [x] 界石
- [ ] 东鄙
  理由：东鄙是发生盗事的那一片边地，问的是眼前的标志物。
- [ ] 守边之卒
  理由：这是追人追到边界的士卒，问题问他们看到了什么。

提示：选一件立在交界处、能亲眼看到的东西。
解析：士卒到了界石就停下。界石标出两地的边界，也让“东鄙”所指的地方更清楚。

## 原文：教学例句 {#check.38.p.granary}
> 道闻群盗将至。尉令二卒守东门，非持符者不得入。二卒终夜在门。
译文：在路上听说一伙盗贼快要到了。县尉命两名士卒守东门，没有凭符的人不许进。两人整夜在门边。

## 单选：县尉派两名士卒“守东门”，他们要怎样当值？ {#check.38.q3}
考点：words.skill.shou-guard
语境：check.38.p.granary

- [ ] 追出城外捕尽所有盗贼
  理由：士卒整夜在门，任务有明确处所。
- [x] 值守门口并查验进入的人
- [ ] 替无符的人借一面符
  理由：规矩是无符不得入。

提示：读“非持符者不得入”，再看两人夜里在哪里。
解析：两人整夜守在门边，查验入门的人，持符的才许入。

## 原文：教学例句 {#check.38.p.refuge}
> 民避乱于山，寇平，乡里复定。父老遣人招之，避者乃归。
译文：百姓为躲避动乱进了山。盗寇被平定，乡里重新安定。父老派人招呼，避难的人才回来。

## 单选：百姓当初为躲乱上山，后来为什么肯回家了？ {#check.38.q4}
考点：words.skill.ding-settle
语境：check.38.p.refuge

- [x] 家乡安定了，他们才敢回来
- [ ] 山中确定了新住处，所以留下
  理由：末句说“乃归”。
- [ ] 父老为每家定了田界
  理由：文中写的是避乱、寇平和返乡。

提示：“乡里复定”之前，原有的祸患怎样了？
解析：寇乱已平，乡里又安定下来。父老派人招呼以后，避乱的人便回来。

## 原文：教学例句 {#check.38.p.rain}
> 父闻子修堤有功，戒曰：“乡人自知之，汝毋伐也。”子默然，未尝言己劳。
译文：父亲听说儿子修堤有功，告诫说：“乡亲自然知道，你不要夸耀。”儿子沉默，从不提自己的辛劳。

## 单选：父亲说“汝毋伐也”，提醒儿子修堤有功以后别做什么？ {#check.38.q5}
考点：words.skill.fa-boast
语境：check.38.p.rain

- [ ] 对敌军发起进攻
  理由：儿子做的是修堤的事，父亲下一句话说功劳该不该挂在嘴上。
- [ ] 继续维修堤坝的行动
  理由：父亲认可修堤的功，并没有叫他停工。
- [x] 夸说自己修堤的功劳

提示：听完父亲的话，儿子还提不提自己的功劳？
解析：乡亲已知道他修堤有功，父亲告诫他不必自夸，所以他不再提起自己的辛劳。

## 原文：教学例句 {#check.38.p.money}
> 客去年假钱十，今还其六。主人但责所余四钱，客如数偿之。
译文：客人去年借钱十枚，现在还了六枚。主人只索要剩下的四枚，客人如数还清。

## 单选：客人先前借十钱，归还了六钱。主人“责所余四钱”是在做什么？ {#check.38.q6}
考点：words.skill.ze-demand
语境：check.38.p.money

- [x] 向客人索还四枚欠钱
- [ ] 因为客人只有四枚钱而斥责他
  理由：从十钱里还了六钱，还欠四钱，主人来索的是这笔欠款。
- [ ] 重新给客人借出四枚钱
  理由：客人“如数偿之”，钱从客人手里还给主人。

提示：剩下四钱是谁欠谁的？
解析：主人向借钱的客人索还欠下的四钱，客人随后照数还清。
