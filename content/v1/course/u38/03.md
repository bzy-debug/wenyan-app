# 课文：先听见一声赞，再听清说的是谁 {#syn38.3}
简介：“贤哉”先说评价，“回也”才点出颜回。循着说话人的口气，分出赞叹、感慨和询问。

## 正文

“贤哉，回也！”如果只听见前两个字，你已知道孔子在称赞，听到“回也”才知道他称赞谁。换个语序转述，就是“颜回真贤啊”。先把评价说出来的这种语序，常叫**谓语前置**，也叫**主谓倒装**。后半有时是一个人名，有时是一整件事。

单看“哉”还听不清说话人的用意。客人望着新桥说“高哉，此桥也”，是在发感叹。若问“此桥谁成之哉”，便还缺一个人名。读对话时，看看说话人已经作出了什么判断，又有没有留下要别人回答的事。

## 知识点：从前置的评价找出它所说的人或事 {#syn38.s.subject}
义项：感叹时谓语先出，后面才点出受到评价的对象
领域：句法
要诀：“贤”“甚”“久”等字究竟落在谁身上，或落在哪件事上？
讲解：“贤哉，回也！”先赞“贤”，再点出颜回。这是感叹句里的谓语前置，也叫主谓倒装。转述时可以说“颜回真贤啊”。
例句：syn38.3.p.yan

## 知识点：根据句意分清带“哉”的感叹与询问 {#syn38.s.tone}
义项：看句中已有评价还是留下待答的信息，辨明说话用意
领域：句法
要诀：此时该倾听一声赞叹，还是给说话人一个他尚不知道的答案？
讲解：同一场谈话可以先赞叹，随即发问。读到问处，应说得出缺的是谁、何故，或哪一项尚待查明。
例句：syn38.3.p.bell

## 原文：古籍引文 {#syn38.3.p.yan}

译文：孔子说：“颜回真贤啊！一竹篮饭，一瓢水，住在简陋的小巷里，别人受不住这种困苦，颜回却依然保持自己的快乐。颜回真贤啊！”

## 单选：孔子开头便说“贤哉”。谁受到这一声赞许？ {#syn38.3.q1}
考点：syn38.s.subject
语境：syn38.3.p.yan

- [ ] 孔子自己
  理由：开口的是孔子，评价后紧跟的名字却是回。
- [ ] 受不住陋巷之苦的众人
  理由：众人的反应是用来映照颜回的。
- [x] 住在陋巷的颜回

提示：叫出“贤”之后，孔子随即提了谁的名字？
解析：评价先到，人名随后才到。中间又写“回也不改其乐”，说明这声赞是有来由的。

## 找原文证据：若有人把开头读成“颜回贤不贤呢”，哪一句最能看出孔子是在说明自己为何赞他？ {#syn38.3.q2}
考点：syn38.s.tone
语境：syn38.3.p.yan

- [ ] 一瓢饮
  理由：这里写的是住在陋巷时的饮食，单这一处还看不到颜回的反应。
- [x] 回也不改其乐
- [ ] 人不堪其忧
  理由：这里说的是换成别人会怎样，还须看颜回本人。

提示：孔子既说别人受不住，还说了颜回自己的哪一点？
解析：孔子已经许他以“贤”，接着叙处境和回应。读成向别人打听颜回贤不贤，就接不上结尾的又一声称赞。

## 单选：这里连用“甚矣”“久矣”。哪一种转述把程度和时间分别配回了原处？ {#syn38.3.q3}
考点：syn38.s.subject
语境：syn38.3.p.decline

- [x] 我衰老得厉害；我很久不再梦见周公
- [ ] 周公衰老得厉害；我的这一个梦持续很久
  理由：“吾衰”说自己衰老，“不复梦见”说已没有这样的梦。
- [ ] 我的梦特别深；周公已经衰老很久
  理由：“甚”紧接的是“吾衰”，“久”紧接的是“不复梦见”。

提示：先给“甚”找一件可深可浅的事，再给“久”找一段延续的时间。
解析：两个分句都先说感受，再点出所感之事。第二句写久未梦见，不能改为做了一场很长的梦。

## 原文：教学例句 {#syn38.3.p.bell}
> 客过钟肆，闻声而叹曰：“清哉，此钟之声也！孰铸之哉？”肆主指少工曰：“此子之作也。”客遍视他钟，独市其所闻者。
译文：客人经过卖钟的铺子，听见钟声，感叹道：“这口钟的声音真清亮啊！是谁铸的呢？”店主指着年轻工匠说：“是这孩子的作品。”客人看遍其他钟，只买下自己听过的那口。
词注：肆：店铺。
  孰：谁。
  市：买。

## 单选：客人两次说“哉”，店主指向少工，实际是在回答哪一件事？ {#syn38.3.q4}
考点：syn38.s.tone
语境：syn38.3.p.bell

- [ ] 钟声清不清亮
  理由：客人已亲耳听过，开口就说清亮。
- [x] 是谁铸了这口钟
- [ ] 客人最后买了哪一口钟
  理由：买钟是店主答了话之后才发生的事。

提示：把“此子”填回客人的话，能填在哪个字的位置？
解析：“清哉”已有判断。“孰铸之哉”留下铸钟者的身份待答，店主指人正可补上。

## 找原文证据：客人赞“清”时，原文把受赞的东西放在了哪里？选出直接点明它的词句。 {#syn38.3.q5}
考点：syn38.s.subject
语境：syn38.3.p.bell

- [x] 此钟之声也
- [ ] 此子之作也
  理由：这是店主答谁做了钟。
- [ ] 遍视他钟
  理由：这是客人后来逐一查看的动作。

提示：客人刚用过耳朵，赞的是听到的什么？
解析：放在“清哉”后面的是这口钟的声音。清亮赞的是声音，少工是稍后才介绍的铸造者。

## 排序：从听钟到知道工匠是谁，这段对话怎样一步步展开？ {#syn38.3.q6}
考点：syn38.s.tone
语境：syn38.3.p.bell

- [3] 店主把少工指给客人
  理由：店主的动作回答“孰”。
- [1] 客人赞叹钟声清亮
  理由：“闻声”以后先说出自己听到的效果。
- [2] 客人打听铸钟的是谁
  理由：听清了声音，还需向店主请教来历。

提示：一个“哉”说自己的感受，另一个“哉”要店主提供什么？
解析：客人先有听声的判断，再提出不知答案的问题；因此店主应第二句指人，不必重答声音清不清。

## 原文：教学例句 {#syn38.3.p.ferry}
> 童随叟出郭，望渡口，曰：“远哉，今日之行也！”至岸，又问：“舟何时来哉？”叟曰：“日中。”二人坐柳下俟之。
译文：孩子跟着老人出城，望向渡口，说：“今天这一程真远啊！”到了岸边，又问：“船什么时候来呢？”老人说：“正午。”两人便坐在柳树下等船。
词注：郭：外城。
  日中：中午。
  俟：等待。

## 单选：孩子开头叹“远”，他把这个“远”说在什么上面了？ {#syn38.3.q7}
考点：syn38.s.subject
语境：syn38.3.p.ferry

- [ ] 老人看不清渡船
  理由：原文没有说老人眼力如何。
- [x] 两人今天要走的这一程
- [ ] 摆渡的船已经离岸很远
  理由：行至岸边，孩子才问船何时来。

提示：“远哉”后面的字，讲当天的行程还是船行的距离？
解析：“今日之行也”是孩子所叹的事。行路远在开头便可感叹，船何时到则留给了后面的问话。

## 单选：老人只答“日中”，为什么这两个字就够了？ {#syn38.3.q8}
考点：syn38.s.tone
语境：syn38.3.p.ferry

- [ ] 孩子先问走了多远，正午是里数的别称
  理由：“远哉”是感叹，“日中”说时刻。
- [ ] 他是在劝孩子到了正午再出城
  理由：二人已到岸边，问的是船。
- [x] 孩子第二次开口要知道的是来船的时刻

提示：若把“日中”直接接到“舟……来”中间，补足了哪一层？
解析：后一句有“何时”，具体留下了时间等人补。第一句已经说出对行程的感受，并没有索要时刻。
