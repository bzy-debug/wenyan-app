# 课文：马之千里者，究竟是哪一匹马 {#syn38.1}
简介：看“者”前的几个字怎样把一类东西挑出来，再接着读这些东西怎么了。

## 正文

马厩里既有善跑的马，也有寻常的马。韩愈写“马之千里者”，先说马，再说哪一类马值得往下谈。用今天的话说，就是“能日行千里的马”。“者”把这个条件收住，下一句才说它一顿可能吃多少。

有些教材把这种语序叫“定语后置”。读的时候可以用手遮住“者”后面的字，看看前面圈住了谁或什么；再把手移开，看作者对它说了什么。“牧者牵马”的“者”跟着“牧”，指放牧的人。这时前面并没有一群马等着你从中挑。

## 知识点：从名词后的一层说明认出哪一类 {#syn38.s.class}
义项：用名词后面的特点，限定下文所说的人或物
领域：句法
要诀：说的是全部，还是其中符合条件的一类？
讲解：“马之千里者”先说马，再用“千里者”说明是哪一类马。教材常称这种写法为定语后置。换成白话，就是能日行千里的马。
例句：syn38.1.p.horse

## 知识点：分开限定的条件和随后所说的事 {#syn38.s.statement}
义项：辨出哪一层是在挑选对象，哪一层是在交代它的情况
领域：句法
要诀：“者”前收进了哪一层？余下的字新说了什么？
讲解：“器之有缺者，勿以盛水”先挑有破口的器物，再嘱咐不要用它盛水。要拿掉这些器物，也得先看破口，不必等它漏过水。
例句：syn38.1.p.pot

## 原文：古籍引文 {#syn38.1.p.horse}
> 马之千里者，一食或尽粟一石。食马者不知其能千里而食也。
译文：能日行千里的马，一顿有时能吃尽一石粮。喂马的人却没有按它能日行千里的本事来喂它。
出处：韩愈《杂说四》马说一段
作者：唐·韩愈

## 单选：马厩里什么马才在“一食或尽粟一石”这句话所说的范围内？ {#syn38.1.q1}
考点：syn38.s.class
语境：syn38.1.p.horse

- [ ] 所有由专人饲养的马
  理由：喂马人随后才出场，首句另有挑选马的条件。
- [x] 具备日行千里本领的马
- [ ] 已经吃足一石粮的马
  理由：吃多少是随后才交代的事，不能倒过来作为挑马的条件。

提示：“者”前有一项本事，下一句“不知其能……”又提到了它。
解析：“千里”说的是行程和能力。韩愈先挑出有这项本领的马，再谈食量。

## 找原文证据：韩愈挑出了这种马，接下来哪几个字才开始讲它的食量？ {#syn38.1.q2}
考点：syn38.s.statement
语境：syn38.1.p.horse

- [ ] 马之千里者
  理由：这几个字说明是哪一类马。
- [ ] 食马者
  理由：这是另一个人，负责饲养。
- [x] 一食或尽粟一石

提示：找同时有顿数、粮食和分量的那句话。
解析：到“者”为止已经认出了马。“一食或尽粟一石”是对这类马另作的说明，“或”也给食量留了余地。

## 原文：古籍引文 {#syn38.1.p.stone}
> 然是说也，余尤疑之。石之铿然有声者，所在皆是也，而此独以钟名，何哉？

## 单选：假如到别处去找苏轼说的这种石头，怎样才算找对？ {#syn38.1.q3}
考点：syn38.s.class
语境：syn38.1.p.stone

- [x] 敲起来也能发出清响
- [ ] 当地也拿“钟”给山命了名
  理由：文章正要分辨许多地方有响石和一地名为石钟这两件事。
- [ ] 石头生来外形都像钟
  理由：“铿然有声”给的是听得见的特点，没有说明形状。

提示：苏轼从声音认石，随后才问山名。
解析：“石”是要寻找的东西，“铿然有声”是它该有的特点。地点和山名都不在这个条件里。

## 单选：“所在皆是也”说的是哪一种分布？ {#syn38.1.q4}
考点：syn38.s.statement
语境：syn38.1.p.stone

- [ ] 各地的山都叫石钟山
  理由：“而此独以钟名”明说名称只落在此处。
- [x] 这样的响石在各处都能找到
- [ ] 每一块石头敲起来都是同一种声音
  理由：作者谈的是响石到处有，没有逐块断言所有石头都响。

提示：先读完“石之……者”，再用“这样的石头”接下一句。
解析：“者”前先挑了石。作者随后才说它们到处可见，由此追问此山得名还有什么别的缘故。

## 原文：教学例句 {#syn38.1.p.pot}
> 陶人出器示客。器之有缺者，皆置篱下；完者陈于案。童误取篱下一瓮，方注水，水从缺处出。
译文：陶工取出陶器给客人看。有破口的都放在篱笆下面，完好的陈列在桌上。孩子误拿了篱下的瓮，才倒进水，水就从破口流出来了。
词注：缺：破损的地方。
  完：完好。

## 找原文证据：陶工只肯卖完好的器物。原文哪处指的是他应当先剔出的一类？ {#syn38.1.q5}
考点：syn38.s.class
语境：syn38.1.p.pot

- [ ] 陶人
  理由：这是制作陶器的人。
- [x] 器之有缺者
- [ ] 童误取篱下一瓮
  理由：这是孩子后来从篱边拿瓮的事，不是陶工起先挑出的一类器物。

提示：先找器物，再找可以从器物本身看出来的条件。
解析：“器之有缺者”挑出陶器中有破口的一类。篱下只是这次摆放它们的地点。

## 排序：如果向客人解释篱下为什么有个漏水的瓮，该怎样顺着原事讲？ {#syn38.1.q6}
考点：syn38.s.statement
语境：syn38.1.p.pot

- [2] 孩子从篱下错拿了一瓮
  理由：“误取”时，陶工已经把器物分开放了。
- [3] 孩子注水，水从破口出来
  理由：倒水在取瓮以后。
- [1] 陶工把有破口的器物放到篱下
  理由：“有缺”是挑器物的条件，“置篱下”是挑出以后对它们所做的事。

提示：器物原来有缺，还是孩子倒水才弄缺了？
解析：陶工照破口分放器物。孩子从那一堆取瓮试水，后面的漏水印证了开头的分法。

## 原文：教学例句 {#syn38.1.p.boat}
> 渡者集于津。舟之有篷者，先载老幼；无篷者乃载薪。日暮，风雨至，篷中儿不湿。
译文：要过河的人聚在渡口。有篷的船先载老人和小孩，无篷的船便载柴。傍晚下起风雨，篷里的孩子没有淋湿。
词注：津：渡口。
  薪：柴。

## 单选：“渡者”和“舟之有篷者”各指什么？ {#syn38.1.q7}
考点：syn38.s.class
语境：syn38.1.p.boat

- [ ] 都是要过河的人，后者指其中带伞的
  理由：“篷”是船上的遮盖，“舟”明写在这层说明前。
- [ ] 前者指第一条渡船，后者指船上的老人
  理由：先有人来到渡口，随后才分船载人或载柴。
- [x] 前者是要过河的人，后者是带篷的船

提示：先看“者”前紧贴着的是渡河的动作，还是在说明一种船。
解析：“渡”是人要做的事。“舟之有篷者”先提出船，再按有没有篷来分；两处“者”指向的东西不同。

## 单选：若将这段话画成渡口示意图，什么该画在船本身，什么是分船以后的安排？ {#syn38.1.q8}
考点：syn38.s.statement
语境：syn38.1.p.boat

- [x] 篷是船已有的，老幼坐上这种船是随后的安排
- [ ] 老幼是区分船本身的标准，有篷是载人以后的结果
  理由：原文先辨舟有篷无篷，才有分工。
- [ ] 风雨是先分船的标记，篷要等雨停才装
  理由：先分船，“日暮”以后才写风雨。

提示：把“舟之有篷者”读完停一停，再看看“先载”的是谁。
解析：“有篷”挑选船。“先载老幼”才说它分到了什么任务。到风雨真的来时，这样分派的好处便看得见了。
