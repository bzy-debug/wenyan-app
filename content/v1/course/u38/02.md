# 课文：口中衔着什么，心中盼着什么 {#syn38.2}
简介：韩愈用两行诗写精卫。口中能衔的是小石，心里盼的是海面有一天平静。

## 正文

“口衔山石细，心望海波平。”两行诗并排看，“口”对“心”，“细”对“平”。可“衔”和“望”要接的东西不一样。

假使眼前有一幅画，鸟嘴里该画细小的山石。“细”原在句尾，讲成白话，可以连到“山石”前。海上此刻该不该画一片平静？诗只说精卫希望波涛平息；心里盼的是“海波平”这一整件事。望见一片平静的海，与盼着海浪平下来，会画出两幅不同的图。

碰见别的诗句，先问动作可以接什么。不要一见字数相同，就把上下句末尾的字都搬到前面。

## 知识点：诗句末尾的字说明所取之物 {#syn38.s.attribute}
义项：借动作和语境确认句尾形容词修饰的名词
领域：句法
要诀：嘴里衔着、手里拿着的，是什么样的东西？
讲解：有些诗把器物的形状、颜色留到末尾说。若动作只是拾取，要把原有所具的特点与后来加工得到的结果分开。
例句：syn38.2.p.bird

## 知识点：把所盼的情形读完整 {#syn38.s.wish}
义项：在“望”“愿”等后面读出谁将怎样，并分清愿望和眼前事实
领域：句法
要诀：愿望里另有谁或什么？它要怎样才算如愿？
讲解：“愿河清”是在盼水清。这个“清”该给河，不能给怀着愿望的人。等下文另有消息，才知道是否真的如愿。
例句：syn38.2.p.rain

## 单选：要画精卫的鸟喙，口中衔着的东西该是什么模样？ {#syn38.2.q1}
考点：syn38.s.attribute
语境：syn38.2.p.bird

- [ ] 一大块山石，被鸟喙一下啄碎
  理由：“衔”写嘴里叼着，没有写啄碎的变化。
- [x] 一块细小的山石
- [ ] 一块石上刻有细纹，纹里夹着海沙
  理由：“细”说眼前山石的大小，原句没有说石纹。

提示：读“衔”后，哪两个字说衔的东西？末尾还给了它什么特点？
解析：把“细”贴着“山石”看，精卫所衔是小石。这一口小石与它想填平的大海相对，才看得出志愿之大。

## 找原文证据：下句要读出精卫希望发生的一整件事，应从原句取哪几个字？ {#syn38.2.q2}
考点：syn38.s.wish
语境：syn38.2.p.bird

- [ ] 口衔山石细
  理由：这是鸟当下能做到的动作，不能单凭它认定愿望已实现。
- [ ] 终年抱寸诚
  理由：这是鸟一年到头的心意。
- [x] 海波平

提示：只答“海波”，还少了精卫对海浪的哪个愿望？
解析：愿望里，海波是要起变化的事物，平是盼到的状态。诗没有告诉我们海波已经平息。

## 原文：教学例句 {#syn38.2.p.rain}
> 麦初秀，农立田间，仰祝曰：“愿夜雨足。”至旦，土犹干，乃汲井灌之。
译文：麦子刚抽穗，农人站在田中仰头祈求：“但愿夜里的雨下得足。”天亮时泥土仍然干，他便打井水浇地。
词注：秀：庄稼抽穗。
  祝：祈祷。
  汲井：从井中打水。

## 单选：天刚亮时，怎样转述农人昨夜的话才没有把盼望写成了消息？ {#syn38.2.q3}
考点：syn38.s.wish
语境：syn38.2.p.rain

- [x] 他求夜雨下足；天亮看地，泥土仍干
- [ ] 他昨夜查明雨量充足，天亮便可以不浇地
  理由：“愿”是祈求；打井水浇地正说明田仍缺水。
- [ ] 他说自己的双脚淋了雨，又在田里待了一夜
  理由：“足”在这里交代雨量，不是人的脚。

提示：把祈求时说的话同天亮亲自见到的土分开。
解析：“夜雨足”整层是所愿之事。后来“土犹干”说的是实际地况，农人才另想办法取水。

## 排序：从所盼到实见，农人这一次怎样决定要不要浇地？ {#syn38.2.q4}
考点：syn38.s.wish
语境：syn38.2.p.rain

- [3] 去井边取水灌麦
  理由：“乃”接地仍然干以后采取的办法。
- [1] 盼夜里的雨水够用
  理由：这是农人站在田里祈求的事。
- [2] 清晨发现田土依旧干
  理由：“至旦”交代查验的时刻。

提示：哪件发生在“愿”里，哪两件是农人后来见到、做到的？
解析：祈雨在先。农人没有光凭所愿就判断麦田已有水，天亮看土以后才动手。

## 原文：教学例句 {#syn38.2.p.chess}
> 童欲配黑棋，至溪拾白石。归题小诗曰：“手收溪石白，磨作一奁棋。”弟视其篮，青石一无。
译文：孩子想给黑棋子配上白子，到溪边捡白石。回来题了两句小诗：“手里收来白色溪石，磨成一盒棋子。”弟弟看他的篮子，一块青石也没有。
词注：奁：盛东西的小盒。

## 单选：孩子在溪边已经做完了“手收溪石白”这件事，当时还没做什么？ {#syn38.2.q5}
考点：syn38.s.attribute
语境：syn38.2.p.chess

- [ ] 还没分出青石和白石
  理由：他已“拾白石”，篮里也没有青石。
- [x] 还没把拾来的白石磨成棋子
- [ ] 还没把青石磨白，所以专留下青石
  理由：所拾就是白石，磨是磨棋子，不是把青石改成白色。

提示：比较诗里“收”和“磨”分别接住哪一步。
解析：“石白”在诗里写所收之物的颜色。磨出棋子在后一行，不能把“白”读成磨完以后才有的颜色。

## 找原文证据：弟弟只看了一眼篮子。哪处观察也能支持把“溪石白”读成孩子所选的石料？ {#syn38.2.q6}
考点：syn38.s.attribute
语境：syn38.2.p.chess

- [x] 青石一无
- [ ] 童欲配黑棋
  理由：这是哥哥先前的打算，不是弟弟看到的篮子。
- [ ] 归题小诗
  理由：这是哥哥回来题诗的行动。

提示：弟弟没有看孩子在溪边捡，只能看他带回了哪些石头。
解析：篮里没有青石，与前面的“拾白石”正好合上。“白”是在挑石时就能看见的特点。

## 原文：教学例句 {#syn38.2.p.boat}
> 渔父出舟，女送至汀，祝曰：“愿父舟安。”父指岸上修竹曰：“归为汝截一枝。”女乃还家。
译文：渔人出船，女儿送到水边，祝愿说：“但愿爹的船一路平安。”父亲指着岸上的长竹说：“回来给你截一根。”女儿这才回家。
词注：汀：水边平地。
  修竹：高长的竹子。

## 单选：女儿送船时希望怎样？原文有没有接着写这愿望已经实现？ {#syn38.2.q7}
考点：syn38.s.wish
语境：syn38.2.p.boat

- [ ] 她要找一只船名叫“舟安”的船，父亲已替她找着
  理由：“愿”后说父亲的船平安，没有给船起名。
- [ ] 她要父亲立即靠岸，后来父亲已同她回家
  理由：“女乃还家”写女儿回去，父亲说的是以后。
- [x] 她盼父亲的船平安；这里只写父女送别

提示：“安”说谁或什么？末句回家的人又是谁？
解析：“父舟安”整层是女儿所愿。父亲说归来后为她截竿，是许诺，还没有叙到船回。

## 原文：教学例句 {#syn38.2.p.reed}
> 织席者晨至水次，细苇已别束。其歌曰：“朝取洲芦细，暮成堂上茵。”客索粗者，乃指旁束与之。
译文：编席人清早来到水边，细芦苇已经另外捆好了。他唱道：“早晨取洲上的细芦苇，傍晚便成了堂上的垫席。”客人来要粗芦苇，他就把旁边那捆指给客人。
词注：水次：水边。
  茵：垫席。

## 单选：客人为什么须另取旁边的一捆？ {#syn38.2.q8}
考点：syn38.s.attribute
语境：syn38.2.p.reed

- [ ] 编席人把前一捆取来削细了，旁边那捆还来不及削
  理由：“细苇已别束”说明起先就照粗细分捆。
- [x] 歌里所取的是细芦，客人要的却是粗芦
- [ ] “朝取”与“暮成”各指一个人，两人各守一捆
  理由：两句合说同一份编席活计，没有另派第二个人。

提示：将“洲芦细”放回清早已经分好的两捆里。
解析：“细”指出编席人取的是哪一捆。客人来索粗苇，编席人才把他引到旁边。
