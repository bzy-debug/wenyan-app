# 课文：治、乱、守、定 {#words.17}
简介：“治县”是有人在办事，“邑定”是当地安定下来，留心句子讲的是谁。

## 正文

“县令治县”，县令是做事的人，县是他治理的地方；“邑乃定”换成说地方安定下来。治县是一项职责，写到路上无警、商人复市，才看得出百姓的日子如何。

一个地方“乱”，不妨再看谁失了秩序；“守”却要问谁仍在什么地方看守。市中虽乱，仓门仍可能有人在守，原文中的“方”“犹”“既”也能帮你辨清当时怎样、后来又怎样。

## 知识点：治 {#words.skill.zhi-govern}
义项：治理、管理地方或政事
领域：实词
要诀：把“谁治理哪里”补成一句话。
讲解：“吏治一邑，先问民所苦”，先问百姓的困苦，是他着手治理这座城邑时做的事。
例句：words.ex.zhi-govern

## 原文：教学例句 {#words.ex.zhi-govern}
> 吏治一邑，先问民所苦。
译文：官吏治理一座城，先去问百姓有什么苦处。

## 知识点：乱 {#words.skill.luan-disorder}
义项：秩序混乱、失去条理
领域：实词
要诀：谁乱了？有没有人已不知道该怎样行动？
讲解：号令相反，大家不知听谁的，秩序随之混乱。“乱”写的是号令造成的局面。
例句：words.ex.luan-disorder

## 原文：教学例句 {#words.ex.luan-disorder}
> 号令相反，众遂乱。
译文：号令互相矛盾，众人于是乱了。

## 知识点：守 {#words.skill.shou-guard}
义项：值守、防护某人或某处
领域：实词
要诀：哪里需要提防，谁一直留在那里？
讲解：士卒在仓门整夜不离，是担任守卫；留到什么时候，也能让人看出这份差事要怎样做。
例句：words.ex.shou-guard

## 原文：教学例句 {#words.ex.shou-guard}
> 卒守仓门，终夜不离。
译文：士卒守卫仓门，一整夜没有离开。

## 知识点：定 {#words.skill.ding-settle}
义项：局势平稳、安定下来
领域：实词
要诀：先前怎样不安定？恢复平静后人们又怎样生活？
讲解：盗贼散去，商人重新开店，便能看出“邑定”指地方安定。换作“心定”，安定下来的是人心。
例句：words.ex.ding-settle

## 原文：教学例句 {#words.ex.ding-settle}
> 盗散而邑定，商复开肆。
译文：盗贼散去，城邑安定，商人重新开店。

## 原文：教学例句 {#words.17.p.county}
> 新令治县，省徭役，平争田之讼。民乃得专力于农。
译文：新县令治理本县，减轻徭役，处理争田的官司。百姓才得以专心务农。

## 单选：读完省徭役、平田讼两件事，再看“治县”，县令在做什么？ {#words.17.q1}
考点：words.skill.zhi-govern
语境：words.17.p.county

- [x] 县令处理地方政事
- [ ] 县令医治了一县的病人
  理由：省徭役、平诉讼都是行政事务。
- [ ] 居民自己决定县令去留
  理由：实施这些措施的是新令。

提示：调减劳役和处理争田的案件，都归谁办理？
解析：新任县令处理地方政事，这两件就是他治理一县时所办的事。

## 原文：教学例句 {#words.17.p.two}
> 守问二吏各欲何事。甲请治东乡，乙请记仓中出入。守以东乡付甲。
译文：郡守问两名官吏各想做什么。甲请求治理东乡，乙请求记录仓库的收支。郡守把东乡交给甲。

## 找原文证据：甲请“治”什么地方？选出这个地名。 {#words.17.q2}
考点：words.skill.zhi-govern
语境：words.17.p.two

- [ ] 仓中
  理由：乙要记仓中出入，甲请管的是另一处。
- [x] 东乡
  第几处：1
- [ ] 二吏
  理由：“二吏”说的是两位来答话的人，要找的是甲请求去的地方。

提示：留意郡守最后交给甲的是哪里。
解析：甲请求治理东乡，郡守后来也把东乡交给他。

## 原文：古籍引文 {#words.17.p.compare}
> 使尧舜御之则天下治，使桀纣御之则天下乱。
译文：假使让尧、舜驾驭它，天下就安定；假使让桀、纣驾驭它，天下就混乱。

## 单选：尧舜执政和桀纣执政，两个假设里与天下“乱”相反的是哪种情形？ {#words.17.q3}
考点：words.skill.luan-disorder
语境：words.17.p.compare

- [ ] 把马车赶得很快
  理由：“乱”的是整个天下，这里没有写马车如何奔驰。
- [ ] 交替派出两位御者
  理由：两个“使……则……”在比较两种治国情形，没有轮换御者。
- [x] 天下秩序安定

提示：原文两回用了“则天下”，再看后面的字。
解析：前句说天下治、秩序安定；后句说天下乱、秩序失常，两句正好相对。

## 原文：教学例句 {#words.17.p.signal}
> 军中鼓欲进，钲欲止，二声并作。众不知所从，行列遂乱。
译文：军中击鼓要前进，击钲要停下，两种声音同时响起。众人不知道该听哪样，队列于是混乱。

## 单选：鼓和钲同时响，军中究竟乱在什么地方？ {#words.17.q4}
考点：words.skill.luan-disorder
语境：words.17.p.signal

- [ ] 进退信号都一律取消
  理由：两种声音仍同时响着。
- [ ] 众人因密谋反叛而离城
  理由：只写不知该听哪一种号令。
- [x] 相反的信号使行列失去秩序

提示：鼓要人前进，钲要人停止，士卒该听哪一个？
解析：两种号令相反，士兵不知该动还是该停，原有队列便乱了。

## 原文：教学例句 {#words.17.p.vault}
> 盗讯至，吏分卒守库。门启则验券，至夜更守不辍。
译文：盗贼的消息传来，官吏派士卒看守库房。开门就核验凭券，入夜仍轮换看守。

## 单选：官吏派士卒“守库”，士卒要做哪些事？ {#words.17.q5}
考点：words.skill.shou-guard
语境：words.17.p.vault

- [ ] 数清库中每一枚钱
  理由：后文实际写的是验券与夜守。
- [ ] 守候一名迟到的客人
  理由：所守的是库，缘由是盗情。
- [x] 防护库房并核查出入

提示：开门时做什么？入夜以后有没有停？
解析：他们看守库房，开门时查验出入的券，夜里也轮班守卫。

## 原文：教学例句 {#words.17.p.fort}
> 敌引去，或请追。将曰：“彼或复来，吾守此隘足矣。”乃留弩士于两崖。
译文：敌人退去，有人请追。将领说：“他们或许还会来，我们守住这处险隘就够了。”于是留下弩手在两侧山崖。

## 找原文证据：将领决定守住隘口，哪几个字写出了这项安排？ {#words.17.q6}
考点：words.skill.shou-guard
语境：words.17.p.fort

- [ ] 或请追
  理由：有人请追，将领却主张守隘，没有采纳追击的提议。
- [ ] 敌引去
  理由：“敌引去”说的是敌人退走；留下人防守是再往后的事。
- [x] 留弩士于两崖

提示：他说完“吾守此隘足矣”之后，把人留在哪里？
解析：把弩士留在两侧山崖，是他安排防守隘口的行动。

## 原文：教学例句 {#words.17.p.peace}
> 寇去，人犹闭户。三日后道路无警，邑乃定，贾人复市。
译文：盗寇离去，众人仍关着门。三天后道路上没有警报，邑里这才安定，商人恢复交易。

## 单选：盗寇刚走，人们还闭着门。后来到什么时候才称得上“邑乃定”？ {#words.17.q7}
考点：words.skill.ding-settle
语境：words.17.p.peace

- [ ] 盗寇刚一离去的瞬间
  理由：当时人们还闭户，后面另有“三日后”。
- [ ] 商人决定货物价格时
  理由：“邑”是“定”的主语，谈的是全邑局势。
- [x] 道路一段时间无警，生计陆续恢复时

提示：留意“三日后”路上的情形，以及商人的动向。
解析：道路连续几天平安无警，商人也重新开市，这才看得出当地安定下来。

## 原文：教学例句 {#words.17.p.news}
> 初讹言水至，民争登丘。吏验堤无患，遍告之，众心始定，各还其舍。
译文：最初误传洪水将至，百姓争着上丘。官吏查验堤坝无恙，遍告百姓，大家的心才安定下来，各自回家。

## 单选：先前百姓争登山丘，后来却各回各家。“众心始定”说的是什么变化？ {#words.17.q8}
考点：words.skill.ding-settle
语境：words.17.p.news

- [x] 由争着逃避到放心归家
- [ ] 由不知人数到确定名额
  理由：文中并未清点人数。
- [ ] 由争渡到定下渡船价钱
  理由：全段只说登丘与还舍。

提示：中间官吏查过堤坝，又告诉了大家什么？
解析：人们起初怕水来而逃，听说堤坝无恙才放心回家。“定”指惊慌的心安了下来。
