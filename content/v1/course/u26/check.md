# 检查：听清君主所乐，数清到岸的舟 {#check.26}

## 原文：古籍引文 {#check.26.p.king}
> 人之言曰：“予无乐乎为君，唯其言而莫予违也。”如其善而莫之违也，不亦善乎？如不善而莫之违也，不几乎一言而丧邦乎？
译文：有人说：“我做君主并没别的乐趣，只是自己说话无人违逆。”如果说的话好又无人反对，不也好吗？若话说得不好也无人反对，岂不接近一句话就使国家败亡了吗？

词注：予：我，引语中君主自称。
  违：违逆、反对。
  几：读 jī，接近。

## 单选：前一句的“莫予违”能读成君主当场严令“你们不要违逆我”吗？ {#check.26.q1}
考点：g26.skill.none
语境：check.26.p.king

- [x] 他在叙说没人违逆自己，以此为乐
- [ ] 能，他正在向现场臣子发一道禁令
  理由：一开头是“人之言曰”，孔子引用的是有人怎样形容为君之乐。
- [ ] 能，后面预报有一个臣子马上违令
  理由：后面分别假设话善、不善，两种情形都说莫之违。

提示：把“予”放回“违”的后面，再问“莫”指哪些人。
解析：“莫予违”可读成“无人违我”，把无人反对当作乐事。接着孔子才分别考虑这样会有什么后果。

## 单选：“唯其言而莫予违也”给做君主的乐趣划了怎样的范围？ {#check.26.q2}
考点：g26.skill.only
语境：check.26.p.king

- [x] 这是引语里那位说话人声称仅有的乐趣
- [ ] 凡被人反对的意见一定都是错的
  理由：后文区分意见本身是好是坏。
- [ ] 所有君主都只能从这一点得到乐趣
  理由：开头只引用一种人的说法，没有逐一谈所有君主。

提示：将“唯”接回前面的“无乐乎为君”。
解析：引语收窄的是这个人自认的乐趣。孔子把话引来以后，恰恰要追问无人反对是否一定可喜。

## 找原文证据：都说无人反对，孔子在哪一种情形中特别担心由此误国？ {#check.26.q3}
考点：g26.skill.none
语境：check.26.p.king

- [x] 如不善而莫之违也
- [ ] 如其善而莫之违也
  理由：前面所说的是话好，随后问“不亦善乎”。
- [ ] 人之言曰
  理由：这里仅交代引用别人的话。

提示：仅抄“莫之违”分不出好坏；找它前面加的条件。
解析：同样“莫之违”，不同在话本身善不善。意见不好却无人反对，才接到最后的忧虑。

## 原文：教学例句 {#check.26.p.gift}
> 三舟约同至。辰时，吏见江上白帆，曰：“舟至矣！”及视，惟一舟已泊，二舟犹在江心。长者问：“皆至乎？”吏曰：“吾所言者，一舟到岸而已，非谓三舟皆至也。”
译文：三艘船约好一同到。早晨，官吏见江上有白帆，说：“船到了！”仔细查看，只有一艘已停靠，两艘还在江心。长者问：“都到了吗？”官吏说：“我所说的，只是一艘到岸，不是说三船都到了。”
词注：泊：停靠。
  江心：江面中央。

## 单选：要照“惟一舟已泊”派人往码头接船，哪一个安排才根据已见实情？ {#check.26.q4}
考点：g26.skill.only
语境：check.26.p.gift

- [x] 先接已经停靠的一舟，另两舟眼下还远
- [ ] 只有一舟参加过约定，其余二舟不算
  理由：开头明说“三舟约同至”。
- [ ] 三舟同约，所以三处人货都已经可以卸
  理由：约定不能替代到岸，二舟仍在江心。

提示：“惟”限制了已经停靠的船数，还是原来相约的船数？
解析：约同至是众人的计划，惟一舟已泊是当时的结果，范围不同。

## 单选：哪句话放到辰时的记录里，既不漏报也不多报？ {#check.26.q5}
考点：g26.skill.all
语境：check.26.p.gift

- [x] 三舟未皆至，一舟已到岸
- [ ] 三舟皆至，只是一舟有人接
  理由：另两艘仍在江心，没写接船人员多少。
- [ ] 三舟皆未到岸
  理由：一舟确实已泊。

提示：用“一舟已泊”和“二舟犹在江心”分别核查。
解析：“未皆”容得下一到二未到。“皆未”会抹掉已经停靠的一舟。

## 单选：官吏特意补“一舟到岸而已”，比只说“舟至矣”多做到什么？ {#check.26.q6}
考点：g26.skill.end
语境：check.26.p.gift

- [ ] 宣布行船全程到此结束
  理由：二舟仍在江心。
- [x] 把来船的消息限定为已经靠岸的一艘
- [ ] 说明另外两艘以后永远不会来
  理由：“而已”限的是此时的报告，没预言其后。

提示：先看他随后否定了哪一种更强的说法。
解析：“而已”让这条消息不再被听成“三舟皆至”。末句所排除的是全数到岸。
