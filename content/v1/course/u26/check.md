# 检查：读史中的人与物综合练习 {#check.26}

## 原文：教学例句 {#p.vocab.check.26.1}
> 史官记师还，卒各归里。唯旧兵留库，库吏数其戈矛，列诸木架。
译文：史官记军队回来，士兵各自返乡。只有旧兵器留在库里，库吏清点戈矛，陈列于木架。

## 单选：首句由“师”转到“卒”，叙述角度怎样变化？ {#q.vocab.check.26.1}
考点：skill.vocab.16.4
语境：p.vocab.check.26.1

- [x] 从全军转到个人 {#q.vocab.check.26.1.o1}
- [ ] 从老师转到弟子 {#q.vocab.check.26.1.o2}
  理由：后文写军队还乡。
- [ ] 从兵器转到仓吏 {#q.vocab.check.26.1.o3}
  理由：首句仍在写人。

提示：与出征、班师、军中等集体情境对照。
解析：全军回来之后，士兵各归其里。

## 原文：教学例句 {#p.vocab.check.26.2}
> 简载春伐东邑，未克而退；秋复至，始克其邑，郡以其图上。
译文：简册记春天出兵征讨东邑，未能攻克便撤退；秋天再到，才攻下那座城邑，郡里把该邑的地图上报。

## 单选：春天的行动达到了何种程度？ {#q.vocab.check.26.3}
考点：skill.vocab.17.1
语境：p.vocab.check.26.2

- [ ] 春天已占东邑 {#q.vocab.check.26.3.o1}
  理由：后文“未克而退”。
- [ ] 只议定出兵未行动 {#q.vocab.check.26.3.o2}
  理由：已写“伐”且后有退兵。
- [x] 已经出兵，但未占得该邑 {#q.vocab.check.26.3.o3}

提示：对象是国家、叛乱者或敌方时，看有无出师。
解析：“伐”说行动，“未克”说当时的结果。

## 原文：教学例句 {#p.vocab.check.26.3}
> 驿报车六乘。发布甲十领、食三十石，分载六车；至郡，吏检粮数，乃署券。
译文：驿站报告有车六辆。发出布制护甲十领、粮食三十石，分由六辆车装载。到郡里，官吏核验粮数，才签署凭据。

## 单选：“六乘”计算什么？ {#q.vocab.check.26.5}
考点：skill.vocab.18.1
语境：p.vocab.check.26.3

- [ ] 铠甲件数 {#q.vocab.check.26.5.o1}
  理由：甲另以领计。
- [ ] 粮食容量 {#q.vocab.check.26.5.o2}
  理由：粮另以石计。
- [x] 运输车辆 {#q.vocab.check.26.5.o3}

提示：读 shèng；留意“车＋数＋乘”的计数格式。
解析：“车六乘”同“六车”前后互证。
