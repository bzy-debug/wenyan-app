# 检查：军队归来之后 {#check.26}

## 原文：教学例句 {#p.vocab.check.26.1}
> 史官记师还，卒各归里。唯旧兵留库，库吏数其戈矛，列诸木架。
译文：史官记道，军队归来，士卒各自还乡。只有旧兵器留在库里，库吏清点戈矛，陈列于木架。

## 单选：先说“师还”，再说“卒各归里”，前后写的是谁？ {#q.vocab.check.26.1}
考点：skill.vocab.16.4
语境：p.vocab.check.26.1

- [x] 从全军转到个人 {#q.vocab.check.26.1.o1}
- [ ] 从老师转到弟子 {#q.vocab.check.26.1.o2}
  理由：后文写军队还乡。
- [ ] 从兵器转到仓吏 {#q.vocab.check.26.1.o3}
  理由：首句仍在写人。

提示：“还”的是整支队伍，谁能各自回乡？
解析：先写全军归来，接着写队伍中的每一名士兵各回乡里。

## 找原文证据：库中留下的“兵”是哪类东西？选出最能看清这一点的原文。 {#q.vocab.check.26.2}
考点：skill.vocab.16.1
语境：p.vocab.check.26.1

- [x] 数其戈矛 {#q.vocab.check.26.2.o1}
- [ ] 卒各归里 {#q.vocab.check.26.2.o2}
  理由：“卒各归里”说士兵各自回家，没指明库中放着什么。
- [ ] 史官记师还 {#q.vocab.check.26.2.o3}
  理由：这一句记全军归来，清点库存是后面的事。

提示：库吏清点时点出了哪些具体物件？
解析：“戈矛”指明库存的是兵器，能分别清点、放上木架。

## 原文：教学例句 {#p.vocab.check.26.2}
> 简载春伐东邑，未克而退；秋复至，始克其邑，郡以其图上。
译文：简册记春天出兵征讨东邑，未能攻克便撤退；秋天再到，才攻下那座城邑，郡里把该邑的地图上报。

## 单选：春天攻东邑，那一回究竟打下来没有？ {#q.vocab.check.26.3}
考点：skill.vocab.17.1
语境：p.vocab.check.26.2

- [ ] 春天已占东邑 {#q.vocab.check.26.3.o1}
  理由：后文“未克而退”。
- [ ] 只议定出兵未行动 {#q.vocab.check.26.3.o2}
  理由：已写“伐”且后有退兵。
- [x] 已经出兵，但未占得该邑 {#q.vocab.check.26.3.o3}

提示：把“春伐”一直读到“未克而退”。
解析：春天出了兵，但没打下来就撤了。发起征讨和取得城邑是两件事。

## 单选：哪一季东邑才被攻下？ {#q.vocab.check.26.4}
考点：skill.vocab.17.2
语境：p.vocab.check.26.2

- [x] 秋季 {#q.vocab.check.26.4.o1}
- [ ] 春季 {#q.vocab.check.26.4.o2}
  理由：春天是“未克而退”，东邑还没有被攻下。
- [ ] 两季都是 {#q.vocab.check.26.4.o3}
  理由：春天有“未克”，秋天才有“始克”。

提示：找到“始克其邑”，往前看写的是何时又来。
解析：“秋复至”接着“始克”，说明秋天第二次到来才攻得此邑。

## 原文：教学例句 {#p.vocab.check.26.3}
> 驿报车六乘。发布甲十领、食三十石，分载六车；至郡，吏检粮数，乃署券。
译文：驿站报告有车六辆。发出布制护甲十领、粮食三十石，分由六辆车装载。到郡里，官吏核验粮数，才签署凭据。

## 单选：驿站报“六乘”，数的是什么？ {#q.vocab.check.26.5}
考点：skill.vocab.18.1
语境：p.vocab.check.26.3

- [ ] 铠甲件数 {#q.vocab.check.26.5.o1}
  理由：甲另以领计。
- [ ] 粮食容量 {#q.vocab.check.26.5.o2}
  理由：粮另以石计。
- [x] 运输车辆 {#q.vocab.check.26.5.o3}

提示：后面怎样用同一个数目说这些车？
解析：前面说“车六乘”，装载时又说“六车”，两处是同一批车。

## 单选：郡吏验粮，应当对照文书上的哪一项？ {#q.vocab.check.26.6}
考点：skill.vocab.18.4
语境：p.vocab.check.26.3

- [x] 三十石食 {#q.vocab.check.26.6.o1}
- [ ] 十领护甲 {#q.vocab.check.26.6.o2}
  理由：被清点的是粮。
