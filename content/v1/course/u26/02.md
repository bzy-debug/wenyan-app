# 课文：“皆未至”和“未皆至”差在哪里 {#g26.2}
简介：遇见“皆”“惟”，先标出谈的是谁，再找否定或条件究竟落到哪一步。

## 正文

同是三人赴约：“三人皆未至”，三个人一个都没到；若说“三人未皆至，甲乙已坐”，只是还没到齐。一个“未”的位置，关系到屋里究竟有没有人。

“惟一人识路”把能识路的人缩到一位。“一人惟识东路”却把这个人熟悉的路缩到东路。“惟”后面接人还是接行动、东西，要回到各自的句子看。

## 知识点：皆与否定的位置 {#g26.skill.all}
义项：人人未做和未必人人都做要分清
领域：虚词
要诀：用少量具体人名试一遍，谁已经做、谁还没做？
讲解：“诸舟未皆返”只保证没有全数返回。若不另报船数，还不能算出仍在江上的有几艘。
例句：g26.ex.all

## 原文：教学例句 {#g26.ex.all}
> 四客皆未入，门犹闭。
译文：四位客人都还没有进去，门仍关着。

## 知识点：惟限定紧随的对象或事情 {#g26.skill.only}
义项：只许这类人，或只做这件事
领域：虚词
要诀：看“只有……”后面是人、物还是某一行动。
讲解：“惟甲读此书”限定读者，“甲惟读此书”限定甲所读的书。二者都未说另一切书不能由别人读。
例句：g26.ex.only

## 原文：教学例句 {#g26.ex.only}
> 十舟中，惟渔舟可入浅浦。
译文：十艘船中只有渔船能进这处浅滩港汊。

## 原文：古籍引文 {#g26.2.p.mind}
> 无恒产而有恒心者，惟士为能。
译文：没有稳定的产业而仍能守住恒心，孟子认为只有士能够做到。

## 单选：孟子用“惟士”限定的是哪一层？ {#g26.2.q1}
考点：g26.skill.only
语境：g26.2.p.mind

- [ ] 士这一生只会守恒心，别事不能做
  理由：被限定的是“为能”的人，不是士的所有本领。
- [x] 他认为，在无恒产的条件下能守住恒心的是哪类人
- [ ] 凡有恒产的人也只有士才有恒心
  理由：前面说的恰是“无恒产”，不能径自换条件。

提示：把“无恒产而有恒心”整组先保留下来。
解析：“者”先提出要讨论的这一种情形，“惟”才把能者限在士。这个说法是孟子的判断。

## 原文：教学例句 {#g26.2.p.seats}
> 约三客于亭。吏初至，曰：“三客皆未至。”须臾甲乙至，丙犹在途。吏更记曰：“三客未皆至。”
译文：约了三位客人在亭子相会。官吏最初到，说：“三位客人都还没到。”片刻后甲乙到了，丙还在路上。官吏改记：“三位客人还没到齐。”
词注：须臾：一会儿。
  更：这里是更改先前的记录。

## 单选：若把第二次仍记成“三客皆未至”，会抹掉什么事实？ {#g26.2.q2}
考点：g26.skill.all
语境：g26.2.p.seats

- [ ] 丙还没到
  理由：这一点旧记和新记都没有说丙已到。
- [ ] 三人原来有约
  理由：无论两次怎样记，开头都有约。
- [x] 甲乙已经到了

提示：把甲、乙、丙分别放入“皆未至”里试一遍。
解析：甲乙的到场让“全没到”失真。还可以说的是“没全到”，即“未皆至”。

## 找原文证据：哪几个字是官吏仍不能写“三客皆至”的依据？ {#g26.2.q3}
考点：g26.skill.all
语境：g26.2.p.seats

- [ ] 甲乙至
  理由：这只说明已有二人抵达。
- [ ] 吏更记曰
  理由：这是改记录的动作。
- [x] 丙犹在途

提示：要否定“全到”，找到一个仍未到的人就够。
解析：“丙犹在途”特意点出尚缺的一人，所以未到齐。

## 原文：教学例句 {#g26.2.p.colors}
> 架有青、赤、白三帛。诸女皆取帛，甲惟取青，乙兼取赤白，丙取赤。
译文：架上有青、红、白三色丝帛。几位女子都取了帛，甲只拿青色，乙同时拿红白两色，丙拿红色。

## 单选：可不可以据“甲惟取青”推断“除了甲，没有人取帛”？ {#g26.2.q4}
考点：g26.skill.only
语境：g26.2.p.colors

- [ ] 可以，惟在这里直接特指甲一人
  理由：“惟”在甲以后，下文还说乙丙各自拿帛。
- [x] 不可以，限定的是甲所取的颜色
- [ ] 不可以，因为甲其实也拿了红帛
  理由：拿红帛的是乙、丙，甲只拿青帛。

提示：谁取了什么颜色，要把“皆”和“惟”分开读。
解析：“诸女皆取帛”已把三人都包括进来。“惟”只在甲个人的选择中排除了另两色。

## 单选：据“诸女皆取帛”，为什么还要读下一层才能记各人领了几种颜色？ {#g26.2.q5}
考点：g26.skill.all
语境：g26.2.p.colors

- [x] “皆”只说明每个人都取过，未说所取颜色一样多
- [ ] “皆”说明每个人三色全拿
  理由：甲惟取青，只有乙兼取二色。
- [ ] “皆”只说明架上三色俱全，没说取的人
  理由：“诸女”才是“皆取”的人。

提示：先找“皆”所连的动作，再看乙的“兼”。
解析：人人取了，不等于人人取全。乙一人取两色，正好显示两种说法有别。

## 原文：教学例句 {#g26.2.p.gate}
> 四门皆闭，惟西门留小隙，尚不足以通人。俄，吏启南门，众由南出。
译文：四座门都关了，只有西门还留一道小缝，不过不足以让人通过。不久，官吏打开南门，众人从南门出去。

## 单选：“惟西门留小隙”能让你在开南门以前就画出一条可走的出路吗？ {#g26.2.q6}
考点：g26.skill.only
语境：g26.2.p.gate

- [ ] 能，只有西门留缝，就是只有西门可出
  理由：紧接着已说“不足以通人”。
- [ ] 能，有一门没有关过，南门本来敞开
  理由：吏到后来才开南门。
- [x] 不能，只有西门留缝，并不足以让人穿过

提示：把“惟”确实限制的“留小隙”读全。
解析：留缝不是能通人。限定这一小处，不能把它扩大成另一个性质。

## 原文：教学例句 {#g26.2.p.store}
> 吏视三仓，二仓已空，一仓有粟。主簿欲书“仓皆空”，吏止之。夜惟发有粟之仓，以济饥者。
译文：官吏查看三个粮仓，两仓已空，一仓还有粮。主簿想记录“仓全空了”，官吏制止了他。夜里只打开有粮的那一仓，接济饥民。

## 找原文证据：哪处是不能写“仓皆空”的直接反例？ {#g26.2.q7}
考点：g26.skill.all
语境：g26.2.p.store

- [ ] 以济饥者
  理由：这是开仓的用途，不是当时查看的库存。
- [ ] 二仓已空
  理由：这能说明有空仓，还不能证明三仓全空。
- [x] 一仓有粟

提示：让“全空”同三座仓逐一核对。
解析：三仓中已有一仓存粮，便足以推翻“皆空”；即便另外两仓确实没有粮也一样。

## 单选：为什么夜里的动作没有把前面的记载改回“仓皆空”？ {#g26.2.q8}
考点：g26.skill.only
语境：g26.2.p.store

- [ ] 有粟之仓整夜仍未打开
  理由：“夜惟发”已经记下开仓。
- [x] 只说开哪一仓救饥，没说仓内粮食全数发尽
- [ ] 惟发一仓就表示三仓全被清空
  理由：其他两仓本已空，“发”也不是数量。

提示：区分开仓和把粮发尽。
解析：“惟”限定开的仓，没限定发粮的数量。末句不能证明散尽了最后一粒。
