# 检查：一张田契和一条学人的办法 {#check.2}

## 原文：教学例句 {#p.check.2.r1}
> 客遗田契于途。农夫见之，藏于其笥。暮有三客来问，其一能言契上之名。农夫取契而示之，余二人视之久，而不能言。
译文：有人把田契遗失在路上。农夫发现田契，收在自己的箱子里。傍晚有三位客人来问，其中一个能说出契上的姓名。农夫取出田契给他们看，另外两人看了很久，却说不出那个姓名。
词注：遗：读 yí，遗失在路上。
  田契：记载田地归属等事项的文书。
  笥：装物的箱子，读 sì。

## 原文：古籍引文 {#p.check.2.r2}
> 三人行，必有我师焉。择其善者而从之，其不善者而改之。
译文：几个人一起走，其中总有值得我学习的人。我选取他们的长处来效法，看出他们的不足便反省自己，加以改正。
词注：焉：在其中，指同行的几个人当中。
  择：挑选。
  从：照着别人的长处学。

## 单选：“农夫见之”中的“之”，怎样补得具体？ {#q.check.2.1}
考点：skill.zhi-object
语境：p.check.2.r1

- [ ] 农夫在路上看见三位客人 {#q.check.2.1.o1}
  理由：三客是在傍晚才来的。
- [ ] 农夫看见自己的箱子 {#q.check.2.1.o2}
  理由：箱子是看见田契以后用来收存它的。
- [x] 农夫看见路上遗落的田契 {#q.check.2.1.o3}
  理由：“之”接住上句的“田契”。同一物件后来还会从箱中被拿出来。

提示：看“见”之前有人丢了什么。
解析：“之”接住上句的“田契”。同一物件后来还会从箱中被拿出来。

## 找原文证据：三人中有一个能说出哪段信息？ {#q.check.2.2}
考点：skill.zhi-link
语境：p.check.2.r1

- [ ] 余二人 {#q.check.2.2.o1}
  理由：这是另外两名来客，没说能报出什么信息。
- [x] 契上之名 {#q.check.2.2.o2}
  理由：“契上”说明姓名在什么地方，“之”将它和“名”连成一处。
- [ ] 藏于其笥 {#q.check.2.2.o3}
  理由：这几个字说的是农夫把田契放在哪里。

提示：在“能言”后找一个完整名称。
解析：“契上”说明姓名在什么地方，“之”将它和“名”连成一处。

## 单选：“其一”让哪一个判断有了把握？ {#q.check.2.3}
考点：skill.qi-part
语境：p.check.2.r1

- [ ] 三人一起报出了同一个姓名 {#q.check.2.3.o1}
  理由：后文说另外两个人都说不出。
- [x] 来询问的三人中有一个能报出姓名 {#q.check.2.3.o2}
  理由：三人中一人能答，另外两人不能。“其一”是在三人中取其一。
- [ ] 第一个到场的人一定就是失主 {#q.check.2.3.o3}
  理由：“其一”只说其中一人，没有交代到场次序，也没有明断失主身份。

提示：先数来客，再看“余二人”。
解析：三人中一人能答，另外两人不能。“其一”是在三人中取其一。

## 单选：“取契而示之”讲的是怎样的动作？ {#q.check.2.4}
考点：skill.er-sequence
语境：p.check.2.r1

- [x] 先拿出田契，接着展示给来人 {#q.check.2.4.o1}
  理由：先取方能出示。这里的“而”顺着农夫的手上动作往下说。
- [ ] 没有取出田契，只说给来人听 {#q.check.2.4.o2}
  理由：“取契”是实际拿取，后面才有“示”。
- [ ] 想拿出田契，却找不到 {#q.check.2.4.o3}
  理由：“视之久”表明来人已经看到了田契。

提示：“取”与“示”能不能连着做？
解析：先取方能出示。这里的“而”顺着农夫的手上动作往下说。

## 单选：已“视之久”，却仍有哪些信息没有报出？ {#q.check.2.5}
考点：skill.er-turn
语境：p.check.2.r1

- [x] 契上所写的姓名 {#q.check.2.5.o1}
  理由：见到田契本来更有机会答出来，偏偏两人看了很久仍说不出姓名。
- [ ] 田契归农夫保管的时辰 {#q.check.2.5.o2}
  理由：傍晚说的是来客到场，全文没让谁报保管时辰。
- [ ] 箱子的大小与颜色 {#q.check.2.5.o3}
  理由：前文用“能言契上之名”定下了比较的事情。

提示：把“能言”与“不能言”放在一起读。
解析：见到田契本来更有机会答出来，偏偏两人看了很久仍说不出姓名。

## 单选：“择其善者而从之”，其中可供选择的长处属于谁？ {#q.check.2.6}
考点：skill.qi-possessive
语境：p.check.2.r2

- [x] 同行的人 {#q.check.2.6.o1}
  理由：“其善者”是同行者身上好的地方。前头出现了人，后头才说取他们的长处。
- [ ] 自己已经有的所有长处 {#q.check.2.6.o2}
  理由：“从之”是向他人学习。
- [ ] 旁观路人以外的某位名师 {#q.check.2.6.o3}
  理由：开头正是从同行的人中找老师。

提示：想想能当“我师”的人从哪里来。
解析：“其善者”是同行者身上好的地方。前头出现了人，后头才说取他们的长处。
