# 课文：其的常见用法 {#l1.5}
简介：“其冠”可以问“谁的帽子”，“其一”则要先看看一共有几个。

## 正文

“客持杖，童扶其杖。”这句教学例句里，客人手里拿着杖，孩子扶的是谁的杖？把“客人的”放回去就读通了。

再读一句教学例句：“客有三杖，取其一。”客人先有三根杖，拿起其中一根。遇到“其二”“其三”，往前找一找总数。假如有四支箭，取后只剩一支，那么取的是其中三支。若只挑走排第三的那一支，就该剩下三支了。

同一句里也有两个“其”都指同一个人的时候。在《论语》那句谈工匠的话里，把他的工作和他的工具放在一起想就清楚了。

## 知识点：其 {#skill.qi-possessive}
义项：指前述人或物所属
领域：虚词
要诀：“其衣”是谁的衣服？
讲解：先前出现过谁，东西又归谁？“童患雨湿其衣”说孩子担心雨淋湿自己的衣裳。
例句：p.ex.qi-possessive

## 知识点：其 {#skill.qi-part}
义项：其中的
领域：虚词
要诀：先数一数原来有几个。
讲解：“二树”后面跟“其一”，说的是两棵当中的一棵。有余数时，还可以看看剩下的数目合不合。
例句：p.ex.qi-part

## 原文：教学例句 {#p.ex.qi-possessive}
> 童患雨湿其衣。
译文：孩子担心雨淋湿自己的衣服。

## 原文：教学例句 {#p.ex.qi-part}
> 庭有二树，其一已枯。
译文：院里有两棵树，其中一棵已经枯了。

## 原文：教学例句 {#p.l1.5.cap}
> 童临池，风吹其冠入水。
译文：孩子来到池边，风把他的帽子吹进水里。

## 单选：谁的帽子落入水中？ {#q.l1.5.1}
考点：skill.qi-possessive
语境：p.l1.5.cap

- [x] 孩子的 {#q.l1.5.1.o1}
- [ ] 风的 {#q.l1.5.1.o2}
  理由：风能吹动帽子，但帽子是谁戴的？
- [ ] 池塘的 {#q.l1.5.1.o3}
  理由：池塘写落帽地点。再看站在池边的人。

提示：是谁来到池边？
解析：到池边的是孩子，风把他头上的帽子吹进了水里。

## 原文：教学例句 {#p.l1.5.carts}
> 庭前有三车，其一无轮。
译文：庭前有三辆车，其中一辆缺轮子。

## 单选：缺轮子的是庭前的几辆车？ {#q.l1.5.2}
考点：skill.qi-part
语境：p.l1.5.carts

- [x] 三辆中有一辆 {#q.l1.5.2.o1}
- [ ] 另外增添一辆 {#q.l1.5.2.o2}
  理由：“其”回指已说到的哪几辆车？
- [ ] 三辆车全部 {#q.l1.5.2.o3}
  理由：“一”能指三辆车都一样吗？

提示：看“一”前面给出的总数。
解析：庭前有三辆车，“其一”说其中一辆，没有说另外两辆也缺轮子。

## 原文：教学例句 {#p.l1.5.nest}
> 燕归，衔泥补其巢。
译文：燕子回来了，衔着泥修补自己的巢。

## 找原文证据：是谁衔泥回去修自己的巢？ {#q.l1.5.3}
考点：skill.qi-possessive
语境：p.l1.5.nest

- [ ] 泥 {#q.l1.5.3.o1}
  理由：泥是用来补巢的材料。谁衔着泥回来？
- [x] 燕 {#q.l1.5.3.o2}
- [ ] 巢 {#q.l1.5.3.o3}
  理由：巢是被修的。找出归来的主人。

提示：找会衔泥筑巢的生物。
解析：归来、衔泥、补巢，做这三件事的都是燕子。“其巢”就是燕子自己的巢。

## 原文：教学例句 {#p.l1.5.stones}
> 匠取五石，择其二以为阶，余三留之。
译文：工匠取来五块石头，挑其中两块做台阶，把其余三块留下。

## 单选：用来做台阶的石头有多少块？ {#q.l1.5.4}
考点：skill.qi-part
语境：p.l1.5.stones

- [ ] 另找来的两块 {#q.l1.5.4.o1}
  理由：前文总共取了几块？有再取一次吗？
- [x] 五块中的两块 {#q.l1.5.4.o2}
- [ ] 五块全部 {#q.l1.5.4.o3}
  理由：留着的三块也用来做台阶了吗？

提示：先有总数，再有被选出的数量。
解析：工匠一共取五块，留下三块，用掉的正好是两块。“其二”读作其中两块。

## 原文：教学例句 {#p.l1.5.wound}
> 马足伤，主人洗其足。
译文：马脚受伤了，主人给它洗脚。

## 单选：“洗其足”中“其”回指谁？ {#q.l1.5.5}
考点：skill.qi-possessive
语境：p.l1.5.wound

- [ ] 医者 {#q.l1.5.5.o1}
  理由：原文里出现了医者吗？
- [ ] 马主人 {#q.l1.5.5.o2}
  理由：虽然主人在洗，受伤的脚是谁的？
- [x] 受伤的马 {#q.l1.5.5.o3}

提示：谁的脚在上句受伤？
解析：上句先说马脚有伤，“其足”便是这匹马的脚。主人是替它清洗的人。

## 原文：教学例句 {#p.l1.5.pear}
> 盘中四梨，其一有斑，余皆洁。
译文：盘中有四个梨，其中一个有斑点，其余都干净。

## 找原文证据：盘里一共有几个梨？选出原文里的说法。 {#q.l1.5.6}
考点：skill.qi-part
语境：p.l1.5.pear

- [ ] 盘 {#q.l1.5.6.o1}
  理由：盘是放梨的地方，数的是盘里的梨。
- [ ] 斑 {#q.l1.5.6.o2}
  理由：斑是外观特征。找前文所数的事物。
- [x] 四梨 {#q.l1.5.6.o3}

提示：先找带有总数的词组。
解析：一共有“四梨”，其中一个有斑。先读总数，就知道“其一”从哪里数起了。

## 单选：“其事”和“其器”，是谁的工作和工具？ {#q.l1.5.7}
考点：skill.qi-possessive
语境：p.l1.5.coat

- [ ] 前者是工匠的，后者是买主的 {#q.l1.5.7.o1}
  理由：读完整句，作者交代了另一位买主吗？
- [x] 两处都可补成“工匠的” {#q.l1.5.7.o2}
  理由：工作和工具都与句首的“工”有关。
- [ ] 两处都指其中的一件 {#q.l1.5.7.o3}
  理由：“事”和“器”前面给出过总数吗？

提示：先找全句唯一明确出现的人物，再把他的身份放回两处。
解析：开头只说了一位工匠。要做好的是他的工作，要先磨利的也是他的工具。

## 原文：教学例句 {#p.l1.5.seeds}
> 翁种三核，其二生芽，一不生。
译文：老人种下三个果核，其中两个发了芽，还有一个没发芽。

## 单选：三颗果核里，发芽的有几颗？ {#q.l1.5.8}
考点：skill.qi-part
语境：p.l1.5.seeds

- [ ] 三个都发了芽 {#q.l1.5.8.o1}
  理由：末尾还有“一不生”，三颗都发芽了吗？
- [ ] 又种下的第二批果核 {#q.l1.5.8.o2}
  理由：“种”出现了几次？有第二批吗？
- [x] 原先三个果核中的两个 {#q.l1.5.8.o3}

提示：对照“其二”和“一不生”。
解析：三颗里有两颗发芽，后面还留着“一不生”。这里的“二”说数量，不是排列的次序。
