# 课文：其的常见用法 {#l1.5}
简介：找“其”所依的上文，分别读清物主和从整体中选出的部分。

## 正文

### 两个“其”，要补的内容不同

教学例句：“客持杖，童扶其杖。”“客有三杖，取其一。”前句可以问“谁的杖”，答案由前面的“客”给出；后句先给出三根，后面才从中选一根。两种读法都要往前找，但一处寻找所属，一处寻找整体。

**还原试读。** 将“其门”补成“这户人家的门”，若前文刚出现这家主人，语义可能合适。将“其一”补成“这些东西中的一个”，则要有已给出的集合；若刚写“二瓮”，就能回答“哪个范围中的一个”。

**别见数字就猜序数。** 若原文既交代总数，又说剩下多少，可以用余数来验证。例如四支箭，取走三支只余一支；如果只选“第三支”，数量就合不上。这是用上下文排除另一种可能，而非死背“其二”的唯一解释。

后面一题有两个“其”。遇到重复的字，可以分别把同一人物补回，看他与事情、器物的关系是否都成立。

## 知识点：其 {#skill.qi-possessive}
义项：指前述人或物所属
领域：虚词
要诀：名词前的领属代词
讲解：“其”后若是衣、门、子等名词，可问“谁的”。用上文给出的人或物来补足。
例句：p.ex.qi-possessive

## 知识点：其 {#skill.qi-part}
义项：其中的
领域：虚词
要诀：从已知整体取一部分
讲解：“其一”“其二”放在一个明确的集合之后，常表示其中的一个或两个。先数清前文给出的整体。
例句：p.ex.qi-part

## 原文：教学例句 {#p.ex.qi-possessive}
> 童患雨湿其衣。
译文：孩子担心雨淋湿自己的衣服。

## 原文：教学例句 {#p.ex.qi-part}
> 庭有二树，其一已枯。
译文：院里有两棵树，其中一棵已经枯了。

## 原文：教学例句 {#p.l1.5.cap}
> 童临池，风吹其冠入水。
译文：孩子来到池边，风把他的帽子吹进水里。

## 单选：谁的帽子落入水中？ {#q.l1.5.1}
考点：skill.qi-possessive
语境：p.l1.5.cap

- [x] 孩子的 {#q.l1.5.1.o1}
- [ ] 风的 {#q.l1.5.1.o2}
  理由：风是施力者，不能拥有帽子。
- [ ] 池塘的 {#q.l1.5.1.o3}
  理由：池是落帽的地方。

提示：是谁来到池边？
解析：“其冠”指上文孩子的帽子。

## 原文：教学例句 {#p.l1.5.carts}
> 庭前有三车，其一无轮。
译文：庭前有三辆车，其中一辆缺轮子。

## 单选：“其一”限定了多大的范围？ {#q.l1.5.2}
考点：skill.qi-part
语境：p.l1.5.carts

- [x] 三辆中有一辆 {#q.l1.5.2.o1}
- [ ] 另外增添一辆 {#q.l1.5.2.o2}
  理由：“其”回指已有的三辆车。
- [ ] 三辆车全部 {#q.l1.5.2.o3}
  理由：“一”只从三辆中取一辆。

提示：看“一”前面给出的总数。
解析：先说三车，随后“其一”选出其中一辆。

## 原文：教学例句 {#p.l1.5.nest}
> 燕归，衔泥补其巢。
译文：燕子回来了，衔着泥修补自己的巢。

## 选段：点选“其巢”的主人。 {#q.l1.5.3}
考点：skill.qi-possessive
语境：p.l1.5.nest

- [ ] 泥 {#q.l1.5.3.o1}
  理由：泥是补巢的材料。
- [x] 燕 {#q.l1.5.3.o2}
- [ ] 巢 {#q.l1.5.3.o3}
  理由：巢是被修补的东西。

提示：找会衔泥筑巢的生物。
解析：归来衔泥的是燕，所补的巢也属于燕。

## 原文：教学例句 {#p.l1.5.stones}
> 匠取五石，择其二以为阶，余三留之。
译文：工匠取来五块石头，挑其中两块做台阶，把其余三块留下。

## 单选：用来做台阶的石头有多少块？ {#q.l1.5.4}
考点：skill.qi-part
语境：p.l1.5.stones

- [ ] 另找来的两块 {#q.l1.5.4.o1}
  理由：“其”承接前面取来的五块。
- [x] 五块中的两块 {#q.l1.5.4.o2}
- [ ] 五块全部 {#q.l1.5.4.o3}
  理由：“择”与“二”限制了数量。

提示：先有总数，再有被选出的数量。
解析：由“余三”倒推，五块中用掉两块。“其二”是其中的两块。

## 原文：教学例句 {#p.l1.5.wound}
> 马足伤，主人洗其足。
译文：马脚受伤了，主人给它洗脚。

## 单选：“洗其足”中“其”回指谁？ {#q.l1.5.5}
考点：skill.qi-possessive
语境：p.l1.5.wound

- [ ] 医者 {#q.l1.5.5.o1}
  理由：原文没有医者。
- [ ] 马主人 {#q.l1.5.5.o2}
  理由：前句明说受伤的是马脚。
- [x] 受伤的马 {#q.l1.5.5.o3}

提示：谁的脚在上句受伤？
解析：“马足伤”解释为什么要洗，“其足”承接这匹马的脚。

## 原文：教学例句 {#p.l1.5.pear}
> 盘中四梨，其一有斑，余皆洁。
译文：盘中有四个梨，其中一个有斑点，其余都干净。

## 选段：“其一”是从哪一组事物中取出一个？ {#q.l1.5.6}
考点：skill.qi-part
语境：p.l1.5.pear

- [ ] 盘 {#q.l1.5.6.o1}
  理由：盘是盛梨的容器。
- [ ] 斑 {#q.l1.5.6.o2}
  理由：斑是一个梨上的特征。
- [x] 四梨 {#q.l1.5.6.o3}

提示：先找带有总数的词组。
解析：“其一”的范围是盘中的四个梨。

## 原文：古籍引文 {#p.l1.5.coat}
> 工欲善其事，必先利其器。
译文：工匠想做好自己的工作，必须先让自己的工具锋利好用。

## 单选：读“其事”“其器”，两处“其”分别该补成谁的？ {#q.l1.5.7}
考点：skill.qi-possessive
语境：p.l1.5.coat

- [ ] 前者是工匠的，后者是买主的 {#q.l1.5.7.o1}
  理由：句中没有引入买主，不能补出新的主人。
- [x] 两处都可补成“工匠的” {#q.l1.5.7.o2}
  理由：工作和工具都与句首的“工”有关。
- [ ] 两处都指其中的一件 {#q.l1.5.7.o3}
  理由：两处“其”后是事与器，分别说明所属，并未从某一组中计数。

提示：先找全句唯一明确出现的人物，再把他的身份放回两处。
解析：把前半句改说成“工欲善工之事”，后半句沿用同一人物。语义贯通，不需要另找一个主人。

## 原文：教学例句 {#p.l1.5.seeds}
> 翁种三核，其二生芽，一不生。
译文：老人种下三个果核，其中两个发芽，一个没有发芽。

## 单选：发芽的是哪部分？ {#q.l1.5.8}
考点：skill.qi-part
语境：p.l1.5.seeds

- [ ] 三个都发了芽 {#q.l1.5.8.o1}
  理由：最后明说“一不生”。
- [ ] 又种下的第二批果核 {#q.l1.5.8.o2}
  理由：文中只有一次种核。
- [x] 原先三个果核中的两个 {#q.l1.5.8.o3}

提示：对照“其二”和“一不生”。
解析：“其二”从“三核”中取二，与剩下的一个相对。
