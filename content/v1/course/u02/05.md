# 课文：作坊里的“其”：谁的、其中的 {#l1.5}
简介：“其刀”说谁用的刀，“取其一”说从几件东西中拿一件。

## 正文

“陶者有二徒”先带出两名徒弟。写“其一善画”时，作者没有给其中一位取名；这里数的是两人里的一个。若接着说“陶者失其刀”，旁边虽然也站着徒弟，失主却是这句开头的陶工，“其刀”指他用的刀。

同一个“其”后面跟“刀”还是跟“一”，会改变你该回头找什么：找刀的主人，或找可供挑选的一组人和物。

## 知识点：其 {#skill.qi-possessive}
义项：他（它）的，指明后面事物的归属
领域：虚词
要诀：先读“其”后面的名称，再找是谁的。
讲解：“利其器”中的器具属于那位准备做事的工匠。
例句：p.l1.5.r1

## 知识点：其 {#skill.qi-part}
义项：其中的，从前面一组人或物中取一部分
领域：虚词
要诀：找前面一共有几人几物，再看这次取几个。
讲解：“其一”是若干人或物中的一个；“其二”在数目清楚的句中也可指其中两个。
例句：p.l1.5.r2

## 原文：古籍引文 {#p.l1.5.r1}
> 工欲善其事，必先利其器。
译文：工匠想把自己的活儿做好，必定先让自己的工具锋利。
词注：工：工匠，指做活的人。
  利：使锋利，这里是磨利手头的工具。
  器：做工用的器具。

## 原文：教学例句 {#p.l1.5.r2}
> 陶者有二徒，其一善画，其一善刻。陶者失其刀，问二徒。善刻者自案下取刀还之。
译文：陶工有两个徒弟，一个善画，一个善刻。陶工丢了自己的刀，便问两人。善刻的徒弟从桌案下取出刀来还他。
词注：陶者：制作陶器的工匠。
  徒：跟师傅学手艺的人。
  案：桌案，徒弟在桌下找到刀。

## 原文：教学例句 {#p.l1.5.r3}
> 舟人使其子取帆，曰：“舟中有三帆，取其一来。”子见一帆已裂，乃择完者授父。
译文：船夫叫儿子取帆，说：“船里有三张帆，拿一张来。”儿子见有一张已经裂了，便挑了完好的交给父亲。
词注：舟人：操船的人。
  完：完整、没有破损，指可以拿来用的帆。
  裂：扯开、破开，这张帆已不能照常使用。

## 单选：“其器”是谁要用的工具？ {#q.l1.5.1}
考点：skill.qi-possessive
语境：p.l1.5.r1

- [x] 准备干活的工匠的 {#q.l1.5.1.o1}
  理由：“工”领起整句。工匠要做好自己的事，先磨利自己手上的工具。
- [ ] 等着拿成品的客人的 {#q.l1.5.1.o2}
  理由：句里出场的是“工”，没有另提买主。
- [ ] 所有同行共有的 {#q.l1.5.1.o3}
  理由：“其事”和“其器”都从眼前这位工匠说起，没有说大家合用。

提示：从句首找想把工作做好的人。
解析：“工”领起整句。工匠要做好自己的事，先磨利自己手上的工具。

## 单选：若把工匠换成木匠，这句话最适合配哪幅图？ {#q.l1.5.2}
考点：skill.qi-possessive
语境：p.l1.5.r1

- [x] 木匠先磨自己的刨刃，再刨木料 {#q.l1.5.2.o1}
  理由：工匠换成木匠，事与器都随之落实：刨木是他的事，刨刃是他的器。
- [ ] 木匠摆出别人的成品叫卖 {#q.l1.5.2.o2}
  理由：“其器”是他的工具，还没有写到做成的物件。
- [ ] 旁人做完木器，木匠才来收拾工具 {#q.l1.5.2.o3}
  理由：“必先”把利器放在做事之前。

提示：“其事”是木匠的活，“其器”跟着谁变？
解析：工匠换成木匠，事与器都随之落实：刨木是他的事，刨刃是他的器。

## 单选：“其一善画”的“一”从哪一组里数出来？ {#q.l1.5.3}
考点：skill.qi-part
语境：p.l1.5.r2

- [ ] 陶工的两把刻刀 {#q.l1.5.3.o1}
  理由：“善画”要由人来做，前句明说“二徒”。
- [x] 陶工的两名徒弟 {#q.l1.5.3.o2}
  理由：“二徒”先把两人合在一起，“其一”再从中点出一人。
- [ ] 陶工与来客 {#q.l1.5.3.o3}
  理由：这一段没有来客，陶工是在介绍自己的徒弟。

提示：往前找和“一”照应的数目。
解析：“二徒”先把两人合在一起，“其一”再从中点出一人。

## 单选：从哪句话能看出丢刀的是师傅？ {#q.l1.5.4}
考点：skill.qi-possessive
语境：p.l1.5.r2

- [ ] “问二徒”，谁被问谁就丢了刀 {#q.l1.5.4.o1}
  理由：是师傅向两人询问。结尾徒弟还刀给他。
- [x] “陶者失其刀”，失物人是陶工 {#q.l1.5.4.o2}
  理由：“陶者”是丢东西的人。“其刀”把刀归到他名下。
- [ ] “善刻者”会刻，刀必定是他的 {#q.l1.5.4.o3}
  理由：擅长刻字说明徒弟会用刀，不能说明这把刀是他的。

提示：把“失”前面的人名读出来。
解析：“陶者”是丢东西的人。“其刀”把刀归到他名下。

## 找原文证据：两个徒弟中，最后替师傅找回刀的是哪一个？ {#q.l1.5.5}
考点：skill.qi-part
语境：p.l1.5.r2

- [ ] 善画 {#q.l1.5.5.o1}
  理由：这里交代另一位徒弟的本领，结尾没有叫他取刀。
- [ ] 陶者失其刀 {#q.l1.5.5.o2}
  理由：这是师傅丢失刀具，尚未说谁找回。
- [x] 善刻者 {#q.l1.5.5.o3}
  理由：“善刻者”就是两徒中善于雕刻的那位，他从案下取回了刀。

提示：“其一”先把徒弟分成两位，下文再用本领认人。
解析：“善刻者”就是两徒中善于雕刻的那位，他从案下取回了刀。

## 单选：船夫叫人“取其一来”，怎样才算照吩咐做了？ {#q.l1.5.6}
考点：skill.qi-part
语境：p.l1.5.r3

- [ ] 按摆放顺序取第一张 {#q.l1.5.6.o1}
  理由：“其一”在这里说的是数量，没说哪张排在头里。
- [x] 从船里的三张帆中拿一张 {#q.l1.5.6.o2}
  理由：“三帆”先划定了范围，“其一”指这几张中的一张。
- [ ] 把孩子自己的一张帆带来 {#q.l1.5.6.o3}
  理由：父亲刚说的“三帆”就在船里，没有让孩子另拿自家的东西。

提示：把父亲两句吩咐连起来读。先有几张，再要几张？
解析：“舟中有三帆”交代可选的数目，孩子只需从中取一张。该挑哪张，要看帆是否完好。

## 找原文证据：开头叫孩子“其子”。从孩子这边读，哪处能看出他与接帆人是什么关系？ {#q.l1.5.7}
考点：skill.qi-possessive
语境：p.l1.5.r3

- [ ] 取帆 {#q.l1.5.7.o1}
  理由：这说的是船夫派下的差事，还看不出二人的辈分。
- [ ] 择完者 {#q.l1.5.7.o2}
  理由：这里儿子在比较哪一张帆能用，并未说交到谁手里。
- [x] 授父 {#q.l1.5.7.o3}
  理由：“授父”明说儿子把选好的帆交给父亲。回头看，“舟人使其子”就是船夫派自己的儿子。

提示：谁在开头吩咐、结尾接帆？儿子怎样称呼他？
解析：发话的舟人与最后接帆的父亲是同一人。开头从父亲说“其子”，结尾从孩子说“授父”，两处称呼相互印证。

## 排序：父子整理船帆，事情是怎样办成的？ {#q.l1.5.8}
考点：skill.qi-part
语境：p.l1.5.r3

- [2] 儿子看到一张帆已经破了 {#q.l1.5.8.o1}
  理由：儿子听了父亲的吩咐去取帆，这才看见其中一张已裂。
- [3] 儿子选了完好的交给父亲 {#q.l1.5.8.o2}
  理由：“乃择完者”是看见破帆之后作的选择。
- [1] 父亲叫儿子从三张帆中取一张 {#q.l1.5.8.o3}
  理由：“取其一来”先交代要取多少张，儿子接下来才挑选。

提示：“其一”说的是要取的数目，“完者”说的是最后选中的帆。
解析：父亲只要三帆中的一张。儿子先看到有张裂帆，这才挑了好的交给父亲。
