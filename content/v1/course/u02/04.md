# 课文：之的常见用法 {#l1.4}
简介：“童拾之”是孩子捡了什么，“客之囊”是客人的什么？同一个字要分开读。

## 正文

先把两句教学例句并在一起：“客失囊，童拾之。”“客之囊有绳。”在第一句，孩子捡到的正是客人丢掉的袋子。把“之”换回“囊”，就成了“童拾囊”。第二句要一口气读到“囊”，“客之囊”就是客人的袋子。

“之”也可以指前面说过的一件事。《论语》说“学而时习之”，问一问“温习什么”，就会想到先前学过的东西。有时用“它”合适，有时用“的”合适；两种都讲不通时，不妨再读下文。

## 知识点：之 {#skill.zhi-object}
义项：代替前文的人或物
领域：虚词
要诀：把“之”换回它所指的东西。
讲解：“习之”的“之”指学过的内容。往前找时，要看什么东西能接在这个动作后面。
例句：p.ex.zhi-object

## 知识点：之 {#skill.zhi-link}
义项：连接修饰语和中心语
领域：虚词
要诀：读到“之”后面，看说的是谁的什么。
讲解：“山之北”是山的北面。先读“北”，再看是哪座山的北面。
例句：p.ex.zhi-link

## 原文：古籍引文 {#p.ex.zhi-object}
> 学而时习之，不亦说乎？
译文：学习了，按时温习所学的内容，不也很愉快吗？

## 原文：教学例句 {#p.ex.zhi-link}
> 山之北有泉。
译文：山的北面有泉。

## 原文：教学例句 {#p.l1.4.seed}
> 翁得瓜种，谨藏之。
译文：老人得到瓜籽，小心地把它们收藏起来。

## 单选：老人收藏的是什么？ {#q.l1.4.1}
考点：skill.zhi-object
语境：p.l1.4.seed

- [x] 瓜籽 {#q.l1.4.1.o1}
- [ ] 老人自己 {#q.l1.4.1.o2}
  理由：“翁”是把东西收好的人。看看他刚刚得了什么。
- [ ] 已经结的瓜 {#q.l1.4.1.o3}
  理由：看看老人拿到的东西有没有结成果实。

提示：老人先前得到了什么？
解析：老人刚得到瓜籽，接着小心收藏。“藏之”就是把这些瓜籽收好。

## 原文：教学例句 {#p.l1.4.roof}
> 夜雨入屋，屋之瓦破矣。
译文：夜里的雨漏进屋内，屋顶的瓦已经破了。

## 单选：“屋之瓦”里的“之”怎样讲？ {#q.l1.4.2}
考点：skill.zhi-link
语境：p.l1.4.roof

- [x] 连接屋和瓦，说明是哪处的瓦 {#q.l1.4.2.o1}
- [ ] 表示前往屋顶 {#q.l1.4.2.o2}
  理由：句子交代的是哪块瓦破了，还是谁在赶路？
- [ ] 代替漏下的雨 {#q.l1.4.2.o3}
  理由：“之”后已有“瓦”，试读“屋的……”。

提示：试着把这三个字念成“屋上的瓦”。
解析：“屋之瓦”就是屋上的瓦。破的是瓦，这句话交代瓦在哪里。

## 原文：教学例句 {#p.l1.4.brush}
> 案有新笔，生取之而书。
译文：桌上有一支新笔，学生拿起它写字。

## 找原文证据：学生拿起了什么来写字？ {#q.l1.4.3}
考点：skill.zhi-object
语境：p.l1.4.brush

- [ ] 案 {#q.l1.4.3.o1}
  理由：案是放东西的桌子。学生取了什么来写？
- [ ] 生 {#q.l1.4.3.o2}
  理由：生是取东西的人，什么能被他拿起来？
- [x] 新笔 {#q.l1.4.3.o3}

提示：桌上原先有什么？
解析：学生从桌上拿起那支新笔。“取之”的“之”替前面说过的笔。

## 原文：教学例句 {#p.l1.4.boat}
> 渔人之舟系于柳下。
译文：渔人的船系在柳树下。

## 找原文证据：系在柳树下的是渔人的什么？ {#q.l1.4.4}
考点：skill.zhi-link
语境：p.l1.4.boat

- [ ] 柳 {#q.l1.4.4.o1}
  理由：柳与船相系。它在“渔人之舟”里面吗？
- [x] 舟 {#q.l1.4.4.o2}
- [ ] 渔人 {#q.l1.4.4.o3}
  理由：渔人说明东西归谁。系在柳下的是谁或什么？

提示：把整组词换成“他的什么”。
解析：“渔人之舟”说的是船；前面的“渔人”告诉我们船归谁。

## 原文：教学例句 {#p.l1.4.lost}
> 有客失囊，邻人拾之以还客。
译文：有个旅客丢了袋子，邻人捡起它归还旅客。

## 单选：“拾之”连起来，是邻人捡起了什么？ {#q.l1.4.5}
考点：skill.zhi-object
语境：p.l1.4.lost

- [x] 捡起袋子 {#q.l1.4.5.o1}
- [ ] 扶起旅客 {#q.l1.4.5.o2}
  理由：“失囊”写谁丢了什么？客人摔倒了吗？
- [ ] 捡起邻人 {#q.l1.4.5.o3}
  理由：邻人是拾东西的人。再找前文的失物。

提示：哪样东西先丢失又被归还？
解析：客人丢了袋子，邻人拾起来还给他。丢的、捡的、还的是同一个袋子。

## 原文：教学例句 {#p.l1.4.slope}
> 村之东有坡，坡上多竹。
译文：村子的东面有山坡，坡上有许多竹子。

## 单选：“村之东”指哪里？ {#q.l1.4.6}
考点：skill.zhi-link
语境：p.l1.4.slope

- [x] 村子的东面 {#q.l1.4.6.o1}
- [ ] 东边的每一个村子 {#q.l1.4.6.o2}
  理由：“东”在最后，说的是村子的东边。
- [ ] 向东走到村子 {#q.l1.4.6.o3}
  理由：山坡的位置句中，有人在向东走吗？

提示：方位是相对于什么说的？
解析：山坡在村子的东边。“村”给“东”定了位置。

## 原文：教学例句 {#p.l1.4.jar}
> 小儿失珠，既得之，纳于匣。
译文：孩子丢了珠子，找到它以后，放进小盒。

## 单选：“既得之”中，“之”代什么？ {#q.l1.4.7}
考点：skill.zhi-object
语境：p.l1.4.jar

- [x] 先前丢失的珠子 {#q.l1.4.7.o1}
- [ ] 后来用来收藏的匣子 {#q.l1.4.7.o2}
  理由：匣在“得之”前出现了，还是在后面才出现？
- [ ] 丢了东西的孩子 {#q.l1.4.7.o3}
  理由：孩子是“得”的人。他先前丢了什么？

提示：看“既得之”之前丢了什么。
解析：小儿先丢了珠子，后来得回的也是那颗珠子，接着才把它收入匣中。

## 单选：“成人之美”怎样读，才能和“不成人之恶”对上？ {#q.l1.4.8}
考点：skill.zhi-link
语境：p.l1.4.shade

- [x] 成／人之美，中心是“美” {#q.l1.4.8.o1}
  理由：“成”管整个“人之美”，下文用“人之恶”占据同一位置。
- [ ] 成人／之／美，把“成人”读成成年人 {#q.l1.4.8.o2}
  理由：看看后半句的“不成”，这里能读成“成年人”吗？
- [ ] 成／人／之美，把“之”读成前往 {#q.l1.4.8.o3}
  理由：“美”与“恶”在这里能当作目的地吗？

提示：找重复出现的“人之……”以及反义的一对字。
解析：两句都从“成”读起：成全别人的好事，不促成别人的坏事。“人之美”和“人之恶”正好相对。
