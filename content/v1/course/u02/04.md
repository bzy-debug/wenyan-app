# 课文：之的常见用法 {#l1.4}
简介：给“之”做两个小实验：在动词后换回所指，在名词之间读出限定关系。

## 正文

### 先观察空位在哪里

教学例句：“客失囊，童拾之。”“客之囊有绳。”在前一句，“拾”还缺一个被拾到的东西。回读前文，用“囊”替换“之”，可以得到“童拾囊”。后一句本来就有中心词“囊”，“客”限定它属于谁，整组仍然指袋子。

| 小实验 | 如果成功，通常说明什么 |
| --- | --- |
| 动词＋之 → 动词＋前文所指 | “之”作宾语代词 |
| 甲之乙 → 甲的乙 | “之”连接限定语和中心词 |

### 所指也可能是一件事

在下面《论语》例句里，先问“习什么”，再往前回找。所温习的是学过的内容，并非必须在“之”前机械寻找最近的名词。若观察到两半句互为对照，可以用同一句式的另半边验证分组。

“之”另有其他用法。本课把这两种常见位置练扎实；若两种小实验都不通，先把疑问留下，不必强行译成“的”。

## 知识点：之 {#skill.zhi-object}
义项：代替前文的人或物
领域：虚词
要诀：动词后的宾语代词
讲解：先找“之”前面的动词，再回到上文找能承受该动作的人或物。
例句：p.ex.zhi-object

## 知识点：之 {#skill.zhi-link}
义项：连接修饰语和中心语
领域：虚词
要诀：表示所属或相关关系
讲解：在“甲之乙”里，先看后面的乙是什么，再读前面的限定。常可换成现代汉语的“的”。
例句：p.ex.zhi-link

## 原文：古籍引文 {#p.ex.zhi-object}
> 学而时习之，不亦说乎？
译文：学习了，按时温习所学的内容，不也很愉快吗？

## 原文：教学例句 {#p.ex.zhi-link}
> 山之北有泉。
译文：山的北面有泉。

## 原文：教学例句 {#p.l1.4.seed}
> 翁得瓜种，谨藏之。
译文：老人得到瓜籽，小心地把它们收藏起来。

## 单选：老人收藏的是什么？ {#q.l1.4.1}
考点：skill.zhi-object
语境：p.l1.4.seed

- [x] 瓜籽 {#q.l1.4.1.o1}
- [ ] 老人自己 {#q.l1.4.1.o2}
  理由：“翁”是收藏者。
- [ ] 已经结的瓜 {#q.l1.4.1.o3}
  理由：原文只有瓜种，还未写到结果。

提示：找前句中作为“得”的对象的词。
解析：“之”作“藏”的宾语，承接刚得到的瓜种。

## 原文：教学例句 {#p.l1.4.roof}
> 夜雨入屋，屋之瓦破矣。
译文：夜里的雨漏进屋内，屋顶的瓦已经破了。

## 单选：“屋之瓦”中“之”的作用是什么？ {#q.l1.4.2}
考点：skill.zhi-link
语境：p.l1.4.roof

- [x] 连接屋和瓦，说明是哪处的瓦 {#q.l1.4.2.o1}
- [ ] 表示前往屋顶 {#q.l1.4.2.o2}
  理由：句中没有人移动。
- [ ] 代替漏下的雨 {#q.l1.4.2.o3}
  理由：“之”后还有中心词“瓦”。

提示：比较“屋的瓦”能否说通。
解析：“屋”限定“瓦”的所属，中心词是瓦。

## 原文：教学例句 {#p.l1.4.brush}
> 案有新笔，生取之而书。
译文：桌上有一支新笔，学生拿起它写字。

## 选段：点出“取之”的“之”指代的物品。 {#q.l1.4.3}
考点：skill.zhi-object
语境：p.l1.4.brush

- [ ] 案 {#q.l1.4.3.o1}
  理由：案是放笔的桌子。
- [ ] 生 {#q.l1.4.3.o2}
  理由：学生是取笔的人。
- [x] 新笔 {#q.l1.4.3.o3}

提示：谁能被拿起来用来写字？
解析：作为书写工具的“新笔”正是“取”的对象。

## 原文：教学例句 {#p.l1.4.boat}
> 渔人之舟系于柳下。
译文：渔人的船系在柳树下。

## 选段：“渔人之舟”中，被限定的中心词是哪个？ {#q.l1.4.4}
考点：skill.zhi-link
语境：p.l1.4.boat

- [ ] 柳 {#q.l1.4.4.o1}
  理由：柳树是系船地点的线索。
- [x] 舟 {#q.l1.4.4.o2}
- [ ] 渔人 {#q.l1.4.4.o3}
  理由：渔人说明船属于谁。

提示：把整组词换成“他的什么”。
解析：“渔人”说明所属，整组词指一条船。

## 原文：教学例句 {#p.l1.4.lost}
> 有客失囊，邻人拾之以还客。
译文：有个旅客丢了袋子，邻人捡起它归还旅客。

## 单选：把“拾之”补足，最合句意的是哪项？ {#q.l1.4.5}
考点：skill.zhi-object
语境：p.l1.4.lost

- [x] 捡起袋子 {#q.l1.4.5.o1}
- [ ] 扶起旅客 {#q.l1.4.5.o2}
  理由：客人是失物者和归还的对象。
- [ ] 捡起邻人 {#q.l1.4.5.o3}
  理由：邻人是动作的发出者。

提示：哪样东西先丢失又被归还？
解析：前句的失物是“囊”，“拾”“还”都围绕它。

## 原文：教学例句 {#p.l1.4.slope}
> 村之东有坡，坡上多竹。
译文：村子的东面有山坡，坡上有许多竹子。

## 单选：“村之东”指哪里？ {#q.l1.4.6}
考点：skill.zhi-link
语境：p.l1.4.slope

- [x] 村子的东面 {#q.l1.4.6.o1}
- [ ] 东边的每一个村子 {#q.l1.4.6.o2}
  理由：“东”是方位，中心不是“村”。
- [ ] 向东走到村子 {#q.l1.4.6.o3}
  理由：这里交代山坡的位置，不叙述行走。

提示：方位是相对于什么说的？
解析：“村”给出方位的参照，“东”才是所指位置。

## 原文：教学例句 {#p.l1.4.jar}
> 小儿失珠，既得之，纳于匣。
译文：孩子丢了珠子，找到它以后，放进小盒。

## 单选：“既得之”中，“之”代什么？ {#q.l1.4.7}
考点：skill.zhi-object
语境：p.l1.4.jar

- [x] 先前丢失的珠子 {#q.l1.4.7.o1}
- [ ] 后来用来收藏的匣子 {#q.l1.4.7.o2}
  理由：匣子在“得之”之后才引入。
- [ ] 丢了东西的孩子 {#q.l1.4.7.o3}
  理由：孩子是找回东西的人。

提示：看“既得之”之前丢了什么。
解析：“失珠”交代失物。找回它，才能接着把它放进匣子。

译文：君子成全别人的好事，不促成别人的坏事。

## 单选：把“成人之美”分组，哪一种能和下半句平行？ {#q.l1.4.8}
考点：skill.zhi-link
语境：p.l1.4.shade

- [x] 成／人之美，中心是“美” {#q.l1.4.8.o1}
  理由：“成”管整个“人之美”，下文用“人之恶”占据同一位置。
- [ ] 成人／之／美，把“成人”读成成年人 {#q.l1.4.8.o2}
  理由：下半句的“不成”已经提示要单独读动词“成”。
- [ ] 成／人／之美，把“之”读成前往 {#q.l1.4.8.o3}
  理由：“美”“恶”在这里不是要前往的地点，两个“之”都连接限定语与中心词。

提示：找重复出现的“人之……”以及反义的一对字。
解析：先把句子中固定不动的部分对齐：“成……／不成……”。变换的是“人之美／人之恶”。“之”前的“人”限定后面的中心词。
