# 课文：公印归谁：“之”指物，也能说谁的 {#l1.4}
简介：失物被谁捡到，又交给了谁？有的“之”跟着物件走，有的“之”夹在名称中间。

## 正文

读教学短文时，可以把一枚公印想成真的东西：“得印”是捡起来，“视之”是看它。后一句没有重复“印”，只用一个“之”，东西还在手里。可到了“县吏之印”，这四个字合起来仍旧是一个东西的名字——县吏的印。

遇到“之”不必马上添一个“的”。试着读完这个动作：谁看？看什么？若前后两部分合起来给物件起名，就换一种读法。

## 知识点：之 {#skill.zhi-object}
义项：代替前面提到的人、事或物，作动作的对象
领域：虚词
要诀：问“这个动作落到谁或什么上”。
讲解：“视之”是看它，“还之”是归还它。被看的或者被归还的事物，要在前文找。
例句：p.l1.4.r1

## 知识点：之 {#skill.zhi-link}
义项：连接修饰语和名词，可读成“的”
领域：虚词
要诀：先找“之”后面说的是哪一件东西。
讲解：“主人之衣”整体仍是一件衣服，前面的主人说明衣服属于谁。
例句：p.l1.4.r2

## 原文：教学例句 {#p.l1.4.r1}
> 吏失印。童得之于井旁，视之，有赤文，曰：“此县吏之印也。”乃持印诣县。
译文：小吏丢了印。孩子在井边捡到它，拿来一看，见上面有红字，便说：“这是县吏的印。”于是拿着印去了县里。
词注：印：印章，此处是县吏办公用的印。
  赤文：红色的文字。
  诣：前往某处，读 yì。

## 原文：教学例句 {#p.l1.4.r2}
> 主人之衣湿，客解己衣与之。主人谢曰：“客之衣亦湿矣。”
译文：主人的衣服湿了，客人脱下自己的衣服给他。主人道谢说：“您的衣服也湿了。”
词注：己：自己，“己衣”指客人自己穿的衣服。
  与：给，这里是把衣服给对方。
  谢：道谢，此处是借到衣服后的回应。

## 原文：古籍引文 {#p.l1.4.r3}
> 君子成人之美，不成人之恶。
译文：君子成全别人的好事，不助长别人的坏事。
词注：成：成全、促成，后面接别人所做的事。
  恶：坏事，与前面的“美”相对，读 è。

## 单选：“童得之于井旁”，孩子在井边捡到了什么？ {#q.l1.4.1}
考点：skill.zhi-object
语境：p.l1.4.r1

- [x] 小吏丢的印 {#q.l1.4.1.o1}
  理由：先说“吏失印”，后说“童得之”，“印”是从丢失到被捡起的同一件东西。
- [ ] 来找失物的小吏 {#q.l1.4.1.o2}
  理由：孩子后来“持印诣县”，手里拿的是印。
- [ ] 刻着红字的水井 {#q.l1.4.1.o3}
  理由：井旁是拾物地点。东西可以带去县里，井不能。

提示：第一句只交代了一件失物。
解析：先说“吏失印”，后说“童得之”，“印”是从丢失到被捡起的同一件东西。

## 单选：孩子“视之”以后才开口，哪项是他亲眼看到的？ {#q.l1.4.2}
考点：skill.zhi-object
语境：p.l1.4.r1

- [x] 印上有红色的文字 {#q.l1.4.2.o1}
  理由：“之”指捡到的印，下一句“有赤文”写印上的字。
- [ ] 县里有人正在找孩子 {#q.l1.4.2.o2}
  理由：去县里是孩子后来的行动。
- [ ] 小吏在井边找印 {#q.l1.4.2.o3}
  理由：小吏只在开头被说成丢了东西，没写他来到井边。

提示：“视之”下面写看见的情形。
解析：“之”指捡到的印，下一句“有赤文”写印上的字。

## 找原文证据：孩子用哪一处说出了这件失物的主人和名称？ {#q.l1.4.3}
考点：skill.zhi-link
语境：p.l1.4.r1

- [ ] 有赤文 {#q.l1.4.3.o1}
  理由：这是印的模样，还没有说它是谁的。
- [ ] 乃持印 {#q.l1.4.3.o2}
  理由：这里写拿起印的动作。
- [x] 县吏之印 {#q.l1.4.3.o3}
  理由：“印”点明物件，“县吏之”点明归属；合起来是县吏的印。

提示：在孩子开口说的那句话里找。
解析：“印”点明物件，“县吏之”点明归属；合起来是县吏的印。

## 单选：把“主人之衣”写成失物签，哪张签写对了？ {#q.l1.4.4}
考点：skill.zhi-link
语境：p.l1.4.r2

- [ ] 客人的衣服，由主人代收 {#q.l1.4.4.o1}
  理由：客人拿出自己的衣服在下一句；开头先说主人的。
- [x] 物件是衣服，主人拥有它 {#q.l1.4.4.o2}
  理由：“主人之衣”作为整体等于“主人的衣服”，不能把“之”当另一件东西。
- [ ] 有人把自己的衣服借给主人 {#q.l1.4.4.o3}
  理由：借衣是下一句的事。这一处先交代主人自己的衣服湿了。

提示：签上物件的名称跟在“之”后。
解析：“主人之衣”作为整体等于“主人的衣服”，不能把“之”当另一件东西。

## 单选：“与之”里的“之”，如果把名字补出来，该补谁？ {#q.l1.4.5}
考点：skill.zhi-object
语境：p.l1.4.r2

- [x] 主人 {#q.l1.4.5.o1}
  理由：衣服从客人手中递给主人。主人的道谢也印证他是“与”的对象。
- [ ] 客人 {#q.l1.4.5.o2}
  理由：客人在脱自己的衣服，是给衣服的人。
- [ ] 衣服 {#q.l1.4.5.o3}
  理由：衣服已经在“解己衣”里交代了。这里说的是给谁。

提示：下一个开口道谢的人是谁？
解析：衣服从客人手中递给主人。主人的道谢也印证他是“与”的对象。

## 找原文证据：主人在道谢时，怎样称呼客人借给他的衣服？ {#q.l1.4.6}
考点：skill.zhi-link
语境：p.l1.4.r2

- [x] 客之衣 {#q.l1.4.6.o1}
  理由：“客之衣”是主人的称呼方式，等于当面对客人说“您的衣服”。
- [ ] 主人谢 {#q.l1.4.6.o2}
  理由：这里只标出说话人。
- [ ] 己衣 {#q.l1.4.6.o3}
  理由：这是叙述客人脱衣的用语，主人尚未开口。

提示：在引号里看谁的衣服。
解析：“客之衣”是主人的称呼方式，等于当面对客人说“您的衣服”。

## 单选：“人之美”在这里说的是哪类事？ {#q.l1.4.7}
考点：skill.zhi-link
语境：p.l1.4.r3

- [x] 别人身上的好处或所做的好事 {#q.l1.4.7.o1}
  理由：两处“之”都把“人”和后面的“美、恶”连起来。君子成全的是别人的好事。
- [ ] 君子外貌长得好看 {#q.l1.4.7.o2}
  理由：“人之”指向他人，后面又有相对的“人之恶”。
- [ ] 有个人觉得君子很漂亮 {#q.l1.4.7.o3}
  理由：“成人之美”的动作是成全，能被成全的是人家的好事。

提示：把“人之美”与“人之恶”并排读。
解析：两处“之”都把“人”和后面的“美、恶”连起来。君子成全的是别人的好事。

## 单选：“视之”和“县吏之印”中的“之”能否都换成“它”？ {#q.l1.4.8}
考点：skill.zhi-object
语境：p.l1.4.r1

- [x] 只有“视之”可读成“看它” {#q.l1.4.8.o1}
  理由：事情始终围绕公印，两个“之”的作用却不同。一处代印，一处说明印的归属。
- [ ] 两处都可以，都是在说这枚印 {#q.l1.4.8.o2}
  理由：后面那处读成“县吏它印”便不成一个名称。
- [ ] 只有“县吏之印”可以 {#q.l1.4.8.o3}
  理由：“视”要有看的对象，前面刚说孩子捡到了一件东西。

提示：一处跟在动词后，一处夹在县吏和印之间。
解析：事情始终围绕公印，两个“之”的作用却不同。一处代印，一处说明印的归属。
