# 课文：而的常见用法 {#l1.6}
简介：把“而”两侧先各自说完整，再分辨是动作衔接，还是出现了意外的结果。

## 正文

### 一条时间线，还是一个落空的预期？

读两句教学例句：“客启扉而入。”“扉虽启，而客不入。”第一句里的两个动作可以画成先开门、后进入的一条线。第二句里，门开本来让人以为客人会进来，实际却没有。比较两项之间的关系，比先给“而”指定一个固定译词更可靠。

1. 补出两边各是谁在做什么，尤其留意后句省了谁。
2. 尝试用“接着”连接。若一个动作确实为下一个创造条件，承接说得通。
3. 再试“却”。若前后有明确落差，把那项原本的预期用自己的话说出来。

### 没有“虽”也能表示转折

有人误以为只要出现两个动词就得译成“然后”。实际上，前一件事有时引出一种处境，后一件事写当事人面对它的态度。练习中的《论语》短句要补出不同的行为者，并仔细读两个“不”，转折才会显出来。

读完本单元，遇到同一个虚词可以先画分组线，再换词试读。分组与人物关系定下来后，译法通常也就清楚了。

## 知识点：而 {#skill.er-sequence}
义项：连接先后发生的动作
领域：虚词
要诀：前动作完成后再做后动作
讲解：相连的两个动词若有自然的先后依赖，“而”可表承接。核对前一件事是否为后一件事创造条件。
例句：p.ex.er-sequence

## 知识点：而 {#skill.er-turn}
义项：引出转折
领域：虚词
要诀：后项与通常预期相反
讲解：若后面的事实与前项带来的预期相反，“而”可读作“却”。从“虽”“未”“犹”等词寻找线索。
例句：p.ex.er-turn

## 原文：教学例句 {#p.ex.er-sequence}
> 客启扉而入室。
译文：客人打开门后进入室内。

## 原文：教学例句 {#p.ex.er-turn}
> 井虽深，而水已涸。
译文：井虽然很深，水却已经干了。

## 原文：教学例句 {#p.l1.6.payment}
> 客解囊而取钱，乃付舟人。
译文：客人解开钱袋取出钱，才付给船夫。

## 排序：按原文排出付钱的过程。 {#q.l1.6.1}
考点：skill.er-sequence
语境：p.l1.6.payment

- [3] 把钱交给船夫 {#q.l1.6.1.o1}
- [2] 取出钱 {#q.l1.6.1.o2}
- [1] 解开钱袋 {#q.l1.6.1.o3}

提示：从袋子还系着的状态想起。
解析：解囊是从袋中取钱的前提，付钱又在取钱之后。

## 单选：“愠”是恼怒。句中“而”连接了谁的处境和谁的反应？ {#q.l1.6.2}
考点：skill.er-turn
语境：p.l1.6.coat

- [ ] 别人不了解自己，然后别人开始生气 {#q.l1.6.2.o1}
  理由：后文是“不愠”，且受评价的是面对不被了解这一处境的人。
- [ ] 自己先动怒，所以别人不了解自己 {#q.l1.6.2.o2}
  理由：颠倒前后关系，又漏读否定词“不”。
- [x] 别人不了解自己，自己却没有恼怒 {#q.l1.6.2.o3}
  理由：前项交代处境，后项展示面对这种处境时的反应。

提示：分清“不知”的人和被评价为君子的人。
解析：补出两边的主语：人不知（我），而（我）不愠。常人可能因不被了解而不平，这里却能不恼，转折由这种落差显出。

## 原文：教学例句 {#p.l1.6.seal}
> 吏破封而展书。
译文：官吏拆开封套，随即展开书信。

## 单选：两项动作有什么关系？ {#q.l1.6.3}
考点：skill.er-sequence
语境：p.l1.6.seal

- [ ] 拆信与展信意思相反 {#q.l1.6.3.o1}
  理由：展开信件符合拆封后的预期。
- [ ] 先展信再拆封 {#q.l1.6.3.o2}
  理由：信原先封着，次序不能颠倒。
- [x] 拆开封套后才展开里面的信 {#q.l1.6.3.o3}

提示：信原先处于什么状态？
解析：封套未开时不能取出里面的信，“而”表承接。

## 原文：教学例句 {#p.l1.6.closed}
> 天已明，而门犹闭。
译文：天已经亮了，门却还关着。

## 选段：哪一处写出与天明后开门的预期不同的事实？ {#q.l1.6.4}
考点：skill.er-turn
语境：p.l1.6.closed

- [ ] 已明 {#q.l1.6.4.o1}
  理由：这是带来预期的前项。
- [ ] 天 {#q.l1.6.4.o2}
  理由：单独的“天”没有表达反向事实。
- [x] 门犹闭 {#q.l1.6.4.o3}

提示：注意表示“仍然”的字。
解析：“犹”表示仍然。门还关着是“而”引出的后项。

## 原文：教学例句 {#p.l1.6.tea}
> 仆揭盖而倾茶于盏。
译文：仆人揭开盖子，然后把茶倒进茶杯。

## 单选：把这句话分成两步，哪一步在先？ {#q.l1.6.5}
考点：skill.er-sequence
语境：p.l1.6.tea

- [ ] 饮尽杯中茶 {#q.l1.6.5.o1}
  理由：原文没有喝茶的动作。
- [x] 揭开盖子 {#q.l1.6.5.o2}
- [ ] 倒茶入杯 {#q.l1.6.5.o3}
  理由：“而”后面的倾茶发生在揭盖之后。

提示：看“而”两边的动词。
解析：先揭盖，接着倾茶，“而”连接前后动作。

## 原文：教学例句 {#p.l1.6.late}
> 路虽近，而泥深难行。
译文：路虽然近，泥却很深，很难走。

## 单选：哪一项保留了原句转折？ {#q.l1.6.6}
考点：skill.er-turn
语境：p.l1.6.late

- [ ] 先走近路，后来才有泥 {#q.l1.6.6.o1}
  理由：“虽”并未引出时间次序。
- [ ] 因为路近，所以泥深 {#q.l1.6.6.o2}
  理由：距离短并未造成泥深。
- [x] 路近，本应易达，偏偏泥深难行 {#q.l1.6.6.o3}

提示：把“而”试换成“却”。
解析：前项“近”看似有利，后项指出实际困难。

## 原文：教学例句 {#p.l1.6.lock}
> 主人以钥开锁而启箱。
译文：主人用钥匙开了锁，接着打开箱子。

## 选段：点选为“启箱”创造条件的前一个动作。 {#q.l1.6.7}
考点：skill.er-sequence
语境：p.l1.6.lock

- [ ] 启箱 {#q.l1.6.7.o1}
  理由：这是后一步。
- [x] 开锁 {#q.l1.6.7.o2}
- [ ] 主人 {#q.l1.6.7.o3}
  理由：这是进行动作的人。

提示：留意“而”的前项。
解析：锁打开后箱子才能开启。

## 原文：教学例句 {#p.l1.6.dry}
> 雨虽终日，而瓮中无水，盖覆其口也。
译文：雨虽然下了一整天，瓮里却没有水，因为盖子覆住了瓮口。

## 单选：雨与瓮中无水之间是何种关系？ {#q.l1.6.8}
考点：skill.er-turn
语境：p.l1.6.dry

- [ ] 先把瓮灌满再倒空 {#q.l1.6.8.o1}
  理由：原文未写倒水。
- [x] 预期落空的转折 {#q.l1.6.8.o2}
- [ ] 下雨直接导致瓮无水 {#q.l1.6.8.o3}
  理由：瓮口被盖住才是水未进入的解释。

提示：区分“而”连接的两项与末句的解释。
解析：有雨却无积水，后文揭示盖子挡雨的原因。
