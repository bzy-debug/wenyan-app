# 课文：一声叩门：“而”连接的两边 {#l1.6}
简介：门是照常开了，还是偏偏没开？两件事怎样接在一起，比孤立翻译“而”更要紧。

## 正文

教学短文里，烧窑人把门闩举起来，门跟着开了。两个动作可以用一个“而”串起。另一句说他叩门很久，“而内无应”，等了半天，里面偏偏没回应。

不必见“而”就选“但是”。先在心里停一下：照前半句看来，本来会怎样？后半句如果顺着走，照动作经过讲便好；如果事情拐了弯，“却”就能把这层意思读出来。

## 知识点：而 {#skill.er-sequence}
义项：把前后接连发生的动作连起来
领域：虚词
要诀：试着按先后把两件事演一遍。
讲解：“举闩而启门”先举闩，接着开门。两个动作之间不须有冲突。
例句：p.l1.6.r1

## 知识点：而 {#skill.er-turn}
义项：引出与前面情形或预期不合的事，可读成“却”
领域：虚词
要诀：想想照前半句，本来容易想到什么结果。
讲解：人听见了，照常会应声；若原文偏写不应，就要保留那层出乎意料。
例句：p.l1.6.r2

## 原文：教学例句 {#p.l1.6.r1}
> 客叩窑门久，而内无应。客将去，窑者始闻之，举闩而启门。
译文：客人敲窑门敲了很久，里面却没有回应。客人正要离开，看窑的人才听见，抬起门闩，打开了门。
词注：叩：敲，这里是敲门。
  闩：横插在门里、使门无法推开的木棍，读 shuān。
  始：才，看窑人是到这时才听见。

## 原文：古籍引文 {#p.l1.6.r2}
> 人不知而不愠，不亦君子乎？
译文：别人不了解自己，自己却不怨怒，这不也是君子的表现吗？
词注：知：了解，这里省去了被了解的自己。
  愠：心里怨恼，读 yùn。

## 原文：教学例句 {#p.l1.6.r3}
> 雨止，舟人解缆而发。至中流，风已息，而舟犹疾。客视水，乃知水急。
译文：雨停了，船夫解开缆绳就出发。到了河心，风已平息，船却仍走得很快。旅客去看水流，才知道水很急。
词注：缆：系船的绳子。
  中流：河流中央。
  息：停歇，句中是风停了。
  疾：快，写的是船行的速度。

## 单选：客人在门外等久了，最出乎他意料的是什么？ {#q.l1.6.1}
考点：skill.er-turn
语境：p.l1.6.r1

- [ ] 自己忘了敲门 {#q.l1.6.1.o1}
  理由：“叩窑门久”明说他敲了很久。
- [ ] 门开之前得先抬起门闩 {#q.l1.6.1.o2}
  理由：抬闩是正常的开门动作；他吃惊的是久久没有应声。
- [x] 敲了这么久，里面仍无人答应 {#q.l1.6.1.o3}
  理由：敲门本来是求回应，“久”加深期待，“无应”把期待打断。

提示：读“而内无应”再看看“久”。
解析：敲门本来是求回应，“久”加深期待，“无应”把期待打断。

## 找原文证据：门闩抬起之后，看窑人紧接着做什么？ {#q.l1.6.2}
考点：skill.er-sequence
语境：p.l1.6.r1

- [ ] 始闻之 {#q.l1.6.2.o1}
  理由：这是看窑人刚听到叩门声时，还没去开门。
- [ ] 客将去 {#q.l1.6.2.o2}
  理由：打算走的是门外的客人，动作发生在开门前。
- [x] 启门 {#q.l1.6.2.o3}
  理由：“而”把举闩、启门串成一套连续动作。启门就是开门。

提示：找“举闩而……”的下半。
解析：“而”把举闩、启门串成一套连续动作。启门就是开门。

## 单选：讲给没学过古文的人听，哪一句保留了“举闩而启门”的意思？ {#q.l1.6.3}
考点：skill.er-sequence
语境：p.l1.6.r1

- [ ] 他抬了门闩，门却开不了 {#q.l1.6.3.o1}
  理由：后文明确写“启门”，门已打开。
- [ ] 他本想开门，却只好把门闩插上 {#q.l1.6.3.o2}
  理由：“举”是抬起，和插上门闩方向不同。
- [x] 他抬起门闩，把门打开 {#q.l1.6.3.o3}
  理由：先把闩抬开，门便可以开。“而”顺着这个动作接下去。

提示：这两个动作中间有什么阻碍吗？
解析：先把闩抬开，门便可以开。“而”顺着这个动作接下去。

## 单选：“人不知而不愠”中，什么反应本来是可能有的？ {#q.l1.6.4}
考点：skill.er-turn
语境：p.l1.6.r2

- [ ] 别人称赞自己，便心满意足 {#q.l1.6.4.o1}
  理由：前半说的是“不知”，不是受到称赞。
- [ ] 别人不了解自己，便听不到声音 {#q.l1.6.4.o2}
  理由：“知”指了解，“愠”指恼怒，两者没有在谈听觉。
- [x] 别人不了解自己，心中怨恼 {#q.l1.6.4.o3}
  理由：不被了解容易生怨，句中偏说“不愠”。这个“而”连接处境与出人意料的反应。

提示：“愠”是怨恼，再看它前面多了哪个字。
解析：不被了解容易生怨，句中偏说“不愠”。这个“而”连接处境与出人意料的反应。

## 单选：这句称许的究竟是谁？ {#q.l1.6.5}
考点：skill.er-turn
语境：p.l1.6.r2

- [ ] 因为恼怒而责备别人的人 {#q.l1.6.5.o1}
  理由：被赞许的是“不愠”。
- [x] 遇到误解仍能不怨的人 {#q.l1.6.5.o2}
  理由：称许的是身处“不知”而“不愠”的人，这一层转折解释了为何值得称许。
- [ ] 总能让别人了解自己的人 {#q.l1.6.5.o3}
  理由：“人不知”交代未被理解的处境，并没写他已让人明白。

提示：问句“不亦君子乎”接在哪种反应之后？
解析：称许的是身处“不知”而“不愠”的人，这一层转折解释了为何值得称许。

## 排序：开船到河心，三步是怎样接上的？ {#q.l1.6.6}
考点：skill.er-sequence
语境：p.l1.6.r3

- [3] 船行到河心 {#q.l1.6.6.o1}
  理由：“至中流”说的是开船后的所在。
- [2] 船夫解缆出发 {#q.l1.6.6.o2}
  理由：船拴在岸边，先解才能出发。
- [1] 岸边雨停 {#q.l1.6.6.o3}
  理由：雨停、松绳、启航，之后才到河心。第一个“而”顺写船夫所做之事。

提示：“解缆而发”是一连串开船动作。
解析：雨停、松绳、启航，之后才到河心。第一个“而”顺写船夫所做之事。

## 找原文证据：风已经停了，哪一处写船况与旅客的预想不合？ {#q.l1.6.7}
考点：skill.er-turn
语境：p.l1.6.r3

- [ ] 客视水 {#q.l1.6.7.o1}
  理由：这是旅客发现异常之后去查看的动作。
- [x] 舟犹疾 {#q.l1.6.7.o2}
  理由：“舟犹疾”写船仍然很快，和风已平息放在一起，才有后面的观察。
- [ ] 风已息 {#q.l1.6.7.o3}
  理由：这是预想船要慢下来的依据，还没说船实际怎样。

提示：“犹”在这里是“还”。
解析：“舟犹疾”写船仍然很快，和风已平息放在一起，才有后面的观察。

## 单选：若删去第一个“而”，口头复述怎样补最合适？ {#q.l1.6.8}
考点：skill.er-sequence
语境：p.l1.6.r3

- [ ] 虽然解开缆绳，却没开船 {#q.l1.6.8.o1}
  理由：下一句船已经到了河中央。
- [x] 船夫解开缆绳，就开了船 {#q.l1.6.8.o2}
  理由：“解缆而发”的两件事相承，可以用“就”相接。到了风停而船快的那句，才适合用“却”。
- [ ] 风先停下来，船夫才解缆 {#q.l1.6.8.o3}
  理由：“风已息”在船到河心后才交代；开船前停的是雨。

提示：先找“发”前面那个“而”。
解析：“解缆而发”的两件事相承，可以用“就”相接。到了风停而船快的那句，才适合用“却”。
