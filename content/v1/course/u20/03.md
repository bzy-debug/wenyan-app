# 课文：沈括怎样观察磁针和花期 {#l5.12}
简介：磁针到底指哪一方？山里的花为什么开得迟？读沈括怎样记下常见的情形，也怎样对待例外。

## 正文

### “常指南”，这个“常”能删吗？

沈括写磁针，既记怎样放比较稳，也记自己家里有指北的针。复述时若丢了“常”“其中有”几个字，原先有所保留的观察，就变成了句句绝对的断言。再读草木花期时，也留心他是换了地点、换了品种，还是依旧在同一畦地里比较。

“盌”就是碗。“纩”（kuàng）在这里是丝绵，“畦”（qí）是有田界的一块地。“芥子许”可以想成芥子那么大的一点；这样就知道“许”在这儿不作“准许”讲。

查字时可直接翻到这里。[纊](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E7%BA%8A)

## 知识点：笔记中的限定 {#skill.l5.12}
义项：从“常”“有”等字看出观察适用的范围
领域：篇章
要诀：哪个判断有条件，哪里又留了例外
讲解：读笔记，别略过“常”“其中有”“同一畦”这些短语。它们告诉我们作者见过哪几种情形，也让人知道他的解释到哪里才算有把握。
例句：p.l5.12.example
复习题：q.l5.12.1 q.l5.12.4 q.l5.12.5 q.l5.12.7

## 原文：教学例句 {#p.l5.12.example}
> 庭梅三株，向阳者先花，背阴者稍晚。岁寒，则前后又异。
译文：庭中三株梅树，向阳的先开花，背阴的稍晚；碰上寒年，开花的先后又会有变化。这说的是眼前这三株梅，要连同朝向和天气一起看。

## 原文：古籍引文 {#p.l5.12.a}
> 方家以磁石磨针锋，则能指南，然常微偏东，不全南也。水浮多荡摇，指爪及盌唇上皆可为之，运转尤速，但坚滑易坠，不若缕悬为最善。其法取新纩中独茧缕，以芥子许蜡缀于针腰，无风处悬之，则针常指南。其中有磨而指北者，予家指南北者皆有之。磁石之指南，犹柏之指西，莫可原其理。
译文：懂这种技艺的人拿磁石磨针尖，针就能指南，不过常略偏东。针浮在水上容易晃，搁在指甲或碗沿上转得快，却容易滑落，还是用丝线悬着最好。沈括说，要取丝绵里的单茧丝，用芥子大小的蜡把丝粘在针腰，在无风处悬起。有的针磨后却指北，他家里两种都有。至于磁石指南、柏树指西，他说不出其中的道理。

## 单选：只抄“则能指南”，会漏掉沈括紧接着补上的哪一点？ {#q.l5.12.1}
考点：skill.l5.12
语境：p.l5.12.a

- [ ] 作者认为磁针只能漂浮在水里 {#q.l5.12.1.o2}
  理由：后面正比较多种放置法。
- [x] 方向常略偏东，不是正南 {#q.l5.12.1.o1}
- [ ] 作者认为所有针同样指北 {#q.l5.12.1.o3}
  理由：“其中有”只引出部分情况。

提示：先读“然”，再看后面怎样形容针的指向。
解析：针常微偏东，并非恰指正南。有了这半句，才保住沈括原来观察的精细处。

## 找原文证据：指北和指南的针，沈括自己家中都见过。请找出他的原话。 {#q.l5.12.2}
考点：skill.l5.12
语境：p.l5.12.a

- [ ] 莫可原其理 {#q.l5.12.2.o3}
  理由：“莫可原”说沈括还说不清原因。要找他家里有什么，得往前读。
- [ ] 指爪及盌唇上皆可为之 {#q.l5.12.2.o2}
  理由：指甲和碗沿都是放针的地方。说自己家里有哪些针，在另一个句子里。
- [x] 予家指南北者皆有之 {#q.l5.12.2.o1}

提示：看看哪一句从一般的针说到了“我家”。
解析：“予家指南北者皆有之”指明样本就在自己家中，两种指向都有。

## 单选：搁在指甲或碗沿上明明转得快，沈括为什么更取丝缕悬针？ {#q.l5.12.3}
考点：skill.l5.12
语境：p.l5.12.a

- [x] 硬而滑的支点易使针掉落，比较还考虑稳定性 {#q.l5.12.3.o1}
- [ ] 能转得快必定不能指南 {#q.l5.12.3.o3}
  理由：转得快是长处。试着读“但坚滑易坠”，问题出在放不稳。
- [ ] 缕悬时作者就不必顾及有无风 {#q.l5.12.3.o2}
  理由：他明写“无风处”。

提示：“但”字之后，这种放法遇到了什么麻烦？
解析：坚而滑的支点虽然容易转动，也容易掉落。沈括把快慢和安稳都考虑在了。

## 单选：他一面说“予家……皆有之”，一面说“莫可原其理”，两句如何并读？ {#q.l5.12.4}
考点：skill.l5.12
语境：p.l5.12.a

- [ ] 前者已经证明全部磁学原理，后者否定曾观察 {#q.l5.12.4.o2}
  理由：看见两种针都在，不等于就知道它们为什么这样指。
- [x] 前者报告所见种类，后者承认难以推究缘由 {#q.l5.12.4.o1}
- [ ] 二者都规定所有物体只向同一方向 {#q.l5.12.4.o3}
  理由：“指南北者”明示观察结果有别。

提示：看见针怎样指，和说清针为什么这样指，是不是同一件事？
解析：两种针他都见过；至于为什么这样指，他却坦言难以推究。观察可以明确，原因仍可未明。

## 原文：古籍引文 {#p.l5.12.b}
> 缘土气有早晚，天时有愆伏。如平地三月花者，深山中则四月花。白乐天游大林寺诗云：“人间四月芳菲尽，山寺桃花始盛开。”盖常理也。此地势高下之不同也。如筀竹笋有二月生者，有四月生者，有五月方生者，谓之晚筀。稻有七月熟者，有八九月熟者，有十月熟者，谓之晚稻。一物同一畦之间，自有早晚，此性之不同也。
译文：各地土气、天时有早有晚。平地三月开花的植物，到了深山，四月才开。沈括引白居易的大林寺诗，说的是地势高下的分别。筀竹出笋有迟早，稻谷成熟也分月份；即使在同一畦地里，同一种作物仍有早有晚，这又是品性有别。

## 单选：引白乐天写大林寺桃花的诗，是为了说明哪两处花期开得不同？ {#q.l5.12.5}
考点：skill.l5.12
语境：p.l5.12.b

- [ ] 二月和五月出笋是因为诗人错记日期 {#q.l5.12.5.o3}
  理由：诗句写的是桃花，并未记录竹笋。
- [ ] 不同品种的水稻同畦而熟期不同 {#q.l5.12.5.o2}
  理由：同畦的稻是往后才举的例子。大林寺的诗正在说山里的桃花。
- [x] 平地与深山花期不同 {#q.l5.12.5.o1}

提示：诗里“人间”和“山寺”，分别接上文哪里的花？
解析：平地花期已过，深山的桃花才开。诗句就讲前一句所说的地势高低之别。

## 找原文证据：谈完地势，沈括又想比较草木本性。哪几个字说明这一回连地块都相同？ {#q.l5.12.6}
考点：skill.l5.12
语境：p.l5.12.b

- [x] 同一畦之间 {#q.l5.12.6.o1}
- [ ] 游大林寺 {#q.l5.12.6.o3}
  理由：这是诗人当初去了哪里，不是沈括说两种作物在同一块田里。
- [ ] 深山中 {#q.l5.12.6.o2}
  理由：这是改变观察地点，与固定地块相反。

提示：找一个说田地的字，注意它前面的数量。
解析：“同一畦之间”把地点定在同一块田上。即便这样还分早晚，沈括便转而从品性来说明。

## 单选：有人读到“十月熟”便说稻都十月成熟，怎样用同段的话纠正？ {#q.l5.12.7}
考点：skill.l5.12
语境：p.l5.12.b

- [ ] 所有提到的月份都是桃花花期 {#q.l5.12.7.o2}
  理由：稻句明用“熟”而非“花”。
- [x] 同段另列七月、八九月的熟稻，只把十月一类称晚稻 {#q.l5.12.7.o1}
- [ ] “有……者”表示一条无例外的规律 {#q.l5.12.7.o3}
  理由：连续几个“有……者”，每次说的稻熟时节都不同。

提示：把每个“有……者”分别圈出来。
解析：稻有七月熟的，有八九月熟的。十月才熟的那一种，沈括特地称为晚稻。

## 单选：概括这段草木观察，怎样把地势和品性两层都保留下来？ {#q.l5.12.8}
考点：skill.l5.12
语境：p.l5.12.b

- [ ] 地势能解释所有品性不同，无需另作考察 {#q.l5.12.8.o3}
  理由：“此性之不同也”把同畦早晚单列一层。
- [ ] 只须知道月份，就能判定一切草木的状态 {#q.l5.12.8.o2}
  理由：原文连举地点和品性的差别。
- [x] 即使季节名称相同，地势和品性也可能分别导致物候早晚 {#q.l5.12.8.o1}

提示：两处“此……不同也”各承接哪一种比较？
解析：平地和山中花期不同；同一畦地里的作物也能有早晚。只看日历上的一个月，说不尽这些差别。
