# 课文：读笔记：在观察、比较和例外之间作判断 {#l5.12}
简介：对读沈括的两篇札记，为作者的结论补回条件与例外。

## 正文

### 暂把笔记抄成一份观察记录

给每个判断补答三问：考察了哪些材料？比较的条件怎样改变？作者有没有写“有……者”“莫可……”这样的保留？读完可以自己写一条有条件的结论，再去查注释。

《梦溪笔谈》的“盌”与“碗”指同类器皿；“纩”（kuàng）在下文指丝绵；“畦”（qí）为分界栽种的一块田地。“芥子许”用小粒的芥子比拟大小，“许”在此不表示许可。这些释词用于理解宋人的观察记录。

查阅《重编国语辞典修订本》的字头。[纊](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E7%BA%8A)

## 知识点：笔记中的限定 {#skill.l5.12}
义项：用比较项、频率词与反例限定观察结论
领域：篇章
要诀：留下“在什么条件下”的证据
讲解：随笔常将观察、例外与待解释的问题写在一起。把“常”“有”“其中”“一物”等词留下，才能准确转述。
例句：p.l5.12.example
复习题：q.l5.12.1 q.l5.12.4 q.l5.12.5 q.l5.12.7

## 原文：教学例句 {#p.l5.12.example}
> 庭梅三株，向阳者先花，背阴者稍晚。岁寒，则前后又异。
译文：庭中三株梅的花期随向阳背阴而异，天冷时又有变化。三株是样本，向阳等是条件，花期是所得观察。

## 原文：古籍引文 {#p.l5.12.a}
> 方家以磁石磨针锋，则能指南，然常微偏东，不全南也。水浮多荡摇，指爪及盌唇上皆可为之，运转尤速，但坚滑易坠，不若缕悬为最善。其法取新纩中独茧缕，以芥子许蜡缀于针腰，无风处悬之，则针常指南。其中有磨而指北者，予家指南北者皆有之。磁石之指南，犹柏之指西，莫可原其理。
译文：以磁石摩擦针尖，可以指南，但常略偏东。浮水易摇，放在指甲或碗沿虽转得快却易落，故以丝缕悬起最好。文中叙悬法及无风条件，又说有些针磨后指北，自己家中两类都有。作者以柏树指西作比，并说难以推究其中道理。

## 单选：如果只摘“则能指南”，漏写了哪项紧接着出现的修正？ {#q.l5.12.1}
考点：skill.l5.12
语境：p.l5.12.a

- [ ] 作者认为磁针只能漂浮在水里 {#q.l5.12.1.o2}
  理由：后面正比较多种放置法。
- [x] 方向常略偏东，不是正南 {#q.l5.12.1.o1}
- [ ] 作者认为所有针同样指北 {#q.l5.12.1.o3}
  理由：“其中有”只引出部分情况。

提示：看“然”后面的方向词。
解析：作者在常见趋势后立即写偏向。准确转述应同时留下主张和修正。

## 找原文证据：哪一处最直接提供作者家中同时有两种针的见证？ {#q.l5.12.2}
考点：skill.l5.12
语境：p.l5.12.a

- [ ] 莫可原其理 {#q.l5.12.2.o3}
  理由：这句表示解释上的保留。
- [ ] 指爪及盌唇上皆可为之 {#q.l5.12.2.o2}
  理由：这句比较放置位置，不说明收藏。
- [x] 予家指南北者皆有之 {#q.l5.12.2.o1}

提示：找第一人称及其所指的样本。
解析：“予家”给出材料范围，南北指向两类都在其经验之内。

## 单选：为什么即使“运转尤速”，作者仍取缕悬？ {#q.l5.12.3}
考点：skill.l5.12
语境：p.l5.12.a

- [x] 硬而滑的支点易使针掉落，比较还考虑稳定性 {#q.l5.12.3.o1}
- [ ] 能转得快必定不能指南 {#q.l5.12.3.o3}
  理由：原文论放置效果，没有把快速与指南视为绝对矛盾。
- [ ] 缕悬时作者就不必顾及有无风 {#q.l5.12.3.o2}
  理由：他明写“无风处”。

提示：对照“但”之前的长处与之后的问题。
解析：判断方法要看多个指标。转得快有优势，易坠却影响使用，丝悬另有适宜条件。

## 单选：怎样区分“予家……皆有之”与“莫可原其理”的作用？ {#q.l5.12.4}
考点：skill.l5.12
语境：p.l5.12.a

- [ ] 前者已经证明全部磁学原理，后者否定曾观察 {#q.l5.12.4.o2}
  理由：举例不等于解释，“莫可原”也没有否认观察。
- [x] 前者报告所见种类，后者承认难以推究缘由 {#q.l5.12.4.o1}
- [ ] 二者都规定所有物体只向同一方向 {#q.l5.12.4.o3}
  理由：“指南北者”明示观察结果有别。

提示：把样本记录和原因解释分成两栏。
解析：作者能够列出家中不同针的表现，同时对原因保留判断，两者并不冲突。

## 原文：古籍引文 {#p.l5.12.b}
> 缘土气有早晚，天时有愆伏。如平地三月花者，深山中则四月花。白乐天游大林寺诗云：“人间四月芳菲尽，山寺桃花始盛开。”盖常理也。此地势高下之不同也。如筀竹笋有二月生者，有四月生者，有五月方生者，谓之晚筀。稻有七月熟者，有八九月熟者，有十月熟者，谓之晚稻。一物同一畦之间，自有早晚，此性之不同也。
译文：土气和天气有早晚变化。平地三月开花的，到深山可能四月才开。沈括引白居易的大林寺诗说明高低不同。又写筀竹出笋和稻子成熟各有早晚，同样作物即便在同一畦地也有差异，说明其本性有所不同。

## 单选：引大林寺诗的一联，是为哪一组比较提供例证？ {#q.l5.12.5}
考点：skill.l5.12
语境：p.l5.12.b

- [ ] 二月和五月出笋是因为诗人错记日期 {#q.l5.12.5.o3}
  理由：诗句写的是桃花，并未记录竹笋。
- [ ] 不同品种的水稻同畦而熟期不同 {#q.l5.12.5.o2}
  理由：稻与同畦出现在下一个说明层次。
- [x] 平地与深山花期不同 {#q.l5.12.5.o1}

提示：读诗句之后带“此”的那一句。
解析：沈括把山寺与人间的花期差别归到地势高下这一组理由。

## 找原文证据：哪一处明确把地块先限制为相同，借此讨论草木本性的差别？ {#q.l5.12.6}
考点：skill.l5.12
语境：p.l5.12.b

- [x] 同一畦之间 {#q.l5.12.6.o1}
- [ ] 游大林寺 {#q.l5.12.6.o3}
  理由：此处说明诗作背景。
- [ ] 深山中 {#q.l5.12.6.o2}
  理由：这是改变观察地点，与固定地块相反。

提示：找“一”与田地单位连用的地方。
解析：同畦减少了地点变化这一解释，作者用它转而说明品性早晚。

## 单选：若读者据此断言“稻都在十月成熟”，原文怎样反驳？ {#q.l5.12.7}
考点：skill.l5.12
语境：p.l5.12.b

- [ ] 所有提到的月份都是桃花花期 {#q.l5.12.7.o2}
  理由：稻句明用“熟”而非“花”。
- [x] 同段另列七月、八九月的熟稻，只把十月一类称晚稻 {#q.l5.12.7.o1}
- [ ] “有……者”表示一条无例外的规律 {#q.l5.12.7.o3}
  理由：这样的句式正是在列不同情况。

提示：数一数“稻有……者”列出了几组。
解析：十月是一个例子，不是所有稻的同一熟期。归纳时应保留“有”。

## 单选：为整段拟一句能保留比较条件的概括，哪条恰当？ {#q.l5.12.8}
考点：skill.l5.12
语境：p.l5.12.b

- [ ] 地势能解释所有品性不同，无需另作考察 {#q.l5.12.8.o3}
  理由：“此性之不同也”把同畦早晚单列一层。
- [ ] 只须知道月份，就能判定一切草木的状态 {#q.l5.12.8.o2}
  理由：原文连举地点和品性的差别。
- [x] 即使季节名称相同，地势和品性也可能分别导致物候早晚 {#q.l5.12.8.o1}

提示：把两个“此……不同也”并在一起读。
解析：先论地势不同，再论同地而品性不同。两个观察尺度共同限制按月份一概而论。
