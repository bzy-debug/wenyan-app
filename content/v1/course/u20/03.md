# 课文：独读沈括：亲见、试验和推想各写在哪里？ {#l5.12}
简介：先写一则自己的短摘要，再回到石碑和山崖上的实物，看哪个结论有多强的根据。

## 正文

不看译文读完一遍，各写两句：“沈括得到的实物是……”“他用这个发现来说明……”。若两句写成同一件事，再读一遍“乃”“则”“盖”相接的地方。

“淤田”指引来泥沙使其沉积改田；“陡门”是调节水流的设施。“横亘”说横贯伸展。只查确实妨碍读通的词，把其余时间还给原文。

## 知识点：分清笔记作者亲见的材料与据此作的推断 {#s.l5.conclusion}
义项：分清笔记作者亲见的材料与据此作的推断
领域：阅读技能
要诀：把“见到什么”和“由此推知什么”分写两行
讲解：“予得”“予见”可记实物或见闻；“则……盖……”常由材料推到判断。摘要应保留判断的人和证据所及的时代、地方。
例句：p.l5.12.example
复习题：q.l5.12.1 q.l5.12.3 q.l5.12.5 q.l5.12.7

## 原文：教学例句 {#p.l5.12.example}
> 予见桥柱有水痕，疑昨夜水涨。
译文：我看到桥柱上有水痕，猜测昨夜河水上涨。水痕是眼见，涨水的时间是推测。

## 原文：古籍引文 {#p.l5.12.a}
> 熙宁中初行淤田法。论者以谓《史记》所载“泾水一斛，其泥数斗，且粪且溉，长我禾黍”，所谓粪即淤也。予出使至宿州，得一石碑，乃唐人凿六陡门，发汴水以淤下泽，民获其利，刻石以颂刺史之功。则淤田之法，其来盖久矣。
译文：熙宁年间开始推行淤田法。有人认为《史记》记的泾水泥多、既施肥又灌溉，其中施肥就是淤田。我出使到宿州，得到一块碑，记的是唐人凿六处水闸，引汴水淤灌低地；百姓受益，刻石颂扬刺史。由此看来，这种办法由来已久。
词注：陡门：节制水流的水闸。
  下泽：地势低洼的湿地。
  颂：称扬功绩。

## 单选：两种材料是谁找到或提出的？ {#q.l5.12.1}
考点：s.l5.conclusion
语境：p.l5.12.a

- [ ] 沈括亲见泾水歌谣写成，又亲见唐人开闸 {#q.l5.12.1.o2}
  理由：他所见的是唐事之碑，不是唐人施工。
- [x] “论者”举《史记》，沈括在宿州得到石碑 {#q.l5.12.1.o1}
- [ ] 唐人读《梦溪笔谈》后给刺史刻碑 {#q.l5.12.1.o3}
  理由：文中顺序跨朝代，沈括读到的是旧碑。

提示：把“论者以谓”和“予出使”各自后的内容列出。
解析：一件是别人对古书的解释，一件是沈括出使所得实物。

## 找原文证据：哪一处最直接给碑上所记的办法定出一个早于宋的时代？ {#q.l5.12.2}
考点：s.l5.conclusion
语境：p.l5.12.a

- [ ] 予出使至宿州 {#q.l5.12.2.o3}
  理由：这标沈括得碑的场合，未交代刻记何代事。
- [ ] 熙宁中 {#q.l5.12.2.o2}
  理由：这是宋朝推行淤田法的时段。
- [x] 乃唐人凿六陡门 {#q.l5.12.2.o1}

提示：找碑文所记工程的实行者。
解析：“唐人”使人能把这一办法至少追溯到唐代。

## 单选：“其来盖久矣”可以概括到哪一步？ {#q.l5.12.3}
考点：s.l5.conclusion
语境：p.l5.12.a

- [x] 在宋以前已有类似做法，石碑提供了唐代一例 {#q.l5.12.3.o1}
- [ ] 熙宁以前绝没有人在农田用过水 {#q.l5.12.3.o3}
  理由：沈括的用意恰是找到先例。
- [ ] 六座水闸一定是天下首创 {#q.l5.12.3.o2}
  理由：碑只能证有此事，不能排尽更早事例。

提示：找结语中表示推断的字，再看碑能证什么。
解析：“盖”留有推断口气，有唐例不等于确定发明人或首创年。

## 单选：“民获其利，刻石以颂刺史之功”为何值得收入你的摘要？ {#q.l5.12.4}
考点：s.l5.conclusion
语境：p.l5.12.a

- [ ] 证明沈括本人就是受颂的刺史 {#q.l5.12.4.o2}
  理由：碑记唐人事，得碑是宋时。
- [x] 交代为何留下这块可供后人查考的碑 {#q.l5.12.4.o1}
- [ ] 说明所颂的是泾水歌谣作者 {#q.l5.12.4.o3}
  理由：碑与汴水工程相连，不能把两则证据混合。

提示：“刻石以……”说的是什么目的？
解析：获利的百姓留下颂功记录，正是后来读者所见实物的来历。

## 原文：古籍引文 {#p.l5.12.b}
> 予奉使河北，边太行而北，山崖之间往往衔螺蚌壳及石子如鸟卵者，横亘石壁如带。此乃昔之海滨，今东距海已近千里，所谓大陆者皆浊泥所湮耳。
译文：我出使河北，沿太行山往北，常在山崖间见嵌着螺蚌壳和鸟卵般的石子，带状横贯石壁。沈括认为此地从前是海滨，如今向东距海已近千里，所谓大陆是浊泥淤积而成的。
词注：边：这里是沿着、顺着。
  往往：多处，沿途一再见到。
  横亘：横向连续伸展。

## 单选：这段里可直接写进“沈括路上看见的东西”的是哪项？ {#q.l5.12.5}
考点：s.l5.conclusion
语境：p.l5.12.b

- [ ] 整片大陆每年淤积多少 {#q.l5.12.5.o3}
  理由：这里没有逐年测出的数目。
- [ ] 千年前的海水当时就在脚下 {#q.l5.12.5.o2}
  理由：“昔之海滨”是他由观察作的判断。

## 找原文证据：哪一小句已从沿途所见转为推断过去的环境？ {#q.l5.12.6}
考点：s.l5.conclusion
语境：p.l5.12.b

- [x] 此乃昔之海滨 {#q.l5.12.6.o1}
- [ ] 横亘石壁如带 {#q.l5.12.6.o3}
  理由：这仍在形容石壁上可见的排列。
- [ ] 边太行而北 {#q.l5.12.6.o2}
  理由：这是奉使所走的路。

提示：找开始说“昔”的判断。
解析：作者没亲见过去的海岸，“此乃”把眼前实物与往昔联系起来。

## 单选：“石子如鸟卵者”可否概括为“发现了鸟蛋化石”？ {#q.l5.12.7}
考点：s.l5.conclusion
语境：p.l5.12.b

- [ ] 可以，“如”总是认定同一物 {#q.l5.12.7.o2}
  理由：在这里“如”表相似，不能删。
- [x] 不能，原文以鸟卵比石子的形状 {#q.l5.12.7.o1}
- [ ] 可以，所有壳都来自鸟类 {#q.l5.12.7.o3}
  理由：“螺蚌壳”明确是另一类实物。

提示：读清被比的是谁，用来比的又是谁。
解析：保持“石子”和“如”的关系，才不会给实地观察添上一种生物。

## 单选：把这段与宿州得碑一段合看，怎样写最恰当？ {#q.l5.12.8}
考点：s.l5.conclusion
语境：p.l5.12.b

- [ ] 凡沈括的推测都已由现代调查证实 {#q.l5.12.8.o3}
  理由：篇中没有现代验证材料，摘要应守住原书的证据。
- [ ] 两处都由沈括亲眼见到历史事件 {#q.l5.12.8.o2}
  理由：唐人施工和昔日海滨都非他当时亲历。
- [x] 一处凭实物推古地貌，一处凭碑记追溯古人的办法 {#q.l5.12.8.o1}

提示：都问一句：他手里的证据究竟是什么？
解析：比较时保留两种证据的差别：一是石壁里的自然物，一是记载往事的人造碑。
