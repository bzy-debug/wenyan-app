# 课文：司马迁亲眼看见了什么 {#l5.10}
简介：司马迁曾读孔子的书，也去过大梁旧址。哪些是亲眼所见，哪些是走访问来的？

## 正文

### “吾过大梁之墟”的“吾”是谁？

列传前面在讲古人，到了“太史公曰”，司马迁自己开口了。他读过谁的书，走到哪里，向谁打听，都要从这个“我”来读。尤其是“想见”二字：读了书而想象其人，和亲身去会面，是两件事。

读到“适”可试作“前往”，“墟”是旧址，“宗”有尊奉之义。把访古时做的事说清，再听他怎样评价往日的人物。这样就不会把一句赞叹误记成一次亲见。

## 知识点：史家的凭据 {#skill.l5.10}
义项：从史家自述辨出亲历、访问和评价
领域：篇章
要诀：问“这件事他从哪里知道”
讲解：读“余读”“吾过”“求问”“观”，便知道司马迁做了什么。后面若有关于古人的评语，再分辨其中多少是他亲见的，多少是他的判断。
例句：p.l5.10.example
复习题：q.l5.10.1 q.l5.10.4 q.l5.10.5 q.l5.10.8

## 原文：教学例句 {#p.l5.10.example}
> 余读其书，后过其里，问于父老，知其家在桥东。
译文：我读过他的书，后来又来到他的故乡。问当地老人，才知道他家在桥东。故里是我亲自到过的，住址则是问来的。

## 原文：古籍引文 {#p.l5.10.a}
> 余读孔氏书，想见其为人。适鲁，观仲尼庙堂车服礼器，诸生以时习礼其家，余祗回留之不能去云。天下君王至于贤人众矣，当时则荣，没则已焉。孔子布衣，传十余世，学者宗之。
译文：我读孔子的书，心中想象他的为人。到鲁地看孔庙及车服礼器，诸生按时在其家习礼，我流连不愿离去。世间君王贤人很多，当时荣耀，死后便过去了。孔子本是平民，过了十余世，学者仍尊奉他。

## 单选：司马迁说“想见其为人”，这一“想”是从哪里来的？ {#q.l5.10.1}
考点：skill.l5.10
语境：p.l5.10.a

- [ ] 与孔子同桌谈话所得口述 {#q.l5.10.1.o2}
  理由：文中先说“余读”，没有记两人见面。
- [x] 读孔氏书而形成的心中印象 {#q.l5.10.1.o1}
- [ ] 参观诸生的新车辆便见到孔子 {#q.l5.10.1.o3}
  理由：到鲁地是在读孔氏书之后。所谓“想见其为人”，还说的是先前读书时的心情。

提示：“想见”之前，他说自己做了什么？
解析：司马迁读孔子的书，想象其为人。亲自到鲁地所见的，是后来写到的庙堂与礼器。

## 找原文证据：若要说司马迁到鲁地亲眼看过什么，该引哪一句？ {#q.l5.10.2}
考点：skill.l5.10
语境：p.l5.10.a

- [ ] 学者宗之 {#q.l5.10.2.o3}
  理由：“学者宗之”说历代学者怎样尊奉孔子，没点明作者在鲁地看到哪件东西。
- [ ] 天下君王至于贤人众矣 {#q.l5.10.2.o2}
  理由：君王、贤人是拿来同孔子相较的。这句话并非参观孔庙的记录。
- [x] 观仲尼庙堂车服礼器 {#q.l5.10.2.o1}

提示：找一个明说去看、又点出实物的动作。
解析：“观仲尼庙堂车服礼器”把所见点了出来。“想见”古人为人，和亲眼见到遗物不同。

## 单选：写孔子，为何先提君王贤人“当时则荣，没则已焉”？ {#q.l5.10.3}
考点：skill.l5.10
语境：p.l5.10.a

- [x] 与孔子身后仍受学者尊奉形成对照 {#q.l5.10.3.o1}
- [ ] 据此把“布衣”解释为君王的礼服 {#q.l5.10.3.o3}
  理由：“布衣”在这儿指平民。正因为没有王位，孔子身后仍有人尊奉才格外值得一说。
- [ ] 说明所有君王都参观了孔宅 {#q.l5.10.3.o2}
  理由：上文去鲁的是司马迁。

提示：往后看，谁过了十余世还受人尊奉？
解析：一般人的荣耀随身而止。孔子一介布衣，十余世以后学者仍尊奉他，这才显出两者的不同。

## 单选：哪一种笔记分清了司马迁眼前所见和对后来世代的评价？ {#q.l5.10.4}
考点：skill.l5.10
语境：p.l5.10.a

- [ ] “想见”表明史家已直接访问孔子 {#q.l5.10.4.o2}
  理由：“余读孔氏书”说明想象源于读书。
- [x] “诸生以时习礼”是具体情形，“学者宗之”概括长期影响 {#q.l5.10.4.o1}
- [ ] “祗回留之”是给所有史官规定的考察时限 {#q.l5.10.4.o3}
  理由：这句话写作者个人流连之情。

提示：一边只记鲁地习礼的情景，另一边已经说到十余世。
解析：诸生按时习礼是具体可见的情景；说学者“宗之”，则在概括孔子身后长久的影响。

## 原文：古籍引文 {#p.l5.10.b}
> 太史公曰：“吾过大梁之墟，求问其所谓夷门。夷门者，城之东门也。天下诸公子亦有喜士者矣，然信陵君之接岩穴隐者，不耻下交，有以也。名冠诸侯，不虚耳。”
译文：太史公说，我经过大梁旧址，询问人们所说的夷门。夷门是城的东门。各国公子中也有人喜爱士人，但信陵君接待隐者，不以结交地位较低者为耻，自有缘故。他的美名高出诸侯，并非虚得。

## 单选：“吾过大梁之墟，求问……”这几句话能证明司马迁做过什么？ {#q.l5.10.5}
考点：skill.l5.10
语境：p.l5.10.b

- [ ] 史家在诸侯会议上核实了所有宫门名 {#q.l5.10.5.o3}
  理由：这里只点明一处旧址、一处城门。
- [ ] 信陵君亲自教史家如何开东门 {#q.l5.10.5.o2}
  理由：“吾”是太史公，未说受访者就是信陵君。
- [x] 史家到了大梁旧址后访求夷门的消息 {#q.l5.10.5.o1}

提示：读过“吾过”，再看是谁在“求问”、问的是什么。
解析：他亲自经过大梁旧址，又打听了夷门。向谁打听，文中没有记名。

## 找原文证据：司马迁认为信陵君的名声当不当得？请找出他自己的评语。 {#q.l5.10.6}
考点：skill.l5.10
语境：p.l5.10.b

- [x] 不虚耳 {#q.l5.10.6.o1}
- [ ] 吾过大梁之墟 {#q.l5.10.6.o3}
  理由：这是司马迁走到哪里，还没说到他如何看信陵君。
- [ ] 城之东门也 {#q.l5.10.6.o2}
  理由：这句说明夷门位置。

提示：找一句直接回应“名冠诸侯”的话。
解析：“不虚耳”说这番声名并非虚得，已经是在评价信陵君。

## 单选：“冠”有帽子和超出的读法。“名冠诸侯”中，怎样把“名”同“诸侯”连起来？ {#q.l5.10.7}
考点：skill.l5.10
语境：p.l5.10.b

- [ ] guān，声名被记在诸侯帽上 {#q.l5.10.7.o2}
  理由：本段没有谈记录或服饰。
- [x] guàn，声名居诸侯之上 {#q.l5.10.7.o1}
- [ ] guàn，史家为诸侯主持冠礼 {#q.l5.10.7.o3}
  理由：“名”是主语，前文比较礼士的声誉。

提示：试将“高出”放在“名”和“诸侯”之间。
解析：声名高出诸侯，“冠”在这里读 guàn。下文“不虚”还要说明这声名有来由。

## 单选：讲司马迁与夷门的关系，哪一项既保留他所见闻，也没有替他多说？ {#q.l5.10.8}
考点：skill.l5.10
语境：p.l5.10.b

- [ ] 他断言天下只有信陵君一人喜士 {#q.l5.10.8.o3}
  理由：首句明说其他公子“亦有喜士者”。
- [ ] 他亲眼看见信陵君迎侯生时的一切细节 {#q.l5.10.8.o2}
  理由：太史公说“吾过大梁之墟”，是后世走到旧址，不是当年在场。
- [x] 他访求了夷门，并肯定信陵君礼下隐者的声望 {#q.l5.10.8.o1}

提示：“吾过”写的是旧址，后来写礼贤的又是谁？
解析：史家亲到大梁旧址，访求夷门，并肯定信陵君结交隐者的声名。亲到旧址不能当作亲见古人迎宾。
