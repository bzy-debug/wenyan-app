# 课文：独读《颜氏家训》：一件小事怎样立得住道理 {#l5.10}
简介：先用自己的话复述一段劝诫，再从作者举的例子里核对。

## 正文

读家训不妨先合上译文，只问：“作者要家里人下次怎么做？”再通读一遍，找一个人的动作，或一个日常生活的比方，看看自己最初写下的意思够不够确切。

两条备用字义：“假”可指借用；“营馔”的“馔”（zhuàn）是饭食。是借出还是借入，谁想吃饱却不肯做饭，都要凭这一次的上下文判断。

## 知识点：用具体事例检验对家训主旨的概括 {#s.l5.evidence}
义项：用具体事例检验对家训主旨的概括
领域：阅读技能
要诀：写下作者要人怎么做，再找他所举的一件事
讲解：劝诫中可能有规矩、实例和结果。概括时应能说出具体行动，并确认自己的说法能解释例子。
例句：p.l5.10.example
复习题：q.l5.10.1 q.l5.10.3 q.l5.10.5 q.l5.10.7

## 原文：教学例句 {#p.l5.10.example}
> 假人之伞，虽晴，必归之。
译文：借了别人的伞，即使天晴也一定归还。若只概括成“应看天气”，就说明不了末句。

## 原文：古籍引文 {#p.l5.10.a}
> 借人典籍，皆须爱护。先有缺坏，就为补治。此亦士大夫百行之一也。济阳江禄读书未竟，虽有急速，必待卷束整齐，然后得起，故无损败。人不厌其求假焉。
译文：借别人的书，要一概爱护。原先已有残坏，就替人补好。这也是读书人应有的操行之一。济阳的江禄读书没读完，即使有急事，也必把书卷收束整齐才起身，所以没有损坏。别人不烦他来借书。
词注：竟：完毕，“未竟”就是尚未读完。
  求假：请求借用，此处指向人借书。
  补治：修补损坏的地方。

## 单选：如果只给这一段留一个标题，哪一个最能包含前后两半？ {#q.l5.10.1}
考点：s.l5.evidence
语境：p.l5.10.a

- [ ] 江禄如何把一卷书读到最后 {#q.l5.10.1.o2}
  理由：原文恰写书还没读完时有急事。
- [x] 怎样待借来的书，才不负出借的人 {#q.l5.10.1.o1}
- [ ] 书卷损坏后只能向人赔钱 {#q.l5.10.1.o3}
  理由：作者说替人修补，没有提赔钱。

提示：开头的规矩怎样在江禄身上看得见？
解析：先说珍惜和修补，随后写江禄收卷无损，都是借书人的操行。

## 找原文证据：哪几个字把“即使有急事也不伤书”落到了手上的动作？ {#q.l5.10.2}
考点：s.l5.evidence
语境：p.l5.10.a

- [ ] 求假 {#q.l5.10.2.o3}
  理由：这是他向别人借书，未说明怎样护书。
- [ ] 读书未竟 {#q.l5.10.2.o2}
  理由：这只是动作发生的场合。
- [x] 卷束整齐 {#q.l5.10.2.o1}

提示：找他起身以前坚持先做的事。
解析：先卷好收齐，再起身，是旁人可以照着做的事。

## 单选：“人不厌其求假焉”的“假”，怎样查义能接上开头？ {#q.l5.10.3}
考点：s.l5.evidence
语境：p.l5.10.a

- [x] 借，旁人不烦他来借书 {#q.l5.10.3.o1}
- [ ] 假期，旁人劝他从读书中休假 {#q.l5.10.3.o3}
  理由：“其求假”承接书不损坏的结果。
- [ ] 虚假，旁人不嫌他假装读书 {#q.l5.10.3.o2}
  理由：前后都在谈处理借来的书，没有作伪之事。

提示：读第一句和“故无损败”。
解析：珍惜书使别人愿借；前面的借、后面的求假正好相应。

## 单选：下面哪一句比本文多断定了一件事？ {#q.l5.10.4}
考点：s.l5.evidence
语境：p.l5.10.a

- [ ] 作者劝人把原已有缺损的借书修好 {#q.l5.10.4.o2}
  理由：“先有缺坏，就为补治”明说这条规矩。
- [x] 江禄亲手修好过这里特指的那一卷破书 {#q.l5.10.4.o1}
- [ ] 江禄有急事也收好书再起身 {#q.l5.10.4.o3}
  理由：他的具体行为写得很清楚。

提示：区分作者给所有人的劝告与随后记载的实例。
解析：文中举江禄收卷无损，没写他在这一次修补某一卷书。

## 原文：古籍引文 {#p.l5.10.b}
> 谚曰：“积财千万，不如薄伎在身。”伎之易习而可贵者，无过读书也。世人不问愚智，皆欲识人之多，见事之广，而不肯读书，是犹求饱而懒营馔，欲暖而惰裁衣也。
译文：谚语说积财千万不如随身有一门小手艺。容易学习而又可贵的本领，没有超过读书的。人无论愚智，都想多认识人、多见世事，却不肯读书，就像想吃饱懒得备饭，想取暖懒得裁衣。
词注：伎：读 jì，技艺、本领。
  营馔：置办饭食；“馔”读 zhuàn。

## 单选：“求饱而懒营馔”照应前面哪种矛盾？ {#q.l5.10.5}
考点：s.l5.evidence
语境：p.l5.10.b

- [ ] 手艺得来容易，所以财富越多越好 {#q.l5.10.5.o3}
  理由：谚语反而强调有本领的重要。
- [ ] 想学做饭，却找不到书 {#q.l5.10.5.o2}
  理由：作者说不肯读，没有说找不到书。
- [x] 想增长见闻，却不肯读书 {#q.l5.10.5.o1}

提示：找“皆欲”之后又被“而不肯”截住的事。
解析：想要结果却不行动，两边结构相同；喻体是做饭，本意是读书。

## 找原文证据：哪几个字显示下一句开始借别的事来说明？ {#q.l5.10.6}
考点：s.l5.evidence
语境：p.l5.10.b

- [x] 是犹 {#q.l5.10.6.o1}
- [ ] 谚曰 {#q.l5.10.6.o3}
  理由：这是标出引述俗谚的地方，并未领起备饭、裁衣的比方。
- [ ] 读书也 {#q.l5.10.6.o2}
  理由：这收住的是先前一句对读书的评价。

提示：“犹”在两个处境之间架起比较。
解析：“是犹”意近“这好比”，后面两例都用来揭出前面的矛盾。

## 单选：“欲暖而惰裁衣”若用来讲本文，应该怎样配对？ {#q.l5.10.7}
考点：s.l5.evidence
语境：p.l5.10.b

- [ ] 裁衣对应积财千万，取暖对应不肯读书 {#q.l5.10.7.o2}
  理由：把行动、愿望和放弃行动混到了一起。
- [x] 取暖对应增长见闻，裁衣对应读书 {#q.l5.10.7.o1}
- [ ] 暖对应饱，所以这段其实教人做家务 {#q.l5.10.7.o3}
  理由：两件家务都是用来比照读书的。

提示：分别写下目的和为此要做的事。
解析：两组比方都让读者看清：单有愿望并不会带来结果。

## 单选：“无过读书也”的范围有多宽？ {#q.l5.10.8}
考点：s.l5.evidence
语境：p.l5.10.b

- [ ] 断言读书只为了胜过别人的财产 {#q.l5.10.8.o3}
  理由：下文说的是识人见事。
- [ ] 断言世间一切事情只有读书有价值 {#q.l5.10.8.o2}
  理由：前面“伎之易习而可贵者”限定了所比的范围。
- [x] 在作者所说易习而可贵的本领中，他尤其推重读书 {#q.l5.10.8.o1}

提示：把“无过”之前的半句一并留下。
解析：概括可以简短，比较范围却不能删得比原话更绝对。
