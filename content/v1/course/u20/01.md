# 课文：读史家自述：所见、所闻与所断 {#l5.10}
简介：细读两段太史公曰，区分亲历的行程、得到的材料和史家自己的评价。

## 正文

### 史书的叙述者何时走到台前？

一篇列传可以写多年以前的人，还可以写作者后来去过哪里、读过什么。“太史公曰”之后常见史家自己的见闻与评价。这时遇到“我”，不能把它接回传主。

读两段篇末评语时各做三栏：**活动（阅读、访问或观察）｜活动所得｜作者据此怎样评价**。“适”可作动词，表示前往；“宗”可表示尊奉；“墟”是旧址。若读到作者“想见”古人，先考虑阅读后的心中形象，再看是否真的记有会面。

## 知识点：史家的凭据 {#skill.l5.10}
义项：按记述动词区分亲历、询访与推评
领域：篇章
要诀：问“他是怎样知道的”
讲解：读“余”“吾”开头的史论，找出读、过、求问、观等动作；对随后形成的评价注明判断者和判断所据。
例句：p.l5.10.example
复习题：q.l5.10.1 q.l5.10.4 q.l5.10.5 q.l5.10.8

## 原文：教学例句 {#p.l5.10.example}
> 余读其书，后过其里，问于父老，知其家在桥东。
译文：我先读书，随后经过那人的故里，向老人询问，得知他家在桥东。行程是亲历，而屋址是询得的。

## 原文：古籍引文 {#p.l5.10.a}
> 余读孔氏书，想见其为人。适鲁，观仲尼庙堂车服礼器，诸生以时习礼其家，余祗回留之不能去云。天下君王至于贤人众矣，当时则荣，没则已焉。孔子布衣，传十余世，学者宗之。
译文：我读孔子的书，心中想象他的为人。到鲁地看孔庙及车服礼器，诸生按时在其家习礼，我流连不愿离去。世间君王贤人很多，当时荣耀，死后便过去了。孔子本是平民，过了十余世，学者仍尊奉他。

## 单选：“想见其为人”的证据来源是哪一项？ {#q.l5.10.1}
考点：skill.l5.10
语境：p.l5.10.a

- [ ] 与孔子同桌谈话所得口述 {#q.l5.10.1.o2}
  理由：文中先说“余读”，没有记两人见面。
- [x] 读孔氏书而形成的心中印象 {#q.l5.10.1.o1}
- [ ] 参观诸生的新车辆便见到孔子 {#q.l5.10.1.o3}
  理由：“适鲁”是下一步行动，现场所见另有说明。

提示：读“想见”之前的第一人称动词。
解析：史家由阅读产生向往，后来到鲁地办的是访古观察，不能把想见当会见。

## 找原文证据：若说明司马迁到鲁地亲自接触过哪些材料，最应引哪一段？ {#q.l5.10.2}
考点：skill.l5.10
语境：p.l5.10.a

- [ ] 学者宗之 {#q.l5.10.2.o3}
  理由：这是对孔子身后影响的归纳。
- [ ] 天下君王至于贤人众矣 {#q.l5.10.2.o2}
  理由：这是转入比较的概述。
- [x] 观仲尼庙堂车服礼器 {#q.l5.10.2.o1}

提示：找带具体地点、对象的观察动词。
解析：“适鲁，观……”明写去处及所见之物，与对古人品格的想象层次不同。

## 单选：为什么提出君王贤人“当时则荣，没则已焉”？ {#q.l5.10.3}
考点：skill.l5.10
语境：p.l5.10.a

- [x] 与孔子身后仍受学者尊奉形成对照 {#q.l5.10.3.o1}
- [ ] 据此把“布衣”解释为君王的礼服 {#q.l5.10.3.o3}
  理由：“布衣”说明孔子是平民，更凸显持续影响。
- [ ] 说明所有君王都参观了孔宅 {#q.l5.10.3.o2}
  理由：上文去鲁的是司马迁。

提示：读两组人物在死后分别怎样。
解析：一般人的荣显随生命结束，孔子以平民身份却在多世之后仍被尊奉。

## 单选：哪份笔记把事实陈述与评论区别得最清楚？ {#q.l5.10.4}
考点：skill.l5.10
语境：p.l5.10.a

- [ ] “想见”表明史家已直接访问孔子 {#q.l5.10.4.o2}
  理由：“余读孔氏书”说明想象源于读书。
- [x] “诸生以时习礼”是具体情形，“学者宗之”概括长期影响 {#q.l5.10.4.o1}
- [ ] “祗回留之”是给所有史官规定的考察时限 {#q.l5.10.4.o3}
  理由：这句话写作者个人流连之情。

提示：在活动细节与跨时代判断之间画线。
解析：现场礼仪给出一个具体切面，篇末的历史比较表达史家的综合判断。

## 原文：古籍引文 {#p.l5.10.b}
> 太史公曰：“吾过大梁之墟，求问其所谓夷门。夷门者，城之东门也。天下诸公子亦有喜士者矣，然信陵君之接岩穴隐者，不耻下交，有以也。名冠诸侯，不虚耳。”
译文：太史公说，我经过大梁旧址，询问人们所说的夷门。夷门是城的东门。各国公子中也有人喜爱士人，但信陵君接待隐者，不以结交地位较低者为耻，自有缘故。他的美名高出诸侯，并非虚得。

## 单选：“求问其所谓夷门”应怎样写进史料卡？ {#q.l5.10.5}
考点：skill.l5.10
语境：p.l5.10.b

- [ ] 史家在诸侯会议上核实了所有宫门名 {#q.l5.10.5.o3}
  理由：这里只点明一处旧址、一处城门。
- [ ] 信陵君亲自教史家如何开东门 {#q.l5.10.5.o2}
  理由：“吾”是太史公，未说受访者就是信陵君。
- [x] 史家到了大梁旧址后访求夷门的消息 {#q.l5.10.5.o1}

提示：在“吾”的连续行动里找到访求对象。
解析：“过”是自己的行程，“求问”是搜集材料；受访人的具体姓名没有写出。

## 找原文证据：哪一句直接表明作者对信陵君声名的态度？ {#q.l5.10.6}
考点：skill.l5.10
语境：p.l5.10.b

- [x] 不虚耳 {#q.l5.10.6.o1}
- [ ] 吾过大梁之墟 {#q.l5.10.6.o3}
  理由：这句说明访求的地点。
- [ ] 城之东门也 {#q.l5.10.6.o2}
  理由：这句说明夷门位置。

提示：在结尾找对声名真假作判断的字。
解析：“不虚耳”明确肯定这个声名有根据，此处已由访古转向人物评价。

## 单选：字书列“冠”guān（帽子）、guàn（超出）。结合史家判断，怎样读“名冠诸侯”？ {#q.l5.10.7}
考点：skill.l5.10
语境：p.l5.10.b

- [ ] guān，声名被记在诸侯帽上 {#q.l5.10.7.o2}
  理由：本段没有谈记录或服饰。
- [x] guàn，声名居诸侯之上 {#q.l5.10.7.o1}
- [ ] guàn，史家为诸侯主持冠礼 {#q.l5.10.7.o3}
  理由：“名”是主语，前文比较礼士的声誉。

提示：代入“名”与比较对象“诸侯”。
解析：“冠”在比较中作谓语，正与“不虚”合成对其声誉的判断。

## 单选：哪条结论合乎史家实际陈述的范围？ {#q.l5.10.8}
考点：skill.l5.10
语境：p.l5.10.b

- [ ] 他断言天下只有信陵君一人喜士 {#q.l5.10.8.o3}
  理由：首句明说其他公子“亦有喜士者”。
- [ ] 他亲眼看见信陵君迎侯生时的一切细节 {#q.l5.10.8.o2}
  理由：这段只明说后人到旧址访求。
- [x] 他访求了夷门，并肯定信陵君礼下隐者的声望 {#q.l5.10.8.o1}

提示：把“吾过”“求问”和“然”之后的评说分层。
解析：亲到遗址为访古，人物评价还须从叙事和论说理解，不能推出直接目击古人。
