# 课文：跟柳宗元走到小潭，沿浔水认方向 {#l5.11}
简介：和柳宗元走到小潭，再沿着柳州的水路读。都是写方向，动的是人，还是水？

## 正文

### 给地图上的箭头找个主人

“向西走”是人在走，“西边有山”则是说山的位置。画路线时，先把站脚处画出来，再看下一句是转身看、举步走，还是换成河水在流。支川已经入了干流，后面的箭头还属于哪一条河？

“篁”（huáng）是竹丛，“冽”（liè）说水寒凉。再读“州治”，“治”是地方官署的驻地。“可砚”不妨补成“可制砚”，回头看看哪一处出产这样的石头。

查字时可直接翻到这里。[篁](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E7%AF%81)

## 知识点：观察点与方位 {#skill.l5.11}
义项：辨清在什么地方、朝哪个方向观察或移动
领域：阅读技能
要诀：换了人或水，就重找箭头的起点
讲解：游人会走、会听、会望，河水也会北流东转。认出谁在动、以哪里为起点，方向就有了着落。
例句：p.l5.11.example
复习题：q.l5.11.1 q.l5.11.3 q.l5.11.5 q.l5.11.7

## 原文：教学例句 {#p.l5.11.example}
> 从亭南行，闻溪声。登石西望，见一桥跨溪。
译文：从亭子往南走，听见溪水声；登上岩石向西望，看见一座桥跨在溪上。人刚才往南走，登高之后却向西看。

## 原文：古籍引文 {#p.l5.11.a}
> 从小丘西行百二十步，隔篁竹，闻水声，如鸣佩环，心乐之。伐竹取道，下见小潭，水尤清冽。
译文：从小丘向西走一百二十步，隔着竹丛听到水声，好像佩环相击，心里为之欢喜。砍竹开道，往下才看见小潭，水格外清凉澄澈。

## 单选：“从小丘西行”若画成一段路，从哪里出发，谁在向西走？ {#q.l5.11.1}
考点：skill.l5.11
语境：p.l5.11.a

- [ ] 小潭；水自潭西流 {#q.l5.11.1.o2}
  理由：“从小丘”明示出发点，水流方向未写。
- [x] 小丘；游人向西走 {#q.l5.11.1.o1}
- [ ] 竹林；佩环向西移动 {#q.l5.11.1.o3}
  理由：佩环只用来比声音。

提示：从哪里出发，和谁在“行”，分开问。
解析：游人从小丘出发向西走。这里写他的脚步，还没有交代水往哪边流。

## 找原文证据：为什么已经听见水响，却还没望见潭面？原文哪三个字写出了原因？ {#q.l5.11.2}
考点：skill.l5.11
语境：p.l5.11.a

- [ ] 水尤清冽 {#q.l5.11.2.o3}
  理由：这是见潭之后的观察。
- [ ] 心乐之 {#q.l5.11.2.o2}
  理由：“心乐之”说听了欢喜。眼前是什么把潭挡住，得往前找。
- [x] 隔篁竹 {#q.l5.11.2.o1}

提示：找挡在游人和水之间的东西。
解析：隔着篁竹，先有水声传来。后来伐竹开路，才往下看见小潭。

## 排序：从听见水响到看见小潭，中间是怎样一步步走过去的？ {#q.l5.11.3}
考点：skill.l5.11
语境：p.l5.11.a

- [1] 隔竹听见流水 {#q.l5.11.3.o1}
- [3] 往下看见小潭 {#q.l5.11.3.o3}
- [2] 砍竹开出道路 {#q.l5.11.3.o2}

提示：“闻”先于“见”。为了走过去，还得做什么？
解析：先隔竹听水，再伐竹取道，最后才从上往下见潭。

## 单选：“如鸣佩环”写的是游人在哪里发现了佩环，还是写他听来怎样？ {#q.l5.11.4}
考点：skill.l5.11
语境：p.l5.11.a

- [ ] 遗物出土，发现佩环的实际地点 {#q.l5.11.4.o2}
  理由：“如”是比拟，没有记出土。
- [x] 听觉印象，用佩环之声形容水响 {#q.l5.11.4.o1}
- [ ] 行政沿革，佩环是小丘古地名 {#q.l5.11.4.o3}
  理由：从“闻水声”往下，是在形容听来怎样，没有给小丘另起地名。

提示：紧挨比喻的那个动作是“闻”还是“见”？
解析：佩环相击是用来比水声的。比喻让人听得出水响，并没有说游人捡到了佩环。

## 原文：古籍引文 {#p.l5.11.b}
> 古之州治在浔水南山石间，今徙在水北，直平四十里，南北东西皆水汇。北有双山夹道崭然，曰背石山。有支川东流入于浔水，浔水因是北而东，尽大壁下。其壁曰龙壁，其下多秀石可砚。
译文：旧州治在浔水以南的山石之间，现在迁到水北，有一带平地绵延四十里，四面水流会聚。北面两山高耸，夹着道路，叫背石山。一条支流向东汇入浔水；浔水由这里先向北再向东，一直流到大岩壁下。岩壁名龙壁，壁下有好石，可以制砚。

## 单选：“古之州治”与“今徙”，在地图上分别要标在哪里？ {#q.l5.11.5}
考点：skill.l5.11
语境：p.l5.11.b

- [ ] 游人先渡支流，再溯到北门 {#q.l5.11.5.o3}
  理由：“古之州治……今徙……”讲的是官署搬了家，未说游人过河。
- [ ] 同一座山从南岸移到北岸 {#q.l5.11.5.o2}
  理由：“徙”的是州治，非山体。
- [x] 旧州治在浔水南，新州治在水北 {#q.l5.11.5.o1}

提示：找两个不同的时间，以及它们各自对应的水岸。
解析：旧州治在浔水南岸，后来迁到水北。移动的是州治的地点。

## 找原文证据：哪几个字把支川汇进浔水时的流向写出来了？ {#q.l5.11.6}
考点：skill.l5.11
语境：p.l5.11.b

- [x] 东流入于浔水 {#q.l5.11.6.o1}
- [ ] 南北东西皆水汇 {#q.l5.11.6.o3}
  理由：“南北东西”是放眼四周；到“有支川”才专写一条水路。
- [ ] 北而东 {#q.l5.11.6.o2}
  理由：这时主语已改作浔水。

提示：先跟着“有支川”往下读，读到下一次点出“浔水”为止。
解析：支川向东流入浔水，所以下句“北而东”才要换成浔水作主语。

## 单选：把“北而东”画成游人向北再向东走，为什么画错了？ {#q.l5.11.7}
考点：skill.l5.11
语境：p.l5.11.b

- [ ] “北而东”只表示过了两天 {#q.l5.11.7.o2}
  理由：北、东在此均为方向。
- [x] 这句明写浔水作主语，应该画干流转向 {#q.l5.11.7.o1}
- [ ] 游客必定只能向南步行 {#q.l5.11.7.o3}
  理由：原文没有对游路作这种限制。

提示：“因是”之前明写的是谁或什么？
解析：向北再转向东的，是支川汇入后的浔水。这两笔应画在河道上。

## 单选：读到“其下多秀石可砚”，应到哪处地物之下找能制砚的石头？ {#q.l5.11.8}
考点：skill.l5.11
语境：p.l5.11.b

- [ ] 背石山的双峰顶上 {#q.l5.11.8.o3}
  理由：先前写双山，随后已经沿水转到大壁。
- [ ] 所有州治的官署内 {#q.l5.11.8.o2}
  理由：“其壁曰龙壁”紧挨在前，“其下”自然接着龙壁说。
- [x] 龙壁之下 {#q.l5.11.8.o1}

提示：把连续两句中的“其壁”“其下”接起来。
解析：刚说那面岩壁叫龙壁，“其下”自然是龙壁之下。那里有可制砚的好石。
