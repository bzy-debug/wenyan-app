# 课文：独读永州游记：沿哪条路，看见什么？ {#l5.11}
简介：从几个相近的方向词中还原路线，也听一听柳宗元自己怎样解释当地的话。

## 正文

一张随手画的小图，只要能辨认分岔和两岸就够用。把每个“由……”写在新一行，再看看作者是在接上一步走，还是另起一路作比较。遇见本地方言，也别急着从字面猜：游记作者有时亲自说明当地怎样叫、怎样念。

地名“渴”在柳宗元这篇里另有音义。读到正文交代了什么，再决定要不要查现代词典里的口渴义。

## 知识点：按参照地点与比较词复原游记中的见闻 {#s.l5.comparison}
义项：按参照地点与比较词复原游记中的见闻
领域：阅读技能
要诀：把每段路线的起点、方向、所见连起来
讲解：“由”“自”交代起点，“其一”分岔，“莫若”在一组风景里评高下。画路线前先看这些词，免得把几条路串成一条。
例句：p.l5.11.example
复习题：q.l5.11.1 q.l5.11.3 q.l5.11.5 q.l5.11.7

## 原文：教学例句 {#p.l5.11.example}
> 自桥东行有亭；自桥北行有泉。
译文：从桥往东有亭，从桥往北有泉。两句都从桥出发，不能画成先到亭再北行。

## 原文：古籍引文 {#p.l5.11.a}
> 由冉溪西南水行十里，山水之可取者五，莫若钴鉧潭。由溪口而西陆行，可取者八九，莫若西山。由朝阳岩东南水行，至芜江，可取者三，莫若袁家渴。皆永中幽丽奇处也。楚越之间方言，谓水之支流者为渴，音若衣褐之褐。
译文：从冉溪向西南行水路十里，有五处山水可赏，首推钴鉧潭。从溪口往西走陆路，可赏者八九处，首推西山。从朝阳岩向东南坐船到芜江，可赏三处，首推袁家渴。这些都是永州的幽美奇胜。楚越一带称水的支流为“渴”，读音像衣褐的“褐”。
词注：可取：值得观赏。
  莫若：没有比得上。
  褐：读 hè，粗布衣。作者借它说明本地方言词的读音。

## 单选：若只打算走到“莫若西山”的那一组，按作者怎么走？ {#q.l5.11.1}
考点：s.l5.comparison
语境：p.l5.11.a

- [ ] 由冉溪西南行水路十里 {#q.l5.11.1.o2}
  理由：这组评的是钴鉧潭。
- [x] 由溪口向西走陆路 {#q.l5.11.1.o1}
- [ ] 由朝阳岩往东南坐船至芜江 {#q.l5.11.1.o3}
  理由：这路首推袁家渴。

提示：每个“莫若”回看前面最近的“由”。
解析：西山在第二组，起点是溪口，行法是陆行。

## 找原文证据：哪四个字明确给“渴”释义，不只说明怎样读？ {#q.l5.11.2}
考点：s.l5.comparison
语境：p.l5.11.a

- [ ] 楚越之间 {#q.l5.11.2.o3}
  理由：这是方言使用范围，还没有说词义。
- [ ] 衣褐之褐 {#q.l5.11.2.o2}
  理由：这是用熟字近似标音。
- [x] 水之支流 {#q.l5.11.2.o1}

提示：把“谓……为……”与“音若……”分开。
解析：作者亲自解释当地用词，所指是支流；读音另说。

## 单选：可以根据“三、五、八九”给这几条路排长度吗？ {#q.l5.11.3}
考点：s.l5.comparison
语境：p.l5.11.a

- [x] 不能，这些数说的是值得看的地方有几处 {#q.l5.11.3.o1}
- [ ] 能，八九是转了八九个弯 {#q.l5.11.3.o3}
  理由：文中没有这样逐个数弯。
- [ ] 能，三一定是三里 {#q.l5.11.3.o2}
  理由：第三路的“三”跟在“可取者”后。

提示：找每个数前面有没有“里”。
解析：只第一组明说“十里”；好景的数目不能当里程。

## 单选：若摘掉前两组，只读“莫若袁家渴”，容易误作哪种断言？ {#q.l5.11.4}
考点：s.l5.comparison
语境：p.l5.11.a

- [ ] 朝阳岩至芜江一带作者最喜欢袁家渴 {#q.l5.11.4.o2}
  理由：这仍保留第三组路线的范围。
- [x] 永州所有胜地都一定比不上袁家渴 {#q.l5.11.4.o1}
- [ ] “莫若”是在作比较 {#q.l5.11.4.o3}
  理由：词义本来如此。

提示：作者在每一路都评了一处。
解析：第三个“莫若”照应本组，可取的三处之中首推袁家渴。

## 原文：古籍引文 {#p.l5.11.b}
> 自西山道口径北，逾黄茅岭而下，有二道。其一西出，寻之无所得；其一少北而东，不过四十丈，土断而川分，有积石横当其垠。其上为睥睨、梁欐之形，其旁出堡坞，有若门焉。窥之正黑，投以小石，洞然有水声，其响之激越，良久乃已。
译文：从西山路口径向北走，越过黄茅岭往下，有两条路。一条向西，沿着走没发现什么；另一条略向北再向东，不到四十丈，土坡中断，水流分开，边缘横着积石。上面像城上矮墙、屋梁，旁边突起像堡垒，有一处像门。向里看很黑，投入小石，空洞中传来水声，响亮的回声很久才停。
词注：睥睨：在这里指城上的矮墙。
  梁欐：屋梁；“欐”读 lì。
  良久：很久。

## 单选：在哪一条路看见积石？ {#q.l5.11.5}
考点：s.l5.comparison
语境：p.l5.11.b

- [ ] 尚未过黄茅岭的时候 {#q.l5.11.5.o3}
  理由：“有二道”在越岭之后。
- [ ] 西出的那条 {#q.l5.11.5.o2}
  理由：“寻之无所得”收住第一条。
- [x] 略往北又向东的那条 {#q.l5.11.5.o1}

提示：两个“其一”各领一条。
解析：作者先略过西路，再详写第二条路的景物。

## 找原文证据：何处提醒我们那只是石头像门，未说真的建了一扇门？ {#q.l5.11.6}
考点：s.l5.comparison
语境：p.l5.11.b

- [x] 有若门焉 {#q.l5.11.6.o1}
- [ ] 正黑 {#q.l5.11.6.o3}
  理由：这是朝里看的结果。
- [ ] 积石 {#q.l5.11.6.o2}
  理由：说明材料，却没有单独表出比拟。

提示：留心表示“像”的字。
解析：“若”为比况，与上文的“之形”相应。

## 单选：探看那处像门的地方，作者的耳朵补充了眼睛未能获得的什么？ {#q.l5.11.7}
考点：s.l5.comparison
语境：p.l5.11.b

- [ ] 洞底有多深的精确数字 {#q.l5.11.7.o2}
  理由：“不过四十丈”是第二条路已走的距离。
- [x] 洞里有水声，回响许久 {#q.l5.11.7.o1}
- [ ] 是谁建的城门 {#q.l5.11.7.o3}
  理由：作者只说象形，也没有找到工匠。

提示：“窥”“投”“有……声”接起来读。
解析：眼只见黑，投石后才听见回响；水声不等于量出了水深。

## 排序：作者如何探看那处像门的石洞？排出他的见闻。 {#q.l5.11.8}
考点：s.l5.comparison
语境：p.l5.11.b

- [2] 投入一块小石 {#q.l5.11.8.o2}
  理由：看不清里面，才有“投以小石”的动作。
- [3] 听见水声，回响许久才停 {#q.l5.11.8.o3}
  理由：“其响”接在投石之后。
- [1] 探头往里看，只见黑暗 {#q.l5.11.8.o1}
  理由：“窥之正黑”是眼睛最先取得的印象。

提示：找出从“窥”转到“投”再转到“响”的地方。
解析：先由目而后由耳。回响来自一次可指出的尝试，文中没有量出洞深。
