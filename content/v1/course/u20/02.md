# 课文：读山水记：用视点复原方位 {#l5.11}
简介：跟随足迹、视线和水流，读懂方位词指的是谁相对谁的位置。

## 正文

### 路线图只添原文许给你的箭头

“向西走”和“西边有山”都写西，前者的箭头属于行人，后者是相对地点。描写水流时，连续方向的主语有时从支川变为干流。试把每句压成“谁｜从哪里｜向哪边｜看见或经过什么”。

“篁”（huáng）可指竹丛，“冽”（liè）形容寒凉，“治”在“州治”中是地方行政机构的驻地。碰到“可砚”，可试补“可以制成砚”，再查它承接何物。课内两篇一写个人进入小潭的感受，一写柳州近治各地的相对方位。

查阅《重编国语辞典修订本》的字头。[篁](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E7%AF%81)

## 知识点：观察点与方位 {#skill.l5.11}
义项：给方向、地物和感知动词配上观察起点
领域：阅读技能
要诀：每换位置就重标参照物
讲解：游记中既可写人的步行、听见、看见，也可写水和地物自身的位置。先看主语，再在纸上画短路线。
例句：p.l5.11.example
复习题：q.l5.11.1 q.l5.11.3 q.l5.11.5 q.l5.11.7

## 原文：教学例句 {#p.l5.11.example}
> 从亭南行，闻溪声。登石西望，见一桥跨溪。
译文：从亭子向南走，听见溪水声；登石向西望，看到溪上一桥。行进方向与登高后的目光方向不同。

## 原文：古籍引文 {#p.l5.11.a}
> 从小丘西行百二十步，隔篁竹，闻水声，如鸣佩环，心乐之。伐竹取道，下见小潭，水尤清冽。
译文：从小丘向西走一百二十步，隔着竹丛听到水声，好像佩环相击，心里为之欢喜。砍竹开道，往下才看见小潭，水格外清凉澄澈。

## 单选：若给第一段画箭头，“西”的起点和运动者分别是什么？ {#q.l5.11.1}
考点：skill.l5.11
语境：p.l5.11.a

- [ ] 小潭；水自潭西流 {#q.l5.11.1.o2}
  理由：“从小丘”明示出发点，水流方向未写。
- [x] 小丘；游人向西走 {#q.l5.11.1.o1}
- [ ] 竹林；佩环向西移动 {#q.l5.11.1.o3}
  理由：佩环只用来比声音。

提示：看“从”之后的地物与“行”的隐含主语。
解析：“从小丘西行”写沿途动作，再由听觉引向所见景物。

## 找原文证据：哪三个字最能解释为什么已经听见水声却尚未看见潭？ {#q.l5.11.2}
考点：skill.l5.11
语境：p.l5.11.a

- [ ] 水尤清冽 {#q.l5.11.2.o3}
  理由：这是见潭之后的观察。
- [ ] 心乐之 {#q.l5.11.2.o2}
  理由：欣喜是听声的反应，没有交代遮挡物。
- [x] 隔篁竹 {#q.l5.11.2.o1}

提示：在“闻”前面找观察者和水之间有什么。
解析：竹丛构成阻隔，后文“伐竹取道，下见小潭”进一步印证。

## 排序：将游人获取信息的过程排好。 {#q.l5.11.3}
考点：skill.l5.11
语境：p.l5.11.a

- [1] 隔竹听见流水 {#q.l5.11.3.o1}
- [3] 往下看见小潭 {#q.l5.11.3.o3}
- [2] 砍竹开出道路 {#q.l5.11.3.o2}

提示：注意“闻”与“见”的先后。
解析：前半先听后喜，开道以后才见其水。比喻声响并非先看到了佩环。

## 单选：“如鸣佩环”应放进记录的哪一栏？ {#q.l5.11.4}
考点：skill.l5.11
语境：p.l5.11.a

- [ ] 遗物出土，发现佩环的实际地点 {#q.l5.11.4.o2}
  理由：“如”是比拟，没有记出土。
- [x] 听觉印象，用佩环之声形容水响 {#q.l5.11.4.o1}
- [ ] 行政沿革，佩环是小丘古地名 {#q.l5.11.4.o3}
  理由：前后都在写行路和感知，没有地名解释。

提示：看看它紧接的感官动词。
解析：“闻水声”领起比喻，声音可比，物体并未因此出现在现场。

## 原文：古籍引文 {#p.l5.11.b}
> 古之州治在浔水南山石间，今徙在水北，直平四十里，南北东西皆水汇。北有双山夹道崭然，曰背石山。有支川东流入于浔水，浔水因是北而东，尽大壁下。其壁曰龙壁，其下多秀石可砚。
译文：从前的州治在浔水南岸山石之间，如今迁到水北，这里有大片平地，四周有水汇流。北面有双山夹道，叫背石山。一条支流东流入浔水；浔水由此向北再向东，直到大岩壁下面。此壁名龙壁，下方有好石可制砚。

## 单选：“古之……今徙……”在图上应记哪两个位置？ {#q.l5.11.5}
考点：skill.l5.11
语境：p.l5.11.b

- [ ] 游人先渡支流，再溯到北门 {#q.l5.11.5.o3}
  理由：这是州治沿革，尚未写游人渡河。
- [ ] 同一座山从南岸移到北岸 {#q.l5.11.5.o2}
  理由：“徙”的是州治，非山体。
- [x] 旧州治在浔水南，新州治在水北 {#q.l5.11.5.o1}

提示：让两个方位都回答“州治在哪里”。
解析：“古之”“今”对举；同一行政驻地在不同时期的位置不同。

## 找原文证据：哪一原文短语说明支川汇入干流的方向？ {#q.l5.11.6}
考点：skill.l5.11
语境：p.l5.11.b

- [x] 东流入于浔水 {#q.l5.11.6.o1}
- [ ] 南北东西皆水汇 {#q.l5.11.6.o3}
  理由：这是概写四周水汇，没有单指这条支川。
- [ ] 北而东 {#q.l5.11.6.o2}
  理由：这时主语已改作浔水。

提示：找“有支川”后的动作。
解析：“支川东流入于浔水”所属关系明确；后句才换成浔水的流向。

## 单选：若在地图上把“北而东”画成游客的脚步，错在哪里？ {#q.l5.11.7}
考点：skill.l5.11
语境：p.l5.11.b

- [ ] “北而东”只表示过了两天 {#q.l5.11.7.o2}
  理由：北、东在此均为方向。
- [x] 这句明写浔水作主语，应该画干流转向 {#q.l5.11.7.o1}
- [ ] 游客必定只能向南步行 {#q.l5.11.7.o3}
  理由：原文没有对游路作这种限制。

提示：先在“因是”前找到名词。
解析：动向词相同，主语改变，地图箭头所代表的对象也应随之改变。

## 单选：“其下多秀石可砚”应将砚材标在何处？ {#q.l5.11.8}
考点：skill.l5.11
语境：p.l5.11.b

- [ ] 背石山的双峰顶上 {#q.l5.11.8.o3}
  理由：先前写双山，随后已经沿水转到大壁。
- [ ] 所有州治的官署内 {#q.l5.11.8.o2}
  理由：本句的最近参照物是龙壁。
- [x] 龙壁之下 {#q.l5.11.8.o1}

提示：连续追溯两个“其”各指什么。
解析：“其壁曰龙壁”命名大壁，“其下”即龙壁下方，秀石是能制砚的材料。
