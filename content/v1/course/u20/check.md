# 检查：三段自读：校书、登山与活板印书 {#check.20}

## 原文：古籍引文 {#p.check.20.a}
> 校定书籍，亦何容易！自杨雄、刘向，方称此职耳。观天下书未遍，不得妄下雌黄。或彼以为非，此以为是；或本同末异；或两文皆欠，不可偏信一隅也。
译文：校订书籍谈何容易！颜之推举扬雄、刘向为能胜任这项工作的人。书还没读得周全，别轻易涂改。这一本以为对的，那一本也许以为错；两本文字可能起头一样，末尾却不同，甚至两本都有缺漏，不能只信一边。

## 单选：“下雌黄”指涂改文字。颜之推为什么劝人不要轻率动笔？ {#q.check.20.1}
考点：skill.l5.10
语境：p.check.20.a

- [ ] 宣称每种改字都来自亲见作者手稿 {#q.check.20.1.o2}
  理由：文中没有任何“亲见手稿”的叙述。
- [x] 列出传文各异、两文皆欠等情形，说明单一材料未必够用 {#q.check.20.1.o1}
- [ ] 只用杨雄、刘向的名字断定某字一定错 {#q.check.20.1.o3}
  理由：说到杨雄、刘向，是举能胜任校书者。这里没有哪一个争议字由他们作了裁决。

提示：“或”字出现了几次？它每次提出什么情况？
解析：有的版本写法不同，有的判断相反，甚至两种文字都缺。只看一处就动笔，怎么知道改的是对的？

## 单选：现在只见甲乙两本，甲多一行。“或两文皆欠”提醒你还要想哪一种可能？ {#q.check.20.2}
考点：skill.l5.12
语境：p.check.20.a

- [ ] 因乙字少，断言乙必为作者定稿 {#q.check.20.2.o3}
  理由：字少，也可能有脱文。到底是不是作者定稿，还得另查来历。
- [ ] 断言甲乙一定同样缺这行 {#q.check.20.2.o2}
  理由：“或”表示可能，不表示两本的实际缺处已经查明。
- [x] 把它当作须再求旁证的可能，不能凭行数判定甲必完整 {#q.check.20.2.o1}

提示：多一行能说明甲比乙长，能不能说明甲就是全本？
解析：颜氏说两本都有缺也有可能。他没有替这两本判定缺了什么，还须找别的材料核对。

## 原文：古籍引文 {#p.check.20.b}
> 遂命仆人过湘江，缘染溪，斫榛莽，焚茅茷，穷山之高而止。攀援而登，箕踞而遨，则凡数州之土壤皆在衽席之下。其高下之势，岈然洼然，若垤若穴，尺寸千里，攒蹙累积，莫得遁隐。萦青缭白，外与天际，四望如一。然后知山之特出，不与培塿为类。
译文：于是使仆人过湘江、沿染溪，除草木，一直到山的高处。攀到山上舒展地坐着，几州的土地像都在坐席下，高低起伏在眼底聚拢，千里如在尺寸之间，远处与天相接。到这时才体会此山的卓绝，不同于小土丘。

## 单选：“缘”是沿着，“衽席”是坐卧的席子。登西山的人怎样走到能俯看数州的地方？ {#q.check.20.3}
考点：skill.l5.11
语境：p.check.20.b

- [x] 过江沿溪上山，登高安坐后俯看数州 {#q.check.20.3.o1}
- [ ] 未离江岸，在地图上把千里量成尺寸 {#q.check.20.3.o3}
  理由：文中有过江、除草木和攀登的连续动作。
- [ ] 先在数州地下坐卧，之后沿溪下山 {#q.check.20.3.o2}
  理由：“攀援而登”清楚标出移动方向。

提示：从“过”“缘”一路读到“攀援而登”。
解析：过江、沿溪、登山，坐定以后，数州仿佛尽在座下。千里如在尺寸之间，是登高亲眼所见的景象。

## 单选：“然后知山之特出”，这个“然后”要接在怎样的一番经历之后？ {#q.check.20.4}
考点：skill.l5.11
语境：p.check.20.b

- [ ] 仆人还没过江时就已量出西山高度 {#q.check.20.4.o2}
  理由：“然后”把判断放在登顶观景之后。
- [x] 实际登临后四望，远近景物尽收眼底 {#q.check.20.4.o1}
- [ ] 据“培塿”一词查出西山精确海拔 {#q.check.20.4.o3}
  理由：把西山与小土丘相比，能讲高下之感，不能由此查出精确海拔。

提示：“四望”时，人是已经登上了山，还是仍在对岸？
解析：登顶后，高低远近收入眼底，作者才领会西山格外卓绝。“培塿”是小土丘，这里拿来作比较。

## 原文：古籍引文 {#p.check.20.c}
> 若止印三二本，未为简易；若印数十百千本，则极为神速。常作二铁板，一板印刷，一板已自布字。此印者才毕，则第二板已具，更互用之，瞬息可就。……昇死，其印为予群从所得，至今保藏。
译文：只印两三本，算不上省事。要印几十、几百、几千本，便快得很。常备两块铁板，这块在印，那块已在排字。这块刚印完，另一块就备好了，轮换着用，很快就能印成。……毕昇死后，他的字印到了沈括的同族亲人手中，一直保存到沈括写下此文时。

## 单选：“更互”是轮换。两块板实际怎样配合？印多少才看得出这办法的长处？ {#q.check.20.5}
考点：skill.l5.12
语境：p.check.20.c

- [ ] 无论印多少都因同时多出两册而加倍 {#q.check.20.5.o3}
  理由：一板印刷时另一板在排字，不是两板同时印。
- [ ] 即使只印两册，作者也断言一定最省事 {#q.check.20.5.o2}
  理由：若只印两三册，沈括明说还谈不上省事。
- [x] 印数大时长处尤其明显，两板交替减少等候 {#q.check.20.5.o1}

提示：别略过开头两个“若”，再给两块板各派它正在做的事。
解析：印数多时格外快。第一板印刷的工夫，第二板已经排好字，换上就能接着印。

## 单选：“其印为予群从所得”记下了一件什么事？单凭这句还能说沈括亲见每次印书吗？ {#q.check.20.6}
考点：skill.l5.10
语境：p.check.20.c

- [x] 说明作者家族保存字印，但不能单凭此句证明他目睹每次印刷 {#q.check.20.6.o1}
- [ ] 说明字印在毕昇死时全部毁去 {#q.check.20.6.o3}
  理由：“所得”“保藏”恰好写保存下来。
- [ ] 证明毕昇把印书全程逐字口授给作者 {#q.check.20.6.o2}
  理由：“昇死”是这句话的起点，只告诉我们他身后留下来的字印到了谁家。

提示：“群从”是同族亲属，句中得到的是字印，还是一份目击说明？
解析：毕昇死后，沈括的同族亲人得到了字印并保存下来。这能说明实物的去向；观察每一次印刷的人是谁，末句并没有说。
