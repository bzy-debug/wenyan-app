## 原文：古籍引文 {#p.check.20.a}
> 校定书籍，亦何容易！自杨雄、刘向，方称此职耳。观天下书未遍，不得妄下雌黄。或彼以为非，此以为是；或本同末异；或两文皆欠，不可偏信一隅也。
译文：校订书籍谈何容易！作者举扬雄、刘向为胜任者。未能广泛观书，不可随意改定。各方判断可能有异，也可能开头相同而末尾有别，甚至两种文本都有缺漏，不能偏信一端。

## 单选：“下雌黄”在这里可按涂改文字来理解。作者怎样为慎改的态度举证？ {#q.check.20.1}
考点：skill.l5.10
语境：p.check.20.a

- [ ] 宣称每种改字都来自亲见作者手稿 {#q.check.20.1.o2}
  理由：文中没有任何“亲见手稿”的叙述。
- [x] 列出传文各异、两文皆欠等情形，说明单一材料未必够用 {#q.check.20.1.o1}
- [ ] 只用杨雄、刘向的名字断定某字一定错 {#q.check.20.1.o3}

## 单选：若校读者只见甲乙两本，甲比乙多一行，应怎样用“或两文皆欠”？ {#q.check.20.2}
考点：skill.l5.12
语境：p.check.20.a

- [ ] 因乙字少，断言乙必为作者定稿 {#q.check.20.2.o3}
  理由：篇幅长短不足以证明来源或年代。
- [ ] 断言甲乙一定同样缺这行 {#q.check.20.2.o2}
  理由：“或”表示可能，不表示两本的实际缺处已经查明。
- [x] 把它当作须再求旁证的可能，不能凭行数判定甲必完整 {#q.check.20.2.o1}

提示：区分警示的可能性与实际校勘结论。
解析：颜氏提出不止一种情形，提醒读者别把仅见的一方或两方当作全部证据。

## 原文：古籍引文 {#p.check.20.b}
> 遂命仆人过湘江，缘染溪，斫榛莽，焚茅茷，穷山之高而止。攀援而登，箕踞而遨，则凡数州之土壤皆在衽席之下。其高下之势，岈然洼然，若垤若穴，尺寸千里，攒蹙累积，莫得遁隐。萦青缭白，外与天际，四望如一。然后知山之特出，不与培塿为类。
译文：于是使仆人过湘江、沿染溪，除草木，一直到山的高处。攀到山上舒展地坐着，几州的土地像都在坐席下，高低起伏在眼底聚拢，千里如在尺寸之间，远处与天相接。到这时才体会此山的卓绝，不同于小土丘。

## 单选：“缘”可作沿着，“衽席”是坐卧之席。哪一种路线到视点的变化符合本文？ {#q.check.20.3}
考点：skill.l5.11
语境：p.check.20.b

- [x] 过江沿溪上山，登高安坐后俯看数州 {#q.check.20.3.o1}
- [ ] 未离江岸，在地图上把千里量成尺寸 {#q.check.20.3.o3}
  理由：文中有过江、除草木和攀登的连续动作。
- [ ] 先在数州地下坐卧，之后沿溪下山 {#q.check.20.3.o2}
  理由：“攀援而登”清楚标出移动方向。

提示：从“过、缘、登”走到“衽席之下”。
解析：到达山高处才有数州似在座下的观察效果，“尺寸千里”是登临视野的压缩。

## 单选：“然后知山之特出”中，“然后”要接回哪项经验？ {#q.check.20.4}
考点：skill.l5.11
语境：p.check.20.b

- [ ] 仆人还没过江时就已量出西山高度 {#q.check.20.4.o2}
  理由：“然后”把判断放在登顶观景之后。
- [x] 实际登临后四望，远近景物尽收眼底 {#q.check.20.4.o1}
- [ ] 据“培塿”一词查出西山精确海拔 {#q.check.20.4.o3}
  理由：培塿指小土丘，用来比较，没有准确测量值。

提示：找到判断之前的观察者及所见范围。
解析：作者从所处视点及其四望所得提出评价，不能把这种现场经验改为绝对测高。

## 原文：古籍引文 {#p.check.20.c}
> 若止印三二本，未为简易；若印数十百千本，则极为神速。常作二铁板，一板印刷，一板已自布字。此印者才毕，则第二板已具，更互用之，瞬息可就。……昇死，其印为予群从所得，至今保藏。
译文：如果只印两三册，不算省事；若印的册数达到数十、数百、数千，便极快。常用两块铁板交替，一块印刷时另一块已排字。这边刚印完另一板就已备好。毕昇死后，他的字印为作者的同族亲人所得，至今保存。

## 单选：“更互”指轮换。根据两种印数和两块板的关系，哪种概括最准确？ {#q.check.20.5}
考点：skill.l5.12
语境：p.check.20.c

- [ ] 无论印多少都因同时多出两册而加倍 {#q.check.20.5.o3}
  理由：一板印刷时另一板在排字，不是两板同时印。
- [ ] 即使只印两册，作者也断言一定最省事 {#q.check.20.5.o2}
  理由：开头“未为简易”限制了结论。
- [x] 印数大时长处尤其明显，两板交替减少等候 {#q.check.20.5.o1}

提示：一面看两个“若”，一面看两块板分做什么。
解析：数量是比较条件，两板交替是效率的一个来源，不能把条件换成无例外规律。

## 单选：末句“其印为予群从所得”能给读者什么证据，又不能单独证明什么？ {#q.check.20.6}
考点：skill.l5.10
语境：p.check.20.c

- [x] 说明作者家族保存字印，但不能单凭此句证明他目睹每次印刷 {#q.check.20.6.o1}
- [ ] 说明字印在毕昇死时全部毁去 {#q.check.20.6.o3}
  理由：“所得”“保藏”恰好写保存下来。
- [ ] 证明毕昇把印书全程逐字口授给作者 {#q.check.20.6.o2}
  理由：句中只交代身后的实物去向。

提示：区分物件传承、目击与事后叙述。
解析：“群从”指同族亲属。所藏实物与作者是否亲眼观察每次工作，是可分别核查的两个判断。
