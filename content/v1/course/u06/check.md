# 检查：在新段落里认出动作和评价 {#check.6}

## 原文：教学例句 {#check.6.p.canal}
> 涝岁，里人晨出，东视旧渠。渠浅，水入田。父率众深之。暮，子南趋，启渠口之闸。水乃出。众曰：“昔水没禾，今禾得全矣。”
译文：涝年，乡人一早出来，向东看旧水渠。渠浅，水漫进田里。父亲率众挖深渠道。傍晚，儿子向南快步赶去，打开渠口的闸，水这才流出。大家说：“以前水淹庄稼，如今庄稼可以保住了。”
词注：渠：引水或排水的水道。
  闸：控制渠口水流的闸门。
  全：保全，说禾苗没有淹坏。

## 单选：若画两支箭头，哪支表示乡人的视线，哪支是儿子走的路？ {#check.6.q1}
考点：l2.skill.direction-adverb
语境：check.6.p.canal

- [ ] 向南的是视线，向东的是儿子走的路
  理由：“东”挨着视，“南”挨着趋。
- [ ] 全部向东，父子始终围在同一处看水
  理由：“南趋”明说儿子另有一段路。
- [x] 向东的是视线，向南的是赶往闸口的路

提示：把每个方向后面的那个动作也读进去。
解析：开头先看水势，后来有人得去开闸。向东的是“视”，向南的是“趋”；把两处都画成路线，会凭空添出一次东行。

## 单选：父亲率众“深之”，哪里看得出这一“深”带来了实际改变？ {#check.6.q2}
考点：l2.skill.change-state
语境：check.6.p.canal

- [x] 开头是渠浅水入田，挖深并开闸后水能流出
- [ ] 乡人从东边看，以为渠水比原来深
  理由：“率众深之”发生在看到渠浅以后，村人还要动手。
- [ ] 儿子向南走，就说明父亲也把田挖深了
  理由：前面点名要处理的是旧渠，行走方向不改变对象。

提示：“之”指向前面哪样东西？段尾又怎样交代水的去向？
解析：深的是渠道，开的是渠口。前后的水势让“深之”可还作“使渠变深”，并有开闸相配合。

## 单选：若给乡人的察看与儿子的开闸各记一笔时辰，两笔怎样写？ {#check.6.q3}
考点：l2.skill.time-adverb
语境：check.6.p.canal

- [ ] 察渠、开闸都在清晨，“晨”一直管到“水乃出”
  理由：到“子南趋”前换了“暮”字，儿子动身开闸已是傍晚。
- [ ] 清晨开闸，傍晚才察看旧渠
  理由：“晨出”接乡人看渠，未轮到儿子往南去。
- [x] 清晨察看旧渠；傍晚儿子赶去开闸

提示：把跟着“晨”的行动和“暮”以后才写到的人分作两笔。
解析：乡人清早出门，先发现水进了田。等“暮”字出现，才读到儿子向南赶往渠口、开闸放水。文中没有交代父亲带人挖渠的准确时刻。

## 原文：教学例句 {#check.6.p.fur}
> 客过山村，衣薄裘，见牧童披草而笑之。俄雨雪，客裘湿，童独不寒。童脱其草衣，衣客，导入舍。客曰：“吾向小汝，今知子善备寒。”乃师之，学结草为衣。
译文：客人路过山村，穿着薄皮衣，看见牧童披着草编的衣服就笑他。不久下起雪，客人的裘湿了，牧童却不冷。童子脱下自己的草衣给客人穿，引他进屋。客人说：“我先前小看你，现在才知道你善于防寒。”便以童子为师，学习用草编衣。
词注：俄：不久。
  雨雪：读 yù xuě，下雪。
  向：先前，客人回想刚见到牧童时。

## 单选：先说客“衣薄裘”，后说童“衣客”，两处“衣”怎样读才接得上？ {#check.6.q4}
考点：l2.skill.garment-verb
语境：check.6.p.fur

- [x] 起初是客自己穿裘，后来是童子把草衣给客人穿
- [ ] 两处都只是说明衣服是什么材料
  理由：“衣客”后接人，前面又有脱下草衣的动作。
- [ ] 起初是皮衣包着童子，后来客人又给他穿草衣
  理由：开头的主语是客，脱下草衣的才是童。

提示：谁的衣服湿了？后来谁脱衣递给谁？
解析：第一处带衣料说自己穿什么；第二处写童子替客人穿上。前后衣物各有主人，才能把动作读对。

## 找原文证据：“吾向小汝”的“小”在说客怎样看人。哪处最能说明他起初的态度？ {#check.6.q5}
考点：l2.skill.see-quality
语境：check.6.p.fur

- [ ] 童独不寒
  理由：这是后来动摇旧看法的事实。
- [ ] 学结草为衣
  理由：这是转变以后的行动。
- [x] 见牧童披草而笑之

提示：“向”指先前，到下雪以前找客的反应。
解析：雪前客笑牧童穿草衣，故所说的“小”是轻看眼前的人；童子的年纪和身量没有因此改变。

## 单选：客人“师之”这一转变，哪一说法既说清缘由又没有多添身份？ {#check.6.q6}
考点：l2.skill.regard-as
语境：check.6.p.fur

- [ ] 他见童子脱衣，就命童子改行做制衣官
  理由：给客人穿衣是帮忙，没有任官的事。
- [x] 他见草衣能御寒，愿向牧童学编法
- [ ] 他命童子去县学给全村授课
  理由：后文只写客人自己学习结草。

提示：把开头的笑和末句所学的本领比较。
解析：童子预备御寒并帮助了客人。客由轻看到愿意拜师，从“学结草”可知这段师生关系所为何事。
