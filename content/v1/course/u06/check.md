# 检查：辨清发出与承受动作的一方 {#check.6}

## 原文：教学例句 {#check.6.p.med}
> 道旁有舍。门署“药”。叟曰：“此医之居也。”
译文：道旁有间屋子，门上题着“药”。老人说：“这是医生的住所。”

## 单选：老人断定了什么？ {#check.6.q1}
考点：l2.skill.judgment
语境：check.6.p.med

- [ ] 老人正在治病
  理由：题目问他对房舍的判断。
- [ ] 门上写了医生姓名
  理由：门上只有“药”字。
- [x] 这所屋子是医生的住所

提示：看“此”在指哪一样东西。
解析：“此”指舍，“医之居也”说明它是哪种住所。

## 原文：教学例句 {#check.6.p.book}
> 客言失书。童曰：“非失也，师借而未还耳。”
译文：客人说丢了书。孩子说：“不是丢了，是先生借去还没归还。”

## 单选：孩子排除了哪种说法？ {#check.6.q2}
考点：l2.skill.reject
语境：check.6.p.book

- [x] 书已经遗失
- [ ] 书尚未送回
  理由：这是孩子承认的情形。
- [ ] 先生借过书
  理由：这是孩子提出的解释。

提示：读“非”紧跟的内容。
解析：“非失”否定丢失，借而未还说明暂时不在手中的原因。

## 原文：教学例句 {#check.6.p.praise}
> 生助邻汲水，归而见誉，赧然。
译文：学生帮邻人打水，回来受到称赞，脸红了。

## 单选：“见誉”写谁受到怎样的对待？ {#check.6.q3}
考点：l2.skill.passive-jian
语境：check.6.p.praise

- [ ] 学生自己夸耀
  理由：“见誉”把生放在承受一方。
- [x] 学生受到赞扬
- [ ] 学生看见有人责骂邻人
  理由：“誉”是称赞，非责骂。

提示：看脸红的人是谁。
解析：“见”放在“誉”前表示被称赞，被赞的是相助的学生。

## 原文：教学例句 {#check.6.p.hire}
> 师傅荐徒，徒用于乡人，遂为之筑屋。
译文：师傅推荐徒弟，徒弟被乡人聘用，于是替他们盖房。

## 找原文证据：“用于乡人”中的聘用者是谁？选出原文称呼。 {#check.6.q4}
考点：l2.skill.passive-yu
语境：check.6.p.hire

- [x] 乡人
- [ ] 徒
  第几处：1
  理由：他被推荐去干活。
- [ ] 师傅
  理由：他负责推荐。

提示：找能决定聘请工匠的人。
解析：“于”后的人实施聘用，徒弟后来为他们工作。

## 原文：教学例句 {#check.6.p.jar}
> 瓮为石所破，酒流满地。
译文：瓮被石头击破，酒流了一地。

## 单选：哪项符合事件方向？ {#check.6.q5}
考点：l2.skill.wei-suo
语境：check.6.p.jar

- [ ] 瓮压碎石头
  理由：后面漏出酒的是哪件东西？
- [ ] 酒冲走石头
  理由：漏酒是结果。
- [x] 石头击破瓮

提示：看“为”和“所”之间是什么。
解析：石头是造成损坏的因素，瓮是受事。

## 原文：教学例句 {#check.6.p.letter}
> 父命弟寄书。书既寄，兄乃释念。
译文：父亲让弟弟寄信。信寄出后，兄长才放下心事。

## 单选：第二句未写寄信人，仍可怎样补足？ {#check.6.q6}
考点：l2.skill.unmarked-passive
语境：check.6.p.letter

- [ ] 信从父亲处自己飞走
  理由：前文已为寄信指定行动者。
- [x] 信已由弟弟寄出
- [ ] 兄长已经在读信
  理由：“寄”不保证信已经到达。

提示：先回到“父命……”后面的那个动作。
解析：“书既寄”写已完成的结果，施事承接受命的弟弟。
