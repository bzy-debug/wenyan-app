# 课文：“见”与“于”：谁受了责备，谁受了称赞 {#l2.5}
简介：“见父”是孩子看到父亲，“见责”又是谁受到责备？先弄清“见”后写的是人还是一件事。

## 正文

试读教学例句“童见父”和“童见责”。“父”是人，孩子见到的是父亲；“责”却是一个动作，孩子挨了责备。两个“见”虽然写法一样，孩子在其中做的事很不相同。

读“治人”与“治于人”也可以这样比较：是他治理别人，还是别人治理他？“于”还常常写地点。教学例句“客问于门”是客人在门口发问；“见问于客”才是客人来问他。同一个“于”字，要连着后面具体的人或地方读。

## 知识点：见＋动词 {#l2.skill.passive-jian}
义项：表示主语承受后面的动作
领域：句法
要诀：“见”后接一个人，还是接他受到的对待？
讲解：“童见责”中的“责”是责备，孩子挨了批评；若说“见父”，父亲是孩子看见的人。
例句：l2.ex.passive-jian

## 原文：教学例句 {#l2.ex.passive-jian}
> 吏失书，见责。
译文：官吏弄丢文书，受了责备。

## 知识点：动词＋于＋人 {#l2.skill.passive-yu}
义项：由“于”引出动作的施事
领域：句法
要诀：前面的人受到了什么？是谁做的？
讲解：“匠信于乡人”，是说乡人信任这位工匠。把两个人的位置换成今天习惯的说法，就好分辨。
例句：l2.ex.passive-yu

## 原文：教学例句 {#l2.ex.passive-yu}
> 众皆称匠，匠信于乡人。
译文：大家都称赞工匠，他为乡人所信任。

## 原文：古籍引文 {#l2.5.p.govern}
> 劳心者治人，劳力者治于人。
译文：动脑力的人治理别人，出体力的人被别人治理。

## 单选：“治人”和“治于人”里的两个“人”，哪一个受治理，哪一个治理别人？ {#l2.5.q1}
考点：l2.skill.passive-yu
语境：l2.5.p.govern

- [ ] 两者都是治理者
  理由：“治人”是劳心者治理别人。这里的“人”受治理。
- [x] 前一个受人治理，后一个治理别人
- [ ] 两者都是受治理的对象
  理由：“治于人”是受别人治理。这个“人”管着劳力者。

提示：先读“治人”，再把“于人”念成“由别人”试试。
解析：先说劳心的人治理别人；再说劳力的人受别人治理。“于人”里的“人”指治理他们的人。

## 找原文证据：后半句用哪两个字说明是别人来治理？ {#l2.5.q2}
考点：l2.skill.passive-yu
语境：l2.5.p.govern

- [x] 于人
- [ ] 劳力者
  理由：“劳力者”是受别人治理的人。
- [ ] 劳心者
  理由：“劳心者”在上半句，问的这两个字在下半句。

提示：只读“治于人”。
解析：“治于人”里，若问“受谁治理”，原文回答的是“于人”。

## 原文：教学例句 {#l2.5.p.blame}
> 童误碎瓮。翁归，童见责，垂手立。
译文：孩子失手打碎大瓮。老人回来，孩子受责，垂手站着。

## 单选：“童见责”是说谁受到责备？ {#l2.5.q3}
考点：l2.skill.passive-jian
语境：l2.5.p.blame

- [ ] 刚回来的老人
  理由：哪一个人做了引起责备的事？
- [ ] 一个名为“责”的人
  理由：“责”在这里指责备的行为。
- [x] 打破瓮的孩子

提示：看“见”后是人物还是动作。
解析：“童见责”是孩子被责备。往前读，他刚打碎了瓮；往后读，他垂手站着。

## 单选：换成教学例句“童见翁而起”，“见”该怎么读？ {#l2.5.q4}
考点：l2.skill.passive-jian
语境：l2.5.p.blame

- [ ] 仍标记受责
  理由：新句中已没有“责”或其他受施的动词。
- [x] 作看见讲，后面是所见的人
- [ ] 使老人站起来
  理由：“而起”的主语沿用童。

提示：“责”是一件事，“翁”是一个人。孩子能够亲眼见到谁？
解析：“翁”是老人。孩子见到老人便起身，正是“看见”的意思。

## 原文：教学例句 {#l2.5.p.envy}
> 新匠工巧，见妒于旧工。旧工毁之，主人不听。
译文：新来的工匠技艺精巧，受到老工匠嫉妒。老工匠诋毁他，主人不听。

## 找原文证据：哪几个字点出嫉妒新匠的人？ {#l2.5.q5}
考点：l2.skill.passive-yu
语境：l2.5.p.envy

- [ ] 新匠
  理由：新匠手艺好，是旧工嫉妒他。
- [ ] 主人
  理由：主人听到的是诋毁之言。
- [x] 旧工
  第几处：1

提示：“妒于……”后是什么人？
解析：“于旧工”点出了人。受嫉妒的是新来的工匠，起嫉妒心的是原来的工匠。

## 单选：“见妒”说新来的工匠怎样受人对待？ {#l2.5.q6}
考点：l2.skill.passive-jian
语境：l2.5.p.envy

- [x] 新匠招人嫉妒
- [ ] 新匠看见别人嫉妒主人
  理由：“毁之”的对象承接新匠。
- [ ] 新匠嫉妒旧工
  理由：原文接着说旧工毁谤新匠，起嫉妒心的是旧工。

提示：后面是谁诋毁谁？
解析：前面说新匠“见妒于旧工”，后面接“旧工毁之”。嫉妒新匠和说他坏话的都是旧工。

## 原文：教学例句 {#l2.5.p.welcome}
> 吏初至，疑于众。既断事平，众乃信之。
译文：官吏刚来时，众人都不信他。后来见他断事公允，大家才信任他。

## 单选：后来大家信任了官吏。照这样读，早先是谁怀疑谁？ {#l2.5.q7}
考点：l2.skill.passive-yu
语境：l2.5.p.welcome

- [ ] 官吏怀疑众人
  理由：下文从不信转为信的人是谁？
- [x] 众人怀疑新吏
- [ ] 官吏怀疑另一位官吏
  理由：文中未出现第二位官吏。

提示：看“众乃信之”把信任归给谁。
解析：“吏初至”时，众人怀疑这位官吏。等他办事公正，原来怀疑他的那些人才转而信任他。

## 原文：教学例句 {#l2.5.p.reward}
> 使者见赏，拜而出。出门见友，告以所受。
译文：使者受到赏赐，拜谢而出。出门看见朋友，就告诉他所得的赏赐。

## 单选：使者先“见赏”，然后“见友”，两次“见”意思相同吗？ {#l2.5.q8}
考点：l2.skill.passive-jian
语境：l2.5.p.reward

- [ ] 都是被看见
  理由：第二处“友”是人名类名词，后面没有另一个动作。
- [ ] 都是看见
  理由：“拜”及“所受”印证实际受赏。
- [x] 先是受赏，后是看见朋友

提示：分别看“见”后是动作还是人。
解析：使者先是受了赏赐，后来出门看见朋友。一处写他的遭遇，一处写他亲眼见到谁。
