# 课文：见与于：从受事往回找 {#l2.5}
简介：比较“见责”“责于人”和普通的“见人”“坐于堂”，用动作关系识别被动。

## 正文

先不翻译标志词，列出动作可能的双方。“童见责”中，受批评的可以是童；“童见父”却是童看见父。“见”后的成分不同，不能见字便断定被动。

“治人”把施事放在前，“治于人”可由“于”引入施事。同样的“于”还可以写地点。若写“客问于门”，门不能发问；若写“见问于客”，客能提出问题。分别核对介词后的对象是否能做该动作。

## 知识点：见＋动词 {#l2.skill.passive-jian}
义项：表示主语承受后面的动作
领域：句法
要诀：表示主语承受后面的动作
讲解：问“见”后的成分是动作还是被看见的事物；再看上下文能否补出动作的实施者。
例句：l2.ex.passive-jian

## 原文：教学例句 {#l2.ex.passive-jian}
> 吏失书，见责。
译文：官吏弄丢文书，受了责备。

## 知识点：动词＋于＋人 {#l2.skill.passive-yu}
义项：由“于”引出动作的施事
领域：句法
要诀：由“于”引出动作的施事
讲解：若句首的人或物承受动作，“于”后的对象有能力施行该动作，可按被动理解。
例句：l2.ex.passive-yu

## 原文：教学例句 {#l2.ex.passive-yu}
> 众皆称匠，匠信于乡人。
译文：大家都称赞工匠，他为乡人所信任。

## 原文：古籍引文 {#l2.5.p.govern}
> 劳心者治人，劳力者治于人。
译文：动脑力的人治理别人，出体力的人被别人治理。

## 单选：同一个“治”出现两次，前后的“人”分别起什么作用？ {#l2.5.q1}
考点：l2.skill.passive-yu
语境：l2.5.p.govern

- [ ] 两者都是治理者
  理由：第一处“治”已经有主语。
- [x] 前一个受治理，后一个实施治理
- [ ] 两者都是受治理的对象
  理由：第二处“于”引入了另一方。

提示：给两处“治”各画一支从施事指向受事的箭头。
解析：前句直接带宾语；后句主语受治，“于人”补出治理者。这是在辨认孟子陈述中的角色。

## 找原文证据：哪部分引出后半句的施事？ {#l2.5.q2}
考点：l2.skill.passive-yu
语境：l2.5.p.govern

- [x] 于人
- [ ] 劳力者
  理由：这是后一分句里受治的一方。
- [ ] 劳心者
  理由：这是前一分句的主语。

提示：只读“治于人”。
解析：“于人”在这一被动结构中回答“由谁”。

## 原文：教学例句 {#l2.5.p.blame}
> 童误碎瓮。翁归，童见责，垂手立。
译文：孩子失手打碎大瓮。老人回来，孩子受责，垂手站着。

## 单选：“童见责”是说谁受到责备？ {#l2.5.q3}
考点：l2.skill.passive-jian
语境：l2.5.p.blame

- [ ] 刚回来的老人
  理由：哪一个人做了引起责备的事？
- [ ] 一个名为“责”的人
  理由：“责”在这里指责备的行为。
- [x] 打破瓮的孩子

提示：看“见”后是人物还是动作。
解析：碎瓮与垂手而立给出行为后果。“见责”写孩子承受责备。

## 单选：若改写成“童见翁而起”，这个“见”承担什么作用？ {#l2.5.q4}
考点：l2.skill.passive-jian
语境：l2.5.p.blame

- [ ] 仍标记受责
  理由：新句中已没有“责”或其他受施的动词。
- [x] 作看见讲，后面是所见的人
- [ ] 使老人站起来
  理由：“而起”的主语沿用童。

提示：比较“责”与“翁”能不能指同一类东西。
解析：“见翁”是看见老人。“见”的解释取决于它与后续成分的关系。

## 原文：教学例句 {#l2.5.p.envy}
> 新匠工巧，见妒于旧工。旧工毁之，主人不听。
译文：新来的工匠技艺精巧，受到老工匠嫉妒。老工匠诋毁他，主人不听。

## 找原文证据：原文用哪个称呼点明心生嫉妒的人？ {#l2.5.q5}
考点：l2.skill.passive-yu
语境：l2.5.p.envy

- [ ] 新匠
  理由：这是被嫉妒的人。
- [ ] 主人
  理由：主人听到的是诋毁之言。
- [x] 旧工
  第几处：1

提示：“妒于……”后是什么人？
解析：“见妒于旧工”把受嫉妒者和嫉妒者分开。

## 单选：哪个复述保留了“见妒”的方向？ {#l2.5.q6}
考点：l2.skill.passive-jian
语境：l2.5.p.envy

- [x] 新匠招人嫉妒
- [ ] 新匠看见别人嫉妒主人
  理由：“毁之”的对象承接新匠。
- [ ] 新匠嫉妒旧工
  理由：这把受事换成施事。

提示：后面是谁诋毁谁？
解析：诋毁行为由旧工发出，和前句旧工嫉妒新匠方向一致。

## 原文：教学例句 {#l2.5.p.welcome}
> 吏初至，疑于众。既断事平，众乃信之。
译文：官吏初到，受到众人怀疑。后来判事公平，人们才信任他。

## 单选：由下句验证，先前是谁怀疑谁？ {#l2.5.q7}
考点：l2.skill.passive-yu
语境：l2.5.p.welcome

- [ ] 官吏怀疑众人
  理由：下文从不信转为信的人是谁？
- [x] 众人怀疑新吏
- [ ] 官吏怀疑另一位官吏
  理由：文中未出现第二位官吏。

提示：看“众乃信之”把信任归给谁。
解析：“疑于众”的施事在“于”后，先疑后信的是同一群人。

## 原文：教学例句 {#l2.5.p.reward}
> 使者见赏，拜而出。出门见友，告以所受。
译文：使者受到赏赐，拜谢而出。出门看见朋友，就告诉他所得的赏赐。

## 单选：两处“见”应怎样区别？ {#l2.5.q8}
考点：l2.skill.passive-jian
语境：l2.5.p.reward

- [ ] 都是被看见
  理由：第二处“友”是人名类名词，后面没有另一个动作。
- [ ] 都是看见
  理由：“拜”及“所受”印证实际受赏。
- [x] 先是受赏，后是看见朋友

提示：分别看“见”后是动作还是人。
解析：“见赏”是被赏赐；“见友”以朋友为宾语，是看见朋友。
