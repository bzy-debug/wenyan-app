# 课文：从“为……所……”读懂被动句 {#l2.6}
简介：“书为雨所湿”明说书被淋湿。有时候古人不写“被”，也能把遭遇交代清楚。

## 正文

比较两句教学例句：“鱼为猫所食”“为客煮鱼”。前一句，从鱼说起，吃鱼的是猫；后一句，有人在替客人煮鱼。读到“为”字可以慢一步，看看后面有没有“所食”这样的说法。

“罪既定，书遂焚”一句没有“被”字。若上文写了谁动手焚书，读者便能接着读成书被烧掉了。反过来，句子从一件东西说起，也可能只是写它本身的变化。先找到前后发生的事，再决定怎样译。

## 知识点：为……所…… {#l2.skill.wei-suo}
义项：用“为”引出施事，以“所”接动作
领域：句法
要诀：“为”后有谁，“所”后又是哪个动作？
讲解：“囊为鼠所啮”，袋子破损，咬它的是老鼠。换个说法，就是老鼠咬了袋子。
例句：l2.ex.wei-suo

## 原文：教学例句 {#l2.ex.wei-suo}
> 囊为鼠所啮，其底遂穿。
译文：袋子被老鼠咬，底部于是破了。

## 知识点：无标志的被动 {#l2.skill.unmarked-passive}
义项：从上下文恢复未明写的施事
领域：句法
要诀：往上找一找：先前是谁动了手？
讲解：“吏已封门，门封三日矣”，后半句只说门已封三日。封门的人在前半句已经交代。
例句：l2.ex.unmarked-passive

## 原文：教学例句 {#l2.ex.unmarked-passive}
> 吏已封门，门封三日矣。
译文：官吏已经封门，门已被封三天。

## 原文：教学例句 {#l2.6.p.map}
> 客为邻所误，循故道，至暮不见渡口。及遇舟人，始知路左。
译文：客人被邻人误导，沿着旧路走，到天黑不见渡口。等遇船夫，才知道走错路。

## 单选：是谁把客人引错了路？把“为邻所误”换个说法。 {#l2.6.q1}
考点：l2.skill.wei-suo
语境：l2.6.p.map

- [ ] 客人替邻人指路
  理由：后来迷路的是谁？
- [x] 邻人误导客人
- [ ] 船夫故意误导邻人
  理由：船夫是在最后才出现的。

提示：“为”和“所”中间写了谁？
解析：客人受邻人误导，走了旧路，一直到傍晚也没找到渡口。说成“邻人误导了客人”，仍是这两个人的这件事。

## 找原文证据：原文怎样称呼给客人指错路的人？ {#l2.6.q2}
考点：l2.skill.wei-suo
语境：l2.6.p.map

- [x] 邻
- [ ] 客
  理由：客人沿旧路走错了方向，他是听了别人指路的人。
- [ ] 舟人
  理由：客人走到傍晚才遇到船夫，这才知道路走错了。

提示：先找“所误”，再往它前面看。
解析：“邻”在“为”和“所误”之间。是邻人把客人引上了错路。

## 原文：教学例句 {#l2.6.p.word}
> 县令命吏刻榜，三日而榜刻。民聚观之。
译文：县令命官吏刻榜文，三天后榜文刻好了。百姓聚集观看。

## 单选：到了第三天，榜文怎样了？ {#l2.6.q3}
考点：l2.skill.unmarked-passive
语境：l2.6.p.word

- [ ] 百姓刻成榜文
  理由：百姓的动作是看。
- [x] 榜文被刻成了
- [ ] 榜文自己拿刀刻字
  理由：前句已经写了受命工作的人。

提示：把“命吏刻榜”和“榜刻”前后相接。
解析：前面已说县令让官吏刻榜文。三天后再从榜文说起，就不必把动手刻字的官吏重说一遍。

## 排序：按榜文制成、展示的过程排列。 {#l2.6.q4}
考点：l2.skill.unmarked-passive
语境：l2.6.p.word

- [2] 榜文刻好
  理由：三日后哪件工作完成了？
- [1] 县令下令刻榜
  理由：制作的命令出现在哪一层？
- [3] 百姓聚观
  理由：未制成之前有榜文可看吗？

提示：看“命”“三日而”“聚观”。
解析：县令先下令，官吏才刻好榜文；百姓聚来观看，是榜文制成以后的事。

## 原文：教学例句 {#l2.6.p.ink}
> 生持书归。途中大雨，书为雨所湿，乃曝之庭中。
译文：学生拿书回家。路上大雨，书被雨淋湿，便把书摊在院里晒。

## 单选：是什么使书湿了？ {#l2.6.q5}
考点：l2.skill.wei-suo
语境：l2.6.p.ink

- [ ] 庭中日光
  理由：后来把书放到院里，是为了晒干它。把书打湿的还得往前找。
- [ ] 学生特意浸书
  理由：文中未写学生把书入水。
- [x] 路上的雨

提示：先看看回家路上是什么天气。
解析：前句说途中下大雨，“书为雨所湿”便是书遭了雨淋。拿到院中去晒，是湿了以后的事。

## 原文：教学例句 {#l2.6.p.door}
> 府吏集牍，尽封而藏之。明日有客求阅，牍已封矣。
译文：府吏收集文书，一一封好收藏。第二天客人想读，文书已经被封好了。

## 单选：第二天客人想借阅时，文书怎样了？是谁做的？ {#l2.6.q6}
考点：l2.skill.unmarked-passive
语境：l2.6.p.door

- [ ] 客人刚刚封的
  理由：客人是第二天才来求阅。
- [ ] 文书被自然风吹干
  理由：前文“尽封”已说明何种处理。
- [x] 前一天府吏把它封上了

提示：哪一动作已经在前一天发生？
解析：“尽封而藏之”已经交代府吏把文书封存。客人第二天想读时，说“牍已封矣”便足够了。

## 单选：谁在笑谁？用“为……所……”来讲“身为宋国笑”。 {#l2.6.q7}
考点：l2.skill.wei-suo
语境：l2.6.p.wood

- [ ] 宋国人为自己所笑
  理由：原句把“身”放在受人耻笑的位置。
- [x] 自己为宋国人所笑
- [ ] 自己为兔所笑
  理由：兔不可复得是事情的起因，这里发笑的是人。

提示：试写成“谁笑话谁”，留意“为”后引入哪一方。
解析：说的是农人受宋国人耻笑。若加上“所”，就是自己“为宋国人所笑”。

## 原文：教学例句 {#l2.6.p.bridge}
> 匠撤旧桥，以木易石。桥撤之日，行者皆从渡。
译文：工匠拆下旧桥，用木料替换石材。桥被拆的那天，过路人都到渡口走。

## 单选：哪一个人动手拆了桥？ {#l2.6.q8}
考点：l2.skill.unmarked-passive
语境：l2.6.p.bridge

- [ ] 改到渡口的行人
  理由：行人只是在应对桥已拆。
- [ ] 桥自己
  理由：头一句“匠撤旧桥”已经说了谁动手。
- [x] 前句所说的工匠

提示：把“桥撤”接回上一句去读。
解析：前面“匠撤旧桥”点出了工匠。后面只说桥撤的那一天，拆桥的人还是他。
