# 课文：为……所与语境中的被动 {#l2.6}
简介：读清“为”后是施事、受益者还是职业；没有标记时，用上下文验方向。

## 正文

“鱼为猫所食”中的鱼承受吃这一动作，猫是施事。“为客煮鱼”则说有人替客人做饭；客人不是煮鱼者。“所”是否与后面的动作组成一块，是很有用的线索。

有些被动意义没有“见、为、于”等标志。“罪既定，书遂焚”要看前文是否写了焚书的人。句首是物，不代表它一定承受动作，例如“火燃”也能说火自己燃烧。必须使解释符合动词和情节。

## 知识点：为……所…… {#l2.skill.wei-suo}
义项：用“为”引出施事，以“所”接动作
领域：句法
要诀：用“为”引出施事，以“所”接动作
讲解：主语通常是受事。将该句展开为“施事＋动作＋主语”，核对事件方向。
例句：l2.ex.wei-suo

## 原文：教学例句 {#l2.ex.wei-suo}
> 囊为鼠所啮，其底遂穿。
译文：袋子被老鼠咬，底部于是破了。

## 知识点：无标志的被动 {#l2.skill.unmarked-passive}
义项：从上下文恢复未明写的施事
领域：句法
要诀：从上下文恢复未明写的施事
讲解：先看主语能不能自行完成动作，再找前面明确出现过的处理者和处理过程。
例句：l2.ex.unmarked-passive

## 原文：教学例句 {#l2.ex.unmarked-passive}
> 吏已封门，门封三日矣。
译文：官吏已经封门，门已被封三天。

## 原文：教学例句 {#l2.6.p.map}
> 客为邻所误，循故道，至暮不见渡口。及遇舟人，始知路左。
译文：客人被邻人误导，沿着旧路走，到天黑不见渡口。等遇船夫，才知道走错路。

## 单选：哪句话把“为邻所误”改成主动说法而保持原意？ {#l2.6.q1}
考点：l2.skill.wei-suo
语境：l2.6.p.map

- [ ] 客人替邻人指路
  理由：后来迷路的是谁？
- [x] 邻人误导客人
- [ ] 船夫故意误导邻人
  理由：船夫是在最后才出现的。

提示：“为”和“所”中间写了谁？
解析：被误导者在句首，邻人才是施事；后文迷路的是客人。

## 找原文证据：选出表明谁误导了客人的称呼。 {#l2.6.q2}
考点：l2.skill.wei-suo
语境：l2.6.p.map

- [x] 邻
- [ ] 客
  理由：这是迷路的一方。
- [ ] 舟人
  理由：这是后来遇到的人。

提示：先找“所误”，再往它前面看。
解析：“邻”在“为……所误”中指施事，客人承受误导。

## 原文：教学例句 {#l2.6.p.word}
> 县令命吏刻榜，三日而榜刻。民聚观之。
译文：县令命官吏刻榜文，三天后榜文刻好了。百姓聚集观看。

## 单选：“榜刻”省去标记，仍可理解成什么？ {#l2.6.q3}
考点：l2.skill.unmarked-passive
语境：l2.6.p.word

- [ ] 百姓刻成榜文
  理由：百姓的动作是看。
- [x] 榜文被刻成了
- [ ] 榜文自己拿刀刻字
  理由：前句已经写了受命工作的人。

提示：把“命吏刻榜”和“榜刻”前后相接。
解析：下句以成品作主语，施事从前句的吏补出来。

## 排序：按榜文制成、展示的过程排列。 {#l2.6.q4}
考点：l2.skill.unmarked-passive
语境：l2.6.p.word

- [2] 榜文刻好
  理由：三日后哪件工作完成了？
- [1] 县令下令刻榜
  理由：制作的命令出现在哪一层？
- [3] 百姓聚观
  理由：未制成之前有榜文可看吗？

提示：看“命”“三日而”“聚观”。
解析：下令、制成、观看依次推进。“榜刻”是中间的结果。

## 原文：教学例句 {#l2.6.p.ink}
> 生持书归。途中大雨，书为雨所湿，乃曝之庭中。
译文：学生拿书回家。路上大雨，书被雨淋湿，便把书摊在院里晒。

## 单选：是什么使书湿了？ {#l2.6.q5}
考点：l2.skill.wei-suo
语境：l2.6.p.ink

- [ ] 庭中日光
  理由：日光出现于晾晒情境，不能解释先前变湿。
- [ ] 学生特意浸书
  理由：文中未写学生把书入水。
- [x] 路上的雨

提示：这里的施事可以是自然事物。
解析：“为雨所湿”中，“雨”是导致书变湿的因素；晾晒是后续补救。

## 原文：教学例句 {#l2.6.p.door}
> 府吏集牍，尽封而藏之。明日有客求阅，牍已封矣。
译文：府吏收集文书，一一封好收藏。第二天客人想读，文书已经被封好了。

## 单选：如何推断末句文书的状态？ {#l2.6.q6}
考点：l2.skill.unmarked-passive
语境：l2.6.p.door

- [ ] 客人刚刚封的
  理由：客人是第二天才来求阅。
- [ ] 文书被自然风吹干
  理由：前文“尽封”已说明何种处理。
- [x] 前一天府吏把它封上了

提示：哪一动作已经在前一天发生？
解析：“牍已封”虽无专门标记，前文明确写了封存书牍的人。

## 原文：古籍引文 {#l2.6.p.wood}
> 兔不可复得，而身为宋国笑。
译文：兔子再也没能得到，自己反倒被宋国人耻笑。

## 单选：把“身为宋国笑”展开成带“所”的说法，哪一句保留原意？ {#l2.6.q7}
考点：l2.skill.wei-suo
语境：l2.6.p.wood

- [ ] 宋国人为自己所笑
  理由：原句把“身”放在受人耻笑的位置。
- [x] 自己为宋国人所笑
- [ ] 自己为兔所笑
  理由：兔不可复得是事情的起因，这里发笑的是人。

提示：试写成“谁笑话谁”，留意“为”后引入哪一方。
解析：“为宋国笑”中的“宋国”借指宋国人。这里的被动不带“所”，可用学过的“为……所”结构说明它。

## 原文：教学例句 {#l2.6.p.bridge}
> 匠撤旧桥，以木易石。桥撤之日，行者皆从渡。
译文：工匠拆下旧桥，用木料替换石材。桥被拆的那天，过路人都到渡口走。

## 单选：“桥撤之日”的“撤”由谁实施？ {#l2.6.q8}
考点：l2.skill.unmarked-passive
语境：l2.6.p.bridge

- [ ] 改到渡口的行人
  理由：行人只是在应对桥已拆。
- [ ] 桥自己
  理由：前句已经明确实施拆除的行动者。
- [x] 前句所说的工匠

提示：找到原句里“撤旧桥”的主语。
解析：“桥撤”换受处理的桥作话题，施事沿用前一句的工匠。
