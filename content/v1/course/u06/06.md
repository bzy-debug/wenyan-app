# 课文：觉得它小，还是把它变小 {#l2.6}
简介：一边看实物有没有改变，一边听人物怎么评价，读清“以……为……”的两种常见说法。

## 正文

登高望远，眼中的城邑显得小了；说某人“小其邑”，变化可能发生在看者的眼光里，城邑的城墙并没有因此缩小。意动用法常可读成“觉得对象怎样”。

也可以用一个身份称呼来表示如何看待或对待别人。“师之”是以他为师，求教的一方未必有权授给他正式的师职。应当找的是求教、行弟子礼等行为，不能见到“师”就补一次任命。

## 知识点：形容词的意动 {#l2.skill.see-quality}
义项：觉得某人或某物有某种性质
领域：句法
要诀：“奇”“小”“贵”的判断是谁作的？
讲解：“客奇其言”是这位客人觉得那番话不同寻常。话已说完，客人的感受不等于他重新改过那番话。
例句：l2.ex.see-quality

## 原文：教学例句 {#l2.ex.see-quality}
> 童初见海，大之。
译文：孩子初见大海，觉得它广阔。

## 知识点：名词的意动 {#l2.skill.regard-as}
义项：把对象当作某种身份的人
领域：句法
要诀：看他接下来用什么礼节待对方。
讲解：“师老农”若紧接着问种植之事，是把老农当老师来求教，不一定有授职、领俸的情节。
例句：l2.ex.regard-as

## 原文：教学例句 {#l2.ex.regard-as}
> 客友舟人，数与之游。
译文：客人把船夫当作朋友，常同他交游。

## 原文：古籍引文 {#l2.6.p.hill}
> 孔子登东山而小鲁，登太山而小天下。
译文：孔子登上东山，觉得鲁国小；登上太山，觉得天下小。
词注：小：觉得眼前的疆域小，说的是登山者的感受。
  太山：即泰山。
出处：《孟子·尽心上》孔子登东山章（太山即泰山）

## 单选：孔子又登一座更高的山，“小”的意思随之怎样读？ {#l2.6.q1}
考点：l2.skill.see-quality
语境：l2.6.p.hill

- [ ] 他把天下实际缩得比鲁国小
  理由：所写动作为登山，没写疆域变更。
- [x] 所见更广，连天下也显得小了
- [ ] 天下人一起认为孔子很小
  理由：两句的主语相同，是孔子在登、在看。

提示：“鲁”和“天下”是在谁的眼光里被衡量？
解析：“小鲁”“小天下”带着所见的对象，说的是登高者的眼界和感受。

## 原文：教学例句 {#l2.6.p.teacher}
> 县令过圃，见老农善接梨，自称弟子而师之。老农仍荷锄入圃，令随而受教。
译文：县令路过果园，见老农善于嫁接梨树，自己以弟子相称，把老农当老师。老农照旧扛锄入园，县令跟着求教。
词注：圃：种植果蔬的园地。
  荷：读 hè，扛在肩上。
  受教：接受指教，这里指向老农学习嫁接。

## 找原文证据：哪句直接写县令把自己放在学生的位置上？ {#l2.6.q2}
考点：l2.skill.regard-as
语境：l2.6.p.teacher

- [x] 自称弟子
- [ ] 善接梨
  理由：这是老农的本领。
- [ ] 荷锄入圃
  理由：这是老农原来的农事。

提示：身份是由谁自己开口说的？
解析：县令自称弟子又随行受教，故“师之”是以老农为师。

## 单选：能从“师之”推出老农被任命为县学官员吗？ {#l2.6.q3}
考点：l2.skill.regard-as
语境：l2.6.p.teacher

- [ ] 一定离开果园赴任
  理由：老农仍荷锄入圃。
- [x] 能确定县令向他学，正式授官没有写
- [ ] 一定授官，凡有弟子必有俸禄
  理由：文中没有任命、学校或俸禄。

提示：观察老农原有生活是否换成了新官职。
解析：这是县令待他的礼节和求教的关系。正式职位超过了原文所交代的内容。

## 原文：教学例句 {#l2.6.p.size}
> 弟看旧砚，薄之，弃诸案隅。匠取石，磨薄其底，较旧减半。
译文：弟弟看着旧砚，轻视它，扔在桌角。工匠取过石砚，把底磨薄，比原来薄了一半。

## 单选：前半句的“薄之”和后半句“磨薄”分别改变了什么？ {#l2.6.q4}
考点：l2.skill.see-quality
语境：l2.6.p.size

- [ ] 两次都是砚底物理上变薄
  理由：弟弟只看了就丢在一边，没有打磨。
- [x] 先写弟弟轻视旧砚，后写砚底真的变薄
- [ ] 工匠也只在评价砚台
  理由：后面已量出厚度减半。

提示：看谁手里有磨石的工序，谁只是把东西弃在一旁。
解析：前句的“薄”可读为看轻，落在态度；后句实际打磨，落在厚度。

## 原文：教学例句 {#l2.6.p.meet}
> 布衣见公子于渡。公子与之论书，悦其言，遂友之。自是数往其庐。
译文：平民在渡口遇见公子。公子同他谈书，很喜欢他的话，便以他为友。此后常到他的茅屋去。
词注：布衣：原指寻常布衣，这里称一个没有官位的平民。
  数：读 shuò，多次。
  庐：简朴的房舍。

## 单选：“友之”以后，谁改变了对谁的相待方式？ {#l2.6.q5}
考点：l2.skill.regard-as
语境：l2.6.p.meet

- [ ] 公子把平民介绍给自己的朋友后不再来往
  理由：“数往其庐”正说明还在来往。
- [ ] 平民得到一个名为“友”的官位
  理由：后文只写了私下探访。
- [x] 公子把平民看作朋友，屡次往访

提示：“遂”前是谁听得高兴？后面谁又往访？
解析：一连串动作都由公子发出。友在此带“之”，表示按朋友相待。

## 排序：公子结交平民，经过了哪几步？ {#l2.6.q6}
考点：l2.skill.regard-as
语境：l2.6.p.meet

- [2] 喜欢他的言论，愿意结交
  理由：“遂友之”接论书而来。
- [3] 后来多次到访
  理由：“自是”写结交以后的日子。
- [1] 渡口会面论书
  理由：先须见面，才有后来的悦其言。

提示：把一次相遇同后来的多次探访分开。
解析：渡口谈书使公子愿意结交；屡次登门，则是这种交情后来的表现。

## 原文：教学例句 {#l2.6.p.straw}
> 客视草屦，贱之，不肯试。里人曰：“此善行泥。”客践泥而不滑，乃珍之。
译文：客人看见草鞋，觉得不值，不肯试。乡人说：“这鞋适合走泥地。”客人穿着走泥地没有滑倒，才珍视它。
词注：屦：鞋，“草屦”是草编的鞋。
  践：踏，此处是穿着草鞋走上泥地。

## 找原文证据：哪几个字写客人对同一双鞋后来的看法与先前不同了？ {#l2.6.q7}
考点：l2.skill.see-quality
语境：l2.6.p.straw

- [ ] 不肯试
  理由：这是看轻草鞋时的反应。
- [x] 乃珍之
- [ ] 此善行泥
  理由：这是乡人说出的用处。

提示：谁真的在泥地走过以后才改变想法？
解析：客人先“贱之”，试过又“珍之”；珍视和看轻都出自同一个人的判断。

## 单选：这段能否支持“草鞋的市价因为试穿而上升”？ {#l2.6.q8}
考点：l2.skill.see-quality
语境：l2.6.p.straw

- [ ] 能，“珍之”一定是市上重新标价
  理由：文中没人交易或说价钱。
- [ ] 能，“践泥”让编鞋的材料变贵
  理由：鞋的材料并没有更换。
- [x] 只写客人的态度变化，没写市价

提示：找有没有买卖双方，还是只有一人试穿。
解析：“贱”“珍”都跟客人自己的经历相连。物的用途在试穿中得到验证，价格没有消息。
