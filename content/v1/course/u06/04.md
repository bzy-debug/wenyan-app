# 课文：判断与否定：者、也、非 {#l2.4}
简介：“此印也”是在认东西，“非佩玉也”是在排除一种认法。

## 正文

“此人，吾师也。”这里没有写“是”字，仍然可以念成“这个人是我的老师”。前面提到“此人”，后面用“吾师”说出身份，“也”放在句末。“者”“也”有时成对出现，有时只用一个；“也”还可以放在解释或陈述的句末。

遇到“非”，要把它后面的意思读完整。“非不欲也”，说话人是在回应“不想”这个说法，意思是自己也想。假如漏读了“非”，意思便反过来了。

## 知识点：者……也 {#l2.skill.judgment}
义项：先说人或事物，再说明它是谁或是什么
领域：句法
要诀：前面在说什么，后面怎样认定它？
讲解：“此亭者，古之驿也”，说的是这座亭子，后半句才指出它从前是驿站。“者”前面也能是物。
例句：l2.ex.judgment

## 原文：教学例句 {#l2.ex.judgment}
> 此亭者，古之驿也。
译文：这座亭子原是旧时的驿站。

## 知识点：非 {#l2.skill.reject}
义项：否定身份或排除一种解释
领域：句法
要诀：说话人驳的是哪一句话？
讲解：“此非墨也，漆也”，说的是眼前这东西。先排除墨，再认定它是漆。
例句：l2.ex.reject

## 原文：教学例句 {#l2.ex.reject}
> 此非墨也，漆也。
译文：这不是墨，是漆。

## 原文：古籍引文 {#l2.4.p.weapon}
> 是何异于刺人而杀之，曰：“非我也，兵也。”
译文：这与刺人并杀死他，却说“不是我，是兵器”的做法有什么不同呢？

## 单选：说“非我也”的人，想推掉什么责任？ {#l2.4.q1}
考点：l2.skill.reject
语境：l2.4.p.weapon

- [x] 想否认杀人的是他自己
- [ ] 否认有兵器
  理由：接下来的话恰恰把责任推给兵器。
- [ ] 否认有人死亡
  理由：前面明说“而杀之”。

提示：把省去的“杀人者”放在两项前面。
解析：孟子打了个比方。一个人刺人致死，竟说“不是我，是兵器”。这句话把该由自己负的责任推给了兵器。

## 单选：说“兵也”的人要把责任推给谁？这两个字承接了什么话？ {#l2.4.q2}
考点：l2.skill.judgment
语境：l2.4.p.weapon

- [x] 补出说话人声称的另一个致死者
- [ ] 说明死者的职业是士兵
  理由：对举项是“我”，所争的是谁造成死亡。
- [ ] 交代兵器已经不在
  理由：并无消失的时间或动作。

提示：将“兵也”同引号内的前一句对读。
解析：“兵”是兵器。沿着他自己的说法补全，便是“不是我杀的，是兵器杀的”。这也正是孟子批评之处。

## 原文：教学例句 {#l2.4.p.seal}
> 客问案上之物。吏曰：“此印也，非佩玉也。”取而示其文。
译文：客人询问案上的东西。官吏说：“这是印，不是佩玉。”拿起来给他看上面的文字。

## 找原文证据：官吏直接说案上这件东西是什么，用的是哪句话？ {#l2.4.q3}
考点：l2.skill.judgment
语境：l2.4.p.seal

- [ ] 示其文
  理由：拿起来给人看印上的文字，是在说出“此印也”之后。
- [ ] 客问
  理由：客人在问案上放着什么，还没说这物件是什么。
- [x] 此印也

提示：找肯定陈述，暂不看排除项。
解析：“此”指案上这件东西。他说“印”，就已认定了这是印章。

## 单选：“非佩玉也”否定了哪一种认法？ {#l2.4.q4}
考点：l2.skill.reject
语境：l2.4.p.seal

- [x] 把案上物认作佩玉的说法
- [ ] 说世上没有佩玉
  理由：官吏指着桌上的这一件东西说“此”，没有谈别的玉器。
- [ ] 官吏不能佩玉
  理由：谈论的是案上物的身份。

提示：还原为“此非……”。
解析：官吏只在辨认眼前这一件东西：此物是印章，并非佩玉。

## 原文：教学例句 {#l2.4.p.well}
> 村东有石阑。过者疑为墓。里老曰：“石阑者，井之栏也。”
译文：村东有石栏。路过的人疑心是墓。当地老人说：“这石栏是井栏。”

## 单选：“石阑者，井之栏也”，前半句指出什么？ {#l2.4.q5}
考点：l2.skill.judgment
语境：l2.4.p.well

- [x] 被说明的物件
- [ ] 井的所在方向
  理由：“东”才说明方位。
- [ ] 制造栏杆的人
  理由：“者”前是物名，此处未介绍工匠。

提示：老人说“井之栏”，是在认人，还是认一件物品？
解析：“石阑者”先提大家正看的那道石栏，后一句才说明它是哪一处的栏杆。

## 找原文证据：老人说这道石栏是什么？找出他的说法。 {#l2.4.q6}
考点：l2.skill.judgment
语境：l2.4.p.well

- [x] 井之栏
- [ ] 村东
  理由：“村东”只说石栏在何处。
- [ ] 过者
  理由：“过者”是路过猜测的人，老人要说明的是眼前的石栏。

提示：谁的栏？
解析：“井之栏”是井的栏杆。这样读，便能明白老人为何纠正过路人的猜测。

## 原文：教学例句 {#l2.4.p.late}
> 友怪客后至。客曰：“非不欲速也，桥圮，不得前耳。”
译文：朋友责怪客人来迟。客人说：“并不是我不想快些，是桥塌了，不能往前走罢了。”

## 单选：客人说“非不欲速”，别人把他迟到的缘由想成了什么？ {#l2.4.q7}
考点：l2.skill.reject
语境：l2.4.p.late

- [ ] 自己确实来迟
  理由：他正在说明迟到的缘故。
- [x] 自己因不想快走而迟到
- [ ] 桥已倒塌
  理由：倒塌正是他给的理由。

提示：“非”后面还有一个“不”。
解析：客人是想赶快到。他怕人误会自己不想快走，所以先说“非不欲速”，再解释桥坏了。

## 单选：如把“非不欲速”改成“不欲速”，意思会怎样？ {#l2.4.q8}
考点：l2.skill.reject
语境：l2.4.p.late

- [x] 变成承认自己不想赶快
- [ ] 仍然表示路坏
  理由：路坏在后一个分句中。
- [ ] 变成说自己已准时到达
  理由：愿望与到达时间不是一回事。

提示：减掉一个否定后再说一遍。
解析：只说“不欲速”就成了“我不愿意快走”，恰好说反了他的本意。
