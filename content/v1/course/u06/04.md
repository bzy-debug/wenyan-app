# 课文：判断与否定：者、也、非 {#l2.4}
简介：在“说的是谁”和“断定什么”之间划出界线，补足简短的回答。

## 正文

“此人，吾师也”并没有一个相当于现代汉语“是”的动词。先把“此人”立为要说明的对象，再看“吾师”给出的身份；末尾“也”帮助收住判断。“者……也”是常见配合，用例也可以只出现其中之一。

“非”否定某种归类或说法。“非不欲也”否定的却是“不想”这个解释。“也”还可以结束解释或陈述；因此要核对前后的词组，不可看见“也”就一律译成“是”。

## 知识点：者……也 {#l2.skill.judgment}
义项：用后项判断前项的身份或性质
领域：句法
要诀：用后项判断前项的身份或性质
讲解：在“者”前圈出话题，在“也”前找解释或类别；不把“者”自动译作“人”。
例句：l2.ex.judgment

## 原文：教学例句 {#l2.ex.judgment}
> 此亭者，古之驿也。
译文：这座亭子原是旧时的驿站。

## 知识点：非 {#l2.skill.reject}
义项：否定身份或排除一种解释
领域：句法
要诀：否定身份或排除一种解释
讲解：问“非”后面被否定的是哪整段意思，再看作者随后提出什么解释。
例句：l2.ex.reject

## 原文：教学例句 {#l2.ex.reject}
> 此非墨也，漆也。
译文：这不是墨，是漆。

## 原文：古籍引文 {#l2.4.p.weapon}
> 是何异于刺人而杀之，曰：“非我也，兵也。”
译文：这与刺人并杀死他，却说“不是我，是兵器”的做法有什么不同呢？

## 单选：引号中的人想排除哪种责任？ {#l2.4.q1}
考点：l2.skill.reject
语境：l2.4.p.weapon

- [x] 想否认杀人的是他自己
- [ ] 否认有兵器
  理由：接下来的话恰恰把责任推给兵器。
- [ ] 否认有人死亡
  理由：前面明说“而杀之”。

提示：把省去的“杀人者”放在两项前面。
解析：“非我”“兵”是两种归责对象。孟子用反问揭出这种推脱的不合理。

## 单选：“兵也”是做什么用的？ {#l2.4.q2}
考点：l2.skill.judgment
语境：l2.4.p.weapon

- [x] 补出说话人声称的另一个致死者
- [ ] 说明死者的职业是士兵
  理由：对举项是“我”，所争的是谁造成死亡。
- [ ] 交代兵器已经不在
  理由：并无消失的时间或动作。

提示：将“兵也”同引号内的前一句对读。
解析：两个短句共用话题，后句省掉主语；这里的“兵”指兵器。

## 原文：教学例句 {#l2.4.p.seal}
> 客问案上之物。吏曰：“此印也，非佩玉也。”取而示其文。
译文：客人询问案上的东西。官吏说：“这是印，不是佩玉。”拿起来给他看上面的文字。

## 找原文证据：哪一句直接说明物件的身份？ {#l2.4.q3}
考点：l2.skill.judgment
语境：l2.4.p.seal

- [ ] 示其文
  理由：这是随后验证判断的动作。
- [ ] 客问
  理由：这是提问。
- [x] 此印也

提示：找肯定陈述，暂不看排除项。
解析：“此”指案上物，“印”给出种类，“也”收住判断。

## 单选：“非佩玉也”的否定范围是？ {#l2.4.q4}
考点：l2.skill.reject
语境：l2.4.p.seal

- [x] 把案上物认作佩玉的说法
- [ ] 说世上没有佩玉
  理由：“此”将话题限于眼前之物。
- [ ] 官吏不能佩玉
  理由：谈论的是案上物的身份。

提示：还原为“此非……”。
解析：“非”排除一种物件识别，不能扩大为普遍断言。

## 原文：教学例句 {#l2.4.p.well}
> 村东有石阑。过者疑为墓。里老曰：“石阑者，井之栏也。”
译文：村东有石栏。路过的人疑心是墓。当地老人说：“这石栏是井栏。”

## 单选：“石阑者”在老人的话中是什么？ {#l2.4.q5}
考点：l2.skill.judgment
语境：l2.4.p.well

- [x] 被说明的物件
- [ ] 井的所在方向
  理由：“东”才说明方位。
- [ ] 制造栏杆的人
  理由：“者”前是物名，此处未介绍工匠。

提示：看后项“井之栏”回答什么。
解析：“石阑者”提示话题，后项给它定名。

## 找原文证据：选出判断中说明用途及归属的一部分。 {#l2.4.q6}
考点：l2.skill.judgment
语境：l2.4.p.well

- [x] 井之栏
- [ ] 村东
  理由：这是位置。
- [ ] 过者
  理由：这是先前猜测的人。

提示：谁的栏？
解析：“井之栏”限定这道石栏属于水井。

## 原文：教学例句 {#l2.4.p.late}
> 友怪客后至。客曰：“非不欲速也，桥圮，不得前耳。”
译文：朋友责怪客人来迟。客人说：“并不是我不想快些，是桥塌了，不能往前走罢了。”

## 单选：客人否认的是哪一解释？ {#l2.4.q7}
考点：l2.skill.reject
语境：l2.4.p.late

- [ ] 自己确实来迟
  理由：他正在说明迟到的缘故。
- [x] 自己因不想快走而迟到
- [ ] 桥已倒塌
  理由：倒塌正是他给的理由。

提示：“非”后面还有一个“不”。
解析：“非不欲速”排除不愿赶快的解释；客人承认受阻。

## 单选：如把“非不欲速”改成“不欲速”，意思会怎样？ {#l2.4.q8}
考点：l2.skill.reject
语境：l2.4.p.late

- [x] 变成承认自己不想赶快
- [ ] 仍然表示路坏
  理由：路坏在后一个分句中。
- [ ] 变成说自己已准时到达
  理由：愿望与到达时间不是一回事。

提示：减掉一个否定后再说一遍。
解析：去掉“非”便少了一层否定，原先被驳回的说法变成了肯定陈述。
