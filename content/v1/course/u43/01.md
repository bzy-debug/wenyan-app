# 课文：从哪里取得，向谁问明 {#fword.43.1}
简介：一件东西在亭中被看见，未必就从亭中得来。循着“于”前面的动作，找出地点、来源或听者。
回读：fword.s.ruhe fword.p.pouch
  fword.s.shuyu fword.p.tile

## 正文

吏员“得简于樵者”，简来自打柴人；他“问于县丞”，县丞却是听他发问的人。人同样在“于”后，信息、物件的去向却要看谁在找谁。若句里只说“坐于亭”，亭是落座之处，不能译成从亭中出发。

几件事接连写在一段里，可以先给“于”换三个说法：“在……”“从……那里”“向……”。把问题交出去、把旧简拿回来、自己到亭子坐，三种动作各有自己的方向。

## 知识点：“于”指出动作所在之处 {#fword.s.yu-place}
义项：在某地做某事
领域：虚词
要诀：坐、宿、会之后的“于某地”可以回答“在哪里”。
讲解：“宿于东亭”写客人在亭里过夜。这个地点没有被“宿”带走，也不是谁拿东西的来源。
例句：fword.p.pouch

## 知识点：“于”指出获取的来源 {#fword.s.yu-from}
义项：从某人或某处得到物品、消息
领域：虚词
要诀：从接收方挨着“受”“取”“闻”回看原先持有什么的人。
讲解：吏员“受简于樵者”，简到了吏员手中；“于”后的樵者是交出的人，并非吏员又要把简发还给他。
例句：fword.p.pouch

## 知识点：“于”指出说话或发问的对象 {#fword.s.yu-to}
义项：向某人说、问或报告
领域：虚词
要诀：“于”后的听者怎样回应，可以反证话往哪里去。
讲解：齐景公“问政于孔子”，景公先开口，答以君臣父子关系的是孔子。“于”把问题交到后者面前。
例句：fword.p.dignitary

## 原文：教学例句 {#fword.p.pouch}
> 吏宿于东亭，受简于樵者，见有县印，惧其有失，问于县丞曰：“如是简何？”丞曰：“封而送之。”
译文：吏员住宿在东亭，从樵夫手中接过竹简。看见上面有县印，怕是遗失的文书，便向县丞询问该怎么处置这份简。县丞让他封好送去。
词注：简：书写用的竹片，这里指文书。
  樵者：打柴的人。
  丞：辅助长官办事的官员。

## 原文：教学例句 {#fword.p.tile}
> 二匠会于窑前。甲取泥于溪滨，乙取泥于山阴。客问于二人：“溪泥孰与山泥宜作瓦？”二人各举一瓦，请客验之。
译文：两个匠人在窑前会面。甲从溪边取泥，乙从山北取泥。客人问两人，溪泥和山泥哪种适合做瓦。两人各拿起一片瓦，请客人察验。
词注：窑：烧砖瓦的窑。
  山阴：山的北面。
  验：察看、检验。

## 原文：古籍引文 {#fword.p.dignitary}
> 齐景公问政于孔子。孔子对曰：“君君，臣臣，父父，子子。”
译文：齐景公向孔子问治国的事。孔子回答：“做国君的尽国君的本分，做臣子的尽臣子的本分，为父为子的人也各尽本分。”
词注：政：治理国家的事。
  对：回答。

## 单选：“宿于东亭”只让我们知道吏员在哪里做了哪件事？ {#fword.q.43.1.1}
考点：fword.s.yu-place
语境：fword.p.pouch

- [ ] 向东亭的县丞请示
  理由：“问”在接简辨印之后，“宿”先写住宿。
- [x] 在东亭过夜
- [ ] 从东亭取来竹简
  理由：递简的是樵者；“宿”本身没有拿东西的意思。

提示：给“宿”提问：他在哪里度过夜晚？
解析：“于”带出的东亭是动作发生处。简和县丞分别属于后两个动作。

## 单选：“甲取泥于溪滨”，泥土从哪里到谁手中？ {#fword.q.43.1.2}
考点：fword.s.yu-from
语境：fword.p.tile

- [ ] 从甲手里送到溪边
  理由：“取泥”在获取，方向不是送回。
- [ ] 从窑前送到溪边给客人
  理由：窑前是会面处，客人后来来问瓦。
- [x] 从溪边到甲手里

提示：只把“取”同它后面这一处“于”连起来。
解析：这里说的是原料出处。不能把所有地名都当作将来前往的终点。

## 单选：“问政于孔子”接着便有“对曰”。在先前的一问中，“于”把问题引向了谁？ {#fword.q.43.1.3}
考点：fword.s.yu-to
语境：fword.p.dignitary

- [x] 齐景公向孔子发问，孔子作答
- [ ] 孔子向齐景公提问，君主作答
  理由：下一句点明“孔子对曰”，答者当先听到问题。
- [ ] 两人都向一个名叫“政”的人请教
  理由：“政”是谈话的内容，没有第三个听者。

提示：用实际应答者倒查谁是受问的人。
解析：“于孔子”交代话讲给谁，“政”交代问什么。受问人与话题分属两处。

## 单选：县丞说“封而送之”回答了前面哪一种问法？ {#fword.q.43.1.4}
考点：fword.s.ruhe
语境：fword.p.pouch

- [ ] “如是简何”问是谁写了简
  理由：答句没点作者，县丞只决定处置办法。
- [x] “如是简何”问怎样处置这份文书
- [ ] “如是简何”问简像哪一种印章
  理由：县丞没描述形状，提出的是封好送去的做法。

提示：“是简”被“如”和“何”夹在中间。
解析：把话还原成“拿这份文书怎么办”，便知道为何封送足以作答。

## 找原文证据：若只标出两名匠人碰面的地点，不把取泥的来处也标进去，应圈哪处？ {#fword.q.43.1.5}
考点：fword.s.yu-place
语境：fword.p.tile

- [ ] 于溪滨
  理由：这是甲取泥的来处，不是两个人约好碰面的地方。
- [ ] 于山阴
  理由：这是乙取泥的来处。
- [x] 于窑前

提示：先看三个“于”各自连着什么动词。
解析：“会”所支配的是会面处，“取”所支配的却是材料来源；位置相像，关系不同。

## 单选：“受简于樵者”若译成“把文书交给了樵夫”，把哪一个方向弄反了？ {#fword.q.43.1.6}
考点：fword.s.yu-from
语境：fword.p.pouch

- [x] 樵夫是给简的人，吏员才是收简的人
- [ ] 吏员住在亭中，不是住在县里
  理由：地点译错不能解释谁交出文书。
- [ ] 吏员向县丞打听，樵夫负责作答
  理由：县丞回答封送；这和吏员从谁手中接简是两件事。

提示：谁接到简，谁才接着查看上面的印？
解析：“受”写吏员接收，“于樵者”指出来处。由他看印、请示，也可验证简在他手上。

## 找原文证据：客人问的是做瓦的本领。“问于二人”中的“二人”在上文怎样合称？ {#fword.q.43.1.7}
考点：fword.s.yu-to
语境：fword.p.tile

- [ ] 山阴
  理由：这里是取泥处，没说这座山向客人答话。
- [x] 二匠
- [ ] 溪滨
  理由：这是原料采集处，不会回答客人。

提示：看谁听了这番问话之后各举一瓦。
解析：受问的是会面的两个匠人；“于”在这儿没有引出“从哪里取来”。

## 单选：“溪泥孰与山泥宜作瓦”若要答得切题，应比较哪件事？ {#fword.q.43.1.8}
考点：fword.s.shuyu
语境：fword.p.tile

- [ ] 溪边与山上的路，哪条更短
  理由：客人问“宜作瓦”，与出行路程无关。
- [ ] 两位匠人，谁在窑边先到
  理由：“孰与”两端是两种泥，不是两个匠人的到达时间。
- [x] 两种泥料，哪种烧瓦更合适

提示：先找题中真正并置的两物，再看所比的方面。
解析：各举一瓦供验，是为了以成品比较原料适用性。这次问话不是要判谁更早到。
