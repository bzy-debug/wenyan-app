# 课文：凭什么做，为了谁做 {#fword.43.2}
简介：工匠凭老图修井，另刻新线给后来人看；有些话交代手头所据，有些话要看他打算把事情做成什么样子。
回读：fword.s.qi-that fword.p.market
  fword.s.yan-close fword.p.etch

## 正文

“以旧图定井深”，图是定深浅的凭据；“刻石以示后来者”，刻石在前，让后来的人看见是目的。在动词旁边给“以”换成“凭”或“来”，便能看出哪件是已经有的依据，哪件仍是想达到的结果。

“为利而来”的“为”后面是所求的好处，“为病者煎药”的“为”后面却先点出受照顾的人。把“想得到什么”和“在替谁做”分问两遍，读者才不会看见同一个“为”就把两者混在一起。

## 知识点：“以”表示判断或行事的凭据 {#fword.s.yi-basis}
义项：凭着某种记录、迹象或经验来判断
领域：虚词
要诀：问“据什么作判断”；依据可以是旧图、旧约，不一定是手持的工具。
讲解：“以旧图定其深”不是拿图纸去量井。图上记着旧井的尺寸，工匠据其记录决定怎样下手。
例句：fword.p.etch

## 知识点：“以”连接前一行动和后一目的 {#fword.s.yi-aim}
义项：先做某事，意在实现后述结果
领域：虚词
要诀：看看前一件是正在做的行动，后一件是否回答“做它为了什么”。
讲解：工匠“刻其数于石，以告后来者”。刻石是现在的事，有人将来读懂是用意，没说他现在已经告知所有人。
例句：fword.p.etch

## 知识点：“为”引出采取行动所求的目的 {#fword.s.wei-aim}
义项：为了某物或某种结果而行动
领域：虚词
要诀：“为利”是求利，“为人”有时是替人；先看后面的词指人还是所得。
讲解：“为宫室之美”说人所贪求的是华美的住宅，不是替屋宅本人办事，更不是被房屋差遣。
例句：fword.p.salary

## 原文：教学例句 {#fword.p.etch}
> 井旁有亭，匠宿焉。翌日为两村治旧井，以旧图定其深，又刻其数于石，以告后来者。其徒曰：“治井为久安，非为一时之誉。于此役，师实尽力焉。”
译文：井旁有一座亭子，工匠在那里住宿。第二天替两个村子修旧井，凭旧图确定井深，又把尺寸刻在石头上，好告诉后来的人。徒弟说：“修井求的是长久安稳，没图一时称赞。在这件事上，师傅确实尽力了。”
词注：治：修整。
  誉：赞誉。
  役：这件劳作。

## 原文：教学例句 {#fword.p.market}
> 市吏约初三会众定秤。其日，众以旧券所记核铜权之重，乃悬权于门以示市人。一贾曰：“吾为信而来，非为利也。”
译文：市吏约定初三会同众人校秤。那天，大家凭旧凭证上的记录核对铜秤锤的重量，再把秤锤悬挂在门上，给赶集的人看。一个商人说：“我来是为求交易可信，不是为求获利。”
词注：券：凭证。
  权：秤锤。
  贾：读 gǔ，商人。

## 原文：古籍引文 {#fword.p.salary}
> 万钟则不辩礼义而受之。万钟于我何加焉？为宫室之美、妻妾之奉、所识穷乏者得我与？
译文：见到丰厚俸禄却不辨礼义就接受。这样的俸禄对我有什么益处呢？是为了华美的住宅、妻妾的侍奉，或让相识的贫困人感激我吗？
词注：钟：底本作“鍾”，古代容量单位；万钟在这里指高禄。
  辩：通“辨”，辨明。
  得我：感激我。

## 单选：匠人“以旧图定其深”时，为什么要取旧图？ {#fword.q.43.2.1}
考点：fword.s.yi-basis
语境：fword.p.etch

- [x] 凭图上旧井的记录定井深
- [ ] 用图纸垂下井去探底
  理由：这是把凭据当成了测量工具，原文没写垂图。
- [ ] 要在井壁上重新画图
  理由：动词是定深，刻字的位置在后来另说的石上。

提示：旧图能给修井人什么信息？
解析：这里的“以”相当于依据。修井人需要图所保存的信息，不是需要一张可代替量绳的纸。

## 单选：将铜权“悬……于门以示市人”，悬挂想实现的是什么？ {#fword.q.43.2.2}
考点：fword.s.yi-aim
语境：fword.p.market

- [ ] 因为大家已看见，才取下秤锤
  理由：原文写“悬”，没有取下；让人看见是悬挂的用意。
- [x] 使赶集的人都能看到校过的秤锤
- [ ] 借用赶集的人作悬挂工具
  理由：人是后来要看见秤锤的一方，不是挂物的工具。

提示：把“以”换成“好让”，看所接动作。
解析：前一动作挂出秤锤，后一动作示众。校秤在过去，让后来人能看是现在的目的。

## 单选：孟子说“为宫室之美”，是在问收高禄的人想得到什么？ {#fword.q.43.2.3}
考点：fword.s.wei-aim
语境：fword.p.salary

- [ ] 受一座房屋委托，替它收俸禄
  理由：“宫室之美”是贪求的好处，并非托人办事的一方。
- [ ] 遭房屋强迫而不得不收
  理由：“为”没有引入加害者，后面列的是接受俸禄的种种动机。
- [x] 想住华美的房屋

提示：把“为了……”放到接受高禄以前读。
解析：“为”引出的可以是行动目的。这里用住宅、侍奉与他人感激列出可能诱因。

## 找原文证据：这一段到了“其日”才实际校秤。“其日”承接哪一处日期？ {#fword.q.43.2.4}
考点：fword.s.qi-that
语境：fword.p.market

- [x] 初三
- [ ] 旧券
  理由：它是过去留下的资料，没说它属于哪一天。
- [ ] 门
  理由：门是后来悬挂秤锤的地方。

提示：从前文找约会之日，而不要问这是谁的日子。
解析：“其日”就是市吏原先约下的那一天。后面的校验是当天做的事。

## 单选：众人“以旧券所记”核重，真正作为核对根据的是什么？ {#fword.q.43.2.5}
考点：fword.s.yi-basis
语境：fword.p.market

- [ ] 当年写券的人；“所记”就是执笔者
  理由：“所记”是记下来的内容；若说记账的人，得写“记者”之类的话。
- [x] 凭证上记载的重量
- [ ] 把整份旧券当作秤锤，称铜有多重
  理由：原文特说“所记”，关注的是其所载数字。

提示：读全“以”后面的“旧券所记”，不要漏“所记”。
解析：核对要有旧标准。这里借助记录，不是把有字的纸张直接当成衡器。

## 找原文证据：为什么要把井深的数字刻在石头上？圈出说明刻石目的的话。 {#fword.q.43.2.6}
考点：fword.s.yi-aim
语境：fword.p.etch

- [ ] 以旧图定其深
  理由：这说修井人如何决定井深，属于先前工作。
- [ ] 非为一时之誉
  理由：这是徒弟否认的动机，没说刻数字想让谁获知。
- [x] 以告后来者

提示：从“刻其数于石”向后找：石上的字是给谁看的？
解析：“以告”写刻石的用意，今后接手的人可据此得知原来井深。

## 单选：“为两村治旧井”和“治井为久安”分别回答了哪两个问题？ {#fword.q.43.2.7}
考点：fword.s.wei-aim
语境：fword.p.etch

- [x] 替谁修？替两村。想达到什么？长久安稳。
- [ ] 替谁修？替工匠自己。想达到什么？两村永不再修井。
  理由：两村是享用水井的一方；“久安”没有说以后永不用修。
- [ ] 用谁的钱修？用两村的钱。为了什么？专求一时声名。
  理由：两村受益不等于两村出钱；徒弟明说“非为一时之誉”。

提示：一处“为”后面是用井的人，另一处后面是修井想带来的好处。
解析：工匠为两村出力，两村是受益者。徒弟再说“为久安”，才把修井的目的说清楚。

## 单选：读“匠宿焉”与“于此役，师实尽力焉”，两处都要译出“在那里”吗？ {#fword.q.43.2.8}
考点：fword.s.yan-close
语境：fword.p.etch

- [ ] 两处都要，师傅说自己只在亭子里修井
  理由：“于此役”是谈这次劳作，不是说工匠在亭内挖井。
- [x] 前句要，指井旁的亭子；后句已说在这件事上，收住话即可
- [ ] 两处都不用，两句话都没提匠人睡在哪里
  理由：“井旁有亭”给住宿留下了可回指的地点。

提示：前一句若不交代地点，会丢了哪一层？后一处在“焉”前已交代什么？
解析：头一个“焉”把人安顿在亭中；第二个随“于此役”落下，句中已点明尽力的事，不用另补一处地点。
