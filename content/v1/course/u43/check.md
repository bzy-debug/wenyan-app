# 检查：守门、树碑和运药 {#check.43}

## 原文：教学例句 {#fword.p.check-letter}
> 童受书于驿卒，将告于里正，遇雨，避于桥下。里正问：“书自谁来？”童以驿封为证。
译文：孩子从驿卒手里接过信，准备向里正报告，遇雨便在桥下躲避。里正问书信来源，孩子拿驿站封记作凭证。
词注：里正：管理乡里事务的人。
  驿封：驿站使用的封记。

## 原文：教学例句 {#fword.p.check-stone}
> 两村争泉，老农以旧图辨水界，刻石以息争。邻翁曰：“吾为两村之和而来，愿各守此界。”
译文：两村争夺泉水，老农凭旧图辨清用水界线，刻石来平息争端。邻村老人说自己为两村和睦而来，希望彼此守界。
词注：界：界线。
  息争：平息争端。
  和：和睦。

## 原文：教学例句 {#fword.p.check-seed}
> 药人视渡曰：“若水浅，则负囊而涉；苟水深，当俟舟。”其囊轻而坚。虽天晚，药人犹守岸。舟人病，故舟失约。
译文：送药人看着渡口：水浅便可背药涉水，若水深便须等船。他的囊袋又轻又牢。虽天已晚，他还守在岸边。船夫病了，因此船没按约来。
词注：负：背。
  俟：等候。
  失约：没有按约前来。

## 单选：“受书于驿卒”“告于里正”“避于桥下”中，书从谁来、话向谁说、人在哪里？ {#fword.q.43.check.1}
考点：fword.s.yu-from
语境：fword.p.check-letter

- [ ] 书从里正来，话向驿卒说，人躲在桥下
  理由：“受书”后接驿卒，“告”后接的才是里正。
- [ ] 书从桥下来，话向里正说，人躲在驿站
  理由：避雨用“避于桥下”；驿卒是人，并非躲雨地点。
- [x] 书从驿卒来，话向里正说，人躲在桥下

提示：给“受”“告”“避”各问一个不同的问题。
解析：同一封信引出三个关系：受是来源，告是对象，避是动作处所。字形相同，方向须随动作变。

## 找原文证据：要知道孩子准备向谁报告，应在原文点哪一处？ {#fword.q.43.check.2}
考点：fword.s.yu-to
语境：fword.p.check-letter

- [x] 于里正
- [ ] 于驿卒
  理由：这是他从谁手里接信。
- [ ] 于桥下
  理由：这是孩子在什么地方避雨。

提示：只盯住“告”的方向，再核对是谁后来问来信的出处。
解析：“告于里正”以里正为听者。雨中暂歇于桥下，不改变报告的去向。

## 单选：句中两见“以”。拿什么作判断的凭据，刻石又打算达到什么目的？ {#fword.q.43.check.3}
考点：fword.s.yi-basis
语境：fword.p.check-stone

- [ ] 用旧图打磨石面，借吵争来辨界
  理由：“辨水界”要用信息，“息争”要令争端停下，不是拿争吵当工具。
- [x] 凭旧图辨水界，刻石好平息争端
- [ ] 拿争端作判断凭据，刻石是为了制作旧图
  理由：旧图在先，息争是将来希望实现的结果。

提示：先区分“以旧图”的名物同“以息争”的动作。
解析：第一处是所据，第二处以另一行动的目的来解释为什么刻石。

## 单选：邻翁说“为两村之和而来”。他此行追求的是什么？ {#fword.q.43.check.4}
考点：fword.s.wei-aim
语境：fword.p.check-stone

- [ ] 受一个人名叫“和”的村民差遣
  理由：“两村之和”是两个村落的关系，不是一个人的名字。
- [ ] 用两村的旧图兑换自己的土地
  理由：拿图辨界的是老农；邻翁只解释来意。
- [x] 两村和睦、不再为水界争执

提示：“之和”落脚在两村怎样相处。
解析：“为”引出的目标是和睦，正与前面刻石息争的意图照应。

## 单选：“若水浅……苟水深……”与后文“虽天晚，药人犹守岸”各做了什么？ {#fword.q.43.check.5}
考点：fword.s.if
语境：fword.p.check-seed

- [x] 前两句按深浅拟定不同办法，后一句说明天晚仍不走
- [ ] 三句都是先后已经发生的事情
  理由：不能把浅、深两种互斥情形连作渡口实录。
- [ ] 前两句让步，后一句断定天晚必能上船
  理由：“若”“苟”设条件，“犹守岸”反说明尚在等候。

提示：哪些情况要二选一，哪一种却未改变守岸的决定？
解析：预案要看水深；天色已晚却还留下，是让步关系。这两种关系虽都能有两分句，用意不同。

## 单选：“囊轻而坚”和“舟人病，故舟失约”分别该用什么连起来？ {#fword.q.43.check.6}
考点：fword.s.parallel
语境：fword.p.check-seed

- [ ] 囊先轻后来变牢；船夫虽然生病仍然守约
  理由：“而”在这里并列，“失约”写的是未做到。
- [x] 囊又轻又牢；船夫患病，所以船误约
- [ ] 囊轻所以不牢；船晚到又恰巧有人病了
  理由：“坚”是牢固，“故”把前病后迟连成因果。

提示：把描写同一件物的两个性质与前后两件事分开。
解析：轻、坚可以同时成立，病、误约却有前因后果；两个虚词不能都译作“然后”。
