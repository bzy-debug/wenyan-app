# 课文：若、虽、故，把两件事怎样连起来 {#fword.43.3}
简介：读守关与种苗的小段，分清尚未发生的条件、让了一步仍成立的判断、前因推出的结果，以及同时可见的两种面貌。

## 正文

守卒在城楼上说“若有警，则鸣鼓”。客人只听了规矩，还没有听见鼓声。在“虽雨，守者不去”里，落雨即使成了实情，也没改变守卒的决定；让步的落脚处在后半句。

“故”又换了一种读法：“湿结难解，故鼓声迟”，前面给出原因，后面交代实际后果。别把并排的两种性质也硬接成因果：说绳“长而韧”，只消告诉读者既长又结实。

## 知识点：若、苟引出尚待满足的条件 {#fword.s.if}
义项：倘若甲发生，就按乙办
领域：虚词
要诀：把前句当作假设；判断文本有没有另交代条件已经满足。
讲解：“若闻三鼓，则启门”是一条规矩。只看这句话，既不能断定已闻三鼓，也不能断定门已经开了。
例句：fword.p.gate

## 知识点：“虽”交代仍改变不了结论的条件 {#fword.s.concession}
义项：虽有甲，后述结论依然成立
领域：虚词
要诀：两半分别读，再问前一层情况能不能使后面的决定改变。
讲解：“虽雨，守者不去”保留了守门的决定。若把“虽”读成“因为”，便会误以为下雨正好是他们留下来的理由。
例句：fword.p.gate

## 知识点：“而”并列两项性质或动作 {#fword.s.parallel}
义项：同说一人一物的两个方面
领域：虚词
要诀：先试放入“又”；两项都能在同一时间成立，就不必添先后。
讲解：守门旧索“长而韧”，说的是绳同时够长又结实。不是先长、过些日子才韧。
例句：fword.p.gate

## 知识点：“故”承前引出结果 {#fword.s.therefore}
义项：因为前述情形，所以发生后一事
领域：虚词
要诀：把两句改读成“因为甲，所以乙”，看因果方向是否相合。
讲解：渠中没有水，故田里苗迟；“故”后接的是已发生的结果，不是说农人有意推迟移苗。
例句：fword.p.seedlings

## 原文：教学例句 {#fword.p.gate}
> 守者相约：“若闻三鼓，则启门；苟未闻，毋启。”其夕虽雨，守者不去。悬槌之索长而韧，湿结难解，故鼓声迟。候者终闻三鼓，乃启。
译文：守门人约定：如果听见三声鼓便开门，倘若还没听见就别开。那晚虽下了雨，他们仍不离开。悬着鼓槌的绳索又长又结实，湿了的绳结难解，所以鼓声来迟。等候的人终于听到三声，才打开门。
词注：索：绳索。
  槌：敲鼓的棒。
  毋：不要。

## 原文：教学例句 {#fword.p.seedlings}
> 小田土细而润。农曰：“苟泉至，可以移苗；若泉未至，姑待之。”是日上渠无水，故苗迟。次日泉通，虽风急，农犹移苗。
译文：小田里的土又细又润。农人说，若泉水引到，就可以移苗；若没到，暂且再等。当天上游水渠没水，所以移苗晚了。次日泉通，虽风急，农人还是去移苗。
词注：润：湿润。
  姑：姑且。
  犹：仍然。

## 单选：刚听到“若闻三鼓，则启门”的规矩时，可以断定的是什么？ {#fword.q.43.3.1}
考点：fword.s.if
语境：fword.p.gate

- [ ] 话音未落门便已开
  理由：规矩在前，实行情形另有后文。
- [ ] 有雨就必须开门
  理由：“若”引出的条件是三鼓，不是天气。
- [x] 三声鼓是开门的条件，尚不能说鼓已经响了

提示：把规定和其夕亲历的事分两行读。
解析：“若”把情况提出来假设，“则”引出条件满足后的动作。等听到鼓声才成了事实。

## 单选：“虽风急，农犹移苗”说明急风改变了农人的决定吗？ {#fword.q.43.3.2}
考点：fword.s.concession
语境：fword.p.seedlings

- [x] 承认风很急，移苗仍照做
- [ ] 正是因为风急，农人才催着移苗
  理由：“虽”承认一层不利条件，不把风急当作行动原因。
- [ ] 风一急，农人就取消移苗
  理由：“犹”保留了实行移苗的决定。

提示：找“虽”所让的一步，再找“犹”坚持的行动。
解析：水已通是前面的情况。作者补写风急，是要说即便如此仍不误移苗。

## 单选：“索长而韧”有没有先后两个阶段？ {#fword.q.43.3.3}
考点：fword.s.parallel
语境：fword.p.gate

- [ ] 绳长，反而毫无韧性
  理由：前后都在肯定它的性质，不含否定“韧”的字。
- [x] 只是同说一条索又长又韧
- [ ] 绳索先变长，后来才结实
  理由：“长”“韧”可以同时描述眼前一条索，文中没有生长经过。

提示：试换成“又”，比换成“然后”多添了什么？
解析：“而”在两项形容之间连起并列的性质；故事中的久雨则是另一个时间过程。

## 单选：“是日上渠无水，故苗迟”，哪一项是已发生的结果？ {#fword.q.43.3.4}
考点：fword.s.therefore
语境：fword.p.seedlings

- [ ] 农人故意藏住渠水
  理由：“故”承接水渠本来无水，不是在判谁有意为之。
- [ ] 上渠从此永远没有水
  理由：次日有“泉通”，无水只是当天的状况。
- [x] 当天移苗晚了

提示：按“因为……所以……”从前向后读。
解析：这里“故”引起结果。水引不来是原因，推迟移苗才是它带来的后果。

## 单选：“苟泉至”与“若泉未至”是先后已发生的两件事，还是农人预先作的两种安排？ {#fword.q.43.3.5}
考点：fword.s.if
语境：fword.p.seedlings

- [x] 两种假设；有水便移苗，没水便再等
- [ ] 两件都已在说话前发生，先移苗又全部拔起
  理由：前文是农人提出办法，当天情况要在“是日”后读。
- [ ] 断定一直有水，不用考虑缺水
  理由：“若泉未至”明确留下了没有水的一种情况。

提示：分别给两句各找一个能够接上的“如果”。
解析：两种可能指向不同的做法；“是日上渠无水”才揭晓当天符合哪一支。

## 单选：“其夕虽雨，守者不去”里的雨与“不去”是什么关系？ {#fword.q.43.3.6}
考点：fword.s.concession
语境：fword.p.gate

- [ ] 雨一停，守者便离开岗位
  理由：原文未写因雨停而离开。
- [x] 下雨本可能使人离开，守者却仍留下
- [ ] 因为下雨，守者才决定留下避雨
  理由：没说这里适合避雨；“虽”是在承认不利情形。

提示：把前句的天气和后句不变的决定分开。
解析：“虽”所让的是雨，“不去”所守的是值守的决定。不要把“尽管”与“因为”混成同一种因果。

## 单选：“小田土细而润”可怎样转述而不增加原文没有的因果？ {#fword.q.43.3.7}
考点：fword.s.parallel
语境：fword.p.seedlings

- [ ] 土所以湿润，唯一原因是颗粒细
  理由：“而”并排两种性质，没给唯一成因。
- [ ] 土从前细，现在只剩湿润
  理由：这句话不比较往昔和现在。
- [x] 小田的土既细，又湿润

提示：“细”与“润”能同时成为对一块土的观察吗？
解析：二者都是当下的特征。用“又”能保住这层关系，用“所以”则作了额外推断。

## 单选：“湿结难解，故鼓声迟”中，“故”哪一种读法会让事件前后相接？ {#fword.q.43.3.8}
考点：fword.s.therefore
语境：fword.p.gate

- [x] 绳索久湿，所以信号来迟
- [ ] 绳子故意不让鼓响
  理由：这里没有有意行事的人，所写是久雨后果。
- [ ] 鼓声以前一向很迟
  理由：“故”后确有“迟”，但前面刚给出这次受雨影响的缘由。

提示：若将两句倒换，原因和结果会不会颠倒？
解析：雨湿在前、迟响在后，“故”把迟到的信号作为结果引出来。
