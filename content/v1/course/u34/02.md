# 课文：把相对的两句放在一起读 {#verse.2}
简介：柳宗元写完“千山”“万径”，只留下江上一叶船。读唐诗，看看两句怎样彼此照应，又从哪里写到了人的心事。
## 正文
“千山鸟飞绝，万径人踪灭。”先把山和路放在一起，再把飞鸟和行人留下的踪迹放在一起。读到两个句末，一个“绝”，一个“灭”，山野就静了下来。这样看过全景，才知道下一句的小船为何格外醒目。

王湾却把另一首诗的结尾写成问话。江边有雁，行船的人想着它能不能替自己捎封家信。两首诗都写船，一首把人留在画中，一首借船上人的念头望向故乡。

## 知识点：顺着相对的字词读一联 {#verse.s.pair}
义项：将上下句位置相当的景物、动作或处境对读
领域：篇章
要诀：按两句相同的位置找两对词，先在心里摆成两行。
讲解：相对的位置有时互相补足，有时互相映照。再问这两句是在说两件先后的事，还是让人同时看见一幅景象。
例句：verse.p.snow

## 知识点：从景物转入人的心事 {#verse.s.feeling}
义项：辨认写景中显出人的处境、愿望或情感的字句
领域：篇章
要诀：读到人称、动作、比拟或问句时，停下来看看是谁的心事。
讲解：知道江上有什么，还须弄懂诗人为什么写到它。由诗里的问话、动作或相比之物去找线索。
例句：verse.p.letter

## 原文：古籍引文 {#verse.p.snow}
> 千山鸟飞绝，万径人踪灭。
> 孤舟蓑笠翁，独钓寒江雪。
译文：群山间看不到飞鸟，许多小路上也看不见人的踪迹。寒江雪中，一条孤舟上，披蓑戴笠的老人独自垂钓。
词注：径：小路。
  蓑笠：蓑衣和斗笠。
出处：《江雪》，全篇

## 原文：古籍引文 {#verse.p.letter}
> 客路青山外，行舟绿水前。
> 潮平两岸阔，风正一帆悬。
> 海日生残夜，江春入旧年。
> 乡书何处达，归雁洛阳边。
译文：旅途通向青山外，船行在绿水间。潮水涨满，两岸显得开阔，顺风里一面船帆高悬。夜还没尽，海上太阳已升起，旧年未过，江上已有春意。家信怎样送到？愿归雁捎到洛阳那边。
词注：客路：旅人的路。
  残夜：将尽的夜。
  乡书：寄往家乡的信。
出处：《次北固山下》，全篇
作者：王湾

## 原文：古籍引文 {#verse.p.farewell}
> 青山横北郭，白水绕东城。
> 此地一为别，孤蓬万里征。
> 浮云游子意，落日故人情。
> 挥手自兹去，萧萧班马鸣。
译文：青山横在外城以北，白水环绕城东。从这里告别，你便如孤蓬远行。浮云像游子的心意，落日像故人的惜别之情。我们挥手分别，离群的马萧萧长鸣。
词注：郭：外城。
  孤蓬：随风飘转的蓬草，借来写远行的友人。
  班马：离群的马。
出处：《送友人》，全篇
作者：李白
版本：据 chinese-poetry《唐诗三百首》录文排印，繁简转写。“遶”按通行字写作“绕”。

## 单选：“千山”对“万径”，“鸟飞”对“人踪”。“绝”和“灭”合起来给人怎样的印象？ {#verse.2.q1}
考点：verse.s.pair
语境：verse.p.snow

- [ ] 鸟先飞尽，过了许久路人才离开
  理由：两句各写一处，没有说明相隔多久。
- [x] 山中和路上都看不到往日的活动
- [ ] 山挡住了飞鸟，道路拦下了行人
  理由：“绝”“灭”说眼前所见，并没把山和路写成障碍。

提示：把两句末尾放在一块儿读。
解析：在天上找鸟，在地上找人，两处都不见踪影。前两句把四周写静了。

## 找原文证据：从四处不见人踪，到看清一个人正在做什么，哪几个字写出了他的动作？ {#verse.2.q2}
考点：verse.s.feeling
语境：verse.p.snow

- [ ] 万径人踪灭
  理由：这仍在说许多小路上看不到人的踪迹。
- [ ] 孤舟蓑笠翁
  理由：这里点出船和装束，动作还在下一句。
- [x] 独钓寒江雪

提示：找老人能亲自做的一件事。
解析：一人独钓是全诗落脚的动作。先前的空山与空路，到了这里都成了他的四周。

## 单选：“海日生残夜，江春入旧年”里，旧夜旧年将尽时，新出现的是哪两样？ {#verse.2.q3}
考点：verse.s.pair
语境：verse.p.letter

- [x] 日光和春意
- [ ] 夜色和旧年
  理由：“残”说夜将尽，“旧”说这一年接近末尾。
- [ ] 家信和归雁
  理由：这两样在后面，是旅人另外挂念的事。

提示：试把“生”“入”前面的词挑出来。
解析：夜未尽而日已生，年未改而春已入。两句都写出了新旧交叠的时候。

## 找原文证据：哪一句把视线从江上的景色引向旅人的牵挂？ {#verse.2.q4}
考点：verse.s.feeling
语境：verse.p.letter

- [ ] 潮平两岸阔
  理由：这句仍在写江面的开阔。
- [ ] 江春入旧年
  理由：这句写江上春意来得早。
- [x] 乡书何处达

提示：找他开口询问的一件事。
解析：他开始问家信怎样寄达，下一句的洛阳便有了着落。

## 单选：“浮云游子意，落日故人情”若分作两幅小画，怎样配人和景？ {#verse.2.q5}
考点：verse.s.pair
语境：verse.p.farewell

- [x] 游子配浮云，故人配落日
- [ ] 游子配落日，故人配浮云
  理由：两边各自摆在同一句里，不能把后半句互换。
- [ ] 两人都配浮云，落日只说明日期
  理由：“故人情”紧挨着落日，日暮的景也参与惜别。

提示：每句都是景物在前，人的心情在后。
解析：两行相同的位置从景写到人，使远行和惜别两份心情可以放在一起读。

## 单选：“孤蓬万里征”接在“此地一为别”后，诗人用孤蓬来比谁的去路？ {#verse.2.q6}
考点：verse.s.feeling
语境：verse.p.farewell

- [ ] 还留在此地送客的人
  理由：“万里征”写踏上远行的人。
- [x] 即将独自远行的友人
- [ ] 一直在水边放马的人
  理由：诗中写到马鸣，却没有放马的人。

提示：“征”是远行；看谁要踏上这段路。
解析：一别之后，友人像蓬草一样远行。“孤”把长路上少人相伴也写进了画面。

## 单选：诗末请归雁捎信。读到这里，我们能确定什么？ {#verse.2.q7}
考点：verse.s.feeling
语境：verse.p.letter

- [ ] 他已经收到洛阳寄来的回信
  理由：读到的是“何处达”的问话，没有收信的叙述。
- [ ] 船正要靠上洛阳城边的码头
  理由：北固山下才是诗题点明的行舟之处。
- [x] 旅人惦记洛阳，想让家信到达

提示：家信的去处与船的所在可以是两个地方。
解析：问家信如何送达，才望向归雁。洛阳是心意所向，诗并没写信已送到。

## 单选：读“孤舟”“独钓”时，哪个字最能和前面的“孤”彼此照应？ {#verse.2.q8}
考点：verse.s.pair
语境：verse.p.snow

- [x] 独
- [ ] 寒
  理由：“寒”写天气，与“孤”可以同在一个画面，却不直接写人少。
- [ ] 雪
  理由：“雪”写环境，没有说明几人在场。

提示：想想船有几条，垂钓的又有几个人。
解析：舟是孤舟，人是独钓。相近的意思分别落在船和人身上，也遥应开头千山万径的寂静。
