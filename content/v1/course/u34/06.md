# 课文：入、出、内、反 {#words.6}
简介：雨夜有人敲门，小仆举烛认人。“客入”和“内客”都写进门，这一步各由谁来做？

## 正文

把门当作两边的分界。“客入”是客人自己跨进去，“吏内客”是把门的官吏让客人进去。这个“内”读 nà。说“毋内诸侯”，听令的就是能够放行的人，即使眼前有诸侯要进，也不能放他们过去。

遇到“出”，先看前后有没有聘书、官职。一位先生久居乡间，郡守屡次来请，随后他“为郡主簿”，这个“出”便指接受征聘。“反”又要认来路：商人上船才想起契据落在客舍，一“反”就改变了方向，他得折回去取。

## 知识点：入 {#skill.u34.ruin}
义项：进入，从外面到里面
领域：实词
要诀：“欲入”还只是要进去，要看门开没开、人过没过。
讲解：项羽带兵往西，想进关，眼前却是关门紧闭。若省去“欲”字，直接译成已经入关，就把这段行程往前多说了一步。
例句：p.u34.ruina

## 原文：古籍引文 {#p.u34.ruina}
> 十一月中，项羽果率诸侯兵西，欲入关，关门闭。
译文：十一月中旬，项羽果然率诸侯的军队西进，想进关，关门却关闭着。

## 单选：项羽到了关外，已经进关了吗？ {#q.u34.6.1}

语境：p.u34.ruina

- [ ] 项羽从关内向关外撤走 {#q.u34.6.1.o1}
  理由：“入”指朝里，方向并非离开。
- [ ] 诸侯军已经进入关内，随即关门 {#q.u34.6.1.o2}
  理由：“欲入”只说打算进入，尚未写成功。
- [x] 项羽想率军由关外进去，眼前的门还关着 {#q.u34.6.1.o3}

提示：留意“欲入”的“欲”，再看关门开着还是关着。
解析：项羽想率军进关，可关门还关着。这句话写到进关受阻为止。

## 原文：教学例句 {#p.u34.ruinb}
> 客立馆外，主人闻叩门声，启扉。客入，置笠于案。
译文：旅客站在馆舍外，主人听见敲门声便开门。客人走进去，把斗笠放在桌上。

## 单选：谁由馆舍外走到馆舍里面？ {#q.u34.6.2}
考点：skill.u34.ruin
语境：p.u34.ruinb

- [ ] 两人一同从外面走入 {#q.u34.6.2.o1}
  理由：原文只写客人在外等候。
- [x] 刚才敲门的客人 {#q.u34.6.2.o2}
- [ ] 开门的主人 {#q.u34.6.2.o3}
  理由：“客入”重新写出了行动者。

提示：“启扉”和“入”的主语是否相同？
解析：主人听见叩门，打开门扇；接着才换客人做主语，进屋摘下斗笠。

## 知识点：出 {#skill.u34.chu}
义项：出仕，出来做官
领域：实词
要诀：隐居的人“出”以后若有了官职，可读作出仕。
讲解：先生隐居十年，郡守屡次来请，“乃出，为郡主簿”。有了后面的官职，就知道“出”是接受征聘、出来任职。
例句：p.u34.chua

## 原文：教学例句 {#p.u34.chua}
> 先生隐居十年，郡守数聘之，乃出，为郡主簿。
译文：先生隐居十年，郡守多次征聘他，他才出来做官，担任郡府主簿。

## 找原文证据：哪几个字写出先生离开隐居生活后担任的职务？ {#q.u34.6.3}
考点：skill.u34.chu
语境：p.u34.chua

- [ ] 数聘之 {#q.u34.6.3.o1}
  理由：多次征聘是邀请，还不能证明接受。
- [ ] 隐居十年 {#q.u34.6.3.o2}
  理由：这是开始任职前的处境。
- [x] 为郡主簿 {#q.u34.6.3.o3}

提示：找受聘后实际担任的职务。
解析：“为郡主簿”说他做了郡里的主簿。“乃出”是说这位原先隐居的人出仕了。

## 原文：教学例句 {#p.u34.chub}
> 州辟书至，生以亲老，辞不出。越明年，始受命，理郡中狱。
译文：州府征聘他的文书送来，读书人因双亲年老，辞谢而不出仕。过了一年才接受任命，办理郡中的案件。

## 单选：收到州府的文书，书生当时推辞了哪件事？ {#q.u34.6.4}
考点：skill.u34.chu
语境：p.u34.chub

- [x] 读书人接受州府任命 {#q.u34.6.4.o1}
- [ ] 读书人迈出家门去看望父母 {#q.u34.6.4.o2}
  理由：“亲老”说明推辞原因，没有交代一次出门探望。
- [ ] 征聘的文书送到家里 {#q.u34.6.4.o3}
  理由：“辟书至”已写文书到家。书生拒绝的是随后要他做的事。

提示：与下一年的“始受命”作对照。
解析：他因家中长辈年老，先辞去征召。到次年才接受任命，处理郡里的案件。

## 知识点：内 {#skill.u34.na}
义项：接纳进入，准予进入（读 nà）
领域：实词
要诀：守门人“内客”，一个人放行，另一个人进门。
讲解：“毋内诸侯”是叫把关的人别让诸侯进来。读 nà 的“内”写是否放行；守门者和想进门的人要分开读。
例句：p.u34.naa

## 原文：古籍引文 {#p.u34.naa}
> 鲰生说我曰：“距关，毋内诸侯，秦地可尽王也。”故听之。
译文：有个浅陋的人劝我：“守住关口，别让诸侯进来，你就能占有整个秦地，在这里称王。”所以我听了他的话。这里“距”同“拒”。

## 单选：鲰生劝沛公“毋内诸侯”，是想拦住谁、拦住什么行动？ {#q.u34.6.5}
考点：skill.u34.na
语境：p.u34.naa

- [ ] 命沛公不要留在关内 {#q.u34.6.5.o1}
  理由：“内”在这里带宾语，句子并未命令沛公出去。
- [ ] 劝诸侯不要接纳沛公 {#q.u34.6.5.o2}
  理由：“诸侯”接在“内”后，是被准入或被拒绝者。
- [x] 阻止各路诸侯进入关内 {#q.u34.6.5.o3}

提示：把关口分成里外两边，想想谁可以决定放行。
解析：把关的是沛公一方，要拦的是希望进关的诸侯。“内”在此读 nà。

## 原文：教学例句 {#p.u34.nab}
> 雨夜，叩门者自言故人。僮执烛视其面，识之，遂内之。
译文：雨夜，敲门人自称老朋友。小仆拿灯照他的脸，认出了他，便让他进来。

## 单选：认出门外的人以后，“遂内之”写谁让谁进了门？ {#q.u34.6.6}
考点：skill.u34.na
语境：p.u34.nab

- [ ] 来客把小仆迎进自己的家 {#q.u34.6.6.o1}
  理由：来客从门外敲门，自称故人。
- [ ] 小仆进门，请来客在门外举灯 {#q.u34.6.6.o2}
  理由：前面“僮执烛”已说明拿灯者。
- [x] 小仆放行，来客获准进门 {#q.u34.6.6.o3}

解析：小仆举烛认人，认出是故友，便让来客进来。获准进门的是“之”所指的来客。

## 知识点：反 {#skill.u34.fan}
义项：返回，循路回去
领域：实词
要诀：契据落在哪儿，“反取之”的人就得往哪儿回。
讲解：“乃反取之”中的“之”是契据。商人已登舟，却把契据落在客舍，所以得先回客舍，取到以后才又到渡口。
例句：p.u34.fana

## 原文：教学例句 {#p.u34.fana}
> 商人既登舟，忽忆契在客舍，乃反取之。得契，复至津。
译文：商人已登船，忽然记起契据在旅店，于是回去取来。拿到契据，他再次到渡口。

## 单选：商人“反取之”，先回到哪处？ {#q.u34.6.7}
考点：skill.u34.fan
语境：p.u34.fana

- [ ] 等船的渡口 {#q.u34.6.7.o1}
  理由：“复至津”在得契之后，是再次到渡口。
- [ ] 先前还没去过的市场 {#q.u34.6.7.o2}
  理由：行程里没有市场，所取之物已有明确位置。
- [x] 留有契据的客舍 {#q.u34.6.7.o3}

提示：先回答东西遗落在哪里，再追踪“反”。
解析：商人记起契据还在客舍，便从船边折返回去取。取到契据后，他才又来到渡口。

## 原文：教学例句 {#p.u34.fanb}
> 童送母至桥，母麾之使反。童还家，告父曰：“母已渡矣。”
译文：孩子送母亲到桥边，母亲挥手让他回去。孩子回到家，告诉父亲母亲已经过桥了。

## 找原文证据：母亲叫孩子“反”，孩子接着做了什么？选出原文。 {#q.u34.6.8}
考点：skill.u34.fan
语境：p.u34.fanb

- [ ] 童送母至桥 {#q.u34.6.8.o1}
  理由：这是此前共同走过的一段。
- [x] 童还家 {#q.u34.6.8.o2}
- [ ] 母已渡矣 {#q.u34.6.8.o3}
  理由：这是孩子向父亲报告母亲的去向，题目要找的是孩子自己往哪儿走。

提示：留意在谁身上用“还”换说了“反”。
解析：“还家”是孩子听了母亲的话以后做的事。所以“使反”是叫他回去。
