# 课文：居、次、临、涉 {#words.5}
简介：给处所动词配上地点，辨认居住、驻扎、靠近与过水。

## 正文

同一条水边可以有四种动作。人在河旁“居”，交代住处；出行的队伍“次”于岸上，是在那里停驻；“临”水，身体已面对水面；“涉”水，则把路线延伸到了水中。读到一个地名，先别急着画前进的箭头，应看动词写停留、接近还是穿过。

本课还要借后文检查理解：筑屋、种菜可说明久居，张幕等候支持临时驻扎，俯视水面只能说明在岸边，脱履褰衣走向对岸才说明要涉过水去。

## 知识点：居 {#skill.u34.ju}
义项：居住，住在
领域：实词
要诀：留意处所和日常生活是否连在一起。
讲解：在“居某处”中，地点是人物的住处。若写暂时借宿、面朝何处，原文通常还会给出别的动作线索。
例句：p.u34.jua

## 原文：教学例句 {#p.u34.jua}
> 陶者居邑东，门前积土，屋后有窑。客欲买器，晨往其家。
译文：陶工住在城东，门前堆着泥土，屋后有窑。旅客想买陶器，早晨到他家去。

## 单选：“居邑东”给想找陶工的客人提供了什么信息？ {#q.u34.5.1}
考点：skill.u34.ju
语境：p.u34.jua

- [ ] 陶工早晨出发去城东卖器 {#q.u34.5.1.o1}
  理由：早晨出发的是客人。
- [x] 陶工家在城东 {#q.u34.5.1.o2}
- [ ] 陶工只管城东的陶器买卖 {#q.u34.5.1.o3}
  理由：“居”交代住处，没有说经营范围。

提示：“其家”应与前面哪个处所相连？
解析：门、屋以及客人登门的后文，都支持把城东读成陶工的住处。

## 原文：教学例句 {#p.u34.jub}
> 妪与女居山下，春种豆，秋收栗。女嫁，妪犹居故屋。
译文：老妇与女儿住在山下，春天种豆，秋天收栗。女儿出嫁后，老妇仍住在老屋里。

## 找原文证据：哪句说明女儿离去后，母亲的住处没有变？ {#q.u34.5.2}
考点：skill.u34.ju
语境：p.u34.jub

- [x] 妪犹居故屋 {#q.u34.5.2.o1}
- [ ] 春种豆 {#q.u34.5.2.o2}
  理由：这里写春天的劳作。
- [ ] 女嫁 {#q.u34.5.2.o3}
  理由：这写女儿生活的变化。

提示：找“仍然”与老屋同时出现的地方。
解析：“犹”把前后连在一起，“居故屋”明确指出老妇依旧住在原处。

## 知识点：次 {#skill.u34.ci}
义项：行进的队伍停驻、驻扎
领域：实词
要诀：看队伍行进之后，在哪个地名停下来。
讲解：行旅或军队可说“次于某地”。若把“次”误作次序，就很难解释“于”后的地点和后来再次出发。
例句：p.u34.cia

## 原文：古籍引文 {#p.u34.cia}
> 齐桓公伐山戎，次于孤竹。
译文：齐桓公出兵攻打山戎，军队在孤竹驻扎。
出处：《史记·秦本纪》节录
作者：西汉·司马迁

## 单选：这句史书记录中，“孤竹”是哪里？ {#q.u34.5.3}
考点：skill.u34.ci
语境：p.u34.cia

- [ ] 齐桓公出兵前常住的都城 {#q.u34.5.3.o1}
  理由：“伐山戎”已交代这是出征的情境。
- [ ] 排在山戎后面的第二个对象 {#q.u34.5.3.o2}
  理由：“次于”在行军句中指出驻扎地点，没有列名次。
- [x] 齐军在出征途中驻扎的地点 {#q.u34.5.3.o3}

提示：“伐”给出行动背景，“于”后接什么？
解析：在出兵语境中，“次于孤竹”是说军队停驻于孤竹。

## 原文：教学例句 {#p.u34.cib}
> 使者与从者次于桥北，张幕候水落。越二日，收幕复行。
译文：使者和随员在桥北驻下，撑起帐幕等水退。过了两天，收起帐幕继续赶路。

## 找原文证据：哪一处表明“次于桥北”是一次临时停驻？ {#q.u34.5.4}
考点：skill.u34.ci
语境：p.u34.cib

- [ ] 使者与从者 {#q.u34.5.4.o1}
  理由：这是队伍的身份。
- [x] 收幕复行 {#q.u34.5.4.o2}
- [ ] 桥北 {#q.u34.5.4.o3}
  理由：这是停驻的位置，单凭地名看不出驻留长短。

提示：在驻扎动作之后，找结束驻扎的动作。
解析：帐幕被收起，队伍重新上路，因此“次”不能读作长住不去。

## 知识点：临 {#skill.u34.lin}
义项：靠近并面对
领域：实词
要诀：注意是否仍在岸上、高处或物件的边缘。
讲解：人可以临深渊、临井，亭也可以临水。它标出人与物所在的位置及面对的方向，未必发生下水或越过的动作。
例句：p.u34.lina

## 原文：古籍引文 {#p.u34.lina}
> 《诗》云：“战战兢兢，如临深渊，如履薄冰。”
译文：曾子引《诗》说：谨慎戒惧，好像面对深渊，又好像踩着薄冰。
出处：《论语·泰伯》节录
作者：孔子弟子及再传弟子编纂

## 单选：“如临深渊”让人设想自己身处何处？ {#q.u34.5.5}
考点：skill.u34.lin
语境：p.u34.lina

- [ ] 已跌入深渊，正在水底 {#q.u34.5.5.o1}
  理由：“临”交代面对险处，没有写失足跌入。
- [x] 来到深渊边，正面对险处 {#q.u34.5.5.o2}
- [ ] 已经渡过深渊，回看身后的路 {#q.u34.5.5.o3}
  理由：句中没有穿过和回望的动作。

提示：区分“临深渊”与“坠深渊”。
解析：人尚在边缘，面对深渊所生的谨慎正能解释“战战兢兢”。

## 原文：教学例句 {#p.u34.linb}
> 井在庭中，童临井俯视，见月影，呼其姊共观。
译文：院子中有口井，孩子来到井边俯身观看，见到月影，喊姐姐一起来看。

## 找原文证据：哪一动作最能帮助判定孩子是站在井边看？ {#q.u34.5.6}
考点：skill.u34.lin
语境：p.u34.linb

- [ ] 共观 {#q.u34.5.6.o1}
  理由：这说邀人一同看，未指明视线方向。
- [x] 俯视 {#q.u34.5.6.o2}
- [ ] 呼其姊 {#q.u34.5.6.o3}
  理由：喊姐姐不能说明孩子面对井口的姿势。

提示：找视线由上向下的动作。
解析：向下俯视，和“临井”所写站在井边、面对井口的位置一致。

## 知识点：涉 {#skill.u34.she}
义项：徒步过水，蹚水而过
领域：实词
要诀：找水流、衣履及对岸的线索。
讲解：“涉”用于水路时，可以说靠步行过河。桥可替代涉水，舟也能免去下水步渡；要从语境核实到对岸的办法。
例句：p.u34.shea

## 原文：教学例句 {#p.u34.shea}
> 溪浅无梁，客脱履涉之，至彼岸，乃复著履。
译文：溪水浅，没有桥，旅人脱下鞋涉水过去，到对岸才又穿上鞋。

## 单选：客人用什么办法到达彼岸？ {#q.u34.5.7}
考点：skill.u34.she
语境：p.u34.shea

- [ ] 找到桥，从桥上过去 {#q.u34.5.7.o1}
  理由：开头的“无梁”排除了过桥。
- [x] 脱鞋踏水渡过浅溪 {#q.u34.5.7.o2}
- [ ] 沿溪边步行，始终没有过水 {#q.u34.5.7.o3}
  理由：“至彼岸”说明已经换到另一边。

提示：“无梁”和“脱履”共同限定了渡法。
解析：溪水浅、没有桥，脱鞋以后直接涉溪，到对岸才再穿鞋。

## 原文：古籍引文 {#p.u34.sheb}
> 岁十一月，徒杠成；十二月，舆梁成，民未病涉也。

## 单选：桥修成后，百姓原来哪一种难处得到解决？ {#q.u34.5.8}
考点：skill.u34.she
语境：p.u34.sheb

- [ ] 每月都必须修理车轮 {#q.u34.5.8.o1}
  理由：“舆梁”指可供车辆通行的桥。
- [ ] 站在岸边看不见过路的人 {#q.u34.5.8.o2}
  理由：“杠”“梁”都是过水设施，与视线无关。
- [x] 不得不下水徒步过河 {#q.u34.5.8.o3}

提示：把“病涉”的“涉”当成桥建成前的过水方式。
解析：行人和车辆有桥可过，百姓得免涉水之苦，“病”是受苦、发愁。
