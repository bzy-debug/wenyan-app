# 课文：居、次、临、涉 {#words.5}
简介：渔人住在岸边，过路人只在岸上搭帐等水退。一个“居”、一个“次”，停在同一处也有不同读法。

## 正文

读“居”，不妨看看门和屋。陶工住在城东，有窑有土，客人想买器物就去他家。读“次”，则要看队伍还走不走。使者一行在桥北张幕等水落，两天后收起帐幕再走，这才知道只是途中停驻。

来到水边以后，脚下又有分别。孩子“临井俯视”，仍立在井边，低头便能看见水里的月影。旅客遇上无桥的浅溪，“脱履涉之”，直到对岸才把鞋穿上。“涉”写出了下水走过这一程。

## 知识点：居 {#skill.u34.ju}
义项：居住，住在
领域：实词
要诀：要辨住处，可以找家门、院落和家人的日常起居。
讲解：“陶者居邑东”说陶工住在城东。门前堆土，屋后有窑，买陶器的客人一早就能去他家找人。
例句：p.u34.jua

## 原文：教学例句 {#p.u34.jua}
> 陶者居邑东，门前积土，屋后有窑。客欲买器，晨往其家。
译文：陶工住在城东，门前堆着泥土，屋后有窑。旅客想买陶器，早晨到他家去。

## 单选：客人要买陶器，“居邑东”告诉他该上哪儿找人？ {#q.u34.5.1}
考点：skill.u34.ju
语境：p.u34.jua

- [ ] 陶工早晨出发去城东卖器 {#q.u34.5.1.o1}
  理由：早晨出发的是客人。
- [x] 陶工家在城东 {#q.u34.5.1.o2}
- [ ] 陶工只管城东的陶器买卖 {#q.u34.5.1.o3}
  理由：“居”交代住处，没有说经营范围。

提示：“其家”应与前面哪个处所相连？
解析：陶工家在城东。前文写住家的门、屋和窑，客人一早就“往其家”。

## 原文：教学例句 {#p.u34.jub}
> 妪与女居山下，春种豆，秋收栗。女嫁，妪犹居故屋。
译文：老妇与女儿住在山下，春天种豆，秋天收栗。女儿出嫁后，老妇仍住在老屋里。

## 找原文证据：哪句说明女儿离去后，母亲的住处没有变？ {#q.u34.5.2}
考点：skill.u34.ju
语境：p.u34.jub

- [x] 妪犹居故屋 {#q.u34.5.2.o1}
- [ ] 春种豆 {#q.u34.5.2.o2}
  理由：母女还同住时春天种豆。要找的是女儿出嫁以后母亲的住处。
- [ ] 女嫁 {#q.u34.5.2.o3}
  理由：这写女儿生活的变化。

提示：找“仍然”与老屋同时出现的地方。
解析：女儿出嫁，老妇却“犹居故屋”。“犹”说的就是仍旧住在那里。

## 知识点：次 {#skill.u34.ci}
义项：行进的队伍停驻、驻扎
领域：实词
要诀：行军或出使途中“次于”某处，注意何时驻下、何时再走。
讲解：“齐桓公伐山戎，次于孤竹。”征讨是整个行程，孤竹是军队途中停驻的地方。“次”在这里是一个动作。
例句：p.u34.cia

译文：齐桓公出兵攻打山戎，军队在孤竹驻扎。

## 单选：齐军出兵，“次于孤竹”说孤竹是什么地方？ {#q.u34.5.3}
考点：skill.u34.ci
语境：p.u34.cia

- [ ] 齐桓公出兵前常住的都城 {#q.u34.5.3.o1}
  理由：“伐山戎”已交代这是出征的情境。
- [ ] 排在山戎后面的第二个对象 {#q.u34.5.3.o2}
  理由：“次于”在行军句中指出驻扎地点，没有列名次。
- [x] 齐军在出征途中驻扎的地点 {#q.u34.5.3.o3}

提示：“伐”给出行动背景，“于”后接什么？
解析：“伐山戎”交代出征，“次于孤竹”记行军途中停在哪里。

## 原文：教学例句 {#p.u34.cib}
> 使者与从者次于桥北，张幕候水落。越二日，收幕复行。
译文：使者和随员在桥北驻下，撑起帐幕等水退。过了两天，收起帐幕继续赶路。

## 找原文证据：哪几个字说明使者一行没在桥北长住？ {#q.u34.5.4}
考点：skill.u34.ci
语境：p.u34.cib

- [ ] 使者与从者 {#q.u34.5.4.o1}
  理由：这告诉你谁停在桥北。等了两天以后，他们留在那里了吗？
- [x] 收幕复行 {#q.u34.5.4.o2}
- [ ] 桥北 {#q.u34.5.4.o3}
  理由：这是停驻的位置，单凭地名看不出驻留长短。

提示：在驻扎动作之后，找结束驻扎的动作。
解析：他们张起帐幕等水退，两天以后收起帐幕继续赶路。桥北是临时驻地。

## 知识点：临 {#skill.u34.lin}
义项：靠近并面对
领域：实词
要诀：临井、临渊，人站在边上便能往下看。
讲解：“战战兢兢”连用两个比喻：站在深渊边，踏在薄冰上。“临”写身处深渊边缘，这样才说得通为什么要如此小心。
例句：p.u34.lina

## 原文：古籍引文 {#p.u34.lina}
> 《诗》云：“战战兢兢，如临深渊，如履薄冰。”
译文：曾子引《诗》说：谨慎戒惧，好像面对深渊，又好像踩着薄冰。
出处：《论语·泰伯》节录
作者：孔子弟子及再传弟子编纂

## 单选：“如临深渊”让人设想自己身处何处？ {#q.u34.5.5}
考点：skill.u34.lin
语境：p.u34.lina

- [ ] 已跌入深渊，正在水底 {#q.u34.5.5.o1}
  理由：“临”交代面对险处，没有写失足跌入。
- [x] 来到深渊边，正面对险处 {#q.u34.5.5.o2}
- [ ] 已经渡过深渊，回看身后的路 {#q.u34.5.5.o3}
  理由：句中没有穿过和回望的动作。

提示：留意“临”的人还在岸上，这个比喻为什么让人“战战兢兢”？
解析：人来到深渊边，向下便是险处。站在那里小心翼翼，正能解释“战战兢兢”。

## 原文：教学例句 {#p.u34.linb}
> 井在庭中，童临井俯视，见月影，呼其姊共观。
译文：院子中有口井，孩子来到井边俯身观看，见到月影，喊姐姐一起来看。

## 找原文证据：孩子站在井边，是从哪个动作看出来的？ {#q.u34.5.6}
考点：skill.u34.lin
语境：p.u34.linb

- [ ] 共观 {#q.u34.5.6.o1}
  理由：这说邀人一同看，未指明视线方向。
- [x] 俯视 {#q.u34.5.6.o2}
- [ ] 呼其姊 {#q.u34.5.6.o3}
  理由：喊姐姐不能说明孩子面对井口的姿势。

提示：找视线由上向下的动作。
解析：“俯视”是低头看。孩子临井俯视，才看见水里的月影。

## 知识点：涉 {#skill.u34.she}
义项：徒步过水，蹚水而过
领域：实词
要诀：留意过河时是否脱鞋、提衣，到了对岸又怎样。
讲解：旅客在这边岸上脱鞋，到“彼岸”才重新穿上。中间的“涉之”，便是踏过浅溪的那段路。
例句：p.u34.shea

## 原文：教学例句 {#p.u34.shea}
> 溪浅无梁，客脱履涉之，至彼岸，乃复著履。
译文：溪水浅，没有桥，旅人脱下鞋涉水过去，到对岸才又穿上鞋。

## 单选：客人用什么办法到达彼岸？ {#q.u34.5.7}
考点：skill.u34.she
语境：p.u34.shea

- [ ] 找到桥，从桥上过去 {#q.u34.5.7.o1}
  理由：开头的“无梁”排除了过桥。
- [x] 脱鞋踏水渡过浅溪 {#q.u34.5.7.o2}
- [ ] 沿溪边步行，始终没有过水 {#q.u34.5.7.o3}
  理由：“至彼岸”说明已经换到另一边。

提示：先看溪上有没有桥，再看客人何时脱鞋、何时穿鞋。
解析：没有桥，客人脱鞋下水，踏过浅溪，到了对岸才把鞋穿上。

## 单选：人行桥和车桥相继修好，百姓以前怎样过河的苦处免掉了？ {#q.u34.5.8}
考点：skill.u34.she
语境：p.u34.sheb

- [ ] 每月都必须修理车轮 {#q.u34.5.8.o1}
  理由：“舆梁”指可供车辆通行的桥。
- [ ] 站在岸边看不见过路的人 {#q.u34.5.8.o2}
  理由：“杠”“梁”都是过水设施，与视线无关。
- [x] 不得不下水徒步过河 {#q.u34.5.8.o3}

提示：把“病涉”的“涉”当成桥建成前的过水方式。
解析：先架起行人可走的小桥，后建成车辆也能过的桥。百姓不必再下水蹚河。
