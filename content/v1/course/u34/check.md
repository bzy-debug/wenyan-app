# 检查：回去见人、涉水过河、进城赴任 {#check.34}

## 原文：古籍引文 {#p.u34.cka}
> 止子路宿，杀鸡为黍而食之，见其二子焉。明日，子路行以告。子曰：“隐者也。”使子路反见之。至，则行矣。
译文：老人留子路过夜，杀鸡做黍饭给他吃，又让两个儿子出来相见。次日，子路离开后把这件事告诉孔子。孔子说那是隐士，叫子路回去见他。子路到了，老人却已经离开。

## 单选：孔子叫子路“反见之”，是叫他回哪儿见谁？ {#q.u34.c1}
考点：skill.u34.fan
语境：p.u34.cka

- [ ] 朝一个此前从未到过的官署前进 {#q.u34.c1.o1}
  理由：此处“反”回指已经走过的一程。
- [x] 回到前一夜留宿的老人那里 {#q.u34.c1.o2}
- [ ] 回到孔子面前，再报告一遍 {#q.u34.c1.o3}
  理由：次日的报告已经发生，新的吩咐是去见老人。

提示：把“行以告”以前的留宿和现在要见的人连起来。
解析：子路才从老人那里回来向孔子报告。孔子听完，叫他回去拜见那位留他住宿的老人。

## 单选：“至，则行矣”中的两个动作各是谁的？ {#q.u34.c2}
考点：skill.u34.zhi
语境：p.u34.cka

- [x] 子路到了，老人已经走了 {#q.u34.c2.o1}
- [ ] 老人到了，子路随后离开 {#q.u34.c2.o2}
  理由：受命回访的是子路，等候被访的是老人。
- [ ] 子路到了，孔子已经离开 {#q.u34.c2.o3}
  理由：子路要见的“之”是刚被称作隐者的人。

提示：孔子派去的是谁？他想见的又是谁？两人各有一个动作。
解析：到了的是子路，已经走了的是那位老人。换过主语，就能明白为什么子路没见到他。

## 原文：教学例句 {#p.u34.ckb}
> 里人问渡于渔者。渔者曰：“吾居西岸，知石梁昨圮。上流有浅滩，可褰裳涉也。”
译文：乡人向渔人打听过水的办法。渔人说：我住在西岸，知道石桥昨天塌了。上游有浅滩，可以提起衣裳蹚过去。

## 单选：渔人为什么先向问路的人说“吾居西岸”？ {#q.u34.c3}
考点：skill.u34.ju
语境：p.u34.ckb

- [x] 他平日住在当地，知道桥的近况 {#q.u34.c3.o1}
- [ ] 他刚从上游涉水而来 {#q.u34.c3.o2}
  理由：他告诉别人可去上游，并未报告自己刚走的路。
- [ ] 他在此临时驻军 {#q.u34.c3.o3}
  理由：人物是渔者，文中也没有队伍行程。

提示：把“居”的处所与“知”后面的消息连读。
解析：渔人住在西岸，知道石桥昨天刚塌。他所说的桥况出自本地人的见闻。

## 找原文证据：哪句话写出了渔人建议的过水办法？选出原文。 {#q.u34.c4}
考点：skill.u34.she
语境：p.u34.ckb

- [ ] 上流有浅滩 {#q.u34.c4.o1}
  理由：浅滩交代可涉的位置，尚未写人的动作。
- [ ] 石梁昨圮 {#q.u34.c4.o2}
  理由：这说明原来过桥的路线失效。
- [x] 可褰裳涉也 {#q.u34.c4.o3}

提示：寻找既写衣裳处理、又写渡法的词句。
解析：提起衣裳，走浅滩蹚过去，这是渔人给乡人的办法。

## 原文：教学例句 {#p.u34.ckc}
> 士居乡，郡辟为功曹，乃出。至郡门，阍者问其名，验辟书而内之。
译文：士人住在乡里，郡府征召他担任功曹，他于是出仕。到了郡府门口，守门人问了姓名，核验征聘文书，让他进门。

## 单选：“士居乡”而后“乃出”，他现在要去做什么？ {#q.u34.c5}
考点：skill.u34.chu
语境：p.u34.ckc

- [ ] 从门内的吏员变成受命离任的人 {#q.u34.c5.o1}
  理由：“郡辟为功曹”是征召任职，方向相反。
- [x] 从在乡居住的士人转为应聘到郡府任职的人 {#q.u34.c5.o2}
- [ ] 从守门的阍者变成受检的来客 {#q.u34.c5.o3}
  理由：阍者在后半段另外出场，并非同一个人。

提示：先读“出”以前的征召，再看他随身的文书。
解析：郡里征召他为功曹，他就由乡里出发去任职。后面在郡门查验的也正是征召文书。

## 单选：查过聘书后，郡门前是谁让谁进去？ {#q.u34.c6}
考点：skill.u34.na
语境：p.u34.ckc

- [x] 守门人核过聘书，让这位士人进入 {#q.u34.c6.o1}
- [ ] 士人核验守门人的文书，允许他进门 {#q.u34.c6.o2}
  理由：“阍者问其名”已经点明门口是谁在查验。
- [ ] 守门人把文书收进屋里，让士人继续在门外等 {#q.u34.c6.o3}
  理由：“内之”承接前来的这位士人，文书是“验”的对象。

提示：试把“之”换成那个已经到郡门的人。
解析：守门人查验聘书，放持书的士人进去。“内之”的“内”读 nà，是准他入门。
