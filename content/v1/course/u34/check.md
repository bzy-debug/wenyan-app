# 检查：赠答、夜舟与梦中人 {#check.34}

## 原文：古籍引文 {#verse.p.quince}
> 投我以木瓜，报之以琼琚。匪报也，永以为好也！
> 投我以木桃，报之以琼瑶。匪报也，永以为好也！
> 投我以木李，报之以琼玖。匪报也，永以为好也！
译文：你赠我木瓜，我拿美玉答你。岂是为了还清人情？是想长久相好。又唱到木桃与美玉、木李与美玉，盼长久交好的心愿一遍遍唱出来。
词注：投：赠给。
  琼琚：美玉。
  匪：非。
出处：《诗经·卫风·木瓜》，全篇
作者：佚名

## 原文：古籍引文 {#verse.p.boat}
> 细草微风岸，危樯独夜舟。
> 星垂平野阔，月涌大江流。
> 名岂文章著，官因老病休。
> 飘飘何所似，天地一沙鸥。
译文：微风吹着岸边细草，高桅下是我夜泊的孤舟。低垂的星光映出平野的辽阔，月影随奔流的大江涌动。难道声名来自文章？做官又因年老多病而休。这样漂泊像什么？像天地间一只沙鸥。
词注：危樯：高高的桅杆。
  著：显著，这里说声名显扬。
  休：停止，这里说离职。
出处：《旅夜书怀》，全篇
作者：杜甫

## 原文：古籍引文 {#verse.p.dream}
> 十年生死两茫茫。不思量。自难忘。
> 千里孤坟，无处话凄凉。纵使相逢应不识，尘满面，鬓如霜。
> 夜来幽梦忽还乡。小轩窗。正梳妆。
> 相顾无言，惟有泪千行。
> 料得年年断肠处，明月夜，短松冈。
译文：生死相隔十年，不刻意思念也忘不掉。孤坟远在千里，没法把凄凉告诉她。即使相逢，想来她也不认得如今满面风尘、两鬓如霜的我。夜里忽然梦见回乡，她正在小窗边梳妆。两人相对落泪，无话可说。想那月明之夜、短松的山冈，年年总叫人断肠。
词注：纵使：即便。
  轩窗：窗。
  料得：想来。
出处：《江城子·十年生死两茫茫》，全篇

## 单选：要是把三章并排抄下，哪一句三次都留在原处，最能说明回赠美玉之人的心愿？ {#verse.check.q1}
考点：verse.s.stanza
语境：verse.p.quince

- [ ] 投我以木瓜
  理由：到了后两章，果子换成了木桃、木李。
- [x] 永以为好也
- [ ] 报之以琼瑶
  理由：美玉的名字随章而换，这一句只在第二章出现。

提示：先找哪一处押在每章结尾。
解析：果子换了，美玉的名字也换了。总在结尾唱出的，是对长久交好的期盼。

## 单选：读到“投我以木桃，报之以琼瑶”，请给两件礼物各找一个去向。 {#verse.check.q2}
考点：verse.s.address
语境：verse.p.quince

- [ ] 我先赠桃给对方，又追加一块玉
  理由：“投我”把“我”放在受赠的一方。
- [ ] 对方先赠玉给我，我才用桃作答
  理由：“报”在第二句，玉才是这一次答赠的礼。
- [x] 对方把桃赠我，我把玉回赠对方

提示：把“我”和承接前句的“之”分配给两位赠答者。
解析：前一句让我收桃，后一句便由我还玉。“匪报也”再补一层，回赠还有愿长久相好的用意。

## 单选：“星垂平野阔，月涌大江流。”把两句合看，哪幅夜景同两句都对得上？ {#verse.check.q3}
考点：verse.s.pair
语境：verse.p.boat

- [x] 星光下是辽阔的原野，月影与流动的大江相接
- [ ] 先在原野等星落，第二天才到江边等月出
  理由：两句同写夜舟周围，诗中没有隔日换地。
- [ ] 星月都映在岸边的细草上，看不见水面
  理由：第二句点明“大江流”，视线已经伸得很远。

提示：分别给星和月找下面与它相连的地面或水面。
解析：“星”“月”相对，“平野”“大江”相对。一联把岸上的广阔与江上的涌动一并写出。

## 找原文证据：哪一句告诉你，结尾的沙鸥是在回答诗人关于自身处境的问题？ {#verse.check.q4}
考点：verse.s.feeling
语境：verse.p.boat

- [ ] 星垂平野阔
  理由：这里写的是舟外夜景，尚未提出比拟。
- [ ] 官因老病休
  理由：这是关于身世的一句，尚未问拿什么来作比。
- [x] 飘飘何所似

提示：找诗人问“像什么”的地方。
解析：“何所似”先问，下一句“一沙鸥”作答。于是孤单漂泊的既是鸥，也有作诗的人。

## 找原文证据：哪几个字标出了从“纵使相逢”的假想，转入夜里的梦？ {#verse.check.q5}
考点：verse.s.imagined
语境：verse.p.dream

- [x] 夜来幽梦忽还乡
- [ ] 千里孤坟
  理由：这是生死相隔的现实。
- [ ] 纵使相逢应不识
  理由：这里还在假设见面之后会怎样。

提示：看看“忽”前面写着什么。
解析：“纵使”是假设，“幽梦”才领起窗前梳妆、相顾流泪的一幕。

## 单选：“小轩窗。正梳妆。相顾无言”写的是怎样一次相见？ {#verse.check.q6}
考点：verse.s.view
语境：verse.p.dream

- [ ] 词中人到了千里外的坟前，亲眼看见她梳妆
  理由：“孤坟”在梦前；梳妆跟在“幽梦”之后。
- [x] 词中人梦见归家，看见她梳妆，两人相对
- [ ] 她写信告知正在梳妆，词中人于远处读信
  理由：“相顾”写梦里彼此望着，没有书信往还。

提示：先看是谁“还乡”，再看“相顾”有几个人。
解析：梦中的他回到她的窗前，“相顾”让两人都在场。醒时隔着生死，才使这次相见尤为难得。
