# 课文：及、如、至、归 {#words.4}
简介：用动作前后的位置，区分追上、前往、到达和返回。

## 正文

给一段行程画两个记号：动身时人在哪里，动作结束时人又在哪里。“追”只写朝某人赶去，“及”才说明已经赶上。史书说“景公如晋”，紧跟着是和晋君盟誓，目的地是晋国。“如”写前往，“至”把镜头放到抵达的一刻。

“归”还多给了一条信息：这趟路通向原来的家园或归处。曾点谈理想的一天，先写在外游乐，再说“咏而归”，读时还要留意人物是在言志，还是在报告已经发生的行程。

## 知识点：及 {#skill.u34.ji}
义项：赶上，追到
领域：实词
要诀：区分“在追”和“已经追上”。
讲解：前人先行，后人追赶。“追及”里的“及”交代追赶所得的结果。也可以说“弗及”，明说没有赶上。
例句：p.u34.jia

## 原文：古籍引文 {#p.u34.jia}
> 项王至阴陵，迷失道，问一田父。田父绐曰：“左。”左，乃陷大泽中。以故汉追及之。
译文：项羽到阴陵迷了路，向一位农人打听。农人骗他说往左。项羽向左前进，陷入大泽，汉军因而追上了他。绐，欺骗。
出处：《史记·项羽本纪》节录

## 单选：汉军在段末处于哪一步？ {#q.u34.4.1}
考点：skill.u34.ji
语境：p.u34.jia

- [ ] 发现项王出走，刚开始寻找 {#q.u34.4.1.o1}
  理由：此段叙述的是项王迷路以后，汉军“追及”的结果。
- [x] 已经赶上了陷在大泽的项王 {#q.u34.4.1.o2}
- [ ] 赶在项王前面进入阴陵 {#q.u34.4.1.o3}
  理由：先到阴陵并问路的是项王。

提示：把“追”和“及”分别换成一个现代动词。
解析：“追”写追赶，“及之”才写追到了项王。

## 原文：教学例句 {#p.u34.jib}
> 弟行在前，兄负米追之。行十里，犹弗及。
译文：弟弟走在前面，哥哥背着米追他。走了十里，还没有赶上。

## 找原文证据：哪几个字说明兄弟间的距离还没有消除？ {#q.u34.4.2}
考点：skill.u34.ji
语境：p.u34.jib

- [x] 犹弗及 {#q.u34.4.2.o1}
- [ ] 弟行在前 {#q.u34.4.2.o2}
  理由：这是出发时两个人的位置。
- [ ] 兄负米追之 {#q.u34.4.2.o3}
  理由：这是哥哥采取的行动，尚未交代结果。

提示：找“走了十里”以后的否定。
解析：“犹”是仍然，“弗及”是没有追上；追了相当远，兄弟还未会合。

## 知识点：如 {#skill.u34.ru}
义项：前往某地
领域：实词
要诀：看“如”后是否是目的地，以及此行去做什么。
讲解：人物作主语、地名承接“如”时，可先试读作“到……去”。若后文写在那里会盟、办事，这一读法能把动作串起来。
例句：p.u34.rua

## 原文：古籍引文 {#p.u34.rua}
> 二十七年，景公如晋，与平公盟，已而背之。
译文：二十七年，秦景公前往晋国，与晋平公结盟，不久又背弃了盟约。

## 单选：“景公如晋”怎样接到下一句？ {#q.u34.4.3}
考点：skill.u34.ru
语境：p.u34.rua

- [ ] 假如景公与晋结盟，就会被人背弃 {#q.u34.4.3.o1}
  理由：“二十七年”引出实事，“已而”继续记后事。
- [ ] 景公像晋君一样，随后与自己结盟 {#q.u34.4.3.o2}
  理由：“晋”是这次外交行程的目的地，平公是会面的人。
- [x] 景公到了晋国，和晋平公结盟 {#q.u34.4.3.o3}

提示：留意“如”的主语是人，后面紧接国名。
解析：从出行到会盟是一条连续的叙事，“如”在这里写往晋。

## 原文：教学例句 {#p.u34.rub}
> 邑人如县，持牒请粟。日暮，始得见令。
译文：乡人前往县衙，拿着文书请求发放粮食。到傍晚才见到县令。

## 单选：乡人拿着文书，先往哪里去？ {#q.u34.4.4}
考点：skill.u34.ru
语境：p.u34.rub

- [ ] 县令的故乡 {#q.u34.4.4.o1}
  理由：“如”只接“县”，没有写县令的家乡。
- [x] 县衙 {#q.u34.4.4.o2}
- [ ] 已经开仓的粮库 {#q.u34.4.4.o3}
  理由：请粮是出行的目的，还未写官府开仓。

提示：分开“如”后面的地方和“请”后面的东西。
解析：“如县”给出地点，“请粟”说明要办的事。

## 知识点：至 {#skill.u34.zhi}
义项：到达，抵达
领域：实词
要诀：观察动作在哪个地点已经完成。
讲解：“欲至”只是打算，“未至”还在路上。地点跟在“至”后时，借后续能在当地做的事判断是否真的到达。
例句：p.u34.zhia

## 原文：古籍引文 {#p.u34.zhia}
> 秦军走，晋兵追之，遂渡泾，至棫林而还。
译文：秦军退走，晋兵追赶，随后渡过泾水，到棫林才折返。棫林是地名。

## 单选：晋兵在哪里结束去程并折返？ {#q.u34.4.5}
考点：skill.u34.zhi
语境：p.u34.zhia

- [ ] 秦军原来驻守的营地 {#q.u34.4.5.o1}
  理由：文中交代了追兵到达的地名，没有交代秦营位置。
- [x] 棫林 {#q.u34.4.5.o2}
- [ ] 泾水的原岸 {#q.u34.4.5.o3}
  理由：渡过泾水之后，文中还接着写“至棫林”。

提示：“而还”之前，哪个动词带出了最远到过的地方？
解析：“至棫林”把去程的最远点钉在棫林，渡泾只是途中的一步。

## 原文：教学例句 {#p.u34.zhib}
> 使者未至，宾候于亭。及暮，使者至，乃授书于宾。
译文：使者还没到，客人在亭中等候。到了傍晚，使者抵达，才把书信交给客人。

## 找原文证据：哪一处行动只有等到使者与客人同处一地才发生？ {#q.u34.4.6}
考点：skill.u34.zhi
语境：p.u34.zhib

- [ ] 使者未至 {#q.u34.4.6.o1}
  理由：此时两人尚未见面。
- [ ] 宾候于亭 {#q.u34.4.6.o2}
  理由：独自在亭中等候并不能证明来者已到。
- [x] 乃授书于宾 {#q.u34.4.6.o3}

提示：先问是候人还是交付物件。
解析：“乃授书”承接第二个“至”，用当面交信证实使者已经到达。

## 知识点：归 {#skill.u34.gui}
义项：回到自己的归处
领域：实词
要诀：问行路人结束在外的活动后要回哪里。
讲解：“归”可以单独用。即使未点出家门，也能由在外的行程判断它表示回去；具体归宿须由原文决定。
例句：p.u34.guia

## 原文：古籍引文 {#p.u34.guia}
> 莫春者，春服既成，冠者五六人，童子六七人，浴乎沂，风乎舞雩，咏而归。
译文：曾点说，暮春时，春衣已经备好，和五六位成人、六七个少年在沂水沐浴，到舞雩台吹风，唱着歌回来。这是他所描述的心愿。

## 单选：曾点设想的游程，以什么动作收尾？ {#q.u34.4.7}
考点：skill.u34.gui
语境：p.u34.guia

- [ ] 一行人刚出门去找舞雩台 {#q.u34.4.7.o1}
  理由：“风乎舞雩”已经把设想中的行程写到那里。
- [x] 一行人唱着歌踏上归途 {#q.u34.4.7.o2}
- [ ] 少年们留在沂水边等大人回来 {#q.u34.4.7.o3}
  理由：“咏而归”未另换行动者。

提示：把“浴”“风”“咏而归”按先后串起。
解析：从沂水、舞雩写到歌咏而返；原文没有进一步指明沿哪条路回去。

> 樵者晨出，暮负薪归。子闻履声，启户迎之。
译文：砍柴者早上出门，傍晚背着柴回来。孩子听见脚步声，开门迎他。

## 找原文证据：哪一处最能确认“归”的落点是家门？ {#q.u34.4.8}
考点：skill.u34.gui
语境：p.u34.guib

- [x] 启户迎之 {#q.u34.4.8.o2}
- [ ] 暮负薪 {#q.u34.4.8.o3}
