# 课文：两章里换了哪几个字 {#verse.1}
简介：读两章《硕鼠》，看看谁在说要走。同样一句心事，唱第二遍时会换个什么说法？
## 正文
读《硕鼠》，不妨由两个短句开始：“无食我黍”“无食我麦”。黍换成麦，那个有粮食被吃、开口说“我”的人却从头都在。等读到“逝将去女”，便容易分清谁要离开谁。这里的“女”读作 rǔ，称对方为“你”。

到了《蒹葭》，试把“道阻且长”和“道阻且跻”并排读。后一章用陡峭换掉了路长，所念的人依旧难以接近。把换掉的字和留下的心事都读出来，一首诗才不会被念成几段互不相干的见闻。

## 知识点：重章中换掉的字 {#verse.s.stanza}
义项：对读同一位置，辨出歌里哪些事物或感受有了变化
领域：篇章
要诀：在第二章找到第一章那句话的位置。
讲解：先看换字，再回头找反复唱的那一句。有时换的是眼前的庄稼，有时是等待的人心里的长短。
例句：verse.p.rat

## 知识点：诗里谁在说话，谁被说到 {#verse.s.address}
义项：从人称和动作辨认说话者、听话者或诗里提到的人
领域：篇章
要诀：先找“我”的东西，再看是谁做后面的动作。
讲解：诗里喊到的名字可能是听话的一方。试给两个人各配一个动作，顺着唱词看看是否说得通。
例句：verse.p.reed

## 原文：古籍引文 {#verse.p.rat}
> 硕鼠硕鼠，无食我黍！三岁贯女，莫我肯顾。逝将去女，适彼乐土。乐土乐土，爰得我所。
> 硕鼠硕鼠，无食我麦！三岁贯女，莫我肯德。逝将去女，适彼乐国。乐国乐国，爰得我直。
译文：大鼠，大鼠，别吃我的黍！我奉养你多年，你却不肯顾念我。我将离开你，去那片乐土，在那里得到安身之处。第二章喊的是别吃我的麦，怨的是你不肯施恩，盼的仍是有个好去处。
词注：女：读 rǔ，称对方为“你”。
  适：前往。
  德：这里是施恩。

## 原文：古籍引文 {#verse.p.ge}
> 彼采葛兮，一日不见，如三月兮！
> 彼采萧兮，一日不见，如三秋兮！
> 彼采艾兮！一日不见，如三岁兮！
译文：那人采葛，一天不见，仿佛过了三个月。那人采萧，一天不见，仿佛隔了三秋。那人采艾，一天不见，仿佛过了三年。
词注：彼：那人。
  如：好像。
  三秋：有九个月、三年两种常见解释，都是说这一日长得难熬。
出处：《诗经·王风·采葛》，全篇

## 原文：古籍引文 {#verse.p.reed}
> 蒹葭苍苍，白露为霜。所谓伊人，在水一方。溯洄从之，道阻且长。溯游从之，宛在水中央。
> 蒹葭萋萋，白露未晞。所谓伊人，在水之湄。溯洄从之，道阻且跻。溯游从之，宛在水中坻。
译文：芦苇茂盛，白露成霜。心里惦念的那个人在水的另一边。我沿着水路追寻，路又险又长，顺水寻去，那人仿佛在水中央。下一章露还未干，岸边依旧难到，路又险又陡，所念的人仿佛在水中的小洲上。
词注：伊人：那个人。
  晞：干。
  跻：升高，这里写路陡。
  宛：仿佛。

## 单选：第二章把“黍”换成“麦”。随着这个换字，诗里哪件事变了？ {#verse.1.q1}
考点：verse.s.stanza
语境：verse.p.rat

- [ ] 说话的人已经搬到了另一个国家
  理由：两章都用“将”，去乐土还是打算。
- [x] 被吃的是哪一种庄稼
- [ ] 被称为“女”的换了一个人
  理由：两章开头都在唤“硕鼠”。

提示：把两句“无食我……”接起来读。
解析：庄稼可以从黍数到麦。“我”反复提出同一个要求，可见怨由一直未解。

## 单选：“逝将去女，适彼乐土。”谁要离开？ {#verse.1.q2}
考点：verse.s.address
语境：verse.p.rat

- [ ] 说话者要把大鼠赶到乐土
  理由：若是赶它走，做“适彼乐土”这件事的就换了人。
- [ ] “女”已先去乐土，回头邀请说话者
  理由：原句没有邀请，“去女”也只是说离开你。
- [x] 说“我”的一方要离开“女”，去乐土

提示：沿着“我黍”的“我”，往后找他的打算。
解析：“女”接在“去”后面，是他要离开的对象。下一句还是他自己打算前往乐土。

## 找原文证据：哪几个字最直接写出说话者觉得自己的付出没有得到照应？ {#verse.1.q3}
考点：verse.s.address
语境：verse.p.rat

- [x] 莫我肯顾
- [ ] 适彼乐土
  理由：这是他打算去的地方。
- [ ] 爰得我所
  理由：这是他盼望的安身之处。

提示：找一句仍在当面埋怨对方的话。
解析：“莫我肯顾”说对方不肯顾念自己。“我”虽在“顾”前面，却是等着被顾念的一方。

## 单选：从“三月”唱到“三岁”，诗中始终只过了多久没见面？ {#verse.1.q4}
考点：verse.s.stanza
语境：verse.p.ge

- [ ] 三年
  理由：“三岁”前面还有个“如”。
- [ ] 从采葛的春天到采艾的秋天
  理由：诗没有交代两次采集的实际日期。
- [x] 一天

提示：看三章都留下了哪四个字。
解析：“一日不见”始终没换。几章反复唱的是思念的日子有多难熬。

## 单选：若让说话的人接一句白话，哪句紧接着“一日不见，如三岁兮”？ {#verse.1.q5}
考点：verse.s.address
语境：verse.p.ge

- [x] 我才一天没见着那个人，就觉得好久了
- [ ] 我采了三年艾草，才遇上那个人
  理由：“彼”指采艾的那个人，诗里也没写相遇。
- [ ] 我要告诉采艾的人我们分别满三年了
  理由：“如”写感觉，不能据此约定离别日期。

提示：分开看“彼”是谁，“不见”是谁的感受。
解析：前半句指着采艾的人，后半句说出惦念那个人的心情。

## 单选：“道阻且长”到下一章成了“道阻且跻”。路难走的原因怎样变了？ {#verse.1.q6}
考点：verse.s.stanza
语境：verse.p.reed

- [ ] 先说草深，后说露重
  理由：草和露都在开头景句里，这两句说的是路。
- [x] 先说路长，后说路陡
- [ ] 先说路难走，后来终于走通了
  理由：第二章仍然说“道阻”。

提示：先保留两章共有的“道阻”，再看末字。
解析：“跻”有升高之意。换一个字，难处有了另一副模样，追寻的心情仍然贯穿两章。

## 找原文证据：循水追寻的是谁？选出诗里指那个人的词。 {#verse.1.q7}
考点：verse.s.address
语境：verse.p.reed

- [ ] 白露为霜
  理由：这是追寻时的景物。
- [ ] 水中坻
  理由：这是说那人仿佛所在的地方。
- [x] 伊人
  第几处：1

提示：找“从之”的“之”可以替回去的称呼。
解析：“所谓伊人”先点出思念的那个人，后面的“从之”才有了要追寻的对象。

## 单选：两章写的位置稍有不同。凭这两章，哪件事还不能确定？ {#verse.1.q8}
考点：verse.s.stanza
语境：verse.p.reed

- [x] 追寻的人是否已经和对方会合
- [ ] 路上有让人难行的地方
  理由：“道阻”在两章都出现了。
- [ ] 对方看起来隔着水
  理由：“在水一方”“宛在水中坻”都能读到这一层。

提示：留意两处“宛在”的口气。
解析：从“水中央”到“水中坻”，眼前的形象换了。两处都说“宛”，还不足以断定终于追到了人。
