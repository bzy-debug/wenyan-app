# 课文：离别时，谁看见了远方 {#verse.3}
简介：人还站在长亭，词里已经有了明晨的风。读一句“念”、一句“何时”，分清眼前的相聚和心里想到的人。
## 正文
柳永写两个人“执手相看泪眼”，转眼又写“今宵酒醒何处”。船还在催着开，这一个夜晚从哪里来？前面有个“念”字。词里的人能从长亭想到别后，读者也可以凭这个字跟过去。

杜甫写《月夜》，开头把眼光放在鄜州的妻子身上，后来才问何时能一同倚窗。读到远处的人，可以先问谁在想他，再问这次相见是已经发生，还是仍被盼望着。

## 知识点：从设想或愿望辨别时间 {#verse.s.imagined}
义项：凭领起设想、询问或祝愿的词区分当时与未至之事
领域：篇章
要诀：找“念”“何时”“但愿”这些把话引向另一时刻的词。
讲解：说得很真切，也可能是临别时在心里先走了一程。看看前面有什么词管到了这幅景象。
例句：verse.p.rain

## 知识点：看景的人与想象这幅景的人 {#verse.s.view}
义项：辨别远处场景落在谁眼中、由谁在此处想起
领域：篇章
要诀：两人是面对面吗？沿着“遥”“共”看各自的位置。
讲解：有人在自己眼前，有人是说话者从远方想见的。读清眼光是从哪里望过去的，就能读懂分离时的相顾。
例句：verse.p.moon

## 原文：古籍引文 {#verse.p.rain}
> 寒蝉凄切。对长亭晚，骤雨初歇。
> 都门帐饮无绪，留恋处、兰舟催发。执手相看泪眼，竟无语凝噎。
> 念去去、千里烟波，暮霭沈沈楚天阔。
> 多情自古伤离别。更那堪、冷落清秋节。
> 今宵酒醒何处，杨柳岸、晓风残月。
> 此去经年，应是良辰、好景虚设。便纵有、千种风情，更与何人说。
译文：傍晚骤雨初停，长亭边寒蝉声切。京城门外举杯无心饮，船却催着启程。两人执手带泪相看，说不出话。想到越去越远，是烟波暮霭里的辽阔楚天。自古多情难舍离别，更何况在冷清秋日。想来今宵酒醒，只见杨柳岸的晓风残月。此后即使有好景和许多情意，又向谁诉说？
词注：无绪：心里纷乱，提不起兴致。
  去去：一程接着一程远去。
  经年：经过长久的时日。
出处：《雨霖铃·寒蝉凄切》，全篇
作者：柳永

## 原文：古籍引文 {#verse.p.moon}
> 今夜鄜州月，闺中只独看。
> 遥怜小儿女，未解忆长安。
> 香雾云鬟湿，清辉玉臂寒。
> 何时倚虚幌，双照泪痕干。
译文：今夜鄜州的月亮，妻子在闺中独自望着。我从远处惦念孩子们，他们还不懂此时忆念长安的心情。想来雾湿云鬓，月光照得手臂生凉。何时才能一同靠着窗帷，让月照着两人，直到泪痕干去？
词注：鄜州：读 fū zhōu，诗中家人所在之地，杜甫此时人在长安。
  未解：还不懂得。
  虚幌：薄而透光的窗帷。
出处：《月夜》，全篇

## 原文：古籍引文 {#verse.p.wish}
> 明月几时有，把酒问青天。不知天上宫阙，今夕是何年。
> 我欲乘风归去，又恐琼楼玉宇，高处不胜寒。起舞弄清影，何似在人间。
> 转朱阁，低绮户，照无眠。
> 不应有恨，何事长向别时圆。人有悲欢离合，月有阴晴圆缺，此事古难全。
> 但愿人长久，千里共婵娟。
译文：我持杯向青天问明月与天上的岁时。想乘风归去，又担心高处难耐寒意，便起舞同自己的清影作伴。月光过楼阁、临窗户、照着难以入眠的人。为什么偏在人分别时最圆？人有离合，月有圆缺，自古难以周全。愿人长久，即使远隔千里，还能同赏这轮月。
词注：胜：经受得住。
  无眠：不能入睡的人。
  婵娟：这里指美好的月亮。
出处：《水调歌头·明月几时有》，词正文
作者：苏轼

## 单选：长亭边“兰舟催发”。到“今宵酒醒何处”，词中的人已经酒醒了吗？ {#verse.3.q1}
考点：verse.s.imagined
语境：verse.p.rain

- [ ] 已抵达杨柳岸，回忆昨夜的长亭
  理由：从“催发”转入“念去去”，是由此时朝后想。
- [x] 还在临别时，想到酒醒会置身何处
- [ ] 在长亭喝醉刚醒，打听船何时开
  理由：“此去经年”接着往别后想，连杨柳岸也在这层设想里。

提示：回头找领起别后景象的“念”。
解析：人在临别处先想到离舟上的夜与清晨，因此读来仿佛亲见，时间却已向前推了一步。

## 找原文证据：哪几个字说明两个人此时还面对面，可以直接看见彼此？ {#verse.3.q2}
考点：verse.s.view
语境：verse.p.rain

- [ ] 千里烟波
  理由：这是想到离去以后的路。
- [ ] 晓风残月
  理由：这是想象酒醒时的景象。
- [x] 执手相看泪眼

提示：找一个须两个人在场才能完成的动作。
解析：“执手”“相看”都要两人相对，恰与后面的无人诉说相照应。

## 单选：“今夜鄜州月，闺中只独看。”诗先把我们带到谁的眼前？ {#verse.3.q3}
考点：verse.s.view
语境：verse.p.moon

- [x] 远在鄜州、独自望月的妻子
- [ ] 独自在长安看月的小儿女
  理由：孩子在鄜州。“未解”说他们还不懂这番思念。
- [ ] 夫妻俩同倚窗前的那一刻
  理由：“何时”在末尾，眼下还未能同看。

提示：看看“闺中”怎样和后面“遥怜”隔空照应。
解析：诗人从别处想象闺中望月的妻子。先写她，再写自己对家人的牵挂。

## 找原文证据：哪一句最清楚地表明相聚仍是心愿？ {#verse.3.q4}
考点：verse.s.imagined
语境：verse.p.moon

- [ ] 今夜鄜州月
  理由：“今夜”点明此刻，尚未提出相聚的愿望。
- [ ] 清辉玉臂寒
  理由：这是他想象中妻子此刻的情景。
- [x] 何时倚虚幌

提示：找一个等待回答的时间问题。
解析：他问“何时”，随后才写“双照”。从现在的“独看”到两人同看，中间还隔着等待。

## 单选：从“我欲乘风归去”到“又恐琼楼玉宇”，可以确定的是哪件事？ {#verse.3.q5}
考点：verse.s.imagined
语境：verse.p.wish

- [x] 他心里先起飞升的念头，又有所顾虑
- [ ] 他已登上月宫，回来报告那里的冷暖
  理由：“欲”“恐”都在写当时的心念。
- [ ] 他劝另一位客人独自上天
  理由：开头明说“我欲”，是他自己的念头。

提示：“欲”与“恐”放在动身之前还是之后？
解析：想去又怕冷，两个念头相继浮现。接下来的“起舞”才从这番设想回到眼前的动作。

## 单选：“千里共婵娟”中，两个人怎样才算“共”？ {#verse.3.q6}
考点：verse.s.view
语境：verse.p.wish

- [ ] 走完千里，已经在一处赏月
  理由：“但愿”说祝愿，“千里”仍保留了距离。
- [x] 身在两地，仍可同赏一轮明月
- [ ] 一人把见到的月色写信告诉另一人
  理由：词里没有寄信，从开头贯穿到末尾的都是月亮。

提示：把“千里”与“共”一起读，两字都要有着落。
解析：月光可以照到相隔的人。“共”连起的是所望的同一轮月，无须把两人的位置拉到一处。

## 单选：既有“小儿女”，为什么开头还说闺中人“独看”？ {#verse.3.q7}
考点：verse.s.view
语境：verse.p.moon

- [ ] 孩子都已去长安，没留在鄜州
  理由：“未解”说不懂，还写到了孩子们在当地的情状。
- [ ] 她已经约好独自出门，不让孩子看月
  理由：原诗没有约定，也没有写出门。
- [x] 孩子虽在身边，却还不能分担她想念长安的心情

提示：读一遍“未解忆长安”，看它解释了什么。
解析：有孩子在旁，仍少了那个懂她为何望月的人。“独”落在无人分担的相思上。

## 找原文证据：临别的人想到以后连好景也难享，哪几个字把这层意思放到了往后的日子？ {#verse.3.q8}
考点：verse.s.imagined
语境：verse.p.rain

- [x] 此去经年
- [ ] 骤雨初歇
  理由：这是临别时刚停的雨。
- [ ] 执手相看泪眼
  理由：两个人还在眼前。

提示：找同时说出离开和时日的地方。
解析：“此去”从当下起算，“经年”把这一想推向将来。后面的好景是他预想将会遇到的。
