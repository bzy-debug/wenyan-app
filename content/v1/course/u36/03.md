# 课文：风雨过后 {#x36.3}
简介：雨停了，水却未必立刻退；病过一场，嗓音也要慢慢恢复。用“已”和“复”分别记下什么终止、什么回到从前。

## 正文

山雨大作，溪水涨进磨坊。“令”后面虽接着一个结果，这里却没有谁在发号施令。“雨令溪涨”就像今天说“大雨使溪水上涨”。要找的是造成结果的事物。

磨轮一度不能转，是坏了；修好以后“复其用”，才回到原来能磨面的状态。“已”又有不同：“雨未已”可以单独说完，意思是雨还没停。等人收拾工具说要“归”，留心他回的是不是自己的住处。

## 知识点：已 {#x36.s.stop}
义项：停止、不再继续
领域：实词
要诀：把能持续的事和它止住的时候对读，如“雨未已”与“雨止”。
讲解：曾子先说仁是自己要担的责任，再说“死而后已”。“已”独自作谓语，意思是到死才停下，不是指标记时间的“已经”。
例句：x36.p.zeng

## 知识点：复 {#x36.s.restore}
义项：恢复到先前的状态
领域：实词
要诀：依次找原来的样子、中间的损失、后来恢复的情形。
讲解：伶人原能唱，病后失声，后来“声乃复”。他随后能试唱，才证明这里说的是嗓音恢复，而不是又说了一次话。
例句：x36.p.singer

## 知识点：令 {#x36.s.causemake}
义项：使某人或事物发生变化
领域：实词
要诀：若“令”前是涨水或雾气，就看它造成了什么结果。
讲解：“水涨，令磨轮没”中，水位一高，磨轮被淹。“令”接起原因和结果，不必替溪水编出一道命令。
例句：x36.p.mill

## 知识点：归 {#x36.s.home}
义项：回到自己的住处、家乡
领域：实词
要诀：区分离开眼前现场和真正回到家；亲人等在何处常能作证。
讲解：“伶人辞众归，妻问”里，辞别听众还只是动身，“归”把他带回家中，这才换成妻子发问。
例句：x36.p.singer

## 原文：教学例句 {#x36.p.mill}
> 山雨未已，水涨，令磨轮没。明日雨止，水退而轮折。工更其轴，磨始复其用。薄暮，工释具归，家人已候门矣。
译文：山雨没停，水位上涨，使磨轮淹在水里。第二天雨停，水退后见磨轮坏了。工匠换了轮轴，磨才恢复原有的用处。傍晚他放下工具回家，家人已经在门口等他了。
词注：没：读 mò，淹没。
  更：更换。
  释具：放下工具。

## 原文：教学例句 {#x36.p.singer}
> 伶人病后失声，雾气又令其咳。旬日雾散，药效渐见，声乃复。试歌一曲，座客叹赏不已。伶人辞众归，妻问：“今日能歌乎？”
译文：歌者病后失声，雾气又使他咳嗽。十来天后雾散，药效渐显，嗓音才恢复。试唱了一曲，在座的客人赞叹不止。歌者向众人辞别回家，妻子问他今天能唱了吗。
词注：伶人：这里指歌者。
  旬日：约十天。
  叹赏：赞叹欣赏。

## 原文：古籍引文 {#x36.p.zeng}
> 曾子曰：“士不可以不弘毅，任重而道远。仁以为己任，不亦重乎？死而后已，不亦远乎？”
译文：曾子说：“士应当胸怀宽广、意志坚强，肩上的担子重，前面的路又长。以实行仁为自己的责任，担子不重吗？直到死才停止，路不远吗？”
词注：弘毅：胸怀宽广，意志坚强。
  任：担子、责任。

## 单选：曾子讲“任重而道远”。“死而后已”说的是什么到了何时才停止？ {#x36.q.3.1}
考点：x36.s.stop
语境：x36.p.zeng

- [ ] 早已去世的人始终没出发
  理由：这里的“已”若作“已经”，在“而后”后边便少了一个动作。
- [ ] 等别人先放下担子，自己才去接手
  理由：“己任”说的是自己的责任，不以别人的行动作条件。
- [x] 践行仁的责任，要到生命结束才停止

提示：把“仁以为己任”接到“……到何时才停”之前。
解析：“后”前写界限，后面“已”是“止”。这样才接得上先说路远、又反问“不亦远乎”。

## 单选：唱完一曲之前先写“声乃复”。病中的伶人是怎样有了这次试唱？ {#x36.q.3.2}
考点：x36.s.restore
语境：x36.p.singer

- [ ] 他向坐客答复说自己唱不了
  理由：本句主语是“声”，并没有人向坐客回话。
- [x] 失去的嗓音终于恢复
- [ ] 把上一首曲子从头又唱了一遍
  理由：“声乃复”时才重新能出声，真正试唱在后。

提示：把“病后失声”和“试歌一曲”放在变化的两头。
解析：“复”在这里表示嗓音回到能唱的状态；接着试唱是检验恢复的实际结果。

## 单选：水上涨以后，“令磨轮没”。是有人下了命令，还是水势带来了什么结果？ {#x36.q.3.3}
考点：x36.s.causemake
语境：x36.p.mill

- [x] 水位太高，磨轮被淹了
- [ ] 工匠奉令把磨轮埋进水底
  理由：前面起作用的是涨水，工匠第二天才来修理。
- [ ] 磨轮自己下令把山雨止住
  理由：轮是被淹的一方，雨停写在第二天。

提示：“令”之前，真正发生变化的是水位还是谁的命令？
解析：“令”把水涨和磨轮被淹接在一起。非人的水势也能“使”一件事发生。

## 找原文证据：“伶人辞众归”去的是住处。下文里哪个动作把家中的一方接了上来？ {#x36.q.3.4}
考点：x36.s.home
语境：x36.p.singer

- [ ] 试歌一曲
  理由：试唱仍在听众面前，尚未动身回家。
- [ ] 辞众
  理由：告别说明离开听众，还没有说到了哪里、又见到谁。
- [x] 妻问

提示：从座中人读下去，下一位开口的是谁？
解析：歌者与听众分别后回家，开口的人换成了妻子。这里的“归”不能只译作从演唱现场走开。

## 单选：“山雨未已”若译成“山雨还没开始”，与下文哪里不合？ {#x36.q.3.5}
考点：x36.s.stop
语境：x36.p.mill

- [ ] 磨坊有根轴需要更换
  理由：换轴出于损坏；单凭换轴不能判断雨停没停。
- [x] 水已经涨到淹轮，且到第二天雨才止
- [ ] 工匠搁下工具，家人就在等他
  理由：这是修好以后的傍晚，不能说明最初何时开始下雨。

提示：同一场雨，前面“未已”，后面“雨止”。
解析：“未已”是尚未停止，能解释雨中涨水和次日才止。这里的“已”与句末“家人已候门”的“已经”用法不同。

## 排序：磨原来能用，什么时候才能说“复其用”？排出失去、修补与恢复的经过。 {#x36.q.3.6}
考点：x36.s.restore
语境：x36.p.mill

- [3] 磨轮重新可以使用
  理由：“复其用”是修理完成的结果。
- [1] 轮被水淹，水退后见它损坏
  理由：有原功能的丧失，才有后来恢复可言。
- [2] 工匠更换轮轴
  理由：原文“工更其轴”，修理在恢复之前。

提示：“始”把磨真正恢复工作放在哪一步之后？
解析：水退不等于磨就能用。“始复”说明经过修理，磨才恢复从前的用途。

## 单选：伶人失声之后，“雾气又令其咳”的“令”怎样牵起前后？ {#x36.q.3.7}
考点：x36.s.causemake
语境：x36.p.singer

- [ ] 说雾中有人命令他咳嗽
  理由：原文只有“雾气”作原因，没有发命令的人。
- [ ] 说明咳嗽把雾气招来
  理由：咳嗽的是伶人，“其”指他；这项把原因和后果倒过来。
- [x] 说明雾气使咳嗽发作

提示：找“令”之前的原因和“令”之后身体的反应。
解析：“雾气”造成“其咳”，方向由前到后。这一使动关系无需一个发号施令的人。

## 单选：薄暮的工匠“释具归”。他是把工具归还别人，还是自己要往哪里去？ {#x36.q.3.8}
考点：x36.s.home
语境：x36.p.mill

- [ ] 回到被淹的河床去找磨轮
  理由：磨已经修好，下一句的地点转到家门。
- [x] 放下工具，回自家
- [ ] 把工具退还给家人，自己留守磨坊
  理由：“释具”已写放下工具；没有说家人原是工具的主人。

提示：“家人已候门”替哪个动作补出了目的地？
解析：“释”的对象是工具，“归”的主语是工匠。家人在门口等着，把“归”的去处点明了。
