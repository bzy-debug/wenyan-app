# 课文：往哪里去，回来怎样答 {#x36.2}
简介：有人差儿子去找医生，也有人派使者到军营。看清来往与答话的方向，免得医生说的话成了送信人的意思。

## 正文

“如”摆在地名前面，可以给行人指出目的地；进了“不如”两个字里，却常把两样东西摆到一起比高低。屈完“如师”，随后和齐侯同看军阵，前后说的是行程。若说自己察病“不如”别人，话题已经换成谁更能胜任。

“复”也得看落在什么事情里面：使者可以回到出发的地方，还可以向派他的人作答。两件事常常连在一起，却不能一遇“复”就把话译成来回走。读到“事母”，则要顺着煎药、问病之类的动作看是谁照料谁。

## 知识点：如 {#x36.s.go}
义项：前往某地
领域：实词
要诀：“使某如某处”先找差谁前往，再看他后来到了谁面前。
讲解：“楚子使屈完如师”让屈完动了身，后面他同齐侯看军阵，方向便对上了。“师”即联军，不是说屈完“像军队”。
例句：x36.p.envoy

## 知识点：如 {#x36.s.compare}
义项：在比较中表示比得上、及得上
领域：实词
要诀：“甲不如乙”要看哪两样东西，究竟比的是哪一点。
讲解：白布“其坚不如青者”，是说论牢实白布赶不上青布。白的颜色并没有变差；原文只在比“坚”。
例句：x36.p.cloth

## 知识点：复 {#x36.s.reply}
义项：向询问者或差遣者作答、回话
领域：实词
要诀：看回到原处的动作有没有写完；若又有“复……曰”，接着读他说的内容。
讲解：仆人“还，复于客曰”，人已经回来，接下去才向主人说哪一种布耐穿。这里的“复”交代答话，不必再把仆人送回一次。
例句：x36.p.cloth

## 知识点：事 {#x36.s.serve}
义项：侍奉、照料亲长
领域：实词
要诀：“事”后若是父母，往旁边找服药、衣食等照应的事。
讲解：“裁衣以事老母”的“事”有一个具体对象：上年纪的母亲。买布做衣服，是儿子侍奉母亲的一件事。
例句：x36.p.cloth

## 原文：教学例句 {#x36.p.doctor}
> 母病，子亲事之。母使子如南里求医。医曰：“吾察目疾，不如东郭翁。”子未得药，归复其母曰：“宜请东郭翁。”
译文：母亲病了，儿子亲自照料。母亲让他去南里求医。医生说：“我诊治眼病，比不上东郭老人。”儿子没取到药，回来向母亲答话说，还是请东郭老人合适。
词注：东郭：东面的外城，此处用来指老人所居之地。
  目疾：眼病。
  宜：合适，应该。

## 原文：教学例句 {#x36.p.cloth}
> 客欲市布，遣仆如东市。仆试二布，一虽白，其坚不如青者。还，复于客曰：“青者可久服。”客买之，裁衣以事老母。
译文：客人想买布，派仆人去东市。仆人试了两种布，一种虽白，却没有青布结实。回来后，他答复客人：“青布可以穿得久。”客人买下青布，裁衣侍奉年老的母亲。
词注：市布：买布。
  坚：牢实、结实。
  服：穿着。

## 原文：古籍引文 {#x36.p.envoy}
> 夏，楚子使屈完如师。师退，次于召陵。齐侯陈诸侯之师，与屈完乘而观之。
译文：夏天，楚君派屈完到诸侯的军队那里。联军后撤，驻扎在召陵。齐侯把诸侯的军队排成阵列，与屈完同车观看。
词注：师：军队。
  次：驻扎。
  陈：排列。
出处：《左传·僖公四年》，屈完至诸侯之师

## 单选：“屈完如师”以后，他同齐侯观看军阵。楚君起先派他做什么？ {#x36.q.2.1}
考点：x36.s.go
语境：x36.p.envoy

- [ ] 当诸侯联军的统帅
  理由：“使”在派人出行，没有授他统辖各军的职务。
- [x] 到诸侯的军中去
- [ ] 学齐侯的样子训练楚军
  理由：“如”后跟的是出使的目的地，后来他已在齐侯身边。

提示：齐侯后来在谁面前陈列军队？先想两人怎样到了同一处。
解析：“使屈完如师”说谁受派、往哪里去；接下来的停驻、看军阵才是军中发生的事。

## 单选：南里的医生说“不如东郭翁”，在哪件事上自认差一筹？ {#x36.q.2.2}
考点：x36.s.compare
语境：x36.p.doctor

- [x] 诊察眼病的本领
- [ ] 离病人家比较近的路程
  理由：“吾察目疾”交代了比较的项目，原文没量两条路。
- [ ] 侍奉自己母亲的时间
  理由：病的是来求诊者的母亲；医生这句话在谈本领。

提示：不要漏掉“不如”前的“吾察目疾”。
解析：两位医生之间比的是眼病诊断。这个“不如”解释了儿子为何没拿药、反去请别人。

## 找原文证据：仆人“复于客”时传回了什么判断？找出他亲口说的那句话。 {#x36.q.2.3}
考点：x36.s.reply
语境：x36.p.cloth

- [ ] 其坚不如青者
  理由：这是叙事人写仆人比布的经过，尚未到回话。
- [ ] 遣仆如东市
  理由：这是最初派出去的差事。
- [x] 青者可久服

提示：“还”过后再读“曰”，引语从哪里开始？
解析：返回的动作用“还”，回话用“复”。仆人的判断给了主人选青布的理由。

## 单选：“子亲事之”把儿子与母亲写成怎样的关系？ {#x36.q.2.4}
考点：x36.s.serve
语境：x36.p.doctor

- [ ] 儿子另外讲起母亲小时候的事
  理由：“事之”是他眼下在做的行动，接下去便是出门求医。
- [x] 儿子亲身照料生病的母亲
- [ ] 儿子替药铺负责一件买卖
  理由：“之”承接母亲，不是药铺的货物。

提示：试把“之”明确写作“母”再读。
解析：“事”在这里带人的宾语，是侍奉。“亲”进一步说明儿子自己操持。

## 单选：若要给仆人画出采买的路线，“如东市”把终点画在哪里？ {#x36.q.2.5}
考点：x36.s.go
语境：x36.p.cloth

- [x] 东边的市场
- [ ] 青布商人回客人家的路上
  理由：这是仆人受派时的去向，商人没有同行。
- [ ] 客人的住处，因为“如”是回来
  理由：买布在先，“还”才写后来回去复命。

提示：接下来试布这件事，要到哪里才能做？
解析：“如”直接带目的地。东市是去比较青白两种布的地方，回程另有一个“还”。

## 单选：若把“其坚不如青者”抄作“青者不如白者坚”，会把原意怎样改掉？ {#x36.q.2.6}
考点：x36.s.compare
语境：x36.p.cloth

- [ ] 只改变说话的口气，仍是青布更结实
  理由：互换“不如”前后两项，会改变比较的高低。
- [ ] 把两块布的颜色对换了
  理由：比较的是“坚”，两块布仍分别是青的和白的。
- [x] 把白布和青布谁更耐用说反了

提示：先说明“其”指刚提起的哪一块布。
解析：原说白布的坚实程度赶不上青布。仆人最后推荐青布，正可倒回来核实方向。

## 单选：儿子“归复其母曰”，若译“他回去又回到母亲那里”，少交代了哪件事？ {#x36.q.2.7}
考点：x36.s.reply
语境：x36.p.doctor

- [ ] 母亲到了东郭又回家
  理由：动“归”、动“复”的一直是求医的儿子。
- [x] 他把医生的建议答给母亲听
- [ ] 他取了两种药交给母亲
  理由：前文说“未得药”，且主要的回话紧跟在“曰”后。

提示：“归”已经交代返回，后面还有整句引语。
解析：儿子亲自求医、带话而回。“复”在此写向差遣他的人作答，回答的内容是另请东郭老人。

## 找原文证据：客人买了青布，拿什么行动侍奉母亲？圈出他亲手安排的那件事。 {#x36.q.2.8}
考点：x36.s.serve
语境：x36.p.cloth

- [x] 裁衣
- [ ] 试二布
  理由：挑选两种布的是被派去的仆人。
- [ ] 复于客
  理由：这是仆人向主人回话，不是儿子照料母亲。

提示：行动者从“仆”换回“客”以后再找。
解析：“以事老母”的“以”表目的。做衣给她穿，正是这里“事”字落到生活中的意思。
