# 检查：一字怎样改变整个情节 {#check.36}

## 原文：教学例句 {#p.check.36.1.road}
> 桥板新易，尚未遍钉。匠戒众徐行。一客闻后有车，遽趋向桥，匠止之。匠数视板隙，初仅容一钱，暮则倍之。见其稍宽，乃闭桥待修。
译文：桥板刚换，还未全部钉牢。工匠告诫大家慢走。一位客人听说后面有车，便急忙赶向桥边，工匠把他叫住。工匠多次查看板缝，起初只容一枚钱，到傍晚已有原来的两倍宽。眼见缝隙越来越宽，他便封了桥，等候修理。

## 单选：工匠让大家怎样过桥？那位客人听到车声又怎样走？ {#q.check.36.1}
考点：skill.words.10.1
语境：p.check.36.1.road

- [ ] 两人都反复进出桥面，多次等待车来 {#q.check.36.1.o3}
  理由：反复查看桥板写在“数视”里。工匠告诫众人的“徐”却是慢。
- [x] 匠要求大家慢走，客人听到后方有车却急忙趋向桥边 {#q.check.36.1.o1}
- [ ] 匠催大家立即走，客人奉命慢慢趋前 {#q.check.36.1.o2}
  理由：“徐行”是工匠要大家慢，着急快步过去的是客人。

提示：工匠说“徐行”，客人听到车声却“遽趋”。
解析：工匠叫大家慢行，客人却急着往桥边赶。两处写的快慢正好相反。

## 单选：工匠不是只看了一眼。他怎样知道桥板的缝在变宽？ {#q.check.36.2}
考点：skill.words.10.3
语境：p.check.36.1.road

- [ ] 只看了一次，就确认桥面已完全断裂 {#q.check.36.2.o2}
  理由：早晚看见的缝宽已不同，还没说桥已经断了。
- [ ] 因为板缝一直同样窄，所以经常封桥 {#q.check.36.2.o3}
  理由：最初只容一枚钱，到傍晚就宽了一倍，此后才封桥。
- [x] 查看不止一次，缝隙在多次查看中呈现渐宽趋势 {#q.check.36.2.o1}

提示：比比早先容一钱的缝与傍晚的宽度。
解析：“数视”是看了好几次；“稍宽”是渐渐变宽。前后观察相对照，工匠才决定封桥。

## 原文：教学例句 {#p.check.36.2.record}
> 县中有老吏，素识水道，常乘小舟往来两岸。新吏循旧图求津，图徒记旧埠，而春水甚急，旧埠已没。老吏导之上流，乃得渡。
译文：县中老吏一向熟悉水道，常乘小船往来两岸。新吏按旧图寻找渡口，图上只记了旧埠头，而春水很急，旧埠头已经淹没。老吏带他向上游走，才得以渡河。

## 单选：老吏为什么能领新吏找到渡口？ {#q.check.36.3}
考点：skill.words.11.1
语境：p.check.36.2.record

- [x] 他早已熟悉水道，经常行舟给这种熟悉提供了经验背景 {#q.check.36.3.o1}
- [ ] 他直到旧埠淹没才与新吏初次相识 {#q.check.36.3.o3}
  理由：“素识”的是水道，没有谈新老二人何时相识。
- [ ] 他曾偶然乘舟一次，今天才首次认识水道 {#q.check.36.3.o2}
  理由：老吏“常乘小舟”，说明行舟并非偶然一次。

提示：“素识”交代他本来知道什么，“常乘”写他平时怎样往来。
解析：他本已熟悉河道，又经常在两岸行舟，能带新吏绕开淹没的旧埠。

## 单选：新吏拿着图找渡口，怎么还是过不去？ {#q.check.36.4}
考点：skill.words.11.3
语境：p.check.36.2.record

- [ ] 旧图的比例很大，新吏因此走得太快 {#q.check.36.4.o3}
  理由：“甚急”说春水湍急。图的比例和新吏走路快慢都没写。
- [x] 图只记旧埠，水势又很急，旧埠已淹没 {#q.check.36.4.o1}
- [ ] 图记遍各个新渡口，但水势仅略微变急 {#q.check.36.4.o2}
  理由：图只记旧埠头，春水却很急，“徒”和“甚”各管一件事。

提示：图上记了几处渡口？那处现在还露在水上吗？
解析：旧图只标旧埠，眼前春水很急，旧埠已经被淹。

## 原文：教学例句 {#p.check.36.3.voice}
> 客夜闻歌于江上，初甚远，移舟就之，歌声益清。闻乡曲，归思弥切。客曰：“歌者殆同乡人也。”及问里居，乃抚掌曰：“诚吾乡人也！”
译文：客人夜间在江上听到歌声，起初离得很远；把船向歌声处移近后，歌声更清楚了。听到家乡曲调，他越发想家。他说唱歌的人大概是同乡。等问过住处，才拍手说，的确是同乡。

## 单选：客人移舟去听，歌声与思乡的心情各有怎样的变化？ {#q.check.36.5}
考点：skill.words.12.2
语境：p.check.36.3.voice

- [ ] 歌者越唱越快，客人划船次数越多 {#q.check.36.5.o2}
  理由：越来越清楚的是歌声，越来越深的是客人的思乡心情。
- [ ] 江水越来越清，歌者也越发想家 {#q.check.36.5.o3}
  理由：原文写“歌声益清”，并没说河水变清；想家的是听曲的客人。
- [x] 船近，歌声听得更清；曲熟，思乡之情更切 {#q.check.36.5.o1}

提示：“益”后是什么更清了？“弥”后又是什么更切了？
解析：船靠近，歌声听得更清楚。认出家乡曲子，他又更想家了。

## 单选：先说“殆同乡”，后来却拍手说“诚吾乡人”。两次判断各凭什么？ {#q.check.36.6}
考点：skill.words.12.3
语境：p.check.36.3.voice

- [x] 先听乡曲而推测，问得居处后才确认 {#q.check.36.6.o1}
- [ ] 两次都只是客人盼归的假设，无新增信息 {#q.check.36.6.o3}
  理由：问过对方居处就是证据的变化，“诚”也表确认。
- [ ] 先问清住处再猜，最后只凭乐曲断定 {#q.check.36.6.o2}
  理由：“及问里居”介于两次说话之间，不在听歌前。

提示：从“闻乡曲”读到“及问里居”，客人又知道了什么？
解析：起初听见乡曲，只是推测。问明住处，才确认歌者果真是同乡。
