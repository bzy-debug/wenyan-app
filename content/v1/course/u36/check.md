# 检查：错放的种粮、渡口和织机 {#check.36}

## 原文：教学例句 {#x36.p.loss}
> 东仓少一囊种。众谓守者曰：“子故取之乎？”守者引众视西仓，囊在焉。搬者曰：“误置耳，过在我。”
译文：东仓少了一袋种子。众人对看守说：“是你有意拿走的吗？”看守带大家看西仓，袋子在那里。搬袋子的人说：“是放错了，过失在我。”
词注：囊：袋子。
  种：留作种子的粮食。
  耳：罢了。

## 原文：教学例句 {#x36.p.ferry}
> 里中欲修渡，遣二人如北津，问冬水深浅及旧舟所在。还，一人复于众曰：“水浅，可立木为梁。”一人出图，指旧舟处。
译文：村里打算修整渡口，派两人去北边渡口打听冬天的水深和旧船所在。回来后，一人向众人答话，说水浅，可以立木搭桥。另一人拿出图，指出旧船的位置。
词注：津：渡口。
  梁：桥。
  处：地方。

## 原文：教学例句 {#x36.p.loom}
> 机轴旧滑，久旱而涩，令纬数断。织者以膏润轴，轴复其滑；织至暮，布成一匹。
译文：织机的轴原本光滑，长久干旱后变得涩滞，使纬线屡屡断掉。织者用油脂润轴，轴恢复了原先的光滑。一直织到傍晚，织成一匹布。
词注：涩：不滑，转动不灵。
  纬：织布时横向的线。
  数：读 shuò，屡次。

## 单选：众人问“子故取之乎”，要查的是哪一层意思？ {#x36.q.check4.1}
考点：x36.s.purpose
语境：x36.p.loss

- [x] 看守有没有存心拿走种子
- [ ] 看守从前有没有在别的仓工作
  理由：“故”摆在“取”前，这句话问拿种子的用意。
- [ ] 种子最早是从哪个仓运来的
  理由：所问是看守是否有意拿走，并没问货的原产地。

提示：结尾搬者说“误置”，与疑心中的哪一种用心相反？
解析：“故取”与“误置”相对，一是疑心存心拿走，一是实际无意错放。问话本身不是定罪。

## 单选：搬袋子的人说“过在我”。他担的是怎样的责任？ {#x36.q.check4.2}
考点：x36.s.fault
语境：x36.p.loss

- [ ] 路过西仓时没看住种子
  理由：他承认的是“误置”，没有说只是经过。
- [ ] 明知种子在西仓，还故意取走
  理由：搬者说自己误放，没承认故意取走。
- [x] 把种子搬错了仓

提示：谁开口说“我”，他紧接在前面承认了哪个动作？
解析：更换了说话人：开头嫌疑指守者，结尾搬者认下的是自己放错位置的过失。

## 单选：“遣二人如北津”，两人是去做什么？ {#x36.q.check4.3}
考点：x36.s.go
语境：x36.p.ferry

- [ ] 从北津返回村里直接造桥
  理由：受差遣时先去北津；“还”才开始写回村的事。
- [x] 前往北渡口打听水情与船的位置
- [ ] 去仿造一座和北津相像的渡口
  理由：“问冬水深浅及旧舟所在”说明要调查，不是仿造。

提示：看看“如”后面是一个地点还是要比较的两种东西。
解析：“如北津”报去处，后面跟调查的内容。回来向众人说的话则在后半段。

## 找原文证据：两人调查以后，一人“复于众”。哪句是他答给村民听的调查意见？ {#x36.q.check4.4}
考点：x36.s.reply
语境：x36.p.ferry

- [x] 水浅，可立木为梁
- [ ] 问冬水深浅及旧舟所在
  理由：这是当初要打听的事，还没得出结论。
- [ ] 指旧舟处
  理由：这是另一人指图的动作，不是第一人开口的话。

提示：分清“曰”后面是谁的话，何处又换了“一人”。
解析：两人一道出行、一道回来，回报方式不同。一人以言作答，一人用图指出旧船。

## 单选：“令纬数断”写的因果关系应怎样说？ {#x36.q.check4.5}
考点：x36.s.causemake
语境：x36.p.loom

- [ ] 纬线断掉，使天久不下雨
  理由：久旱出现在纱线断以前，是轴涩的背景。
- [ ] 织者下令把纬线一道道剪断
  理由：原文的难处是断线，抹油后还要继续织，并无剪线之命。
- [x] 轴转得涩，使纬线屡断

提示：往“令”前找机器出了哪种状况。
解析：“涩”是原因，“数断”是结果。把“令”换作“致使”就能把这一小段接通。

## 找原文证据：“轴复其滑”所恢复的状态，最初在哪几个字里就交代了？ {#x36.q.check4.6}
考点：x36.s.restore
语境：x36.p.loom

- [ ] 布成一匹
  理由：这是恢复顺滑以后织成的产物，不是轴原先的状态。
- [x] 机轴旧滑
- [ ] 久旱而涩
  理由：这是发生问题后中间的状况，并非原来的长处。

提示：“复”前后的顺序是从前、失常、回到从前；找第一步。
解析：旧时滑，久旱涩，润后复滑。前面的“旧”给“复”提供了可以比对的原状。
