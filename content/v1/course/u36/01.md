# 课文：灯破了，该怪谁 {#x36.1}
简介：灯碎是真事，是谁故意打碎的，却得另外查。“问其故”与“故击之”差一个位置，给人定下的责任也不同。

## 正文

学徒守着一排灯，一夜过去，破了一盏。店主人先问缘故，这时还不知道是谁的过失。若他接着问“故碎之邪”，便又多了一问：碰巧弄破，还是特意打碎？译成“故意”之前，看看这个“故”后面有没有接着一个人做的动作。

读审问、劝谏一类文字，还得注意话传给了谁。“主谓徒曰”是主人向学徒开口。“徒谓主曰”只换了两个人的位置，答话和发问便可能颠倒。这一课读两桩小事，再听《左传》里臣下怎样接住君主认错的话。

## 知识点：故 {#x36.s.cause}
义项：发生一件事的原因
领域：实词
要诀：若有人“问其故”，他等的是一番解释。
讲解：主人已经看见碎灯，问的自然不是灯碎没碎。学徒答“吾挂灯不牢”，给的正是碎灯的缘故。
例句：x36.p.lamp

## 知识点：过 {#x36.s.fault}
义项：做错的事、过失
领域：实词
要诀：看到“谁无过”“过在我”，先找哪桩事出了错。
讲解：“人谁无过”把“过”当作人会有也会改的过失；接着的“过而能改”才是动词，指犯了错误。同一个字连用两次，句中的职务不同。
例句：x36.p.remonstrate

## 知识点：故 {#x36.s.purpose}
义项：故意做某事
领域：实词
要诀：在动作前试补“特意”，再看这是有人疑心还是原文认定。
讲解：“翁疑童故决其瓮”中，老人疑心孩子有意弄破瓮。后来却查到旧裂缝。读出“故意”这层意思，不等于已经证实有人那么做。
例句：x36.p.vat

## 知识点：谓 {#x36.s.tell}
义项：对某人说话
领域：实词
要诀：“甲谓乙曰”，先分出哪一边开口、哪一边听。
讲解：“主谓众曰”的“众”是听话的人。把“谓”译作“叫作”便读不通紧跟着的一整段话；主人不是给众人起名字。
例句：x36.p.lamp

## 原文：教学例句 {#x36.p.lamp}
> 肆中夜风起，灯堕而碎。主问其故。徒曰：“吾挂灯不牢，此吾过也。”主谓众曰：“其失可戒，非故碎之也。”
译文：铺中夜里起风，灯掉下来碎了。主人问缘故。学徒说：“是我没挂牢，这是我的过失。”主人对众人说：“这样的失误要引以为戒，他没有故意打碎灯。”
词注：肆：店铺。
  徒：学徒。
  戒：警惕、引以为戒。

## 原文：教学例句 {#x36.p.vat}
> 邻家夜失半瓮水。翁疑童故决其瓮，谓童曰：“汝夜至此乎？”童指瓮下旧隙，注水验之，水果从隙出。翁乃知失水之故。
译文：邻家一瓮水夜里少了半瓮。老人怀疑孩子故意弄破瓮，便问他夜间来过没有。孩子指出瓮底原有的裂缝，灌水一试，果然见水从裂缝流出。老人这才知道水怎么少了。
词注：决：这里指弄破器壁让水流出。
  隙：裂缝。
  注：灌入。

## 原文：古籍引文 {#x36.p.remonstrate}
> 三进及溜，而后视之，曰：“吾知所过矣，将改之。”稽首而对曰：“人谁无过？过而能改，善莫大焉。”
译文：士季三次进前，到了檐下，晋灵公这才看他，说：“我知道自己错在哪里了，要改正。”士季叩头回答：“谁没有过错呢？犯了错而能改，没有比这更好的了。”
词注：溜：屋檐下滴水的地方。
  稽首：叩头行礼。
  对：回答。

## 单选：老人最后弄清的“失水之故”，是哪件事？ {#x36.q.1.1}
考点：x36.s.cause
语境：x36.p.vat

- [x] 瓮底原有裂缝，水由此漏走
- [ ] 孩子夜间来过，特意打翻了水瓮
  理由：这是老人开头的怀疑，灌水后发现的却是旧隙。
- [ ] 先前就认识守瓮的孩子
  理由：“故”跟在“失水之”后，这里要解释水为何变少。

提示：把“水果从隙出”当成一次试验的结果。
解析：开头知道少了半瓮水，结尾才知道缘由。试验所得正好回答“怎么会少”。

## 单选：“此吾过也”的“此”，学徒自己认领的是哪一桩？ {#x36.q.1.2}
考点：x36.s.fault
语境：x36.p.lamp

- [ ] 夜里起风，这是他做错的事
  理由：风是天气；他承认的是“吾挂灯不牢”。
- [ ] 故意击碎了灯
  理由：主人最后说“非故碎之”，有过失不等于存心毁坏。
- [x] 当初没把灯挂牢

提示：从学徒自己的话里分出动作和后果。
解析：“过”是学徒应担的过失。风起和灯碎是经过，“挂灯不牢”才是他能改正的疏忽。

## 单选：“疑童故决其瓮”是在怀疑孩子的什么？ {#x36.q.1.3}
考点：x36.s.purpose
语境：x36.p.vat

- [ ] 孩子能不能说出以前那场事故
  理由：这里是老人自己的猜想，并没有提一桩早先的事故。
- [x] 他会不会是有意把瓮弄漏
- [ ] 孩子知不知道水瓮原来的主人
  理由：“故”在动作“决”前面，没说孩子认识谁。

提示：“疑”是老人心里怎样想，“故”则形容他猜孩子怎样做。
解析：怀疑孩子碰坏瓮，同怀疑他存心破坏是两回事。老人想到的是后者，而后面的验证并不支持这一猜测。

## 单选：“主谓众曰”这句换了说话的人。谁在向谁解释灯碎的事？ {#x36.q.1.4}
考点：x36.s.tell
语境：x36.p.lamp

- [x] 铺主人向在场的众人解释
- [ ] 学徒向主人再次认错
  理由：学徒的自认止于“此吾过也”，后面另起“主”。
- [ ] 众人一致向主人报告
  理由：“众”在“谓”后，写的是主人讲话的对象。

提示：不要把“谓”前后的人互换。
解析：主人先听完学徒自述，再对众人说明自己的判断。引语中的“其失”也在说学徒的失误。

## 找原文证据：“主问其故。”学徒的答话中，哪几个字直接给出导致灯碎的疏忽？ {#x36.q.1.5}
考点：x36.s.cause
语境：x36.p.lamp

- [ ] 此吾过也
  理由：这是承认责任，还没解释失手的细节。
- [ ] 主谓众曰
  理由：这是主人随后开口说话。
- [x] 吾挂灯不牢

提示：把“为什么会掉下来”当成主人的问题来读。
解析：问“故”是追问原因；没挂牢，遇风便会掉落。结果和责任都不能代替这个原因。

## 单选：士季劝君主改过。只看“人谁无过”的这个“过”，人都有可能“有”什么？ {#x36.q.1.6}
考点：x36.s.fault
语境：x36.p.remonstrate

- [ ] 责备君主的权力
  理由：士季谈的是人人难免有错，没有授予谁责备人的权力。
- [x] 自己的过错
- [ ] 从这里经过的一段路
  理由：下句是在说犯错后能改，没有行人的去向。

提示：把“有过—改过”连起来试读。
解析：前一个“过”是名词；君主说自己错了，士季并不要求人永不犯错，着力处在一个“改”字。

## 找原文证据：主人承认学徒有疏忽。哪句话又说明他不认为学徒是存心的？ {#x36.q.1.7}
考点：x36.s.purpose
语境：x36.p.lamp

- [x] 非故碎之也
- [ ] 其失可戒
  理由：这承认动作有失，未判定是不是故意。
- [ ] 灯堕而碎
  理由：只写灯掉下来的结果，不交代人的用心。

提示：找“非”究竟否定了什么。
解析：“非”否定的是有意打碎，不否定灯已破，也不否定挂得不牢有错。

## 单选：“谓童曰”后引出一句问话。是谁开口追问谁？ {#x36.q.1.8}
考点：x36.s.tell
语境：x36.p.vat

- [ ] 孩子问老人有没有半夜来取水
  理由：“谓童”的是前句的“翁”；“汝”向孩子发问。
- [ ] 作者把孩子称为半夜来的人
  理由：“乎”标出这是问题，当时还没人查明水是怎么漏的。
- [x] 老人问孩子夜里来没来

提示：把引语里的“汝”还原成面前的那个人。
解析：“谓”把听话的孩子接到引语上。老人是在查问，不能把问句当成已经坐实的指责。
