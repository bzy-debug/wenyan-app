# 课文：“莫春”是什么时候？追一个古字的分工 {#d33.1}
简介：旧字兼写几个词时，后来可能另造一个字专写其中一义。抄引和解释可以各有一栏。

## 正文

翻开《论语·先进》，曾点所说的季节写成“莫春”。再翻“莫”条，除了今天熟悉的 mò，还有读 mù、表示晚的一项；这个用法后来通常写作“暮”。“莫春”于是能和“春服既成”接上。可是“莫我知”若照样读成“黄昏”，这句感叹就读错了。

| 本课工作表 | 先留什么 | 再填什么 |
| --- | --- | --- |
| 底本栏 | 所见的“莫”或“責” | 抄原句时照原字 |
| 释义栏 | 本句是哪一个意思 | 若有后起专字，如“暮”“債”，可在这里说明 |

“古、今”只比较这项用法的前后。即使后来用“債”写欠款，今天仍会说“責问”。不能把一份古书里每个“責”都换掉。[查“莫”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=莫)

## 知识点：分辨古今专字 {#skill.d33.split}
义项：从本句找出旧字所表的那个词，再与后来的专用字相对
领域：阅读技能
要诀：找到一句中确实需要的那个意思，先别替整页换字。
讲解：“莫春”说季节晚，“莫我知”说没人理解。用暮来说明，只适合前一例。
例句：p.d33.1.r1

## 知识点：底本与释义分栏 {#skill.d33.record}
义项：摘录保留底本实际字形，在注中说明今天常用的写法或词义
领域：阅读技能
要诀：底本栏要让别人能找回那一行，解释栏才写你如何读。
讲解：遇见“收責”可在释义中说明收债。把全文的責一律换成債，会连不指欠款的地方也改坏。
例句：p.d33.1.r3

## 原文：教学例句 {#p.d33.1.r4}
> 客責主人曰：“何失信也？”主人出券，以示所負之債。教学字条：責，可指责问；古书中也有欠款义。債，欠下的钱物。
译文：客人责问主人为什么失信。主人拿出契券，给他看所欠的债。前者是说话的动作，后者才是所欠的钱财。
词注：券：凭据。
  負：欠。

## 单选：查“莫”见到两栏：“mò，没有谁；mù，晚，后常写暮”。曾点回答时，这句话先定下什么？ {#q.d33.1.1}
考点：skill.d33.split
语境：p.d33.1.r1

- [ ] 没有人穿春衣 {#q.d33.1.1.o1}
  理由：“春服既成”接着说春衣已合时宜，非但没说无人穿衣，还写了准备出游的人。
- [x] 暮春这个时节 {#q.d33.1.1.o2}
  理由：“莫”修饰“春”，应读 mù，指春将尽。这一意思后来用“暮”来写。
- [ ] 禁止少年在春日出游 {#q.d33.1.1.o3}
  理由：后面正是曾点想与少年同游，语气并非下禁令。

提示：听完“莫春”，再看衣物和出行的季节。
解析：“莫”修饰“春”，应读 mù，指春将尽。这一意思后来用“暮”来写。

## 找原文证据：除“莫春”本身，哪句话从应季衣物给这项读法提供线索？ {#q.d33.1.2}
考点：skill.d33.split
语境：p.d33.1.r1

- [ ] 詠而歸 {#q.d33.1.2.o1}
  理由：唱着归家是活动的结尾，没有说明穿戴或季节。
- [x] 春服既成 {#q.d33.1.2.o2}
  理由：“春服既成”延续时令话头，支持把莫春读成暮春。
- [ ] 童子六七人 {#q.d33.1.2.o3}
  理由：这是同游者的数量，哪一季都能这样数。

提示：留意哪处物件随天气而变化。
解析：“春服既成”延续时令话头，支持把莫春读成暮春。

## 单选：孔子感叹的“莫”也在古书里，仍照“暮春”读，会遇到什么问题？ {#q.d33.1.4}
考点：skill.d33.split
语境：p.d33.1.r2

- [ ] “莫我知”指没有知识可学，和季节一样讲得通 {#q.d33.1.4.o1}
  理由：“知”的对象是我，后一句换成子贡说“子”。
- [ ] 孔子和子贡都在说春天，日暮与春暮意思相同 {#q.d33.1.4.o2}
  理由：这段话根本未定季节，“知子”说的是理解谁。
- [x] 子贡问的是谁了解老师，整段没有提到一天中的时候 {#q.d33.1.4.o3}
  理由：一个从我说，一个从您说，同在谈无人了解。这个莫用 mò，不需用暮释它。

提示：把“莫我知”与子贡回话中的“莫知子”并排。
解析：一个从我说，一个从您说，同在谈无人了解。这个莫用 mò，不需用暮释它。

## 单选：参看“計會”和“收”，孟尝君在薛地要办哪件事？ {#q.d33.1.5}
考点：skill.d33.split
语境：p.d33.1.r3

- [x] 去收所欠的钱款 {#q.d33.1.5.o1}
  理由：在“收責”中，責是后来常以債书写的欠款。不是今天“责任”义所指的事。
- [ ] 查谁有道义责任便任命他 {#q.d33.1.5.o2}
  理由：孟尝君要能算账的人，这句话没有任命职官。
- [ ] 向薛地的人发一道责问书 {#q.d33.1.5.o3}
  理由：账目和收取配在一起，更像讨债；问话本身是对门客说的。

提示：客人要会办账，收的东西应该能记进账里。
解析：在“收責”中，責是后来常以債书写的欠款。不是今天“责任”义所指的事。

## 单选：整理引文时发现自己的稿子写了“收債”，底本实为“收責”。如何修改？ {#q.d33.1.6}
考点：skill.d33.record
语境：p.d33.1.r3

- [x] 原文恢复“收責”，旁边写“即收债” {#q.d33.1.6.o1}
  理由：“收責”能如实复现底本，“即收债”说明词义。两栏有不同任务。
- [ ] 保留“收債”并说两字在所有场合都相同 {#q.d33.1.6.o2}
  理由：二字只在特定意义上有古今分工，不能拿来全篇互换。
- [ ] 底本一定漏了人旁，直接断作抄错了 {#q.d33.1.6.o3}
  理由：旧字曾写这个意思；仅凭今天的习惯不能断底本讹误。

提示：对得上的古字旧义不必先判错别字。
解析：“收責”能如实复现底本，“即收债”说明词义。两栏有不同任务。

## 找原文证据：凭哪句当面说出的话，可看出开头的“責”是在责问？ {#q.d33.1.7}

  理由：这是随后拿出凭据时所说的钱债，并非责问的话。

解析：客人质问“为何失信”，故“責主人”是责问主人。后面另有明确写出的債字。

## 单选：给这场争执写两行通俗释义，哪一种没有把两个用字混在一起？ {#q.d33.1.8}
考点：skill.d33.record
语境：p.d33.1.r4

- [ ] 原稿两个字都应写作“債”，这样全篇才统一 {#q.d33.1.8.o1}
  理由：“債主人曰”并不能表达对主人发问。用字分工不能凭统一字形决定。
- [ ] 客人收债，主人又责问客人 {#q.d33.1.8.o2}
  理由：只看到钱债会误读首句。首先发问的是客人，主人拿出的是契券。
- [x] 客人责问，主人出示欠债凭据 {#q.d33.1.8.o3}
  理由：两个所指，一个是责问的动作，一个是所欠的款项。解释旧用时不能全局换字。

提示：把“曰”和“出券”分别还给它们的主人。
解析：两个所指，一个是责问的动作，一个是所欠的款项。解释旧用时不能全局换字。
