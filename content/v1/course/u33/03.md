# 课文：穷、达、困、全 {#words.3}

简介：家中田地不少，朋友为什么还说他“穷”？守城人的水源被断了，为什么还能守住？

## 正文

《孟子》把“穷则独善其身”接在“不得志”之后。碰到一位家里有田、三次上书却无人采纳的士人，就能明白这种“穷”：他有主张，却一直没有机会实行。得志而“达”，他的作为便能惠及百姓。

“困其军”说困住谁，“全其城”说保住什么。还要看后面的结果。守城的人被断了水道，却能在夜里凿井，城池并未陷落。另一个故事里，吏员引水保住了下游的城，仍有田地被淹。“全”所及的是城，不能扩大到每一块田。

## 知识点：穷 {#skill.words.3.1}
义项：处境不顺，抱负无从施展
领域：实词
要诀：士人说“穷”，还得看他的主张能不能施展。
讲解：先读“不得志，修身见于世”，再读“穷则独善其身”。两句说的都是无从施展抱负时怎样修身。这里的“穷”要从有无施展的机会来讲。
例句：p.words.3.1

## 原文：古籍引文 {#p.words.3.1}
> 古之人，得志，泽加于民；不得志，修身见于世。穷则独善其身，达则兼善天下。
译文：古人得志时，将恩泽施给百姓；不得志时，修养自己，使品行显于世。不得志就修好自己，显达就让天下人一同受益。

## 找原文证据：上文用哪三个字写出了“穷则独善其身”的处境？ {#q.words.3.1}
考点：skill.words.3.1
语境：p.words.3.1

- [x] 不得志
- [ ] 达则兼善天下
  理由：“达”是与“穷”相对的另一处境。
- [ ] 泽加于民
  理由：这是得志时施及民众的效果。

提示：先配对“得志”与“达”，再找“穷”对应的三个字。
解析：“不得志”接着换成了“穷”：抱负无从施展，要先修养自身。

## 原文：教学例句 {#p.words.3.2}
> 士家多田，三上书言政，皆不用。友叹曰：“子之道今穷矣。”
译文：士人家中有许多田。他三次上书议政，建议一次也没被采纳。朋友感叹：“你想做的事，如今行不通啊！”

## 单选：既然“家多田”，友人何以仍说他“穷”？ {#q.words.3.2}
考点：skill.words.3.1
语境：p.words.3.2

- [x] 他说的治政主张始终没有机会实行 {#q.words.3.2.o1}
- [ ] 因为他已亲自实施三次新政 {#q.words.3.2.o3}
  理由：“皆不用”说的是建议未被采纳。
- [ ] 因为三次上书已用尽全部田产 {#q.words.3.2.o2}
  理由：“皆不用”说三次建议都没被采纳，和田产多少没有关系。

提示：他已经三次上书。那些建议后来怎样了？
解析：友人说的是“子之道”行不通。他家中有田，却一直没有机会施展治政主张。

## 知识点：达 {#skill.words.3.2}
义项：得志显达，有施展抱负的地位
领域：实词
要诀：已有施政机会的人得志，做事便能影响百姓。
讲解：“士穷”先说志不得伸，“达”则指有了施展抱负的机会。到了这个地步仍“不离道”，所作所为才不至于让百姓失望。
例句：p.words.3.3

## 原文：古籍引文 {#p.words.3.3}
> 故士穷不失义，达不离道。穷不失义，故士得己焉；达不离道，故民不失望焉。
译文：所以士人在失意时不丢掉义，在显达时不离开正道。失意而守义，士人便能保有自身的操守；显达而循道，百姓便不失所望。

## 单选：一个士人“达”，为什么牵涉百姓会不会失望？ {#q.words.3.3}
考点：skill.words.3.2
语境：p.words.3.3

- [x] 他有施展抱负的机会，怎样行道会影响百姓 {#q.words.3.3.o1}
- [ ] 因为“达”指传递一封百姓的书信 {#q.words.3.3.o2}
  理由：“士穷”与“达”并列说士人的处境。“民不失望”是说百姓的期望。
- [ ] 因为无论穷达，百姓只期望他的俸禄增加 {#q.words.3.3.o3}
  理由：“不离道”紧扣持守正道，并未说到俸禄。

提示：对照“士得己”与“民不失望”两种影响。
解析：显达的人有施展抱负的机会。他能否坚持自己的道，会影响百姓，所以说“不离道”才使“民不失望”。

## 原文：教学例句 {#p.words.3.4}
> 布衣陈水利之策，无人用。后为郡守，发民浚渠，或曰：“其人今达，得行旧议矣。”
译文：那人还是平民时提出水利办法，没有人采用。后来做了郡守，调人疏浚渠道，有人说他如今显达，得以施行旧日的建议了。

## 单选：从前无人采用的水利主张，如今为什么办得成了？ {#q.words.3.4}
考点：skill.words.3.2
语境：p.words.3.4

- [x] 从无权施策到有官职能疏渠 {#q.words.3.4.o1}
- [ ] 从前不懂水利，如今才第一次想到办法 {#q.words.3.4.o3}
  理由：开头说布衣时已提出计策。
- [ ] 终于从远地走到了渠道旁 {#q.words.3.4.o2}
  理由：原文在“今达”前先说他“后为郡守”，改变的是身份。

提示：对照“布衣”与“后为郡守”，再看谁能调人疏渠。
解析：当初他只是提出建议，现在做了郡守，可以调人疏渠。“达”使他有机会实行旧议。

## 知识点：困 {#skill.words.3.3}
义项：围困，使人无法脱身
领域：实词
要诀：写围城时，要分清守军眼下受困和城池最终陷落。
讲解：“以困守者”道明断水的用意。城里的人随即凿井，原文到“城未下”为止，所以只写到了围困这一步。
例句：p.words.3.5

## 原文：教学例句 {#p.words.3.5}
> 敌围南城，断其水道，以困守者。守者夜凿井，城未下。
译文：敌军包围南城，截断水路，以此困住守城者。守城者夜间挖井，城没有被攻下。

## 单选：敌军要“困守者”。南城后来怎样了？ {#q.words.3.5}
考点：skill.words.3.3
语境：p.words.3.5

- [ ] 守城的人都投降了 {#q.words.3.5.o2}
  理由：投降与围困是不同的结果，末句只说城未下。
- [ ] 敌军从未围过城 {#q.words.3.5.o3}
  理由：凿井是在水道被断之后作的应对。
- [x] 水道被截断了，城还没被攻下 {#q.words.3.5.o1}

提示：“困”的对象是守城人。再看他们当夜做了什么。
解析：断水是要使守城的人陷入困境。守军夜里挖井，城还没被攻下。

## 原文：教学例句 {#p.words.3.6}
> 伏卒绝谷口，困追骑于中。骑不得出，舍马缘崖而上。
译文：伏兵切断谷口，把追来的骑兵困在谷内。骑兵出不去，只得弃马攀崖。

## 单选：“困追骑于中”是谁把谁困住？ {#q.words.3.6}
考点：skill.words.3.3
语境：p.words.3.6

- [ ] 追兵困住伏在谷口的士卒 {#q.words.3.6.o2}
  理由：“伏卒”先绝谷口，接着做下一个动作。
- [x] 伏兵困住入谷的追兵 {#q.words.3.6.o1}
- [ ] 追兵正在谷口休息，因疲倦而睡 {#q.words.3.6.o3}
  理由：“不得出”“缘崖”写去路被截断。

提示：是谁守着谷口，谁只好弃马攀崖？
解析：伏兵封住谷口，把追来的骑兵困在谷中。后面弃马攀崖的正是那批骑兵。

## 知识点：全 {#skill.words.3.4}
义项：使……保全，免遭毁损
领域：实词
要诀：“全”后面是人、是书还是一座城？看究竟保住了什么。
讲解：吏员开陂分走涨水，“遂全下邑”说这才保住下游城邑。“田有没者”还交代，保住城和居民并不等于每块田都幸免。
例句：p.words.3.7

## 原文：教学例句 {#p.words.3.7}
> 江暴涨，吏决空陂以分水，遂全下邑。田有没者，而居民无恙。
译文：江水猛涨，官吏开通蓄水的空池分流，保全了下游的城邑。有农田被淹，居民平安。

## 单选：“全下邑”能读成“所有地方都没受损”吗？ {#q.words.3.7}
考点：skill.words.3.4
语境：p.words.3.7

- [ ] 官吏把所有水都引回大江 {#q.words.3.7.o3}
  理由：他使江水分流，未说处置了所有水。
- [ ] 下邑原来没有居民 {#q.words.3.7.o2}
  理由：末句明说“居民无恙”。
- [x] “全”是分水保城的动作，且仍有田地被淹 {#q.words.3.7.o1}

提示：兼看前面的分水和后面被淹的田。
解析：“全”是说开陂分水保住了下游城邑。居民无恙，田地仍有被淹的。

## 原文：教学例句 {#p.words.3.8}
> 火及藏书楼，生挟师手稿出。他卷多烬，其独全此编，人以为幸。
译文：火烧到藏书楼，学生夹着老师的手稿出来。其他卷册多烧成灰，他唯独保全了这一编，人们认为幸运。

## 找原文证据：书楼起火，学生怎样保住了老师的这部手稿？选出原文。 {#q.words.3.8}
考点：skill.words.3.4
语境：p.words.3.8

- [x] 挟师手稿出
- [ ] 他卷多烬
  理由：这说明其他卷册的遭遇，没有直接说明此编怎样获救。
- [ ] 人以为幸
  理由：这是事后评价，未交代抢救动作。

提示：从火场里实际带出了什么？
解析：“挟师手稿出”说他挟着手稿离开火场。所以别卷多已烧毁，唯独这一编保存下来。
