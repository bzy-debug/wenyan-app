# 课文：怜、爱、恶、乐 {#words.2}

简介：见背柴人光脚走在雪里，小吏脱鞋相赠。齐王却说“吾何爱一牛”。从人肯给什么、舍不得什么，可以读出他的心思。

## 正文

在“怜其寒”一句，小吏亲眼看见背柴的人受冻。他随后脱下自己的鞋给那个人，他怜的是背柴人光脚受冻的苦楚。齐王问“吾何爱一牛”，是反问自己何至于舍不得一头牛。为什么用羊换牛？得听他自己接下来说，他不忍看着牛发抖走向死地。

“能好人，能恶人”中的“好”读 hào，“恶”读 wù。同一个“人”字，放在前半句是喜爱谁，放在后半句是厌恶谁。再读“好之者不如乐之者”，两处“之”指的都是同一件事。从喜爱它到做起来就觉得快乐，“乐”又进了一层。

## 知识点：怜 {#skill.words.2.1}
义项：怜惜、体恤
领域：实词
要诀：有人受苦，谁看见了，又为他做了什么？
讲解：小吏看见背柴的人光脚走在雪里，便“怜其寒”。他同情那人挨冻，所以脱下鞋送给他。
例句：p.words.2.1

## 原文：教学例句 {#p.words.2.1}
> 吏见负薪者跣行雪中，怜其寒，解履与之。
译文：小吏见背柴人赤脚行在雪中，体恤他受冻，把鞋脱下来给他。

## 单选：小吏为什么把鞋送给那个背柴人？ {#q.words.2.1}
考点：skill.words.2.1
语境：p.words.2.1

- [ ] 小吏自己，因脱鞋受冻 {#q.words.2.1.o2}
  理由：脱鞋发生在起怜惜之情后。
- [x] 背柴人，因他雪中赤足受冻 {#q.words.2.1.o1}

译文：邻家姑娘日夜织布供养母亲，老妇怜惜她劳苦，替她打水。

## 找原文证据：老妇做了哪件事，帮织布的女子分担劳苦？ {#q.words.2.2}
考点：skill.words.2.1
语境：p.words.2.2

- [ ] 昼夜织
  理由：这是老妇所见的劳苦。
- [x] 为代汲
- [ ] 以奉其母
  理由：奉养的人是织女，未交代老妇行动。

## 知识点：爱 {#skill.words.2.2}
义项：吝惜、舍不得付出
领域：实词
要诀：先看舍不得的是牛、钱还是别的财物，再听人物怎样解释。
讲解：齐王问“吾何爱一牛”，意思是“我何至于舍不得一头牛？”他接着用“不忍”说自己的缘由：牛在发抖，他不忍眼看它被杀。
例句：p.words.2.3

## 原文：古籍引文 {#p.words.2.3}
> 齐国虽褊小，吾何爱一牛？即不忍其觳觫，若无罪而就死地，故以羊易之也。
译文：齐国纵然狭小，我何至于吝惜一头牛？只是不忍看它战栗，像无罪而走向死地，所以用羊换下了它。

## 单选：齐王问“吾何爱一牛”，是在否认哪一种用羊换牛的理由？ {#q.words.2.3}
考点：skill.words.2.2
语境：p.words.2.3

- [ ] 看到牛害怕便不忍心 {#q.words.2.3.o2}
  理由：“即不忍其觳觫”正是齐王承认的理由。要找他否认的理由，应回读“吾何爱一牛”。
- [x] 舍不得拿出一头牛 {#q.words.2.3.o1}
- [ ] 不愿以羊换牛 {#q.words.2.3.o3}
  理由：“故以羊易之”明确说已决定换。

译文：亭桥损坏已久，商人愿意出木料，里正舍不得十金，不肯修理。

## 单选：哪件事说明里正“爱十金”是舍不得出钱？ {#q.words.2.4}
考点：skill.words.2.2
语境：p.words.2.4

- [x] 有材料可用，里正仍不肯花钱修桥 {#q.words.2.4.o1}
- [ ] 亭桥已经坏了很久 {#q.words.2.4.o2}
  理由：桥坏说明需要修，还没说里正态度。
- [ ] 商贾愿意出材料 {#q.words.2.4.o3}

## 知识点：恶 {#skill.words.2.3}
义项：读 wù，厌恶
领域：实词
要诀：“好”是喜欢谁，“恶”是厌恶谁，两个动作都能带人作宾语。
讲解：“能好人，能恶人”，两个“能”后都接一个动作。前一个是喜爱人，后一个是厌恶人。“恶”作动词时读 wù。
例句：p.words.2.5

## 原文：古籍引文 {#p.words.2.5}
> 子曰：“唯仁者能好人，能恶人。”
译文：孔子说，只有有仁德的人才能恰当地喜欢人、厌恶人。
出处：《论语·里仁》节选

## 单选：前面说“好人”，后面说“恶人”。后一个“人”跟“恶”是什么关系？ {#q.words.2.5}
考点：skill.words.2.3
语境：p.words.2.5

- [ ] 与“恶”合成一个名词，指坏人 {#q.words.2.5.o2}
  理由：两边都有“能”，相对的动词分别为好、恶。
- [x] 是“恶”（wù）的对象，与“好人”的人对应 {#q.words.2.5.o1}
- [ ] 是发出恶意的施事者 {#q.words.2.5.o3}
  理由：施事者在前面，是“仁者”。

提示：把两处“能”后面都读成“动作＋对象”。
解析：“好”是喜爱，“恶”读 wù，是厌恶。两处“人”都是被喜爱或被厌恶的人。

## 原文：教学例句 {#p.words.2.6}
> 令恶吏之侵渔百姓，闻一吏夺民田，立命还之。
译文：县令厌恶属吏侵夺百姓利益，听说有小吏强占民田，当即命其归还。

## 单选：县令厌恶的具体是什么？ {#q.words.2.6}
考点：skill.words.2.3
语境：p.words.2.6

- [x] 小吏侵夺百姓财物的行为 {#q.words.2.6.o1}
- [ ] 百姓前来报告失田 {#q.words.2.6.o3}
  理由：县令命归还田地，文中没有责怪报信者。
- [ ] 所有在县中办事的小吏 {#q.words.2.6.o2}
  理由：“之侵渔百姓”限定了他厌恶的内容。

提示：从“侵渔百姓”往下找，哪件事让县令立即命人纠正？
解析：县令憎恶小吏侵夺百姓财物。一个官吏夺民田，就是文中举的实例。

## 知识点：乐 {#skill.words.2.4}
义项：以某事为乐
领域：实词
要诀：读“乐此”时，可接着问：做什么事让他觉得快乐？
讲解：同一件事，先是懂得，继而喜欢，再往深处才是“乐之”，做起来本身就觉得快乐。“乐”在这里读 lè。
例句：p.words.2.7

## 原文：古籍引文 {#p.words.2.7}
> 子曰：“知之者不如好之者，好之者不如乐之者。”
译文：孔子说，知道它的人不如喜爱它的人，喜爱它的人又不如以它为乐的人。
出处：《论语·雍也》节选

## 单选：同是做一件事，“乐之”比“好之”还多了什么？ {#q.words.2.7}
考点：skill.words.2.4
语境：p.words.2.7

- [x] 从这件事本身得到乐趣 {#q.words.2.7.o1}
- [ ] 知道这件事的名称 {#q.words.2.7.o3}
  理由：“知之”在排列之首，还没有说到喜欢与乐趣。
- [ ] 专门研究用乐器演奏它 {#q.words.2.7.o2}
  理由：三项共用“之”，文中未提音乐。

提示：“之”没有换对象，比较的是人对同一件事的态度。
解析：先是知道、进而喜爱，再到能从中得到乐趣。节选没有限定这件事必须是哪一门技艺。

## 原文：教学例句 {#p.words.2.8}
> 童习刻石，暮而众散，独留治其文。父问何不归，曰：“吾乐此耳。”
译文：孩子学刻石，天晚众人散去，他独自留下修整刻文。父亲问他为何不归，他说自己以这件事为乐。

## 单选：孩子说“吾乐此耳”，是喜欢做什么？ {#q.words.2.8}
考点：skill.words.2.4
语境：p.words.2.8

- [ ] 听见父亲催他回去 {#q.words.2.8.o2}
  理由：父亲发问在他独留以后。
- [x] 自愿留下修整石上刻文 {#q.words.2.8.o1}
- [ ] 傍晚大家散去 {#q.words.2.8.o3}
  理由：众散是场景，独留治文才是他自己的活动。

提示：大家散去后，孩子留下来还在做什么？
解析：“此”指修整石上的刻文。旁人散了，他还愿意留下，正因为他以此为乐。
