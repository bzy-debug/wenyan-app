# 课文：怜、爱、恶、乐 {#words.2}

简介：找出受感情所向的人或事，分清同情、吝惜、厌恶与乐在其中。

## 正文

见到“爱”先别只想到喜爱。齐王说自己何至于“爱一牛”，紧跟着解释自己不忍见牛战栗。**舍不得财物**和**不忍见其受苦**是两种可以用前后文检验的解释。

“恶”与“好”并列时要给两字分别找对象。在“好之者不如乐之者”里，“好”“乐”都带“之”；后一句又进一层，写做这件事本身已成为乐趣。

## 知识点：怜 {#skill.words.2.1}
义项：怜惜、体恤
领域：实词
要诀：看看人物见了谁的苦处，又为他做了什么。
讲解：“怜其……”可领起同情的对象或缘故。实际帮扶是判断这种态度的一条证据。
例句：p.words.2.1

## 原文：教学例句 {#p.words.2.1}
> 吏见负薪者跣行雪中，怜其寒，解履与之。
译文：小吏见背柴人赤脚行在雪中，体恤他受冻，把鞋脱下来给他。

## 单选：小吏所“怜”的对象和缘由如何配对？ {#q.words.2.1}
考点：skill.words.2.1
语境：p.words.2.1

- [ ] 小吏自己，因脱鞋受冻 {#q.words.2.1.o2}
  理由：脱鞋发生在起怜惜之情后。
- [x] 背柴人，因他雪中赤足受冻 {#q.words.2.1.o1}
- [ ] 柴草，因柴草受到雪压 {#q.words.2.1.o3}
  理由：“跣行”和受鞋的都是背柴人。

提示：从赠鞋回看先前观察到的处境。
解析：“怜其寒”写小吏体恤背柴人的寒苦，“解履与之”使这种态度落到行动。

## 原文：教学例句 {#p.words.2.2}
> 邻女昼夜织以奉其母，媪怜之，为代汲。
译文：邻家姑娘日夜织布供养母亲，老妇怜惜她劳苦，替她打水。

## 找原文证据：哪一处说明老妇体恤织者，愿替她分担？ {#q.words.2.2}
考点：skill.words.2.1
语境：p.words.2.2

- [ ] 昼夜织
  理由：这是老妇所见的劳苦。
- [x] 为代汲
- [ ] 以奉其母
  理由：奉养的人是织女，未交代老妇行动。

提示：找“媪怜之”后落到手上的事。
解析：“代”表示替别人承担汲水这件事，印证“怜”的具体对象。

## 知识点：爱 {#skill.words.2.2}
义项：吝惜、舍不得付出
领域：实词
要诀：辨清是在珍爱人，还是在计较所付出的财物。
讲解：当人们争论是否舍得一项财物时，“爱”可表吝惜；由所惜的对象及人物的辩解来定。
例句：p.words.2.3

## 原文：古籍引文 {#p.words.2.3}
> 齐国虽褊小，吾何爱一牛？即不忍其觳觫，若无罪而就死地，故以羊易之也。
译文：齐国纵然狭小，我何至于吝惜一头牛？只是不忍看它战栗，像无罪而走向死地，所以用羊换下了它。

## 单选：齐王说“吾何爱一牛”，他在为自己排除哪种动机？ {#q.words.2.3}
考点：skill.words.2.2
语境：p.words.2.3

- [ ] 看到牛害怕便不忍心 {#q.words.2.3.o2}
  理由：这是他接着承认的理由。
- [x] 舍不得拿出一头牛 {#q.words.2.3.o1}
- [ ] 不愿以羊换牛 {#q.words.2.3.o3}
  理由：“故以羊易之”明确说已决定换。

提示：把反问所否定的理由与“即不忍”所肯定的理由分开。
解析：“何爱”反问何至于吝惜牛的价值；后文用不忍见它战栗解释自己为何换羊。

## 原文：教学例句 {#p.words.2.4}
> 亭桥久坏，商贾愿出材，里正爱十金，不肯葺。
译文：亭桥损坏已久，商人愿意出木料，里正舍不得十金，不肯修理。

## 单选：把“里正爱十金”读作“吝惜钱财”，哪一点最有力？ {#q.words.2.4}
考点：skill.words.2.2
语境：p.words.2.4

- [x] 有材料可用，里正仍不肯花钱修桥 {#q.words.2.4.o1}
- [ ] 亭桥已经坏了很久 {#q.words.2.4.o2}
  理由：桥坏说明需要修，还没说里正态度。
- [ ] 商贾愿意出材料 {#q.words.2.4.o3}
  理由：慷慨出材的是商贾，并非里正。

提示：找“爱十金”之后由同一人作的决定。
解析：不肯修理与舍不得十金相互印证，前面愿出木料的商人恰好形成对照。

## 知识点：恶 {#skill.words.2.3}
义项：读 wù，厌恶
领域：实词
要诀：和“好”对照，分别问喜欢谁、厌恶谁。
讲解：作态度动词时，“恶”读 wù，后面可接人或事情。若读成形容人坏，就解释不了与“好”的平行关系。
例句：p.words.2.5

## 原文：古籍引文 {#p.words.2.5}
> 子曰：“唯仁者能好人，能恶人。”
译文：孔子说，只有有仁德的人才能恰当地喜欢人、厌恶人。
出处：《论语·里仁》节选

## 单选：“能好人，能恶人”中的第二个“人”起什么作用？ {#q.words.2.5}
考点：skill.words.2.3
语境：p.words.2.5

- [ ] 与“恶”合成一个名词，指坏人 {#q.words.2.5.o2}
  理由：两边都有“能”，相对的动词分别为好、恶。
- [x] 是“恶”（wù）的对象，与“好人”的人对应 {#q.words.2.5.o1}
- [ ] 是发出恶意的施事者 {#q.words.2.5.o3}
  理由：施事者在前面，是“仁者”。

提示：把两处“能”后面都读成“动作＋对象”。
解析：好与恶构成态度上的对举；“人”都是态度所向的对象。

## 原文：教学例句 {#p.words.2.6}
> 令恶吏之侵渔百姓，闻一吏夺民田，立命还之。
译文：县令厌恶属吏侵夺百姓利益，听说有小吏强占民田，当即命其归还。

## 单选：县令厌恶的具体是什么？ {#q.words.2.6}
考点：skill.words.2.3
语境：p.words.2.6

- [x] 小吏侵夺百姓财物的行为 {#q.words.2.6.o1}
- [ ] 百姓前来报告失田 {#q.words.2.6.o3}
  理由：县令命归还田地，文中没有责怪报信者。
- [ ] 所有在县中办事的小吏 {#q.words.2.6.o2}
  理由：“之侵渔百姓”限定了他厌恶的内容。

提示：将“吏之侵渔百姓”整个放在“恶”的后面。
解析：侵渔指侵夺，后一件夺田使所恶之事具体可见。

## 知识点：乐 {#skill.words.2.4}
义项：以某事为乐
领域：实词
要诀：问人物从哪件事本身得到快乐。
讲解：“乐之”将对象直接接在“乐”后，可译为做这件事自有乐趣。“乐”此时读 lè。
例句：p.words.2.7

## 原文：古籍引文 {#p.words.2.7}
> 子曰：“知之者不如好之者，好之者不如乐之者。”
译文：孔子说，知道它的人不如喜爱它的人，喜爱它的人又不如以它为乐的人。
出处：《论语·雍也》节选

## 单选：沿着“知之—好之”往下读，“乐之”多出哪一层？ {#q.words.2.7}
考点：skill.words.2.4
语境：p.words.2.7

- [x] 从这件事本身得到乐趣 {#q.words.2.7.o1}
- [ ] 知道这件事的名称 {#q.words.2.7.o3}
  理由：“知之”在排列之首，还没有说到喜欢与乐趣。
- [ ] 专门研究用乐器演奏它 {#q.words.2.7.o2}
  理由：三项共用“之”，文中未提音乐。

提示：注意三组词后面重复的字。
解析：同一对象引出三层态度；题目可以判断这种关系，单凭节选无需把“之”指定为某一门技艺。

## 原文：教学例句 {#p.words.2.8}
> 童习刻石，暮而众散，独留治其文。父问何不归，曰：“吾乐此耳。”
译文：孩子学刻石，天晚众人散去，他独自留下修整刻文。父亲问他为何不归，他说自己以这件事为乐。

## 单选：“吾乐此耳”中的“此”应接回哪里？ {#q.words.2.8}
考点：skill.words.2.4
语境：p.words.2.8

- [ ] 听见父亲催他回去 {#q.words.2.8.o2}
  理由：父亲发问在他独留以后。
- [x] 自愿留下修整石上刻文 {#q.words.2.8.o1}
- [ ] 傍晚大家散去 {#q.words.2.8.o3}
  理由：众散是场景，独留治文才是他自己的活动。

提示：找“独留”是为了做什么。
解析：“此”承具体活动，回答了为何众人散去他仍愿留下。
