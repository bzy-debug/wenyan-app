# 检查：在新情境中辨处境与态度 {#check.33}

## 原文：教学例句 {#p.words.check.33.1}
> 使者危言于君前，请薄征以安流民。君从之，流民始归其庐。
译文：使者在君前直言，请求减轻赋税以安顿流亡百姓。君主采纳，流亡百姓才返回住所。

## 单选：使者怎样说话，又希望谁安定下来？ {#q.words.check.33.1}
考点：skill.words.1.1
语境：p.words.check.33.1

- [ ] 他用危险的话吓住君主，让自己得到安逸 {#q.words.check.33.1.o2}
  理由：“请薄征”是建议，“安”后的“流民”是安顿对象。
- [x] 他直言请求减轻赋税，想让流民安定 {#q.words.check.33.1.o1}
- [ ] 他暗中不肯说话，生怕流民离开 {#q.words.check.33.1.o3}
  理由：“危言于君前”已明确开口。

提示：分别给“言”和“安”各找一个承接的动作。
解析：直谏见于请薄征，使流民安定见于“归其庐”，两个词分别写进言方式和政策所向。

## 原文：教学例句 {#p.words.check.33.2}
> 二骑疾至，告边粟将尽。主将不病敌至，独病无粮。
译文：两骑飞快到来，报告边地储粮将尽。主将不担心敌人到来，只担心缺粮。

## 单选：两处容易当作病患的词应怎样分别读？ {#q.words.check.33.2}
考点：skill.words.1.4
语境：p.words.check.33.2

- [ ] “疾至”是憎恶到来，“病无粮”是已经饿病 {#q.words.check.33.2.o3}
  理由：“不病……独病……”并列两件可忧之事，未写主将患病。
- [x] “疾至”是很快到来，“病无粮”是忧虑缺粮 {#q.words.check.33.2.o1}
- [ ] “疾至”指疾病蔓延，“病无粮”指骑手生病 {#q.words.check.33.2.o2}
  理由：来的是“二骑”，所报的是粮情。

提示：“疾”紧连哪个动作，“病”后又跟哪件事？
解析：前句写送报的速度，后句说明主将真正忧虑的是供应。

## 原文：教学例句 {#p.words.check.33.3}
> 医者怜贫妪，不取直。其徒爱一剂之资，欲索之。
译文：医生体恤贫苦的老妇，不收诊疗报酬。他的徒弟舍不得一剂药的费用，想讨回来。

## 单选：“怜”和“爱”各落在什么对象上？ {#q.words.check.33.3}
考点：skill.words.2.2
语境：p.words.check.33.3

- [ ] 两人都只因喜欢这味药而争执 {#q.words.check.33.3.o3}
  理由：医者的态度与贫妪相连，徒弟计较的是费用。
- [x] 医生体恤老妇，徒弟舍不得药钱 {#q.words.check.33.3.o1}
- [ ] 医生舍不得报酬，徒弟疼爱老妇 {#q.words.check.33.3.o2}
  理由：“不取直”是医生所为，“欲索之”是徒弟的主张。

提示：看“不取”与“欲索”分别是谁的决定。
解析：这两字虽都可写情感，句中一处向人、一处向财，后面的行动也正相反。

## 原文：教学例句 {#p.words.check.33.4}
> 生乐闻己过，恶面誉而背讥者。友直言其失，生起谢之。
译文：学生乐于听人指出自己的过失，厌恶当面恭维却背后讥讽的人。朋友直说他的差错，他起身表示感谢。

## 单选：朋友提醒他犯错，为什么得到感谢？ {#q.words.check.33.4}
考点：skill.words.2.3
语境：p.words.check.33.4

- [x] 他乐于闻过，所恶的是当面捧、背后讥的做法 {#q.words.check.33.4.o1}
- [ ] 他喜欢别人只当面称赞自己的优点 {#q.words.check.33.4.o3}
  理由：“恶面誉而背讥者”给这一做法的是负面评价。
- [ ] 他厌恶一切批评，所以起身驱赶朋友 {#q.words.check.33.4.o2}
  理由：“谢之”在这段叙述中是感谢，朋友的直言合前句所乐。

提示：先分开“乐”与“恶”的对象，再对照朋友做了什么。
解析：当面坦直指出过失符合闻过所乐，与口头恭维、背后讥讽恰好不同。

## 原文：教学例句 {#p.words.check.33.5}
> 师戒门人曰：“穷而无位，犹可教乡人；达而主郡，尤当念民饥。”
译文：老师告诫学生说，不得志、没有官位时尚可教导乡人；得志而主持一郡事务，尤其该关心百姓饥苦。

## 单选：若译成“从前没钱、后来发财”，哪组线索会失去解释？ {#q.words.check.33.5}
考点：skill.words.3.2
语境：p.words.check.33.5

- [ ] 犹可／尤当 {#q.words.check.33.5.o3}
  理由：这是衡量可做和该做的程度，本身没说身份。
- [ ] 教乡人／民饥 {#q.words.check.33.5.o2}
  理由：这两项是可以做的事与关心的事，并非处境对举的直接标志。
- [x] 无位／主郡 {#q.words.check.33.5.o1}

提示：紧靠“穷”“达”寻找并列的个人地位。
解析：有无任事地位解释了行动能影响的范围，原文没有报告门人钱财增减。

## 原文：教学例句 {#p.words.check.33.6}
> 寇困孤城，守将夜启北门，纵老弱出。黎明城陷，而老弱得全。
译文：贼兵围困孤城，守将夜间打开北门让年老体弱者出去。天亮城陷，那些人得以保全。

## 单选：末句要求怎样分清“困”与“全”的对象？ {#q.words.check.33.6}
考点：skill.words.3.4
语境：p.words.check.33.6

- [x] 被围后来失陷的是城，得以保住的是先离开的老弱 {#q.words.check.33.6.o1}
- [ ] 贼兵被困，靠守将开门才全部脱身 {#q.words.check.33.6.o3}
  理由：“纵老弱出”明确开门放走的是老弱。
- [ ] 城已全保，老弱仍困在城里 {#q.words.check.33.6.o2}
  理由：“城陷”与“老弱得全”分别给出两种结局。

提示：把末句的两个主语分别接回前文。
解析：围城、开门、城陷各有先后。保全了部分人，不能推出全城也获保。
