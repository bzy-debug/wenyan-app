## 原文：教学例句 {#p.check.33.r2}
> 甲抄：羣馬蚤出，日中而返。乙抄：群馬蚤出，日中而返。查检小条：羣，转查群；蚤，虫名，也可借写早。
译文：两种抄法都是群马很早出发，中午回来。羣、群有字形表的回指，蚤则要按出发的时间判读。两抄为教学自编。
词注：日中：正午。
  返：回来。

## 原文：古籍引文 {#p.check.33.r3}
> 國君則平衡，大夫則綏之，士則提之。注：綏讀曰妥，妥之謂下於心。
译文：捧持器物时，对国君之器，捧到与心口齐平；对大夫之器，捧得再低些；对士之器，还要提奉在下。郑玄注说，这里的綏读为妥，意指低于心口。
词注：平衡：按上文说的衡量标准，捧到与心口齐平。
  下於心：低于心口。
出处：《礼记注疏·曲礼下》执器一节及郑玄注，节录

## 原文：教学例句 {#p.check.33.r4}
> 习读样条（教学自拟，示范今音）：湄，水边，读若眉。
> 读者误写：“眉即水边。”
译文：此样条是用眉提示湄的读音，并没有说面上的眉毛就是水边。
词注：湄：水边，读 méi。

## 单选：字条说“取”古书中也可表示迎娶，后常专写“娶”。在此处哪处搭配支持它？ {#q.check.33.1}
考点：skill.d33.split
语境：p.check.33.r1

- [ ] “必告”是一定夺取，所以取只能指抢夺 {#q.check.33.1.o1}
  理由：“告父母”说要禀告，并没有写抢夺。
- [ ] “取妻”是妻子前去拿一件东西 {#q.check.33.1.o2}
  理由：“妻”接在取后，整句问如何成婚。
- [x] “取妻”后还谈告父母，正说婚事 {#q.check.33.1.o3}
  理由：取在这里是娶妻。后起的娶能说明这一词义，不能用来解释别处所有“取”字。

提示：看诗句询问的是一件怎样的人生大事。
解析：取在这里是娶妻。后起的娶能说明这一词义，不能用来解释别处所有“取”字。

## 单选：只摘这两句作读书卡，哪张卡既交代古书原字，又便于今天阅读？ {#q.check.33.2}
考点：skill.d33.record
语境：p.check.33.r1

- [ ] 原文抄“娶妻”，注明系逐字照录此页 {#q.check.33.2.o1}
  理由：本页的字是取，说成照录就少了原貌。
- [x] 原文抄“取妻”，旁注“娶妻” {#q.check.33.2.o2}
  理由：引文保留这个底本的取，释义交代在婚事中读成娶。这样读者能回到原页核字。
- [ ] 原文抄“取妻”，旁注“取和娶无论何处均同义” {#q.check.33.2.o3}
  理由：婚姻语境可这样读；一般拿取物品不能改说迎娶。

提示：检查“引文”和“旁注”各需要承担什么。
解析：引文保留这个底本的取，释义交代在婚事中读成娶。这样读者能回到原页核字。

## 单选：为何能把“蚤出”说成早出，却不把原句的蚤认成早的无条件异体？ {#q.check.33.4}
考点：skill.d33.loan
语境：p.check.33.r2

- [ ] “群马”身上会有跳蚤，因此必是在驱虫 {#q.check.33.4.o1}
  理由：句中写出、返的行程，没有捉虫或驱虫的动作。
- [ ] 甲乙两抄“蚤”都一样，说明蚤是早的正式简体 {#q.check.33.4.o2}
  理由：两本同写蚤只说明这处无异文，不能证明简繁关系。
- [x] “出”与“日中而返”构成行程时间，支持此处借写早 {#q.check.33.4.o3}
  理由：行程中的蚤是早，字条还列明其虫名义，两种情况不能一并换写。

提示：靠哪条信息能在“虫名”和“迟早”之间选择？
解析：行程中的蚤是早，字条还列明其虫名义，两种情况不能一并换写。

## 单选：郑玄在“綏读曰妥”后补“下于心”，这里应当怎样写旁注？ {#q.check.33.5}
考点：skill.d33.substitute
语境：p.check.33.r3

- [ ] 经文写妥，郑玄另提出綏，意在使人安心 {#q.check.33.5.o1}
  理由：术语前后恰好抄反，“心”在“下于心”里是参照高度。
- [x] 经文写綏，依郑注读作妥，说的是执器高度低于心口 {#q.check.33.5.o2}
  理由：郑注用妥解这处綏。下于心口是他对行为的说明，旁注要连同这个理由保留。
- [ ] 只记綏和妥音似，不必理会所释的高度 {#q.check.33.5.o3}
  理由：郑注明说“下於心”，给了这段礼仪动作的含义。

提示：先认“读曰”后面的字，再看紧接的解释。
解析：郑注用妥解这处綏。下于心口是他对行为的说明，旁注要连同这个理由保留。

## 单选：怎样改这位读者的笔记，才忠实于眼前的样条？ {#q.check.33.6}
考点：skill.d33.sound
语境：p.check.33.r4

- [ ] 水边可写眉或湄，须把两字收入异体表 {#q.check.33.6.o1}
  理由：样条没有“异体”或“同字”说明，只在“读若”后给眉。
- [x] 湄指水边，此处用眉提示今音 {#q.check.33.6.o2}
  理由：“水边”解释湄；“眉”提示其音。本条没有任何说明把眉毛和水边当成同一个词。
- [ ] 把“水边”删除，这条注只说读音 {#q.check.33.6.o3}
  理由：样条明列水边作为定义，一并删掉就少了一项实在的信息。

提示：把逗号前后的两类信息各写一遍。
解析：“水边”解释湄；“眉”提示其音。本条没有任何说明把眉毛和水边当成同一个词。
