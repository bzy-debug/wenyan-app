# 课文：“民之望之”，两个“之”各连什么 {#g25.1}
简介：先问谁盼谁，再看看整件事被拿来比作什么。

## 正文

“吾闻舟之至”中，“舟至”本来就能说成一句话。现在说“我听说……”，我听说的便是船到这件事。“之”夹在舟与至之间，不必译成船“的”什么。换成“舟至，吾迎之”，后一个“之”却能换成船。

试读“子之武城”。这里找不到另一个说孔子行动的字；武城又是地名，“之”自己便是“前往”。一见“之”便删，会把这一趟行程一起删掉。

## 知识点：主谓之间的“之” {#g25.skill.clause}
义项：把“某人做某事”作为一整件事来谈
领域：句法
要诀：暂遮住“之”，试读谁怎样；再把整组接回原句。
讲解：“吾喜母之安”里，“母安”已经说全一件事。高兴的是母亲平安，不是高兴得到母亲的某件东西。
例句：g25.ex.clause

## 原文：教学例句 {#g25.ex.clause}
> 里人喜雨之至。
译文：乡人高兴雨来了。

## 知识点：之带目的地 {#g25.skill.go}
义项：向某处去
领域：实词
要诀：看它后面是不是地名，再找同一个人到达后的行动。
讲解：读“使者之赵”可以问“往何处”。“使者之至”却应问“谁到了”，两句虽都有使者，所写的关系不同。
例句：g25.ex.go

## 原文：教学例句 {#g25.ex.go}
> 弟之郊，暮乃归。
译文：弟弟到郊外去，傍晚才回来。

## 单选：“民之望之”里，哪一个“之”能换成百姓盼着来的人？ {#g25.1.q1}
考点：g25.skill.clause
语境：g25.1.p.hope

- [ ] “民”后面的一个
  理由：“民望”本来就是百姓在盼，前一个“之”把主语和动作连在一起。
- [x] “望”后面的一个
- [ ] 两个都能换
  理由：换了前一个，百姓和“望”的关系就说不通。

提示：试着问“百姓望谁”，答案该接在“望”哪一边？
解析：前一个“之”把百姓盼望的情形连成整体；后一个才给“望”补上对象。

## 单选：作者拿什么来同百姓的盼望相比较？ {#g25.1.q2}
考点：g25.skill.clause
语境：g25.1.p.hope

- [ ] 百姓的眼睛和天上的雨滴
  理由：两边都是“望”的情形，并不在比两件东西的形状。
- [x] 旱时盼望下雨的迫切
- [ ] 雨后的百姓已经见到来人
  理由：比方只写盼望，还没写盼到。

提示：两边各找出一个“望”，给它补上盼的事。
解析：“若”把两种盼望相连。先认出整件事，才知道比的是急切之情。

## 单选：若要把孔子的行程写在地图边，该抄哪一层意思？ {#g25.1.q3}
考点：g25.skill.go
语境：g25.1.p.town

- [ ] 他听见一种名叫武城的歌声
  理由：“武城”接在第一个“之”后，是此行所往。
- [x] 他到了武城，随后才记听见什么
- [ ] 他离开武城后一路唱歌
  理由：唱歌的人没有说是孔子，“闻”写的是他听到。

提示：先看看“子”后有没有别的字在写出行。
解析：“子之武城”有出行的人和目的地，“之”在这里就是前往。“弦歌之声”才说什么声音。

## 找原文证据：哪一组字是到了地方以后才记下的见闻？ {#g25.1.q4}
考点：g25.skill.go
语境：g25.1.p.town

- [ ] 子
  理由：这是孔子的称谓，还不知道他听见了什么。
- [x] 闻弦歌之声
- [ ] 武城
  理由：城名只交代所到之处。

提示：把行程与听觉分成前后两步。
解析：前一句先交代去处，后一句才写在那儿听见的声音。

## 原文：教学例句 {#g25.1.p.letter}
> 兄之齐，寄书告安。弟未得书，闻商言兄之病，忧之。及书至，乃知兄已愈。
译文：哥哥去了齐国，写信回来报平安。弟弟还没收到信，听商人说哥哥患病，十分担心。等信到了，才知道哥哥已病愈。
词注：愈：病好了。
  及：等到，这里等的是书信送达。

## 单选：弟弟那时从商人那里听到了什么？ {#g25.1.q5}
考点：g25.skill.clause
语境：g25.1.p.letter

- [x] 哥哥患病这件事
- [ ] 哥哥的病已经痊愈
  理由：病愈是信到后才知道。
- [ ] 哥哥让商人到别处寻药
  理由：“兄之病”没写遣人寻药。

提示：把“兄之病”读成“哥哥病了”，再接“商言”。
解析：“兄之齐”写去齐国，“兄之病”却把谁病了连作商人所说的内容。弟弟当时也只听到了传话。

## 排序：先后有哪些消息到了弟弟这里？按哥哥出行后的经过排列。 {#g25.1.q6}
考点：g25.skill.go
语境：g25.1.p.letter

- [2] 弟未得信，听商人说哥哥病了
  理由：听商人说时，还没读到信。
- [3] 信到后得知病已好
  理由：“及书至”才给弟弟另一个消息。
- [1] 哥哥去齐，写信报安
  理由：起首写“兄之齐，寄书告安”。

提示：写信和收到信是两个时刻。
解析：“之齐”交代人在何处。信虽已寄出，到弟弟手里还需时间，故商人的话先传到。

## 原文：教学例句 {#g25.1.p.wait}
> 客将之郡。友问归期，答曰：“吾之归也，必在麦熟后。”友遂约秋相见。
译文：客人将去郡城。朋友问何时回来，他答道：“我回来，一定在麦熟以后。”朋友于是约好秋天见面。
词注：郡：此处指郡城。
  期：约定或预计的时间。

## 单选：听到“将之郡”，朋友这才为什么事开口？ {#g25.1.q7}
考点：g25.skill.go
语境：g25.1.p.wait

- [ ] 人已经在归路，他想打听路有多长
  理由：“将”放在去郡城前，回答也说未来。
- [x] 人要出门，他想知道几时能回来
- [ ] 他也要去郡城，请求同行
  理由：答话只给归期，未安排同行。

提示：一个“将”把到郡这件事放在何时？
解析：“将之郡”是还要出行。问话自然接着问回来的时候。

## 找原文证据：若在日历上记“吾之归也”，哪几个字替它标了日期范围？ {#g25.1.q8}
考点：g25.skill.clause
语境：g25.1.p.wait

- [ ] 秋相见
  理由：这是朋友听完后另订的见面之约。
- [ ] 将之郡
  理由：这说去向，并非归期。
- [x] 麦熟后

提示：找客人自己答“归期”的话。
解析：“吾之归”把回来作为所谈的事，“必在麦熟后”才是对这件事定的时间。
