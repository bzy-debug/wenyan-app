# 课文：被特意提到前面的那个人 {#g25.2}
简介：从“唯令是听”还原听谁的令，从“尔是过”认清被责备的是谁。

## 正文

“众人唯老匠之言是听”，试着换回“众人只听老匠的话”。“听”落在末尾，听的对象放在了前面。“是”在这里把已经提出的对象同动作接住，不能读成“老匠的话是听”。

相同意思也可用“之”提宾。《孟子》说有人“惟弈秋之为听”，正在下棋的那个人只留心弈秋所教。若换成“弈秋之来，众皆喜”，“来”的还是弈秋本人，句子的读法又换了。

## 知识点：用“是”提起动作的对象 {#g25.skill.shi-first}
义项：将被听从、被责怪等对象提到动词前
领域：句法
要诀：把“是”前的对象移回动词后，谁做、对谁做还能说通吗？
讲解：“唯贤是举”可以还作“只举荐贤人”。“贤”指被举荐的人；谁来举荐要从更大的句子中找。
例句：g25.ex.shi-first

## 原文：教学例句 {#g25.ex.shi-first}
> 众唯老吏之令是从。
译文：众人只听从老吏的号令。

## 知识点：用“之”提起动作的对象 {#g25.skill.zhi-first}
义项：“唯甲之听”强调只听甲
领域：句法
要诀：先找最后的动作，再问“听谁的”“取哪样”。
讲解：“唯实之求”可读成“只求实情”。这里的“之”引出动词，与“客之来”中把客与来连成一件事不同。
例句：g25.ex.zhi-first

## 原文：教学例句 {#g25.ex.zhi-first}
> 取材之际，匠唯坚木之求。
译文：选材时，木匠只寻求坚实的木料。

## 单选：读到“听”才知道，前面特意提起的弈秋是听讲的人，还是学生听从的人？ {#g25.2.q1}
考点：g25.skill.zhi-first
语境：g25.2.p.chess

- [ ] 弈秋听从这个学生
  理由：前面明说由弈秋教两人。
- [x] 学生听从弈秋
- [ ] 两个学生都只听这一个学生
  理由：“其一人”只写到学生中的一位。

提示：把字序换成“其一人惟听……”试读。
解析：“惟弈秋之为听”是较长的一种提宾格式。开头已说弈秋作教师，末尾这位学生把心思放在老师的话上。

## 找原文证据：哪几个字限定了后半句只是在说两名学生中的一个？ {#g25.2.q2}
考点：g25.skill.zhi-first
语境：g25.2.p.chess

- [ ] 惟弈秋
  理由：这些字限定这名学生听谁，并不挑选哪名学生。
- [ ] 诲二人弈
  理由：这是整组受教的人数。
- [x] 其一人

提示：两个“只”容易混在一起：谁听讲，与听谁讲不同。
解析：“其一人”选出学生，“惟弈秋”再指定这名学生所听从的老师。

## 单选：孔子喊“求”后说“尔是过”，该把“尔”放回哪一处？ {#g25.2.q3}
考点：g25.skill.shi-first
语境：g25.2.p.blame

- [ ] 放到“求”后读成“请求你”
  理由：“求”是孔子叫冉求的名字。
- [x] 放到“过”后，作被责备的对象
- [ ] 放到“过”前作责备别人的人
  理由：“尔是过”把动词所及的对象提了出来。

提示：若将“过”读作责备，孔子把矛头指向谁？
解析：“尔是过”相当于“过尔”。孔子用问话提醒冉求承担责任，这一句没有写冉求去责备别人。

## 原文：教学例句 {#g25.2.p.order}
> 吏约舟人曰：“潮急，众唯鼓是听，一鼓解缆，未鼓勿发。”客虽呼舟，舟人不应。及鼓，乃行。
译文：官吏同船夫约定：“潮急，大家只听鼓声为号，一通鼓就解缆，没响就别开船。”客人虽呼喊，船夫不理会。等鼓响了，才开船。
词注：缆：系船的绳。
  发：这里指船启程。

## 单选：若把“唯鼓是听”理解成听到任何声音都可离岸，哪个细节首先讲不通？ {#g25.2.q4}
考点：g25.skill.shi-first
语境：g25.2.p.order

- [x] 客呼舟而舟人不应
- [ ] 潮急，必须约定信号
  理由：急流解释为何谨慎，不能单独指出哪个信号有效。
- [ ] 众人都在江边
  理由：在江边不能说明约定听哪种声音。

提示：有两种可听见的声音，哪一种没让船开？
解析：“鼓”是听候的唯一号令。客人的呼喊也是声响，船夫却不应，正显出这个限制。

## 排序：船夫依据什么先等候、后启程？ {#g25.2.q5}
考点：g25.skill.shi-first
语境：g25.2.p.order

- [2] 客人呼船，船夫仍等
  理由：呼声不在约定之内。
- [1] 吏先指定只以鼓为号
  理由：说定信号，才谈能否解缆。
- [3] 鼓响后启程
  理由：“及鼓，乃行”交代最后的行动。

提示：先分辨发号的人和求船的人。
解析：有声音还不够，得是约定的那种声音。末句从行动上验证“鼓”正是“听”的对象。

## 原文：教学例句 {#g25.2.p.cloth}
> 织工择丝，曰：“吾唯白丝之取。”徒以朱丝进，工却之。及白丝至，乃受。
译文：织工选丝时说：“我只取白丝。”徒弟送上红丝，他退了回去。等白丝送到，才收下。
词注：朱：红色。
  却：退回，不接纳。

## 单选：将第一句写成“白丝取走了织工”，错误落在哪里？ {#g25.2.q6}
考点：g25.skill.zhi-first
语境：g25.2.p.cloth

- [ ] 织工没有取丝，只是看看颜色
  理由：末句已写到“乃受”。
- [ ] 织工希望徒弟替白丝选主人
  理由：前写织工择丝，后写他自己收下。
- [x] 白丝是他要取的物，不是取物的人

提示：动手选择的是“吾”，那“取”还缺什么？
解析：“唯白丝之取”强调取白丝。“却朱受白”是同一选择后来怎样落到实处。

## 原文：教学例句 {#g25.2.p.mirror}
> 令曰：“吾唯实是问。”吏以美辞对，令复问其验。史谓吏曰：“君问事实耳，非问辞之美也。”
译文：县令说：“我只问实情。”属吏用漂亮话回答，县令再追问有什么凭据。记录的小吏告诉他：“县令问的是事实，不是辞藻有多美。”

## 单选：“复问其验”怎样帮你认定“唯实是问”的重点？ {#g25.2.q7}
考点：g25.skill.shi-first
语境：g25.2.p.mirror

- [x] 县令还要凭据，光有漂亮话不够
- [ ] 县令只想知道下属是否会作文
  理由：末句明说没有问辞藻之美。
- [ ] 是事实开口问了县令
  理由：话说到最后，发问的一直是县令。

提示：谁在追问，“实”是问的人还是所问的事？
解析：把语序还作“只问实情”，美辞不足以作答，追问凭据便顺理成章。

## 单选：若把织工的“唯白丝之取”换成这一段的说法，哪一句只换字序，不换所取？ {#g25.2.q8}
考点：g25.skill.zhi-first
语境：g25.2.p.mirror

- [x] 吾唯白丝是取
- [ ] 吾唯白丝之至是候
  理由：这变成等白丝到来，不再说选择白丝。
- [ ] 吾唯取丝者是问
  理由：动作由取变成问，所问也成了取丝的人。

提示：保留“吾”“白丝”“取”三个成分，再试试提宾用的字。
解析：“唯甲之取”与“唯甲是取”都突出取甲。此处用织工的话回看县令的“唯实是问”。
