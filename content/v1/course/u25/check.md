# 检查：从一封来信和修渠的争议中辨对象 {#check.25}

## 原文：教学例句 {#check.25.p.letter}
> 客之楚，久不归。其子闻邻言父之病，欲往省。适父书至，曰：“吾病已瘳，惟家书是待。”子乃止行，作书报之。
译文：客人去了楚地，久久没回家。儿子听邻人说父亲病了，想去探望。恰好父亲的信到了，信上说：“我的病已经好了，只盼家里的信。”儿子便不再动身，写信回报。
词注：省：读 xǐng，探望。
  适：恰好。
  瘳：读 chōu，病好。

## 单选：邻人的话和父亲的信为什么使儿子作出不同决定？ {#check.25.q1}
考点：g25.skill.clause
语境：check.25.p.letter

- [ ] 邻人受邀去探望，父亲叫他等信
  理由：想动身的是儿子，信寄到的也是家中。
- [x] 邻人说父亲病了，父亲后来自己写信说已好
- [ ] 两人都在报告父亲去楚的日期
  理由：“父之病”写身体状况，“已瘳”也不谈日期。

提示：给“闻”的内容和信里的“已瘳”分别标时间。
解析：“父之病”整体是邻人所言。家信更新了消息，儿子才从打算探望改为写信。

## 单选：父亲说“惟家书是待”，后来谁做了能满足这份期待的事？ {#check.25.q2}
考点：g25.skill.shi-first
语境：check.25.p.letter

- [ ] 邻人带儿子即日出门
  理由：儿子已止行。
- [ ] 父亲先寄了报平安的信就无需回信
  理由：他在那封信里还明确表示在等家书。
- [x] 儿子提笔回信

提示：先读成“只等家书”，再找谁能从家中写来。
解析：所待是从家里来的信，并非父亲已经寄出的这一封。儿子的动作和它恰好相应。

## 排序：两地之间的行动和消息怎样衔接？ {#check.25.q3}
考点：g25.skill.go
语境：check.25.p.letter

- [2] 儿闻病讯，打算前往
  理由：儿只到“欲往”，还未动身。
- [3] 父信到了，儿改写家书
  理由：看过来信才有止行之举。
- [1] 父往楚，久未归家
  理由：“客之楚”先说明父亲在哪儿。

提示：别把“之楚”的人和“欲往”的人合成一个。
解析：父亲已出行，儿子只想出行。新信赶在动身前到了，往返最后是由书信完成的。

## 原文：教学例句 {#check.25.p.canal}
> 田缺水，父子寻泉所从出，得之于山后。父问：“何以引水？”子指竹曰：“此所以通水也。”父先归，邻翁与子伐竹。子归，父问所与伐者，子举邻翁名，又曰：“吾所以迟者，竹密难行也。”
译文：田里缺水，父子寻到泉源，在山后找到了。父亲问：“用什么引水？”儿子指着竹子说：“可以用它通水。”父亲先回去了，邻家的老人同儿子一道伐竹。儿子回来后父亲问同他伐竹的人是谁，儿子说出邻翁的名字，又说：“我回来迟，因为竹林密，路难走。”
词注：伐：砍。
  密：竹子长得密，难以通过。

## 找原文证据：要在图上标出泉源，哪几个字给了位置？ {#check.25.q4}
考点：g25.skill.route
语境：check.25.p.canal

- [ ] 竹密难行
  理由：这是林中状况，不能用来标泉源。
- [ ] 田缺水
  理由：这是父子动身的缘故。
- [x] 于山后

提示：把“得之”同父子先前寻的东西连起来。
解析：找的是水所从出的地点，“于山后”标明找见的位置。

## 单选：父亲问“所与伐者”，哪一个答法会把伐竹对象与同伴弄反？ {#check.25.q5}
考点：g25.skill.companion
语境：check.25.p.canal

- [x] 答“山后的竹”，拿被砍的东西当成同行的人
- [ ] 答“邻翁”，说出同伐者的身份
  理由：“邻翁与子伐竹”已交代两人同做。
- [ ] 答出邻翁姓名
  理由：原文明说儿子举出了名字。

提示：“伐什么”和“与谁伐”，缺的是同一样东西吗？
解析：竹子被伐，邻翁一起伐；父亲问的是“与”后的那个人。

## 单选：前后两次“所以”，能用竹子和晚归的两件事分别说明吗？ {#check.25.q6}
考点：g25.skill.means
语境：check.25.p.canal

- [x] 竹子是引水所凭，竹密难行是迟归的缘故
- [ ] 竹子是迟归的人，竹林是引水的终点
  理由：前面缺水在田里，后面迟归的是儿子。
- [ ] 两处都说“于是”，不必理会后面答什么
  理由：“此”指竹，“竹密难行”答为什么迟，两处各有具体内容。

提示：把父亲的“何以引水”同儿子自解“所以迟”对着读。
解析：能引水的是竹筒，路难走却是耽误行程的原因。两处“以”要求填的内容不同。
