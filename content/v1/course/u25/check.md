# 检查：读懂任官与治事综合练习 {#check.25}

## 原文：教学例句 {#p.vocab.check.25.1}
> 乡人举生于郡。郡先察其行，三月后，书至，除生为书佐。生乃辞家赴府。
译文：乡人向郡里推荐书生。郡里先考察他的品行，三个月后任书到来，授予他书佐之职。他这才辞家到官府赴任。

## 单选：乡人在这条任职链中做了什么？ {#q.vocab.check.25.1}
考点：skill.vocab.13.1
语境：p.vocab.check.25.1

- [x] 提出人选 {#q.vocab.check.25.1.o1}
- [ ] 替书生赴府 {#q.vocab.check.25.1.o2}
  理由：赴府者是书生。
- [ ] 发出任书 {#q.vocab.check.25.1.o3}
  理由：任书在郡里考察后才来。

提示：举谁、由谁来选用，可以帮助识别荐举。
解析：“举生于郡”使候选人进入郡里的考察范围。

## 单选：哪一步使书生有了确定的新职？ {#q.vocab.check.25.2}
考点：skill.vocab.13.3
语境：p.vocab.check.25.1

- [ ] 受乡人推荐 {#q.vocab.check.25.2.o1}
  理由：其后还经过三个月考察。
- [ ] 辞别家人 {#q.vocab.check.25.2.o2}
  理由：已经受职后才辞家。
- [x] 授任书佐 {#q.vocab.check.25.2.o3}

提示：若接官名，且有赴任、领印等动作，要考虑授职义。
解析：“除生为书佐”明说职名与授任。

## 原文：教学例句 {#p.vocab.check.25.2}
> 县丞摄令事，令还，丞交印。令以仓事繁，复使丞领之，丞职如故。
译文：县丞暂代县令的事务，县令回来，县丞交印。县令因粮仓事务繁多，又让县丞兼管，县丞的本职照旧。

## 找原文证据：哪处表示代理县令的期限已到？ {#q.vocab.check.25.3}
考点：skill.vocab.14.2
语境：p.vocab.check.25.2

- [ ] 丞职如故 {#q.vocab.check.25.3.o1}
  理由：交代兼领仓事时的本职。
- [x] 令还，丞交印 {#q.vocab.check.25.3.o2}
- [ ] 令事 {#q.vocab.check.25.3.o3}
  理由：说的是被代理的事务。

提示：找原任缺席与复归的边界。
解析：县令回来，县丞交还代理所用的官印。

## 单选：后来“领之”有怎样的职责变化？ {#q.vocab.check.25.4}
考点：skill.vocab.14.1
语境：p.vocab.check.25.2

- [ ] 接任县令不再做丞 {#q.vocab.check.25.4.o1}
  理由：县令已回，本职如故。
- [x] 保留县丞本职并兼管仓事 {#q.vocab.check.25.4.o2}
- [ ] 丢掉本职只管仓 {#q.vocab.check.25.4.o3}
  理由：末句明确说明本职如故。

提示：兼办时原职还在，另有一项职掌。
解析：“之”承仓事，“如故”说明旧职仍在。

## 原文：教学例句 {#p.vocab.check.25.3}
> 吏甲典仓，乙典簿。守令乙按去年出粟之数，乙持旧券来，所记皆合。
译文：甲吏掌管仓库，乙吏掌管簿籍。郡守命乙查验去年发粮的数量，乙拿着旧凭据过来，记录都相符。

## 单选：平时保管簿籍的是谁？ {#q.vocab.check.25.5}
考点：skill.vocab.15.2
语境：p.vocab.check.25.3

- [ ] 郡守 {#q.vocab.check.25.5.o1}
  理由：他发出查验命令。
- [x] 乙吏 {#q.vocab.check.25.5.o2}
- [ ] 甲吏 {#q.vocab.check.25.5.o3}
  理由：“甲典仓”所管为仓。

提示：若接所掌的仓库、文书等，先读作职掌。
解析：“乙典簿”在句首先说明乙的本职。

## 单选：如何理解“按去年出粟之数”？ {#q.vocab.check.25.6}
考点：skill.vocab.15.3
语境：p.vocab.check.25.3

- [ ] 要求甲重新发粮 {#q.vocab.check.25.6.o1}
  理由：查的是“去年”的数。
- [x] 凭旧记录核验发粮数 {#q.vocab.check.25.6.o2}
- [ ] 亲自搬运全部库存 {#q.vocab.check.25.6.o3}
  理由：乙带来的物是旧券。

提示：看所按对象是否为案卷、登记或事实。
解析：“旧券”和“所记皆合”分别交代凭据与核验结果。
