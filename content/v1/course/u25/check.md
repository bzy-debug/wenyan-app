# 检查：从举荐到任官 {#check.25}

## 原文：教学例句 {#p.vocab.check.25.1}
> 乡人举生于郡。郡先察其行，三月后，书至，除生为书佐。生乃辞家赴府。
译文：乡人向郡里推荐书生。郡里先考察他的品行，三个月后任书到来，授予他书佐之职。他这才辞别家人，到郡府赴任。

## 单选：书生后来做了书佐，乡人最初替他做了什么？ {#q.vocab.check.25.1}
考点：skill.vocab.13.1
语境：p.vocab.check.25.1

- [x] 提出人选 {#q.vocab.check.25.1.o1}
- [ ] 替书生赴府 {#q.vocab.check.25.1.o2}
  理由：辞家赴府的是书生本人。
- [ ] 发出任书 {#q.vocab.check.25.1.o3}
  理由：乡人推荐时任书还没来，中间隔着三个月的考察。

提示：从“乡人举生于郡”里找出乡人把谁交给郡里考察。
解析：乡人先向郡里推荐书生。考察和任命，是郡里后来做的事。

## 单选：从什么时候起，书生才真正有了官职？ {#q.vocab.check.25.2}
考点：skill.vocab.13.3
语境：p.vocab.check.25.1

- [ ] 受乡人推荐 {#q.vocab.check.25.2.o1}
  理由：其后还经过三个月考察。
- [ ] 辞别家人 {#q.vocab.check.25.2.o2}
  理由：已经受职后才辞家。
- [x] 授任书佐 {#q.vocab.check.25.2.o3}

提示：乡人推举时并没有说授他什么职，后来文书上怎样写？
解析：“除生为书佐”正式授他书佐之职，他这才辞家去郡府。

## 原文：教学例句 {#p.vocab.check.25.2}
> 县丞摄令事，令还，丞交印。令以仓事繁，复使丞领之，丞职如故。
译文：县丞暂代县务，待县令回来便交还官印。县令因粮仓事务繁多，又让县丞兼管，县丞的本职照旧。

## 找原文证据：指出县丞结束代办县令职务的那一处。 {#q.vocab.check.25.3}
考点：skill.vocab.14.2
语境：p.vocab.check.25.2

- [ ] 丞职如故 {#q.vocab.check.25.3.o1}
  理由：“丞职如故”说县丞本职照旧，已经说到兼管仓事了。
- [x] 令还，丞交印 {#q.vocab.check.25.3.o2}
- [ ] 令事 {#q.vocab.check.25.3.o3}
  理由：“令事”说的是县令的事务，看不出何时交回去。

提示：一人回来，另一人随即交出了什么？
解析：县令回来，县丞把印交还。往后他兼管仓事，已是另一桩安排。

## 单选：县令又让县丞“领之”，县丞手里的差事有何变化？ {#q.vocab.check.25.4}
考点：skill.vocab.14.1
语境：p.vocab.check.25.2

- [ ] 接任县令不再做丞 {#q.vocab.check.25.4.o1}
  理由：县令自己已经回来，县丞还在原职上。
- [x] 保留县丞本职并兼管仓事 {#q.vocab.check.25.4.o2}
- [ ] 丢掉本职只管仓 {#q.vocab.check.25.4.o3}
  理由：末句特意交代“丞职如故”，本职还在。

提示：“之”接的是哪个差事？再看末句“丞职如故”。
解析：新添的是仓事，县丞原有的职务照旧，所以是兼管。

## 原文：教学例句 {#p.vocab.check.25.3}
> 吏甲典仓，乙典簿。守令乙按去年出粟之数，乙持旧券来，所记皆合。
译文：甲吏掌管仓库，乙吏掌管簿籍。郡守命乙查验去年发粮的数量，乙拿着旧凭据过来，记录都相符。

## 单选：郡守要核对簿册，平日管簿册的是谁？ {#q.vocab.check.25.5}
考点：skill.vocab.15.2
语境：p.vocab.check.25.3

- [ ] 郡守 {#q.vocab.check.25.5.o1}
  理由：他发出查验命令。
- [x] 乙吏 {#q.vocab.check.25.5.o2}
- [ ] 甲吏 {#q.vocab.check.25.5.o3}
  理由：“甲典仓”所管为仓。

提示：甲、乙各“典”什么？
解析：“乙典簿”交代乙掌管簿籍，所以查旧数的差事也交给了他。

## 单选：郡守叫乙“按去年出粟之数”，乙要做什么？ {#q.vocab.check.25.6}
考点：skill.vocab.15.3
语境：p.vocab.check.25.3

- [ ] 要求甲重新发粮 {#q.vocab.check.25.6.o1}
  理由：查的是“去年”的数。
- [x] 凭旧记录核验发粮数 {#q.vocab.check.25.6.o2}
- [ ] 亲自搬运全部库存 {#q.vocab.check.25.6.o3}
  理由：乙带来的物是旧券。

提示：乙带来了“旧券”，后来又说“所记皆合”。
解析：乙拿旧凭据核对去年的放粮记录，发现数目相符。这就是郡守要他做的查验。
