# 课文：领、摄、罢、黜 {#vocab.14}
简介：同是换人办差，看看谁在兼任、谁在暂代，又有谁真正离了职。

## 正文

县令不在，请县丞代办公务，这是“摄”。如果县丞仍任原职，又管一座粮仓，则是“领”。读不清时，不急着背官名，先往后找一句：原来的人何时回来，印信交给了谁？

再看离职。文书只说“罢”，可以是免去职务，缘由还得另找。“黜”常用在查出过失、决定罢退不用之时。

## 知识点：领 {#skill.vocab.14.1}
义项：兼任
领域：实词
要诀：留意他原先管什么，如今又多管了什么。
讲解：“仍治县”说县令原来的差事照旧；“复领郡仓”说他另外还掌管郡仓，两份差事都在身上。
例句：p.vocab.14.1.example

## 原文：教学例句 {#p.vocab.14.1.example}
> 令仍治县，复领郡仓。
译文：县令仍治理本县，又兼管郡仓。

## 原文：教学例句 {#p.vocab.14.1.a}
> 丞不离本职，复领河渠之事。
译文：县丞没有离开原职，又兼管河渠事务。

## 单选：县丞没有离开本职，又“领”河渠之事。这个“领”怎么讲？ {#q.vocab.14.1}
考点：skill.vocab.14.1
语境：p.vocab.14.1.a

- [ ] 辞去原职 {#q.vocab.14.1.o1}
  理由：开头已说“不离本职”。
- [x] 兼任 {#q.vocab.14.1.o2}
- [ ] 领取物品 {#q.vocab.14.1.o3}
  理由：“河渠之事”是一项职掌。

提示：“不离本职”与“复”要连起来读。
解析：县丞原来的差事还在，又多管一摊河渠事务，是兼任。

## 原文：教学例句 {#p.vocab.14.1.b}
> 王命司徒领学事，每罢朝即往学宫。
译文：国君命司徒兼管学校事务，他每次退朝就去学宫。

## 单选：司徒退朝后还须去学宫。他现在多了什么差事？ {#q.vocab.14.2}
考点：skill.vocab.14.1
语境：p.vocab.14.1.b

- [x] 原职之外兼办学务 {#q.vocab.14.2.o1}
- [ ] 只当学生听讲 {#q.vocab.14.2.o2}
  理由：司徒“领学事”，是去管理学务；去学宫并不等于在那里做学生。
- [ ] 交卸全部朝务 {#q.vocab.14.2.o3}
  理由：他是在退朝以后去学宫，可见朝务还在。

提示：先退朝，再到学宫，一天里去了两处。
解析：司徒照旧上朝，另外还管学务，所以退朝后要赶到学宫。

## 知识点：摄 {#skill.vocab.14.2}
义项：暂时代理
领域：实词
要诀：代谁办差，又代到什么时候？
讲解：县令生病，县丞才“摄县事”。等到“令愈乃还印”，官印交还，县丞代办的日子也就结束了。
例句：p.vocab.14.2.example

## 原文：教学例句 {#p.vocab.14.2.example}
> 令病，丞摄县事，令愈乃还印。
译文：县令患病，县丞暂代县务，等县令病好了才把印交还给他。

## 原文：教学例句 {#p.vocab.14.2.a}
> 主簿出郡，书吏摄其事，约主簿还即止。
译文：主簿外出，书吏暂时代他办事，约好等他回来就交还。

## 单选：主簿外出时让书吏“摄其事”，书吏是怎样办这份差的？ {#q.vocab.14.3}
考点：skill.vocab.14.2
语境：p.vocab.14.2.a

- [ ] 摄取图像 {#q.vocab.14.3.o1}
  理由：主簿不在，书吏代办的是主簿的公务。
- [ ] 永久继任 {#q.vocab.14.3.o2}
  理由：两人约好“还即止”，主簿一回来便结束。
- [x] 暂时代理 {#q.vocab.14.3.o3}

提示：双方约好主簿一回来就怎样？
解析：书吏只在主簿外出这段日子代办。主簿回来，这份差事就交还。

## 原文：教学例句 {#p.vocab.14.2.e}
> 长史未到，命掾摄之，俟长史至则交印。
译文：长史还没到，命属官代理，等长史到了便交印。

## 找原文证据：哪一句说清了属吏什么时候要交回官印？ {#q.vocab.14.4}
考点：skill.vocab.14.2
语境：p.vocab.14.2.e

- [ ] 长史未到 {#q.vocab.14.4.o1}
  理由：长史没到，是请人暂代的缘由。
- [x] 俟长史至则交印 {#q.vocab.14.4.o2}
- [ ] 命掾 {#q.vocab.14.4.o3}
  理由：“命掾”只说派哪位属官，还没说代到何时。

提示：印交出去以后，他还用代长史办事吗？
解析：长史没有到任，属吏暂代；等长史一到就交印，代理到此结束。

## 知识点：罢 {#skill.vocab.14.3}
义项：免去职务
领域：实词
要诀：读到“罢”，看这个人还管不管原来的事。
讲解：“罢其尉职”后又收回他的官印，这名县尉便不再任职。单看“罢”字，还说不准为什么免职。
例句：p.vocab.14.3.example

## 原文：教学例句 {#p.vocab.14.3.example}
> 罢其尉职，收其印。
译文：免去他的县尉职务，收回官印。

## 原文：教学例句 {#p.vocab.14.3.a}
> 县丞因病请退，郡罢其职，听归养。
译文：县丞因病请求退职，郡里免去其职，准他回家休养。

## 单选：县丞因病请退，郡里“罢其职”，对他的职务作了怎样的安排？ {#q.vocab.14.5}
考点：skill.vocab.14.3
语境：p.vocab.14.3.a

- [ ] 暂休半日 {#q.vocab.14.5.o1}
  理由：当事人已请退并获准归养。
- [x] 免去职务 {#q.vocab.14.5.o2}
- [ ] 疲乏 {#q.vocab.14.5.o3}
  理由：“其职”是所罢的对象。

提示：他请求的是“退”，郡里随后又准他“归养”。
解析：县丞免职归家养病。这里交代了病因，不能把“罢”一概读作受罚。

## 原文：教学例句 {#p.vocab.14.3.b}
> 议罢冗吏三人，令交簿归里。
译文：议定免去三位冗员的职务，命他们交回簿册返乡。

## 单选：三名官吏交还簿册、回到乡里，他们的职务怎样了？ {#q.vocab.14.6}
考点：skill.vocab.14.3
语境：p.vocab.14.3.b

- [ ] 休沐后仍按旧例值班 {#q.vocab.14.6.o1}
  理由：三人已经交还簿册回乡，后面没说再来值班。
- [ ] 三人调任邻郡 {#q.vocab.14.6.o2}
  理由：他们回的是乡里，没说调往邻郡。
- [x] 三人已经离职 {#q.vocab.14.6.o3}

提示：文书交给别人，自己也回乡了。
解析：三人把公务交接完，便离开了原来的职位。

## 知识点：黜 {#skill.vocab.14.4}
义项：罢退不用
领域：实词
要诀：先看查出什么过失，再看原来的人还留不留。
讲解：查出官吏贪污，就“黜之而更择吏”。另择人来任事，可见原来那人已被罢退。
例句：p.vocab.14.4.example

## 原文：教学例句 {#p.vocab.14.4.example}
> 按得其贪，黜之而更择吏。
译文：查出他贪污，便将他罢免，另选官吏。

## 原文：教学例句 {#p.vocab.14.4.a}
> 守仓者盗米，事验，黜之，禁复入仓。
译文：管仓的人偷米，查实以后便将他撤职，不许他再进粮仓。

## 单选：守仓人偷米，查实后官府“黜之”，怎样处置了他？ {#q.vocab.14.7}
考点：skill.vocab.14.4
语境：p.vocab.14.4.a

- [ ] 遮盖过失 {#q.vocab.14.7.o1}
  理由：既已查实盗米，又禁其入仓，事情没有被掩盖。
- [x] 罢退不用 {#q.vocab.14.7.o2}
- [ ] 擢升 {#q.vocab.14.7.o3}
  理由：他连仓库也不得再进，哪里还获得升迁？

提示：留意“禁复入仓”：以后还让他管粮吗？
解析：盗米的事已查实，守仓人被撤下，此后不得再进仓。

## 原文：教学例句 {#p.vocab.14.4.b}
> 考诸吏，廉者留，贪者黜，榜示其名。
译文：考核众吏，廉洁者留任，贪污者罢退，张榜公布他们的名字。

## 单选：考核之后，哪些人被免去职务？ {#q.vocab.14.8}
考点：skill.vocab.14.4
语境：p.vocab.14.4.b

- [ ] 所有参加考核的人 {#q.vocab.14.8.o1}
  理由：廉者留任。
- [ ] 张榜的人 {#q.vocab.14.8.o2}
  理由：榜上公布的是考核结果。
- [x] 考核发现贪污的人 {#q.vocab.14.8.o3}

提示：把“廉者留”和“贪者黜”对着读。
解析：廉洁者留下，贪污者被罢退；榜上公布的就是这次考核的结果。
