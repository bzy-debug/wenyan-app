# 课文：领、摄、罢、黜 {#vocab.14}
简介：利用印信、任期和去留判断官吏身份。

## 正文

把“旧职是否仍在”“新职是否暂代”“离职原因是否受罚”分别记录。**领**可在原职之外兼管，**摄**常有暂代缘由；**罢**可只写免职，**黜**常见于贬退不用。仅见一个官名时，继续读交印、复任、兼办等线索。

## 知识点：领 {#skill.vocab.14.1}
义项：兼任
领域：实词
要诀：兼办时原职还在，另有一项职掌。
讲解：“令仍治县，复领郡仓”的“仍”保住旧职，“复”添上新职。县令同时治县与管仓，正是兼领。
例句：p.vocab.14.1.example

## 原文：教学例句 {#p.vocab.14.1.example}
> 令仍治县，复领郡仓。
译文：县令仍治理本县，又兼管郡仓。

## 原文：教学例句 {#p.vocab.14.1.a}
> 丞不离本职，复领河渠之事。
译文：县丞没有离开原职，又兼管河渠事务。

## 单选：这段话里的“领”是什么意思？ {#q.vocab.14.1}
考点：skill.vocab.14.1
语境：p.vocab.14.1.a

- [ ] 辞去原职 {#q.vocab.14.1.o1}
  理由：开头已说“不离本职”。
- [x] 兼任 {#q.vocab.14.1.o2}
- [ ] 领取物品 {#q.vocab.14.1.o3}
  理由：“河渠之事”是一项职掌。

提示：兼办时原职还在，另有一项职掌。
解析：“复”给原来的职位添了一项职责。

## 原文：教学例句 {#p.vocab.14.1.b}
> 王命司徒领学事，每罢朝即往学宫。
译文：国君命司徒兼管学校事务，他每次退朝就去学宫。

## 单选：“领学事”后司徒的工作怎样变化？ {#q.vocab.14.2}
考点：skill.vocab.14.1
语境：p.vocab.14.1.b

- [x] 原职之外兼办学务 {#q.vocab.14.2.o1}
- [ ] 只当学生听讲 {#q.vocab.14.2.o2}
  理由：“命……领”分派事务。
- [ ] 交卸全部朝务 {#q.vocab.14.2.o3}
  理由：他仍须上朝。

提示：兼办时原职还在，另有一项职掌。
解析：朝事与学事并行，符合兼领的情形。

## 知识点：摄 {#skill.vocab.14.2}
义项：暂时代理
领域：实词
要诀：找原任缺席与复归的边界。
讲解：“令病，丞摄县事”从县令患病起代理；读到“令愈乃还印”，代理的终点也明白了。
例句：p.vocab.14.2.example

## 原文：教学例句 {#p.vocab.14.2.example}
> 令病，丞摄县事，令愈乃还印。
译文：县令生病，县丞暂代县务，县令痊愈才还印。

## 原文：教学例句 {#p.vocab.14.2.a}
> 主簿出郡，书吏摄其事，约主簿还即止。
译文：主簿外出到郡里，书吏暂代理他的事务，约定主簿回来就停止。

## 单选：这段话里的“摄”是什么意思？ {#q.vocab.14.3}
考点：skill.vocab.14.2
语境：p.vocab.14.2.a

- [ ] 摄取图像 {#q.vocab.14.3.o1}
  理由：对象是职务。
- [ ] 永久继任 {#q.vocab.14.3.o2}
  理由：“还即止”限定了期限。
- [x] 暂时代理 {#q.vocab.14.3.o3}

提示：找原任缺席与复归的边界。
解析：原任一回来，代理便结束。

## 原文：教学例句 {#p.vocab.14.2.e}
> 长史未到，命掾摄之，俟长史至则交印。
译文：长史还没到，命属官代理，等长史到了便交印。

## 找原文证据：哪处给代理期划定终点？ {#q.vocab.14.4}
考点：skill.vocab.14.2
语境：p.vocab.14.2.e

- [ ] 长史未到 {#q.vocab.14.4.o1}
  理由：这是暂代的起因。
- [x] 俟长史至则交印 {#q.vocab.14.4.o2}
- [ ] 命掾 {#q.vocab.14.4.o3}
  理由：说的是人选。

提示：找原任缺席与复归的边界。
解析：交印表示暂时行使的权力归还本官。

## 知识点：罢 {#skill.vocab.14.3}
义项：免去职务
领域：实词
要诀：看收印、归里或交接是否显示职位终止。
讲解：“罢其尉职”紧接“收其印”。官印被收回，原来的尉职随之终止；免职缘由还须看别处记载。
例句：p.vocab.14.3.example

## 原文：教学例句 {#p.vocab.14.3.example}
> 罢其尉职，收其印。
译文：免去他的县尉职务，收回官印。

## 原文：教学例句 {#p.vocab.14.3.a}
> 县丞因病请退，郡罢其职，听归养。
译文：县丞因病请求退职，郡里免去其职，准他回家休养。

## 单选：这段话里的“罢”是什么意思？ {#q.vocab.14.5}
考点：skill.vocab.14.3
语境：p.vocab.14.3.a

- [ ] 暂休半日 {#q.vocab.14.5.o1}
  理由：当事人已请退并获准归养。
- [x] 免去职务 {#q.vocab.14.5.o2}
- [ ] 疲乏 {#q.vocab.14.5.o3}
  理由：“其职”是所罢的对象。

提示：看收印、归里或交接是否显示职位终止。
解析：这里写免职，不一定含惩罚。

## 原文：教学例句 {#p.vocab.14.3.b}
> 议罢冗吏三人，令交簿归里。
译文：议定免去三位冗员的职务，命他们交回簿册返乡。

## 单选：“交簿归里”意味着什么？ {#q.vocab.14.6}
考点：skill.vocab.14.3
语境：p.vocab.14.3.b

- [ ] 休沐后仍按旧例值班 {#q.vocab.14.6.o1}
  理由：交簿与“罢”相承。
- [ ] 三人调任邻郡 {#q.vocab.14.6.o2}
  理由：去处是乡里，并无新职。
- [x] 三人已经离职 {#q.vocab.14.6.o3}

提示：看收印、归里或交接是否显示职位终止。
解析：簿册移交、人员返乡，落实“罢”的结果。

## 知识点：黜 {#skill.vocab.14.4}
义项：罢退不用
领域：实词
要诀：关注过失、考核和被排除在职位之外的结果。
讲解：“按得其贪，黜之而更择吏”既交代贪墨被查出，又写改选别人。原吏失职受罚，位置也不再保留。
例句：p.vocab.14.4.example

## 原文：教学例句 {#p.vocab.14.4.example}
> 按得其贪，黜之而更择吏。
译文：查明他贪墨，将他罢退，另选官吏。

## 原文：教学例句 {#p.vocab.14.4.a}
> 守仓者盗米，事验，黜之，禁复入仓。
译文：看守仓库的人偷米，事情查实，把他罢退，禁止再进仓库。

## 单选：这段话里的“黜”是什么意思？ {#q.vocab.14.7}
考点：skill.vocab.14.4
语境：p.vocab.14.4.a

- [ ] 遮盖过失 {#q.vocab.14.7.o1}
  理由：事已查实并作处置。
- [x] 罢退不用 {#q.vocab.14.7.o2}
- [ ] 擢升 {#q.vocab.14.7.o3}
  理由：当事人被禁止再进仓库。

提示：关注过失、考核和被排除在职位之外的结果。
解析：处分从过失出发，以失去职务结束。

## 原文：教学例句 {#p.vocab.14.4.b}
> 考诸吏，廉者留，贪者黜，榜示其名。
译文：考核众吏，廉洁者留任，贪污者罢退，张榜公布他们的名字。

## 单选：哪一组受到“黜”的处置？ {#q.vocab.14.8}
考点：skill.vocab.14.4
语境：p.vocab.14.4.b

- [ ] 所有参加考核的人 {#q.vocab.14.8.o1}
  理由：廉者留任。
- [ ] 张榜的人 {#q.vocab.14.8.o2}
  理由：榜上公布的是考核结果。
- [x] 考核发现贪污的人 {#q.vocab.14.8.o3}

提示：关注过失、考核和被排除在职位之外的结果。
解析：“留”与“黜”是考核后的两种处理。
