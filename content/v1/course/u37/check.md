# 检查：孟子论易牛，乡人议修图 {#check.37}

## 原文：古籍引文 {#check.37.p.ox}
> 曰：“是心足以王矣。百姓皆以王为爱也，臣固知王之不忍也。”王曰：“然，诚有百姓者。齐国虽褊小，吾何爱一牛？即不忍其觳觫，若无罪而就死地，故以羊易之也。”曰：“王无异于百姓之以王为爱也。以小易大，彼恶知之？”
译文：孟子说：“有这样的心就足以行王道了。百姓都以为大王是吝惜，我本来就知道大王是不忍心。”齐王说：“是，的确有百姓这样想。齐国虽小，我哪里会舍不得一头牛？我只是不忍看它发抖，像没有罪却要走向死地，所以拿羊换了它。”孟子说：“对于百姓认为您吝惜，您不必奇怪。拿小的换下大的，他们怎么知道您的心思呢？”

## 单选：齐王先说“诚有百姓者”，再问“吾何爱一牛”。他承认了什么，又否认了什么？ {#check.37.q1}
考点：x37.ai-spare
语境：check.37.p.ox

- [ ] 承认自己爱财，否认百姓知道换过牛羊
  理由：齐王以“不忍其觳觫”说明动机；没有说换羊这件事无人知道。
- [ ] 承认也怜惜那只羊，否认自己怜惜发抖的牛
  理由：“不忍其觳觫”正是他解释为何放牛，没说羊也在面前发抖。
- [x] 承认确有百姓这样想，否认自己因吝惜一头牛才换羊

提示：谁作“以王为爱”的判断？“吾何爱”又出自谁？
解析：齐王确认的是百姓有这种看法。他用反问否认自己舍不得牛的价值，另以亲见的颤抖解释为何换羊。

## 单选：若把“臣固知王之不忍也”读成“我听了大王这番解释才明白”，对话何处就接不上？ {#check.37.q2}
考点：x37.gu-already
语境：check.37.p.ox

- [ ] 齐王先说“齐国虽褊小”，孟子才头一次谈到百姓
  理由：原文先引百姓看法，后有齐王的回应。
- [ ] “固”把百姓和孟子都写成同样知道齐王不忍
  理由：起初百姓是“以王为爱”，与孟子的判断不同。
- [x] 孟子先说自己本知道齐王不忍，齐王随后才解释发抖的牛

提示：从第一句孟子的话读到“王曰”，谁先把“不忍”说出口？
解析：“固知”在齐王讲“觳觫”以前已经说出口。这个“固”交代孟子原有的判断，并没有把过去的百姓也算作知情人。

## 单选：“以小易大，彼恶知之？”孟子这次替谁说明了什么难处？ {#check.37.q3}
考点：x37.wu-how
语境：check.37.p.ox

- [x] 替百姓说明，他们见小羊换下大牛，怎能据此知道齐王心里的不忍
- [ ] 替齐王说明，他厌恶百姓知道牛羊大小
  理由：“彼”接百姓，“恶知”追问他们如何得知，不是“厌恶知情”。
- [ ] 替百姓追问，他们怎么会不晓得羊比牛小
  理由：“以小易大”正是百姓看到的事实，难知的是换羊的动机。

提示：把眼睛能看见的交换，和别人心里才能知道的缘由分开。
解析：百姓可见小换大，却未必知道齐王因牛发抖而心软。“恶知”读作“怎么知道”，才接得上孟子请王不要奇怪。

## 原文：教学例句 {#check.37.p.map}
> 邑人将修水道图，请老工绘之。工曰：“吾善测浅深，然足病，不堪行远。子第携图来，吾为子辨近岸诸滩。”弟子乃航而测远滩，旬日而返。工合二图，曰：“大滩皆克定其处；细石不可胜标，举其碍舟者耳。”
译文：乡人要修订水道图，请老工匠来绘制。他说：“我擅长测水的深浅，但脚有病，经不起走远路。你只管把图拿来，我替你辨明近岸各滩。”徒弟于是坐船去测远处的浅滩，十天后回来。老工匠将两图合起来说：“大滩都能够定出位置。细石标不尽，只标其中妨碍行船的罢了。”
词注：航：此处指乘船前去。
  滩：水浅多石的地方。
  举：这里指挑出来标示。
  旬日：十天。

## 单选：老工既说“不堪行远”，又说“子第携图来”。他解释了什么，又准徒弟怎样做？ {#check.37.q4}
考点：x37.kan-bear
语境：check.37.p.map

- [ ] 他的脚受不了远行，要徒弟先给水图编号再送来
  理由：脚病确实是不能远行的原因；“第”用在“携图来”前，是让徒弟只管拿来，没提编号。
- [x] 他受不了远行，让徒弟只管带图来，近岸的浅深他仍能辨
- [ ] 他不擅长判水势，索性把全图交给徒弟一人去画
  理由：“善测浅深”和后来亲自合图，都说明他仍有判断的本领。

提示：“不堪”的是哪一件事？“第”后面又是哪一个人可以去做的动作？
解析：“不堪”落到远行，不能据此抹去老工的本领。“第”解除徒弟的顾虑，吩咐他尽管把图带来。

## 找原文证据：图合好了，哪几个字明确说大滩的位置都能确定？ {#check.37.q5}
考点：x37.ke-can
语境：check.37.p.map

- [x] 皆克定其处
- [ ] 携图来
  理由：这是老工最初对带图人的嘱咐。
- [ ] 旬日而返
  理由：这是徒弟返程所用的时间，未说明测定了多少。

提示：找“克”领的动作，也找它前头表示无一遗漏的字。
解析：“克定”是能定下来，“皆”把这种把握落在所有大滩。后面另说细石，不能把它们也算进“皆”。

## 单选：水里有几块不妨碍行船的小石，图上没有标出。这样画符合老工的打算吗？ {#check.37.q6}
考点：x37.sheng-all
语境：check.37.p.map

- [ ] 违背“大滩皆克定其处”：定出大滩就必须列尽滩上每块小石
  理由：“皆”管“大滩”，不是“细石”。
- [x] 符合。细石标不尽，老工挑的是妨碍行船的那些。
- [ ] 违背“细石不可胜标”：老工要求一块石都不能在图上出现
  理由：“举其碍舟者”明说仍会挑一部分标出。

提示：“不可胜标”以后，老工给出了什么取舍办法？
解析：“胜”说能否标尽。“不可胜标”并非不许标；下一句把有限的图面留给会影响行船的石头。
