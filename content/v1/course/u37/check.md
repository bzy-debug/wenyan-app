# 检查：从物件、数量和后果辨实词 {#check.37}

## 原文：教学例句 {#check.37.p.rudder}
> 舟子检长篙，见篙末裂，而手所执处完，乃削其裂者。
译文：船夫查看长篙，见篙的末端裂开，手握处却完好，便削去裂处。

## 单选：船夫动刀削的是哪一处？ {#check.37.q1}
考点：words.skill.mo-tip
语境：check.37.p.rudder

- [ ] 手握处
  理由：文中说手所执处完好。
- [ ] 船体的尾部
  理由：他检查的是长篙。
- [x] 长篙裂开的末端

提示：看“末”和持篙处怎样对写。
解析：“篙末”是篙的末端，后文“裂者”回指该处。

## 原文：教学例句 {#check.37.p.mulberry}
> 桑下有落实，童拾而食之，手及齿皆紫。
译文：桑树下有掉下来的果实，孩子拾起来吃，手和牙齿都染紫了。

## 单选：“落实”具体是说什么落下？ {#check.37.q2}
考点：words.skill.shi-fruit
语境：check.37.p.mulberry

- [ ] 树上垂下的细枝
  理由：“食之”和染紫指向成熟的桑实。
- [ ] 办事的方案得到了落实
  理由：下文能把落下的东西拾起吃。
- [x] 桑树结的果实

提示：找“之”指的、能入口的东西。
解析：这里“落”修饰“实”，树下可拾可食的是桑果。

## 原文：教学例句 {#check.37.p.ropes}
> 五舟待发而缆寡，止得二条。舟人相借，犹不能舟舟有缆。
译文：五条船等待出发，缆绳却少，只有两条。船夫相互借用，仍不能让每条船都有绳。

## 单选：“缆寡”为什么不等于完全没有缆？ {#check.37.q3}
考点：words.skill.gua-few
语境：check.37.p.ropes

- [x] 原文给出实数两条，只是不够五船分用
- [ ] 每一条船都另有两根
  理由：两条是现有缆绳的总数。
- [ ] 船夫们还没想过用绳
  理由：他们已在相借。

提示：分别数船和绳。
解析：两绳与五舟的差额解释“寡”，意思是少。

## 原文：教学例句 {#check.37.p.seals}
> 南仓五门，吏暮悉封之。北仓一门以待车，独未封。
译文：南仓有五道门，官吏傍晚全部封上。北仓有一道门留待车来，唯独没有封。

## 单选：“悉封之”说哪些门全封上了？ {#check.37.q4}
考点：words.skill.xi-all
语境：check.37.p.seals

- [ ] 两仓所有的门
  理由：独未封的北仓门是例外。
- [x] 南仓的五道门
- [ ] 北仓留待车辆的一道门
  理由：它明确未封。

提示：把“之”指回它前面的一组门。
解析：“悉”涵盖南仓五门；北仓门在下一句另说。

## 原文：教学例句 {#check.37.p.spring}
> 农待邻归而共播，邻秋乃返。父曰：“春已过，失播种之时矣。”
译文：农人等邻人归来一同播种，邻人到秋天才回来。父亲说：“春天已过，已经错过播种季节了。”

## 单选：父亲认为失去的是什么？ {#check.37.q5}
考点：words.skill.shi-miss
语境：check.37.p.spring

- [x] 适宜播种的时机
- [ ] 先前储下的全部种子
  理由：只说春已过，没说种子不见。
- [ ] 一块原有的耕地
  理由：地的归属没有发生变化。

提示：“春已过”是在核对什么条件？
解析：“失”带“播种之时”作对象，指季节的机会已经错过。

## 原文：教学例句 {#check.37.p.banner}
> 军书遇火，吏弃空匣，抱书出，以存众卒之籍。将军按籍点卒。
译文：军中文书遭遇火灾，官吏丢下空匣，抱着文书出来，以保全士卒名册。将军凭册点兵。

## 单选：将军后来能点兵，印证了“存”的哪一层意义？ {#check.37.q6}
考点：words.skill.cun-preserve
语境：check.37.p.banner

- [ ] 空匣被仔细收藏起来
  理由：官吏弃的是空匣。
- [x] 名册从火中得以保全
- [ ] 将军前去慰问每位士卒
  理由：“按籍”说明他用的是保下的记录。

提示：想一想“以存”所接的名物在后文怎样使用。
解析：士卒之籍是被保全的对象，仍可据以清点。
