# 检查：绳有几条，门关了几扇 {#check.37}

## 原文：教学例句 {#check.37.p.rudder}
> 舟子检长篙，见篙末裂，而手所执处完，乃削其裂者。
译文：船夫查看长篙，见篙的末端裂开，手握处却完好，便削去裂处。

## 单选：船夫削掉了长篙的什么部位？ {#check.37.q1}
考点：words.skill.mo-tip
语境：check.37.p.rudder

- [ ] 手握处
  理由：文中说手所执处完好。
- [ ] 船体的尾部
  理由：他检查的是长篙。
- [x] 长篙裂开的末端

提示：手握的地方“完”，那一头有什么不同？
解析：手中握着的部位完好，裂的是长篙末端，所以他削的是裂开的那头。

## 原文：教学例句 {#check.37.p.mulberry}
> 桑下有落实，童拾而食之，手及齿皆紫。
译文：桑树下有掉下来的果实，孩子拾起来吃，手和牙齿都染紫了。

## 单选：桑树下有“落实”，孩子捡起吃的是什么？ {#check.37.q2}
考点：words.skill.shi-fruit
语境：check.37.p.mulberry

- [ ] 树上垂下的细枝
  理由：“食之”和染紫指向成熟的桑实。
- [ ] 办事的方案得到了落实
  理由：下文能把落下的东西拾起吃。
- [x] 桑树结的果实

提示：留心树的种类，以及孩子吃后手和牙齿的颜色。
解析：桑树结的果实落在地上，孩子拾来吃，手和牙齿都染成了紫色。

## 原文：教学例句 {#check.37.p.ropes}
> 五舟待发而缆寡，止得二条。舟人相借，犹不能舟舟有缆。
译文：五条船等待出发，缆绳却少，只有两条。船夫相互借用，仍不能让每条船都有绳。

## 单选：五只船只有两条缆绳，怎样解释“缆寡”？ {#check.37.q3}
考点：words.skill.gua-few
语境：check.37.p.ropes

- [x] 原文给出实数两条，只是不够五船分用
- [ ] 每一条船都另有两根
  理由：两条是现有缆绳的总数。
- [ ] 船夫们还没想过用绳
  理由：他们已在相借。

提示：数目虽然不够分，究竟有没有缆绳？
解析：确有两条，只是对五只船来说太少。“寡”没有说一条也没有。

## 原文：教学例句 {#check.37.p.seals}
> 南仓五门，吏暮悉封之。北仓一门以待车，独未封。
译文：南仓有五道门，官吏傍晚全部封上。北仓有一道门留待车来，唯独没有封。

## 单选：“悉封之”说全部关上的，是哪几道门？ {#check.37.q4}
考点：words.skill.xi-all
语境：check.37.p.seals

- [ ] 两仓所有的门
  理由：独未封的北仓门是例外。
- [x] 南仓的五道门
- [ ] 北仓留待车辆的一道门
  理由：它明确未封。

提示：哪一仓的门特意留了一道等车？
解析：南仓五道门都封了。北仓另留一门，所以“悉”只指前面南仓的门。

## 原文：教学例句 {#check.37.p.spring}
> 农待邻归而共播，邻秋乃返。父曰：“春已过，失播种之时矣。”
译文：农人等邻人归来一同播种，邻人到秋天才回来。父亲说：“春天已过，已经错过播种季节了。”

## 单选：父亲说“失播种之时”，究竟错过了什么？ {#check.37.q5}
考点：words.skill.shi-miss
语境：check.37.p.spring

- [x] 适宜播种的时机
- [ ] 先前储下的全部种子
  理由：只说春已过，没说种子不见。
- [ ] 一块原有的耕地
  理由：地的归属没有发生变化。

提示：起先要等人一起播种，邻人回来时已是什么季节？
解析：等到秋天人回来，春播的日子已过。失去的是适宜播种的机会。

## 原文：教学例句 {#check.37.p.banner}
> 军书遇火，吏弃空匣，抱书出，以存众卒之籍。将军按籍点卒。
译文：军中文书遇火，官吏撇下空匣，抱着文书出来，保住了士卒名册。将军照着名册点人。

## 单选：将军还能按名册点兵，说明大火里保住了什么？ {#check.37.q6}
考点：words.skill.cun-preserve
语境：check.37.p.banner

- [ ] 空匣被仔细收藏起来
  理由：官吏弃的是空匣。
- [x] 名册从火中得以保全
- [ ] 将军前去慰问每位士卒
  理由：“按籍”说明他用的是保下的记录。

提示：官吏丢下空匣，抱出来的又是什么？
解析：装书的匣子没带走，记着士兵姓名的册籍却从火里抢了出来，后来还能照册点名。
