# 课文：谁做得到，什么经得起 {#x37.3}
简介：听清“善”在说本领，“克”在说能否做到，再看“堪”和“胜”究竟把意思放在哪儿。

## 正文

问“你有什么长处”，答“我善辨古器”，所说的是本领；问“今晚能修完吗”，答“未克”，所说的是成不成。一个人有本领，未必每一回都赶得及。

“不堪久役”里，人受不住的是长期劳作。“不可胜记”却可以发生在一个完全胜任记录的人身上：要记的事太多，记不尽。先读“堪”后面压在人身上的是什么，再读“胜”后面的动作有没有做到尽头。

## 知识点：善，领起一个人的长处 {#x37.shan-skilled}
义项：擅长做某事
领域：实词
要诀：看“善”后面接的是哪一门本领。
讲解：“客善治漆”说他擅长处理漆料，还不能据此断定他必定接下眼前的活计。
例句：x37.ex.shan-skilled

## 原文：教学例句 {#x37.ex.shan-skilled}
> 有客善相马，过厩而驻。
译文：有位客人擅长看马的优劣，经过马厩时停了下来。

## 知识点：克，在动词前说能做到 {#x37.ke-can}
义项：能够，做得到
领域：实词
要诀：找它领起的动作，看看有没有需要攻破的东西。
讲解：“二人卒克全书”若接着说“诸卷无一损”，两人做到的是保全书籍，没有打败书的意思。
例句：x37.ex.ke-can

## 原文：教学例句 {#x37.ex.ke-can}
> 泉远，日往返者鲜克久之。
译文：泉水很远，每天往返的人很少能长期坚持。

## 知识点：堪，承受得住某种负担 {#x37.kan-bear}
义项：受得住，经得起
领域：实词
要诀：把重量、劳累或忧苦同承受它的人或物相配。
讲解：“薄板不堪重器”是板子经不住重物。若只译成“这木板不好”，就漏掉了它承受的是什么。
例句：x37.ex.kan-bear

## 原文：教学例句 {#x37.ex.kan-bear}
> 老牛病，已不堪此车。
译文：老牛病了，已拉不动这样一辆车。

## 知识点：胜，放在动作前表示尽、完 {#x37.sheng-all}
义项：尽，全部完成
领域：虚词
要诀：读“胜”后面的动词，哪件事做不完？
讲解：“不可胜书”可以已经写下很多，只是写不尽。不能据此推出一件也没写，更不是比较谁写得好。
例句：x37.ex.sheng-all

## 原文：教学例句 {#x37.ex.sheng-all}
> 谷中百花杂开，其名不可胜举。
译文：山谷中百花杂开，花名举不尽。

## 单选：先读“夫子恶乎长”，再读“我善养”。孟子答的是哪一种“善”？ {#x37.3.q1}
考点：x37.shan-skilled
语境：x37.3.p.strength

- [x] 自己擅长做什么，以养气回答所长
- [ ] 自己从不憎恶别人的言论
  理由：前面的“恶乎长”在问哪方面擅长，不能把“恶”读成厌恶。
- [ ] 认可公孙丑这番问话问得好
  理由：“善”后紧跟的是“养吾浩然之气”，不是对提问下评语。

提示：是谁在问长处，谁接过来介绍自己的长处？
解析：“我善养”直接答上文“恶乎长”。“善”引出自己的本领，这正是上句问话所求。

## 单选：士季为什么特意引“鲜克有终”来劝说晋灵公？ {#x37.3.q2}
考点：x37.ke-can
语境：x37.3.p.lasting

- [ ] 众人一开始都会犯错，所以改过也做不到
  理由：“鲜”说少有，并没有断言无人能改。
- [x] 开始并不难，难的是把改过坚持到底
- [ ] 能打败别人，才有资格劝人改过
  理由：“克”后面接“有终”，不是作为交战对手的人。

提示：把“有初”和“有终”并在一起，找少有人能做到的那一端。
解析：“克”说能不能，“鲜”说能做到的人少。士季以此劝君主别停在最初肯改的一刻。

## 找原文证据：“民不堪命”是嫌哪一样负担太重？找出前文写这种负担何等频繁的地方。 {#x37.3.q3}
考点：x37.kan-bear
语境：x37.3.p.wars

- [ ] 宋殇公立
  理由：这里只交代在位的国君。
- [x] 十年十一战
- [ ] 民不堪命
  理由：是承受不了的结果，还没说什么事一再发生。

提示：哪些字把时间和发生的次数放在一起？
解析：十年里有十一场战事，紧接才写百姓不堪征发。这种“不堪”重在负担太重。

## 单选：孟子说“谷不可胜食”“材木不可胜用”。用他这两句劝说国君，保留哪层意思才说得通？ {#x37.3.q4}
考点：x37.sheng-all
语境：x37.3.p.grain

- [ ] 本国的粮木无法胜过邻国的粮木
  理由：三句谈取用同生长的关系，没有比较两国粮木高下。
- [ ] 治理有方以后，粮食和木材都不许食用
  理由：“不可”连“胜食、胜用”读，不是禁人吃粮用木。
- [x] 不妨生长、取用有时，粮木就丰足得吃不完、用不尽

提示：试把两处“胜”同时换成“尽”。
解析：同一个“胜”先领“食”，后领“用”。用不尽说数量丰足，并非取消使用的许可。

## 原文：教学例句 {#x37.3.p.copy}
> 馆有残书十卷。客善补纸，请治之。旬日，九卷可读，一卷墨漫，竟未克辨。
译文：馆里有十卷残书。客人擅长修补书纸，请求修整。过了十天，九卷已经可读，有一卷墨迹洇成一片，终究没能辨认。
词注：旬日：十天。
  墨漫：墨迹洇开，字形模糊。

## 单选：若因最后一卷没读出来就删掉“客善补纸”，会删错什么？ {#x37.3.q5}
考点：x37.shan-skilled
语境：x37.3.p.copy

- [x] 修补纸张是他的长处，和辨清每处墨迹是两回事
- [ ] 他已经把十卷所有字都认对了
  理由：末卷的结果明说“未克辨”。
- [ ] 他为人仁善，所以一定不收修书费用
  理由：“补纸”是他说得上手的事，报酬并未交代。

提示：分开修纸和识字这两件事。
解析：“善”只把补纸列为所长。纸可修补，洇没的字仍未必都能辨认。

## 找原文证据：客人“未克辨”的只是末卷。原文哪里说明造成这个结果的难处？ {#x37.3.q6}
考点：x37.ke-can
语境：x37.3.p.copy

- [x] 一卷墨漫
- [ ] 九卷可读
  理由：这是其余九卷的结果。
- [ ] 十卷
  理由：这是起初书的总数，没有交代辨字的难处。

提示：看看末卷的字迹怎样了。
解析：墨迹洇成一片，让辨字这件事没能做成。“未克”落在“辨”，不等于十卷全未修好。

## 原文：教学例句 {#x37.3.p.tray}
> 山寺藏碑拓数箧。僧取一箧，置薄案上，案足摇，曰：“案不堪此重。”乃分置二案。客录其题，自朝至暮，犹不可胜录。
译文：山寺藏有几箱碑刻拓本。僧人取一箱放在轻薄的桌上，桌脚晃动，说：“桌子受不住这重量。”便分放在两张桌子上。客人抄录拓本的题名，从早到晚，还是没能录完。
词注：碑拓：从石碑上捶拓下来的纸本。
  箧：箱子。
  案：桌子。

## 找原文证据：僧人靠什么判断“案不堪此重”？选出桌子已经显出的征象。 {#x37.3.q7}
考点：x37.kan-bear
语境：x37.3.p.tray

- [ ] 取一箧
  理由：这交代拿了一箱，没写桌子承重时的变化。
- [ ] 乃分置二案
  理由：这是发觉问题之后减轻负担的办法。
- [x] 案足摇

提示：先找分成两桌以前看得见的变化。
解析：箱子放上去，桌脚就摇，显示原桌经不起这份重量。分开放是随后采取的办法。

## 单选：“自朝至暮，犹不可胜录”能否写进记事说“客一字未录”？ {#x37.3.q8}
考点：x37.sheng-all
语境：x37.3.p.tray

- [ ] 能，桌子没能承重，所以拓本全毁了
  理由：僧人已经分置二案，没说拓本损毁。
- [ ] 能，“不可”说明寺里从一开始就禁止抄写
  理由：原文先说“客录其题”，已经记了动作。
- [x] 不能，他已经花时间抄录，只是题名没有全部录尽

提示：哪件事从早持续到晚？“胜”限定的是动手还是做完？
解析：“胜录”是录尽。花了一天仍录不尽，不能抹掉他这一天已抄的部分。
