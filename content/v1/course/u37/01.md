# 课文：“诚”是认定了，还是姑且这样说 {#x37.1}
简介：一边是孟子说眼前的人果然是齐人，一边是他请人设想将来。再听“固”交代的旧情形和“第”放行的下一步。

## 正文

有人来报“东堤缺”。亲自看过，回来说“堤诚缺矣”，这便是确认。还没去看，先说“堤诚缺，则移舟”，这是商量万一报得属实该如何办。别只看有没有“诚”，要看说话人见过什么，后面那件事已经发生还是尚待决定。

“吾固知之”要往前读：在别人告诉我以前，我本已知道。“君第言之”要往后读：这话让对方只管说。一个交代旧情形，一个解开眼前的顾虑。

## 知识点：诚，确认所说属实 {#x37.cheng-fact}
义项：的确，实在
领域：虚词
要诀：问一句：说话人用它确认了哪件事？
讲解：“此言诚当”是在承认刚才那番话说得对。“诚”修饰“当”，并未评价发话者是不是诚实的人。
例句：x37.ex.cheng-fact

## 原文：教学例句 {#x37.ex.cheng-fact}
> 观其刻，诚旧印也。
译文：看过上面的刻文，确实是旧印。

## 知识点：诚，提出当真的假设 {#x37.cheng-if}
义项：如果当真如此
领域：虚词
要诀：先把条件留空，读到后面看会推出什么。
讲解：“诚得一舟，乃可渡”以找到船为前提。谁也还没说船已经找到了。
例句：x37.ex.cheng-if

## 原文：教学例句 {#x37.ex.cheng-if}
> 雨诚止，则开窑门。
译文：雨若真停了，就把窑门打开。

## 知识点：固，说明原已如此 {#x37.gu-already}
义项：本来，原就
领域：虚词
要诀：看眼下所谈的情形是不是早已具备。
讲解：“吾家固有此本”说家里原就有这个本子。要证明有人新近送书，还得另有记载。
例句：x37.ex.gu-already

## 原文：教学例句 {#x37.ex.gu-already}
> 此渠固通南塘，淤而后塞。
译文：这条渠原本通到南塘，淤积以后才堵住。

## 知识点：第，叫人只管去做 {#x37.di-goahead}
义项：只管，尽管
领域：虚词
要诀：留意对方犹豫的是哪一个动作。
讲解：“子第入”是在让迟疑的人只管进门。“第”后直接接“入”，没有给人排座次。
例句：x37.ex.di-goahead

## 原文：教学例句 {#x37.ex.di-goahead}
> 客惮涉水，舟人曰：“君第登舟。”
译文：客人怕过水，船夫说：“您只管上船。”

## 单选：公孙丑谈起两位齐国名相，孟子这句“子诚齐人也”是怎么接他的话的？ {#x37.1.q1}
考点：x37.cheng-fact
语境：x37.1.p.qi

- [ ] 夸他为人诚实，愿意坦白家乡
  理由：孟子说的是“齐人”，没有评价他守不守信。
- [x] 听他举的人物，感叹他果然是齐国人
- [ ] 先假定他是齐国人，再让他证实籍贯
  理由：“也”收住判断，后面直接评论他熟悉的人。

提示：留意“齐人也”后紧跟哪两个人名。
解析：管仲、晏子都是齐相。孟子借公孙丑熟悉的人物评说他的眼光，“诚”加强了“齐人”这一判断。

## 单选：孟子说“诚如是也，民归之”，是不是在报告百姓已经归附一位君主？ {#x37.1.q2}
考点：x37.cheng-if
语境：x37.1.p.water

- [ ] 是，已经亲见百姓跟随一位在位的君主
  理由：开头的“如有”没有指出一个已经出现的人。
- [ ] 是在怀疑水是否会往低处流
  理由：水向下流是用来比百姓归附的，不是这里设下的条件。
- [x] 是在推想，若有这样的君主，百姓就会归向他

提示：往前找“是”承接的是“已有”还是“如有”。
解析：“如有”先设想一位不嗜杀的君主。“诚如是”接住同一个设想，才说百姓会怎样。

## 单选：按孟子这句话，不去“思”的人原先有没有仁义礼智？ {#x37.1.q3}
考点：x37.gu-already
语境：x37.1.p.nature

- [ ] 原来没有，要靠别人从外面教给他才有
  理由：“非由外铄我也”排除了从外面才得来的说法。
- [x] 孟子认为原就有，只是没有去思求
- [ ] 有过，后来因不去想而已经丧失
  理由：原文只说“弗思”，没有说“已失”。

提示：把“我固有之”同“弗思”分作两层。
解析：“固”落在“有”上。前半句判断原先就有，后半句另说人有没有思求它。

## 原文：教学例句 {#x37.1.p.bell}
> 县有旧钟，工见而不敢言，或言其裂。令叩而察之，曰：“钟诚裂矣。汝第言所见。”
译文：县里有口旧钟，工匠看见了不敢开口，另有人说它裂了。县令敲过又察看，说：“钟确实裂了。你只管说自己看见了什么。”
词注：令：县令。
  叩：敲击。

## 找原文证据：县令凭什么把“有人说钟裂”改口为“钟诚裂矣”？找出他亲自核实消息的动作。 {#x37.1.q4}
考点：x37.cheng-fact
语境：x37.1.p.bell

- [x] 叩而察之
- [ ] 言所见
  理由：这是后来请对方补说见闻。
- [ ] 或言其裂
  理由：这是先收到的消息，不是县令所做的查验。

提示：找在前一次传闻和县令下判断之间的动作。
解析：县令敲了钟，又察看它，才肯定“诚裂”。这是确认裂痕，不是在商量如果裂了怎么办。

## 单选：听到“汝第言所见”，工匠现在可以怎样做？ {#x37.1.q5}
考点：x37.di-goahead
语境：x37.1.p.bell

- [x] 只管说出自己看见的情形
- [ ] 等县令叫到自己的次序才能说
  理由：没有给几个人排先后，说话的对象只有眼前的工匠。
- [ ] 必须替没看见的人一并作证
  理由：“所见”收在他自己的见闻之内。

提示：“第”紧靠的下一件事是“言”。
解析：县令已经检查过钟，接下来又许工匠直说。“第”在这里消除顾虑。

## 原文：教学例句 {#x37.1.p.well}
> 客言寺后有泉。僧曰：“寺后固有井，吾少时尝汲焉。今井诚有水，则可留宿。”乃遣童视之，未返。
译文：客人说寺后有泉。僧人说：“寺后本来就有井，我小时候曾在那里打水。如今井里若真有水，就可以留下过夜。”于是派孩子去看，孩子还没有回来。
词注：汲：从井里打水。
  焉：在那儿，指前面的井。

## 找原文证据：客人刚传来消息，僧人凭哪句话能说井是“固有”的？ {#x37.1.q6}
考点：x37.gu-already
语境：x37.1.p.well

- [ ] 乃遣童视之
  理由：这是派人查看今天的井况。
- [x] 吾少时尝汲焉
- [ ] 今井诚有水
  理由：这是他如今还要查证的事。

提示：哪件往事发生在客人到来很久以前？
解析：年少时就打过水，足以说明这个井不是听客人说起才知道的。井今天有水没有，还须另查。

## 单选：僧人说“今井诚有水”，接下来哪一笔记事才合乎原意？ {#x37.1.q7}
考点：x37.cheng-if
语境：x37.1.p.well

- [ ] 僧人确认了水量，已经安排所有人留宿
  理由：“则可”把留宿系在水况上，孩子还没回来。
- [ ] 派人去确定僧人小时候有没有来过寺院
  理由：僧人怀疑的是今天的水况，打水是他的亲历。
- [x] 等孩子回报，再决定是否留宿

提示：分清“少时”所见和“今”要问的事。
解析：过去打到过水，不能保证今天井里仍有水。这里的“诚”要连下句“则可”读。

## 原文：教学例句 {#x37.1.p.letter}
> 弟得兄书，不识末行，欲问师而惧。师曰：“汝第持书来，共读之。”
译文：弟弟收到兄长的信，不认得末行字，想请教老师又害怕。老师说：“你只管把信拿来，我们一起读。”

## 单选：老师说“第持书来”，打消的是弟弟的哪一点顾虑？ {#x37.1.q8}
考点：x37.di-goahead
语境：x37.1.p.letter

- [ ] 怕信纸没有依行次排好
  理由：难处是“不识末行”，不是行次错乱。
- [ ] 怕兄长也得跟着一起来见老师
  理由：“共读”的是老师和眼前的弟弟，没叫写信的人来。
- [x] 想带信来请教，却怕开口

提示：先读发话以前弟弟“欲”做什么。
解析：弟弟想问而惧，老师便让他只管拿来。“第”指向眼前可以去做的事。
