# 课文：“恶”是在问，还是在说好恶 {#x37.2}
简介：辨认谈话的对象：是憎恶一种做法，是问安定天下的办法，还是借别人也知道的事反问一声？

## 正文

“恶其言”，说的是听者厌恶那些话，读 wù。“恶知其名”，问的是从哪里能知道名字，读 wū。遇到一个生词，先别忙着定读音，试着把下句放回来：对方会举出自己厌恶的东西，还是交代消息的来处？

谈钱物时也别照搬今天的用法。旁人说主人“爱一金”，可能嫌他舍不得出钱。至于“子独不见……乎”，往往并不等你报出见没见过：说话人已经把众人熟悉的事情摆出来，等你想一想那件事说明什么。

## 知识点：爱，舍不得付出财物 {#x37.ai-spare}
义项：吝惜，舍不得给出
领域：实词
要诀：看说话人谈的是喜欢一件东西，还是舍不舍得付钱出物。
讲解：若工料已齐，主人却“爱其费而止”，拦住事情的是不愿付这笔费用。
例句：x37.ex.ai-spare

## 原文：教学例句 {#x37.ex.ai-spare}
> 主人爱新帛，解旧衣以补囊。
译文：主人舍不得用新丝帛，拆了旧衣服来补袋子。

## 知识点：恶，厌恶某人或某种行为 {#x37.wu-dislike}
义项：读 wù，憎恶、讨厌
领域：实词
要诀：先读“恶”的对象，再问谁在表示嫌恶。
讲解：“我恶欺人者”中，“欺人者”整组是被厌恶的人。换成“哪里有欺人者”，就从表态读成了问话。
例句：x37.ex.wu-dislike

## 原文：教学例句 {#x37.ex.wu-dislike}
> 吏恶争功者，故不为之请。
译文：官吏厌恶争功的人，所以不替他说情。

## 知识点：恶，在问话中追问处所或办法 {#x37.wu-how}
义项：读 wū，哪里、怎么
领域：虚词
要诀：看答话是交代从哪里、凭什么，还是表达好恶。
讲解：“子恶得此简”若接“得于井旁”，便是问从哪儿得来，与喜欢或憎恶这件东西无关。
例句：x37.ex.wu-how

## 原文：教学例句 {#x37.ex.wu-how}
> 门既扃，客恶从入？
译文：门已经锁了，客人从哪儿进来？

## 知识点：独，配合否定和问语发反问 {#x37.du-rhetoric}
义项：难道，岂
领域：虚词
要诀：读完紧接的事例，看说话人是在提醒听者什么。
讲解：“子独不闻昨夜之雷乎”可借人人听得到的雷声提醒对方。“子”并不因此变成全村唯一没听见的人。
例句：x37.ex.du-rhetoric

## 原文：教学例句 {#x37.ex.du-rhetoric}
> 渠已涸，君独不见岸裂乎？
译文：水渠已经干了，您难道没看见岸都裂了么？

## 原文：古籍引文 {#x37.2.p.disgust}

## 单选：“恶称人之恶者”里，哪个“恶”说的是君子自己的态度？ {#x37.2.q1}
考点：x37.wu-dislike
语境：x37.2.p.disgust

- [ ] 两个都是。君子在列自己两件同样的行为
  理由：“称……者”合起来说一类人，君子表明对这种人的态度。
- [x] 头一个。君子厌恶那种张扬别人过恶的人
- [ ] 后一个。君子在张扬自己有多厌恶别人
  理由：“人之恶”是别人的不好之处，放在“称”之后。

提示：先找“者”把什么样的人圈在一起。
解析：“称人之恶者”是张扬别人的过恶的人。开头的“恶”读 wù，才是孔子说自己厌恶这类人。

## 单选：梁襄王问“天下恶乎定”，孟子为什么答“定于一”？ {#x37.2.q2}
考点：x37.wu-how
语境：x37.2.p.realm

- [ ] 王已经选定一人，问那人姓什么
  理由：接下去才另问“孰能一之”；两个问题所求不同。
- [ ] 王问天下人憎恶谁，孟子答只憎恶一个人
  理由：“定于一”答的是安定所系，没列令人厌恶的人。
- [x] 王问凭怎样的局面能安定，孟子答归于统一

提示：比较先问“恶乎定”，后问“孰能一之”。
解析：“恶乎”引出第一问，“定于一”正答怎样才安定。第二问的“孰”才把问题转到人。

## 单选：楚使来请庄周做官。庄周问“子独不见……乎”，接着又讲牛的下场，是要使者怎样想？ {#x37.2.q3}
考点：x37.du-rhetoric
语境：x37.2.p.envoy

- [ ] 报出上一次亲眼见祭牛的年月
  理由：下文只写祭牛一生的待遇和结局，没有查问见闻日期。
- [ ] 承认自己是楚国唯一没见过祭牛的人
  理由：庄周直接拿祭牛打比方，并没有把使者同其他人的经历逐一比较。
- [x] 想想祭牛虽受优待，却已经失去自己作主的余地

提示：读到“岂可得乎”，牛到头来还能选择吗？
解析：庄周用反问把使者的注意力引到一个熟悉的例子。祭牛身披文绣却无法脱身，正可用来回应显贵的邀约。

## 原文：教学例句 {#x37.2.p.cloth}
> 邑人议为贫者制衣。甲出粟而不出帛。乙曰：“彼爱帛耳。”甲解其藏，惟见弊絮，曰：“吾恶空许人者，故先以所有助之。”
译文：乡里人商议给穷人制衣。甲拿出粮食，却没拿布帛。乙说：“他就是舍不得布帛。”甲打开自己的储藏处，里面只有破絮，说：“我厌恶空口答应别人的人，所以先拿自己有的东西来帮忙。”
词注：弊絮：破旧的丝绵。
  空许：没有实际把握便许诺。

## 单选：乙说“彼爱帛耳”，他的指责是哪一种？ {#x37.2.q4}
考点：x37.ai-spare
语境：x37.2.p.cloth

- [x] 甲手头有帛，却不舍得拿给穷人
- [ ] 甲没有帛，所以拿粮来帮忙
  理由：这是后来打开储藏处所能支持的解释，乙当时说的是另一种。
- [ ] 甲偏爱穿丝帛，宁可不吃粮
  理由：乙在议论甲出不出帛，没说甲穿什么。

提示：把乙的猜测和开藏以后的见闻分开。
解析：“出粟而不出帛”引出乙的猜测。他用“爱”指甲吝惜；打开储藏处以后，这项指责就站不住了。

## 找原文证据：甲说“吾恶空许人者”。从他自己的做法里，哪几个字能看出他想避免只在嘴上许诺？ {#x37.2.q5}
考点：x37.wu-dislike
语境：x37.2.p.cloth

- [ ] 惟见弊絮
  理由：这是储藏处的情形，还不是甲怎样援助。
- [x] 先以所有助之
- [ ] 彼爱帛耳
  理由：这是乙的猜测，不能当作甲自己的做法。

提示：找甲实际能交给人家的东西。
解析：甲厌恶空许，所以先拿得出来的粮食帮人。他所厌恶的是轻许的做法，与制衣救贫这件事无关。

## 原文：教学例句 {#x37.2.p.elm}
> 园中老榆将伐。童曰：“独不见其上有巢乎？雏犹未飞。”匠仰视，果有之，乃徙锯。
译文：园里的老榆树快要砍了。孩子说：“难道没看见树上有巢吗？雏鸟还不会飞。”工匠抬头看，果然有，便把锯移开了。

## 单选：孩子问完便说“雏犹未飞”，工匠又移开锯。把这番问话换成哪句，最接近孩子的用意？ {#x37.2.q6}
考点：x37.du-rhetoric
语境：x37.2.p.elm

- [ ] 请查查这里究竟有没有鸟巢，我并不知道
  理由：孩子已说“雏犹未飞”，他自己正以巢中雏鸟劝阻。
- [ ] 请说说园里究竟只有哪一个人没看见巢
  理由：孩子没有点人数，工匠也不报姓名，只改了行动。
- [x] 看看树上还有巢，先别锯这棵树

提示：孩子有疑问要人作答，还是已有理由要人改主意？
解析：“独不见……乎”把工匠的目光引向巢，后一句接上不能立刻伐树的缘故。

## 原文：教学例句 {#x37.2.p.wax}
> 生持无款之画，问售者：“子恶知此为周叟笔？”对曰：“周叟作此画时，我侍其侧，非闻诸人。”生欲购之，而爱其金，竟空手归。
译文：学生拿着一幅没有署名的画，问卖家：“你怎么知道是周老画的？”卖家说：“周老画这幅画时，我就在他身边，并非听别人转述。”学生想买，却舍不得出钱，最后空手回去了。
词注：无款：画上没有作者署名。
  闻诸人：从别人那里听说。

## 找原文证据：“子恶知”追问卖家的根据。卖家拿出的是哪一种亲身见闻？ {#x37.2.q7}
考点：x37.wu-how
语境：x37.2.p.wax

- [x] 我侍其侧
- [ ] 非闻诸人
  理由：这是排除传闻，还没有正面交代他怎样得知画者。
- [ ] 竟空手归
  理由：这是学生后来没买成画的结果。

提示：哪一句能放在“我之所以知道，是因为……”后面？
解析：“恶”在这里读 wū，问“怎么知道”。卖家答自己曾在场看周老作画。

## 单选：“欲购之，而爱其金”转折在哪里？ {#x37.2.q8}
考点：x37.ai-spare
语境：x37.2.p.wax

- [x] 对画有购买意愿，到了付钱时却舍不得
- [ ] 先喜欢金色的画，后来嫌画没有署名
  理由：“其金”是要付出的钱，不是画面上的颜色。
- [ ] 卖家很珍爱这幅画，拒不出手
  理由：“欲购”到“空手归”的主语都是学生，卖家只答了来历。

提示：分别给“欲购”和“爱其金”找主语。
解析：正因为想买，舍不得付钱才构成转折。末了空手回去，和这个读法也相合。
