# 课文：听到一个字音，翻到哪一条？ {#d46.1}
简介：给子贡的玉和孔子的酒各选一个“沽”义，再把几处简写放回繁体字头。

## 正文

在字典里查“沽”，会读 gū，就能从音序进去。同栏还有“姑”和“孤”。“沽”右边的“古”提示读音线索，可是“古”自己读 gǔ；它也没告诉你这是买还是卖。“罟”也含“古”，其上的网形倒能帮你认出要找的字。下面的小索引只列这次会用到的几项。

| 音序 | 同音字头（节选） |
| --- | --- |
| gū | 姑、孤、沽 |
| gǔ | 古、谷、罟 |
| fā | 發（发出、启程） |
| fà | 髮（头发） |

翻到字条才开始读意思。“沽”条兼收买入和卖出。子贡拿美玉问孔子，玉已经在手中；“沽”是另去买玉，还是把这块玉卖出去？再翻《乡党》，古疏把另一处“沽”跟“市脯”的“市”一起讲。同一个字，交易方向变了。

卷末考证还保留另一种理解，认为“沽酒”是一类酿了两宿的酒。只要引疏作证，注明“疏以沽为买”，就不会把另一说悄悄删掉。[核卷末考证](https://github.com/kanripo/KR1h0007/blob/3deaf2c46d2849519048a43445a4d66aa3c5871f/KR1h0007_010.txt#L418-L423)

《重编国语辞典修订本》可按字头核对今音、义项和所列例句。[查“沽”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=沽) · [查“罟”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=罟)

## 知识点：按所闻字音找字头 {#skill.d46.sound}
义项：从读音找到候选字，再拿整字和原句对照
领域：阅读技能
要诀：先查音节，再比偏旁
讲解：声旁给个大致方向。同音栏里还有别的字，认出原字才可以往下抄释义。
例句：p.d46.1.r1

## 知识点：把辞书的书证放回句中 {#skill.d46.proof}
义项：比较所引原句里谁拿着什么，选出解释得通的义项
领域：阅读技能
要诀：先看东西原在谁手里
讲解：同一字条可以兼收买和卖。若两个义项都查得到，需要找出谁原来有这件东西、谁后来得到它。
例句：p.d46.1.r2

## 知识点：一个简字对应几个繁体 {#skill.d46.simplified}
义项：把简写放回原句，分别还原各义的繁体字头
领域：阅读技能
要诀：先读出词，再从原书核字
讲解：简体的“发”可对应發和髮。读者要查头发便翻髮条，要查发出或出发便翻發条。节引原书时保留所据字形。
例句：p.d46.1.r4

## 原文：古籍引文 {#p.d46.1.r2}
> 沽酒市脯不食者，沽，買也。酒不自作，未必精潔；脯不自作，不知何物之肉，故不食也。
译文：疏家认为，买来的酒和肉干不吃：酒出自别人之手，未必精洁；肉干不是自制，不能确知来自什么肉。
词注：市：在市场上买。
  脯：肉干。
出处：《论语注疏·乡党》沽酒市脯章疏

## 原文：教学例句 {#p.d46.1.r3}
> 漁者曬罟於岸，小兒指罟問其名。
译文：捕鱼人在岸边晒网，小孩指着网问它叫什么。
词注：罟：读 gǔ，此处指用来捕鱼的网。

## 原文：教学例句 {#p.d46.1.r4}
> 翁病三月，髮白。病已，與客晨發。
译文：老人病了三个月，头发白了。病好后，他和客人清早动身。
词注：病已：病已经好了。

## 原文：教学例句 {#p.d46.1.r5}
> 既束髮，取弓發矢。
译文：他束好头发，拿起弓放箭。
词注：束髮：把头发束起来。
  矢：箭。

## 单选：朗读者把“沽”念作 gū。音序小表列 gū〔姑、孤、沽〕，gǔ〔古、谷、罟〕。翻哪一条才查得到这个动词？ {#q.d46.1.1}
考点：skill.d46.sound
语境：p.d46.1.r1

- [ ] gū 栏的孤 {#q.d46.1.1.o1}
  理由：音节找对了，玉的主人没有说“孤”。
- [x] gū 栏的沽 {#q.d46.1.1.o2}
  理由：gū 把人带到同音栏，原句的三点水再把字头定在“沽”。
- [ ] gǔ 栏的古 {#q.d46.1.1.o3}
  理由：“古”是声旁，声调和整字都没有对上。

提示：把音、字形各核一遍。
解析：gū 把人带到同音栏，原句的三点水再把字头定在“沽”。

## 找原文证据：辞书兼收“买入”“卖出”。哪一处先说明玉已经在手，能帮助判断“沽诸”的方向？ {#q.d46.1.2}
考点：skill.d46.proof
语境：p.d46.1.r1

- [ ] 子貢曰 {#q.d46.1.2.o1}
  理由：只交代是谁开口，没有说谁有玉。
- [x] 有美玉於斯 {#q.d46.1.2.o2}
  理由：“有美玉於斯”先把美玉放在眼前，藏和卖是处置同一块玉的两个办法。
- [ ] 求善賈 {#q.d46.1.2.o3}
  理由：求的是合适的价钱或买主；这个短语还没有交代玉本在何处。

提示：先看提问的起点。
解析：“有美玉於斯”先把美玉放在眼前，藏和卖是处置同一块玉的两个办法。

## 单选：要给“买入”义抄一条有出处的书证，哪张笔记保留了这位疏家的理由？ {#q.d46.1.3}
考点：skill.d46.proof
语境：p.d46.1.r2

- [x] 《乡党》“沽酒市脯”；疏说酒、脯都不自作。 {#q.d46.1.3.o1}
  理由：疏把沽和市都读成买；酒、肉干都是从外面买来，才会有酒是否洁净、肉出何物的疑虑。
- [ ] 《乡党》“不食”；孔子把自己酿的酒拿去卖。 {#q.d46.1.3.o2}
  理由：疏明说“酒不自作”，没有写出售家酿。
- [ ] 《子罕》“求善贾而沽诸”；既想要玉，便去买。 {#q.d46.1.3.o3}
  理由：《子罕》开头已说自己有玉，另一个办法是将它出售。

提示：把“市脯”也读进去。
解析：疏把沽和市都读成买；酒、肉干都是从外面买来，才会有酒是否洁净、肉出何物的疑虑。

## 单选：卷末考证又引另一说，以“沽酒”为酿了两宿的酒。若原先只抄了“沽，买也”，怎样补才准确？ {#q.d46.1.4}
考点：skill.d46.proof
语境：p.d46.1.r2

- [ ] 把“买也”改成“买酿了两宿的酒”，合为一条注。 {#q.d46.1.4.o1}
  理由：两说分歧就在“沽”是购买动作还是酒的名称，不能拼成同一释词。
- [x] 注明这是疏的读法，另列卷末所引的异说。 {#q.d46.1.4.o2}
  理由：保留“疏作买解”便知道第一说的来处；另一说把“沽酒”整体当一类酒，应单记。
- [ ] 写成孔子亲口解释“沽”就是酒放两宿。 {#q.d46.1.4.o3}
  理由：经文只说饮食取舍，两宿说是后人提出的读法。

提示：分清是谁在解经。
解析：保留“疏作买解”便知道第一说的来处；另一说把“沽酒”整体当一类酒，应单记。

## 单选：听到读音 gǔ，表中找到〔古、谷、罟〕。把“罟”认作“古”的另写，漏看了哪一处线索？ {#q.d46.1.5}
考点：skill.d46.sound
语境：p.d46.1.r3

- [ ] “古”和“罟”同音，所以原字必定写错了。 {#q.d46.1.5.o1}
  理由：同音字同列一栏很平常，不能据此删掉网形。
- [ ] “漁者”在前，字典就该查鱼部的“鮕”。 {#q.d46.1.5.o2}
  理由：渔人可以拿网，施事的身份不决定后面器物的部首。
- [x] 上部有网形，岸边晒的又是捕鱼用具。 {#q.d46.1.5.o3}
  理由：声音相同只缩小范围；整字上部的网形和“晒”的对象，都把候选缩到罟。

提示：别人指的是可以拿出来晒的东西。
解析：声音相同只缩小范围；整字上部的网形和“晒”的对象，都把候选缩到罟。

## 单选：小字条给“罟”两项：①网，如“罔谓之罟”；②用网捕，如“罔罟禽兽”。新句在“晒”后该取哪一项？ {#q.d46.1.6}
考点：skill.d46.proof
语境：p.d46.1.r3

- [ ] ②，小儿问渔者怎样捕鱼，所以“罟”应译为下网。 {#q.d46.1.6.o1}
  理由：孩子指着“罟”问名称；没有问打鱼的手法。
- [x] ①，岸上晒的是能张开晾干的网。 {#q.d46.1.6.o2}
  理由：“晒罟”和“指罟”都把它当具体器物，可用字书释“网”的书证来比。
- [ ] ②，“渔者”是捕鱼人，所以“晒”后还要再接捕鱼动作。 {#q.d46.1.6.o3}
  理由：职业不能代替句法：“晒”已经是动作，还要问他晒什么。

提示：看“其名”回指什么。
解析：“晒罟”和“指罟”都把它当具体器物，可用字书释“网”的书证来比。

## 单选：简写本抄作“发白……晨发”。用表中 fā〔發〕、fà〔髮〕两栏复原，两个位置各查什么？ {#q.d46.1.7}
考点：skill.d46.simplified
语境：p.d46.1.r4

- [ ] 發、發 {#q.d46.1.7.o1}
  理由：前面是生病后头发变白，和出发无关。
- [x] 髮、發 {#q.d46.1.7.o2}
  理由：头发变白，写髮；清晨上路，写發。一种简写合并了原书中两个字。
- [ ] 髮、髮 {#q.d46.1.7.o3}
  理由：后面接“与客”，说的是人清早动身。

提示：看看“白”和“晨”分别贴着哪一个动作或事物。
解析：头发变白，写髮；清晨上路，写發。一种简写合并了原书中两个字。

## 单选：排印本把“束发，取弓发矢”全写成简体。回引这段繁体原文，哪种改法有据？ {#q.d46.1.8}
考点：skill.d46.simplified
语境：p.d46.1.r5

- [ ] 束發，取弓發矢 {#q.d46.1.8.o1}
  理由：一开始束起来的是头发，不是发出去的东西。
- [x] 束髮，取弓發矢 {#q.d46.1.8.o2}
  理由：同样写成“发”，一处能束，一处有箭射出，回查时分别进髮条、發条。
- [ ] 束髮，取弓髮矢 {#q.d46.1.8.o3}
  理由：后半写将箭射出去，“髮”条只有毛发这一边的意思。

提示：把“束什么”“对箭做什么”各答一次。
解析：同样写成“发”，一处能束，一处有箭射出，回查时分别进髮条、發条。
