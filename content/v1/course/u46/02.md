# 课文：这几个字是谁写的？ {#d46.2}
简介：从经文翻到音义和卷末考证，把另一本的字与校书人的判断分开。

## 正文

一页注疏常把好几代人的话排在一起。大字写“子谓子贡曰……孰愈”，小字“孔曰：愈犹胜也”才是解释。若现代译者写“谁更强些”，这能说明他怎样理解“愈”，不能用来证明古本写过“强”字。

拿两支笔记“闻如字，本或作问字，非”。前一支抄版本材料：有的本子写“问”。另一支抄按断：写这条音义的人认为“问”不对。读者即便赞同，也不能把异本记录删掉。

若疏家说“若臯陶謨之九德也”，他是在拿另一部书来比。经文中一个人既温和又严正，可以借那边并写两面品德的例子来读。回引时写清书名和谁引证，别给正文添上注家才说的话。[本章疏文](https://github.com/kanripo/KR1h0007/blob/3deaf2c46d2849519048a43445a4d66aa3c5871f/KR1h0007_007.txt#L375-L378)

卷末遇到“又一说……当作”，先向上找它在讨论经、注还是疏。有人以文意主张改字，有人报出某本实有此字，他们能提供的证据不同。

## 知识点：找出被解释或被校的原句 {#skill.d46.layers}
义项：按经、注、疏及卷末标记，把解释归给实际说话的人
领域：阅读技能
要诀：先找“注”“疏”或“考证”，再看它重引了哪几个字
讲解：校语可能针对注文中的一个字。只有找到被校的那一句，才知道修改会落到书页哪一层。
例句：p.d46.2.r1

## 知识点：分别记异本与校者按断 {#skill.d46.collate}
义项：把某本实际写什么和校者赞成什么分开记录
领域：阅读技能
要诀：“本作”记字样，“非”“当作”要问是谁的判断
讲解：读到“或作”只能说有本如此。读到“当作”还要找所据版本；也可能只是据义提议。
例句：p.d46.2.r2

## 找原文证据：要引用孔子的问题，哪几个字可以放入引号作为经文？ {#q.d46.2.1}
考点：skill.d46.layers
语境：p.d46.2.r1

- [ ] 愈，猶勝也 {#q.d46.2.1.o1}
  理由：讲解“愈”的是集解所录的注家。
- [ ] 孔曰 {#q.d46.2.1.o2}
  理由：“孔曰”在“注”之后，是这条注的署名。
- [x] 女與回也孰愈 {#q.d46.2.1.o3}
  理由：“女与回也孰愈”是问话，注家另用一个“胜”字帮读者理解“愈”。

提示：看“注”字前后。
解析：“女与回也孰愈”是问话，注家另用一个“胜”字帮读者理解“愈”。

## 单选：现代译者写“你和颜回谁更强些”。若要查这句译意中的“强”从何来，哪份记录分得清三层？ {#q.d46.2.2}
考点：skill.d46.layers
语境：p.d46.2.r1

- [ ] 注说“女与回也”，经文只剩“胜也”。 {#q.d46.2.2.o1}
  理由：“女与回也”在经文，“胜”恰是注文才出现的字。
- [x] 经作“愈”，注用“胜”释它，译者据此写“强”。 {#q.d46.2.2.o2}
  理由：译文能帮助读懂旧注，却不能拿“强”证明正文有这一字形。
- [ ] 经作“强”，孔子又用“愈”自注。 {#q.d46.2.2.o3}
  理由：经文问的是“孰愈”；小字解词也不属于孔子问话。

提示：引语里的字和解释里的字有先后。
解析：译文能帮助读懂旧注，却不能拿“强”证明正文有这一字形。

## 找原文证据：为“闻一以知十”的“闻”记一个版本差异，只抄哪几个字可以保留异本所见？ {#q.d46.2.3}
考点：skill.d46.collate
语境：p.d46.2.r2

- [ ] 非 {#q.d46.2.3.o1}
  理由：这是判断一个写法有误，单凭它看不出另本作什么。
- [ ] 如字 {#q.d46.2.3.o2}
  理由：“如字”给本字注音，没有报出另本字样。
- [x] 本或作問字 {#q.d46.2.3.o3}
  理由：“本或作问字”可以直接填入异文栏；原本的“闻”仍然照录。

提示：寻找“另一本写了什么”。
解析：“本或作问字”可以直接填入异文栏；原本的“闻”仍然照录。

## 单选：笔记要分列“闻怎么读”和“另本作什么、音义取不取”。哪一种把三项都抄对了？ {#q.d46.2.4}
考点：skill.d46.collate
语境：p.d46.2.r2

- [x] 闻照常音；有本作问；音义不取问。 {#q.d46.2.4.o1}
  理由：“如字”说闻照常音，“本或作问字”记异文，“非”表示写音义的人不采纳问字。
- [ ] 闻照常音；音义反对问字，所以没有任何一本作问。 {#q.d46.2.4.o2}
  理由：一个写法被判错，不等于没人这样抄过。
- [ ] 闻要按问的音读；有本作问；音义不取问。 {#q.d46.2.4.o3}
  理由：“如字”让闻照通常的音读。另本“问”只是一项版本记录，不是本字的注音。

提示：末尾还有一个“非”。
解析：“如字”说闻照常音，“本或作问字”记异文，“非”表示写音义的人不采纳问字。

## 单选：本章疏又说：“若臯陶謨之九德也。”《皋陶谟》把看似相反的品格并列。回到眼前经文，这条引书说明什么？ {#q.d46.2.5}
考点：skill.d46.layers
语境：p.d46.2.r3

- [ ] 孔子向皋陶发问，温、威、恭是对方三次作答。 {#q.d46.2.5.o1}
  理由：经文在形容孔子，没有两人对话。皋陶的篇名在疏里才出现。
- [x] 疏借《皋陶谟》的九德说明“温而厉”等并写两面；那部书是疏援引的典据。 {#q.d46.2.5.o2}
- [ ] 经文明说孔子逐条有了那九德，可把“九德”二字放进原句。 {#q.d46.2.5.o3}
  理由：“若”是疏家拿来相比，经文只列了这三组品貌。

提示：找出疏的“若”拿什么来比什么。
解析：读者从旧书的九德知道，一人兼有两种相反相成的品格本有类似的说法。“若臯陶謨之九德也”是疏家的举证，不能抄成经文。

## 单选：卷末这条跟在“疏郑注云八十缕为升”这一栏后。要核“升”字，先翻回哪一行？ {#q.d46.2.7}

## 单选：只凭这里的“又一说……当作登”，校样底下能写哪句话？ {#q.d46.2.8}
考点：skill.d46.collate
语境：p.d46.2.r5

- [x] 有人据字义主张“升”应作“登”，此处未举写“登”的具体本子。 {#q.d46.2.8.o1}
  理由：“于义为惬”明说理由在义理上讲得通；疑改应照疑改记，另本有此字须另有凭据。
- [ ] 古本都写“登”，后来只有四库本误写“升”。 {#q.d46.2.8.o2}
  理由：“又一说”没有报告所有古本，更没有说仅这一版不同。
- [ ] “登成也”是孔子解释头上怎样戴冠。 {#q.d46.2.8.o3}
  理由：这是提议改字者的理由，所谈的是缕数的说法。

提示：在这段话里找没找到“某本作登”？
解析：“于义为惬”明说理由在义理上讲得通；疑改应照疑改记，另本有此字须另有凭据。
