## 原文：古籍引文 {#p.check.46.r1}
> 元氏之世，在洛京時，有一才學重臣，新得《史記音》，而頗紕繆。誤反顓頊字，頊當為許録反，錯作許縁反。遂一一謂言從來謬音專旭，當音專翾耳。此人先有高名，翕然信行。朞年之後，更有碩儒苦相究討，方知誤焉。
译文：颜之推记述：北魏在洛阳时，一位素有学问声望的重臣得到一部《史记音》，但本子颇有讹误。“颛顼”的“顼”本用“许録”注音，却抄成“许縁”。他便对人说，向来读得近“专旭”都错了，应当近“专翾”。人们信他的名声，跟着这样读。过了一年，有学问的人再三查究，才发现错误。
词注：顓頊：传说中的古帝名，普通话读 zhuān xù。
  許録反：颜之推认为此本应有的反切。
  朞年：一整年。
  究討：反复查究。

## 原文：古籍引文 {#p.check.46.r5}
> 詩云：「有杕之杜。」江南本並木傍施太。傳曰：「杕，獨皃也。」徐仙民音徒計反。《說文》曰：「杕，樹皃也」，在木部；《韻集》音次第之第。而河北本皆為夷狄之狄，讀亦如字，此大誤也。
译文：颜之推说，江南的《诗》本用木旁的“杕”。他列出传的释义、徐仙民的反切、《说文》的木部和《韵集》的比音。河北本作“狄”，照“狄”通常的音读；颜之推认为这是错的。
词注：杕：此处指树孤立的样子。
  次第：次序。此处举“次第”的“第”作比音。
出处：《颜氏家训·书证》第十七，“有杕之杜”条
作者：北齐·颜之推

## 单选：依颜之推所取的字形和《韵集》的比音，查简表 dì〔第、杕〕、dí〔狄、荻〕。哪条笔记既查对了字，又能解出“有杕之杜”写树的样子？ {#q.check.46.1}
考点：skill.d46.sound
语境：p.check.46.r5

- [ ] dì 栏的第：后面出现了“次第”，就要查次序。 {#q.check.46.1.o1}
  理由：“次第之第”只供音。本篇要找的字是木旁，写的是树。
- [x] dì 栏的杕：拿“第”作比音，拿传的“独”释杜树独立的样子。 {#q.check.46.1.o2}
- [ ] dí 栏的狄：既有本如此写，颜之推也应取这个读音。 {#q.check.46.1.o3}
  理由：河北本的写法须记下，但作者明确不同意，不能归为他的取字。
- [ ] dì 栏的杕：诗里是一株杜树，单凭《韵集》的“第”就能解为排行第一的树。 {#q.check.46.1.o4}
  理由：“第”只说明怎么念，不能替传的“独皃”讲树的样子。

提示：作者引的资料中，哪一处只给声音，哪一处还给了写树的意思？
解析：《韵集》的“第”把读者带到 dì 栏；《说文》的木部和诗中的树再帮助确定“杕”。若只抄读音，便分不清字头和注音用的字。

## 单选：抄本从“许録”变成“许縁”。颜之推说校出的是什么音误？哪一部分的取音依据变了？ {#q.check.46.2}
考点：skill.d46.collate
语境：p.check.46.r1

- [ ] 两切下字不同，换的是声母；韵和声调仍都取自同一个“许”。 {#q.check.46.2.o1}
  理由：下字用来定韵和调；取声母的是两切都有的上字“许”。
- [x] 按颜之推的记载，取声母的上字仍是許，给韵和声调的下字由録误成縁。 {#q.check.46.2.o2}
  理由：真正改变的是提供韵和调的下字；传播很广与查得可靠，在此是前后两件事。
- [ ] 把上字許改作縁，重臣当场就发现是抄错了。 {#q.check.46.2.o3}
  理由：“许録”“许縁”的上字相同；重臣自己还照错本教人。

提示：并排写两组反切，留意两个位置各管哪部分声音。
解析：真正改变的是提供韵和调的下字；传播很广与查得可靠，在此是前后两件事。

## 单选：疏为“不贰过”引《易·系辞下》“有不善未尝不知，知之未尝复行也”。在哀公问答旁边怎样记这个出处？ {#q.check.46.3}
考点：skill.d46.layers
语境：p.check.46.r2

- [ ] 哀公问颜回会不会背《易》，孔子答说他从不念错。 {#q.check.46.3.o1}
  理由：哀公问谁好学；经文的“不贰过”也没有“背诵”一义。
- [ ] 把“知之未尝复行也”接在哀公的问话中，补出他问的第二件事。 {#q.check.46.3.o2}
  理由：这一句来自疏家后来征引的另一篇，不在哀公问题里。
- [x] 疏借《易》中另一处谈颜回的话，解释他知错以后不再犯；经文仍照录“不贰过”。 {#q.check.46.3.o3}

提示：先确定哀公当时在问什么，再看疏借哪一句来解释孔子的回答。
解析：“贰过”是再犯同一过错。《系辞下》所见的“知之未尝复行”说明颜回知错后如何行事；书名与后一句同属疏的引证。

## 单选：把异本音义放回经文“今也则亡未闻好学者也”。照无“亡”本排印，剩下的字怎样连？是谁在作判断？ {#q.check.46.5}
考点：skill.d46.boundary
语境：p.check.46.r3

- [ ] 今也则。亡未闻好学者也。 {#q.check.46.5.o1}
  理由：除了保留“亡”，又在“则”后硬截断，违背“连下句读”。
- [ ] 今也则亡。未闻好学者也。 {#q.check.46.5.o2}
  理由：这里仍有“亡”，是另一种本子。
- [x] “今也则未闻好学者也”连读，是孔子说自己如今未再听闻。 {#q.check.46.5.o3}
  理由：没了“亡”，“则”直接引出“未闻好学者也”；保留同一段的陈述，句界却得重排。
- [ ] “今也则未闻好学者也”连读，改由哀公反问孔子是否未曾听说。 {#q.check.46.5.o4}
  理由：变的是“亡”字的有无；孔子的答语并未结束，也没有新的“问曰”。

提示：实际把“亡”遮住。谁在说话，答语到这里结束了吗？
解析：没了“亡”，“则”直接引出“未闻好学者也”；保留同一段的陈述，句界却得重排。

## 单选：简体译写“二十九发尽白”。回引古疏时，哪一条同时核对了繁体字形和说法的出处？ {#q.check.46.6}
考点：skill.d46.simplified
语境：p.check.46.r4

- [ ] “二十九髮盡白”，是孔子答语直接报出的年龄。 {#q.check.46.6.o1}
  理由：经文只说“不幸短命死矣”；年岁和白发在疏中。
- [ ] “二十九發盡白”，是颜回答哀公时说自己已经出发。 {#q.check.46.6.o2}
  理由：存世引文在说头发变白；这里的发与出发无关。
- [x] “二十九髮盡白”，是疏家解释“不幸短命”时列的细节。 {#q.check.46.6.o3}
  理由：髮是头发。孔子答语没有二十九这几个字；回引时两件事都应交代清楚。

提示：除了发的字头，还得对准经、疏的位置。
解析：髮是头发。孔子答语没有二十九这几个字；回引时两件事都应交代清楚。
