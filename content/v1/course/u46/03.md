# 课文：把“焉”挪过句界，会变成什么话？ {#d46.3}
简介：给同一串字试两种有古注可查的断法，说出每种停顿改变了哪一句。

## 正文

读“十室之邑……”时，先把“必有”管到哪儿画出来。“焉”若跟在“者”后面，就能把前一句收住；若“焉”领起“不如”，得试试“怎么会不如”的问法。两种停法动的只有一个字，孔子说别人是否和自己一样好学，却变了。

原书音义记卫瓘把“焉”读在下句。疏家解释完两种读法，说“义并得通，故具存焉”。检验断句，要能替两边各讲一句通顺的话。下面另有一则失火的记事，先读无标点的原文，再看“不”往哪一边放。

## 知识点：比较有据的两种句界 {#skill.d46.boundary}
义项：移动争议字的停顿位置，并分别说明两种读法
领域：阅读技能
要诀：把争议字先接上句，再接下句
讲解：两种停顿都见于古注时，把句界和对应的语意成对记下来。留住分歧，仍能指出两说都承认的事实。
例句：p.d46.3.r1

## 知识点：用句界复核是谁问、谁叙述 {#skill.d46.voice}
义项：按停顿和问辞，核实一句是发问、反问还是记事
领域：阅读技能
要诀：先确定引语到哪儿，后面一句再找主语
讲解：陈述“不如”与反问“焉不如”语气相反。把“不”读作“否”并在此停，后一动作也会从“没有问”变成“问了”。
例句：p.d46.3.r2

## 原文：古籍引文 {#p.d46.3.r1}
> 子曰十室之邑必有忠信如丘者焉不如丘之好學也
译文：孔子说，十户的小邑一定有忠信像我这样的人。下文有两读：一读谓好学不如我；一读反问怎会不如我好学。
词注：丘：孔子的名，此处自称。
  十室之邑：只有十户的小邑。

## 单选：若先按“必有忠信如丘者焉”停，下一句怎样接？ {#q.d46.3.1}
考点：skill.d46.boundary
语境：p.d46.3.r1

- [ ] 前面否认有人忠信，后面改说他们都好学。 {#q.d46.3.1.o1}
  理由：“必有”先肯定存在；没有否定忠信的人。
- [x] 承认有人同样忠信，接着说对方不如自己好学。 {#q.d46.3.1.o2}
  理由：句末“焉”收住存在句；下一句从“不如”开始，正面说不及。
- [ ] 从“焉”起反问怎么会不如自己。 {#q.d46.3.1.o3}
  理由：这要把“焉”移到下一句，和题中给定的停顿不同。

提示：这一次把“焉”留给“者”。
解析：句末“焉”收住存在句；下一句从“不如”开始，正面说不及。

## 单选：卫瓘读“必有忠信如丘者／焉不如丘之好学也”。这里问的是什么？ {#q.d46.3.2}
考点：skill.d46.voice
语境：p.d46.3.r1

- [ ] 那个忠信的人在哪里读书？ {#q.d46.3.2.o1}
  理由：“焉”接着“不如”，不是独立向人打听地点。
- [x] 怎能说他们在好学上不如我？ {#q.d46.3.2.o2}
  理由：“焉不如”相当于“安不如”，是反问。按这一路，好学像孔子的人也可有。
- [ ] 十户之邑究竟有没有人忠信？ {#q.d46.3.2.o3}
  理由：这件事已由“必有”承认；反问落在后面的“不如”。

提示：先把“焉”换成“安”试读。
解析：“焉不如”相当于“安不如”，是反问。按这一路，好学像孔子的人也可有。

## 单选：甲译“忠信与我相当，好学却不及我”，乙译“既能忠信如我，怎会不如我好学”。什么地方必须在两份校读中对照？ {#q.d46.3.3}
考点：skill.d46.boundary
语境：p.d46.3.r1

- [x] “者焉／不如”和“者／焉不如” {#q.d46.3.3.o1}
  理由：把焉挪过句界，它就由上句的收尾变成下句的问辞。
- [ ] “忠／信”与“忠信” {#q.d46.3.3.o2}
  理由：把两种品德拆开，并不能说明下句由陈述变成反问。
- [ ] “十室／之邑”与“十室之邑” {#q.d46.3.3.o3}
  理由：这只关乎村邑大小，改不了“不如”的语气。

提示：只移动一个有分歧的字。
解析：把焉挪过句界，它就由上句的收尾变成下句的问辞。

## 单选：有人把两份译文概括为“一本说小邑没有忠信的人，一本说有”。如何依据原文修订？ {#q.d46.3.4}
考点：skill.d46.voice
语境：p.d46.3.r1

- [ ] 两读都承认小邑的人全比孔子更好学。 {#q.d46.3.4.o1}
  理由：“必有”不是“人人如此”，反问也未说胜过孔子。
- [x] 两读都承认“必有忠信如丘者”；分歧在好学能否比得上。 {#q.d46.3.4.o2}
  理由：忠信这一判断在“焉”前已经成立，改变的是后一句怎么评量好学。
- [ ] 两读争的是孔子说“丘”时指哪位弟子。 {#q.d46.3.4.o3}
  理由：孔子在这里自称丘，自称不随“焉”的停顿改变。

提示：先圈两种断法都没拆开的部分。
解析：忠信这一判断在“焉”前已经成立，改变的是后一句怎么评量好学。

## 单选：若依疏家以“伤人乎”结问，接下来的三个字怎样断？ {#q.d46.3.5}
考点：skill.d46.boundary
语境：p.d46.3.r2

- [ ] “不”读作“否”，在它后面停，再另起“问马”。 {#q.d46.3.5.o1}
  理由：这是另一种有据的断法；疏家这里明确把“不问马”作记事者的话。
- [ ] 把“问”接在“退朝”后，再问人是否伤马。 {#q.d46.3.5.o2}
  理由：这样打散了“曰伤人乎”的问语，还改变了受伤者。
- [x] “不问马”连读，叙述者交代孔子未问马。 {#q.d46.3.5.o3}
  理由：“乎”收住孔子的话，随后记事者另记他没有问起马。

提示：疏把问话和记事分成两层。
解析：“乎”收住孔子的话，随后记事者另记他没有问起马。

## 单选：两种停法都可谈末尾的马。原文哪一件事不随停顿改变？ {#q.d46.3.6}
考点：skill.d46.voice
语境：p.d46.3.r2

- [ ] 孔子一回家先问马有没有事。 {#q.d46.3.6.o1}
  理由：顺序中“伤人乎”在前，两种古读都承认这一问。
- [ ] 作者肯定把马厩写成公家的。 {#q.d46.3.6.o2}
  理由：“厩”一字没有说明归属，注家对此也有不同意见。
- [x] 孔子退朝后先问到人的安危。 {#q.d46.3.6.o3}
  理由：两说共同的起点是失火后先关心人，分歧发生于随后是否问马。

提示：先把“不”遮住，再读前半。
解析：两说共同的起点是失火后先关心人，分歧发生于随后是否问马。

## 找原文证据：对照这个卷末按语，要在无标点经文里准确落刀，应该圈哪几个字作依据？ {#q.d46.3.7}
考点：skill.d46.boundary
语境：p.d46.3.r3

- [ ] 而後問馬也 {#q.d46.3.7.o1}
  理由：说明句界改变后的意思，没有直接指明在何字处停。
- [x] 不字絶句 {#q.d46.3.7.o2}
  理由：“不字绝句”把“不”留在前边；“问马”于是可另成一事。
- [ ] 先問人 {#q.d46.3.7.o3}
  理由：只说明先问什么，尚未交代停顿落在哪个字后。

提示：找到直接说“在此断”的话。
解析：“不字绝句”把“不”留在前边；“问马”于是可另成一事。

## 单选：如果给人物动作写旁批，哪一条能把卷末“先问人而后问马”与通常的“不问马”区分开？ {#q.d46.3.8}
考点：skill.d46.voice
语境：p.d46.3.r3

- [ ] 这一读让马先开口回答，孔子才问到人。 {#q.d46.3.8.o1}
  理由：“先问人”的先后清楚，句里也没有马开口。
- [x] 这一读把“不”读“否”并在此停，后面还写了问马。 {#q.d46.3.8.o2}
  理由：这一读把否的用法和问马这一动作连在一起；另一读以“不”否定“问马”。
- [ ] 两读都说不曾问马，只是一处用了问号。 {#q.d46.3.8.o3}
  理由：按语明说“而后问马”，所记动作确有差别。

提示：不要只换标点符号，重讲一遍发生的事。
解析：这一读把否的用法和问马这一动作连在一起；另一读以“不”否定“问马”。
