# 课文：鱼有几尾，礼有几件 {#lex41.3}
简介：一行写潭中有“百许头”鱼，一行写送客“白璧一双”。一处约计，一处点清了实数。
回读：lex.s.river lex41.3.p3
  lex.s.guard lex41.3.p4

## 正文

先找出数的究竟是什么。史书里可以把礼物放在前面，接着报数：“白璧一双”就是两件白璧合成一双。若下一行换作“玉斗一双”，不能把两双误看成同一份礼物。

数里若有“许”，报数的人往往留了余地。“百许头”适合远观鱼群；若写交接凭单，就不能凭这句话担保恰好一百头。对比“十余人”：它明确比十人多，“十人许”只说人数约在十人上下。

## 知识点：数量后的许，在某数上下 {#lex.s.approx}
义项：将数量中的许读为估量，区分上下约数与超过底数的余数
领域：实词
要诀：数目是否来自一一核点？“许”前后有数量单位吗？
讲解：“百许头”可以表成百来条。这里的“许”与“应许”某事无关。
例句：lex41.3.p1

## 知识点：名物之后列数量 {#lex.s.items}
义项：把名物后面的数词、量词配回对应的物品
领域：句法
要诀：每次换了物名，就从后面寻找属于它的那一组数。
讲解：“弓二，矢十”逐项数弓和箭。遇到“一双”，一双之内还有两件。
例句：lex41.3.p2

## 原文：古籍引文 {#lex41.3.p1}

词注：可：大约。
  头：这里用来计鱼。

## 单选：能否把这份游记填成“鱼的清点实数＝100”？ {#lex41.3.q1}
考点：lex.s.approx
语境：lex41.3.p1

- [ ] 应写成超过百尾，至少一百零一 {#lex41.3.q1.o1}
  理由：“许”只把数目放在百尾上下，没有给出这个下限。

- [x] 只宜记作约百尾，确数还不知道 {#lex41.3.q1.o2}

- [ ] 可以，“头”字说明逐尾点过 {#lex41.3.q1.o3}
  理由：有计数单位，也仍然可以报约数。

提示：注意数字两边的两个字。
解析：“可”“许”都写估量；作者记游时所见，并没有列出清点记录。

## 单选：若改成“一百余头”，相比原文多了哪层限定？ {#lex41.3.q2}
考点：lex.s.approx
语境：lex41.3.p1

- [x] 明确超过一百，原文只说在一百上下 {#lex41.3.q2.o1}

- [ ] 明确少于一百 {#lex41.3.q2.o2}
  理由：有余数的一方超过整百。

- [ ] 明确恰好一百 {#lex41.3.q2.o3}
  理由：“余”保留了未具体列出的部分。

提示：把“余”的零头与“许”的估量分开。
解析：“余”表示整百另有零头；“许”自身没有说明多于还是少于这个数。

## 单选：按张良报的清单，大王与大将军分别收到什么？ {#lex41.3.q3}
考点：lex.s.items
语境：lex41.3.p2

- [ ] 大王得两双璧，大将军只得一只斗 {#lex41.3.q3.o1}
  理由：“再拜”数的是礼节动作，不可添进物件里。

- [x] 大王得一对白璧，大将军得一对玉斗 {#lex41.3.q3.o2}

- [ ] 每人一璧一斗，两人合为一双 {#lex41.3.q3.o3}
  理由：两次“一双”各紧跟一个物名。

提示：从第一个“一双”逐项读到第二个“一双”。
解析：每次先列物名和“一双”，随后说明献给谁。

## 单选：若按“件”而非按“双”装匣，这两份礼物共几件？ {#lex41.3.q4}
考点：lex.s.items
语境：lex41.3.p2

- [x] 四件，两璧两斗 {#lex41.3.q4.o1}

- [ ] 两件，一璧一斗 {#lex41.3.q4.o2}
  理由：这样把一双误算成一件。

- [ ] 六件，另把两次行礼也计入 {#lex41.3.q4.o3}
  理由：“拜”是献礼时的动作，不能装匣。

提示：留意两处相同的单位。
解析：白璧、玉斗各一双，一双是两件。

## 原文：教学例句 {#lex41.3.p3}
> 记行者曰：“余自孟津渡河，北行十里许，见废亭。亭旁有小溪，水可涉也。”
译文：记行的人从孟津渡过黄河，向北走了约十里，看见一座废亭。亭旁有一条可以蹚过的小溪。
词注：孟津：黄河渡口。
  涉：蹚水而过。

## 单选：地图上有两处水道，哪一处能用原文的“河”标记？ {#lex41.3.q5}
考点：lex.s.river
语境：lex41.3.p3

- [ ] 由孟津一直流到废亭的北向水道 {#lex41.3.q5.o1}
  理由：“北行”写人的路线，未说河流向北。

- [x] 孟津渡处的黄河 {#lex41.3.q5.o2}

- [ ] 废亭边的小溪 {#lex41.3.q5.o3}
  理由：看见小溪在过河之后。

提示：从哪个渡口出发，走了多远才遇到另一处水？
解析：先在孟津渡河，北行后方见小溪；这是行程的两个不同位置。

## 单选：若给后来者写一张路条，“十里许”该记成什么？ {#lex41.3.q6}
考点：lex.s.approx
语境：lex41.3.p3

- [x] 向北约十里 {#lex41.3.q6.o1}

- [ ] 向北至少十一里 {#lex41.3.q6.o2}
  理由：“许”没有“余”所含的超出底数的限定。

- [ ] 获准北行十里，到了必须停下 {#lex41.3.q6.o3}
  理由：“许”跟在里数后，沿途也没有发布命令的人。

提示：看“许”是在回答走多远，还是谁准许。
解析：“许”跟在里数后，只估一段路程，不能据此精确定位到里界。

## 原文：教学例句 {#lex41.3.p4}
> 城将遣爪牙之士巡堞，授之弩二、矢三十。士受而登，明旦以未发之矢归库。
译文：守将派勇士巡视城上的矮墙，发给他们两张弩、三十支箭。士卒领了上城，次晨将未射的箭还库。
词注：堞：城墙上的矮墙。
  弩：用机械发箭的弓。

## 单选：这里说“爪牙之士”，从所派的事情看是什么人？ {#lex41.3.q7}
考点：lex.s.guard
语境：lex41.3.p4

- [ ] 替工匠修理城墙的徒弟 {#lex41.3.q7.o1}
  理由：“巡堞”说巡守，未说施工。

- [x] 负责上城巡守的武士 {#lex41.3.q7.o2}

- [ ] 潜入城里夺箭的敌军 {#lex41.3.q7.o3}
  理由：武器是守将当面发的。

提示：看受谁差遣、领什么东西、到哪里去。
解析：守将交武器，命他们巡守，“士”指守城人；不必另添“恶人”的评语。

## 单选：武库发出的装备应怎样记？ {#lex41.3.q8}
考点：lex.s.items
语境：lex41.3.p4

- [x] 两张弩，三十支箭 {#lex41.3.q8.o1}

- [ ] 三十张弩，两支箭 {#lex41.3.q8.o2}
  理由：名物后的数目被颠倒了。

- [ ] 共三十件，其中有两张弩 {#lex41.3.q8.o3}
  理由：三十专跟在“矢”后，弩还得另计。

提示：沿原来的次序把数添到各个物名下。
解析：“弩二、矢三十”先写物名，再各记实数。
