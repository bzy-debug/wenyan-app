# 课文：一百石收多少 {#lex41.1}
简介：“赋十一”和“得粟十一石”都写了十和一。后面一句交代实数，前面一句要先知道征税的比率。
回读：skill.vocab.9.3 lex41.1.p5

## 正文

古书说赋税有时用“什一”，也可写作“十一”。若是“岁取其十一”，它先把收成分成十份，再取其中一份。换成“得粟十一石”，十一却是直接给粟计数。看数字前后是取税的份额，还是可逐一核点的数目。

若写作“三分其田，留其二”，顺着动词读即可：整块田分三份，留下其中两份。先把整份圈出来，再写取走、留下或分给谁的份数。

## 知识点：征取语境的“什一、十一” {#lex.s.tenth}
义项：分清从总量抽取十分之一与点数十一件
领域：实词
要诀：找出所收的总量，看看这个数字是实物数还是份额。
讲解：“征其什一”按所收的十分之一征取；“粟十一石”直接说十一石。
例句：lex41.1.p1

## 知识点：分成若干份，从中取几份 {#lex.s.portion}
义项：读出“几分……取／有其几”的整体与所占份额
领域：实词
要诀：先找到要分的整体，再数留下或取走的是哪几份。
讲解：“三分天下有其二”说的是三份中据有两份。先读完整话，再把它换成今天的分数写法。
例句：lex41.1.p3

## 原文：古籍引文 {#lex41.1.p1}
> 夏后氏五十而贡，殷人七十而助，周人百亩而彻，其实皆什一也。
译文：孟子说夏、商、周三代的田制名称和所举田亩数不同，实际征取的比例都是十分之一。
词注：什一：十分取一。

## 单选：三种办法名称不同，孟子说它们在哪一点相同？ {#lex41.1.q1}
考点：lex.s.tenth
语境：lex41.1.p1

- [ ] 每户的田一律划作一百亩 {#lex41.1.q1.o1}
  理由：前面列的数本就不同。

- [x] 按他的说法，所取份额都是十分之一 {#lex41.1.q1.o2}

- [ ] 三种办法都只向十一家收取 {#lex41.1.q1.o3}
  理由：句子没有说户数。

提示：最后一句用“皆”把哪一点放在了一起？
解析：“其实皆什一”把三个名称合在一起说；五十、七十、百亩并不是同一田亩数。

## 单选：若只用孟子所说的比例示意，收获八十份应取几份？ {#lex41.1.q2}
考点：lex.s.tenth
语境：lex41.1.p1

- [x] 八份 {#lex41.1.q2.o1}

- [ ] 十一份 {#lex41.1.q2.o2}
  理由：这样把什一当成了固定数。

- [ ] 七十二份 {#lex41.1.q2.o3}
  理由：七十二是取八份之后的余数。

提示：先把八十份每十份圈作一组。
解析：每十份取一，八十份中便是八份；这里是用相同单位说明比例。

## 原文：教学例句 {#lex41.1.p2}
> 旧令赋粟十一。今年得粟二百石，当输二十石。另有种粟十一石，封之不输。
译文：旧令按收成的十分之一征粟。今年收了二百石，应交二十石。另有种粟十一石，封存起来不用交。
词注：输：交纳。
  种粟：留作种子的粟。

## 找原文证据：同样写“十一”，哪一处确实是在清点十一石粮？ {#lex41.1.q3}
考点：lex.s.tenth
语境：lex41.1.p2

- [ ] 当输二十石 {#lex41.1.q3.o1}
  理由：这里是按比率算出的本年税额，明写二十。

- [x] 种粟十一石 {#lex41.1.q3.o2}

- [ ] 旧令赋粟十一 {#lex41.1.q3.o3}
  理由：若定额十一石，就与本年应输二十石矛盾。

提示：哪一句说的是另行封存的种粮？
解析：这处紧跟“石”，报出实存的种粮数；前一处可用二百取二十校验。

## 单选：若收成比二百石减半，旧令不变，该怎样改税额？ {#lex41.1.q4}
考点：lex.s.tenth
语境：lex41.1.p2

- [x] 收一百石，交十石 {#lex41.1.q4.o1}

- [ ] 仍交二十石 {#lex41.1.q4.o2}
  理由：二十石对应原来的二百石收成。

- [ ] 改交十一石 {#lex41.1.q4.o3}
  理由：“十一”在旧令里说的是十份取一份。

提示：试把原来二百石交二十石的办法用在一百石上。
解析：“十一”是税率，收成减半，实交同样减半。

## 单选：“三分天下有其二”中，周已有天下的几分？ {#lex41.1.q5}
考点：lex.s.portion
语境：lex41.1.p3

- [ ] 三分之一 {#lex41.1.q5.o1}
  理由：一份是其余所占，周有其二。

- [x] 三分之二 {#lex41.1.q5.o2}

- [ ] 一半 {#lex41.1.q5.o3}
  理由：“二”是周所据的份数，总份数在“三分”中。

提示：分成几份？“有”的又是几份？
解析：被分的是整个天下，接下来的“二”是三份中的两份。

## 原文：教学例句 {#lex41.1.p5}
> 今年麦熟，所得倍于去岁。取其十之一入仓，另书所入之数，亦倍于去岁。
译文：今年小麦丰收，收成是去年的两倍。取十分之一存入仓库，把所入的数目另记下来，也比去年加了一倍。
词注：去岁：去年。

## 单选：去年以十分之一入仓，入了六斗；今年税率相同，“所入之数”该记多少？ {#lex41.1.q6}
考点：skill.vocab.9.3
语境：lex41.1.p5

- [ ] 十八斗 {#lex41.1.q6.o1}
  理由：“倍于去岁”是现在为原来的两倍，不是在原数外再加两个原数。

- [x] 十二斗 {#lex41.1.q6.o2}

- [ ] 六十斗 {#lex41.1.q6.o3}
  理由：十是一份占总数的比例，把六乘十得到的是去年的总收成。

提示：问的是仓中实收，先把今年同去年相比较。
解析：收成翻了一倍，所取的比例不变，入仓数随之翻一倍。

## 原文：教学例句 {#lex41.1.p4}
> 四分其帛，一以制帷，二以为衾，余藏诸箧。
译文：把帛分成四份，一份做帷帐，两份做被子，剩下的收在箱中。
词注：衾：被子。
  诸箧：在箱子里。

## 单选：若手里原有四十尺帛，拿来做衾的有多少？ {#lex41.1.q7}
考点：lex.s.portion
语境：lex41.1.p4

- [ ] 十尺 {#lex41.1.q7.o1}
  理由：十尺只相当于一份。

- [x] 二十尺 {#lex41.1.q7.o2}

- [ ] 两尺 {#lex41.1.q7.o3}
  理由：“二”承接上句分成的四份，不是在另报两尺。

提示：“二”前面还省着哪个计数单位？
解析：“二以为衾”指四份中的两份，即原帛的一半。

## 单选：箱中存了原帛的多少？ {#lex41.1.q8}
考点：lex.s.portion
语境：lex41.1.p4

- [x] 四分之一 {#lex41.1.q8.o1}

- [ ] 四分之三 {#lex41.1.q8.o2}
  理由：三份已经用掉，不能同时存进箱里。

- [ ] 一半 {#lex41.1.q8.o3}
  理由：四分之二是制衾的部分。

提示：只数已经指定用途的份，再看余下几份。
解析：一份作帷，两份作衾，四份里余一份。
