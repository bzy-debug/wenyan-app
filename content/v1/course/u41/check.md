# 检查：算仓粮、记修堤、量桥材 {#check.41}

## 原文：教学例句 {#lex41.check.p1}
> 里人共得麦三百斗，输其十一于官。分所余为三，二以给病户，一留为种。
译文：乡人合收小麦三百斗，取十分之一纳给官府。把剩下的分成三份，两份发给有病人的人家，一份留做种子。
词注：斗：容量单位。

## 单选：还没有分给病户以前，纳给官府的小麦已有多少？ {#lex41.check.q1}
考点：lex.s.tenth
语境：lex41.check.p1

- [ ] 一百斗 {#lex41.check.q1.o1}
  理由：三分要到交纳之后才做。

- [x] 三十斗 {#lex41.check.q1.o2}

- [ ] 十一斗 {#lex41.check.q1.o3}
  理由：这里先说所收总数，又说按多少份额交，不是点出十一斗的实数。

提示：先处理“输其十一”，暂时停在“所余”之前。
解析：“输其十一”取三百斗中的十分之一；后面才去分余粮。

## 单选：留种按哪一笔粮的三分之一计算？ {#lex41.check.q2}
考点：lex.s.portion
语境：lex41.check.p1

- [x] 纳粮后的二百七十斗，所以留九十斗 {#lex41.check.q2.o1}

- [ ] 原收三百斗，所以留一百斗 {#lex41.check.q2.o2}
  理由：这会让已经上交的也进入第二次分配。

- [ ] 已交官府的三十斗，所以留十斗 {#lex41.check.q2.o3}
  理由：“所余”指乡人手里余下的麦。

提示：留意“分”后面先写的两个字。
解析：“分所余为三”明定分的是余粮，留种占其中一份。

## 原文：教学例句 {#lex41.check.p2}
> 水坏东堤。吏告郡，居有顷，报至，许发卒。吏自登堤督役者三，然后归舍。
译文：水冲坏东堤。县吏上报郡里，过了一会儿得到回复，准许调发士卒。县吏自己三次登堤督工，然后才回住处。
词注：报：回复。
  督役：监督工程。

## 单选：“居有顷”写的是从哪件事到哪件事的间隔？ {#lex41.check.q3}
考点：lex.s.elapsed
语境：lex41.check.p2

- [ ] 从堤坏到堤修好 {#lex41.check.q3.o1}
  理由：末句只说回到住处，未记竣工日期。

- [x] 从上报郡里到郡里回复 {#lex41.check.q3.o2}

- [ ] 从第一次登堤到第三次登堤 {#lex41.check.q3.o3}
  理由：登堤都在回复以后。

提示：把这个短语遮住，看看两旁各发生什么。
解析：“吏告郡”在前，“报至”在后，夹在两者之间的是等候答复的一会儿。

## 单选：当日的督工记录能落实哪件事？ {#lex41.check.q4}
考点：lex.s.times
语境：lex41.check.p2

- [x] 同一个县吏三次登堤督工 {#lex41.check.q4.o1}

- [ ] 共有三名县吏各自登堤 {#lex41.check.q4.o2}
  理由：“吏自”接一个人亲自做的事。

- [ ] 郡中先后三次批准修堤 {#lex41.check.q4.o3}
  理由：回复出现在前，句末的三次指登堤督役。

提示：把“者三”紧前面的动作读完整。
解析：“自登堤督役者三”把前面的动作当成一项来数。

## 原文：教学例句 {#lex41.check.p3}
> 桥已圮，计两岸相去四丈许。库出长木六、短木十，工请益长木二。
译文：桥塌后，估量两岸相距约四丈。仓库拨出长木六根、短木十根，工匠请求再加两根长木。
词注：圮：倒塌。
  益：增添。

## 单选：木工能把“四丈许”当作精确裁木尺寸吗？ {#lex41.check.q5}
考点：lex.s.approx
语境：lex41.check.p3

- [ ] 不能，因为至少要四十一丈 {#lex41.check.q5.o1}
  理由：“许”不是另加一个十位或个位。

- [x] 还需实量，这只是估计两岸间距 {#lex41.check.q5.o2}

- [ ] 可以，只应刚好裁四丈 {#lex41.check.q5.o3}
  理由：“许”留下误差。

提示：看报距离时是否把零头也量清了。
解析：“许”随在长度之后，“计”又交代是估量；单凭此句无从下精确尺寸。

## 单选：若“益长木二”的请求还没获准，已经拨出的是多少？ {#lex41.check.q6}
考点：lex.s.items
语境：lex41.check.p3

- [x] 六根长木，十根短木 {#lex41.check.q6.o1}

- [ ] 八根长木，十根短木 {#lex41.check.q6.o2}
  理由：多出来的两根还只是请求。

- [ ] 六根短木，十根长木 {#lex41.check.q6.o3}
  理由：数量列在各自的木料名称之后。

提示：只把“库出”所领的物料写入已发一栏。
解析：“库出”领前两项实发清单；“工请”另起一个尚在请求的动作。
