# 课文：过了几天，辞让几次 {#lex41.2}
简介：“居五日”写两件事相隔多久；“辞让者三”写一件事做了几次。两种数目各有落处。

## 正文

史传里忽然插进“居五日”，不必急着给人物找住处。前后的两件事中间过了五天；若真是搬家居住，通常还得有住处等线索。

“鲁连辞让者三”，读到“者”也先别忙着找“三个人”。前面已有做事的人“鲁连”，这里把他辞让的动作拎出来，说明共辞让三次。碰到“辞让者三人”，才有计人的“人”作凭。

## 知识点：居接时段，在两事之间标出经过的时间 {#lex.s.elapsed}
义项：区分相隔若干时日与在某地居住
领域：实词
要诀：时间放在哪两件事中间？句里有没有交代住处？
讲解：“居有顷”只说过了一会儿；“居五日”便给出两件事之间的天数。
例句：lex41.2.p1

## 知识点：动词短语＋者＋次数 {#lex.s.times}
义项：由既定施事辨“者三”数同一动作的次数
领域：句法
要诀：先找谁已经在做事，再问有何依据把数目读成人数。
讲解：“鲁连辞让者三”主语已定，写的是他辞让三回。若是一群人，名数和语境会另有线索。
例句：lex41.2.p2

## 单选：若在“桓侯体痛”前添一个时间标记，应填什么？ {#lex41.2.q1}
考点：lex.s.elapsed
语境：lex41.2.p1

- [ ] 桓侯整整痛了五天才让人去找 {#lex41.2.q1.o1}
  理由：五日放在“体痛”前，未规定疼痛持续多久。

- [x] 距上文所记的事已经五天 {#lex41.2.q1.o2}

- [ ] 桓侯已在秦国居住五天 {#lex41.2.q1.o3}
  理由：去秦国的是扁鹊，未说桓侯搬家。

提示：把“居五日”与后面的“体痛”按原次序读。
解析：“居五日”先交代时间经过，随后才写体痛求医。

## 单选：读者能从本段确定哪段时间？ {#lex41.2.q2}
考点：lex.s.elapsed
语境：lex41.2.p1

- [x] 从前段事毕到桓侯体痛，相隔五日 {#lex41.2.q2.o1}

- [ ] 扁鹊逃到秦国用了五日 {#lex41.2.q2.o2}
  理由：这里只说求医时他已经离开。

- [ ] 从体痛到桓侯死恰好五日 {#lex41.2.q2.o3}
  理由：“遂死”没有另记日数。

提示：不要把表示经过的五日挪到段尾去。
解析：“居五日”向前承接，随后落在“桓侯体痛”；桓侯何日死并未精确记载。

## 单选：若写一条封赏记录，辞赏者一栏与辞让次数一栏怎样填？ {#lex41.2.q3}
考点：lex.s.times
语境：lex41.2.p2

- [ ] 平原君一人，让位三次 {#lex41.2.q3.o1}
  理由：欲封别人的是平原君，受封而推辞的是鲁连。

- [x] 鲁连一人，辞让三次 {#lex41.2.q3.o2}

- [ ] 三人，每人各辞一次 {#lex41.2.q3.o3}
  理由：句中写明辞让的是鲁连，未添另外两人。

提示：把两个名字分开放，“辞让”紧接谁？
解析：“鲁连”领起“辞让”，后面的数目落在这个动作上。

## 单选：“终不肯受”承接怎样的经过？ {#lex41.2.q4}
考点：lex.s.times
语境：lex41.2.p2

- [x] 经数次辞让，鲁连始终未受封赏 {#lex41.2.q4.o1}

- [ ] 前两个人受赏，最后一人拒绝 {#lex41.2.q4.o2}
  理由：没有三名受赏者。

- [ ] 鲁连第三回终于接受 {#lex41.2.q4.o3}
  理由：“终不肯受”正好说明结局相反。

提示：先读准“三”指什么，再看“终”的结果。
解析：“者三”记录同一人屡次辞让；结尾又明确未受。

## 原文：教学例句 {#lex41.2.p3}
> 使者既发，居有顷，北门始启。门吏呼使者者三，使者远矣，莫之应。
译文：使者出发后，过了一会儿北门才打开。门吏呼喊使者三次，使者已走远，没有人应声。
词注：发：出发。
  有顷：一会儿。

## 单选：使者出发和北门打开之间，有多长时间可据？ {#lex41.2.q5}
考点：lex.s.elapsed
语境：lex41.2.p3

- [ ] 使者在门边等了三次才出发 {#lex41.2.q5.o1}
  理由：三次说的是后来门吏的呼喊。

- [x] 只知道过了一小段时间 {#lex41.2.q5.o2}

- [ ] 门吏在北门住了整整一天 {#lex41.2.q5.o3}
  理由：“有顷”并无一日之意，文中也未叙述搬住。

提示：“居有顷”里有没有确数？
解析：“居有顷”标间隔，没有可以换算的准确时刻。

## 单选：若有人把“三”填成“三位使者”，门吏究竟做过什么就读丢了？ {#lex41.2.q6}
考点：lex.s.times
语境：lex41.2.p3

- [x] 门吏三次呼喊那位已经走远的使者 {#lex41.2.q6.o1}

- [ ] 门吏先后开过三道城门 {#lex41.2.q6.o2}
  理由：这里只有一处北门，计数也不连着“启”。

- [ ] 使者三次回头答话 {#lex41.2.q6.o3}
  理由：末句说没有人回应。

提示：先用白话说清数目之前的整件事。
解析：“门吏呼使者”是整个动作，句末“者三”数呼喊次数。

## 原文：教学例句 {#lex41.2.p4}
> 童持书候客。居三日，客未至。童之市问行贾者再，皆云未见。
译文：孩子拿着信等客人。过了三天，客人还没到。孩子到集市向行商打听了两次，都说没见过。
词注：行贾：往来经商的商人。

## 单选：写到“客未至”时，三日算在谁的哪件事上？ {#lex41.2.q7}
考点：lex.s.elapsed
语境：lex41.2.p4

- [ ] 两次打听之间相隔三天 {#lex41.2.q7.o1}
  理由：“居三日”在两次打听之前。

- [x] 孩子候客到这时已过了三天 {#lex41.2.q7.o2}

- [ ] 客人在市上已经住满三日 {#lex41.2.q7.o3}
  理由：客未到，也未说明他身在市上。

提示：沿着“候客”往下读到“未至”。
解析：“居三日”夹在候客和仍不见客之间。

## 单选：把末句记成“找了两个商人”够准确吗？ {#lex41.2.q8}
考点：lex.s.times
语境：lex41.2.p4

- [x] 只明说到市上打听了两回，未数出不同商人的人数 {#lex41.2.q8.o1}

- [ ] 够准确，者再一定代表另外两个人 {#lex41.2.q8.o2}
  理由：“再”在这里回数前面的动作。

- [ ] 不够，应记成商人来访两回 {#lex41.2.q8.o3}
  理由：去市上的是孩子，等的客人并未出现。

提示：分清问了几次和问了几位不同的人。
解析：“问行贾者再”数的是问询这件事；两回所问是否同一人，文字没有交代。
