# 课文：再看一次：同席与割席 {#l3.2}

简介：两件平行的小事怎样逐渐勾勒出两个人？

## 正文

读双人故事可以画一个两行两列的小表格。第一行填锄菜时谁照旧、谁动手；第二行填读书时谁照旧、谁离席。两个场景都填完，再读“子非吾友也”，你就能看见这句话由谁说向谁，前面有哪两层铺垫。

“**又尝**”另起一件往事，并不保证第二件事就在同一天。“席”是席地坐时所用的席子；割开共坐的席子，首先是一个可见的动作，其社会意义再由末句确定。

## 知识点：又尝 {#skill.l3.2.1}
义项：由另一件往事补证人物特点
领域：篇章
要诀：把两组反应放在相同栏位
讲解：另举一事后，要检查两段对照的对象有无改变，而不要自行补出两件事紧挨着发生。
例句：p.l3.2.a

## 知识点：同席 {#skill.l3.2.2}
义项：从席位的合分理解交往关系
领域：文化背景
要诀：用人物的话校准动作含义
讲解：同坐一席是场景事实。分席是否表示绝交，要看说话内容或后文行为，不能见“席”便断定。
例句：p.l3.2.a

## 原文：古籍引文 {#p.l3.2.a}
> 管宁、华歆共园中锄菜。见地有片金，管挥锄与瓦石不异，华捉而掷去之。又尝同席读书，有乘轩冕过门者，宁读如故，歆废书出看。宁割席分坐，曰：“子非吾友也。”
译文：管宁、华歆一起在园中锄菜。看见地上有块金子，管宁照样挥锄，把它当成瓦石；华歆拿起又扔开。两人又曾同席读书，有贵显之人乘车经过，管宁照旧读，华歆放下书出去看。管宁割开席子分坐，说：“你不是我的朋友。”

## 单选：下面哪一对动作都属于华歆？ {#q.l3.2.1}
考点：skill.l3.2.1
语境：p.l3.2.a

- [ ] 把金掷去；照旧读书
  理由：第二项属于管宁。
- [x] 捡金而又掷去；放下书出去看
- [ ] 把金当瓦石；放下书出去看
  理由：前一项是管宁的反应。

提示：按人物排列表格，再横跨两个场景。
解析：第一段称“华”，第二段称“歆”，都是华歆。不要把简称误当新人。

## 找原文证据：哪处提示读者换到另一件往事？ {#q.l3.2.2}
考点：skill.l3.2.1
语境：p.l3.2.a

- [ ] 宁读如故
  理由：这已是第二段中的反应。
- [x] 又尝同席读书
- [ ] 华捉而掷去之
  理由：仍是园中见金。

提示：找兼有“另一次”和“曾经”意味的词。
解析：“又尝”接续举例，园中与席上的对比因而并列。

## 单选：怎样确认割席在这里有绝交之意？ {#q.l3.2.3}
考点：skill.l3.2.2
语境：p.l3.2.a

- [ ] 两人把席割坏便无法读书
  理由：读书用席不能据此推断永远不能读。
- [ ] “捉而掷去”就是抛弃友情
  理由：被掷去的是金。
- [x] “子非吾友也”把动作的意思说了出来

提示：区分实物被处置与关系被说明。
解析：若只看割席，尚可理解为分坐；紧随其后的否认朋友关系才定下含义。

## 单选：末句“子”“吾”分别指谁？ {#q.l3.2.4}
考点：skill.l3.2.2
语境：p.l3.2.a

- [ ] 管宁、华歆
  理由：“宁割席分坐，曰”指定了说话者。
- [x] 华歆、管宁
- [ ] 过门者、华歆
  理由：过门者没有参加对话。

提示：先给“曰”补上主语。
解析：管宁说话，自称吾，对眼前的华歆称子。

## 原文：教学例句 {#p.l3.2.b}
> 周、陆同席校书。闻市中歌，陆出听，周守其卷。又尝校谱，有人持画过，陆起视，周仍书。暮，陆自请别坐，曰：“恐妨君也。”翌日二人复会。
译文：周、陆同席校书，听到集市有人唱歌，陆出去听，周仍看书卷。又一次校谱，有人带画经过，陆起身观看，周继续书写。傍晚陆请求另坐，说怕妨碍对方。次日两人又聚在一起。

## 找原文证据：第二次分心时，周保持原状的证据是哪句？ {#q.l3.2.5}
考点：skill.l3.2.1
语境：p.l3.2.b

- [ ] 周守其卷
  理由：这是第一次听歌时。
- [ ] 陆起视
  理由：这是陆的新动作。
- [x] 周仍书

提示：题目问第二件事，而且要找周。
解析：“又尝”划开两个场景；“仍”表示持守先前所做之事。

## 单选：为什么不可把这里的“别坐”解释成绝交？ {#q.l3.2.6}
考点：skill.l3.2.2
语境：p.l3.2.b

- [ ] 分开座位必是师徒礼仪
  理由：原文没有说二人是师徒。
- [x] 陆怕妨碍对方，次日二人又聚
- [ ] 周从未见到陆起身
  理由：周看见与否并无交代。

提示：把分坐前后的话与行动一起读。
解析：陆自述意图，次日复会又给出后续证据，两处都支持暂时另坐。

## 排序：把两次校勘与后续行动排好。 {#q.l3.2.7}
考点：skill.l3.2.1
语境：p.l3.2.b

- [3] 二人次日重聚
  理由：“翌日”在陆请求别坐之后。
- [2] 校谱时陆去看画
  理由：“又尝”另举一事。
- [1] 校书时陆去听歌
  理由：“闻市中歌”在前段。

提示：先识别两项工作，再读“翌日”。
解析：两段都出现陆起身，区分歌与画才能排对。

## 单选：“恐妨君也”应补出怎样的主客关系？ {#q.l3.2.8}
考点：skill.l3.2.2
语境：p.l3.2.b

- [ ] 持画者怕妨碍二人
  理由：持画者经过后未参与对话。
- [ ] 周担心歌声打扰陆
  理由：请别坐与说话的人是陆。
- [x] 陆担心自己打扰周

提示：从主动请求换座的人往下读。
解析：陆仍是“曰”的主语，“君”是陆对周的称呼。
