# 课文：再看一次：同席与割席 {#l3.2}

简介：锄菜时见了金子，读书时见了显贵的车。留心管宁与华歆在这两件事里各自怎样反应。

## 正文

管宁和华歆都见到了地上的金子。管宁照常挥锄，华歆却把金子捡起来又扔掉了。读到同席读书时，再分开看两人：谁还在读书，谁放下书出了门？知道这两次经过，管宁割席时说的那句话就有了来由。

**又尝**相当于“还有一回”，没有说两件事发生在同一天。**席**是两人铺在地上坐的席子。只看“割席分坐”，可以知道两人分开坐了。再读“子非吾友也”，才知道管宁把这件事看得多重。

## 知识点：又尝 {#skill.l3.2.1}
义项：再讲一件往事，看同一个人又怎样反应
领域：篇章
要诀：换了一件事，还是要分别看这两个人。
讲解：“又尝”另讲一回往事。读过锄菜和读书两段，再把管宁的两次反应放在一起，华歆的也放在一起。
例句：p.l3.2.a

## 知识点：同席 {#skill.l3.2.2}
义项：从同坐、分坐及当事人的话读懂彼此的关系
领域：文化背景
要诀：分开坐是什么意思，要听当事人怎么说。
讲解：同坐一席写的是两人的位置。“子非吾友也”和“恐妨君也”虽然都出现在分坐时，意思可大不一样。
例句：p.l3.2.a

## 原文：古籍引文 {#p.l3.2.a}
> 管宁、华歆共园中锄菜。见地有片金，管挥锄与瓦石不异，华捉而掷去之。又尝同席读书，有乘轩冕过门者，宁读如故，歆废书出看。宁割席分坐，曰：“子非吾友也。”
译文：管宁、华歆一起在园中锄菜。看见地上有块金子，管宁照样挥锄，把它当成瓦石；华歆拿起又扔开。两人又曾同席读书，有位显贵乘车从门前经过，管宁照旧读书，华歆放下书出去看。管宁割开席子分坐，说：“你不是我的朋友。”

## 单选：下面哪一对动作都属于华歆？ {#q.l3.2.1}
考点：skill.l3.2.1
语境：p.l3.2.a

- [ ] 把金掷去；照旧读书
  理由：第二项属于管宁。
- [x] 捡金而又掷去；放下书出去看
- [ ] 把金当瓦石；放下书出去看
  理由：前一项是管宁的反应。

提示：园中简称他“华”，读书时又怎样称他？
解析：园中“华捉而掷去之”，读书时“歆废书出看”。一处用姓，一处用名，说的都是华歆。

## 找原文证据：哪处提示读者换到另一件往事？ {#q.l3.2.2}
考点：skill.l3.2.1
语境：p.l3.2.a

- [ ] 宁读如故
  理由：这已是第二段中的反应。
- [x] 又尝同席读书
- [ ] 华捉而掷去之
  理由：仍是园中见金。

提示：找兼有“另一次”和“曾经”意味的词。
解析：前面还在园里锄菜，“又尝”就是“还有一次”，接下来已换到两个人同席读书。

## 单选：怎样确认割席在这里有绝交之意？ {#q.l3.2.3}
考点：skill.l3.2.2
语境：p.l3.2.a

- [ ] 两人把席割坏便无法读书
  理由：割开的是席子。原文没有说他们从此不能读书。
- [ ] “捉而掷去”就是抛弃友情
  理由：被掷去的是金。
- [x] “子非吾友也”把动作的意思说了出来

提示：管宁割开席子之后，开口说了什么？
解析：光看“割席分坐”，只知道两个人分开坐了。管宁亲口说“你不是我的朋友”，这才说清割席的用意。

## 单选：末句“子”“吾”分别指谁？ {#q.l3.2.4}
考点：skill.l3.2.2
语境：p.l3.2.a

- [ ] 管宁、华歆
  理由：“宁割席分坐，曰”指定了说话者。
- [x] 华歆、管宁
- [ ] 过门者、华歆
  理由：过门者没有参加对话。

提示：先给“曰”补上主语。
解析：“宁割席分坐，曰”，开口的是管宁，他用“吾”自称，对面那位“子”就是华歆。

## 原文：教学例句 {#p.l3.2.b}
> 周、陆同席校书。闻市中歌，陆出听，周守其卷。又尝校谱，有人持画过，陆起视，周仍书。暮，陆自请别坐，曰：“恐妨君也。”翌日二人复会。
译文：周、陆同席校书，听到集市有人唱歌，陆出去听，周仍看书卷。又一次校谱，有人带画经过，陆起身观看，周继续书写。傍晚陆请求另坐，说怕妨碍对方。次日两人又聚在一起。

## 找原文证据：有人带画经过时，哪三个字写周还在做自己的事？ {#q.l3.2.5}
考点：skill.l3.2.1
语境：p.l3.2.b

- [ ] 周守其卷
  理由：这是第一次听歌时。
- [ ] 陆起视
  理由：这是陆的新动作。
- [x] 周仍书

提示：先找“又尝校谱”，再看周的动作。
解析：第二回陆起身看画，周“仍书”。“仍”让人看出他还在接着写。

## 单选：为什么不可把这里的“别坐”解释成绝交？ {#q.l3.2.6}
考点：skill.l3.2.2
语境：p.l3.2.b

- [ ] 分开座位必是师徒礼仪
  理由：原文没有说二人是师徒。
- [x] 陆怕妨碍对方，次日二人又聚
- [ ] 周从未见到陆起身
  理由：周看见与否并无交代。

提示：把分坐前后的话与行动一起读。
解析：陆说“恐妨君也”，是自己怕打扰周。第二天二人又聚在一起，看不出有绝交的意思。

## 排序：两次校书校谱时发生了什么？按文中先后排一排。 {#q.l3.2.7}
考点：skill.l3.2.1
语境：p.l3.2.b

- [3] 二人次日重聚
  理由：“翌日”在陆请求别坐之后。
- [2] 校谱时陆去看画
  理由：“又尝”另举一事。
- [1] 校书时陆去听歌
  理由：“闻市中歌”在前段。

提示：听歌是在校书还是校谱时？“翌日”又在谁提议别坐之后？
解析：先是校书时听见歌，陆出去听；又有一回校谱，他去看画。说到“翌日”，已是在另坐之后。

## 单选：“恐妨君也”是谁怕打扰谁？ {#q.l3.2.8}
考点：skill.l3.2.2
语境：p.l3.2.b

- [ ] 持画者怕妨碍二人
  理由：持画者经过后未参与对话。
- [ ] 周担心歌声打扰陆
  理由：请别坐与说话的人是陆。
- [x] 陆担心自己打扰周

提示：从主动请求换座的人往下读。
解析：请求分开坐的是陆，说话的也是陆。他称周为“君”，是担心自己打扰周。
