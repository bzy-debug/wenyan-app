# 课文：一问两答：礼与偷饮 {#l3.3}

简介：两个人行为相反，却各自从一条规则出发解释自己。

## 正文

遇到两次“何以”，先写两个空句：“父亲问谁为何做了什么？”不要把前问的对象一直沿用到后问。答话中即使都提到礼，**依据**也可以不同：有人着眼于饮酒的礼仪，有人从取得酒的方式说起。

第二段把对子换成父子以外的一对兄弟。读完先问：这里究竟有几个孩子喝酒？相近的题材不能替代眼前的语法证据。

## 知识点：复问 {#skill.l3.3.1}
义项：在连续问答中重新定位被问者
领域：篇章
要诀：把每次问答各自配对
讲解：“又问”“谓曰”可换受话人；省去的“答”的主语通常要从该轮问话恢复。
例句：p.l3.3.a

## 知识点：礼 {#skill.l3.3.2}
义项：辨认行为依据的礼与行为本身是否合礼
领域：文化背景
要诀：问答者在谈哪一层行为
讲解：同样说礼，一人可以谈饮酒时的仪节，另一人谈偷取本身。把理由与当事人相配。
例句：p.l3.3.a

## 原文：古籍引文 {#p.l3.3.a}
> 钟毓兄弟小时，值父昼寝，因共偷服药酒。其父时觉，且托寐以观之。毓拜而后饮，会饮而不拜。既而问毓何以拜，毓曰：“酒以成礼，不敢不拜。”又问会何以不拜，会曰：“偷本非礼，所以不拜。”
译文：钟毓兄弟儿时，趁父亲午睡，一起偷喝药酒。父亲当时已醒，暂且装睡观察。钟毓先行礼后喝，钟会喝了却没有行礼。父亲接着分别问缘故：钟毓认为酒用来成礼，不能不拜；钟会说偷本身就不合礼，所以没拜。

## 找原文证据：父亲能分别追问两个孩子，是因为哪一处动作？ {#q.l3.3.1}
考点：skill.l3.3.1
语境：p.l3.3.a

- [ ] 值父昼寝
  理由：这是兄弟最初见到的情形。
- [ ] 因共偷服药酒
  理由：这是孩子的行为。
- [x] 且托寐以观之

提示：父亲醒后做了什么？
解析：托寐是假装睡着；“以观之”使后来对两种举动的提问有了根据。

## 单选：哪种转述保持了钟毓的理由？ {#q.l3.3.2}
考点：skill.l3.3.2
语境：p.l3.3.a

- [ ] 行过礼就等于得到父亲许可
  理由：钟毓没有说父亲许可。
- [x] 酒用于成礼，所以即使在偷饮时他也行了礼
- [ ] 偷饮原本不合礼，所以不能拜
  理由：这是钟会的解释。

提示：抓钟毓答语的开头。
解析：钟毓谈饮酒与成礼的关系，未把行拜说成偷取的许可。

## 单选：“又问会”改变了什么？ {#q.l3.3.3}
考点：skill.l3.3.1
语境：p.l3.3.a

- [x] 同一发问者转向另一个孩子
- [ ] 钟会接过父亲的问题去问兄长
  理由：“会”在“问”后，是被问者。
- [ ] 父亲转而询问另一件偷酒往事
  理由：仍在解释刚观察的同一场景。

提示：比较两次“问”后面紧跟的名字。
解析：先问毓为何拜，再问会为何不拜，问题对象和所问动作一同换了。

## 单选：两兄弟的答语能证明哪一点？ {#q.l3.3.4}
考点：skill.l3.3.2
语境：p.l3.3.a

- [x] 他们分别从饮酒仪节和偷取行为解释拜与不拜
- [ ] 钟会不知道喝酒时可以行礼
  理由：他给的是“不拜”的理由，没有说不知礼。
- [ ] 父亲认可二人偷饮的行为
  理由：没有父亲最后的裁定。

提示：答语可证明解释内容，能否证明父亲的判断？
解析：两种理由都用到礼，不能由孩子自辩推出父亲赞同。

## 原文：古籍引文 {#p.l3.3.b}
> 孔文举有二子，大者六岁，小者五岁。昼日父眠，小者床头盗酒饮之。大儿谓曰：“何以不拜？”答曰：“偷那得行礼！”
译文：孔文举有两个儿子，大的六岁，小的五岁。白天父亲睡着，小儿在床边偷酒喝。大儿问他为什么不行礼，小儿答：“偷东西哪里还谈得上行礼！”

## 单选：谁问“何以不拜”，又是谁回答？ {#q.l3.3.5}
考点：skill.l3.3.1
语境：p.l3.3.b

- [x] 哥哥问，偷酒的小儿回答
- [ ] 小儿问，哥哥答
  理由：“大儿谓曰”领起问句。
- [ ] 父亲问，两个儿子一起答
  理由：父亲在睡，问者明写“大儿”。

提示：“谓曰”前是谁？
解析：省略的被问者从前句偷酒的小儿恢复，回答也属于他。

## 找原文证据：哪一句把“偷”和“行礼”放在一起衡量？ {#q.l3.3.6}
考点：skill.l3.3.2
语境：p.l3.3.b

- [ ] 何以不拜
  理由：这是问题，还未提出判断。
- [ ] 小者床头盗酒饮之
  理由：这是叙述行为，还没有口头解释。
- [x] 偷那得行礼

提示：看答句如何回应哥哥。
解析：“那得”表示哪里能，孩子用偷与礼的不相称回答。

## 单选：钟氏故事说二人“共偷服药酒”。就眼前孔氏故事比较，谁喝了酒？ {#q.l3.3.7}
考点：skill.l3.3.1
语境：p.l3.3.b

- [ ] 两家都只有小儿喝
  理由：钟氏段明言“共偷服”。
- [ ] 两家兄弟都喝
  理由：孔氏段只写大儿提问。
- [x] 钟氏二人都喝，孔氏只写小儿喝

提示：比较“共”与“小者”各管哪个动作。
解析：两篇材料人物构成相似，不能据此把两家的行为也抄成相同。

## 单选：“偷那得行礼”适宜怎样读？ {#q.l3.3.8}
考点：skill.l3.3.2
语境：p.l3.3.b

- [ ] 叙述者颁布礼仪规则
  理由：这是人物答语，并非篇外规训。
- [x] 小儿用反问说明不拜的理由
- [ ] 小儿请教怎样完成拜礼
  理由：“那得”在这里反问能否说得通。

提示：读出回答的语气，再判断是谁的主张。
解析：小儿没有询问拜的步骤，而是在用偷酒的性质解释自己的举动。
