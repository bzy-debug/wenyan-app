# 课文：一问两答：礼与偷饮 {#l3.3}

简介：兄弟俩一人先拜再喝，一人喝了不拜。父亲挨个儿问起来，两人竟都拿“礼”作答。

## 正文

钟氏兄弟偷喝的是同一份药酒，父亲问他们的却是两个问题：问钟毓为什么拜，问钟会为什么不拜。读他们的回答时，看清各人说的“礼”落在哪里。一个谈喝酒时该怎样做，一个从酒是偷来的说起。

再读孔家的兄弟。父亲也在睡，问答里也有“何以不拜”。可是谁开口问、谁喝了酒，要在这一段重新找，不能把钟家的事直接搬过来。

## 知识点：复问 {#skill.l3.3.1}
义项：连续发问时，辨清每一次问的是谁
领域：篇章
要诀：把每一个“问”后面的人名读出来。
讲解：父亲先问毓，毓自己答；“又问会”，接着回答的才是会。在一段对话里，提问的人可以没变，回答的人却已经换了。
例句：p.l3.3.a

## 知识点：礼 {#skill.l3.3.2}
义项：分清人物说的是做事时的礼节，还是这件事本身合不合礼
领域：文化背景
要诀：听清他解释的是怎样喝酒，还是酒怎样得来。
讲解：钟毓觉得饮酒时该行礼。钟会却从“偷”说起，觉得偷酒这件事本来就不合礼。
例句：p.l3.3.a

## 原文：古籍引文 {#p.l3.3.a}
> 钟毓兄弟小时，值父昼寝，因共偷服药酒。其父时觉，且托寐以观之。毓拜而后饮，会饮而不拜。既而问毓何以拜，毓曰：“酒以成礼，不敢不拜。”又问会何以不拜，会曰：“偷本非礼，所以不拜。”
译文：钟毓兄弟儿时，趁父亲午睡，一起偷喝药酒。父亲当时已醒，暂且装睡观察。钟毓先行礼后喝，钟会喝了却没有行礼。父亲先问钟毓为什么拜。钟毓说：“酒是用来行礼的，我不敢不拜。”又问钟会为什么没拜，钟会答：“偷原本就不合礼，所以没有拜。”

## 找原文证据：哪几个字写出父亲醒了以后怎样看清了两个孩子的举动？ {#q.l3.3.1}
考点：skill.l3.3.1
语境：p.l3.3.a

- [ ] 值父昼寝
  理由：这是兄弟最初见到的情形。
- [ ] 因共偷服药酒
  理由：这是孩子的行为。
- [x] 且托寐以观之

提示：父亲醒后做了什么？
解析：“托寐”是假装睡着。父亲一旁看着，才知道哪个孩子拜了、哪个没拜，后来也就能分别发问。

## 单选：钟毓为什么要先拜再喝？ {#q.l3.3.2}
考点：skill.l3.3.2
语境：p.l3.3.a

- [ ] 行过礼就等于得到父亲许可
  理由：钟毓没有说父亲许可。
- [x] 酒用于成礼，所以即使在偷饮时他也行了礼
- [ ] 偷饮原本不合礼，所以不能拜
  理由：这是钟会的解释。

提示：“酒以成礼”是谁说的？
解析：钟毓拿饮酒的礼节解释自己为什么拜。至于偷酒有没有人准许，他一句也没说。

## 单选：读到“又问会”，谁问谁了？ {#q.l3.3.3}
考点：skill.l3.3.1
语境：p.l3.3.a

- [x] 同一发问者转向另一个孩子
- [ ] 钟会接过父亲的问题去问兄长
  理由：“会”在“问”后，是被问者。
- [ ] 父亲转而询问另一件偷酒往事
  理由：仍在解释刚观察的同一场景。

提示：比较两次“问”后面紧跟的名字。
解析：开口的还是父亲。先问钟毓为什么拜，再转过来问钟会为什么没拜。

## 单选：从两兄弟亲口说的话，能知道什么？ {#q.l3.3.4}
考点：skill.l3.3.2
语境：p.l3.3.a

- [x] 他们分别从饮酒仪节和偷取行为解释拜与不拜
- [ ] 钟会不知道喝酒时可以行礼
  理由：他给的是“不拜”的理由，没有说不知礼。
- [ ] 父亲认可二人偷饮的行为
  理由：没有父亲最后的裁定。

提示：听完二人的解释，原文有没有写父亲怎么想？
解析：哥哥说的是饮酒的礼节，弟弟说的是偷酒这件事。两个人都在解释自己的做法，父亲赞不赞成，文中没有交代。

## 原文：古籍引文 {#p.l3.3.b}
> 孔文举有二子，大者六岁，小者五岁。昼日父眠，小者床头盗酒饮之。大儿谓曰：“何以不拜？”答曰：“偷那得行礼！”
译文：孔文举有两个儿子，大的六岁，小的五岁。白天父亲睡着，小儿在床边偷酒喝。大儿问他为什么不行礼，小儿答：“偷东西哪里还谈得上行礼！”

## 单选：谁问“何以不拜”，又是谁回答？ {#q.l3.3.5}
考点：skill.l3.3.1
语境：p.l3.3.b

- [x] 哥哥问，偷酒的小儿回答
- [ ] 小儿问，哥哥答
  理由：“大儿谓曰”领起问句。
- [ ] 父亲问，两个儿子一起答
  理由：父亲在睡，问者明写“大儿”。

提示：看“谓曰”前面是谁，床边拿酒的又是谁。
解析：大儿问的是正在床边偷酒的小儿。后面只写“答曰”，回答的就是刚被哥哥问到的小儿。

## 找原文证据：小儿用哪几个字解释偷酒时为何没有行礼？ {#q.l3.3.6}
考点：skill.l3.3.2
语境：p.l3.3.b

- [ ] 何以不拜
  理由：这是问题，还未提出判断。
- [ ] 小者床头盗酒饮之
  理由：这是叙述行为，还没有口头解释。
- [x] 偷那得行礼

提示：看答句如何回应哥哥。
解析：“那得”就是“哪里能”。小儿反问哥哥：既然是在偷酒，哪里还谈得上行礼？

## 单选：钟家和孔家各有兄弟二人。两个故事分别写了谁喝酒？ {#q.l3.3.7}
考点：skill.l3.3.1
语境：p.l3.3.b

- [ ] 两家都只有小儿喝
  理由：钟氏段明言“共偷服”。
- [ ] 两家兄弟都喝
  理由：孔氏段只写大儿提问。
- [x] 钟氏二人都喝，孔氏只写小儿喝

提示：钟家写“共偷服”，孔家写谁在床头饮酒？
解析：钟家的兄弟“共偷服”，两人都喝。孔家明说“小者……饮之”，哥哥在下一句出现，做的是发问。

## 单选：小儿这句“偷那得行礼”是什么语气？ {#q.l3.3.8}
考点：skill.l3.3.2
语境：p.l3.3.b

- [ ] 叙述者颁布礼仪规则
  理由：说话的是小儿，他在回答哥哥的问题。
- [x] 小儿用反问说明不拜的理由
- [ ] 小儿请教怎样完成拜礼
  理由：“那得”在这里反问能否说得通。

提示：“那得”是认真问哥哥，还是说“哪里能呢”？
解析：哥哥问的是“为什么没拜”，小儿便反问“偷东西哪里还谈得上行礼”。这就是他给自己的解释。
