# 检查：辨清人物和说话人综合检查 {#check.9}

## 原文：教学例句 {#p.story.check.9.a}
> 驿吏见客负病童，问曰：“子自何来？”客曰：“自南村来。其父使我求医。”吏指东舍曰：“医在彼。”客趋而往。
译文：驿吏见客人背着病童，问从哪里来。客人说孩子的父亲托他从南村来求医。驿吏指出医生的住处，客人赶了过去。
词注：负：背在背上，此处是背着患病的孩子。
  趋：快步走，客人得到指点便赶往东舍。

## 单选：客人说的“其父”是谁的父亲？ {#q.story.check.9.1}
考点：skill.story.l3.1.1
语境：p.story.check.9.a

- [ ] 驿吏的父亲
  理由：驿吏刚在路上见到他们。
- [x] 病童的父亲
  理由：客人正背着病童，受托来找医生。
- [ ] 医生的父亲
  理由：此时还在寻找医生。

提示：谁病了，需要人求医？
解析：客人正背着病童，受托来找医生。

## 单选：“趋而往”的人是谁？ {#q.story.check.9.2}
考点：skill.story.l3.1.2
语境：p.story.check.9.a

- [x] 背孩子的客人
  理由：“趋”是快步走，求医的客人循着指引前去。
- [ ] 东舍的医生
  理由：医生是大家要去找的人。
- [ ] 指路的驿吏
  理由：驿吏指明方向，由求医者赶去。

提示：谁刚刚得到了自己需要的方向？
解析：“趋”是快步走，求医的客人循着指引前去。

## 找原文证据：哪一处表明客人亲自听到了医生的住处？ {#q.story.check.9.3}
考点：skill.story.l3.2.1
语境：p.story.check.9.a

- [ ] 其父使我求医
  理由：这是托付事情。
- [ ] 自南村来
  理由：这是客人自述来处。
- [x] 吏指东舍曰
  理由：驿吏一边指一边说，客人直接得到了消息。

提示：找到给眼前人指路的动作。
解析：驿吏一边指一边说，客人直接得到了消息。

## 原文：教学例句 {#p.story.check.9.b}
> 竹桥新成，村长使人告邻村。使者归曰：“有翁在桥头，似欲渡而未行。”既问之，翁曰：“吾待孙耳，岂畏桥哉！”言毕，孙至，携之而渡。
译文：竹桥建成，村长派人通知邻村。来人回报，一个老人在桥头像要渡桥却没走。问过才知他是在等孙子。孙子来了，他牵着孙子过桥。
词注：既：已经；“既问之”是说问过老人以后。
  渡：过河，此处是走过竹桥。

## 找原文证据：指出使者拿不准的那一部分。 {#q.story.check.9.4}
考点：skill.story.l3.2.2
语境：p.story.check.9.b

- [x] 似欲渡
  理由：“似”表明想过桥是旁人的猜想。
- [ ] 在桥头
  理由：所在的位置是使者看见的。
- [ ] 使者归曰
  理由：这是叙述者交代的回报。

提示：哪一个词有“好像”之意？
解析：“似”表明想过桥是旁人的猜想。

## 单选：孙子来之前，老人做了什么？ {#q.story.check.9.5}
考点：skill.story.l3.3.1
语境：p.story.check.9.b

- [ ] 已经牵孙过去
  理由：孙子是“言毕”之后才来。
- [x] 站在桥头等人
  理由：“吾待孙耳”说明一直在等孙子。
- [ ] 试着走上新桥又折回
  理由：原文没有写试桥。

提示：读他对问话的解释。
解析：“吾待孙耳”说明一直在等孙子。

## 单选：老人说“岂畏桥哉”是在说什么？ {#q.story.check.9.6}
考点：skill.story.l3.3.2
语境：p.story.check.9.b

- [ ] 不知道新桥牢不牢
  理由：下句写他等到孙子便渡桥。
- [ ] 想问孙子怕不怕桥
  理由：“吾”承接的是老人自己。
- [x] 自己并不怕桥
  理由：“岂……哉”在这里以反问否定怕桥的猜想。

提示：把老人后来过桥的举动接上。
解析：“岂……哉”在这里以反问否定怕桥的猜想。
