# 检查：认出故事里的每个人 {#check.9}

## 原文：古籍引文 {#p.check.9.a}
> 谢太傅寒雪日内集，与儿女讲论文义。俄而雪骤，公欣然曰：“白雪纷纷何所似？”兄子胡儿曰：“撒盐空中差可拟。”兄女曰：“未若柳絮因风起。”公大笑乐。即公大兄无奕女，左将军王凝之妻也。
译文：谢太傅在下雪天召集家人，和子侄辈谈论文义。忽然雪下大了，他问纷飞白雪像什么。侄儿胡儿说大致像向空中撒盐；侄女说不如比作柳絮随风飞起。谢太傅大笑，很高兴。这位侄女就是他长兄无奕的女儿、左将军王凝之的妻子。

## 单选：“兄女”是说谁的侄女？ {#q.check.9.1}
考点：skill.l3.1.1
语境：p.check.9.a

- [x] 以谢太傅为中心，是他兄长的女儿
- [ ] 以王凝之为中心，是他兄长的女儿
  理由：王凝之被介绍为丈夫。
- [ ] 以胡儿为中心，是胡儿兄长的女儿
  理由：“即公大兄无奕女”明确所从。

提示：末尾的“公大兄”是谁的长兄？
解析：“公”是谢太傅，“公大兄无奕女”就是他长兄无奕的女儿。前面说的“兄女”，正是这位侄女。

## 找原文证据：比雪的问答结束后，哪句话告诉我们说“柳絮”的是谁家女儿？ {#q.check.9.2}
考点：skill.l3.1.2
语境：p.check.9.a

- [ ] 与儿女讲论文义
  理由：“儿女”笼统地说家里的晚辈，没有点出作比的是谁。
- [ ] 公大笑乐
  理由：这是太傅的反应。
- [x] 即公大兄无奕女

提示：找叙述者事后的介绍。
解析：“即公大兄无奕女”接着前面的“兄女”说，这才知道她是谢太傅长兄无奕的女儿。

## 单选：两名晚辈各自怎样回答太傅？ {#q.check.9.3}
考点：skill.l3.3.1
语境：p.check.9.a

- [x] 胡儿说撒盐，兄女说柳絮
- [ ] 太傅先说柳絮，兄女表示同意
  理由：太傅提出的是问题。
- [ ] 兄女说撒盐，胡儿改为柳絮
  理由：把两个“曰”的主语互换了。

提示：每读到一个“曰”，先标名字。
解析：“兄子胡儿曰”后是撒盐，“兄女曰”后是柳絮。侄女说“未若”，是在和前一个比法相比。

## 原文：教学例句 {#p.check.9.b}
> 杜生与许生同席听琴。曲终，杜生记其节，许生问琴之价。又尝同观画，杜指其山势，许问绢几何直。师问许生何以待曲终乃言，许生曰：“听者不间其曲，礼也。”师曰：“二子所留意者异。”
译文：杜生与许生同坐听琴。曲终，杜记乐曲节奏，许问琴价。又一次看画，杜指画中的山势，许问画绢值多少钱。老师问许生，为什么等曲子奏完才开口。许生说，听者不打断乐曲，这是礼节。老师说两人留意的东西不同。

## 单选：为什么老师说两人留意的事情不同？ {#q.check.9.4}
考点：skill.l3.2.1
语境：p.check.9.b

- [ ] 杜问琴价，许指山势
  理由：这些行动的归属都倒了。
- [ ] 许只在听琴时关注价格
  理由：“绢几何直”仍是问价值。
- [x] 杜两次都注意作品，许两次都问价格

提示：把两人各自的两件事排在一起。
解析：听琴时杜生记节奏，许生问琴价；看画时杜生看山势，许生还在问价。这才有了老师后来的话。

## 单选：只看“同席听琴”，能知道什么？ {#q.check.9.5}
考点：skill.l3.2.2
语境：p.check.9.b

- [ ] 两人已宣布结交终身
  理由：同席场面没有这种约定。
- [x] 两人坐在一起听琴
- [ ] 二人关注点完全一样
  理由：后文正要展示关注不同。

提示：同席说的是两人的座位。知道座位，能知道他们在想什么吗？
解析：两人坐在一处，听的是同一支曲子。至于各自留心什么，要读到曲终后的事才知道。

## 单选：许生说“礼也”，是在解释哪一项行动？ {#q.check.9.6}
考点：skill.l3.3.2
语境：p.check.9.b

- [ ] 他只打听琴价
  理由：“待曲终乃言”问的是何时说，不是问什么。
- [x] 他等琴曲奏完才开口
- [ ] 他替杜生记下了节奏
  理由：记节的是杜生。

提示：老师问他为什么打听琴价，还是为什么等到曲终才开口？
解析：老师问“何以待曲终乃言”，问的是为什么等了这么久。许生说听琴时打断别人不合礼，解释的是开口的时机。
