# 检查：跟住人物综合检查 {#check.9}

## 原文：古籍引文 {#p.check.9.a}
> 谢太傅寒雪日内集，与儿女讲论文义。俄而雪骤，公欣然曰：“白雪纷纷何所似？”兄子胡儿曰：“撒盐空中差可拟。”兄女曰：“未若柳絮因风起。”公大笑乐。即公大兄无奕女，左将军王凝之妻也。
译文：谢太傅在寒冷的雪天办家庭聚会，和子侄辈谈论文义。忽然雪下大了，他问纷飞白雪像什么。侄儿胡儿说大致像向空中撒盐；侄女说不如比作柳絮随风飞起。谢太傅大笑，很高兴。这位侄女就是他长兄无奕的女儿、左将军王凝之的妻子。

## 单选：“兄女”中的“兄”以谁为亲属定位的中心？ {#q.check.9.1}
考点：skill.l3.1.1
语境：p.check.9.a

- [x] 以谢太傅为中心，是他兄长的女儿
- [ ] 以王凝之为中心，是他兄长的女儿
  理由：王凝之被介绍为丈夫。
- [ ] 以胡儿为中心，是胡儿兄长的女儿
  理由：“即公大兄无奕女”明确所从。

提示：把结尾的“公大兄”接到前面的简称。
解析：兄女是谢太傅的侄女；结尾换一种亲属关系又介绍了同一人。

## 找原文证据：哪一部分在问答结束后补出说柳絮者的身份？ {#q.check.9.2}
考点：skill.l3.1.2
语境：p.check.9.a

- [ ] 与儿女讲论文义
  理由：这只交代聚会对象。
- [ ] 公大笑乐
  理由：这是太傅的反应。
- [x] 即公大兄无奕女

提示：找叙述者事后的介绍。
解析：“即……也”的补叙让“兄女”有了更具体的家族位置。

## 单选：两名晚辈各自怎样回答太傅？ {#q.check.9.3}
考点：skill.l3.3.1
语境：p.check.9.a

- [x] 胡儿说撒盐，兄女说柳絮
- [ ] 太傅先说柳絮，兄女表示同意
  理由：太傅提出的是问题。
- [ ] 兄女说撒盐，胡儿改为柳絮
  理由：把两个“曰”的主语互换了。

提示：每读到一个“曰”，先标名字。
解析：两个回答各有独立主语；“未若”引出兄女对前一个比法的比较。

## 原文：教学例句 {#p.check.9.b}
> 杜生与许生同席听琴。曲终，杜生记其节，许生问琴之价。又尝同观画，杜指其山势，许问绢几何直。师问许生何以待曲终乃言，许生曰：“听者不间其曲，礼也。”师曰：“二子所留意者异。”
译文：杜生与许生同坐听琴。曲终，杜记乐曲节奏，许问琴价。又一次看画，杜指画中的山势，许问画绢值多少钱。老师问许生，为什么等曲子奏完才开口。许生说，听者不打断乐曲，这是礼节。老师说两人留意的东西不同。

## 单选：听琴与看画两件事怎样合起来支持老师的评价？ {#q.check.9.4}
考点：skill.l3.2.1
语境：p.check.9.b

- [ ] 杜问琴价，许指山势
  理由：这些行动的归属都倒了。
- [ ] 许只在听琴时关注价格
  理由：“绢几何直”仍是问价值。
- [x] 杜两次都注意作品，许两次都问价格

提示：把两人各自的两件事排在一起。
解析：“又尝”把第二事作为旁证，而不是只讲一次偶然问价。

## 单选：这里的“同席”能直接证明什么？ {#q.check.9.5}
考点：skill.l3.2.2
语境：p.check.9.b

- [ ] 两人已宣布结交终身
  理由：同席场面没有这种约定。
- [x] 两人坐在一起听琴
- [ ] 二人关注点完全一样
  理由：后文正要展示关注不同。

提示：先读座位的字面事实，再读老师怎样评价。
解析：位置相同给两人提供相同的听琴机会，不代表其判断相同。

## 单选：许生说“礼也”，是在解释哪一项行动？ {#q.check.9.6}
考点：skill.l3.3.2
语境：p.check.9.b

- [ ] 他只打听琴价
  理由：“待曲终乃言”问的是何时说，不是问什么。
- [x] 他等琴曲奏完才开口
- [ ] 他替杜生记下了节奏
  理由：记节的是杜生。

提示：把许生的解释接回老师问话里的动词。
解析：许生援引听乐不打断的礼节解释发问时间；这项礼节本身不能证明问价比观画更合礼。
