# 课文：回到同一个人：顾荣的一席烤肉 {#l3.1}

简介：同一个人先端肉、后受肉，后来又在危急时出现。怎样把这些称呼接回去？

## 正文

先记下席间的分工。**行炙人**是分送烤肉的人，“行”看的是他在席间所做的事。**受炙人**侧重同一个人从顾荣手中得到过什么。两者若被画成两个人，渡江一段便失去着落。

读到“有一人”先留空。文中先让读者看见此人的行动，再用“乃……也”揭示身份。做第二段练习时，也先遮住最后一句，分开记“现在知道什么”和“读到最后才能知道什么”。

## 知识点：受炙人 {#skill.l3.1.1}
义项：用先前的受事身份辨认后来的人
领域：篇章
要诀：对照两次称呼所含的动作
讲解：古文可用一个人以前做过或经历过的事来称呼他。把第二处称呼还原为“此前谁受过什么”，与前段相接。
例句：p.l3.1.a

## 知识点：乃……也 {#skill.l3.1.2}
义项：凭揭示句回填前文的未知身份
领域：句法
要诀：找到揭晓之前的空位
讲解：“乃”有多种用法。问明来历后用“乃……也”点出身份，此处可读作“原来是……”。
例句：p.l3.1.a

## 原文：古籍引文 {#p.l3.1.a}
> 顾荣在洛阳，尝应人请。觉行炙人有欲炙之色，因辍己施焉。同坐嗤之，荣曰：“岂有终日执之而不知其味者乎？”后遭乱渡江，每经危急，常有一人左右己。问其所以，乃受炙人也。
译文：顾荣在洛阳曾赴宴。他发现分送烤肉的人流露出想吃的神色，便把自己那份让给他。同席者笑他。顾荣说，哪有整天拿着烤肉却不知道滋味的道理？后来遇乱渡江，每逢危急，总有一个人在旁相助。问起缘故，才知道此人就是当年受肉的人。

## 单选：“行炙人”和“受炙人”是什么关系？ {#q.l3.1.1}
考点：skill.l3.1.1
语境：p.l3.1.a

- [x] 同一人，先给席间分肉，又收到顾荣的肉
- [ ] 两位宾客，相互让出自己的席位
  理由：“行炙”交代的是传送烤肉。
- [ ] 两名侍者，一人传菜一人护送
  理由：结尾用旧事揭示那位帮助者的身份。

提示：把两处称呼各改写成一个动作。
解析：分肉是那人的职事，受肉是他与顾荣之间发生的事。后一称呼让前后两段接起来。

## 找原文证据：哪几个字首次引入渡江时尚未说出身份的帮手？ {#q.l3.1.2}
考点：skill.l3.1.2
语境：p.l3.1.a

- [x] 常有一人
- [ ] 同坐嗤之
  理由：“同坐”仍是宴上众人。
- [ ] 乃受炙人也
  理由：此处已经揭晓身份。

提示：先找“后来”的场景，再找泛称。
解析：先用“一人”保留悬念，直到问明缘故才出现“受炙人”。

## 单选：顾荣说“终日执之”，执的是什么？ {#q.l3.1.3}
考点：skill.l3.1.1
语境：p.l3.1.a

- [ ] 渡江用的船桨
  理由：这句话发生在渡江前的宴席上。
- [ ] 顾荣的手
  理由：“不知其味”要说的是食物。
- [x] 在宴席上分送的烤肉

提示：看“其味”能落在哪个对象上。
解析：执肉者长时间经手食物却未必有机会品尝，顾荣用这一点回应席间的讥笑。

## 排序：按读者得到信息的顺序排列。 {#q.l3.1.4}
考点：skill.l3.1.2
语境：p.l3.1.a

- [3] 得知相助者与旧事的关联
  理由：问过之后才揭晓身份。
- [2] 知道顾荣渡江时有人相助
  理由：此时只称“一人”。
- [1] 看见一个人想吃烤肉
  理由：“有欲炙之色”在宴席一段。

提示：区分人物相识的时间与读者获知身份的时间。
解析：先写席间施肉，后写渡江遇助，最后才把两段人物合为一人。

## 原文：教学例句 {#p.l3.1.b}
> 里人负薪，遇雨，借宿于陶者。陶者分其粟。明年窑坏，有人载木而来，助为屋。陶者不识，问之，乃昔日负薪者也。
译文：乡人背柴遇雨，在制陶人家借宿。制陶人分给他粮食。第二年窑坏了，有人运木来帮忙搭屋。制陶人没认出来，问过才知就是往日的背柴人。

## 单选：来人可以用哪件往事辨认？ {#q.l3.1.5}
考点：skill.l3.1.1
语境：p.l3.1.b

- [ ] 他曾把粟分给陶者
  理由：分粟的是陶者。
- [ ] 他曾造窑，见过窑坏
  理由：造窑是推测，文中没说。
- [x] 他曾背柴遇雨，在陶者处借宿

提示：找一个只属于来客的旧动作。
解析：起初说“里人负薪”，结尾说“昔日负薪者”，两处用同一动作指人。

## 找原文证据：从哪句才可确定来人的身份？ {#q.l3.1.6}
考点：skill.l3.1.2
语境：p.l3.1.b

- [x] 乃昔日负薪者也
- [ ] 明年窑坏
  理由：这是次年的事由。
- [ ] 有人载木而来
  理由：此处还只有泛称。

提示：留意首次照应昔日动作的句子。
解析：载木表明他带来了什么；“昔日负薪者”才把他与借宿人相连。

## 单选：“问之”里，发问者和被问者分别是谁？ {#q.l3.1.7}
考点：skill.l3.1.1
语境：p.l3.1.b

- [x] 陶者问运木来的人
- [ ] 陶者问邻居来人是谁
  理由：邻居没有在场。
- [ ] 负薪人问陶者是否有粮
  理由：前文已转入第二年。

提示：把“不识”和“问”的主语连起来。
解析：“陶者不识”表明认不出来的是主人，他接着询问眼前的来客。

## 单选：删去末句之后，读者还能确定什么？ {#q.l3.1.8}
考点：skill.l3.1.2
语境：p.l3.1.b

- [ ] 来者正是昔日受粟人
  理由：这是末句才证实的。
- [x] 有人在窑坏后运木来帮忙
- [ ] 陶者问清了来人姓名
  理由：全文也没有写姓名。

提示：区分可见行动与事后辨认。
解析：人物的行为一开始就可见，身份须有最后的揭示句才能确定。
