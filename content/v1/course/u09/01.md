# 课文：顾荣渡江时，是谁帮了他 {#l3.1}

简介：席间有人想吃烤肉，渡江时又有人扶助顾荣。要读到哪一句，才知道说的是不是同一个人？

## 正文

在宴席上，**行炙人**是给客人分送烤肉的那个人。顾荣把自己那一份让给了他。后来再称他为**受炙人**，用的是他从顾荣手里接过烤肉这件事。

读到渡江时“常有一人左右己”，先别急着给这个人添名字。故事让我们先看到他在危急时相助，等顾荣一问，才用“乃……也”道出他的来历。读下面陶工的故事，也可以停在主人发问的地方，想想这时陶工已经知道什么，又还没认出谁。

## 知识点：受炙人 {#skill.l3.1.1}
义项：凭他先前受过的帮助认出此人
领域：篇章
要诀：看称呼里说的是他当年做的哪件事。
讲解：同一个人，因为分烤肉叫“行炙人”，因为曾收下顾荣的烤肉又叫“受炙人”。名字没有写出来，两处的事却能接上。
例句：p.l3.1.a

## 知识点：乃……也 {#skill.l3.1.2}
义项：读到“原来是……”才知道先前写的是谁
领域：句法
要诀：找出是到哪一句才知道他是谁。
讲解：“乃……也”接在问明来历之后，这里的“乃”读作“原来”。回头再看先前的“一人”，就知道说的是谁了。
例句：p.l3.1.a

## 原文：古籍引文 {#p.l3.1.a}
> 顾荣在洛阳，尝应人请。觉行炙人有欲炙之色，因辍己施焉。同坐嗤之，荣曰：“岂有终日执之而不知其味者乎？”后遭乱渡江，每经危急，常有一人左右己。问其所以，乃受炙人也。
译文：顾荣在洛阳曾赴宴。他发现分送烤肉的人流露出想吃的神色，便把自己那份让给他。同席者笑他。顾荣说：“哪有整天拿着烤肉，却连味道都不知道的人呢？”后来遇乱渡江，每逢危急，总有一个人在旁相助。问起缘故，才知道此人就是当年受肉的人。

## 单选：“行炙人”和“受炙人”是什么关系？ {#q.l3.1.1}
考点：skill.l3.1.1
语境：p.l3.1.a

- [x] 同一人，先给席间分肉，又收到顾荣的肉
- [ ] 两位宾客，相互让出自己的席位
  理由：“行炙”交代的是传送烤肉。
- [ ] 两名侍者，一人传菜一人护送
  理由：帮顾荣渡过险境的，结尾明说就是当年的“受炙人”。

提示：把两处称呼各改写成一个动作。
解析：他在席上给客人分肉，后来又收到顾荣自己那份。等顾荣问起江上的帮手，才知道正是这个受过肉的人。

## 找原文证据：刚写到渡江时，哪几个字只说有人来帮忙，还没说这人是谁？ {#q.l3.1.2}
考点：skill.l3.1.2
语境：p.l3.1.a

- [x] 常有一人
- [ ] 同坐嗤之
  理由：“同坐”仍是宴上众人。
- [ ] 乃受炙人也
  理由：此处已经揭晓身份。

提示：宴席过后，故事用哪几个字头一次提到帮手？
解析：先是“常有一人”，只见其人相助。等顾荣问了缘故，作者才写“乃受炙人也”。

## 单选：顾荣说“终日执之”，执的是什么？ {#q.l3.1.3}
考点：skill.l3.1.1
语境：p.l3.1.a

- [ ] 渡江用的船桨
  理由：这句话发生在渡江前的宴席上。
- [ ] 顾荣的手
  理由：“不知其味”要说的是食物。
- [x] 在宴席上分送的烤肉

提示：“不知其味”里的“味”，是什么味道？
解析：分肉人整天拿着烤肉，却未必尝过。顾荣问这一句，是在回答同席人为什么要把肉让给他。

## 排序：照故事告诉我们的先后，排一排这三件事。 {#q.l3.1.4}
考点：skill.l3.1.2
语境：p.l3.1.a

- [3] 得知相助者与旧事的关联
  理由：问过之后才揭晓身份。
- [2] 知道顾荣渡江时有人相助
  理由：此时只称“一人”。
- [1] 看见一个人想吃烤肉
  理由：“有欲炙之色”在宴席一段。

提示：顾荣是在谁来帮忙之前还是之后，才问清对方来历的？
解析：先写宴上的烤肉，再写渡江时有人帮忙。读到末句，才知道帮手跟旧日宴席的关系。

## 原文：教学例句 {#p.l3.1.b}
> 里人负薪，遇雨，借宿于陶者。陶者分其粟。明年窑坏，有人载木而来，助为屋。陶者不识，问之，乃昔日负薪者也。
译文：乡人背柴遇雨，在制陶人家借宿。制陶人分给他粮食。第二年窑坏了，有人运木来帮忙搭屋。制陶人没认出来，问过才知就是往日的背柴人。

## 单选：陶工是凭哪件往事认出送木头的人？ {#q.l3.1.5}
考点：skill.l3.1.1
语境：p.l3.1.b

- [ ] 他曾把粟分给陶者
  理由：分粟的是陶者。
- [ ] 他曾造窑，见过窑坏
  理由：造窑是推测，文中没说。
- [x] 他曾背柴遇雨，在陶者处借宿

提示：来人眼下运木，故事开头他背着什么？
解析：开头的乡人“负薪”，结尾还是“昔日负薪者”。这根线把现在送木头的人和往日借宿的客人连起来了。

## 找原文证据：从哪句才可确定来人的身份？ {#q.l3.1.6}
考点：skill.l3.1.2
语境：p.l3.1.b

- [x] 乃昔日负薪者也
- [ ] 明年窑坏
  理由：这是次年的事由。
- [ ] 有人载木而来
  理由：这时只写“有人”送木头，陶工还没认出他来。

提示：刚写“有人载木而来”时，陶工认出他了吗？
解析：“载木”只能看出他带了木头。直到称他“昔日负薪者”，才知道来的是那位背柴借宿的人。

## 单选：“问之”里，发问者和被问者分别是谁？ {#q.l3.1.7}
考点：skill.l3.1.1
语境：p.l3.1.b

- [x] 陶者问运木来的人
- [ ] 陶者问邻居来人是谁
  理由：故事没有写陶工向邻居打听。
- [ ] 负薪人问陶者是否有粮
  理由：前文已转入第二年。

提示：把“不识”和“问”的主语连起来。
解析：没认出来的是陶工，所以开口问的也是陶工。他面前就是赶来送木头的人。

## 单选：如果故事停在“陶者不识，问之”，还能知道哪件事？ {#q.l3.1.8}
考点：skill.l3.1.2
语境：p.l3.1.b

- [ ] 来者正是昔日受粟人
  理由：这是末句才证实的。
- [x] 有人在窑坏后运木来帮忙
- [ ] 陶者问清了来人姓名
  理由：全文也没有写姓名。

提示：有人做了什么？他的来历这时说出来了吗？
解析：能看见的，是有人在窑坏以后运木来帮忙。这个人从前在这里借过宿，要读到下一句才知道。
