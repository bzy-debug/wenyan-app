# 课文：谁让谁离开 {#l3.1}

简介：荀巨伯去看望病友，却遇上攻城。两个人都说了“子”，指的是同一个人吗？

## 正文

“友人语巨伯曰”中，“语”读 yù，告诉。“语巨伯”只说消息是告诉谁的，后面的引语才是所说的内容。说话的是病人，下面的“吾”便是病人自己，“子”是来探望的巨伯。到了“巨伯曰”，把两人的位置对调，后面的“子令吾去”就读通了。

读到“不忍委之”，还得回到两个人相处的地方。“委”是丢下，能留下照顾病人的正是客人。“之”指病友。要是碰上几个没写姓名的动作，先试着把姓名补进去，看谁能做这件事。

## 知识点：换人说话 {#skill.story.l3.1.1}
义项：吾、子随说话人换指
领域：篇章
要诀：遇到新的“曰”，重新认一遍我和你。
讲解：朋友说“子可去”是在劝巨伯。巨伯回话时，“子”便是刚才劝他的人。
例句：p.story.l3.1.a

## 知识点：补出动作的人 {#skill.story.l3.1.2}
义项：从动作和问答衔接恢复主语
领域：句法
要诀：先问是谁能做这个动作，再读下一句。
讲解：病友要巨伯走，后文“不忍委之”的人便是刚受劝的巨伯。
例句：p.story.l3.1.a

## 知识点：语（yù），告诉某人 {#lex.s.tell-yu}
义项：从“语”所带的人推知谁受告，再寻找告诉他的内容
领域：实词
要诀：“语”后接一个人，再有一句话，这个人通常是听的一方。
讲解：“友人语巨伯曰”中的巨伯是受告者。若写“闻其语”，可闻的是一番话，那里的“语”便是名词。
例句：p.story.l3.1.a

## 原文：古籍引文 {#p.story.l3.1.a}
> 荀巨伯远看友人疾，值胡贼攻郡。友人语巨伯曰：“吾今死矣，子可去。”巨伯曰：“远来相视，子令吾去，败义以求生，岂荀巨伯所行邪！”贼既至，谓巨伯曰：“大军至，一郡尽空，汝何男子，而敢独止？”巨伯曰：“友人有疾，不忍委之，宁以我身代友人命。”
译文：荀巨伯从远处来探病，碰上郡城被攻。病友以为自己要死，劝他快走。巨伯说，远道来探望，怎能为活命丢了情义？来兵问他众人都走了为何独留，他说不忍丢下病友，宁可替他死。
词注：值：正碰上，此处接攻郡这件意外事。
  语：读 yù，告诉别人；这里是病友对巨伯说。
  委：丢下不顾，“委之”指丢下患病的朋友。
  止：停留；“独止”指别人已走而他仍留在城中。

## 单选：“子令吾去”是谁对谁说的？ {#q.story.l3.1.1}
考点：skill.story.l3.1.1
语境：p.story.l3.1.a

- [x] 荀巨伯对病友
  理由：巨伯接过病友的话：“您叫我离开。”
- [ ] 来兵对荀巨伯
  理由：来兵要到“贼既至”才开口。
- [ ] 病友对荀巨伯
  理由：“巨伯曰”已经换了说话人。

提示：回看这句话前面谁“曰”。
解析：巨伯接过病友的话：“您叫我离开。”

## 单选：若在“语巨伯”旁写“巨伯说了一番话”，人物关系哪里颠倒了？ {#q.story.l3.1.tell}
考点：lex.s.tell-yu
语境：p.story.l3.1.a

- [x] 是病友告诉巨伯；“子可去”是让巨伯走
- [ ] 是巨伯把病友的病情告诉来兵
  理由：来兵在“贼既至”以后才与巨伯交谈。
- [ ] “语”是巨伯说的话，病友从旁听见
  理由：“友人”先开口；巨伯说的话另由“巨伯曰”领起。

提示：读到第一个“曰”先停下，分清谁在“语”，谁紧接在“语”后。
解析：“友人语巨伯”是朋友告诉巨伯，并没有说巨伯此时已经开口；后面的“子可去”才是病友告诉他的事。

## 单选：是谁“不忍委之”？ {#q.story.l3.1.3}
考点：skill.story.l3.1.2
语境：p.story.l3.1.a

- [ ] 来兵不忍丢下巨伯
  理由：“巨伯曰”之后是巨伯自己说明心意。
- [ ] 病友不忍丢下大军
  理由：病友要巨伯先走，没提大军的去留。
- [x] 荀巨伯不忍丢下病友
  理由：能走却留下的是巨伯，“之”指患病的朋友。

提示：谁先解释“友人有疾”？
解析：能走却留下的是巨伯，“之”指患病的朋友。

## 原文：教学例句 {#p.story.l3.1.b}
> 舟人见童子独立岸上，问曰：“汝何待？”答曰：“吾兄未至。”少顷，兄至，语舟人曰：“弟畏水，愿君携之。”舟人执其手而登。
译文：船夫见一个孩子独站岸边，问他等谁。孩子说在等哥哥。不久哥哥来了，请船夫带怕水的弟弟上船。船夫牵着孩子登船。
词注：舟人：操舟的人，指船夫。
  少顷：过了一小会儿。
  携：牵着、带着，哥哥托船夫带弟弟上船。

## 单选：“愿君携之”里，“君”指谁？ {#q.story.l3.1.5}
考点：skill.story.l3.1.1
语境：p.story.l3.1.b

- [x] 船夫
  理由：哥哥同船夫说话，请对方带上弟弟。
- [ ] 弟弟
  理由：“之”才指要受照料的弟弟。
- [ ] 哥哥
  理由：哥哥在开口求人，自称时不会用这里的“君”。

提示：哥哥在向谁说明弟弟怕水？
解析：哥哥同船夫说话，请对方带上弟弟。

## 找原文证据：哥哥把弟弟怕水的事告诉了一个人。在哪里能读到“告诉谁”？ {#q.story.l3.1.boat-tell}
考点：lex.s.tell-yu
语境：p.story.l3.1.b

- [ ] 汝何待
  理由：这是船夫问孩子的话，哥哥还没到。
- [ ] 弟畏水
  理由：这几个字是告诉对方的内容。
- [x] 语舟人

解析：“语舟人”标出受告的是船夫；哥哥在引语里说明怕水的是弟弟，请他照看。
