# 课文：“再而衰”，第二次做了什么 {#g27.1}
简介：一句话只写一次的动作或对象，到后面有时还管用。找回它，才好判断哪些事重复、哪些结果变了。

## 正文

“甲负米，乙粟”若出现在两人运粮的记载里，读者可把前一个“负”借给乙：甲背米，乙背粟。重复的是背，所背的东西却换了。

再看“客得书，展而读”。“展”后没有写手中之物，并不表示客人忽然去展开别的东西。书仍在手里，展开、阅读都可以接它。若下文另交代新物，便要从那一处重新分辨。

## 知识点：由对举补回谓语 {#g27.skill.echo}
义项：并列句后半沿用前半已有的动作
领域：句法
要诀：两个分句各写了谁，差了哪一个相同动作？
讲解：“甲宿东舍，乙西舍”写住宿分配。乙与甲相对，西舍与东舍相对，宿便可沿用。
例句：g27.ex.echo

## 原文：教学例句 {#g27.ex.echo}
> 东舟载米，西舟盐。
译文：东船载米，西船载盐。

## 知识点：连续动作省去已知宾语 {#g27.skill.object}
义项：从前句找回拿、读、交等动作所涉及的对象
领域：句法
要诀：谁手里有什么？下一动作能否还作用在它上面？
讲解：“童拾简，持以告师”要留住已拾到的简，不能见到动词连写就凭空添物。
例句：g27.ex.object

## 原文：教学例句 {#g27.ex.object}
> 吏得牍，启而读。
译文：官吏得了文书，打开来读。

## 原文：古籍引文 {#g27.1.p.drum}
> 一鼓作气，再而衰，三而竭。
译文：第一次击鼓使士气振作，第二次击鼓，士气衰退；第三次击鼓，士气就耗尽了。
出处：《左传·庄公十年》曹刿答鲁庄公节录
版本：Kanseki Repository，tls
底本链接：https://github.com/kanripo/KR1e0001/blob/dc3dc18e0039e05679d98bc650c2f980f8dcabac/KR1e0001_003.txt#L798-L800
作者：《左传》编者
原文权利：古籍公版正文节引，转为通行简体字并标点。
译注权利：项目自撰今译、讲解及练习。
词注：再：这里是第二次。
  竭：耗尽，此处说士气。

## 单选：读完“一鼓作气”，后面的“再”和“三”该接上哪一个相同动作？ {#g27.1.q1}
考点：g27.skill.echo
语境：g27.1.p.drum

- [x] 第二次、第三次击鼓
- [ ] 第二次、第三次作气，每次都同样振作
  理由：后面一层是“衰”，一层是“竭”。
- [ ] 两次衰、三次竭，鼓只敲一次
  理由：数字与第一处“一鼓”排成一列。

提示：先把一、再、三排成一行，哪个字最先紧跟在数目后？
解析：只在第一处写出鼓，后两处接过这项动作。鼓敲了三次，士气却不是三次都振作。

## 排序：按三次相同信号下士气的变化排列。 {#g27.1.q2}
考点：g27.skill.echo
语境：g27.1.p.drum

- [2] 其后衰退
  理由：“再”承接首次，以“衰”报变化。
- [3] 最后耗尽
  理由：“竭”在第三次出现。
- [1] 初次振作
  理由：“作气”属于“一鼓”。

提示：把三次击鼓和三种结果分作两列。
解析：沿用到后面的是“鼓”。从“作”到“衰”到“竭”的是气。

## 原文：教学例句 {#g27.1.p.ink}
> 生得友书，启而读，复缄置箧中。师问何以缄之，曰：“友有私言。”
译文：学生收到朋友的信，拆开阅读，又封好放进箱中。老师问他为什么封起来，学生说：“朋友写了些私话。”
词注：缄：封好。
  箧：装东西的箱子。

## 单选：“启而读，复缄”省去好几次物名，哪一种补法能一直读到最后？ {#g27.1.q3}
考点：g27.skill.object
语境：g27.1.p.ink

- [ ] 开箱、读箱、又封箱
  理由：箧到“置箧中”才用作放信的地方，读箱说不通。
- [ ] 打开老师的书、读朋友的诗、封杂物
  理由：原文只交代朋友的一封信，不曾换物。
- [x] 拆信、读信、又封信

提示：哪个物件既能被阅读，又含有不便公开的私话？
解析：“友书”从收信时一路承接，末句的私言解释了为何封存。

## 找原文证据：后文哪几个字能反过来说明被读到、又被封存的是朋友的来信？ {#g27.1.q4}
考点：g27.skill.object
语境：g27.1.p.ink

- [ ] 师问
  理由：老师开口询问，不是信的内容。
- [ ] 置箧中
  理由：箱中可放许多东西，单凭放置还不能定是书信。
- [x] 友有私言

提示：从学生为什么不让别人看去想。
解析：朋友的私话写在信上，因而需要保存着又封住。这是对前面几个动作对象的补证。

## 原文：教学例句 {#g27.1.p.sacks}
> 仓前分役。甲负米，乙豆。甲至厨，解囊倾入瓮；乙至厩，亦解囊，而豆散地。
译文：仓前分派活计。甲背米，乙背豆。甲到厨房，解开袋子，把米倒入瓮；乙到马厩，也解开袋子，豆却撒在地上。
词注：役：差事，这里指搬运的活计。
  厩：马棚。

## 单选：“乙豆”若只抄这两个字，漏了哪项必须从上句接来的事？ {#g27.1.q5}
考点：g27.skill.echo
语境：g27.1.p.sacks

- [ ] 乙也要背米，豆是他的名字
  理由：末句明确他的袋子里散出的是豆。
- [x] 乙也要背运，所背换成豆
- [ ] 两人都要把豆倒进同一个瓮
  理由：二人去处不同，甲运的是米。

提示：对上“甲”和“乙”，再对上“米”和“豆”。
解析：两人分担同类活计，“负”由前句沿用；分派给各人的粮食有别。

## 单选：“倾入瓮”未明写倒了什么，为什么可以补“米”，不能因结尾见“豆”就改成豆？ {#g27.1.q6}
考点：g27.skill.object
语境：g27.1.p.sacks

- [x] 这时在厨房解囊的是甲，豆还随乙去马厩
- [ ] “瓮”字本身只许装米
  理由：容器名无法决定其中放米还是豆。
- [ ] 原文说二人已在路上交换袋子
  理由：没有交换，末句乙的豆仍在自己袋中。

提示：从动作一路追踪甲的担子，不要从末句往回挑最近的物名。
解析：读者补的是甲的袋中物。后来另起“乙至厩”，才轮到承接豆。

## 原文：教学例句 {#g27.1.p.lamp}
> 匠收二器，铜盏纳匣，木盏囊中。暮客索木盏，匠取而授之。客捧归。
译文：工匠收拾两件器物，把铜盏装入匣，把木盏放在袋中。傍晚客人索要木盏，工匠取出来交给他。客人捧着回去了。

## 单选：实际找木盏时，为什么该到袋中去？ {#g27.1.q7}
考点：g27.skill.echo
语境：g27.1.p.lamp

- [x] “木盏囊中”沿用前面的收纳动作，给它分了另一处
- [ ] 傍晚客人已把木盏装入自己的袋子
  理由：他先索要，工匠才去取。
- [ ] “木盏”是木匣的名字，也在铜盏匣里
  理由：一开始已说是两件器物，并列了两处。

提示：给两个盏各配一处，两处共同做了什么？
解析：“铜盏纳匣，木盏囊中”在两项之间省下重复的“纳”。位置不同，动作相同。

## 单选：最后“客捧归”只写了手上的动作。凭什么知道捧回的是木盏？ {#g27.1.q8}
考点：g27.skill.object
语境：g27.1.p.lamp

- [ ] “归”前省去的是工匠，客人捧的是工匠
  理由：捧的动作承接所授的器物。
- [ ] 两盏最初由同一匠人收下，所以客一并带走
  理由：索取时只说木盏。
- [x] 客点名索木盏，匠取出来授他，持物的人这才换成客

提示：从“索、取、授、捧”给这一件东西换手。
解析：最初两器都可能拿。客说出木盏后，后面一串动作所及的对象便确定了。
