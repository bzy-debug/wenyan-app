# 检查：读出没写的成分，听懂留有余地的问话 {#check.27}

## 原文：古籍引文 {#check.27.p.brothers}
> 司马牛忧曰：“人皆有兄弟，我独亡。”子夏曰：“商闻之矣：‘死生有命，富贵在天。’君子敬而无失，与人恭而有礼。四海之内，皆兄弟也。君子何患乎无兄弟也？”
译文：司马牛忧愁地说：“别人都有兄弟，唯独我没有。”子夏说：“我听说过：‘死生有定命，富贵由天。’君子行事谨慎而不失当，对人恭敬有礼，天下的人都可视为兄弟。君子何必忧虑没有兄弟呢？”
出处：《论语·颜渊》司马牛忧无兄弟章

词注：亡：这里同“无”，没有；后面承接上句的“兄弟”。
  商：子夏的名，此处自称。
  患：担心、忧虑。

## 单选：若将“我独亡”译作“只有我逃亡了”，司马牛的哪组对照会被拆散？ {#check.27.q1}
考点：g27.skill.object
语境：check.27.p.brothers

- [x] 别人有兄弟，同自己没有兄弟的对照
- [ ] 别人失礼同自己守礼的对照
  理由：敬与礼是子夏的劝慰，并非司马牛自己的抱怨。
- [ ] 子夏富贵同司马牛贫穷的对照
  理由：富贵在子夏后来引用的话里出现，司马牛没与他比贫富。

提示：给“有”和“亡”分别补上一个对象，两处能否用同样的词？
解析：“兄弟”只在前半明写。后半的“亡”可接同一对象，“有”和“无”才正好相对。

## 找原文证据：子夏不是替他查家谱。哪句话最能说明末尾一问另有劝慰的根据？ {#check.27.q2}
考点：g27.skill.rhetorical
语境：check.27.p.brothers

- [ ] 商闻之矣
  理由：这只表明子夏要引述听来的话，还没提出待人的道理。
- [x] 四海之内，皆兄弟也
- [ ] 人皆有兄弟
  理由：这是司马牛发愁时的话，还没改变他对兄弟的看法。

提示：在子夏的答话里找“兄弟”范围发生变化的地方。
解析：司马牛先说自己的骨肉，子夏却从与人相处说到四海皆可作兄弟。有了这一层，问句才听得出安慰的意思。

## 单选：“何患乎无兄弟也”更接近子夏希望对方接受的哪句话？ {#check.27.q3}
考点：g27.skill.rhetorical
语境：check.27.p.brothers

- [ ] 你确有一位亲兄弟，现在已经找到
  理由：“四海之内”扩大了兄弟的说法，并未报告找回亲人。
- [ ] 请把你失散兄弟的姓名写下，我去寻访
  理由：子夏给的是待人之道，没有询问姓名去处。
- [x] 若能敬人有礼，不必只为没有亲兄弟而忧愁

提示：把最后一个问句同开头的“忧”连起来。
解析：子夏不再追问人数，而是用一番理由化解“忧”。反问的用意要由整段回应来定。

## 原文：教学例句 {#check.27.p.boat}
> 父遇故友于津，留与语。子独视舟，见缆垂水，问舟人曰：“得无缆断乎？”舟人引之，缆完。子欲即行，父曰：“雾犹蔽岸，无乃太急乎？未辨彼岸，何从而登？”子乃系舟待晴。
译文：父亲在渡口遇见老朋友，留下一道交谈。儿子独自察看船，看见缆绳垂水，问船夫：“莫非缆绳断了？”船夫往上一拉，绳完好。儿子想马上走，父亲说：“岸还被雾遮着，恐怕太急了吧？连对岸都认不清，从哪儿登岸呢？”儿子便拴住船待天放晴。
词注：完：完好，绳子没断。
  蔽：遮住。
  彼：那，此处指对岸。

## 单选：父亲“留与语”时，与谁交谈？儿子当时在做什么？ {#check.27.q4}
考点：g27.skill.preobj
语境：check.27.p.boat

- [ ] 与船夫交谈，儿子同故友拉绳
  理由：同船夫说话的是后面问缆绳的儿子。
- [ ] 与儿子交谈，父子一起看船
  理由：“子独视舟”将两人的行动分开。
- [x] 与故友交谈，儿子独自看船

提示：“与”后的同谈者须从刚遇见的人中找。
解析：先是父遇故友，便省下“与〔故友〕语”的人名。儿子另行看船，要到下一句才开始问话。

## 单选：拉绳查验之前，可以把“缆断”当作已知前提吗？ {#check.27.q5}
考点：g27.skill.dewu
语境：check.27.p.boat

- [ ] 不可以，因为儿子根本没问船夫
  理由：“得无缆断乎”正出自他的问话。
- [ ] 可以，船夫把断绳修补好了才叫“完”
  理由：原文只写引绳查看，没写修补。
- [x] 不可以，儿子只是因为绳垂水而起疑

提示：把“见缆垂水”与“缆完”放在提问前后。
解析：见到绳垂水属实，绳是否断仍待核实；拉起后才有凭据撤去这一猜测。

## 单选：儿子原想开船，父亲说“无乃太急乎”后为什么他反而把船系住了？ {#check.27.q6}
考点：g27.skill.wunai
语境：check.27.p.boat

- [ ] 父亲证实缆绳已经断掉，叫他重新打结
  理由：刚才船夫已检查“缆完”。
- [x] 他听出父亲担心雾大难辨登岸处，在劝他稍候
- [ ] 父亲只是问想几点开船，儿子答待晴正是某个钟点
  理由：父亲接着问如何登岸，理由是雾遮岸。

提示：把父亲的两问连起来，再观察孩子的举动。
解析：“无乃”先作婉转劝止，下一问指出此刻登岸无从。系舟待晴才是对这一顾虑的实际回应。
