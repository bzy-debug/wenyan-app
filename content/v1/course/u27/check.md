# 检查：从渡江、寻人读到取粮 {#check.27}

## 原文：教学例句 {#p.vocab.check.27.1}
> 道止于江。舟人道昔年水涨之事，客闻之，待水稍退，乃济。
译文：道路止于江边。船夫讲述从前涨水的事，客人听了，等水稍退，才渡江。

## 单选：“道止于江”和“舟人道昔年水涨之事”，后一个“道”怎么讲？ {#q.vocab.check.27.1}
考点：skill.vocab.19.2
语境：p.vocab.check.27.1

- [ ] 一条路 {#q.vocab.check.27.1.o1}
  理由：后面是“水涨之事”。
- [x] 讲述旧事 {#q.vocab.check.27.1.o2}
- [ ] 横渡大江 {#q.vocab.check.27.1.o3}
  理由：到末句客人才过江。

提示：客人后来说“闻之”，听见的是哪件事？
解析：前一个“道”是路，到江边就断了；后一个“道”是舟人讲起从前涨水的事。

## 单选：客人到了江边，为什么过了一会儿才渡江？ {#q.vocab.check.27.2}
考点：skill.vocab.19.4
语境：p.vocab.check.27.1

- [ ] 道路早已恢复 {#q.vocab.check.27.2.o1}
  理由：没有修路情节。
- [x] 听了旧事后等待水势减退 {#q.vocab.check.27.2.o2}
- [ ] 没有找到去江边的路 {#q.vocab.check.27.2.o3}
  理由：开头已到江边。

提示：“待水稍退”以前，舟人说过什么？
解析：客人听舟人讲起从前涨水的事，等水势退去些才过江。

## 原文：教学例句 {#p.vocab.check.27.2}
> 里吏按籍，见一役者亡。明日，其人自山中归，得失散之弟，二人偕至。
译文：乡吏核对名册，发现一个服役的人逃走了。次日，那人从山里回来，找到了失散的弟弟，两人一道前来。

## 单选：里吏发现役者“亡”，明日此人又“归”。前一天出了什么事？ {#q.vocab.check.27.3}
考点：skill.vocab.20.2
语境：p.vocab.check.27.2

- [x] 此人逃走后又回来了 {#q.vocab.check.27.3.o1}
- [ ] 此人死后留下弟弟 {#q.vocab.check.27.3.o2}
  理由：“其人自山中归”说本人回来。
- [ ] 遗失了一本簿籍 {#q.vocab.check.27.3.o3}
  理由：“亡”的主语是役者。

提示：回来时，他是从哪里回来的？
解析：役者离了原处逃进山里，次日又回来。这样才接得上“归”。

## 单选：役者先与弟弟“失散”，后来“得失散之弟”，兄弟二人怎样了？ {#q.vocab.check.27.4}
考点：skill.vocab.20.1
语境：p.vocab.check.27.2

- [x] 失散的二人团聚 {#q.vocab.check.27.4.o1}
- [ ] 弟弟得到了吏职 {#q.vocab.check.27.4.o2}
  理由：“得失散之弟”说找到弟弟，这里没有授官。
- [ ] 二人在山中继续失散 {#q.vocab.check.27.4.o3}
  理由：后文“二人偕至”，说的是兄弟一起来了。

提示：弟弟原先“失散”，末了却“二人偕至”。
解析：兄长找到了失散的弟弟，二人这才一起回来。

## 原文：教学例句 {#p.vocab.check.27.3}
> 里正为老者书券。老者以券取粟；是岁无饥，故仓尚有余。
译文：里正替老人写了凭券。老人凭券领粮；这年没有饥荒，因此仓里还剩下粮食。

## 单选：谁去取粮，又是谁替他写券？ {#q.vocab.check.27.5}
考点：skill.vocab.21.3
语境：p.vocab.check.27.3

- [ ] 老人自写券给里正 {#q.vocab.check.27.5.o1}
  理由：“为老者”说里正替老人写，动笔的是里正。
- [ ] 里正独自办两件事 {#q.vocab.check.27.5.o2}
  理由：开头是里正写券，后来改由老人拿券去取粟。
- [x] 老人领粮，里正写券 {#q.vocab.check.27.5.o3}

提示：“为老者”的人是谁？下句“以券”的又是谁？
解析：里正替老人写券，老人拿着这张券去领粮。

## 单选：老人拿券去取粟，这张券有什么用？ {#q.vocab.check.27.6}
考点：skill.vocab.21.4
语境：p.vocab.check.27.3

- [ ] 所领的粮食 {#q.vocab.check.27.6.o1}
  理由：所取之物在“取”后。
- [ ] 仓有余粮的原因 {#q.vocab.check.27.6.o2}
  理由：仓有余是因为无饥。
- [x] 领粮的凭证 {#q.vocab.check.27.6.o3}

提示：“以券”可以试读为“凭着这张券”。
解析：里正替他写下的文书，就是老人领取粮食时所用的凭证。
