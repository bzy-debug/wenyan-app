# 课文：“与饮”是跟谁，“军函陵”又在哪里 {#g27.2}
简介：不是每一处地点都写“于”，也不是每一个“与”后都再报一次姓名。

## 正文

“客宿亭中”，白话可以补成“客人在亭中住宿”。补一个“在”，是为说清亭子同“宿”的关系，并不表示原文凡是地名就缺“于”。如“离亭”便是离开亭子，两句话的方向正相反。

“主人留客，与饮”，还有一种省写：“与”已在，“与谁”却未重说。前面刚留客，能同主人饮的，自然是这位客人。要是后来又来了朋友，便须按人物出现的时刻重新判断。

## 知识点：直接接在动作后的处所 {#g27.skill.place}
义项：按动词辨在何处或到何处，不把地名当受事
领域：句法
要诀：先试“在这个地方做”，再看事情有无从一处移到另一处。
讲解：读“客宿西亭”可以补“在西亭”，若成“过西亭”，写的就是经过该地。补词为了说明本句话，不是替作者改字。
例句：g27.ex.place

## 原文：教学例句 {#g27.ex.place}
> 吏宿东舍，客宿西舍。
译文：官吏住在东舍，客人住在西舍。

## 知识点：介词留下而对象省写 {#g27.skill.preobj}
义项：“与、以”等后从前文承接人或物
领域：句法
要诀：试用“与谁”“用何物”发问，回到前一句找。
讲解：“父唤子，与观灯”，父亲唤过来的是孩子，后来便是同孩子看灯。“与”在，省了同看的人。
例句：g27.ex.preobj

## 原文：教学例句 {#g27.ex.preobj}
> 客遇旧友，留与食。
译文：客人遇见老朋友，留他一道用饭。

## 单选：若要在地图标出两个驻地，原文的字序要怎样展开？ {#g27.2.q1}
考点：g27.skill.place
语境：g27.2.p.camp

- [ ] 晋先从函陵出发，秦随后由氾南撤回
  理由：这里只有驻地，没写出发与撤回。
- [ ] 晋驻军于秦，函陵和氾南是两位统兵者
  理由：两国名各在“军”前，两处地名各在“军”后。
- [x] 晋驻军于函陵，秦驻军于氾南

提示：先把两个“军”都读成驻军。
解析：函陵和氾南都是驻军所在。白话自然要说“驻在”，不必因此在引文中另添于字。

## 找原文证据：若地图上只给秦国军营立一枚地点牌，应写原文中的哪两字？ {#g27.2.q2}
考点：g27.skill.place
语境：g27.2.p.camp

- [ ] 函陵
  理由：那是晋军驻地。
- [x] 氾南
- [ ] 晋
  理由：这是第一方的国名。

提示：先找后一个“军”，再看紧跟它的地方。
解析：两句并列而次序不乱：秦接氾南，晋接函陵。

## 单选：“与饮”里若把没说出的人名补上，谁和谁同席？ {#g27.2.q3}
考点：g27.skill.preobj
语境：g27.2.p.meal

- [ ] 项王独饮，沛公已在“留”以前走了
  理由：留人正接在与饮之前。
- [ ] 沛公留下项王，同一位没有提名的使者共饮
  理由：“留沛公”已定留下的对象。
- [x] 项王与刚留下的沛公

提示：先问项王留谁，再将此人放在“与”后。
解析：“与〔沛公〕饮”仍承上句。整句话并未引进第三个共同饮酒者。

## 原文：教学例句 {#g27.2.p.gift}
> 客访故人，不遇，宿村东。明旦，故人来谢，客得新茶，与饮。日中，客离村东，故人送之。
译文：客人访老友未遇，住在村东。次日清早，老友来致歉，客人得了新茶，同老友一起喝。正午客人离开村东，老友送他。

## 单选：两次“村东”相同，可以都译成“在村东”就算读完了吗？ {#g27.2.q4}
考点：g27.skill.place
语境：g27.2.p.gift

- [ ] 第一次说老友住村东，第二次才说客也住下
  理由：“宿村东”的主语是来访未遇的客。
- [x] 第一次是住宿的地方，第二次说从那里离开
- [ ] 都表示客当天住下，无关出发
  理由：第二次有“离”，故人还为他送行。

提示：对着“宿”和“离”分别问处所和起点。
解析：地名不变，动词让它承担不同关系，不能见地名就用同一个“在”。

## 单选：“与饮”怎样补，既留下两个人，又不把茶说成人？ {#g27.2.q5}
考点：g27.skill.preobj
语境：g27.2.p.gift

- [ ] 客人同新茶一道饮故人
  理由：茶是所饮之物，不是一同饮的人。
- [ ] 客人同正午来送行的第三人饮酒
  理由：正午送行的仍是故人，文中没添酒或另一个人。
- [x] 客人同来谢的故人饮新茶

提示：分别问“同谁饮”“饮什么”。
解析：“与”后省去的是同饮之人。紧靠它的“新茶”虽是名词，却只能作饮的东西。

## 原文：古籍引文 {#g27.2.p.ox}
> 王见之，曰：“牛何之？”对曰：“将以衅钟。”王曰：“舍之！”
译文：王见了它，问：“牛要到哪儿去？”牵牛的人答：“将用它的血涂钟行礼。”王说：“放了它！”
出处：《孟子·梁惠王上》齐宣王见牵牛者节录
版本：Kanseki Repository，tls
底本链接：https://github.com/kanripo/KR1h0001/blob/8decdf43d5a82b779f7950a7782b9a5e09659564/KR1h0001_001.txt#L381-L387
作者：孟子及其后学
原文权利：古籍公版正文节引，转为通行简体字并标点。
译注权利：项目自撰今译、讲解及练习。
词注：衅钟：古时用牲血涂钟而祭。
  舍：放开，在这里指把牛放走。

## 单选：“将以衅钟”里，钟在句中已经有了位置。哪一样仍要由王的问话补给“以”？ {#g27.2.q6}
考点：g27.skill.preobj
语境：g27.2.p.ox

- [ ] 以王作牵牛的人
  理由：王是发问这一方，问的正是牛的去向。
- [ ] 把钟用作运牛的器具
  理由：“衅钟”说的是在钟上行礼，不是搬运。
- [x] 用的是眼前这头牛，行礼时取其血

提示：从“牛何之”到“舍之”，王一直着眼什么？
解析：“将以〔牛〕衅钟”在这里交代牛的用途；答者不必把问句中已有的“牛”再说一次。

## 原文：教学例句 {#g27.2.p.inn}
> 暮，父宿驿西，子宿驿东。翌旦，子持图就父，与视归路，乃相携而行。
译文：傍晚父亲住在驿站西边，儿子住在驿站东边。次日清晨儿子带图去找父亲，同父亲查看归路，便相伴出发。

## 排序：从父子分别投宿到一道出发，按原文排。 {#g27.2.q7}
考点：g27.skill.place
语境：g27.2.p.inn

- [2] 早晨子持图去就父
  理由：不是父亲由西往东去接孩子。
- [1] 夜里分别宿在驿站东西
  理由：两处“宿”分给不同的人。
- [3] 两人看路后相携出发
  理由：相携在同看归路以后。

提示：先标两处住宿地，再标“就”指向谁。
解析：“宿驿东”说孩子原先在何处，“就父”才使两人会面，后面才说得通“相携”。

## 找原文证据：“与视归路”中同看地图的人没有重写。前文哪两字让你找得到他？ {#g27.2.q8}
考点：g27.skill.preobj
语境：g27.2.p.inn

- [ ] 持图
  理由：交代手里有图，没指出与谁同行。
- [x] 就父
- [ ] 驿东
  理由：这只是儿子昨晚的住宿地方。

提示：儿子带着图去见谁？
解析：刚“就父”，即同父亲看路。“相携”再说父子的会合确已发生。
