# 课文：“莫非如此？”是揣测、劝告，还是反问 {#g27.3}
简介：同样有个问号，有人缺消息，有人已有理由，还有人借问话劝听者收手。

## 正文

“得无失物乎”可以是见着空匣生疑；若答“物方在案”，原来的猜想就得改。孔子说“为之难，言之得无讱乎”，却是在说明做起来难，说起来岂能不慎。读完理由，再听他是否真在等人报告物情。

“无乃……乎（与）”也常把担忧或批评说得婉转。“无乃过急乎”大致是“这样恐怕太急了吧”。婉转并不等于毫无立场，但它也不自动证明被怀疑的事情属实。

## 知识点：无乃……乎的委婉揣度 {#g27.skill.wunai}
义项：恐怕如此吧，可表示担忧或批评
领域：虚词
要诀：观察对方有什么做法，引出这番担心或责问。
讲解：“桥未成而驱车，无乃太急乎”，桥未成是前提，问话意在提醒赶车人留步。
例句：g27.ex.wunai

## 原文：教学例句 {#g27.ex.wunai}
> 粮尽而留客，无乃难乎？
译文：粮尽了还要留客，恐怕很难吧？

## 知识点：得无……乎的待核猜测 {#g27.skill.dewu}
义项：从见闻提出一种可能，再听如何核实
领域：句法
要诀：说话人手中是迹象，还是已经查到的事实？
讲解：“案空，得无书失乎”，案空只够让人起疑。若回答书已收入箱中，不能再断言遗失。
例句：g27.ex.dewu

## 原文：教学例句 {#g27.ex.dewu}
> 客独至，得无失伴乎？
译文：客人独自到了，莫非跟同伴走散了？

## 知识点：凭已给的理由判读反问 {#g27.skill.rhetorical}
义项：问法将听者引向已有的判断
领域：阅读技能
要诀：看前面的理由是否已把答案说定，后面还需提供什么消息。
讲解：“道塞无人得过，吾独能飞乎”并非求问自己能否飞，而是说明自己也过不去。
例句：g27.ex.rhetorical

## 原文：教学例句 {#g27.ex.rhetorical}
> 冰且裂，岂可载重车乎？
译文：冰快裂了，怎么能承载重车呢？

## 单选：“无乃为佞乎”是谁对谁提出的看法？后来对方怎样回应？ {#g27.3.q1}
考点：g27.skill.wunai
语境：g27.3.p.fault

- [x] 微生亩疑孔子如此奔忙是为逞口才，孔子否认
- [ ] 孔子自认只会逞口才，请人证实
  理由：孔子在说“非敢为佞”。
- [ ] 微生亩说自己不愿开口，请孔子代答
  理由：他一开口便呼对方“丘”，质问的是孔子。

提示：把微生亩的问话和孔子的“非敢”分开。
解析：“无乃”带出批评性的猜度，是发问者对孔子动机的解释。孔子接着说明自己的理由不同。

## 单选：孔子特意先说“为之难”，后面这一问希望听者领会什么？ {#g27.3.q2}
考点：g27.skill.rhetorical
语境：g27.3.p.words

- [x] 实行不易，所以说起来岂能不慎
- [ ] 凡事说得慢就一定已经做成
  理由：原句由做事难说到慎言，不能倒推已做成。
- [ ] 孔子没听清一个字的读音，等弟子回答
  理由：没问字音，前面还给出了慎言的理由。

提示：前半句话是等待补报的消息，还是后半句已有的理由？
解析：在这个上下文里，“得无讱乎”要求人想见慎重的必要。不能一见“得无”就译成还不知事实的猜测。

## 原文：教学例句 {#g27.3.p.calf}
> 暮，牧童独归。母不见犊，问：“得无失其犊乎？”童指篱外曰：“方就草耳。”母出，果见之。
译文：傍晚牧童独自回来。母亲没见小牛，问：“莫非把小牛丢了吗？”孩子指着篱笆外说：“它只是在吃草。”母亲出去，果然看见了它。
词注：犊：小牛。
  就草：靠近青草取食。
  果：果然，后文有亲眼核实。

## 单选：母亲问话的那一刻，证据已经足以认定丢牛吗？ {#g27.3.q3}
考点：g27.skill.dewu
语境：g27.3.p.calf

- [ ] 足够，“得无”表示已经查清且不可更改
  理由：孩子指出篱外，母亲又亲自看见。
- [x] 还不足，她只看见孩子独归，未见小牛
- [ ] 足够，因为孩子已经承认把牛丢了
  理由：孩子的答话是“方就草耳”。

提示：把提问时所见和出门后所见分开。
解析：“得无”提出的是一种待确认的解释，母亲见到的是人牛没同时进门，不能由此断言失牛。

## 找原文证据：孩子说的情况最终由哪处直接验证？ {#g27.3.q4}
考点：g27.skill.dewu
语境：g27.3.p.calf

- [ ] 问
  理由：提出疑问还不是查到了牛。
- [ ] 牧童独归
  理由：这是母亲怀疑的起点。
- [x] 果见之

提示：找母亲亲自从篱笆外得知答案的地方。
解析：“果见之”的“之”指牛。一旦母亲见到了，最初“得无失其犊乎”的担心便消除。

## 原文：教学例句 {#g27.3.p.cart}
> 工方合车轴，胶未干。主人命试车，工曰：“无乃太早乎？胶尚黏手，车何可行？”主人止。
译文：工匠正在装合车轴，胶还没干。主人叫试车，工匠说：“恐怕太早了吧？胶还黏手，车怎么能行？”主人停手了。

## 单选：工匠先说“无乃太早乎”，是要主人报时辰，还是想改变眼下的安排？ {#g27.3.q5}
考点：g27.skill.wunai
语境：g27.3.p.cart

- [ ] 要主人告诉他今天是哪一时辰
  理由：他后面举胶黏手作理由，没问钟点。
- [x] 劝主人暂缓试车
- [ ] 向主人报喜，说车比预计早做好了
  理由：胶未干，主人随后也止了。

提示：问话之后，他列的是时辰，还是不宜动手的事实？
解析：“无乃”把反对试车说得婉转，黏手是他能当场指出的依据。

## 单选：第二问“车何可行”换成陈述，哪句与结尾最合？ {#g27.3.q6}
考点：g27.skill.rhetorical
语境：g27.3.p.cart

- [ ] 工匠断定这车日后永远不能用
  理由：“太早”只说现在。
- [ ] 他不懂驾车，想请主人教驾法
  理由：前面谈的是胶，不是如何驱车。
- [x] 胶未干，此时还不可试行

提示：看主人听后是演示驾法，还是收回命令。
解析：工匠给了即时理由，主人就此止住。这是用反问加强劝阻，不是讨教路线或驾法。

## 原文：教学例句 {#g27.3.p.lock}
> 仓门闭，吏呼不应，问于童曰：“得无典仓者病乎？”童曰：“未可知，吾往问邻。”邻曰：“今早见之赴县。”
译文：仓门关着，官吏喊人无人应，问孩子：“莫非管仓的人病了吗？”孩子说：“还不知道，我去问邻居。”邻居说：“今天早晨看见他去县里了。”

## 单选：这番问答最后能写进记录的，哪项最稳当？ {#g27.3.q7}
考点：g27.skill.dewu
语境：g27.3.p.lock

- [x] 孩子未确认患病，邻人只报告今早见他赴县
- [ ] 官吏已经诊断他生病，孩子只是去请药
  理由：“得无”是猜测，“未可知”也未加确认。
- [ ] 邻人已证明此人全天不可能生病
  理由：早晨赴县的见闻不能证明整天怎样。

提示：三人各知道多少？别把问句改记成诊断。
解析：闭门无人应可以有多种原因。邻人给一条独立见闻，仍没有替管仓人诊病。

## 原文：教学例句 {#g27.3.p.depth}
> 客临水问：“深几许？”舟人投石系绳，量而告之。客闻水深过人，复问：“我不善游，岂可涉乎？”遂登舟。
译文：客人临水问：“多深？”船夫用绳系石投入水中，量了告诉他。客人得知水深过人，又问：“我不会游，怎么能蹚过去呢？”便上了船。

## 单选：两句都在发问，为什么前一句要实际测量，后一句却接着上船？ {#g27.3.q8}
考点：g27.skill.rhetorical
语境：g27.3.p.depth

- [ ] 两句都在问同一数值，船夫须量两次
  理由：第二问有“岂可涉”，问的不是几许深。
- [ ] 前问是客自夸善游，后问猜船去了哪里
  理由：他明说自己不善游，船就在眼前。
- [x] 前问缺水深的消息，后问已有水深与不会游两条理由

提示：先看测量的结果，再读登舟前已经知道的事。
解析：“深几许”真在等答案。“岂可涉乎”已据所知否定徒涉的可行，故登舟而不再索取数值。
