# 检查：从游说、心愿读到转述与上报 {#check.35}

## 原文：教学例句 {#p.check.35.a}
> 市人将伐道旁槐以为薪。老者说之曰：“暑日行人皆息其阴，可尽伐乎？”市人止。
译文：市上的人要砍路旁槐树做柴。老人劝道，暑天行人都在树荫下歇息，能全砍吗？人们便停下了。

## 找原文证据：哪一处结果可以验证老者这次游说发生了作用？ {#q.check.35.1}
考点：skill.words.7.1
语境：p.check.35.a

- [x] 市人止
- [ ] 行人皆息其阴
  理由：这是老人提出的劝说理由。
- [ ] 以为薪
  理由：这是市人原先砍树的目的。

提示：看提议被听到之后，准备砍树的人怎样做。
解析：“止”接在游说之后，表明对方改变了原先的打算。

## 原文：教学例句 {#p.check.35.b}
> 客请少留舟以待母。舟人许之，收橹系舟于柳。
译文：客人请求稍留船只等母亲。船夫答应，收起桨，把船系在柳树上。

## 单选：船夫所“许”的具体内容是什么？ {#q.check.35.2}
考点：skill.words.7.3
语境：p.check.35.b

- [x] 暂时停船等客人的母亲
- [ ] 把柳树连同舟船交给客人
  理由：系船是等人的办法，未说转给客人。
- [ ] 称赞客人母亲划船的本领
  理由：所答复的是留下船的请求。

提示：把答话放回“客请”的语境。
解析：“少留舟”是所请，“许之”作出应允，收橹系舟是随后实际做的事。

## 原文：教学例句 {#p.check.35.c}
> 门外有屐声，仆意客至，开门，乃童负薪归。
译文：门外传来木屐的声音，仆人猜想客人到了，开门才发现是孩子背柴归来。

## 单选：记录此事时，哪一项应写作仆人的判断而非所见？ {#q.check.35.3}
考点：skill.words.8.1
语境：p.check.35.c

- [x] 客人到了
- [ ] 孩子背柴回来
  理由：这是开门后看清的来人。
- [ ] 门外有木屐声
  理由：这是引起猜测的声音。

提示：把“意”与“乃”标出的两个认知时刻区别开。
解析：“意客至”是还未开门时的猜想，亲眼所见的却是负薪的孩子。

## 原文：教学例句 {#p.check.35.d}
> 主欲留客饮。客念邻儿独守门户，辞曰：“归视之，乃敢安。”
译文：主人想留客饮酒。客人考虑到邻家的孩子独自守门，辞谢说，回去看看他才能放心。

## 找原文证据：哪一处是客人辞谢挽留时顾及的具体情形？ {#q.check.35.4}
考点：skill.words.8.3
语境：p.check.35.d

- [ ] 主欲留客饮
  理由：这是主人的愿望。
- [ ] 归视之
  理由：这是客人要去做的事。
- [x] 邻儿独守门户

提示：找“念”紧接的那一层。
解析：客人心里放不下孩子独守门户，所以回去看望，而未应邀饮酒。

## 原文：教学例句 {#p.check.35.e}
> 学者言物虽小而可用，举断绳系简之事。友取余绳，试之果便。
译文：读书人说东西虽小也有用处，举出用断绳捆竹简的事。朋友取来绳头一试，果然方便。

## 单选：“举断绳系简之事”在谈话中起了什么作用？ {#q.check.35.5}
考点：skill.words.9.1
语境：p.check.35.e

- [ ] 规定所有余绳都必须拿来捆竹简
  理由：例子说明一种用途，没有排除其他用途。
- [ ] 推荐一位擅长编绳的人
  理由：所举的是一件事，原文没有举荐人。
- [x] 给“小物可用”补上一个可以检验的例子

提示：把前面的概括同后面的试用相连。
解析：系简这个具体用法能支持“物虽小而可用”，朋友随后还亲手作了验证。

## 原文：教学例句 {#p.check.35.f}
> 驿卒见道陷，以告县丞。丞度其深广，具数以闻。郡守得报，命发丁治道。
译文：驿卒见道路塌陷，把消息告诉县丞。县丞测量深度和宽度，把数字详细上报。郡守收到报告，命派人修路。

## 排序：顺着险情从发现到上报、处置的次序排列。 {#q.check.35.6}
考点：skill.words.9.4
语境：p.check.35.f

- [2] 县丞量出尺寸后向郡里报告
- [1] 驿卒把路陷的消息告诉县丞
- [3] 郡守收到报告下令修路

提示：“告县丞”指出第一位接收人；“以闻”后还有谁得报？
解析：由现场发现者到县丞，再由县丞上报郡守；发丁修路发生在收到报告之后。
