# 检查：从游说、心愿读到转述与上报 {#check.35}

## 原文：教学例句 {#p.check.35.a}
> 市人将伐道旁槐以为薪。老者说之曰：“暑日行人皆息其阴，可尽伐乎？”市人止。
译文：市上的人要砍路旁槐树做柴。老人劝道，暑天行人都在树荫下歇息，能全砍吗？人们便停下了。

## 找原文证据：老者劝人留下槐树。哪几个字说明砍树的人改了主意？ {#q.check.35.1}
考点：skill.words.7.1
语境：p.check.35.a

- [x] 市人止
- [ ] 行人皆息其阴
  理由：这是老人提出的劝说理由。
- [ ] 以为薪
  理由：这是市人原先砍树的目的。

提示：看提议被听到之后，准备砍树的人怎样做。
解析：市人本打算伐槐作柴，听了老人的话却“止”了。这个停手的动作写出游说的结果。

## 原文：教学例句 {#p.check.35.b}
> 客请少留舟以待母。舟人许之，收橹系舟于柳。
译文：客人请求稍留船只等母亲。船夫答应，收起桨，把船系在柳树上。

## 单选：客人请船夫帮什么忙，船夫又答应了什么？ {#q.check.35.2}
考点：skill.words.7.3
语境：p.check.35.b

- [x] 暂时停船等客人的母亲
- [ ] 把柳树连同舟船交给客人
  理由：系船是等人的办法，未说转给客人。
- [ ] 称赞客人母亲划船的本领
  理由：所答复的是留下船的请求。

提示：把答话放回“客请”的语境。
解析：“少留舟”是稍微停船，“以待母”说等谁。船夫收橹系船，已开始照办。

## 原文：教学例句 {#p.check.35.c}
> 门外有屐声，仆意客至，开门，乃童负薪归。
译文：门外传来木屐的声音，仆人猜想客人到了，开门才发现是孩子背柴归来。

## 单选：门外传来脚步声，仆人还没开门就作了什么猜测？ {#q.check.35.3}
考点：skill.words.8.1
语境：p.check.35.c

- [x] 客人到了
- [ ] 孩子背柴回来
  理由：这是开门后看清的来人。
- [ ] 门外有木屐声
  理由：这是引起猜测的声音。

提示：把开门以前猜的和开门以后看到的人分开。
解析：他听见木屐声便猜客人到了。门一开，才看清是背柴归来的孩子。

## 原文：教学例句 {#p.check.35.d}
> 主欲留客饮。客念邻儿独守门户，辞曰：“归视之，乃敢安。”
译文：主人想留客饮酒。客人考虑到邻家的孩子独自守门，辞谢说，回去看看他才能放心。

## 找原文证据：哪几个字说明，客人为什么不肯留下喝酒？ {#q.check.35.4}
考点：skill.words.8.3
语境：p.check.35.d

- [ ] 主欲留客饮
  理由：这是主人的愿望。
- [ ] 归视之
  理由：“归视之”说他打算回去探看。让他放不下心的是邻家孩子眼下的处境。
- [x] 邻儿独守门户

提示：找“念”紧接的那一层。
解析：客人惦记邻家的孩子独自守门，想回去看看，心里才踏实。

## 原文：教学例句 {#p.check.35.e}
> 学者言物虽小而可用，举断绳系简之事。友取余绳，试之果便。
译文：读书人说东西虽小也有用处，举出用断绳捆竹简的事。朋友取来绳头一试，果然方便。

## 单选：学者说小东西也有用，为什么特意讲起用断绳系竹简的事？ {#q.check.35.5}
考点：skill.words.9.1
语境：p.check.35.e

- [ ] 规定所有余绳都必须拿来捆竹简
  理由：例子说明一种用途，没有排除其他用途。
- [ ] 推荐一位擅长编绳的人
  理由：所举的是一件事，原文没有举荐人。
- [x] 给“小物可用”补上一个可以检验的例子

提示：把前面的概括同后面的试用相连。
解析：系简是断绳能派上的一个用场。朋友又拿余下的绳亲手试过，果然好用。

## 原文：教学例句 {#p.check.35.f}
> 驿卒见道陷，以告县丞。丞度其深广，具数以闻。郡守得报，命发丁治道。
译文：驿卒见道路塌陷，把消息告诉县丞。县丞测量深度和宽度，把数字详细上报。郡守收到报告，命派人修路。

## 排序：从驿卒发现道路塌陷，到郡守派人修路，中间各步怎样衔接？按原文排序。 {#q.check.35.6}
考点：skill.words.9.4
语境：p.check.35.f

- [2] 县丞量出尺寸后向郡里报告
- [1] 驿卒把路陷的消息告诉县丞
- [3] 郡守收到报告下令修路

提示：“告县丞”指出第一位接收人；“以闻”后还有谁得报？
解析：驿卒先报给县丞，县丞量了深浅宽窄，再把数目报给郡守。郡守收报后才派人修路。
