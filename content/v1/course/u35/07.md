# 课文：说、称、许、然：这句话对谁起作用 {#words.7}
简介：有人劝别人改变做法，有人评说好坏。听者点头，可能是赞同判断，也可能是答应请求。

## 正文

### 把一句话放回两人之间
自编例句“父说其子，使从师”，说话人想改变儿子的选择。这里的“说”读 **shuì**。换作“父称其子能学”，父亲已在评价儿子。“称”后可接人，也可接值得称道的一点，例如“称其德”。

听的人也会表态。听到“请借一舟”后“许之”，答应的是把船借出去。听到“西堤不固”后“然其言”，是觉得这一判断正确；此后是否愿意出力修堤，还要再读。

## 知识点：说 {#skill.words.7.1}
义项：用言辞劝人采纳主张（shuì）
领域：实词
要诀：找劝说者希望对方改变的做法。
讲解：“说某人”可表示去游说他。后文写接受、拒绝或不肯行动，都说明游说有目的，未必成功。
例句：p.words.7.ex1

## 知识点：称 {#skill.words.7.2}
义项：赞许、称道
领域：实词
要诀：看话中专门指出了哪一点好处。
讲解：“称其……”常带出一个人或事物被称赞的特性。后面跟优点或善行，往往不是称呼姓名。
例句：p.words.7.ex2

## 知识点：许 {#skill.words.7.3}
义项：应允请求或承诺做事
领域：实词
要诀：从“许”向前找请求，向后看约定的行动。
讲解：若先有人“请”“乞”，答者“许之”常表示同意其请求；若许人以物，则是承诺将物给他。
例句：p.words.7.ex3

## 知识点：然 {#skill.words.7.4}
义项：以某人的话、做法为对
领域：实词
要诀：想一想被认可的是哪句话。
讲解：“然其言”“以为然”可写对判断的认可。它本身只表示赞同，不能独自说明已经照办。
例句：p.words.7.ex4

## 原文：教学例句 {#p.words.7.ex1}
> 冰薄，少者欲渡。父说之，使待舟。
译文：冰薄，年轻人想过河。父亲劝他等船。

## 原文：教学例句 {#p.words.7.ex2}
> 里中称王叟之信，凡贷物，虽久必还。
译文：村人称赞王老伯守信用。他借来的东西，即使时间久了也必定归还。

## 原文：教学例句 {#p.words.7.ex3}
> 生请借书五日，师许之，戒勿污其纸。
译文：学生请求借书五天，老师答应，并嘱咐不要弄脏纸张。

## 原文：教学例句 {#p.words.7.ex4}
> 客言北路泥深，主人然其言，命车由南。
译文：客人说北路泥深，主人认为他说得对，叫车走南路。

## 单选：“茅焦说秦王”里的“说”应怎样读、怎样理解？ {#q.words.7.1}
考点：skill.words.7.1
语境：p.words.7.a

- [ ] 读 shuō，秦王给茅焦讲述自己迎太后的经过
  理由：“秦王乃迎”写在茅焦劝说之后。
- [ ] 读 yuè，秦王为茅焦而喜悦
  理由：“茅焦”在动作前，是主动去影响秦王的人。
- [x] 读 shuì，茅焦劝秦王改变对待太后的做法

提示：看谁影响了谁，以及“乃”后发生什么。
解析：茅焦是劝说者，秦王是被劝者；迎太后是秦王随后采取的行动。

## 原文：教学例句 {#p.words.7.b}
> 县将罢夜渡。船人说令曰：“市散常晚，宜留一舟。”令不听。
译文：县里将停办夜渡。船夫劝县令说，集市常散得晚，应当留一条船。县令没有采纳。

## 单选：“船人说令”已经发生，哪一件事仍未做到？ {#q.words.7.2}
考点：skill.words.7.1
语境：p.words.7.b

- [ ] 县令听到了一个与原计划不同的意见
  理由：末句是没有采纳意见，前面已写当面进言。
- [x] 让县令同意保留夜渡船
- [ ] 船夫提出留下船只的主张
  理由：“宜留一舟”已经说出了主张。

提示：劝说这个动作与劝说成功是两回事。
解析：“说”说明船夫试图影响县令；“不听”交代这次劝说未被采纳。

## 单选：两处“称”都用来做什么？ {#q.words.7.3}
考点：skill.words.7.2
语境：p.words.7.c

- [ ] 比较骏马的力气与身体是否相称
  理由：后半句又说“称其德”，同一动词带出被赞许的方面。
- [x] 说明骏马究竟凭什么受到赞许
- [ ] 分别说出骏马的两个名字
  理由：“力”“德”并列的是两种特性。

提示：把“不……，……也”两边并排读。
解析：前半排除力气，后半点明品性，是在选择值得称道之处。

## 原文：教学例句 {#p.words.7.d}
> 大水退，邻里称媪好义，曰：“水方涨，家家求舟，独媪以舟济病者。”
译文：洪水退后，邻里称赞老妇乐于助人，说水正上涨时家家需要船，唯独她用船渡送病人。

## 找原文证据：邻里称赞老妇助人，举出了哪一件实际行为？ {#q.words.7.4}
考点：skill.words.7.2
语境：p.words.7.d

- [x] 以舟济病者
- [ ] 大水退
  理由：这是邻里事后评说的时间。
- [ ] 家家求舟
  理由：这是大家当时的处境。

提示：找出老妇在众人需要船时做了什么。
解析：在船紧缺时用它渡病人，说明“称”评说的是这次义举。

## 原文：教学例句 {#p.words.7.e}
> 匠请取园中槁木补桥，主许之，命童开门。
译文：工匠请求取园中的枯木修桥，主人答应了，叫童子开门。

## 单选：“许之”具体答应什么？ {#q.words.7.5}
考点：skill.words.7.3
语境：p.words.7.e

- [ ] 工匠承诺替童子守门
  理由：“主许之”交代答复者是主人。
- [x] 准许工匠取用园中的枯木
- [ ] 答应把整座园子送给工匠
  理由：请求只涉及槁木。

提示：把“之”换回上一句提出的请求。
解析：工匠请取槁木，主人答应并让人开门，所许之事前后相合。

## 原文：教学例句 {#p.words.7.f}
> 舟人许客明晨载其箱，未及解缆而风起。客留箱岸上。
译文：船夫答应明早替客人载箱子，还没来得及解开缆绳就起了风。客人把箱子留在岸上。

## 单选：船夫的“许”与事情的实际结果是什么关系？ {#q.words.7.6}
考点：skill.words.7.3
语境：p.words.7.f

- [ ] 他已把箱子送达，只是自己未能回程
  理由：末句交代箱子仍在岸上。
- [ ] 他拒绝了请求，所以没有开船
  理由：阻碍开船的是起风，答话本是同意。
- [x] 他作了承诺，箱子暂未载走

提示：看“明晨”与“未及”各自交代什么。
解析：“许”表承诺；风起使这项承诺尚未实现。

## 原文：教学例句 {#p.words.7.g}
> 二人观堤，甲曰：“下有鼠穴，水且入。”乙初不信，掘土见穴，乃然其言。
译文：两人查看堤岸，甲说下面有鼠洞，水快要进来了。乙起先不信，挖土见到洞，才认为甲说得对。

## 找原文证据：乙从“不信”到“然其言”，直接根据是什么？ {#q.words.7.7}
考点：skill.words.7.4
语境：p.words.7.g

- [ ] 水且入
  理由：这是甲的判断，并非乙新看到的情况。
- [x] 掘土见穴
- [ ] 二人观堤
  理由：这只交代两人一开始在做什么。

提示：找乙态度改变以前取得的新证据。
解析：乙亲眼看到洞，才承认甲对堤下情况的判断。

## 原文：教学例句 {#p.words.7.h}
> 客谓主人曰：“此渠可灌东田。”主人然之，顾家无余力，岁内未凿。
译文：客人对主人说，这条渠可用来灌溉东田。主人赞同，只是家里缺乏余力，当年没有开凿。

## 单选：“主人然之”可以确定什么？ {#q.words.7.8}
考点：skill.words.7.4
语境：p.words.7.h

- [x] 主人同意此渠可灌田的判断
- [ ] 主人开凿后才相信客人的话
  理由：“岁内未凿”明确当年没有施工。
- [ ] 主人已经许诺当年一定凿好
  理由：“然之”承认办法可行，工期并未约定。

提示：分清判断可行与立即开工。
解析：“然”有认可之意；家中余力和实际开凿是随后另外交代的两层事情。
