# 课文：说、称、许、然 {#words.7}
简介：船夫劝县令留一条夜渡船，县令没有答应。劝过谁、称赞谁、答应了哪件事，不能混在一起读。

## 正文

自编例句“父说其子，使从师”，父亲是希望儿子去拜师，劝他作出这个选择，“说”读 shuì。要是写成“父称其子能学”，父亲是在夸儿子有学习的本领。读“称其德”也一样，“德”就是值得称道的那一点。

听话的人怎么回答，也要看他听到的是什么。“请借一舟”是请求，主人“许之”，就是答应借船。“西堤不固”说的是堤不牢靠，主人“然其言”，只是同意这个判断。至于他会不会马上修堤，要等下文再说。

## 知识点：说 {#skill.words.7.1}
义项：用言辞劝人采纳主张（shuì）
领域：实词
要诀：“说”读 shuì 时，听听发话的人想叫对方怎样做。
讲解：父亲见冰薄，劝年轻人等船。“说之”的“之”指那个想渡河的人，“说”读 shuì。读到有人开口劝时，还不一定知道对方会不会听。
例句：p.words.7.ex1

## 知识点：称 {#skill.words.7.2}
义项：赞许、称道
领域：实词
要诀：“称其德”的“德”，是说话的人欣赏的那一点。
讲解：“称王叟之信”是称许王叟守信。王叟借了东西，隔得再久也肯归还，乡人这一句夸奖便有了来由。
例句：p.words.7.ex2

## 知识点：许 {#skill.words.7.3}
义项：应允请求或承诺做事
领域：实词
要诀：有人开口“请”，有人答“许”，回读请求便知答应了什么。
讲解：学生请借书五天，老师“许之”，又叮嘱别弄脏纸页。“之”指刚才的借书请求，老师已经答应。
例句：p.words.7.ex3

## 知识点：然 {#skill.words.7.4}
义项：以某人的话、做法为对
领域：实词
要诀：“然其言”表示同意对方的判断，是否照办还得看后文。
讲解：客人说北路泥深，主人“然其言”，认可他的判断。后来吩咐车从南路走，才写了主人怎样照办。
例句：p.words.7.ex4

## 原文：教学例句 {#p.words.7.ex1}
> 冰薄，少者欲渡。父说之，使待舟。
译文：冰薄，年轻人想过河。父亲劝他等船。

## 原文：教学例句 {#p.words.7.ex2}
> 里中称王叟之信，凡贷物，虽久必还。
译文：村人称赞王老伯守信用。他借来的东西，即使时间久了也必定归还。

## 原文：教学例句 {#p.words.7.ex3}
> 生请借书五日，师许之，戒勿污其纸。
译文：学生请求借书五天，老师答应，并嘱咐不要弄脏纸张。

## 原文：教学例句 {#p.words.7.ex4}
> 客言北路泥深，主人然其言，命车由南。
译文：客人说北路泥深，主人认为他说得对，叫车走南路。

## 单选：“茅焦说秦王”里的“说”应怎样读、怎样理解？ {#q.words.7.1}
考点：skill.words.7.1
语境：p.words.7.a

- [ ] 读 shuō，秦王给茅焦讲述自己迎太后的经过
  理由：“秦王乃迎”写在茅焦劝说之后。
- [ ] 读 yuè，秦王为茅焦而喜悦
  理由：“茅焦”在动作前，是主动去影响秦王的人。
- [x] 读 shuì，茅焦劝秦王改变对待太后的做法

提示：先读“秦王乃迎太后”，再问是谁说动了秦王。
解析：茅焦劝秦王，秦王这才把太后迎回。“说”读 shuì，是游说。

## 原文：教学例句 {#p.words.7.b}
> 县将罢夜渡。船人说令曰：“市散常晚，宜留一舟。”令不听。
译文：县里将停办夜渡。船夫劝县令说，集市常散得晚，应当留一条船。县令没有采纳。

## 单选：船夫已经开口游说县令，却没能办成哪件事？ {#q.words.7.2}
考点：skill.words.7.1
语境：p.words.7.b

- [ ] 县令听到了一个与原计划不同的意见
  理由：末句是没有采纳意见，前面已写当面进言。
- [x] 让县令同意保留夜渡船
- [ ] 船夫提出留下船只的主张
  理由：“宜留一舟”已经说出了主张。

提示：船夫提了什么办法？县令最后听进去了吗？
解析：他希望留下夜渡的船。劝是劝了，县令“不听”，并未答应。

## 单选：说到骏马，句中两个“称”在评说什么？ {#q.words.7.3}
考点：skill.words.7.2
语境：p.words.7.c

- [ ] 比较骏马的力气与身体是否相称
  理由：后半句又说“称其德”，同一动词带出被赞许的方面。
- [x] 说明骏马究竟凭什么受到赞许
- [ ] 分别说出骏马的两个名字
  理由：“力”“德”并列的是两种特性。

提示：把“不……，……也”两边并排读。
解析：“不称其力”先把力气排除，“称其德”再指出骏马品性值得称道。

## 原文：教学例句 {#p.words.7.d}
> 大水退，邻里称媪好义，曰：“水方涨，家家求舟，独媪以舟济病者。”
译文：洪水退后，邻里称赞老妇乐于助人，说水正上涨时家家需要船，唯独她用船渡送病人。

## 找原文证据：大水上涨时，老妇做了什么，让邻里后来称赞她？选出原文。 {#q.words.7.4}
考点：skill.words.7.2
语境：p.words.7.d

- [x] 以舟济病者
- [ ] 大水退
  理由：这是邻里事后评说的时间。
- [ ] 家家求舟
  理由：这是大家当时的处境。

提示：找出老妇在众人需要船时做了什么。
解析：家家都在求船，她却拿自己的船渡病人。邻里说她“好义”，举的就是这件事。

## 原文：教学例句 {#p.words.7.e}
> 匠请取园中槁木补桥，主许之，命童开门。
译文：工匠请求取园中的枯木修桥，主人答应了，叫童子开门。

## 单选：工匠得到主人许可，可以拿什么做什么？ {#q.words.7.5}
考点：skill.words.7.3
语境：p.words.7.e

- [ ] 工匠承诺替童子守门
  理由：“主许之”交代答复者是主人。
- [x] 准许工匠取用园中的枯木
- [ ] 答应把整座园子送给工匠
  理由：读工匠的请求，他只想取园里的枯木补桥。

提示：把“之”换回上一句提出的请求。
解析：园主答应他取园里的枯木补桥。童子开门，是主人答应以后吩咐的事。

## 原文：教学例句 {#p.words.7.f}
> 舟人许客明晨载其箱，未及解缆而风起。客留箱岸上。
译文：船夫答应明早替客人载箱子，还没来得及解开缆绳就起了风。客人把箱子留在岸上。

## 单选：船夫答应明早载箱，箱子后来上船了吗？ {#q.words.7.6}
考点：skill.words.7.3
语境：p.words.7.f

- [ ] 他已把箱子送达，只是自己未能回程
  理由：末句交代箱子仍在岸上。
- [ ] 他拒绝了请求，所以没有开船
  理由：阻碍开船的是起风，答话本是同意。
- [x] 他作了承诺，箱子暂未载走

提示：看风是在解缆之前还是之后起来的。
解析：船夫的承诺已说出口。风在解缆前就起来，箱子还在岸上。

## 原文：教学例句 {#p.words.7.g}
> 二人观堤，甲曰：“下有鼠穴，水且入。”乙初不信，掘土见穴，乃然其言。
译文：两人查看堤岸，甲说下面有鼠洞，水快要进来了。乙起先不信，挖土见到洞，才认为甲说得对。

## 找原文证据：乙原先不信甲的话，看到什么才改了主意？选出原文。 {#q.words.7.7}
考点：skill.words.7.4
语境：p.words.7.g

- [ ] 水且入
  理由：这是甲的判断，并非乙新看到的情况。
- [x] 掘土见穴
- [ ] 二人观堤
  理由：这只交代两人一开始在做什么。

提示：找乙态度改变以前取得的新证据。
解析：乙掘开堤土，亲眼看见鼠洞，这才认可甲说的堤下有穴。

## 原文：教学例句 {#p.words.7.h}
> 客谓主人曰：“此渠可灌东田。”主人然之，顾家无余力，岁内未凿。
译文：客人对主人说：“这条渠能灌东田。”主人也这样想，只是家里没有余力，那一年还没有开凿。

## 单选：主人“然之”，究竟同意了客人的什么话？ {#q.words.7.8}
考点：skill.words.7.4
语境：p.words.7.h

- [x] 主人同意此渠可灌田的判断
- [ ] 主人开凿后才相信客人的话
  理由：“岁内未凿”明确当年没有施工。
- [ ] 主人已经许诺当年一定凿好
  理由：“然之”承认办法可行，工期并未约定。

提示：看看“然”之前客人说了什么，再看开渠的事后来办了没有。
解析：主人赞同这条渠可以灌东田的说法。他家缺人力，当年并没有开渠。
