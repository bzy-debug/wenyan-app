# 课文：一斗交给谁，夜行过了几更 {#cult51.3}
简介：看孟子谈“什一”，循柳宗元笔下的小溪辨水的哪一岸，再读一份夜间交粮的记录。

## 正文

孟子说“什一使自赋”，其中的“十”和“一”要按份数读：以十份计，取其中一份。这个比数没有说“每家必交一斗”，更不是历朝税率。若原文记食邑多少户，那是在数得享其赋入的户数，不能径当成某人收到的粮食斗数。

先认参照物，再解释地名：“水之阳”在水北，“山之阳”在山南，阴面则相反。地图的地名可能迁改；朝代和当地山水得一并核对。遇“二更”“四更”可先排同夜的早晚。要换算成今天的几点，须另有时制依据。古尺、里、斗也先用书中自己的单位读，不能随手补一个现代数。

## 知识点：以什一读赋入的份额 {#c51.s.tax}
义项：按基数、比数与缴纳对象理解田赋
领域：文化背景
要诀：先写原数，再写其中应交的一份。
讲解：“什一”是十取一，“自赋”说由他们自己缴纳。记户数与记多少斗粮不是一回事；精确换成今制，要另查时代和量器。
例句：c51.3.p.a

## 知识点：山南水北为阳 {#c51.s.bank}
义项：先定山水，再定阴阳所指的方位
领域：文化背景
要诀：看到阳，先追问“谁的阳”？
讲解：“溪在灌水之阳”，参照的是水，落点在北岸。“舍在山阴”用的是山，落点在北坡。不能把每个“阳”都朝一边画。
例句：c51.3.p.b

## 知识点：从所用量名判断能核到哪一步 {#c51.s.units}
义项：区别户数、里数、尺宽与容积，换成今制另须尺度
领域：文化背景
要诀：把数字连同所数的东西一起抄下。
讲解：食邑以户计，只说明享受哪些户的赋入；谷粟多少要另有实数。门宽以尺记、道里以里记，时代、地区和实物尺度不同，先别折算成现代长度。
例句：c51.3.p.d

## 知识点：循更次辨同夜先后 {#c51.s.watch}
义项：同一夜的更次用来排出早晚
领域：文化背景
要诀：先找是否同一夜，再比较第几更。
讲解：一夜通常分五更。若记录只给“三更”，仅据这段话便说是某一分某一秒，证据不够。
例句：c51.3.p.c

## 原文：教学例句 {#c51.3.p.c}
> 县有新约：“田入十斗者，纳一斗于仓。”谷熟，甲收六十斗。其家在山阳，仓在山阴。是夜二更发，四更乃至。
译文：县里有新约：“田里每收十斗，就向仓里交一斗。”谷熟后，甲收了六十斗。他家在山南，仓在山北。当夜二更出发，四更才到。
词注：纳：缴入。
  发：出发。

## 原文：教学例句 {#c51.3.p.d}
> 客记宿驿曰：“二更过津，三更雨作，未至驿。雨止方至。”又记津去驿三里，驿门广八尺，未言所用何尺。
译文：旅客记夜宿驿站，说：“二更过渡口；三更开始下雨，还没到驿站。雨停了才到。”他又记下渡口到驿站三里、驿门宽八尺，未说明用哪一种尺。
词注：驿：供传递公文、过往人员等歇息的设施。
  广：宽。

## 单选：“国中什一使自赋”若记作一条税则，哪种写法最合原句？ {#c51.3.q1}
考点：c51.s.tax
语境：c51.3.p.a

- [ ] 国都每十户选一户，免除全户赋税 {#c51.3.q1.o1}
  理由：“什一”标所取比例，没有选户或免税的话。
- [ ] 不论收多少，每户固定交一斗 {#c51.3.q1.o2}
  理由：原文没有一斗这样的定额。
- [x] 在国都内取十份中的一份，由当地人缴纳 {#c51.3.q1.o3}

提示：“什一”与“自赋”各说了什么？
解析：一是征取的比例，一是缴纳方式。“请”还标出这是建议，不能写成已经实施的全国定制。

## 单选：要画出愚溪的大致位置和流向，哪一笔可据这句话落下？ {#c51.3.q2}
考点：c51.s.bank
语境：c51.3.p.b

- [ ] 灌水南边画小溪，向东接入潇水 {#c51.3.q2.o1}
  理由：水之阳在北岸。
- [x] 灌水北边画小溪，向东接入潇水 {#c51.3.q2.o2}
- [ ] 潇水北边画灌水，向西接入小溪 {#c51.3.q2.o3}
  理由：“东流入于潇水”的主语是溪。

提示：“阳”紧跟哪个水名？“东流”的又是什么？
解析：位置以灌水为准，流向以溪为主。两个不同的参照能画出一张简明水系图。

## 单选：按这份县约，甲应把几斗送到哪里？ {#c51.3.q3}
考点：c51.s.tax
语境：c51.3.p.c

- [ ] 一斗送到甲家 {#c51.3.q3.o1}
  理由：约文不是每户定交一斗，方向也反了。
- [x] 六斗送入仓 {#c51.3.q3.o2}
- [ ] 六十斗全送入仓 {#c51.3.q3.o3}
  理由：“十斗者，纳一斗”只取一成。

提示：六十斗里有几个十斗？
解析：收数是六十斗，十取一得六斗；“纳……于仓”交代交粮的去处。这里无需先将斗折成现代单位。

## 单选：与“灌水之阳”对照，甲家和粮仓在山的哪两面？ {#c51.3.q4}
考点：c51.s.bank
语境：c51.3.p.c

- [x] 家在山南，仓在山北 {#c51.3.q4.o1}
- [ ] 家在山北，仓在山南 {#c51.3.q4.o2}
  理由：这里的参照是山，不能照搬水阳在北。
- [ ] 都在山南，只是仓更靠东 {#c51.3.q4.o3}
  理由：“山阴”与“山阳”已分开两面。

提示：同一个阳字，配的是水还是山？
解析：山南称阳，山北称阴；从家到仓，要从南面到北面。

## 单选：账簿另记“到仓时已是四更”，这与行程相合吗？ {#c51.3.q5}
考点：c51.s.watch
语境：c51.3.p.c

- [ ] 不合，四更必定在二更之前 {#c51.3.q5.o1}
  理由：同一夜的更序递增。
- [ ] 不合，隔了两更一定跨过两整天 {#c51.3.q5.o2}
  理由：更是夜间的分段。
- [x] 相合，二更出发、四更才到，同在这一夜 {#c51.3.q5.o3}

提示：“是夜”同时管住发与至。
解析：“二更发”定起点，“四更乃至”定抵达时段。写到这里即可，不必硬换成现代钟点。

## 单选：把“过渡口、开始下雨、到驿站”排顺，哪条与更次和“方”相合？ {#c51.3.q6}
考点：c51.s.watch
语境：c51.3.p.d

- [ ] 二更已到驿站，三更重过渡口 {#c51.3.q6.o1}
  理由：“未至驿”是三更雨起时的情形。
- [ ] 三更先过津，二更再遇雨 {#c51.3.q6.o2}
  理由：“二更过津”已经给定渡口的先后。
- [x] 二更过津，三更遇雨，雨止才到驿站 {#c51.3.q6.o3}

提示：同一夜先二更，再三更；“方至”还要等什么？
解析：两处更次定过津、遇雨的先后；最后一次抵达只能放在雨停之后。

## 单选：若替平阳侯记一笔收入，哪件事能从这里确定？ {#c51.3.q7}
考点：c51.s.units
语境：c51.3.p.e

- [ ] 每年收到一万零六百三十斗谷 {#c51.3.q7.o1}
  理由：“户”是计户，并非计谷。
- [x] 用于划定新食邑的是一万零六百三十户，每年实收谷数未载 {#c51.3.q7.o2}
- [ ] 在旧食邑之上，又多出一万零六百三十户，两处一并保留 {#c51.3.q7.o3}
  理由：“除前所食邑”说从前的那一处已经取消。

提示：数目落在“户”上；末句又怎样处理旧邑？
解析：汉廷按户数定食邑，平阳侯享其赋入。没有每户应纳和实收多少，不能把户数当作全年所得。

## 单选：给古驿画示意图，哪一种图注同时保住宽度、里程和材料的限度？ {#c51.3.q8}
考点：c51.s.units
语境：c51.3.p.d

- [x] 渡口距驿三里，门宽八尺；折成今制还须考当时当地的尺度 {#c51.3.q8.o1}
- [ ] 古尺一律与今尺相同，八尺可直接作今天的八尺 {#c51.3.q8.o2}
  理由：记载特地没给所用何尺，而且尺长历代有异。
- [ ] 三里是驿门的宽度，八尺是渡口到驿的水程 {#c51.3.q8.o3}
  理由：“津去驿”和“门广”各有不同的测量对象。

提示：先在数字旁各记“路程”还是“门宽”。
解析：沿用原单位可画出相对位置并记尺寸。要给现代米数，另查度量衡依据；这份记录单独算不出来。
