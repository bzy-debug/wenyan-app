# 检查：读一段祭告，再看两份地方记录 {#check.51}

## 原文：古籍引文 {#c51.check.p.a}
> 且在邦域之中矣，是社稷之臣也。何以伐为？
译文：何况颛臾已经在鲁国的疆域之内，是鲁国的臣属，为什么要攻打它呢？
词注：邦域：国家的疆域，此处指鲁国。
  是：这，指上文的颛臾。
出处：《论语·季氏》孔子论季氏将伐颛臾，节取反问
作者：孔子弟子及再传弟子

## 原文：教学例句 {#c51.check.p.b}
> 郡志录宋时二人事：“许生登第，未授官，归省亲。林生下第，亦归。”父老迎许生于水阴，未见，遣人渡水求之，果在阳岸。
译文：郡志记宋时两人：“许生考中，还没有授官，回家探亲。林生落榜，也回家。”父老在水的南岸迎许生，没见着，派人过河去找，果然在北岸。
词注：省亲：探望父母。
  下第：科举考试未获录取。

## 原文：教学例句 {#c51.check.p.c}
> 庄簿记：“岁收麦百斗，租什一，余入私廪。”运麦车至渡，二更水长，待至五更始济。护粮之兵车，御者持辔，车右执炬照岸。
译文：庄园账簿记着：“年收麦一百斗，租十取一，余下存入自家粮仓。”运麦车到渡口，二更时水涨，等到五更才过河。护送运麦的战车上，驾车的人拿着缰绳，车右举火把照岸。
词注：廪：粮仓。
  济：渡河。

## 单选：这里由“在邦域之中”推到“社稷之臣”，是在申明什么？ {#c51.check.q1}
考点：c51.s.altars
语境：c51.check.p.a

- [ ] 颛臾一方专门替人清扫祭坛 {#c51.check.q1.o1}
  理由：“邦域”“伐”讨论的是疆域与攻伐。
- [ ] 鲁国君主将亲自到颛臾祭谷神 {#c51.check.q1.o2}
  理由：本段没有交代赴祭。
- [x] 颛臾本是鲁国臣属，动兵缺少理由 {#c51.check.q1.o3}

提示：将“邦域”“臣”“伐”三个词串起来。
解析：“社稷”从国之所祀推到国家。“何以伐为”正反诘：对本国臣属，何以兴兵？

## 单选：两人一起归乡，郡志可为许生确认的履历是哪一项？ {#c51.check.q2}
考点：c51.s.exam
语境：c51.check.p.b

- [ ] 已经入仕，暂请假探亲 {#c51.check.q2.o1}
  理由：“未授官”正好排除此说。
- [x] 已考中，尚未得到具体官职 {#c51.check.q2.o2}
- [ ] 与林生一同落榜 {#c51.check.q2.o3}
  理由：林生下第；许生是登第。

提示：“登”和“下”各跟在谁的名字后面？
解析：两人归乡这件事相同，考试结果却不同。“未授官”又把许生考中与任职分成两步。

## 单选：父老最先在哪边等人，后来往哪边去找？ {#c51.check.q3}
考点：c51.s.bank
语境：c51.check.p.b

- [ ] 在水北等，渡到水南找 {#c51.check.q3.o1}
  理由：水北为阳，并非水阴。
- [x] 在水南等，渡到水北找 {#c51.check.q3.o2}
- [ ] 先在山北，再到山南 {#c51.check.q3.o3}
  理由：原文用水作参照，且明写渡水。

提示：起点叫“水阴”，终点叫“阳岸”。
解析：这次阴阳标两岸。把“渡水”也放回路线，方向就不必凭今日地名猜。

## 单选：仓吏想把古账输入新册。这份庄簿足以结出什么，又少了哪项换算依据？ {#c51.check.q4}
考点：c51.s.tax
语境：c51.check.p.c

- [x] 租麦十斗、自存九十斗；要换成今日公升，还缺当时斗的容量 {#c51.check.q4.o1}
- [ ] 租麦九十斗，其余十斗入仓 {#c51.check.q4.o2}
  理由：“租什一”指应交的一份。
- [ ] 租入十公升、自存九十公升，因为古斗等于现代公升 {#c51.check.q4.o3}
  理由：“斗”是古量名，没有时地和量器容量，不能直接改写成公升。

提示：先圈“百斗”，再圈“什一”。
解析：百斗的十分之一是十斗。所缴和留存都可以沿用同一量器的“斗”来核。

## 单选：渡口记录里，水涨到过河之间只可确定什么？ {#c51.check.q5}
考点：c51.s.watch
语境：c51.check.p.c

- [ ] 连续等了五个夜晚 {#c51.check.q5.o1}
  理由：这里是同一段夜间行程中的两个更次。
- [ ] 二更已渡完，五更才发现水涨 {#c51.check.q5.o2}
  理由：“始济”把实际过河放在五更。
- [x] 从二更等到五更，确切钟点未记 {#c51.check.q5.o3}

提示：分辨“水长”和“始济”各属于哪一更。
解析：“待至”承接水涨，叙事先候后渡。可核的是更次和先后，不宜再添几点几分。

## 找原文证据：有人以为照岸的人兼着驾车。哪一处分明另有人在掌缰？ {#c51.check.q6}
考点：c51.s.chariot
语境：c51.check.p.c

- [ ] 车右执炬照岸 {#c51.check.q6.o1}
  理由：这只说明谁举火照岸。
- [ ] 运麦车至渡 {#c51.check.q6.o2}
  理由：有车到来，未指明车上分工。
- [x] 御者持辔 {#c51.check.q6.o3}

提示：找出缰绳在哪个人手中。
解析：“御者”与“车右”分别搭配不同器具；这辆车上掌缰者与照路者各司其事。
