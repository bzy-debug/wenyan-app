# 课文：“举孝廉”和“举进士”，都考过试吗 {#cult51.1}
简介：把张衡和苏洵的经历各排成一行，区分谁在荐人、谁来延请、谁参加考试。

## 正文

张衡传里有三条来路。举孝廉，是地方举他；辟，是公府延请他去做事；朝廷特征，是皇帝闻其本领而召他。至于他接没接受、后来做了什么官，还要看“不行”“不就”“拜郎中”。李密《陈情表》的“察臣孝廉”“举臣秀才”也当从推荐读起。

到了北宋，“举进士再不中”写苏洵应进士考试，两次没考中。若把汉代的举孝廉比作这场考试，便凭空给张衡添了一张考卷。反过来，登第说的是考取；要把某个实职写进履历，还须见到授职的话。

## 知识点：察举、府辟与朝廷征召 {#c51.s.summon}
义项：从荐者或发命者分清入仕途径
领域：文化背景
要诀：为“举、辟、征、拜”各添一个施事者。
讲解：“连辟公府”是屡受公府延请；“公车特征，拜郎中”才明写朝廷特召并授官。一个动词不能把这两步全包。
例句：c51.1.p.a

## 知识点：从应举、登第读到授官 {#c51.s.exam}
义项：科举应试、考中和得到具体官职是不同记事
领域：文化背景
要诀：应、中、授各记一格，原文没写的留空。
讲解：在宋人的墓志里，“举进士”后还可接“不中”。登第证明考取；任县尉、主簿等须有下一条任命。
例句：c51.1.p.c

## 原文：古籍引文 {#c51.1.p.c}

## 原文：教学例句 {#c51.1.p.d}
> 宋人记其兄曰：“兄三举始登第。明年授某县尉，乃之县。”又记其友：“亦举进士，不第而归。”
译文：一位宋人记他的兄长说：“兄长应试三次才考中。次年受任某县县尉，才到县里去。”又记他的朋友说：“也参加进士考试，没有考中便回来了。”
词注：第：这里指科举考试录取。
  授：任命。

## 单选：张衡早年收到的两种邀约能否记作“两度入官”？ {#c51.1.q1}
考点：c51.s.summon
语境：c51.1.p.a

- [ ] 可以，孝廉、公府就是他当时的两个官名 {#c51.1.q1.o1}
  理由：“公府”是延请他的官署，“孝廉”是察举科目。
- [ ] 不能，因为两次科举考试他都落榜 {#c51.1.q1.o2}
  理由：“不行”“不就”说没有赴任，没有落第的记载。
- [x] 不能，地方荐举和公府延请，他都未去 {#c51.1.q1.o3}

提示：问一问“不”字管的是考取还是赴请。
解析：地方的“举”和府署的“辟”是不同途径。下文另记朝廷“拜郎中”，到那里才可确记受官。

## 找原文证据：若要证明某些府署曾想请张衡入府办事，应抄哪句？ {#c51.1.q2}
考点：c51.s.summon
语境：c51.1.p.a

- [ ] 举孝廉 {#c51.1.q2.o1}
  理由：这是受地方荐举。
- [x] 连辟公府 {#c51.1.q2.o2}
- [ ] 永元中 {#c51.1.q2.o3}
  理由：这只标出发生的大致时期。

提示：找出发出邀请的官署。
解析：“连”说多次，“辟”说延请，“公府”交代这次聘请来自哪里。

## 单选：朝廷召张衡之后，这次确已授职的证据是什么？ {#c51.1.q3}
考点：c51.s.summon
语境：c51.1.p.b

- [ ] “安帝雅闻”，皇帝早已听说他 {#c51.1.q3.o1}
  理由：知道他的本领与授官是两件事。
- [x] “拜郎中”，明写授给的官名 {#c51.1.q3.o2}
- [ ] “善术学”，他擅长这门学问 {#c51.1.q3.o3}
  理由：这是被召的理由，尚非任命。

提示：哪个动词后面紧跟一个官名？
解析：征召之外，传记特写“拜郎中”。只引前半句会漏掉确任的根据。

## 单选：苏洵“举进士再不中”，应如何概括这两次经历？ {#c51.1.q4}
考点：c51.s.exam
语境：c51.1.p.c

- [x] 两度应进士考试，未获录取 {#c51.1.q4.o1}
- [ ] 两度获授进士官职而婉拒 {#c51.1.q4.o2}
  理由：“不中”说明考试结果，没说授官。
- [ ] 两度被举孝廉而没有就任 {#c51.1.q4.o3}
  理由：宋代此处明说进士，而且“中”与考试相应。

提示：把“举”同后面的“中”一起读。
解析：“举进士”在这里是应试。“再不中”给出两次结果，恰能排除“已取得功名”的误会。

## 找原文证据：苏洵换一个科目应试也没考中，原文哪句写了这件事？ {#c51.1.q5}
考点：c51.s.exam
语境：c51.1.p.c

- [ ] 举进士再不中 {#c51.1.q5.o1}
  理由：这里仍说原先参加的进士考试。
- [ ] 退而叹曰 {#c51.1.q5.o2}
  理由：这是之后的反应。
- [x] 又举茂才异等不中 {#c51.1.q5.o3}

提示：留心“又”以后多了什么科名。
解析：“又举”承原来的应试，“茂才异等”标出所换科目，“不中”再说明结果。

## 找原文证据：哪一处能证明此次是朝廷特别召张衡，并非某位府主自行请他？ {#c51.1.q6}
考点：c51.s.summon
语境：c51.1.p.b

  理由：有本领只能说明缘由。
- [ ] 郎中 {#c51.1.q6.o2}

解析：在安帝闻名的背景下，“公车特征”明确写出朝廷的征命。

## 单选：要写“兄长何时有了这项具体职务”，哪一栏有据？ {#c51.1.q7}
考点：c51.s.exam
语境：c51.1.p.d

- [ ] 第三次应考之日就到县履职 {#c51.1.q7.o1}
  理由：“明年授”将任命另记在次年。
- [x] 登第后第二年，任县尉 {#c51.1.q7.o2}
- [ ] 第一次应试就获派到县里 {#c51.1.q7.o3}
  理由：三举才登第，“乃之县”又更晚。

提示：注意“登第”和“授”中间的时间词。
解析：考中、授官、赴县依次叙述。“明年”接在登第之后，县尉才是具体职名。

## 找原文证据：朋友有应试经历，却未被录取，原文哪几个字最直接？ {#c51.1.q8}
考点：c51.s.exam
语境：c51.1.p.d

- [x] 不第而归 {#c51.1.q8.o1}
- [ ] 亦举进士 {#c51.1.q8.o2}
  理由：这是去应试，还不知道结果。
- [ ] 始登第 {#c51.1.q8.o3}
  理由：这是前面记兄长的话。

提示：先看指的是兄长还是朋友。
解析：朋友这一句止于“不第而归”，不能从兄长获授县尉推到他身上。
