# 课文：社稷是谁在守，战车是谁在驾 {#cult51.2}
简介：同是大臣和将领，先分清他们守护什么，再看战车上的分工。
回读：c51.s.summon c51.2.p.c

## 正文

宗庙是祭祖之所，社、稷关乎土神与谷神的祭祀。读“危社稷”“社稷之臣”时，危及的是国家，责问的是臣下能不能为国尽职；读到祭品、旱涝、祭祀的时日，字面上的祭事又十分要紧。

鞍之战列人很快，“邴夏御齐侯，逢丑父为右”，一人驾车，一人在车右护卫。车右也叫戎右；并非所有乘车的人都执辔。要辨谁在驾车，跟住“御”以及谁手持缰绳。

## 知识点：宗庙社稷在祭事与国事中所指不同 {#c51.s.altars}
义项：以所奉之祭与所论安危辨礼制名物
领域：文化背景
要诀：看作者在说祭祖、备祭品，还是说存亡与臣职。
讲解：祭祖与宗庙相连，牲畜谷物可用于祭社稷。“社稷之臣”中的“社稷”却不能只当成一处建筑，要放回国家安危去读。
例句：c51.2.p.a

## 知识点：御者与车右的分工 {#c51.s.chariot}
义项：御者驾车，车右在车上护卫
领域：文化背景
要诀：先找驾车的动词，再分其余人的位置。
讲解：读“某御某，某为右”时，前一个人御车，第二个名字是车上所载之人；末一个名字有“为右”另作标记。
例句：c51.2.p.b

## 原文：教学例句 {#c51.2.p.c}
> 府辟陈生为掾。生服齐衰，未就。服除，府复辟之，使从行。车陷于泥，生执辔御之，车右下推，乃出。
译文：府署延请陈生为属吏。陈生正在服丧，没有前往。服丧期满，府署再次延请他，让他随行。车陷在泥里，陈生执缰驾车，车右下来推车，这才脱困。
词注：掾：属吏。
  辔：驾驭牲口的缰绳。

## 单选：项羽说宋义“非社稷之臣”，这句话具体责备他什么？ {#c51.2.q1}
考点：c51.s.altars
语境：c51.2.p.a

- [ ] 守庙时忘记清扫祭器 {#c51.2.q1.o1}
  理由：整段讲兵事，没有祭器。
- [ ] 自称是国君，不肯作臣子 {#c51.2.q1.o2}
  理由：“非……之臣”是项羽的批评，没有夺君位的话。
- [x] 国家安危在眼前，却只顾私事而不顾士卒 {#c51.2.q1.o3}

提示：把它和“国家安危”对起来。
解析：社稷在这里代指国家。“不恤士卒而徇其私”点明宋义没尽到哪一份责任。

## 单选：若各找一名齐、晋车上的驾车人，应写谁？ {#c51.2.q2}
考点：c51.s.chariot
语境：c51.2.p.b

- [ ] 齐逢丑父、晋郑丘缓 {#c51.2.q2.o1}
  理由：这两人都标成“为右”。
- [x] 齐邴夏、晋解张 {#c51.2.q2.o2}
- [ ] 齐侯、郤克 {#c51.2.q2.o3}
  理由：他们在“御”的后面，由别人为他们驾车。

提示：两组句子的用字和顺序几乎一样。
解析：先取两个“御”字前的人名，再分别对上齐、晋。全段四个动词正好分出两组驾车者和车右。

## 找原文证据：想记下晋方车右的姓名与职分，应选哪一处？ {#c51.2.q3}
考点：c51.s.chariot
语境：c51.2.p.b

- [ ] 晋解张御郤克 {#c51.2.q3.o1}
  理由：这是晋方御者与所载之人。
- [x] 郑丘缓为右 {#c51.2.q3.o2}
- [ ] 逢丑父为右 {#c51.2.q3.o3}
  理由：他在前面齐方一组。

提示：先对所属的一方，再看“为右”。
解析：原文是平行写法。逢丑父对郑丘缓，两人护的是不同的车。

## 单选：这次车陷泥中，缰绳握在谁手上，下来推的又是谁？ {#c51.2.q4}
考点：c51.s.chariot
语境：c51.2.p.c

- [x] 陈生执缰，车右下来推 {#c51.2.q4.o1}
- [ ] 车右执缰，陈生在地上推 {#c51.2.q4.o2}
  理由：“生执辔”直接说明谁掌缰。
- [ ] 两人都是御者，轮流下来推 {#c51.2.q4.o3}
  理由：“车右下推”另标一人的职分。

提示：要分的是两个人，不只是两件差事。
解析：执辔是驾车的实证；下车推车是车右临时做的事，不能因此把他的职分改作御者。

## 单选：怎样把“府辟”“服齐衰”“服除”合成陈生的一段履历？ {#c51.2.q5}
考点：c51.s.summon
语境：c51.2.p.c

- [ ] 先受朝廷征召参加考试，换好官服才入场 {#c51.2.q5.o1}
  理由：这是府辟，没有考场；齐衰是丧服。
- [ ] 最初便入府就任，后来才穿齐衰随车出发 {#c51.2.q5.o2}
  理由：“未就”和“服除”先后分明，出发时服期已经结束。
- [x] 初受府署延请时正在居丧，服期已毕再获延请才随行 {#c51.2.q5.o3}

提示：先分哪一方延请，再看两次邀请中隔着什么。
解析：府署两次发出延请。齐衰提示人在服丧，“服除”标明后来才可应请；两条线索共同解释了这次赴职。

## 单选：这一段两次说“变置”。前一次要换谁，后一次涉及什么？ {#c51.2.q6}
考点：c51.s.altars
语境：c51.2.p.d

- [ ] 两次都要换百姓，免得再出灾荒 {#c51.2.q6.o1}
  理由：前句的责任在诸侯；后句说的是祭祀与灾变。
- [ ] 两次都只换祭品 {#c51.2.q6.o2}
  理由：第一次明说“诸侯危社稷”；后文祭品也已合礼。
- [x] 先换危害国家的诸侯，后改置受祭的社稷 {#c51.2.q6.o3}

提示：前一次紧承哪个人？后一次前面列了哪些祭事？
解析：孟子先谈危国的君主，又设祭已尽礼而仍旱涝的情形。两个“社稷”有联系，落在句中的轻重不同。

## 找原文证据：不看陈生的官称，仍能判定他正在驾车。证据是哪一处？ {#c51.2.q8}
考点：c51.s.chariot
语境：c51.2.p.c

- [x] 生执辔御之 {#c51.2.q8.o1}
- [ ] 使从行 {#c51.2.q8.o2}
  理由：只说跟着队伍走。
- [ ] 车右下推 {#c51.2.q8.o3}
  理由：这是另一个人在车外所做的事。

提示：找缰绳以及操车的动词。
解析：“执辔”明写工具，“御之”说明操控的是车，两处互相印证。
