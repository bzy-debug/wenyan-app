# 检查：人情与往来综合练习 {#check.24}

## 原文：教学例句 {#p.vocab.check.24.1}
> 父故自远至。子代父迎之，厚之以酒食。客指壁间旧画，述昔与父同观之事。
译文：父亲的旧友从远方到来。儿子代父迎接，用酒食款待他。客人指着墙上的旧画，讲从前与父亲一同赏画的事。

## 找原文证据：哪处说明客人与父亲早就相识？ {#q.vocab.check.24.1}
考点：skill.vocab.10.2
语境：p.vocab.check.24.1

- [ ] 自远至 {#q.vocab.check.24.1.o1}
  理由：这是来路远近。
- [ ] 壁间旧画 {#q.vocab.check.24.1.o2}
  理由：仅有旧画尚不能证明相识。
- [x] 昔与父同观 {#q.vocab.check.24.1.o3}

提示：可试问两人原先是否相识。
解析：共同赏画是两人过去的交往。

## 单选：“厚之以酒食”是怎样待客？ {#q.vocab.check.24.2}
考点：skill.vocab.10.4
语境：p.vocab.check.24.1

- [ ] 给食物称重 {#q.vocab.check.24.2.o1}
  理由：“之”指客人。
- [x] 拿酒食殷勤款待 {#q.vocab.check.24.2.o2}
- [ ] 把旧画卖给客人 {#q.vocab.check.24.2.o3}
  理由：末句只写观画。

提示：若后面带人，看看怎样对待这个人。
解析：“以酒食”说明款待所用之物。

## 原文：教学例句 {#p.vocab.check.24.2}
> 农假锄于邻，负之往田。日暮返锄，邻复以瓜遗之。
译文：农人向邻居借锄，背着它到田里去。日暮还锄，邻居又送给他瓜。

## 单选：哪一样东西只是借来使用？ {#q.vocab.check.24.3}
考点：skill.vocab.11.3
语境：p.vocab.check.24.2

- [ ] 田 {#q.vocab.check.24.3.o1}
  理由：田是去处。
- [ ] 瓜 {#q.vocab.check.24.3.o2}
  理由：瓜由邻人赠送。
- [x] 锄 {#q.vocab.check.24.3.o3}

提示：找借用之后须退还的迹象。
解析：“假锄”与“返锄”首尾相应。

## 单选：哪一动作改变了瓜的归属？ {#q.vocab.check.24.4}
考点：skill.vocab.11.1
语境：p.vocab.check.24.2

- [x] 邻人赠瓜给农人 {#q.vocab.check.24.4.o1}
- [ ] 农人背瓜去田 {#q.vocab.check.24.4.o2}
  理由：他背的是锄。
- [ ] 农人把瓜还给邻人 {#q.vocab.check.24.4.o3}
  理由：返还的是借来的锄。

提示：读 wèi；留意赠者、受者与礼物。
解析：末句“以瓜遗之”以农人为受赠者。

## 原文：教学例句 {#p.vocab.check.24.3}
> 士省母，途遇旧邻，闻其家失火。归取布帛，周之；明日乃至母舍。
译文：士人去探望母亲，路上碰见从前的邻居，听说他家失火。士人回去取布帛接济邻居，第二天才到母亲家。
