# 检查：访旧友、借锄头、送布帛 {#check.24}

## 原文：教学例句 {#p.vocab.check.24.1}
> 父故自远至。子代父迎之，厚之以酒食。客指壁间旧画，述昔与父同观之事。
译文：父亲的旧友从远方到来。儿子代父迎接，用酒食款待他。客人指着墙上的旧画，讲从前与父亲一同赏画的事。

## 找原文证据：哪处说明客人与父亲早就相识？ {#q.vocab.check.24.1}
考点：skill.vocab.10.2
语境：p.vocab.check.24.1

- [ ] 自远至 {#q.vocab.check.24.1.o1}
  理由：这是来路远近。
- [ ] 壁间旧画 {#q.vocab.check.24.1.o2}
  理由：仅有旧画尚不能证明相识。
- [x] 昔与父同观 {#q.vocab.check.24.1.o3}

提示：听来客谈旧画，哪几个字表明当年有两个人一起观看？
解析：“昔与父同观”说来客从前曾和父亲一起赏画，两人早有交情。

## 单选：“厚之以酒食”是怎样待客？ {#q.vocab.check.24.2}
考点：skill.vocab.10.4
语境：p.vocab.check.24.1

- [ ] 给食物称重 {#q.vocab.check.24.2.o1}
  理由：“之”指客人。
- [x] 拿酒食殷勤款待 {#q.vocab.check.24.2.o2}
- [ ] 把旧画卖给客人 {#q.vocab.check.24.2.o3}
  理由：末句只写观画。

提示：父亲的旧友由儿子迎进屋。儿子拿什么招待他？
解析：儿子拿出酒食款待父亲的旧友，这正是原文说的“厚”。

## 原文：教学例句 {#p.vocab.check.24.2}
> 农假锄于邻，负之往田。日暮返锄，邻复以瓜遗之。
译文：农人向邻居借锄，背着它到田里去。日暮还锄，邻居又送给他瓜。

## 单选：哪一样东西只是借来使用？ {#q.vocab.check.24.3}
考点：skill.vocab.11.3
语境：p.vocab.check.24.2

- [ ] 田 {#q.vocab.check.24.3.o1}
  理由：田是去处。
- [ ] 瓜 {#q.vocab.check.24.3.o2}
  理由：瓜由邻人赠送。
- [x] 锄 {#q.vocab.check.24.3.o3}

提示：看哪一样东西用完还给了原主。
解析：农人早上借锄，傍晚还锄。瓜则是后来收到的礼物。

## 单选：还过锄头，那只瓜又从谁手里到了谁手里？ {#q.vocab.check.24.4}
考点：skill.vocab.11.1
语境：p.vocab.check.24.2

- [x] 邻人赠瓜给农人 {#q.vocab.check.24.4.o1}
- [ ] 农人背瓜去田 {#q.vocab.check.24.4.o2}
  理由：他背的是锄。
- [ ] 农人把瓜还给邻人 {#q.vocab.check.24.4.o3}
  理由：农人归还的是锄。后一句换邻人作主语，又写赠瓜这件事。

提示：“返锄”到此结束前一件事，再读邻人的新动作。
解析：邻人“以瓜遗之”，把瓜送给了农人。瓜归受赠的人。

## 原文：教学例句 {#p.vocab.check.24.3}
> 士省母，途遇旧邻，闻其家失火。归取布帛，周之；明日乃至母舍。
译文：士人去探望母亲，路上碰见从前的邻居，听说他家失火。士人回去取布帛接济邻居，第二天才到母亲家。

## 单选：士人原先为何出门？ {#q.vocab.check.24.5}
考点：skill.vocab.12.2
语境：p.vocab.check.24.3

- [x] 探望母亲 {#q.vocab.check.24.5.o1}
- [ ] 调查火灾 {#q.vocab.check.24.5.o2}
  理由：遇邻时才听说火灾。
- [ ] 向邻人借布 {#q.vocab.check.24.5.o3}
  理由：他自己取布给邻人。

提示：遇见旧邻之前，他已经有了什么行程？
解析：士人本来出门去看望母亲，路上才得知邻人家里失火。

## 单选：“周之”中的帮助落到了谁身上？ {#q.vocab.check.24.6}
考点：skill.vocab.12.4
语境：p.vocab.check.24.3

- [x] 失火的旧邻 {#q.vocab.check.24.6.o1}
- [ ] 士人自己 {#q.vocab.check.24.6.o2}
  理由：取布者是救助人。
- [ ] 等他到来的母亲 {#q.vocab.check.24.6.o3}
  理由：次日才到母舍。

提示：他听到火灾的消息才折回去取布，是想帮谁？
解析：失火的是旧邻，得布帛接济的也是这位邻人。
