# 检查：路上相逢，家门相助 {#check.24}

## 原文：教学例句 {#p.vocab.check.24.new1}
> 客行遇故，执手言少时共学事。其夜宿故人家；故人以旧砚遗之，曰：“留为别后之识。”
译文：客人路上遇见老朋友，两人拉着手说起小时候同学的事。那晚他住在老朋友家，朋友送他一方旧砚，说留着作分别后的纪念。
词注：执手：握住手
  识：读 zhì，标记、记念。

## 找原文证据：客人在路上遇见了谁？选出他们谈起的那件往事，据此判断两人的关系。 {#q.vocab.check.24.new1}
考点：skill.vocab.10.2
语境：p.vocab.check.24.new1

- [ ] 客行 {#q.vocab.check.24.new1.o1}
  理由：单说客人出行，不能确定途中遇见的是谁。
- [ ] 以旧砚遗之 {#q.vocab.check.24.new1.o2}
  理由：这是眼下送别的一件事，不是两人回忆的旧事。
- [x] 少时共学 {#q.vocab.check.24.new1.o3}

提示：找两个人早年一起做的事。
解析：“少时共学”补明往日交情，这才可以把“故”直接读作故人。

## 单选：这方砚后来归谁？据“遗之”和赠言来答。 {#q.vocab.check.24.new2}
考点：skill.vocab.11.1
语境：p.vocab.check.24.new1

- [x] 归客人，可以带走作纪念 {#q.vocab.check.24.new2.o1}
- [ ] 归老朋友，客人写完必须还 {#q.vocab.check.24.new2.o2}
  理由：“留为别后之识”是让客人留着，没约归期。
- [ ] 主人遗失了砚，等客人帮忙找 {#q.vocab.check.24.new2.o3}
  理由：“以旧砚遗之”把客人写成受赠者，东西在主人手里有意交出。

提示：把“留为”同“约某日归还”比较。
解析：这里“遗”读 wèi，是赠送。物品所有者的嘱咐排除了借用和遗失两个读法。

## 原文：教学例句 {#p.vocab.check.24.new2}
> 邻家乏牛，假牛于田翁，耕毕即归。翁家有余种，又贷二斛与邻，约秋成乃偿。
译文：邻家缺牛，向老农借牛，耕完即归还。老农家有多余的种粮，又借出两斛给邻家，约定秋收之后才偿还。
词注：乏：缺少
  斛：古代容量单位。

## 单选：“假牛于田翁”，从谁这一边写借牛？ {#q.vocab.check.24.new3}
考点：skill.vocab.11.3
语境：p.vocab.check.24.new2

- [ ] 写邻家把自己的牛送给老农 {#q.vocab.check.24.new3.o1}
  理由：“耕毕即归”说明邻家用完要还。
- [x] 写邻家从老农那里借进一头牛 {#q.vocab.check.24.new3.o2}
- [ ] 写老农向邻家借牛 {#q.vocab.check.24.new3.o3}
  理由：缺牛的是邻家，老农出牛。

提示：把“于田翁”和前面的“邻家乏牛”连起来。
解析：借入的是牛。“假”所写的使用者是邻家，“于田翁”交代向谁借入。

## 找原文证据：到秋收时邻家还得做什么？选出原文里的约定，用它判断老农怎样处置种粮。 {#q.vocab.check.24.new4}
考点：skill.vocab.11.4
语境：p.vocab.check.24.new2

- [ ] 翁家有余种 {#q.vocab.check.24.new4.o1}
  理由：有富余只能说明为什么有粮可分，不能决定白送还是出借。
- [ ] 耕毕即归 {#q.vocab.check.24.new4.o2}
  理由：这也是归还，不过约的是耕完还牛，没有说种粮何时偿还。
- [x] 约秋成乃偿 {#q.vocab.check.24.new4.o3}

提示：找一句写秋收之后双方还要履行什么约定。
解析：老农借出，邻家秋后要还；这与上文耕完立即还牛有相同的借还关系。

## 原文：教学例句 {#p.vocab.check.24.new3}
> 女闻父病，归省之，数日不去。闻邻媪亦病，遂携汤往问，候其安而后归。
译文：女儿听说父亲生病，回家探望，几天没离去。听说邻家老妇也病了，就带着汤去探望，等她安稳了才回来。
词注：媪：老年妇女
  候：等候、看望。

## 单选：“归省之”说她回来做什么？ {#q.vocab.check.24.new5}
考点：skill.vocab.12.2
语境：p.vocab.check.24.new3

- [x] 回家看望患病的父亲 {#q.vocab.check.24.new5.o1}
- [ ] 回家反省自己做错的事 {#q.vocab.check.24.new5.o2}
  理由：前句给出的原因是“父病”，没有提她犯过错。
- [ ] 省下路费，好为邻妇买药 {#q.vocab.check.24.new5.o3}
  理由：“之”接父亲，是她要探望的人。

提示：先找代词“之”接的是前面的谁。
解析：“省”在这里读 xǐng。“父病”是她回家的缘由，“数日不去”说明她留在父亲身边。

## 单选：把“往问”记入村志，怎样才能交代女儿为什么到了邻家？ {#q.vocab.check.24.new6}
考点：skill.vocab.12.1
语境：p.vocab.check.24.new3

- [ ] 去查问老妇是否偷偷拿了汤 {#q.vocab.check.24.new6.o1}
  理由：汤是女儿自己带去的，起因是邻媪生病。
- [x] 带汤去慰问患病的老妇，等她安稳才离开 {#q.vocab.check.24.new6.o2}
- [ ] 去向老妇打听父亲病势，问完就走 {#q.vocab.check.24.new6.o3}
  理由：写父亲的事在“闻邻媪亦病”之前，女儿这次还留下来等老妇安顿。

提示：想想女儿带去的东西，再看“候其安”中的人是谁。
解析：“问”的对象是病中的邻媪。女儿带汤前去、等她安稳才走，把“问”读成慰问、探视，前后的举动便相合。
