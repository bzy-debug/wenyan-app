# 课文：李广等士卒喝完水，司马迁亲眼看见了什么？ {#l4.8}
简介：把军中的轶事、史家的亲见和百姓的谚语分开，看三类材料如何合写一个人。

## 正文

在缺粮断水的地方，水找到了，李广却“不近水”。究竟为什么？读“士卒不尽饮”，以全队是否喝到水作界线。仅说“李广爱兵”还看不出这件事要付什么代价；等到他自己也须候着，宽厚才有值得记的一笔。

后段换成太史公的声音。第一条证据来自书中的话，第二条由“余睹”担保：他亲眼见过李广朴实少言的样子。“及死之日”以后概述众人哀悼，不能把“余睹”的范围扩大成天下每个人的反应都经他目验。读史传，不妨在心里给这些话换不同的引号。

末句再加一条没署个人姓名的谚语。桃李不开口招人，树下仍会让人走出小路。要把这个比喻接回李广，既要保住“不言”的寡辞，也要保住“成蹊”的感召。少一端，比方都会失去一半用处。

## 知识点：用行动次序解释人物品格 {#skill.l4.8.a}
义项：辨认在困境中谁先谁后，推知人物为别人承担的代价
领域：阅读技能
要诀：先问水找到了没有，再问此刻李广已经能喝了吗。
讲解：“士卒不尽饮，广不近水”把李广放进同样的缺水处境，仍将先取之便让给士兵，比一声赞语多了可检验的行动。
例句：p.l4.8.a

## 知识点：给史家的每种材料标出处 {#skill.l4.8.b}
义项：区分亲见、叙事总括、引语与谚语，并限制各自所能证明的事
领域：篇章
要诀：从“《传》曰”“余睹”“谚曰”三个开头读。
讲解：太史公凭亲见写将军寡言，凭群体反应概述其得人，末了借桃李之谚说明人的品行何以无言而有感召。
例句：p.l4.8.b

## 原文：古籍引文 {#p.l4.8.a}
> 广之将兵，乏绝之处，见水，士卒不尽饮，广不近水；士卒不尽食，广不尝食。宽缓不苛，士以此爱乐为用。
译文：李广带兵到了缺粮少水的地方，发现水源，只要士卒尚未全都喝上水，他便不走近水边；士卒还没有全吃上饭，他也不开口尝。待人宽厚，从不苛刻，士卒因此爱戴他，乐意为他效力。
词注：将兵：“将”读 jiàng，率领军队。
  乏绝：供应匮乏以至断绝。
  不苛：对部下不苛刻。

## 原文：古籍引文 {#p.l4.8.b}
> 太史公曰：《传》曰：“其身正，不令而行；其身不正，虽令不从。”其李将军之谓也？余睹李将军悛悛如鄙人，口不能道辞。及死之日，天下知与不知，皆为尽哀。彼其忠实心诚信于士大夫也？谚曰：“桃李不言，下自成蹊。”此言虽小，可以谕大也。
译文：太史公说：古书讲，自身端正，不用下令别人也跟从；自身不正，纵然发令也没人听从。大概就是在说李将军吧？我见将军朴实得像个乡人，说不出漂亮话。等他去世，认识或不认识他的人都为他哀伤。也许是他那忠厚诚实的心取得了士大夫的信任吧？俗谚说桃李不会招呼人，树下自会踏出一条小路。这是寻常小事，却可用来说明更大的道理。
词注：睹：亲眼见到。
  鄙人：乡野之人，这里用来形容将军外表朴实。
  蹊：小路。

## 找原文证据：队伍陷在缺粮少水的地方，哪处最能证明李广自己也受同一条饮水次序约束？ {#q.l4.8.1}
考点：skill.l4.8.a
语境：p.l4.8.a

- [ ] 见水 {#q.l4.8.1.o1}
  理由：这只交代水已经找到。
- [x] 士卒不尽饮，广不近水 {#q.l4.8.1.o2}
- [ ] 宽缓不苛 {#q.l4.8.1.o3}
  理由：这是一句总评，没写他本人怎样做。

提示：找同一句里同时出现“士卒”和“广”的地方。
解析：见到水还要等，是将领取水机会让给士兵。这个限制落在自己身上，关怀才有行动可查。

## 单选：“士以此爱乐为用”是怎样一种话？ {#q.l4.8.2}
考点：skill.l4.8.b
语境：p.l4.8.a

- [ ] 引录一位士兵在饮水时说过的话 {#q.l4.8.2.o1}
  理由：没有人称、引号或发言情境支持这一说法。
- [x] 叙述中概括士卒反应，并用“此”把反应接回上文 {#q.l4.8.2.o2}
- [ ] 后人用桃李作的一句谚语 {#q.l4.8.2.o3}
  理由：谚语在另一段“太史公曰”中。

提示：如果“此”要指前文，前面有什么做法可指？
解析：不抢先吃喝、待人宽和，合起来解释士卒为何愿为他出力。这是传记所给的解释。

## 单选：把“士卒不尽食”读成“只要有一个士兵没吃完自己的食物，将军便永不能进食”，哪里说得过满？ {#q.l4.8.3}
考点：skill.l4.8.a
语境：p.l4.8.a

- [x] 段中强调要让士卒都先得到饮食，未写一套逐口监察的军规 {#q.l4.8.3.o1}
- [ ] 这句意思仅限军粮耗尽，若有水源便不再适用 {#q.l4.8.3.o2}
  理由：两组话都从困境里仍有水食可分写起，焦点在如何分。
- [ ] 这句话与饮水次序全无关系 {#q.l4.8.3.o3}
  理由：两句结构成对，正可互相解释。

提示：用“见水”一组对读“不尽食”一组。
解析：史家在行军困境中选两个日常动作写品格。关于每口饭怎样监管的细则，段中没有交代。

## 单选：若把前半段换成“李广爱兵，士兵也爱他”，最先失去的是什么？ {#q.l4.8.4}
考点：skill.l4.8.b
语境：p.l4.8.a

- [ ] 史家对全体士卒人数的统计 {#q.l4.8.4.o1}
  理由：原文没有统计人数。
- [ ] 司马迁在军中亲见李广取水的声明 {#q.l4.8.4.o2}
  理由：这里只叙其带兵的习惯，未以“余睹”担保这件事。
- [x] 一项读者能在具体处境里检验的行动证据 {#q.l4.8.4.o3}

提示：想一想少水时谁能先喝，比“爱”字多告诉我们什么。
解析：宽厚本可是一句空评。待士卒之后才动水食，让读者看到这位将领愿意自己付出什么。

## 单选：“余睹李将军悛悛如鄙人”同“不令而行”放在一起，并不矛盾，为什么？ {#q.l4.8.5}
考点：skill.l4.8.a
语境：p.l4.8.b

- [ ] “鄙人”断定李广是品行卑劣的人，恰好需要严令 {#q.l4.8.5.o1}
  理由：紧接“口不能道辞”，着眼不善辞令。
- [x] 前者写本人寡言朴实，后者看他能否用身教使人相从 {#q.l4.8.5.o2}
- [ ] 史家因见其寡言，推断他的士卒只靠严令才肯听从 {#q.l4.8.5.o3}
  理由：所引的是“其身正，不令而行”，方向正好相反。

提示：把“余睹”所见的举止同格言中的“身”相照。
解析：史家看见的并非一位巧辩者，正因如此，他才转问人们对李广的信重从何而来。

## 找原文证据：要给“史家亲眼见过”标一条引文，哪一条能直接使用？ {#q.l4.8.6}
考点：skill.l4.8.b
语境：p.l4.8.b

- [ ] 天下知与不知，皆为尽哀 {#q.l4.8.6.o1}
  理由：这里概述死后的哀悼，没有说作者逐一到场。
- [x] 余睹李将军悛悛如鄙人 {#q.l4.8.6.o2}
- [ ] 桃李不言，下自成蹊 {#q.l4.8.6.o3}
  理由：“谚曰”表明这是大众流传的话。

提示：找能同时指出观察者和观察对象的原话。
解析：“余睹”担保的是后面这段外貌举止。引书、记民间反应、引谚都有各自的来源。

## 单选：桃李树下有人走出小路，最能照应前文哪两个相连的现象？ {#q.l4.8.7}
考点：skill.l4.8.a
语境：p.l4.8.b

- [ ] 桃李象征死后才获的功名，小路只指将军曾经走过的行军路线 {#q.l4.8.7.o1}
  理由：“下自成蹊”的要点是有人不断前来；眼前一段讲大家为将军尽哀。
- [ ] 李广生前从未讲话，死后才得到官府褒奖 {#q.l4.8.7.o2}
  理由：“口不能道辞”指不善辞令，褒奖也未在这里提到。
- [x] 本人不善言辞，人们却自然愿意亲近并哀悼他 {#q.l4.8.7.o3}

提示：分别给“不言”和“成蹊”在李广身上各找一个着落。
解析：比喻不能只对上一个词。树不自招人对应将军的质朴，路自然形成对应众人被他的为人打动。

## 排序：按论赞出现的次序标三种材料。 {#q.l4.8.8}
考点：skill.l4.8.b
语境：p.l4.8.b

- [1] 先引《传》里关于身教的话 {#q.l4.8.8.o1}
  理由：“《传》曰”在论赞起头。
- [3] 末引桃李之谚，为前文的大小两端作比 {#q.l4.8.8.o2}
  理由：“此言虽小”紧随“谚曰”。
- [2] 再说自己见到的李广和他死后人们的反应 {#q.l4.8.8.o3}
  理由：“余睹”之后才写众人尽哀。

提示：先看两个“曰”各由谁领起，中间找“余”。
解析：材料来自格言、见闻、谚语。它们合力说明同一人，承担的证明作用并不相同。
