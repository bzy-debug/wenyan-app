# 课文：李广怎样待士卒，司马迁怎样评他 {#l4.8}
简介：先看李广和士卒谁先饮水，再听司马迁说自己见过怎样的李广。

## 正文

队伍到了缺粮少水的地方，终于看见水，谁先喝？再往下读，谁先吃？两个“不尽”很要紧：士卒还没有全喝上、吃上，李广就不先动。只说“他们一起吃喝”，会漏掉士卒为什么愿意为他效力。

到“太史公曰”，写法变了。司马迁先引古书，然后才说“余睹”，写自己所见的李广朴实、不善言辞。再往下，写众人悼念，引桃李不言的谚语。亲眼见过一个人，说这个人身后受到怎样的爱戴，拿一句谚语来比，三者要各按各的读。

## 知识点：从行为次序推知品格 {#skill.l4.8.a}
义项：从人物做过的事、旁人对他的反应，看评价有没有根据
领域：阅读技能
要诀：先找士卒与李广谁先喝、谁先吃。
讲解：“士卒不尽饮，广不近水”把两个人的先后写得很清楚。懂得他怎样待人，才看得出士卒“爱乐为用”的来处。
例句：p.l4.8.a

## 知识点：分清传主的事和史家的评语 {#skill.l4.8.b}
义项：分清传记记下的事、史家亲眼所见和借来的比喻
领域：篇章
要诀：“余睹”说亲眼所见，“谚曰”又是谁的话？
讲解：“余睹”领着李广的神态和口才。写到“桃李不言”已经是在引用俗谚，不能当成李广生平中又一件往事。
例句：p.l4.8.b

## 原文：古籍引文 {#p.l4.8.a}
> 广之将兵，乏绝之处，见水，士卒不尽饮，广不近水；士卒不尽食，广不尝食。宽缓不苛，士以此爱乐为用。
译文：李广带兵到了物资匮乏之处，见到水，士卒没有全喝到，他就不靠近水；士卒没有全吃到，他就不尝食。他待人宽厚、不苛刻，士卒因此喜爱他，乐于给他效力。

## 原文：古籍引文 {#p.l4.8.b}
> 太史公曰：《传》曰：“其身正，不令而行；其身不正，虽令不从。”其李将军之谓也？余睹李将军悛悛如鄙人，口不能道辞。及死之日，天下知与不知，皆为尽哀。彼其忠实心诚信于士大夫也？谚曰：“桃李不言，下自成蹊。”此言虽小，可以谕大也。
译文：太史公说：古书说，自身端正，不下令也有人行动；自身不正，下了令也没人听。说的大概是李将军吧？我见李将军朴实拘谨，像乡野人，不善言辞。他去世时，天下认识和不认识他的人都深为哀痛。想来他的忠实诚心赢得了士大夫的信任吧？俗谚说桃李不开口，树下自然走出了路。这句话浅近，却能说明大道理。

## 找原文证据：哪一处最能支持“李广让士卒先得到饮水”？ {#q.l4.8.1}
考点：skill.l4.8.a
语境：p.l4.8.a

- [ ] 乏绝之处 {#q.l4.8.1.o1}
  理由：“乏绝之处”只交代缺水少粮，要看谁让谁先喝，还得读到“近水”。
- [x] 士卒不尽饮，广不近水 {#q.l4.8.1.o2}
- [ ] 士以此爱乐为用 {#q.l4.8.1.o3}
  理由：“乐为用”说士卒愿意为李广效力，没说李广怎样让他们先喝。

提示：找带两个人物和两个否定的完整句。
解析：“士卒不尽饮，广不近水”：只要还有士卒没喝到，李广就不先去喝。两个“不”合起来，先后就明白了。

## 单选：这段写李广怎样带兵，读者听到的是谁的叙述？ {#q.l4.8.2}
考点：skill.l4.8.b
语境：p.l4.8.a

- [ ] 李广自述怎样求得爱戴 {#q.l4.8.2.o1}
  理由：全段以“广”“士”称人，没有第一人称自述。
- [x] 叙事者概述带兵习惯，辅以缺水缺食时的具体作为 {#q.l4.8.2.o2}
- [ ] 一位具名士卒的逐字证词 {#q.l4.8.2.o3}
  理由：文中没有士卒开口。

提示：看叙述者怎样称呼李广，是否用了“曰”。
解析：这一段由史家用第三人称叙述：士卒还没吃，他就不尝；他待人宽厚，士卒乐于效力。文中没有引哪一个士卒的话。

## 单选：“士以此爱乐为用”中的“此”主要指什么？ {#q.l4.8.3}
考点：skill.l4.8.a
语境：p.l4.8.a

- [x] 上文记载的体恤士卒和宽厚的作风 {#q.l4.8.3.o1}
- [ ] 李广得到士卒赠送的水 {#q.l4.8.3.o2}
  理由：文中只有饮水次序。
- [ ] 士卒因受严刑而惧怕 {#q.l4.8.3.o3}
  理由：原文正写“不苛”。

提示：从“以此”返回最近的评价和两件小事。
解析：“此”往前指。缺水少粮时让士卒在先，平日里待人也宽厚，这些都是士卒喜爱他的缘由。

## 单选：若写成“李广曾命令士卒必须喜欢自己”，问题何在？ {#q.l4.8.4}
考点：skill.l4.8.b
语境：p.l4.8.a

- [ ] 把饮水与饮食区分开来 {#q.l4.8.4.o1}
  理由：原文自己就并列二事。
- [ ] 用“士卒”翻译了文中的“士” {#q.l4.8.4.o2}
  理由：这里的“士”正可联系带兵语境理解。
- [x] 把叙述者写的自然反应换成原文没有的命令 {#q.l4.8.4.o3}

提示：检查有没有“令”或李广的话语。
解析：“士以此爱乐为用”说的是士卒见李广这样待人，自己乐意为他效力。原文连一道命令都没有写。

## 单选：“口不能道辞”与“皆为尽哀”合读，能支持哪一判断？ {#q.l4.8.5}
考点：skill.l4.8.a
语境：p.l4.8.b

- [ ] 凡不善言谈的人都会受到天下人悼念 {#q.l4.8.5.o1}
  理由：司马迁写的是李广的为人和大家对他的哀悼。只凭一个人，推不出人人少言都必受爱戴。
- [x] 李广不靠善辩取信，却能使人怀念 {#q.l4.8.5.o2}
- [ ] 哀悼者都是因听过他的演说而来 {#q.l4.8.5.o3}
  理由：作者特别说“知与不知”，又说他不善言辞。

提示：把口才与最后产生的影响分别记下。
解析：他生前不善辞令，死时却连素不相识的人都哀悼他。司马迁把这两件事接起来，读者才会追问，真正打动人的是李广的什么品行。

## 找原文证据：史家明确标出亲身观察，是在哪一处？ {#q.l4.8.6}
考点：skill.l4.8.b
语境：p.l4.8.b

- [ ] 《传》曰 {#q.l4.8.6.o1}
  理由：此处引成说。
- [x] 余睹李将军悛悛如鄙人 {#q.l4.8.6.o2}
- [ ] 谚曰 {#q.l4.8.6.o3}
  理由：此处引民间常言。

提示：找表示亲见的第一人称动词。
解析：“余”是司马迁自己，“睹”是看见。他亲眼所见的是李将军朴实拘谨的样子。

## 单选：桃李树下自然走出了小路，这个比喻怎样说到李广身上？ {#q.l4.8.7}
考点：skill.l4.8.a
语境：p.l4.8.b

- [ ] 他亲自种桃李并修筑军道 {#q.l4.8.7.o1}
  理由：“谚曰”说明是比喻，不是另一件生平逸事。
- [ ] 士卒都模仿他学得相同口才 {#q.l4.8.7.o2}
  理由：“口不能道辞”强调他不以此见长。
- [x] 不凭言辞招徕，人们仍愿亲近、信任他 {#q.l4.8.7.o3}

提示：从树下的小路想到走来的人。
解析：桃李不开口召人，树下却自有人来，走出了小路。司马迁借这句俗谚，说李广虽不善言谈，仍凭为人赢得信任。

## 排序：按论赞组织材料的先后整理。 {#q.l4.8.8}
考点：skill.l4.8.b
语境：p.l4.8.b

- [1] 引古书谈以身行教，联系李广 {#q.l4.8.8.o1}
  理由：“《传》曰”是论赞开端。
- [3] 引桃李谚语收束人物影响 {#q.l4.8.8.o2}
  理由：“谚曰”把读者从李广一人引到通俗譬喻。
- [2] 从史家所见转到李广死后的众人反应 {#q.l4.8.8.o3}
  理由：“余睹”和“及死之日”在古书与俗谚之间。

提示：沿着“《传》曰”“余睹”“谚曰”三处往下读。
解析：先引古书论身正，再说史家亲见和众人哀悼。最后的桃李谚语，才把李广不靠言语而能使人亲近的意思收住。
