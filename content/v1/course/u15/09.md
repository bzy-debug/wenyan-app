# 课文：庄宗怎样得天下，又怎样失天下 {#l4.9}
简介：晋王托付三支箭，欧阳修为何先写“世言”？从这两个字读到庄宗得天下、失天下的两幅情景。

## 正文

《伶官传序》写在传记前面。欧阳修要问庄宗为什么能得天下，后来又为什么会失去。说到晋王临终交给庄宗三支箭，他特意在前面加上“世言”：这是世间所传，别把它当成作者亲见的旧事。

同一个庄宗，盛时携战果入太庙，衰时听到夜半一呼便仓皇东逃。一盛一衰写得这样悬殊，难道一句“得之难而失之易”便能说完？紧接的“抑”另问一种可能：回看这个人怎样行事，成败会不会都能找到人的原因？

两处“仇”都说仇敌。晋王说“梁，吾仇也”，后段的“仇雠”（chóu chóu）将两个意思相近的字连用。底本写“仇讐己滅，天下己定”，这里将“讐”转写为“雠”，两处“己”按句意读作“已经”的“已”。“断发”的“发”在底本作“髪”，指剪断头发。

## 知识点：分清传闻、史事和评语 {#skill.l4.9.a}
义项：分清世间流传的说法、史家记下的场面和他自己的评语
领域：阅读技能
要诀：是谁传下这件事，又是谁在评论它？
讲解：“世言”领出三矢的传闻。到“岂……欤”“抑……欤”，提问的已是欧阳修，他在斟酌怎样解释庄宗的成败。
例句：p.l4.9.a

## 知识点：同一人物的盛衰对照 {#skill.l4.9.b}
义项：比较同一个人盛时和衰时的经历，追问他为何成功、为何失败
领域：篇章
要诀：庄宗得意时和仓皇时，身边各发生了什么？
讲解：还矢入庙时，他能向先王报告成功；后来士卒尚未见敌就已离散。先把两个场面看明白，再读史家为什么追问人事。
例句：p.l4.9.b

## 原文：古籍引文 {#p.l4.9.a}
> 呜呼！盛衰之理，虽曰天命，岂非人事哉？原庄宗之所以得天下与其所以失之者，可以知之矣。世言晋王之将终也，以三矢赐庄宗而告之曰：“梁，吾仇也；燕王，吾所立；契丹与吾约为兄弟，而皆背晋以归梁。此三者，吾遗恨也。与尔三矢，尔其无忘乃父之志！”
译文：唉，兴衰的道理，虽说天命，难道不也关乎人的作为吗？推究庄宗为什么得天下、又为什么失天下，就可以理解。世间传说晋王临终把三支箭交给庄宗，告诉他：梁是仇敌，燕王是我扶立的，契丹曾约为兄弟，却背晋归梁。这几件事是我的遗恨。交你三箭，别忘了父亲的心愿。

## 原文：古籍引文 {#p.l4.9.b}
> 方其系燕父子以组，函梁君臣之首，入于太庙，还矢先王而告以成功，其意气之盛，可谓壮哉！及仇雠已灭，天下已定，一夫夜呼，乱者四应，仓皇东出，未及见贼而士卒离散，君臣相顾，不知所归，至于誓天断发，泣下沾襟，何其衰也！岂得之难而失之易欤？抑本其成败之迹，而皆自于人欤？
译文：当他缚住燕王父子，把梁国君臣的首级装匣送进太庙，将箭还给先王、报告成功时，意气何等壮盛！等到仇敌已灭、天下已定，一人夜呼，四方应乱，他仓皇向东出逃，还没见敌军，士卒已经离散。君臣相望无处可去，直至对天立誓、断发流泪，多么衰颓！难道只是得难失易？还是推究成败经过，两者都源自人的作为？

## 找原文证据：故事开头哪两个字说明，晋王托箭一事来自世间传说？ {#q.l4.9.1}
考点：skill.l4.9.a
语境：p.l4.9.a

- [x] 世言 {#q.l4.9.1.o1}
- [ ] 呜呼 {#q.l4.9.1.o2}
  理由：“呜呼”是欧阳修开篇的感叹，并没有告诉人晋王托箭的故事从哪里听来。
- [ ] 可以知之矣 {#q.l4.9.1.o3}
  理由：“可以知之矣”是说推究庄宗得失就能明白道理。下面的故事另有两个字交代来处。

提示：找引出晋王将终一事的词。
解析：“世言”就是世间传说。三矢的细节虽写得生动，开头这两个字仍在提醒读者，欧阳修说的是听来的事。

## 单选：“原庄宗之所以得天下与其所以失之者”要求怎样读材料？ {#q.l4.9.2}
考点：skill.l4.9.b
语境：p.l4.9.a

- [x] 同时追问取得与失去的原因 {#q.l4.9.2.o1}
- [ ] 先认定天命已经解释全部经过 {#q.l4.9.2.o2}
  理由：开头的反问给人事保留核心位置。
- [ ] 只需列出敌人的名字 {#q.l4.9.2.o3}
  理由：这种名录没有回答“所以”。

提示：两个“所以”分别对应庄宗的哪一阶段？
解析：这里的“原”要读作推究、追寻。两个“所以”并排，要求既看庄宗怎样取得天下，也看他又怎样失掉天下。

## 单选：说“吾遗恨也”的是谁？欧阳修怎样引出这句话？ {#q.l4.9.3}
考点：skill.l4.9.a
语境：p.l4.9.a

- [x] 世间传说中晋王对庄宗所说的话 {#q.l4.9.3.o1}
- [ ] 欧阳修本人对梁的私人仇恨 {#q.l4.9.3.o2}
  理由：“吾”处在“告之曰”后。
- [ ] 庄宗回顾自己失天下的总结 {#q.l4.9.3.o3}
  理由：故事时点是父亲临终托付。

提示：从“世言”往下读：晋王在“告”谁？引号里的“吾”是谁？
解析：“世言”是外面一层，里面又有晋王对庄宗的“告之曰”。说“吾遗恨”的“吾”属于父亲，不属于欧阳修，也不属于庄宗。

## 单选：接过三支箭时，庄宗面前还有什么事等着他去做？ {#q.l4.9.4}
考点：skill.l4.9.b
语境：p.l4.9.a

- [ ] 晋王嘱子放弃旧日未了之事 {#q.l4.9.4.o1}
  理由：“无忘”要求他继续记取。
- [x] 继承者被郑重托以尚未完成的事业 {#q.l4.9.4.o2}
- [ ] 庄宗此时已经还矢告功 {#q.l4.9.4.o3}
  理由：交箭与还箭处在不同阶段。

提示：看“与尔”后最重要的嘱咐。
解析：“与尔三矢”时，父亲交下的遗志还等着庄宗去完成。先读懂这份托付，才能看出后来还矢告功和天下已定后的不同处境。

## 单选：“抑本其成败之迹”在文中是谁在做什么？ {#q.l4.9.5}
考点：skill.l4.9.a
语境：p.l4.9.b

- [x] 史家另提出一种解释，邀请读者推究人事 {#q.l4.9.5.o1}
- [ ] 晋王临终重新交代三支箭的用途 {#q.l4.9.5.o2}
  理由：此处不在遗言引语内。
- [ ] 乱军问庄宗该走哪条路 {#q.l4.9.5.o3}
  理由：“本其成败之迹”针对整段经历。

提示：观察两个“欤”连续出现的位置。
解析：“抑”有“还是”的意思。听过“得之难而失之易”的第一问，再顺着“抑”读，才听得见史家进一步提出的人事解释。

## 找原文证据：哪句说明庄宗还没遇敌，手下的人就已散了？ {#q.l4.9.6}
考点：skill.l4.9.b
语境：p.l4.9.b

- [x] 未及见贼而士卒离散 {#q.l4.9.6.o1}
- [ ] 函梁君臣之首 {#q.l4.9.6.o2}
  理由：此为盛时战功。
- [ ] 还矢先王而告以成功 {#q.l4.9.6.o3}
  理由：此为胜利后的宗庙礼仪。

提示：注意“未及……而……”：哪件事还没发生，哪件事却已经发生了？
解析：还没见到敌人，自己一方的士卒就已经离散。这个“未及……而……”把衰时军心涣散的情形写到了眼前。

## 单选：“何其衰也”与“士卒离散”在叙述上怎样分工？ {#q.l4.9.7}
考点：skill.l4.9.a
语境：p.l4.9.b

- [ ] 两者都是乱兵的原话 {#q.l4.9.7.o1}
  理由：段中没有标出乱兵发言。
- [x] 前者评点衰败程度，后者给出可见事实 {#q.l4.9.7.o2}
- [ ] 前者是详细经过，后者是对天命的评价 {#q.l4.9.7.o3}
  理由：离散是事件，感叹才显出评价。

提示：一个词组报告动作，另一个带感叹。
解析：“士卒离散”是能看到的事，“何其衰也”是欧阳修看到这个局面发出的感叹。后面的两问才进一步追究缘由。

## 排序：按庄宗在这一段经历的实际先后排列。 {#q.l4.9.8}
考点：skill.l4.9.b
语境：p.l4.9.b

- [2] 仇敌消灭后，一呼而四方响应叛乱 {#q.l4.9.8.o1}
  理由：“及”转写天下已定之后的变故。
- [3] 仓皇东出，君臣相顾无所归 {#q.l4.9.8.o2}
  理由：君臣失措是夜呼、叛乱、士卒离散后的局面。
- [1] 携战果入庙，还矢告功 {#q.l4.9.8.o3}
  理由：“方其”回到告捷时的盛况。

提示：由“方其”走到“及”，再读出逃以后。
解析：还矢告功在前；仇敌已灭、天下已定后，一人夜呼，四方应乱；仓皇出逃、君臣无所归都在其后。
