# 课文：三支箭的传闻，怎样写进庄宗的兴亡？ {#l4.9}
简介：一位父亲的遗命、一幅入庙告功的场景，和一阵半夜的呼声，在欧阳修的史论里各作什么用？

## 正文

先给开头的两种话各找主人。追问“岂非人事哉”的是作者；说“吾遗恨”的是父亲，却又只是“世言”所传的父亲的话。“世言”两个字留在抄录旁边，便不会把交箭时的每个细节都说成欧阳修亲见。

到了另一个选段，镜头里的庄宗已在祖庙。他将拘系俘虏、收取首级、归还三矢、告成等事一口气做完。转到“及”，起事的人却从“一夫”写起，竟至君臣相对不知去向。前后都有一串动作，一串显出能控制局面，另一串显出再也控制不了局面。

“得之难而失之易”听来已经足够感慨。作者偏又追问“抑本其成败之迹”，邀请读者回去核对这同一个人怎样得、怎样失。他不是要求读者先判明天命存在与否，而是把可以从史迹追究的人事放到前台。

## 知识点：辨别传闻、所叙史事与论断 {#skill.l4.9.a}
义项：给进言、转述和作者的判断分别找到发话者与引入语
领域：阅读技能
要诀：父亲说“吾”，谁先把父亲的话带进来的？
讲解：“世言”标明传说来路；“原庄宗……”和末段两问才是作者追原因的声音。同一篇文字并非从头到尾都用同样的历史把握说话。
例句：p.l4.9.a

## 知识点：以同一人物的前后处境检验兴亡之论 {#skill.l4.9.b}
义项：从两段中各取行动证据，比较一个人得势与失势时的主动程度
领域：篇章
要诀：“方其”引盛，“及”转衰，两边各拣一个动作。
讲解：得胜时入庙告成功，败时连敌军还没见到，队伍已先溃散。欧阳修让落差可见，才引作者与读者共同追究其故。
例句：p.l4.9.b

## 原文：古籍引文 {#p.l4.9.a}
> 呜呼！盛衰之理，虽曰天命，岂非人事哉？原庄宗之所以得天下与其所以失之者，可以知之矣。世言晋王之将终也，以三矢赐庄宗而告之曰：“梁，吾仇也；燕王，吾所立；契丹与吾约为兄弟，而皆背晋以归梁。此三者，吾遗恨也。与尔三矢，尔其无忘乃父之志！”
译文：唉！国家盛衰，虽有人归给天命，难道不也在人做的事吗？追一追庄宗取得天下和后来失去天下的缘由，就可从中明白。世人传说，晋王临终给庄宗三支箭，告诉他：“梁是我的仇敌；燕王是我扶立的；契丹同我结为兄弟。后来他们都背晋归梁。这些是我的遗恨。给你三支箭，千万别忘了你父亲的心愿！”
词注：原：追究事情的根由。
  世言：世间相传，交代故事来历。
  乃父：你的父亲，“乃”指你、你的。

## 原文：古籍引文 {#p.l4.9.b}
> 方其系燕父子以组，函梁君臣之首，入于太庙，还矢先王而告以成功，其意气之盛，可谓壮哉！及仇雠已灭，天下已定，一夫夜呼，乱者四应，仓皇东出，未及见贼而士卒离散，君臣相顾，不知所归，至于誓天断发，泣下沾襟，何其衰也！岂得之难而失之易欤？抑本其成败之迹，而皆自于人欤？
译文：当年庄宗用绳系着燕王父子，把梁国君臣的首级装在匣里，来到太庙，向先王还箭报捷，何等意气昂扬！等仇敌消灭、天下平定，夜里一人呼喊，应乱的四起。他仓皇向东出逃，还没见到敌人就已众叛兵散，君臣相看，不知去哪里，只得对天断发立誓，眼泪沾湿衣襟。衰落到这一步！是取得天下难、失去天下容易吗？还是追查成败的经过，两头都能追到人的作为上？
词注：组：丝带、绳索。
  函：用匣子盛装。
  抑：还是，用在提出另一种可能的问句中。

## 找原文证据：要给“三矢相授”这一段标注消息性质，应摘开头哪几个字？ {#q.l4.9.1}
考点：skill.l4.9.a
语境：p.l4.9.a

- [x] 世言 {#q.l4.9.1.o1}
- [ ] 原庄宗之所以得天下 {#q.l4.9.1.o2}
  理由：“原”是作者自己追究得失的意向。
- [ ] 呜呼 {#q.l4.9.1.o3}
  理由：叹词标出感慨，不能交代故事从哪里来。

提示：寻找相当于“人们相传”的两个字。
解析：欧阳修先写“世言”，才讲临终遗矢。这允许读者使用故事理解论旨，同时保留它的传闻身份。

## 单选：“得天下”与“失之”为什么必须合读？ {#q.l4.9.2}
考点：skill.l4.9.b
语境：p.l4.9.a

- [x] 同一人先得后失，作者用两面追问为何人事值得考察 {#q.l4.9.2.o1}
- [ ] 只要得天下，后来的失地便可解释为天命 {#q.l4.9.2.o2}
  理由：“岂非人事哉”把人如何作为提到前台。
- [ ] 庄宗与晋王各得各失，二人分别提供一半材料 {#q.l4.9.2.o3}
  理由：“庄宗之所以得……其所以失”指向同一传主。

提示：找“其”的先行者，再看两处“所以”各问什么。
解析：作者选的是一人盛衰，不是两位君主的优劣榜。两边对读，才能追索先后究竟有什么改变。

## 单选：“此三者，吾遗恨也”应记在谁名下，哪一点能作依据？ {#q.l4.9.3}
考点：skill.l4.9.a
语境：p.l4.9.a

- [x] 故事里的晋王；“尔其无忘乃父之志”正是父亲嘱咐儿子 {#q.l4.9.3.o1}
- [ ] 欧阳修；“吾”在古文里一律是写文章的人 {#q.l4.9.3.o2}
  理由：这里有“告之曰”划入引语。
- [ ] 庄宗；他已经在太庙归还三矢 {#q.l4.9.3.o3}
  理由：归矢出现在后段，这里尚在父亲临终之时。

提示：读“与尔三矢”时，谁给，谁收？
解析：“世言”领进传闻，传闻中又有父亲的话。判断“吾”之前，先把这两层人声分开。

## 单选：若删去“虽曰天命，岂非人事哉”，仅留下遗命，读者最难看出什么？ {#q.l4.9.4}
考点：skill.l4.9.b
语境：p.l4.9.a

- [ ] 梁、燕、契丹是谁提到的 {#q.l4.9.4.o1}
  理由：晋王的引语仍立着。
- [x] 记三矢是为追究兴亡中人的作用，并非只给三支箭作来历 {#q.l4.9.4.o2}
- [ ] 世人是否传过一种有关晋王遗命的说法 {#q.l4.9.4.o3}
  理由：“世言”仍在遗命之前，删去篇首议论也保留了这一消息来源。

提示：把末尾的“志”接回文章开头那一问。
解析：父亲留下的事与儿子后来怎样应对，在“人事”这一问下才共同构成历史评论。

## 单选：“方其”一串动作，到“及仇雠已灭”才翻过来。哪个细节特别能把盛时的从容同败时的茫然对照？ {#q.l4.9.5}
考点：skill.l4.9.a
语境：p.l4.9.b

- [x] 从入太庙告成功，到君臣相顾不知往哪里去 {#q.l4.9.5.o1}
- [ ] 从结组缚燕父子，到函盛梁君臣之首 {#q.l4.9.5.o2}
  理由：这两件都在打胜时。
- [ ] 从仓皇东出，到泣下沾襟 {#q.l4.9.5.o3}
  理由：这两件都在败亡一边。

提示：从“方其”和“及”各选一个场景。
解析：盛时连归矢、告祭都能按意愿完成；事变突起，君臣连下一步去处都拿不定。

## 找原文证据：哪一处让人看出，败局并非一开始就有强敌列阵在庄宗眼前？ {#q.l4.9.6}
考点：skill.l4.9.b
语境：p.l4.9.b

- [x] 未及见贼而士卒离散 {#q.l4.9.6.o1}
- [ ] 函梁君臣之首 {#q.l4.9.6.o2}
  理由：此为往日战功。
- [ ] 还矢先王而告以成功 {#q.l4.9.6.o3}
  理由：这也在“方其”领下的兴盛一段。

提示：“未及”说明士卒离散发生在什么之前？
解析：还没看见叛军，自己的部下已先离散。作者用这一层先后，把失败的原因逼回统治者自身处境。

## 单选：结尾连续两问，同一整段引述晋王遗言相比，谁在说话有了怎样的变化？ {#q.l4.9.7}
考点：skill.l4.9.a
语境：p.l4.9.b

- [ ] 晋王继续训子，责备儿子在太庙礼数不全 {#q.l4.9.7.o1}
  理由：末问回顾的是庄宗后来的成败，早已越出临终遗言。
- [x] 作者直接权衡得失与人事，邀请读者从先前事实作判断 {#q.l4.9.7.o2}
- [ ] 乱兵在夜里询问庄宗接下来向何处逃走 {#q.l4.9.7.o3}
  理由：“本其成败之迹”是追究整段历史的口吻。

提示：把“本其成败之迹”同篇首“原庄宗”放在一起。
解析：开头起意追究，结尾带着读者回看成败。引语为议论提供材料，不能把每个问号都归父亲。

## 排序：只用下列三个节点还原作者让人看见的落差。 {#q.l4.9.8}
考点：skill.l4.9.b
语境：p.l4.9.b

- [2] 天下平定后忽有夜呼，应者四起 {#q.l4.9.8.o1}
  理由：“及”将时代推至仇敌消灭之后。
- [3] 未及见敌自己的队伍已散，君臣无所归 {#q.l4.9.8.o2}
  理由：这才落到“何其衰也”的情状。
- [1] 得胜归来，将战果与父命一同带到太庙 {#q.l4.9.8.o3}
  理由：这是“方其”之盛。

提示：先看“方”，再看“及”，最后找“未及”。
解析：得天下在先不意味着能守住天下。把败时何其迅速和盛时所成的事并列，“皆自于人”的问法才有力量。
