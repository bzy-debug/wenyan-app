# 检查：史传中的判断综合阅读 {#check.15}

## 原文：古籍引文 {#p.check.15.a}
> 天之亡我，非战之罪也。今日固决死，愿为诸君快战，必三胜之，为诸君溃围、斩将、刈旗，令诸君知天亡我，非战之罪也。乃分其骑以为四队，四向。汉军围之数重。
译文：项羽说，是天要亡我，并非作战的过错。今天已决定死战，愿给各位痛快打一场，一定多次战胜对方，替你们冲围、斩将、夺旗，让各位知道是天亡我。于是把骑兵分为四队朝向四方，汉军把他们围了好几层。

## 原文：古籍引文 {#p.check.15.b}
> 自矜功伐，奋其私智而不师古，谓霸王之业，欲以力征经营天下，五年卒亡其国，身死东城，尚不觉寤而不自责，过矣。乃引“天亡我，非用兵之罪也”，岂不谬哉！
译文：他自夸功业，只凭个人才智而不肯借鉴古人，想着完成霸王事业，想靠武力征服来治理天下。五年终于失国，身死东城，还不醒悟自责，已经错了。竟又用“天要亡我，并非用兵之过”作解释，岂不荒谬！

## 单选：“愿为诸君快战”透露谁想用行动向谁证明判断？ {#q.check.15.1}
考点：skill.l4.7.a
语境：p.check.15.a

- [ ] 司马迁想让写史者相信天命 {#q.check.15.1.o1}
  理由：“诸君”是当场的听者。
- [ ] 汉军要向项羽展示取胜的理由 {#q.check.15.1.o2}
  理由：后面的汉军处于包围项羽的一方。
- [x] 项羽想让身边随从相信他的解释 {#q.check.15.1.o3}

提示：“为诸君”与“令诸君知”互相照应。
解析：人物以第一人称提出自我辩护，随从是他面对的听众。

## 单选：项羽若确能在局部交战中取胜，这最直接能说明什么？ {#q.check.15.2}
考点：skill.l4.8.a
语境：p.check.15.a

- [ ] 经营天下的每一项选择都正确 {#q.check.15.2.o1}
  理由：临阵表现与长期治理的证据范围不同。
- [x] 他还具备眼前作战的能力 {#q.check.15.2.o2}
- [ ] 失国只能由天命造成 {#q.check.15.2.o3}
  理由：局部获胜不能排除其他长期原因。

提示：把一次战斗与五年事业放到不同时间尺度。
解析：战斗表现可以表明眼前的本领，其证明范围不能自动扩大到整个败亡原因。

## 找原文证据：哪句写出宣言之后实际实施的部署？ {#q.check.15.3}
考点：skill.l4.9.a
语境：p.check.15.a

- [ ] 天之亡我 {#q.check.15.3.o1}
  理由：这是人物给出的解释。
- [ ] 必三胜之 {#q.check.15.3.o2}
  理由：这是项羽预期达到的结果。
- [x] 乃分其骑以为四队 {#q.check.15.3.o3}

提示：找叙事转回行动的“乃”。
解析：分队是叙述者记下的行为，前面多句仍是人物要人相信的主张。

## 单选：评者举“不师古”“以力征经营天下”，针对的是哪句自辩？ {#q.check.15.4}
考点：skill.l4.7.b
语境：p.check.15.b

- [ ] 听者不肯与他同行 {#q.check.15.4.o1}
  理由：并没有这样的辩词。
- [x] 败亡完全缘于天，自己用兵并无过错 {#q.check.15.4.o2}
- [ ] 汉军包围分为几层 {#q.check.15.4.o3}
  理由：包围层数不解释五年的政治选择。

提示：把人物的归因与评者列出的原因对照。
解析：这些选择把责任移回人事，反驳把失败完全交给天命。

## 找原文证据：哪处最明确是评者对于人物自解的裁断？ {#q.check.15.5}
考点：skill.l4.8.b
语境：p.check.15.b

- [x] 岂不谬哉 {#q.check.15.5.o1}
- [ ] 天亡我，非用兵之罪也 {#q.check.15.5.o2}
  理由：这是评者引述项羽的说法。
- [ ] 身死东城 {#q.check.15.5.o3}
  理由：这是列入评议的生平结局。

提示：看引号外的收尾。
解析：“乃引”先转述项羽，收句才用反问直斥其归因。

## 单选：这一段把时幅拉到“五年”的作用是什么？ {#q.check.15.6}
考点：skill.l4.9.b
语境：p.check.15.b

- [ ] 专为订正当日骑兵数量 {#q.check.15.6.o1}
  理由：评者的视野扩大到整个事业。
- [ ] 说明项羽临终快战持续整整五年 {#q.check.15.6.o2}
  理由：“五年”对应经营天下到亡国。
- [x] 以长期的选择与结局重新衡量临终的说法 {#q.check.15.6.o3}

提示：找“五年”前的事业、后的结局。
解析：时间范围一扩，反复倚重武力等人事因素就进入了因果判断。
