# 检查：《项羽本纪》：最后一战能证明谁的解释？ {#check.15}

## 原文：古籍引文 {#p.check.15.a}
> 天之亡我，非战之罪也。今日固决死，愿为诸君快战，必三胜之，为诸君溃围、斩将、刈旗，令诸君知天亡我，非战之罪也。乃分其骑以为四队，四向。汉军围之数重。
译文：项羽说：是天要使我灭亡，不是我不能作战。今天固然决意一死，仍想为诸位痛快地打一仗，一定取得三次胜利，替大家冲破包围、斩敌将、砍敌旗，让大家知道是天使我亡，不是作战的过错。随即把骑兵分成四队，分向四方。汉军已将他围了几重。
词注：固：本来、固然。
  快战：痛快地打一仗。
  刈：读 yì，割、斩，这里指砍倒军旗。

## 原文：古籍引文 {#p.check.15.b}
> 三年，遂将五诸侯灭秦，分裂天下，而封王侯，政由羽出，号为“霸王”。位虽不终，近古以来未尝有也。及羽背关怀楚，放逐义帝而自立，怨王侯叛己，难矣。自矜功伐，奋其私智而不师古，谓霸王之业，欲以力征经营天下，五年卒亡其国，身死东城，尚不觉寤而不自责，过矣。乃引“天亡我，非用兵之罪也”，岂不谬哉！
译文：三年间，项羽就率五路诸侯灭了秦，划分天下，分封王侯，政令由他发出，号称霸王。这个地位虽没能保持到最后，近古以来却不曾有过这样的事。等到项羽舍弃关中、眷恋楚地，放逐义帝而自立，又怨恨王侯背叛自己，局面便难维持了。他自夸战功，逞自己的聪明而不取法前人，以为成就霸王的事业要靠武力征伐来经营天下。才五年便丢了国家，死在东城，尚不醒悟、不责备自己，错得厉害！竟援引“天要我灭亡，不是用兵的过错”来解释，难道不荒谬吗？
词注：政由羽出：号令由项羽发出。
  背关怀楚：舍弃关中，心向楚地。
  矜：夸耀。
  功伐：功绩，尤指战功。
  寤：醒悟。

## 单选：“非战之罪”究竟是谁的自我解释？ {#q.check.15.1}
考点：skill.l4.7.a
语境：p.check.15.a

- [ ] 记本纪的司马迁，叙事一开头便表赞同 {#q.check.15.1.o1}
  理由：句中有“为诸君”，说话者正面对自己的部下。
- [ ] 叙述者根据汉军围困的形势，为项羽转述一项已证实的结论 {#q.check.15.1.o2}
  理由：“愿为诸君”还在请人观看接下来的战斗，眼前是人物的自辩。
- [x] 项羽自己，要让眼前的诸君相信 {#q.check.15.1.o3}

提示：顺着“我”“为诸君”辨说话人的位置。
解析：项羽把今日一战当作自证。史家把这番话记下来，并不等于已替他同意其判断。

## 单选：项羽提到溃围、斩将、刈旗，在这段话里这些事处在什么状态？ {#q.check.15.2}
考点：skill.l4.8.a
语境：p.check.15.a

- [ ] 是史家已经逐项查证完成的战报 {#q.check.15.2.o1}
  理由：此段写到分骑、被围为止，愿语尚非结果。
- [x] 是他许给部下的具体表现，想用来证明自己仍善战 {#q.check.15.2.o2}
- [ ] 是他承认的三项用兵错误 {#q.check.15.2.o3}
  理由：三件事都是他想以战绩给大家看的本领。

提示：把“愿”“必”“为诸君”先读出声，再读末两句叙事。
解析：行动确已开始，三胜仍是项羽的承诺。阅读允许相信他有决心，却不能替这个节选补上完成时。

## 找原文证据：哪里已由项羽的口头解释，转成叙述者报告他实际发出的部署？ {#q.check.15.3}
考点：skill.l4.9.a
语境：p.check.15.a

- [ ] 必三胜之 {#q.check.15.3.o1}
  理由：这还是项羽所许的战果。
- [ ] 愿为诸君快战 {#q.check.15.3.o2}
  理由：这是作战意愿。
- [x] 乃分其骑以为四队 {#q.check.15.3.o3}

提示：找说话口气从“我、诸君”换成“其”的地方。
解析：“乃”以下可以从外面观察，第一件可观察的事是骑兵分为四队。这同他给败亡归因是两层记录。

## 单选：太史公盯住“五年卒亡其国”，同项羽要展示一日快战相比，观察尺度怎样变了？ {#q.check.15.4}
考点：skill.l4.7.b
语境：p.check.15.b

- [ ] 从部下人数，改为推算谁能斩杀多少敌将 {#q.check.15.4.o1}
  理由：史家聚焦“经营天下”，并未清点战斗杀伤。
- [x] 从眼前一次交锋，改看数年以武力经营天下的成败 {#q.check.15.4.o2}
- [ ] 从项羽在部下眼中的勇力，改看敌将对那一战的评价 {#q.check.15.4.o3}
  理由：史家问到“经营天下”，既没引敌将的话，也没有把考察限于那一天。

提示：圈出“天下”与“五年”，再回想项羽许给谁看。
解析：临场勇猛并不能回答多年治理为什么失败。争议正是项羽把哪一种能耐当成了全部解释。

## 找原文证据：要引用史家自己的直接评语，哪一句最有辨识力？ {#q.check.15.5}
考点：skill.l4.8.b
语境：p.check.15.b

- [x] 岂不谬哉 {#q.check.15.5.o1}
- [ ] 天亡我，非用兵之罪也 {#q.check.15.5.o2}
  理由：这是太史公引来质问的项羽说法。
- [ ] 霸王之业 {#q.check.15.5.o3}
  理由：这是被谈论的事业，单独摘下尚未透露作者态度。

提示：留意“乃引”后面先引谁，再由谁发问。
解析：引文结束才有“岂不谬哉”。把引来的话当作史家信念，会把这一段的方向完全读反。

## 单选：把项羽的盛衰合成两笔史事，再来看“天亡我”这句话。哪种写法保留了太史公要读者比较的变化？ {#q.check.15.6}
考点：skill.l4.9.b
语境：p.check.15.b

- [ ] 当年分封王侯，后来仍能分封；这样一位霸王只可能因天命而亡 {#q.check.15.6.o1}
  理由：“怨王侯叛己”已写王侯不再听命，最后更有“五年卒亡其国”。
- [ ] 当年连一场仗也没赢过，后来因不会作战失去天下 {#q.check.15.6.o2}
  理由：前面明记他领诸侯灭秦。太史公质疑的是他把整个败局归给天命。
- [x] 从前号令天下、分封王侯，后来怨王侯背叛，终至失国；太史公由此追问他自己的作为 {#q.check.15.6.o3}

提示：先看“政由羽出”时是谁发号施令，再看后来那些王侯还听不听命。
解析：当初是项羽主动分封，到后来却拦不住王侯背叛。太史公把项羽如何用权、如何失势连起来考察；即便项羽临战能胜，也解释不了这段变化。
