# 课文：相如避车，真是怕廉颇吗 {#l4.7}
简介：相如避开廉颇的车，门客竟要辞去。读到相如亲口解释时，看看同一件事还有怎样的读法。

## 正文

廉颇觉得，自己立的是军功，相如却只凭口舌就排在自己前面。“徒”这个字，先记在廉颇名下。随后史家写相如称病，又写他在路上看见廉颇便避车。我们确实看见他避让了。可是断定他胆小的，是跟随他的门客。

相如先不提自己的苦心，反倒请门客比一比，廉颇和秦王哪一个更有威势。他连秦王都敢当廷呵斥，何至于偏偏怕廉颇？读到“顾吾念之”，再停一停：这是相如亲口说起他真正顾虑的事。两人如果只争个人的高下，赵国面对强秦，就少了他们共同支撑的局面。

## 知识点：同一件事，各人怎么看 {#skill.l4.7.a}
义项：分清人物做了什么、旁人怎么想，以及人物自己怎样解释
领域：篇章
要诀：说他“怕”的是谁？回避又是谁亲眼能看见的？
讲解：“引车避匿”记下相如的行动。门客从这一举动猜他害怕，后文却容相如开口解释。读到评语，要认出是哪一个人的话。
例句：p.l4.7.a

## 知识点：从前后两件事看用意 {#skill.l4.7.b}
义项：把一个人前后做的事放在一起，看对他用意的猜测是否说得通
领域：阅读技能
要诀：把这次回避与当廷面对秦王的那一次并读。
讲解：相如敢呵斥比廉颇更有威势的秦王，单用胆怯来解释避车就很难讲通。他随后才点出赵国的处境。
例句：p.l4.7.b

## 原文：古籍引文 {#p.l4.7.a}
> 廉颇曰：“我为赵将，有攻城野战之大功，而蔺相如徒以口舌为劳，而位居我上。且相如素贱人，吾羞，不忍为之下。”宣言曰：“我见相如，必辱之。”相如闻，不肯与会。相如每朝时，常称病，不欲与廉颇争列。已而相如出，望见廉颇，相如引车避匿。于是舍人相与谏曰：“臣所以去亲戚而事君者，徒慕君之高义也。今君与廉颇同列，廉君宣恶言，而君畏匿之，恐惧殊甚。且庸人尚羞之，况于将相乎？臣等不肖，请辞去。”
译文：廉颇说，自己攻城野战有大功，蔺相如只凭口舌立功却位居自己之上，而且相如原先身份低微，他以屈居其下为羞。廉颇扬言见了便要羞辱相如。相如听说不肯相会，常在上朝时称病，不想和廉颇争位次。后来相如外出，远远见到廉颇便调车避开。门客们一同进言：当初离开亲人来侍奉您，只因仰慕您的高义。如今同朝的廉将军出言攻击，您却怕他躲他，胆怯得厉害。寻常人尚以此为羞，何况将相？我们不成材，请准许告辞。

## 原文：古籍引文 {#p.l4.7.b}
> 蔺相如固止之，曰：“公之视廉将军孰与秦王？”曰：“不若也。”相如曰：“夫以秦王之威，而相如廷叱之，辱其群臣，相如虽驽，独畏廉将军哉？顾吾念之，强秦之所以不敢加兵于赵者，徒以吾两人在也。今两虎共斗，其势不俱生。吾所以为此者，以先国家之急而后私仇也。”廉颇闻之，肉袒负荆，因宾客至蔺相如门谢罪。
译文：相如坚决挽留门客，问诸位看廉将军与秦王相比谁更厉害。回答是廉将军不及秦王。相如说，秦王那样有威势，自己还当庭斥责他，使其群臣受辱，难道偏怕廉将军？只是想到强秦不轻易向赵用兵，是因他们两人在。二虎相斗难以俱全，自己是把国家急务放在私人怨仇之前。廉颇得知后袒身背荆，经由宾客到相如门前谢罪。

## 单选：把相如之功说成“徒以口舌为劳”的是谁？ {#q.l4.7.1}
考点：skill.l4.7.a
语境：p.l4.7.a

- [x] 正在为自己位次不平的廉颇 {#q.l4.7.1.o1}
- [ ] 叙述者在结尾给二人定功 {#q.l4.7.1.o2}
  理由：这句话出现在“廉颇曰”的引语中。
- [ ] 相如在朝堂上自谦 {#q.l4.7.1.o3}
  理由：“我为赵将”的说话者是廉颇。

提示：保留开头的引号再读“徒”。
解析：“廉颇曰”后面是廉颇自己的话。他用“徒”把相如的外交之功说轻了，也就说出了他为什么对位次不服。

## 单选：仅凭“引车避匿”一件事，哪种结论仍需别的证据？ {#q.l4.7.2}
考点：skill.l4.7.b
语境：p.l4.7.a

- [ ] 两人这次没有当面冲突 {#q.l4.7.2.o1}
  理由：避开的结果支持这一判断。
- [x] 相如回避的根本原因是害怕廉颇 {#q.l4.7.2.o2}
- [ ] 相如外出时远远见到了廉颇 {#q.l4.7.2.o3}
  理由：“望见廉颇”直接写了这一点。

提示：将亲眼可见的动作和内心推断分开。
解析：别人能看见的是相如调车躲开。怕对方是一种解释，顾全大局也是一种解释，单看车往哪边走，分不出来。

## 找原文证据：哪一处是叙述人写相如的动作，而非廉颇的发言？ {#q.l4.7.3}
考点：skill.l4.7.a
语境：p.l4.7.a

- [ ] 我见相如，必辱之 {#q.l4.7.3.o1}
  理由：这一宣言出于廉颇。
- [ ] 吾羞 {#q.l4.7.3.o2}
  理由：“吾”是廉颇的自称。
- [x] 相如引车避匿 {#q.l4.7.3.o3}

提示：留意最后一次“曰”的引语何时结束。
解析：“我见相如，必辱之”是廉颇亲口扬言。到“相如引车避匿”，已经换成史家在写相如路上做的事。

## 单选：上朝时称病，路上又避车，两件事放在一起能看出什么？ {#q.l4.7.4}
考点：skill.l4.7.b
语境：p.l4.7.a

- [ ] 相如患有一种不能坐车的病 {#q.l4.7.4.o1}
  理由：他确实外出乘车，文中只说称病。
- [x] 相如在朝会和出行两种场合都回避争执 {#q.l4.7.4.o2}
- [ ] 廉颇每次都会兑现羞辱他的话 {#q.l4.7.4.o3}
  理由：本段只写廉颇的宣言。

提示：把一个行为放朝中，另一个放路上。
解析：上朝称病，出行避车，两次动作合在一起，才能看出相如一再避免与廉颇碰面。至于他为什么这样做，后文才回答。

## 找原文证据：相如自己怎么说国事与私仇哪一件更要紧？ {#q.l4.7.5}
考点：skill.l4.7.a
语境：p.l4.7.b

- [x] 以先国家之急而后私仇也 {#q.l4.7.5.o1}
- [ ] 肉袒负荆 {#q.l4.7.5.o2}
  理由：负荆请罪是廉颇听说此事后的行动。题目要找相如自己怎么取舍。
- [ ] 其势不俱生 {#q.l4.7.5.o3}
  理由：“不俱生”预想的是两虎争斗的后果；接下来，相如才明说国事与私怨的先后。

提示：找带“先”“后”的价值排序。
解析：“先国家之急”与“后私仇”一先一后，写的是哪件事更要紧。这是相如自己的说明。

## 单选：相如为什么先请人比较廉颇与秦王？ {#q.l4.7.6}
考点：skill.l4.7.b
语境：p.l4.7.b

- [x] 借自己曾面对更强者的行动，质疑单以胆怯解释避车 {#q.l4.7.6.o1}
- [ ] 宣称廉颇在军事上毫无功劳 {#q.l4.7.6.o2}
  理由：比较威势，并未抹去廉颇军功。
- [ ] 证明秦王也曾因私怨向相如负荆 {#q.l4.7.6.o3}
  理由：负荆的是廉颇。

提示：把“不若”接到“廷叱之”。
解析：门客承认廉颇威势不及秦王。相如提醒他们，自己敢当廷斥责秦王，何必独独惧怕廉颇？他借往事请门客重新想避车的缘由。

## 单选：“强秦之所以不敢加兵”应以怎样的口吻写入摘要？ {#q.l4.7.7}
考点：skill.l4.7.a
语境：p.l4.7.b

- [ ] 秦王亲口承认，他绝不向赵用兵 {#q.l4.7.7.o1}
  理由：本段没有秦王的发言。
- [ ] 叙述者宣布，赵从此不再遭秦进攻 {#q.l4.7.7.o2}
  理由：原文只记相如当时的权衡。
- [x] 相如解释说，赵有他们二人可使秦有所忌惮 {#q.l4.7.7.o3}

提示：找这一判断外面的“曰”。
解析：说“强秦之所以不敢加兵”的是相如。他认为赵国有自己和廉颇，足以使秦忌惮。复述时把这句话归给相如，才保留了原文的口气。

## 排序：按相如当面说明动机的论证次序排列。 {#q.l4.7.8}
考点：skill.l4.7.b
语境：p.l4.7.b

- [3] 说明国家急务在私仇之前 {#q.l4.7.8.o1}
  理由：说“吾所以为此”时，相如已交代国事前提。
- [2] 推演两名赵臣相斗对国家的不利 {#q.l4.7.8.o2}
  理由：“顾吾念之”才转到赵国的处境。
- [1] 引秦王之威，排除单以恐惧解释 {#q.l4.7.8.o3}
  理由：“孰与秦王”先查避车是否因为畏惧。

提示：从“独畏”读到“顾吾念之”，再读“吾所以”。
解析：先拿面对秦王的往事回应“怕廉颇”的猜测，再讲两人相斗会给赵国带来的危险，最后才说国事重于私仇。
