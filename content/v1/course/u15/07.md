# 课文：蔺相如避车，谁把退让读成了胆怯？ {#l4.7}
简介：同一辆车驶开了。门客有一套解释，相如另有一套；史家先后把哪些事实交给了读者？

## 正文

廉颇说相如“徒以口舌为劳”，跟随相如的人却说自己“徒慕君之高义”。先不要替谁判输赢：同一个“徒”，前者在轻看口舌之功，后者在强调自己只因高义才留下。读完两家的话，再看夹在两段话里的称病与避车。能看见的只是这些行动，“恐惧殊甚”是门客下的判断。

相如没有先喊冤。他先问秦王与廉将军谁威势大。等门客承认秦王更强，他才举自己敢于当廷呵斥秦王的旧事。读到“顾吾念之”，推理还要多走一步：敢斥秦而隐避廉，只能使“胆怯”这个解释生疑；两位将相都在，秦兵才有所顾忌，这才交代了相如容让的缘故。

传记最后把廉颇送到相如门前。裸露上身、背着荆条是来请罪的姿态，古人以此表示愿受责罚。这个动作接在相如的长段说明之后，用可见的反应写两人关系的变化。它没有替赵国预订此后每一场胜仗。

## 知识点：分开可见动作与人物评语 {#skill.l4.7.a}
义项：从引语的边界认出是谁把一种动机安在行动上
领域：篇章
要诀：“引车避匿”后再找“舍人……曰”，两句分别由谁叙说？
讲解：退车人人可见。门客说君“畏”，廉颇说相如“徒以口舌为劳”，两种价值判断各有说话人的立场。
例句：p.l4.7.a

## 知识点：用前后事件检验对动机的解释 {#skill.l4.7.b}
义项：用已发生的可比行动排除一个解释，再寻找更充分的动机
领域：阅读技能
要诀：相如在秦廷做过什么？两位赵臣若争斗，谁得便宜？
讲解：当廷斥秦使怯懦之说难以自圆；赵国面对强秦则说明相如为何忍让。两件证据用力的地方不同。
例句：p.l4.7.b

## 原文：古籍引文 {#p.l4.7.a}
> 廉颇曰：“我为赵将，有攻城野战之大功，而蔺相如徒以口舌为劳，而位居我上。且相如素贱人，吾羞，不忍为之下。”宣言曰：“我见相如，必辱之。”相如闻，不肯与会。相如每朝时，常称病，不欲与廉颇争列。已而相如出，望见廉颇，相如引车避匿。于是舍人相与谏曰：“臣所以去亲戚而事君者，徒慕君之高义也。今君与廉颇同列，廉君宣恶言，而君畏匿之，恐惧殊甚。且庸人尚羞之，况于将相乎？臣等不肖，请辞去。”
译文：廉颇自陈身为赵将，立过攻城野战的大功，却让只靠言辞立功的相如居于自己之上；又嫌相如出身卑微，以屈居其下为耻，公开说见面就要羞辱他。相如听说后避而不见，朝会常称病，不愿争位次。有一次远远看见廉颇，他让车掉开躲避。门客共同劝他：我们离开亲人跟随您，只因仰慕您的高义。如今您对同列的廉君这样躲藏，显得太怕他。普通人尚以此为耻，何况将相？我们不才，请容辞去。
词注：徒：仅仅，表示说话人眼中只值这么多。
  宣言：公开扬言。
  亲戚：亲属，包括父母等至亲。

## 原文：古籍引文 {#p.l4.7.b}
> 蔺相如固止之，曰：“公之视廉将军孰与秦王？”曰：“不若也。”相如曰：“夫以秦王之威，而相如廷叱之，辱其群臣，相如虽驽，独畏廉将军哉？顾吾念之，强秦之所以不敢加兵于赵者，徒以吾两人在也。今两虎共斗，其势不俱生。吾所以为此者，以先国家之急而后私仇也。”廉颇闻之，肉袒负荆，因宾客至蔺相如门谢罪。
译文：相如坚决挽留，先问廉将军比秦王怎么样，门客答比不上。他说：“秦王那样有威势，我尚敢在朝廷上呵斥他、使他的群臣蒙羞。我虽愚钝，难道偏怕廉将军？我想到的是，强秦不敢攻赵，只因我们两人都在。两虎相斗，势必不能两全。我这样做，是把国家的急难放在前头，把私人怨隙放在后头。”廉颇听说后，袒露上身背了荆条，由宾客引到相如门下请罪。
词注：孰与：用来比较，两者相较如何。
  驽：本指劣马，此处是相如自谦。
  谢罪：向人认错、赔罪。

## 单选：廉颇先比功劳，又说“位居我上”。究竟是哪两件事在他眼里配不上？ {#q.l4.7.1}
考点：skill.l4.7.a
语境：p.l4.7.a

- [x] 相如靠言辞所得的功劳，与相如高于自己的官位 {#q.l4.7.1.o1}
- [ ] 廉颇曾在战场上立功，却没有官职 {#q.l4.7.1.o2}
  理由：他开口便自称“我为赵将”。
- [ ] 相如原本位高，却不肯在朝廷露面 {#q.l4.7.1.o3}
  理由：廉颇说“素贱人”，强调的是相如原先地位低。

提示：把“我”“相如”各写成一行，看功与位怎样排。
解析：相如的功是“徒以口舌为劳”，这一个“徒”便带着廉颇的评判。不能把它直接记作史家的定论。

## 单选：同一件避车的事，哪一步已经从外在动作走到对内心的猜测？ {#q.l4.7.2}
考点：skill.l4.7.b
语境：p.l4.7.a

- [ ] 相如在路上望见了廉颇 {#q.l4.7.2.o1}
  理由：这是叙述者交代的相遇。
- [x] 门客说“恐惧殊甚” {#q.l4.7.2.o2}
- [ ] 舍人相与劝谏，并提出辞去 {#q.l4.7.2.o3}
  理由：说出劝辞、提出辞去都可记录；给避车者判断动机的是他们话里的“恐惧”。

提示：问一句：站在路边的人能亲眼看到恐惧的分量吗？
解析：引车是可见行动，胆怯是门客替这个行动给的解释。后文将让相如自己开口。

## 找原文证据：门客以辞去相逼，原先追随相如的理由写在哪里？ {#q.l4.7.3}
考点：skill.l4.7.a
语境：p.l4.7.a

- [ ] 且庸人尚羞之 {#q.l4.7.3.o1}
  理由：这是他们拿一般人的羞耻感来责问相如。
- [ ] 且相如素贱人 {#q.l4.7.3.o2}
  理由：“素贱人”出自廉颇之口。
- [x] 徒慕君之高义也 {#q.l4.7.3.o3}

提示：先找“臣所以去亲戚而事君者”，把后半句接上。
解析：门客把追随的基础设为高义。如今他们把退让看作恐惧，自然就要问自己是否还该留下。

## 单选：只读“常称病”，为什么不能在病历上记蔺相如长期染疾？ {#q.l4.7.4}
考点：skill.l4.7.b
语境：p.l4.7.a

- [ ] “称病”在古书中无论何处都等于身体健康 {#q.l4.7.4.o1}
  理由：这个词不能单独证明健康或疾病。
- [x] 叙述紧跟着说他不欲争列，并另写路遇也避开 {#q.l4.7.4.o2}
- [ ] 门客声称相如怕廉颇，就能据此证明他身体一向很好 {#q.l4.7.4.o3}
  理由：门客是在解释退让，并未提供身体状况的证据。

提示：看看“每朝时”和后面路上相逢的两种场合。
解析：一到朝会便称病，又在路上避车，这些事都与避争相合。本文关心的正是这两件事为何一起发生。

## 找原文证据：相如先让门客比较秦王与廉颇。哪一句说出了他们承认的比较结果？ {#q.l4.7.5}
考点：skill.l4.7.a
语境：p.l4.7.b

- [x] 不若也 {#q.l4.7.5.o1}
- [ ] 相如虽驽 {#q.l4.7.5.o2}
  理由：这是相如自谦时说的话，不是门客的回答。
- [ ] 徒以吾两人在也 {#q.l4.7.5.o3}
  理由：这是相如接着说明秦为何不动赵。

提示：“公之视廉将军孰与秦王”下一句由谁作答？
解析：门客亲口承认廉将军不及秦王，这为相如举自己曾当廷呵斥秦王的事实铺了路。

## 单选：相如既已举出“廷叱”秦王，为什么还要添“两虎共斗”？ {#q.l4.7.6}
考点：skill.l4.7.b
语境：p.l4.7.b

- [x] 前例只够破除“怕廉颇”的猜测，虎斗才交代赵国为何经不起内争 {#q.l4.7.6.o1}
- [ ] 前例证明相如更能打，虎斗是约廉颇决斗 {#q.l4.7.6.o2}
  理由：后面说“其势不俱生”，正是应避免的危险。
- [ ] 要把秦王和相如各比作一虎 {#q.l4.7.6.o3}
  理由：强秦“不敢加兵”紧接“吾两人在”，两虎所指是赵国两臣。

提示：先问相如敢不敢，再问他愿不愿争。
解析：能压住一个更有威势的人，说明这里的退让另有原因。赵国倚重两人，才解释他选择退一步。

## 单选：见廉颇负荆到门，能为哪种理解添一条段内根据？ {#q.l4.7.7}
考点：skill.l4.7.a
语境：p.l4.7.b

- [ ] 相如早料到会获道歉，所以整段解释都只是设局 {#q.l4.7.7.o1}
  理由：结尾记廉颇的行动，未写相如事先预知。
- [ ] 当时强秦一定已决定撤军 {#q.l4.7.7.o2}
  理由：两位赵臣和解，不能代秦军下命令。
- [x] 相如的解释传到廉颇那里，确实引起他求和谢罪的行动 {#q.l4.7.7.o3}

提示：把“闻之”与“谢罪”接起来，别越过这层因果。
解析：接在引语后的行为能说明话被人听取并产生反应。它不能独立证实引语里的每一项战略判断。

## 排序：若代门客复述这番答话，怎样讲才保留相如说服他们的次序？ {#q.l4.7.8}
考点：skill.l4.7.b
语境：p.l4.7.b

- [3] 再明白相如容让，是要保存赵国倚重的两个人 {#q.l4.7.8.o1}
  理由：末一层才把私仇放到国事之后。
- [2] 想起相如曾在秦廷当面斥责更强者 {#q.l4.7.8.o2}
  理由：此例首先排除单纯畏惧。
- [1] 先承认廉将军的威势不及秦王 {#q.l4.7.8.o3}
  理由：这层比较由门客自己作出。

提示：“独畏……哉”回答了什么？“顾吾念之”又开启了什么？
解析：答话一半拆去旧解释，一半补出新解释。若只说廉颇终于道歉，便漏了相如怎样使门客改换眼光。
