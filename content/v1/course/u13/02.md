# 课文：荀子的并列与递进 {#l4.2}
简介：分别重建“善假于物”和“积而不舍”两段推理。

## 正文

登高招手、顺风呼喊，都没有把身体变强，却使看见、听见的人增加。荀子写到车马、舟楫，把同一种关系移到远行和渡水。先读每句中的否定，再找一句收束这些例子的总判断。

后段换了问题。积土、积水写由小而多；骐骥与驽马写一次与多次；两次“锲”又让读者看做与停带来的不同结果。给每一组各起一个小标题，再决定它们合起来能说明什么。驽马的例子并不保证任何人在相同时间内走得一样远。

## 知识点：并列例证的共同关系 {#skill.l4.2.a}
义项：从不同意象中抽取反复出现的关系
领域：篇章
要诀：把每组例子改写成同一语法结构
讲解：找到例子间可替换的部分和一直保留下来的关系，再以收束句检验。
例句：p.l4.2.a

## 知识点：对照所支持的结论 {#skill.l4.2.b}
义项：从一组对照判定作者能主张到哪一步
领域：阅读技能
要诀：指出比较中改变的是哪一项
讲解：不要给例子补上文中未经比较的条件，分清所证的因素和未经检验的因素。
例句：p.l4.2.b

## 原文：古籍引文 {#p.l4.2.a}
> 吾尝终日而思矣，不如须臾之所学也。吾尝跂而望矣，不如登高之博见也。登高而招，臂非加长也，而见者远；顺风而呼，声非加疾也，而闻者彰。假舆马者，非利足也，而致千里；假舟楫者，非能水也，而绝江河。君子生非异也，善假于物也。
译文：我曾整天独自思索，不及片刻所学；也曾踮脚远望，不及登高看得广。在高处招手，手臂没变长，远处却能看见；顺风呼喊，声音没变强，听来却清楚。借车马不靠脚快也能到千里外，借舟桨不会游水也能渡河。君子的禀性没有什么特别，他善于借助外物。

## 原文：古籍引文 {#p.l4.2.b}
> 积土成山，风雨兴焉；积水成渊，蛟龙生焉；积善成德，而神明自得，圣心备焉。故不积跬步，无以至千里；不积小流，无以成江海。骐骥一跃，不能十步；驽马十驾，功在不舍。锲而舍之，朽木不折；锲而不舍，金石可镂。
译文：土积成山，风雨从这里兴起；水积成深潭，蛟龙在这里生长；善行积成德，通明的智慧自然获得，圣人的心也就具备。小步不积到不了千里，小流不积成不了江海。良马跳一次走不了十步，驽马拉车走十天，功效在于不停。雕刻一会就停，连朽木也刻不断；不断刻下去，金石也能刻上花纹。

## 单选：车马与舟楫在段中共同担任何种论据？ {#q.l4.2.1}
考点：skill.l4.2.a
语境：p.l4.2.a

- [ ] 两种工具都能让人学会游泳 {#q.l4.2.1.o1}
  理由：“非能水也”保留不会游泳这个条件。
- [ ] 车马比舟楫更能说明个人天赋 {#q.l4.2.1.o2}
  理由：作者把两者并列，没有评定高下。
- [x] 借助合适工具，可以完成身体本身难以完成的事 {#q.l4.2.1.o3}

提示：把“假……者，非……也，而……”补完整。
解析：两例共享借物、身体能力并未改变、达成较大效果的结构。

## 找原文证据：哪句直接排除了“看得远是因为招手者手臂变长”的解释？ {#q.l4.2.2}
考点：skill.l4.2.b
语境：p.l4.2.a

- [ ] 而见者远 {#q.l4.2.2.o1}
  理由：这是要解释的效果。
- [ ] 不如登高之博见也 {#q.l4.2.2.o2}
  理由：这句比较两种望远方式，未直接说到手臂。
- [x] 臂非加长也 {#q.l4.2.2.o3}

提示：找紧跟在招手动作后的否定。
解析：作者特意保留臂长这个条件，好让高处的作用显出来。

## 单选：“君子生非异也”收束的是哪一串观察？ {#q.l4.2.3}
考点：skill.l4.2.a
语境：p.l4.2.a

- [ ] 四种工具各有同样的实际用途 {#q.l4.2.3.o1}
  理由：一个帮助人听见，一个帮助渡河，用途不同。
- [x] 借高处、风势和交通工具，常能放大效果 {#q.l4.2.3.o2}
- [ ] 只有君子能从别人处借到舟车 {#q.l4.2.3.o3}
  理由：文中举的是读者能认可的日常经验。

提示：看“善假于物”的“物”向前包括什么。
解析：“物”统摄具体助力，作者以此解释君子可贵之处。

## 单选：由“吾尝终日而思矣”能推出哪一判断？ {#q.l4.2.4}
考点：skill.l4.2.b
语境：p.l4.2.a

- [ ] 作者认为凡有思考便会妨碍学习 {#q.l4.2.4.o1}
  理由：“不如”比较所得，不是全面排除思考。
- [x] 作者在所作比较中更肯定从学习得到的收获 {#q.l4.2.4.o2}
- [ ] 时间越短，效果必定越好 {#q.l4.2.4.o3}
  理由：长短分别放在两种活动中，不能抽出独立规律。

提示：留意比较两端各在做什么。
解析：一端是整日思，一端是须臾所学；作者以自己的经验引入学习与借助外物的关系。

## 找原文证据：积土、积水之后，哪句话把论证转向人的修养？ {#q.l4.2.5}
考点：skill.l4.2.a
语境：p.l4.2.b

- [ ] 风雨兴焉 {#q.l4.2.5.o1}
  理由：这里仍说山中现象。
- [ ] 不积小流 {#q.l4.2.5.o2}
  理由：这是后文回到自然现象的反向说法。
- [x] 积善成德 {#q.l4.2.5.o3}

提示：寻找第三个“积”所接的对象。
解析：“善”与“德”接替土、山和水、渊，把多次善行与品德联系起来。

## 单选：良马和驽马这一组能支持哪一判断？ {#q.l4.2.6}
考点：skill.l4.2.b
语境：p.l4.2.b

- [ ] 驽马在同样长的时间内跑得比良马快 {#q.l4.2.6.o1}
  理由：比较的是一跃和十驾，时间并不相同。
- [ ] 良马只有换成驽马才能走远 {#q.l4.2.6.o2}
  理由：原文未讨论换马，只比较两种行进情形。
- [x] 一次突进有其限度，持续行进可以积功 {#q.l4.2.6.o3}

提示：对照“一跃”和“十驾”。
解析：作者有意把良马的短促一跃与驽马的持续前行并置，最后点出“不舍”。

## 排序：按作者从积累转向坚持的铺陈排列。 {#q.l4.2.7}
考点：skill.l4.2.a
语境：p.l4.2.b

- [1] 举土、水与善行的积累 {#q.l4.2.7.o1}
  理由：三个“积”正面举出由小而成。
- [3] 以马行与雕刻对照是否坚持 {#q.l4.2.7.o2}
  理由：“一跃／十驾”与“舍／不舍”是后面的持久对比。
- [2] 从缺少跬步、小流反说其必要 {#q.l4.2.7.o3}
  理由：“故不积”接着改用反面的说法。

提示：依次找“积”“不积”“不舍”。
解析：同一论旨先正说结果，再反说缺少积累，最后落实到能不能持久。

## 单选：刻朽木与刻金石为什么故意选难度悬殊的材料？ {#q.l4.2.8}
考点：skill.l4.2.b
语境：p.l4.2.b

- [ ] 金石本来比朽木更软 {#q.l4.2.8.o1}
  理由：这会破坏作者用难易反差凸显坚持的写法。
- [x] 即使容易的会因停止而失败，困难的也有因坚持而成的可能 {#q.l4.2.8.o2}
- [ ] 说明选择材料对雕刻毫无影响 {#q.l4.2.8.o3}
  理由：“可镂”不等于所有材料耗时相等。

提示：把材料难易和动作“舍／不舍”分别标出来。
解析：作者使材料的有利与不利条件逆向排列，突出是否持续用力。
