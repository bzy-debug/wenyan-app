# 课文：船帮人渡江，驽马又说明了什么？ {#l4.2}
简介：同一篇《劝学》两度写到千里。读清荀子在什么地方讲借力，什么地方讲日积月累。

## 正文

先踮脚，再登高；先在高处招手，再顺风呼喊。若只记景象，几例好像都是人在努力。留意荀子自己补的否定：手臂没有变长，声音没有变强。不变的和变好的成对出现，才看出高处、顺风起了什么作用。舟楫一例也一样。能渡过水面，未必是掌舟的人本来就能泅水。

两段都写到千里，不能互换。第一段是“假舆马者……致千里”，人的双脚没有格外便利，车马替他延伸了行程；第二段是“不积跬步，无以至千里”，指一次又一次迈步。把它们各自的结句抄在旁边，一句落在“善假”，另一组落在“不舍”。

试读骏马和劣马的反差。荀子给前者一次跳跃，给后者接连走十程；这当然不是一场公平的赛跑。正因起点差、用力的次数也不同，驽马的进境才足以反问：只看一次表现，凭什么就评定日后的成就？

## 知识点：辨认一组譬喻共同的关系 {#skill.l4.2.a}
义项：找出形象虽异、反复成立的条件与效果
领域：篇章
要诀：登高、顺风、乘车、乘船，换了哪样条件？
讲解：手臂、嗓音、双脚并未先变强，原本难以做到的事却做到了。把这一层保留下来，换个例子仍能讲明“假于物”。
例句：p.l4.2.a

## 知识点：给对比的结论划定范围 {#skill.l4.2.b}
义项：读出比较中保持和改变的条件，避免把推论扩大
领域：阅读技能
要诀：不要只比骐骥与驽马，还要比“一跃”和“十驾”。
讲解：这段证明不断用力能够积功；它没有拿两匹马用同样长的时间测速度。多辨清一个条件，就少下一个未经证明的结论。
例句：p.l4.2.b

## 原文：古籍引文 {#p.l4.2.a}
> 吾尝终日而思矣，不如须臾之所学也。吾尝跂而望矣，不如登高之博见也。登高而招，臂非加长也，而见者远；顺风而呼，声非加疾也，而闻者彰。假舆马者，非利足也，而致千里；假舟楫者，非能水也，而绝江河。君子生非异也，善假于物也。
译文：我曾整天思量，不如片刻中学到的多；曾踮脚张望，不如站高处看得广。登高招手，臂未伸长，却能让远处的人看见；顺风呼喊，声音未加大，听者却听得分明。凭车马行远的人不必脚快，借船桨过江的人不必自己会游水。君子的禀性没有特别之处，他善于借助外在条件。
词注：假：凭借、利用。
  绝：横渡江河。
  疾：这里形容声音强，不讲速度。

## 原文：古籍引文 {#p.l4.2.b}
> 积土成山，风雨兴焉；积水成渊，蛟龙生焉；积善成德，而神明自得，圣心备焉。故不积跬步，无以至千里；不积小流，无以成江海。骐骥一跃，不能十步；驽马十驾，功在不舍。锲而舍之，朽木不折；锲而不舍，金石可镂。
译文：土一点点堆成山，风雨从那里兴起；水汇成深渊，蛟龙便生于其中；善行积出德性，高明的见识也随之而来，圣人的心境由此具备。所以小步不积，哪里能到千里之外？细流不汇，又拿什么成江海？好马一跳也走不了十步，慢马连走十程，功劳在不放弃。刻一会儿便停，朽木也刻不断；刻个不停，金石也能刻出纹来。
词注：跬步：很小的步子。
  无以：没有可用来做成某事的办法。
  舍：停止、放下正在做的事。

## 单选：“跂而望”不如“登高”，和开头“终日而思”有什么关系？ {#q.l4.2.1}
考点：skill.l4.2.a
语境：p.l4.2.a

- [ ] 站得越久看得越远，所以独自思考贵在持久 {#q.l4.2.1.o1}
  理由：“终日”的思考反而不如短时学习。
- [ ] 登高能让眼睛变好，正如背书能改善天性 {#q.l4.2.1.o2}
  理由：接下来反复说人的身体条件未变。
- [x] 踮脚仍受原地视野所限，登高让“换一种求知办法”变得可见 {#q.l4.2.1.o3}

提示：先辨“终日”和“须臾”各修饰什么，再读同样的“不如”。
解析：两次“不如”把道理接起来。花的力气未必小，若始终靠原有条件，看到的仍有限。

## 找原文证据：荀子写到船以后，哪句专门堵住“渡江是因为这人会游水”的解释？ {#q.l4.2.2}
考点：skill.l4.2.b
语境：p.l4.2.a

- [ ] 而绝江河 {#q.l4.2.2.o1}
  理由：这说的是他做成了什么。
- [ ] 善假于物也 {#q.l4.2.2.o2}
  理由：这是整组例证的概括，尚未指出渡江者缺少哪种本领。
- [x] 非能水也 {#q.l4.2.2.o3}

提示：“水”在这句话里可以换作一个动作。
解析：渡江是事实，会游泳却没有被当成原因。把两件事隔开，船桨能帮什么忙才看得分明。

## 单选：把“臂非加长”与“声非加疾”都删掉，论证会少交代什么？ {#q.l4.2.3}
考点：skill.l4.2.a
语境：p.l4.2.a

- [ ] 借助外物可以省去招手、发声这些动作 {#q.l4.2.3.o1}
  理由：登高的人仍招手，顺风的人仍开口。
- [x] 招手和呼喊传得更远，并不需要人自身先变得更强 {#q.l4.2.3.o2}
- [ ] 高处和顺风究竟哪个办法更有效 {#q.l4.2.3.o3}
  理由：原文没有在二者之间作高下比较。

提示：只留下“见者远”“闻者彰”再读一次。
解析：剩下的只是效果好。两句否定原本说明的是效果为什么好：改变的是位置、风向等条件。

## 单选：有人把末句概括为“君子天生眼力比人好”。先用哪一组对应来检验？ {#q.l4.2.4}
考点：skill.l4.2.b
语境：p.l4.2.a

- [ ] “利足”和“致千里”合说君子生来擅跑 {#q.l4.2.4.o1}
  理由：前面明说“非利足”。
- [x] “生非异”说禀赋，“善假”说他怎样用已有条件 {#q.l4.2.4.o2}
- [ ] “闻者彰”就是听者天生听力明敏 {#q.l4.2.4.o3}
  理由：“顺风”先交代了可听清的条件，未说听者天资提升。

提示：读到“非”不要停，把最后四字也带上。
解析：结尾把“天生不同”和“会利用外物”分开。早先的舟车正是后一项的具体说明。

## 找原文证据：由小步走到远处，原文哪几个字明说缺了日常积累就无从到达？ {#q.l4.2.5}
考点：skill.l4.2.a
语境：p.l4.2.b

- [ ] 骐骥一跃，不能十步 {#q.l4.2.5.o1}
  理由：这里换成了骏马一次跳跃的对照。
- [ ] 积善成德 {#q.l4.2.5.o2}
  理由：这句落在修养上，还没有把小步和远路连起来。
- [x] 不积跬步，无以至千里 {#q.l4.2.5.o3}

提示：留心表示必要条件的“无以”。
解析：“无以”说没有凭借、没有办法。单次的小步似乎不多，每一步却是行远的条件。

## 单选：驽马为何能和骐骥放在一起谈？ {#q.l4.2.6}
考点：skill.l4.2.b
语境：p.l4.2.b

- [ ] 两匹马在相同路程里赛跑，驽马速度更快 {#q.l4.2.6.o1}
  理由：二者发力的次数和时长不同。
- [ ] 骐骥本来只适合拉车，不能跑长路 {#q.l4.2.6.o2}
  理由：文中只限制“一跃”所及，并没有给马下这种定论。
- [x] 作者故意让较弱的马走许多程，同较强的马只跳一次相较 {#q.l4.2.6.o3}

提示：在“骐骥”后圈“一”，在“驽马”后圈“十”。
解析：这是天资与持续用力的对照，不是同场测速。“功在不舍”直接指明荀子关心的差别。

## 排序：把“积”一段的推理次序摆出来。 {#q.l4.2.7}
考点：skill.l4.2.a
语境：p.l4.2.b

- [1] 从土、水聚集讲到积善成德 {#q.l4.2.7.o1}
  理由：开头三句都从一点点累积写起。
- [3] 再拿快马慢马、停刻续刻说明何以贵在不停 {#q.l4.2.7.o2}
  理由：驽马和金石都在最后两组对照中出现。
- [2] 翻过来说，不积小步、小流便难到远处 {#q.l4.2.7.o3}
  理由：“故不积”将刚才的正面说法倒过来检验。

提示：三个位置依次找“积”“不积”“不舍”。
解析：同一道理经过三番检验：积得起来、缺了不成、条件差也能靠持续用力前进。

## 单选：读到“金石可镂”，能从这组比照里推出哪一句？ {#q.l4.2.8}
考点：skill.l4.2.b
语境：p.l4.2.b

- [ ] 一开始就应该挑最硬的东西练，以免在朽木上浪费时间 {#q.l4.2.8.o1}
  理由：木与金石用来显示难易，文中没有规定选材。
- [x] 材料难刻仍可以留下刻痕，关键在是否坚持刻下去 {#q.l4.2.8.o2}
- [ ] 坚持越久，做任何事都一定成功 {#q.l4.2.8.o3}
  理由：本段说的是积累及雕刻的譬喻，没逐项保证所有结果。

提示：两处“锲而”之后，最小的一字之别是什么？
解析：舍与不舍是作者点出的关节。解释要能同时说清易刻的朽木为什么没断、难刻的金石为什么能留痕。
