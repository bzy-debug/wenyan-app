# 课文：荀子借舟车、驽马讲什么道理 {#l4.2}
简介：借来一条船，人没学会游水，却能渡河。读荀子的例子，分清变了什么、没变什么。

## 正文

站得高些招手，手臂没有变长，远处的人却能看见。顺风呼喊，嗓音没有变强，别人听得却更清楚。读到车马、舟楫，不妨照样问：人身上的哪样本事没有变？有了外物相助，又办成了什么事？到“善假于物也”，这些例子就有了共同的落脚处。“假”在这里是借助。

后段转谈积累。土积起来成山，水积起来成渊；轮到人，多次善行也能积成品德。骐骥和驽马这一对要多看一眼：一匹只跳一次，一匹拉车走了十天。读作“驽马比良马快”就漏掉了这一长一短。“功在不舍”说的是不停。

## 知识点：几个例子共同说明什么 {#skill.l4.2.a}
义项：从并排举出的几个例子里，看出它们共同说明的道理
领域：篇章
要诀：把“没有变的本事”和“办成的事”并排读。
讲解：人不会游水，借舟却能过河。用这个问法再看车马、高处和风，就明白荀子为何接连举例。
例句：p.l4.2.a

## 知识点：对照所支持的结论 {#skill.l4.2.b}
义项：弄清两样东西比的是哪一点，判断这个比较能说明什么
领域：阅读技能
要诀：先看看两边究竟差在什么地方。
讲解：骐骥“一跃”，驽马“十驾”。两马走的时日不同，这一例能说明坚持有功，不能替它们评速度。
例句：p.l4.2.b

## 原文：古籍引文 {#p.l4.2.a}
> 吾尝终日而思矣，不如须臾之所学也。吾尝跂而望矣，不如登高之博见也。登高而招，臂非加长也，而见者远；顺风而呼，声非加疾也，而闻者彰。假舆马者，非利足也，而致千里；假舟楫者，非能水也，而绝江河。君子生非异也，善假于物也。
译文：我曾整天独自思索，所得还不及学习片刻；也曾踮起脚远望，终究没有登高看得远。在高处招手，手臂没变长，远处却能看见；顺风呼喊，声音没变强，听来却清楚。借车马不靠脚快也能到千里外，借舟桨不会游水也能渡河。君子的禀性没有什么特别，他善于借助外物。

## 原文：古籍引文 {#p.l4.2.b}
> 积土成山，风雨兴焉；积水成渊，蛟龙生焉；积善成德，而神明自得，圣心备焉。故不积跬步，无以至千里；不积小流，无以成江海。骐骥一跃，不能十步；驽马十驾，功在不舍。锲而舍之，朽木不折；锲而不舍，金石可镂。
译文：土积成山，风雨从这里兴起；水积成深潭，蛟龙在这里生长；善行积成德，通明的智慧自然获得，圣人的心也就具备。小步不积到不了千里，小流不积成不了江海。良马跳一次走不了十步，驽马拉车走十天，功效在于不停。雕刻一会就停，连朽木也刻不断；不断刻下去，金石也能刻上花纹。

## 单选：荀子连续说借车马、借舟楫，两件事一起说明什么？ {#q.l4.2.1}
考点：skill.l4.2.a
语境：p.l4.2.a

- [ ] 两种工具都能让人学会游泳 {#q.l4.2.1.o1}
  理由：“非能水也”保留不会游泳这个条件。
- [ ] 车马比舟楫更能说明个人天赋 {#q.l4.2.1.o2}
  理由：作者把两者并列，没有评定高下。
- [x] 借助合适工具，可以完成身体本身难以完成的事 {#q.l4.2.1.o3}

提示：把“假……者，非……也，而……”补完整。
解析：借车马的人未必脚快，借船的人也不必会游水。身体的本领没变，却能远行、渡河，靠的是合适的工具。

## 找原文证据：哪句直接排除了“看得远是因为招手者手臂变长”的解释？ {#q.l4.2.2}
考点：skill.l4.2.b
语境：p.l4.2.a

- [ ] 而见者远 {#q.l4.2.2.o1}
  理由：远处的人看见招手，正是要解释的现象；手臂有没有变长，还得看前一句。
- [ ] 不如登高之博见也 {#q.l4.2.2.o2}
  理由：这句比较两种望远方式，未直接说到手臂。
- [x] 臂非加长也 {#q.l4.2.2.o3}

提示：找紧跟在招手动作后的否定。
解析：“臂非加长也”明说手臂没变长。这样一来，远处能看见招手，该归功于人站得高。

## 单选：“君子生非异也”之前，哪些例子给这句话作了铺垫？ {#q.l4.2.3}
考点：skill.l4.2.a
语境：p.l4.2.a

- [ ] 四种工具各有同样的实际用途 {#q.l4.2.3.o1}
  理由：一个帮助人听见，一个帮助渡河，用途不同。
- [x] 借高处、风势和交通工具，常能放大效果 {#q.l4.2.3.o2}
- [ ] 只有君子能从别人处借到舟车 {#q.l4.2.3.o3}
  理由：文中举的是读者能认可的日常经验。

提示：看“善假于物”的“物”向前包括什么。
解析：高处帮人招手，顺风帮人传声，车马和舟楫帮人远行。荀子把这些合在“善假于物”一句里，说明君子善于借助外物。

## 单选：由“吾尝终日而思矣”能推出哪一判断？ {#q.l4.2.4}
考点：skill.l4.2.b
语境：p.l4.2.a

- [ ] 作者认为凡有思考便会妨碍学习 {#q.l4.2.4.o1}
  理由：“不如”比较所得，不是全面排除思考。
- [x] 作者在所作比较中更肯定从学习得到的收获 {#q.l4.2.4.o2}
- [ ] 时间越短，效果必定越好 {#q.l4.2.4.o3}
  理由：长短分别放在两种活动中，不能抽出独立规律。

提示：留意比较两端各在做什么。
解析：荀子拿自己终日独自思索，和片刻有所学习相比，说后者收获大。这句话没有说思考本身有害。

## 找原文证据：积土、积水之后，哪句话把论证转向人的修养？ {#q.l4.2.5}
考点：skill.l4.2.a
语境：p.l4.2.b

- [ ] 风雨兴焉 {#q.l4.2.5.o1}
  理由：“风雨兴焉”接的是积土成山，还没转到人的善行。
- [ ] 不积小流 {#q.l4.2.5.o2}
  理由：“不积小流”又举流水作比，要找转到人身上的一句，还得回看“善”。
- [x] 积善成德 {#q.l4.2.5.o3}

提示：寻找第三个“积”所接的对象。
解析：土积成山，水积成渊，写到第三次“积”，所积的是“善”，所得的是“德”。这才落到了人的修养上。

## 单选：良马和驽马这一组能支持哪一判断？ {#q.l4.2.6}
考点：skill.l4.2.b
语境：p.l4.2.b

- [ ] 驽马在同样长的时间内跑得比良马快 {#q.l4.2.6.o1}
  理由：比较的是一跃和十驾，时间并不相同。
- [ ] 良马只有换成驽马才能走远 {#q.l4.2.6.o2}
  理由：原文未讨论换马，只比较两种行进情形。
- [x] 一次突进有其限度，持续行进可以积功 {#q.l4.2.6.o3}

提示：对照“一跃”和“十驾”。
解析：骐骥跳一次，驽马却走了十天。荀子说驽马也能积功，特意将缘故点作“不舍”。

## 排序：按作者从积累转向坚持的铺陈排列。 {#q.l4.2.7}
考点：skill.l4.2.a
语境：p.l4.2.b

- [1] 举土、水与善行的积累 {#q.l4.2.7.o1}
  理由：三个“积”正面举出由小而成。
- [3] 以马行与雕刻对照是否坚持 {#q.l4.2.7.o2}
  理由：“一跃／十驾”与“舍／不舍”是后面的持久对比。
- [2] 从缺少跬步、小流反说其必要 {#q.l4.2.7.o3}
  理由：“故不积”接着改用反面的说法。

提示：依次找“积”“不积”“不舍”。
解析：开头正说积少能成什么，接着反问不积小步、小流还能不能至远成海。末了用马行、雕刻说怎样坚持下去。

## 单选：荀子把朽木和金石放在一起讲，想说明什么？ {#q.l4.2.8}
考点：skill.l4.2.b
语境：p.l4.2.b

- [ ] 金石本来比朽木更软 {#q.l4.2.8.o1}
  理由：金石比朽木难刻。难刻的东西，荀子为什么还说“可镂”？
- [x] 即使容易的会因停止而失败，困难的也有因坚持而成的可能 {#q.l4.2.8.o2}
- [ ] 说明选择材料对雕刻毫无影响 {#q.l4.2.8.o3}
  理由：“可镂”是说刻得动。荀子还特意写了“不舍”，得一直刻下去。

提示：把材料难易和动作“舍／不舍”分别标出来。
解析：朽木容易刻，半途停手也刻不断；金石难刻，不停手也有刻成的可能。这一难一易，衬出“舍”和“不舍”的差别。
