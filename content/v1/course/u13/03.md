# 课文：韩非为何把古人的办法换个时代再试 {#l4.3}
简介：洪水来了要疏水，暴君当道又该怎么办？读韩非怎样把古人的办法放到另一个时代去试。

## 正文

先把办法配回它要解决的事。天下发大水，鲧、禹疏通水道；桀、纣暴虐，汤、武起兵征伐。韩非接着把时代调换：若有人碰上桀、纣之乱还只知疏水，汤、武会怎么看？两处“必为……笑矣”都是韩非设想的反应。读到最后一次“笑”，才看出他想问的是当时一心赞美古法的人。

后段又把古今放在一起看。为什么从前“民不争”，如今却“民争”？韩非先算一家五子怎样变为二十五孙，再说人多而财少，虽费力劳作仍不够用。争夺是这样一步步解释出来的。这是韩非在文中的说法；要了解各时代实际有多少人口、物资，还得另有史料。

## 知识点：换个时代，旧法还管用吗 {#skill.l4.3.a}
义项：换个时代或处境，看原先的办法还能不能解决问题
领域：篇章
要诀：古法原来要解什么难题？拿到另一个时代，难题还一样吗？
讲解：鲧禹治水本来得当，可桀纣暴乱时只会疏河，就答非所问了。韩非用设想让办法和当时的需要相对照。
例句：p.l4.3.a

## 知识点：时势怎样影响治国的办法 {#skill.l4.3.b}
义项：找出时代条件变了，治国的办法也要跟着变的具体理由
领域：阅读技能
要诀：从“民多”到“民争”，中间写了什么？
讲解：一家二十五孙只能说明人口增长。韩非接着讲货财少、劳作辛苦而所得不足，才用“故”说到争夺。
例句：p.l4.3.b

## 原文：古籍引文 {#p.l4.3.a}
> 中古之世，天下大水，而鲧禹决渎；近古之世，桀纣暴乱，而汤武征伐。今有构木钻燧于夏后氏之世者，必为鲧禹笑矣；有决渎于殷周之世者，必为汤武笑矣。然则今有美尧舜汤武禹之道于当今之世者，必为新圣笑矣。是以圣人不期修古，不法常行，论世之事，因为之备。
译文：中古遭洪水，鲧禹疏导水道；近古桀纣暴乱，汤武起兵征讨。假使有人在夏代还专做架木、钻火的事，就会被鲧禹笑；在殷周专做疏水的事，就会被汤武笑。那么在今天只赞美古圣之道，也会被当世明者笑。圣人不求照搬古代，不把惯例当固定准则；他考察当世之事，依此作准备。

## 原文：古籍引文 {#p.l4.3.b}
> 古者丈夫不耕，草木之实足食也；妇女不织，禽兽之皮足衣也。不事力而养足，人民少而财有余，故民不争，是以厚赏不行，重罚不用，而民自治。今人有五子不为多，子又有五子，大父未死而有二十五孙，是以人民众而货财寡，事力劳而供养薄，故民争。虽倍赏累罚而不免于乱。
译文：作者说，古时男子不耕、女子不织，野果与兽皮便够吃穿。人少物足，所以不必重赏重罚而人们能自治。如今一人有五子不算多，儿子又各生五子，祖父在世就有二十五孙。人多而物资少，费力劳动而所得薄，于是发生争夺；即使增加赏罚也免不了动乱。

## 单选：汤武“笑”只知疏水的人，这一幕是怎样写出来的？ {#q.l4.3.1}
考点：skill.l4.3.a
语境：p.l4.3.a

- [x] 把治理水患的办法挪到讨伐暴君的处境所作的设想 {#q.l4.3.1.o1}
- [ ] 证明水利工程在任何时代都无益 {#q.l4.3.1.o2}
  理由：开头明说鲧禹所处的是天下大水之时。
- [ ] 汤武亲自嘲笑鲧禹的一次史实 {#q.l4.3.1.o3}
  理由：引出此事的是“有……者”，前后的人物并非实际会面。

提示：看“有……者，必……”的结构。
解析：韩非并没有记两代人见过面。他把能疏水的人放进汤武所面对的时代，设想那时的人会怎么评价这种办法。

## 找原文证据：哪一处明说疏导水道之所以切合当时的问题？ {#q.l4.3.2}
考点：skill.l4.3.b
语境：p.l4.3.a

- [ ] 不法常行 {#q.l4.3.2.o1}
  理由：“不法常行”是读完几个时代的例子所得的结论。疏河为什么合适，要往前看鲧、禹所处的情形。
- [x] 天下大水 {#q.l4.3.2.o2}
- [ ] 桀纣暴乱 {#q.l4.3.2.o3}
  理由：桀、纣暴乱引出汤、武征伐。题目问的是前面那一对，鲧、禹为何疏水。

提示：找“而鲧禹决渎”紧接的处境。
解析：“天下大水”先点出当时急待解决的问题，“而鲧禹决渎”才说他们用什么办法应对。

## 单选：“新圣笑”承接两次古人之笑，想让当时人重新考虑什么？ {#q.l4.3.3}
考点：skill.l4.3.a
语境：p.l4.3.a

- [ ] 古代哪些君王最爱取笑别人 {#q.l4.3.3.o1}
  理由：笑是设例中的反应，不是人物性格材料。
- [x] 赞古者能否说明古法适合今日要解决的事 {#q.l4.3.3.o2}
- [ ] 新圣是否也能重复尧舜所有功绩 {#q.l4.3.3.o3}
  理由：作者的反问方向是古法能否适今，并未比功。

提示：比较三次“笑”中被笑者的共同点。
解析：前两次被笑的人，都只会拿旧时的办法解眼前的难题。到第三次“笑”，韩非把同一个问题转向今日推崇古法的人。

## 单选：“因为之备”中的“因”承接什么？ {#q.l4.3.4}
考点：skill.l4.3.b
语境：p.l4.3.a

- [x] 考察当世事务所得的实际情形 {#q.l4.3.4.o1}
- [ ] 鲧禹当年受笑的经历 {#q.l4.3.4.o2}
  理由：文中设想受笑的是错用方法的人。
- [ ] 古圣留下的一套恒常行动 {#q.l4.3.4.o3}
  理由：上文说“不法常行”。

提示：往前看看，“论”的究竟是古例还是当世之事？
解析：“论世之事”是先考察当世的事，“因”是依照考察所得的情形，“为之备”才是据此作应对。

## 单选：古今两段怎样检验“古时少用赏罚，今日也应如此”的推论？ {#q.l4.3.5}
考点：skill.l4.3.a
语境：p.l4.3.b

- [ ] 证明古人从来没有任何规定 {#q.l4.3.5.o1}
  理由：作者说的是厚赏重罚在所论处境下不用。
- [ ] 把一家五子当成古人生活方式的证据 {#q.l4.3.5.o2}
  理由：五子的例子列在“今人”之后。
- [x] 把两时的人口与财物条件摊开，看前提是否仍在 {#q.l4.3.5.o3}

提示：找两个时代各自“故”之前的条件。
解析：古时人少、物有余，今日人多、所分薄。韩非把这两种处境列出来，让人看看原来的赏罚之法是否还能照搬。

## 单选：韩非数到“二十五孙”，是要先说明什么？ {#q.l4.3.6}
考点：skill.l4.3.b
语境：p.l4.3.b

- [ ] 说明祖父偏爱孙辈导致争产 {#q.l4.3.6.o1}
  理由：原文没有写家庭偏爱。
- [x] 具体说明人口如何在几代间增加 {#q.l4.3.6.o2}
- [ ] 直接证明重罚必能平乱 {#q.l4.3.6.o3}
  理由：结尾反说加码仍可能乱。

提示：看这一计算后面的“是以”先谈什么。
解析：从五子数到二十五孙，先说清人怎样多起来。后文还要写人多财少、劳而所得薄，才说到为什么相争。

## 找原文证据：与古时“不事力而养足”构成直接反向比较的是哪一句？ {#q.l4.3.7}
考点：skill.l4.3.a
语境：p.l4.3.b

- [ ] 今人有五子不为多 {#q.l4.3.7.o1}
  理由：五子写一家怎样繁衍；要对应“不事力而养足”，还须找到劳动和所得。
- [x] 事力劳而供养薄 {#q.l4.3.7.o2}
- [ ] 虽倍赏累罚 {#q.l4.3.7.o3}
  理由：“倍赏累罚”已经谈到争夺出现后怎样治理，没说劳作和所得。

提示：在写“今人”的几句里，找人辛苦到什么程度、所得够不够。
解析：古时不用费力而供养充足，今日费力劳作仍不够用。两句都写出了劳动多少和所得厚薄，正好可以对读。

## 排序：按韩非在今人一段中提出的解释次序排列。 {#q.l4.3.8}
考点：skill.l4.3.b
语境：p.l4.3.b

- [3] 谋生所得不足，引出争夺 {#q.l4.3.8.o1}
  理由：“故民争”把社会后果放在资源变化之后。
- [1] 世代繁衍使人口增多 {#q.l4.3.8.o2}
  理由：祖父、子、孙的数字先展示人口增长。
- [2] 人与货财之间渐趋紧张 {#q.l4.3.8.o3}
  理由：“是以人民众而货财寡”承接人口计算。

提示：追踪“是以”和“故”各接什么。
解析：先写人口世代繁衍，再说人多财少。直到“事力劳而供养薄”，才出现他用“故”引出的最后一步：人于是相争。
