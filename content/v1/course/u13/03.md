# 课文：把同一个办法放到另一个时代 {#l4.3}
简介：如果把治洪水的本领拿来应付桀纣的暴政，仍算善治吗？韩非让古今相互对照。

## 正文

鲧、禹面前是泛滥的大水，再好的办法也得先对付水；汤、武面对桀、纣，难处却不在水道。留心两次“有……者，必为……笑”，它们都是设想。韩非没有记鲧、禹某天真的笑过造屋的人，而是把一件从前有用的事送到另一种困境里，请读者看它还能解决什么。

“今”一出现，读者才发现这一问也是问自己。有人盛赞先王之道，韩非请他先“论世之事”。“因为之备”当作“依着它另作准备”读；别让今天相连的“因为”遮住那个表示依凭的“因”。

第二段把“今昔条件不同”落实在供养问题上。先看人口和可用财物的关系，再读争夺从哪里来。祖父尚在而孙辈已多的算例不是人口调查，却使一句“人民众”有了可想见的来历。文末即使加重赏罚也未免于乱，还不能反过来说韩非凭这一例便证成了任何一种政策。

## 知识点：检验事例换了条件是否仍适用 {#skill.l4.3.a}
义项：辨明旧事所解决的问题，再比较换时换地后的问题
领域：篇章
要诀：给“决渎”“征伐”各配回当时的难处。
讲解：前人的事迹受推崇，并不自动回答今日所需。韩非有意让决水道的人碰上另一个时代，迫使人指出原先成功的条件。
例句：p.l4.3.a

## 知识点：从时势读出作者的政策理由 {#skill.l4.3.b}
义项：接起人口、财物、行为与治理效果，循文判断作者主张
领域：阅读技能
要诀：“是以”“故”“虽”分别把道理推进到哪里了？
讲解：古时财用够、人少争，是文中所设的一种条件；到了劳苦而所得薄之时，就不能只问赏罚比过去重了几倍。
例句：p.l4.3.b

## 原文：古籍引文 {#p.l4.3.a}
> 中古之世，天下大水，而鲧禹决渎；近古之世，桀纣暴乱，而汤武征伐。今有构木钻燧于夏后氏之世者，必为鲧禹笑矣；有决渎于殷周之世者，必为汤武笑矣。然则今有美尧舜汤武禹之道于当今之世者，必为新圣笑矣。是以圣人不期修古，不法常行，论世之事，因为之备。
译文：到中古时，天下洪水泛滥，鲧、禹疏通水道；到近古时，桀、纣暴虐作乱，汤、武便出兵讨伐。如果有人在夏代把架木造屋、钻木取火当治世办法，必会让鲧、禹笑话；到了殷周还只会疏通河渠，也会被汤、武笑话。这样推来，如今若只盛赞尧、舜、汤、武、禹的旧道，新圣人也要笑了。因此圣人不以复古为目标，不一味仿效常例，而是观察当世之事，按其需要设法应对。
词注：决渎：开通水道以疏泄洪水。
  期：以……为目标、指望。
  法：效法，拿来作准则。

## 原文：古籍引文 {#p.l4.3.b}
> 古者丈夫不耕，草木之实足食也；妇女不织，禽兽之皮足衣也。不事力而养足，人民少而财有余，故民不争，是以厚赏不行，重罚不用，而民自治。今人有五子不为多，子又有五子，大父未死而有二十五孙，是以人民众而货财寡，事力劳而供养薄，故民争。虽倍赏累罚而不免于乱。
译文：古时男子不耕种，草木的果实也够吃；女子不纺织，兽皮也足以蔽体。不费许多力气便能生活，人少而财物有余，所以少争；不用厚赏重罚，民间也有秩序。如今一家有五个儿子还不算多，儿子们又各有五子，祖父在世便可有二十五个孙子。于是人多财少，劳作辛苦而供养微薄，争夺随之而起；即使加重赏罚也避免不了混乱。这是韩非对古今处境的陈说。

## 单选：洪水时有人疏通河道，暴君当政时有人起兵。韩非为何先把这两件事写在一起？ {#q.l4.3.1}
考点：skill.l4.3.a
语境：p.l4.3.a

- [x] 让读者看见当时各有要解决的事，才好追问照搬到后世行不行 {#q.l4.3.1.o1}
- [ ] 排出古代圣人的座次，越晚出生越高明 {#q.l4.3.1.o2}
  理由：“笑”的对象是用错时机的人，不是被排座次的古人。
- [ ] 证明征伐与治水须由同一位君主同时推行 {#q.l4.3.1.o3}
  理由：两事分别系在不同年代。

提示：给两件事各补一个“为了解决……”。
解析：治水对洪灾，征伐对暴乱。先立住办法与处境的对应，后面的错置才有可笑之处。

## 找原文证据：“圣人不期修古”后，哪一句正面说明怎样找因应当世的办法？ {#q.l4.3.2}
考点：skill.l4.3.b
语境：p.l4.3.a

- [ ] 不法常行 {#q.l4.3.2.o1}
  理由：这仍在说什么不该照搬。
- [x] 论世之事，因为之备 {#q.l4.3.2.o2}
- [ ] 今有构木钻燧于夏后氏之世者 {#q.l4.3.2.o3}
  理由：这是设想用错年代的一例。

提示：找带“为之备”的话，“之”接回前面要考察的事。
解析：“因”承接所考察的时势，随后才有相应的措施。作者并没有叫人凡见古法便弃。

## 单选：“今有构木钻燧于夏后氏之世者”是韩非在报告史实吗？ {#q.l4.3.3}
考点：skill.l4.3.a
语境：p.l4.3.a

- [ ] 是说鲧、禹亲眼看见这人，后来据实作了记载 {#q.l4.3.3.o1}
  理由：“今有……者，必……”是在作设想。
- [x] 是在假设把早期的办法搬进另一时世，看会得到什么评价 {#q.l4.3.3.o2}
- [ ] 是说夏时从未有人造屋取火 {#q.l4.3.3.o3}
  理由：是否有人日常取火，不是这次治世比较的问题。

提示：把“有……者，必为……笑”换成“若有人……”。
解析：韩非让古人也成为评判者，使当代人尊古的主张受同一种检验。这里不需补写一场相遇。

## 单选：若以“先王中有人成功过”作结，韩非还会追问什么？ {#q.l4.3.4}
考点：skill.l4.3.b
语境：p.l4.3.a

- [x] 先王面对的事与今天待解决的事，还有哪些相同之处 {#q.l4.3.4.o1}
- [ ] 今天的人称颂先王，是不是已经有了同样的成效 {#q.l4.3.4.o2}
  理由：赞美是对旧事的评价，要检验的是当下能否办成相应之事。
- [ ] 先王被尊为圣人以前是否从未遭人嘲笑 {#q.l4.3.4.o3}
  理由：他设想的是办法换个年代的效果。

提示：回到结尾“论世之事”的“世”。
解析：旧办法是否切题，要比较两次面对的难处。受人称颂本身不能证明拿来就有效。

## 单选：过去赏罚很少动用，文中能直接支持的缘由是哪一项？ {#q.l4.3.5}
考点：skill.l4.3.a
语境：p.l4.3.b

- [ ] 当时掌权者从来不设赏罚 {#q.l4.3.5.o1}
  理由：“不行”“不用”写未施行，不等于从无制度。
- [ ] 古时有重赏严罚但始终秘密施行 {#q.l4.3.5.o2}
  理由：本段写其不必动用；并无秘密执法一层。
- [x] 人口少而财用足，人之间少有争夺 {#q.l4.3.5.o3}

提示：“故民不争”之前讲人和物各是什么情形？
解析：韩非将不争放在物产和人口的关系之后；事情少起争端，赏罚不用也能维持秩序。

## 单选：祖父健在而已有二十五个孙子，这笔数在论证里做什么？ {#q.l4.3.6}
考点：skill.l4.3.b
语境：p.l4.3.b

- [ ] 精确统计天下每一户都有同样多的人 {#q.l4.3.6.o1}
  理由：“五子不为多”与再乘一次，是举例说明增长。
- [x] 把后代增多写得可数，好接到人多而财少的处境 {#q.l4.3.6.o2}
- [ ] 证明赏罚加倍会鼓励人生五个儿子 {#q.l4.3.6.o3}
  理由：赏罚在段末才出现，文中没有设这重因果。

提示：不要停在算出孙子的数量，读接下来的“是以”。
解析：家庭世代的算例转到人口与供养的压力。处理争夺的问题也随条件改变。

## 找原文证据：韩非写今人，哪一句把辛苦劳作和所得不丰直接连在一起？ {#q.l4.3.7}
考点：skill.l4.3.a
语境：p.l4.3.b

- [ ] 人民众而货财寡 {#q.l4.3.7.o1}
  理由：这里点的是人同财的多寡，没有正说劳力与供养。
- [x] 事力劳而供养薄 {#q.l4.3.7.o2}
- [ ] 虽倍赏累罚而不免于乱 {#q.l4.3.7.o3}
  理由：这里已经说到施政的效果。

提示：找“劳”字；它左右的两件事并非一起增加。
解析：前面古人“不事力而养足”，此处今人出力多却供养薄。两个时代的关系正好倒过来。

## 排序：依段中“是以”“故”“虽”重建今人的困境。 {#q.l4.3.8}
考点：skill.l4.3.b
语境：p.l4.3.b

- [3] 即使加重赏罚，动乱仍未消失 {#q.l4.3.8.o1}
  理由：末句承认加强赏罚，也限定了它的成效。
- [1] 子孙增加，财物相对不足 {#q.l4.3.8.o2}
  理由：家庭算例后紧跟人众财寡。
- [2] 劳苦而所得有限，于是争夺起来 {#q.l4.3.8.o3}
  理由：“故民争”承接供养薄。

提示：先交代供养条件，再读人的反应，末了才谈政策。
解析：这一段解释难度何以增加，不能倒读成“先重罚，所以人口变多”。
