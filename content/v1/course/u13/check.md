# 检查：《天论》：能做的是祭天，还是应对旱情？ {#check.13}

## 原文：古籍引文 {#p.check.13.a}
> 天行有常，不为尧存，不为桀亡。应之以理则吉，应之以乱则凶。强本而节用，则天不能贫；养备而动时，则天不能病；修道而不贰，则天不能祸。
译文：天的运行有它的常度，不因尧而存在，也不因桀而消失。人按治道应对就吉，以乱政应对就凶。使农业根基强盛并节制用度，天就不能使人贫困；养备充足、行动合时，天便不能使人困病；修治正道不二其心，天也不能使人受祸。
词注：常：不随人事任意更易的规律。
  理：治理得当，与“乱”相对。
  强本：使农业等生计根本强固。

## 原文：古籍引文 {#p.check.13.b}
> 雩而雨，何也？曰：“无他也，犹不雩而雨也。”日月食而救之，天旱而雩，卜筮然后决大事，非以为得求也，以文之也。故君子以为文，而百姓以为神。以为文则吉，以为神则凶也。
译文：举行雩祭后就下雨，怎么回事？荀子回答：没有别的缘故，同没有行雩也会下雨一样。日月食时行救护礼，天旱时祈雨，占卜之后才决定大事，这些不是以为能得到所求，而是用礼文来表达。君子把它看作礼文，百姓却以为有神力；看作礼文有益，信为神力则有害。
词注：雩：读 yú，祈雨的祭礼。
  卜筮：古人在大事前所行的占问。
  文：此处指以礼文作表达。

## 单选：尧和桀一贤一暴。把这两个名字都放在“天行”后，是让读者比较什么？ {#q.check.13.1}
考点：skill.l4.1.a
语境：p.check.13.a

- [x] 人君不同，天的运行有没有随之出现或停下 {#q.check.13.1.o1}
- [ ] 两人的政绩究竟谁能换来风调雨顺 {#q.check.13.1.o2}
  理由：“不为……存”“不为……亡”都在排除这层直接对应。
- [ ] 两位君主是否在同一年遭过日食 {#q.check.13.1.o3}
  理由：这段没有记某年的天象。

提示：留心前半说谁变了，后半的“常”说什么没变。
解析：作者把人间的巨大差别推到眼前，再指出两者都处在同一套天的常度之中。

## 找原文证据：三个“则天不能……”之前各有人的行动；哪一项具体谈到了物用？ {#q.check.13.2}
考点：skill.l4.2.a
语境：p.check.13.a

- [x] 强本而节用 {#q.check.13.2.o1}
- [ ] 修道而不贰 {#q.check.13.2.o2}
  理由：这谈坚持所行的道。
- [ ] 养备而动时 {#q.check.13.2.o3}
  理由：这谈准备充足、行动合时，未点出节用。

提示：找能直接解释“不贫”的那一项。
解析：“强本”同“节用”相配，用来解释人怎样应对贫困。排比的另外两项各有落点。

## 单选：既说“天行有常”，荀子为什么还要人“强本而节用”？ {#q.check.13.3}
考点：skill.l4.3.b
语境：p.check.13.a

- [ ] 人循道而行可暂时改变日月运行 {#q.check.13.3.o1}
  理由：第一句特意排除了天随人君存亡。
- [x] 天的运行有常度，百姓是否贫困还取决于能否巩固生计、节制用度 {#q.check.13.3.o2}
- [ ] 既然天有常，一切人事结果必然相同 {#q.check.13.3.o3}
  理由：作者随后明说应之以理、以乱会有吉凶之别。

提示：“应之”的主语要从人这边补。
解析：天照常运行，人仍能务农节用，使百姓免于贫困。“强本而节用”说的正是人可以尽力的事。

## 单选：求雨之后果然下了雨。作者为何还举“不雩而雨”？ {#q.check.13.4}
考点：skill.l4.3.a
语境：p.check.13.b

- [ ] 说明两次下雨的日期与雨量完全相同 {#q.check.13.4.o1}
  理由：“犹”比较的是下雨可不可以发生，没有比较雨量。
- [ ] 责备没有参加求雨的百姓破坏礼仪 {#q.check.13.4.o2}
  理由：这里是在回答雨为何下，并未追究缺席者。
- [x] 换掉“举行仪式”这个条件，看看下雨是不是仍可能发生 {#q.check.13.4.o3}

提示：把两句中都有的“雨”留下，看少了哪件事。
解析：雨后于仪式，不能单凭先后就说仪式致雨。没有雩祭也会下雨，恰好检验了这一点。

## 找原文证据：既然不主张靠仪式得雨，荀子究竟给礼仪留下了什么作用？ {#q.check.13.5}
考点：skill.l4.1.b
语境：p.check.13.b

- [ ] 非以为得求也 {#q.check.13.5.o1}
  理由：这里排除一种理解，尚未说礼的正面用意。
- [ ] 以为神则凶也 {#q.check.13.5.o2}
  理由：这是把礼看成神力的后果。
- [x] 以文之也 {#q.check.13.5.o3}

提示：“非以为……”之后还有一句肯定的话。
解析：“文”在此可读作以礼文来修饰、表达。常行的仪礼和能够驱使天象是两回事。

## 单选：把“君子以为文”解释成“君子也承认仪式有求雨法力”，和哪一组原意冲突？ {#q.check.13.6}
考点：skill.l4.2.b
语境：p.check.13.b

- [ ] 百姓和君子各举行了一种日期不同的雩祭 {#q.check.13.6.o1}
  理由：二者是在解释同样的礼仪。
- [x] 君子看重礼文，另一种看法却把仪式当作神力 {#q.check.13.6.o2}
- [ ] 荀子要求君子从此取消所有礼仪 {#q.check.13.6.o3}
  理由：他交代了“以文之”的意义。

提示：在两个“以为”后各填一个字。
解析：“文”与“神”说明同一件事如何被理解；两边评价有别，不能用相同的法力解释它们。
