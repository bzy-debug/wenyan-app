# 检查：诸子如何立论综合阅读 {#check.13}

## 原文：古籍引文 {#p.check.13.a}
> 天行有常，不为尧存，不为桀亡。应之以理则吉，应之以乱则凶。强本而节用，则天不能贫；养备而动时，则天不能病；修道而不贰，则天不能祸。
译文：天的运行有恒常规律，不因尧存在，也不因桀灭亡。人应对得有条理就顺利，胡乱应对就不顺。务农节用，天不能使人贫；储备足、行动合时，天不能使人受困；守正不二，天不能降祸于人。

## 原文：古籍引文 {#p.check.13.b}
> 雩而雨，何也？曰：“无他也，犹不雩而雨也。”日月食而救之，天旱而雩，卜筮然后决大事，非以为得求也，以文之也。故君子以为文，而百姓以为神。以为文则吉，以为神则凶也。
译文：行求雨礼后下雨，是什么缘故？荀子说，与不行礼也下雨一样。遇日月食举行救护之礼，旱时行求雨礼，大事前占卜，是为了礼文修饰，并非据此就能得到所求。所以君子把它当作礼文，百姓把它视为神效。前一种理解吉，后一种理解凶。

## 单选：“不为尧存，不为桀亡”这一对人名要说明什么？ {#q.check.13.1}
考点：skill.l4.1.a
语境：p.check.13.a

- [x] 两种截然不同的统治者不能左右天的运行 {#q.check.13.1.o1}
- [ ] 尧和桀用了相同的农政 {#q.check.13.1.o2}
  理由：文中比较的是天行与人物的关系，未说农政相同。
- [ ] 天分别奖赏尧、惩罚桀 {#q.check.13.1.o3}
  理由：两个“不为”恰好排除这种对应。

提示：先找两个“不为”共用的主语。
解析：两端都说天行有常，借人的巨大差异突显天的规律不因人而改。

## 找原文证据：作者把吉凶的差别放在哪一组人自己的行动上？ {#q.check.13.2}
考点：skill.l4.2.a
语境：p.check.13.a

- [x] 应之以理则吉，应之以乱则凶 {#q.check.13.2.o1}
- [ ] 不为尧存 {#q.check.13.2.o2}
  理由：这排除了一种解释，尚未交代吉凶。
- [ ] 天行有常 {#q.check.13.2.o3}
  理由：这指出保持不变的一端。

提示：同一个“应”怎样分别承接“理”和“乱”？
解析：“应”是人的应对，两种应对带来相反结局。

## 单选：若某地收成不足，依“强本而节用”的思路，先查什么？ {#q.check.13.3}
考点：skill.l4.3.b
语境：p.check.13.a

- [ ] 君主名字是否与古圣相同 {#q.check.13.3.o1}
  理由：两个“不为”排除以人物名号解释天行。
- [x] 农业生产与开支有没有得到妥善安排 {#q.check.13.3.o2}
- [ ] 日月是否按另一套规律运行 {#q.check.13.3.o3}
  理由：开头为整段设定“天行有常”的前提。

提示：把“贫”向前接到人的两个动作。
解析：荀子将贫与否联系到农业基础与用度，要求查可由人调整的环节。

## 单选：“犹不雩而雨也”怎样检验雩礼导致降雨的说法？ {#q.check.13.4}
考点：skill.l4.3.a
语境：p.check.13.b

- [ ] 说有雨时人们才开始行礼 {#q.check.13.4.o1}
  理由：这改变了原文给定的先后次序。
- [ ] 说举行雩礼之后绝不下雨 {#q.check.13.4.o2}
  理由：第一句恰以礼后降雨为所问的现象。
- [x] 另设没有举行雩礼而也降雨的情形 {#q.check.13.4.o3}

提示：留心“犹”比较的两种情形。
解析：作者保留降雨、改变是否行礼，迫使读者区分先后与因果。

## 找原文证据：哪句直接否定把仪式当作实现所求的手段？ {#q.check.13.5}
考点：skill.l4.1.b
语境：p.check.13.b

- [ ] 以文之也 {#q.check.13.5.o1}
  理由：这里正面说明作者认可的作用。
- [ ] 君子以为文 {#q.check.13.5.o2}
  理由：这是君子的理解方式。
- [x] 非以为得求也 {#q.check.13.5.o3}

提示：找带否定的判断。
解析：作者把仪式的作用限在礼文一面，明言它不能凭自身取得所求。

## 单选：哪项准确保留了荀子对仪式的限定？ {#q.check.13.6}
考点：skill.l4.2.b
语境：p.check.13.b

- [ ] 凡涉及仪式都应取消 {#q.check.13.6.o1}
  理由：“以文之也”给仪式保留了一种用途。
- [x] 承认其礼文意义，反对归给它左右天象的能力 {#q.check.13.6.o2}
- [ ] 只有君子行礼之后才会下雨 {#q.check.13.6.o3}
  理由：君子和百姓分的是认识方式。

提示：对照“文”和“神”所指的功能。
解析：区别的是同一仪式可以怎样被理解，不能把理解差异改成气象差异。
