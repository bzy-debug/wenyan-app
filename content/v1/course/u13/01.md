# 课文：孟子怎样区分不为与不能 {#l4.1}
简介：能举百钧，却举不起一根羽毛，齐宣王肯信吗？看孟子怎样把这个问题问到王自己身上。

## 正文

有人说自己举得起百钧，却举不起一根羽毛；眼力好得能看清秋毫，却看不见一车柴。孟子问齐宣王信不信。王只答一个“否”。到这里，谈的还只是力气和眼力。

话锋转在“今恩足以及禽兽”。王既然曾对一头牛动过恻隐之心，为什么自己的百姓还没有得到保护？孟子借王刚刚承认的道理来追问：羽毛没举起来，是没用力；百姓没得到保护，会不会也是王还没有把这份心用在他们身上？

### 哪些事确实做不到

夹着泰山跃过北海，说“我不能”，孟子认账。为长者“折枝”也说“我不能”，他却不认。“折枝”到底是什么动作，历来有几种解释；读这一问一答，只需抓住孟子把它当作举手能办的小事。孟子在末句明说，王未把恩推及百姓，属于后一类。

## 知识点：难事和易事怎样作比 {#skill.l4.1.a}
义项：找出例子里一难一易的两件事，看作者拿它们来比什么
领域：篇章
要诀：孟子举的两件事，哪件难，哪件容易？
讲解：能举百钧的人举得起羽毛，能辨秋毫的人看得见车薪。要读出比喻落在哪里，再找孟子随后提到的禽兽和百姓。
例句：p.l4.1.a

## 知识点：不为与不能的辨别 {#skill.l4.1.b}
义项：分清确实做不到，还是能做却没做
领域：阅读技能
要诀：“我不能”是在说哪一件事？
讲解：挟山跨海超出人的能力，替长者做件小事却力所能及。要分清两句“我不能”，得看说话人受托做什么。
例句：p.l4.1.b

## 原文：古籍引文 {#p.l4.1.a}
> 有复于王者曰：“吾力足以举百钧，而不足以举一羽；明足以察秋毫之末，而不见舆薪。”则王许之乎？曰：“否。”今恩足以及禽兽，而功不至于百姓者，独何与？然则一羽之不举，为不用力焉；舆薪之不见，为不用明焉；百姓之不见保，为不用恩焉。故王之不王，不为也，非不能也。
译文：有人自称能举百钧却举不起羽毛，眼力能辨秋毫却看不见一车柴，王肯认可吗？王说不认可。如今您的恩能施及禽兽，成效却没到百姓身上，究竟为什么？羽毛没有举起，是没用力；车柴没有看见，是没用眼力；百姓没受保护，是没施恩。王没能施行王道，是没有去做，其实有能力做到。

## 原文：古籍引文 {#p.l4.1.b}
> 挟太山以超北海，语人曰：“我不能。”是诚不能也。为长者折枝，语人曰：“我不能。”是不为也，非不能也。故王之不王，非挟太山以超北海之类也；王之不王，是折枝之类也。
译文：夹着泰山跨过北海，说自己办不到，这是真办不到。为长者做一件轻易之事却说办不到，这是没去做，有能力做。所以王没有行成王道，与挟山跨海不同，属于为长者折枝这一类。

## 单选：孟子说看不见一车柴，拿力气的例子来比，相当于说举不起什么？ {#q.l4.1.1}
考点：skill.l4.1.a
语境：p.l4.1.a

- [x] 羽毛，属于已有能力足以应付的对象 {#q.l4.1.1.o1}
- [ ] 秋毫，都是足以证明眼力的细小事物 {#q.l4.1.1.o2}
  理由：车薪比秋毫大得多，二者构成反差。
- [ ] 百钧，都是人声称已经举起来的物件 {#q.l4.1.1.o3}
  理由：孟子说的是看不见一车柴。

提示：比较两个“而”字后面的事。
解析：车薪在眼力一例中，相当于力气一例中的羽毛：一车柴比秋毫容易看见，正如羽毛比百钧容易举起。两例都在问，人明明能做，怎么偏说做不到？

## 单选：齐王答“否”，在此刻亲自承认了什么？ {#q.l4.1.2}
考点：skill.l4.1.b
语境：p.l4.1.a

- [ ] 百姓已经受到保护 {#q.l4.1.2.o1}
  理由：谈百姓是在王答“否”之后。
- [x] 这两种关于能力的自述难以相信 {#q.l4.1.2.o2}
- [ ] 施恩比看柴困难得多 {#q.l4.1.2.o3}
  理由：齐王答的是是否认可眼前的说法。

提示：“许之”的“之”回指哪两句话？
解析：孟子问“王许之乎”，王才答“否”。齐王此刻不信的是那两句自述，还没亲口谈到百姓。

## 找原文证据：从力气、眼力转到政事时，哪句点出没有得到相应保护的人？ {#q.l4.1.3}
考点：skill.l4.1.a
语境：p.l4.1.a

- [ ] 明足以察秋毫之末 {#q.l4.1.3.o1}
  理由：秋毫之末极细小，能看见它说明眼力很好。这里还没有谈到百姓。
- [x] 百姓之不见保 {#q.l4.1.3.o2}
- [ ] 为不用力焉 {#q.l4.1.3.o3}
  理由：“不用力”回答的是羽毛为什么没举起来，还没转到受保护的人。

提示：读完“一羽之不举”“舆薪之不见”，看第三句说到了谁。
解析：一羽没举起、一车柴没看见，到了第三句，换成百姓没受到保护。“见保”在这里就是受到保护。

## 单选：若要反驳孟子关于“不为”的结论，最需要质疑哪一步？ {#q.l4.1.4}
考点：skill.l4.1.b
语境：p.l4.1.a

- [ ] 一根羽毛是否比百钧轻 {#q.l4.1.4.o1}
  理由：这个重量差已经由日常判断承认，尚未触及施恩的推论。
- [x] 曾经怜悯禽兽，是否足以表明能把恩推及百姓 {#q.l4.1.4.o2}
- [ ] “否”是不是一句答话 {#q.l4.1.4.o3}
  理由：“否”是齐王的回答。要反驳孟子，还得说明王的恻隐之心为什么不能推及百姓。

提示：检验从日常例子通向王政的那一步。
解析：王对牛动过恻隐之心，孟子据此说他也能把恩惠推及百姓。若要反驳“不为”的结论，正要问这一步推得出、推不出。

## 找原文证据：孟子把王的处境放在哪一类？选出明说归类的原句。 {#q.l4.1.5}
考点：skill.l4.1.a
语境：p.l4.1.b

- [x] 是折枝之类也 {#q.l4.1.5.o1}
- [ ] 是诚不能也 {#q.l4.1.5.o2}
  理由：“诚不能”紧接挟山跨海。还得读到“王之不王”，才知道王属于哪类。
- [ ] 非挟太山以超北海之类也 {#q.l4.1.5.o3}
  理由：这句排除了一类，尚未说正面归入哪一类。

提示：末尾先排除，再确认。
解析：前一句先排除挟山跨海，末一句再明说“是折枝之类也”。王面对的是力所能及之事。

## 单选：两个人都说“我不能”，读者应怎样判断？ {#q.l4.1.6}
考点：skill.l4.1.b
语境：p.l4.1.b

- [ ] 只要对象是长者，谁也不能拒绝 {#q.l4.1.6.o1}
  理由：这一段比较的是能力和行动，没有讨论拒绝的礼制。
- [x] 连同前面要求完成的具体行动来判断 {#q.l4.1.6.o2}
- [ ] 只要说了两遍，第二次就一定是推托 {#q.l4.1.6.o3}
  理由：两次分属不同的设例。

提示：把“我不能”各自接回它所回应的要求。
解析：一个人要挟山跨海，另一个人只需为长者做件小事。他们都说“我不能”，孟子却只认可前一个人的解释。

## 排序：依原文整理孟子回应疑问的步骤。 {#q.l4.1.7}
考点：skill.l4.1.a
语境：p.l4.1.b

- [2] 举折枝例，指出能做而不做 {#q.l4.1.7.o1}
  理由：第二个“我不能”要拿来与跨海对比。
- [3] 把王没有行成王道归入第二类 {#q.l4.1.7.o2}
  理由：直到“故”才将两种设例应用到王身上。
- [1] 举跨海例，承认有确实做不到的事 {#q.l4.1.7.o3}
  理由：“诚不能”先承认能力极限。

提示：先读挟山跨海，再读为长者折枝，最后看孟子怎样说王。
解析：先承认真有办不到的事，再举一件能办却推说不能的事，最后才问王自己的处境属于哪一边。

## 单选：哪句话保留了“诚不能”的分量？ {#q.l4.1.8}
考点：skill.l4.1.b
语境：p.l4.1.b

- [x] 孟子接受能力确有极限，同时质疑王以此为理由 {#q.l4.1.8.o1}
- [ ] 孟子认为只要肯做，跨北海也很容易 {#q.l4.1.8.o2}
  理由：“诚”明说第一种情形确实办不到。
- [ ] 孟子认为王只需亲自为长者折枝即可完成王政 {#q.l4.1.8.o3}
  理由：例子用于辨别行为性质，并非施政清单。

提示：看第一个判断中的“诚”。
解析：“诚”就是真、确实。孟子承认人有力不能及之事，所以他接下来要辨的是：王眼下这件事，能算在其中吗？
