# 课文：齐宣王说了一个“否”，孟子怎样接下去问？ {#l4.1}
简介：齐宣王先要判断别人的话可不可信。等他开口，孟子才把同一把尺子递回给他。

## 正文

有人自称力大到能举百钧，却拿不起一根羽毛。这个人是真的力气小吗？齐王还没来得及只替他找理由，孟子又说有人能辨鸟兽秋日新生的细毛，却看不见一车柴。把两个“足以”一起读，后一句眼力的主人还是这个假想的“吾”。这时候王所不信的，还只是两番自述。

到“今恩足以及禽兽”，问话变了。齐宣王曾经怜惜一头将被宰杀的牛；前举禽兽、后举百姓，是要王反观已有的恻隐为何没有化成保民的行动。换成普通话来复述：王既然不信举重者举不起羽毛，怎么解释自己肯怜这一头牛，百姓却仍未受保护？这是孟子的追问，其说服力有赖于读者同意这两种能力可以相提并论。

再往下，孟子自己给“不能”留了位置。挟山跨海不在人力所及，为长者做件小事却可以。关于“折枝”，有把“枝”读作“肢”、说是按摩肢体的解法，也有折取树枝的读法。这里判定王属于哪一边，靠孟子最后的明文，无须把某种训释设成过关条件。

## 知识点：辨出成对例子的对应处 {#skill.l4.1.a}
义项：比较两组事物的难易，并指出作者把这个关系用到了哪里
领域：篇章
要诀：在“举百钧／举一羽”旁并排写下“察秋毫／见舆薪”。
讲解：力大与目明本是两种本领，难事能办、易事反而办不到的关系却相同。等读到“今恩”，再看这层关系怎样移到了王的行为上。
例句：p.l4.1.a

## 知识点：区分能力和已做的事 {#skill.l4.1.b}
义项：用具体任务与可用能力辨别“不肯做”和“做不到”
领域：阅读技能
要诀：两处“我不能”说出口以前，受托做的事各是什么？
讲解：挟山跨海一例，是孟子自己承认真有不能；折枝一例，容许他指出人有时把未曾行动说成了能力不足。
例句：p.l4.1.b

## 原文：古籍引文 {#p.l4.1.a}
> 有复于王者曰：“吾力足以举百钧，而不足以举一羽；明足以察秋毫之末，而不见舆薪。”则王许之乎？曰：“否。”今恩足以及禽兽，而功不至于百姓者，独何与？然则一羽之不举，为不用力焉；舆薪之不见，为不用明焉；百姓之不见保，为不用恩焉。故王之不王，不为也，非不能也。
译文：假使有人禀告大王：“我能举起百钧，却举不起一根羽毛；我能看清秋毫尖，却看不见一车柴。”大王会认可吗？王说：“不。”如今大王的恩能到禽兽那里，功效却不到百姓身上，这是为什么？一根羽毛没举起来，是没用力；一车柴没看见，是没用眼；百姓没得到保护，是没把恩施过去。因此大王未能以王道治天下，是没有去做，并不是做不到。
词注：复：禀告，向君王陈说。
  许：认可那人的说法。
  见保：“见”表被动，得到保护。

## 原文：古籍引文 {#p.l4.1.b}
> 挟太山以超北海，语人曰：“我不能。”是诚不能也。为长者折枝，语人曰：“我不能。”是不为也，非不能也。故王之不王，非挟太山以超北海之类也；王之不王，是折枝之类也。
译文：把泰山夹在身边跨过北海，告诉人家“我办不到”，这是真办不到。为长辈折枝这样的小事也说“我办不到”，这是没去做，并非没有能力。大王没有施行王道，归不到挟山跨海一类，应归到折枝一类。“折枝”的动作有异解，段中用它与极难之事作对比。
词注：诚：的确。
  超：跃过、跨过。
  王之不王：前“王”指君王，后“王”读 wàng，指行王道而王天下。

## 单选：同一个人能辨秋毫，却说没看见一车柴。孟子为什么还要先说举羽毛的事？ {#q.l4.1.1}
考点：skill.l4.1.a
语境：p.l4.1.a

- [x] 用两种本领说同一桩蹊跷事：费力的能做，容易的反倒做不到 {#q.l4.1.1.o1}
- [ ] 先证实力气大，再用力气解释眼力好 {#q.l4.1.1.o2}
  理由：羽毛、秋毫分别考验力气和眼力，段中没有一方决定另一方的话。
- [ ] 把两项弱点相加，说明眼前这个人确实无能 {#q.l4.1.1.o3}
  理由：两例都先承认他具备相当强的本领。

提示：把“足以”后面与“而”后面的事成对读。
解析：举百钧与见秋毫分别是难事。两次都把易事放在后面，齐王便先承认：拿能力不足解释这个落差，说不通。

## 单选：“王许之乎”若当作王给人下命令，哪一处会接不上？ {#q.l4.1.2}
考点：skill.l4.1.b
语境：p.l4.1.a

- [ ] 下文出现“百姓”，可知王已经下令施恩 {#q.l4.1.2.o1}
  理由：百姓是在王答话之后才引进的。
- [x] 下文王只答“否”，是在判断那人的说法可信不可信 {#q.l4.1.2.o2}
- [ ] 听者自称能举百钧，这是王任命他的依据 {#q.l4.1.2.o3}
  理由：“有复于王者”是设想中的进言人，文中没有任命。

提示：看问号之前是谁在向谁陈述。
解析：“许”在这里是认可。孟子借来王自己作出的判断，还要把这个判断用到王待百姓的问题上。

## 找原文证据：从设例转到王政时，哪句话正面交代王曾把恩施给谁？ {#q.l4.1.3}
考点：skill.l4.1.a
语境：p.l4.1.a

- [ ] 百姓之不见保 {#q.l4.1.3.o1}
  理由：这句说还没受保护的人。
- [x] 今恩足以及禽兽 {#q.l4.1.3.o2}
- [ ] 明足以察秋毫之末 {#q.l4.1.3.o3}
  理由：这仍在谈设例中那人的眼力。

提示：找孟子第二次开口后出现的第一个对象。
解析：论证先有一个起点：王并非从来不动怜悯之心。随后才有“禽兽能得到，百姓为什么得不到”的追问。

## 单选：有人不同意孟子的推断，却同意羽毛比百钧轻。他该质疑哪一环？ {#q.l4.1.4}
考点：skill.l4.1.b
语境：p.l4.1.a

- [ ] 齐王说“否”是不是只用了一个字 {#q.l4.1.4.o1}
  理由：答话很短，仍清楚表示了王的判断。
- [x] 怜悯禽兽的心，是否足以表明王有能力保民 {#q.l4.1.4.o2}
- [ ] 孟子是否应先说车薪、再说羽毛才好听 {#q.l4.1.4.o3}
  理由：两组假设的先后可以讨论，但调换顺序无法推翻从恻隐到保民的类推。

提示：找出从两种日常本领转到王身上的那一步。
解析：不同意的可以是类推的根据。承认举重者能举羽，并不自动等于承认一次怜悯足以办成所有保民之事。

## 找原文证据：读第二段，哪一句把判断落到了眼前这位王身上？ {#q.l4.1.5}
考点：skill.l4.1.a
语境：p.l4.1.b

- [x] 王之不王，是折枝之类也 {#q.l4.1.5.o1}
- [ ] 是诚不能也 {#q.l4.1.5.o2}
  理由：这还在判断挟山跨海。
- [ ] 为长者折枝 {#q.l4.1.5.o3}
  理由：这只是第二个设例，王还没入句。

提示：在两个“我不能”之后，找再次出现“王”的地方。
解析：“类”指出归类的方向：王自己的“不王”，应拿后一种情况来理解。

## 单选：两处“语人曰”后面说的话相同。为什么孟子一处信、一处不信？ {#q.l4.1.6}
考点：skill.l4.1.b
语境：p.l4.1.b

- [ ] 说话者后一次换成了长者，所以不可信 {#q.l4.1.6.o1}
  理由：长者是受人帮助的一方，原文没有拿年龄评断真假。
- [x] 得看话前面的要求：一件远超人力，一件是日常小事 {#q.l4.1.6.o2}
- [ ] 两处要分辨的是说话人的身份，长者地位高便应当相信 {#q.l4.1.6.o3}
  理由：“为长者”交代受助者的身份，没有把长者写成第二次发言的人。

提示：分别用一句现代话说出被要求做的事。
解析：孟子核对的是任务和能力是否相称。仅凭一句“我不能”，还分不出不肯和不能。

## 排序：把“跨海”“折枝”这段话还原为一段答辩。 {#q.l4.1.7}
考点：skill.l4.1.a
语境：p.l4.1.b

- [2] 再换一件轻易之事，检验同一句托辞 {#q.l4.1.7.o1}
  理由：第二次“我不能”是拿来和前一次比的。
- [3] 最后说明齐王的情况应归在哪边 {#q.l4.1.7.o2}
  理由：“故王之不王”才把设例接回王政。
- [1] 先给“不能”留出一种真实情形 {#q.l4.1.7.o3}
  理由：跨海先立下确实超出能力的情形。

提示：先读“诚”，再读“不为”，最后找“故”。
解析：孟子先把对方有理由的那种情形讲明，再排除王用它推托的可能。若一开头就定王的罪，两个设例的用处便看不出来。

## 单选：“折枝”的具体动作有不同说法。即使先搁下这点，哪项判断仍有原文保证？ {#q.l4.1.8}
考点：skill.l4.1.b
语境：p.l4.1.b

- [x] 在这次对比中，孟子把它当成人力可及的事 {#q.l4.1.8.o1}
- [ ] 王受过一次具体的折枝命令，却当面拒绝 {#q.l4.1.8.o2}
  理由：这是孟子所举的例子，没有记载王受过这道命令。
- [ ] 只要查明“枝”是哪种树枝，王道成败便能确定 {#q.l4.1.8.o3}
  理由：一词的训解不能代替孟子对王行事的判断。

提示：把“是诚不能也”和第二个“是……也”对着读。
解析：两句判语划出了界限。即使对动作的训释有分歧，也不影响作者在这段话里所作的难易区分。
