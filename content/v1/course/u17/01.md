# 课文：“好学”和“冠者”怎样读 {#l5.1}
简介：查到“好”“冠”的两种读音后，把它们放回孔子和曾皙的话里试读。

## 正文

### “好学”的“好”读几声？

翻到“好”字，可以读 hǎo，也可以读 hào。“好学”是说学得好，还是说爱学习？往下读到“不耻下问”，孔文子肯向别人请教，他怎样对待学习便清楚了。

“冠”也要这样查：guān 可以指帽子，guàn 可以指戴帽或行冠礼。遇上“冠者”，先别急着选排在最前面的读音，看下文是在点帽子，还是在数人。记笔记时把帮你拿定主意的那几个字一并抄下。拼音是今天的普通话读音，不能据此推定古人当时怎么念。

查字时可直接翻到这里。[好](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%A5%BD) · [冠](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%86%A0)

## 知识点：音义分项 {#skill.l5.1}
义项：根据上下文选择字音和字义
领域：阅读技能
要诀：把两个读音连同意思各试一次
讲解：一个字头下常有几种读音，每种读音还可能有几个解释。先找这个字和哪些词搭在一起，再挑读得通的那一个。
例句：p.l5.1.example

## 原文：教学例句 {#p.l5.1.example}
> 生好问，师好其勤。
译文：学生爱提问，老师也欣赏他的勤勉。两处“好”后面，都能接着问一句“喜欢什么”，所以两处都可以试读 hào。

## 原文：古籍引文 {#p.l5.1.a}
> 子贡问曰：“孔文子何以谓之‘文’也？”子曰：“敏而好学，不耻下问，是以谓之‘文’也。”
译文：子贡问：“孔文子为什么得到‘文’这个称号？”孔子说：“他聪敏好学，肯向地位或学识不如自己的人请教，所以称他为‘文’。”

## 单选：“好学”的“好”，该读 hǎo（优良）还是 hào（喜爱）？ {#q.l5.1.1}
考点：skill.l5.1
语境：p.l5.1.a

- [x] hào，喜爱学习 {#q.l5.1.1.o1}
- [ ] hǎo，已经学好一切 {#q.l5.1.1.o3}
  理由：“下问”说明他还会向别人求教。
- [ ] hǎo，所学的内容优良 {#q.l5.1.1.o2}
  理由：子贡问的是孔文子为什么得这个称号，没有人在评他所读的书好不好。

提示：把两个意思各接上“学”，看哪一个说的是孔文子的为人。
解析：“学”是孔文子喜欢做的事，所以“好”读 hào。下句说他肯向别人请教，又给了一条线索。

## 找原文证据：孔文子怎样做，让你相信他确实爱学？请找出原话。 {#q.l5.1.2}
考点：skill.l5.1
语境：p.l5.1.a

- [ ] 子贡问曰 {#q.l5.1.2.o2}
  理由：这是子贡发问，孔文子没有在此开口。
- [x] 不耻下问 {#q.l5.1.2.o1}
- [ ] 何以谓之 {#q.l5.1.2.o3}
  理由：“何以”是子贡在问缘故，还没轮到孔子讲孔文子的为人。

提示：分清谁在向孔子发问，谁是孔子在称赞的人。
解析：“不耻下问”说他肯向地位或学识不如自己的人请教。

## 单选：若给辞书中的 hào 添一条例句，怎样引这段话最清楚？ {#q.l5.1.3}
考点：skill.l5.1
语境：p.l5.1.a

- [ ] 引“孔文子”，释“好”为谥号 {#q.l5.1.3.o3}
  理由：被问的称号是“文”。
- [ ] 只引“敏而”，释“好”为敏捷 {#q.l5.1.3.o2}
  理由：“敏”说反应敏捷，接着还要说他爱做什么，不能把两个字只讲成一个意思。
- [x] 引“敏而好学，不耻下问”，说明“好”带学习活动 {#q.l5.1.3.o1}

提示：保留“好”的对象，再留下一件能说明此人爱学的事。
解析：只抄“好”，看不出该读几声。连同“学”和“不耻下问”一起抄，别人也能凭这句话读出来。

## 单选：若把“下问”的人当成子贡，为什么就讲不清孔文子的“好学”了？ {#q.l5.1.4}
考点：skill.l5.1
语境：p.l5.1.a

- [x] 失去孔文子好学的具体行为证据 {#q.l5.1.4.o1}
- [ ] 说明孔子是来向子贡请教的 {#q.l5.1.4.o3}
  理由：“子曰”引的是答话，提问在前。
- [ ] 证明“好”应该念 hǎo {#q.l5.1.4.o2}
  理由：把下问的人认错了，不会凭空得出 hǎo 的读音。还得看“好”带的“学”讲不讲得通。

提示：问称号的是子贡。答话里是谁既“好学”又“不耻下问”？
解析：子贡是来问孔文子为何得谥的。孔子所举的两件好处，都在孔文子身上。

## 单选：“冠”可指帽子（guān），也可指行冠礼（guàn）。“冠者五六人”说的是谁？ {#q.l5.1.5}
考点：skill.l5.1
语境：p.l5.1.b

- [ ] guān，五六顶帽子 {#q.l5.1.5.o2}
  理由：五六后面明明数的是“人”，下文还数了六七个孩子。
- [x] guàn，行过冠礼的人 {#q.l5.1.5.o1}
- [ ] guàn，每人正给童子戴帽 {#q.l5.1.5.o3}
  理由：下文列两组同行者，没有写行礼现场。

提示：看看五六后面数的是“人”还是件数。
解析：已行冠礼的人是成年人，下面还另数了六七个童子。两处数的都是人。

## 找原文证据：曾皙还点了哪一群人，使我们知道“冠者”指成年人？ {#q.l5.1.6}
考点：skill.l5.1
语境：p.l5.1.b

- [ ] 春服 {#q.l5.1.6.o3}
  理由：衣服可以提示季节，不能单独确定这两组人的分别。
- [ ] 舞雩 {#q.l5.1.6.o2}
  理由：“乎舞雩”说明吹风的地点。
- [x] 童子 {#q.l5.1.6.o1}

提示：紧接“五六人”，下一组叫什么？
解析：“童子”与“冠者”对举，一边是孩子，一边是已成年的人。

## 单选：上文说了春衣，为什么还不能把“冠者”读成几顶帽子？ {#q.l5.1.7}
考点：skill.l5.1
语境：p.l5.1.b

- [x] “冠者”在数人，与“春服”各自成句 {#q.l5.1.7.o1}
- [ ] 古文中的“冠”只有一个读音 {#q.l5.1.7.o3}
  理由：字典收有帽子与加冠等不同音义。
- [ ] 春服从来不与帽子并用 {#q.l5.1.7.o2}
  理由：春衣和帽子能不能同穿，这段没有议论。

提示：“既成”说什么已备好？下一句“五六人”又在数什么？
解析：春服已备是一件事，数同行的人是另一件事。“者”后面接着人数，还要顺着下一句读。

## 单选：给“冠（guàn）”摘个例子，怎样保留最能辨音的上下文？ {#q.l5.1.8}
考点：skill.l5.1
语境：p.l5.1.b

- [ ] 只引“风乎舞雩”，以“风”当作“冠”的注音 {#q.l5.1.8.o2}
  理由：风与冠是不同的字，地点和动作也没有给冠注音。
- [x] 并引“冠者五六人，童子六七人”，指出两组身份对举 {#q.l5.1.8.o1}
- [ ] 只引“冠”，据字形断定在数帽子 {#q.l5.1.8.o3}
  理由：只摘“冠”这个字，帽子和行冠礼两种意思都还在。

提示：让读笔记的人也能看清与“冠者”同行的是谁。
解析：把“冠者五六人，童子六七人”一并留下，年龄、身份的分别就看得见。
