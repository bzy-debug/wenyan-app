# 课文：翻到字头，还要往下找 {#l5.1}
简介：两个字紧挨着，什么时候值得把它们合起来查？

## 正文

翻到“犹”，会见到“如同”“还”等意思。再往“猶”字下找“猶豫”，才有“迟疑，拿不定主意”这一条。书按繁体字排时，要认得这两个写法。

“须”也有等待的意思；但“须臾”另立一条，说的是很短的一段时间。查到整词之后还可以做一步：把“片刻”换进原句，看能否交代下一件事何时发生。[查“須臾”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=須臾)

## 知识点：查找复词并用下文复核 {#s.l5.wordhead}
义项：查找复词并用下文复核
领域：阅读技能
要诀：先查整词，再读紧跟它的动作
讲解：先记下两个相连的字，看辞书是否另收词条。把查到的解释放回句子，看看谁做了什么、隔了多久。
例句：p.l5.1.example
复习题：q.l5.1.1 q.l5.1.3 q.l5.1.5 q.l5.1.7

## 原文：教学例句 {#p.l5.1.example}
> 客方踌躇，未决所往。
译文：客人正踌躇，没拿定主意去哪里。“踌躇”可以连着查。

## 原文：古籍引文 {#p.l5.1.a}
> 秦惠王欲先伐韩，后伐蜀，恐不利；欲先伐蜀，恐韩袭秦之敝，犹豫未能决。
译文：秦惠王想先攻韩再攻蜀，怕不利；想先攻蜀，又怕韩国趁秦国困弊来袭，一时定不下来。
词注：敝：困乏、疲弱。这里说一国被耗损后的处境。
  犹豫：迟疑，拿不定主意。

## 单选：“犹豫未能决”，该查哪一个词条？ {#q.l5.1.1}
考点：s.l5.wordhead
语境：p.l5.1.a

- [x] 犹豫：迟疑 {#q.l5.1.1.o1}
- [ ] 豫：预备 {#q.l5.1.1.o3}
  理由：单查“豫”漏掉了紧相连的“犹”。
- [ ] 犹：如同 {#q.l5.1.1.o2}
  理由：“如同”后要有可作比较的事，这里写两种难下的决定。

提示：看“未能决”是在说心思还是准备工作。
解析：“犹豫”和“未能决”前后相应，合查能读通。

## 找原文证据：哪几个字可用来复核“犹豫”的解释？ {#q.l5.1.2}
考点：s.l5.wordhead
语境：p.l5.1.a

- [ ] 先伐韩 {#q.l5.1.2.o2}
  理由：这只是考虑到的一种先后次序。
- [x] 未能决 {#q.l5.1.2.o1}
- [ ] 秦之敝 {#q.l5.1.2.o3}
  理由：这是秦王担心的一个后果。

提示：找最后说秦王有没有定主意的地方。
解析：“未能决”明说决定还没做成。

## 单选：若只抄“秦惠王欲先伐韩”，会漏掉秦王的哪层意思？ {#q.l5.1.3}
考点：s.l5.wordhead
语境：p.l5.1.a

- [ ] 他不再顾虑韩国 {#q.l5.1.3.o3}
  理由：“恐韩袭秦之敝”正写他的顾虑。
- [ ] 他已经决定先攻韩 {#q.l5.1.3.o2}
  理由：后文还在考虑先攻蜀。
- [x] 这只是他权衡的两种办法之一 {#q.l5.1.3.o1}

提示：留意第二次出现的“欲”。
解析：两个“欲”各说一种打算。“犹豫”收住的是两面权衡。

## 单选：辞书把“猶豫”列为一个条目。引用这句做用例，抄哪段最便于人查验？ {#q.l5.1.4}
考点：s.l5.wordhead
语境：p.l5.1.a

- [x] 犹豫未能决 {#q.l5.1.4.o1}
- [ ] 后伐蜀 {#q.l5.1.4.o3}
  理由：只说次序，读者不知道要查哪个词。
- [ ] 恐韩袭秦之敝 {#q.l5.1.4.o2}
  理由：只留了担忧的事，没留下被解释的词。

提示：把所查的词和紧跟它的说明一并留下。
解析：这五个字既有词头，又有同句解释它的处境。

## 原文：古籍引文 {#p.l5.1.b}
> 西门豹曰：“诺，且留待之须臾。”须臾，豹曰：“廷掾起矣。状河伯留客之久。”
译文：西门豹说：“好，姑且留下等他一会儿。”过了片刻，他说：“廷掾们起来吧。看来河伯把客人留了很久。”
词注：须臾：读 xū yú，片刻。
  廷掾：读 tíng yuàn，县廷属吏。

## 单选：第一个“须臾”给“待”补充了什么？ {#q.l5.1.5}
考点：s.l5.wordhead
语境：p.l5.1.b

- [ ] 等谁 {#q.l5.1.5.o2}
  理由：“之”已经代要等的人。
- [x] 等多久 {#q.l5.1.5.o1}
- [ ] 等在何处 {#q.l5.1.5.o3}
  理由：“须臾”是时长，未指定地方。

提示：试换成“一会儿”。
解析：“待之”有了对象，“须臾”说等的时间。

## 单选：第二个“须臾”移到“豹曰”之前，怎样接下文？ {#q.l5.1.6}
考点：s.l5.wordhead
语境：p.l5.1.b

- [ ] 西门豹同时说出了两段话 {#q.l5.1.6.o3}
  理由：前一个“待”在两次说话之间留了时间。
- [ ] 暂且需要一个叫臾的人说话 {#q.l5.1.6.o2}
  理由：“豹”才是后句说话的人。
- [x] 过了一会儿，西门豹又开口 {#q.l5.1.6.o1}

提示：看看两处“曰”之间发生了什么。
解析：同一表示短时的词，这次交代他再次开口的时间。

## 单选：“留客之久”的“久”，能证明“须臾”意为很久吗？ {#q.l5.1.7}
考点：s.l5.wordhead
语境：p.l5.1.b

- [x] 不能，前者说留客，后者写西门豹等候 {#q.l5.1.7.o1}
- [ ] 能，“须臾”只在段末表短时 {#q.l5.1.7.o3}
  理由：词义没有这样的段落位置限制。
- [ ] 能，凡在同一段里时间就相等 {#q.l5.1.7.o2}
  理由：叙述所写的等待和人物所说的留客是两回事。

提示：别把西门豹说的话当作叙述者计时。
解析：等了片刻是叙事时间；留客之久是西门豹当场的说辞。

## 单选：把这一用例收进词条，怎样记录第二次出现的“须臾”？ {#q.l5.1.8}
考点：s.l5.wordhead
语境：p.l5.1.b

- [ ] 须／臾豹曰——等待姓臾的人 {#q.l5.1.8.o2}
  理由：“豹”承上指西门豹，“臾豹”没有人物依据。
- [x] 须臾，豹曰——片刻之后，豹说 {#q.l5.1.8.o1}
- [ ] 须臾豹／曰——“须臾豹”是称呼 {#q.l5.1.8.o3}
  理由：前句已写全名，不能凭相邻三字造出新人。

提示：对照上句末尾同样的两个字。
解析：句首的时间词独立可通，不必同后面的人名连读。
