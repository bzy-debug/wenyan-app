# 课文：先找字头，再辨音义 {#l5.1}
简介：读“好学”和“冠者”，比较同一字头下不同读音所领的义项。

## 正文

### 两次检索才能读通一句

在教育部《重编国语辞典修订本》中检索「好」，留意 hǎo 与 hào 各自统领的释义。读到“好学”，可以试两种解释：“学得好”，还是“喜欢学习”？再看评价此人的其他语句，解释通了才记读音。

「冠」也分 guān、guàn。前者可以是帽子，后者可以表示戴帽或行冠礼。读「冠者」时，要看这个词与哪一类人并列。字头旁的第一种读音未必适合眼前的一句。

记录一条能在新文章里用的笔记：**字头 → 候选读音 → 句中的搭配 → 此处的解释**。现代普通话注音用来认读，不用它反推古人当时的实际发音。

查阅《重编国语辞典修订本》的字头。[好](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%A5%BD) · [冠](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%86%A0)

义项：依搭配在一个字头下选读音与释义
领域：阅读技能
要诀：把候选音义成对代入
讲解：字典按字头收字，一字可有几个读音。说明词性、指出搭配，再选能够解释整句的音义。

## 原文：教学例句 {#p.l5.1.example}
> 生好问，师好其勤。
译文：学生喜欢发问，老师欣赏他的勤勉。这里两处“好”都可以带对象，按 hào 试读。

## 原文：古籍引文 {#p.l5.1.a}
> 子贡问曰：“孔文子何以谓之‘文’也？”子曰：“敏而好学，不耻下问，是以谓之‘文’也。”
译文：子贡问孔文子为什么被称为“文”。孔子说，他敏于学习，喜爱求学，不以向地位或学识不如自己的人请教为耻，所以得此称号。

## 单选：若字典给出 hǎo“优良”、hào“喜爱”，这里用哪一项？ {#q.l5.1.1}
考点：skill.l5.1
语境：p.l5.1.a

- [x] hào，喜爱学习 {#q.l5.1.1.o1}
- [ ] hǎo，已经学好一切 {#q.l5.1.1.o3}
  理由：“下问”说明他还会向别人求教。
- [ ] hǎo，所学的内容优良 {#q.l5.1.1.o2}
  理由：问答在解释孔文子的品行，没有评论教材优劣。

提示：把释义和“学”连起来，再读下句。
解析：“好”可以带所爱之事。“学”是他喜爱的活动，下句又具体写他求教。

## 找原文证据：哪处行为给“好学”的读法提供了旁证？ {#q.l5.1.2}
考点：skill.l5.1
语境：p.l5.1.a

- [ ] 子贡问曰 {#q.l5.1.2.o2}
  理由：这是子贡发问，孔文子没有在此开口。
- [x] 不耻下问 {#q.l5.1.2.o1}
- [ ] 何以谓之 {#q.l5.1.2.o3}
  理由：这是询问称号的由来，尚未说到品行。

提示：分清发问者和被评价的人。
解析：愿意向别人请教，正是孔文子喜爱学习的表现。

## 单选：要将此段作为辞书的例证，哪一种引法交代得最清楚？ {#q.l5.1.3}
考点：skill.l5.1
语境：p.l5.1.a

- [ ] 引“孔文子”，释“好”为谥号 {#q.l5.1.3.o3}
  理由：被问的称号是“文”。
- [ ] 只引“敏而”，释“好”为敏捷 {#q.l5.1.3.o2}
  理由：“敏”与“好”相连，仍是两个不同的品质。
- [x] 引“敏而好学，不耻下问”，说明“好”带学习活动 {#q.l5.1.3.o1}

提示：找含有目标字并能确定用法的短语。
解析：保留“好”的对象及下句行为，别人就能复查你选的义项。

## 单选：若把“下问”误接成子贡的行为，会怎样影响判断？ {#q.l5.1.4}
考点：skill.l5.1
语境：p.l5.1.a

- [x] 失去孔文子好学的具体行为证据 {#q.l5.1.4.o1}
- [ ] 说明孔子是来向子贡请教的 {#q.l5.1.4.o3}
  理由：“子曰”引的是答话，提问在前。
- [ ] 证明“好”应该念 hǎo {#q.l5.1.4.o2}
  理由：误认行为人不能为另一读音提供证据。

提示：看“是以”把哪些品质归给同一人。
解析：答话里的“敏”“好学”“不耻下问”共同解释孔文子的称号。

## 原文：古籍引文 {#p.l5.1.b}
> 莫春者，春服既成，冠者五六人，童子六七人，浴乎沂，风乎舞雩，咏而归。

## 单选：查“冠”见 guān（帽）、guàn（加冠）。哪种理解能说明“冠者五六人”？ {#q.l5.1.5}
考点：skill.l5.1
语境：p.l5.1.b

- [ ] guān，五六顶帽子 {#q.l5.1.5.o2}
  理由：计数单位是“人”，还与“童子”并列。
- [x] guàn，行过冠礼的人 {#q.l5.1.5.o1}
- [ ] guàn，每人正给童子戴帽 {#q.l5.1.5.o3}
  理由：下文列两组同行者，没有写行礼现场。

提示：留意人数以及下一组人的称呼。
解析：“者”指人，和童子对举。“冠”取行冠礼的义项，在此表示已经成年。

## 找原文证据：哪一称呼最能帮助读者确认“冠者”按年龄身份分组？ {#q.l5.1.6}
考点：skill.l5.1
语境：p.l5.1.b

- [ ] 春服 {#q.l5.1.6.o3}
  理由：衣服可以提示季节，不能单独确定这两组人的分别。
- [ ] 舞雩 {#q.l5.1.6.o2}
  理由：“乎舞雩”说明吹风的地点。
- [x] 童子 {#q.l5.1.6.o1}

提示：在连续出现的两个人数前找名词。
解析：“童子六七人”与“冠者五六人”的句式相同，两个称呼分指年少者和成年人。

## 单选：为什么不能只见“春服”便断定“冠”是名物“帽子”？ {#q.l5.1.7}
考点：skill.l5.1
语境：p.l5.1.b

- [x] “冠者”在数人，与“春服”各自成句 {#q.l5.1.7.o1}
- [ ] 古文中的“冠”只有一个读音 {#q.l5.1.7.o3}
  理由：字典收有帽子与加冠等不同音义。
- [ ] 春服从来不与帽子并用 {#q.l5.1.7.o2}
  理由：文本并没有规定服饰的搭配。

提示：按短语划出“春服既成”和“冠者五六人”。
解析：同一段中有衣服，并不决定后文每个服饰字都作名词。要核对“者”和“人”。

## 单选：若做辞书引例，怎样摘录能让人复查 guàn 所指的人？ {#q.l5.1.8}
考点：skill.l5.1
语境：p.l5.1.b

- [ ] 只引“风乎舞雩”，以“风”当作“冠”的注音 {#q.l5.1.8.o2}
  理由：风与冠是不同的字，地点和动作也没有给冠注音。
- [x] 并引“冠者五六人，童子六七人”，指出两组身份对举 {#q.l5.1.8.o1}
- [ ] 只引“冠”，据字形断定在数帽子 {#q.l5.1.8.o3}
  理由：单字脱离“者”和分组，不能说明本句音义。

提示：让引文保留能消除歧义的邻近词。
解析：读音分项解决的是这个字在这里指什么；引例应保留人数和童子的对举。
