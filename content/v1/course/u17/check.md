# 检查：查音、释字与名物：独立检索 {#check.17}

## 原文：古籍引文 {#p.check.17.a}
> 不违农时，谷不可胜食也；数罟不入洿池，鱼鳖不可胜食也；斧斤以时入山林，材木不可胜用也。

## 单选：辞书列“数”shǔ（点数）、cù（细密）。哪项更能解释“数罟不入洿池”？ {#q.check.17.1}
考点：skill.l5.1
语境：p.check.17.a

- [ ] shǔ，点清网有几张才进池塘 {#q.check.17.1.o2}
  理由：“不入”针对何种网可以下水，没写清点后入池。
- [x] cù，修饰捕鱼的网眼细密 {#q.check.17.1.o1}
- [ ] shǔ，数鱼而不数鳖 {#q.check.17.1.o3}
  理由：“数”紧挨“罟”，鱼鳖在下一分句中。

提示：看“数”之后被修饰的名物。
解析：罟是网，“数罟”指密网。不让密网入池与保护鱼鳖的结果能接上。

## 单选：释“斤”有重量单位、斧一类工具等项。哪种试代能使第三分句通顺？ {#q.check.17.2}
考点：skill.l5.3
语境：p.check.17.a

- [ ] 食器，以时入山采鱼 {#q.check.17.2.o3}
  理由：上一句写池鱼，此句对象已换为山林和材木。
- [ ] 重量，木料达到一斤方能入山 {#q.check.17.2.o2}
  理由：“入山林”的是采伐一方，木料无须先进山。
- [x] 工具，与“斧”并列，代指采伐活动 {#q.check.17.2.o1}

提示：顺着“入山林”一直读到“材木”。
解析：“斧斤”是采伐用具；时令限制说明使用它们的活动。

## 单选：“洿”字生僻，有人径自改作“污”，称二字到处可换。怎样复核？ {#q.check.17.3}
考点：skill.l5.2
语境：p.check.17.a

- [x] 先存原字，查“洿池”的积水池义，再核字书所记关系 {#q.check.17.3.o1}
- [ ] 见到三点水便断定池水肮脏 {#q.check.17.3.o3}
  理由：部件提示与水有关，未必评价水质。
- [ ] 见到同音立即互换，词义无需比对 {#q.check.17.3.o2}
  理由：同音只能提供检索线索，不能证明各用法相同。

提示：区分释读此句与宣布两字通用。
解析：水域和鱼鳖可支持池义，不能据此断定“洿”“污”的全部用法相同。

## 原文：古籍引文 {#p.check.17.b}
> 子曰：“饭疏食饮水，曲肱而枕之，乐亦在其中矣。不义而富且贵，于我如浮云。”
译文：孔子说，吃简单的食物、喝水，弯着手臂把它当枕头，乐趣也在其中。以不义手段获得的富贵，在我看来像浮云。

## 单选：查“枕”见名物“枕头”和动作“以……作枕”。哪一项可以带后面的“之”？ {#q.check.17.4}
考点：skill.l5.1
语境：p.check.17.b

- [ ] 名物，名叫“之”的枕头 {#q.check.17.4.o2}
  理由：前面已有能供回指的“肱”，“之”不是枕头名。
- [x] 动作，把弯曲的手臂作枕 {#q.check.17.4.o1}
- [ ] 名物，曲肱托着另一只枕头 {#q.check.17.4.o3}
  理由：原文没有另添一件寝具。

提示：把候选义项放在“之”前面试读。
解析：“枕之”中的“之”是动作对象，回指前面的手臂。选动作义可以保持句子连贯。

## 单选：有人把底本“肱”直接抄为“胳膊”。如何标注才便于复查？ {#q.check.17.5}
考点：skill.l5.2
语境：p.check.17.b

- [ ] 把所有“肱”都注明为“膊”的异体字 {#q.check.17.5.o3}
  理由：两词意思相近不能直接证明字形关系。
- [ ] 将“胳膊”写进引号，称古本本就如此 {#q.check.17.5.o2}
  理由：白话释义不等于古本实际字形。
- [x] 原文保留“肱”，把“胳膊”记入今译 {#q.check.17.5.o1}

提示：分别记录古书字形和现代解释。
解析：“肱”可释为手臂，释义相近与异体关系仍是两个问题。

## 单选：若注“肱”为上臂，整段对“乐”的说明怎样读最稳妥？ {#q.check.17.6}
考点：skill.l5.3
语境：p.check.17.b

- [x] 生活朴素依然有乐，不义的富贵不值得求 {#q.check.17.6.o1}
- [ ] 应精确计算一餐几升，才能说明快乐 {#q.check.17.6.o3}
  理由：这段没有列升数，论旨在处境与取舍。
- [ ] “肱”是豪华寝具，富贵使人快乐 {#q.check.17.6.o2}
  理由：“曲肱而枕之”交代的恰是就身取枕的简朴。

提示：把用手臂作枕与末句价值判断放在一起。
解析：字书解释出身体部位，读者再循“亦”“不义”判断这种生活与价值选择的关系。
