# 检查：另翻三条：逡巡、女、语 {#check.17}

## 原文：古籍引文 {#p.check.17.a}
> 于是二子愀然改容，超若自失，逡巡避席曰：“鄙人固陋，不知忌讳，乃今日见教。”
译文：于是两人神色变了，茫然像有所失，恭顺地退下座席，说：“我们鄙陋，不懂避忌，到今天才受到指教。”
词注：愀然：读 qiǎo rán，脸色有所改变，显出郑重或不安。
  逡巡：读 qūn xún，这里说二人恭谨退让的样子。

## 单选：“逡巡”有迟疑、谦退等解释。紧邻哪个动作使谦退一义贴切？ {#q.check.17.1}
考点：s.l5.wordhead
语境：p.check.17.a

- [ ] 神色变化本身 {#q.check.17.1.o2}
  理由：变色在前，未直接交代身体怎样退让。
- [x] 离开座席 {#q.check.17.1.o1}
- [ ] 开始教别人 {#q.check.17.1.o3}
  理由：他们说自己“见教”，是受教的人。

提示：读“逡巡”后紧跟的两个字。
解析：“避席”是离席以示敬，恰好给合查所得的谦退义补上动作。

## 单选：若要在按首字编排的辞书里找完整用例，从哪里入手？ {#q.check.17.2}
考点：s.l5.wordhead
语境：p.check.17.a

- [ ] 先把“逡巡”改写成“巡行” {#q.check.17.2.o3}
  理由：原书没有说两人出去巡察。
- [ ] 到“巡”下只抄巡察之义 {#q.check.17.2.o2}
  理由：那会漏掉合词及避席的礼貌场合。

解析：依首字查整词，再用“避席”说明本句为什么取谦退义。

## 原文：古籍引文 {#p.check.17.b}
> 子谓子夏曰：“女为君子儒，无为小人儒。”
译文：孔子对子夏说：“你要做君子那样的儒者，不要做小人那样的儒者。”
词注：女：这里读 rǔ，同“汝”，你。
  无：用于告诫，意为不要。

## 单选：“女”字下有“女子”和“同汝，你”。这句取哪项？ {#q.check.17.3}
考点：s.l5.loanreading
语境：p.check.17.b

- [x] 汝，你，称面前的子夏 {#q.check.17.3.o1}
- [ ] 女儿，孔子在告诫自己的孩子 {#q.check.17.3.o3}
  理由：这里的称名和说话对象都是子夏。
- [ ] 女子，另来了一位女学生 {#q.check.17.3.o2}
  理由：句首点名孔子在对子夏说话。

提示：看看引语前的“谓”带谁。
解析：说话的场合和告诫的语气都支持第二人称。

## 找原文证据：抄哪一处，可说明释“女”为“你”的依据？ {#q.check.17.4}

## 原文：古籍引文 {#p.check.17.c}
> 孟子见梁襄王，出，语人曰：“望之不似人君，就之而不见所畏焉。”
译文：孟子见过梁襄王，出来后告诉别人：“远望他不像国君，走近他，也看不出什么使人敬畏的地方。”
词注：语：这里读 yù，告诉。
  就：走近，靠近。

## 单选：“语”有 yǔ（话语）和 yù（告诉）等项。“出，语人曰”取哪项？ {#q.check.17.5}
考点：s.l5.rolevoice
语境：p.check.17.c

- [ ] yǔ，别人发表的言论 {#q.check.17.5.o3}
  理由：“人”是听话人，孟子才是发言者。
- [ ] yǔ，指一本语录 {#q.check.17.5.o2}
  理由：这里没有书，后面的“曰”正引说出的话。
- [x] yù，告诉别人 {#q.check.17.5.o1}

提示：谁出来后对谁说话？
解析：“语”带了听告的人，又引出说话内容，是动词“告诉”。

## 单选：给这条辞例标出人物，哪项合适？ {#q.check.17.6}
考点：s.l5.rolevoice
语境：p.check.17.c

- [x] 孟子告诉别人，他对梁襄王印象如何 {#q.check.17.6.o1}
- [ ] 别人出来告诉梁襄王自己的印象 {#q.check.17.6.o3}
  理由：“语人”把别人放在受告的位置。
- [ ] 梁襄王告诉孟子他对百姓的印象 {#q.check.17.6.o2}
  理由：“出”承接的是入见的孟子。

提示：从“孟子见梁襄王”顺着读到引语。
解析：记录告者、受告者和所告之事，正能复核 yù 这一读法。
