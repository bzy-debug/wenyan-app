# 检查：查一查鱼网、斧斤和曲肱 {#check.17}

## 原文：古籍引文 {#p.check.17.a}
> 不违农时，谷不可胜食也；数罟不入洿池，鱼鳖不可胜食也；斧斤以时入山林，材木不可胜用也。
译文：不耽误农时，谷物就吃不尽。细密的渔网不下池塘，鱼鳖就吃不尽。按时节进山伐木，木材就用不尽。

## 单选：“数罟不入洿池”的“数”，该读成 shǔ（点数）还是 cù（细密）？ {#q.check.17.1}
考点：skill.l5.1
语境：p.check.17.a

- [ ] shǔ，点清网有几张才进池塘 {#q.check.17.1.o2}
  理由：“不入”针对何种网可以下水，没写清点后入池。
- [x] cù，修饰捕鱼的网眼细密 {#q.check.17.1.o1}
- [ ] shǔ，数鱼而不数鳖 {#q.check.17.1.o3}
  理由：“数”紧挨“罟”，鱼鳖在下一分句中。

提示：“罟”是网。哪种读法解释了禁用哪一种网？
解析：“数罟”是密网。禁用这样的网，和下句说的鱼鳖吃不尽正好接上。

## 单选：“斤”既是重量单位，也可指斧一类工具。怎样读“斧斤以时入山林”？ {#q.check.17.2}
考点：skill.l5.3
语境：p.check.17.a

- [ ] 食器，以时入山采鱼 {#q.check.17.2.o3}
  理由：上一句写池鱼，此句对象已换为山林和材木。
- [ ] 重量，木料达到一斤方能入山 {#q.check.17.2.o2}
  理由：“入山林”的是采伐一方，木料无须先进山。
- [x] 工具，与“斧”并列，代指采伐活动 {#q.check.17.2.o1}

提示：留意入山之后取得的是什么。
解析：“斧斤”合说砍伐用具。定时入山采伐，才接得上后面的“材木”。

## 单选：能把底本里的“洿”径改为“污”，还说二字处处可换吗？该从何查起？ {#q.check.17.3}
考点：skill.l5.2
语境：p.check.17.a

- [x] 先存原字，查“洿池”的积水池义，再核字书所记关系 {#q.check.17.3.o1}
- [ ] 见到三点水便断定池水肮脏 {#q.check.17.3.o3}
  理由：三点水可以提示水义。池水到底脏不脏，看偏旁还说不准。
- [ ] 见到同音立即互换，词义无需比对 {#q.check.17.3.o2}
  理由：同音只能提供检索线索，不能证明各用法相同。

提示：能读通“洿池”，和证明两个字用法全同，需要的根据一样吗？
解析：鱼鳖生活在池水里，可用来理解“洿池”。要讲两字能否通用，还得另查字书。

## 原文：古籍引文 {#p.check.17.b}
> 子曰：“饭疏食饮水，曲肱而枕之，乐亦在其中矣。不义而富且贵，于我如浮云。”
译文：孔子说，吃简单的食物、喝水，弯着手臂把它当枕头，乐趣也在其中。以不义手段获得的富贵，在我看来像浮云。

## 单选：“枕之”的“枕”是一个枕头，还是一个动作？ {#q.check.17.4}
考点：skill.l5.1
语境：p.check.17.b

- [ ] 名物，名叫“之”的枕头 {#q.check.17.4.o2}
  理由：刚说“曲肱”，“之”正能接回这只手臂，并没有给枕头命名。
- [x] 动作，把弯曲的手臂作枕 {#q.check.17.4.o1}
- [ ] 名物，曲肱托着另一只枕头 {#q.check.17.4.o3}
  理由：弯起手臂就能枕，句中没有说另外取了一个枕头。

提示：前面刚刚弯起了什么？试着用那个词换下“之”。
解析：“之”指弯起来的手臂。把它当枕头，是“枕”这个动作。

## 单选：想用“胳膊”解释“肱”，引文和注释该怎么写？ {#q.check.17.5}
考点：skill.l5.2
语境：p.check.17.b

- [ ] 把所有“肱”都注明为“膊”的异体字 {#q.check.17.5.o3}
  理由：解释身体部位可以用近义词，要说“肱”“膊”是同一个字的写法，还差字书上的根据。
- [ ] 将“胳膊”写进引号，称古本本就如此 {#q.check.17.5.o2}
  理由：白话释义不等于古本实际字形。
- [x] 原文保留“肱”，把“胳膊”记入今译 {#q.check.17.5.o1}

提示：若别人拿底本来对，在哪儿该看到“肱”？
解析：引号里照写“肱”，注里用“胳膊”来解释。意思相近，还不能据此把两个字说成异体字。

## 单选：知道“肱”是上臂后，再读“乐亦在其中”，哪种解释也能照顾到末句？ {#q.check.17.6}
考点：skill.l5.3
语境：p.check.17.b

- [x] 生活朴素依然有乐，不义的富贵不值得求 {#q.check.17.6.o1}
- [ ] 应精确计算一餐几升，才能说明快乐 {#q.check.17.6.o3}
  理由：看下文怎样谈不义的富贵，不必从上句算一顿饭有多少升。
- [ ] “肱”是豪华寝具，富贵使人快乐 {#q.check.17.6.o2}
  理由：“曲肱而枕之”交代的恰是就身取枕的简朴。

提示：把曲肱作枕的生活，和“不义而富且贵”放在一起想。
解析：饭食简朴，连枕头也用自己的手臂，仍有可乐。用不义换来的富贵，反而轻如浮云。
