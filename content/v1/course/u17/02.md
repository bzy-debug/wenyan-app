# 课文：原书的“归”，另一处为什么写“馈”？ {#l5.2}
简介：对照两段记同一件事的话，再试查“蚤起”的“蚤”。

## 正文

《论语》说阳货“归孔子豚”，《孟子》叙同一件事用了“馈”。把阳货、孔子、豚一一对齐，就能看出两句究竟在哪个动作上相同。这里的“归”可以通“馈”，读 kuì。

碰到“蚤起”，可以查“蚤”字下通“早”的一项，再查它前后写的是人的起居还是昆虫。引古书时保留原字，在旁边写解释；改成常见字再说原书就是这样写的，会丢掉查证的线索。

## 知识点：借助平行记载辨识借字 {#s.l5.loanreading}
义项：借助平行记载辨识借字
领域：阅读技能
要诀：比对同一人、物和动作
讲解：若某个字按常义读不通，先找相同的句法、相同的故事或可靠的辞书用例。不能只凭两个字今天听着相近就互换。
例句：p.l5.2.example
复习题：q.l5.2.1 q.l5.2.3 q.l5.2.5 q.l5.2.7

## 原文：教学例句 {#p.l5.2.example}
> 仆蚤行，日未出。
译文：仆人早早动身，太阳还没有出来。“蚤”写的是出行的时刻。

## 原文：古籍引文 {#p.l5.2.a}
> 阳货欲见孔子，孔子不见，归孔子豚。孔子时其亡也，而往拜之。
译文：阳货想让孔子来见自己，孔子不去见他。阳货送孔子一只小猪。孔子挑他不在时前去拜谢。
词注：归：这里通“馈”，读 kuì，赠送。
  豚：读 tún，小猪。
  亡：人不在家。

## 单选：对读《孟子》的“馈孔子蒸豚”，哪一处能帮你释“归”？ {#q.l5.2.1}
考点：s.l5.loanreading
语境：p.l5.2.a

- [x] “馈”占据了同一个动作的位置 {#q.l5.2.1.o1}
- [ ] “豚”表示归家的方向 {#q.l5.2.1.o3}
  理由：“豚”是猪，正是所送的东西。
- [ ] “蒸”取代了“孔子” {#q.l5.2.1.o2}
  理由：“蒸”修饰豚，收礼人两处都是孔子。

提示：把两句的收礼人、礼物先对齐。
解析：两段都讲阳货赠豚，另一记载的“馈”使这里的赠送义有据。

## 找原文证据：哪几个字连起来能看清“归”的受者和所送之物？ {#q.l5.2.2}
考点：s.l5.loanreading
语境：p.l5.2.a

- [ ] 欲见 {#q.l5.2.2.o2}
  理由：这是阳货想做的另一件事。
- [x] 孔子豚 {#q.l5.2.2.o1}
- [ ] 时其亡也 {#q.l5.2.2.o3}
  理由：这是孔子选拜谢时机。

提示：读“归”之后相接的两个名词。
解析：“孔子”是收礼的人，“豚”是送去的猪。

## 单选：若把“归孔子豚”译成“孔子的猪跑回家”，哪一点讲不通？ {#q.l5.2.3}
考点：s.l5.loanreading
语境：p.l5.2.a

- [ ] “豚”一定指已经长成的大猪 {#q.l5.2.3.o3}
  理由：“豚”指小猪，大小也不能解释赠礼。
- [ ] “欲见”本义就是送猪 {#q.l5.2.3.o2}
  理由：想见与送猪是两件相连的事。
- [x] 原来的送礼人与收礼人被抹掉了 {#q.l5.2.3.o1}

提示：拿“馈孔子蒸豚”的人物关系来核对。
解析：换成猪自己回家，就解释不了平行记载里的“馈”和下文的拜谢。

## 单选：笔记怎样既保存底本文字，又写明自己的理解？ {#q.l5.2.4}
考点：s.l5.loanreading
语境：p.l5.2.a

- [x] 抄“归孔子豚”，旁记“归通馈，赠送” {#q.l5.2.4.o1}
- [ ] 凡见“归”一律译成赠送 {#q.l5.2.4.o3}
  理由：这条证据只说明眼前这个用例。
- [ ] 把引号内改作“馈”，说《论语》原作馈 {#q.l5.2.4.o2}
  理由：这把用来解释的另一种写法冒充成本字面。

提示：区分抄录与释读。
解析：引文保留“归”；旁注交代解释所据，日后仍可复核。

## 原文：古籍引文 {#p.l5.2.b}
> 蚤起，施从良人之所之，遍国中无与立谈者。
译文：妻子早早起身，暗中跟着丈夫看他到哪里去。走遍都城，没有人同他站着交谈。
词注：良人：妻子称丈夫。
  之所之：他要去的地方。第二个“之”意为往、去。
  蚤：这里通“早”，说起身的时间。

## 单选：查“蚤”，有“跳蚤”和“通早”两项，哪项能放进“蚤起”？ {#q.l5.2.5}
考点：s.l5.loanreading
语境：p.l5.2.b

- [ ] 跳蚤，指妻子跟着的一只虫 {#q.l5.2.5.o2}
  理由：后文跟随的是“良人”，即丈夫。
- [x] 通“早”，说妻子何时起身 {#q.l5.2.5.o1}
- [ ] 凡带虫旁都指人物的外貌 {#q.l5.2.5.o3}
  理由：字形不能直接决定这一句的用义。

提示：把解释放到“起”之前试读。
解析：“早”说明起身的时间，正好接人起身跟随的动作。

## 单选：“蚤起”能证明下面哪一条？ {#q.l5.2.6}
考点：s.l5.loanreading
语境：p.l5.2.b

- [ ] 写虫的“蚤”也必须改成“早” {#q.l5.2.6.o3}
  理由：指虫时意思不同，不能照搬。
- [ ] 古书里的“蚤”从不用来写虫 {#q.l5.2.6.o2}
  理由：一个例子无法排除字的本义。
- [x] 这里曾用“蚤”来写早晚的“早” {#q.l5.2.6.o1}

提示：一条用例所能证明的范围有多大？
解析：这处借写要和它所出现的语境一起记。

## 找原文证据：哪一处最能接在“早早起身”后面，构成妻子接着做的事？ {#q.l5.2.7}
考点：s.l5.loanreading
语境：p.l5.2.b

- [x] 施从良人之所之 {#q.l5.2.7.o1}
- [ ] 无与立谈者 {#q.l5.2.7.o3}
  理由：这是跟踪之后的观察结果。
- [ ] 蚤起 {#q.l5.2.7.o2}
  理由：这就是要解释的起身动作。

提示：找妻子刚起身便做的动作。
解析：她起身后暗中跟随丈夫，后面才说她观察到了什么。

## 单选：另见“早”字时，为何不能单凭读音倒改成“蚤”？ {#q.l5.2.8}
考点：s.l5.loanreading
语境：p.l5.2.b

- [ ] 因为两字今天一定不同音 {#q.l5.2.8.o2}
  理由：今天普通话的读音不能作这个否定判断。
- [x] 借写须有那一处的用例或版本证据 {#q.l5.2.8.o1}
- [ ] 因为“蚤”只能写在“起”前 {#q.l5.2.8.o3}
  理由：这一条引文没有给全书订用字规则。

提示：判断自己手里的证据究竟只来自哪里。
解析：《孟子》的一个例子给出可查的写法，未授权读者替别的底本改字。
