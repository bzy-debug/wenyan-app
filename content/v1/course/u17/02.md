# 课文：古书为什么写“女”和“莫” {#l5.2}
简介：读到古书里的“女”和“莫”，怎样说明它在这里是什么意思，又不把原字抄丢？

## 正文

### 古书为什么把“你”写成“女”？

孔子开口叫“由”，接着说“诲女”。人就在跟前，“女”若照“女子”讲，话便绕远了。查到古书中“女”可以借写“汝”，这一句就能读成“教你”。抄经文仍写“女”，心里的那句白话另记。

再看“莫”。它原能表示日暮，后来添了“暮”字来分担这个意思。这和“峯／峰”同一个字有两种写法又不尽相同。把原书怎么写、这句话怎么讲分开记；想说明两个字的来历，再查字书。暂时只能读通句意也无妨。

查字时可直接翻到这里。[女](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%A5%B3) · [莫](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E8%8E%AB) · [峰](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%B3%B0) · [《异体字字典》字形检索](https://dict.variants.moe.edu.tw/)

## 原文：教学例句 {#p.l5.2.example}
> 父告子曰：“女当徐行，前有深沟。”
译文：父亲对孩子说：“你得慢慢走，前面有条深沟。”这里的“女”就是父亲口中的“你”。

## 原文：古籍引文 {#p.l5.2.a}
> 子曰：“由！诲女知之乎！知之为知之，不知为不知，是知也。”
译文：孔子说：“仲由！我告诉你怎样对待知道和不知道的事吧。知道就说知道，不知道就说不知道，这才是明智。”

## 单选：孔子叫了声“由”，接着说“诲女”。这个“女”该按哪一义来查？ {#q.l5.2.1}
考点：skill.l5.2
语境：p.l5.2.a

- [x] 作第二人称，指受教的仲由 {#q.l5.2.1.o1}
- [ ] 嫁女，指老师为人主婚 {#q.l5.2.1.o3}
  理由：后文反复谈知与不知，没有婚礼。
- [ ] 女子，说明受教者性别 {#q.l5.2.1.o2}
  理由：开头叫的是仲由，称呼与下文连贯。

提示：把“诲女”换成老师当面会说的话。
解析：“由”是仲由的名。老师叫住他，说“教你”，这里用“女”来写“汝”。

## 找原文证据：原文哪个字是孔子直接叫听者的名字？ {#q.l5.2.2}
考点：skill.l5.2
语境：p.l5.2.a

- [ ] 子曰 {#q.l5.2.2.o2}
  理由：“子曰”交代说话者，并未点出听者。
- [x] 由 {#q.l5.2.2.o1}
- [ ] 是知也 {#q.l5.2.2.o3}
  理由：“是知也”已经在讲怎样才算明智，没有叫人名。

提示：看“诲女”前单独喊出来的字。
解析：“由！”一声把听话的人点出来。后面的“女”就指他。

## 单选：想让同学既看到原书怎样写，又读懂“女”，怎样抄、怎样注？ {#q.l5.2.3}
考点：skill.l5.2
语境：p.l5.2.a

- [ ] 正文改成“汝”，不标明改动 {#q.l5.2.3.o3}
  理由：“汝”有助释义，却并非此底本印出的字。
- [ ] 正文改成“你”，声称是逐字引文 {#q.l5.2.3.o2}
  理由：替同学讲成“你”可以，若把它当引文抄下，便看不出底本原来写“女”。
- [x] 正文抄“女”，注中说明作“汝”解 {#q.l5.2.3.o1}

提示：引号里放原字，想一想白话该写在哪里。
解析：经文抄“女”，注里说明它借作“汝”，就是“你”。这样两件事都能交代清楚。

## 单选：能否从这句话推出，别处凡有“女”字都要读成“你”？ {#q.l5.2.4}
考点：skill.l5.2
语境：p.l5.2.a

- [x] 同一字头另有指女性的用例，仍须按句判断 {#q.l5.2.4.o1}
- [ ] 古书每次出现“女”都在对人说话 {#q.l5.2.4.o3}
  理由：这回孔子在当面教仲由；换到别处，得先看还有没有一个正在听话的人。
- [ ] 这里训“汝”，应把辞书其他释义删掉 {#q.l5.2.4.o2}
  理由：这个例子只告诉我们孔子这句话怎么读。辞书收的其他用法仍各有出处。

提示：再翻同一个字头，看看还有哪些用法。
解析：这次是孔子在同仲由说话，别处“女”还可指女性。借字要逐句认。

## 原文：古籍引文 {#p.l5.2.b}
> 伍子胥曰：“为我谢申包胥曰：吾日莫途远，吾故倒行而逆施之。”于是申包胥走秦告急，求救于秦。秦不许。
译文：伍子胥请人转告申包胥：“我如今天色已晚，路又遥远，所以才会倒行逆施。”申包胥于是奔到秦国求救。秦国起初没有答应。

## 单选：“莫”可以表示禁止，也曾用来写“暮”。伍子胥说“日莫途远”，怎样读得通？ {#q.l5.2.5}
考点：skill.l5.2
语境：p.l5.2.b

- [ ] 不要有太阳，路途就会变短 {#q.l5.2.5.o2}
  理由：“日莫”说天晚，“途远”说路远。说话人没有在吩咐谁别做什么。
- [x] 天色已晚，路途尚远 {#q.l5.2.5.o1}
- [ ] 没有一天需要走远路 {#q.l5.2.5.o3}
  理由：“途远”明说前途遥远。

提示：让“日莫”与“途远”各说一件身不由己的事。
解析：天将晚，路还远。两句紧紧相对，伍子胥借此道出他觉得自己处境窘迫。

## 找原文证据：说完“日莫”，伍子胥又用了哪两个字来讲自己的处境？ {#q.l5.2.6}
考点：skill.l5.2
语境：p.l5.2.b

- [ ] 秦不许 {#q.l5.2.6.o3}
  理由：这是秦国对求救的态度。
- [ ] 走秦告急 {#q.l5.2.6.o2}
  理由：这是申包胥下一步的行动，已换人物。
- [x] 途远 {#q.l5.2.6.o1}

提示：留在伍子胥这句话里，不要读到申包胥赴秦的那一层。
解析：“途远”接在“日莫”后，路远更衬出天色已晚。

## 单选：字书说后来用“暮”字专写日暮。给底本的“莫”作注，怎样说合适？ {#q.l5.2.7}
考点：skill.l5.2
语境：p.l5.2.b

- [x] 古今字形有分工，本文“莫”保留了旧用 {#q.l5.2.7.o1}
- [ ] “莫”是本段抄手偶然漏写一笔 {#q.l5.2.7.o3}
  理由：先有“莫”写天晚，后来又有“暮”。见到旧写法，不宜照今字添笔。
- [ ] “莫”“暮”在任何句里都能互换 {#q.l5.2.7.o2}
  理由：禁止义的“莫”不能照此随意换成“暮”。

提示：想想旧写法有来历，和抄错了字有什么分别。
解析：旧书以“莫”写天晚，后来“暮”字分担了这一用法；底本的字自有来历。

## 单选：“峯、峰”是同一个字的两种写法。“莫、暮”是不是也处处可以相换？ {#q.l5.2.8}
考点：skill.l5.2
语境：p.l5.2.b

- [ ] 比较两字是否都能写进同一个方格 {#q.l5.2.8.o2}
  理由：方格与词义、用字沿革无关。
- [x] 查字书并比较“莫”表禁止时能否换成“暮” {#q.l5.2.8.o1}
- [ ] 按照笔画多少，把复杂者一律列作异体 {#q.l5.2.8.o3}
  理由：笔画变化既可出现于异体，也可出现于分化字。

提示：除了天晚，“莫”还可以用来劝人别做某事。
解析：把表示禁止的“莫”换成“暮”就读不通了。二字曾分担天晚的意思，用法却不全相同。
