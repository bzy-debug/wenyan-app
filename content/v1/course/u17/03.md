# 课文：“衣帛”的“衣”，是衣裳还是穿衣？ {#l5.3}
简介：把两个读音放回子路的袍子和孟子的桑树之间。

## 正文

翻到“衣”，先并排抄两项：yī，衣物；yì，穿、穿着。碰见“衣布”“衣帛”，先问布、帛在这里是不是所穿的东西。若整句还缺一个动作，而布帛正好是它的对象，动词项就值得试。

“锦衣”的“衣”却可以指一件衣物。查字不必急着给通篇统一读音。[查“衣”](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=衣)

## 知识点：从句中搭配确定多音字的音义 {#s.l5.rolevoice}
义项：从句中搭配确定多音字的音义
领域：实词
要诀：问后面跟的是穿戴者还是所穿之物
讲解：“衣”读 yī 可指衣服；读 yì 可表示穿、穿着。字形相同，句中所管的成分却不同。
例句：p.l5.3.example
复习题：q.l5.3.1 q.l5.3.3 q.l5.3.5 q.l5.3.7

## 原文：教学例句 {#p.l5.3.example}
> 客衣布，其衣甚薄。
译文：客人穿布衣，他的衣裳很薄。头一个“衣”说穿着，后一个“衣”指衣裳。

## 原文：古籍引文 {#p.l5.3.a}
> 子曰：“衣敝缊袍，与衣狐貉者立，而不耻者，其由也与？”
译文：孔子说：“穿破旧的絮袍，同穿狐貉皮衣的人站在一起，仍不觉得羞耻的，大概是仲由吧？”
词注：缊袍：填旧絮的袍子。此处“缊”读 yùn。
  狐貉：狐狸和貉的皮毛，这里借指裘衣。

## 单选：“衣敝缊袍”的“衣”应查哪个音义？ {#q.l5.3.1}
考点：s.l5.rolevoice
语境：p.l5.3.a

- [x] yì，穿 {#q.l5.3.1.o1}
- [ ] yī，包裹物品的外皮 {#q.l5.3.1.o3}
  理由：后文写穿不同衣物的人站在一起。
- [ ] yī，衣裳 {#q.l5.3.1.o2}
  理由：“敝缊袍”已经是所穿的衣物，这里要说人怎么穿着。

提示：看与它平行的“衣狐貉者”。
解析：两个“衣”都带所穿衣物，写的是穿着。

## 找原文证据：哪一处和“衣敝缊袍”有一样的搭配？ {#q.l5.3.2}
考点：s.l5.rolevoice
语境：p.l5.3.a

- [ ] 而不耻者 {#q.l5.3.2.o2}
  理由：这是面对衣着差异的态度。
- [x] 衣狐貉 {#q.l5.3.2.o1}
- [ ] 其由也与 {#q.l5.3.2.o3}
  理由：这是孔子指出可能是谁。

提示：找另一个“衣”字连带的词。
解析：一边是旧袍，一边是皮衣；两边都是人穿衣物。

## 单选：“衣狐貉者”怎样译能让“者”有着落？ {#q.l5.3.3}
考点：s.l5.rolevoice
语境：p.l5.3.a

- [ ] 替仲由缝补旧袍的人 {#q.l5.3.3.o3}
  理由：原文写穿戴，没有缝补的动作。
- [ ] 一堆狐狸和貉的皮 {#q.l5.3.3.o2}
  理由：这样没了与仲由并立的人。
- [x] 穿狐貉皮衣的人 {#q.l5.3.3.o1}

提示：谁能和仲由站在一起？
解析：“者”把“衣狐貉”整个用来指人。

## 单选：“由”在这段中是谁？ {#q.l5.3.4}
考点：s.l5.rolevoice
语境：p.l5.3.a

- [x] 穿旧袍却不以为耻的仲由 {#q.l5.3.4.o1}
- [ ] 把旧袍送给别人的人 {#q.l5.3.4.o3}
  理由：文中只写穿旧袍，没写相赠。
- [ ] 那件狐貉皮衣的名称 {#q.l5.3.4.o2}
  理由：“其由也与”是在推许一个人。

提示：从最后一句回指“而不耻者”。
解析：孔子说的是仲由的态度；两种衣着的对照才有意义。

## 原文：古籍引文 {#p.l5.3.b}
> 五亩之宅，树之以桑，五十者可以衣帛矣。鸡豚狗彘之畜，无失其时，七十者可以食肉矣。
译文：五亩的宅地上种桑，五十岁的人就可以穿丝织物了。鸡、猪、狗等牲畜的饲养不耽误时节，七十岁的人就可以吃肉了。
词注：树：种植。
  帛：丝织物。
  彘：读 zhì，猪。

## 单选：“衣帛”的“衣”是哪一个读音？ {#q.l5.3.5}
考点：s.l5.rolevoice
语境：p.l5.3.b

- [ ] yī，整句列出两种织物 {#q.l5.3.5.o2}
  理由：“五十者可以”后要说他们可以做什么。
- [x] yì，穿上帛衣 {#q.l5.3.5.o1}
- [ ] yī，桑树的外皮 {#q.l5.3.5.o3}
  理由：“五十者”说人，与树皮无关。

提示：对读末尾“可以食肉”。
解析：“衣帛”和“食肉”都由动作领着对象，所以“衣”取穿之义。

## 找原文证据：哪个短语最适合拿来检验“衣帛”的读法？ {#q.l5.3.6}
考点：s.l5.rolevoice
语境：p.l5.3.b

- [ ] 无失其时 {#q.l5.3.6.o3}
  理由：这是饲养牲畜的要求。
- [ ] 五亩之宅 {#q.l5.3.6.o2}
  理由：这是种桑的地方，不与“衣帛”句法平行。
- [x] 食肉 {#q.l5.3.6.o1}

提示：对照两处“可以”之后的词。
解析：一个是“穿＋帛”，一个是“吃＋肉”，搭配相照。

## 单选：是谁“衣帛”？ {#q.l5.3.7}
考点：s.l5.rolevoice
语境：p.l5.3.b

- [x] 五十岁的人 {#q.l5.3.7.o1}
- [ ] 七十岁的人这个短语 {#q.l5.3.7.o3}
  理由：“七十者”在下一句，直接接“食肉”。
- [ ] 种下的桑树 {#q.l5.3.7.o2}
  理由：桑树提供蚕桑生产所需，穿衣的主语另有其人。

提示：紧挨着第一个“可以”的是谁？
解析：“五十者”是第一个“可以”的主语；两句有各自的年龄条件。

## 单选：如果为“衣（yì）”补一条短例，哪种抄法最好？ {#q.l5.3.8}
考点：s.l5.rolevoice
语境：p.l5.3.b

- [ ] 五亩之宅——五亩地里种着衣服 {#q.l5.3.8.o2}
  理由：这四字里连所查的“衣”都没有。
- [x] 可以衣帛——可以穿丝织的衣服 {#q.l5.3.8.o1}
- [ ] 衣帛——衣和帛两种物产 {#q.l5.3.8.o3}
  理由：把动词并作名词，漏了“可以”领起的动作。

提示：留下一个表明后面是动作的词。
解析：连同“可以”来引，照应句中用法，旁人也能复查读音。
