# 课文：一箪食，一豆羹：用什么来盛 {#l5.3}
简介：“一豆羹”里的“豆”能盛羹。顺着箪、豆、瓢的名字，读一读古人怎样说饭食的多少。

## 正文

### 一豆羹，究竟有些什么？

查“箪”可以用繁体字头“簞”：这是竹编的盛器。“豆”除了指豆类作物，还可以指一种有高足的盛食器。把“一豆羹”和“一箪食”并排看，便能分清哪个字说食物、哪个字说用什么盛。

我们说“一碗汤”，也把器名用来计量。没有别的器制、时代依据，不必硬算一豆合今天多少升。往下读更有意思：给人这一点吃的，用什么态度给？接受的人又为什么不肯要？

查字时可直接翻到这里。[簞](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E7%B0%9E) · [豆](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E8%B1%86)

## 知识点：容器计量 {#skill.l5.3}
义项：用器名表示所盛食物的量
领域：实词
要诀：将器名和食物的名字配起来
讲解：“一箪食”是一个箪所盛的饭食。字书可以告诉你箪是怎样的器具；要换算成多少升，还须另找依据。
例句：p.l5.3.example
复习题：q.l5.3.1 q.l5.3.2 q.l5.3.5 q.l5.3.8

## 原文：教学例句 {#p.l5.3.example}
> 客持一壶酒、一筐梨，至友人家。
译文：客人带着一壶酒、一筐梨到了朋友家。壶与筐是器物，也用来说明其中有多少酒、梨。

## 原文：古籍引文 {#p.l5.3.a}
> 一箪食，一豆羹，得之则生，弗得则死。嘑尔而与之，行道之人弗受；蹴尔而与之，乞人不屑也。
译文：一箪饭、一器羹，得到便能活，得不到就要死。吆喝着给人，路人也不肯收；用脚踢给人，乞者也不屑接受。

## 单选：“豆”既可指豆类，也可指盛食器。“一豆羹”该怎样理解？ {#q.l5.3.1}
考点：skill.l5.3
语境：p.l5.3.a

- [x] 一器盛着的羹 {#q.l5.3.1.o1}
- [ ] 用一颗豆限定羹的配方 {#q.l5.3.1.o3}
  理由：原文比较食物与尊严，没有列原料。
- [ ] 一颗豆子就是一碗羹 {#q.l5.3.1.o2}
  理由：“羹”是所盛食物，与前面的“食”并列。

提示：把“一豆羹”照着它前面三个字的样子读一遍。
解析：羹是食物，“豆”是盛羹的器具。前面的一箪饭也是这样说的。

## 找原文证据：原文用哪个短语和“一豆羹”并举？ {#q.l5.3.2}
考点：skill.l5.3
语境：p.l5.3.a

- [ ] 得之则生 {#q.l5.3.2.o2}
  理由：“得之则生”说得到食物便可活命，没有再数另一种器皿。
- [x] 一箪食 {#q.l5.3.2.o1}
- [ ] 行道之人 {#q.l5.3.2.o3}
  理由：“行道之人”说的是路上走的人，找表示盛器和饭食的短语还要往前看。

提示：找一找，哪三个字也是“一件器物＋里面的食物”。
解析：“一箪食”里的箪盛饭，“一豆羹”里的豆盛羹。

## 单选：要给这里的“豆”配上一句器物说明，哪件事可以说准？ {#q.l5.3.3}
考点：skill.l5.3
语境：p.l5.3.a

- [ ] 乞者只肯接受以豆类为原料的食物 {#q.l5.3.3.o3}
  理由：“不屑”紧跟“蹴尔”，与原料无关。
- [ ] 作者规定每一豆恰有某个现代毫升数 {#q.l5.3.3.o2}
  理由：知道这是盛羹的器皿，还不知道它有多大。原文没给换算成升的尺寸。
- [x] 这里把“豆”用作盛羹的器名 {#q.l5.3.3.o1}

提示：分清“拿什么来盛”和“恰好盛多少”。
解析：从字义和句子能断定豆在这里是盛羹的器具；多少毫升，这段没有说。

## 单选：孟子写饭和羹，为什么还要写“嘑尔”“蹴尔”？ {#q.l5.3.4}
考点：skill.l5.3
语境：p.l5.3.a

- [x] 食物虽关生死，受辱的给予方式仍可能被拒 {#q.l5.3.4.o1}
- [ ] 不肯吃饭是因为容器损坏 {#q.l5.3.4.o3}
  理由：被拒的是呼喝或踢给的施舍，没有说器皿破损。
- [ ] 一箪饭比一豆羹更有价值 {#q.l5.3.4.o2}
  理由：两种食物并列，文中没有比较价格。

提示：先问人饿到什么地步，再看饭是怎样递过去的。
解析：这些饭食关系生死，可要是吆喝着给、用脚踢给对方，路人和乞者仍会拒绝。

## 原文：古籍引文 {#p.l5.3.b}
> 子曰：“贤哉回也！一箪食，一瓢饮，在陋巷，人不堪其忧，回也不改其乐。贤哉回也！”

## 单选：读过“一箪食”，再遇到“一瓢饮”，怎样给“瓢”作注？ {#q.l5.3.5}
考点：skill.l5.3
语境：p.l5.3.b

- [ ] “瓢”是水面的漂动，写饮料在流动 {#q.l5.3.5.o2}
  理由：前句有一箪饭，后句相应也得读成一件装饮料的器具。
- [x] “瓢”是取饮料的器具，借指一瓢所盛 {#q.l5.3.5.o1}
- [ ] “瓢”就是陋巷的地名 {#q.l5.3.5.o3}
  理由：地点另由“在陋巷”说明。

提示：找出箪和瓢各用来盛什么。
解析：箪里是吃的，瓢里是喝的。颜回的日常所需就这样简朴。

## 找原文证据：住陋巷、吃喝都简单。哪一句说出了颜回对这种生活的态度？ {#q.l5.3.6}
考点：skill.l5.3
语境：p.l5.3.b

- [ ] 在陋巷 {#q.l5.3.6.o3}
  理由：这只是住所，尚未写颜回心境。
- [ ] 一瓢饮 {#q.l5.3.6.o2}
  理由：“一瓢饮”只说颜回喝的是什么，留意后来哪个字才说他的心情。
- [x] 回也不改其乐 {#q.l5.3.6.o1}

提示：读过常人的“忧”，看看写回颜回时用了哪个字。
解析：“回也不改其乐”才点出颜回的心境。前面的箪、瓢、陋巷都在写他怎样过日子。

## 单选：感到“忧”的是哪些人？“乐”的又是谁？ {#q.l5.3.7}
考点：skill.l5.3
语境：p.l5.3.b

- [x] 别人受不了这种忧苦，颜回却仍然快乐 {#q.l5.3.7.o1}
- [ ] 孔子因看见瓢而忧，颜回因买到瓢而乐 {#q.l5.3.7.o3}
  理由：文中既没写买卖，也没说孔子忧。
- [ ] 颜回先忧后乐，别人未出场 {#q.l5.3.7.o2}
  理由：先说“人不堪”，后说“回也不改”，忧与乐分别落在两种人身上。

提示：两句的开头，一个是“人”，一个是“回”。
解析：一般人难堪其忧，颜回却不改其乐。处境相同，两边的感受并不一样。

## 单选：从“一豆羹”“一瓢饮”这两例，可以学到怎样读新的食器名？ {#q.l5.3.8}
考点：skill.l5.3
语境：p.l5.3.b

- [ ] 凡“箪”“瓢”“豆”所在句都可删掉器名 {#q.l5.3.8.o2}
  理由：若把箪和瓢都删掉，只剩“食”“饮”，就看不见这一箪、一瓢的日子了。
- [x] 看到数词、器名与食饮相连，先试作一器之量 {#q.l5.3.8.o1}
- [ ] 只要古书写穷人，“豆”就一定是盛器 {#q.l5.3.8.o3}
  理由：人物贫富无法决定字义，还须核对所接词语。

提示：换了器物名，两类短语里还留着哪些相同的位置？
解析：看到数词、器名和食物相接，不妨先读成一器所盛的分量。至于为何写它，要看各篇的人和事。
