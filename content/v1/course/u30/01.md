# 课文：临水以后，队伍渡了吗 {#h30.1}
简介：看到地名，别忙着画下一段行程。“次”“临”“涉”“济”写的是不同的步子。

## 正文

“次于孤竹”里，孤竹是停军的地方。等再读到出发的动词，才把队伍从那里移开。若只是“临水”，人走到了水边、面对水面，却还没有到彼岸。

“涉”在写徒步过溪时，人脚下就是水；“济”着重已经渡过，未必交代用不用船。古书说人“病涉”，是为蹚水过河而苦，并不是说人人过河都生了病。

## 知识点：次 {#skill.h30.1.ci-encamp}
义项：行进的队伍停驻、驻扎
领域：实词
要诀：行军或出使途中“次于”某处，注意何时驻下、何时再走。
讲解：“齐桓公伐山戎，次于孤竹。”征讨是整个行程，孤竹是军队途中停驻的地方。“次”在这里是一个动作。
例句：p.h30.1.1

## 单选：齐军出兵，“次于孤竹”说孤竹是什么地方？ {#q.h30.1.1}
考点：skill.h30.1.ci-encamp
语境：p.h30.1.1

- [ ] 齐桓公出兵前常住的都城 {#q.h30.1.1.o1}
  理由：“伐山戎”已交代这是出征的情境。
- [ ] 排在山戎后面的第二个对象 {#q.h30.1.1.o2}
  理由：“次于”在行军句中指出驻扎地点，没有列名次。
- [x] 齐军在出征途中驻扎的地点 {#q.h30.1.1.o3}

提示：“伐”给出行动背景，“于”后接什么？
解析：“伐山戎”交代出征，“次于孤竹”记行军途中停在哪里。

## 原文：教学例句 {#p.h30.1.2}
> 使者与从者次于桥北，张幕候水落。越二日，收幕复行。
译文：使者和随员在桥北驻下，撑起帐幕等水退。过了两天，收起帐幕继续赶路。
词注：次：行军停驻。

## 找原文证据：哪几个字说明使者一行没在桥北长住？ {#q.h30.1.2}
考点：skill.h30.1.ci-encamp
语境：p.h30.1.2

- [ ] 使者与从者 {#q.h30.1.2.o1}
  理由：这告诉你谁停在桥北。等了两天以后，他们留在那里了吗？
- [x] 收幕复行 {#q.h30.1.2.o2}
- [ ] 桥北 {#q.h30.1.2.o3}
  理由：这是停驻的位置，单凭地名看不出驻留长短。

提示：在驻扎动作之后，找结束驻扎的动作。
解析：他们张起帐幕等水退，两天以后收起帐幕继续赶路。桥北是临时驻地。

## 知识点：临 {#skill.h30.1.lin-face}
义项：靠近并面对
领域：实词
要诀：临井、临渊，人站在边上便能往下看。
讲解：“战战兢兢”连用两个比喻：站在深渊边，踏在薄冰上。“临”写身处深渊边缘，这样才说得通为什么要如此小心。
例句：p.h30.1.3

## 单选：“如临深渊”让人设想自己身处何处？ {#q.h30.1.3}
考点：skill.h30.1.lin-face
语境：p.h30.1.3

- [ ] 已跌入深渊，正在水底 {#q.h30.1.3.o1}
  理由：“临”交代面对险处，没有写失足跌入。
- [x] 来到深渊边，正面对险处 {#q.h30.1.3.o2}
- [ ] 已经渡过深渊，回看身后的路 {#q.h30.1.3.o3}
  理由：句中没有穿过和回望的动作。

提示：留意“临”的人还在岸上，这个比喻为什么让人“战战兢兢”？
解析：人来到深渊边，向下便是险处。站在那里小心翼翼，正能解释“战战兢兢”。

## 原文：教学例句 {#p.h30.1.4}
> 井在庭中，童临井俯视，见月影，呼其姊共观。
译文：院子中有口井，孩子来到井边俯身观看，见到月影，喊姐姐一起来看。

## 找原文证据：孩子站在井边，是从哪个动作看出来的？ {#q.h30.1.4}
考点：skill.h30.1.lin-face
语境：p.h30.1.4

- [ ] 共观 {#q.h30.1.4.o1}
  理由：这说邀人一同看，未指明视线方向。
- [x] 俯视 {#q.h30.1.4.o2}
- [ ] 呼其姊 {#q.h30.1.4.o3}
  理由：喊姐姐不能说明孩子面对井口的姿势。

提示：找视线由上向下的动作。
解析：“俯视”是低头看。孩子临井俯视，才看见水里的月影。

## 原文：教学例句 {#p.h30.1.5}
> 溪浅无梁，客脱履涉之，至彼岸，乃复著履。
译文：溪水浅，没有桥，旅人脱下鞋涉水过去，到对岸才又穿上鞋。
词注：涉：步行过水。

## 知识点：涉 {#skill.h30.1.she-wade}
义项：徒步过水，蹚水而过
领域：实词
要诀：留意过河时是否脱鞋、提衣，到了对岸又怎样。
讲解：旅客在这边岸上脱鞋，到“彼岸”才重新穿上。中间的“涉之”，便是踏过浅溪的那段路。
例句：p.h30.1.5

## 单选：客人用什么办法到达彼岸？ {#q.h30.1.5}
考点：skill.h30.1.she-wade
语境：p.h30.1.5

- [ ] 找到桥，从桥上过去 {#q.h30.1.5.o1}
  理由：开头的“无梁”排除了过桥。
- [x] 脱鞋踏水渡过浅溪 {#q.h30.1.5.o2}
- [ ] 沿溪边步行，始终没有过水 {#q.h30.1.5.o3}
  理由：“至彼岸”说明已经换到另一边。

提示：先看溪上有没有桥，再看客人何时脱鞋、何时穿鞋。
解析：没有桥，客人脱鞋下水，踏过浅溪，到了对岸才把鞋穿上。

## 原文：古籍引文 {#p.h30.1.6}
> 岁十一月，徒杠成；十二月，舆梁成，民未病涉也。
译文：每年十一月，行人过的桥修成；十二月，车辆过的桥修成，百姓就不再因徒步渡水而受苦。

  杠：供行人过水的小桥。

## 单选：人行桥和车桥相继修好，百姓以前怎样过河的苦处免掉了？ {#q.h30.1.6}
考点：skill.h30.1.she-wade
语境：p.h30.1.6

- [ ] 每月都必须修理车轮 {#q.h30.1.6.o1}
  理由：“舆梁”指可供车辆通行的桥。
- [ ] 站在岸边看不见过路的人 {#q.h30.1.6.o2}
  理由：“杠”“梁”都是过水设施，与视线无关。
- [x] 不得不下水徒步过河 {#q.h30.1.6.o3}

提示：把“病涉”的“涉”当成桥建成前的过水方式。
解析：先架起行人可走的小桥，后建成车辆也能过的桥。百姓不必再下水蹚河。

## 原文：教学例句 {#p.h30.1.7}
> 日暮众济河，灯在彼岸。
译文：天晚了，众人渡河，灯火在那一岸。

## 知识点：济 {#skill.h30.1.ji-cross}
义项：渡过水域
领域：实词
要诀：遇到水，试读为“渡过去”；若带人，可指送人过水。
讲解：“日暮众济河”，河横在眼前，灯火却在彼岸。这群人傍晚要渡水到对岸。
例句：p.h30.1.7

## 原文：教学例句 {#p.h30.1.8}
> 山水暴涨，人不能济溪，留宿此岸。
译文：山里溪水暴涨，人们过不去，只好在这边岸上过夜。

## 单选：人们留宿此岸，因为溪水暴涨，不能“济”。什么事没做成？ {#q.h30.1.7}
考点：skill.h30.1.ji-cross
语境：p.h30.1.8

- [ ] 接济 {#q.h30.1.7.o1}
  理由：“济溪”接的是阻路的溪水，没有人在求救济。
- [x] 渡过水域 {#q.h30.1.7.o2}
- [ ] 成功完成 {#q.h30.1.7.o3}
  理由：结尾说留在此岸，写的正是没能过溪。

提示：他们想到哪一岸去，最后又留在哪里？
解析：水大过不了溪，人们只好留在这一岸。“济”就是渡过。

## 原文：教学例句 {#p.h30.1.9}
> 津吏待风息，乃济客于东岸。
译文：渡口的吏员等风停了，才送旅客过河到东岸。

## 单选：风停以后，旅客到了哪里？ {#q.h30.1.8}
考点：skill.h30.1.ji-cross
语境：p.h30.1.9

- [ ] 得到盘缠仍留原地 {#q.h30.1.8.o1}
  理由：“于东岸”给出去处。
- [ ] 沿岸只往北走 {#q.h30.1.8.o2}
  理由：津吏在渡口送客过水。
- [x] 被送过水，到达东岸 {#q.h30.1.8.o3}

提示：“济客”的人是渡口的吏员，东岸是目的地。
解析：渡口的吏员等风停了才送客人过水，旅客由此到了东岸。
