# 课文：或与莫：有人、无人和不要 {#syntax.5}
简介：先问是谁做动作，再分清句中未点名的人、所说人群的范围和听者要遵守的禁令。

## 正文

“或告之”可以有一个未点名的主语，即“有人告诉他”。这与“明日或雨”的不确定、“舟或车”的选择不同。回答“是谁做动作”时，若下文已有回应和后果，要保留那件事确实发生过。

“众莫应”把范围定为在场众人，意思是无人作答。“汝莫应”若是直接对听者的告诫，则可读为“你不要答”。两者的区别会改变故事：前者交代已经出现的场面，后者规定应当怎样做，并未保证听者照办。

## 知识点：或（有人、有的） {#l2.skill.huo-some}
义项：指一个未点名的人，或从一群人中分出一部分
领域：虚词
要诀：指一个未点名的人，或从一群人中分出一部分
讲解：先问谁做了随后那个动作。“或……或……”若在叙述实际群体，可分别读“有的人……有的人……”。
例句：l2.ex.huo-some

## 原文：教学例句 {#l2.ex.huo-some}
> 市中或呼其名，客回首。
译文：市上有人叫他的名字，客人回了头。

## 知识点：莫（没有谁） {#l2.skill.mo-none}
义项：表示一定范围内无人做某事
领域：虚词
要诀：表示一定范围内无人做某事
讲解：找出前面引出的相关人群，避免无根据地扩大为所有人或所有时段。
例句：l2.ex.mo-none

## 原文：教学例句 {#l2.ex.mo-none}
> 坐客莫识此字。
译文：在座的客人没有谁认得这个字。

## 知识点：莫（禁止） {#l2.skill.mo-prohibit}
义项：面对听话人劝止或禁止某个动作
领域：虚词
要诀：面对听话人劝止或禁止某个动作
讲解：找直接引语、听话人和说话人的意图，再分清下句是遵命还是违背。
例句：l2.ex.mo-prohibit

## 原文：教学例句 {#l2.ex.mo-prohibit}
> 父戒儿曰：“莫近井。”
译文：父亲叮嘱孩子：“不要靠近井。”

## 原文：古籍引文 {#syntax.5.p.govern}
> 或谓孔子曰：“子奚不为政？”
译文：有人对孔子说：“您为什么不参与政事呢？”

## 单选：能从“或谓孔子曰”确定什么？ {#syntax.5.q1}
考点：l2.skill.huo-some
语境：syntax.5.p.govern

- [ ] 也许问过，也许没问过
  理由：下文已经记下那人所问的话。
- [x] 有人确实向孔子发问，但没写姓名
- [ ] 孔子正问自己为何不为政
  理由：“谓孔子”中的孔子是被问的人。

提示：用“谁向孔子开口”来提问。
解析：“或”在“谓”前充当发问者，原文保留了他的话却未署名。

## 原文：教学例句 {#syntax.5.p.shade}
> 行者憩于道旁，或卧树下，或汲泉。童问前路，众莫知。
译文：过路人在路旁休息，有人躺在树下，有人打泉水。孩子询问前路，这些人没有谁知道。

## 单选：两处“或”如何分配前面的“行者”？ {#syntax.5.q2}
考点：l2.skill.huo-some
语境：syntax.5.p.shade

- [x] 有的人躺着，有的人打水
- [ ] 命令每人必须先躺下再打水
  理由：没有规定行动次序，只交代不同人正在做什么。
- [ ] 作者拿不准大家是否存在
  理由：已明说一群行者在休息。

提示：把两个“或”后实际发生的动作并排看。
解析：“或……或……”在此从行者中分述两种活动。

## 单选：“众莫知”可以断定多大的范围？ {#syntax.5.q3}
考点：l2.skill.mo-none
语境：syntax.5.p.shade

- [x] 眼前被问的这群人都不知道前路
- [ ] 只是不许他们告诉孩子
  理由：当时写的是询问所得的结果。
- [ ] 这条路世上无人知道
  理由：范围由“众”限于在场者。

提示：先找“众”承接哪群人。
解析：“莫”给出无人知晓的结果，范围不可跨出这次问路。

## 原文：教学例句 {#syntax.5.p.fire}
> 吏戒众曰：“仓中多薪，莫持火入。”夜有一人持炬而入，吏止之。
译文：官吏告诫众人：“仓中柴多，不要持火进去。”夜间有个人举火把进入，官吏阻止了他。

## 单选：哪一项与官吏说的“莫持火入”相合？ {#syntax.5.q4}
考点：l2.skill.mo-prohibit
语境：syntax.5.p.fire

- [ ] 这是汇报无人举火进过仓
  理由：“戒众曰”引出告诫，随后还出现了违者。
- [x] 这是禁令，后来有人没有遵守
- [ ] 这是怀疑夜里有无火把
  理由：官吏明确要求不要带火进去。

提示：想想后来出现的一个人能不能违反一条禁令。
解析：禁令表达应如何行事，并不自动成为事后事实。

## 找原文证据：哪段直接写出与禁令相违的行动？ {#syntax.5.q5}
考点：l2.skill.mo-prohibit
语境：syntax.5.p.fire

- [ ] 仓中多薪
  理由：这是颁令的原因。
- [x] 持炬而入
- [ ] 吏止之
  理由：这是官吏应对违令的行动。

提示：找那位夜行者带着什么、做了什么。
解析：原先禁止持火入仓，此人却带着火炬进入。

## 原文：教学例句 {#syntax.5.p.inscription}
> 郡人观碑，莫能读其末字。或以纸拓之，持归问师。
译文：郡里人在看碑，没有谁能读出最后一个字。有个人用纸拓下，带回去请教老师。

## 单选：“莫能读”是否已说明老师也不认识这个字？ {#syntax.5.q6}
考点：l2.skill.mo-none
语境：syntax.5.p.inscription

- [ ] 老师既然是本郡人就一定不会
  理由：文中没有把老师列在当时看碑的人之中。
- [x] 只能说当时看碑的人读不出来
- [ ] “莫”是命令老师不要念
  理由：这里是旁述众人遇到的困难。

提示：比较现场看碑与回去问师两个场景。
解析：“莫”所概括的是现场郡人，不足以推断未出场者。

## 单选：什么行动提示“或”在这里指实际的一人？ {#syntax.5.q7}
考点：l2.skill.huo-some
语境：syntax.5.p.inscription

- [ ] 作者在两种字形间猜测
  理由：没人提出两种可能字形。
- [x] 拓下文字并带走问师
- [ ] 众人都各自拓下一份
  理由：“莫能读”说读字，并不说人人拓碑。

提示：看“或”后有没有连续行动。
解析：在场者中有人做了“拓、持归、问师”这些事，姓名未给出。

## 原文：教学例句 {#syntax.5.p.repair}
> 父见桥坏，戒二子曰：“莫渡。”二子还。其日里人亦莫渡。
译文：父亲看见桥坏了，叮嘱两个儿子：“不要过桥。”两个儿子回来了。这一天村人也没有谁渡桥。

## 单选：把父亲的话同末句比较，哪项保留了差别？ {#syntax.5.q8}
考点：l2.skill.mo-prohibit
语境：syntax.5.p.repair

- [ ] 先是说两个儿子已经过桥
  理由：他们听到告诫后回来了。
- [ ] 两处都在命令村人
  理由：第一次听话的是两个儿子，末句是叙事。
- [x] 先是叫儿子别过桥，后是记村人无人过桥

提示：分别找出谁在说话、谁在记事。
解析：第一处“莫”禁行；第二处“莫”概括村人的实际行为。
