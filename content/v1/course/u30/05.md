# 课文：“或”是有人，“莫”是没人还是别做 {#syntax.5}
简介：“众莫应”写无人应声，“汝莫应”是叫人别出声。听清谁在说、对谁说，就能读出差别。

## 正文

“或告之”，有人把消息告诉他了，只是没写这个人叫什么。若下文还记了对方的答话，就更不能把这件事读成也许发生过。“明日或雨”才是说也许；“舟或车”则是从两样东西里选一样。

“莫”也要放回整句话。“众莫应”，问的是当时有谁应声，答案是一个也没有。“汝莫应”，若是当面对人叮嘱，就该读成“你别答话”。有没有人真的遵守这声嘱咐，还要往下看。

## 知识点：或（有人、有的） {#l2.skill.huo-some}
义项：有人、有的人，指没说出姓名的人或一群人中的一部分
领域：虚词
要诀：问“谁做了这件事”，看人有没有点名。
讲解：市上有人叫，客人回头，呼喊确实发生了，只是姓名不详。写到一群人“或……或……”，还可以指其中有些人这样做，另一些人那样做。
例句：l2.ex.huo-some

## 原文：教学例句 {#l2.ex.huo-some}
> 市中或呼其名，客回首。
译文：市上有人叫他的名字，客人回了头。

## 知识点：莫（没有谁） {#l2.skill.mo-none}
义项：没有谁，所说的这群人里一个也没有
领域：虚词
要诀：先找出原文说的是哪一群人。
讲解：“坐客莫识此字”只说在座的客人一个也不认得。未在座的人认不认得，还不知道。
例句：l2.ex.mo-none

## 原文：教学例句 {#l2.ex.mo-none}
> 坐客莫识此字。
译文：在座的客人没有谁认得这个字。

## 知识点：莫（禁止） {#l2.skill.mo-prohibit}
义项：不要、别，劝阻或禁止对方做某事
领域：虚词
要诀：这句话是告诉人过去怎样，还是叮嘱人接下来别做什么？
讲解：父亲对孩子说“莫近井”，是要孩子别靠近井口。听完究竟靠近了没有，要读后面的行动。
例句：l2.ex.mo-prohibit

## 原文：教学例句 {#l2.ex.mo-prohibit}
> 父戒儿曰：“莫近井。”
译文：父亲叮嘱孩子：“不要靠近井。”

译文：有人对孔子说：“您为什么不参与政事呢？”

## 单选：能从“或谓孔子曰”确定什么？ {#syntax.5.q1}
考点：l2.skill.huo-some
语境：syntax.5.p.govern

- [ ] 也许问过，也许没问过
  理由：下文已经记下那人所问的话。
- [x] 有人确实向孔子发问，但没写姓名
- [ ] 孔子正问自己为何不为政
  理由：“谓孔子”中的孔子是被问的人。

提示：用“谁向孔子开口”来提问。
解析：“谓孔子曰”后面连原话都有。可知确有人问孔子，只是没有交代这个人的姓名。

## 原文：教学例句 {#syntax.5.p.shade}
> 行者憩于道旁，或卧树下，或汲泉。童问前路，众莫知。
译文：过路人在路旁休息，有人躺在树下，有人打泉水。孩子询问前路，这些人没有谁知道。

## 单选：两个“或”写歇脚的行人分别在做什么？ {#syntax.5.q2}
考点：l2.skill.huo-some
语境：syntax.5.p.shade

- [x] 有的人躺着，有的人打水
- [ ] 命令每人必须先躺下再打水
  理由：没有规定行动次序，只交代不同人正在做什么。
- [ ] 作者拿不准大家是否存在
  理由：已明说一群行者在休息。

提示：把两个“或”后实际发生的动作并排看。
解析：过路人都在歇脚，有人躺在树下，有人去打水。两个“或”各指其中一些人。

## 单选：“众莫知”说哪些人不知道前路？ {#syntax.5.q3}
考点：l2.skill.mo-none
语境：syntax.5.p.shade

- [x] 眼前被问的这群人都不知道前路
- [ ] 只是不许他们告诉孩子
  理由：当时写的是询问所得的结果。
- [ ] 这条路世上无人知道
  理由：范围由“众”限于在场者。

提示：先找“众”承接哪群人。
解析：“众”接的是路边这群行旅。孩子问了，他们都不知道，这段话说到这里为止。

## 原文：教学例句 {#syntax.5.p.fire}
> 吏戒众曰：“仓中多薪，莫持火入。”夜有一人持炬而入，吏止之。
译文：官吏告诫众人：“仓中柴多，不要持火进去。”夜间有个人举火把进入，官吏阻止了他。

## 单选：哪一项与官吏说的“莫持火入”相合？ {#syntax.5.q4}
考点：l2.skill.mo-prohibit
语境：syntax.5.p.fire

- [ ] 这是汇报无人举火进过仓
  理由：“戒众曰”引出告诫，随后还出现了违者。
- [x] 这是禁令，后来有人没有遵守
- [ ] 这是怀疑夜里有无火把
  理由：官吏明确要求不要带火进去。

提示：“戒众曰”发生在先，举火把的人是在这之前还是之后进仓的？
解析：先有“戒众曰”，才有“莫持火入”，这是告诫。后来偏有一人举着火把入仓，可见下了禁令仍有人不听。

## 找原文证据：哪段直接写出与禁令相违的行动？ {#syntax.5.q5}
考点：l2.skill.mo-prohibit
语境：syntax.5.p.fire

- [ ] 仓中多薪
  理由：仓里柴多，说明为什么不能带火。违令的人做了什么，是在夜里写的。
- [x] 持炬而入
- [ ] 吏止之
  理由：“止之”是官吏拦住带火的人。违令的是谁，要看他拦人之前的动作。

提示：找那位夜行者带着什么、做了什么。
解析：有柴怕火，官吏刚禁止带火入仓，夜里这人却“持炬而入”。“炬”就是火把。

## 原文：教学例句 {#syntax.5.p.inscription}
> 郡人观碑，莫能读其末字。或以纸拓之，持归问师。
译文：郡里人在看碑，没有谁能读出最后一个字。有个人用纸拓下，带回去请教老师。

## 单选：“莫能读”是否已说明老师也不认识这个字？ {#syntax.5.q6}
考点：l2.skill.mo-none
语境：syntax.5.p.inscription

- [ ] 老师既然是本郡人就一定不会
  理由：文中没有把老师列在当时看碑的人之中。
- [x] 只能说当时看碑的人读不出来
- [ ] “莫”是命令老师不要念
  理由：这里写看碑的人都认不出字，老师还没出场。

提示：比较现场看碑与回去问师两个场景。
解析：“莫能读”只管眼前观碑的人。后来才有人带着拓下的字去问老师，老师能不能认出来，文中还没说。

## 单选：哪件事说明这里的“或”指看碑人中的一位？ {#syntax.5.q7}
考点：l2.skill.huo-some
语境：syntax.5.p.inscription

- [ ] 作者在两种字形间猜测
  理由：没人提出两种可能字形。
- [x] 拓下文字并带走问师
- [ ] 众人都各自拓下一份
  理由：“莫能读”说读字，并不说人人拓碑。

提示：看“或”后有没有连续行动。
解析：有人取纸、拓字、携归问师。这些事都发生了，“或”正指那个虽没写姓名、却做了这一串事的人。

## 原文：教学例句 {#syntax.5.p.repair}
> 父见桥坏，戒二子曰：“莫渡。”二子还。其日里人亦莫渡。
译文：父亲看见桥坏了，叮嘱两个儿子：“不要过桥。”两个儿子回来了。这一天村人也没有谁渡桥。

## 单选：把父亲的话同末句比较，哪项保留了差别？ {#syntax.5.q8}
考点：l2.skill.mo-prohibit
语境：syntax.5.p.repair

- [ ] 先是说两个儿子已经过桥
  理由：他们听到告诫后回来了。
- [ ] 两处都在命令村人
  理由：第一次听话的是两个儿子，末句是叙事。
- [x] 先是叫儿子别过桥，后是记村人无人过桥

提示：分别找出谁在说话、谁在记事。
解析：父亲对两个儿子亲口说“莫渡”，是在劝止。后来叙述者说“里人亦莫渡”，才是在记这一天村里没人过桥。
