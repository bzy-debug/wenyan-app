# 课文：军报说的是出征，还是已经攻下 {#h30.3}
简介：把出兵、渡河、攻克和出逃各落在它所说的人与地点上。

## 正文

“伐某国”先交代兵锋所向。“伐而不克”便是已经出师，却还没有取胜，不能把一个“伐”就写成捷报。“克”还要看后面接的是什么，此课读攻克城邑的一义。

有人“亡入魏”，失去的不是一个叫魏的东西，人也没有死，他逃到了魏地。遇到军队“绝江”，可先找彼岸的行动：若大队已经到了对岸，“绝”便是横渡；单说交通断绝则没有这个动作。

## 原文：教学例句 {#p.h30.3.1}
> 史书某国伐邻，未记胜负。
译文：史书记某国讨伐邻国，未记载胜负。
词注：伐：发兵征讨。

## 知识点：伐 {#skill.h30.3.fa-campaign}
义项：出兵征讨
领域：实词
要诀：“伐”说出兵征讨，战果还须往后读。
讲解：“某国伐邻”只说这个国家征讨邻国。“未记胜负”提醒我们，此处无从判定究竟谁赢了。
例句：p.h30.3.1

## 原文：教学例句 {#p.h30.3.2}
> 春，诸侯伐叛国，秋乃议和。
译文：春日，诸侯出兵征讨叛国，秋天才商议讲和。
词注：伐：发兵征讨。

## 单选：诸侯春天“伐叛国”，这是什么行动？ {#q.h30.3.1}
考点：skill.h30.3.fa-campaign
语境：p.h30.3.2

- [ ] 夸耀 {#q.h30.3.1.o1}
  理由：讲和之前两方处于征战中。
- [ ] 砍伐 {#q.h30.3.1.o2}
  理由：所伐对象是叛国。
- [x] 出兵征讨 {#q.h30.3.1.o3}

提示：到秋天双方才议和，春天先发生了什么？
解析：诸侯出兵征讨叛国。“秋乃议和”说的是征讨以后的事。

## 原文：教学例句 {#p.h30.3.3}
> 书称东国伐西国，末言未克而还。
译文：记载说东国出兵征讨西国，末了说没能攻克便回去。
词注：伐：发兵征讨。
  克：攻取、攻下。

## 单选：只读到“东国伐西国”，能知道什么？ {#q.h30.3.2}
考点：skill.h30.3.fa-campaign
语境：p.h30.3.3

- [ ] 西国已经投降 {#q.h30.3.2.o1}
  理由：末句说明东国未克。
- [x] 东国对西国发动征讨 {#q.h30.3.2.o2}
- [ ] 必是东国获胜 {#q.h30.3.2.o3}
  理由：“伐”只交代行动。

提示：别把末尾的“未克”提前读进“伐”里。
解析：“伐”告诉你已经出兵。后面明写“未克”，这次进攻没有打下来。

## 原文：教学例句 {#p.h30.3.4}
> 围邑久而未克，师乃还。
译文：围城很久没能攻克，军队才回去。
词注：克：攻取、攻下。

## 知识点：克 {#skill.h30.3.ke-capture}
义项：攻克
领域：实词
要诀：已经围城，与已经占了城，有什么分别？
讲解：“围邑久而未克”，城围了很久，却一直没攻下。读到军队后来撤走，更能看出“未克”的分量。
例句：p.h30.3.4

## 原文：教学例句 {#p.h30.3.5}
> 史记是岁克二邑，二邑遂入其版图。
译文：史书记载这一年攻克两座城邑，两邑于是并入其版图。
词注：克：攻取、攻下。

## 单选：为什么那两座城邑后来划进了己方版图？“克”是什么意思？ {#q.h30.3.3}
考点：skill.h30.3.ke-capture
语境：p.h30.3.5

- [ ] 能够 {#q.h30.3.3.o1}
  理由：“克二邑”后又说两邑并入版图，写的是已经实现的战果。
- [x] 攻克 {#q.h30.3.3.o2}
- [ ] 约束自己 {#q.h30.3.3.o3}
  理由：“二邑”是两座城邑，是攻打的目标。

提示：读“二邑遂入其版图”，原来是谁控制的地方？
解析：城邑已经攻下，所以领地随之改变。“克”交代的是攻打的结果。

## 原文：教学例句 {#p.h30.3.6}
> 书言克其城，后载城门易守，县印归于新主。
译文：记载说攻下那座城，随后写城门换了守者，县印归于新主人。
词注：克：攻取、攻下。

## 找原文证据：从哪一处可以看出，城池已经换了主人？ {#q.h30.3.4}
考点：skill.h30.3.ke-capture
语境：p.h30.3.6

- [ ] 书言 {#q.h30.3.4.o1}
  理由：“书言”只说有文书记载，未说城归了谁。
- [ ] 其城 {#q.h30.3.4.o2}
  理由：“其城”只点出被围攻的城池，还看不出已经易手。
- [x] 县印归于新主 {#q.h30.3.4.o3}

提示：找县里的官印最后交到了谁手中。
解析：县印落到新主人手里，说明这座城已被攻下，换了管辖的人。

## 原文：教学例句 {#p.h30.3.7}
> 囚夜亡，吏晨视空室。
译文：囚犯夜里逃跑，官吏早晨看见空屋。
词注：亡：逃走。

## 知识点：亡 {#skill.h30.3.wang-flee}
义项：逃跑
领域：实词
要诀：若一个人离了原处，后来还可追、还可归，“亡”可指逃跑。
讲解：“囚夜亡”，到早晨官吏打开牢房，只见一间空屋。囚犯是趁夜逃走了。
例句：p.h30.3.7

## 原文：古籍引文 {#p.h30.3.8}
> 赵悼襄王元年，廉颇既亡入魏，赵使李牧攻燕，拔武遂、方城。
译文：赵悼襄王元年，廉颇已经出逃到了魏国。赵派李牧攻燕，攻取武遂、方城。
词注：既：已经。
  拔：攻取城邑。

## 单选：说“廉颇既亡入魏”，能为廉颇记下哪一项去向？ {#q.h30.3.5}
考点：skill.h30.3.wang-flee
语境：p.h30.3.8

- [ ] 战死在魏国 {#q.h30.3.5.o1}
  理由：“入魏”接的是出逃的去处。
- [x] 从赵出逃，到了魏国 {#q.h30.3.5.o2}
  理由：“亡”写出逃，“入魏”再交代逃去哪里。随后出征攻燕的是李牧。
- [ ] 李牧攻燕之后才从魏归赵 {#q.h30.3.5.o3}
  理由：“既”交代已经发生的事，也没有说他归赵。

提示：想想“入魏”能接在哪一种“亡”后面。
解析：“亡”写出逃，“入魏”再交代逃去哪里。随后出征攻燕的是李牧。

## 原文：教学例句 {#p.h30.3.9}
> 役者亡，家人求之，三日后见于邻里。
译文：服役的人逃走，家人寻找他，三天后在邻近村落见到了他。
词注：亡：逃走。

## 单选：家人三天后还能见到他。先前说役者“亡”，是说他怎样了？ {#q.h30.3.6}
考点：skill.h30.3.wang-flee
语境：p.h30.3.9

- [ ] 已经死亡 {#q.h30.3.6.o1}
  理由：人还能被家人找到。
- [x] 离开原处，人在别处 {#q.h30.3.6.o2}
- [ ] 丢了一件器物 {#q.h30.3.6.o3}
  理由：被寻找、被看见的都是役者。

提示：三天后家人在什么地方见到了他？
解析：服役的人离开了原处。三天后，家人又在邻里见到他。这个“亡”写他逃走了。

## 原文：教学例句 {#p.h30.3.10}
> 绝江而南，遂宿南岸。
译文：横渡大江往南，就住在南岸。
词注：绝江：横渡大江。

## 知识点：绝 {#skill.h30.3.jue-cross}
义项：横渡
领域：实词
要诀：认清渡水前后，人分别在哪一岸。
讲解：“绝江而南”，随后就宿在南岸。横过江面，才到了后来过夜的地方。
例句：p.h30.3.10

## 原文：教学例句 {#p.h30.3.11}
> 客发西岸，绝水至东岸。
译文：客人从西岸出发，横渡水面到达东岸。

## 单选：客人从西岸动身，后来到了东岸，“绝水”是怎样走的？ {#q.h30.3.7}
考点：skill.h30.3.jue-cross
语境：p.h30.3.11

- [ ] 灭绝 {#q.h30.3.7.o1}
  理由：客人还活着，已经从西岸来到东岸。
- [ ] 断流 {#q.h30.3.7.o2}
  理由：原文写的是客人过水，没说河水中断。
- [x] 横渡 {#q.h30.3.7.o3}

提示：西岸和东岸之间隔着什么？
解析：由西岸到东岸，须横过水面，这里的“绝”是横渡。

## 原文：教学例句 {#p.h30.3.12}
> 前路临江，舟人载客绝之，泊对岸。
译文：路通到江边，船夫载着客人渡江，靠在对岸。

## 单选：“舟人载客绝之”里的“之”指什么？ {#q.h30.3.8}
考点：skill.h30.3.jue-cross
语境：p.h30.3.12

- [ ] 被拒绝的客人 {#q.h30.3.8.o1}
  理由：船夫正载着客人。
- [ ] 停船的码头 {#q.h30.3.8.o2}
  理由：“之”先承接前文的江。
- [x] 横渡的江水 {#q.h30.3.8.o3}

提示：前面写“临江”，后来又停在对岸。
解析：舟人载客横过眼前这条江，“之”指江水。
