# 检查：读一段行军记事综合检查 {#check.30}

## 原文：教学例句 {#p.h30.check.1}
> 师东行，夕次泽旁。明日临水，深不可涉，乃乘舟济。
译文：军队向东进发，傍晚驻在水泽旁。次日到水边，水深不能蹚过，于是乘船渡河。
词注：次：行军停驻。
  涉：步行过水。

## 单选：看到“夕次泽旁”时，能把军队的位置记在哪里？ {#q.h30.check.1}
考点：skill.h30.1.ci-encamp
语境：p.h30.check.1

- [ ] 刚好排在第二支队伍后面 {#q.h30.check.1.o1}
  理由：这里“次”带地点，没有排次序。
- [ ] 已经乘舟抵达彼岸 {#q.h30.check.1.o2}
  理由：过河是第二天的事。
- [x] 傍晚停驻在泽旁 {#q.h30.check.1.o3}
  理由：行军途中的“次”写驻扎。第二天才接着临水、乘船。

提示：找日落和次日之间停在何处。
解析：行军途中的“次”写驻扎。第二天才接着临水、乘船。

## 原文：教学例句 {#p.h30.check.2}
> 里人问渡于渔者。渔者曰：“吾居西岸，知石梁昨圮。上流有浅滩，可褰裳涉也。”
译文：乡人向渔人打听过水的办法。渔人说：我住在西岸，知道石桥昨天塌了。上游有浅滩，可以提起衣裳蹚过去。
词注：涉：步行过水。

## 找原文证据：哪句话写出了渔人建议的过水办法？选出原文。 {#q.h30.check.2}
考点：skill.h30.1.she-wade
语境：p.h30.check.2

- [ ] 上流有浅滩 {#q.h30.check.2.o1}
  理由：浅滩交代可涉的位置，尚未写人的动作。
- [ ] 石梁昨圮 {#q.h30.check.2.o2}
  理由：这说明原来过桥的路线失效。
- [x] 可褰裳涉也 {#q.h30.check.2.o3}

提示：寻找既写衣裳处理、又写渡法的词句。
解析：提起衣裳，走浅滩蹚过去，这是渔人给乡人的办法。

## 原文：教学例句 {#p.h30.check.3}
> 驿报车六乘。发布甲十领、食三十石，分载六车；至郡，吏检粮数，乃署券。
译文：驿站报告有车六辆。发出布制护甲十领、粮食三十石，分由六辆车装载。到郡里，官吏核验粮数，才签署凭据。
词注：乘：在车数后读 shèng，计车的单位。

## 单选：驿站报“六乘”，数的是什么？ {#q.h30.check.3}
考点：skill.h30.2.sheng-chariot
语境：p.h30.check.3

- [ ] 铠甲件数 {#q.h30.check.3.o1}
  理由：甲另以领计。
- [ ] 粮食容量 {#q.h30.check.3.o2}
  理由：粮另以石计。
- [x] 运输车辆 {#q.h30.check.3.o3}

提示：后面怎样用同一个数目说这些车？
解析：前面说“车六乘”，装载时又说“六车”，两处是同一批车。

## 原文：教学例句 {#p.h30.check.4}
> 史官记师还，卒各归里。唯旧兵留库，库吏数其戈矛，列诸木架。
译文：史官记道，军队归来，士卒各自还乡。只有旧兵器留在库里，库吏清点戈矛，陈列于木架。
词注：卒：军中士兵。

## 找原文证据：库中留下的“兵”是哪类东西？选出最能看清这一点的原文。 {#q.h30.check.4}
考点：skill.h30.2.bing-arms
语境：p.h30.check.4

- [x] 数其戈矛 {#q.h30.check.4.o1}
- [ ] 卒各归里 {#q.h30.check.4.o2}
  理由：“卒各归里”说士兵各自回家，没指明库中放着什么。
- [ ] 史官记师还 {#q.h30.check.4.o3}
  理由：这一句记全军归来，清点库存是后面的事。

提示：库吏清点时点出了哪些具体物件？
解析：“戈矛”指明库存的是兵器，能分别清点、放上木架。

## 原文：教学例句 {#p.h30.check.5}
> 简载春伐东邑，未克而退；秋复至，始克其邑，郡以其图上。
译文：简册记春天出兵征讨东邑，未能攻克便撤退；秋天再到，才攻下那座城邑，郡里把该邑的地图上报。
词注：伐：发兵征讨。
  克：攻取、攻下。

## 单选：春天攻东邑，那一回究竟打下来没有？ {#q.h30.check.5}
考点：skill.h30.3.fa-campaign
语境：p.h30.check.5

- [ ] 春天已占东邑 {#q.h30.check.5.o1}
  理由：后文“未克而退”。
- [ ] 只议定出兵未行动 {#q.h30.check.5.o2}
  理由：已写“伐”且后有退兵。
- [x] 已经出兵，但未占得该邑 {#q.h30.check.5.o3}

提示：把“春伐”一直读到“未克而退”。
解析：春天出了兵，但没打下来就撤了。发起征讨和取得城邑是两件事。

## 单选：哪一季东邑才被攻下？ {#q.h30.check.6}
考点：skill.h30.3.ke-capture
语境：p.h30.check.5

- [x] 秋季 {#q.h30.check.6.o1}
- [ ] 春季 {#q.h30.check.6.o2}
  理由：春天是“未克而退”，东邑还没有被攻下。
- [ ] 两季都是 {#q.h30.check.6.o3}
  理由：春天有“未克”，秋天才有“始克”。

提示：找到“始克其邑”，往前看写的是何时又来。
解析：“秋复至”接着“始克”，说明秋天第二次到来才攻得此邑。
