# 检查：保留原话的语气和范围 {#check.30}

## 原文：教学例句 {#check.30.p.rain}
> 昨池涸，今骤雨，水满矣。童指水问：“可放鱼乎？”父曰：“可。”
译文：昨天池塘干涸，今天下急雨，水已满了。孩子指着水问：“可以放鱼了吗？”父亲说：“可以。”

## 单选：“水满矣”同后面孩子的话分别做了什么？ {#check.30.q1}
考点：l2.skill.yi-change
语境：check.30.p.rain

- [ ] 两句都说放鱼已经完成
  理由：原文只写征询许可。
- [ ] 先向父亲打听水量，再命令他放鱼
  理由：父亲回答的是能否放鱼。
- [x] 先告知池水已有变化，再询问能否放鱼

提示：区分“昨池涸”和最后的回答。
解析：“矣”指眼前新状态，“乎”把下一项行动交给人确认。

## 原文：教学例句 {#check.30.p.coin}
> 商问客所失几何。客曰：“遗之道旁者，二钱耳；余钱具在。”
译文：商人问客人丢了多少钱。客人说：“掉在路旁的只有两枚，其余的都在。”

## 单选：“二钱耳”限定的是什么？ {#check.30.q2}
考点：l2.skill.er-limit
语境：check.30.p.coin

- [ ] 袋里剩下的全部钱数
  理由：“余钱具在”另说剩余的钱，数量未交代。
- [x] 掉在路旁的钱数
- [ ] 商人赚到的钱数
  理由：答话谈的是客人掉的钱。

提示：先读“遗之道旁者”所圈定的对象。
解析：“耳”限止遗失的数量，不能把两枚当作全部。

## 原文：教学例句 {#check.30.p.thief}
> 夜闻叩门声，邻人皆出，莫见来者。或举灯照篱下，得一小犬。
译文：夜里听见敲门声，邻人都出来，无人见到来者。有人提灯照篱笆下，发现一只小狗。

## 单选：先写“莫见”，再写“或举灯”，人物范围怎样变了？ {#check.30.q3}
考点：l2.skill.huo-some
语境：check.30.p.thief

- [ ] 先说一人没看见，再说全体都举灯
  理由：首句有“邻人皆出”，后句没有“皆举灯”。
- [x] 先说邻人无人见到来者，后说其中有人提灯
- [ ] 两句都只表达作者猜想
  理由：提灯后发现小狗，是实际结果。

提示：分别给“见”和“举”补主语。
解析：“莫”概括无人见到，“或”引出一个未点名的行动者。

## 原文：教学例句 {#check.30.p.horse}
> 翁方疗马足，戒孙曰：“莫解其缰。”孙应而守之。
译文：老人正在治疗马脚，嘱咐孙子：“不要解开它的缰绳。”孙子答应了，守着马。

## 单选：“莫解其缰”是哪一种话？ {#check.30.q4}
考点：l2.skill.mo-prohibit
语境：check.30.p.horse

- [x] 告诫孙子不要解开缰绳
- [ ] 汇报此前没有人解过缰绳
  理由：“戒孙曰”写的是面对孙子的嘱咐。
- [ ] 推测缰绳也许坏了
  理由：没有断裂或损坏的描述。

提示：孙子听后为什么答应？
解析：祖父要求禁止一个动作，孙子应承后守马。

## 原文：教学例句 {#check.30.p.ash}
> 屋后有灰。童曰：“盖邻人昨焚草，吾未见也。”主人往问，邻果以实告。
译文：屋后有灰。孩子说：“大概是邻人昨天烧草，我没有见到。”主人前去询问，邻人果然据实相告。

## 单选：孩子说“盖”时，他的消息来自哪里？ {#check.30.q5}
考点：l2.skill.gai-guess
语境：check.30.p.ash

- [x] 从灰作推测，自己没有亲见
- [ ] 自己曾帮忙烧草
  理由：“吾未见也”排除亲历。
- [ ] 邻人已经当面告诉他
  理由：主人是其后才去问。

提示：分开孩子说话和主人核实的两个时点。
解析：“盖”与“未见”的分寸吻合，后来应验不能变成孩子早有确证。

## 原文：教学例句 {#check.30.p.houses}
> 风折道旁树，十家皆损其篱，惟桥东一舍无恙。
译文：风折断路边的树，十户人家的篱笆都受了损，只有桥东一家安好。

## 单选：“惟”在哪一项上划定例外？ {#check.30.q6}
考点：l2.skill.wei-only
语境：check.30.p.houses

- [x] 桥东这一家没有遭损
- [ ] 所有房屋都只损了篱笆
  理由：“惟”紧接的是一家，限制无恙的对象。
- [ ] 桥东的人家只有一家
  理由：限定的是免遭损坏的房舍，不是在点算地理分布。

提示：将“无恙”的主语完整找出。
解析：“惟桥东一舍”圈出免遭损坏的一家，与受损诸家对照。
