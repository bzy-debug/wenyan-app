# 课文：乎、哉、矣、耳：话说到哪里 {#syntax.4}
简介：用同一件事试换句末词，再从实际回答和前后情形恢复原话的语气。

## 正文

“客至乎”问客人到没到，听者可以答“至”或“未至”；“客至矣”则告知眼下已有新情形。判断时先看说话人是否掌握消息，以及听者实际怎样回应。

“贤哉”把赞叹提到前面，末尾若还有人名，须接起来读。“一人耳”给数量划界，“恐迟耳”也可限制理由。乎、哉可以出现在不同性质的问句或感叹句中，不要将单字和某个标点一对一配对。

## 知识点：乎（询问） {#l2.skill.hu-query}
义项：用问句请对方确认一件事是否成立
领域：虚词
要诀：用问句请对方确认一件事是否成立
讲解：试补“是还是不是”，并检查下一句是不是作答。
例句：l2.ex.hu-query

## 原文：教学例句 {#l2.ex.hu-query}
> 母问：“粥熟乎？”儿曰：“未也。”
译文：母亲问：“粥熟了吗？”孩子答：“还没有。”

## 知识点：哉（感叹） {#l2.skill.zai-praise}
义项：突出说话人对人、物或事情的评价
领域：虚词
要诀：突出说话人对人、物或事情的评价
讲解：看“哉”前是否为评价词，后面的人物或情境是否说明评价为何而发。
例句：l2.ex.zai-praise

## 原文：教学例句 {#l2.ex.zai-praise}
> 美哉此花，雨后益鲜！
译文：这花真美啊，雨后越发鲜艳！

## 知识点：矣（新情况） {#l2.skill.yi-change}
义项：提示到当前时点情况已变或已如此
领域：虚词
要诀：提示到当前时点情况已变或已如此
讲解：先比较原有预期与眼下情况，分辨是宣布新事实还是请人确认。
例句：l2.ex.yi-change

## 原文：教学例句 {#l2.ex.yi-change}
> 昨水尚浅，今没阶矣。
译文：昨天水还浅，今天已经淹没台阶了。

## 知识点：耳（限止） {#l2.skill.er-limit}
义项：把数量、理由或所说的程度限于前面一项
领域：虚词
要诀：把数量、理由或所说的程度限于前面一项
讲解：找“耳”前可以接“而已”的那一组词，保留它的范围。
例句：l2.ex.er-limit

## 原文：教学例句 {#l2.ex.er-limit}
> 行囊无他物，一卷书耳。
译文：行李里没有别的东西，只有一卷书罢了。

## 原文：古籍引文 {#syntax.4.p.hui}
> 贤哉回也！一箪食，一瓢饮，在陋巷，人不堪其忧，回也不改其乐。
译文：颜回真贤德啊！一竹筐饭，一瓢水，住在简陋的巷子，别人忍受不了那困苦，颜回却不改他的快乐。

## 单选：“贤哉回也”要求旁人回答“贤不贤”吗？ {#syntax.4.q1}
考点：l2.skill.zai-praise
语境：syntax.4.p.hui

- [x] 孔子已经在赞叹颜回贤德
- [ ] 孔子还不知道所说的人是谁
  理由：“回也”清楚点出了颜回。
- [ ] 孔子在数颜回有多少食物
  理由：数量在下文，用来说明生活状况。

提示：把“人不堪”和“回也不改”对照。
解析：“贤”是已经作出的评价，下文说明这种赞叹因何而发。

## 原文：教学例句 {#syntax.4.p.barge}
> 客问：“舟至乎？”童曰：“向未至，今系岸矣。”客披衣而起。
译文：客人问：“船到了吗？”孩子答：“方才还没有到，现在已经系在岸边了。”客人披衣起身。

## 单选：第一句交给孩子确认什么？ {#syntax.4.q2}
考点：l2.skill.hu-query
语境：syntax.4.p.barge

- [ ] 客人是否应该披衣
  理由：披衣在答话之后。
- [x] 船有没有到
- [ ] 舟是谁的
  理由：“舟至乎”没有问船主身份。

提示：看孩子回答的是哪一种变化。
解析：“乎”把“舟至”提作待确认的事项。

## 单选：“系岸矣”对“向未至”作了什么更新？ {#syntax.4.q3}
考点：l2.skill.yi-change
语境：syntax.4.p.barge

- [ ] 船离岸的时间仍需询问
  理由：孩子在通报现状，未问何时离岸。
- [x] 方才没到的船，如今已经靠岸
- [ ] 过去和现在都未到
  理由：已经能够系岸，表明船来了。

提示：比较“向”和“今”。
解析：过去与当前的情形不同，“矣”把已发生的变化告诉客人。

## 原文：教学例句 {#syntax.4.p.scroll}
> 邻问：“所得书多乎？”生展一卷曰：“此一卷耳，非多也。”
译文：邻人问：“你得到的书多吗？”学生展开一卷，说：“只有这一卷罢了，不多。”

## 单选：邻人问的是书的什么方面？ {#syntax.4.q4}
考点：l2.skill.hu-query
语境：syntax.4.p.scroll

- [ ] 书中写了什么
  理由：答话给的是一卷的数量。
- [ ] 书原来由谁收藏
  理由：问句没有疑问人称。
- [x] 所得书的数量是否多

提示：将“所得书多”改为能肯定或否定的问题。
解析：“乎”用在“多”后，请学生就数量作答。

## 单选：“耳”把学生的回答限在什么范围内？ {#syntax.4.q5}
考点：l2.skill.er-limit
语境：syntax.4.p.scroll

- [ ] 他永远只读这一卷
  理由：“所得”说本次得到的书。
- [x] 所得只有眼前这一卷
- [ ] 一卷里只写了一个字
  理由：指的是卷数，不是字数。

提示：先将“此一卷”和“非多”连读。
解析：“一卷耳”限制的是这一次所得的数量。

## 原文：教学例句 {#syntax.4.p.dyke}
> 昨堤犹缺，今水至而堤完矣。父老登堤叹曰：“壮哉，此堤！”
译文：昨天堤坝还有缺口，今天水到时堤坝已经修好了。父老登堤感叹：“这堤真壮观啊！”

## 单选：哪种读法保留了“堤完矣”同昨天的联系？ {#syntax.4.q6}
考点：l2.skill.yi-change
语境：syntax.4.p.dyke

- [ ] 这座堤从来不曾损坏
  理由：“昨堤犹缺”明说有过缺口。
- [x] 昨天还有缺口，现在已修好了
- [ ] 今天的人尚在询问堤修好了没有
  理由：这是与“昨”相对的肯定陈述。

提示：留心“昨……今……”的对照。
解析：“矣”在这里收住新情况，水已至而堤也已修好。

## 找原文证据：哪组词直接表达父老对堤的评价？ {#syntax.4.q7}
考点：l2.skill.zai-praise
语境：syntax.4.p.dyke

- [x] 壮哉
- [ ] 父老登堤
  理由：这是观察前的动作。
- [ ] 今水至
  理由：这是水情。

提示：找带有好坏、强弱等评价意味的词。
解析：“壮”评说堤坝，配“哉”发为赞叹。

## 原文：教学例句 {#syntax.4.p.delay}
> 客后期，友问其故。客曰：“待渡耳，未尝他往。”
译文：客人误了约，朋友问缘故。客人说：“只是等船渡河罢了，并没有去别处。”

## 单选：客人用“耳”想让朋友怎样理解迟到的缘故？ {#syntax.4.q8}
考点：l2.skill.er-limit
语境：syntax.4.p.delay

- [ ] 等待的具体时长已经算清
  理由：文中没有给时间长短。
- [x] 只因等渡，没有另去别处
- [ ] 今后不会再等渡船
  理由：“耳”限制这次迟到的解释。

提示：把“待渡”接在“只是因为……”之后。
解析：“耳”在此限制的是理由，后句排除另有所往。
