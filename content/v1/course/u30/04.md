# 课文：“乎”“哉”“矣”“耳”：听句尾的语气 {#syntax.4}
简介：客人问“舟至乎”，孩子答“系岸矣”。读一问一答，听出句末几个字带来的差别。

## 正文

“客至乎”，说话人还想听一句回答：客人到没到？换作“客至矣”，听到的人就该知道，客人已经到了。同样是“客至”，谁手里有消息、谁还在等消息，差别就在句末。

“贤哉回也”把“贤哉”放在前面，一口气读到“回”，才听全这是在夸谁。“一人耳”是只此一人；“恐迟耳”是只因怕迟到。读“耳”要看它前面究竟是人数还是缘由。“乎”“哉”也各有别的用法，得顺着说话人的意思读，单凭问号或叹号判断不了。

## 知识点：乎（询问） {#l2.skill.hu-query}
义项：……吗？请对方确认是不是这样
领域：虚词
要诀：后面能接一句“是”或“还没有”吗？
讲解：问“粥熟乎”，孩子答“未也”。把这一问一答放在一起，就听得出母亲在打听粥熟了没有。
例句：l2.ex.hu-query

## 原文：教学例句 {#l2.ex.hu-query}
> 母问：“粥熟乎？”儿曰：“未也。”
译文：母亲问：“粥熟了吗？”孩子答：“还没有。”

## 知识点：哉（感叹） {#l2.skill.zai-praise}
义项：表示感叹，带出说话人对人或事的评价
领域：虚词
要诀：先听赞叹什么，再找称赞的是谁。
讲解：“美哉此花”先说“真美”，再指出是眼前这朵花；后面还交代它雨后格外鲜艳。
例句：l2.ex.zai-praise

## 原文：教学例句 {#l2.ex.zai-praise}
> 美哉此花，雨后益鲜！
译文：这花真美，雨后格外鲜艳！

## 知识点：矣（新情况） {#l2.skill.yi-change}
义项：已经这样了，告诉人眼下的情况或刚有的变化
领域：虚词
要诀：眼下的情形和先前有什么不同？
讲解：昨天水还浅，今天台阶已经没在水里。“矣”把眼前的变化告诉人。
例句：l2.ex.yi-change

## 原文：教学例句 {#l2.ex.yi-change}
> 昨水尚浅，今没阶矣。
译文：昨天水还浅，今天已经淹没台阶了。

## 知识点：耳（限止） {#l2.skill.er-limit}
义项：罢了、而已，表示只有这些或只因这件事
领域：虚词
要诀：试在“耳”前的词后面添上“罢了”。
讲解：说“一卷书耳”，是行李里只带了这一卷。遇到“待渡耳”，要看它限制的是不是迟到的缘由。
例句：l2.ex.er-limit

## 原文：教学例句 {#l2.ex.er-limit}
> 行囊无他物，一卷书耳。
译文：行李里没有别的东西，只有一卷书罢了。

## 原文：古籍引文 {#syntax.4.p.hui}
> 贤哉回也！一箪食，一瓢饮，在陋巷，人不堪其忧，回也不改其乐。
译文：颜回真是贤德啊！一小筐饭，一瓢水，住在简陋的巷子里，别人受不了这样的困苦，颜回仍然自得其乐。

## 单选：说“贤哉回也”时，孔子是在发问，还是心里已经有了评价？ {#syntax.4.q1}
考点：l2.skill.zai-praise
语境：syntax.4.p.hui

- [x] 孔子已经在赞叹颜回贤德
- [ ] 孔子还不知道所说的人是谁
  理由：“回也”清楚点出了颜回。
- [ ] 孔子在数颜回有多少食物
  理由：数量在下文，用来说明生活状况。

提示：把“人不堪”和“回也不改”对照。
解析：“贤哉”是赞叹，“回也”点出他赞的是颜回。别人受不了这样的困苦，颜回却依然快乐，后文正是在解释为什么贤。

## 原文：教学例句 {#syntax.4.p.barge}
> 客问：“舟至乎？”童曰：“向未至，今系岸矣。”客披衣而起。
译文：客人问：“船到了吗？”孩子答：“方才还没有到，现在已经系在岸边了。”客人披衣起身。

## 单选：客人开口向孩子打听什么？ {#syntax.4.q2}
考点：l2.skill.hu-query
语境：syntax.4.p.barge

- [ ] 客人是否应该披衣
  理由：披衣在答话之后。
- [x] 船有没有到
- [ ] 舟是谁的
  理由：“舟至乎”没有问船主身份。

提示：看孩子回答的是哪一种变化。
解析：客人还不知道船到了没有，才问“舟至乎”。孩子报出船已经在岸边，恰好答了这个疑问。

## 单选：孩子说“系岸矣”，船的情形和方才有什么不同？ {#syntax.4.q3}
考点：l2.skill.yi-change
语境：syntax.4.p.barge

- [ ] 船离岸的时间仍需询问
  理由：孩子在通报现状，未问何时离岸。
- [x] 方才没到的船，如今已经靠岸
- [ ] 过去和现在都未到
  理由：已经能够系岸，表明船来了。

提示：比较“向”和“今”。
解析：“向”指方才，那时船还没到；现在船已系在岸上。孩子用“矣”告诉客人，这件事有了变化。

## 原文：教学例句 {#syntax.4.p.scroll}
> 邻问：“所得书多乎？”生展一卷曰：“此一卷耳，非多也。”
译文：邻人问：“你得到的书多吗？”学生展开一卷，说：“只有这一卷罢了，不多。”

## 单选：邻人问的是书的什么方面？ {#syntax.4.q4}
考点：l2.skill.hu-query
语境：syntax.4.p.scroll

- [ ] 书中写了什么
  理由：答话给的是一卷的数量。
- [ ] 书原来由谁收藏
  理由：邻人问“多乎”，没问“谁的书”。
- [x] 所得书的数量是否多

提示：将“所得书多”改为能肯定或否定的问题。
解析：邻人问“多乎”，学生就报“此一卷”。这一问一答谈的都是这次拿到的书有多少。

## 单选：“耳”把学生的回答限在什么范围内？ {#syntax.4.q5}
考点：l2.skill.er-limit
语境：syntax.4.p.scroll

- [ ] 他永远只读这一卷
  理由：“所得”说本次得到的书。
- [x] 所得只有眼前这一卷
- [ ] 一卷里只写了一个字
  理由：指的是卷数，不是字数。

提示：先将“此一卷”和“非多”连读。
解析：“耳”跟在“一卷”后，是说这回得到的书只有眼前这一卷。至于他一生读过多少书，这里没有说。

## 原文：教学例句 {#syntax.4.p.dyke}
> 昨堤犹缺，今水至而堤完矣。父老登堤叹曰：“壮哉，此堤！”
译文：昨天堤坝还有缺口，今天水到时堤坝已经修好了。父老登堤感叹：“这堤真壮观啊！”

## 单选：哪种读法保留了“堤完矣”同昨天的联系？ {#syntax.4.q6}
考点：l2.skill.yi-change
语境：syntax.4.p.dyke

- [ ] 这座堤从来不曾损坏
  理由：“昨堤犹缺”明说有过缺口。
- [x] 昨天还有缺口，现在已修好了
- [ ] 今天的人尚在询问堤修好了没有
  理由：“昨堤犹缺”说昨天还有缺口，“今……堤完矣”已经说出修好了。

提示：留心“昨……今……”的对照。
解析：昨天有缺口，今天已经修好。“堤完矣”报的是眼下水来时堤坝的情形。

## 找原文证据：哪组词直接表达父老对堤的评价？ {#syntax.4.q7}
考点：l2.skill.zai-praise
语境：syntax.4.p.dyke

- [x] 壮哉
- [ ] 父老登堤
  理由：“登堤”只写父老走上堤坝。走上去之后，他们才开口赞叹。
- [ ] 今水至
  理由：“今水至”说水到了。父老觉得堤坝怎样，要找他们说的话。

提示：找父老登上堤坝后亲口说的赞叹。
解析：父老登堤，开口便说“壮哉”。写水到、写登堤，都是事情的经过，这两个字才说出了他们的赞叹。

## 原文：教学例句 {#syntax.4.p.delay}
> 客后期，友问其故。客曰：“待渡耳，未尝他往。”
译文：客人误了约，朋友问缘故。客人说：“只是等船渡河罢了，并没有去别处。”

## 单选：客人用“耳”想让朋友怎样理解迟到的缘故？ {#syntax.4.q8}
考点：l2.skill.er-limit
语境：syntax.4.p.delay

- [ ] 等待的具体时长已经算清
  理由：文中没有给时间长短。
- [x] 只因等渡，没有另去别处
- [ ] 今后不会再等渡船
  理由：“耳”限制这次迟到的解释。

提示：把“待渡”接在“只是因为……”之后。
解析：朋友问的是为何误期。客人答“待渡耳”，也就是只因等渡船，还特意补了一句“未尝他往”。
