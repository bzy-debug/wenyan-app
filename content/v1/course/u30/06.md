# 课文：夫、盖、惟：从开头到范围 {#syntax.6}
简介：把引起议论、保留推测与限定对象分开；在失去某个虚词时判断原意会少哪一层。

## 正文

“夫舟所以济水”先提出舟来议论。“夫”放在开头可作发语词；在“樵夫”一类词里却指人。“盖”可以引出推想，也能引出对上文的解说。若紧跟“未之见”“未可决”等保留语气的词，较宜读成“大概”。本课只在有这种旁证时要求判作推测。

“惟士为能”限制的是能做到的人。挪成“士惟能读书”，被限制的就成了能做的事。读时指给自己看：作者从哪些候选中留下了哪一个？句末“与（欤）”有时表示询问，其位置与“与友行”的介词不同；本课用问答各辨一例。

## 知识点：夫（发语） {#l2.skill.fu-frame}
义项：在句首领起要陈述或议论的事项
领域：虚词
要诀：在句首领起要陈述或议论的事项
讲解：把后面的整句读通，看“夫”是否另指一个人。下文的理据常接着所提的话题展开。
例句：l2.ex.fu-frame

## 原文：教学例句 {#l2.ex.fu-frame}
> 夫救火贵早，迟则延及邻舍。
译文：说到救火，贵在早动手，迟了就会蔓延到邻居家。

## 知识点：盖（推测） {#l2.skill.gai-guess}
义项：结合保留判断的措辞，把说明读成推想
领域：虚词
要诀：结合保留判断的措辞，把说明读成推想
讲解：寻找说话人所据的迹象以及他尚欠的确证。有明确解释因果的语境须另作判断。
例句：l2.ex.gai-guess

## 原文：教学例句 {#l2.ex.gai-guess}
> 足迹向南，客盖已南去，然未审也。
译文：脚印朝南，客人大概已往南去了，但还未查实。

## 知识点：惟、唯（限定） {#l2.skill.wei-only}
义项：只肯定某一对象或某一项行动
领域：虚词
要诀：只肯定某一对象或某一项行动
讲解：看紧接其后的词组是什么，再找上下文与之相对的其他候选。
例句：l2.ex.wei-only

## 原文：教学例句 {#l2.ex.wei-only}
> 诸门皆闭，惟西门开。
译文：各处城门都关了，只有西门开着。

## 知识点：与（欤，疑问） {#l2.skill.yu-query}
义项：在句末引出可由听者确认或否认的判断
领域：虚词
要诀：在句末引出可由听者确认或否认的判断
讲解：若“与”在句末，观察它是否还有可带的同伴或受事；再看对方的回答。
例句：l2.ex.yu-query

## 原文：教学例句 {#l2.ex.yu-query}
> 客问：“此子之舟与？”曰：“然。”
译文：客人问：“这是您的船吗？”回答：“是的。”

## 原文：古籍引文 {#syntax.6.p.means}
> 无恒产而有恒心者，惟士为能。
译文：没有稳定的产业而仍有坚定操守，孟子认为只有士能够做到。
出处：《孟子·梁惠王上》论恒产与恒心

## 单选：按孟子这句话，“惟”限制了什么？ {#syntax.6.q1}
考点：l2.skill.wei-only
语境：syntax.6.p.means

- [x] 被认为能够做到这件事的人
- [ ] 士能够做的事只有一件
  理由：被限定的词是“士”，不是士的全部本领。
- [ ] 只要有产业就一定没有操守
  理由：前面的话以“无恒产”为条件，并未论所有有产业者。

提示：把“惟”后第一项名词指出来。
解析：“惟士”是把能者限于士；这是在读孟子所作的判断。

## 单选：“盖有之”同“我未之见”合起来作了多强的断定？ {#syntax.6.q2}
考点：l2.skill.gai-guess
语境：syntax.6.p.known

- [ ] 已经亲见，所以十分肯定
  理由：下句明说“未之见”。
- [x] 承认可能有，自己未曾见到
- [ ] 断言绝不会有
  理由：前句仍然保留“有之”的可能。

提示：用自己未见的后半句校准前一句的语气。
解析：“盖”在这里保留推想；未见并不等于证明没有。

## 原文：教学例句 {#syntax.6.p.barrier}
> 父语儿曰：“夫守堤，在察其微。此土湿，盖有隙，未可遽决。”乃掘而验之。
译文：父亲对孩子说：“说到守堤，要察看细微变化。这处土湿，大概有个缝，还不能立刻断定。”于是挖开查验。

## 单选：“夫守堤”中的“夫”怎样领起下文？ {#syntax.6.q3}
考点：l2.skill.fu-frame
语境：syntax.6.p.barrier

- [ ] 称守堤者是某个丈夫
  理由：下文讲的是怎样守堤这个事项。
- [ ] 表示守堤已结束
  理由：随后还在观察、查验。
- [x] 先提出守堤来讲应注意什么

提示：看“在察其微”评说的是人还是做法。
解析：“夫”引起议论，后面由一般做法落到眼前的湿土。

## 单选：掘土验证之前，父亲对“有隙”的把握如何？ {#syntax.6.q4}
考点：l2.skill.gai-guess
语境：syntax.6.p.barrier

- [x] 根据土湿推想，尚待检验
- [ ] 绝不可能有缝隙
  理由：说“盖有隙”才会挖开查验。
- [ ] 已经挖见缝隙
  理由：“乃掘”是在说完这话以后。

提示：“未可遽决”排除哪种读法？
解析：“土湿”是迹象，“盖”提出一种解释，“验”还在后面。

## 原文：教学例句 {#syntax.6.p.cloth}
> 三色陈于案，女工惟取青者。客问：“将染衣与？”对曰：“非也，将缘衣。”
译文：案上摆着三色布，女工只取青色的。客人问：“是要染衣吗？”她答：“不是，是要给衣服镶边。”

## 找原文证据：哪一段直接写出三色中只取哪一种？ {#syntax.6.q5}
考点：l2.skill.wei-only
语境：syntax.6.p.cloth

- [ ] 将缘衣
  理由：这是取布的用途。
- [x] 惟取青者
- [ ] 三色陈于案
  理由：这是列出可选择的范围。

提示：找带有限定词的选择动作。
解析：“惟”限制实际选取，未说另外两色不存在。

## 单选：“将染衣与”的“与”起什么作用？ {#syntax.6.q6}
考点：l2.skill.yu-query
语境：syntax.6.p.cloth

- [ ] 表示把做好的衣服送给人
  理由：“非也”是在否定所猜用途。
- [ ] 引出和谁一同染衣
  理由：“与”在句末，后面没有同伴。
- [x] 询问染衣这一猜测对不对

提示：听女工用“非也”回应什么。
解析：与通欤，作语气词。答话先否定，再纠正用途。

## 原文：教学例句 {#syntax.6.p.plough}
> 师曰：“夫耕有时，雨过则土润。”童举耒问：“今可耕与？”师曰：“可矣。”
译文：老师说：“耕田有其时节，雨后土便湿润。”孩子举起耒问：“现在可以耕了吗？”老师说：“可以了。”

## 单选：开头“夫耕有时”为什么先说得较宽？ {#syntax.6.q7}
考点：l2.skill.fu-frame
语境：syntax.6.p.plough

- [ ] 先禁止学生在雨后耕作
  理由：雨后土润是有利条件。
- [x] 先提出耕作时机这个话题，随后说雨后的条件
- [ ] 先介绍了一位名叫“夫耕”的人
  理由：课文随即谈的是何时能下田。

提示：看后一句能为哪一个话题提供说明。
解析：句首“夫”引出耕作有时的判断，土润说明其中一个条件。

## 单选：“可矣”的答话让哪个字的功能清楚了？ {#syntax.6.q8}
考点：l2.skill.yu-query
语境：syntax.6.p.plough

- [x] 问句末的“与”是在请求确认
- [ ] “夫”是在询问老师姓名
  理由：师的首句是讲耕作。
- [ ] 举耒的“举”是在否定耕作
  理由：举农具是孩子已经做的动作。

提示：把问答一起读作“现在可以了吗？可以了”。
解析：“与”在“今可耕”之后，不带人或物，以“可矣”即可回答。
