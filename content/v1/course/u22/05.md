# 课文：谕、属、使、请 {#vocab.5}
简介：郡守派官吏去巡堤，船夫却是自己请求先出发。看清哪句话由谁说，哪件事由谁做。

## 正文

谁去取书？“使人取书”是把人派出去取。“请取书”若是说话人请求准许他亲自去，便可读作“请允许我去”。遇到省去的人名，接着看究竟是谁动了身。

## 知识点：谕 {#skill.vocab.5.1}
义项：告知并使人明白
领域：实词
要诀：找受话者和需要说明的内容。
讲解：“令谕众以修堤之意”可先分“众”和“修堤之意”：百姓是听话者，修堤的用意则是县令要说明给他们的内容。
例句：p.vocab.5.1.example

## 原文：教学例句 {#p.vocab.5.1.example}
> 令谕众以修堤之意。
译文：县令向众人说明修堤的用意。

## 原文：教学例句 {#p.vocab.5.1.a}
> 吏谕民曰：“明日水至，宜迁高处。”
译文：官吏告知百姓明天水会到，应移往高处。

## 单选：洪水将至，官吏对百姓说“宜迁高处”。“谕民”是在做什么？ {#q.vocab.5.1}
考点：skill.vocab.5.1
语境：p.vocab.5.1.a

- [x] 告知并使人明白 {#q.vocab.5.1.o1}
- [ ] 比喻 {#q.vocab.5.1.o2}
  理由：说的是明天的安排，没有拿别物作比。
- [ ] 暗自猜测 {#q.vocab.5.1.o3}
  理由：“曰”后写出向百姓说明的话。

提示：官吏把哪一桩消息和应对办法告诉了百姓？
解析：官吏说明水何时来，也叫百姓往高处迁。“谕”是把事情讲给他们明白。

## 原文：教学例句 {#p.vocab.5.1.b}
> 众不解新令，长者谕以其故，众乃从。
译文：众人不明白新命令，长者说明其中缘由，众人才遵从。

## 单选：长者做了什么使众人改变做法？ {#q.vocab.5.2}
考点：skill.vocab.5.1
语境：p.vocab.5.1.b

- [ ] 替他们执行命令 {#q.vocab.5.2.o1}
  理由：遵从新令的仍是众人。
- [ ] 更换命令内容 {#q.vocab.5.2.o2}
  理由：“谕以其故”是说明这样下令的缘由，命令本身没换。
- [x] 向他们说明原由 {#q.vocab.5.2.o3}

提示：从“不解”到“乃从”，中间是谁作了解释？
解析：长者讲清了新令的缘由，众人才照着办。“其故”正是他们先前没弄明白的地方。

## 知识点：属 {#skill.vocab.5.2}
义项：嘱托
领域：实词
要诀：“属”读 zhǔ 时，留意托给谁什么事。
讲解：“属邻人护其牛”里老人已经病了，护牛的是受托的邻人。“属”把两人的分工连起来，读 zhǔ。
例句：p.vocab.5.2.example

## 原文：教学例句 {#p.vocab.5.2.example}
> 翁病，属邻人护其牛。
译文：老人病了，托邻人照料他的牛。

## 原文：教学例句 {#p.vocab.5.2.a}
> 母将远行，属女善视幼弟。
译文：母亲将远行，嘱托女儿好好照看幼弟。

## 单选：母亲要远行，“属女善视幼弟”是在对女儿做什么？ {#q.vocab.5.3}
考点：skill.vocab.5.2
语境：p.vocab.5.2.a

- [ ] 归属 {#q.vocab.5.3.o1}
  理由：“善视”是交代给女儿办的事。
- [x] 嘱托 {#q.vocab.5.3.o2}
- [ ] 连续不断 {#q.vocab.5.3.o3}
  理由：这里有明确的托付者与受托者。

提示：母亲走后，照看幼弟的事交给谁？
解析：母亲把照看小儿子的事托付给女儿。作嘱托讲的“属”读 zhǔ。

## 原文：教学例句 {#p.vocab.5.2.e}
> 友属我寄书，临别复言：“毋忘此札。”
译文：朋友托我寄信，分别时又说别忘记这封信。

## 找原文证据：朋友用哪句话再次叮咛先前托付的事？ {#q.vocab.5.4}
考点：skill.vocab.5.2
语境：p.vocab.5.2.e

- [x] 毋忘此札 {#q.vocab.5.4.o1}
- [ ] 复言 {#q.vocab.5.4.o2}
  理由：这只说明又说话，未说明说了什么。
- [ ] 临别 {#q.vocab.5.4.o3}
  理由：这交代说话时间。

提示：留意临别时他为什么再提那封信。
解析：“毋忘此札”是说别忘了这封信。朋友临别又提醒一遍要代寄的事。

## 知识点：使 {#skill.vocab.5.3}
义项：派遣
领域：实词
要诀：“使”后的人往往是下一动作的执行者。
讲解：“君使臣问邻国之政”由国君派遣，实际去打听的是臣子。夹在“使”和“问”间的“臣”同时接住这两层关系。
例句：p.vocab.5.3.example

## 原文：教学例句 {#p.vocab.5.3.example}
> 君使臣问邻国之政。
译文：国君派臣子去询问邻国政事。

## 原文：教学例句 {#p.vocab.5.3.a}
> 郡守使吏循堤，暮则报水。
译文：郡守派官吏巡行堤岸，傍晚报告水情。

## 单选：郡守“使吏循堤”，查堤的任务怎样到了官吏身上？ {#q.vocab.5.5}
考点：skill.vocab.5.3
语境：p.vocab.5.3.a

- [ ] 使者 {#q.vocab.5.5.o1}
  理由：“使”在“吏”前，写郡守派人。
- [x] 派遣 {#q.vocab.5.5.o2}
- [ ] 假如 {#q.vocab.5.5.o3}
  理由：下文交代例行任务，未设假定条件。

提示：谁在傍晚回来报告水情？谁让他出发？
解析：郡守派人巡堤，傍晚由受派的官吏报告水情。

## 原文：教学例句 {#p.vocab.5.3.b}
> 商主使童问舟期，童至津而返。
译文：商主派孩子去问船期，孩子走到渡口又返回。

## 单选：实际去渡口打听的是谁？ {#q.vocab.5.6}
考点：skill.vocab.5.3
语境：p.vocab.5.3.b

- [x] 孩子 {#q.vocab.5.6.o1}
- [ ] 船夫 {#q.vocab.5.6.o2}
  理由：船夫可能知道船期，却不是受派去问的人。
- [ ] 商主 {#q.vocab.5.6.o3}
  理由：商人让童子去问船期。看后句是谁到了渡口又折返。

提示：渡口去了一趟又回来的人，是否就是发话的那个人？
解析：商人派童子打听船期。“童至津而返”写的是童子的往返。

## 知识点：请 {#skill.vocab.5.4}
义项：请求允许自己做
领域：实词
要诀：看请求之后谁亲自做事。
讲解：“弟请代兄荷薪”是弟弟请求自己替哥哥担柴。把“请”后的话改成弟弟的口吻：“请让我代哥哥去。”
例句：p.vocab.5.4.example

## 原文：教学例句 {#p.vocab.5.4.example}
> 弟请代兄荷薪。
译文：弟弟请求允许自己替哥哥背柴。

## 原文：教学例句 {#p.vocab.5.4.a}
> 子曰：“父足痛，请负父归。”遂俯背。
译文：儿子说父亲脚疼，请让我背您回去，于是俯身。

## 单选：儿子一边说“请负父归”，一边俯下背。“请”在这里怎样讲？ {#q.vocab.5.7}
考点：skill.vocab.5.4
语境：p.vocab.5.4.a

- [ ] 探听消息 {#q.vocab.5.7.o1}
  理由：引语里已经提出具体做法。
- [ ] 邀请父亲背人 {#q.vocab.5.7.o2}
  理由：儿子俯身才是准备背人的人。
- [x] 请求允许自己做 {#q.vocab.5.7.o3}

提示：是谁俯下背来，准备背另一个人？
解析：“负父”的是儿子。他在请求准许自己背父亲回去。

## 原文：教学例句 {#p.vocab.5.4.b}
> 众难渡水，舟子请先试之，独棹轻舟往。
译文：众人难以渡水，船夫请求自己先试，独自划小船前去。

## 单选：“请先试之”请求的是哪件事？ {#q.vocab.5.8}
考点：skill.vocab.5.4
语境：p.vocab.5.4.b

- [x] 由船夫先试水路 {#q.vocab.5.8.o1}
- [ ] 请别人先将船划回 {#q.vocab.5.8.o2}
  理由：船夫自持船桨出发。
- [ ] 命众人抢先上船 {#q.vocab.5.8.o3}
  理由：下一句是船夫独往。

提示：把“请先试之”与“独棹轻舟”两处的主语补出来。
解析：请求先试的是船夫，独自划小船试水的也是他。
