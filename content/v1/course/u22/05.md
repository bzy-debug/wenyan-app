# 课文：“请”后面的事，要谁去做？ {#v22.2}
简介：公子吕向郑庄公提两条路，一条请准自己做，一条请国君做。两句都带“请”，动手的人却换了。

## 正文

“臣请事之”已把“臣”摆在前面，等于请求君主允许自己侍奉大叔。公子吕随后说“若弗与，则请除之”，请的是庄公自己处置大叔。两句话是在摆出两个选择，并未真的先后做成两件事。

若说“使吏循堤”，是上级派官吏出去；“属我寄书”是朋友把信托付给我。“使”“属”都把事情交给别人，“请”则要多听一步：接下来谁获得允准，谁会亲自去做？

## 知识点：属 {#skill.vocab.5.2}
义项：嘱托
领域：实词
要诀：“属”读 zhǔ 时，留意托给谁什么事。
讲解：“属邻人护其牛”里老人已经病了，护牛的是受托的邻人。“属”把两人的分工连起来，读 zhǔ。
例句：p.vocab.5.2.example

## 原文：教学例句 {#p.vocab.5.2.example}
> 翁病，属邻人护其牛。
译文：老人病了，托邻人照料他的牛。

## 原文：教学例句 {#p.vocab.5.2.a}
> 母将远行，属女善视幼弟。
译文：母亲将远行，嘱托女儿好好照看幼弟。

## 单选：母亲要远行，“属女善视幼弟”是在对女儿做什么？ {#q.vocab.5.3}
考点：skill.vocab.5.2
语境：p.vocab.5.2.a

- [ ] 归属 {#q.vocab.5.3.o1}
  理由：“善视”是交代给女儿办的事。
- [x] 嘱托 {#q.vocab.5.3.o2}
- [ ] 连续不断 {#q.vocab.5.3.o3}
  理由：这里有明确的托付者与受托者。

提示：母亲走后，照看幼弟的事交给谁？
解析：母亲把照看小儿子的事托付给女儿。作嘱托讲的“属”读 zhǔ。

## 原文：教学例句 {#p.vocab.5.2.e}
> 友属我寄书，临别复言：“毋忘此札。”
译文：朋友托我寄信，分别时又说别忘记这封信。
词注：札：书信
  毋：不要。

## 找原文证据：朋友用哪句话再次叮咛先前托付的事？ {#q.vocab.5.4}
考点：skill.vocab.5.2
语境：p.vocab.5.2.e

- [x] 毋忘此札 {#q.vocab.5.4.o1}
- [ ] 复言 {#q.vocab.5.4.o2}
  理由：这只说明又说话，未说明说了什么。
- [ ] 临别 {#q.vocab.5.4.o3}
  理由：这交代说话时间。

提示：留意临别时他为什么再提那封信。
解析：“毋忘此札”是说别忘了这封信。朋友临别又提醒一遍要代寄的事。

## 知识点：使 {#skill.vocab.5.3}
义项：派遣
领域：实词
要诀：“使”后的人往往是下一动作的执行者。
讲解：“君使臣问邻国之政”由国君派遣，实际去打听的是臣子。夹在“使”和“问”间的“臣”同时接住这两层关系。
例句：p.vocab.5.3.example

## 原文：教学例句 {#p.vocab.5.3.example}
> 君使臣问邻国之政。
译文：国君派臣子去询问邻国政事。

## 原文：教学例句 {#p.vocab.5.3.a}
> 郡守使吏循堤，暮则报水。
译文：郡守派官吏巡行堤岸，傍晚报告水情。

## 单选：郡守“使吏循堤”，查堤的任务怎样到了官吏身上？ {#q.vocab.5.5}
考点：skill.vocab.5.3
语境：p.vocab.5.3.a

- [ ] 使者 {#q.vocab.5.5.o1}
  理由：“使”在“吏”前，写郡守派人。
- [x] 派遣 {#q.vocab.5.5.o2}
- [ ] 假如 {#q.vocab.5.5.o3}
  理由：下文交代例行任务，未设假定条件。

提示：谁在傍晚回来报告水情？谁让他出发？
解析：郡守派人巡堤，傍晚由受派的官吏报告水情。

## 原文：教学例句 {#p.vocab.5.3.b}
> 商主使童问舟期，童至津而返。
译文：商主派孩子去问船期，孩子走到渡口又返回。
词注：津：渡口。

## 找原文证据：“使童问舟期”的差事并非商人自己办。哪处把实际跑了一趟的人写明了？ {#q.vocab.5.6}
考点：skill.vocab.5.3
语境：p.vocab.5.3.b

- [ ] 商主使童 {#q.vocab.5.6.o1}
  理由：此处说谁派遣谁，还不够证明受命的人已经去过。
- [ ] 问舟期 {#q.vocab.5.6.o2}
  理由：这是差事的内容，还没写完成的人。
- [x] 童至津而返 {#q.vocab.5.6.o3}

提示：找“使”后办事的记录，而不仅是命令。
解析：“商主使童”交代差遣，“童至津而返”交代童子完成往返。主事的人和跑腿的人要分开。

## 知识点：请 {#skill.vocab.qing-you}
义项：请求对方去做
领域：实词
要诀：把“请”后面的动词补上主语。若是说话人在请听者采取行动，由谁点头、谁行动？
讲解：“门者曰：请君解剑”，门吏开口，佩剑的客人才解剑。若只译一个“请”字，仍可能把两个人的事情写反。
例句：p.vocab.qing-you.example

## 原文：教学例句 {#p.vocab.qing-you.example}
> 门者曰：“请君解剑。”客解而入。
译文：门吏说：“请您解下佩剑。”客人照办，进了门。
词注：门者：守门人。

## 原文：古籍引文 {#p.vocab.qing-you.a}
> 欲与大叔，臣请事之；若弗与，则请除之，无生民心。
译文：您若要把国家交给大叔，请允许我去侍奉他；若不打算交给他，就请您除掉他，不要让百姓生出二心。
词注：事：侍奉
  大叔：此处指郑庄公之弟共叔段。
出处：《左传·隐公元年》公子吕谏郑庄公
作者：《左传》编者，传统题左丘明

## 单选：公子吕把两条路都说了。“臣请事之”“则请除之”两处，分别是请谁去做事？ {#q.vocab.qing-you.1}
考点：skill.vocab.qing-you
语境：p.vocab.qing-you.a

- [ ] 请大叔侍奉国君；请百姓处置大叔 {#q.vocab.qing-you.1.o1}
  理由：两处“之”都是动作涉及的大叔，不能因此把他当动作发出者。
- [x] 愿由公子吕自己侍奉；请郑庄公处置大叔 {#q.vocab.qing-you.1.o2}
- [ ] 请郑庄公侍奉大叔；公子吕自行处置大叔 {#q.vocab.qing-you.1.o3}
  理由：“臣”是公子吕自称；处置与否取决于受谏的君主。

提示：前一个“请”前有“臣”，后一个承上文“若弗与”问的是国君怎么办。
解析：同一番劝告里，“请”可求准自己做事，也可劝对方行动。翻译时把两个人写出来，才能看清公子吕给庄公的选择。

## 原文：教学例句 {#p.vocab.qing-you.b}
> 客请主人闭窗，曰：“案上书为风所乱。”主人起而闭之。
译文：客人请主人把窗关上，说案上的书被风吹乱了。主人起身关窗。
词注：案：放置书物的几案。

## 排序：谁提议，谁动手？按客人说话和主人行动的先后排列。 {#q.vocab.qing-you.2}
考点：skill.vocab.qing-you
语境：p.vocab.qing-you.b

- [2] 客人说明风吹乱了书 {#q.vocab.qing-you.2.o1}
  理由：“曰”后的话仍出自客人。
- [1] 客人开口请主人关窗 {#q.vocab.qing-you.2.o2}
  理由：请求由客人提出，已指明所请之人。
- [3] 主人起身把窗关上 {#q.vocab.qing-you.2.o3}
  理由：“主人起而闭之”让我们知道由谁照办。

提示：“请主人”已说明听者，最后一句再把他写作主语。
解析：这不是客人请求准许自己关窗。请求对象和最后执行的人都是主人。

## 知识点：请 {#skill.vocab.5.4}
义项：请求允许自己做
领域：实词
要诀：看请求之后谁亲自做事。
讲解：“弟请代兄荷薪”是弟弟请求自己替哥哥担柴。把“请”后的话改成弟弟的口吻：“请让我代哥哥去。”
例句：p.vocab.5.4.example

## 原文：教学例句 {#p.vocab.5.4.example}
> 弟请代兄荷薪。
译文：弟弟请求允许自己替哥哥背柴。

## 原文：教学例句 {#p.vocab.5.4.a}
> 子曰：“父足痛，请负父归。”遂俯背。
译文：儿子说父亲脚疼，请让我背您回去，于是俯身。
词注：负：背在背上。

## 单选：儿子一边说“请负父归”，一边俯下背。“请”在这里怎样讲？ {#q.vocab.5.7}
考点：skill.vocab.5.4
语境：p.vocab.5.4.a

- [ ] 探听消息 {#q.vocab.5.7.o1}
  理由：引语里已经提出具体做法。
- [ ] 邀请父亲背人 {#q.vocab.5.7.o2}
  理由：儿子俯身才是准备背人的人。
- [x] 请求允许自己做 {#q.vocab.5.7.o3}

提示：是谁俯下背来，准备背另一个人？
解析：“负父”的是儿子。他在请求准许自己背父亲回去。

## 原文：古籍引文 {#p.vocab.5.4.b}
> 孟子对曰：“王好战，请以战喻。填然鼓之，兵刃既接，弃甲曳兵而走。”
译文：孟子答道：“大王喜好作战，请让我用战事打个比方。”接着他描述鼓声响起、两军交锋、有人丢盔拖着兵器逃跑的情景。
词注：喻：用例子作比说明
  曳：拖着。
出处：《孟子·梁惠王上》寡人之于国也章

## 单选：孟子说“请以战喻”。大王若答应，接下来由谁举例，谁听？ {#q.vocab.5.8}
考点：skill.vocab.5.4
语境：p.vocab.5.4.b

- [ ] 请两位将领轮流给大王讲战况 {#q.vocab.5.8.o1}
  理由：问答只交代孟子向大王说话，没有请另一位将领。
- [x] 孟子举例给大王听 {#q.vocab.5.8.o2}
- [ ] 大王说自己的作战经历，孟子只负责发问 {#q.vocab.5.8.o3}
  理由：起头标“孟子对曰”，鼓声与逃兵正是孟子接着描绘的例子。

提示：从“请”往后读，谁已经开始讲鼓声、兵刃和逃兵？
解析：“我”虽没写出来，后面的行动把它补足。这句是“请允许我以作战为喻”，同“请您去处置”要分开。
