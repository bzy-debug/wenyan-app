# 检查：三番交谈，谁在开口 {#check.22}

## 原文：教学例句 {#p.vocab.check.22.new1}
> 客夜系马不固，马逸，损邻人之苗。客往谢邻人曰：“过在我，请自补种。”
译文：客人夜里没把马拴牢，马跑掉，糟蹋了邻居的禾苗。客人去向邻居赔礼，说：“过错在我，请准我自己把苗补种上。”
词注：固：牢靠
  逸：逃脱。

## 单选：客人来“谢”，要为哪件事作交代？ {#q.vocab.check.22.new1}
考点：skill.vocab.4.1
语境：p.vocab.check.22.new1

- [x] 自己没有拴好马，伤了邻家的苗 {#q.vocab.check.22.new1.o1}
- [ ] 邻人替他把马找了回来 {#q.vocab.check.22.new1.o2}
  理由：邻人的禾苗受了损；没说邻人替客人找马。
- [ ] 对方送了他禾苗，他不肯收 {#q.vocab.check.22.new1.o3}
  理由：损坏的是邻人的庄稼，文中没有赠苗这回事。

提示：把“过在我”说出的是谁和“系马不固”的人对上。
解析：他先犯错，又亲自承认。这里的“谢”该读作赔不是。

## 单选：说完“请自补种”，谁打算下田补苗？ {#q.vocab.check.22.new2}
考点：skill.vocab.5.4
语境：p.vocab.check.22.new1

- [ ] 客人请另一位种田人代劳 {#q.vocab.check.22.new2.o1}
  理由：“自”表示亲自，没有请来另外的人。
- [x] 说话的客人亲自种 {#q.vocab.check.22.new2.o2}
- [ ] 客人请邻人自己补种 {#q.vocab.check.22.new2.o3}
  理由：“自”接说话人刚认下的过错：他要自己补救。

提示：试补“请准我……”再看“自”所指。
解析：先向受损失的邻人赔礼，再请准自己下田补种。向谁请求、由谁实际干活，要分开读。

## 原文：教学例句 {#p.vocab.check.22.new2}
> 有客夜至，主人请客持灯照阶，客举灯。既入，主人酌酒；客谢曰：“归途尚远，不能饮。”
译文：有客人夜间来到。主人请他持灯照台阶，客人举起灯。进屋后，主人斟酒，客人谢绝，说回去的路还远，不能喝。
词注：阶：台阶
  酌：斟酒。

## 找原文证据：主人请人照阶。哪处表明举灯的人确实是受请求的一方？ {#q.vocab.check.22.new3}
考点：skill.vocab.qing-you
语境：p.vocab.check.22.new2

- [ ] 主人酌酒 {#q.vocab.check.22.new3.o1}
  理由：这是进去之后主人做的另一件事。
- [ ] 有客夜至 {#q.vocab.check.22.new3.o2}
  理由：这里仅交代来访的时间，没人举灯。
- [x] 客举灯 {#q.vocab.check.22.new3.o3}

提示：回到“请客”之后，找接了这桩事的人。
解析：有些“请”是请求允许自己做事，此处直写“请客”，随后客人亲手举灯。

## 单选：客人谢过以后，按他自己说的，会发生什么？ {#q.vocab.check.22.new4}
考点：skill.vocab.xie-decline
语境：p.vocab.check.22.new2

- [x] 酒虽已斟好，他却不喝 {#q.vocab.check.22.new4.o1}
- [ ] 他把酒喝完才告辞 {#q.vocab.check.22.new4.o2}
  理由：“不能饮”说清楚他谢绝的是这杯酒。
- [ ] 他责怪主人不曾劝酒 {#q.vocab.check.22.new4.o3}
  理由：主人已亲自酌酒；客人解释的是回程远。

提示：客人拿归途作理由，要解释收下还是推掉？
解析：“谢曰”的后一句交代了婉辞的缘由。“谢”不能一概换成表示感谢的“谢谢”。

## 原文：教学例句 {#p.vocab.check.22.new3}
> 风折庭树，邻人共扶之。主设食以谢众，众就食。主问树可活否，园丁指新芽而对曰：“其可活矣。”
译文：风刮折了庭树，邻人一起来扶树。主人备饭感谢大家，众人就餐。主人问树还能不能活，园丁指着新芽回答说，大概可以活。
词注：设食：备饭待人
  庭：院子。

## 单选：主人备饭“谢众”，邻人先前做了什么，使“谢”可以读作感谢？ {#q.vocab.check.22.new5}
考点：skill.vocab.xie-thanks
语境：p.vocab.check.22.new3

- [ ] 责备主人伤了庭树 {#q.vocab.check.22.new5.o1}
  理由：原文说风折树，未说有人责备树主。
- [x] 合力扶了受损的庭树 {#q.vocab.check.22.new5.o2}
- [ ] 把主人邀去吃饭而遭拒绝 {#q.vocab.check.22.new5.o3}
  理由：前文是邻人帮忙；设食请客的反而是主人。

提示：哪件事发生在“设食”以前，又帮了主人？
解析：邻人出力在先，主人以饭相待在后，这是受惠后答谢。

## 找原文证据：园丁“对”的是什么问题？找出发问的原话。 {#q.vocab.check.22.new6}
考点：skill.vocab.4.4
语境：p.vocab.check.22.new3

- [ ] 众就食 {#q.vocab.check.22.new6.o1}
  理由：说的是邻人应邀吃饭，不是问园丁的话。
- [ ] 新芽 {#q.vocab.check.22.new6.o2}
  理由：这是园丁指给人看的作答依据，不是问题。
- [x] 树可活否 {#q.vocab.check.22.new6.o3}

提示：“否”把一个陈述变成了疑问。
解析：“主问”引出问题。“对曰”后园丁直接给了判断，主人与园丁一问一答。
