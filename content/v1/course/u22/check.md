# 检查：听话与辨意综合练习 {#check.22}

## 原文：教学例句 {#p.vocab.check.22.1}
> 门吏让客迟至。客谢曰：“舟为风留。”吏乃开门。
译文：守门官责备客人到得晚，客人道歉说船被风阻住，官吏才开门。

## 单选：门吏“让客”的缘由是什么？ {#q.vocab.check.22.1}
考点：skill.vocab.4.3
语境：p.vocab.check.22.1

- [ ] 官吏愿把门交给客人 {#q.vocab.check.22.1.o1}
  理由：迟到是他指出的问题。
- [ ] 客人抢先入门 {#q.vocab.check.22.1.o2}
  理由：门到末句才打开。
- [x] 客人到得迟 {#q.vocab.check.22.1.o3}

提示：看“让”后面是否说出受责者的过错。
解析：“让”后接“迟至”，明说责备针对的是时间。

## 单选：客人提风阻行船，意在做什么？ {#q.vocab.check.22.2}
考点：skill.vocab.4.1
语境：p.vocab.check.22.1

- [ ] 宣布次日不再来 {#q.vocab.check.22.2.o1}
  理由：客人已在门前。
- [x] 为迟到道歉并解释 {#q.vocab.check.22.2.o2}
- [ ] 向官吏致谢送船 {#q.vocab.check.22.2.o3}
  理由：官吏没有送船。

提示：找有没有过失，以及对方是否因此不悦。
解析：先受责再用“谢曰”交代理由，意思是致歉。

## 原文：教学例句 {#p.vocab.check.22.2}
> 令使二吏视桥，属其长录损木之数。长请先下，众执绳护之。
译文：县令派两名官吏查看桥梁，嘱托领头的官吏记下损木数量。领头人请求先下去，众人拉绳护着他。

## 单选：记下损木数是谁交代的事？ {#q.vocab.check.22.3}
考点：skill.vocab.5.2
语境：p.vocab.check.22.2

- [ ] 众人指示县令 {#q.vocab.check.22.3.o1}
  理由：县令是派遣者。
- [x] 县令嘱托领头的官吏 {#q.vocab.check.22.3.o2}
- [ ] 领头人嘱托众人 {#q.vocab.check.22.3.o3}
  理由：“属其长”是向领头人交代。

提示：“属”读 zhǔ 时，留意托给谁什么事。
解析：“属”与“使”都承接县令为主语。

## 单选：“请先下”的人怎样实现自己的请求？ {#q.vocab.check.22.4}
考点：skill.vocab.5.4
语境：p.vocab.check.22.2

- [ ] 请县令来桥下 {#q.vocab.check.22.4.o1}
  理由：并未说县令到现场。
- [x] 由领头人先下去查看 {#q.vocab.check.22.4.o2}
- [ ] 让众人先下 {#q.vocab.check.22.4.o3}
  理由：众人在上面执绳。

提示：看请求之后谁亲自做事。
解析：“长请”与后文众人“护之”相应，受护者是领头人。

## 原文：教学例句 {#p.vocab.check.22.3}
> 行者不信人言道迂，径行至涧。顾见向所过亭在山后，始知行已远。
译文：旅人不信别人说道路曲折，径直走到山涧。他回头看见先前经过的亭子已在山后，才知道走得很远。

## 单选：出发时，他对路人的提醒如何回应？ {#q.vocab.check.22.5}
考点：skill.vocab.6.1
语境：p.vocab.check.22.3

- [ ] 已了解全程 {#q.vocab.check.22.5.o1}
  理由：到末句才知道走远了。
- [ ] 写信询问道路 {#q.vocab.check.22.5.o2}
  理由：“不信人言”涉及态度。
- [x] 不相信所说的路况 {#q.vocab.check.22.5.o3}

提示：寻找“疑”以及核实后改变态度的词。
解析：“信”的对象是“人言”，它说的是路况。

## 单选：哪种动作让他看见先前经过的亭子？ {#q.vocab.check.22.6}
考点：skill.vocab.6.4
语境：p.vocab.check.22.3

- [ ] 弯腰看水底 {#q.vocab.check.22.6.o1}
  理由：亭在山后。
- [x] 回头看 {#q.vocab.check.22.6.o2}
- [ ] 向山前奔跑 {#q.vocab.check.22.6.o3}
  理由：“向所过”说明亭是已经经过的。

提示：区分转身回望与心里顾虑。
解析：“顾见”先写回头，再写看见之物。
