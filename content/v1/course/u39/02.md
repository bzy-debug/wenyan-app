# 课文：礼给谁，问题又问谁 {#g39.2}
简介：从动词后面分别读出交付的东西、接话的人、动手的地点和用的器具。

## 正文

“授客一书”中，交出去的是一封信，接过信的是客；若再说“授书于庭”，庭是交接地点。两个原句都把补充的成分写在“授”后边。

古文中介词结构本来就常出现在谓语后。有些教材把用现代汉语转述时往前移的情形称为“状语后置”。先问“于”后是可以答话的人、发生事情的地方，还是比较的另一方。“以”后若是工具，试着用这件东西做一次动作。

## 知识点：授受句中的人和物 {#g39.skill.gift}
义项：分开交出东西的人、所得者和所得之物
领域：句法
要诀：试着给礼簿填上送者、受者、品物三栏。
讲解：同样在“授”后，孩子可以领东西，钥匙可以被拿走。看“授童钥”不能把孩子和钥匙都当作送出去的物品。
例句：g39.ex.gift

## 原文：教学例句 {#g39.ex.gift}
> 父予女一笥。
译文：父亲给女儿一只竹箱。

## 知识点：谓语后的处所 {#g39.skill.site}
义项：从动作后面的于字结构找出做事地点
领域：句法
要诀：把“于”后的内容放在简图上，看能否标出发生地。
讲解：“刻名于木”把处所“于木”放在谓语之后。转述为“在木头上刻名字”，地点便移到了动作前面。有些教材把这样的介词结构后置称作“状语后置”。
例句：g39.ex.site

## 原文：教学例句 {#g39.ex.site}
> 匠绘鱼于屏。
译文：工匠把鱼画在屏风上。

## 知识点：谓语后的交谈对象 {#g39.skill.addressee}
义项：辨“问于、告于”等后面的人是谁
领域：句法
要诀：谁肯开口、谁会回答？
讲解：“妇以火警告于邻”里，火警是要说的事，邻居是听见报告的人。
例句：g39.ex.addressee

## 原文：教学例句 {#g39.ex.addressee}
> 生问于友，友为解之。
译文：学生向朋友发问，朋友为他解答。

## 知识点：谓语后的工具 {#g39.skill.posttool}
义项：辨动作后“以”带来的手段和动作用到的物
领域：句法
要诀：可以拿什么去做，做完改变了什么？
讲解：“缚竹以索”是用绳绑竹，竹是被绑的东西，“以索”说用什么来绑。遇到这样的介宾短语后置，也要分清它说的是工具还是地点。有些教材把这类写法称为状语后置。
例句：g39.ex.posttool

## 原文：教学例句 {#g39.ex.posttool}
> 工穿板以锥。
译文：工匠用锥子钻木板。

## 原文：古籍引文 {#g39.2.p.corn}
> 原思为之宰，与之粟九百，辞。子曰：“毋！以与尔邻里乡党乎！”
译文：原思做孔子的家臣。孔子给他九百量的粟，他推辞。孔子说：“别推辞，可以用来给你的邻里乡亲嘛！”

## 单选：第一次给粟时，递给谁，递出的又是什么？ {#g39.2.q1}
考点：g39.skill.gift
语境：g39.2.p.corn

- [ ] 孔子已经直接把粟给了乡亲
  理由：分给乡亲是原思推辞后孔子提出的办法。
- [ ] 原思给孔子粟
  理由：“辞”的是获给粟的原思。
- [x] 孔子给原思粟

提示：把前一句的原思带进“与之”的“之”。
解析：“与”后先接领粟的原思，再接物品及其数目。邻里是在孔子接下来的答话里出现的。

## 原文：教学例句 {#g39.2.p.map}
> 画工宿津亭，绘二桥于壁，标其名于下。里正指图问于舟人：“晚潮至，何桥可通？”舟人指西桥。
译文：画工住在渡口的亭舍，在墙上画出两座桥，在下方标出桥名。里正指着图向船夫问：“晚潮到了，哪座桥能过？”船夫指了西桥。

## 单选：“宿津亭”和“绘二桥于壁”都写到地方。给画工记住处、给壁画记所在，两栏如何填？ {#g39.2.q2}
考点：g39.skill.site
语境：g39.2.p.map

- [ ] 两处“地名”都是画里的景物：画中有一座津亭、一堵墙
  理由：“津亭”直接接在“宿”后，说画工住在哪儿；“绘”的对象才是二桥。
- [x] 住在渡口亭舍；画落在墙上
- [ ] 住在津亭；画落在桥面上，画的是一堵墙
  理由：动作是“绘二桥”，“于壁”交代把它们画在哪里，不能互换。

提示：先问住在哪里，再问画了什么、画在哪里。
解析：“宿津亭”的地点直接跟在动词后。“绘二桥于壁”先交代所画之物，再以“于壁”写作画处。

## 单选：里正在哪位人物那里问到了西桥？ {#g39.2.q3}
考点：g39.skill.addressee
语境：g39.2.p.map

- [x] 船夫
- [ ] 一位名叫西桥的人
  理由：人用手指出西桥，并没有把它当人来问。
- [ ] 画工
  理由：画工负责绘图和题名。

提示：“问于”后的名字能否和下一句答话的人对上？
解析：“于舟人”把问题送到船夫面前。后面船夫指桥，正好接上。

## 原文：教学例句 {#g39.2.p.cord}
> 木工欲审两柱之高，度柱以绳，将刻识于门。徒授工一刀，工取而刻之。
译文：木匠要查清两根柱子的高度，用绳量柱，准备在门上刻下记号。学徒递给木匠一把刀，木匠接过来刻下记号。
词注：审：查明。
  度：量一量。
  识：作记号，此处指所刻标记。

## 找原文证据：木匠没有用刀量高度，哪几个字写出他怎样量柱？ {#g39.2.q4}
考点：g39.skill.posttool
语境：g39.2.p.cord

- [ ] 徒授工一刀
  理由：刀是学徒随后递给木匠用来刻记号的。
- [x] 度柱以绳
- [ ] 刻识于门
  理由：这一处说记录落在哪里。

提示：先划出动词“度”管到哪里。
解析：“度柱”是量柱子，句末“以绳”才写量柱所用的工具。

## 单选：“徒授工一刀，工取而刻之”中，刀怎样到了木匠手边？ {#g39.2.q5}
考点：g39.skill.gift
语境：g39.2.p.cord

- [ ] 学徒交给木匠一根柱，刀留在自己手中
  理由：“授”后交付的东西写成“一刀”。
- [x] 学徒递刀，木匠接过
- [ ] 木匠给学徒，学徒刻门
  理由：“工取”已经说是木匠接过。

提示：把“授”的人和下一句“取”的人分别圈出。
解析：“授”前是徒，“授”后依次是受刀的人和刀。到“取”，受刀者才成了行动者。

## 单选：工匠完成后，去哪里可以找到刻下的量高记录？ {#g39.2.q6}
考点：g39.skill.site
语境：g39.2.p.cord

- [ ] 学徒手上的刀刃
  理由：刀已递给木匠，是刻记号的工具。
- [ ] 绳上
  理由：绳子用来量，刻痕另有地点。
- [x] 门上

提示：“刻识”后紧跟什么地方？
解析：“刻识于门”把门交代为刻记号的地方，读者要把地点归给“刻”，不能归给“度”。

## 原文：教学例句 {#g39.2.p.wax}
> 库吏封缄以蜡。使者疑其中有图，问于库吏，吏曰：“粟簿耳。”使者乃纳缄入囊。
译文：管库的吏员用蜡封好包件。使者疑心里面有地图，便向库吏询问。库吏说：“只是粮册。”使者便把包件收入袋中。
词注：缄：封好的包件。
  簿：登记用的册子。

## 单选：“封缄以蜡”若要讲清用什么封，哪种复述最贴切？ {#g39.2.q7}
考点：g39.skill.posttool
语境：g39.2.p.wax

- [x] 用蜡封好包件
- [ ] 把袋口熔成蜡
  理由：袋子最后才用来收包件。
- [ ] 把蜡装进包里运走
  理由：包里装的是粮册。

提示：留心“封”后先出现了要封的东西。
解析：“封缄”已说出封什么。随后“以蜡”补出封口的材料。

## 找原文证据：想知道使者向谁打听，原文哪处足以确定？ {#g39.2.q8}
考点：g39.skill.addressee
语境：g39.2.p.wax

- [ ] 使者疑其中有图
  理由：这是提问的起因。
- [x] 问于库吏
- [ ] 乃纳缄入囊
  理由：这是问明以后的动作。

提示：不要把疑心的内容当成受问的人。
解析：“问于库吏”把受问者写明。紧接着的“吏曰”又让这个人亲自回答。
