# 检查：核清货与数，读完整封报告 {#check.39}

## 原文：教学例句 {#check.39.p.grain}
> 岁歉，库吏出粟五囊，授舟人三囊，留二囊以待后来者。东舟载二囊，西舟一囊。里长书其数于板，封之以泥。
译文：收成不好，库吏取出五袋谷子，交给船夫三袋，留下两袋等待后来的人。东船装走两袋，西船装走一袋。里长把数目写在木板上，用泥封好。

## 单选：仓里还剩多少？“西舟一囊”又省了哪个动作？ {#check.39.q1}
考点：g39.skill.items
语境：check.39.p.grain

- [ ] 留下两袋；西船也留一袋在仓里
  理由：这句同“东舟载二囊”对着说，西船做的仍是“载”。
- [ ] 留下三袋；西船载一袋
  理由：三袋已授给船夫，留下的是“二囊”。
- [x] 留下两袋；西船载一袋

提示：先找“留”后有多少，再把东、西两船的账并排看。
解析：五袋中，留下两袋。两船分装另三袋，“东舟载二囊，西舟一囊”后一句承前省了“载”，不能换成库吏做的“留”。

## 单选：把交付与封存分开记，谁领了什么？里长又用什么封存记录？ {#check.39.q2}
考点：g39.skill.gift
语境：check.39.p.grain

- [ ] 舟人领粟三囊；木板是封泥的工具
  理由：木板用来写数目；封记录另用“以泥”交代的东西。
- [x] 舟人领粟三囊；里长用泥封住记录
- [ ] 库吏领粟三囊；里长用泥封住记录
  理由：“授”前面的库吏负责交出去，“授”后面的舟人才是领粮的。

提示：在“授”后面读领粮的人和物数，再找“封”后写的材料。
解析：船夫领了三袋谷。木板用来记数；“封之以泥”另说用泥封好，不能把木板记成封存所用的材料。

## 原文：教学例句 {#check.39.p.rope}
> 村南有堑，匠系木于岸，以成浮桥。长者请渡，三呼其孙，使持杖相迎。孙问于匠：“吾祖何在？”匠指东岸。孙见祖挥巾者再，始知其在东岸。
译文：村南有一道沟，工匠把木头系在岸边，做成浮桥。老人想过沟，三次招呼孙子，让他持杖去迎。孙子问工匠：“我的祖父在哪儿？”工匠指给他看东岸。孙子见祖父两次挥巾，才知道祖父在东岸。

## 单选：若在记事里分开填“叫人”和“挥巾”的次数，两栏怎样写？ {#check.39.q3}
考点：g39.skill.tally
语境：check.39.p.rope

- [ ] 两声呼唤，三次挥巾
  理由：第一数直接放在“呼”前，后面“者再”收在挥巾之后。
- [x] 三声呼唤，两次挥巾
- [ ] 三个孙子各应一声，两块巾各挥一次
  理由：数的是动作，人和巾都没有相应增加。

提示：“三呼”和“挥巾者再”，报数的位置一样吗？
解析：三在动作前，数呼唤；再在整件挥巾的事后，仍报这个动作的次数。

## 单选：若把“系木于岸，问于匠”的“于”都当作地点，会读错哪里？ {#check.39.q4}
考点：g39.skill.site
语境：check.39.p.rope

- [ ] 两处都应当答“在哪里”；工匠的住处是东岸
  理由：孙子打听的是祖父的所在，工匠住在哪儿没有说。
- [x] 木头系在岸边；孙子是向工匠问，并非在工匠家问
- [ ] 两处都该答“问谁”；岸边的人与工匠都是受问者
  理由：“于岸”接着“系木”，木头要系在什么地方，和向谁打听是两回事。

提示：先看各跟在哪个动词后。能指给孙子看东岸的是谁？
解析：系木需要固定处，所以“于岸”说明地点；问话需要听者，工匠指着东岸作答，他是孙子问的人。

## 原文：教学例句 {#check.39.p.account}
> 吏验乡人所贷而未偿之粟，令里长遍告之。邻翁闻吏已至仓，趋往。及门，识其声者曰：“昨持券来，东里周叟也。”
译文：官吏查验乡人借去还没还的谷粮，命里长逐一通知借粮人。邻翁听说官吏已到仓，赶去。到了门边，有人辨出他的声音，说：“昨天带借券来过的，是东里的周叟。”

## 单选：官吏查什么，又让谁去通知？要怎样读才没有把两个人的事混在一起？ {#check.39.q5}
考点：g39.skill.nested
语境：check.39.p.account

- [ ] 查全乡收成，命里长通知各家
  理由：“所贷而未偿”收窄了范围，句中说的是乡人欠的粮。
- [x] 查乡人借去未还的谷粮，吩咐里长去通知
- [ ] 查乡人借去未还的谷粮，里长命官吏去通知
  理由：“令里长遍告之”先写官吏的命令，接着要去通知的是受命的里长。

提示：先读到“粟”才答查什么；再跟着“令”找受命办事的人。
解析：“所贷而未偿”都跟着“粟”，只有两个条件都合的粮算入核验。官吏自己查，另叫里长去通知乡人。

## 单选：邻翁刚才听到了什么？“昨持券来”的人又是谁？ {#check.39.q6}
考点：g39.skill.later
语境：check.39.p.account

- [ ] 听说官吏已经到仓；昨持券来的是官吏
  理由：官吏出现在传来的消息中，持券者却在末句另报姓名。
- [ ] 听说自己也该赶往仓库；昨持券者是周叟
  理由：“趋往”写邻翁听到消息以后的反应，不能也塞进“闻”的内容。
- [x] 听说官吏已经到仓；昨持券来的是东里的周叟

提示：“趋往”的是谁？再跟着辨认声音的人读过“来”，听他报出句末的人名。
解析：邻翁听说的是“吏已至仓”，自己才动身。“昨持券来”先没报姓名，“东里周叟也”接在后面，才知道昨天来的是周叟。
