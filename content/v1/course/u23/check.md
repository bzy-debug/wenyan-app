# 检查：时序与数量综合练习 {#check.23}

## 原文：教学例句 {#p.vocab.check.23.1}
> 客尝游南市。是日旦至，商方启肆，货犹在箧。
译文：客人曾逛过南市。这天清晨到来时，商人正在开店，货物还在箱子里。

## 单选：哪件事属于客人的以往经历？ {#q.vocab.check.23.1}
考点：skill.vocab.7.2
语境：p.vocab.check.23.1

- [ ] 清点箱中货物 {#q.vocab.check.23.1.o1}
  理由：文中未说客人清点。
- [ ] 看商人正在开店 {#q.vocab.check.23.1.o2}
  理由：这是“是日”的见闻。
- [x] 游过南市 {#q.vocab.check.23.1.o3}

提示：看看后面是不是一项以往的经历。
解析：“尝”领过去经历，后句转到这一天。

## 找原文证据：原文中哪一处印证开店尚在进行？ {#q.vocab.check.23.2}
考点：skill.vocab.7.4
语境：p.vocab.check.23.1

- [ ] 是日旦至 {#q.vocab.check.23.2.o1}
  理由：只交代到达时刻。
- [ ] 客尝游南市 {#q.vocab.check.23.2.o2}
  理由：这是以往经历。
- [x] 货犹在箧 {#q.vocab.check.23.2.o3}

提示：用突发事情作观察点，看另一动作是否仍在进行。
解析：货物还在箱里，尚未取出陈列。

## 原文：教学例句 {#p.vocab.check.23.2}
> 暮云起，俄雨，行者避于桥下。雨止，旋出，衣尚干。
译文：傍晚起云，不久便下雨，行人在桥下躲避。雨停了，随即出来，衣服还是干的。

## 单选：云起与下雨间隔多久？ {#q.vocab.check.23.3}
考点：skill.vocab.8.1
语境：p.vocab.check.23.2

- [x] 短短一会儿 {#q.vocab.check.23.3.o1}
- [ ] 一整夜 {#q.vocab.check.23.3.o2}
  理由：“俄”表示间隔短。
- [ ] 整整一日 {#q.vocab.check.23.3.o3}
  理由：从暮云到雨未写跨日。

提示：前后动作之间的短短一段时间是判断依据。
解析：“俄”把下雨接在暮云升起之后。

## 单选：行者出桥的时机是什么？ {#q.vocab.check.23.4}
考点：skill.vocab.8.2
语境：p.vocab.check.23.2

- [ ] 云刚起即出来 {#q.vocab.check.23.4.o1}
  理由：当时尚未入桥避雨。
- [ ] 衣湿后出来 {#q.vocab.check.23.4.o2}
  理由：“衣尚干”说明未湿。
- [x] 雨刚停随即出来 {#q.vocab.check.23.4.o3}

提示：若下句紧接上事，先试“随即”。
解析：“旋出”前面紧挨“雨止”。

## 原文：教学例句 {#p.vocab.check.23.3}
> 旧园有梨十余株，桃五株。去岁新植桃三，今春倍之，凡植桃九株于两岁之间。
译文：园中原有十多株梨、五株桃。去年新种三株桃，今年春天种的数目加倍，两年间共新种九株桃。

## 单选：仅凭首句可确定哪项数量？ {#q.vocab.check.23.5}
考点：skill.vocab.9.2
语境：p.vocab.check.23.3

- [ ] 梨与桃共十五株 {#q.vocab.check.23.5.o1}
  理由：梨的零数未明。
- [x] 梨多于十株 {#q.vocab.check.23.5.o2}
- [ ] 梨正好十株 {#q.vocab.check.23.5.o3}
  理由：数后有“余”。

提示：数词之后、单位之前的余表示超过那个整数。
解析：“十余株”有确定的下界，没有确数。

## 单选：为什么两年“凡植桃九株”？ {#q.vocab.check.23.6}
考点：skill.vocab.9.3
语境：p.vocab.check.23.3

- [ ] 去年六株今年三株 {#q.vocab.check.23.6.o1}
  理由：“今春倍之”是今年数量加倍。
- [ ] 每年各九株 {#q.vocab.check.23.6.o2}
  理由：“凡”领两年总数。
- [x] 去年三株，今年六株 {#q.vocab.check.23.6.o3}

提示：先找原数，再与新数相对。
解析：“之”指去岁三株，今年倍植六株，共九株。
