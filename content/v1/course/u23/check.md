# 检查：修书人的日程与账目 {#check.23}

## 原文：教学例句 {#p.vocab.check.23.new1}
> 旧书肆修残卷。客来时，工方补纸，案上浆犹湿。工曰：“吾尝为人补此书，识其行次。”
译文：旧书铺修补残卷。客人来时，匠人正在补纸，桌上的浆糊还湿着。他说自己过去替人补过这部书，知道文字行列的次序。
词注：书肆：书铺
  案：桌案。

## 找原文证据：哪四个字直接写客人进店那会儿匠人的活还在做？ {#q.vocab.check.23.new1}
考点：skill.vocab.7.4
语境：p.vocab.check.23.new1

- [ ] 识其行次 {#q.vocab.check.23.new1.o1}
  理由：这是匠人所知，并不是他当时正在做的工序。
- [x] 工方补纸 {#q.vocab.check.23.new1.o2}
- [ ] 客来时 {#q.vocab.check.23.new1.o3}
  理由：这个短语只交代观察的时间，没写手头的活。

提示：留意哪个短语能换成“正在……”。
解析：“客来时”定下观察的时刻，“方”把补纸放在进行中，“浆犹湿”也和眼前情形相合。

## 单选：凭“吾尝为人补此书”，能知道工匠什么经历？ {#q.vocab.check.23.new2}
考点：skill.vocab.7.2
语境：p.vocab.check.23.new1

- [ ] 一直在这家铺子修同一卷书，从未中断 {#q.vocab.check.23.new2.o1}
  理由：“尝”只说过去有这件事，推不出持续时间。
- [ ] 他今天第一次碰到这部书 {#q.vocab.check.23.new2.o2}
  理由：“识其行次”的由来就是过去补过。
- [x] 以往修补过这部书，所以熟悉行次 {#q.vocab.check.23.new2.o3}

提示：“吾尝”领起的是今天的新动作还是以往的事？
解析：他拿先前做过的事解释自己为何认得行次。译成“曾经”就足够了。

## 原文：教学例句 {#p.vocab.check.23.new2}
> 纸既干，工命徒取函。徒入内，俄而持函出；工纳卷，旋闭其盖。
译文：纸干了，匠人让学徒去取书匣。学徒进屋，没过多久便拿着匣子出来。匠人装进书卷，随即合上匣盖。
词注：函：匣子
  纳：放入。

## 单选：“俄而”量的是哪一段时间？ {#q.vocab.check.23.new3}
考点：skill.vocab.8.1
语境：p.vocab.check.23.new2

- [x] 学徒进屋到拿匣出来之间 {#q.vocab.check.23.new3.o1}
- [ ] 纸从湿到干之间 {#q.vocab.check.23.new3.o2}
  理由：纸已干以后，工匠才让学徒去拿匣。
- [ ] 书从写成到今天修好之间 {#q.vocab.check.23.new3.o3}
  理由：这句的两端都是学徒眼前的动作。

提示：分别找“俄而”之前和之后学徒做的事。
解析：“入内”与“持函出”前后相接，只能读出相隔不久，不能算出具体用了几刻。

## 排序：依次排出书匣里有书以前和以后的动作。 {#q.vocab.check.23.new4}
考点：skill.vocab.8.2
语境：p.vocab.check.23.new2

- [3] 匠人随即把盖子合上 {#q.vocab.check.23.new4.o1}
  理由：“旋闭其盖”紧接装书，不是再去取盖。
- [1] 学徒把匣子送到 {#q.vocab.check.23.new4.o2}
  理由：先有拿来的匣子，才谈得上装书。
- [2] 匠人把书卷装进去 {#q.vocab.check.23.new4.o3}
  理由：“工纳卷”承接学徒送匣。

提示：“旋”放在闭盖以前，接的是谁刚做完的动作？
解析：“旋”表示合盖紧接装卷；三步虽挨得近，原文仍写出了先后。

## 原文：教学例句 {#p.vocab.check.23.new3}
> 肆中计纸，白者十二卷，黄者八卷，凡二十卷。又有残纸十余叶，别贮之。
译文：铺里清点纸张，白纸十二卷，黄纸八卷，合计二十卷。另有残纸十多张，另外存放。
词注：叶：此处指一张纸
  贮：存放。

## 单选：二十卷是白纸的数目，还是怎样得来的？ {#q.vocab.check.23.new5}
考点：skill.vocab.9.1
语境：p.vocab.check.23.new3

- [ ] 白纸以外还有整整二十卷黄纸 {#q.vocab.check.23.new5.o1}
  理由：黄纸数已经明说是八卷。
- [ ] 连残纸也算在内，共二十卷 {#q.vocab.check.23.new5.o2}
  理由：“又有”“别贮”把残纸另外列出，且以叶计。
- [x] 白纸十二卷与黄纸八卷相加的总数 {#q.vocab.check.23.new5.o3}

提示：看“凡”前面紧挨着哪两项，又如何相加。
解析：“凡”总括同一笔账中的白纸、黄纸，不能把后面另存的零张混入。

## 单选：若有人把“残纸十余叶”抄成“恰有十叶”，漏了什么？ {#q.vocab.check.23.new6}
考点：skill.vocab.9.2
语境：p.vocab.check.23.new3

- [x] 十叶之外还有零数，但没说确数 {#q.vocab.check.23.new6.o1}
- [ ] 十叶已全数用完 {#q.vocab.check.23.new6.o2}
  理由：“别贮之”说明另外存着，不能推出用完。
- [ ] 残纸正好比整纸多十叶 {#q.vocab.check.23.new6.o3}
  理由：“余”跟在数词后，不是在比较两笔账。

提示：看“余”前有没有一个作为基数的“十”。
解析：“十余叶”是十多叶。原文没给出余下的数，不能据此写成恰好十叶。
