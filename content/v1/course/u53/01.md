## 正文

读“事父母”，先问处在“事”前后的是哪两方。再读下面两段，把想做、获准、已经做三类事情分开。一位学生请归，老师许了；一位书手被举，县里还没有发召。都写到人快要动身，凭据却不同。

## 原文：古籍引文 {#rv53.1.p1}
> 子曰：“事父母几谏，见志不从，又敬不违，劳而不怨。”
译文：孔子说：“侍奉父母，劝谏时要委婉。见他们不肯采纳，仍怀敬意、不忤逆，即使辛劳也不抱怨。”
词注：几谏：委婉地劝谏。几读 jī。
出处：《论语·里仁》节录
作者：孔子弟子及再传弟子编录

## 原文：教学例句 {#rv53.1.p2}
> 陈生学于郡，家书久不至。生谓师曰：“愿暂归，问书不至之故。使人代问，不如身往也。”师许之。
译文：陈生在郡里求学，很久没收到家信。他对老师说：“我想暂时回家，打听收不到信的缘故。派人代问，比不上自己去。”老师答应了。
词注：身往：自己亲自去。

## 原文：教学例句 {#rv53.1.p3}
> 县求能校书者，乡人举梁生。使者未至，生闻而喜，遽束装。父问：“有召书乎？”曰：“未也。”乃已其行，衣囊犹置堂上。
译文：县里物色能校书的人，乡人推荐梁生。使者还没到，梁生听说后很高兴，赶忙收拾行装。父亲问：“有召你去的文书吗？”回答：“还没有。”他便取消了这趟出行，衣袋还搁在堂上。
词注：召书：召人前往的文书。

## 单选：有人把“事父母”翻成“谈论父母的事”。下文哪种关系反倒因此说不清？ {#rv53.1.q1}
考点：x36.s.serve
语境：rv53.1.p1

- [ ] 父母受命替子女把几件公事办完
  理由：“见志不从”说劝谏没有被接受，未写父母派差办公。
- [ ] 乡里外人替父母指责子女不敬
  理由：“事父母”的一方正是劝谏的人，原文没请外人责备。
- [x] 子女原在侍奉父母，劝谏后仍要以敬意相待

提示：把“事”看作动作，接着问“几谏”的人会向谁开口。
解析：“事”在此是侍奉。父母是受侍奉、也可能受到子女委婉劝谏的人。

## 单选：将“生谓师曰”改写成“老师劝陈生回家”，会同哪一句明显抵牾？ {#rv53.1.q2}
考点：x36.s.tell
语境：rv53.1.p2

- [ ] “陈生学于郡”说明老师也住陈家
  理由：在郡求学的是陈生，并未写老师住在哪里。
- [x] 末尾“师许之”，表示老师应允学生的请求
- [ ] “家书久不至”说明家里已回话同意
  理由：久不至恰是没收到回信，无法得知家人的意见。

提示：“生谓师”先定谁在开口，再找“愿”的主人。
解析：陈生对老师说出自己的打算，老师听后应允。把说与听调换，请求便无从安放。

## 单选：陈生想“问书不至之故”。他动身前知道哪一层，还要打听哪一层？ {#rv53.1.q3}
考点：x36.s.cause
语境：rv53.1.p2

- [x] 知道信久未到，还不知为何未到
- [ ] 已经知道送信人故意扣信，只要去追责
  理由：“之故”是想查的缘由，原文未给出扣信者。
- [ ] 知道信里写的是旧事，打算重问一遍
  理由：连信都没收到，不能先断定信里写了什么。

提示：在“问”后补一句完整的问题。
解析：陈生要问“为什么这么久没有信”。“故”指原因，并非已经把过错判给某个人。

## 单选：陈生提了两个打听消息的办法。他把哪一个看得更好？ {#rv53.1.q4}
考点：x36.s.compare
语境：rv53.1.p2

- [ ] 派人去比自己亲往好，他只须等回报
  理由：“使人代问”在“不如”的前一边，是被说成不及的办法。
- [ ] 先派人去，再按来信告诉他的路线前往
  理由：“不如”在比较，不交代两趟先后执行的行程。
- [x] 自己回家，比央人代问更好

提示：把“不如”换成“比不上”，留住前后两项的位置。
解析：“使人代问”不及“身往”，这番比较正解释了他为什么要请假回家。

## 单选：“愿暂归”能写成“陈生已返家”吗？ {#rv53.1.q5}
考点：x36.s.home
语境：rv53.1.p2

- [ ] 能。师生本在陈家，老师说话时他已到了
  理由：首句说陈生在郡求学，回家正是他的请求。
- [x] 不能。他请求回自己家，篇末只写老师应允
- [ ] 不能。“归”在这里是要把家信退给寄件人
  理由：“归”的是陈生本人；信尚未至，手里没有可退的信。

提示：先给“归”找出行的人，再给“愿”留出余地。
解析：陈生要回的是自己的家。“许之”让他可以回去，没有接写到家的情形。

## 单选：官吏若只凭“乡人举梁生”，该把梁生的名字写进哪份记录？ {#rv53.1.q6}
考点：skill.h28.1.ju-recommend
语境：rv53.1.p3

- [x] 乡里推荐的校书人选
- [ ] 县里已经授职的校书人名单
  理由：县里正在求才，文末仍无召书，更未写授职。
- [ ] 从县里辞职回乡的人名册
  理由：行装刚束好，还没动身去县里。

提示：看看举他的人和将来能够任用他的人是不是同一方。
解析：推荐来自乡人；县里是否任用是下一步。只据一个“举”就登记到任，会早记一层。

## 单选：“遽束装”最能看出，梁生来不及先核实什么就行动了？ {#rv53.1.q7}
考点：skill.h29.2.ju-hurry
语境：rv53.1.p3

- [ ] 尚未得到父亲回信，便命使者立刻出门
  理由：父亲当面发问，文中也未写梁生差遣使者。
- [ ] 不知道住处会不会失火，所以上堂抢救衣物
  理由：“闻而喜”接着收拾，缘由是听说被举。
- [x] 尚未确定县里有召书，便急忙收拾衣囊

提示：把父亲后来问的事同梁生较早做的动作对看。
解析：“遽”落在束装上，写他核实之前的急切；不是说他已急速赶到县城。

## 单选：句末“乃已其行”后特意把衣囊留在堂上，是要让人看出什么？ {#rv53.1.q8}
考点：x36.s.stop
语境：rv53.1.p3

- [ ] 已经完成出差，归来后才把包放在家里
  理由：“未也”刚说明未得召书，这里没有外出办完事的经过。
- [x] 原打算走的这一趟停下来，行装没有被带走
- [ ] 从此失去被荐的资格，不得再次报名
  理由：停了的是“其行”，乡人的推荐未说已被取消。

提示：把“行”当作“已”所停止的那件事。
解析：“已”在这里能带“其行”，意思是停下出行。末尾静置的衣囊与这一读法相合。
