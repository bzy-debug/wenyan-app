## 正文

《子路》引一句旧话，想的是为政者积百年之功，能给一国带来什么变化。换到渡口，眼前几步的区别也要细读：在岸上面对河水，乘舟渡河，这两件事之间还隔着等船的工夫。读最后一段，试着把亲眼所见和听人转报分开。

## 原文：古籍引文 {#rv53.3.p1}
> 子曰：“‘善人为邦百年，亦可以胜残去杀矣。’诚哉是言也！”
译文：孔子说：“‘善人治理一个国家一百年，也可以感化残暴的人，免用杀刑了。’这话真说得对呀！”
词注：为：这里指治理。
出处：《论语·子路》节录

## 原文：教学例句 {#rv53.3.p2}
> 河暴涨，城外之野尽为泽。里人将往对岸迎其亲，暮临河而止，隔水见灯。旦，舟至，乃济。
译文：河水猛涨，城外的田野尽成了水泽。一名乡人想去对岸接亲人，傍晚走到河边停下，隔水看见灯火。早晨船来了，他才渡过去。
词注：泽：积水之地。

## 原文：教学例句 {#rv53.3.p3}
> 郡遣师助民完堤。取水之卒二人先至村舍，村老问：“师皆至乎？”一卒曰：“大队尚宿上津，旦乃至此。”
译文：郡里派军队来帮百姓修堤。两个来取水的士兵先到了村舍。村老问：“部队都到了吗？”一个士兵说：“大队人马还宿在上游渡口，明早才到这里。”
词注：完堤：修好堤岸。

## 原文：教学例句 {#rv53.3.p4}
> 囚亡，吏于西岸得其履，报曰：“囚绝河东矣。”舟人曰：“吾见其沿岸走，未见其渡也。”暮，囚见获于西岸。
译文：囚犯逃了。吏员在西岸捡到他的鞋，报告说：“囚犯已经渡河到东边了。”船夫说：“我看见他沿岸跑，没有看见他渡河。”傍晚，囚犯在西岸被抓到。
词注：履：鞋。

## 单选：“善人为邦百年”设想百年后什么地方可以“胜残去杀”？ {#rv53.3.q1}
考点：skill.h31.1.bang-state
语境：rv53.3.p1

- [ ] 善人独居的一座房子，百年之后不再杀牲
  理由：“为邦”说的是治理，“去杀”说施政的结果，没有提到家宅或杀牲。
- [x] 善人长久治理的一国，其政教渐渐见效
- [ ] 善人结交的一群朋友，彼此约定不再争论
  理由：上下文谈治国而论用刑，“邦”不能读成朋友组成的帮伙。

提示：看“为”所治理的范围，能在那里施政用刑的是谁？
解析：邦是一国。“百年”写为政日久，后面的“胜残去杀”才有了着落。

## 单选：“城外之野尽为泽”在这段水情里画出的受淹范围是哪一处？ {#rv53.3.q2}
考点：skill.h31.1.ye-countryside
语境：rv53.3.p2

- [x] 城外郊野，积水连成一片
- [ ] 城中所有街巷，已经只好行船
  理由：原文点明“城外”，没有说城里街巷也淹了。
- [ ] 远离一切村落、从无人烟的荒地
  理由：“野”在这里用城作界，说的是郊外，不能据此断定无人居住。

提示：先圈出“野”前面标位置的两个字。
解析：“城外之野”是城外的郊野。这句话交代水涨后的景象，没有替全城或所有村子报灾。

## 单选：“暮临河而止”时，这个乡人应当画在什么地方？ {#rv53.3.q3}
考点：skill.h30.1.lin-face
语境：rv53.3.p2

- [ ] 已在对岸亲人的家里，停步等人开门
  理由：“隔水见灯”说明他仍与灯火隔河。
- [ ] 正坐船行到河心，因为天黑停船
  理由：“旦，舟至”说明船到是在次日早晨。
- [x] 这一岸的河边，望见对岸灯火

提示：从“隔水”回头辨认“临河”的位置。
解析：临河是来到河边、面对河水。那夜他看得见对岸，还没坐上第二天才来的船。

## 单选：如果把“乃济”译成“他这才救了亲人”，会把原文哪一步说过了头？ {#rv53.3.q4}
考点：skill.h30.1.ji-cross
语境：rv53.3.p2

- [ ] 天亮他才抵达这边河岸，此前没到过水边
  理由：“暮临河而止”已经交代头天傍晚到这边河岸。
- [x] 船到后他才渡河，原文没有交代迎亲的结果
- [ ] 他把船借给亲人在东岸自救，自己未渡
  理由：“将往对岸”的乡人仍是“乃济”的主语，没有说亲人借到船。

提示：船来以前做不到、来了就能做的是什么事？
解析：这里的“济”是渡水。“将往”是目的，结尾只写坐船过河，不能据此添出接到亲人的经过。

## 单选：村老发问时，面前已经有几位怎样的人？ {#rv53.3.q5}
考点：skill.h30.2.zu-soldier
语境：rv53.3.p3

- [x] 两名先来取水的士兵，后来其中一人答话
- [ ] 两位带队将领，告诉村老全军都在屋内
  理由：原文称他们为“卒”，答话者又说大队尚在上游。
- [ ] 两位当地修堤的村民，在替外来的军队传话
  理由：“郡遣师”下面说“取水之卒”，把两人列在前来的军士之中。

提示：对着读“卒二人”和“一卒曰”。
解析：“卒”指士兵。“二人”数的是先到的士兵，“一卒”是其中一位开口作答。

## 单选：如果村老听到“师”字就去找一位教书先生，他会误解村里在等谁？ {#rv53.3.q6}
考点：skill.h30.2.shi-army
语境：rv53.3.p3

- [ ] 已在村舍歇脚的两个人，此行只有他们二位
  理由：“大队尚宿上津”明说还有人在路上。
- [ ] 主持修堤的村老，他带本村学生一起取水
  理由：村老是在问“师皆至乎”的人，军队是由郡里派来的。
- [x] 郡里派来帮忙修堤的军队，大队人马尚未到村

提示：把开头的“郡遣师”与结尾的“大队”连起来。
解析：“师”指军队。先到的两名士兵也在这支队伍中，但见到他们，还不能说整支队伍都到了。

## 单选：若把开头两字“囚亡”记作“囚犯死亡”，会与后面哪件事冲突？ {#rv53.3.q7}
考点：skill.h30.3.wang-flee
语境：rv53.3.p4

- [ ] 吏员捡到一只鞋，因此已经认出了尸体
  理由：吏员拾到的是鞋，原文没说找到尸体。
- [x] 傍晚囚犯被捕，前面说的是逃脱羁押
- [ ] 船夫声称亲眼见他溺水，所以不能说死在岸上
  理由：船夫只说见他沿岸跑，未见他渡水，更没见他溺水。

提示：找出句末“见获”的人，和开头的“囚”对照。
解析：“亡”说逃走。追问他有没有过河、后来又抓到他，都是逃走之后才会有的事。

## 单选：“囚绝河东矣”比船夫的证词多作了哪一步判断？ {#rv53.3.q8}
考点：skill.h30.3.jue-cross
语境：rv53.3.p4

- [x] 吏员断言囚犯已横渡到东岸，船夫只见他沿岸跑
- [ ] 吏员断言河道已经断流，船夫却亲眼看见水涨
  理由：“绝河”的是囚犯，原句没有说河本身断了。
- [ ] 船夫看见囚犯登上东岸，吏员却不信他过河
  理由：船夫说的是“未见其渡”，不能改成亲眼见他登岸。

提示：把“绝河”同船夫说的“沿岸走”画成两条方向不同的线。
解析：“绝河”是横渡。西岸拾到一只鞋不能证实人已过到东岸；他后来在西岸被捕，也未给出其间的完整行踪。
