# 检查：一册县志，两种传闻 {#check.53}

## 原文：教学例句 {#rv53.check.p1}
> 县求能织者教里中女。有荐林媪者，书吏遽书“媪至”。令问：“未见其人，何以书至？”使人候之。使者归，言未至之故：“前溪桥坏，媪候舟耳。”
译文：县里找擅长织布的人教乡里的女子。有人推荐林婆婆，书吏急忙记下“林婆婆到了”。县令问：“人还没见到，凭什么记作已到？”便派人去等。使者回来，说了她还没到的缘故：“前溪的桥坏了，婆婆在等船呢。”
词注：媪：年长的妇女。

## 原文：教学例句 {#rv53.check.p2}
> 纪河工者书：“迁东仓吏何生为津吏，故津吏胡生以私取舟直黜。师至南岸，遣二人绝江，问北岸所须；余皆留。”后人据此谓“军尽在北”，误也。
译文：记河工的人写道：“将东仓的吏员何生调任渡口；原来的渡口吏员胡生因为私取船钱被罢退。军队到了南岸，派两人横渡大江去问北岸需要什么；其余人都留下。”后来有人据此说“全军都在北岸”，说错了。
词注：舟直：船钱。

## 单选：抄录使者的话时，“未至之故”下面该写什么？ {#rv53.check.q1}
考点：x36.s.cause
语境：rv53.check.p1

- [ ] 书吏曾误记林媪已经到了
  理由：这是县令追问书吏的缘由，没有解释林媪为什么没来。
- [x] 桥坏了，林媪还在等船
- [ ] 乡人向县里推荐了会织布的林媪
  理由：推荐说清了县里为什么请她，却没有说她为什么耽搁。

提示：要回答的是“为什么还没来”，看使者回来后亲口说了什么。
解析：“未至之故”是未到的原因。桥断、候舟连在一起，才是使者给出的答复。

## 单选：“书吏遽书‘媪至’”写出了哪两件事之间没留出查问的工夫？ {#rv53.check.q2}
考点：skill.h29.2.ju-hurry
语境：rv53.check.p1

- [x] 听说有人荐林媪，书吏就急着写她到了
- [ ] 林媪等到船，书吏立即为她登记船钱
  理由：使者后来仍报“候舟”，书吏更没有经手船钱。
- [ ] 县令看见林媪进门，书吏才赶快补上记录
  理由：县令反问“未见其人”，恰好说明何以不能记作已到。

提示：“遽”落在哪个动作上？这个动作发生在县令问话前还是问话后？
解析：书吏从听到有人推荐，径直跳到写“已到”。“遽”写的是下笔仓促，不是林媪赶路快。

## 单选：若要补全何生的前后职事，依“迁东仓吏何生为津吏”该怎么写？ {#rv53.check.q3}
考点：skill.h28.2.qian-transfer
语境：rv53.check.p2

- [ ] 先在渡口收船钱，因私取钱而改去东仓
  理由：私取舟直的是胡生；“为津吏”也不是调回仓里。
- [ ] 原来兼管东仓与渡口，后来只管东仓
  理由：“东仓吏何生”告诉读者原职，“为津吏”才是改任的去处。
- [x] 先任东仓吏，后调任渡口的吏员

提示：“迁”后跟着人的原职和姓名，留心“为”所引出的新职。
解析：何生原在东仓，后来调到渡口。记事人用“迁”交代职务变更，没有写他受处分。

## 单选：胡生也离开了原来的岗位，他和何生的情形有何不同？ {#rv53.check.q4}
考点：skill.h28.3.chu-dismiss
语境：rv53.check.p2

- [ ] 胡生只是轮班暂歇，何生才是被处分的人
  理由：“以私取舟直黜”紧接胡生，受处分的就是他。
- [x] 胡生因私取船钱被罢退，何生另有新任
- [ ] 二人因同一件贪财的事被一同逐出渡口
  理由：何生正调来当津吏，原文也没有说他私取舟直。

提示：对照前面的“迁……为”和后面的“以……黜”。
解析：“黜”说罢退。原因只写在胡生名下；何生从东仓调来，不能把前任的罪过算给他。

## 单选：读到“师至南岸”，军队的行程先有哪一点可以确定？ {#rv53.check.q5}
考点：skill.h30.2.shi-army
语境：rv53.check.p2

- [x] 军队到过南岸，此后只有被派出的两人去北岸询问
- [ ] 整支军队都已经到北岸，两人留在南岸看守
  理由：“遣二人绝江”是派两人过江，“余皆留”说其余人均未跟去。
- [ ] 一位教书人到了南岸，带弟子去问北岸缺什么
  理由：末句说“军”，上文也写分派人手；“师”是参与河工的军队。

提示：“师”“军”指向同一群人，再看“二人”占了多少。
解析：这里的“师”交代整支军队的到达地点。派出两人并不等于全军换了岸。

## 单选：把后来附会的“军尽在北”划掉，只保留“绝江”能支持的行程，应当怎么记？ {#rv53.check.q6}
考点：skill.h30.3.jue-cross
语境：rv53.check.p2

- [ ] 众军截断了江面航路，两人留在原地指挥
  理由：“绝江”的人是受派的两人；横渡有明确的另一岸。
- [ ] 两人沿南岸去看水势，还没有向北岸出发
  理由：“问北岸所须”紧接“绝江”，要过江才去得了对岸。
- [x] 奉派的两人从南岸横渡去问北岸需要什么，其余人仍留在南岸

提示：在“绝江”前面标出人数，在后面标出所去的地方。
解析：“绝”写横过江面。这条记录把派去的两人和留下的人分得很清楚，不能把一部分人的行程抄到全军名下。
