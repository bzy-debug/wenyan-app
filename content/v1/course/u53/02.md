## 正文

《先进》这段要留心谁在说话。子路派子羔做费邑的长官，孔子不赞成，出来辩解的仍是子路。下面几段又换了问题：前任为何离职，新任管到了哪些事？任官、免官和分派差事不能混成一笔。

## 原文：古籍引文 {#rv53.2.p1}
> 子路使子羔为费宰。子曰：“贼夫人之子。”子路曰：“有民人焉，有社稷焉，何必读书，然后为学？”子曰：“是故恶夫佞者。”
译文：子路让子羔做费邑的长官。孔子说：“这是害了人家的孩子。”子路说：“那里有百姓，也有社稷，何必只有读书才算学习？”孔子说：“所以我厌恶那种巧言强辩的人。”
词注：佞：这里指善于以巧言强辩。

## 原文：教学例句 {#rv53.2.p2}
> 杨生旧掌县门，岁终迁为仓吏。前仓吏周生以失簿罢。杨既典仓簿，市租犹属他吏。
译文：杨生原管县门，年终调任仓吏。前任仓吏周生因为遗失账册被免职。杨生接管了粮仓的账册，集市上的税收仍由别的吏员负责。
词注：仓簿：粮仓的账册。

## 原文：教学例句 {#rv53.2.p3}
> 市有二吏，同校斗斛。甲私其亲，长吏黜之，命乙独任其事。乙善辨斗斛大小，取官斛相比，果有不合者。
译文：市场里两名吏员一起校验量器。甲偏袒亲属，长官便罢退甲，命乙独自担任。乙擅长辨别量器的容量，拿官定量器一比，果然有容量不合的。
词注：斗斛：用来量粮的容器。

## 原文：教学例句 {#rv53.2.p4}
> 仓旧自东门受粟。使者晨至，见众皆候于西门，异之。问之，乃知东廊方修。少顷，两吏各召一列先入，众不知所从，行始乱。
译文：粮仓一向从东门收粮。使者早晨来，见众人都在西门等，觉得奇怪。一问才知东廊正在修。过了一会儿，两名吏员各叫一排人先进，众人不知道该听谁的，队列这才乱起来。
词注：行：这里读 háng，指队列。

## 单选：费邑的百姓、子羔和善辩的人都在这段话里。孔子说“恶”时，明确指向哪一方？ {#rv53.2.q1}
考点：x37.wu-dislike
语境：rv53.2.p1

- [x] 指向“佞者”，厌恶的是强词辩解的做派
- [ ] 指向子羔，断定他生性恶劣，不能为学
  理由：孔子说任命会害了子羔；末句紧接子路辩解，点出的是“佞者”。
- [ ] 指向费邑百姓，认为他们使学习变得困难
  理由：“有民人焉”是子路为任命辩解时说的话，不是孔子责怪百姓。

提示：留心末句“恶”后面紧接着的几个字。
解析：这里“恶”读 wù，表示厌恶。子路拿治理百姓也算学习来回答，孔子批评的是这番巧辩。

## 单选：“岁终迁为仓吏”应怎样记进杨生的履历？ {#rv53.2.q2}
考点：skill.h28.2.qian-transfer
语境：rv53.2.p2

- [ ] 年底搬家到仓边，仍照旧看管县门
  理由：“为仓吏”明说换了职事，住处倒没有写。
- [ ] 年底因遗失仓簿被免去仓吏一职
  理由：“以失簿罢”的是周生，不能挪到杨生名下。
- [x] 年底从掌县门改任仓吏，职位高低未说明

提示：把“旧掌”与“迁为”分列，看看名字换了没有。
解析：前后都是杨生：原掌县门，后来改任仓吏。“迁”交代调职，单凭这条记事分不出升降。

## 单选：要查“哪位吏员因何离职”，该从“前仓吏周生以失簿罢”摘出哪条记录？ {#rv53.2.q3}
考点：skill.h28.2.ba-remove
语境：rv53.2.p2

- [ ] 杨生丢失账册，周生奉命暂时代管
  理由：“以失簿罢”前写着周生；杨生是接任者。
- [x] 周生丢失账册，因而被免去仓吏的职务
- [ ] 周生找到失簿，仓里的清查才宣告结束
  理由：“罢”的是前仓吏周生，没有写找回账册或停止清查。

提示：“以失簿”解释紧接着的“罢”。
解析：周生先前管仓，因为失簿而去职；杨生后来接任。这里“罢”是免职。

## 单选：交接以后，有人来核对粮仓账册，又来问集市交了多少租。按“杨既典仓簿”，哪一件归杨生负责？ {#rv53.2.q4}
考点：skill.h28.3.dian-manage
语境：rv53.2.p2

- [x] 仓簿归他掌管，市租仍须问别的吏员
- [ ] 两件都归他，因为仓簿包括县里所有的收支
  理由：文末明说“市租犹属他吏”，不能把市租也装进仓簿。
- [ ] 两件都不归他；他只把仓簿当典籍来读
  理由：“迁为仓吏”后说“典仓簿”，交代接手的差事，并非阅读书目。

提示：认清“典”的对象，再看“犹属”把什么事留给别人。
解析：“典”是主管，所管的是仓簿。作者还特意说市租归别人，划清了杨生的职责。

## 单选：甲被“黜”之后，原来两人一起校量器的差事怎么办？ {#rv53.2.q5}
考点：skill.h28.3.chu-dismiss
语境：rv53.2.p3

- [ ] 甲降职留在原处，乙专管给他定罪
  理由：“命乙独任其事”里的“独”排除了两人仍一同校验。
- [ ] 甲乙一并辞退，新来的吏员带来了官斛
  理由：取官斛校比的是乙，说明他仍在做这件事。
- [x] 甲退出，长吏让乙独自接着做

提示：先找“黜之”的“之”，再看“独任”的是谁。
解析：被罢退的是徇私的甲。乙继续任事，故“黜”不能把两人都算进去。

## 单选：凭哪件事能把“乙善辨斗斛大小”译成乙有一门本领？ {#rv53.2.q6}
考点：x37.shan-skilled
语境：rv53.2.p3

- [ ] 他不曾偏袒亲属，因此必定生性善良
  理由：徇私的明写是甲；乙如何校验，才说明“善辨”的本领。
- [x] 他取官斛比对，确实辨出容量不合的量器
- [ ] 长吏称赞量器制得好，没有叫人再查
  理由：乙亲自取官斛相比，原文没有长吏称赞量器的话。

提示：把“善辨”后面的实际动作找出来。
解析：“善”后面连着“辨斗斛大小”，说他擅长分辨。拿官斛作准，便可看出他如何做这件事。

## 单选：使者“异之”，他此时知道什么，又还不知道什么？ {#rv53.2.q7}
考点：skill.h31.2.yi-find-strange
语境：rv53.2.p4

- [x] 看见大家在西门等，觉得反常，尚不知东廊在修
- [ ] 事先知道修廊，便特意命人改在西门等
  理由：“问之，乃知”说明修廊是问过才知道的。
- [ ] 已经看见两吏争执，认定他们故意扰乱队伍
  理由：两吏各召一列是“少顷”以后的事，不能用来解释当时为何惊异。

提示：把“旧自东门”同使者眼前所见并排读。
解析：平日走东门，眼前却都等在西门。“异之”是使者对眼前情形感到奇怪，并非已经看出了原委。

## 单选：在“行始乱”以前，哪一个变化使人群失去了原先的次序？ {#rv53.2.q8}
考点：skill.h31.2.luan-disorder
语境：rv53.2.p4

- [ ] 仓廊一动工，来交粮的百姓立即起事反叛
  理由：修廊解释的是换门；动乱或反叛在这段话中都没有根据。
- [ ] 使者一到便遣散队伍，西门再也不准收粮
  理由：使者只是询问，稍后仍有两名吏员招呼人入内。
- [x] 两名吏员各叫一排人先进，大伙不知道听谁的

提示：找“始”所标出的那一刻，读它前面的“各”与“不知”。
解析：“乱”说队列失去秩序。地点的改变发生得早，两道相冲的招呼才让人不知如何排队。
