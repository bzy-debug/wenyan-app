# 课文：花鸟起头，诗究竟在说谁 {#prose45.1}
简介：从花开、虫鸣转到人的婚嫁和思念，再看一个“如”字怎样把两件不同的事放到一起。

## 正文

“桃之夭夭，灼灼其华”让人先看见盛开的桃花。唱到“之子于归”，才知道这首歌要为出嫁的女子祝福。这样先从别的事物唱起，叫起兴。它不要求一片花瓣就代表一个具体的人。

诗若说“泣涕如雨”，则是借雨势写泪多。读这种比喻，试问“谁像什么，像在哪儿”。比和兴可以同在一章，“先唱了什么”与“拿什么比什么”得分别从诗句里找。

## 知识点：从章首景物转入所咏的人事 {#prose45.xing}
义项：指出景物以后真正被歌咏的人事
领域：篇章
要诀：接读景物之后的头一件人事。
讲解：诗人用飞鸟起兴，接着写出门送人。若只说这篇写鸟，就没说到送别；至于鸟怎样引起联想，要看下文，未必一一对应。
例句：prose45.ex.xing

## 原文：教学例句 {#prose45.ex.xing}
> 谷鸟鸣春晓，行人今日归。
译文：清晨山谷里鸟鸣，远行的人今天归来。

## 知识点：从比喻读出两端及共同之处 {#prose45.simile}
义项：区分被描写的人物、所借事物和相似点
领域：篇章
要诀：尝试说全“用什么形容什么”。
讲解：说“孤舟如叶”，借叶写船小而轻；不能拿这句话断定船是用树叶做成的。
例句：prose45.ex.simile

## 原文：教学例句 {#prose45.ex.simile}
> 客散如秋叶，庭中一席空。
译文：客人们像秋叶般飘散，庭中留下一处空座。

## 单选：若只把这章题作“园里开了桃花”，漏掉了歌声最后向谁、为哪件事送祝愿？ {#prose45.1.q1}
考点：prose45.xing
语境：prose45.1.p.peach

- [ ] 向游子祝愿他早日回到桃园
  理由：“于归”在此写女子出嫁，不是重回果园。
- [x] 向出嫁的女子祝愿家庭和美
- [ ] 向种桃的人祝愿收成多
  理由：本章从“华”转到“之子于归”，没有写种植者。

提示：花句后“之子”开始说到什么人？
解析：桃花领起了婚嫁的喜气，接下两句才说祝的是谁、愿她怎样。

## 单选：有人逐字解释“树是父亲，花是女儿”。这章本身支持到哪一步？ {#prose45.1.q2}
考点：prose45.xing
语境：prose45.1.p.peach

- [ ] 父女关系已明说，只是没有写母亲
  理由：这一章并未写父亲或母亲。
- [ ] 既然不能逐一配人，开头就同婚嫁毫无关系
  理由：鲜明的花与下文祝愿同在一章，开头可以引起人事。
- [x] 能看出花景引向婚嫁祝辞，没有给树和花各派一个家庭角色

提示：区分诗写出的转接和读者自加的对应。
解析：抓得到起兴的方向，不等于每处景物都必须对应一位亲属。

## 找原文证据：虫鸣虫跳之后，哪句最先把歌声带到人的离思？ {#prose45.1.q3}
考点：prose45.xing
语境：prose45.1.p.insects

- [x] 未见君子，忧心忡忡
- [ ] 喓喓草虫
  理由：这还是开章所闻的虫声。
- [ ] 我心则降
  理由：这是往下设想见面以后心情平复，转入人事处还在前面。

提示：找第一处说到所思之人以及心情的字。
解析：前两小句都在写虫。“未见君子”接出人事，听者于是明白接下来要说谁的忧心。

## 单选：若删去虫鸣虫跳以后所有的句子，只能留下怎样的读法？ {#prose45.1.q4}
考点：prose45.xing
语境：prose45.1.p.insects

- [ ] 歌者只是害怕虫子，虫子走了就会放心
  理由：原诗将心安系于相见，而未说害怕虫子。
- [ ] 仍可从“草虫”二字推断思念的人何日回家
  理由：归期在整章也没有交代。
- [x] 能听见、看见虫子；不能仅凭这些字确定歌者为何忧、何时心安

提示：让“我心则降”回到它自己的前一句。
解析：人的忧与安靠“未见”“既见”说清。开头引兴，不能独自替代后面的歌辞。

## 原文：古籍引文 {#prose45.1.p.cloud}
> 出其东门，有女如云。虽则如云，匪我思存。缟衣綦巾，聊乐我员。
译文：走出东门，女子多得像云一般。虽然如此众多，却不是我心里惦念的人。那位着白衣、戴暗绿色巾的人，才能让我欢喜。

## 单选：“有女如云”之后却说“匪我思存”。若把“如云”换成白话，该保留哪一层？ {#prose45.1.q5}
考点：prose45.simile
语境：prose45.1.p.cloud

- [ ] 心里所思的人像云一样已从东门消失
  理由：“如云”紧跟“有女”，说眼前的许多人。
- [x] 出门所见女子众多，多也不能使说话者改换所思
- [ ] 女子全穿和云一样的白衣，所以彼此认不出
  理由：白衣在末句用来写特定的一人，未说全都穿白。

提示：分清眼前的“有女”和心里的“我思”。
解析：众多女子与特意惦念的一人构成对照。云所帮助描写的是人多，并没有把所思之人写走。

## 找原文证据：说话者并没有因“如云”而改变心意，原文哪一句直接把眼前众人和所思之人分开？ {#prose45.1.q6}
考点：prose45.simile
语境：prose45.1.p.cloud

- [x] 匪我思存
- [ ] 有女如云
  理由：这是说眼前所见的众多女子，还没交代心里所思。
- [ ] 出其东门
  理由：这只交代人从哪里走出来。

提示：找否定“这些便是我所惦念的”那几个字。
解析：“虽则”让步，接“匪”才落出不同。若只取“如云”，看不到比喻在本章里为何有用。

## 单选：同是见女子，这里的“如”跟“有女如云”所说的相似处一样吗？ {#prose45.1.q7}
考点：prose45.simile
语境：prose45.1.p.compare

- [ ] 一样，都说明衣裳是从花朵和云制成的
  理由：“如”连接描写和所借之物，未说制作衣裳。
- [x] 不一样。“颜如舜华”借花写一人的面容，“有女如云”借云写人多
- [ ] 一样，都只计算路上有多少女子
  理由：“颜”将此句收在同车一人的容貌上。

提示：把紧靠“如”的主语各说一遍。
解析：一个是“颜”，一个承“有女”。比喻两端不同，便不能把上篇读出的“众多”搬过来。

## 单选：给这一章配画，画家把木槿画成孟姜手里确实握着的花。文字保证有这件事吗？ {#prose45.1.q8}
考点：prose45.simile
语境：prose45.1.p.compare

- [ ] 能，既写木槿又写佩玉，便都属于佩戴物
  理由：“佩”直接领“玉”，木槿却在“颜如”之后。
- [ ] 能，孟姜的名字就是这种花的别名
  理由：末句指人，词注所说的花另在“舜华”。
- [x] 不能保证。花用来形容容颜，诗只明写她身上佩玉

提示：比较哪一样接“如”，哪一样接“佩”。
解析：读比喻时可想见花，却不能据此增记“手持鲜花”的动作。
