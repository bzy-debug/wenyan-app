# 检查：送别的燕子，诗人的旧战场 {#check.45}

## 原文：古籍引文 {#check.45.p.swallow}
> 燕燕于飞，差池其羽。之子于归，远送于野。瞻望弗及，泣涕如雨。
译文：燕子飞翔，翅羽参差舒展。那人出嫁，我远远送到郊野。张望也看不到了，眼泪落得像雨一样。
出处：《诗经·邶风·燕燕》首章
版本：chinese-poetry 固定录文
底本链接：https://github.com/chinese-poetry/chinese-poetry/blob/b8594f81a89752241442f2ce267d6f66f96704ee/%E8%AF%97%E7%BB%8F/shijing.json#L281-L281
作者：佚名
原文权利：公版古籍正文节引，转为简体并标点。
译注权利：本项目编写今译、词注与题解。
词注：差池：这里写两翼舒展而参差的样子。
  瞻望：向远处看。
  弗及：望不及，看不见。

## 单选：从“燕燕于飞”循着这一章往下，真正让说话人落泪的是哪一件事？ {#check.45.q1}
考点：prose45.xing
语境：check.45.p.swallow

- [ ] 燕子飞得太远，送行者正为飞鸟迷路担心
  理由：“之子于归”以后已转到送人。
- [x] 远送出嫁的人，送到已望不见
- [ ] 郊外一场骤雨把鸟的两翼打湿
  理由：“如雨”在形容眼泪，未报一场真雨。

提示：哪一句由燕羽转入送别的人事？
解析：起于燕飞，接出人行。最后的眼泪要循送别、望不及这条线去读。

## 单选：若摄影者在末句拍一场真的大雨，会把哪两样读混？ {#check.45.q2}
考点：prose45.simile
语境：check.45.p.swallow

- [x] 把用来形容泪多的雨，当成郊外确实发生的天气
- [ ] 把远望的人当作出嫁者本人
  理由：这一处确有送者与行者之分，但“如雨”涉及的是泪落的情状。
- [ ] 把参差的燕羽当作远行人的斗笠
  理由：这里的比喻明写在“泣涕如雨”，并未说斗笠。

提示：把“如”前后各说一遍。
解析：落下的是送别者的泪，雨是借来让人想见泪多之物；现场是否下雨不能由比喻决定。

## 原文：古籍引文 {#check.45.p.post}
> 秦时明月汉时关，万里长征人未还。
译文：自秦汉以来的明月照着边关，远征万里的将士仍没有归还。
出处：《出塞》前两句
版本：chinese-poetry 固定录文
底本链接：https://github.com/chinese-poetry/chinese-poetry/blob/b8594f81a89752241442f2ce267d6f66f96704ee/%E5%85%A8%E5%94%90%E8%AF%97/%E5%94%90%E8%AF%97%E4%B8%89%E7%99%BE%E9%A6%96.json#L87-L87
作者：王昌龄
原文权利：公版古籍正文节引，转为简体并标点。
译注权利：本项目编写今译、词注与题解。
词注：关：边地关塞。
  还：归来。

## 单选：“秦时明月汉时关”写边地久远，为什么不宜把它断成“秦时有月无关、汉时有关无月”？ {#check.45.q3}
考点：prose45.mutual
语境：check.45.p.post

- [x] 两朝分说月和关，合读见秦汉以来边关戍守之久
- [ ] 下一句“人未还”说明戍卒曾亲历秦、汉两朝
  理由：绵延的是边地征戍，不是同一个人的寿数。
- [ ] “汉时”明说此刻又新修了一关，专门替代秦月
  理由：月与建筑不成这类取代关系，诗也没说新修。

提示：先看月和关能否同入一幅夜景。
解析：互文使秦汉与明月、关塞共同入意。下一句转到长期征戍之人迟迟未归。

## 原文：教学例句 {#check.45.p.market}
> 市雨初霁，布帆联岸，车盖接街；担夫相呼，估客相问，众声杂起。及鼓三通，负贩俱集。客曰：“吾方见一市之盛。”
译文：集市雨后初晴，布帆船沿岸相连，车辆在街上接连不断；挑担的人相呼应，商人互相问询，各种声音纷起。鼓敲了三遍，背货贩卖的人都聚了来。客人说：“我这才见到了整个集市的兴盛。”
词注：布帆：这里以帆指挂着布帆的船。
  车盖：这里以车上的盖指一辆辆车。
  估客：来往做买卖的商人。
  负贩：背着货物做买卖的人。

## 单选：把“布帆联岸，车盖接街”记作“各家把帆布和顶盖拆下来晾干”，会漏掉什么？ {#check.45.q4}
考点：prose45.metonym
语境：check.45.p.market

- [ ] 明说拆卸是雨后赶集的规定
  理由：文字只说雨停，不曾规定要拆帆卸盖。
- [x] 以帆和盖代船车，交代水陆两处往来、聚集的规模
- [ ] 所有船车都在鼓响后才到这里
  理由：先已写帆、盖相连，之后才有鼓声和负贩聚集。

提示：哪两类交通工具分别会沿岸和接街？
解析：以醒目的部分称整个交通工具，才能同岸、街、水陆来往的后文配合。

## 单选：写到客人说“一市之盛”以前，哪一种概括接得住前面的铺陈？ {#check.45.q5}
考点：prose45.catalog
语境：check.45.p.market

- [ ] 只写了一位客人的服饰行李，再由服装猜他富有
  理由：文中所列的船、车、人声分属整座市场。
- [ ] 鼓点取代了所有交易，集市其实已经散尽
  理由：鼓三通后正有“负贩俱集”。
- [x] 水陆所见、街市所闻和商贩聚来，共同写集市兴旺

提示：把布帆、车盖、呼问各放回一个场景。
解析：作者从船车写到众声，再写鼓后人聚。客人的感叹把这些侧面一起收起来。

## 原文：古籍引文 {#check.45.p.red}
> 折戟沉沙铁未销，自将磨洗认前朝。东风不与周郎便，铜雀春深锁二乔。
译文：折断的戟沉在沙中，铁还没有销蚀，我拿来磨洗，认出是前代的遗物。假如东风不曾给周瑜便利，二乔也许早在铜雀台中被锁过了春天。
出处：《赤壁》全诗
版本：chinese-poetry 固定录文
底本链接：https://github.com/chinese-poetry/chinese-poetry/blob/b8594f81a89752241442f2ce267d6f66f96704ee/%E5%85%A8%E5%94%90%E8%AF%97/%E5%94%90%E8%AF%97%E4%B8%89%E7%99%BE%E9%A6%96.json#L617-L618
作者：杜牧
原文权利：公版古籍正文节引，转为简体并标点。
译注权利：本项目编写今译、词注与题解。
词注：周郎：周瑜，曾与刘备一方联军在赤壁击败曹操。
  二乔：大乔、小乔，分别嫁孙策、周瑜。
  铜雀：铜雀台，此处用来设想曹操一方获胜的后果。

## 单选：诗借赤壁旧事写“铜雀春深锁二乔”，展签若写“二乔确曾在台中被囚”，该如何改？ {#check.45.q6}
考点：prose45.old
语境：check.45.p.red

- [x] 把它还原为失去东风之助后、另一种战局可能带来的结局
- [ ] 改成周瑜获胜以后亲自把二乔送进台中
  理由：“东风不与”先设一个改变胜负条件的前提。
- [ ] 改成杜牧亲眼见两人被带上台，之后才找折戟
  理由：前两句写眼前物，后二句转向旧战与设想。

提示：先读“东风不与周郎便”，再读其下设想。
解析：折戟引出赤壁旧事，诗人借设想来衡量东风的分量。想象中的结局不能当成既成史实。
