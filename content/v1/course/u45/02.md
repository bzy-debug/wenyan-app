# 课文：把半句话补回来，还是用一物称另一物 {#prose45.2}
简介：先把互文的两半合读，再顺着“管弦”“铁”问，在此处听到或用到的到底是什么。

## 正文

“烟笼寒水月笼沙”分两半写烟与月、水与沙，同一夜泊之景中烟雾与月色一同笼罩水岸。若把它硬切成“水上绝无月光、沙上绝无烟”，便从分写添出了排除。上下文分别说一部分，合起来才取得全意，叫互文。

“无管弦”遇到的却是另一回事。在送客饮酒的场面里，说没有管弦，是说没乐声助兴。不是从下一半句补回字，而是由乐器想到以它演奏的音乐。这种因关联而用一个名称指另一事物的写法，叫借代。

## 知识点：据上下文把互文分写的成分合读 {#prose45.mutual}
义项：合读两边后检验哪些意思由双方共同承担
领域：篇章
要诀：先试直译，再看它是否凭空添了“只”。
讲解：“东西邻里同修渠，东运土，西运石，土石皆分担”末句已说明两头都出力，不能硬规定东边永远不碰石头。古诗中还须凭上下文判断能否这样合读。
例句：prose45.ex.mutual

## 原文：教学例句 {#prose45.ex.mutual}
> 田南田北尽春耕，南驱牛，北执耒，两处牛耒相随行。
译文：田南田北都在春耕，两地都有牛和农具同行。

## 知识点：根据正在做的事还原借代的具体所指 {#prose45.metonym}
义项：沿材料、器具或服饰与所指的实际联系解释
领域：篇章
要诀：试把代称换回去，看是谁在听、奏或使用。
讲解：“举觞而丝竹作”说的是举杯时音乐响起；酒席上丝线和竹竿不会自行演奏。换到编竹篓，竹也可以只是材料。
例句：prose45.ex.metonym

## 原文：教学例句 {#prose45.ex.metonym}
> 席间丝竹忽歇，客始闻阶雨。
译文：席上音乐忽然停下，客人才听见雨落台阶的声音。

## 原文：古籍引文 {#prose45.2.p.qin}
> 烟笼寒水月笼沙，夜泊秦淮近酒家。商女不知亡国恨，隔江犹唱后庭花。
译文：雾气与月色笼罩清寒的河水和沙岸，夜里船泊秦淮，靠近酒家。歌女不懂亡国之恨，还隔着江唱《后庭花》。

  商女：此处指以歌唱为业的女子。
  后庭花：曲名，作《玉树后庭花》，这里引起对陈朝灭亡的联想。

## 单选：这幅秦淮夜景，怎样读才不致由两半分写添出一条并不存在的分界？ {#prose45.2.q1}
考点：prose45.mutual
语境：prose45.2.p.qin

- [ ] 先有白昼水雾，等雾散了月光才照来
  理由：下文定时为“夜泊”，没有雾散、天黑的经过。
- [ ] 月光只能照到沙上，烟雾严格止于水面
  理由：诗句并排点景，没有写出一道隔开两者的线。
- [x] 水、沙同在烟雾与月色笼罩的夜景里

提示：把两个“笼”放回同一幅夜泊图。
解析：烟与月、水与沙分在两半写，合起来是水岸一带的夜色。字面配对并不排除彼此交叠。

## 找原文证据：前一句若读成烟、月分属昼夜，下一句哪两个字最先使这种分读失去根据？ {#prose45.2.q2}
考点：prose45.mutual
语境：prose45.2.p.qin

- [x] 夜泊
- [ ] 隔江
  理由：这是听歌时两方隔着江面。
- [ ] 近酒家
  理由：这是停船地点的补充。

提示：找明说整幅景在什么时刻的字。
解析：开头是今夜停泊眼前的一片水岸。诗没有把烟和月分别安置在白天和夜里。

## 原文：古籍引文 {#prose45.2.p.du}
> 舍南舍北皆春水，但见群鸥日日来。花径不曾缘客扫，蓬门今始为君开。
译文：屋南屋北都是春水，平日只见群鸥飞来。平时不曾特意为来客扫花径、开柴门，今天却为您扫径开门。

  蓬门：简陋的门户。
  今始：今天才。

## 单选：只译“从没扫过路，今天开了门”，丢掉了哪一层待客心意？ {#prose45.2.q3}
考点：prose45.mutual
语境：prose45.2.p.du

- [x] 平日少客，如今扫径与开门都是为这位来客
- [ ] 主人今天仍不肯扫径，特地让客人站在外面
  理由：花径和蓬门相对写，末句落在“为君”迎人。
- [ ] 主人平日根本不出门，今天被迫放弃幽居
  理由：诗在说接客，没有断言主人平日的行动范围。

提示：把“缘客”和“为君”、“不曾”和“今始”合看。
解析：上下分写两种动作，也分写平日与今天。合读才有专为这一位客人破例迎接的意味。

## 单选：依这两联，能否说诗人此前从未清扫过自家的花径？ {#prose45.2.q4}
考点：prose45.mutual
语境：prose45.2.p.du

- [x] 不能，诗里限制的是为了迎客而特意清扫
- [ ] 不能，因为只有客人能替主人扫花径
  理由：“为君”说主人为客而做，没有调换做事的人。
- [ ] 能，“不曾”否定了他一生所有扫径的动作
  理由：“不曾”后还有“缘客”，不能删掉这层条件。

提示：找“不曾”后面写明缘故的字。
解析：一段诗在说平日少客、今日有客；补全互文仍要保留“为客”的范围。

## 原文：古籍引文 {#prose45.2.p.lute}
> 主人下马客在船，举酒欲饮无管弦。醉不成欢惨将别，别时茫茫江浸月。忽闻水上琵琶声，主人忘归客不发。
译文：送客的主人下马，客人在船上，临别举起酒杯却没有音乐助兴。喝了酒也欢乐不起来，将别时茫茫江面浸着月影。忽然水上传来琵琶声，主人忘了回去，客人也不出发。
出处：《琵琶行》送客闻声章节录
版本：chinese-poetry 固定录文

词注：管弦：管乐、弦乐器，这里借指宴饮时的乐声。
  不发：客人的船没有出发。

## 单选：“无管弦”跟后面“忽闻”合起来，发生了哪一种变化？ {#prose45.2.q5}
考点：prose45.metonym
语境：prose45.2.p.lute

- [x] 先是举杯时没有乐声，后来水面传来琵琶声
- [ ] 刚才举杯一片寂静，连人讲话的声音也没有
  理由：“管弦”只指音乐，不能将一切声音都抹去。
- [ ] 先证明船上没有丝线竹管，后来从水里捞出乐器
  理由：“闻”写听到，未写打捞或清点物资。

提示：听者等到的是某种声音，还是某种原材料？
解析：乐器名在饮酒场合代指音乐。琵琶声是从无乐到有乐的转折。

## 找原文证据：“管弦”指乐声，这一读法在下文有哪一处正面呼应？ {#prose45.2.q6}
考点：prose45.metonym
语境：prose45.2.p.lute

- [x] 忽闻水上琵琶声
- [ ] 别时茫茫江浸月
  理由：这里写月映江面，还没出现音乐。
- [ ] 主人忘归客不发
  理由：这是被音乐留住的结果，没有点明所听。

提示：找“闻”后真正听见的东西。
解析：先无助饮之乐，后忽闻弹奏，都是就耳中所闻说。

## 原文：古籍引文 {#prose45.2.p.iron}
> 许子以釜甑爨，以铁耕乎？曰：“然。”“自为之与？”曰：“否，以粟易之。”
译文：“许先生用锅和甑做饭，用铁制农具耕田吗？”答：“是。”“自己制作这些东西吗？”答：“不是，用粮食换来的。”

底本链接：https://github.com/kanripo/KR1h0001/blob/8decdf43d5a82b779f7950a7782b9a5e09659564/KR1h0001_005.txt#L421-L431

  爨：生火做饭。
  易：交换。

## 单选：“以铁耕”中的“铁”，为什么要落实为铁制农具？ {#prose45.2.q7}
考点：prose45.metonym
语境：prose45.2.p.iron

- [ ] 许子将铁块直接撒进田里当种子
  理由：“以……耕”写用什么耕，不是在说播种哪种作物。
- [ ] “铁”比喻许子性格刚直，与工具无关
  理由：前问釜甑，继问器物是否自制、如何换取，都在谈实际用具。
- [x] “耕”要用能耕田的器物，材料名称代指它制成的工具

提示：先读“以铁”后面的动作，再看后面问自制什么。
解析：釜甑可炊，铁器可耕，两种器具都可通过交易得到。这里借材料称成品。

## 单选：把“以粟易之”续在后面，哪一条消息得到确认，哪一条仍不能断定？ {#prose45.2.q8}
考点：prose45.metonym
语境：prose45.2.p.iron

- [ ] 许子到山里采矿，自铸了铁犁
  理由：对“自为之与”明确答“否”。
- [ ] 许子拿铁换粮，并从此不再种地
  理由：“以粟”说交出的是粮，不是铁。
- [x] 工具由交换得来，但没有说出那件铁制农具的具体形制

提示：“铁”所指的大类和器物究竟长什么样，是两层问题。
解析：可以从耕作推知是铁制农具，再由答话确定交易来源；原文没有列出特定的式样。
