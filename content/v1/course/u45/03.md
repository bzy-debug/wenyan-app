# 课文：赋铺开的景，文里带来的旧事 {#prose45.3}
简介：跟欧阳修听秋声、张衡看仲春，再听苏轼笔下的客人讲到曹操时，怎样由旧事说起眼前。

## 正文

一段写秋色、秋容、秋气、秋意，像是一次次重新起头。其实四处都朝向同一个“秋”。认出每次从哪个侧面写，就能把铺陈读出层次，而不必替作者增添四段游程。

另一种写法是用典。提到“周郎”或“伯牙”，作者可以把旧事的一层意思带进眼前的感慨。典故注释会交代旧人旧事；读正文还要问，这样借来是为了说明眼前谁的什么处境？并非每个知道的细节都该抄进译文。

## 知识点：按同一对象的侧面归拢赋中铺陈 {#prose45.catalog}
义项：找出不同所见所感共同写出什么
领域：篇章
要诀：试给每组取一个小标题，再回到作者收束的那句。
讲解：一段将潮声写得如鸣鼓、如千车，不能据此记为真的先有鼓队、后有车队。
例句：prose45.ex.catalog

## 原文：教学例句 {#prose45.ex.catalog}
> 近听檐溜，远听溪涛，俯听阶石，皆此一雨也。
译文：近听屋檐滴水，远听溪流喧响，低头听台阶受雨，听到的都是这场雨。

## 知识点：由典故中的处境说明本文此刻的观点或感受 {#prose45.old}
义项：区分旧事、本文当下与设想
领域：篇章
要诀：在典故注释里只挑此处真正用到的一层。
讲解：若有人说“吾失知音，弦亦可绝”，他用典借的是伯牙痛失知己那一层。要断言他当场断了琴弦，还须有当场行动的文字。
例句：prose45.ex.old

## 原文：教学例句 {#prose45.ex.old}
> 友亡，客抚琴曰：“钟期既往，谁听此曲？”
译文：朋友去世，客人抚琴说：“懂琴的钟子期已经离去，谁来听这支曲子？”

## 原文：古籍引文 {#prose45.3.p.autumn}
> 盖夫秋之为状也，其色惨淡，烟霏云敛；其容清明，天高日晶；其气栗冽，砭人肌骨；其意萧条，山川寂寥。故其为声也，凄凄切切，呼号愤发。
译文：说到秋天的面貌，色调暗淡，烟气弥漫而云气收敛；容貌清朗，天空高远阳光明净；秋气寒冽，像针刺进肌骨；秋意萧条，山河寂静。所以它的声音凄切，像是呼号迸发。

## 单选：“惨淡”“清明”紧挨着，会不会前一句刚说暗、后一句便反悔？ {#prose45.3.q1}
考点：prose45.catalog
语境：prose45.3.p.autumn

- [ ] 会，后一句撤回了“惨淡”，只肯承认秋日晴朗
  理由：四次“其”是分说各面，没有撤回前说的字眼。
- [ ] 会，作者先写室内暗，再写第二天搬到山外
  理由：没有“次日”或重新出行，“其”一直指秋。
- [x] 两句各从一面写秋：先写色调，再写天高日明的形貌

提示：把四处“其”后紧随的名词摘出来看。
解析：色、容、气、意依次铺开，合起来才引出作者耳中秋声的性情。

## 找原文证据：哪一句把前面对色、容、气、意的铺写收回“听到的秋声”？ {#prose45.3.q2}
考点：prose45.catalog
语境：prose45.3.p.autumn

- [ ] 山川寂寥
  理由：这是“其意萧条”一层铺写，还未转到声。
- [ ] 其容清明
  理由：这里仍写面貌，由天空和日光来说明。
- [x] 故其为声也

提示：找既承接前面、又带出听觉的一处。
解析：“故”是收束，“声”接到耳中，下面才评说它如何凄切。

## 原文：古籍引文 {#prose45.3.p.spring}
> 于是仲春令月，时和气清。原隰郁茂，百草滋荣。王雎鼓翼，鸧鹒哀鸣。交颈颉颃，关关嘤嘤。于焉逍遥，聊以娱情。
译文：到了仲春的好时节，气候温和清朗，高地低地都草木茂盛，百草欣欣向荣。雎鸠振翅，黄鹂鸣啭；鸟儿交颈，飞上飞下，鸣声应和。我便在这里自在游赏，姑且舒畅心情。

## 单选：把“原隰”“百草”和后面的鸟翼、鸟鸣合看，末尾“于焉”承接了什么？ {#prose45.3.q3}
考点：prose45.catalog
语境：prose45.3.p.spring

- [x] 可以在那里逍遥娱情的整片春日田野
- [ ] 只有埋在田里的某一种草药
  理由：写到鸟鸣鸟飞，铺展的范围超过了一种草。
- [ ] 自春到秋所有鸟类的迁徙次序
  理由：“仲春令月”给整段定了时节。

提示：先为众多名物找共同的地方和季节。
解析：前面铺野地、草木、飞鸟与声音，最后才把欣赏这片景的人写了出来。

## 单选：“鸧鹒哀鸣”中的“哀”能否单独证明赋中人此刻只感到悲痛？ {#prose45.3.q4}
考点：prose45.catalog
语境：prose45.3.p.spring

- [ ] 不能，因为全段只叙植物，没有鸟声
  理由：“鼓翼”“哀鸣”“关关嘤嘤”都刻意写到鸟。
- [x] 不能，鸟声是春野的一笔，人的此刻心意还须看“娱情”
- [ ] 能，凡出现“哀”字，末句必定改写丧友
  理由：此处并未提到死别，末句还明说“娱情”。

提示：区分所听的声音与听者收住全段时说的话。
解析：铺陈中的一个声调不足以代替作者自述。“于焉逍遥”交代他怎样置身其中。

## 原文：古籍引文 {#prose45.3.p.cao}
> 客曰：“月明星稀，乌鹊南飞，此非曹孟德之诗乎？西望夏口，东望武昌，山川相缪，郁乎苍苍，此非孟德之困于周郎者乎？方其破荆州，下江陵，顺流而东也，舳舻千里，旌旗蔽空，酾酒临江，横槊赋诗，固一世之雄也，而今安在哉？”
译文：客人说：“月明、星稀，乌鹊南飞，这不是曹操的诗吗？西望夏口，东望武昌，山水环绕、草木苍翠，这不是曹操被周瑜困住的地方吗？当他攻破荆州、拿下江陵，顺流东下时，船队绵延千里，旌旗遮天，他临江斟酒、横执长矛吟诗，确是一世英雄，如今又到哪里去了呢？”

## 单选：客人引“月明星稀”，又一口气数曹操的船和旌旗，最后为何要说“而今安在哉”？ {#prose45.3.q5}
考点：prose45.old
语境：prose45.3.p.cao

- [ ] 责问苏轼为何把自己写的诗误给曹操
  理由：“此非曹孟德之诗乎”是客人指出诗句的来处。
- [x] 回想英雄当年声势之大，才更显如今无处可寻
- [ ] 请船夫循着眼前仍然遮天的旌旗去找曹操
  理由：“方其”领往事，“而今”已经换回说话时。

提示：把“方其”和“而今”各放在一侧。
解析：原诗、旧战、往日排场都由眼前江山引出。客人借一世英雄也已逝去，才有眼下的感慨。

## 找原文证据：哪些字最能阻止读者把曹操临江赋诗画成苏轼当夜亲眼所见？ {#prose45.3.q6}
考点：prose45.old
语境：prose45.3.p.cao

- [x] 而今安在哉
- [ ] 山川相缪
  理由：这能写眼前地势，却未说明曹操距今已远。
- [ ] 顺流而东
  理由：这仍是追叙当年的行动。

提示：找客人自己由过去转回现在的一问。
解析：“而今安在”恰说明眼前不见其人。客人是在借旧事说今情。

## 原文：古籍引文 {#prose45.3.p.harp}
> 盖钟子期死，伯牙终身不复鼓琴。何则？士为知己者用，女为说己者容。
译文：钟子期去世，伯牙终身不再弹琴。为什么呢？士人为了解自己的人出力，女子为欣赏自己的人修饰容貌。

## 单选：司马迁在信中说伯牙不再鼓琴，随即问“何则”。哪种接法没有把典故读成司马迁自己的履历？ {#prose45.3.q7}
考点：prose45.old
语境：prose45.3.p.harp

- [ ] 任少卿已经向伯牙学会了古曲
  理由：书中引用的旧事与收信人所会的乐曲无关。
- [ ] 司马迁自述学琴失败，因而停笔写史
  理由：停止鼓琴的人明写是伯牙，没有说司马迁停笔。
- [x] 伯牙的旧事说明知己对一个人施展才能的分量

提示：分别给“不复鼓琴”和“士为知己者用”找主语。
解析：“何则”把个别旧事接到一类人。借古事说明知己的重要，不须把琴和琴师安到写信人身上。

## 单选：删掉“士为知己者用”，只留下“伯牙终身不复鼓琴”，读者最难看出的会是什么？ {#prose45.3.q8}
考点：prose45.old
语境：prose45.3.p.harp

- [ ] 故事中死者是否是伯牙本人
  理由：“钟子期死”已指明死者。
- [ ] 伯牙究竟有没有停止弹琴
  理由：“不复鼓琴”在删剩的句子里仍很清楚。
- [x] 作者此处从琴事取来的是“谁能理解我”这一层

提示：被删去的是旧事本身，还是作者用旧事说的话？
解析：紧随的概括指明为何特意提伯牙。它帮助读者选取典故在本篇所用的意思。
