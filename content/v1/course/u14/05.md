# 课文：两次落泪之间，究竟是什么变得更可怕？ {#l4.5}
简介：听蒋氏讲完祖父的死，再听他回答免役的提议。同一个人的悲色，为何反而更重？

## 正文

柳宗元笔下，蒋家捕蛇可以抵赋，祖、父已死于此，自己也屡遇危险。作者此时是谈话中的“余”，见人面带愁色，自然想帮他免役。把两句并着看：“更若役”去掉了什么，“复若赋”又把什么放回了这个家？若只看前半，好意似乎一定是好事。

到这里，请在心里换个声音读。说“君将哀而生之乎”的是被救的人。蒋氏不替赋敛下抽象定义，只说一年两次冒死和乡邻“旦旦有是”是两种活法。他没有说捕蛇安全，甚至把自己有朝一日也会死于此算了进去。

最后“余闻而愈悲”又换回书写者。蒋氏比较自己与邻人，柳宗元由这一次谈话重读孔子论苛政的话，再解释为何写给察访民间疾苦的人。以百姓的原话作证，与替百姓说出一切道理，是这段最要紧的分别。

## 知识点：在对话中识别谁在比较哪两种处境 {#skill.l4.5.a}
义项：跟随说话人变化，解释看似反常的取舍
领域：篇章
要诀：“余将告”是柳宗元的话；“吾斯役”由蒋氏说。
讲解：作者想替蒋氏除去捕蛇之危，蒋氏却连同恢复纳赋一并比较。他的反常选择主张的是两害有轻重。
例句：p.l4.5.a

## 知识点：从一连串反问辨认立场 {#skill.l4.5.b}
义项：从比较对象与引语边界辨识反问的真实着力处
领域：阅读技能
要诀：在“岂若”“安敢”“孰知”前各写上发问者。
讲解：蒋氏问怎敢怨役，话里有他与乡邻的处境之别；作者问谁知赋敛之毒，已把发问递给文章外的读者。
例句：p.l4.5.b

## 原文：古籍引文 {#p.l4.5.a}
> 吾祖死于是，吾父死于是，今吾嗣为之十二年，几死者数矣。言之，貌若甚戚者。余悲之，且曰：“若毒之乎？余将告于莅事者，更若役，复若赋，则何如？”蒋氏大戚，汪然出涕，曰：“君将哀而生之乎？则吾斯役之不幸，未若复吾赋不幸之甚也。向吾不为斯役，则久已病矣。”
译文：我祖父死在这差事上，父亲也是。如今轮到我，做了十二年，几次差点死掉。他说起这些，脸上很悲伤。我也为他难过，问能否向管事的人陈说，给他换了差役，让他照旧缴赋。蒋氏更加难过，眼泪流下来：“您是要怜悯我、救活我吗？那么我服这差役的不幸，还赶不上重新纳赋的不幸。假若先前没有这差事，我早已穷困不堪了。”
词注：嗣：接续祖、父所做的差役。
  若：你、你的，如“更若役”。
  向：假若先前，用于设想另一种处境。

## 原文：古籍引文 {#p.l4.5.b}
> 盖一岁之犯死者二焉，其余则熙熙而乐，岂若吾乡邻之旦旦有是哉？今虽死乎此，比吾乡邻之死则已后矣，又安敢毒耶？余闻而愈悲。孔子曰：“苛政猛于虎也。”吾尝疑乎是，今以蒋氏观之，犹信。呜呼！孰知赋敛之毒有甚是蛇者乎？故为之说，以俟夫观人风者得焉。
译文：一年冒死不过两次，其余时候还可以安稳度日，哪像乡邻天天遇到这样的苦难？纵使今天死在这差事上，比起乡邻也算死得晚了，我又哪敢怨恨它？我听了更悲伤。孔子说苛政比虎还凶，我从前怀疑这话，如今看了蒋氏才相信。谁知道赋敛的毒害竟比蛇更重！所以写下这篇说，希望考察民生的人能从中有所领会。
词注：毒：在“安敢毒耶”中是怨恨。
  旦旦：天天。
  俟：等待、期待。

## 单选：柳宗元起初听到蒋家遭遇，提出“更若役，复若赋”。两项如果都做到，蒋氏还需面对什么？ {#q.l4.5.1}
考点：skill.l4.5.a
语境：p.l4.5.a

- [ ] 不再捕蛇并从此免去一切税役 {#q.l4.5.1.o1}
  理由：“复若赋”的“复”指恢复。
- [ ] 继续捕蛇，同时多领一份官府给付 {#q.l4.5.1.o2}
  理由：“更若役”就在说要替他改变所服的役。
- [x] 退出捕蛇的差役，重新承担赋税 {#q.l4.5.1.o3}

提示：把提议拆成一项要换掉的事、一项要恢复的事。
解析：柳宗元本以为可救他脱险，提议却连着一个代价。蒋氏接话，先问的正是这算不算救他。

## 找原文证据：蒋氏听了好意却哭得更悲。哪句话直接说出他对两种不幸的比较？ {#q.l4.5.2}
考点：skill.l4.5.b
语境：p.l4.5.a

- [ ] 吾父死于是 {#q.l4.5.2.o1}
  理由：这是捕蛇的危险，不能单独说明他为何不愿免役。
- [ ] 君将哀而生之乎 {#q.l4.5.2.o2}
  理由：这句回应柳宗元的好意，还未说复赋与捕蛇孰重。
- [x] 未若复吾赋不幸之甚也 {#q.l4.5.2.o3}

提示：在蒋氏自己的话里找“若”的比较用法。
解析：“未若”比较两害的分量：捕蛇很不幸，改回纳赋在他看来还要严重。

## 单选：“向吾不为斯役，则久已病矣”应放在哪一栏阅读笔记？ {#q.l4.5.3}
考点：skill.l4.5.a
语境：p.l4.5.a

- [ ] 柳宗元证明蒋氏已经停役多年 {#q.l4.5.3.o1}
  理由：“向……则……”推的是未走的路。
- [x] 蒋氏对另一种活法的推想 {#q.l4.5.3.o2}
- [ ] 官府刚刚宣布改役后的实际结果 {#q.l4.5.3.o3}
  理由：柳宗元才提出替他向主事人陈说。

提示：试把“向”译成“假若当初”。
解析：这句假设解释蒋氏今天的选择。“病”在这里说困苦，他没有自称因停捕而患过某种疾病。

## 单选：叙事先写“貌若甚戚”，后写“大戚”。后一次所添的是什么？ {#q.l4.5.4}
考点：skill.l4.5.b
语境：p.l4.5.a

- [ ] 后一次证明先前诉说祖父遭难全是虚话 {#q.l4.5.4.o1}
  理由：一种不幸更重，不会使另一种变假。
- [ ] 先前蒋氏已请求免去捕蛇，现在忽然变卦 {#q.l4.5.4.o2}
  理由：先前是叙述经历，提议免役的是“余”。
- [x] 相同的悲色有了另一层缘故：怕被改回赋税 {#q.l4.5.4.o3}

提示：分别问：是哪番话刚说完，叙述者才写这个“戚”？
解析：第一次悲的是家人在役中丧命；第二次泪下，才显出“救他脱险”在他眼里的另一面。

## 找原文证据：蒋氏拿邻里的遭遇和自己相较。哪个短语把他们受威胁的频率写得最清楚？ {#q.l4.5.5}
考点：skill.l4.5.a
语境：p.l4.5.b

- [ ] 一岁之犯死者二焉 {#q.l4.5.5.o1}
  理由：一年两次说的是捕蛇人自己。
- [ ] 比吾乡邻之死则已后矣 {#q.l4.5.5.o2}
  理由：这里比先死后死，回答的是死亡的早晚。
- [x] 旦旦有是 {#q.l4.5.5.o3}

提示：先找到“一岁……二”，再找同它相对的时间词。
解析：“旦旦”是天天。蒋氏比较的是危险怎样侵入日常生活，并没有把蛇说成无毒。

## 单选：“又安敢毒耶”里的“毒”是怨恨。在蒋氏口中，反问的用意是什么？ {#q.l4.5.6}
考点：skill.l4.5.b
语境：p.l4.5.b

- [ ] 声称自己从未害怕过蛇 {#q.l4.5.6.o1}
  理由：开头说“几死者数矣”，危险说得很明白。
- [x] 既然两头都凶险，自己怎敢独怪这项差役 {#q.l4.5.6.o2}
- [ ] 质问乡邻为什么不同他一起去捕蛇 {#q.l4.5.6.o3}
  理由：反问落在“吾”面对的差役上，没有向邻人招募。

提示：读反问前的“比吾乡邻”，先弄清他在跟谁比。
解析：这不是给差役唱赞歌。蒋氏说，自己纵然死于此，也可能比受赋敛逼迫的邻人死得晚。

## 单选：“吾尝疑乎是，今以蒋氏观之，犹信”中，谁改变了自己的判断？ {#q.l4.5.7}
考点：skill.l4.5.a
语境：p.l4.5.b

- [x] 写这篇“说”的人，因蒋氏的经历重新理解孔子的话 {#q.l4.5.7.o1}
- [ ] 蒋氏，因孔子这番劝告愿意继续捕蛇 {#q.l4.5.7.o2}
  理由：孔子的话是叙述者听完后才引的。
- [ ] 乡邻，听说蒋家境况后相信苛政无害 {#q.l4.5.7.o3}
  理由：乡邻没有在这里发言，“苛政猛于虎”也恰非无害。

提示：沿着“余闻”向下读，何处换过说话人？
解析：“余闻而愈悲”已接回作者。过去的疑与如今的信，是他在同一段里交代的自我修正。

## 单选：若末段止于蒋氏的反问，全文会少掉哪一步？ {#q.l4.5.8}
考点：skill.l4.5.b
语境：p.l4.5.b

- [ ] 蒋氏为何在改役建议面前哭泣的说明 {#q.l4.5.8.o1}
  理由：他亲口比较之后，这点已经有了说明。
- [ ] 关于毒蛇外形的最后一项证据 {#q.l4.5.8.o2}
  理由：段末谈的是为谁写、为什么写。
- [x] 由一户人的选择追问赋敛，为考察民情的人写下这件事 {#q.l4.5.8.o3}

提示：“故为之说”里的“为”是谁动笔？
解析：从“孰知”到“以俟”，作者把个人叙述交给更广的读者，请他们留意一项制度的代价。
