# 课文：蒋氏为什么宁愿继续捕蛇 {#l4.5}
简介：听说要免去捕蛇的苦役，蒋氏怎么哭得更伤心了？把柳宗元的好意和蒋氏自己算的账放在一起读。

## 正文

祖父、父亲都死于捕蛇，自己也数次险死。柳宗元听了想替蒋氏求情：“更若役，复若赋。”前半句要给他换掉差役，后半句却是恢复通常的赋税。蒋氏听到这里，竟比先前更加悲痛。柳宗元以为能救他的办法，在他看来会叫他更难活下去。

听听蒋氏怎样算这笔账。捕蛇一年两次冒死，余下的日子还过得下去；乡邻却“旦旦有是”，天天受逼迫。“又安敢毒耶”是他为自己说话：两害相较，哪里还敢怨捕蛇？到“余闻而愈悲”，“余”已经换回听故事的柳宗元。他为蒋氏一家悲，也为蒋氏的乡邻悲。

## 知识点：说话者与反常选择 {#skill.l4.5.a}
义项：从说话人自己的处境，理解他为什么作出这个选择
领域：篇章
要诀：谁想改差役，谁听了提议流眼泪？
讲解：柳宗元担心捕蛇会害死蒋氏；蒋氏却知道，改回一般赋税更难度日。两人都在说怎样让他活下去，却各有一番盘算。
例句：p.l4.5.a

## 知识点：从反问里听出轻重 {#skill.l4.5.b}
义项：从两种苦处哪个更重，听懂反问里没有直说的态度
领域：阅读技能
要诀：把“一年两次”和“天天如此”接回各自的人。
讲解：蒋氏一年两次冒死，乡邻却天天受苦。知道他怎样比较，再听“安敢毒耶”，就明白他为什么说自己不敢怨这份差事。
例句：p.l4.5.b

## 原文：古籍引文 {#p.l4.5.a}
> 吾祖死于是，吾父死于是，今吾嗣为之十二年，几死者数矣。言之，貌若甚戚者。余悲之，且曰：“若毒之乎？余将告于莅事者，更若役，复若赋，则何如？”蒋氏大戚，汪然出涕，曰：“君将哀而生之乎？则吾斯役之不幸，未若复吾赋不幸之甚也。向吾不为斯役，则久已病矣。”
译文：蒋氏说，祖父和父亲都死在这件事上，自己接着做了十二年，也几次濒死。说时神色忧伤。我怜惜他，问是否怨苦这差事，愿替他向主管陈说，换掉捕蛇役、恢复赋税。他更加悲痛，流泪说：您想让我活命吗？这差事虽然不幸，却还比不上恢复赋税那么不幸。如果我从前没做这差事，早就困苦不堪了。

## 原文：古籍引文 {#p.l4.5.b}
> 盖一岁之犯死者二焉，其余则熙熙而乐，岂若吾乡邻之旦旦有是哉？今虽死乎此，比吾乡邻之死则已后矣，又安敢毒耶？余闻而愈悲。孔子曰：“苛政猛于虎也。”吾尝疑乎是，今以蒋氏观之，犹信。呜呼！孰知赋敛之毒有甚是蛇者乎？故为之说，以俟夫观人风者得焉。
译文：蒋氏说，一年冒生命危险两次，其余日子还能安然度过，哪像乡邻天天如此？即使现在因此死去，也比乡邻死得晚，又哪里敢怨这差事？我听了更加悲痛。孔子说苛政比老虎还凶，我曾有疑问，如今看蒋氏的事，的确可信。有谁知道征敛的毒害还能超过这蛇？于是写成此说，留给考察民情的人读。

## 单选：叙述者的方案中，免掉蛇役的同时还有什么变化？ {#q.l4.5.1}
考点：skill.l4.5.a
语境：p.l4.5.a

- [ ] 只把捕蛇的次数减到一年一次 {#q.l4.5.1.o1}
  理由：“更若役”是更换差役，作者没有提议减少捕蛇次数。
- [ ] 蒋氏一家从此免除一切负担 {#q.l4.5.1.o2}
  理由：“复若赋”的“复”是恢复。
- [x] 蒋氏要重新承担一般赋税 {#q.l4.5.1.o3}

提示：并读提议中的“更”和“复”。
解析：“更若役”是给蒋氏换掉差役，“复若赋”是恢复他应缴的赋税。要两句一起读，才知道蒋氏听见的并非免掉一切负担。

## 找原文证据：哪句话已经把两种不幸的轻重说清？ {#q.l4.5.2}
考点：skill.l4.5.b
语境：p.l4.5.a

- [ ] 若毒之乎 {#q.l4.5.2.o1}
  理由：“若毒之乎”是柳宗元在问苦不苦。两种负担哪个更重，是蒋氏后来才说的。
- [ ] 言之，貌若甚戚者 {#q.l4.5.2.o2}
  理由：神情可以显示痛苦，未比较两种负担。
- [x] 未若复吾赋不幸之甚也 {#q.l4.5.2.o3}

提示：寻找直接比较的“未若”。
解析：“未若”就是比不上。捕蛇已经够不幸，可蒋氏说，它还比不上恢复赋税那样不幸。

## 单选：为什么“大戚”比先前的“貌若甚戚”更难按常理解释？ {#q.l4.5.3}
考点：skill.l4.5.a
语境：p.l4.5.a

- [ ] 他听懂了提议者要让他多捕一倍的蛇 {#q.l4.5.3.o1}
  理由：提议是“更若役”，不是加役。
- [x] 平常看来免除险役应令人宽心，他却更害怕 {#q.l4.5.3.o2}
- [ ] 他并不知道祖父曾经死于捕蛇 {#q.l4.5.3.o3}
  理由：蒋氏刚亲口讲过祖父的遭遇。

提示：先标出第二次悲戚发生在哪句话之后。
解析：先前提到父祖丧命，他显得忧伤；现在听说能免役，反倒流下泪来。往下读他的答话，才知道让他害怕的是恢复赋税。

## 单选：蒋氏问“君将哀而生之乎”，他怕求情的人想错了什么？ {#q.l4.5.4}
考点：skill.l4.5.b
语境：p.l4.5.a

- [ ] 祖父、父亲捕蛇而死都是假话 {#q.l4.5.4.o1}
  理由：蒋氏并未撤回自己的叙述。
- [ ] 叙述者根本不怜悯蒋氏 {#q.l4.5.4.o2}
  理由：“余悲之”明写怜悯。
- [x] 恢复普通赋税就一定是在救蒋氏 {#q.l4.5.4.o3}

提示：比较提议者的目的与提议实际带来的负担。
解析：柳宗元确实想帮他。蒋氏问他是否想让自己活下去，接着说明按这个办法做，他就要重受赋敛。

## 找原文证据：哪一句标志从蒋氏的权衡转回叙述者的反应？ {#q.l4.5.5}
考点：skill.l4.5.a
语境：p.l4.5.b

- [ ] 又安敢毒耶 {#q.l4.5.5.o1}
  理由：“又安敢毒耶”仍是蒋氏自己说的话。要找听者的反应，再往下读一句。
- [ ] 比吾乡邻之死则已后矣 {#q.l4.5.5.o2}
  理由：“吾”是正在回应的蒋氏。
- [x] 余闻而愈悲 {#q.l4.5.5.o3}

提示：谁是讲述自己遭遇的人，谁在听？
解析：前一句“又安敢毒耶”仍是蒋氏说的。“余闻而愈悲”中，有人听了刚才这番话，更加悲痛，这个人是柳宗元。

## 单选：蒋氏说乡邻“旦旦有是”，是在比哪一件事？ {#q.l4.5.6}
考点：skill.l4.5.b
语境：p.l4.5.b

- [ ] 蛇的数量：一年两条与每天两条 {#q.l4.5.6.o1}
  理由：“旦旦有是”并未说乡邻天天捕蛇。
- [x] 危险出现的频率：一年两次与几乎天天 {#q.l4.5.6.o2}
- [ ] 两种死亡方式哪一种更快 {#q.l4.5.6.o3}
  理由：原文比较的是所受逼迫的频度。

提示：对读“一岁”“二”与“旦旦”。
解析：“二焉”是每年两次，“旦旦”是天天。蒋氏比的是各人多久要吃一次苦，正因为乡邻日日受逼迫，他才宁可冒险捕蛇。

## 单选：最后“为之说”主要写给谁看？ {#q.l4.5.7}
考点：skill.l4.5.a
语境：p.l4.5.b

- [x] 有机会考察民情的人 {#q.l4.5.7.o1}
- [ ] 只写给主管捕蛇差役的官员 {#q.l4.5.7.o2}
  理由：叙述者起初提到莅事者，篇末写作对象扩为考察民情的人。
- [ ] 想学捕蛇方法的人 {#q.l4.5.7.o3}
  理由：文末所指是“观人风者”。

提示：跟读“以俟夫”之后的对象。
解析：“以俟夫观人风者得焉”说得很明白：写下这篇文章，要让考察民情的人知道征敛怎样影响百姓的生计。

## 单选：“孰知赋敛之毒有甚是蛇者乎”最接近哪一种表述？ {#q.l4.5.8}
考点：skill.l4.5.b
语境：p.l4.5.b

- [ ] 只要有蛇的地方就一定有苛税 {#q.l4.5.8.o1}
  理由：蒋氏事例说明轻重关系，没有设定普遍地理规律。
- [ ] 作者等待读者报出发明蛇毒的人名 {#q.l4.5.8.o2}
  理由：“孰知”指向人们对赋敛之害的认识。
- [x] 从这个个案可见，赋敛甚至比蛇更害人，这值得察知 {#q.l4.5.8.o3}

提示：把“甚是蛇”接回蒋氏和邻人的对照。
解析：祖父和父亲都死于捕蛇，蒋氏却仍怕恢复赋税。柳宗元问谁知赋敛之毒更甚，是要人留意这个轻重倒过来的事实。
