# 课文：让两种主张相遇 {#l4.4}
简介：对读韩非与韩愈，区分严格的归谬和针对行为的反诘。

## 正文

《韩非子·难一》里，两句夸口单独听似乎都能成立。发问者暂时接受它们，再构造一个两句话必须同时适用的情形：无论答什么，至少一句要撤回。这是从对方前提推出矛盾的归谬。课文保留底本“楯”，即盾。

《师说》把另一组判断并置。家长肯为孩子聘师，轮到自己却以从师为耻。韩愈还区分句读之学和传道解惑：轻重所在与实际求学的选择落差很大。这能质疑家长的取舍，却不必说世上逻辑上绝不可能有这种家长。

## 知识点：让前提接受同一检验 {#skill.l4.4.a}
义项：把分开提出的判断放在可比较的一个情境下
领域：篇章
要诀：问两种说法或做法能否彼此照应
讲解：先保持双方原话，再设计能让二者同时接受检验的比较。
例句：p.l4.4.a

## 知识点：驳论结论的力度 {#skill.l4.4.b}
义项：区分两说不可兼真和行为取舍不当
领域：阅读技能
要诀：看作者是说“不可能”还是说“不明”
讲解：互相排斥的全称断言与实际行为显出的价值倒置，需要不同强度的结论。
例句：p.l4.4.b

## 原文：古籍引文 {#p.l4.4.a}
> 楚人有鬻楯与矛者，誉之曰：“吾楯之坚，莫能陷也。”又誉其矛曰：“吾矛之利，于物无不陷也。”或曰：“以子之矛陷子之楯，何如？”其人弗能应也。夫不可陷之楯与无不陷之矛，不可同世而立。
译文：楚地有个卖盾和矛的人，夸盾说没有东西能穿透它，又夸矛说没有东西穿不透。有人问，拿你的矛对你的盾，结果怎样？卖者答不上来。不能被穿透的盾与什么都能穿透的矛，这两种说法无法同时成立。

## 原文：古籍引文 {#p.l4.4.b}
> 爱其子，择师而教之；于其身也，则耻师焉，惑矣。彼童子之师，授之书而习其句读者，非吾所谓传其道、解其惑者也。句读之不知，惑之不解，或师焉，或不焉，小学而大遗，吾未见其明也。
译文：疼爱孩子，挑选老师教他；轮到自己，却以从师为耻，真叫人费解。儿童的老师教读书、练句读，和我说的传道解惑的老师用意有别。不懂句读、不解道理，这些人一项肯求师，一项却不肯。小处肯学，大处反而丢了，我看不出这是明智。

## 找原文证据：哪句话让先前分说的两项夸口必须同场受检？ {#q.l4.4.1}
考点：skill.l4.4.a
语境：p.l4.4.a

- [ ] 其人弗能应也 {#q.l4.4.1.o1}
  理由：这是被问之后的反应。
- [ ] 又誉其矛曰 {#q.l4.4.1.o2}
  理由：这里开始第二次夸口，尚未让两物相遇。
- [x] 以子之矛陷子之楯，何如 {#q.l4.4.1.o3}

提示：找第三个人开口说的话。
解析：同一情形落进两句断言的范围。不论设想什么结果，都会抵触其中一句。

## 单选：作者由卖者无言能够推出什么？ {#q.l4.4.2}
考点：skill.l4.4.b
语境：p.l4.4.a

- [ ] 卖者说的两句话一定都假 {#q.l4.4.2.o1}
  理由：推出不能兼真，尚不能指定每句话的真假。
- [x] 两项不留例外的夸口不能同时成立 {#q.l4.4.2.o2}
- [ ] 没有任何人能回答任何关于矛楯的问题 {#q.l4.4.2.o3}
  理由：难题来自这两项特定断言同时成立的要求。

提示：留意末句“不可”后紧接的范围。
解析：不能“同世而立”的是按两项绝对描述成立的两物。

## 单选：若卖者改说“我的盾通常很坚固”，原来的归谬为何会失力？ {#q.l4.4.3}
考点：skill.l4.4.a
语境：p.l4.4.a

- [ ] 卖者一沉默便能证明两项性质都成立 {#q.l4.4.3.o1}
  理由：沉默不是性质的证据。
- [x] “通常”给具体反例留下余地 {#q.l4.4.3.o2}
- [ ] 盾只要改称别的名字就不再是原物 {#q.l4.4.3.o3}
  理由：改动的是量词，物件没换。

提示：比较“通常”与“莫能”。
解析：若允许例外，一次穿透已不能与盾的一般性质构成直接矛盾。

## 单选：“其人弗能应也”在段中与末句怎样分工？ {#q.l4.4.4}
考点：skill.l4.4.b
语境：p.l4.4.a

- [x] 先记问答受阻，再揭示受阻的理由 {#q.l4.4.4.o1}
- [ ] 两句都是卖者继续吆喝的话 {#q.l4.4.4.o2}
  理由：末句“夫”引出作者的概括。
- [ ] 先证明盾已被穿透，再记交易失败 {#q.l4.4.4.o3}
  理由：原文没有实验，也未说交易结果。

提示：分清叙述反应和作者判断。
解析：答不出是故事里呈现的现象，末句才明说两个判断不能兼真。

## 找原文证据：哪句把同一位家长置于另一种求学位置？ {#q.l4.4.5}
考点：skill.l4.4.a
语境：p.l4.4.b

- [ ] 授之书而习其句读者 {#q.l4.4.5.o1}
  理由：这是说明童子之师的工作。
- [ ] 爱其子 {#q.l4.4.5.o2}
  理由：这是比较的起点，还没换位置。
- [x] 于其身也，则耻师焉 {#q.l4.4.5.o3}

提示：先找其子，再找这个成人自己。
解析：“其身”与“其子”并列，轮到自己时，对求师的态度倒转。

## 单选：“吾未见其明也”批评什么？ {#q.l4.4.6}
考点：skill.l4.4.b
语境：p.l4.4.b

- [ ] 父亲绝不可能兼有爱子与耻师两种行为 {#q.l4.4.6.o1}
  理由：开头就把两件事写成现实中的做法。
- [ ] 教授儿童句读的人全无价值 {#q.l4.4.6.o2}
  理由：韩愈区分所教内容，所批评的是取舍。
- [x] 肯学小处却搁下更重要的疑惑，这种取舍欠明智 {#q.l4.4.6.o3}

提示：接回它前面的“小学而大遗”。
解析：作者评价轻重倒置；行为在现实中能同时存在，才构成批评对象。

## 排序：整理韩愈把两种选择放在一起检验的过程。 {#q.l4.4.7}
考点：skill.l4.4.a
语境：p.l4.4.b

- [3] 追问小处学、大处遗是否明智 {#q.l4.4.7.o1}
  理由：“小学而大遗”是把两种学习选择比较后的评价。
- [2] 分清习句读与传道解惑 {#q.l4.4.7.o2}
  理由：“彼童子之师”接着界定小处所学。
- [1] 并置为子择师和自己耻师 {#q.l4.4.7.o3}
  理由：文章以家长在两个角色上的不同选择起笔。

提示：先人物，再教学内容，末了评价。
解析：人物行为的反差，需要说明两类教学的功能，才显出其取舍的问题。

## 单选：将此段与卖者故事并读，哪项准确？ {#q.l4.4.8}
考点：skill.l4.4.b
语境：p.l4.4.b

- [x] 卖者的断言不能兼真，家长的做法能够并存却失当 {#q.l4.4.8.o1}
- [ ] 韩愈也通过一句无法回答的交易问题结束文章 {#q.l4.4.8.o2}
  理由：韩愈收在对求学取舍的评价。
- [ ] 两文都证明故事中人物从未真正存在 {#q.l4.4.8.o3}
  理由：两文议论的是说法或行为，没有否定人物存在。

提示：对读“不可同世而立”和“未见其明”。
解析：结论的力度不同：一处排除两说共真，一处评论行为是否明智。
