# 课文：卖者的夸口与家长的求师 {#l4.4}
简介：同是指出别人的毛病，韩非说两句夸口不能同时为真，韩愈说一个人的取舍不明智。

## 正文

一面盾，说是什么也刺不穿；一支矛，又说什么都能刺穿。有人问：拿你这支矛，刺你这面盾呢？若刺穿了，夸盾的话便站不住；若刺不穿，夸矛的话又站不住。先顺着对方的说法，再让人看到这会推出矛盾，这样的辩法叫归谬。课文里的“楯”就是盾。

韩愈也把两件事放在一起问。一个人肯为孩子择师，到自己头上却耻于从师；肯在句读上用心，更大的疑惑却搁下了。这样的家长当然可能有，韩愈批的是他的取舍，所以收在“吾未见其明也”：我看不出这有什么明智。

## 知识点：把两种主张放在一起检验 {#skill.l4.4.a}
义项：把两种说法或做法放在同一件事上，看它们能否说得通
领域：篇章
要诀：让两个说法谈到同一件事。
讲解：若只问盾坚不坚，或只问矛利不利，卖者都能夸下去。一旦拿他自己的矛对他自己的盾，两句夸口就要一起算数了。
例句：p.l4.4.a

## 知识点：一句反驳能说明什么 {#skill.l4.4.b}
义项：分清“两种说法不能都真”和“一个人做事分错了轻重”
领域：阅读技能
要诀：作者究竟说“不可能”，还是“这样做不明智”？
讲解：矛、盾的两项绝对夸口不能同时为真。家长为孩子择师却不肯自己求师，这些事能同时发生，问题在他的轻重取舍。
例句：p.l4.4.b

## 原文：古籍引文 {#p.l4.4.a}
> 楚人有鬻楯与矛者，誉之曰：“吾楯之坚，莫能陷也。”又誉其矛曰：“吾矛之利，于物无不陷也。”或曰：“以子之矛陷子之楯，何如？”其人弗能应也。夫不可陷之楯与无不陷之矛，不可同世而立。
译文：楚地有个卖盾和矛的人，夸盾说没有东西能穿透它，又夸矛说没有东西穿不透。有人问，拿你的矛对你的盾，结果怎样？卖者答不上来。这面盾若真什么都刺不穿，这支矛便不能样样都刺得穿，两句夸口不能同时成立。

## 原文：古籍引文 {#p.l4.4.b}
> 爱其子，择师而教之；于其身也，则耻师焉，惑矣。彼童子之师，授之书而习其句读者，非吾所谓传其道、解其惑者也。句读之不知，惑之不解，或师焉，或不焉，小学而大遗，吾未见其明也。
译文：疼爱孩子，挑选老师教他；轮到自己，却以从师为耻，真叫人费解。儿童的老师教读书、练句读，和我说的传道解惑的老师用意有别。不懂句读、不解道理，这些人一项肯求师，一项却不肯。小处肯学，大处反而丢了，我看不出这是明智。

## 找原文证据：谁问的哪一句话，使卖者没法把两件货分开来夸？ {#q.l4.4.1}
考点：skill.l4.4.a
语境：p.l4.4.a

- [ ] 其人弗能应也 {#q.l4.4.1.o1}
  理由：“弗能应”是卖者答不出话。让他答不出的那句追问在前面。
- [ ] 又誉其矛曰 {#q.l4.4.1.o2}
  理由：这里开始第二次夸口，尚未让两物相遇。
- [x] 以子之矛陷子之楯，何如 {#q.l4.4.1.o3}

提示：卖者夸完两件货，听的人怎样问他？
解析：“以子之矛陷子之楯”把卖者的两件货放在了一起。刺得穿还是刺不穿？无论他怎么答，总得收回前面的一句。

## 单选：作者由卖者无言能够推出什么？ {#q.l4.4.2}
考点：skill.l4.4.b
语境：p.l4.4.a

- [ ] 卖者说的两句话一定都假 {#q.l4.4.2.o1}
  理由：推出不能兼真，尚不能指定每句话的真假。
- [x] 两项不留例外的夸口不能同时成立 {#q.l4.4.2.o2}
- [ ] 没有任何人能回答任何关于矛楯的问题 {#q.l4.4.2.o3}
  理由：难题来自这两项特定断言同时成立的要求。

提示：留意末句“不可”后紧接的范围。
解析：“不可同世而立”只够说明两说不能都真。段中没人实际试过，究竟哪件货夸过了头，还不能断定。

## 单选：如果卖者只说“我的盾通常很坚固”，原来的问法为什么难不住他了？ {#q.l4.4.3}
考点：skill.l4.4.a
语境：p.l4.4.a

- [ ] 卖者一沉默便能证明两项性质都成立 {#q.l4.4.3.o1}
  理由：沉默不是性质的证据。
- [x] “通常”给具体反例留下余地 {#q.l4.4.3.o2}
- [ ] 盾只要改称别的名字就不再是原物 {#q.l4.4.3.o3}
  理由：改动的是量词，物件没换。

提示：比较“通常”与“莫能”。
解析：“通常坚固”留着例外。即使这支矛能刺穿它，也不必推翻“通常”这句话；原来的“莫能陷”却不容有例外。

## 单选：“其人弗能应也”在段中与末句怎样分工？ {#q.l4.4.4}
考点：skill.l4.4.b
语境：p.l4.4.a

- [x] 先记问答受阻，再揭示受阻的理由 {#q.l4.4.4.o1}
- [ ] 两句都是卖者继续吆喝的话 {#q.l4.4.4.o2}
  理由：末句“夫”引出作者的概括。
- [ ] 先证明盾已被穿透，再记交易失败 {#q.l4.4.4.o3}
  理由：原文没有实验，也未说交易结果。

提示：一句写卖者当场的反应，一句写作者从中看出了什么。
解析：“弗能应”先记卖者答不上来。末句再从故事里退一步，说明两句夸口彼此相冲，所以他难以回答。

## 找原文证据：哪句写这位家长轮到自己求师时是什么态度？ {#q.l4.4.5}
考点：skill.l4.4.a
语境：p.l4.4.b

- [ ] 授之书而习其句读者 {#q.l4.4.5.o1}
  理由：这里在说教孩子的老师教什么，还没说家长自己肯不肯求教。
- [ ] 爱其子 {#q.l4.4.5.o2}
  理由：爱孩子、肯为孩子择师，是比较的一边。另一边要看他怎样对待自己从师。
- [x] 于其身也，则耻师焉 {#q.l4.4.5.o3}

提示：先找其子，再找这个成人自己。
解析：先是“其子”，接着是“其身”。同一个家长替孩子找老师，轮到自己，却觉得从师丢人。

## 单选：“吾未见其明也”批评什么？ {#q.l4.4.6}
考点：skill.l4.4.b
语境：p.l4.4.b

- [ ] 父亲绝不可能兼有爱子与耻师两种行为 {#q.l4.4.6.o1}
  理由：开头就把两件事写成现实中的做法。
- [ ] 教授儿童句读的人全无价值 {#q.l4.4.6.o2}
  理由：韩愈区分所教内容，所批评的是取舍。
- [x] 肯学小处却搁下更重要的疑惑，这种取舍欠明智 {#q.l4.4.6.o3}

提示：接回它前面的“小学而大遗”。
解析：句读不懂，家长肯为孩子择师；自己有更大的疑惑，反倒羞于求教。“小学而大遗”说的是这种轻重取舍。

## 排序：整理韩愈把两种选择放在一起检验的过程。 {#q.l4.4.7}
考点：skill.l4.4.a
语境：p.l4.4.b

- [3] 追问小处学、大处遗是否明智 {#q.l4.4.7.o1}
  理由：“小学而大遗”是把两种学习选择比较后的评价。
- [2] 分清习句读与传道解惑 {#q.l4.4.7.o2}
  理由：“彼童子之师”接着界定小处所学。
- [1] 并置为子择师和自己耻师 {#q.l4.4.7.o3}
  理由：文章以家长在两个角色上的不同选择起笔。

提示：先人物，再教学内容，末了评价。
解析：先读家长怎样对待孩子和自己，再看这两处究竟想学什么。辨清句读与传道解惑的轻重，才懂结尾那句批评。

## 单选：将此段与卖者故事并读，哪项准确？ {#q.l4.4.8}
考点：skill.l4.4.b
语境：p.l4.4.b

- [x] 卖者的断言不能兼真，家长的做法能够并存却失当 {#q.l4.4.8.o1}
- [ ] 韩愈也通过一句无法回答的交易问题结束文章 {#q.l4.4.8.o2}
  理由：韩愈收在对求学取舍的评价。
- [ ] 两文都证明故事中人物从未真正存在 {#q.l4.4.8.o3}
  理由：两文议论的是说法或行为，没有否定人物存在。

提示：对读“不可同世而立”和“未见其明”。
解析：两项夸口无法兼真；为儿子求师又自己耻师，却是韩愈眼前就有的事。他问的是这样选到底明不明智。
