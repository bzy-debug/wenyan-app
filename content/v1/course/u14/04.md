# 课文：拿矛刺盾，和替孩子择师，是同一种矛盾吗？ {#l4.4}
简介：读两篇不肯听任人自圆其说的文章。韩非让两句话相遇，韩愈却让同一个大人回头看自己如何行事。

## 正文

楚人先说盾“莫能陷”，请把这句话想成一个承诺：这支矛也在不能刺穿它的兵器里。等他又说自己的矛“于物无不陷”，同一面盾便又出现在必须被刺穿的东西里。问者不必挑选信哪句，只须问这一矛碰上这一盾会怎样。文末说“不可同世而立”，说的是这两种绝对许诺。

韩愈面对的倒是一件完全可能发生的事。家长肯给孩子择师，却怕别人看见自己向人求教。童子所学是“句读”，古书没有今天这样的标点，须有人教他在哪里断开；成人该求的还有明道解惑。轻重两项摆好，“小学而大遗”才是批评：小处肯学，大处却落下了。

不妨让两位作者各答一句“究竟哪里不对”。韩非能问“你的两句话要怎样同时算真”；韩愈能问“把该下功夫的事放在后面，这样的取舍可算明智”。读者若都答一句“前后矛盾”，正好丢掉了两篇的分别。

## 知识点：将两种说法置于同一条件下检验 {#skill.l4.4.a}
义项：分清不能同真的断言和可以并做却轻重失当的行为
领域：篇章
要诀：矛盾能真正相碰；求师的两件事也要放在同一个家长身上看。
讲解：“无不陷”将一切物件纳入，偏与“莫能陷”在这一面盾上相撞。去掉其中一个全称，原来的反问就不再管用。
例句：p.l4.4.a

## 知识点：追问反驳究竟推翻了什么 {#skill.l4.4.b}
义项：分清批评的对象与仍可保留的部分
领域：阅读技能
要诀：说“答不出”，究竟没证明哪一种兵器的好坏？
讲解：《师说》没有斥责教孩子句读。它保留初学的价值，驳的是大人顾得上孩子的句读却不肯求解自己的大惑。
例句：p.l4.4.b

## 原文：古籍引文 {#p.l4.4.a}
> 楚人有鬻楯与矛者，誉之曰：“吾楯之坚，莫能陷也。”又誉其矛曰：“吾矛之利，于物无不陷也。”或曰：“以子之矛陷子之楯，何如？”其人弗能应也。夫不可陷之楯与无不陷之矛，不可同世而立。
译文：楚国有个卖盾和矛的人，先夸自己的盾坚固得没东西能刺穿，又夸自己的矛锋利得什么都刺得穿。有人就问：“拿你的矛刺你的盾，怎么样？”他没法作答。既是绝对刺不穿的盾，又有无物不能穿的矛，两者不可能同时成立。
词注：鬻：读 yù，出售。
  陷：刺穿。
  或：有个人，指那位发问者。
出处：《韩非子·难一》节录

## 原文：古籍引文 {#p.l4.4.b}
> 爱其子，择师而教之；于其身也，则耻师焉，惑矣。彼童子之师，授之书而习其句读者，非吾所谓传其道、解其惑者也。句读之不知，惑之不解，或师焉，或不焉，小学而大遗，吾未见其明也。
译文：爱孩子，就替孩子选个老师来教；轮到自己，却把从师当作羞耻，这就糊涂了。教童子的老师教他读书、熟悉哪里停顿，并非我这里所说传道、解惑的人。不懂句读，尚肯找人教；心中有惑，反不求解。小处学习，大处遗漏，我看不出这有什么高明。
词注：耻师：以从师求教为耻。
  句读：“读”读 dòu，指诵读古书时的分句、停顿。
  遗：漏掉、舍下。

## 找原文证据：哪一句把卖者关于矛和盾的两番话，变成一次可以设想的相遇？ {#q.l4.4.1}
考点：skill.l4.4.a
语境：p.l4.4.a

- [ ] 吾矛之利，于物无不陷也 {#q.l4.4.1.o1}
  理由：这是矛的主人单方面夸矛。
- [ ] 夫不可陷之楯与无不陷之矛，不可同世而立 {#q.l4.4.1.o2}
  理由：这是作者作出的判断，试问已经提出。
- [x] 以子之矛陷子之楯，何如 {#q.l4.4.1.o3}

提示：看哪句话既说“你的矛”，又说“你的盾”。
解析：问者没有另找兵器。他就让同一人的两件货物碰在一起，使“无不”与“莫能”不能相安。

## 单选：楚人答不出，读者能据此判定矛在实战中一定刺不穿盾吗？ {#q.l4.4.2}
考点：skill.l4.4.b
语境：p.l4.4.a

- [ ] 能；在答不出之前，卖者没有收回盾很坚的判断 {#q.l4.4.2.o1}
  理由：没收回也仍是他的自夸，不能代替一次真实的试验。
- [x] 不能；可断定的是两句夸口至少有一句站不住 {#q.l4.4.2.o2}
- [ ] 能；“弗能应”就是口头承认矛刺不穿 {#q.l4.4.2.o3}
  理由：沉默没有表明究竟哪件货物的说法失实。

提示：区分文中实际发生的言语和提问里假设的试验。
解析：如果刺穿，盾的说法破产；如果刺不穿，矛的说法破产。无须知道试验的真实结果，也能检验两句总括。

## 单选：若卖者只说“这支矛能刺穿好些盾”，原来那一问还能同样逼出矛盾吗？ {#q.l4.4.3}
考点：skill.l4.4.a
语境：p.l4.4.a

- [ ] 能；矛可以刺穿别的盾，这一面至少也该留下伤痕 {#q.l4.4.3.o1}
  理由：“好些”没有交代这一面是否包含在内，更未描述试验。
- [x] 不能；“好些”可以不包括他正在卖的这一面 {#q.l4.4.3.o2}
- [ ] 能；既是兵器就必有一件劣质 {#q.l4.4.3.o3}
  理由：质量好坏和两句断言能否同真是两回事。

提示：原文中哪一个字把这面盾也算进矛所能刺的东西？
解析：原句“于物无不陷”罩住一切物件，因而也罩住这面盾。只说“好些”以后，这个包含关系就没有了。

## 单选：若有人总结“韩非劝买东西之前先验货”，漏掉了结尾中的哪层意思？ {#q.l4.4.4}
考点：skill.l4.4.b
语境：p.l4.4.a

- [x] 两种绝对性质放在同一世界里，本就无法同时成立 {#q.l4.4.4.o1}
- [ ] 作者已替买主挑出应该购买的那一件 {#q.l4.4.4.o2}
  理由：结尾没判哪件好用。
- [ ] 讲买卖故事的目的是替这位卖者选择哪句该撤回 {#q.l4.4.4.o3}
  理由：原文判两句不能同真，没指定必须撤回哪一句。

提示：读“不可同世而立”，它把问题从一桩交易移到哪里？
解析：末句判断的是两种性质是否相容。关于购物的提醒纵然有用，也没有说出韩非这里的推论。

## 找原文证据：韩愈把同一个人安排师长的两种做法并列。哪一处转回这位成人自己？ {#q.l4.4.5}
考点：skill.l4.4.a
语境：p.l4.4.b

- [ ] 择师而教之 {#q.l4.4.5.o1}
  理由：这里说他为孩子寻师。
- [ ] 彼童子之师 {#q.l4.4.5.o2}
  理由：这里是在解释孩子的老师教到哪一步。
- [x] 于其身也，则耻师焉 {#q.l4.4.5.o3}

提示：先分“其子”与“其身”，再看是谁以从师为耻。
解析：孩子有师，家长自己却不肯问师。后面谈句读与解惑，要说明两种待遇的轻重。

## 单选：“非吾所谓传其道、解其惑者也”是否在责怪教孩子识句读的老师？ {#q.l4.4.6}
考点：skill.l4.4.b
语境：p.l4.4.b

- [ ] 是在说这些老师都不通文理，误导了孩子 {#q.l4.4.6.o1}
  理由：“授之书而习其句读”承认他们承担初学工作。
- [ ] 是在说孩子学会句读就解决了成人的疑惑 {#q.l4.4.6.o2}
  理由：韩愈接着特意把这两件事分开。
- [x] 这里先划出两种教学任务，批评随后落在成人的取舍上 {#q.l4.4.6.o3}

提示：“于其身也”先说了谁，“小学而大遗”又说谁？
解析：童子之师做的是教读书的事；有惑的成人自己却不肯求师。作者特意分清所指，才避免把批评落错人。

## 排序：从“爱其子”读到“吾未见其明也”，依次发生哪三步判断？ {#q.l4.4.7}
考点：skill.l4.4.a
语境：p.l4.4.b

- [3] 由所取所舍判其轻重倒置 {#q.l4.4.7.o1}
  理由：“小学而大遗”点明具体取舍，末句作出总评。
- [2] 分清授句读和传道解惑的任务 {#q.l4.4.7.o2}
  理由：中间解释为何不能用孩子有老师来抵消家长的不足。
- [1] 指出对子女求师，对自己却以从师为耻 {#q.l4.4.7.o3}
  理由：两面的实际行为先摆出。

提示：先找两个人的位置，再找学什么，最后找作者评语。
解析：韩愈先摆出两种做法，说了一声“惑矣”。等到分清句读和解惑两件事，他才点明这糊涂究竟在哪里：小处肯学，大处却放过了。

## 单选：一面替孩子择师，一面不肯自己求师，在事实上完全做得到。韩愈批评它，依据是什么？ {#q.l4.4.8}
考点：skill.l4.4.b
语境：p.l4.4.b

- [x] 求小而失大，把更需要解决的困惑留了下来 {#q.l4.4.8.o1}
- [ ] 两件事如矛与盾一样，绝无可能同时发生 {#q.l4.4.8.o2}
  理由：文中恰恰说有人同时这样做。
- [ ] 师道已断，天下没有能教大人的教师 {#q.l4.4.8.o3}
  理由：这一段没有清点教师人数。

提示：把“小学而大遗”读成一句关于取舍的评价。
解析：卖者的两句夸口放在一起便有一句要落空。家长替孩子择师和自己不肯求师却可以同时发生，韩愈追问的是为什么小处肯学，大处反而丢下。
