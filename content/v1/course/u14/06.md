# 课文：苏洵怎样解释六国的败亡 {#l4.6}
简介：没有割地的国家为什么也灭亡？苏洵先接下这个难题，再设想六国本来还能怎样做。

## 正文

“弊在赂秦”，苏洵立刻替读者追问：六国难道都曾贿赂秦国吗？回答时，他没有硬说每一国都割了地，而是多说了一步：有的诸侯割地，自家力量受损，原先能倚靠他们的邻国也就失去援助，很难独自保全。“不赂者以赂者丧”要把两个国家分开才能读明白。

“向使”是“假使当初”。从这里起，苏洵把各国已经作过的选择换了一遍，再问这样与秦较量，胜负会如何。“或未易量”只说难以预料。倘若读成“联军必胜”，就把他特意留下的“或”抹去了。

## 知识点：作者怎样解释败因 {#skill.l4.6.a}
义项：看作者怎么回应例外、设想别的选择，从中读出他认为败在哪里
领域：篇章
要诀：割地的国家先失去什么？哪个邻国也跟着吃亏？
讲解：割地者自损国力，未割地者也可能因此失掉强援。“不能独完”说的正是少了盟友以后难以独存的国家。
例句：p.l4.6.a

## 知识点：史论的假设语气 {#skill.l4.6.b}
义项：分清史实、他人提出的疑问，以及作者对未发生之事的推想
领域：阅读技能
要诀：这句是在质疑，在假设，还是在估量胜负？
讲解：“或曰”引出另一个人的疑问；“向使”假设当初另有选择；“或未易量”才说胜负或许难料。要逐句给它留足分寸。
例句：p.l4.6.b

## 原文：古籍引文 {#p.l4.6.a}
> 六国破灭，非兵不利、战不善，弊在赂秦。赂秦而力亏，破灭之道也。或曰：“六国互丧，率赂秦耶？”曰：“不赂者以赂者丧。盖失强援，不能独完。故曰弊在赂秦也。”
译文：六国覆灭，问题不在兵器不利、仗打不好，弊端在割地贿秦。割地使自己力量亏损，是走向覆灭的路。有人问，六国相继灭亡，难道全割地了吗？作者答，不割地的也因割地者而亡，因为失去强援，无法单独保全。所以仍说弊端在割地贿秦。

## 原文：古籍引文 {#p.l4.6.b}
> 向使三国各爱其地，齐人勿附于秦，刺客不行，良将犹在，则胜负之数、存亡之理，当与秦相较，或未易量。呜呼！以赂秦之地封天下之谋臣，以事秦之心礼天下之奇才，并力西向，则吾恐秦人食之不得下咽也。
译文：假使三国各自珍惜土地，齐国不依附秦，刺客不去，良将还在，那么与秦较量，胜负存亡或许不容易断定。若用贿秦的土地封赏谋臣，用侍奉秦的心意礼遇奇才，合力向西抗秦，那么恐怕秦人连饭也吃不安稳了。

## 单选：没有割地的国家，怎么也会因邻国割地而灭亡？ {#q.l4.6.1}
考点：skill.l4.6.a
语境：p.l4.6.a

- [ ] 强援本来就是秦国 {#q.l4.6.1.o1}
  理由：“失强援”的是不能独完的诸侯。
- [x] 他国失势会使未赂秦者失去援助 {#q.l4.6.1.o2}
- [ ] 没有赂秦的国家暗中也送了地 {#q.l4.6.1.o3}
  理由：作者保留“不赂者”的事实。

提示：把两个“者”分写成不同国家。
解析：割地者损失的是自己的地和国力。另一些国家没有割地，却少了有力的盟友，这才是苏洵用来回答异议的理由。

## 找原文证据：哪句话是设想的反对者提出的问题？ {#q.l4.6.2}
考点：skill.l4.6.b
语境：p.l4.6.a

- [ ] 盖失强援，不能独完 {#q.l4.6.2.o1}
  理由：“盖失强援”已经是在解释为什么没割地也会亡。提出异议的是之前发问的人。
- [ ] 赂秦而力亏 {#q.l4.6.2.o2}
  理由：“赂秦而力亏”是苏洵先立下的主张。发难者接下来才问是否每国都曾割地。
- [x] 六国互丧，率赂秦耶 {#q.l4.6.2.o3}

提示：“或曰”后谁开始说话？
解析：“或曰”就是“有人问”。提出“率赂秦耶”的人怀疑六国是否全都贿秦，随后单独一个“曰”才接回作者的回答。

## 排序：按作者对未赂秦者的解释，排出因果顺序。 {#q.l4.6.3}
考点：skill.l4.6.a
语境：p.l4.6.a

- [3] 孤立的国家难以独自保全 {#q.l4.6.3.o1}
  理由：“不能独完”在失援之后，才是所要解释的结果。
- [2] 未割地者失去强大外援 {#q.l4.6.3.o2}
  理由：“失强援”是另一方随之承受的影响。
- [1] 其他诸侯割地而力量受损 {#q.l4.6.3.o3}
  理由：“赂秦而力亏”首先发生在愿意割地的一方。

提示：先看割了地的一国，再看原先能请它帮忙的邻国。
解析：先有割地者力量减弱，再有盟友少了强援，最后写未割地者不能独存。从一国的损失，才说到另一国的结局。

## 单选：按开篇的主张，哪一句超出了苏洵的表述？ {#q.l4.6.4}
考点：skill.l4.6.b
语境：p.l4.6.a

- [x] 六国每一仗都获胜，兵器也毫无缺陷 {#q.l4.6.4.o1}
- [ ] 苏洵把割地作为覆亡的主要病因 {#q.l4.6.4.o2}
  理由：“弊在赂秦”明确这样立论。
- [ ] 开篇主动排除了两种常见的总解释 {#q.l4.6.4.o3}
  理由：“非兵不利、战不善”做了这一步。

提示：区分否定总病因与给每一仗下判断。
解析：说覆亡的主要病根不在兵器、作战，并不等于说每一件兵器都好用、每一仗都打赢。开头谈的是六国相继破灭的大局。

## 找原文证据：哪四字写出替代方案里诸侯重新合力的动作？ {#q.l4.6.5}
考点：skill.l4.6.a
语境：p.l4.6.b

- [ ] 齐人勿附于秦 {#q.l4.6.5.o1}
  理由：“齐人勿附于秦”只说齐国应当怎样选择。诸侯一起行动，要看带“并”的那一句。
- [x] 并力西向 {#q.l4.6.5.o2}
- [ ] 良将犹在 {#q.l4.6.5.o3}
  理由：良将若在，是诸侯尚可倚仗的条件之一；“犹在”还没有写各国合力的动作。

提示：找一个有方向的共同动作。
解析：“并力”是大家把力气合起来，“西向”是一起对着西边的秦。前面的爱地、保将都说各自该做什么，这里才写合力。

## 单选：“或未易量”说到了什么程度？能读成六国一定会赢吗？ {#q.l4.6.6}
考点：skill.l4.6.b
语境：p.l4.6.b

- [x] 少了承诺确定的胜者，只说胜负很难预定 {#q.l4.6.6.o1}
- [ ] 少了对未发生情形的设想 {#q.l4.6.6.o2}
  理由：“向使”正是设想的起点。
- [ ] 少了提及秦国的名字 {#q.l4.6.6.o3}
  理由：前面紧接“与秦相较”。

提示：留意“或”和“未易”的分量。
解析：“向使”以下都是假设。即使各种条件真能改变，苏洵也只说胜负或许难料，没有替六国断定最后一定获胜。

## 单选：“以赂秦之地封天下之谋臣”在替代方案中改变了什么？ {#q.l4.6.7}
考点：skill.l4.6.a
语境：p.l4.6.b

- [x] 同一资源的去向，由资敌改为招致本方人才 {#q.l4.6.7.o1}
- [ ] 割给秦的地凭空增加了一倍 {#q.l4.6.7.o2}
  理由：句子重分资源，未增添土地。
- [ ] 谋臣取代秦国成为六国的敌国 {#q.l4.6.7.o3}
  理由：“封”是给谋臣封赏。

提示：为两个“以”分别找出资源和受益者。
解析：同一份土地，拿去送秦会削弱自己，拿去封赏谋臣则能招揽人才。改变的是诸侯把手上的东西用在谁身上。

## 单选：“秦人食之不得下咽”应怎样写进阅读笔记？ {#q.l4.6.8}
考点：skill.l4.6.b
语境：p.l4.6.b

- [ ] 秦王在当时诸侯已经合力之后的真实反应 {#q.l4.6.8.o1}
  理由：诸侯合力也是设想的一部分，不能先当作史实。
- [x] 苏洵在一组假设后的形象推测，写秦可能感到巨大威胁 {#q.l4.6.8.o2}
- [ ] 史书记载秦人因某次宴会而废食 {#q.l4.6.8.o3}
  理由：这句话处在“则吾恐”之后。

提示：留意引出结果的“则吾恐”。
解析：“则吾恐”紧跟合力抗秦的设想。饭都吃不下，是苏洵借来形容秦人届时会有多大压力，尚未写成史实。
