# 课文：六国论的异议与假设 {#l4.6}
简介：跟踪苏洵如何回应反例，并给没有发生的另一条历史保留余地。

## 正文

“弊在赂秦”刚说完，一个声音便问：六国难道全都割地了吗？若把开头硬读为每一国都亲自割地，反例确实棘手。作者转而说明盟友的作用，把没有割地的国家也放进因果链。

“向使”领起另一个过去。这一段重新安排各国的选择，再用“或未易量”说胜负可能另当别论。作者没有记载一场联军获胜的战争；这个设想是为了给真实执政者留下警戒。

## 知识点：驳复中的致败机制 {#skill.l4.6.a}
义项：从反例或替代方案复原作者所说的致败途径
领域：篇章
要诀：追问割地如何改变整个联盟的处境
讲解：把个人或一国的行动与他者所受的间接影响分开，再读整体因果。
例句：p.l4.6.a

## 知识点：史论的假设语气 {#skill.l4.6.b}
义项：区分史实、发难与反事实判断的承诺程度
领域：阅读技能
要诀：圈出“或曰”“向使”“或”等话语标记
讲解：先确定谁说、是否假设，再判断作者究竟声称必然、可能，还是只是在发问。
例句：p.l4.6.b

## 原文：古籍引文 {#p.l4.6.a}
> 六国破灭，非兵不利、战不善，弊在赂秦。赂秦而力亏，破灭之道也。或曰：“六国互丧，率赂秦耶？”曰：“不赂者以赂者丧。盖失强援，不能独完。故曰弊在赂秦也。”
译文：六国覆灭，问题不在兵器不利、仗打不好，弊端在割地贿秦。割地使自己力量亏损，是走向覆灭的路。有人问，六国相继灭亡，难道全割地了吗？作者答，不割地的也因割地者而亡，因为失去强援，无法单独保全。所以仍说弊端在割地贿秦。

## 原文：古籍引文 {#p.l4.6.b}
> 向使三国各爱其地，齐人勿附于秦，刺客不行，良将犹在，则胜负之数、存亡之理，当与秦相较，或未易量。呜呼！以赂秦之地封天下之谋臣，以事秦之心礼天下之奇才，并力西向，则吾恐秦人食之不得下咽也。
译文：假使三国各自珍惜土地，齐国不依附秦，刺客不去，良将还在，那么与秦较量，胜负存亡或许不容易断定。若用贿秦的土地封赏谋臣，用侍奉秦的心意礼遇奇才，合力向西抗秦，那么恐怕秦人连饭也吃不安稳了。

## 单选：“不赂者以赂者丧”补入了哪条新联系？ {#q.l4.6.1}
考点：skill.l4.6.a
语境：p.l4.6.a

- [ ] 强援本来就是秦国 {#q.l4.6.1.o1}
  理由：“失强援”的是不能独完的诸侯。
- [x] 他国失势会使未赂秦者失去援助 {#q.l4.6.1.o2}
- [ ] 没有赂秦的国家暗中也送了地 {#q.l4.6.1.o3}
  理由：作者保留“不赂者”的事实。

提示：把两个“者”分写成不同国家。
解析：割地对一国是自损，对盟友则意味着可以依赖的力量减弱。

## 找原文证据：哪句话是设想的反对者提出的问题？ {#q.l4.6.2}
考点：skill.l4.6.b
语境：p.l4.6.a

- [ ] 盖失强援，不能独完 {#q.l4.6.2.o1}
  理由：这是对反例的回答。
- [ ] 赂秦而力亏 {#q.l4.6.2.o2}
  理由：这是作者的因果判断。
- [x] 六国互丧，率赂秦耶 {#q.l4.6.2.o3}

提示：“或曰”后谁开始说话？
解析：设问的声音挑战论点能否覆盖全部六国，后一个“曰”才回应它。

## 排序：按作者对未赂秦者的解释，排出因果顺序。 {#q.l4.6.3}
考点：skill.l4.6.a
语境：p.l4.6.a

- [3] 孤立的国家难以独自保全 {#q.l4.6.3.o1}
  理由：“不能独完”在失援之后，才是所要解释的结果。
- [2] 未割地者失去强大外援 {#q.l4.6.3.o2}
  理由：“失强援”是另一方随之承受的影响。
- [1] 其他诸侯割地而力量受损 {#q.l4.6.3.o3}
  理由：“赂秦而力亏”首先发生在愿意割地的一方。

提示：从他国变化移向自身处境。
解析：直接受损和间接受损是两步，合在一起才回答未赂国家为何也亡。

## 单选：按开篇的主张，哪一句超出了苏洵的表述？ {#q.l4.6.4}
考点：skill.l4.6.b
语境：p.l4.6.a

- [x] 六国每一仗都获胜，兵器也毫无缺陷 {#q.l4.6.4.o1}
- [ ] 苏洵把割地作为覆亡的主要病因 {#q.l4.6.4.o2}
  理由：“弊在赂秦”明确这样立论。
- [ ] 开篇主动排除了两种常见的总解释 {#q.l4.6.4.o3}
  理由：“非兵不利、战不善”做了这一步。

提示：区分否定总病因与给每一仗下判断。
解析：排除兵器与作战作为总解释，不能推出每一战无败、每件兵器皆优。

## 找原文证据：哪四字写出替代方案里诸侯重新合力的动作？ {#q.l4.6.5}
考点：skill.l4.6.a
语境：p.l4.6.b

- [ ] 齐人勿附于秦 {#q.l4.6.5.o1}
  理由：这是单就齐国所改的条件。
- [x] 并力西向 {#q.l4.6.5.o2}
- [ ] 良将犹在 {#q.l4.6.5.o3}
  理由：这是希望保住的力量之一。

提示：找一个有方向的共同动作。
解析：“并力”把各自分散的力量合起来，“西向”交代向秦。

## 单选：“或未易量”比“必胜秦”少承诺了什么？ {#q.l4.6.6}
考点：skill.l4.6.b
语境：p.l4.6.b

- [x] 少了承诺确定的胜者，只说胜负很难预定 {#q.l4.6.6.o1}
- [ ] 少了对未发生情形的设想 {#q.l4.6.6.o2}
  理由：“向使”正是设想的起点。
- [ ] 少了提及秦国的名字 {#q.l4.6.6.o3}
  理由：前面紧接“与秦相较”。

提示：留意“或”和“未易”的分量。
解析：作者先改变条件，再重开胜负问题，没有宣布历史本必改写成胜利。

## 单选：“以赂秦之地封天下之谋臣”在替代方案中改变了什么？ {#q.l4.6.7}
考点：skill.l4.6.a
语境：p.l4.6.b

- [x] 同一资源的去向，由资敌改为招致本方人才 {#q.l4.6.7.o1}
- [ ] 割给秦的地凭空增加了一倍 {#q.l4.6.7.o2}
  理由：句子重分资源，未增添土地。
- [ ] 谋臣取代秦国成为六国的敌国 {#q.l4.6.7.o3}
  理由：“封”是给谋臣封赏。

提示：为两个“以”分别找出资源和受益者。
解析：土地与敬意原先投向秦，设想中转给人才，从而有望加强合力。

## 单选：“秦人食之不得下咽”应怎样写进阅读笔记？ {#q.l4.6.8}
考点：skill.l4.6.b
语境：p.l4.6.b

- [ ] 秦王在当时诸侯已经合力之后的真实反应 {#q.l4.6.8.o1}
  理由：诸侯合力也是设想的一部分，不能先当作史实。
- [x] 苏洵在一组假设后的形象推测，写秦可能感到巨大威胁 {#q.l4.6.8.o2}
- [ ] 史书记载秦人因某次宴会而废食 {#q.l4.6.8.o3}
  理由：这句话处在“则吾恐”之后。

提示：留意引出结果的“则吾恐”。
解析：“恐”保留推量，“不得下咽”把政治压力写成身体感受。
