# 课文：六国并非国国赂秦，苏洵怎样回应？ {#l4.6}
简介：“六国破灭”和“每一国都赂秦”不是同一句话。跟着文中的提问人，看作者怎样把论点补完整。

## 正文

先把篇首缩到两个因果句：割地事秦会亏损自身力量；自身亏损会一步步走向破灭。假想的问者专挑没有割地的国家来问，打断了这个读来顺畅的解释。苏洵要保住他的论点，至少要说清另一个国家怎样受牵连。

“盖失强援”给出中间那一环。若周围可援之国都因赂秦变弱，不赂的国家也难独存。这里旁证的是联盟关系，未要求把每个国家的所作所为都说成一样。把“或曰”的问话和“曰”的回答互换，理由与质疑就会倒置。

后段开出另一份历史：“向使”领起几个作者明知没有同时成为现实的条件，到“或未易量”，他连结果也没有说满。至于秦人饭都吃不下，已是顺着这套设想写出忧惧，用来说明合力的威力，不能摘作战果。

## 知识点：沿直接与间接两路重建败因 {#skill.l4.6.a}
义项：说明作者怎样将一项反例接回自己的解释
领域：篇章
要诀：一边写“赂者力亏”，另一边写“不赂者失去谁”。
讲解：苏洵正面承认有不赂之国。用“失强援”补上间接影响，他才能让总论不必依赖所有国家都亲手赂秦。
例句：p.l4.6.a

## 知识点：辨明史论里的未然语气 {#skill.l4.6.b}
义项：划清史事、反事实条件和作者设想的结果
领域：阅读技能
要诀：从“向使”读至“则”，再辨“或”“吾恐”各保留了什么。
讲解：拟想另一条历史道路可用来质疑败亡是否必然。文本中条件具体到国家、刺客和良将，也不会因此变成实际战史。
例句：p.l4.6.b

## 原文：古籍引文 {#p.l4.6.a}
> 六国破灭，非兵不利、战不善，弊在赂秦。赂秦而力亏，破灭之道也。或曰：“六国互丧，率赂秦耶？”曰：“不赂者以赂者丧。盖失强援，不能独完。故曰弊在赂秦也。”
译文：六国灭亡，症结不在兵器不锐、作战不善，而在以财地求秦宽容。贿赂秦国耗损自己力量，是走向破灭的路。有人问：“六国接连亡了，难道全都贿赂秦国吗？”回答说：“没贿赂的也因贿赂的那些国家而亡。失去有力外援，无法独自保全，所以说毛病在赂秦。”
词注：弊：症结、祸根。
  率：一概、全都。
  完：保全自己。
出处：《六国论》节录

## 原文：古籍引文 {#p.l4.6.b}
> 向使三国各爱其地，齐人勿附于秦，刺客不行，良将犹在，则胜负之数、存亡之理，当与秦相较，或未易量。呜呼！以赂秦之地封天下之谋臣，以事秦之心礼天下之奇才，并力西向，则吾恐秦人食之不得下咽也。
译文：假如那三国各自珍惜土地，齐国不依附秦国，刺客不出行，良将仍在，那么拿双方相比，谁胜谁负、谁存谁亡，或许就没那么好说了。要是把割给秦国的土地用来封赏谋臣，把讨好秦国的心思用来礼待奇才，合力向西对付秦，我怕秦人连饭都咽不下去。
词注：向使：假使当年。
  数：在“胜负之数”里指形势、定数。
  礼：礼遇，以礼相待。

## 单选：首句说“弊在赂秦”，假想的问者挑出了哪一种国家作为难题？ {#q.l4.6.1}
考点：skill.l4.6.a
语境：p.l4.6.a

- [ ] 兵器本来锐利、作战也很出色的秦国 {#q.l4.6.1.o1}
  理由：问者问的是六国是否“率赂”，没有评秦军强弱。
- [x] 同样灭亡却没拿土地财物去讨好秦的国家 {#q.l4.6.1.o2}
- [ ] 已经贿赂秦国、而且自始至终平安的国家 {#q.l4.6.1.o3}
  理由：问者以六国“互丧”为前提。

提示：把“率”换成“全都”，看质疑落在哪里。
解析：若六国都因自己贿秦才灭亡，不贿秦的一国便构成反例。苏洵接下来要解的正是这个难处。

## 找原文证据：苏洵怎样补上“别人赂秦”到“自己也亡”的中间一步？ {#q.l4.6.2}
考点：skill.l4.6.b
语境：p.l4.6.a

- [ ] 赂秦而力亏 {#q.l4.6.2.o1}
  理由：这是直接讲赂者自身实力的损失。
- [ ] 六国互丧 {#q.l4.6.2.o2}
  理由：这句话陈列需要解释的结局，还没有给原因。
- [x] 盖失强援，不能独完 {#q.l4.6.2.o3}

提示：找“盖”领起的那句话。
解析：不赂者也要依靠盟友，一旦强援削弱，独力就难以保全。两个败因说的是不同环节。

## 排序：按对话的推进，把苏洵自己的断言、读者可能的反问和回答放回原位。 {#q.l4.6.3}
考点：skill.l4.6.a
语境：p.l4.6.a

- [3] 说明未曾贿秦者也会因盟援丧失而亡 {#q.l4.6.3.o1}
  理由：答者解释了同一病根的间接作用。
- [2] 追问六国是否全曾以财地事秦 {#q.l4.6.3.o2}
  理由：“率赂秦耶”把个别情形当作考验。
- [1] 先说赂秦耗去国力，因此是败亡的病根 {#q.l4.6.3.o3}
  理由：这是“或曰”之前的立论。

提示：用“或曰”和紧随其后的“曰”分清两人的话。
解析：结尾重复开头的判断时，已经多说明一件事：行为虽有不同，所受的损害可以相连。

## 单选：把“非兵不利、战不善”解释成“六国每次作战都获胜”，问题出在哪里？ {#q.l4.6.4}
考点：skill.l4.6.b
语境：p.l4.6.a

- [x] 作者在排除他认为的主要病根，未列举每场战事的结果 {#q.l4.6.4.o1}
- [ ] 凡有“不善”二字就表示六国不曾善战 {#q.l4.6.4.o2}
  理由：“不善”处在“非”所统摄的说法里。
- [ ] “赂秦而力亏”只在称赞六国本有作战的本领 {#q.l4.6.4.o3}
  理由：苏洵以此句说明贿赂削弱国力，焦点仍是败因。

提示：先问这句话回答的是“为什么亡”还是“哪一战取胜”。
解析：段首在争败因。把否定一种解释扩大成关于所有战役的纪录，就超出了这一段。

## 找原文证据：后段的哪一句容许另一种胜负，却没有保证它？ {#q.l4.6.5}
考点：skill.l4.6.a
语境：p.l4.6.b

- [ ] 刺客不行 {#q.l4.6.5.o1}
  理由：这是列在“向使”下的假设条件。
- [x] 或未易量 {#q.l4.6.5.o2}
- [ ] 并力西向 {#q.l4.6.5.o3}
  理由：这是作者设想的联合行动。

提示：找语气最不肯说死的几个字。
解析：“或”是或许，“未易量”是难以预料。苏洵为另一种可能留位置，而不是预报它一定发生。

## 单选：“向使”后面列四件事，哪一种读法不会把未发生的历史当作事实？ {#q.l4.6.6}
考点：skill.l4.6.b
语境：p.l4.6.b

- [x] 把爱惜土地、齐不附秦等都读成重设条件，再看结局还有没有把握 {#q.l4.6.6.o1}
- [ ] 苏洵从史书查出齐国确实没有依附秦 {#q.l4.6.6.o2}
  理由：“齐人勿附”在“向使”的范围里。
- [ ] 六国已有良将长存，所以战败只因一次失误 {#q.l4.6.6.o3}
  理由：“良将犹在”同样是作者重设的条件。

提示：试把句首换成“假如当年”。
解析：一直读到“则”才走出假设部分。前面列得再具体，也没有改变它们是反事实条件的身份。

## 单选：封赏谋臣、礼遇奇才这两句的力度来自什么安排？ {#q.l4.6.7}
考点：skill.l4.6.a
语境：p.l4.6.b

- [x] 把曾用于讨好秦的土地与心力，想象成用来扶持自己的人才 {#q.l4.6.7.o1}
- [ ] 宣称六国事实上已将这些地全给了各国贤者 {#q.l4.6.7.o2}
  理由：“以……封”“以……礼”描绘的是另一种用法。
- [ ] 谋臣和奇才各为不同国家所用，所以不能合力 {#q.l4.6.7.o3}
  理由：“并力西向”偏说这些用才的路数可以归于一处。

提示：两个“以”后跟的东西本来花在谁身上？
解析：还是那些土地和精力，改一个去向就出现另一种局面。苏洵借此使批评既有损失，也有可设想的出路。

## 单选：说“秦人食之不得下咽”，在这篇史论中怎样读最妥当？ {#q.l4.6.8}
考点：skill.l4.6.b
语境：p.l4.6.b

- [ ] 记录秦王某晚确曾因病不能进食 {#q.l4.6.8.o1}
  理由：段中无人观察秦王吃饭，“吾恐”还领着这句话。
- [x] 夸写秦人面对合力西向时的压力，仍在作者设想之内 {#q.l4.6.8.o2}
- [ ] 宣布六国若联合，秦必在当日亡国 {#q.l4.6.8.o3}
  理由：作者没有给战期与战果。

提示：留意“吾恐”是谁对何种局面作判断。
解析：末句把秦的忧惧写得可见。它延续此前的假设语气，不能反过来用作已发生战果的证据。
