# 检查：读《留侯论》：什么才算大勇 {#check.14}

## 原文：古籍引文 {#p.check.14.a}
> 古之所谓豪杰之士者，必有过人之节。人情有所不能忍者，匹夫见辱，拔剑而起，挺身而斗，此不足为勇也。天下有大勇者，卒然临之而不惊，无故加之而不怒，此其所挟持者甚大，而其志甚远也。
译文：古来称为豪杰的人，一定有超人的节操。常人遇到难以忍受的事，受辱就拔剑挺身争斗，这还算不上勇。真正大勇的人，突遇变故不惊，无故受辱不怒，因为他心里持守着大事，志向深远。
出处：《留侯论》节录

## 原文：古籍引文 {#p.check.14.b}
> 夫子房受书于圯上之老人也，其事甚怪，然亦安知其非秦之世有隐君子者，出而试之？观其所以微见其意者，皆圣贤相与警戒之义。世不察，以为鬼物，亦已过矣。且其意不在书。
译文：张良从桥上老人那里受书，事情很奇异，可又怎知不是秦时的隐士出面考验他呢？看老人委婉显露的意思，都合于贤人彼此警戒的道理。世人不细察，视为鬼神，也实在过头了。老人的用意不在书本本身。

## 单选：同样受辱，苏轼所说的常人和大勇者各怎样应对？ {#q.check.14.1}
考点：skill.l4.4.a
语境：p.check.14.a

- [x] 立即争斗，还是为了远志控制反应 {#q.check.14.1.o1}
- [ ] 受辱时身边是否带着书 {#q.check.14.1.o2}
  理由：这段说有人受辱便起而争斗，还没有谈老人授书。
- [ ] 豪杰是否从未遭受无故加害 {#q.check.14.1.o3}
  理由：作者特意设“无故加之”的情境。

提示：看“见辱”与“无故加之”后的动词。
解析：常人受辱，立刻拔剑争斗；苏轼称赞的大勇者遇到无故冒犯，却能忍住不怒。比较的是同样受辱之后的反应。

## 找原文证据：哪句直接撤回了常人对拔剑争斗的赞誉？ {#q.check.14.2}
考点：skill.l4.5.b
语境：p.check.14.a

- [x] 此不足为勇也 {#q.check.14.2.o1}
- [ ] 天下有大勇者 {#q.check.14.2.o2}
  理由：“天下有大勇者”开始正面说什么才算大勇。前一句才收回对逞勇的称许。
- [ ] 其志甚远也 {#q.check.14.2.o3}
  理由：这是苏轼在解释另一种人为什么能沉得住气。

提示：找指向前述举动的“此”。
解析：“此”指刚说的拔剑起而争斗，“不足为勇”就是认为做到这样还算不上大勇。

## 单选：作者给“无故加之而不怒”补上哪项解释？ {#q.check.14.3}
考点：skill.l4.6.a
语境：p.check.14.a

- [ ] 从未意识到别人加害 {#q.check.14.3.o1}
  理由：“加之”已设定外来的冒犯，作者另解释其不怒。
- [ ] 不敢承担争斗的后果 {#q.check.14.3.o2}
  理由：段中明提出的是“大”与“远”。
- [x] 心中持守的大事和长远的志向 {#q.check.14.3.o3}

提示：从“不怒”向后找“此其”。
解析：后文说他心里持守的事大、志向又远。有更要紧的事放在心上，才不肯为了眼前的冒犯打乱自己的打算。

## 单选：苏轼提到“秦之世有隐君子”，是已经认定老人的身份了吗？ {#q.check.14.4}
考点：skill.l4.6.b
语境：p.check.14.b

- [ ] 同意只有鬼神才能授书 {#q.check.14.4.o1}
  理由：他明确批评“以为鬼物”。
- [x] 提出可以解释此事的一种人间可能 {#q.check.14.4.o2}
- [ ] 确认老人是已知身份的秦代隐士 {#q.check.14.4.o3}
  理由：“安知其非”只提出可能，未列确定身分的证据。

提示：把“安知其非”换成现代汉语。
解析：“安知其非”就是怎么知道他不是呢？苏轼用隐士出面试人的解释，质疑非鬼神不足以说明此事的看法，并没查明老人的身份。

## 单选：世人怎样解释这桩怪事？苏轼又是怎么想的？ {#q.check.14.5}
考点：skill.l4.5.a
语境：p.check.14.b

- [x] 世人因事怪便归于鬼物，作者从老人的用意读成警戒 {#q.check.14.5.o1}
- [ ] 双方都只关心书的版本 {#q.check.14.5.o2}
  理由：“且其意不在书”明示作者另有关注。
- [ ] 世人见过老人，作者也做过当面访问 {#q.check.14.5.o3}
  理由：两者都在解释故事，段中未记采访。

提示：看“以为鬼物”与“观其所以”各取什么依据。
解析：世人只见事怪，便看作鬼神。苏轼细看老人怎样试探张良，觉得从贤者警戒后辈的用心也能解释得通。

## 找原文证据：哪一句提醒读者应换一个中心来解读授书一事？ {#q.check.14.6}
考点：skill.l4.4.b
语境：p.check.14.b

- [x] 且其意不在书 {#q.check.14.6.o1}
- [ ] 秦之世有隐君子者 {#q.check.14.6.o2}
  理由：隐君子是对老人身份的猜想。作者提醒人将目光从书上移开的话在段末。
- [ ] 其事甚怪 {#q.check.14.6.o3}
  理由：“其事甚怪”先承认桥上受书这件事奇异，还没挑明老人用意究竟在哪里。

提示：寻找明确否定字面事件中心的一句。
解析：“且其意不在书”是说授书背后还有用意。把这一句接到“出而试之”，便明白作者为何更关心老人怎样考验张良。
