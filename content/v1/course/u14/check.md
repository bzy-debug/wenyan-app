# 检查：《留侯论》：勇气可以从一时的隐忍看出来吗？ {#check.14}

## 原文：古籍引文 {#p.check.14.a}
> 古之所谓豪杰之士者，必有过人之节。人情有所不能忍者，匹夫见辱，拔剑而起，挺身而斗，此不足为勇也。天下有大勇者，卒然临之而不惊，无故加之而不怒，此其所挟持者甚大，而其志甚远也。
译文：古来称为豪杰的人，必有超过常人的节操。遇上一般人忍不住的事，普通人受辱便拔剑，挺身相斗，这还不配叫勇。天下有大勇的人，突发的事临头不惊，无端的冒犯加身不怒，因为他所怀抱的重大，所立的志向深远。
词注：见辱：受到侮辱。
  卒然：猝然，突如其来。
  挟持：此处说心中所持守、怀抱的东西。

## 原文：古籍引文 {#p.check.14.b}
> 夫子房受书于圯上之老人也，其事甚怪，然亦安知其非秦之世有隐君子者，出而试之？观其所以微见其意者，皆圣贤相与警戒之义。世不察，以为鬼物，亦已过矣。且其意不在书。
译文：张良从桥上老人手里受书，这事固然奇特，但怎知不是秦时一位隐居的君子特意出来试他？看老人以含蓄举动表露出的用意，无非是贤者之间互相警策的道理。世人未加细察，竟当成鬼神之事，也说过头了。何况老人的用意并不在那部书本身。
词注：圯：读 yí，桥。
  警戒：提醒、告诫。
  过：在“亦已过矣”里指说得过头。

## 单选：“拔剑而起”与“卒然临之而不惊”，作者在比较两种人遇到变故或冒犯时的哪一点？ {#q.check.14.1}
考点：skill.l4.4.a
语境：p.check.14.a

- [x] 能否稳住自己，不因惊怒立刻行动 {#q.check.14.1.o1}
- [ ] 有没有带兵打赢一场仗 {#q.check.14.1.o2}
  理由：两句都写遇事如何自处。
- [ ] 豪杰从未受辱，而匹夫必然常受辱 {#q.check.14.1.o3}
  理由：二者都被放在遭遇冲击的场合里。

提示：把“不能忍”与“不惊”“不怒”放在一起看。
解析：拔剑只在一瞬间。苏轼更看重的是，突来的变故没叫人慌张，无端的侮辱也没叫人发怒。后文还要问，这个人心里装着多大的事。

## 找原文证据：哪处反着常人的第一眼看法，直接否定拔剑相斗就算勇？ {#q.check.14.2}
考点：skill.l4.5.b
语境：p.check.14.a

- [x] 此不足为勇也 {#q.check.14.2.o1}
- [ ] 必有过人之节 {#q.check.14.2.o2}
  理由：这句话先提豪杰应具的操守。
- [ ] 其志甚远也 {#q.check.14.2.o3}
  理由：这在解说大勇者的长志。

提示：找出紧跟在“挺身而斗”后面的判断。
解析：读者或许先把勇气认作敢动手，作者的“此不足”迫使人重想用什么作判断。

## 单选：苏轼为什么要交代“大勇”者心里所持、所志的事情？ {#q.check.14.3}
考点：skill.l4.6.a
语境：p.check.14.a

- [ ] 证明只要没反击就一定是豪杰 {#q.check.14.3.o1}
  理由：文中还说了所持甚大、所志甚远。
- [ ] 只要能忍，所要做的事本身就一定正当 {#q.check.14.3.o2}
  理由：文中由“所挟持者甚大”解释为何不怒，没反推所有隐忍都有大志。
- [x] 解释为什么能不急着还击，使外表平静和内心有志相连 {#q.check.14.3.o3}

提示：“此其……也”是在替哪两件反常行为找缘由？
解析：临事不惊、受辱不怒不是无所挂怀。作者给出的内在理由是，他看重的事比这一时的胜负更大。

## 单选：“安知其非秦之世有隐君子者”换成哪种说法还保有作者的分寸？ {#q.check.14.4}
考点：skill.l4.6.b
语境：p.check.14.b

- [ ] 老人已被考证为秦代某个姓名可知的隐士。 {#q.check.14.4.o1}
  理由：“安知其非”提出可能，没有给姓名或旁证。
- [x] 怎能断定那不是一位出面试他的隐士？ {#q.check.14.4.o2}
- [ ] 老人绝不可能生活在秦朝。 {#q.check.14.4.o3}
  理由：这个反问恰好把隐士的可能性留下。

提示：注意问的是“怎知不是”，并非“已经知道是”。
解析：苏轼在同世人的怪异解释竞争，所提的是一条能讲通细节的解释，尚未写成身份档案。

## 找原文证据：哪几个字表明把老人看成鬼物的是旁观世人，并非本文作者？ {#q.check.14.5}
考点：skill.l4.5.a
语境：p.check.14.b

- [x] 世不察，以为鬼物 {#q.check.14.5.o1}
- [ ] 其事甚怪 {#q.check.14.5.o2}
  理由：苏轼承认事情奇特，这不等于已经认作鬼神。
- [ ] 且其意不在书 {#q.check.14.5.o3}
  理由：这里说的是老人试人的用意。

提示：问自己：“以为”前是谁没细察？
解析：同一段有两个解释者。作者的“亦已过矣”评价的，正是世人这番说法。

## 单选：“且其意不在书”能否据以否认张良在圯上受书？ {#q.check.14.6}
考点：skill.l4.4.b
语境：p.check.14.b

- [x] 不能，作者改问老人为何给书，并未撤销开头所叙的事 {#q.check.14.6.o1}
- [ ] 能，既然不是为了书，就没有交付过书 {#q.check.14.6.o2}
  理由：目的与事件并非一回事。
- [ ] 能，写“其事甚怪”就是说前面的事全是虚构 {#q.check.14.6.o3}
  理由：对事情感到惊异不等于宣布它不存在。

提示：分别给“事”和“意”找出它们谈的对象。
解析：开头把受书当作待解释之事；结尾移开读者的注意，让人从物品转向借此试人的用心。
