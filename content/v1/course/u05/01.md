# 课文：名词作动词与状语 {#l2.1}
简介：先找一句话的主要动作，再判断名词是在发出动作还是修饰它。

## 正文

### 先留出动词的位置

“客衣布衣”里，前一个“衣”后面跟着“布衣”，能读成“穿着布衣”。换到“客夜衣布衣”，“夜”说明穿衣的时间，动作仍在“衣”。遇到两个熟悉的名词挨在一起，先按谁、做什么、涉及何物分组，再问是否已经有主要动词。

### 用上下句验证

方位词能修饰行动，如“东行”是向东行；名词也能指出动作方式，如“舟行”在与“陆行”对举时可以指乘船而行。孤立的“舟行”也可能是“船在前进”。先找前文主语是否已定，避免只凭词序作答。

## 知识点：名词动用 {#l2.skill.noun-verb}
义项：在谓语位置表示行动
领域：实词
要诀：在谓语位置表示行动
讲解：试把词读成支配后面物件的动作，检查前后是否缺谓语。
例句：l2.ex.noun-verb

## 原文：教学例句 {#l2.ex.noun-verb}
> 寒甚，子衣重裘。
译文：寒冷得很，孩子穿上厚皮衣。

## 知识点：名词作状语 {#l2.skill.noun-adverb}
义项：表示动作的方向、时间或方式
领域：实词
要诀：表示动作的方向、时间或方式
讲解：已有主要动词时，问前面的名词是否回答何时、往哪儿或怎样做。
例句：l2.ex.noun-adverb

## 原文：教学例句 {#l2.ex.noun-adverb}
> 客昼伏夜行。
译文：旅客白天藏身，夜里赶路。

## 原文：古籍引文 {#l2.1.p.mulberry}

译文：在五亩宅地上种植桑树。

## 单选：把“树”读成哪种意思，句子才交代了要做的事？ {#l2.1.q1}
考点：l2.skill.noun-verb
语境：l2.1.p.mulberry

- [x] 种植
- [ ] 树的阴影
  理由：句中尚未提到遮阴。
- [ ] 一棵成树
  理由：若是数树，这句话哪里说明在宅地做什么？

提示：把“树”同“以桑”连起来。
解析：“树”处在动作位置，“以桑”点明种的是桑树。

## 原文：教学例句 {#l2.1.p.grain}
> 使者暮至，主人馆之于西舍。明旦，使者辞而行。
译文：使者傍晚到来，主人安排他住在西边的屋子。第二天早晨，使者告辞上路。

## 单选：“主人馆之于西舍”中，主人怎样接待来客？ {#l2.1.q2}
考点：l2.skill.noun-verb
语境：l2.1.p.grain

- [ ] 把西舍送给使者作家产
  理由：客人次晨告辞，原文只交代一夜接待。
- [x] 安排使者在西舍住下
- [ ] 向使者打听旅馆的位置
  理由：西舍已经指定，“之”承接来客。

提示：若“馆”只是房屋名，此句中谁对“之”做了什么？
解析：“馆”本可指客舍，在这里带宾语“之”，表示安置客人住宿。

## 原文：教学例句 {#l2.1.p.road}
> 使者出邑，东行二里，夜宿山寺。既旦，复东。
译文：使者出城，向东走两里，夜里宿在山寺。天亮后，又向东去。

## 找原文证据：哪一个字限定“宿”发生的时间？ {#l2.1.q3}
考点：l2.skill.noun-adverb
语境：l2.1.p.road

- [x] 夜
- [ ] 山寺
  理由：山寺是住宿处。
- [ ] 邑
  理由：邑是出发地点。

提示：只找能回答“什么时候住下”的成分。
解析：“夜”放在“宿”前，说明住宿发生在夜里。

## 单选：“东行”与末尾“复东”应怎样分别读？ {#l2.1.q4}
考点：l2.skill.noun-adverb
语境：l2.1.p.road

- [ ] 两处都指东方有座城
  理由：原文以使者作主语，写的是行程。
- [x] 前者是向东行，后者是又往东去
- [ ] 前者是向东行，后者是折向西方
  理由：“复”表示再次，没有转向的依据。

提示：前一处还写出了“行”，后一处还需要一个动作。
解析：“行”已有动作义，前面的“东”限定方向；“复东”处“东”承担谓语。

## 原文：教学例句 {#l2.1.p.path}
> 父子欲入山，途绝。父斧枯木以通径，子乃前行。
译文：父子打算入山，路断了。父亲用斧砍倒枯木来打通小路，儿子才向前行。

## 单选：“父斧枯木”中，“斧”在这里做什么用？ {#l2.1.q5}
考点：l2.skill.noun-verb
语境：l2.1.p.path

- [ ] 称枯木为斧头
  理由：下句通路，不能支持给木头取名。
- [ ] 仅列举父亲拥有的工具
  理由：“枯木”需要由一个动作支配。
- [x] 作谓语，表示用斧砍

提示：用“父亲对枯木做了什么”发问。
解析：“斧”带“枯木”作动作对象。砍木的目的由“以通径”交代。

## 找原文证据：儿子向哪个方向走？选出修饰“行”的字。 {#l2.1.q6}
考点：l2.skill.noun-adverb
语境：l2.1.p.path

- [ ] 父
  第几处：1
  理由：这是另一个人。
- [ ] 山
  理由：山是父子要去的地方。
- [x] 前

提示：看清儿子做的动作是哪一个。
解析：“前行”的“前”指出向前，主要动作是“行”。

## 原文：教学例句 {#l2.1.p.cross}
> 两客并至津。甲舟渡，乙循岸北行。既暮，二人会于桥。
译文：两位客人一起来到渡口。甲乘船过河，乙沿岸向北走。天黑后，两人在桥边会合。

## 单选：甲和乙各自怎样行路？ {#l2.1.q7}
考点：l2.skill.noun-adverb
语境：l2.1.p.cross

- [ ] 甲的船自行过河，甲留在渡口
  理由：全段分别交代两个人的去向。
- [x] 甲乘船渡河，乙沿岸向北走
- [ ] 二人都乘船向北
  理由：“循岸”交代乙与甲路线不同。

提示：“甲”“乙”已经分别点明两个主语。
解析：“舟”在“甲舟渡”里写渡河方式，“北”在“北行”里写行路方向。

## 原文：教学例句 {#l2.1.p.rain}
> 天将雨，母衣其幼子以裘，乃抱之出门。
译文：快下雨了，母亲给小儿穿上皮衣，才抱他出门。

## 单选：两次出现“母亲”相关的动作，哪种读法能连起来？ {#l2.1.q8}
考点：l2.skill.noun-verb
语境：l2.1.p.rain

- [ ] 小儿给母亲穿衣
  理由：“母”是“衣其幼子”的动作发出者。
- [ ] 先把衣服抱走，再让孩子独行
  理由：“抱之”的“之”接前面的孩子。
- [x] 先给孩子穿衣，再抱出门

提示：留意“衣”后面直接跟着谁。
解析：“衣其幼子以裘”是用皮衣给孩子穿上，“乃”连接穿衣与抱出。
