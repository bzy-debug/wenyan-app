# 课文：王身边的“左右”是谁 {#l2.1}
简介：读人说话、转身的动作和土地的尺寸，判断连在一起的字是不是今天常用的那个词。

## 正文

“左右争言”能不能讲成“左边和右边抢着说话”？先听听谁有本事开口。“左右”原可指身边两侧，在君主身边，有时便用来称近侍。“顾左右”则要读出人的动作：他转头看了身边的人。

另一个容易认错的词是“地方”。“大国地方百里”该在心里断成“大国／地／方百里”，地是土地，方说方形地面一边的长度。若后面只跟地名或地势，不能仅凭看见“地”“方”二字就断定在报面积。

## 知识点：左右 {#l2.skill.court-attendants}
义项：君主身边的侍从
领域：实词
要诀：看“左右”会不会说话、接命或行礼。
讲解：“令左右取衣”，君主发令，身边的人能去拿衣。若原文说“左右两壁”，两壁才是左右两侧的实物。
例句：l2.ex.court-attendants

## 原文：教学例句 {#l2.ex.court-attendants}
> 君起，左右奉衣。
译文：国君起身，近侍捧上衣服。

## 知识点：地……方…… {#l2.skill.square-land}
义项：土地纵横的尺度
领域：阅读技能
要诀：遇到“方若干里”，先弄清数的是边长还是路程。
讲解：方十里是边长十里的方形地面。不能把十里直接当作面积，也不能把“地方”一律当作“场所”。
例句：l2.ex.square-land

## 原文：教学例句 {#l2.ex.square-land}
> 园地方二里，四隅有树。
译文：园地是个方形，每边二里，四角有树。

## 知识点：顾 {#l2.skill.look-back}
义项：回头或转向旁边看
领域：实词
要诀：看“顾”之后谁或什么进入他的视线。
讲解：一个人已经往前走，听到身后有声而“顾”，是回头看。若说的是挂念、照顾，则未必有这样的转头动作。
例句：l2.ex.look-back

## 原文：教学例句 {#l2.ex.look-back}
> 童已出门，闻呼而顾。
译文：孩子已经出门，听见呼唤就回过头来。

## 原文：古籍引文 {#l2.1.p.wang}
> 王顾左右而言他。
译文：王转头看了看身边的侍从，转而谈别的事。
词注：顾：王把目光转向身边。
  左右：君王近旁随侍的人。
  他：别的事情，这里说换了话题。

## 单选：王转头时，视线落在谁身上？ {#l2.1.q1}
考点：l2.skill.court-attendants
语境：l2.1.p.wang

- [x] 身边的近侍
- [ ] 左右两国派来的使节
  理由：原文没有提到两个国家或来使。
- [ ] 同他说话的孟子
  理由：“左右”指王近旁随侍的人。

提示：这句话把“左右”当成王眼前的人来写。
解析：“左右”在这里是近侍。王看了他们一眼，岔开了话。

## 单选：只看这句话，怎样讲“顾……而言他”最贴近原意？ {#l2.1.q2}
考点：l2.skill.look-back
语境：l2.1.p.wang

- [ ] 王先照料侍从，再回答原来的问题
  理由：“言他”说的是别的事。
- [x] 王转过头，换了话题
- [ ] 王替孟子打听侍从的意见
  理由：文中写的是王看和说，没有写他发问。

提示：分别看王的目光和接下来的言语。
解析：“顾”写转身看，“言他”写所说的话变了。两步都得留下。

## 原文：古籍引文 {#l2.1.p.great}
> 大国地方百里，君十卿禄。
译文：大国的土地按每边百里计，国君的俸禄为卿的十倍。
词注：方：用方形来算，百里指一边之长。
  卿：高级官员，此处以卿的俸禄为比较标准。
  禄：做官所得的俸给。

## 单选：给人画这段的示意图，“百里”该标在哪里？ {#l2.1.q3}

语境：l2.1.p.great

- [x] 方形国土的一条边
- [ ] 表示全部土地面积的格子中央，写“百平方里”
  理由：“里”在这里量一边的长度。
- [ ] 国都到边城的一条指定驿道
  理由：原文没有给出两座城或一条路线。

## 原文：教学例句 {#l2.1.p.court}
> 君命左右发帘。帘起，见庭中一客，客顾门外，若有所待。
译文：国君让侍从揭起帘子。帘子揭起，看到庭中一位客人。客人回头看门外，像在等人。

## 找原文证据：哪两个字写出了侍从奉命做的事？ {#l2.1.q4}
考点：l2.skill.court-attendants
语境：l2.1.p.court

- [ ] 帘起
  理由：这是帘子已经揭起的结果。
- [x] 发帘
- [ ] 顾门外
  理由：转头看门外的是客人。

提示：读“命左右……”时，把谁听命和命他做什么分开。
解析：“左右”是听命的侍从，“发帘”是揭帘。后面另写了庭中客人的动作。

## 单选：“若有所待”是在根据什么作猜测？ {#l2.1.q5}
考点：l2.skill.look-back
语境：l2.1.p.court

- [ ] 国君叫人揭开了帘子
  理由：“若有所待”紧接的是客人的动作。
- [ ] 客人已经出去把同伴迎了进来
  理由：只写“顾”，还没出门迎人。
- [x] 客人把头转向门外

提示：谁“顾”，他看的又是哪边？
解析：文中只看见客人转头望门外，才说像是在等人。“若”没有说等的人一定会来。

## 原文：教学例句 {#l2.1.p.plot}
> 图有两田：甲地方一里，乙地方二里。吏以直绳度其一边。
译文：图上有两块方田，甲每边一里，乙每边二里。官吏用直绳量其中一边。

## 找原文证据：官吏量的是边长还是周长？选出直接说明的原文。 {#l2.1.q6}
考点：l2.skill.square-land
语境：l2.1.p.plot

- [ ] 直绳
  理由：这是测量工具。
- [ ] 两田
  理由：这是图上田的数目。
- [x] 其一边

提示：要找的是绳量到什么，不是拿什么量。
解析：“度其一边”说量一条边，正好说明前两处“方一里”“方二里”的读法。

## 原文：教学例句 {#l2.1.p.escort}
> 使者行而顾，惟一童随之。既入馆，告其左右曰：“明旦早发。”众应诺。
译文：使者边走边回望，只有一个孩子跟着他。到了馆舍，他告诉身边的侍从：“明早早点出发。”众人应下了。
词注：惟：只有。
  旦：早晨，“明旦”是明日早晨。
  应诺：出声答应。

## 排序：使者一路上先看到什么，随后又交代了什么？按先后排。 {#l2.1.q7}
考点：l2.skill.look-back
语境：l2.1.p.escort

- [2] 入馆交代明日早发
  理由：“既入馆”才开始向众人说话。
- [1] 回望看见一童随行
  理由：回望时还在路上。
- [3] 侍从答应
  理由：应诺是听到交代后的反应。

提示：“顾”和“告”各发生在哪里？
解析：“顾”让使者看见身后的随行人，“既入馆”才转入他吩咐众人的一幕。

## 单选：若把第二个场景的“左右”讲作左边右边，哪句话就最难解释？ {#l2.1.q8}
考点：l2.skill.court-attendants
语境：l2.1.p.escort

- [ ] 既入馆
  理由：这是到了什么地方，没有点明谁听命。
- [ ] 明旦早发
  理由：这交代出发时间，不能单凭时辰认出听者。
- [x] 众应诺

提示：哪一种反应必须由人作出？
解析：“众”是接话的一群人；他们齐声应下，说明“左右”指使者身边的侍从。
