# 课文：名词作动词与状语 {#l2.1}
简介：“衣布衣”的两个“衣”怎么读？从穿什么、向哪儿走，认出名词在句里的用处。

## 正文

教学例句“客衣布衣”，若两个“衣”都当作衣服，就没说客人做了什么。把前一个“衣”读成“穿”，后面就接得上了：客人穿着布衣。再读“客夜衣布衣”，多出来的“夜”交代穿衣的时间。

有些名词放在动作前面，还可以说用什么方式做。“舟行”要看前文：若说的是一个人，又跟“陆行”对着写，就可能是乘船而行；若前面说的是一只船，也可能只是船在往前走。

## 知识点：名词动用 {#l2.skill.noun-verb}
义项：在谓语位置表示行动
领域：实词
要诀：如果这里是动作，人做了什么？
讲解：“子衣重裘”，重裘是厚皮衣。孩子把它穿在身上，“衣”在这里就当动词用了。
例句：l2.ex.noun-verb

## 原文：教学例句 {#l2.ex.noun-verb}
> 寒甚，子衣重裘。
译文：寒冷得很，孩子穿上厚皮衣。

## 知识点：名词作状语 {#l2.skill.noun-adverb}
义项：表示动作的方向、时间或方式
领域：实词
要诀：是何时、向哪里，还是怎样做？
讲解：“昼伏夜行”已经有“伏”“行”两个动作。“昼”“夜”分别说什么时候藏身、什么时候赶路。
例句：l2.ex.noun-adverb

## 原文：教学例句 {#l2.ex.noun-adverb}
> 客昼伏夜行。
译文：旅客白天藏身，夜里赶路。

## 原文：古籍引文 {#l2.1.p.mulberry}
> 五亩之宅，树之以桑。
译文：在五亩宅地上种植桑树。

## 单选：五亩宅地上要做什么？这里的“树”怎样读才通？ {#l2.1.q1}
考点：l2.skill.noun-verb
语境：l2.1.p.mulberry

- [x] 种植
- [ ] 树的阴影
  理由：句中尚未提到遮阴。
- [ ] 一棵成树
  理由：若是数树，这句话哪里说明在宅地做什么？

提示：把“树”同“以桑”连起来。
解析：“以桑”点明要种的是桑树。“树”在这里就读成“种植”。

## 原文：教学例句 {#l2.1.p.grain}
> 使者暮至，主人馆之于西舍。明旦，使者辞而行。
译文：使者傍晚到来，主人安排他住在西边的屋子。第二天早晨，使者告辞上路。

## 单选：“主人馆之于西舍”中，主人怎样接待来客？ {#l2.1.q2}
考点：l2.skill.noun-verb
语境：l2.1.p.grain

- [ ] 把西舍送给使者作家产
  理由：客人次晨告辞，原文只交代一夜接待。
- [x] 安排使者在西舍住下
- [ ] 向使者打听旅馆的位置
  理由：西舍已经指定，“之”承接来客。

提示：若“馆”只是房屋名，此句中谁对“之”做了什么？
解析：“馆之”是留他住宿，“于西舍”才说住在西边的房里。“馆”在这儿写主人如何待客。

## 原文：教学例句 {#l2.1.p.road}
> 使者出邑，东行二里，夜宿山寺。既旦，复东。
译文：使者出城，向东走两里，夜里宿在山寺。天亮后，又向东去。

## 找原文证据：使者什么时候住进山寺？找出“宿”前的那个字。 {#l2.1.q3}
考点：l2.skill.noun-adverb
语境：l2.1.p.road

- [x] 夜
- [ ] 山寺
  理由：山寺是住宿处。
- [ ] 邑
  理由：邑是出发地点。

提示：只找能回答“什么时候住下”的成分。
解析：“夜宿”就是夜里住宿。前一个字交代时间，后一个字写人做什么。

## 单选：前面的“东行”和天亮后的“复东”，各怎样读？ {#l2.1.q4}
考点：l2.skill.noun-adverb
语境：l2.1.p.road

- [ ] 两处都指东方有座城
  理由：原文以使者作主语，写的是行程。
- [x] 前者是向东行，后者是又往东去
- [ ] 前者是向东行，后者是折向西方
  理由：“复”表示再次，没有转向的依据。

提示：前一处还写出了“行”，后一处还需要一个动作。
解析：“东行”已有“行”，在前面加个“东”，便是向东走。“复东”只有一个“东”，在这里直接说又向东去了。

## 原文：教学例句 {#l2.1.p.path}
> 父子欲入山，途绝。父斧枯木以通径，子乃前行。
译文：父子打算入山，路断了。父亲用斧砍倒枯木来打通小路，儿子才向前行。

## 单选：“父斧枯木”里的“斧”，是在说手里的工具，还是他在路上做的事？ {#l2.1.q5}
考点：l2.skill.noun-verb
语境：l2.1.p.path

- [ ] 称枯木为斧头
  理由：下句通路，不能支持给木头取名。
- [ ] 仅列举父亲拥有的工具
  理由：“枯木”需要由一个动作支配。
- [x] 作谓语，表示用斧砍

提示：用“父亲对枯木做了什么”发问。
解析：斧本是工具；“斧枯木”把它用来写人的动作，就是拿斧子砍枯木。目的也说了，要打通小路。

## 找原文证据：小路通了，哪个字说儿子向哪里走？ {#l2.1.q6}
考点：l2.skill.noun-adverb
语境：l2.1.p.path

- [ ] 父
  第几处：1
  理由：父亲负责砍木，后面“前行”的人却是儿子。
- [ ] 山
  理由：山是父子要去的地方。
- [x] 前

提示：看清儿子做的动作是哪一个。
解析：“前行”读作向前走，“前”说方向。

## 原文：教学例句 {#l2.1.p.cross}
> 两客并至津。甲舟渡，乙循岸北行。既暮，二人会于桥。
译文：两位客人一同到了渡口。甲乘船过河，乙沿岸向北走。天黑后，两人在桥边会合。

## 单选：甲和乙各自怎样行路？ {#l2.1.q7}
考点：l2.skill.noun-adverb
语境：l2.1.p.cross

- [ ] 甲的船自行过河，甲留在渡口
  理由：全段分别交代两个人的去向。
- [x] 甲乘船渡河，乙沿岸向北走
- [ ] 二人都乘船向北
  理由：“循岸”交代乙与甲路线不同。

提示：一个人到了水上，另一个人还在岸上。分开读他们的去向。
解析：甲乘船过河，“舟”说怎样渡；乙沿岸向北走，“北”说朝哪里走。

## 原文：教学例句 {#l2.1.p.rain}
> 天将雨，母衣其幼子以裘，乃抱之出门。
译文：快下雨了，母亲给小儿穿上皮衣，才抱他出门。

## 单选：母亲先给孩子做了什么，才抱他出门？ {#l2.1.q8}
考点：l2.skill.noun-verb
语境：l2.1.p.rain

- [ ] 小儿给母亲穿衣
  理由：读“母衣其幼子”，是母亲给幼子穿衣。
- [ ] 先把衣服抱走，再让孩子独行
  理由：“抱之”的“之”接前面的孩子。
- [x] 先给孩子穿衣，再抱出门

提示：留意“衣”后面直接跟着谁。
解析：“以裘”是用皮衣。先给小儿穿上皮衣，母亲才抱着他出门。
