# 检查：“衣青衣”的两个“衣” {#check.5}

## 原文：教学例句 {#check.5.p.robe}
> 客将远行，晨起，衣青衣而出。
译文：客人将远行，早晨起来，穿上青衣出门。

## 单选：两个“衣”各起什么作用？ {#check.5.q1}
考点：l2.skill.noun-verb
语境：check.5.p.robe

- [x] 前一个写穿，后一个指衣服
- [ ] 两处都只指衣服
  理由：若都指物，谁做了什么便说不全。
- [ ] 前一个说衣服，后一个写给人穿
  理由：“青”修饰的是后一个“衣”。

提示：看颜色词修饰哪一个字。
解析：第一个“衣”是穿，后一个“衣”才是青色的衣服。合起来是穿好青衣出门。

## 原文：教学例句 {#check.5.p.valley}
> 行者过谷，南望见烟，循烟而往。
译文：行人经过山谷，朝南望见炊烟，循着烟前往。

## 找原文证据：哪个字写观察的方向？ {#check.5.q2}
考点：l2.skill.noun-adverb
语境：check.5.p.valley

- [ ] 烟
  第几处：1
  理由：烟是看到的事物。
- [x] 南
- [ ] 谷
  理由：谷是经过的地方。

提示：行人朝哪一边看到了烟？
解析：“南望”就是朝南看。“烟”则是行人望见的东西。

## 原文：教学例句 {#check.5.p.banks}
> 水涌，众人厚其岸。土既积，水不能越。
译文：水上涨，众人把岸堤加厚。土堆好后，水不能漫过去。

## 单选：“厚其岸”以后，岸堤有什么变化？ {#check.5.q3}
考点：l2.skill.cause-state
语境：check.5.p.banks

- [x] 人堆土使岸变厚
- [ ] 岸使众人更加厚道
  理由：堆土的结果落在哪里？
- [ ] 众人只是认为岸很厚
  理由：“土既积”说明做了实际工作。

提示：比较岸堤前后的变化。
解析：“土既积”说大家已经堆起土来。这样把岸堤加厚，水便漫不过去了。

## 原文：教学例句 {#check.5.p.cattle}
> 牧者叱牛，牛止；复以草诱之，使前。
译文：牧人喝住牛，牛停了，又用草引诱它，让它向前。

## 单选：牧人用草引它，又让谁往前走？ {#check.5.q4}
考点：l2.skill.cause-motion
语境：check.5.p.cattle

- [x] 让牛向前
- [ ] 让牧人站到牛前
  理由：“诱之”所引导的对象是谁？
- [ ] 让草向前长
  理由：草是引诱所用的东西。

提示：牧人拿草招引的是谁？
解析：牧人先喝住牛，再用草引它。“使前”承前省了牛，即让牛向前走。

## 原文：教学例句 {#check.5.p.cloth}
> 富人贱布衣，见卖者，薄其货而不顾。
译文：富人看轻布衣，见卖衣人，轻视他的货物而不看。

## 单选：富人说布衣“贱”，是怎样看待这种衣物？ {#check.5.q5}
考点：l2.skill.evaluative
语境：check.5.p.cloth

- [x] 看不起布衣
- [ ] 把衣服做薄一些
  理由：没写富人动手制衣。
- [ ] 给布衣降价出售
  理由：卖衣的是别人。

提示：“不顾”写态度还是加工？
解析：“贱”“薄”都是富人看不起这货物。文中写他连看也不看，没写买卖定价。

## 原文：教学例句 {#check.5.p.elder}
> 生闻叟长于算，执弟子礼而师之。
译文：学生听说老人擅长计算，以弟子礼相见，把他当老师。

## 单选：“师之”怎样理解？ {#check.5.q6}
考点：l2.skill.treat-as
语境：check.5.p.elder

- [ ] 老人替学生聘师
  理由：行弟子礼的是学生，他想拜老人为师。
- [ ] 学生使老人入官学任职
  理由：原文只交代相见时的礼节。
- [x] 学生尊老人为老师

提示：“弟子礼”由谁行给谁？
解析：学生行弟子礼，是把这位擅长算术的老人当老师。这里的“之”就是老人。
