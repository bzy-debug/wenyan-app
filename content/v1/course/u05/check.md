# 检查：随国君出游，替乡人问树 {#check.5}

## 原文：教学例句 {#check.5.p.levy}
> 君适东田，车已发，而掌图者犹在后。君顾，谓左右曰：“缓行，待之。”掌图者乃及车，出图指田曰：“此地方二里。”君问其南北，答曰：“亦二里。”
译文：国君要到东边的田地去，车已经出发，管地图的人还在后头。国君回头看，对侍从说：“走慢一点，等他。”管图的人这才赶上车，打开图指着田说：“这块田是边长二里的方田。”国君问南北有多长，答说：“也是二里。”
词注：掌：主管，此处掌管地图。
  顾：转头向后看。
  缓：放慢，叫车队等一等。

## 单选：国君已经带着人出发，为何还吩咐“左右”等一等？ {#check.5.q1}
考点：l2.skill.court-attendants
语境：check.5.p.levy

- [x] 跟在身边的侍从已经随车，能指图的人却落后了
- [ ] “左右”就是掌图者，国君请他独自在田边等车
  理由：君说“待之”时，掌图者还没有赶上。
- [ ] 田的左右两侧各少了一位测量者
  理由：“谓左右”之后是给人的吩咐，文中只写一人落后。

提示：谁能当下听令，谁还须被等？
解析：掌图者在后，君转头看到他落在车后，向身旁的人发令。“左右”和“待之”的“之”是不同的人。

## 排序：图是怎样到国君面前的？按这次东行的经过排。 {#check.5.q2}
考点：l2.skill.overtake-ji
语境：check.5.p.levy

- [3] 掌图者赶上，展开图讲田地
  理由：须“及车”相会以后，才能当面指图答问。
- [1] 君往东田，掌图者尚未随上
  理由：“适”说此行所向，出发时队伍已分开。
- [2] 国君回顾，吩咐放慢行程
  理由：“缓行”给落后的人留下赶上的机会。

提示：把“适”“顾”“及”各接回正在做这事的人。
解析：先出发留下了一个距离，顾而缓行缩短距离，“及车”才使后面的指图问答成为可能。

## 单选：国君为何在听到“地方二里”后，又能得到“南北亦二里”的答话？ {#check.5.q3}
考点：l2.skill.square-land
语境：check.5.p.levy

- [x] “方二里”以一边的长度说方田，南北那一边也是二里
- [ ] 从国都到东田恰好二里，再往南北各行二里
  理由：作答的人已指着田，君问的是田的南北。
- [ ] 所有边加起来共二里，南北又占其中二里
  理由：“亦二里”说另一方向也这么长，不是把总长重新分配。

提示：把“地方二里”按“地／方二里”读，再看“亦”在与什么相照。
解析：前面指的是田形与边长。国君改问另一方向，“亦”使两条尺度对得上。

## 原文：教学例句 {#check.5.p.mulberry}
> 村西有桑，岁旱，叶尽落。童循西道往视，掘土见其本尚润，反告里老。里老曰：“可救也。蚕以桑叶为食，此桑实数家衣食之本。”乃教童引水沃之。明年叶复生。
译文：村西有棵桑树，年景干旱，叶子落尽。孩子沿西边的路去看，挖土发现树根还有湿气，回来告诉村中老人。老人说：“可以救。蚕吃桑叶，这棵桑树实在是几家人衣食的根本。”于是教孩子引水浇它。次年树又长出了叶子。
词注：岁：年成，这里说这一年遇到旱情。
  循：沿着路走。
  沃：浇，这里是把水引到桑树根部。

## 找原文证据：老人后来凭什么判断桑树还可救？找出孩子回来报告的关键发现。 {#check.5.q4}
考点：l2.skill.come-back-fan
语境：check.5.p.mulberry

- [x] 其本尚润
- [ ] 叶尽落
  理由：落叶是人们担心树枯的原因。
- [ ] 明年叶复生
  理由：这是救树后的结果，说“可救”时还未发生。

提示：顺着孩子“往视”到“反告”之间读，他掘土看见什么？
解析：“反告”是看完回来报告。报告所依据的是树根仍有湿气，老人才能在尚未重新长叶时主张救树。

## 单选：老人也说“本”，为什么不能把他的话读成“几家人的衣食长在树根上”？ {#check.5.q5}
考点：l2.skill.basis-ben
语境：check.5.p.mulberry

- [x] 树提供叶，叶养蚕，几家人的生活靠它维持
- [ ] 因为“衣食”专指包住树根的布和土
  理由：老人提起蚕吃桑叶，谈的是几家的生计。
- [ ] 因为根已干死，几家人以后只能拾落叶
  理由：孩子看到的正是树根尚润，且次年生叶。

提示：把“蚕以桑叶为食”同“数家衣食”连着想。
解析：挖土看见的是根；老人把养蚕、谋生的关系接进来，后一个“本”就指生活所依靠的基础。

## 单选：若有人要问“救桑之道”，这段里哪一句能回答他？ {#check.5.q6}
考点：l2.skill.way-dao
语境：check.5.p.mulberry

- [ ] 循西道往视
  理由：这说的是孩子从哪里走，并没有教怎样救树。
- [ ] 明年叶复生
  理由：这是后来见到的结果，没说人做了什么。
- [x] 引水沃之

提示：最初走的“道”和所问的方法，哪一个能跟“教童”相接？
解析：路能把孩子带到桑树旁；要学救桑的办法，还得读老人所教的引水浇树。
