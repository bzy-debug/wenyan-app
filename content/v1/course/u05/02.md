# 课文：使动：是谁使谁改变 {#l2.2}
简介：把词展开成“使某人或某物怎样”，核对结果真正落在谁身上。

## 正文

“门开”只报门的状态。“风开其门”则需要把风和门的变化联系起来。辨认使动时，可将句子拆成两层：一层写谁施加影响，另一层写谁发生变化。

如教学例句“医安其心”，要验证安心的是谁。若读成“医生心里安定”，就丢掉了“其心”这一对象。与下文“病者乃眠”连读，可见安定的是病者的心。动作也可以这样读，例如“止之”可能是让一个正行进的人停下。

## 知识点：形容词使动 {#l2.skill.cause-state}
义项：使动作对象具有某种状态
领域：句法
要诀：使动作对象具有某种状态
讲解：将形容词展开为“使宾语变得……”。比较施加影响者和承受变化者。
例句：l2.ex.cause-state

## 原文：教学例句 {#l2.ex.cause-state}
> 工坚其堤，水不复溢。
译文：工匠使河堤牢固，水不再漫出。

## 知识点：动作使动 {#l2.skill.cause-motion}
义项：使宾语做某个动作
领域：句法
要诀：使宾语做某个动作
讲解：有些本可单独作谓语的动词带上宾语，表示主语使宾语行动。先找实际移动或停下的一方。
例句：l2.ex.cause-motion

## 原文：教学例句 {#l2.ex.cause-motion}
> 童牵犬欲行，父止之。
译文：孩子想牵狗走，父亲让他停下。

## 原文：古籍引文 {#l2.2.p.hard}
> 必先苦其心志，劳其筋骨。
译文：一定先使他的心志受苦，使他的筋骨劳累。

## 单选：两项变化分别落在哪里？ {#l2.2.q1}
考点：l2.skill.cause-state
语境：l2.2.p.hard

- [x] 其心志受苦，其筋骨劳累
- [ ] 心志使别人痛苦，筋骨使别人劳累
  理由：这两项都在“苦”“劳”后面。
- [ ] 苦的是筋骨，累的是心志
  理由：让每个词各自连回紧随其后的对象。

提示：把“苦”和“劳”都按“使……怎样”试读。
解析：“苦其心志”“劳其筋骨”结构平行。心志、筋骨分别是受影响的一方。

## 找原文证据：原文说哪一部分受劳累？ {#l2.2.q2}
考点：l2.skill.cause-state
语境：l2.2.p.hard

- [ ] 其心志
  理由：这是“苦”涉及的对象。
- [ ] 必先
  理由：这是次序和语气。
- [x] 其筋骨

提示：“劳”紧接的对象是什么？
解析：“劳”后直接接“其筋骨”，表使筋骨劳累。

## 原文：教学例句 {#l2.2.p.horse}
> 马惊欲逸。御者下车，止马于门外。客乃徐登。
译文：马受惊想逃。驾车人下车，让马停在门外。客人这才慢慢上车。

## 单选：实际停下的是谁？是谁使它停下？ {#l2.2.q3}
考点：l2.skill.cause-motion
语境：l2.2.p.horse

- [ ] 驾车人停步，马仍在逃
  理由：“止”后面直接接“马”。
- [ ] 客人停下，马使他停下
  理由：客人后面才登车。
- [x] 马停下，驾车人使它停下

提示：把“止马”补作“使……停”。
解析：“御者”施加影响，“马”是停下的一方；因此客人能登车。

## 排序：按御者制住马的经过排列。 {#l2.2.q4}
考点：l2.skill.cause-motion
语境：l2.2.p.horse

- [2] 御者让马停住
  理由：“乃”后面的事需等什么条件？
- [1] 马受惊想逃
  理由：御者为什么需要下车？
- [3] 客人登车
  理由：马未停时能徐徐登车吗？

提示：先读“欲逸”，再读“乃”。
解析：先有惊马，后有止马，安定下来才可登车。

## 原文：教学例句 {#l2.2.p.water}
> 泉水寒，客不能饮。主人温其水，客乃饮。
译文：泉水凉，客人喝不下。主人把水温热，客人才喝。

## 单选：“温其水”与“泉水寒”怎样衔接？ {#l2.2.q5}
考点：l2.skill.cause-state
语境：l2.2.p.water

- [ ] 主人觉得水本来就很暖
  理由：开头已经说水寒。
- [ ] 客人觉得主人温和
  理由：“温”的对象是水。
- [x] 主人使凉水变温热

提示：喝水以前，哪一样东西状态改变了？
解析：前后描述同一份水。主人做事使其温热，才有“客乃饮”。

## 原文：教学例句 {#l2.2.p.boat}
> 两舟争进，长者呼而止之。两舟皆泊，乃许小舟先发。
译文：两船争着前进，长者呼喊让它们停下。两船都靠住后，才准小船先出发。

## 找原文证据：哪句话证实两船都因劝止而停下？ {#l2.2.q6}
考点：l2.skill.cause-motion
语境：l2.2.p.boat

- [ ] 小舟先发
  理由：这是停稳以后再放行。
- [x] 两舟皆泊
- [ ] 争进
  理由：这是干预前的情形。

提示：找紧接呼止动作的结果。
解析：“两舟皆泊”把呼止后双方都停止前行的结果写出来。

## 原文：教学例句 {#l2.2.p.board}
> 木板甚曲。匠以火矫之，直其板，然后为扉。
译文：木板很弯。工匠用火矫正，使木板变直，然后用来作门。

## 单选：“直其板”说明了什么变化？ {#l2.2.q7}
考点：l2.skill.cause-state
语境：l2.2.p.board

- [ ] 匠人站得笔直
  理由：“其板”是动作对象。
- [ ] 匠人只认为板很直
  理由：用火矫正说明发生了加工。
- [x] 匠人使弯板变直

提示：将“甚曲”与后来的结果对照。
解析：先曲后直是板的状态变化。匠人以加工造成这个结果。

## 原文：教学例句 {#l2.2.p.bird}
> 鹤病，久伏。翁抚而养之，既健，乃飞之空庭。鹤振翼而上。
译文：鹤病了，长久卧着。老人照料它，等康复后才让它在空院里飞。鹤振翅而起。

## 单选：“飞之”中的“之”在做什么？ {#l2.2.q8}
考点：l2.skill.cause-motion
语境：l2.2.p.bird

- [ ] 老人射中飞鹤
  理由：前文一直写照料病鹤，没有射猎。
- [x] 鹤在飞，老人让它飞
- [ ] 老人自己飞到院内
  理由：下文振翅的是鹤。

提示：“振翼”的主语可以帮助确定谁飞。
解析：“飞之”使鹤飞起。老人是发出引导的一方。
