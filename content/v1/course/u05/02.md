# 课文：使动：是谁使谁改变 {#l2.2}
简介：“门开”和“风开其门”都说门开了。后一句还交代了什么？

## 正文

“门开”，我们知道门开了。“风开其门”，还能读出是什么把门吹开的。要分清这样的句子，可以把两件事分别说出来：谁做了什么，谁因此有了变化？

试读教学例句“医安其心”，再接着读“病者乃眠”。是医生自己心安了，还是病人的心安定下来？后面睡着的是病人；医生做的事，是让他安心。古书里“止之”也可以这样读：有人本在前进，另一个人叫他停下。

## 知识点：形容词使动 {#l2.skill.cause-state}
义项：使动作对象具有某种状态
领域：句法
要诀：究竟是谁或什么变了？
讲解：“工坚其堤”，变牢固的是堤。工匠加固了它，所以下句才说河水不再漫出来。
例句：l2.ex.cause-state

## 原文：教学例句 {#l2.ex.cause-state}
> 工坚其堤，水不复溢。
译文：工匠使河堤牢固，水不再漫出。

## 知识点：动作使动 {#l2.skill.cause-motion}
义项：使宾语做某个动作
领域：句法
要诀：谁让它停，谁真的停下？
讲解：“童牵犬欲行，父止之”里，父亲出面制止，打算出发的孩子才停下来。
例句：l2.ex.cause-motion

## 原文：教学例句 {#l2.ex.cause-motion}
> 童牵犬欲行，父止之。
译文：孩子想牵狗走，父亲让他停下。

## 原文：古籍引文 {#l2.2.p.hard}
> 必先苦其心志，劳其筋骨。
译文：一定先使他的心志受苦，使他的筋骨劳累。

## 单选：“苦”与“劳”分别使人哪里受苦、哪里受累？ {#l2.2.q1}
考点：l2.skill.cause-state
语境：l2.2.p.hard

- [x] 其心志受苦，其筋骨劳累
- [ ] 心志使别人痛苦，筋骨使别人劳累
  理由：这两项都在“苦”“劳”后面。
- [ ] 苦的是筋骨，累的是心志
  理由：让每个词各自连回紧随其后的对象。

提示：把“苦”和“劳”都按“使……怎样”试读。
解析：先读“苦其心志”，心志受苦；再读“劳其筋骨”，筋骨受累。两句用的是同一个读法。

## 找原文证据：原文说哪一部分受劳累？ {#l2.2.q2}
考点：l2.skill.cause-state
语境：l2.2.p.hard

- [ ] 其心志
  理由：“心志”接在“苦”后。身体劳累要往后半句找。
- [ ] 必先
  理由：“必先”说的是一定要先经历什么，还没提到筋骨。
- [x] 其筋骨

提示：“劳”挨着的是心志，还是筋骨？
解析：“劳”后紧跟“其筋骨”，说的是使他的筋骨受累。

## 原文：教学例句 {#l2.2.p.horse}
> 马惊欲逸。御者下车，止马于门外。客乃徐登。
译文：马受惊想逃。驾车人下车，让马停在门外。客人这才慢慢上车。

## 单选：马受了惊，是谁让谁停下来？ {#l2.2.q3}
考点：l2.skill.cause-motion
语境：l2.2.p.horse

- [ ] 驾车人停步，马仍在逃
  理由：“止”后面直接接“马”。
- [ ] 客人停下，马使他停下
  理由：客人后面才登车。
- [x] 马停下，驾车人使它停下

提示：把“止马”补作“使……停”。
解析：驾车人下车把马制住，停在门外的是马。等马停稳，客人才慢慢登车。

## 排序：按御者制住马的经过排列。 {#l2.2.q4}
考点：l2.skill.cause-motion
语境：l2.2.p.horse

- [2] 御者让马停住
  理由：“乃”后面的事需等什么条件？
- [1] 马受惊想逃
  理由：御者为什么需要下车？
- [3] 客人登车
  理由：马未停时能徐徐登车吗？

提示：先读“欲逸”，再读“乃”。
解析：马先受惊想逃，驾车人才下车制住它。客人登车更在后面。

## 原文：教学例句 {#l2.2.p.water}
> 泉水寒，客不能饮。主人温其水，客乃饮。
译文：泉水凉，客人喝不下。主人把水温热，客人才喝。

## 单选：泉水起初很凉，主人接着怎样做？ {#l2.2.q5}
考点：l2.skill.cause-state
语境：l2.2.p.water

- [ ] 主人觉得水本来就很暖
  理由：开头已经说水寒。
- [ ] 客人觉得主人温和
  理由：“温”的对象是水。
- [x] 主人使凉水变温热

提示：喝水以前，哪一样东西状态改变了？
解析：水起初是凉的，客人喝不下。主人把水温热以后，他才喝。

## 原文：教学例句 {#l2.2.p.boat}
> 两舟争进，长者呼而止之。两舟皆泊，乃许小舟先发。
译文：两船争着前进，长者呼喊让它们停下。两船都靠住后，才准小船先出发。

## 找原文证据：两条船都停了吗？哪句话说得最清楚？ {#l2.2.q6}
考点：l2.skill.cause-motion
语境：l2.2.p.boat

- [ ] 小舟先发
  理由：“乃许小舟先发”是停稳以后的安排。
- [x] 两舟皆泊
- [ ] 争进
  理由：“两舟争进”说的是长者开口以前，两船还在争先。

提示：找紧接呼止动作的结果。
解析：“两舟皆泊”里，“皆”是都。长者呼止后，两船都停住了。

## 原文：教学例句 {#l2.2.p.board}
> 木板甚曲。匠以火矫之，直其板，然后为扉。
译文：木板很弯。工匠用火矫正，使木板变直，然后用来作门。

## 单选：“直其板”说明了什么变化？ {#l2.2.q7}
考点：l2.skill.cause-state
语境：l2.2.p.board

- [ ] 匠人站得笔直
  理由：“其板”是工匠手里那块弯木板。
- [ ] 匠人只认为板很直
  理由：用火矫正说明发生了加工。
- [x] 匠人使弯板变直

提示：将“甚曲”与后来的结果对照。
解析：板原先很弯，经过工匠用火矫正，变直了。“直其板”写他把板弄直。

## 原文：教学例句 {#l2.2.p.bird}
> 鹤病，久伏。翁抚而养之，既健，乃飞之空庭。鹤振翼而上。
译文：鹤病了，长久卧着。老人照料它，等康复后才让它在空院里飞。鹤振翅而起。

## 单选：“飞之”写老人让谁飞起来？ {#l2.2.q8}
考点：l2.skill.cause-motion
语境：l2.2.p.bird

- [ ] 老人射中飞鹤
  理由：前文一直写照料病鹤，没有射猎。
- [x] 鹤在飞，老人让它飞
- [ ] 老人自己飞到院内
  理由：下文振翅的是鹤。

提示：结尾的翅膀是谁扇动的？
解析：老人一直照料病鹤。等鹤康复，他让鹤在院里飞，后一小句写它振翅而起。
