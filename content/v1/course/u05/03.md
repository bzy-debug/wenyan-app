# 课文：从树根读到做事的根本 {#l2.3}
简介：“本”能埋在土里，“本”也可以是一件事最靠得住的基础。读“道”时也试着走这一步。

## 正文

写树木时，“本”可以是树根；写世事时，它又可以说一件事情赖以立住的基础。理解引申义，先保留两种意思之间相通的地方，再回到句中看：眼前真有一株树，还是有人借树来说另一件事？

“道”本可指可走的道路，也能指做事的办法、做人当循的准则。比方里两个意思甚至会同时出现。“道若大路”是在拿路来讲道理，若讲成“一条大路像一条大路”，这个比方就讲不明白了。

## 知识点：本（草木） {#l2.skill.tree-root}
义项：草木的根或靠根的部位
领域：实词
要诀：找掘土、拔树、浇根等实在动作。
讲解：“培其本”时若围着一株树加土，所培的是根。后文再谈别的事，要重新确认这个“本”指什么。
例句：l2.ex.tree-root

## 原文：教学例句 {#l2.ex.tree-root}
> 树将倾，匠培其本。
译文：树快倒了，工匠在树根周围培土。

## 知识点：本（事理） {#l2.skill.basis-ben}
义项：事情赖以成就的根本
领域：实词
要诀：问说话人认为缺了什么，后面的事就难以办成。
讲解：人也能“务本”。当作者谈为人或谋生，所说的本常是一切从何立起，不必找地里一棵树。
例句：l2.ex.basis-ben

## 原文：教学例句 {#l2.ex.basis-ben}
> 里老曰：“水，稻之本也。”
译文：村里老人说：“水是稻作的根本。”

## 知识点：道（道路） {#l2.skill.path-dao}
义项：供人车通行的道路
领域：实词
要诀：能在上面赶车、遇人或遇阻，多半说的是路。
讲解：“道有覆车”说道路上有翻倒的车。要确定是哪条路，还得继续看它通向哪里。
例句：l2.ex.path-dao

## 原文：教学例句 {#l2.ex.path-dao}
> 大道通津，小径入林。
译文：大路通向渡口，小径通进树林。

## 知识点：道（方法、准则） {#l2.skill.way-dao}
义项：做事可循的办法或道理
领域：实词
要诀：看所问的是往哪处走，还是怎样办事。
讲解：“养蚕之道”能由选叶、避湿等办法来回答。即使附近也说到道路，仍应分清两种“道”。
例句：l2.ex.way-dao

## 原文：教学例句 {#l2.ex.way-dao}
> 儿问种菽之道，父教之择种。
译文：孩子请教种豆的方法，父亲教他选种。

## 原文：古籍引文 {#l2.3.p.scholar}
> 君子务本，本立而道生。
译文：君子致力于根本。根本立住，所循的道也由此生出。
词注：务：用心致力于。
  立：确立，此处说根本立得住。
  道：这里指为人处世的道理。
出处：《论语·学而》有子论为仁之本章

## 单选：为什么不能只把“务本”讲成照看树根？ {#l2.3.q1}
考点：l2.skill.basis-ben
语境：l2.3.p.scholar

- [ ] 这里“本”特指写下言论的册子
  理由：没有读书、传书的举动。
- [x] 这是谈君子为人的基础，后面接着说“道生”
- [ ] 这里明确要君子亲手种树
  理由：原句没有种植对象或田园。

提示：从“君子”读到“道”，整句谈的是哪一类事？
解析：“本立而道生”说根本确立以后道才能生出。树根托住树的关系，在这里引申为做人的基础。

## 原文：教学例句 {#l2.3.p.root}
> 园丁掘土，见树本已伤，乃止锄。徒问养树之道，曰：“先毋伤其本。”
译文：园丁掘土，见树根已经受伤，便停下锄头。学徒请问养树的方法，他说：“先别弄伤根。”

## 找原文证据：哪处写的是眼前树木已经受到的损伤？ {#l2.3.q2}
考点：l2.skill.tree-root
语境：l2.3.p.root

- [x] 树本已伤
- [ ] 乃止锄
  理由：这是发现以后采取的行动。
- [ ] 养树之道
  理由：这是学徒要请教的事。

提示：找掘土以后亲眼见到的东西。
解析：能被锄头伤到的“本”是根。后面不许伤根，也是在说这件实物。

## 单选：徒弟问“养树之道”，哪种答话才答在所问之处？ {#l2.3.q3}
考点：l2.skill.way-dao
语境：l2.3.p.root

- [x] 说怎样做才养得好这株树
- [ ] 只把树根的颜色告诉他
  理由：颜色本身还没回答该怎么办。
- [ ] 指出去园里的最近一条路
  理由：人已在园中，问的是养树。

提示：园丁实际回答时用的是“毋伤”，是在指路还是教做法？
解析：学徒想学养树的方法，师父给了一条具体做法：先别伤根。

## 原文：教学例句 {#l2.3.p.road}
> 二客行至道岐，问津。樵者指东道，曰：“桥在彼，可渡。”
译文：两位客人走到岔路，询问渡处。樵夫指着东边的路说：“桥在那边，可以过河。”
词注：岐：道路分岔。
  问津：打听可从哪里渡水。
  彼：那边，指樵者所示之处。

## 单选：樵者所指的“东道”可以怎样画？ {#l2.3.q4}
考点：l2.skill.path-dao
语境：l2.3.p.road

- [ ] 画成一条教人待客的规矩
  理由：“桥在彼”在给行人指位置。
- [x] 画成通往桥边的一条路
- [ ] 画成渡船上的主人
  理由：指向的是东边的路，并未出现船主。

提示：“道岐”和“桥在彼”之间，行人需要知道什么？
解析：客人正在找过河处，樵者所指能接着走到桥边，故“道”是道路。

## 原文：古籍引文 {#l2.3.p.compare}
> 夫道若大路然，岂难知哉？人病不求耳。
译文：道理像大路一样，难道难以知道吗？人们的毛病在于不去求罢了。
词注：病：苦于，此处指出人求道的毛病所在。
  耳：罢了，用在句末收住语气。

## 单选：“若”连起的两边应怎样读，才能保留孟子的比方？ {#l2.3.q5}
考点：l2.skill.way-dao
语境：l2.3.p.compare

- [x] 拿人人可知的大路，来说明可求的道理
- [ ] 用一条泥路和另一条泥路比长短
  理由：末句说人的毛病是“不求”，没量距离。
- [ ] 把问学改成问去国都的路线
  理由：回答谈求道，没有给地名。

提示：先将“若”读作“像”，看两侧各说什么。
解析：“大路”让听者想见一条好认的道路，借以说明所求的道也并非难以了解。

## 原文：教学例句 {#l2.3.p.school}
> 屋后有古桑，风折其枝，童掘土视本，本尚固。师曰：“读书必先识字，此亦学之本也。”
译文：屋后有一棵老桑树，风吹断枝条，孩子挖土看根，树根还牢固。先生说：“读书须先识字，这也是学业的根本。”
词注：固：牢固，说桑树的根仍扎得稳。
  亦：也，老师从树根转而比说识字。

## 单选：童子挖土所看与先生说的“学之本”是同一样东西吗？ {#l2.3.q6}
考点：l2.skill.tree-root
语境：l2.3.p.school

- [x] 一个是实在的树根，一个借根说学习的基础
- [ ] 都是折断的枝条
  理由：枝虽折，孩子看的根却尚固。
- [ ] 都是一本识字课本
  理由：挖土的动作无法说明在找课本。

提示：两人说话时，一个在树旁做什么，一个在教什么？
解析：“掘土”让前一个本落在树根；先生另说读书识字，后一个本就有了引申义。

## 找原文证据：先生具体把什么看作学习的基础？从原文找出这个动作。 {#l2.3.q7}
考点：l2.skill.basis-ben
语境：l2.3.p.school

- [x] 识字
- [ ] 视本
  理由：这是童子看树根。
- [ ] 风折其枝
  理由：这是屋后发生的事。

提示：看“读书必先……”接了什么。
解析：“此亦学之本”的“此”承接先识字。这里找的是基础具体指什么。

## 原文：教学例句 {#l2.3.p.market}
> 商问县令生财之道，令指毁桥曰：“先通此道，则货可至。”
译文：商人问县令怎样才能生财，县令指着坏桥说：“先打通这条道路，货物就能到了。”

## 单选：“通此道”实际要求先解决什么？ {#l2.3.q8}
考点：l2.skill.path-dao
语境：l2.3.p.market

- [ ] 给商人指派一位管钱的人
  理由：“货可至”取决于通路，未说人事安排。
- [x] 修通阻断货运的桥路
- [ ] 只背熟一段谈生财的道理
  理由：县令手指的是坏桥。

提示：前一句在问办法，答话却指着哪件眼前的实物？
解析：问的是抽象的“生财之道”，县令给的办法却落在具体道路上。两个“道”不能都译成同一词。
