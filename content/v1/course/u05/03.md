# 课文：意动：把对象看成什么 {#l2.3}
简介：在“改变了对象”和“改变了评价”之间作出有证据的判断。

## 正文

同一句“高其台”，若接着写运土增筑，可以是使台变高；若只写仰望与称赞，判断则要另据语境。意动侧重人的看法：当事人认为某物大、小、可贵，或者把某人看作老师、朋友。

识读时先问，原文有没有交代对象真的发生变化。再问，这是谁眼中的评价。遇到“友其人”，可先展开成“以其人为友”，看后面是否写以朋友之礼相待。

## 知识点：形容词意动 {#l2.skill.evaluative}
义项：认为对象具有某种性质
领域：句法
要诀：认为对象具有某种性质
讲解：评价来自观察者的眼光，并不意味着对象实际变大、变小、变贵。
例句：l2.ex.evaluative

## 原文：教学例句 {#l2.ex.evaluative}
> 童初至海，壮其涛。
译文：孩子初到海边，觉得波涛壮阔。

## 知识点：名词意动 {#l2.skill.treat-as}
义项：把对象当作某种身份的人
领域：句法
要诀：把对象当作某种身份的人
讲解：用“把……当作老师、朋友”等关系来补足，再用礼遇、问学等行动验证。
例句：l2.ex.treat-as

## 原文：教学例句 {#l2.ex.treat-as}
> 客贤其人，遂友之。
译文：客人认为那人贤能，于是把他当朋友。

## 原文：古籍引文 {#l2.3.p.mountain}
> 孔子登东山而小鲁，登太山而小天下。
译文：孔子登上东山，觉得鲁国小；登上太山，觉得天下小。

## 单选：登山后，哪一样真正发生了变化？ {#l2.3.q1}
考点：l2.skill.evaluative
语境：l2.3.p.mountain

- [ ] 天下地形被重新丈量
  理由：句中写登山后的感受，未写测量。
- [x] 看鲁国与天下时的眼光
- [ ] 鲁国疆界实际缩小
  理由：登高不能改变国界。

提示：将“小”试读成“以……为小”。
解析：“登”改变观察位置，“小”的评价由观察者作出，所观之物没有缩小。

## 找原文证据：哪一处明确写出了第二次作评价的对象？ {#l2.3.q2}
考点：l2.skill.evaluative
语境：l2.3.p.mountain

- [x] 天下
- [ ] 太山
  理由：这是登上的地方。
- [ ] 东山
  理由：这是第一次登临之处。

提示：找第二个“小”后面的词。
解析：“小天下”中，天下是被看作小的对象。

## 原文：教学例句 {#l2.3.p.tutor}
> 村有老陶者。诸生师之，从而学埏土之法。陶者未尝为学官。
译文：村中有一位老陶工。学生们把他当老师，跟随他学习揉泥的方法。他没有担任过学官。

## 单选：学生怎样看待陶者？ {#l2.3.q3}
考点：l2.skill.treat-as
语境：l2.3.p.tutor

- [x] 在制陶这件事上把他当老师
- [ ] 让他来学生处拜师
  理由：“从而学”的主语是学生。
- [ ] 任命他为负责学校的官员
  理由：末句交代他没做过学官。

提示：看是谁跟着谁学。
解析：“师之”说学生拜他为师，以老师的身份对待他。

## 找原文证据：哪一处行动能验证学生把陶者当老师？ {#l2.3.q4}
考点：l2.skill.treat-as
语境：l2.3.p.tutor

- [ ] 村有老陶者
  理由：这是人物的出场。
- [x] 从而学埏土之法
- [ ] 未尝为学官
  理由：这是他的任职情况。

提示：找“师之”之后学生做的事。
解析：跟随陶者学习手艺，是师生关系在行动上的表现。

## 原文：教学例句 {#l2.3.p.plain}
> 客过山村，陋其舍，不肯入。及闻主人能医，乃求见。
译文：客人经过山村，嫌屋子简陋，不肯进去。等听说主人会医术，才请求相见。

## 单选：“陋其舍”最合哪一种意思？ {#l2.3.q5}
考点：l2.skill.evaluative
语境：l2.3.p.plain

- [x] 客人认为房舍简陋
- [ ] 客人动手把屋子改得简陋
  理由：此时他还不肯入屋。
- [ ] 主人嫌客人衣着简陋
  理由：“客”是前半句的主语。

提示：从“不肯入”判断客人是在观看还是改建。
解析：房舍是被评价的对象，嫌弃来自客人的判断。

## 原文：教学例句 {#l2.3.p.guest}
> 士无车马，邑令客之，亲延入堂，列席于上。
译文：士人没有车马，县令把他当贵客，亲自请进厅堂，为他安排上席。

## 单选：“客之”与下句如何相互印证？ {#l2.3.q6}
考点：l2.skill.treat-as
语境：l2.3.p.guest

- [x] 县令以客礼待他，所以上席相迎
- [ ] 县令自己到别人家作客
  理由：“延入堂”的人是县令。
- [ ] 士人受命去外地客居
  理由：上席设在眼前，没有远行。

提示：读“亲延”和“上”所体现的礼遇。
解析：“客”在这里以宾客身份看待士人。请入堂、列上席落实了客礼。

## 原文：教学例句 {#l2.3.p.lantern}
> 童见萤，奇其光，捧以示母。母视之，光自若也。
译文：孩子见到萤火虫，觉得它的光奇特，捧给母亲看。母亲看时，光还跟原来一样。

## 单选：末句为何有助于读懂“奇其光”？ {#l2.3.q7}
考点：l2.skill.evaluative
语境：l2.3.p.lantern

- [x] 光没有变化，惊奇的是孩子
- [ ] 母亲使萤光变得奇特
  理由：母亲看到时光“自若”。
- [ ] 孩子把光弄得更亮
  理由：句中只写捧给人看。

提示：谁的感受发生了变化？
解析：“奇”写孩子对萤光的判断；下文“自若”排除使光改变的解释。

## 原文：教学例句 {#l2.3.p.friend}
> 翁友樵者，岁相过。有人问其故，翁曰：“取其信也。”
译文：老人把樵夫当朋友，每年彼此探访。有人问缘故，老人说：“看重他守信。”

## 单选：“友樵者”中的“友”怎样补读？ {#l2.3.q8}
考点：l2.skill.treat-as
语境：l2.3.p.friend

- [ ] 让另一个人同樵夫结交
  理由：相互探访的是老人和樵夫。
- [x] 以樵者为朋友
- [ ] 把朋友训练成樵夫
  理由：原句已称对方为樵者。

提示：后面的“相过”意味着哪两方往来？
解析：“友”带“樵者”作对象，指老人把樵夫当朋友相待。
