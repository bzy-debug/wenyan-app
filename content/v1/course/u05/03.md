# 课文：意动：把对象看成什么 {#l2.3}
简介：“小鲁”是鲁国真的变小了，还是登高的人看它小？读出说话人的眼光。

## 正文

“高其台”要看前后说了什么。如果有人运土来增筑，就真把台筑高了。若写的是人仰头看台、赞它高，改变的便可能只是人对它的看法。

古人也把怎样看待一个人写进一个字里。读教学例句“友其人”，试着念成“把那人当作朋友”，再往下看他们如何往来。“师之”同理，想知道学生是不是把某人当老师，就看他有没有上前请教。

## 知识点：形容词意动 {#l2.skill.evaluative}
义项：认为对象具有某种性质
领域：句法
要诀：这是东西变了，还是人看它的眼光变了？
讲解：“壮其涛”说孩子觉得海上的波涛壮阔。读到他人的评价，先找出是谁在这样看。
例句：l2.ex.evaluative

## 原文：教学例句 {#l2.ex.evaluative}
> 童初至海，壮其涛。
译文：孩子初到海边，觉得波涛壮阔。

## 知识点：名词意动 {#l2.skill.treat-as}
义项：把对象当作某种身份的人
领域：句法
要诀：他把对方当成什么人？
讲解：“友之”可以读作把他当朋友。相互探访，或遇事向他请教，往往能说明两个人如何相待。
例句：l2.ex.treat-as

## 原文：教学例句 {#l2.ex.treat-as}
> 客贤其人，遂友之。
译文：客人认为那人贤能，于是把他当朋友。

## 原文：古籍引文 {#l2.3.p.mountain}
> 孔子登东山而小鲁，登太山而小天下。
译文：孔子登上东山，觉得鲁国小；登上太山，觉得天下小。

## 单选：孔子登了山，发生变化的是什么？ {#l2.3.q1}
考点：l2.skill.evaluative
语境：l2.3.p.mountain

- [ ] 天下地形被重新丈量
  理由：句中写登山后的感受，未写测量。
- [x] 看鲁国与天下时的眼光
- [ ] 鲁国疆界实际缩小
  理由：登高不能改变国界。

提示：将“小”试读成“以……为小”。
解析：登山改变了孔子看鲁国、看天下的位置。“小”是他登高后觉得它们显小。

## 找原文证据：第二次登山，孔子觉得什么小？ {#l2.3.q2}
考点：l2.skill.evaluative
语境：l2.3.p.mountain

- [x] 天下
- [ ] 太山
  理由：太山是孔子登上的山，他登山后放眼望向哪里？
- [ ] 东山
  理由：东山是他第一次登的地方。第二句得读到“小”字之后。

提示：找第二个“小”后面的词。
解析：“登太山而小天下”，登的是太山，觉得小的是天下。

## 原文：教学例句 {#l2.3.p.tutor}
> 村有老陶者。诸生师之，从而学埏土之法。陶者未尝为学官。
译文：村中有一位老陶工。学生们拜他为师，跟着他学揉泥。他没有担任过学官。

## 单选：学生怎样看待陶者？ {#l2.3.q3}
考点：l2.skill.treat-as
语境：l2.3.p.tutor

- [x] 在制陶这件事上把他当老师
- [ ] 让他来学生处拜师
  理由：“从而学”的主语是学生。
- [ ] 任命他为负责学校的官员
  理由：末句交代他没做过学官。

提示：看是谁跟着谁学。
解析：学生跟着陶工学本领，已经把他当老师，所以说“师之”。陶工虽没做过学官，也可以教人。

## 找原文证据：学生做了什么，能看出他们以陶工为师？ {#l2.3.q4}
考点：l2.skill.treat-as
语境：l2.3.p.tutor

- [ ] 村有老陶者
  理由：“村有老陶者”刚介绍这位陶工，还没写学生怎样待他。
- [x] 从而学埏土之法
- [ ] 未尝为学官
  理由：“未尝为学官”说的是陶工没做过学官。看看学生是来做什么的。

提示：找“师之”之后学生做的事。
解析：“从而学埏土之法”是跟着他学怎样揉泥。这件事比称呼更能说明他们怎样对待陶工。

## 原文：教学例句 {#l2.3.p.plain}
> 客过山村，陋其舍，不肯入。及闻主人能医，乃求见。
译文：客人经过山村，嫌屋子简陋，不肯进去。等听说主人会医术，才请求相见。

## 单选：客人见到房舍便不肯进，“陋其舍”该怎样读？ {#l2.3.q5}
考点：l2.skill.evaluative
语境：l2.3.p.plain

- [x] 客人认为房舍简陋
- [ ] 客人动手把屋子改得简陋
  理由：此时他还不肯入屋。
- [ ] 主人嫌客人衣着简陋
  理由：“客”是前半句的主语。

提示：从“不肯入”判断客人是在观看还是改建。
解析：客人嫌这所房子简陋，所以没进去。“陋”写的是他对屋子的看法。

## 原文：教学例句 {#l2.3.p.guest}
> 士无车马，邑令客之，亲延入堂，列席于上。
译文：士人没有车马，县令把他当贵客，亲自请进厅堂，为他安排上席。

## 单选：县令怎样待这个士人？从“客之”往下读看看。 {#l2.3.q6}
考点：l2.skill.treat-as
语境：l2.3.p.guest

- [x] 县令以客礼待他，所以上席相迎
- [ ] 县令自己到别人家作客
  理由：“延入堂”的人是县令。
- [ ] 士人受命去外地客居
  理由：上席设在眼前，没有远行。

提示：读“亲延”和“上”所体现的礼遇。
解析：县令亲自请他入堂，又安排上座。“客之”就是把这位士人当贵客相待。

## 原文：教学例句 {#l2.3.p.lantern}
> 童见萤，奇其光，捧以示母。母视之，光自若也。
译文：孩子见到萤火虫，觉得它的光奇特，捧给母亲看。母亲看时，光还跟原来一样。

## 单选：孩子觉得萤光奇特。母亲看到时，光变了吗？ {#l2.3.q7}
考点：l2.skill.evaluative
语境：l2.3.p.lantern

- [x] 光没有变化，惊奇的是孩子
- [ ] 母亲使萤光变得奇特
  理由：母亲看到时光“自若”。
- [ ] 孩子把光弄得更亮
  理由：句中只写捧给人看。

提示：谁的感受发生了变化？
解析：“光自若也”说光还跟原来一样。觉得它特别的是孩子，这才叫“奇其光”。

## 原文：教学例句 {#l2.3.p.friend}
> 翁友樵者，岁相过。有人问其故，翁曰：“取其信也。”
译文：老人把樵夫当朋友，每年彼此探访。有人问缘故，老人说：“看重他守信。”

## 单选：“友樵者”中的“友”怎样补读？ {#l2.3.q8}
考点：l2.skill.treat-as
语境：l2.3.p.friend

- [ ] 让另一个人同樵夫结交
  理由：相互探访的是老人和樵夫。
- [x] 以樵者为朋友
- [ ] 把朋友训练成樵夫
  理由：原句已称对方为樵者。

提示：后面的“相过”意味着哪两方往来？
解析：两人每年相互探访。老人看重樵夫守信，把他当作朋友，便说“友樵者”。
