# 检查：驿舍三番问答 {#check.42}

## 原文：教学例句 {#fword.p.check-keys}
> 驿吏得钥，系诸柱。客问：“昨有失钥之人，有诸？”吏曰：“有。君若见之，幸相告，我当以钥还之。”
译文：驿吏拾得钥匙，把它系在柱子上。来客问，昨天有人丢了钥匙，真有这回事吗？驿吏答有，又请来客若遇见那人就告诉自己，他会还钥匙。
词注：驿：接待使者和旅人的驿站。
  系：拴。

## 原文：教学例句 {#fword.p.check-river}
> 两舟人相助移舟。暮见一客立于岸，曰：“其失渡者乎？”一人解缆，谓同伴曰：“子其留此，吾往问之。”同伴许诺。
译文：两个船夫互相帮忙挪船。傍晚看见一个客人站在岸边，猜他大概错过了渡船。一人解开缆绳，嘱同伴留下，自己去问。对方答应了。
词注：失渡：没能搭上渡船。
  解缆：解开系船的绳索。

## 原文：教学例句 {#fword.p.check-bells}
> 更卒守城，有约：“钟鸣三，则启关。”其夕，客闻一声，问：“何以知非启关之钟？”卒以三声之约告之，曰：“城门固闭，何惧之有？”
译文：值夜的守卒有约在先，要敲三下钟才开关。那一晚，来客听见一声，问凭什么知道这不是开关的钟。守卒用三声的约定解释，告诉他城门牢牢关着，有什么可怕的。
词注：更卒：值夜巡更的士卒。
  启关：打开关门。

## 单选：“系诸柱”与“有诸”两处“诸”若都译“众多”，会漏掉哪两层？ {#fword.q.42.check.1}
考点：fword.s.zhu-place
语境：fword.p.check-keys

- [x] 把钥匙系在柱上；问丢钥匙这件事是否属实
- [ ] 问柱子有几根；再问共有几枚钥匙
  理由：文中拾得的是一把钥匙，两处都没有计数。
- [ ] 把柱子送给客人；再问钥匙要搬到哪里
  理由：柱是系钥匙的处所，后一问则没有接地点。

提示：一个“诸”后有“柱”，另一个停在问句末。
解析：前者合“之于”，之承钥，于引柱；后者合“之乎”，问有无其事。

## 单选：这里“幸相告”要由谁把消息告诉谁？与两个舟人“相助”的用法有何不同？ {#fword.q.42.check.2}
考点：fword.s.xiang-one
语境：fword.p.check-keys

- [ ] 失主在请客人代还钥匙
  理由：失主尚未出现，钥匙也还在驿吏手中。
- [x] 客人若见失主应告知驿吏，只向一方传话
- [ ] 驿吏和客人都得同时通知对方
  理由：开口嘱托的是驿吏，条件“君若见之”落在客人。

提示：谁要拿钥匙去还人，谁便需要先收到消息。
解析：驿吏对客人说“请告诉我”。双向动作可译“互相”，这种有所请求的“相告”要找准受者。

## 单选：“其失渡者乎”和“子其留此”听来都委婉。分别该当什么听？ {#fword.q.42.check.3}
考点：fword.s.qi-guess
语境：fword.p.check-river

- [ ] 前后都是船夫确认过的消息
  理由：他刚看到客人，正要去查问，前句不是核实结果。
- [ ] 前后都在劝岸上的客人留下
  理由：第二句明说“谓同伴”，听者与岸上客人不同。
- [x] 前句猜岸上人的处境，后句请同伴留下

提示：看哪一句后来需要“问之”，哪一句得到“许诺”。
解析：同一个“其”，在疑问里舒缓推断，在向同伴说的祈使句里表达劝望。

## 找原文证据：哪处必须看成两个船夫一起出力、彼此帮助？ {#fword.q.42.check.4}
考点：fword.s.xiang-both
语境：fword.p.check-river

- [x] 相助移舟
- [ ] 吾往问之
  理由：这是一人上岸问旅客，同伴留在原处。
- [ ] 同伴许诺
  理由：这是同伴答应留守，不是双方共同做的事。

提示：区分移舟时和分头行动以后。
解析：“两舟人相助”先写彼此配合；后来解缆的人和留守的人才各做各的。

## 单选：客人问“何以知”，守卒为什么提到“三声之约”？ {#fword.q.42.check.5}
考点：fword.s.heyi
语境：fword.p.check-bells

- [ ] 客人问城门是哪天修的
  理由：题中的“其夕”只说那晚，并没有问修门日期。
- [x] 客人要判断的根据，而一声尚不合三声的约定
- [ ] 客人要求马上再敲两下
  理由：“何以知”要证据，并没有要求人改变信号。

提示：看答句以什么解释信号，不要只数钟响。
解析：“何以”在这里相当于凭什么，三声才开关的约定正是判断的根据。

## 单选：守卒说“何惧之有”时，是想知道客人害怕哪件事吗？ {#fword.q.42.check.6}
考点：fword.s.he-zhi
语境：fword.p.check-bells

- [ ] 他请客人逐件报告恐惧的事
  理由：守卒刚给出城门牢闭的理由，话意落在安慰上。
- [ ] 他问这份害怕属于城内哪一个人
  理由：“之”用来提起“何惧”，没有引出领属者。
- [x] 他用反问表示城门仍闭，无须害怕

提示：把它还原成“有何惧”，紧接上一句城门状况。
解析：城门未开，守卒据此反问有什么可怕的。并非所有带“何”的问句都在等新消息。
