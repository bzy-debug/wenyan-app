# 课文：四种问句，四种答法 {#fword.42.3}
简介：问要用什么，问两者孰优，问一件事怎么办，或反问有什么可担心的。这四种问话不能用同一种话来回答。

## 正文

邻人问“何以渡水”，说“用舟”便答对了所问；问“陆行孰与舟行速”，便必须把陆行与行船两边都摆出来。两句都用疑问词，一句问凭借，另一句问比较结果。

“如伤者何”把受伤的人夹在“如”与“何”中，急着问怎样安顿他。“何患之有”却不等于“如患何”：前一句往往是反问有什么忧患，实际上认为没有，后一句才是在就一个实有的难题问办法。

## 知识点：“何以”问依据或凭借 {#fword.s.heyi}
义项：还原为“以何”，用什么或凭什么
领域：虚词
要诀：答句能补到“以……”中，才回答了手段或根据。
讲解：“何以度其深”要回答的是测水深的工具；答“以长竿”可以，答“在河边”只能说地点。
例句：fword.p.river

## 知识点：“孰与”比较两项 {#fword.s.shuyu}
义项：先辨哪两项，再判比较的方面
领域：虚词
要诀：把两者分别圈出，再给轻重、快慢或好坏各找依据。
讲解：“陆运孰与舟运速”问题里已点出“速”，不是询问谁在运粮。距离相同时，先到的一方才合这次比较。
例句：fword.p.grain

## 知识点：“如……何”问怎样处置 {#fword.s.ruhe}
义项：被安顿的人或待解决的事夹在“如”与“何”之间
领域：虚词
要诀：拿被夹住的对象来问“把它怎么办”。
讲解：“如湿粟何”关心的是眼前这批受潮的谷物。下一句农人请把湿粟搬出晒干，回答的是处置办法。
例句：fword.p.grain

## 知识点：“何……之有”反问有什么 {#fword.s.he-zhi}
义项：把疑问宾语还原到“有”后，再听上下文是否在否认
领域：虚词
要诀：“何患之有”先读作“有何患”，还要看说话人是否认为无须忧虑。
讲解：“仓已固，何患之有”先说粮仓牢固，再说哪有什么可担忧的。“之”提示宾语提前，无须另找一个人物作它的所指。
例句：fword.p.grain

## 原文：教学例句 {#fword.p.river}
> 秋水涨。客问：“何以度其深？”舟子出长竿。又问：“北津孰与南津浅？”舟子曰：“南津可涉。”客顾伤者曰：“如之何？”舟子乃留舟载之。
译文：秋水上涨。客人问用什么测深浅，船夫拿出长竿。客人再问南北两处渡口哪个浅，船夫说南津可以涉水。客人转身看看伤者，问怎样安顿他。船夫就留下船载他。
词注：度：读 duó，测量。
  涉：徒步渡水。
  津：渡口。

## 原文：教学例句 {#fword.p.grain}
> 西仓受雨。吏问：“如湿粟何？”农请出而曝之。又问：“陆运孰与舟运速？”答曰：“同日发，舟先至。”乃以舟移粟入东仓。仓已固，农曰：“何患之有？”
译文：西仓进了雨水。官吏问湿粟怎么办，农人提议搬出晾晒。再问陆运与水运哪个快，答说同日出发则船先到，于是用船运粟入东仓。东仓牢固了，农人说，还有什么可担忧的？
词注：曝：晾晒。
  患：忧虑。

## 原文：古籍引文 {#fword.p.jiang}
> 对曰：“姜氏何厌之有？不如早为之所，无使滋蔓！”
译文：祭仲答说：“姜氏哪会有满足的时候？不如早些给这件事作好安排，别让它继续蔓延！”
词注：厌：满足。
  滋蔓：滋长蔓延。

## 原文：教学例句 {#fword.p.deed}
> 里人争田。吏曰：“何以知此田属汝？”甲出旧券，券有四至，皆合。
译文：村人争田。官吏问甲凭什么知道这田归他。甲拿出旧契，上面记有四面的边界，一一吻合。
词注：券：契据。
  四至：四面边界到达之处。

## 单选：客人问“何以度其深”，长竿为什么是合适的回答？ {#fword.q.42.3.1}
考点：fword.s.heyi
语境：fword.p.river

- [x] 问用什么去量，长竿正好作工具
- [ ] 问哪边渡口较浅，长竿标出了南津
  理由：比较渡口是后一个问题。
- [ ] 问水为何上涨，长竿原是涨水原因
  理由：舟子拿竿来是为测水，不会导致水涨。

提示：把“何以”两字的关系展开成“以何”。
解析：所缺的是“以长竿”这一手段。把它解释成一律问“为什么”，这次答话便对不上。

## 单选：“陆运孰与舟运速”要求比较什么，又按什么标准？ {#fword.q.42.3.2}
考点：fword.s.shuyu
语境：fword.p.grain

- [ ] 陆路与水路，比哪边的粟更干
  理由：前面湿粟虽需晾晒，此处问题却换成了“速”。
- [x] 陆路运粟与水路运粟，比哪种先到
- [ ] 两位运粮人，比谁拿得多
  理由：问题里比较的是两种运输方式，“速”定下了快慢。

提示：试用“甲同乙相比，谁更……”复述。
解析：“同日发，舟先至”与“速”相扣，回答的是比较结果。

## 找原文证据：“如之何”把需要安顿的人夹在中间。这里的“之”对应哪两个字？ {#fword.q.42.3.3}
考点：fword.s.ruhe
语境：fword.p.river

- [ ] 南津
  第几处：2
  理由：这是可步涉的地点，不是需要船载的人。
- [ ] 舟子
  第几处：3
  理由：船夫留下船帮忙，是来办事的那一方。
- [x] 伤者

提示：问句前客人转身看谁？接下来又用船载谁？
解析：别人或许能涉水，伤者却需要另外安顿。“如之何”就是拿眼前这个人怎么办。

## 单选：祭仲问“姜氏何厌之有”，紧接着劝国君早作安排。他认为姜氏会怎样？ {#fword.q.42.3.4}
考点：fword.s.he-zhi
语境：fword.p.jiang

- [x] 不会轻易满足，所以得早作安排
- [ ] 已经心满意足，国君只需庆贺
  理由：“无使滋蔓”是怕事态继续蔓延，不是贺辞。
- [ ] 不清楚她厌恶哪种食物，须派人打听
  理由：“厌”在这里是满足，“何厌之有”不是问饮食好恶。

提示：还原为“有何厌”，再听问话后提出的劝告。
解析：疑问宾语“何厌”移到“有”前，这是反问姜氏哪里会有厌足；因此才接劝止之言。

## 找原文证据：吏问“何以知”，靠的是哪件可以拿出来比对四至的东西？ {#fword.q.42.3.5}
考点：fword.s.heyi
语境：fword.p.deed

- [ ] 此田
  理由：田是争议对象，不是甲刚刚出示的凭证。
- [x] 旧券
- [ ] 里人
  理由：乡人有争执，出现了人还不算得出了依据。

提示：找能回答“凭什么知道田属你”的实物。
解析：同是“何以”，在这里要的是判断的证据。契据上的四至与实际相合，才使认定有据。

## 单选：回答“北津孰与南津浅”，哪一种答法照顾到了问句里真正的两端？ {#fword.q.42.3.6}
考点：fword.s.shuyu
语境：fword.p.river

- [ ] 只报测量用的竿有多长
  理由：这回答工具的尺寸，没比较两处渡口。
- [ ] 报告伤者从北方来
  理由：此处没有问人从哪里来，而在比较两处的深浅。
- [x] 比较两处水深，说明南津较浅可涉

提示：圈出“孰与”两旁的地点，再找末尾的形容词。
解析：这里问的是北津与南津相比谁浅。随后解决安顿伤者，是另一个问题。

## 单选：若以“如湿粟何”发问，三句答话中哪句最切题？ {#fword.q.42.3.7}
考点：fword.s.ruhe
语境：fword.p.grain

- [x] 摊开晾晒，再转运干燥处
- [ ] 湿粟看起来像沙土
  理由：这里的“如”与“何”配合，不是要求给粟作比喻。
- [ ] 湿粟比干粟重
  理由：这是比较轻重，没有处置受潮粮食。

提示：把“湿粟”放进“拿……怎么办”。
解析：两字之间是待处理的物件。官吏的问题需要实际方案，故农人以晾晒作答。

## 单选：“何患之有”中的“之”为什么不能译作另一个需要照看的“他”？ {#fword.q.42.3.8}
考点：fword.s.he-zhi
语境：fword.p.grain

- [ ] “之”表示要前往粮仓，反问谁将出发
  理由：移粟已经结束，“仓已固”后农人才说这句话。
- [x] “何患”是被提到“有”前的宾语，问的是还有什么忧患
- [ ] “之”指搬粟的人，农人要问这人在哪里
  理由：原句动词是“有”，并没有寻找人的动作。

提示：把句序还原成“有何患”，看意思是否已足。
解析：牢固的新仓让农人放心。他以反问断定无须担忧，不是在增加一个人物。
