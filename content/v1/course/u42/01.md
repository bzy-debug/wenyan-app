# 课文：书放在哪里，人又问谁 {#fword.42.1}
简介：一声招呼里，丢下了什么，递给了谁？把“诸”展开，把“相”指的人找回来。

## 正文

友人带来两卷书，说“置诸案”。书和桌子都得有地方安顿：“诸”可以拆成“之于”，即把它们放在桌上。若朋友说“闻君欲远行，有诸”，问的是有没有这回事，尾音相当于“乎”，没在问哪个地点。

两个人“相顾”，是你看我、我看你；老人嘱咐行人“幸相告”，是请他回来告诉自己。是双向的动作，还是一方朝另一方做事，读后来的答话往往比数有几个人更可靠。

## 知识点：“诸”合说“之于” {#fword.s.zhu-place}
义项：在动作后把对象同地点或另一对象连起来
领域：虚词
要诀：将“诸”展开为“之于”，分别为两者找着落。
讲解：“置诸案”中的“之”承书，“于案”安置书。省掉其中一层，就只剩一句没说完的“放”或一个空地点。
例句：fword.p.book

## 知识点：“诸”合说“之乎” {#fword.s.zhu-question}
义项：句末回指一件事并询问它是否成立
领域：虚词
要诀：先补“有这回事吗”，再看下句是否应答。
讲解：定公问一言能否兴邦，又问“有诸”。这里没有给出地点，孔子答的是这件事是否真能如此。
例句：fword.p.ruler

## 知识点：“相”写双方彼此行动 {#fword.s.xiang-both}
义项：同一动作由两方朝对方实施
领域：虚词
要诀：两人各能用“对方”作动作对象，才是彼此。
讲解：“二人相视而笑”，一人抬眼，另一人也回望；如果只译成一人看他，另一半动作便丢了。
例句：fword.p.book

## 知识点：“相”在话中偏指一方 {#fword.s.xiang-one}
义项：有一个行动者，受动作的一方要从对话中补出
领域：虚词
要诀：把“相”换成我或你，核对谁在请求、谁会受益。
讲解：朋友说“幸相告”，看对方答“诺”便知道他是请求听者把消息告诉自己；并非两人约好互报消息。
例句：fword.p.book

## 原文：教学例句 {#fword.p.book}
> 友携二卷至，主人曰：“置诸案。闻君欲远行，有诸？”友曰：“未也。若有舟至，幸相告。”主曰：“诺。”二人相视而笑。
译文：朋友带来两卷书，主人让他放在桌上，问他是否真的要远行。朋友答说还没有，请主人有船到时通知自己。主人答应，两人相望而笑。
词注：案：桌案。
  幸：盼望、请。

## 原文：教学例句 {#fword.p.mountain}
> 山道有岐，兄弟相扶而上。弟解囊，置诸石上，谓兄曰：“吾往汲泉，幸相待。”兄止不前。
译文：山路有岔口，兄弟二人互相搀扶着登山。弟弟取下行囊，放在石上，说要去取水，请哥哥等自己。哥哥停下脚步。
词注：岐：岔路。
  囊：行囊。

## 原文：古籍引文 {#fword.p.ruler}
> 定公问：“一言而可以兴邦，有诸？”孔子对曰：“言不可以若是其几也。人之言曰：‘为君难，为臣不易。’如知为君之难也，不几乎一言而兴邦乎？”
译文：鲁定公问：“一句话便能使国家兴盛，有这样的事吗？”孔子回答，话不能说得这么肯定。人们说“做君主难，当臣子也不容易”。如果因此懂得为君之难，不就接近一句话使国家兴盛了吗？
词注：邦：国家。
  几：接近。

## 单选：“置诸案”若补回两个字，书友要做什么？ {#fword.q.42.1.1}
考点：fword.s.zhu-place
语境：fword.p.book

- [ ] 把所有桌案排好
  理由：“诸”后没有几个同类的桌子，前面带来的是两卷书。
- [ ] 问桌案上是否已有书
  理由：主人在吩咐放书；发问的是下一句。
- [x] 把这两卷书放在桌案上

提示：试将“置之于案”的“之”换成实际物件。
解析：“诸”既承接两卷书，又把“案”接成放置的处所。

## 单选：定公问“有诸”，他等孔子回答什么？ {#fword.q.42.1.2}
考点：fword.s.zhu-question
语境：fword.p.ruler

- [x] 一句话能兴邦，究竟有没有这回事
- [ ] 兴邦的话藏在哪个国家
  理由：“邦”是前句讨论的国家，没有藏话的地点。
- [ ] 国家一共有多少句话
  理由：“有”并非在清点数量；孔子答的是能否达到那种结果。

提示：把“诸”展开成“之乎”，先说清楚“之”指哪件事。
解析：定公复述一个说法后又追问真假，“诸”让他不必把整件事重复一遍。

## 单选：兄弟“相扶而上”时，两人的动作如何相连？ {#fword.q.42.1.3}
考点：fword.s.xiang-both
语境：fword.p.mountain

- [ ] 兄弟分头上山去找别人
  理由：“扶”要有受扶的人，这里两人在一起相扶。
- [x] 各自扶着对方上山
- [ ] 只有弟弟扶哥哥，哥哥按住行囊
  理由：行囊在下一句才取下；此处以兄弟二人同作动作。

提示：山路上两个人都在“扶”，受扶的人分别是谁？
解析：可以说哥哥扶弟弟，也可以说弟弟扶哥哥。“相”把这两个方向并在一起。

## 单选：“幸相告”的消息最后该从谁送到谁那里？ {#fword.q.42.1.4}
考点：fword.s.xiang-one
语境：fword.p.book

- [ ] 两人都要给对方报一遍船期
  理由：等船消息的是客人，主人只答应向他报信。
- [ ] 朋友自己告诉船夫
  理由：主人在场听请求，船夫还没出场。
- [x] 主人告诉准备出行的朋友

提示：找说“诺”的人，他答应替谁做事？
解析：说话人请对方“告诉我”。这个“相”偏指请求者，不写相互通报。

## 找原文证据：弟弟“置诸石上”。“诸”里那个可替成“之”的对象，前文用哪个字点出？ {#fword.q.42.1.5}
考点：fword.s.zhu-place
语境：fword.p.mountain

- [x] 囊
- [ ] 岐
  理由：这里交代道路分岔，不是拿下来安放的物件。
- [ ] 泉
  理由：这是后来要去取的水，还没拿到。

提示：从“解”了什么接到“置”了什么。
解析：“囊”是被放下的物件，“石上”是安放的处所；合起来才能读全这个“诸”。

## 单选：这段话两见“诸”。第二次出现时，哪一句答话正好接得上？ {#fword.q.42.1.6}
考点：fword.s.zhu-question
语境：fword.p.book

- [ ] 书卷一共有多少？答“未也”
  理由：前面已说两卷；这里问话紧接远行的传闻。
- [x] 是否真要远行？答“未也”
- [ ] 把书放在哪里？答“未也”
  理由：问地点应答一个处所；“未也”只能暂时否认所问之事。

提示：把两处分别读作“之于”和“之乎”。
解析：前一个后面跟桌案，后一个问句到此完结。朋友说还没有动身，回应的是后者。

## 找原文证据：“相告”只托对方做一件事。哪处却明确写两个人朝着对方做同一个动作？ {#fword.q.42.1.7}
考点：fword.s.xiang-both
语境：fword.p.book

- [ ] 若有舟至
  理由：这是答应报信的条件。
- [ ] 幸相告
  理由：说话人只请对方告诉自己。
- [x] 二人相视而笑

提示：找出同时明写两人以及他们眼神来往的短句。
解析：“视”落在双方身上，彼此相望；“告”在这个场景中只往一个方向。

## 单选：把“幸相待”译成兄弟互等，会与后面什么安排抵触？ {#fword.q.42.1.8}
考点：fword.s.xiang-one
语境：fword.p.mountain

- [x] 弟弟离开取水，只请留在原处的哥哥等自己
- [ ] 哥哥正准备去取水，请弟弟在石边等他
  理由：说“吾往汲泉”的是弟弟。
- [ ] 两人都要到泉边，再把囊交给别人
  理由：囊放在石上，哥哥止步，并没有第二个取泉人。

提示：把“相”还原为这句话里可以说出的“我”。
解析：哥哥留、弟弟去，受等待的是弟弟。两人的位置不同，不能一概说成互相等待。
