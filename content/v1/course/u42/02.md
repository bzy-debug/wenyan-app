# 课文：是猜想，还是一声嘱咐 {#fword.42.2}
简介：孔子答话时说“其恕乎”，行人饯别时却劝朋友“子其早归”。留意谁还有选择、谁能把事情办成。

## 正文

有人看见雾中出现帆影，说“其客舟乎”。船从何来，他其实尚不知道。“其”在这里把判断说得有余地。再听好友说“子其待之”，等船是你尚可去做的事，这一个“其”在郑重相劝。

“其人”“其日”也可能只把眼光拉回刚才提到的人、日子。师傅说“于染布之法，吾尽心焉”，已经明说用心的是哪方面。这个“焉”收住语意，译成白话不用另添一个地点。

## 知识点：“其”舒缓一项猜想 {#fword.s.qi-guess}
义项：推测某事或某个人大概如此
领域：虚词
要诀：说完还须等消息核实，或者语中有“乎”。
讲解：帆影没到岸就说“其客舟乎”，只能听成大概是客船吧。说话人还没看清，要给下一步验证留余地。
例句：fword.p.fog

## 知识点：“其”寄托给听者的劝望 {#fword.s.qi-urge}
义项：劝告或郑重嘱咐听者采取行动
领域：虚词
要诀：能照着办、也能不照办的事，试补“你还是……吧”。
讲解：“子其少待”把等候托付给眼前人。答“诺”的人是在应允，不是在给猜想提供证据。
例句：fword.p.fog

## 知识点：“其”指示刚提过的对象 {#fword.s.qi-that}
义项：在名词前复指那个人或那个时候
领域：虚词
要诀：“其日”可还原成“那天”，从前文找是哪一天。
讲解：约定初五开缸，后文才写“其日”。把“其”译成谁的所有物，反倒说不出“这一天”是哪天。
例句：fword.p.dye

## 知识点：“焉”放在句末收束语气 {#fword.s.yan-close}
义项：不另给地点或人物，语意在末字顿住
领域：虚词
要诀：先读掉末字；已有完整处所或判断，再看补一个“那里”是否有据。
讲解：“于染布之法，吾尽心焉”，谈论的方面已经在“于染布之法”。末字收住这句话，不再引入另一间染坊。
例句：fword.p.dye

## 原文：教学例句 {#fword.p.fog}
> 昨约客舟今日来。津吏见雾中一帆，曰：“其客舟乎？”又谓童曰：“子其少待，俟舟近而后问。”童曰：“诺。”雾既散，乃知渔舟也。
译文：昨天约好客船今日到。渡吏看见雾中一面帆，猜想是客船，又让孩子稍等，待船近些再问。孩子答应。雾散后才看清是渔船。
词注：津吏：管理渡口的人。
  少待：稍等。
  俟：等候。

## 原文：教学例句 {#fword.p.dye}
> 染者约以初五发缸。其日，徒见水微赤，曰：“缸色尚浅，其未成乎？”师曰：“子其徐搅之。于染布之法，吾尽心焉。”
译文：染工约定初五开染缸。那天，学徒见缸水微红，说颜色还浅，问大概是还没有染成吧。师傅嘱他慢慢搅动，又说自己对染布的方法已经尽心。
词注：发缸：打开染缸。
  徒：学徒。
  徐：慢慢地。

## 原文：古籍引文 {#fword.p.shu}
> 子贡问曰：“有一言而可以终身行之者乎？”子曰：“其恕乎！己所不欲，勿施于人。”
译文：子贡问，有没有一个字可以终身奉行。孔子说，大概是“恕”吧；自己不愿意的事，不要强加给别人。
词注：恕：推己及人，体谅别人。
  施：加在别人身上。

## 原文：教学例句 {#fword.p.hearth}
> 翁为童定日学陶，曰：“十月朔至。”其日雨，童冒雨至。翁曰：“汝于成约，吾无疑焉。”乃授之以土。
译文：老人同孩子定下学制陶的日子，让他十月初一来。那天下雨，孩子冒雨而来。老人说：“说到你履行约定，我没有疑虑了。”便给他陶土。
词注：朔：农历每月初一。
  成约：履行所立的约定。

## 单选：从“其客舟乎”读到“雾既散，乃知渔舟”，哪种先后与所见相合？ {#fword.q.42.2.1}
考点：fword.s.qi-guess
语境：fword.p.fog

- [ ] 他先确认是客船，又在雾散后催船返回
  理由：“其……乎”留下了猜测余地，后来查见的还是渔船。
- [x] 先凭帆影猜是客船；待雾已散，才认出渔船
- [ ] 他先猜客船，在大雾尚未散去时就认出了渔船
  理由：“既散”说散雾这个变化已经完成，再接认船。

提示：一句是待核的猜想；另一句中“既”把什么变化放到了确认之前？
解析：猜客船时只有帆影；“雾既散”写雾已散了，这时才认出渔船。将两层混在一起，会把猜想当成查验结果。

## 单选：“子其徐搅之”应当让学徒作出哪种回应？ {#fword.q.42.2.2}
考点：fword.s.qi-urge
语境：fword.p.dye

- [ ] 报告自己觉得染缸大概正慢慢转
  理由：师傅直接喊“子”，接着是学徒能控制的动作。
- [ ] 寻找某个人所有的搅杆
  理由：“其”后接动作“徐搅”，没有领属的名物。
- [x] 放慢手势，照着师傅的嘱咐去搅

提示：能不能回一句“好，我照办”？
解析：师傅是在对听者提出做法，“其”给嘱咐留了劝告的口气。

## 单选：来了雨的“其日”，指哪一天？ {#fword.q.42.2.3}
考点：fword.s.qi-that
语境：fword.p.hearth

- [x] 前面师徒约定的十月初一
- [ ] 孩子拥有的一整个月
  理由：“其”这里要接一个具体的“日”，不是表示日期所有权。
- [ ] 初一以后第一次晴天
  理由：来时明说下了雨，并无改期。

提示：把“其日”换成“那一天”，往前找日子。
解析：前一句留下日期，后一句用“其”把读者带回该日；真正的新消息是那天下雨。

## 单选：“于染布之法，吾尽心焉。”这句话还要再补一个地点才能读通吗？ {#fword.q.42.2.4}
考点：fword.s.yan-close
语境：fword.p.dye

- [ ] 要补另一个染缸，表示师傅正在其中
  理由：“于染布之法”说的是在这门手艺上尽心，不是在缸里。
- [x] 不用；用心的方面已经说了，“焉”在句尾收住语气
- [ ] 要补染坊门外，师傅要人到那里去
  理由：原句没有命人出门。

提示：句首“于……”已经交代了哪一方面？
解析：有些“焉”能回指“在那里”；此处谈什么已经明说，句末无需另立一个处所。

## 单选：子贡问一字能否终身奉行。孔子的“其恕乎”用怎样的口气领出答案？ {#fword.q.42.2.5}
考点：fword.s.qi-guess
语境：fword.p.shu

- [ ] 把“恕”说成子贡家里所有的一件东西
  理由：“恕”是可践行的准则，没有主人和物件的关系。
- [ ] 命令子贡猜另一个人有没有宽恕他
  理由：回答马上解释自己不愿的事勿加于人，没有让他调查某人。
- [x] 提出“恕”大概合适，再用一句话说明

提示：“其……乎”夹着的是一个候选答案。
解析：孔子用带商量的口气点出一个字，接着说如何行恕。说得委婉，并不表示没有主张。

## 找原文证据：渡吏先猜来船，再把一件可以照做的事托给孩子。哪几个字属于后一层？ {#fword.q.42.2.6}
考点：fword.s.qi-urge
语境：fword.p.fog

- [x] 子其少待
- [ ] 其客舟乎
  理由：这一句是辨认帆影的猜测。
- [ ] 乃知渔舟也
  理由：这是雾散后实际知道的事。

提示：能接上孩子“诺”的是哪句话？
解析：孩子只需依言稍等。“其”在这里朝听者发出劝告，与先前猜客船的“其”有别。

## 找原文证据：“其日，徒见水微赤。”要恢复“其日”的所指，前文哪一处给出了约定日期？ {#fword.q.42.2.7}
考点：fword.s.qi-that
语境：fword.p.dye

- [ ] 染者
  理由：这是提出约定的人。
- [x] 初五
- [ ] 发缸
  理由：这说那天准备做什么，没给日期。

提示：先知道“那天”是哪天，再看当天出了什么事。
解析：“其”让“日”复指先约的初五，不能挨见“其”就问“谁的”。

## 单选：“汝于成约，吾无疑焉。”老人为什么无需在“焉”后另译出一个地点？ {#fword.q.42.2.8}
考点：fword.s.yan-close
语境：fword.p.hearth

- [ ] 因为原句省去了孩子另要去的一座城
  理由：约的是来学陶，原文从未提及进城。
- [ ] 因为“焉”表示老人自己还有疑问
  理由：“无疑”已明说没有疑虑，与发问不同。
- [x] 老人已经点明所谈的是孩子守约，这句话在此收束

提示：先把句首的“于成约”带进译文。
解析：他相信的，是孩子守这个约的态度。译完这层意思即可停住，不必转去找“那里”。
