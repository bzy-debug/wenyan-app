## 正文

亲近与亲人，厚礼与优待，读起来容易互相牵扯。试用后文核对：是谁需要赡养？谁原先常来往、如今渐渐不来？谁只是把粮食暂借给别人？

## 原文：教学例句 {#rv52.3.p1}
> 旦，樵者入县见令，言：“吾亲皆老。昨暮归，釜中无粟。”令命吏察其家。
译文：清早，打柴人入县署拜见县令，说父母年迈，昨晚回家时锅里已没有粮。县令命人察看他家。
词注：釜：锅。

## 原文：教学例句 {#rv52.3.p2}
> 岁饥，县出廪粟恤贫。富人季生复以私粟周邻，限秋偿之。县令厚季生，每至，必延之上坐。
译文：年成饥荒，县里开仓拿粮赈贫。富户季生又用私粮周济邻居，约到秋天偿还。县令优待季生，每逢来访，总请他坐上座。
词注：廪：粮仓。

## 原文：古籍引文 {#rv52.3.p3}
> 子游曰：“事君数，斯辱矣；朋友数，斯疏矣。”
译文：子游说，事奉国君而过于烦琐，就要受辱；对朋友也过于烦琐，就会失去亲近。
词注：数：读 shuò，这里说过于频繁。

## 单选：“旦”交代樵者何时进县？ {#rv52.3.q1}
考点：skill.vocab.8.3
语境：rv52.3.p1

- [x] 次日清早
- [ ] 前一日晚饭前
  理由：昨暮是他回家见空锅的时间。
- [ ] 清早到县后又过了一整天
  理由：这里没有经过一日的说法。

提示：把它和樵者所说的“昨暮”分开。
解析：“旦”在记叙者的话开头，指本次拜见发生在清晨。

## 单选：樵者“入县见令”要做什么？ {#rv52.3.q2}
考点：skill.vocab.6.3
语境：rv52.3.p1

- [ ] 在县署门上看见一纸命令
  理由：随后有人听他说话，又叫小吏核察，是县令本人。
- [ ] 被县令派去察看另一个家庭
  理由：派人察看在樵者陈情之后。
- [x] 亲自拜见县令，陈说家中情况

提示：“言”后是谁的自述？
解析：这里“见”是拜见；“令”是他去见的县令。

## 单选：“吾亲皆老”所指何人？ {#rv52.3.q3}
考点：skill.vocab.10.1
语境：rv52.3.p1

- [ ] 县令的两个亲信
  理由：樵者说“吾亲”，说的是自己家。
- [x] 樵者的父母
- [ ] 所有跟樵者亲近的邻人
  理由：这番陈情专说须由家里奉养老人。

提示：后文察的是哪一户？
解析：“亲”用作名词指父母；请求核验的是樵者自己的家境。

## 单选：樵者上一次回到自家是什么时候？ {#rv52.3.q4}
考点：skill.vocab.8.4
语境：rv52.3.p1

- [x] 昨天傍晚
- [ ] 今天清晨
  理由：清晨他出门去见县令。
- [ ] 县令下令以后的黄昏
  理由：“昨”把这件事放在陈情以前。

提示：读完整个“昨暮归”。
解析：“暮”指傍晚，这件事发生在前一天，是今晨求见的缘故。

## 单选：县里“恤贫”已经怎样做了？ {#rv52.3.q5}
考点：skill.vocab.12.3
语境：rv52.3.p2

- [ ] 向季生借粮，到秋日再还
  理由：秋偿是季生周济邻里时的约定。
- [ ] 把缺粮人召来询问，并未发粮
  理由：“出廪粟”已写出实际救济。
- [x] 拿公仓的粮食救济缺粮的人

提示：先看“恤”前怎么用粮。
解析：这里“恤”落实为以公粮赈贫，不止是同情。

## 单选：季生“以私粟周邻”，私粮去了哪里？ {#rv52.3.q6}
考点：skill.vocab.12.4
语境：rv52.3.p2

- [ ] 交给县里，换取上座的资格
  理由：受粮的是邻人，请上座的是县令，文中没有交易。
- [x] 借给缺粮邻人，秋后偿还
- [ ] 留在自己仓里预备秋收
  理由：“周邻”已经把粮拿出来帮人。

提示：“周”后是哪一方？
解析：周是周济；粮的来处是季生私仓，用处是接济邻人。

## 单选：哪件事体现县令“厚季生”？ {#rv52.3.q7}
考点：skill.vocab.10.4
语境：rv52.3.p2

- [x] 季生来访时被请上座
- [ ] 县令认为季生的粮囤得太厚
  理由：“厚”直接接人，后文写招待方式。
- [ ] 县令要求季生多还公粮
  理由：未说季生借公粮，更没说催还。

提示：“每至”以下写怎样待客。
解析：厚是优待；“必延之上坐”让人看见待遇有什么不同。

## 单选：在朋友一层，“疏”说的是怎样的结果？ {#rv52.3.q8}
考点：skill.vocab.10.3
语境：rv52.3.p3

- [ ] 来往的日程安排得稀疏而合宜
  理由：“斯”引出过分烦琐造成的后果。
- [ ] 把朋友的过失写成奏疏
  理由：这里与朋友相处，未有上书陈事。
- [x] 原有交情渐远

提示：前后两句都在说一种相处方式的后果。
解析：“疏”是疏远；说话人提醒，即使本来相熟也可能伤了交情。
