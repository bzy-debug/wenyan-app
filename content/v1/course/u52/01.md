## 正文

先用手指在纸上标出客人、童子和老人的位置。“顾”可以只动眼睛和头；“去”和“适”却要画出离开的地方和要去的地方。把起点和终点分开，就能读清谁还在原地。

## 原文：教学例句 {#rv52.1.p1}
> 客去南舍，欲适北村。童子将客行，顾见老叟独立于桥，乃止。
译文：客人离开南边的屋子，要去北村。孩子领客人前行，回头见老人独自站在桥上，就停下了。
词注：舍：房屋。

## 原文：教学例句 {#rv52.1.p2}
> 村有古槐，水啮其本。故道已绝，守林者在东冈。客乃诣东冈，求见守林者。
译文：村里有老槐树，流水侵蚀树根。旧路已断，守林人在东冈。客人就到东冈求见。
词注：啮：本指咬，这里形容流水侵蚀。

## 原文：古籍引文 {#rv52.1.p3}
> 子夏曰：“君子有三变：望之俨然，即之也温，听其言也厉。”
译文：子夏说，君子给人三种感受：远望庄重，走近温和，听他说话又很严正。
词注：俨然：庄重的样子。

## 单选：若要找客人动身以前住的屋子，该往哪儿找？ {#rv52.1.q1}
考点：skill.leave
语境：rv52.1.p1

- [ ] 北村，是“去”指明的去处
  理由：北村在“欲适”之后，只是此行的目的地。
- [x] 南舍，是他刚离开的地方
- [ ] 桥上，是他回身离开的地方
  理由：桥上站着老人，文中没说客人住在那里。

提示：看“去”和“适”各接什么。
解析：“去南舍”先交代从哪里出来，接下来才说要往哪里走。

## 单选：“欲适北村”只够确认哪一件事？ {#rv52.1.q2}
考点：l2.skill.travel-shi
语境：rv52.1.p1

- [x] 客人打算去北村
- [ ] 客人刚好在北村遇见童子
  理由：“欲”说的是尚待实现的打算。
- [ ] 客人以为北村适宜久居
  理由：这里“适”直接接地名，后面接着写行路。

提示：北村在行人前面还是身后？
解析：“适”带目的地；“欲”又表明此刻还不能把到达写成事实。

## 单选：“童子将客行”里的童子担任什么角色？ {#rv52.1.q3}
考点：skill.vocab.2.2
语境：rv52.1.p1

- [ ] 留在家里，打算稍后出门
  理由：“将”后接“客”，两人已经动身。
- [ ] 等客人在前面来领自己
  理由：这会调换“将”前后两个人的角色。
- [x] 给客人带路

提示：谁在“将”之前，谁紧跟在后？
解析：“将客”是领着客人走。下一动作是回头看，不是临行准备。

## 单选：桥在身后。童子怎样发现老人没有跟来？ {#rv52.1.q4}
考点：l2.skill.look-back
语境：rv52.1.p1

- [ ] 登桥去照料老人时才知道
  理由：“顾见”之后才停步，没有上桥照看的动作。
- [x] 转头看见老人仍站在桥上
- [ ] 事先顾虑老人不能过桥
  理由：“见”记的是眼前所见，并非预先担忧。

提示：把“顾”和“见”连起来读。
解析：这里“顾”指回头看；老人仍在桥上，孩子才停下来。

## 单选：流水已经伤到槐树的哪一部分？ {#rv52.1.q5}
考点：l2.skill.tree-root
语境：rv52.1.p2

- [x] 靠地面的根部
- [ ] 树梢新长的细枝
  理由：“本”与树相连，写受水侵蚀的根部。
- [ ] 最先长成的那一圈年轮
  理由：“本”在这里指部位，文中没有数树龄。

提示：水贴着地面冲刷。
解析：“其”指古槐，“本”落实到树根，水冲刷的是树的根基。

## 单选：守林人若要修“故道”，要动手修什么？ {#rv52.1.q6}
考点：l2.skill.path-dao
语境：rv52.1.p2

- [ ] 村里传下的护林道理
  理由：“绝”后行人须另去东冈，关涉交通。
- [ ] 流水侵蚀出的河槽
  理由：原文分开写水啮树根和旧路断绝。
- [x] 以前通行的路

提示：客人随后改往东冈。
解析：“故道”是旧路，路断了会改变行人的路线。

## 单选：“诣东冈，求见守林者”把哪两步分开写了？ {#rv52.1.q7}
考点：skill.vocab.1.2
语境：rv52.1.p2

- [ ] 先得到守林人批准，才上东冈
  理由：所求的是见人，不是准他入山。
- [x] 先到东冈，再请求见人
- [ ] 先进见守林人，再请他去东冈
  理由：“诣”后写东冈，“求见”才写见谁。

提示：“诣”紧接地点。
解析：到达东冈与见到守林人是两件事；“求见”还未说见到了。

## 单选：哪种变化使人从“俨然”读到了“温”？ {#rv52.1.q8}
考点：skill.vocab.3.2
语境：rv52.1.p3

- [x] 看他的人走近了
- [ ] 君子马上换了一套言辞
  理由：听言是第三层，这一层未开始谈话。
- [ ] 君子走远以后神色缓和
  理由：从远望到“即之”是距离变近。

提示：对读“望之”和“即之”。
解析：“即”指接近。远观和近处相接，见到的神情有所不同。
