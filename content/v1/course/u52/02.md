# 课文：受托的人能替谁作主 {#rv52.2}
简介：客人把一件事托给亭长，县中却要他亲自说明。

## 正文

读交往的文字，可以先分清三件事：登门不等于见到了人，派人传话不等于让他作主，推辞与责备也会把话引向不同的人。

## 原文：教学例句 {#rv52.2.p1}
> 雨坏桥。里正率三人造陶翁，属以守舟之事。翁辞曰：“足病，不能久立。”
译文：雨水毁桥。里正带三个人登门拜访陶老翁，把看守渡船的事托付给他。老翁推辞，说脚有病，不能久站。
词注：里正：这里指主持乡里事务的人。

## 原文：教学例句 {#rv52.2.p2}
> 县君使吏召舟师。吏趋入其户，不待答而取篙。舟师让之曰：“召我可也，何取吾物？”
译文：县令派小吏去叫船工。小吏快步进门，没有等回话便取走竹篙。船工责备他：叫我可以，为什么拿我的东西？
词注：篙：撑船的竹竿。

## 原文：古籍引文 {#rv52.2.p3}
> 始吾于人也，听其言而信其行；今吾于人也，听其言而观其行。
译文：起初我待人，听了他的话就相信他的行为；如今听了他说什么，还要看他怎样做。
词注：行：实际行为。

## 单选：门前来了里正和三人，谁领头？ {#rv52.2.q1}
考点：skill.vocab.2.3
语境：rv52.2.p1

- [ ] 三个人领里正来办事
  理由：“率”前的人领着后面的人。
- [ ] 陶翁带里正和三人去渡口
  理由：众人刚来见陶翁。
- [x] 里正带那三个人同来

提示：把“率三人”单独读一遍。
解析：“率”是带领，跟随者是三人；接着的“造”交代去拜访谁。

## 单选：门簿该怎样记“造陶翁”？ {#rv52.2.q2}
考点：skill.vocab.1.3
语境：rv52.2.p1

- [ ] 陶翁替里正造了新舟
  理由：舟只是稍后托人看守，没有造舟。
- [x] 里正一行登门访陶翁
- [ ] 里正请陶翁先到县署
  理由：众人先去了陶翁那里，方向相反。

提示：“造”后面写的是人。
解析：“造陶翁”指到陶翁处拜访，随后才开口托事。

## 单选：“属以守舟之事”希望由谁负责？ {#rv52.2.q3}
考点：skill.vocab.5.2
语境：rv52.2.p1

- [x] 希望陶翁替大家守舟
- [ ] 请三人把渡船过户给陶翁
  理由：所托是“事”，没有把船送给谁。
- [ ] 请陶翁另找里正替他守船
  理由：里正是托付的一方。

提示：谁听完这话便推辞？
解析：“属”读 zhǔ，意为嘱托；老翁的话说明托付落在他身上。

## 单选：陶翁说“足病”是要表达什么？ {#rv52.2.q4}
考点：skill.vocab.4.2
语境：rv52.2.p1

- [ ] 他已经守完船，前来告辞
  理由：托事与答话相接，他尚未接差。
- [ ] 他不愿让里正进屋
  理由：推辞的对象是刚提到的守舟之事。
- [x] 这项差事他不能接

提示：把理由和前一句所托的事相连。
解析：这里“辞”是推辞。他说明不能久立，回应的是能否负责守舟。

## 单选：“县君使吏召舟师”，门前来的是谁？ {#rv52.2.q5}
考点：skill.vocab.5.3
语境：rv52.2.p2

- [ ] 县令，由小吏领他来召人
  理由：县令派人去，没有亲自到船工家。
- [x] 受县令差遣的小吏
- [ ] 奉船工之命来请县令的小吏
  理由：船工正是被召的人。

提示：按“使、召”各找一个对象。
解析：县令差遣小吏，小吏应当去召船工，差遣并不包含取篙的授权。

## 单选：小吏怎样进了门？ {#rv52.2.q6}
考点：skill.vocab.3.3
语境：rv52.2.p2

- [x] 快步走进船工家
- [ ] 顺着竹篙滑进屋里
  理由：取篙是进门以后的事。
- [ ] 多次来往，渐渐同船工亲近
  理由：“趋入”紧接取篙，记的是这一次的动作。

提示：“趋”同“入”连读。
解析：“趋”交代步子快，“入其户”交代走进哪里。

## 单选：船工在“让之”。他介意哪件事？ {#rv52.2.q7}
考点：skill.vocab.4.3
语境：rv52.2.p2

- [ ] 小吏不肯让他先入门
  理由：原句里船工问的是“何取吾物”。
- [ ] 小吏邀他到县里，他一概拒绝
  理由：“召我可也”已允诺可以去。
- [x] 小吏未得答允就拿竹篙

提示：责备落在哪句问话上？
解析：“让”是责备；船工接受传召，却不许小吏顺手取物。

## 单选：“信其行”同后一句的“观其行”怎样区别？ {#rv52.2.q8}
考点：skill.vocab.6.1
语境：rv52.2.p3

- [ ] 从前只看行动，现在专信言辞
  理由：这把“始、今”的先后颠倒了。
- [x] 从前听到承诺就信了，现在还要看人怎样做
- [ ] 从前读信才知道，现在亲自旁听
  理由：两处都说“听其言”，原文没有书信。

提示：两句都有“听其言”，留意后半句换了哪个字。
解析：信是相信，观是观察；听了话以后怎样判断人，前后不同。
