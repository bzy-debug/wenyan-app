# 检查：水涨后的一封家书 {#check.52}

## 原文：教学例句 {#rv52.check.p1}
> 舟子将二客出峡，顾其弟尚立岸上，乃使一客返，属弟以护母之事。弟曰：“亲病，我当留。”
译文：船工领两个客人出峡，回望弟弟还站在岸上，便派一位客人回去，托弟弟照料母亲。弟弟答应留下照顾病中的母亲。
词注：属：读 zhǔ。

## 原文：教学例句 {#rv52.check.p2}
> 暮水至门，寺僧尽移米上楼。旦，见村人数家无食，启廪恤之。
译文：傍晚水涨到门前，寺僧把米搬到楼上。清早见几户村民没有粮食，便开仓赈济。
词注：启廪：打开粮仓。

## 单选：出峡时谁带着谁？ {#rv52.check.q1}
考点：skill.vocab.2.2
语境：rv52.check.p1

- [x] 船工领着两名客人
- [ ] 弟弟领船工和两客人
  理由：弟弟尚在岸上。
- [ ] 两名客人将要随弟弟上岸
  理由：“将”后直接接二客，写带客的人。

提示：按“将”前后来认人。
解析：船工是领行者，两名客人是被他带出峡的人。

## 单选：舟子是怎样发现弟弟的？ {#rv52.check.q2}
考点：l2.skill.look-back
语境：rv52.check.p1

- [ ] 登岸去探望病人时听他说
  理由：被派回岸上的是客人。
- [ ] 临行前忧虑弟弟会生病
  理由：“尚立岸上”是眼前亲见，病的是母亲。
- [x] 回头望见弟弟还在岸上

提示：把“顾”同随后看到的情形连起来。
解析：“顾”指回望，他看到了身后未走的弟弟。

## 单选：客人回去是要替舟子传达哪项托付？ {#rv52.check.q3}
考点：skill.vocab.5.2
语境：rv52.check.p1

- [ ] 请母亲保管弟弟的东西
  理由：“护母”已点明受照料的人。
- [x] 请弟弟留下照看母亲
- [ ] 命弟弟带另一客人出峡
  理由：舟子正带人出峡，弟弟回答“我当留”。

提示：“以”后交代所托的事。
解析：“属弟以护母之事”把弟弟写作受托的一方。

## 单选：弟弟说“亲病”，这段里能具体认出谁生病了吗？ {#rv52.check.q4}
考点：skill.vocab.10.1
语境：rv52.check.p1

- [x] 能，是前面嘱他照看的母亲
- [ ] 是出峡的哥哥
  理由：哥哥正是托他照顾母亲的人。
- [ ] 是返岸报信的客人
  理由：客人只是代传口信。

提示：先读“护母”，再看“亲”。
解析：亲在这里指父母，前文已经把这位患病的长辈说清。

## 单选：“旦”把开仓的事排在哪个时段？ {#rv52.check.q5}
考点：skill.vocab.8.3
语境：rv52.check.p2

- [ ] 水还未涨的那天清晨
  理由：叙述先写暮水与移米，再说旦。
- [ ] 夜间刚搬米上楼时
  理由：移米与见村人由两个时间分开。
- [x] 水涨、移米后的次晨

提示：比较两个句首的时间词。
解析：“暮”至“旦”跨过一夜，开仓接济在次晨。

## 单选：若要核实寺僧“恤之”究竟做了什么，应查哪项记录？ {#rv52.check.q6}
考点：skill.vocab.12.3
语境：rv52.check.p2

- [ ] 傍晚丈量水有多深
  理由：丈水不能说明村民获得什么帮助。
- [x] 次晨从粮仓拨米给缺食的村人
- [ ] 把米从门口搬上楼
  理由：移米保全了粮食，实际救济在“启廪”以后。

提示：“之”指刚说到的几户人。
解析：“恤”写以粮赈济，把人与粮的去向接上才读得出。
