# 检查：换句话，辨清“之”“其”“焉” {#check.29}

## 原文：教学例句 {#check.29.p.salt}
> 盐商将之越，先遣人候潮。潮至乃发。
译文：盐商将要前往越地，先派人等候潮水。潮来才出发。

## 单选：哪里是盐商预定的目的地？ {#check.29.q1}
考点：l2.skill.zhi-go
语境：check.29.p.salt

- [ ] 派去等候的那个人
  理由：派人是出发前做的事。
- [x] 越地
- [ ] 潮水
  理由：潮至决定出发时机。

提示：读“将之……”后直接出现了什么。
解析：先遣人候潮，是在等出发的时机。“之越”才交代盐商准备往越地去。

## 原文：教学例句 {#check.29.p.crop}
> 农夫患苗之不长，晨夕往视。邻曰：“候雨可也。”
译文：农夫担忧禾苗不长，早晚去看。邻人说：“等雨就好。”

## 单选：农夫究竟担心什么？ {#check.29.q2}
考点：l2.skill.zhi-subject
语境：check.29.p.crop

- [ ] 禾苗将到别处去
  理由：句中另有“不长”说禾苗的情况。
- [x] 禾苗不长这件事
- [ ] 邻人不来帮忙
  理由：邻人在下句才开口。

提示：把“苗”和“不长”合起来。
解析：“苗不长”就是“禾苗不长”。整个“苗之不长”接在“患”后，所以担心的是这一件事。

## 原文：教学例句 {#check.29.p.storm}
> 海上云黑，舟人曰：“其将雨乎？速系舟以待。”顷之果雨。
译文：海上乌云密布，船夫说：“恐怕要下雨吧？快系好船等着。”不一会儿果然下雨。

## 单选：船夫说“其将雨乎”时，雨已经下了吗？ {#check.29.q3}
考点：l2.skill.qi-guess
语境：check.29.p.storm

- [ ] 正命令云下雨
  理由：命令是让人系船。
- [x] 从云色推测将雨
- [ ] 已亲身淋到雨
  理由：“顷之果雨”在说话之后。

提示：不要把后来应验的事挪到说话之前。
解析：说话时，船夫只见乌云，推想将要下雨。“顷之果雨”在后面，才知道他猜中了。

## 原文：教学例句 {#check.29.p.seal}
> 吏将远行，付印于弟曰：“印不可失，汝其谨藏。”弟缄之。
译文：官吏将出远门，把印交给弟弟，说：“印不能丢，你要谨慎保管。”弟弟将它封好。

## 找原文证据：哪一段直接叮嘱保管人该怎么做？ {#check.29.q4}
考点：l2.skill.qi-urge
语境：check.29.p.seal

- [x] 汝其谨藏
- [ ] 印不可失
  理由：“印不可失”说的是印要紧，还没说要弟弟怎样保管。
- [ ] 弟缄之
  理由：“弟缄之”写弟弟听完怎样做。题目要找哥哥当时怎么吩咐。

提示：找对听话人发出的行动要求。
解析：“印不可失”先交代理由，“汝其谨藏”才对弟弟说该做什么。后来弟弟把印封好，照着做了。

## 原文：教学例句 {#check.29.p.ford}
> 访客循溪，见桥断，问樵者：“今焉渡？”樵者指溪上小舟。
译文：来访的人沿溪走，看见桥断，问打柴人：“现在在哪里渡溪？”打柴人指向溪上的小船。

## 单选：怎样的回答能直接回应访客所问？ {#check.29.q5}
考点：l2.skill.yan-where
语境：check.29.p.ford

- [ ] 解释桥当初怎样建成
  理由：访客要继续赶路，未问造桥。
- [ ] 只说是否应该修桥
  理由：答语应能指明当前如何找到渡处。
- [x] 指出可渡溪之处

提示：樵者用手指向了哪里？这个动作能回答哪种问题？
解析：桥已断，访客想知道如今可以在哪里过溪。打柴人指小舟，便把可渡之处告诉了他。

## 原文：教学例句 {#check.29.p.water}
> 童抱巨瓮汲泉。母曰：“但濯一笔耳，焉用此瓮？”取小盂授之。
译文：孩子抱大瓮打泉水。母亲说：“只是洗一支笔罢了，哪里用得着这瓮？”拿小钵给他。

## 单选：从母亲递小钵的动作看，“焉用此瓮”是什么意思？ {#check.29.q6}
考点：l2.skill.yan-why
语境：check.29.p.water

- [ ] 询问大瓮存放地点
  理由：孩子正抱着瓮。
- [ ] 禁止孩子洗笔
  理由：小钵仍可用来取水洗笔。
- [x] 洗笔所需的水少，无须用大瓮

提示：比较容器大小和“但濯一笔”。
解析：只洗一支笔，用小钵取水就够了。母亲给孩子换了容器，正说明“焉用此瓮”是说何必用大瓮。
