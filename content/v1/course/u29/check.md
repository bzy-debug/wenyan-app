# 检查：史书的一日与一岁综合检查 {#check.29}

## 原文：教学例句 {#p.h29.check.1}
> 某公五年春三月乙丑，雨。丙寅，河溢。夏四月，民徙高地。
译文：某公在位第五年，春三月乙丑日下雨。丙寅日，河水漫出。夏四月，百姓迁到高处。

## 找原文证据：若只录河水漫出的日名，抄哪两个字？ {#q.h29.check.1}
考点：skill.h29.1.cyclical-day
语境：p.h29.check.1

- [x] 丙寅 {#q.h29.check.1.o1}
  理由：“丙寅，河溢”单独作一条；月下分日，不要把三月的两天并作一天。
- [ ] 四月 {#q.h29.check.1.o2}
  理由：这是后来居民迁移的月。
- [ ] 乙丑 {#q.h29.check.1.o3}
  理由：乙丑下雨，河溢另记其日。

提示：留意每一个日名紧接哪件事。
解析：“丙寅，河溢”单独作一条；月下分日，不要把三月的两天并作一天。

## 原文：教学例句 {#p.h29.check.2}
> 五月晦，客至，宿一夕。六月朔，辞主人而行。
译文：五月最后一天，客人抵达，留宿一夜。六月初一，向主人告辞离去。
词注：朔：每月初一。
  晦：每月最后一天。

## 单选：客人留宿跨过了什么界线？ {#q.h29.check.2}
考点：skill.h29.1.hui-last
语境：p.h29.check.2

- [x] 五月的最后一天到六月的第一天 {#q.h29.check.2.o1}
  理由：五月晦和六月朔前后相接，跨月却只过了一夜。
- [ ] 两年交替 {#q.h29.check.2.o2}
  理由：前后是同一年相邻的五月和六月。
- [ ] 一个整月 {#q.h29.check.2.o3}
  理由：“一夕”只说一夜。

提示：把晦、朔按月内的位置一前一后读。
解析：五月晦和六月朔前后相接，跨月却只过了一夜。

## 原文：教学例句 {#p.h29.check.3}
> 商素不渡夜津。是夕舟至，商仍宿岸舍，待旦乃行。
译文：商人向来不夜渡。这晚船来，他仍宿岸边，等天亮才走。
词注：素：向来。

## 单选：“素不渡夜津”是在交代哪种情形？ {#q.h29.check.3}
考点：skill.h29.2.su-always
语境：p.h29.check.3

- [x] 商人原有的习惯，让人看懂他此夜的选择 {#q.h29.check.3.o1}
  理由：这次仍然留宿，因为向来不在夜里渡河。
- [ ] 商人今夜才突然怕水 {#q.h29.check.3.o2}
  理由：“素”把这个习惯推到以前。
- [ ] 渡口此夜没有船 {#q.h29.check.3.o3}
  理由：原文明说船至。

提示：把“素”与其后的“仍”对读。
解析：这次仍然留宿，因为向来不在夜里渡河。

## 原文：教学例句 {#p.h29.check.4}
> 桥板新易，尚未遍钉。匠戒众徐行。一客闻后有车，遽趋向桥，匠止之。匠数视板隙，初仅容一钱，暮则倍之。见其稍宽，乃闭桥待修。
译文：桥板刚换，还未全部钉牢。工匠告诫大家慢走。一位客人听说后面有车，便急忙赶向桥边，工匠把他叫住。工匠多次查看板缝，起初只容一枚钱，到傍晚已有原来的两倍宽。眼见缝隙越来越宽，他便封了桥，等候修理。
词注：遽：急忙。

## 单选：工匠不是只看了一眼。他怎样知道桥板的缝在变宽？ {#q.h29.check.4}
考点：skill.h29.2.shuo-repeated
语境：p.h29.check.4

- [ ] 只看了一次，就确认桥面已完全断裂 {#q.h29.check.4.o1}
  理由：早晚看见的缝宽已不同，还没说桥已经断了。
- [ ] 因为板缝一直同样窄，所以经常封桥 {#q.h29.check.4.o2}
  理由：最初只容一枚钱，到傍晚就宽了一倍，此后才封桥。
- [x] 查看不止一次，缝隙在多次查看中呈现渐宽趋势 {#q.h29.check.4.o3}

提示：比比早先容一钱的缝与傍晚的宽度。
解析：“数视”是看了好几次；“稍宽”是渐渐变宽。前后观察相对照，工匠才决定封桥。

## 原文：教学例句 {#p.h29.check.5}
> 吏记：“九月上旬，粮车三至；中旬，舟继至。”后人欲书车至之日，不得其详。
译文：官吏记下九月上旬粮车来了三回，中旬船又来到。后人想记粮车抵达的具体日期，却找不到详记。
词注：上旬：每月的前十天。

## 单选：从这份记录能落实哪一项？ {#q.h29.check.5}
考点：skill.h29.3.xun-ten-days
语境：p.h29.check.5

- [ ] 粮车第十天才第一次来 {#q.h29.check.5.o1}
  理由：上旬并不专指第十日。
- [ ] 粮车分别在初一初二初三抵达 {#q.h29.check.5.o2}
  理由：只有次数，没有逐日日期。
- [x] 粮车在九月头十天内来过三回 {#q.h29.check.5.o3}
  理由：“上旬”划出十天时段，“三至”只计次数。

提示：分清三次和三天。
解析：“上旬”划出十天时段，“三至”只计次数。

## 原文：教学例句 {#p.h29.check.6}
> 冬十月受任，至明年二月而罢。吏欲书“居官期年”，史止之。
译文：冬十月受任，到次年二月去职。小吏想写在任满一年，史官制止了他。
词注：期年：读 jī nián，满一年。
  明年：相对于文中所指之年的下一年。

## 单选：任期跨了年，为何仍不能写“期年”？ {#q.h29.check.6}
考点：skill.h29.3.ji-full-year
语境：p.h29.check.6

- [x] 从十月至次年二月还不到完整一年 {#q.h29.check.6.o1}
  理由：只过了一次年界，离下一年十月还有好几个月。
- [ ] 因为二月不在新年 {#q.h29.check.6.o2}
  理由：明年二月当然已进入下一年。
- [ ] 因为“期年”专指一月 {#q.h29.check.6.o3}
  理由：期年计的是一年，不是一个月份。

提示：分别算历年界线与任职时长。
解析：只过了一次年界，离下一年十月还有好几个月。
