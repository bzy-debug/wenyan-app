# 课文：焉：相当于“于此”，还是在发问 {#syntax.3}
简介：用陈述、问答和反问核对“焉”指向哪里，以及能否补出一个对象。

## 正文

“凿池，蓄鱼焉”中，前面刚提出池，后一分句欠一个处所；“焉”可展开为“于此”。它也可以把关系引回到事物或事项，例如“闻义而有取焉”，能读成“于其中有所取”。只在确实有可回指对象时作这种展开。

“焉往”在问目的地；“割鸡焉用牛刀”是用提问表达何必。前者可以实际回答地名，后者的重点是工具与任务不相称。另有偏重语气的句末“焉”，不能见它在末尾就凭空增译一个地方。

## 知识点：焉（于此、于其中） {#l2.skill.yan-about}
义项：承接上文提到的地方或事物，给动作补出处所或范围
领域：虚词
要诀：承接上文提到的地方或事物，给动作补出处所或范围
讲解：试写成“于＋上文某物”。如果找不到具体对应项，须保留其他可能，不强补地名。
例句：l2.ex.yan-about

## 原文：教学例句 {#l2.ex.yan-about}
> 园有故井，积叶焉。
译文：园里有口旧井，落叶积在里面。

## 知识点：焉（疑问处所） {#l2.skill.yan-where}
义项：用于询问行动的地点或去处
领域：虚词
要诀：用于询问行动的地点或去处
讲解：试用地名作答，再看原文是否真的在寻求处所信息。
例句：l2.ex.yan-where

## 原文：教学例句 {#l2.ex.yan-where}
> 客问：“失马焉在？”童指西林。
译文：客问：“丢的马在哪里？”孩子指向西边的林子。

## 知识点：焉用（何用、何必用） {#l2.skill.yan-why}
义项：在反问中质疑某种做法的必要性
领域：虚词
要诀：在反问中质疑某种做法的必要性
讲解：检验后面的宾语是工具还是地方，看上下文是否认为这个办法用不着。
例句：l2.ex.yan-why

## 原文：教学例句 {#l2.ex.yan-why}
> 取一瓢水，焉用巨舟？
译文：取一瓢水，何必要用大船？

## 原文：古籍引文 {#syntax.3.p.knife}
> 割鸡焉用牛刀？
译文：杀鸡何必用宰牛的刀？

## 单选：问句把鸡和牛刀放在一起，要人注意什么？ {#syntax.3.q1}
考点：l2.skill.yan-why
语境：syntax.3.p.knife

- [ ] 哪里有宰牛的刀可买
  理由：句中未问刀所在之处。
- [x] 小事用不着这样的大工具
- [ ] 割鸡与宰牛先做哪件
  理由：此句只说割鸡所用的工具。

提示：把“焉用”换成“何必用”试读。
解析：问句质疑工具与任务是否相称，并未索要地名。

## 原文：教学例句 {#syntax.3.p.shed}
> 场旁有廪，岁丰则贮粟焉。客问：“所余之粟焉在？”吏指廪。
译文：场边有粮仓，丰年便把粮食贮在那里。客人问：“剩的粮食在哪里？”官吏指向粮仓。

## 单选：“贮粟焉”可展开成哪一句？ {#syntax.3.q2}
考点：l2.skill.yan-about
语境：syntax.3.p.shed

- [x] 把粮食贮在场旁的仓里
- [ ] 把粮仓藏进谷堆
  理由：“贮”的宾语是粟。
- [ ] 问何必要储粮
  理由：这是丰年储粮的陈述。

提示：先找前面已经提出的储粮地点。
解析：后一分句的“焉”回接前一句的“廪”。

## 单选：第二个“焉”在追问什么？ {#syntax.3.q3}
考点：l2.skill.yan-where
语境：syntax.3.p.shed

- [ ] 仓库在丰年是否开启
  理由：问题的对象是余粟。
- [x] 剩粮的位置
- [ ] 剩粮的数量
  理由：“吏指廪”指示处所，未数粮。

提示：看官吏用什么方式作答。
解析：“焉在”相当于“在哪里”，官吏指明粮仓。

## 原文：教学例句 {#syntax.3.p.river}
> 使者将发，童问：“子将焉往？”曰：“之郡。”童又问：“道经吾里，能寄书乎？”
译文：使者准备出发，孩子问：“您要往哪里去？”答：“去郡城。”孩子又问：“路过我乡，能替我带信吗？”

## 单选：“之郡”答复了原问中的哪项信息？ {#syntax.3.q4}
考点：l2.skill.yan-where
语境：syntax.3.p.river

- [x] “焉”所问的目的地
- [ ] “子”所问的姓名
  理由：答语中只有去处。
- [ ] “将”所问的出发时刻
  理由：没有回答几时动身。

提示：把“往郡城”读成一个动作加地点。
解析：“子将焉往”问人往何处，答语给了地名。

## 原文：教学例句 {#syntax.3.p.seed}
> 庭有隙地，父种葵焉。童持大犁至。父笑曰：“地不满一席，焉用此犁？”乃授之小锄。
译文：院中有一小块空地，父亲在那里种葵。孩子拿大犁来。父亲笑说：“地还没有一张席子大，何必用这犁？”便给他小锄。

## 单选：父亲想让孩子另问大犁放在哪里吗？ {#syntax.3.q5}
考点：l2.skill.yan-why
语境：syntax.3.p.seed

- [ ] 他要孩子去问别人借犁
  理由：孩子已经持犁来到。
- [x] 他在说明小地用不着大犁
- [ ] 他想知道自己能否耕完所有田地
  理由：说的是眼前这块隙地，随后换给小锄。

提示：看答话之后换了什么工具。
解析：“焉用”质疑使用的必要，给小锄的举动印证这一点。

## 找原文证据：“种葵焉”所说的种植处，前文如何称呼？ {#syntax.3.q6}
考点：l2.skill.yan-about
语境：syntax.3.p.seed

- [ ] 葵
  理由：这是种下的东西。
- [x] 隙地
- [ ] 小锄
  理由：这是后来交给孩子的工具。

提示：把“种葵于……”补全。
解析：“焉”回指“庭有隙地”中的空地。

## 原文：教学例句 {#syntax.3.p.seal}
> 吏开二匣。一贮印焉，一贮简焉。客问：“旧印焉在？”吏举其一。
译文：官吏打开两个匣子。一个里面贮印，一个里面贮简。客问：“旧印在哪儿？”官吏举起其中一匣。

## 单选：客人想从两个匣子中确定什么？ {#syntax.3.q7}
考点：l2.skill.yan-where
语境：syntax.3.p.seal

- [x] 旧印在哪一个匣子里
- [ ] 印章需要刻几个字
  理由：“旧印”已存在，未谈刻字。
- [ ] 简牍是否一定比印贵
  理由：问句没有比较价格。

提示：留心“旧印焉在”与“举其一”怎样相接。
解析：疑问的“焉”索取处所；前两处“焉”在陈述各匣贮物。

## 原文：教学例句 {#syntax.3.p.terms}
> 师授二策，生读而得一义焉，乃书其义以问。
译文：老师给两篇简策，学生读后从中领会了一层意思，就写出那层意思来请教。

## 单选：“得一义焉”的“焉”将理解的来源接回哪里？ {#syntax.3.q8}
考点：l2.skill.yan-about
语境：syntax.3.p.terms

- [ ] 请教老师时才听见的回答
  理由：学生先领会，随后才去问。
- [ ] 简策存放的仓库
  理由：原文没有给出实体存放地点。
- [x] 刚读过的两篇简策

提示：把“读而得”合起来读。
解析：“焉”可展开为“于其中”，所承接的是简策里的内容。
