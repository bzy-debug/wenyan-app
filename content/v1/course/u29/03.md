# 课文：“焉”是“在那里”，还是“在哪里” {#syntax.3}
简介：“蓄鱼焉”已经说过鱼养在哪里，“焉往”却是在问去处。看上下句能不能接起来。

## 正文

“凿池，蓄鱼焉”：前面刚说挖了池子，后面的鱼当然养在池里。“焉”在这里一句抵得上“于此”。提到的也可以是事情：“闻义而有取焉”，是听了道理，从中有所收获。要这样读，总得能说出这个“其中”究竟指什么。

问人“焉往”，报个地名就能答。问“割鸡焉用牛刀”，若只回答刀在厨房，就答岔了。这里问的是杀鸡何必动用宰牛的刀。还有些句末的“焉”主要表示语气；前文没有可指回的地点，就不用硬译一个“在那里”。

## 知识点：焉（于此、于其中） {#l2.skill.yan-about}
义项：在那里，或在其中；所指的地方或事物前面已经提过
领域：虚词
要诀：把“焉”换成“在那里”，再问那里是哪儿。
讲解：“园有故井，积叶焉”先点出旧井，“焉”便可读成“在井里”。有时回指的是前文所讲的事情，意思是“从中”或“在其中”。
例句：l2.ex.yan-about

## 原文：教学例句 {#l2.ex.yan-about}
> 园有故井，积叶焉。
译文：园里有口旧井，落叶积在里面。

## 知识点：焉（疑问处所） {#l2.skill.yan-where}
义项：哪里、往哪里，问所在的地方或要去的地方
领域：虚词
要诀：试着报个地名，看答不答得上。
讲解：问“失马焉在”，答“在西边林子里”，一问一答能接上，这个“焉”问的就是地方。
例句：l2.ex.yan-where

## 原文：教学例句 {#l2.ex.yan-where}
> 客问：“失马焉在？”童指西林。
译文：客问：“丢的马在哪里？”孩子指向西边的林子。

## 知识点：焉用（何用、何必用） {#l2.skill.yan-why}
义项：何必用，反问某种办法是否用得着
领域：虚词
要诀：说话人真在找工具，还是嫌用不着？
讲解：取一瓢水却要用大船，说“焉用巨舟”是嫌这办法太费事。用“何必用大船”读，才能听出这层意思。
例句：l2.ex.yan-why

## 原文：教学例句 {#l2.ex.yan-why}
> 取一瓢水，焉用巨舟？
译文：取一瓢水，何必要用大船？

## 单选：问句把鸡和牛刀放在一起，要人注意什么？ {#syntax.3.q1}
考点：l2.skill.yan-why
语境：syntax.3.p.knife

- [ ] 哪里有宰牛的刀可买
  理由：句中未问刀所在之处。
- [x] 小事用不着这样的大工具
- [ ] 割鸡与宰牛先做哪件
  理由：此句只说割鸡所用的工具。

提示：把“焉用”换成“何必用”试读。
解析：用牛刀去杀鸡，工具大大超过了所需。“焉用”是问何必要用这么大的刀。

## 原文：教学例句 {#syntax.3.p.shed}
> 场旁有廪，岁丰则贮粟焉。客问：“所余之粟焉在？”吏指廪。
译文：场边有粮仓，丰年便把粮食贮在那里。客人问：“剩的粮食在哪里？”官吏指向粮仓。

## 单选：“贮粟焉”可展开成哪一句？ {#syntax.3.q2}
考点：l2.skill.yan-about
语境：syntax.3.p.shed

- [x] 把粮食贮在场旁的仓里
- [ ] 把粮仓藏进谷堆
  理由：“贮”的宾语是粟。
- [ ] 问何必要储粮
  理由：“岁丰则贮粟焉”说年成好时把粮食存在那里。真正的发问要等客人开口。

提示：先找前面已经提出的储粮地点。
解析：“廪”就是粮仓。先说场边有仓，再说丰年把粮食存在那里，第二句末尾的“焉”指回这个仓。

## 单选：第二个“焉”在追问什么？ {#syntax.3.q3}
考点：l2.skill.yan-where
语境：syntax.3.p.shed

- [ ] 仓库在丰年是否开启
  理由：问题的对象是余粟。
- [x] 剩粮的位置
- [ ] 剩粮的数量
  理由：“吏指廪”指示处所，未数粮。

提示：看官吏用什么方式作答。
解析：客人问“焉在”，官吏便伸手指向仓。报出粮仓的位置就能答这个问题。

## 原文：教学例句 {#syntax.3.p.river}
> 使者将发，童问：“子将焉往？”曰：“之郡。”童又问：“道经吾里，能寄书乎？”
译文：使者准备出发，孩子问：“您要往哪里去？”答：“去郡城。”孩子又问：“路过我乡，能替我带信吗？”

## 单选：使者答“之郡”，回答的是孩子想知道的什么事？ {#syntax.3.q4}
考点：l2.skill.yan-where
语境：syntax.3.p.river

- [x] “焉”所问的目的地
- [ ] “子”所问的姓名
  理由：答语中只有去处。
- [ ] “将”所问的出发时刻
  理由：没有回答几时动身。

提示：把“往郡城”读成一个动作加地点。
解析：“焉往”问往哪里去。使者回答“之郡”，把郡城这个去处说给了孩子听。

## 原文：教学例句 {#syntax.3.p.seed}
> 庭有隙地，父种葵焉。童持大犁至。父笑曰：“地不满一席，焉用此犁？”乃授之小锄。
译文：院中有一小块空地，父亲在那里种葵。孩子拿大犁来。父亲笑说：“地还没有一张席子大，何必用这犁？”便给他小锄。

## 单选：父亲看见孩子拿来大犁，为什么问“焉用此犁”？ {#syntax.3.q5}
考点：l2.skill.yan-why
语境：syntax.3.p.seed

- [ ] 他要孩子去问别人借犁
  理由：孩子已经持犁来到。
- [x] 他在说明小地用不着大犁
- [ ] 他想知道自己能否耕完所有田地
  理由：说的是眼前这块隙地，随后换给小锄。

提示：看答话之后换了什么工具。
解析：一席之地就用大犁，父亲觉得用不着，所以递给孩子一把小锄。“焉用此犁”是在问何必用它。

## 找原文证据：“种葵焉”所说的种植处，前文如何称呼？ {#syntax.3.q6}
考点：l2.skill.yan-about
语境：syntax.3.p.seed

- [ ] 葵
  理由：葵是父亲种的作物；说种在什么地方，要往前读“庭有……”。
- [x] 隙地
- [ ] 小锄
  理由：父亲递给孩子的是小锄，“种葵”要找的是一块地方。

提示：把“种葵于……”补全。
解析：先说庭院里有一小块空地，再说“种葵焉”，意思是在那块空地种葵。

## 原文：教学例句 {#syntax.3.p.seal}
> 吏开二匣。一贮印焉，一贮简焉。客问：“旧印焉在？”吏举其一。
译文：官吏打开两个匣子。一个里面贮印，一个里面贮简。客问：“旧印在哪儿？”官吏举起其中一匣。

## 单选：客人想从两个匣子中确定什么？ {#syntax.3.q7}
考点：l2.skill.yan-where
语境：syntax.3.p.seal

- [x] 旧印在哪一个匣子里
- [ ] 印章需要刻几个字
  理由：“旧印”已存在，未谈刻字。
- [ ] 简牍是否一定比印贵
  理由：问句没有比较价格。

提示：留心“旧印焉在”与“举其一”怎样相接。
解析：旧印在哪个匣里？官吏拿起其中一个匣子就答了。前面“一贮印焉，一贮简焉”的两个“焉”都可读作“在里面”。

## 原文：教学例句 {#syntax.3.p.terms}
> 师授二策，生读而得一义焉，乃书其义以问。
译文：老师给两篇简策，学生读后从中领会了一层意思，就写出那层意思来请教。

## 单选：学生是从哪里领会了那一层意思？ {#syntax.3.q8}
考点：l2.skill.yan-about
语境：syntax.3.p.terms

- [ ] 请教老师时才听见的回答
  理由：学生先领会，随后才去问。
- [ ] 简策存放的仓库
  理由：学生读的是简策。这里没说简策收藏在哪间仓库。
- [x] 刚读过的两篇简策

提示：把“读而得”合起来读。
解析：学生先读两篇简策，从里面领会了一层意思，有了这点收获才写下来问老师。“焉”回指刚读过的简策。
