# 课文：“之”是说去哪里，还是说一件事 {#syntax.1}
简介：“客之楚”说客人要出门，“客之来”说客人到来的这件事。读清两处“之”各管什么。

## 正文

“客之楚”，客人往哪里去？往楚国去。“之”本身就是“去”的意思。再读“客之来，吾甚喜”：客人的动作由“来”说出，让我高兴的是“客人来”这件事。这个“之”夹在人和动作之间，把“客来”连成一组，交给后半句评说。

“吾知子之好学”也可以这样拆。先把“子好学”读通，再补成“我知道你爱学习”。有时整组词交代说话的时机，有时作“知”的对象。若读到“取书而读之”，又要问“读什么”。前文已经说到了书，末尾的“之”正好指这本书。

## 知识点：之（往） {#l2.skill.zhi-go}
义项：前往某地
领域：实词
要诀：“之”后面是什么地方？
讲解：“商人之吴”，前有出行的商人，后有目的地吴。下面又说住在江边，合起来就是一段行程。
例句：l2.ex.zhi-go

## 原文：教学例句 {#l2.ex.zhi-go}
> 商人之吴，舍于江上。
译文：商人前往吴地，住在江边。

## 知识点：之（主谓之间） {#l2.skill.zhi-subject}
义项：用在主语和动作或状态之间，把整件事连在一起说
领域：虚词
要诀：先把“弟之至”读成“弟弟到了”。
讲解：“吾喜弟之至”中，我高兴什么？弟弟到了。“之”把人和动作连在一起，整件事才是“喜”的对象。
例句：l2.ex.zhi-subject

## 原文：教学例句 {#l2.ex.zhi-subject}
> 吾喜弟之至。
译文：弟弟到了，我很高兴。

## 原文：古籍引文 {#syntax.1.p.wucheng}
> 子之武城，闻弦歌之声。
译文：孔子前往武城，听见奏乐歌唱的声音。

## 单选：哪一个“之”是说孔子去了一个地方？ {#syntax.1.q1}
考点：l2.skill.zhi-go
语境：syntax.1.p.wucheng

- [ ] 两处都交代行程
  理由：第二处把弦歌与声音连接在一起。
- [x] “子之武城”的“之”
- [ ] “弦歌之声”的“之”
  理由：“弦歌”说明是什么声音，没有给出目的地。

提示：找人名或称谓之后的地名。
解析：“子之武城”能直接讲成“孔子去了武城”。到了那里，他听见弦歌。“弦歌之声”的“之”只把弦歌和声音连起来。

## 找原文证据：孔子所去的是什么地方？从原文选出地名。 {#syntax.1.q2}
考点：l2.skill.zhi-go
语境：syntax.1.p.wucheng

- [x] 武城
- [ ] 子
  理由：“子”是孔子，他是去的人；要找他去哪里，看“之”后面的地名。
- [ ] 弦歌
  理由：“弦歌”是孔子到达后听见的乐声。

提示：地点紧接表移动的“之”。
解析：“武城”跟在动词“之”后面，正好回答“孔子去了哪里”。

## 单选：“人之将死”这一组词在后半句中起什么作用？ {#syntax.1.q3}
考点：l2.skill.zhi-subject
语境：syntax.1.p.bird

- [ ] 把“言”认作“人”的另一个名称
  理由：“其言”是“他的话”。后半句评说这些话怎么样。
- [x] 交代在什么情形下谈人的言语
- [ ] 说人正要前往名叫“死”的地方
  理由：“将死”写将要发生的事。

提示：把两半各分成情形和评说。
解析：“人之将死”要连着读：人将死的时候。后面的“其言也善”才说这时人的言语有什么特点。前半说鸟，写法相同。

## 找原文证据：前半段用哪一整组词交代鸟鸣的情形？ {#syntax.1.q4}
考点：l2.skill.zhi-subject
语境：syntax.1.p.bird

- [x] 鸟之将死
- [ ] 其鸣也哀
  理由：“哀”说叫声怎样。要找的是何时听到这样的叫声。
- [ ] 其言也善
  理由：“其言”已经转到人这一半，鸟在前半句。

提示：先把修饰鸟鸣发生时间的词读全。
解析：先交代鸟将死，再说它的叫声哀切。“其鸣也哀”回答叫声怎样，“鸟之将死”回答什么时候。

## 原文：教学例句 {#syntax.1.p.letter}
> 客之齐，既至，寄书告弟。弟读之，乃知兄之安。
译文：客人前往齐国，到后写信告诉弟弟。弟弟读了信，才知道哥哥平安。

## 单选：“客之齐”和“弟读之”分别怎么读？ {#syntax.1.q5}
考点：l2.skill.zhi-go
语境：syntax.1.p.letter

- [ ] 客属于齐国，弟去读书的地方
  理由：“既至”接续出行；“读”所承接的是信。
- [x] 客前往齐国，弟读那封信
- [ ] 两处都是“前往”
  理由：第二处“之”给“读”补了对象。

提示：先看“既至”，再找弟弟手上有什么。
解析：“客之齐”下面接“既至”，说明客人确实到了齐国。“弟读之”前面已经说哥哥寄了信，弟弟读的是信。

## 单选：弟弟从信里知道了什么？ {#syntax.1.q6}
考点：l2.skill.zhi-subject
语境：syntax.1.p.letter

- [x] 哥哥平安这件事
- [ ] 哥哥将书交给名叫安的人
  理由：“兄之安”以哥哥为陈述对象，未另引收信人。
- [ ] 哥哥去了一个叫“安”的地方
  理由：行程中给出的目的地是齐国。

提示：把“兄”和“安”先读成“哥哥平安”。
解析：把“兄之安”读成“哥哥平安”。弟弟读信之后，才知道这件事。

## 原文：教学例句 {#syntax.1.p.city}
> 师将之郡，生问归期。师曰：“吾之归也，当在春末。”
译文：老师将要到郡城去，学生问他的归期。老师说：“我回来，应在春末。”

## 单选：学生为什么在这时问归期？ {#syntax.1.q7}
考点：l2.skill.zhi-go
语境：syntax.1.p.city

- [ ] 学生将赴郡城求学
  理由：将之郡的主语是“师”。
- [x] 老师将要出行，目的地是郡城
- [ ] 老师刚从郡城归来
  理由：“将”与对将来归期的回答一致。

提示：“之郡”处在“将”后，谁将做什么？
解析：要走的是老师，“将”说明还没走。正因为老师准备前往郡城，学生才问他何时回来。

## 单选：“吾之归也”被拿来谈什么？ {#syntax.1.q8}
考点：l2.skill.zhi-subject
语境：syntax.1.p.city

- [ ] 谁想得到老师的归期
  理由：学生已经问了，老师在回答。
- [x] 老师回来的时间
- [ ] 老师回程的车马
  理由：“当在春末”给的是季节。

提示：将后半句接在“我回来这件事”后。
解析：学生问“归期”，老师就以“吾之归也”接过“我回来”这个话题，再用“当在春末”答时间。
