# 课文：之：前往，还是把一件事提出来 {#syntax.1}
简介：把“人之地”和“人之动作”放在一起试读，指出谁在移动、谁在做下一件事。

## 正文

读“客之楚”，先试问“客往哪里去”。楚是目的地，“之”自身就是移动的动作。读“客之来，吾甚喜”，则已有“来”说明客做什么；说话人高兴的是“客来”这件事。主谓之间的“之”常把原可独立成句的一组词收在一起，让它作话题、时间条件或另一个动词的对象。

遇到“之”不要只看左右两个字。“吾知子之好学”须一直读到“好学”，才知道“知”的内容。若是“取书而读之”，动作“读”还少宾语，此时再考虑以前课学过的代词。

## 知识点：之（往） {#l2.skill.zhi-go}
义项：作动词，支配所往的地方
领域：实词
要诀：作动词，支配所往的地方
讲解：先看前面有无出发的人，再问后面能不能作为目的地。有时前文还会补出行程。
例句：l2.ex.zhi-go

## 原文：教学例句 {#l2.ex.zhi-go}
> 商人之吴，舍于江上。
译文：商人前往吴地，住在江边。

## 知识点：之（主谓之间） {#l2.skill.zhi-subject}
义项：把主语和动作收成更大的句子成分
领域：虚词
要诀：把主语和动作收成更大的句子成分
讲解：把“甲之行”还原为“甲行”，再问整件事是什么时候、为何或谁知道的事。
例句：l2.ex.zhi-subject

## 原文：教学例句 {#l2.ex.zhi-subject}
> 吾喜弟之至。
译文：我高兴弟弟到了。

## 单选：两个“之”里，哪一个交代了行程？ {#syntax.1.q1}
考点：l2.skill.zhi-go
语境：syntax.1.p.wucheng

- [ ] 两处都交代行程
  理由：第二处把弦歌与声音连接在一起。
- [x] “子之武城”的“之”
- [ ] “弦歌之声”的“之”
  理由：“弦歌”说明是什么声音，没有给出目的地。

提示：找人名或称谓之后的地名。
解析：“子”是出行的人，“武城”是前往的地点；接着才写所闻。

## 找原文证据：孔子所去的是什么地方？从原文选出地名。 {#syntax.1.q2}
考点：l2.skill.zhi-go
语境：syntax.1.p.wucheng

- [x] 武城
- [ ] 子
  理由：这是对孔子的称呼。
- [ ] 弦歌
  理由：这是所闻之声的来源。

提示：地点紧接表移动的“之”。
解析：“之武城”可回答“往何处”。

## 单选：“人之将死”这一组词在后半句中起什么作用？ {#syntax.1.q3}
考点：l2.skill.zhi-subject
语境：syntax.1.p.bird

- [ ] 把“言”认作“人”的另一个名称
  理由：“其言”另开一层，才是随后所评说的对象。
- [x] 交代在什么情形下谈人的言语
- [ ] 说人正要前往名叫“死”的地方
  理由：“将死”写将要发生的事。

提示：把两半各分成情形和评说。
解析：与“鸟之将死”相对，“之”把人和将死收为一组，给下句定下时间情形。

## 找原文证据：前半段用哪一整组词交代鸟鸣的情形？ {#syntax.1.q4}
考点：l2.skill.zhi-subject
语境：syntax.1.p.bird

- [x] 鸟之将死
- [ ] 其鸣也哀
  理由：这是对鸟鸣的评说。
- [ ] 其言也善
  理由：这是说人的言语。

提示：先把修饰鸟鸣发生时间的词读全。
解析：“鸟之将死”整体说明什么时候；“其鸣也哀”才评说叫声。

## 原文：教学例句 {#syntax.1.p.letter}
> 客之齐，既至，寄书告弟。弟读之，乃知兄之安。
译文：客人前往齐国，到后写信告诉弟弟。弟弟读了信，才知道哥哥平安。

## 单选：“客之齐”和“弟读之”分别怎么读？ {#syntax.1.q5}
考点：l2.skill.zhi-go
语境：syntax.1.p.letter

- [ ] 客属于齐国，弟去读书的地方
  理由：“既至”接续出行；“读”所承接的是信。
- [x] 客前往齐国，弟读那封信
- [ ] 两处都是“前往”
  理由：第二处“之”给“读”补了对象。

提示：先看“既至”，再找弟弟手上有什么。
解析：第一处“之”后有地名，第二处“之”在“读”后承接“书”。

## 单选：弟弟从信里知道了什么？ {#syntax.1.q6}
考点：l2.skill.zhi-subject
语境：syntax.1.p.letter

- [x] 哥哥平安这件事
- [ ] 哥哥将书交给名叫安的人
  理由：“兄之安”以哥哥为陈述对象，未另引收信人。
- [ ] 哥哥去了一个叫“安”的地方
  理由：行程中给出的目的地是齐国。

提示：把“兄”和“安”先读成“哥哥平安”。
解析：“知”带的是一件事；“之”连接“兄”和说他的“安”。

## 原文：教学例句 {#syntax.1.p.city}
> 师将之郡，生问归期。师曰：“吾之归也，当在春末。”
译文：老师将要到郡城去，学生问他的归期。老师说：“我回来，应在春末。”

## 单选：学生为什么在这时问归期？ {#syntax.1.q7}
考点：l2.skill.zhi-go
语境：syntax.1.p.city

- [ ] 学生将赴郡城求学
  理由：将之郡的主语是“师”。
- [x] 老师将要出行，目的地是郡城
- [ ] 老师刚从郡城归来
  理由：“将”与对将来归期的回答一致。

提示：“之郡”处在“将”后，谁将做什么？
解析：“之”在此表示前往，整句写预定行程。

## 单选：“吾之归也”被拿来谈什么？ {#syntax.1.q8}
考点：l2.skill.zhi-subject
语境：syntax.1.p.city

- [ ] 谁想得到老师的归期
  理由：学生已经问了，老师在回答。
- [x] 老师回来的时间
- [ ] 老师回程的车马
  理由：“当在春末”给的是季节。

提示：将后半句接在“我回来这件事”后。
解析：“吾归”加“之”后成为所谈的事项，“当在春末”补出时间。
