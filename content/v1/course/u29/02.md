# 课文：“其”是在猜测、叮嘱，还是反问 {#syntax.2}
简介：“其恕乎”带着斟酌，“子其慎之”是在嘱咐人。先看谁在对谁说话。

## 正文

子贡想找一个可以终身践行的字。孔子答“其恕乎”，可以听成“大概是‘恕’吧”，再说自己不愿承受的事不要加给别人。这里的“其”带着斟酌的口气。像“雨声渐近，其将至乎”，说话人也有根据，只是还没看见雨真的到了。

听到“子其慎之”，要先认出“子”就是眼前的听者。这是当面嘱咐人小心。再换成“其可弃之乎”，如果前文已经说尽东西的用处，说话人多半是在问“怎么能丢呢”。同样带着问号，要从理由和答话里听出说话人是否真的拿不准。

## 知识点：其（推测） {#l2.skill.qi-guess}
义项：表示推测或斟酌，大概、恐怕
领域：虚词
要诀：所见只是迹象，还是已经看清？
讲解：岸上传来喊船的声音，可以猜客人快到了。句中若还有一个“乎”，译作“大概……吧”能留下这点不确定。
例句：l2.ex.qi-guess

## 原文：教学例句 {#l2.ex.qi-guess}
> 闻岸上人呼舟，客其至乎？
译文：听见岸上有人喊船，客人大概要到了吧？

## 知识点：其（劝勉） {#l2.skill.qi-urge}
义项：劝对方去做某事，可读作“要”“可要”
领域：虚词
要诀：“其”后面的事要谁做？
讲解：父亲说“尔其善守此书”，“尔”是儿子，“守”是他该做的事。父亲是在嘱咐儿子看好书。
例句：l2.ex.qi-urge

## 原文：教学例句 {#l2.ex.qi-urge}
> 父戒儿曰：“尔其善守此书。”
译文：父亲嘱咐孩子：“你要好好保管这本书。”

## 知识点：其……乎（反问） {#l2.skill.qi-rhet}
义项：用问句说出心里已有的判断，可读作“难道……吗”
领域：虚词
要诀：把反问换成说话人赞成的回答。
讲解：“彼尝救我，其可忘乎？”对方救过我的命，这一层理由已经说出。“怎能忘呢”便是说不能忘。
例句：l2.ex.qi-rhet

## 原文：教学例句 {#l2.ex.qi-rhet}
> 彼尝救我，其可忘乎？
译文：他曾救我，怎能忘记呢？

## 原文：古籍引文 {#syntax.2.p.shu}
> 子贡问曰：“有一言而可以终身行之者乎？”子曰：“其恕乎！己所不欲，勿施于人。”
译文：子贡问：“有没有一个字，足以终身践行？”孔子说：“大概是恕吧！自己不想要的，不要加给别人。”

## 单选：孔子是用什么口气说“其恕乎”的？ {#syntax.2.q1}
考点：l2.skill.qi-guess
语境：syntax.2.p.shu

- [ ] 命令子贡马上原谅某一个人
  理由：后面解释的是待人的原则，未点出某件过失。
- [x] 用斟酌的口气提出一个答案
- [ ] 询问“恕”属于谁
  理由：子贡问的是哪个字可以终身践行，没问东西属于谁。

提示：留意子贡在问“一言”，孔子怎样提出自己的回答。
解析：子贡问能一生照做的是哪一个字。孔子答“大概是恕吧”，再用“己所不欲，勿施于人”说明恕的意思。

## 原文：教学例句 {#syntax.2.p.ferry}
> 舟未至。童望水上白帆，曰：“其吾兄之舟乎？”父曰：“未可知，汝其少待。”
译文：船还没到。孩子望见水上的白帆，说：“大概是我哥哥的船吧？”父亲说：“还不能确定，你且稍等。”

## 单选：孩子看见白帆时，认出那是谁的船了吗？ {#syntax.2.q2}
考点：l2.skill.qi-guess
语境：syntax.2.p.ferry

- [ ] 认为哥哥绝不在船上
  理由：孩子望见帆，想到的恰好是哥哥可能来了。
- [ ] 已经认出船上的哥哥
  理由：原文只说望见白帆。
- [x] 猜是哥哥的船，还未证实

提示：留心父亲接下去怎样回答。
解析：孩子看见的是白帆，没写他看清了船上的人。“其……乎”是在猜。父亲答“未可知”，船主是谁仍待确认。

## 单选：“汝其少待”要孩子做什么？ {#syntax.2.q3}
考点：l2.skill.qi-urge
语境：syntax.2.p.ferry

- [ ] 猜想他人会等候
  理由：“汝”是父亲当面叮嘱的对象。
- [ ] 把等待这件事交给哥哥
  理由：父亲没有对船上的人说话。
- [x] 稍等片刻，再看情况

提示：父亲对谁开口？“待”由谁做？
解析：父亲对孩子说“汝”，让眼前这个人再等一会儿。“其”放在“少待”前，是叮嘱的口气。

## 原文：教学例句 {#syntax.2.p.lamp}
> 友将夜行。主人赠灯曰：“道多石，子其执此。灯可照路，其可弃乎？”
译文：朋友准备走夜路。主人送灯说：“路上石头多，你要拿着这灯。灯能照路，怎能丢弃呢？”

## 找原文证据：哪句话直接叮嘱朋友采取行动？ {#syntax.2.q4}
考点：l2.skill.qi-urge
语境：syntax.2.p.lamp

- [ ] 道多石
  理由：“道多石”在说为什么需要灯，还没有叫朋友做什么。
- [x] 子其执此
- [ ] 灯可照路
  理由：“灯可照路”解释为什么要带上灯，不是当面嘱咐对方的动作。

提示：找对“子”说的可实行的动作。
解析：“执此”的“此”就是灯。主人把灯递给朋友，叫他拿好；路上石头多、灯能照路，是主人给的理由。

## 单选：主人问“其可弃乎”，希望朋友怎样回答？ {#syntax.2.q5}
考点：l2.skill.qi-rhet
语境：syntax.2.p.lamp

- [ ] 请先确定灯归谁
  理由：两人谈的是带灯行路，非灯的所有权。
- [x] 不能丢，夜里需要照路
- [ ] 可以丢掉，路面平整
  理由：主人特意说“道多石”。

提示：把“灯可照路”当作问句的理由。
解析：朋友要走夜路，灯能照明。主人问“其可弃乎”，按前面的理由，心里已有答案：不能丢。

## 原文：教学例句 {#syntax.2.p.gate}
> 暮雪塞路，门外有叩者。主曰：“其行客乎？未识其人，先问之。”
译文：大雪在傍晚堵住了路，门外有人敲门。主人说：“大概是过路的旅人吧？还不知道是谁，先问问他。”

## 找原文证据：哪四个字直接表明主人尚不能确认身份？ {#syntax.2.q6}
考点：l2.skill.qi-guess
语境：syntax.2.p.gate

- [ ] 先问之
  理由：“先问之”说主人准备开口打听。
- [x] 未识其人
- [ ] 暮雪塞路
  理由：雪堵了路，是旅人可能来敲门的一条线索，不能说明主人已经认出来人。

提示：找出主人自己说“还认不出来”的那句话。
解析：先说“其行客乎”，接着说“未识其人”。既然还不认识叩门的人，前一句就只能是猜测。

## 原文：教学例句 {#syntax.2.p.medicine}
> 父病，子得药。有欲夺之者。子曰：“此以救父，其可与人乎？”抱药而去。
译文：父亲生病，儿子得了药。有人想夺药。儿子说：“这是用来救父亲的，怎能给别人呢？”抱着药走了。

## 单选：从行动反推，儿子问“其可与人乎”是什么意思？ {#syntax.2.q7}
考点：l2.skill.qi-rhet
语境：syntax.2.p.medicine

- [ ] 认真询问该送给哪一个人
  理由：他已抱药离去，没有挑选收药人。
- [ ] 后悔已经把药送人
  理由：药还在他怀中。
- [x] 决意留药救父

提示：将问句和“抱药而去”对读。
解析：儿子说药是用来救父亲的，又把药抱走了。前后的话和行动都指向同一个意思：这药怎能给别人？

## 原文：教学例句 {#syntax.2.p.garrison}
> 令遣人守堤，戒曰：“水方长，尔其数视之。”守者每夜三巡。
译文：县令派人守堤，嘱咐说：“水正在上涨，你们要常去察看。”守堤的人每夜巡查三次。

## 单选：末句怎样印证“尔其数视之”的语气？ {#syntax.2.q8}
考点：l2.skill.qi-urge
语境：syntax.2.p.garrison

- [ ] 守者发现原先的猜想错误
  理由：前句是交办事项，后句写执行。
- [x] 守者反复巡视，实行了叮嘱
- [ ] 守者替水位决定是否上涨
  理由：能够由守者做的是巡视。

提示：“戒曰”是谁对谁说？守者后来怎样照办？
解析：“戒曰”领起县令的吩咐。守者每夜巡堤三次，正照着“数视之”去做。
