# 课文：昨日与今日：长安和太阳 {#l3.5}

简介：昨天说太阳远，今天说太阳近。孩子为何会给出两个答案？听听他分别是怎么想的。

## 正文

元帝把长安和太阳放在一起问远近。儿子第一回说“不闻”，他听说过有人从长安来，却没听说有人从太阳那边来。第二回说“举目见日”，他改从自己眼睛能看到什么来说。这两个回答得分开听。

“明日”是第二天。元帝把昨天的事说给群臣听，这就是“告以此意”；“更重问之”才是又开口问了一次。今天提起昨天的话，不等于昨天的事又发生了一回。

## 知识点：更问 {#skill.l3.5.1}
义项：再问同一个问题，比较前后两次回答
领域：篇章
要诀：留心哪一次是重新发问，哪一次只是在转述。
讲解：元帝第二天先把昨日的话告诉群臣，随后又问孩子。转述那一次不多算一个问答。
例句：p.l3.5.a

## 知识点：所据 {#skill.l3.5.2}
义项：分清人物凭什么作判断：从别人那里听说，还是亲眼所见
领域：阅读技能
要诀：把“听说过什么”和“亲眼看见什么”分开。
讲解：明帝先用来客的消息答父亲，后来改说眼睛望见的景象。想知道他为何改口，就要听两次理由。
例句：p.l3.5.a

## 原文：古籍引文 {#p.l3.5.a}
> 晋明帝数岁，坐元帝膝上。有人从长安来，元帝问洛下消息，潸然流涕。明帝问何以致泣，具以东渡意告之。因问明帝：“汝意谓长安何如日远？”答曰：“日远。不闻人从日边来，居然可知。”元帝异之。明日集群臣宴会，告以此意，更重问之，乃答曰：“日近。”元帝失色，曰：“尔何故异昨日之言邪？”答曰：“举目见日，不见长安。”
译文：晋明帝小时坐在父亲元帝膝上。有人从长安来，元帝打听洛阳一带的消息，流下眼泪。孩子问为什么哭，元帝详细告诉他东渡的缘故，又问他长安与太阳哪个远。孩子答：“太阳远。没听说有人从太阳那边来，这就知道了。”元帝觉得这话出奇。第二天召集群臣宴饮，元帝说起这件事，又问了一遍。孩子却答“太阳近”。元帝变了脸色，问他为何和昨天说的不一样。孩子回答：“抬头就能看见太阳，却看不见长安。”

## 排序：照元帝先后遇到、问到的事，排一排。 {#q.l3.5.1}
考点：skill.l3.5.1
语境：p.l3.5.a

- [1] 元帝询问洛下消息而流泪
  理由：来者引发关于故地的话题。
- [3] 元帝向群臣说起昨日答语再问
  理由：“明日”标明已换一天。
- [2] 孩子用无人从日边来说明日远
  理由：这是父子第一次问答。

提示：先给“明日”画一条界线。
解析：听到来客的消息落泪、第一次问长安和太阳，都在第一天。到了“明日”的宴会上，元帝才向群臣说起旧话，再问孩子。

## 单选：第一天判断“日远”直接凭什么？ {#q.l3.5.2}
考点：skill.l3.5.2
语境：p.l3.5.a

- [ ] 太阳每天都在移动
  理由：孩子没有使用运行轨迹作理由。
- [ ] 抬头看不见太阳
  理由：抬头看见太阳在第二答。
- [x] 有人从长安来，却没听说有人来自太阳那边

提示：留意“不闻”二字，孩子没听说过什么？
解析：长安确实来了客人，太阳那边却没听说有人来。孩子凭这个差别答“日远”。

## 找原文证据：哪句话明确把两次不同回答相对照？ {#q.l3.5.3}
考点：skill.l3.5.1
语境：p.l3.5.a

- [ ] 具以东渡意告之
  理由：此处交代东渡缘故。
- [x] 尔何故异昨日之言邪
- [ ] 元帝异之
  理由：这是对第一次回答感到出奇。

提示：留意“异”前后搭配有何不同。
解析：两处都有“异”。“元帝异之”是说父亲觉得孩子的话出奇；“异昨日之言”才是在问今天为什么和昨天说得不同。

## 单选：孩子第二天为什么改口说太阳近？ {#q.l3.5.4}
考点：skill.l3.5.2
语境：p.l3.5.a

- [x] 把能否看到当成远近的依据
- [ ] 宣布已经有人从日边来
  理由：没有增加这样的来客。
- [ ] 说长安在一夜间迁走
  理由：孩子未谈地点发生变化。

提示：第一次他说“不闻”，第二次他说“见”到了什么？
解析：这回孩子一抬头就看得见太阳，却看不到长安。他换了一个理由来判断远近。

## 原文：教学例句 {#p.l3.5.b}
> 客问山路孰近。樵者曰：“西径近，昨负薪由之，未午已至。”明旦客复问，樵者望涧曰：“今东道可行。西径水涨，虽近，吾未见人得过。”客乃从东。
译文：客人问哪条山路近。樵夫说西边小径近，昨天背柴走过，中午前就到了。第二天客人又问，樵夫看着山涧说今天东边大路可走，西径涨水，路虽近，还没见人能过。客人便走东道。

## 找原文证据：樵夫说西径近，哪句话表明他亲自走过？ {#q.l3.5.5}
考点：skill.l3.5.2
语境：p.l3.5.b

- [x] 昨负薪由之
- [ ] 今东道可行
  理由：这是第二日对通行的判断。
- [ ] 客乃从东
  理由：这是客人最后的选择。

提示：找说话人自己走过哪条路。
解析：“昨负薪由之”是说樵夫昨天背着柴走的就是西径，所以他知道中午前就能到。

## 单选：客人第二天“复问”以后，西径是不是变长了？ {#q.l3.5.6}
考点：skill.l3.5.1
语境：p.l3.5.b

- [x] 文中仍说西径近，改变的是当天能否通行
- [ ] “乃从东”证明东路缩短了
  理由：选东路是因为可通行。
- [ ] 昨天的西径已经不存在
  理由：水涨不等于山路消失。

提示：比较走多少路，和能不能走过去，是不是同一件事？
解析：西径“虽近”，还是那条近路；今天涨了水，能不能走过去成了另一个问题。

## 单选：樵夫说“吾未见人得过”，这句话说到了什么程度？ {#q.l3.5.7}
考点：skill.l3.5.2
语境：p.l3.5.b

- [x] 到说话时樵者没有见到人成功渡过
- [ ] 昨天背柴的人没有到达
  理由：昨天樵者已走到。
- [ ] 樵者已经验证所有人永远过不了
  理由：未见不能推出永远不可能。

提示：他只说自己到此时见过什么。
解析：樵夫到说话时，还没看见有人走过去。这足以解释他为什么指东道，却不能说往后谁也过不去。

## 单选：“昨负薪”相对于第一次问路是什么时间？ {#q.l3.5.8}
考点：skill.l3.5.1
语境：p.l3.5.b

- [ ] 客人走东道之后
  理由：那是故事末尾。
- [x] 问路之前一天
- [ ] 第二次问路当天
  理由：“昨”出现在第一次答语里。

提示：樵夫是在哪一回答话里说“昨”的？
解析：第一次问路时，樵夫说“昨天我背柴从那儿走过”。背柴是在这次问路的前一天。
