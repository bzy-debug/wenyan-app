# 课文：昨日与今日：长安和太阳 {#l3.5}

简介：一句话换了答案，事情究竟变了，还是判断所凭的证据变了？

## 正文

小孩子把同一个远近问题回答了两次。读第一答，标出**听说**的来源；读第二答，标出**眼见**的对象。这不是一次测量有两个结果，而是对话者换了用来支持说法的依据。

“明日”顺接，指第二天。第二天的“告以此意”回指先前的回答：元帝先把昨日情形说给群臣，再重新发问。叙述提到某件事的地方可以很靠后，那件事发生的时间却没有改变。

## 知识点：更问 {#skill.l3.5.1}
义项：由再次发问回接前次的回答
领域：篇章
要诀：分开原事与在后来讲起原事
讲解：“更”“昨日”“前言”等词把两场对话勾住；复述昨日答语，并不表示问答发生了第三次。
例句：p.l3.5.a

## 知识点：所据 {#skill.l3.5.2}
义项：区别从听闻推断与从亲见推断
领域：阅读技能
要诀：给每个判断标明证据类型
讲解：比较回答时，先记录人物依据的是传来的消息、目下所见还是事后验证，再看结论适用的范围。
例句：p.l3.5.a

## 原文：古籍引文 {#p.l3.5.a}
> 晋明帝数岁，坐元帝膝上。有人从长安来，元帝问洛下消息，潸然流涕。明帝问何以致泣，具以东渡意告之。因问明帝：“汝意谓长安何如日远？”答曰：“日远。不闻人从日边来，居然可知。”元帝异之。明日集群臣宴会，告以此意，更重问之，乃答曰：“日近。”元帝失色，曰：“尔何故异昨日之言邪？”答曰：“举目见日，不见长安。”
译文：晋明帝小时坐在父亲元帝膝上。有人从长安来，元帝打听洛阳一带的消息，流下眼泪。孩子问为什么哭，元帝详细告诉他东渡的缘故，又问他长安与太阳哪个远。孩子从没人从太阳那边来的说法判太阳远。元帝觉得出奇。第二天对群臣讲起此事再问，孩子却说太阳近；元帝追问为何不同，他说抬头能见太阳，却看不见长安。

## 排序：下列叙事节点应怎样排？ {#q.l3.5.1}
考点：skill.l3.5.1
语境：p.l3.5.a

- [1] 元帝询问洛下消息而流泪
  理由：来者引发关于故地的话题。
- [3] 元帝向群臣说起昨日答语再问
  理由：“明日”标明已换一天。
- [2] 孩子用无人从日边来说明日远
  理由：这是父子第一次问答。

提示：先给“明日”画一条界线。
解析：问故地消息和第一次比较都在前一天；宴会中先转述又重问。

## 单选：第一天判断“日远”直接凭什么？ {#q.l3.5.2}
考点：skill.l3.5.2
语境：p.l3.5.a

- [ ] 太阳每天都在移动
  理由：孩子没有使用运行轨迹作理由。
- [ ] 抬头看不见太阳
  理由：抬头看见太阳在第二答。
- [x] 有人从长安来，却没听说有人来自太阳那边

提示：找第一答里的感知动词。
解析：“不闻”表示没有听说；把有来客与无这种来客的消息对照，形成第一种推断。

## 找原文证据：哪句话明确把两次不同回答相对照？ {#q.l3.5.3}
考点：skill.l3.5.1
语境：p.l3.5.a

- [ ] 具以东渡意告之
  理由：此处交代东渡缘故。
- [x] 尔何故异昨日之言邪
- [ ] 元帝异之
  理由：这是对第一次回答感到出奇。

提示：留意“异”前后搭配有何不同。
解析：“异昨日之言”是与昨天的说法不同；“异之”是元帝觉得这番话出奇。

## 单选：第二个回答改变了哪一环？ {#q.l3.5.4}
考点：skill.l3.5.2
语境：p.l3.5.a

- [x] 把能否看到当成远近的依据
- [ ] 宣布已经有人从日边来
  理由：没有增加这样的来客。
- [ ] 说长安在一夜间迁走
  理由：孩子未谈地点发生变化。

提示：分清证据变化与物体变化。
解析：“举目见日，不见长安”给出眼前的可见性，换的是推断标准。

## 原文：教学例句 {#p.l3.5.b}
> 客问山路孰近。樵者曰：“西径近，昨负薪由之，未午已至。”明旦客复问，樵者望涧曰：“今东道可行。西径水涨，虽近，吾未见人得过。”客乃从东。
译文：客人问哪条山路近。樵夫说西边小径近，昨天背柴走过，中午前就到了。第二天客人又问，樵夫看着山涧说今天东边大路可走，西径涨水，路虽近，还没见人能过。客人便走东道。

## 找原文证据：哪句话表明对西径路程的判断来自亲历？ {#q.l3.5.5}
考点：skill.l3.5.2
语境：p.l3.5.b

- [x] 昨负薪由之
- [ ] 今东道可行
  理由：这是第二日对通行的判断。
- [ ] 客乃从东
  理由：这是客人最后的选择。

提示：找说话人自己走过哪条路。
解析：“负薪由之”以本人走西径的经历支持路近，不是转述他人的估计。

## 单选：客人第二天“复问”以后，西径是不是变长了？ {#q.l3.5.6}
考点：skill.l3.5.1
语境：p.l3.5.b

- [x] 文中仍说西径近，改变的是当天能否通行
- [ ] “乃从东”证明东路缩短了
  理由：选东路是因为可通行。
- [ ] 昨天的西径已经不存在
  理由：水涨不等于山路消失。

提示：比较“虽近”和“得过”的两项条件。
解析：两次答语分别提供原有路程和新近水况；不应将它们误读成两个互斥的里程数。

## 单选：“吾未见人得过”最稳妥的读法是？ {#q.l3.5.7}
考点：skill.l3.5.2
语境：p.l3.5.b

- [x] 到说话时樵者没有见到人成功渡过
- [ ] 昨天背柴的人没有到达
  理由：昨天樵者已走到。
- [ ] 樵者已经验证所有人永远过不了
  理由：未见不能推出永远不可能。

提示：限定观察的时间与范围。
解析：这是当天樵者的观察范围，足以说明他为何推荐东道，不等于全称断言。

## 单选：“昨负薪”相对于第一次问路是什么时间？ {#q.l3.5.8}
考点：skill.l3.5.1
语境：p.l3.5.b

- [ ] 客人走东道之后
  理由：那是故事末尾。
- [x] 问路之前一天
- [ ] 第二次问路当天
  理由：“昨”出现在第一次答语里。

提示：“昨”以哪一次发话为坐标？
解析：第一次回答回忆昨日亲历，叙述出现时间晚于亲历实际发生时间。
