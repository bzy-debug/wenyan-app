# 课文：风大了，魏文侯为什么还要赴约 {#l3.4}

简介：风大了，魏文侯还是亲自去找虞人。他是去打猎，还是另有一件事非去不可？

## 正文

“魏文侯与虞人期猎”说的是先前约好要去打猎。到第二天，文侯是不是真打了猎，还要读到最后一个“罢”字才知道。虞人掌管山泽田猎；在君主身旁劝阻他的“左右”是侍从。

“会天疾风”就是恰巧碰上大风。读“不可以风疾之故而失信”时，可以先抽出“以风疾之故”——因为风太大；再合起来说，“不能因为风太大就失了信用”。别把“可以”当成现代汉语里的一个词。

下篇换作陶工同船夫相约，也遇上坏天气。读到最后，看陶工当日把瓮背往哪里，才知道运瓮的事办了没有。

## 知识点：期 {#skill.l3.4.1}
义项：分清原先约好做什么和后来实际做了什么
领域：实词
要诀：约好要做的事，读到结尾再看做成了没有。
讲解：“期猎”能看出两人约好去打猎；若问那天有没有真的打猎，还要找末句实际做了什么。
例句：p.l3.4.a

## 知识点：会 {#skill.l3.4.2}
义项：恰巧遇上原先没料到的事
领域：虚词
要诀：试把“会”读成“恰巧碰上”。
讲解：先有人相约，随后“会天疾风”。大风出乎原先的安排，侍从和文侯便各自作了反应。
例句：p.l3.4.a

## 原文：古籍引文 {#p.l3.4.a}
> 魏文侯与虞人期猎。明日，会天疾风，左右止文侯，不听，曰：“不可以风疾之故而失信，吾不为也。”遂自驱车往，犯风而罢虞人。
译文：魏文侯和掌管山泽田猎的虞人约好去打猎。第二天正遇上大风，侍从劝阻他，文侯不听，说：“不能因为风大就失信。这样的事我不做。”于是他亲自驾车，冒风赶去告诉虞人，这次不打猎了。

## 单选：文侯最后做了什么？ {#q.l3.4.1}
考点：skill.l3.4.1
语境：p.l3.4.a

- [ ] 独自猎得禽兽后再通知虞人
  理由：没有猎获的记载，末句写“罢”。
- [ ] 取消驾车，叫虞人等到风停
  理由：“自驱车往”已发生。
- [x] 亲自去通知虞人取消打猎

提示：读“遂自驱车往”之后，他是出猎还是罢猎？
解析：“期猎”只是相约去打猎。文侯亲自驾车冒风前去，最后办的是“罢虞人”这件事：告诉虞人不必出猎了。

## 找原文证据：第二天碰上了什么事，叫侍从来劝文侯？请找原文。 {#q.l3.4.2}
考点：skill.l3.4.2
语境：p.l3.4.a

- [ ] 与虞人期猎
  理由：这是原先的约定。
- [ ] 左右止文侯
  理由：这是侍从对新条件的反应。
- [x] 会天疾风

提示：找天气变化本身。
解析：“会”在这里读作“恰逢”。因为碰上大风，侍从才劝他别去。

## 单选：“吾不为也”是说自己不做哪件事？ {#q.l3.4.3}
考点：skill.l3.4.1
语境：p.l3.4.a

- [x] 我不做因风大而失信的事
- [ ] 我不肯亲自驾车
  理由：下句恰写亲自驾车。
- [ ] 我不再与虞人相约
  理由：话的对象是失信，未说以后不约。

提示：“不可……而失信”，文侯不肯做的究竟是哪件事？
解析：“不为”的事就在前面半句：因为风大而对人失信。他随后亲自驾车前往，正是在照这话办。

## 排序：从相约到罢猎，三件事是怎样发生的？ {#q.l3.4.4}
考点：skill.l3.4.2
语境：p.l3.4.a

- [2] 遇疾风，侍从劝止
  理由：劝止回应的是当天的天气。
- [3] 亲自驱车去取消出猎
  理由：“遂”引出表态后的行动。
- [1] 同虞人相约打猎
  理由：相约在“明日”之前。

提示：先看“明日”前后各发生什么，再看“遂”后文侯去了哪里。
解析：先约打猎，翌日碰上大风，有人劝阻，文侯还是亲自去找虞人，给这次约定一个交代。

## 原文：教学例句 {#p.l3.4.b}
> 陶者期舟人以明日载瓮。夜雨，溪涨。旦，陶者至津，会舟人方系缆，曰：“水疾，不可以涉。”陶者乃与之约后三日，负瓮而还。
译文：陶工和船夫约好次日载运陶瓮。夜间下雨，溪水上涨。天亮陶工来到渡口，正碰到船夫在系缆绳，船夫说水流急，不能渡。陶工于是和他另约三日后运送，背着瓮回去了。

## 单选：“约后三日”能证明三天后一定运出陶瓮吗？ {#q.l3.4.5}
考点：skill.l3.4.1
语境：p.l3.4.b

- [ ] 可以，因为陶者已经到了渡口
  理由：陶工到了渡口，当天又背着瓮回去，这不能说明下次已经运成。
- [ ] 可以，因为“还”表示船已归来
  理由：“负瓮而还”的是陶者。
- [x] 只能证明另定了日期

提示：最后有哪一个行动真的发生？
解析：故事写到陶工背着瓮回家就停了。三天后的事只有一个新约定，还没写他究竟运没运成。

## 找原文证据：陶工到渡口时正巧看见了什么？请找原文。 {#q.l3.4.6}
考点：skill.l3.4.2
语境：p.l3.4.b

- [ ] 溪涨
  理由：写的是涨水。
- [x] 会舟人方系缆
- [ ] 陶者至津
  理由：只交代陶者到了哪里。

提示：找到“会”与正在进行的动作。
解析：“会”是恰巧碰上，“方”是正在。陶工到渡口时，船夫恰好正系着缆绳。

## 单选：风“疾”、水也“疾”，两个“疾”说的是哪一点？ {#q.l3.4.7}
考点：skill.l3.4.2
语境：p.l3.4.b

- [ ] 都写出行者着急
  理由：被形容的是水与风。
- [ ] 都说水或风生了病
  理由：上下文都在交代为何难以出行。
- [x] 都在形容自然力量的急劲

提示：先看这个字前面的主语。
解析：风“疾”是风势猛，水“疾”是水流急。一路劝罢猎，一路说不能渡，都是天气和水势妨碍了出行。

## 单选：两人都去赴了约，结尾各怎样？ {#q.l3.4.8}
考点：skill.l3.4.1
语境：p.l3.4.b

- [ ] 两人都在原地派侍从传话
  理由：二人都亲自到场。
- [ ] 两人都在原定日期完成约定的工作
  理由：一处罢猎，一处背瓮回去。
- [x] 文侯去取消一次出猎，陶者另约了运输日期

提示：一处读到“罢”，另一处读到“约后三日”。
解析：文侯冒风去告诉虞人取消出猎；陶工背着瓮回来，又约了三天后再运。两人都去了，原先约的事却都没在当天做。
