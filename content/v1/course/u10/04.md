# 课文：先约、到期、践约：文侯遇疾风 {#l3.4}

简介：分清约定的内容和实际做成的事。

## 正文

记一份只有两栏的小账：左栏写约定，右栏写后来当真发生的动作。《韩非子》中的文侯是否真的打了猎？去赴约并不等于完成打猎。末句的目的和结果要单独读。

“**左右**”在君主身边的场面可指侍从。“**期**”若带着一项未来活动，是相约去做；“会”在“会天疾风”里是正遇上。不能把“会”一律译成开会。第二段练习再换一个起约人，检验相同读法是否仍成立。

“不可以风疾之故而失信”怎么分？先找“因为什么”：“以风疾之故”是“因为风大”。余下的“不可……而失信”交代文侯的判断。遇到像现代词的两个字，先试试后一个字是否带着自己的宾语。

## 知识点：期 {#skill.l3.4.1}
义项：把约定中的未来行动与实际结果分开
领域：实词
要诀：分列原约与最后实际行动
讲解：承诺、相约只是人物对未来的安排。追踪末句的实行动作，才能判断约定如何被处理。
例句：p.l3.4.a

## 知识点：会 {#skill.l3.4.2}
义项：在叙事中引出碰上的意外条件
领域：虚词
要诀：用“恰逢”试接意外事件
讲解：时间已定之后，“会”有时引入恰在此时发生的事。由接下来的反应辨明它有没有改变原计划。
例句：p.l3.4.a

## 原文：古籍引文 {#p.l3.4.a}
> 魏文侯与虞人期猎。明日，会天疾风，左右止文侯，不听，曰：“不可以风疾之故而失信，吾不为也。”遂自驱车往，犯风而罢虞人。
译文：魏文侯和掌管山泽田猎的虞人约好去打猎。第二天正遇上大风，侍从劝阻，文侯没听，说不能因为风大就失信，我不做这样的事。于是亲自驱车前往，冒风去让虞人取消这次出猎。

## 单选：文侯最后做了什么？ {#q.l3.4.1}
考点：skill.l3.4.1
语境：p.l3.4.a

- [ ] 独自猎得禽兽后再通知虞人
  理由：没有猎获的记载，末句写“罢”。
- [ ] 取消驾车，叫虞人等到风停
  理由：“自驱车往”已发生。
- [x] 亲自去通知虞人取消打猎

提示：追踪“遂”以后真正实施的动作。
解析：“期猎”只说约定内容；“往”是在赴约处说明变化，“罢”结束了原计划。

## 找原文证据：哪几个字直接指出旧计划碰上的新条件？ {#q.l3.4.2}
考点：skill.l3.4.2
语境：p.l3.4.a

- [ ] 与虞人期猎
  理由：这是原先的约定。
- [ ] 左右止文侯
  理由：这是侍从对新条件的反应。
- [x] 会天疾风

提示：找天气变化本身。
解析：“会”领起恰逢大风的情况，所以下面才有侍从的劝阻。

## 单选：怎样补全“吾不为也”所指的事？ {#q.l3.4.3}
考点：skill.l3.4.1
语境：p.l3.4.a

- [x] 我不做因风大而失信的事
- [ ] 我不肯亲自驾车
  理由：下句恰写亲自驾车。
- [ ] 我不再与虞人相约
  理由：话的对象是失信，未说以后不约。

提示：沿上一句的否定往回找。
解析：“不为”承接“以风疾之故而失信”，并非拒绝做原约所涉及的一切事情。

## 排序：按当事人获得信息、作出回应的先后排列。 {#q.l3.4.4}
考点：skill.l3.4.2
语境：p.l3.4.a

- [2] 遇疾风，侍从劝止
  理由：劝止回应的是当天的天气。
- [3] 亲自驱车去取消出猎
  理由：“遂”引出表态后的行动。
- [1] 同虞人相约打猎
  理由：相约在“明日”之前。

提示：暂且删掉引语，只看时间和行动。
解析：意外天气介于约定与亲往之间。文侯实际履行的是向对方说明变化的责任。

## 原文：教学例句 {#p.l3.4.b}
> 陶者期舟人以明日载瓮。夜雨，溪涨。旦，陶者至津，会舟人方系缆，曰：“水疾，不可以涉。”陶者乃与之约后三日，负瓮而还。
译文：陶工和船夫约好次日载运陶瓮。夜间下雨，溪水上涨。天亮陶工来到渡口，正碰到船夫在系缆绳，船夫说水流急，不能渡。陶工于是和他另约三日后运送，背着瓮回去了。

## 单选：“约后三日”能证明三天后一定运出陶瓮吗？ {#q.l3.4.5}
考点：skill.l3.4.1
语境：p.l3.4.b

- [ ] 可以，因为陶者已经到了渡口
  理由：到渡口是天亮时的行动。
- [ ] 可以，因为“还”表示船已归来
  理由：“负瓮而还”的是陶者。
- [x] 只能证明另定了日期

提示：最后有哪一个行动真的发生？
解析：叙事以背瓮回去收束，三天后的运输只存在于新约之中。

## 找原文证据：陶工到渡口时，哪一处表示碰上船夫正在做事？ {#q.l3.4.6}
考点：skill.l3.4.2
语境：p.l3.4.b

- [ ] 溪涨
  理由：写的是涨水。
- [x] 会舟人方系缆
- [ ] 陶者至津
  理由：只交代陶者到了哪里。

提示：找到“会”与正在进行的动作。
解析：“方”表正在，“会”把陶者到来与船夫系缆连在同一时刻。

## 单选：“水疾”与“风疾”合读，“疾”的共同线索是什么？ {#q.l3.4.7}
考点：skill.l3.4.2
语境：p.l3.4.b

- [ ] 都写出行者着急
  理由：被形容的是水与风。
- [ ] 都说水或风生了病
  理由：上下文都在交代为何难以出行。
- [x] 都在形容自然力量的急劲

提示：先看这个字前面的主语。
解析：溪涨后水流急，风势也可急劲。两处的主体都排除了人物患病的读法。

## 单选：对照两个故事，哪项保留了实际结果的差别？ {#q.l3.4.8}
考点：skill.l3.4.1
语境：p.l3.4.b

- [ ] 两人都在原地派侍从传话
  理由：二人都亲自到场。
- [ ] 两人都在原定日期完成约定的工作
  理由：一处罢猎，一处背瓮回去。
- [x] 文侯去取消一次出猎，陶者另约了运输日期

提示：末段各找一个收束动作。
解析：一个以“罢”收束，一个还有新的“三日”之约，不能把“赴约”误作“原计划照办”。
