# 检查：约好的事，后来办成了吗 {#check.10}

## 原文：古籍引文 {#p.check.10.a}
> 齐宣王使人吹竽，必三百人。南郭处士请为王吹竽，宣王说之，廪食以数百人。宣王死，湣王立，好一一听之，处士逃。
译文：齐宣王要人吹竽，总要三百人合奏。南郭处士请求给王吹竽，宣王很高兴，让他跟那几百人一起领口粮。宣王去世，湣王即位，爱听竽手一个个吹，南郭处士便逃走了。

## 排序：南郭处士先遇到什么事，后来又怎样了？ {#q.check.10.1}
考点：skill.l3.4.1
语境：p.check.10.a

- [3] 处士逃走
  理由：“处士逃”接在新王的喜好之后。
- [2] 湣王即位要逐个听奏
  理由：宣王去世之后才换了听法。
- [1] 请入宣王的合奏队伍
  理由：最先是在三百人合奏的安排下申请。

提示：换王之前和之后，各是谁在听？
解析：宣王在位时，处士主动请求合奏。湣王即位后爱一个个听，接下来写的就是处士逃走。

## 单选：处士为什么逃走？哪一说法最合原文？ {#q.check.10.2}
考点：skill.l3.5.2
语境：p.check.10.a

- [x] 改为单听使个人本领容易显露，逃走紧随其后
- [ ] 宣王下令捉处士
  理由：宣王此时已死。
- [ ] 湣王已经当众逐一考试并宣布他落选
  理由：只说“好一一听之”，没有写考试结果。

提示：原文写了新王怎样听竽，有没有写他已经怎样处置了处士？
解析：众人合奏时难辨一个人吹得怎样，单独吹就容易听出来。处士紧接着逃走，原文没有写他受罚。

## 找原文证据：原先哪项规矩能让处士混在竽手中间？请找原文。 {#q.check.10.3}
考点：skill.l3.6.1
语境：p.check.10.a

- [ ] 好一一听之
  理由：这已是新王的听法。
- [ ] 宣王死
  理由：死讯标志后来局面改变，并非旧有保护。
- [x] 必三百人

提示：宣王要多少人一同吹？一个人在众人之中容易被听出来吗？
解析：开头的“必三百人”交代合奏的人数。等看到新王要逐一听、处士随即逃走，才明白这么多人一起吹对他意味着什么。

## 原文：教学例句 {#p.check.10.b}
> 圃者期客尝梨。客至，圃者指枝曰：“昨见其黄，以为可食。”会有梨坠，剖之，中尚涩。客笑曰：“悦其色而未知其味也。”圃者更约十日。及期，客复问梨可食否。圃者曰：“既尝而知其涩矣，安得复以色断之？”
译文：园丁约客人来尝梨。客人到时，他指着枝头说昨天看梨黄了，以为已经可以吃。恰有梨落下，切开尝来里面还涩。客人笑说喜欢它的颜色，却还没弄清滋味。园丁另定了十天后的日子。到了约定时间，客人又问梨能不能吃。园丁说，既尝过并知道先前它是涩的，哪能又只凭颜色断定？

## 找原文证据：是什么给了两人剖梨尝味的机会？请找原文。 {#q.check.10.4}
考点：skill.l3.4.2
语境：p.check.10.b

- [ ] 昨见其黄
  理由：只观察了颜色。
- [ ] 圃者更约十日
  理由：这是试过后的安排。
- [x] 会有梨坠

提示：先有梨落下，才便于剖开。
解析：正巧有梨从树上掉下来，二人才能剖开尝味。“会”说的就是这个巧合。

## 单选：客人后来“复问梨可食否”，重新提起了先前哪次判断？ {#q.check.10.5}
考点：skill.l3.5.1
语境：p.check.10.b

- [ ] 圃者起初说任何黄梨都不可以吃
  理由：“以为可食”恰好相反。
- [ ] 十日后的试吃已经结束
  理由：只写到期再问，没有写再次试吃。
- [x] 园丁初见梨黄就以为能吃，剖尝却还涩

提示：头一次园丁看的是梨皮，后来尝到的又是什么滋味？
解析：头一回看见梨黄，园丁就以为能吃，尝过才知还涩。十天后“复问”，问的仍是能吃不能吃。

## 单选：园丁说“既尝而知其涩矣”，把什么当成这次答话的根据？ {#q.check.10.6}
考点：skill.l3.6.2
语境：p.check.10.b

- [ ] 这次一定仍涩，所以谁都不必再尝
  理由：他质疑的是“以色断之”，没有给出本次味道。
- [x] 上次尝过，已经知道仅看颜色会误判
- [ ] 只要等足十天梨便必甜
  理由：到期是约定，不能代替品尝。

提示：上次尝来是涩的，这一次能只看梨皮就知道滋味吗？
解析：“既尝”说的是上次已尝过，园丁由此知道梨黄不等于味甜。这一回究竟熟没有，单看颜色还不能定。
