# 检查：重建事序综合检查 {#check.10}

## 原文：古籍引文 {#p.check.10.a}
> 齐宣王使人吹竽，必三百人。南郭处士请为王吹竽，宣王说之，廪食以数百人。宣王死，湣王立，好一一听之，处士逃。
译文：齐宣王要人吹竽，总要三百人合奏。南郭处士请求给王吹竽，宣王喜欢他，使他在数百人之列领受供养。宣王去世，湣王即位，喜欢一个个听，处士便逃走。

## 排序：把处士所经历的变化排好。 {#q.check.10.1}
考点：skill.l3.4.1
语境：p.check.10.a

- [3] 处士逃走
  理由：“处士逃”接在新王的喜好之后。
- [2] 湣王即位要逐个听奏
  理由：宣王去世之后才换了听法。
- [1] 请入宣王的合奏队伍
  理由：最先是在三百人合奏的安排下申请。

提示：换王之前和之后，各是谁在听？
解析：请求入乐队是开端，逐个听是新条件，逃走是叙述的结果。

## 单选：关于处士逃走的原因，哪种说法最符合证据？ {#q.check.10.2}
考点：skill.l3.5.2
语境：p.check.10.a

- [x] 改为单听使个人本领容易显露，逃走紧随其后
- [ ] 宣王下令捉处士
  理由：宣王此时已死。
- [ ] 湣王已经当众逐一考试并宣布他落选
  理由：只说“好一一听之”，没有写考试结果。

提示：分清从先后关系可推的原因和明写的处罚。
解析：新听法与逃相邻，支持对暴露风险的推断；如何处罚没有交代。

## 找原文证据：处士最后逃走。带着这个结局回看，什么条件原可让他藏在众人之中？ {#q.check.10.3}
考点：skill.l3.6.1
语境：p.check.10.a

- [ ] 好一一听之
  理由：这已是新王的听法。
- [ ] 宣王死
  理由：死讯标志后来局面改变，并非旧有保护。
- [x] 必三百人

提示：从后来怕单听的结果，倒推原先的环境。
解析：合奏可以掩盖个体奏得怎样。“必三百人”在初读时像是人数交代，到“处士逃”时才显出另一层关系。

## 原文：教学例句 {#p.check.10.b}
> 圃者期客尝梨。客至，圃者指枝曰：“昨见其黄，以为可食。”会有梨坠，剖之，中尚涩。客笑曰：“悦其色而未知其味也。”圃者更约十日。及期，客复问梨可食否。圃者曰：“既尝而知其涩矣，安得复以色断之？”
译文：园丁约客人来尝梨。客人到时，他指着枝头说昨天看梨黄了，以为已经可以吃。恰有梨落下，切开尝来里面还涩。客人笑说喜欢它的颜色，却还没弄清滋味。园丁另定了十天后的日子。到了约定时间，客人又问梨能不能吃。园丁说，既尝过并知道先前它是涩的，哪能又只凭颜色断定？

## 找原文证据：哪句话使二人碰到一个可以实际尝验的机会？ {#q.check.10.4}
考点：skill.l3.4.2
语境：p.check.10.b

- [ ] 昨见其黄
  理由：只观察了颜色。
- [ ] 圃者更约十日
  理由：这是试过后的安排。
- [x] 会有梨坠

提示：先有梨落下，才便于剖开。
解析：“会”表示恰逢，随后试吃把看颜色的初步推测变成可核验的问题。

## 单选：客人后来“复问梨可食否”，重新提起了先前哪次判断？ {#q.check.10.5}
考点：skill.l3.5.1
语境：p.check.10.b

- [ ] 圃者起初说任何黄梨都不可以吃
  理由：“以为可食”恰好相反。
- [ ] 十日后的试吃已经结束
  理由：只写到期再问，没有写再次试吃。
- [x] 园丁初见梨黄就以为能吃，剖尝却还涩

提示：找上一回讨论能不能吃时所得的结论。
解析：“复问”把两个日期的讨论接起来，后来检验能否成熟并不抹掉第一次判断的失误。

## 单选：园丁说“既尝而知其涩矣”，把什么当成这次答话的根据？ {#q.check.10.6}
考点：skill.l3.6.2
语境：p.check.10.b

- [ ] 这次一定仍涩，所以谁都不必再尝
  理由：他质疑的是“以色断之”，没有给出本次味道。
- [x] 上次尝过，已经知道仅看颜色会误判
- [ ] 只要等足十天梨便必甜
  理由：到期是约定，不能代替品尝。

提示：先把已经完成的检验和现在还要判断的事分开。
解析：“既”把上回经验当作已知事实；园丁凭它拒绝再次只按颜色下结论。
