# 检查：还原事情的先后综合检查 {#check.10}

## 原文：教学例句 {#p.story.check.10.a}
> 暮，野客扣门求火。主人怪其无灯，客曰：“向过桥时，风灭吾炬。行十里，始见君家灯耳。”主人燃薪授之，客谢而行。
译文：天晚了，行人敲门借火。主人奇怪他没灯。他说先前过桥时风吹灭火把，走了十里才见到这家的灯。主人点燃木柴给他，行人道谢走了。
词注：扣：敲，行人敲门借火。
  炬：火把。
  薪：柴，主人点燃木柴给行人。

## 排序：照客人实际经历排列。 {#q.story.check.10.1}
考点：skill.story.l3.4.1
语境：p.story.check.10.a

- [3] 敲门向主人求火
  理由：这是最先落笔、最后才发生的事。
- [1] 风吹灭火把
  理由：“向”说先前的过桥途中。
- [2] 走十里才看见灯
  理由：“始”说在黑暗里走了一段才见灯。

提示：先读客人的答话，再看开头。
解析：回到经历本身，遇风、见灯、借火依次发生。

## 找原文证据：哪几个字提醒读者，答话回到了早先？ {#q.story.check.10.2}
考点：skill.story.l3.4.2
语境：p.story.check.10.a

- [ ] 暮
  理由：日暮是敲门时的大致背景。
- [x] 向过桥时
  理由：“向”把说话的时间拉回过桥时。
- [ ] 客谢而行
  理由：这是最后告别。

提示：找能译成“先前”的字。
解析：“向”把说话的时间拉回过桥时。

## 单选：“主人怪其无灯”写的是谁的反应？ {#q.story.check.10.3}
考点：skill.story.l3.5.2
语境：p.story.check.10.a

- [x] 屋主人见来客没灯，觉得奇怪
  理由：叙述中嵌着主人当时的看法，随后客人才说明原委。
- [ ] 路人判断主人不肯借火
  理由：没有这样的路人。
- [ ] 客人自己觉得火把不该熄灭
  理由：这是把“主人”的反应给了客人。

提示：“怪”是谁做出的判断？
解析：叙述中嵌着主人当时的看法，随后客人才说明原委。

## 原文：教学例句 {#p.story.check.10.b}
> 渔父常留断绳，结而悬诸舟。会邻舟失缆，渔父自岸返舟，取绳还岸，系邻舟。或谓：“盍新制一缆？”邻人曰：“水急，不可待也。”
译文：渔父素常把断绳接起来挂在船上。一次邻船丢了缆绳，他从岸边回船取绳，回岸系住邻船。有人问为何不新做缆绳，邻人说水急，不能等。
词注：缆：系船的大绳。
  会：正巧碰上，转入邻船丢了缆绳的事。
  盍：何不，旁人提出再做一条绳的办法。

## 找原文证据：选出最能表示平日习惯的词句。 {#q.story.check.10.4}
考点：skill.story.l3.5.1
语境：p.story.check.10.b

- [x] 常留断绳
  理由：“常”点出积绳是平日的做法。
- [ ] 会邻舟失缆
  理由：这是偶然发生的一回。
- [ ] 水急
  理由：这是眼前的情形。

提示：哪个字表示不止一回？
解析：“常”点出积绳是平日的做法。

## 单选：取绳一程，他先回哪里，又到哪里？ {#q.story.check.10.5}
考点：skill.story.l3.6.1
语境：p.story.check.10.b

- [ ] 先回家，再到渔市
  理由：这两处都不在这趟取绳路上。
- [ ] 先回邻船，再回自己船上
  理由：绳本来挂在自己的船上。
- [x] 先回自己的船，再回岸边
  理由：“自岸返舟”去取绳，“取绳还岸”才来系邻船。

提示：跟着“返舟”“还岸”读。
解析：“自岸返舟”去取绳，“取绳还岸”才来系邻船。

## 单选：“盍新制一缆”说的是什么？ {#q.story.check.10.6}
考点：skill.story.l3.6.2
语境：p.story.check.10.b

- [x] 旁人另外提出的办法
  理由：有人建议新做，邻人说明眼下来不及。
- [ ] 邻人实施后的补救
  理由：邻人回答水急等不得。
- [ ] 渔父已经做好的新缆
  理由：他用的是留存的断绳。

提示：“盍”可读成“为什么不”。
解析：有人建议新做，邻人说明眼下来不及。
