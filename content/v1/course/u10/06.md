# 课文：前言到危局：华歆、王朗同舟 {#l3.6}

简介：在转折处停下来，听人物自己解释早先为什么犹豫。

## 正文

把船上的抉择分成两个问题：船有余地时接不接人？追兵到了还留不留人？如果只读第一问，就会用“爽快”“迟疑”过早评价人物。读到“**本所以疑**”，用后来的危局给“本”补上先前的顾虑。

“**既已**”把接纳旅客列为已经形成的事实，“宁可以……邪”借反问衡量危急时的责任。结尾只写众人据这件事作比较，评价不能脱离两次具体的选择。

## 知识点：本所以 {#skill.l3.6.1}
义项：由事后解释补出先前未说明的顾虑
领域：句法
要诀：把“正为此”的“此”接回眼前情形
讲解：“所以”在“本所以疑”中表示疑虑的缘由；暂缓评价，直到人物说出先前没明说的理由。
例句：p.l3.6.a

## 知识点：既已 {#skill.l3.6.2}
义项：由已成事实推导眼下如何行动
领域：虚词
要诀：把承诺前与承担以后分开
讲解：人物说“既已”常以既成的关系作为后续选择的依据，先找事实再找态度。
例句：p.l3.6.a

## 原文：古籍引文 {#p.l3.6.a}
> 华歆、王朗俱乘船避难，有一人欲依附，歆辄难之。朗曰：“幸尚宽，何为不可？”后贼追至，王欲舍所携人。歆曰：“本所以疑，正为此耳。既已纳其自托，宁可以急相弃邪？”遂携拯如初。世以此定华、王之优劣。
译文：华歆和王朗坐船逃难，有人想搭船。华歆起初觉得为难，王朗认为船上幸有余地。后来贼人追到，王朗想抛下搭船人。华歆说先前犹疑正因为顾虑这种变故；既然已经接受托付，哪里能因情势紧急而抛弃他？于是依旧携带、救助那人。世人由此评说两人。

## 单选：“正为此耳”的“此”最能接到哪一变化？ {#q.l3.6.1}
考点：skill.l3.6.1
语境：p.l3.6.a

- [ ] 搭船人偷走财物
  理由：全文未写他偷盗。
- [ ] 船从一开始就没有余地
  理由：王朗明确说“幸尚宽”。
- [x] 追兵来临，可能难以始终保护搭船人

提示：往歆说话前一两句寻找新出现的危局。
解析：开头只写难，追兵出现后“本所以疑”才交代他预想过照顾对方的风险。

## 找原文证据：华歆拒绝抛下那人，以哪句为理由的起点？ {#q.l3.6.2}
考点：skill.l3.6.2
语境：p.l3.6.a

- [ ] 幸尚宽
  理由：这是王朗最早谈船的位置。
- [ ] 有一人欲依附
  理由：提出搭船请求尚不等于已被接纳。
- [x] 既已纳其自托

提示：哪一处写出相互关系已成立？
解析：自托已经被接纳是事实；“宁可以急相弃邪”据此反问危急时能否弃人。

## 单选：“歆辄难之”能否译成“华歆已经拒绝那人上船”？ {#q.l3.6.3}
考点：skill.l3.6.1
语境：p.l3.6.a

- [x] 不宜，后文表明他后来已在船上
- [ ] 可以，后来出现的是另一个搭船者
  理由：“所携人”承接先前同一人。
- [ ] 可以，王朗从未答应过载人
  理由：王朗开头明确认为可以。

提示：留出“觉得为难”与“最后决定”之间的距离。
解析：“难”说起初态度，不能抹掉后来已经接纳的事实。

## 单选：“遂携拯如初”支持怎样的结局？ {#q.l3.6.4}
考点：skill.l3.6.2
语境：p.l3.6.a

- [x] 仍带着那人，没有照王朗的意思抛下他
- [ ] 华歆跳上另一条船
  理由：从始至终只叙同舟应变。
- [ ] 已经到达安全之地
  理由：“携拯”并未叙写抵达。

提示：“如初”说的是哪项做法延续？
解析：结尾交代对所携者的处置，读者可以据此评价应对，不能补写航行终点。

## 原文：教学例句 {#p.l3.6.b}
> 里老欲托书于商。商始辞，曰：“道有两歧，恐误所之。”问明其里，乃受。至歧路，伴欲弃书以速行。商曰：“向者辞，虑此也。既受人书，岂以迟故弃之？”乃访其门而授书。
译文：老人想托商人捎信。商人起初推辞，害怕岔路走错目的地。问明住处才接信。到岔路，同伴想丢信以加快行程，商人说先前推辞正顾虑这类事。既然接下别人的信，怎能因为耽搁就抛下？于是寻找收信人的门，将信送去。

## 单选：“向者辞，虑此也”把哪两处连在一起？ {#q.l3.6.5}
考点：skill.l3.6.1
语境：p.l3.6.b

- [ ] 先前已送完信，后来才询问住址
  理由：询问住址在接信之前。
- [ ] 先前不识老人，后来认出老人是同伴
  理由：老人未与商人一同行路。
- [x] 先前怕误路，到岔路又面临寻址的耽搁

提示：“向者”不是指眼下说话这个时刻。
解析：商人用当下的困难解释最初的犹豫，人物立场并未前后颠倒。

## 找原文证据：哪句话是商人坚持送到的前提？ {#q.l3.6.6}
考点：skill.l3.6.2
语境：p.l3.6.b

- [x] 既受人书
- [ ] 伴欲弃书
  理由：这只是同伴的打算。
- [ ] 道有两歧
  理由：这是先前顾虑的路况。

提示：把前提与随后的反问配对。
解析：商人用已经接受托付这一事实承担后续义务。

## 排序：按委托关系的发展排列。 {#q.l3.6.7}
考点：skill.l3.6.2
语境：p.l3.6.b

- [3] 商人访门送达
  理由：“乃”承接拒绝弃信。
- [1] 商人问清里居后接信
  理由：知道地址才接受。
- [2] 同伴想丢信加快行程
  理由：分歧出现在两人到岔路时。

提示：区别同伴想做的事与最后真正做的事。
解析：问明受书、途中起议、坚持送达构成整段。弃书只是提议，没有实施。

## 单选：把两段并读，哪种概括没有漏掉决定变化的关键？ {#q.l3.6.8}
考点：skill.l3.6.1
语境：p.l3.6.b

- [ ] 商人的话与同伴提议一致
  理由：同伴想丢信，商人拒绝。
- [ ] 两人开始都答应得很爽快
  理由：先有“难之”或“始辞”。
- [x] 两次先有顾虑；承接托付后都不因困难弃置

提示：两段都要从前后两个时点取证。
解析：只写最后助人会漏掉先前犹豫；只写最初推辞又会误判最后的选择。
