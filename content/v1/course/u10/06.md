# 课文：华歆、王朗同舟遇险 {#l3.6}

简介：华歆开始为难，追兵来时却不肯丢下同船的人。发生了什么，让他作出这两次选择？

## 正文

有个人来搭船，船上还有空处，华歆为什么觉得为难？读到这里可以先留个疑问。等追兵一来，王朗想丢下那人，华歆才说“本所以疑，正为此耳”——我原先担心的正是今天这样的情形。

再看“既已”。那人来求助时，还没有上船；如今两人已经接受了他的托付，危急关头还能丢下他吗？“宁可以……邪”要连起来读成反问。世人后来评说华歆和王朗，两人前后怎样做都要放在眼里。

## 知识点：本所以 {#skill.l3.6.1}
义项：听人物后来的解释，读懂他原先担心什么
领域：句法
要诀：他原先担心什么，要等他亲口解释。
讲解：“本所以疑”是“原先之所以犹豫”。“此”指的是什么，回头看他说话前刚遇到的危险。
例句：p.l3.6.a

## 知识点：既已 {#skill.l3.6.2}
义项：先说已经做了什么，再说明如今该怎样做
领域：虚词
要诀：“既已”后面，是哪件不能抹去的事？
讲解：可以接着想：“既然已经答应了人家，现在还能怎么办？”人物接下来的选择，往往由先前的托付而来。
例句：p.l3.6.a

## 原文：古籍引文 {#p.l3.6.a}
> 华歆、王朗俱乘船避难，有一人欲依附，歆辄难之。朗曰：“幸尚宽，何为不可？”后贼追至，王欲舍所携人。歆曰：“本所以疑，正为此耳。既已纳其自托，宁可以急相弃邪？”遂携拯如初。世以此定华、王之优劣。
译文：华歆和王朗坐船逃难，有人想搭船。华歆起初觉得为难，王朗认为船上幸有余地。后来贼人追到，王朗想抛下搭船人。华歆说先前犹疑正因为顾虑这种变故；既然已经接受托付，哪里能因情势紧急而抛弃他？于是他们照旧带着那人，护着他。世人据此评说华歆和王朗两人孰优孰劣。

## 单选：华歆说“正为此耳”，原来担心的是什么？ {#q.l3.6.1}
考点：skill.l3.6.1
语境：p.l3.6.a

- [ ] 搭船人偷走财物
  理由：全文未写他偷盗。
- [ ] 船从一开始就没有余地
  理由：王朗明确说“幸尚宽”。
- [x] 追兵来临，可能难以始终保护搭船人

提示：他说这话之前，船外来了谁？王朗想怎么办？
解析：追兵到了，王朗提出弃人，华歆这才解释：先前觉得为难，就是怕遇险以后不能护人到底。

## 找原文证据：华歆认为有哪件事已经做了，所以不能弃人？请找原文。 {#q.l3.6.2}
考点：skill.l3.6.2
语境：p.l3.6.a

- [ ] 幸尚宽
  理由：王朗说“幸尚宽”，意思是船上还有空处。
- [ ] 有一人欲依附
  理由：提出搭船请求尚不等于已被接纳。
- [x] 既已纳其自托

提示：搭船人已经把自己托付给他们，华歆用哪几个字说已经接下了这份托付？
解析：“既已纳其自托”说他们已经答应了搭船人的请求。有了这一步，才有后来那句反问：怎能一遇急事就丢下他？

## 单选：“歆辄难之”能否译成“华歆已经拒绝那人上船”？ {#q.l3.6.3}
考点：skill.l3.6.1
语境：p.l3.6.a

- [x] 不宜，后文表明他后来已在船上
- [ ] 可以，后来出现的是另一个搭船者
  理由：“所携人”承接先前同一人。
- [ ] 可以，王朗从未答应过载人
  理由：王朗开头明确认为可以。

提示：华歆起初犹豫，那人后来到底上船了没有？
解析：“难之”写华歆刚听到请求时觉得难办。后来王朗要丢下的是“所携人”，可见那人已经跟他们上了船。

## 单选：“遂携拯如初”告诉我们，船上的人最后怎样做了？ {#q.l3.6.4}
考点：skill.l3.6.2
语境：p.l3.6.a

- [x] 仍带着那人，没有照王朗的意思抛下他
- [ ] 华歆跳上另一条船
  理由：从始至终只叙同舟应变。
- [ ] 已经到达安全之地
  理由：“携拯”并未叙写抵达。

提示：“如初”说的是哪项做法延续？
解析：“如初”是照旧，他们仍然带着那人。船后来到了哪里，本文没有再说下去。

## 原文：教学例句 {#p.l3.6.b}
> 里老欲托书于商。商始辞，曰：“道有两歧，恐误所之。”问明其里，乃受。至歧路，伴欲弃书以速行。商曰：“向者辞，虑此也。既受人书，岂以迟故弃之？”乃访其门而授书。
译文：老人想托商人捎信。商人起初推辞，害怕岔路走错目的地。问明住处才接信。到岔路，同伴想丢信以加快行程，商人说先前推辞正顾虑这类事。既然接下别人的信，怎能因为耽搁就抛下？于是商人找到收信人的家，把信交给了对方。

## 单选：商人说“向者辞，虑此也”，先前和眼下各有什么难处？ {#q.l3.6.5}
考点：skill.l3.6.1
语境：p.l3.6.b

- [ ] 先前已送完信，后来才询问住址
  理由：询问住址在接信之前。
- [ ] 先前不识老人，后来认出老人是同伴
  理由：老人未与商人一同行路。
- [x] 先前怕误路，到岔路又面临寻址的耽搁

提示：“向者辞”说的是以前。商人当时怕两条岔路会让他怎样？
解析：先前商人担心遇上岔路、找错地方；如今正当岔路，同伴又嫌送信耽搁。眼前的事解释了他的担忧。

## 找原文证据：商人为什么认为不能丢信？找出他提起的那件事。 {#q.l3.6.6}
考点：skill.l3.6.2
语境：p.l3.6.b

- [x] 既受人书
- [ ] 伴欲弃书
  理由：这只是同伴的打算。
- [ ] 道有两歧
  理由：这是先前顾虑的路况。

提示：他说“岂以迟故弃之”之前，先承认自己已经做了什么？
解析：“既受人书”就是已经接下了人家的信。商人觉得，既然答应代送，就不能为了赶路把信丢掉。

## 排序：从老人托信到收信人拿到信，先后发生了什么？ {#q.l3.6.7}
考点：skill.l3.6.2
语境：p.l3.6.b

- [3] 商人访门送达
  理由：“乃”承接拒绝弃信。
- [1] 商人问清里居后接信
  理由：知道地址才接受。
- [2] 同伴想丢信加快行程
  理由：分歧出现在两人到岔路时。

提示：区别同伴想做的事与最后真正做的事。
解析：商人先问清住处才收信，到了岔路同伴想把信丢掉。商人没有照做，最后找上门把信交到了。

## 单选：华歆和商人起初怎么想，后来又怎么做？ {#q.l3.6.8}
考点：skill.l3.6.1
语境：p.l3.6.b

- [ ] 商人的话与同伴提议一致
  理由：同伴想丢信，商人拒绝。
- [ ] 两人开始都答应得很爽快
  理由：先有“难之”或“始辞”。
- [x] 两次先有顾虑；承接托付后都不因困难弃置

提示：比较两人接受托付前后的话。
解析：华歆怕日后有危险，商人怕走错路。可两人一旦接下托付，遇险、误时也都没把人或信丢下。
