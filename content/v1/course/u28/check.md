# 检查：从察举到授官综合检查 {#check.28}

## 原文：教学例句 {#p.h28.check.1}
> 太守察林生孝廉。林生辞。岁后诏至，拜其弟为县令，弟遂视事。
译文：太守推举林生为孝廉，林生辞谢了。一年后诏令下达，授他弟弟为县令，弟弟随即到任理事。
词注：孝廉：察举选人的科目。

## 单选：这家兄弟，谁只是受到察举而没有应召？ {#q.h28.check.1}
考点：skill.h28.1.cha-recommend
语境：p.h28.check.1

- [ ] 太守 {#q.h28.check.1.o1}
  理由：太守是最先推举林生的人。
- [ ] 被任为县令的弟弟 {#q.h28.check.1.o2}
  理由：弟弟收到任命后已经“视事”。
- [x] 兄长林生 {#q.h28.check.1.o3}
  理由：林生辞谢的是察举，后来拜为县令、已经视事的是弟弟。

提示：在“林生辞”之后，查明下次受命的人有没有换。
解析：林生辞谢的是察举，后来拜为县令、已经视事的是弟弟。

## 原文：教学例句 {#p.h28.check.2}
> 乡人举生于郡。郡先察其行，三月后，书至，除生为书佐。生乃辞家赴府。
译文：乡人向郡里推荐书生。郡里先考察他的品行，三个月后任书到来，授予他书佐之职。他这才辞别家人，到郡府赴任。
词注：郡：地方行政区域。

## 单选：从什么时候起，书生才真正有了官职？ {#q.h28.check.2}
考点：skill.h28.1.chu-appoint
语境：p.h28.check.2

- [ ] 受乡人推荐 {#q.h28.check.2.o1}
  理由：其后还经过三个月考察。
- [ ] 辞别家人 {#q.h28.check.2.o2}
  理由：已经受职后才辞家。
- [x] 授任书佐 {#q.h28.check.2.o3}

提示：乡人推举时并没有说授他什么职，后来文书上怎样写？
解析：“除生为书佐”正式授他书佐之职，他这才辞家去郡府。

## 原文：教学例句 {#p.h28.check.3}
> 县丞摄令事，令还，丞交印。令以仓事繁，复使丞领之，丞职如故。
译文：县丞暂代县务，待县令回来便交还官印。县令因粮仓事务繁多，又让县丞兼管，县丞的本职照旧。
词注：印：官印，此处代表办理公务的凭信。

## 找原文证据：指出县丞结束代办县令职务的那一处。 {#q.h28.check.3}
考点：skill.h28.2.she-act
语境：p.h28.check.3

- [ ] 丞职如故 {#q.h28.check.3.o1}
  理由：“丞职如故”说县丞本职照旧，已经说到兼管仓事了。
- [x] 令还，丞交印 {#q.h28.check.3.o2}
- [ ] 令事 {#q.h28.check.3.o3}
  理由：“令事”说的是县令的事务，看不出何时交回去。

提示：一人回来，另一人随即交出了什么？
解析：县令回来，县丞把印交还。往后他兼管仓事，已是另一桩安排。

## 单选：县令又让县丞“领之”，县丞手里的差事有何变化？ {#q.h28.check.4}
考点：skill.h28.2.ling-concurrent
语境：p.h28.check.3

- [ ] 接任县令不再做丞 {#q.h28.check.4.o1}
  理由：县令自己已经回来，县丞还在原职上。
- [x] 保留县丞本职并兼管仓事 {#q.h28.check.4.o2}
- [ ] 丢掉本职只管仓 {#q.h28.check.4.o3}
  理由：末句特意交代“丞职如故”，本职还在。

提示：“之”接的是哪个差事？再看末句“丞职如故”。
解析：新添的是仓事，县丞原有的职务照旧，所以是兼管。

## 原文：教学例句 {#p.h28.check.5}
> 县令韩方召书吏，吏至，白韩令曰：“簿已具。”令自按之。
译文：县令韩方召来书吏，书吏禀告韩县令，说簿册已备齐。县令亲自查验。

## 单选：县令韩方、韩令、末句的“令”，一共说了几个人？ {#q.h28.check.5}
考点：skill.h28.3.title-name
语境：p.h28.check.5

- [ ] 三人，因为有三种称呼 {#q.h28.check.5.o1}
  理由：这段里另有一名书吏，不能把县令的简称算作新人。
- [x] 同一人，前后换了称法 {#q.h28.check.5.o2}
  理由：开头写姓名和官职，“韩令”用姓带职，末句径以官名称他。
- [ ] 两人，因为韩方和韩令末字不同 {#q.h28.check.5.o3}
  理由：令是官名，前面已写他是县令。

提示：看看接受书吏禀告的人的姓和官。
解析：开头写姓名和官职，“韩令”用姓带职，末句径以官名称他。

## 原文：教学例句 {#p.h28.check.6}
> 吏甲典仓，乙典簿。守令乙按去年出粟之数，乙持旧券来，所记皆合。
译文：甲吏掌管仓库，乙吏掌管簿籍。郡守命乙查验去年发粮的数量，乙拿着旧凭据过来，记录都相符。

## 单选：郡守叫乙“按去年出粟之数”，乙要做什么？ {#q.h28.check.6}
考点：skill.h28.3.an-inspect
语境：p.h28.check.6

- [ ] 要求甲重新发粮 {#q.h28.check.6.o1}
  理由：查的是“去年”的数。
- [x] 凭旧记录核验发粮数 {#q.h28.check.6.o2}
- [ ] 亲自搬运全部库存 {#q.h28.check.6.o3}
  理由：乙带来的物是旧券。

提示：乙带来了“旧券”，后来又说“所记皆合”。
解析：乙拿旧凭据核对去年的放粮记录，发现数目相符。这就是郡守要他做的查验。
