# 检查：他们为什么担心，又为什么改了主意 {#check.28}

## 原文：教学例句 {#p.vocab.check.28.1}
> 山客恐雨涨溪，早去。至溪，水已及桥面，幸有舟，乃得归。
译文：山客担心下雨使溪水上涨，提早出发。到了溪边，水已漫到桥面，幸亏有船，才得以回家。

## 单选：山客临出门时，已经知道溪水涨到桥面了吗？ {#q.vocab.check.28.1}
考点：skill.vocab.22.3
语境：p.vocab.check.28.1

- [ ] 他笃定不会涨水 {#q.vocab.check.28.1.o1}
  理由：他正是担心水涨才早早出发。
- [ ] 出门时已亲眼看清桥面 {#q.vocab.check.28.1.o2}
  理由：“至溪”以后才见到水位，出门时心里还只是担心。
- [x] 当时只是担心上涨，见水在后 {#q.vocab.check.28.1.o3}

提示：“恐雨涨溪”和“至溪，水已及桥面”发生在什么时候？
解析：出门时山客担心水涨，到了溪边才亲眼看见水已及桥。

## 单选：桥面已经被水漫到，山客靠什么才得以回家？ {#q.vocab.check.28.2}
考点：skill.vocab.22.1
语境：p.vocab.check.28.1

- [ ] 他没有看见溪水 {#q.vocab.check.28.2.o1}
  理由：他来到溪边已经见到。
- [ ] 桥面积水 {#q.vocab.check.28.2.o2}
  理由：水及桥面反而阻行。
- [x] 溪边有船 {#q.vocab.check.28.2.o3}

提示：“幸”字接着写了溪边的什么东西？
解析：溪边恰好有船，他才得以渡过涨水的溪流回家。

## 原文：教学例句 {#p.vocab.check.28.2}
> 新吏请改旧券，众异其议。吏陈旧券之弊，长者善之，众亦以为可。
译文：新官吏提议改换旧凭券，众人觉得他的建议奇特。官吏陈述旧券的弊病，长者赞同，众人也觉得可行。

## 单选：新吏刚提改券时，众人怎样看他的主意？ {#q.vocab.check.28.3}
考点：skill.vocab.23.3
语境：p.vocab.check.28.2

- [x] 觉得此议与平常不同 {#q.vocab.check.28.3.o1}
- [ ] 立即动手换券 {#q.vocab.check.28.3.o2}
  理由：此时还在讨论。
- [ ] 已知券上有假字 {#q.vocab.check.28.3.o3}
  理由：文中没说有假字。

提示：留意最初的“异其议”与后来的“亦以为可”。
解析：大家起初觉得改券的提议不同寻常，听过理由才同意。

## 单选：“长者善之”，长者赞同的是什么？ {#q.vocab.check.28.4}
考点：skill.vocab.23.4
语境：p.vocab.check.28.2

- [x] 新吏提出并说明理由的改券建议 {#q.vocab.check.28.4.o1}
- [ ] 旧券的弊病本身 {#q.vocab.check.28.4.o2}
  理由：听过旧券的毛病以后，长者赞成的是把它改一改。
- [ ] 长者自己的命令 {#q.vocab.check.28.4.o3}
  理由：提议出自新吏；长者是在听过他的理由后表态。

提示：谁在前一句讲了旧券的毛病？最初又提过什么办法？
解析：新吏提议改券，又解释旧券的弊端，长者认可的是这个提议。

## 原文：教学例句 {#p.vocab.check.28.3}
> 旧架载书，木已蠹，不胜其重。童易之，仍加一箧，架裂。师令减半，乃足以承书。
译文：旧书架已被虫蛀，承受不住书的重量。孩子不当回事，又加上一箱，架子裂了。老师让搬走一半，剩下的书它才承受得住。

## 单选：旧书架“不胜其重”，是说书和架子之间出了什么问题？ {#q.vocab.check.28.5}
考点：skill.vocab.24.1
语境：p.vocab.check.28.3

- [ ] 书多得数不清 {#q.vocab.check.28.5.o1}
  理由：“其重”指重量。
- [ ] 孩子在举重中落败 {#q.vocab.check.28.5.o2}
  理由：此处是木架载书。
- [x] 书的重量超过旧架的承受能力 {#q.vocab.check.28.5.o3}

提示：旧架的木头已经被虫蛀了。
解析：架子已经虫蛀，原有书的分量就超过了它能承受的重量。

## 单选：孩子起初怎样看这副书架，结果又做了什么？ {#q.vocab.check.28.6}
考点：skill.vocab.24.4
语境：p.vocab.check.28.3

- [x] 低估危险，又加了一箱 {#q.vocab.check.28.6.o1}
- [ ] 觉得已满，主动搬走一半 {#q.vocab.check.28.6.o2}
  理由：减半是老师后来命令的。
- [ ] 发现虫蛀，立刻换架 {#q.vocab.check.28.6.o3}
  理由：他继续往上加书。

提示：从“童易之”一直读到“仍加一箧”。
解析：他没把旧架的危险放在心上，又放上一箱书，书架便裂了。
