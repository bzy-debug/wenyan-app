## 原文：古籍引文 {#p.check.19.a}
> 有朋自远方来，不亦乐乎？注：包曰：“同门曰朋。”……音义：“……有或作友，非。……”

## 单选：给自己的注释加署名，哪一种写法可信？ {#q.check.19.1}
考点：skill.l5.7
语境：p.check.19.a

- [ ] 孔子在这句话里亲自把朋定义为同门 {#q.check.19.1.o2}
  理由：定义出现在“注：包曰”之后。
- [x] 包注以“同门”解释经文中的“朋” {#q.check.19.1.o1}
- [ ] 包注判“友”字错误 {#q.check.19.1.o3}
  理由：“非”出现在接下来的音义中。

提示：先分清经文、注、音义的边界。
解析：“同门曰朋”只应按包注引用，不可改为孔子在经文中的原话。

## 单选：“有或作友，非”包含哪两层信息？ {#q.check.19.2}
考点：skill.l5.8
语境：p.check.19.a

- [ ] 证明所有抄本都写“友” {#q.check.19.2.o3}
  理由：“或”只报告某些写法，与“所有”不同。
- [ ] 先介绍友善的美德，再赞同所有版本 {#q.check.19.2.o2}
  理由：“或作”说字面，“非”表否定判断。
- [x] 报告另一写法，并表示不赞同这一写法 {#q.check.19.2.o1}

提示：把“或作”和“非”分别落实。
解析：有异文记录并且有取舍态度。记校语时要把两层都保留下来。

## 原文：古籍引文 {#p.check.19.b}
> 使民以时。注：包曰：“作事使民，必以其时，不妨夺农务。”音义：“道，音导，本或作导，包云治也。……”
译文：役使民众要合乎时节。包注说安排事务及役使百姓要避开农务。音义另对本章前文的“道”注音为导，记有本作“导”，并记包氏释为治。

## 单选：“包云治也”与“本或作导”分别解决什么问题？ {#q.check.19.3}
考点：skill.l5.8
语境：p.check.19.b

- [x] 前者说明词义，后者记录传本写形 {#q.check.19.3.o1}
- [ ] 两者都证明应将正文所有“道”改成“治” {#q.check.19.3.o3}
  理由：“本或作”说“导”，释义也不等于直接改字。
- [ ] 前者指定官职，后者写明刊刻年份 {#q.check.19.3.o2}
  理由：“治”是所训之义，两处都没有年份。

提示：分清“云……也”与“作某”的术语。
解析：音、义、字形可同记在一条音义中，摘录时须明确证据类别。

## 单选：单引“使民以时”四字经文后，怎样补上注文的理解？ {#q.check.19.4}
考点：skill.l5.7
语境：p.check.19.b

- [ ] 经文直接列举了播种、收割的月份 {#q.check.19.4.o2}
  理由：经文只说“以时”，没有列任何月份。
- [x] 包注把“以时”具体解释为避免妨夺农务 {#q.check.19.4.o1}
- [ ] “不妨夺农务”属于孔子原句的下半截 {#q.check.19.4.o3}
  理由：底本明用“注：包曰”换了层次。

提示：找“以时”在注文中的展开。
解析：可借包注说明时与农事的关系，摘引时仍须区分经与注。

## 单选：以两次“见”所引的对象为线索，哪个主干句界最稳妥？ {#q.check.19.5}
考点：skill.l5.9
语境：p.check.19.c

- [ ] 见贤思齐焉见／不贤而内自省也 {#q.check.19.5.o3}
  理由：第二个“见”需要后面的“不贤”作对象。
- [ ] 见贤思／齐焉见不贤／而内自省也 {#q.check.19.5.o2}
  理由：“思齐”是想要看齐；拆开后两套行为难以对应。
- [x] 见贤思齐焉／见不贤而内自省也 {#q.check.19.5.o1}

提示：分辨“见贤”和“见不贤”各带来的反应。
解析：两组分别写见到谁、自己如何调整；“焉”处收住第一组。

## 单选：哪一组对应最能说明并非要求读者“看见别人就责备别人”？ {#q.check.19.6}
考点：skill.l5.9
语境：p.check.19.c

- [x] 思齐／内自省，都指向读者自身的行动 {#q.check.19.6.o1}
- [ ] 见／见，表示只须旁观，不必反省 {#q.check.19.6.o3}
  理由：末端已有“自省”。
- [ ] 贤／不贤，这就表示必须公开批判他人 {#q.check.19.6.o2}
  理由：二者是所见对象，之后的动词才写应如何行动。

提示：把每个“见”的后半部分单列出来。
解析：看齐是改善自己，内省也是审视自己。正确的句界使这层共同指向清楚可见。
