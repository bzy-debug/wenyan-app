## 原文：古籍引文 {#p.check.19.a}
> 有朋自远方来，不亦乐乎？注：包曰：“同门曰朋。”……音义：“……有或作友，非。……”
译文：有同道从远方来，不也令人高兴吗？包氏注说，同门叫作“朋”。音义又记有本子把“有”写成“友”，并评说这写法不妥。

## 单选：给“同门曰朋”注明是谁的说法，哪一种署法合乎原书？ {#q.check.19.1}
考点：skill.l5.7
语境：p.check.19.a

- [ ] 孔子在这句话里亲自把朋定义为同门 {#q.check.19.1.o2}
  理由：定义出现在“注：包曰”之后。
- [x] 包注以“同门”解释经文中的“朋” {#q.check.19.1.o1}
- [ ] 包注判“友”字错误 {#q.check.19.1.o3}
  理由：“非”出现在接下来的音义中。

提示：找这四个字之前离它最近的“曰”。
解析：“同门曰朋”是包氏注对“朋”的解释，引用时应归在包注名下。

## 单选：“有或作友，非”这么短，既记了什么，又评了什么？ {#q.check.19.2}
考点：skill.l5.8
语境：p.check.19.a

- [ ] 证明所有抄本都写“友” {#q.check.19.2.o3}
  理由：“或”只报告某些写法，与“所有”不同。
- [ ] 先介绍友善的美德，再赞同所有版本 {#q.check.19.2.o2}
  理由：“或作友”记下看到的字，“非”才是编者不赞同的口气。
- [x] 报告另一写法，并表示不赞同这一写法 {#q.check.19.2.o1}

提示：先读“或作”，再单读末尾的“非”。
解析：音义先记有本写作“友”，又说这种写法不妥。只写其中一句，会漏掉另一层。

## 原文：古籍引文 {#p.check.19.b}
> 使民以时。注：包曰：“作事使民，必以其时，不妨夺农务。”音义：“道，音导，本或作导，包云治也。……”
译文：役使百姓要选合适的时节。包氏注说，让百姓做事，务必避开农忙。音义又回头解释本章前面的字：“道”读作“导”，有本子也写作“导”，包氏解为治理。

## 单选：“包云治也”和“本或作导”，一条说义，一条说字，怎样分？ {#q.check.19.3}
考点：skill.l5.8
语境：p.check.19.b

- [x] 前者说明词义，后者记录传本写形 {#q.check.19.3.o1}
- [ ] 两者都证明应将正文所有“道”改成“治” {#q.check.19.3.o3}
  理由：异文是“导”，包氏以“治”解“道”。后一个字是解释，不是校者叫你换上的字。
- [ ] 前者指定官职，后者写明刊刻年份 {#q.check.19.3.o2}
  理由：包注说“治”，是讲这个字什么意思。这里并未说明何年刊刻。

提示：“云……也”是在解词，“作”后面跟的是什么？
解析：包氏以“治”解释“道”；“本或作导”记的是另一本的写法。两句话不能都当作改字命令。

## 单选：经文只写“使民以时”，包注怎样讲清楚这个“时”？ {#q.check.19.4}
考点：skill.l5.7
语境：p.check.19.b

- [ ] 经文直接列举了播种、收割的月份 {#q.check.19.4.o2}
  理由：经文只说“以时”，没有列任何月份。
- [x] 包注把“以时”具体解释为避免妨夺农务 {#q.check.19.4.o1}
- [ ] “不妨夺农务”属于孔子原句的下半截 {#q.check.19.4.o3}
  理由：“不妨夺农务”的前面有“注：包曰”，说详细话的是注家。

提示：什么时候役使百姓，会妨碍他们原有的事？
解析：包氏以不耽误农务解释“以时”。可以借他的注读经，也要让读者知道“不妨夺农务”是谁的话。

## 单选：把两次“见”分别接上各自的对象，最该在哪里断开？ {#q.check.19.5}
考点：skill.l5.9
语境：p.check.19.c

- [ ] 见贤思齐焉见／不贤而内自省也 {#q.check.19.5.o3}
  理由：第二个“见”需要后面的“不贤”作对象。
- [ ] 见贤思／齐焉见不贤／而内自省也 {#q.check.19.5.o2}
  理由：“思齐”是想要看齐；拆开后两套行为难以对应。
- [x] 见贤思齐焉／见不贤而内自省也 {#q.check.19.5.o1}

提示：“见贤”和“见不贤”之后，各有怎样的反应？
解析：一边见贤而思齐，一边见不贤而反省。到“焉”处收住第一组，两句就都能念通。

## 单选：见到好榜样，或见到不贤的人，各要怎样对待自己？哪两项最能相互印证？ {#q.check.19.6}
考点：skill.l5.9
语境：p.check.19.c

- [x] 思齐／内自省，都指向读者自身的行动 {#q.check.19.6.o1}
- [ ] 见／见，表示只须旁观，不必反省 {#q.check.19.6.o3}
  理由：末端已有“自省”。
- [ ] 贤／不贤，这就表示必须公开批判他人 {#q.check.19.6.o2}
  理由：“贤”“不贤”说看见了怎样的人。自己应怎样做，还要读后面的“思齐”“自省”。

提示：注意每个“见”之后，谁要去做些什么。
解析：“思齐”是自己想向对方看齐，“内自省”是自己反省。两种所见不同，着眼点都在自己身上。
