## 原文：古籍引文 {#p.check.19.a}
> 于蜀，蜀守冰凿离碓，辟沫水之害，穿二江成都之中。
译文：在蜀地，蜀郡郡守冰凿开离碓，避除沫水的祸害，在成都城中开通两条水道。

## 单选：“于蜀，蜀守冰”怎样在古地图旁标注？ {#q.check.19.1}
考点：s.l5.geography
语境：p.check.19.a

- [ ] 把“蜀守冰”三字全标作一条河 {#q.check.19.1.o2}
  理由：后面“凿”“辟”“穿”要有主持者。
- [x] 先标蜀地，再写当地郡守冰主持工程 {#q.check.19.1.o1}
- [ ] 写冰层守住了蜀地 {#q.check.19.1.o3}
  理由：“守”在这里指郡守，后面的“冰”是人名。

提示：这一句由区域转到做事的人。
解析：“于蜀”定位，“蜀守”是职称，“冰”才是受此称的人。

## 找原文证据：哪几个字直接说两条水道与城的关系？ {#q.check.19.2}
考点：s.l5.geography
语境：p.check.19.a

- [ ] 凿离碓 {#q.check.19.2.o3}
  理由：这里说施工处的一项开凿。
- [ ] 沫水之害 {#q.check.19.2.o2}
  理由：这里说明要避免的水患。
- [x] 成都之中 {#q.check.19.2.o1}

提示：找“穿二江”之后的地点。
解析：“成都之中”说明水道穿行的地方。

## 单选：若下文改称项羽，为什么不用添一张人物卡？ {#q.check.19.3}
考点：s.l5.naming
语境：p.check.19.b

- [x] 项籍字羽，仍是同一人 {#q.check.19.3.o1}
- [ ] “字羽”是给下一代取名 {#q.check.19.3.o3}
  理由：主语仍是篇首先介绍的项籍。
- [ ] 下相是他另一个名字 {#q.check.19.3.o2}
  理由：“人也”说明下相是籍贯。

提示：把姓、名和字分别填入一行。
解析：“项”配“籍”是姓名；以姓配字称“项羽”仍指传主。

## 单选：这里的“年二十四”该记在哪一栏？ {#q.check.19.4}

语境：p.check.19.b

## 单选：收信人是杓直还是梦得？哪种判断有据？ {#q.check.19.5}
考点：s.l5.address
语境：p.check.19.c

- [ ] 同时上奏给两位皇帝 {#q.check.19.5.o3}
  理由：“足下书”说的是来往书信，未见称臣或奏事。
- [ ] 写给梦得，杓直只是驿站 {#q.check.19.5.o2}
  理由：“杓直足下”在信首直接称呼对方。
- [x] 写给杓直，梦得是前一封信的转递来处 {#q.check.19.5.o1}

提示：辨明开头的称呼和“于……处”的作用。
解析：信首称杓直；“于梦得处得”另交代一次收信的途径。

## 单选：“意皆勤厚”的“皆”，据本段最稳妥地指什么？ {#q.check.19.6}
考点：s.l5.address
语境：p.check.19.c

- [x] 对方先后两封来信的情意 {#q.check.19.6.o1}
- [ ] 朝廷下达的两道尊号 {#q.check.19.6.o3}
  理由：这里谈收信，没谈礼部。
- [ ] 杓直、梦得各写一封 {#q.check.19.6.o2}
  理由：前一次也称“足下前一次书”，写信人未变。

提示：两次“得”后面各收到了谁的什么？
解析：两封都是“足下”的信，只是到达的途径有别。
