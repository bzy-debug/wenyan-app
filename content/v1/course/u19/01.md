# 课文：“河内”“山东”在谁的地图上？ {#l5.7}
简介：跟着梁惠王搬粮，再听范增讲沛公入关前后的变化。

## 正文

梁惠王的“河”指黄河，河内、河东是战国魏国所辖的两个区域。先在纸上只写这两个名字；哪里歉收，就看看人往哪边移、粮食又往哪边运。

再读楚汉之际的“山东”，参照的是崤山以东一带，不能照今天山东省的边界来画。在只想弄清一席话时，认出“山东”和“入关”的前后对照，常比记一个现代城市名更管用。

## 知识点：用原文中的方位和时代理解古地名 {#s.l5.geography}
义项：用原文中的方位和时代理解古地名
领域：文化背景
要诀：保留地名，再画人和物的去向
讲解：古代区域名有时以山、河、关隘为参照。先读文中与它相对的地方及往来的动词，再决定需查哪一时代的地图。
例句：p.l5.7.example
复习题：q.l5.7.1 q.l5.7.3 q.l5.7.5 q.l5.7.7

## 原文：教学例句 {#p.l5.7.example}
> 客自河东来，其家犹在河东。
译文：客人从河东来，家还在河东。这里的河东是区域名；“自”和“在”分别说明来处和所在。

## 原文：古籍引文 {#p.l5.7.a}
> 河内凶，则移其民于河东，移其粟于河内。河东凶亦然。
译文：河内遇上荒年，就把那里的百姓迁往河东，把粮食运往河内。河东遇上荒年也照这样办理。
词注：凶：年成不好，庄稼歉收。
  粟：谷子，这里泛指粮食。

## 单选：河内荒年时，人和粮分别移往哪里？ {#q.l5.7.1}
考点：s.l5.geography
语境：p.l5.7.a

- [x] 人往河东，粮往河内 {#q.l5.7.1.o1}
- [ ] 人往河内，粮往河东 {#q.l5.7.1.o3}
  理由：这把两处“移”的对象对调了。
- [ ] 人和粮都往河东 {#q.l5.7.1.o2}
  理由：第二个“于”领的是河内。

提示：把“民”和“粟”各用一根箭头连到“于”后的地点。
解析：河东接走一部分百姓，河内收到粮，两个方向相反。

## 找原文证据：哪几个字直接说明粮运到河内？ {#q.l5.7.2}
考点：s.l5.geography
语境：p.l5.7.a

- [ ] 移其民于河东 {#q.l5.7.2.o2}
  理由：这一句写百姓的去向。
- [x] 移其粟于河内 {#q.l5.7.2.o1}
- [ ] 河东凶亦然 {#q.l5.7.2.o3}
  理由：这是说换个地方遇灾也照办。

提示：粮食在原文里叫什么？
解析：“粟”在这里代粮，“于河内”写所到之处。

## 单选：河东遇荒年时，“亦然”怎样落到这张简图上？ {#q.l5.7.3}
考点：s.l5.geography
语境：p.l5.7.a

- [ ] 两地一起迁到第三个区域 {#q.l5.7.3.o3}
  理由：原文只举河内、河东相互调济。
- [ ] 去向照抄不变，仍把粮运出河东 {#q.l5.7.3.o2}
  理由：救荒办法相同，受灾地点已变。
- [x] 两地对调，把部分河东百姓迁往河内、把粮运入河东 {#q.l5.7.3.o1}

提示：这回换了哪个地方歉收？
解析：“亦然”重用办法，按灾地交换人和粮的起讫处。

## 单选：为什么先把“河内”作为区域名处理？ {#q.l5.7.4}
考点：s.l5.geography
语境：p.l5.7.a

- [x] 它能遇荒年、有人有粮，还与河东相对 {#q.l5.7.4.o1}
- [ ] 这是越南现代城市河内的来历 {#q.l5.7.4.o3}
  理由：梁惠王所说的是战国魏地，单凭同名不能跨时代认地。
- [ ] 这里记的是河水内部有无泥沙 {#q.l5.7.4.o2}
  理由：百姓迁徙、调粮不能在“河水里面”理解。

提示：看“河内”能承受什么事。
解析：一地受灾、人与粮在两地间移，这些搭配先确定了地名的性质。

## 原文：古籍引文 {#p.l5.7.b}
> 范增说项羽曰：“沛公居山东时，贪于财货，好美姬。今入关，财物无所取，妇女无所幸，此其志不在小。”
译文：范增劝项羽说：“沛公在崤山以东时贪财好色。如今入关，财物不取，妇女不宠幸，看来他的志向不小。”
词注：说：这里读 shuì，劝说。
  幸：宠幸。这里说沛公没有宠幸女子。

## 单选：哪一对词标出范增所作比较的前后两段？ {#q.l5.7.5}
考点：s.l5.geography
语境：p.l5.7.b

- [ ] 财货／财物 {#q.l5.7.5.o2}
  理由：这两个词指比较的内容，不是两个地点和时段。
- [x] 居山东时／今入关 {#q.l5.7.5.o1}
- [ ] 项羽／沛公 {#q.l5.7.5.o3}
  理由：前后行为说的都是沛公。

提示：留意“时”和“今”各跟什么。
解析：“居山东时”是从前，“今入关”是眼前；在两个处境中对照同一个人。

## 单选：如果按现代行政图只在人口住址栏写“山东省”，会漏掉什么？ {#q.l5.7.6}
考点：s.l5.geography
语境：p.l5.7.b

- [ ] 范增没有比较地点 {#q.l5.7.6.o3}
  理由：两地和时段正是引出行为变化的依据。
- [ ] 沛公的家必定在今天山东省 {#q.l5.7.6.o2}
  理由：“居”写当时身处何处，没有这样精确的籍贯结论。
- [x] 这段话所说的是古代关东与入关的对照 {#q.l5.7.6.o1}

提示：看后面哪个动词表明已越过地理界限。
解析：“入关”需要古代关隘作参照，一省的现代边界不足以说明这句。

## 单选：范增据什么说“其志不在小”？ {#q.l5.7.7}
考点：s.l5.geography
语境：p.l5.7.b

- [x] 同一人入关前后取舍财物等表现判若两样 {#q.l5.7.7.o1}
- [ ] 项羽刚被称为沛公 {#q.l5.7.7.o3}
  理由：项羽是听话人，沛公是受议论的人。
- [ ] 崤山本身很高 {#q.l5.7.7.o2}
  理由：山的高低没有进入这个推断。

提示：问自己这张地图帮你看见了谁的哪种变化。
解析：地名交代前后场合，反常的举止才引出范增的判断。

## 单选：给这一段写读书笔记，哪项保留了说话者？ {#q.l5.7.8}
考点：s.l5.geography
语境：p.l5.7.b

- [ ] 司马迁断言沛公的志向仅限一地 {#q.l5.7.8.o2}
  理由：原文是范增的推测，且说“不在小”。
- [x] 据范增对项羽的说法，沛公入关后举止有变 {#q.l5.7.8.o1}
- [ ] 沛公向项羽自述他在山东的经历 {#q.l5.7.8.o3}
  理由：这是旁人谈论沛公，并非沛公自述。

提示：引语前是谁“说”谁？
解析：历史地名能帮你复原场合，却不能把人物言论直接改作史家的断语。
