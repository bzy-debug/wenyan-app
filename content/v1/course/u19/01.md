# 课文：这句话是孔子说的，还是注家说的 {#l5.7}
简介：读一页《论语注疏》，认清孔子说了哪几个字，又有哪些是后来的注家替读者讲的。

## 正文

### “子曰”和“包曰”隔着什么？

读《论语注疏》，眼前虽只有一页，却不止一个人在说话。“子曰”领出经文里孔子的话；“注：包曰”是何晏等人所集的注中引了包咸的说法；读到“疏：正义曰”，又该听邢昺等疏家怎样讲。本课用引号帮你看清纸本上原由版式分开的层次。

读完一小段，试在纸上左边抄经文，右边记“包注说……”。再问自己：要是告诉别人“这四个字是孔子说的”，应该从哪一边抄？

查字时可直接翻到这里。[諡](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E8%AB%A1)

## 知识点：经注分层 {#skill.l5.7}
义项：辨明经文里的话和注家所说的话
领域：阅读技能
要诀：看“曰”前署了谁
讲解：先读经文说了什么，再看注家是在解哪个字、哪一句。用到注家的话，也把他的名字和“注”字一起记下。
例句：p.l5.7.example
复习题：q.l5.7.1 q.l5.7.2 q.l5.7.5 q.l5.7.8

## 原文：教学例句 {#p.l5.7.example}
> 友问：“雨足乎？”答曰：“田已润。”
译文：朋友问：“雨下够了吗？”对方答：“田土已经湿润了。”你若在旁边添一句“足，够也”，那是你给“足”作的注。

## 原文：古籍引文 {#p.l5.7.a}
> 子曰：“君子不器。”注：包曰：“器者各周其用，至于君子，无所不施。”
译文：孔子说：“君子不拘于一种用处。”包氏的注是这样讲的：一件器具各有它能派上的用场，君子却能应付许多不同的事。

## 单选：想逐字引孔子这一章的原话，应该抄哪一句？ {#q.l5.7.1}
考点：skill.l5.7
语境：p.l5.7.a

- [x] 君子不器 {#q.l5.7.1.o1}
- [ ] 无所不施 {#q.l5.7.1.o3}
  理由：“无所不施”已经在包氏的引号里了。
- [ ] 器者各周其用 {#q.l5.7.1.o2}
  理由：这句在“注：包曰”后，属包氏的解释。

提示：从“子曰”读到“注”字为止。
解析：“君子不器”才是经文。接下来怎样理解器物的用处，是包氏在讲。

## 找原文证据：看到哪两个字，就知道注中要引包氏的说法了？ {#q.l5.7.2}
考点：skill.l5.7
语境：p.l5.7.a

- [ ] 子曰 {#q.l5.7.2.o2}
  理由：“子曰”引出经文中的孔子之言。
- [x] 包曰 {#q.l5.7.2.o1}
- [ ] 至于君子 {#q.l5.7.2.o3}
  理由：到“至于君子”时，包氏早在说话；这里是从器物转到人。

提示：看“曰”字前面写的是谁。
解析：“包曰”是包氏说。引他的解释，应当连同这层来历一起交代。

## 单选：照包注读，器物和君子的分别在哪里？ {#q.l5.7.3}
考点：skill.l5.7
语境：p.l5.7.a

- [ ] 君子禁止百姓使用器物 {#q.l5.7.3.o3}
  理由：“君子不器”评说君子自身，并非向百姓发布禁令。
- [ ] 君子制器时不需工具 {#q.l5.7.3.o2}
  理由：“其用”在谈器物的用途，没有谈制造工艺。
- [x] 器物各有专用，君子所能施展的范围广 {#q.l5.7.3.o1}

提示：先读器物“各周其用”，再读君子“无所不施”。
解析：器物各有自己的用处，君子却能因事而施，不局限于一种用处。包氏这样解“不器”。

## 单选：给“君子不器”做笔记，怎样记才看得出哪些话是包氏解释的？ {#q.l5.7.4}
考点：skill.l5.7
语境：p.l5.7.a

- [x] 经文记“君子不器”，另记包注以器物各有专用来解 {#q.l5.7.4.o1}
- [ ] 仅写“古人都说器物无用” {#q.l5.7.4.o3}
  理由：引文肯定各器有其用，也不能代表所有古人。
- [ ] 把包氏和孔子合写为两位共同说“无所不施” {#q.l5.7.4.o2}
  理由：“子曰”之后还有“注：包曰”。讲话的先后分明，不能把两人合署在同一句话上。

提示：将经文原句和“包注以为……”各写一行试试。
解析：经文很短，解释来自包注。两边各有归属，后来翻笔记还能分清。

## 原文：古籍引文 {#p.l5.7.b}
> 子贡问曰：“孔文子何以谓之文也？”注：孔曰：“孔文子，卫大夫孔圉，文，谥也。”子曰：“敏而好学，不耻下问，是以谓之文也。”
译文：子贡问：“孔文子为什么被称为‘文’？”孔氏在注里说明，他是卫国的大夫孔圉，“文”是谥号。经文里孔子答：“他聪敏好学，不以向下面的人请教为耻，所以称他为‘文’。”

## 单选：“文，谥也”是谁说的？是在经文里，还是在注文里？ {#q.l5.7.5}
考点：skill.l5.7
语境：p.l5.7.b

- [ ] 问话的子贡，正在自答 {#q.l5.7.5.o2}
  理由：子贡的话问到“文也”就收住了。接下来先读注文，稍后才轮到孔子回答。
- [x] “孔曰”所引注文，解释称号的性质 {#q.l5.7.5.o1}
- [ ] 经文中孔子回答的首句 {#q.l5.7.5.o3}
  理由：孔子的回答另有“子曰”领起。

提示：一处作“孔曰”，一处作“子曰”，两处之间还有一个“注”字。
解析：此句属于集解所引的孔氏注。孔子在问答中亲口说的话另由“子曰”领起。

## 找原文证据：问孔文子何以得“文”这个谥，孔子举了哪一实际行为？ {#q.l5.7.6}
考点：skill.l5.7
语境：p.l5.7.b

- [ ] 文，谥也 {#q.l5.7.6.o3}
  理由：这是注文对“文”的性质的说明。
- [ ] 卫大夫孔圉 {#q.l5.7.6.o2}
  理由：卫大夫孔圉是这位人物的身份和姓名；他的行为要到孔子的答话里找。
- [x] 不耻下问 {#q.l5.7.6.o1}

提示：到孔子答话的部分找，别停在孔氏注说的姓名上。
解析：孔子说他好学、肯下问。孔注说卫大夫孔圉，是在说明这个人是谁。

## 单选：给孔文子记名字时，为什么不能把“孔圉”和“文”都登记成生前的名字？ {#q.l5.7.7}
考点：skill.l5.7
语境：p.l5.7.b

- [x] 注把前者作为姓名、后者作为谥号来解释 {#q.l5.7.7.o1}
- [ ] 经文说子贡自号“文” {#q.l5.7.7.o3}
  理由：子贡问的是孔文子，非问自己的称号。
- [ ] 古人不可能同时有名与谥 {#q.l5.7.7.o2}
  理由：同一个人可以有名也有谥。要分开登记，正因为注文把两种称呼讲清了。

提示：从注文里找“谥”字。
解析：人名叫孔圉，“文”却是他的谥。注文特意分成两句说明。

## 单选：假如暂时盖住注文，单读经文仍然能知道什么？ {#q.l5.7.8}
考点：skill.l5.7
语境：p.l5.7.b

- [ ] 他名字的最后一个字是圉 {#q.l5.7.8.o2}
  理由：姓名见注文。
- [x] 孔文子敏而好学，不以向下请教为羞 {#q.l5.7.8.o1}
- [ ] “文”被明确下定义为谥 {#q.l5.7.8.o3}
  理由：经文问称号缘由，但“谥也”这一定义出自注。

提示：遮住“注：孔曰”以后，直到下一个“子曰”才接着读。
解析：敏而好学、不耻下问，还能在孔子的答话里读到。明确写出的姓名及“谥也”的解释都在注里。
