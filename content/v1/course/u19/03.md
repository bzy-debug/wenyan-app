# 课文：脱去标点，用平行句式复原句意 {#l5.9}
简介：面对连续字串，先辨反复出现的结构，再验证停顿是否留下完整意思。

## 正文

### 暂时遮掉句读

做一个简单实验，两次朗读同一行。第一次只圈重复的词，第二次为每组主谓、条件和结果临时划界。若两边还能形成意思相反或层层递进的两句，就把自己的停顿写在纸上。

试读教学例句“见善则从见过则改”。两个“见”引出不同对象，两个“则”各引出反应，这比在行中间凭字数对半切可靠。正式练习的古文刻意隐去内部标点。题目只追问影响句意的关键位置，其余逗号、分号等容许不同处理。

## 知识点：平行句界 {#skill.l5.9}
义项：用复现的句式与述谓完整性判断停顿
领域：句法
要诀：先配成对结构，再试读句界
讲解：在无标点片段中寻找成对的条件与结果、重复的谓语、组织成组的否定。能读通的标点方式不必只有一种。
例句：p.l5.9.example
复习题：q.l5.9.1 q.l5.9.3 q.l5.9.5 q.l5.9.7

## 原文：教学例句 {#p.l5.9.example}
> 客至则启户客去则掩户
译文：客人到来便开门，客人离去便关门。两组“客＋动词＋则＋动作”对应，是停顿的一条依据。

## 原文：古籍引文 {#p.l5.9.a}
> 可与言而不与言失人不可与言而与之言失言知者不失人亦不失言
译文：可以与之交谈却不交谈，便错失了人；不适合与之交谈却对他说，便失了言。明智的人既不会错失人，也不会失言。

## 单选：先不加全部标点。哪一种切分能留下第一种错误的完整结果？ {#q.l5.9.1}
考点：skill.l5.9
语境：p.l5.9.a

- [x] 可与言而不与言／失人／不可与言…… {#q.l5.9.1.o1}
- [ ] 可与／言而不与言失／人不可与言…… {#q.l5.9.1.o3}
  理由：把“可与言”的“言”切开后，后面的对应结构也断了。
- [ ] 可与言而不／与言失／人不可与言…… {#q.l5.9.1.o2}
  理由：“与言失”无法和后面的“失言”构成对应结果。

提示：先找能与“失言”位置相对的两字。
解析：“失人”和“失言”分别给出两种不当选择的后果。关键在于保住这两个动宾组合。

## 单选：若把第二种错误读成“不与言”，漏掉原句哪一项转折？ {#q.l5.9.2}
考点：skill.l5.9
语境：p.l5.9.a

- [ ] 本可相谈，实际也相谈 {#q.l5.9.2.o2}
  理由：第二半以“不可”开头。
- [x] 本不宜与之谈，却实际与之谈 {#q.l5.9.2.o1}
- [ ] 知者一概不与任何人交谈 {#q.l5.9.2.o3}
  理由：结句写两种失误皆能避免。

提示：找第二个“而”后真正发生的动作。
解析：“不可与言而与之言”中的“而”把适宜性和实际行为对举。

## 单选：哪两项并列构成全段结语？ {#q.l5.9.3}
考点：skill.l5.9
语境：p.l5.9.a

- [ ] 与之、知者 {#q.l5.9.3.o3}
  理由：前一个在动作短语内部，后一个开启新主语。
- [ ] 可与、不可与 {#q.l5.9.3.o2}
  理由：这两项开启前面的两组条件。
- [x] 不失人、亦不失言 {#q.l5.9.3.o1}

提示：找“知者”之后的两个否定。
解析：结语用两个不失回扣上文两个失，句法对称与意思相合。

## 单选：整理读书笔记时，哪种对句界的说明可复核？ {#q.l5.9.4}

## 单选：前两组比较里连续出现“地利地利”，应怎样理解？ {#q.l5.9.5}
考点：skill.l5.9
语境：p.l5.9.b

- [ ] 两个“地利”合成四字地名 {#q.l5.9.5.o2}
  理由：两边各有“不如”，提示同型比较。
- [x] 前一个“地利”收住上一比较，后一个开下一比较 {#q.l5.9.5.o1}
- [ ] 一个“地利”必是抄手误重，应当删掉 {#q.l5.9.5.o3}
  理由：两句分别需要宾语和主语，可以先按传文读通。

提示：检查两个“不如”各需要哪两项。
解析：前句是天时对地利，后句是地利对人和，重复恰好把比较接起来。

## 单选：哪一种停顿既保留两个比较，也让后面的举例自成一层？ {#q.l5.9.6}
考点：skill.l5.9
语境：p.l5.9.b

- [ ] 天时不如地／利地利不如人和三里／之城…… {#q.l5.9.6.o3}
  理由：这里的“地利”是一个比较项，“三里之城”是一个名词短语。
- [ ] 天时不如／地利地利不如人／和三里之城…… {#q.l5.9.6.o2}
  理由：最后一个比较项是“人和”；拆出“和”不足以另起。
- [x] 天时不如地利／地利不如人和／三里之城…… {#q.l5.9.6.o1}

提示：留意末端的“人和”和随后出现的长度。
解析：“人和”收束比较，“三里之城”转换为一个有具体规模的例子。

## 单选：查“郭”为外城。在后半段最应把哪两组并读？ {#q.l5.9.7}
考点：skill.l5.9
语境：p.l5.9.b

- [x] 三里之城、七里之郭 {#q.l5.9.7.o1}
- [ ] 人和三里、不胜七里 {#q.l5.9.7.o3}
  理由：三里、七里是城郭规模，不是对人和及胜负的度量。
- [ ] 之郭环、之而不 {#q.l5.9.7.o2}
  理由：前者混入后句动作，后者未形成对应短语。

提示：找相同的“数词＋里＋之＋名物”。
解析：城、郭相对，量词和结构一致，是检验这处句界的第二条证据。

## 单选：“环而攻之而不胜”末尾的“而”透露怎样的关系？ {#q.l5.9.8}
考点：skill.l5.9
语境：p.l5.9.b

- [ ] 只有获胜之后才能围起来 {#q.l5.9.8.o2}
  理由：“不胜”是否定结果，不能理解成先胜。
- [x] 围攻一事与未能获胜之间有转折 {#q.l5.9.8.o1}
- [ ] 两个“而”都是地点名的一部分 {#q.l5.9.8.o3}
  理由：紧邻的“环”“攻”“胜”都是动作或结果。

提示：试给“不胜”前加一个白话连接词。
解析：围起来攻打却未得胜；这个结果使例子能接在前面的比较之后。
