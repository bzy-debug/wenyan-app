# 课文：没有标点，读到哪里停 {#l5.9}
简介：遮去标点，找出两边互相照应的词，试着在一口气能说完的地方停下来。

## 正文

### 这一口气，读到哪里可以停？

先念教学例句“见善则从见过则改”。两个“见”各有对象，两个“则”各带出人的反应。这样读，停顿自有来处，不必数到正中间就断开。

读下面的古文，先圈反复出现的词，看看一边主张什么，另一边与它相应还是相反。再从头念一遍：刚才停下的地方，话说完整没有？题中留下的是需要你判断的句界；有些地方加逗号还是分号，两种都可能说得通。

## 知识点：平行句界 {#skill.l5.9}
义项：借前后相应的句子判断停顿
领域：句法
要诀：念完一边，找另一边相应的话
讲解：没有标点时，可以认重复的动作、成对的条件和结果，也可以认相应的两句否定。讲得清为什么在这里停，比认定只有一种标法更要紧。
例句：p.l5.9.example
复习题：q.l5.9.1 q.l5.9.3 q.l5.9.5 q.l5.9.7

## 原文：教学例句 {#p.l5.9.example}
> 客至则启户客去则掩户
译文：客人来就开门，客人走就关门。前后各有一个“客”和一个“则”，照这两层意思读，就知道该在哪里停。

## 原文：古籍引文 {#p.l5.9.a}
> 可与言而不与言失人不可与言而与之言失言知者不失人亦不失言
译文：可以跟他谈却没谈，是错过了人；不适合跟他谈却谈了，是说错了话。明智的人既不错过人，也不失言。

## 单选：读开头这一长串字。在哪里停，才能说清第一种做法会错失什么？ {#q.l5.9.1}
考点：skill.l5.9
语境：p.l5.9.a

- [x] 可与言而不与言／失人／不可与言…… {#q.l5.9.1.o1}
- [ ] 可与／言而不与言失／人不可与言…… {#q.l5.9.1.o3}
  理由：把“可与言”的“言”切开后，后面的对应结构也断了。
- [ ] 可与言而不／与言失／人不可与言…… {#q.l5.9.1.o2}
  理由：“与言失”无法和后面的“失言”构成对应结果。

提示：后面有个“失言”，前面应有哪两个字与它成对？
解析：第一种错误是“失人”，第二种是“失言”。把这两处各自读完整，动作和结果就能对上。

## 单选：第二种错法里，本来该不该说？实际又说了没有？ {#q.l5.9.2}
考点：skill.l5.9
语境：p.l5.9.a

- [ ] 本可相谈，实际也相谈 {#q.l5.9.2.o2}
  理由：这半句从“不可与言”起，先说的就是本不适宜与他交谈。
- [x] 本不宜与之谈，却实际与之谈 {#q.l5.9.2.o1}
- [ ] 知者一概不与任何人交谈 {#q.l5.9.2.o3}
  理由：结句写两种失误皆能避免。

提示：跟着第二个“而”往下念。
解析：“不可与言”说本来不宜谈，“而与之言”却说真的同他谈了。这一转才带出“失言”。

## 单选：“知者”一出现，前面两种错误分别用哪两句话收住？ {#q.l5.9.3}
考点：skill.l5.9
语境：p.l5.9.a

- [ ] 与之、知者 {#q.l5.9.3.o3}
  理由：“与之”还在说跟谁交谈；读到“知者”，才换成聪明人会怎样做。
- [ ] 可与、不可与 {#q.l5.9.3.o2}
  理由：“可与”“不可与”出现在开头，是分说两种情形。结尾要往“知者”以后找。
- [x] 不失人、亦不失言 {#q.l5.9.3.o1}

提示：找“知者”后面彼此相应的两个“不”。
解析：“不失人，亦不失言”把前面的两种失误各收回来一次。

## 单选：想让别人也听得出你为什么在这里停，怎样说明最有说服力？ {#q.l5.9.4}
考点：skill.l5.9
语境：p.l5.9.a

- [x] 指出“失人／失言”对应，再说明“知者”开启总结 {#q.l5.9.4.o1}
- [ ] 认为教材用了分号，所以其他停顿符号都错 {#q.l5.9.4.o3}
  理由：知道哪里一层意思已尽，再商量这里用逗号还是分号，次序可以分清。
- [ ] 只说底本每隔六字必停 {#q.l5.9.4.o2}
  理由：试问停下来以前，谁做了什么、出了什么错？单数字数答不上这两个问题。

提示：说一说原句哪些字前后相应。
解析：“失人”对“失言”，随后“知者”另起一句总收。句界有了着落，停处用逗号还是分号仍可以讨论。

## 原文：古籍引文 {#p.l5.9.b}
> 天时不如地利地利不如人和三里之城七里之郭环而攻之而不胜
译文：有利时机不如地理优势，地理优势不如人心协同。有一座内城三里、外城七里的城，围攻它却没有取胜。

## 单选：为什么“地利地利”要连写两个“地利”？ {#q.l5.9.5}
考点：skill.l5.9
语境：p.l5.9.b

- [ ] 两个“地利”合成四字地名 {#q.l5.9.5.o2}
  理由：前后各有一个“不如”，分别需要有两样东西拿来比较。
- [x] 前一个“地利”收住上一比较，后一个开下一比较 {#q.l5.9.5.o1}
- [ ] 一个“地利”必是抄手误重，应当删掉 {#q.l5.9.5.o3}
  理由：前一句要说天时不如什么，后一句又要说什么不如人和。两个“地利”各有位置。

提示：两个“不如”前后，各比哪两样东西？
解析：前一个“地利”是上一句拿来比的对象，后一个“地利”接着同“人和”比较。重复有它的用处。

## 单选：应怎样停顿，让两重比较都说完，再开始讲城郭的例子？ {#q.l5.9.6}
考点：skill.l5.9
语境：p.l5.9.b

- [ ] 天时不如地／利地利不如人和三里／之城…… {#q.l5.9.6.o3}
  理由：这里的“地利”是一个比较项，“三里之城”是一个名词短语。
- [ ] 天时不如／地利地利不如人／和三里之城…… {#q.l5.9.6.o2}
  理由：“人和”说众人同心。若把“和”切给下句，前面的比较就没说完。
- [x] 天时不如地利／地利不如人和／三里之城…… {#q.l5.9.6.o1}

提示：“人和”说完，后面换成了哪件有尺寸的东西？
解析：天时不如地利，地利不如人和。到“三里之城”，才从比较转入一座具体的城。

## 单选：“郭”是外城。后文哪两组字适合成对地读？ {#q.l5.9.7}
考点：skill.l5.9
语境：p.l5.9.b

- [x] 三里之城、七里之郭 {#q.l5.9.7.o1}
- [ ] 人和三里、不胜七里 {#q.l5.9.7.o3}
  理由：三里、七里是城郭规模，不是对人和及胜负的度量。
- [ ] 之郭环、之而不 {#q.l5.9.7.o2}
  理由：“环”已经说到围攻的动作了。退回去找两个同是“三里”“七里”起头的短语。

提示：找“几里之什么”这样的两组话。
解析：“三里之城”对“七里之郭”，都先说规模、再说城郭。这里若拆散，就读不出两者相应。

## 单选：“环而攻之而不胜”的末一个“而”，该用怎样的口气读？ {#q.l5.9.8}
考点：skill.l5.9
语境：p.l5.9.b

- [ ] 只有获胜之后才能围起来 {#q.l5.9.8.o2}
  理由：“不胜”是否定结果，不能理解成先胜。
- [x] 围攻一事与未能获胜之间有转折 {#q.l5.9.8.o1}
- [ ] 两个“而”都是地点名的一部分 {#q.l5.9.8.o3}
  理由：紧邻的“环”“攻”“胜”都是动作或结果。

提示：围攻以后，事情如预想的一样吗？
解析：围起来攻打，却未得胜。末一个“而”一转，下文就可以追问：为什么围攻却不能取胜？
