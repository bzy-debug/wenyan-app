# 课文：名丘，字仲尼：一人还是两人？ {#l5.8}
简介：用传记开头认清名、字、旧名和籍贯，避免把一人拆成几人。

## 正文

史书第一次介绍人，有时像填一行短表。“某地人也”先记来处，“字某”接着交代另一称呼。再读下去，若见“其亲名之曰……”或“更名……”，就把原名、后名排成先后，别另添一位传主。

称名习惯可以帮你读，却不能替古人添材料。传中没交代谁取字或哪一年改名，笔记就留空。

## 知识点：根据称名动词辨认同一人的多种称呼 {#s.l5.naming}
义项：根据称名动词辨认同一人的多种称呼
领域：文化背景
要诀：在“名、字、更名”旁写清它们各管哪一项
讲解：传记常把籍贯、名、字挨着写。“名之曰”说给谁取名，“字某”另记其字；“更名”还会带来先后次序。
例句：p.l5.8.example
复习题：q.l5.8.1 q.l5.8.3 q.l5.8.5 q.l5.8.7

## 原文：教学例句 {#p.l5.8.example}
> 里人许宁，字安之，安之少好学。
译文：乡里有个许宁，字安之。后句仍在说许宁年轻时爱学习。

## 原文：古籍引文 {#p.l5.8.a}
> 鲁襄公二十二年而孔子生。生而首上圩顶，故因名曰丘云。字仲尼，姓孔氏。
译文：孔子生于鲁襄公二十二年。据传，他生来头顶中间低陷，所以取名为丘。字仲尼，姓孔。
词注：圩顶：头顶中央低陷。
  字：本名之外的一个称呼，这里是“仲尼”。

## 单选：给孔子建一张称名卡，哪项与原文相合？ {#q.l5.8.1}
考点：s.l5.naming
语境：p.l5.8.a

- [x] 姓孔，名丘，字仲尼 {#q.l5.8.1.o1}
- [ ] 名仲尼，字襄公 {#q.l5.8.1.o3}
  理由：“襄公”用来纪年，“仲尼”前明确是“字”。
- [ ] 姓丘，字孔 {#q.l5.8.1.o2}
  理由：“姓孔氏”和“名曰丘”各有明文。

提示：找三个分别领起称呼的词。
解析：“名曰”“字”“姓”把三项分得很清楚。

## 找原文证据：若有人把“仲尼”当成孔子的另一位老师，哪处可直接纠正？ {#q.l5.8.2}
考点：s.l5.naming
语境：p.l5.8.a

- [ ] 鲁襄公二十二年 {#q.l5.8.2.o2}
  理由：这只交代出生之年。
- [x] 字仲尼 {#q.l5.8.2.o1}
- [ ] 首上圩顶 {#q.l5.8.2.o3}
  理由：这写身体特征，没引出一位老师。

提示：这里没有另起一个人物作主语。
解析：“字仲尼”承接孔子，说明仲尼是他的字。

## 单选：“鲁襄公二十二年”能不能当孔子的年龄？ {#q.l5.8.3}
考点：s.l5.naming
语境：p.l5.8.a

- [ ] 可以，它记孔子改名的年岁 {#q.l5.8.3.o3}
  理由：这里没有“更名”，而是在记出生。
- [ ] 可以，孔子生时已经二十二岁 {#q.l5.8.3.o2}
  理由：后面紧接“孔子生”，足以排除。
- [x] 不能，它借鲁君在位年数记孔子出生之年 {#q.l5.8.3.o1}

提示：留意年数前面是谁的称号。
解析：前面用国君年次作纪年，后面才介绍刚出生的人。

## 单选：这段话说明谁替孔子取了字吗？ {#q.l5.8.4}
考点：s.l5.naming
语境：p.l5.8.a

- [x] 只写他的字是仲尼，没有说取字者是谁 {#q.l5.8.4.o1}
- [ ] 仲尼另替孔子取了字 {#q.l5.8.4.o3}
  理由：“仲尼”本身就是字。
- [ ] 鲁襄公亲自取字 {#q.l5.8.4.o2}
  理由：纪年者不等于取名者。

提示：注意“字仲尼”到底多长。
解析：传文分项明确，取字的人却未交代，不能凭纪年补出。

## 原文：古籍引文 {#p.l5.8.b}
> 司马相如者，蜀郡成都人也，字长卿。少时好读书，学击剑，故其亲名之曰犬子。相如既学，慕蔺相如之为人，更名相如。
译文：司马相如是蜀郡成都人，字长卿。少年喜欢读书，学剑，父母给他取名犬子。后来求学，他仰慕蔺相如的为人，改名相如。
词注：其亲：他的父母。
  更名：改名。“更”读 gēng。

## 单选：这次“字长卿”和“更名相如”各记什么？ {#q.l5.8.5}
考点：s.l5.naming
语境：p.l5.8.b

- [ ] 长卿是改名以前的籍贯 {#q.l5.8.5.o2}
  理由：籍贯另写“蜀郡成都人”。
- [x] 长卿是字，相如是后来改用的名 {#q.l5.8.5.o1}
- [ ] 相如是字，长卿是父母起的名 {#q.l5.8.5.o3}
  理由：父母所取明写“犬子”。

提示：把“字”“名之”“更名”各圈出来。
解析：一人有字，又有名前后的变动，这两条线不要交错。

## 单选：“慕蔺相如之为人”里是哪两个人？ {#q.l5.8.6}
考点：s.l5.naming
语境：p.l5.8.b

- [ ] 长卿仰慕自己的父亲犬子 {#q.l5.8.6.o3}
  理由：“犬子”是他的旧名，不是父亲。
- [ ] 蔺相如改姓司马 {#q.l5.8.6.o2}
  理由：传文说改名，未说改姓，两人也未合为一人。
- [x] 司马相如仰慕蔺相如 {#q.l5.8.6.o1}

提示：谁后来才把自己的名改成“相如”？
解析：“慕”要有被仰慕的对象；同用“相如”二字不等于同一人。

## 找原文证据：如果要给“犬子是旧名”找直证，抄哪一处？ {#q.l5.8.7}
考点：s.l5.naming
语境：p.l5.8.b

- [x] 其亲名之曰犬子 {#q.l5.8.7.o1}
- [ ] 字长卿 {#q.l5.8.7.o3}
  理由：这只交代字。
- [ ] 蜀郡成都人也 {#q.l5.8.7.o2}
  理由：这是籍贯。

提示：谁给传主起了这个名？
解析：“其亲”是父母，“之”指传主，“名……曰”交代所取之名。

## 排序：排出传主名字来历中的三件事。 {#q.l5.8.8}
考点：s.l5.naming
语境：p.l5.8.b

- [2] 他学习后，仰慕蔺相如的为人 {#q.l5.8.8.o2}
  理由：“既学，慕……”在取旧名之后，说明了为什么想改。
- [3] 他把自己的名改为相如 {#q.l5.8.8.o3}
  理由：“更名”是仰慕蔺相如之后的行动。
- [1] 父母给他起名犬子 {#q.l5.8.8.o1}
  理由：“少时”接父母给他起名，是回忆的起点。

提示：先把篇首介绍用的“司马相如者”挪开，只看少年时代起的叙述。
解析：篇首先用后来的通行称呼介绍传主；回叙从“犬子”这个旧名开始。
