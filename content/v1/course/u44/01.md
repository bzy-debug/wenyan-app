# 课文：先把来信和回信摆对 {#prose44.1}
简介：从“足下”“仆”认出当面称谁，再听一位想自荐的人为何先问“难道还没找到吗”。

## 正文

信里说“辱赐书”，来信是对方写给我的。“辱”是收信一方客气，不能因此把这封信读成骂人的信。眼前正在读的，则可能是我给对方的回信。

写信的人未必一开口就提出所求。先承认对方的好意，再说自己为什么办不成；先问对方能不能找到人，再转到自己的处境。读到后段，回头看看开头的问话是否另有用意。

## 知识点：在往还书信中分清自称、称人和两封信的去向 {#prose44.mail}
义项：用称谓和收发动作分清谁写给谁
领域：篇章
要诀：找“奉、赐、报”所指的是哪一封。
讲解：若你来信借书，我回信说“足下所求，仆已封之”，求书的是你，封好书的是我。两个称呼分居两端。
例句：prose44.ex.mail

## 原文：教学例句 {#prose44.ex.mail}
> 足下前书问稻事，仆今具答。
译文：您上一封信问稻田的事，我现在详细回复。

## 知识点：从客气话和下文辨出写信所求或所辞 {#prose44.intent}
义项：以接下来的理由、请求校正字面语气
领域：篇章
要诀：问候以后，作者终于要对方做什么？
讲解：“倘有余刻”只看字面是设想对方有闲。后面若接“愿为一正”，这才知道前面在给请人改稿留余地。
例句：prose44.ex.intent

## 原文：教学例句 {#prose44.ex.intent}
> 岂敢劳君？然道远无人，愿为寄此书。
译文：哪里敢劳烦您呢？不过路远找不到人，还是希望您帮忙寄这封信。

## 原文：古籍引文 {#prose44.1.p.ren}
> 太史公牛马走司马迁再拜言，少卿足下：曩者辱赐书，教以顺于接物，推贤进士为务。意气懃懃恳恳，若望仆不相师，而用流俗人之言。仆非敢如此也。
译文：自谦如牛马般奔走的太史公司马迁再次拜上，奉告少卿：承蒙您先前给我写信，教我要善于待人接物，以推荐人才为要务。您情意恳切，好像埋怨我没有遵从您的教导，却听信世俗人的话。我不敢这样做。

## 单选：“曩者辱赐书”说的是哪一封信？按时间把收信人写在这信和眼前回信上。 {#prose44.1.q1}
考点：prose44.mail
语境：prose44.1.p.ren

- [ ] 前信寄少卿，如今少卿才写信给太史公
  理由：开头是太史公自署，“少卿足下”是他对眼前收信人的称呼。
- [x] 少卿先前写给司马迁，如今司马迁回信给少卿
- [ ] 少卿以后才会来信；司马迁正在请他赐教
  理由：“曩者”把来信放在过去；后面已经说出了信中所教的内容。

提示：“曩者”把收到对方来信放在哪一个时候？眼前署名“再拜言”的又是谁？
解析：司马迁以“曩者”追述先前受信，再向少卿致答。如果把它读成“将来”，当时就不应已有信中的劝告可供转述。

## 单选：有人把这段转述为“任少卿来信，明说司马迁听信流俗”。哪一字提醒你，这样写得太满？ {#prose44.1.q2}
考点：prose44.intent
语境：prose44.1.p.ren

- [ ] “仆”，说明所埋怨的是少卿的仆役
  理由：司马迁用“仆”称自己。
- [ ] “辱”，说明先前是一封当面辱骂的信
  理由：这里是对收信的谦辞，不是对骂信内容的描述。
- [x] “若”，这是司马迁从对方口气中体会到的埋怨

提示：区分前半明确转述的劝告和后来猜到的责备。
解析：“教以”直述来信怎样劝人；“若望仆”才转到司马迁觉得对方似乎在埋怨什么。

## 原文：古籍引文 {#prose44.1.p.han}
> 愈虽不才，其自处不肯后于恒人。閤下将求之而未得欤？古人有言：“请自隗始。”愈今者惟朝夕刍米仆赁之资是急，不过费閤下一朝之享而足也。
译文：韩愈虽然不才，说到自期也不肯落在常人之后。阁下莫非还没找到要寻的人？古人说过：“请从我郭隗开始。”我眼下急需的只是日常草料、米粮和雇用仆人的费用，不过花费阁下一顿饭的用度就够了。

## 单选：韩愈问“閤下将求之而未得欤”，紧接着提郭隗和自己的用度，想让收信人怎样做？ {#prose44.1.q3}
考点：prose44.intent
语境：prose44.1.p.han

- [x] 把自己也看作可礼遇的人，给他眼下所需的资助
- [ ] 算清阁下平日的开支，再替他管理饮食
  理由：“愈今者……是急”把急用放回韩愈本人身上。
- [ ] 托韩愈去外地寻郭隗，找到才给旅费
  理由：郭隗是“古人”，他的旧事用来说明眼前的自荐。

提示：谁在问寻人，下一句又把谁搬到收信人面前？
解析：韩愈不径说“请用我”，而从“是否尚未得人”引到“请自隗始”，随后把自己的需要说清。

## 单选：信里出现“愈”“閤下”“隗”。谁是眼前相称的两方？ {#prose44.1.q4}
考点：prose44.mail
语境：prose44.1.p.han

- [ ] 韩愈同时给郭隗、于襄阳两人写信
  理由：郭隗是被援引的古人，并非第二位收件人。
- [x] “愈”是写信人，“閤下”是他称呼的收信人
- [ ] 郭隗写给韩愈，称韩愈为阁下
  理由：“古人有言”引的才是郭隗的话，随后又回到“愈今者”。

提示：把古人说过的一句暂用括号括起来。
解析：开头“愈虽不才”和后文“愈今者”都是韩愈自称；“閤下”始终朝向于襄阳。

## 原文：教学例句 {#prose44.1.p.copy}
> 足下前以孤本见寄，戒仆勿示人。仆已录毕，谨封还之。昨有客求观，仆以足下之戒辞，幸勿疑。
译文：您先前寄来孤本，叮嘱我不要给别人看。我已抄完，恭敬地封好奉还。昨日有人求看，我以您的嘱咐为由谢绝，希望您别疑心。
词注：孤本：存世稀少、此处只得一部的书。
  见寄：寄给我。
  辞：谢绝。

## 单选：若要登记孤本的来去，把哪两次交接写进簿中才有凭据？ {#prose44.1.q5}
考点：prose44.mail
语境：prose44.1.p.copy

- [ ] 仆收到书后让客人翻阅，客人又替仆归还
  理由：客人求观时被谢绝，没有接到书。
- [ ] 足下把书寄给客人，客人转给仆抄写
  理由：“足下前以孤本见寄”里“见寄”是寄给写回信的人。
- [x] 足下先寄给仆，仆抄完封还足下

提示：分开“见寄”“封还”和停在请求上的“求观”。
解析：同一部孤本从足下到仆，再由仆封还。客人只提过请求，不能把他填成经手人。

## 单选：为什么写过“谨封还之”，还要多说一段客人求观的事？ {#prose44.1.q6}
考点：prose44.intent
语境：prose44.1.p.copy

- [ ] 责问主人为何让客人来索书
  理由：原文只说有客求观，未说由主人派来。
- [x] 说明自己守了不示人的约，请对方放心
- [ ] 借客人的名义再求多留几天
  理由：已经“封还”，没有提出延期。

提示：把最后“幸勿疑”接回信首的叮嘱。
解析：寄主最牵挂的是不让旁人看。叙述确曾拒客，才说明受托的人怎样守住了这条约定。

## 原文：教学例句 {#prose44.1.p.bells}
> 少游足下，承示新作，命仆删其繁。仆既读之，有二句未安，别纸具陈。若谓仆尽可其文，则过矣。
译文：少游足下，承蒙您把新作给我看，让我删去繁冗处。我已经读过，有两句觉得不妥，另纸详说。如果以为我全都赞同这篇文章，那就错了。
词注：承示：承蒙您给我看。
  具陈：详细说明。
  可其文：认可这篇文章。

## 单选：“命仆删其繁”中，原稿是谁写的，谁受托删改？ {#prose44.1.q7}
考点：prose44.mail
语境：prose44.1.p.bells

- [ ] 回信人写原稿，请少游删改
  理由：“承示新作”表明回信人是收到稿子的一方。
- [ ] 两人托另一名仆人改稿
  理由：紧接的“仆既读之”仍是写信人叙述自己的动作。
- [x] 少游写原稿，自称“仆”的回信人受托删改

提示：“足下”与“仆”在这一句各处在哪一端？
解析：开头用“足下”称少游，谢他示稿。受“命”的“仆”正是眼前报告读后意见的人。

## 找原文证据：回信开头很客气。哪一句最能防止少游把它当成毫无保留的赞许？ {#prose44.1.q8}
考点：prose44.intent
语境：prose44.1.p.bells

- [x] 有二句未安
- [ ] 承示新作
  理由：收到了新作，不等于赞同每一句。
- [ ] 别纸具陈
  理由：这交代意见写在哪里，没有说明意见好坏。

提示：找写信人点明具体保留意见的地方。
解析：指出两句不妥，是实际读后意见。末句又明说不能把来信读成全篇认可。
