# 检查：一封答书与一篇桥序 {#check.44}

## 原文：教学例句 {#check.44.p.seed}
> 承足下寄粟种一囊，命仆试诸坂田。仆已付耕者赵翁，秋当报其获。足下欲即以多收闻于郡，得毋早乎？
译文：承蒙您寄来一袋谷种，要我在坡田试种。我已交给种田的赵老翁，到秋天应当回报收成。您想立刻把丰收的消息报给郡里，恐怕早了吧？
词注：坂田：坡地上的田。
  报其获：报告实收多少。
  闻于郡：使郡里知道。

## 单选：同一袋谷种先后到了谁手中？谁在眼前的回信中说明这件事？ {#check.44.q1}
考点：prose44.mail
语境：check.44.p.seed

- [x] 足下寄种给仆，仆再交给种田的赵翁；回信由仆写
- [ ] 仆先交耕者，耕者又把种子转给赵翁
  理由：“耕者赵翁”是同一个人，“耕者”说他做什么，赵翁是对他的称呼。
- [ ] 仆寄种给足下，足下托耕者回复
  理由：“承足下寄”已把寄种的一方写明，回信人说“仆已付”。

提示：对照“足下寄”和“仆已付”里的两个动作。
解析：眼前读到的是回信，信中先追述来种方向，再说种子交给赵翁。叙述只有两次交接。

## 单选：“得毋早乎”表面问早不早，这个人实际上希望足下怎样办？ {#check.44.q2}
考点：prose44.intent
语境：check.44.p.seed

- [ ] 今年不用播种，秋天把原种退还
  理由：试种已交耕者，等的是收获。
- [ ] 赶快报丰收，来信已经保证多收
  理由：“秋当报其获”把可查收成的时间留在秋天。
- [x] 等秋天知道实收，再把消息报上去

提示：种子刚交接，回信约定哪一季才报真实结果？
解析：这个问句婉转劝止眼下的禀报。全文只能保证已交种，尚不保证丰收。

## 原文：教学例句 {#check.44.p.bridge}
> 任生将守西渡，里人饯之，请余为序。昔余过故桥，东岸商舟竞泊，西汀渔火相望；及涨，舟皆徙。乃知昨日之安，不足据为今日之常。书此以赠任生。
译文：任生将去守西渡，乡人设宴送别，请我作序。以前我经过旧桥，东岸商船争着停泊，西边沙洲上渔火遥遥相对；到了涨水时，船都移走了。我才知道昨天的安稳不能认作今天的常态。把这件事写来送给任生。
词注：饯：设宴为远行的人送别。
  汀：水边的平地。
  徙：移走。

## 单选：讲到旧桥和涨水，作者为什么仍把本文称为赠序？ {#check.44.q3}
考点：prose44.occasion
语境：check.44.p.bridge

- [ ] 旧桥刚落成，建桥人请作者记工程年月
  理由：文章说的是昔过故桥，明说“里人饯之”。
- [ ] 商船刚移走，渔民请作者记录渔火的来历
  理由：渔火出现在回忆里，请作者作序的是饯行的乡人。
- [x] 任生将守渡口，乡人送行请作者赠他经验

提示：把开头“将守”同末尾“以赠”相连。
解析：旧游提供赠言的材料；将赴渡口的任生才是眼前写序的缘由。

## 找原文证据：叙过旧桥、船徙之后，哪一句已将一次经历归纳为对守渡者的提醒？ {#check.44.q4}
考点：prose44.turn
语境：check.44.p.bridge

- [ ] 及涨，舟皆徙
  理由：这是水涨后的事件，为接下来的道理提供根据。
- [x] 昨日之安，不足据为今日之常
- [ ] 西汀渔火相望
  理由：写旧游所见，还没有说明应怎样看待渡口。

提示：找可带到另一天、另一个渡口去用的一句。
解析：“乃知”以下从水涨前后得到认识，旧游遂成赠序中给任生的忠告。

## 单选：把旧桥两旁的图景分别补全，哪张图没有移错对象？ {#check.44.q5}
考点：prose44.pair
语境：check.44.p.bridge

- [ ] 两边商船竞泊，东岸另有一队渔人迁往西汀
  理由：下句以“渔火”为主，并没写一队人穿过两岸。
- [x] 东岸是争泊的商船，西汀是相望的渔火
- [ ] 东岸渔火在追逐，西汀众船在互望
  理由：“竞泊”说船，“相望”说灯火，不能倒换。

提示：分别给“竞泊”“相望”圈出本句主语。
解析：两个方位各带一幅景。两句可分别读通，合起来才构成涨水之前的一望。

## 单选：若按时间给旧游分成两幅画，界线应该落在哪里？ {#check.44.q6}
考点：prose44.parallel
语境：check.44.p.bridge

- [x] 一幅并画商舟、渔火，另一幅从“及涨”开始画船的迁移
- [ ] 先画涨水，再画商舟争相到已空的岸边停泊
  理由：“及涨”写在“竞泊”以后，接着是“皆徙”。
- [ ] 先画东岸只有商舟，再画等商舟散去西边才生渔火
  理由：方位的对举没有标出先后。

提示：找真正改变水况和泊船情形的字。
解析：“东岸、西汀”把空间铺开，“及涨”才引出后来。同样是逗号相接，两处关系并不相同。
