# 课文：为什么送他一篇序，为什么给墨池作记 {#prose44.2}
简介：在出行、观物、听人请求之后，找作者哪一天拿起笔，又想改变读者怎样想。

## 正文

篇题中的“序”未必是给一部书写在前面的话。朋友将行，作者也能作一篇序相赠；说完那人的处境，才会明白文字为什么偏在临行时送去。

记一处遗迹，不等于为关于它的传说作保。曾巩看墨池、问旧事，转而讨论王羲之晚年才写得好；这个道理能从晚年书艺来谈，并不需要先把池边的传闻坐实。

## 知识点：用篇末的行期、嘱托或请记辨明作序作记的缘起 {#prose44.occasion}
义项：辨清为谁、在什么事情发生时写
领域：篇章
要诀：把题名放一旁，看看是谁将行或谁请作者动笔。
讲解：若序里说“将之南郡”，受赠人还在出发之际。切勿把序写成他回乡后的功成记录。
例句：prose44.ex.occasion

## 原文：教学例句 {#prose44.ex.occasion}
> 友将赴郡，来告别，赠以此序。
译文：朋友将到郡里任事，来辞别，我写这篇序相赠。

## 知识点：区分记下的行事或见闻与作者由此说出的道理 {#prose44.turn}
义项：读出从一件事转向判断的那一步
领域：篇章
要诀：看看末句判断适用于眼前这次，还是也在劝别人。
讲解：“涉十里，始得泉”在叙路；若接“求之不止，斯有得也”，作者已从自己这趟路想到求索的道理。
例句：prose44.ex.turn

## 原文：教学例句 {#prose44.ex.turn}
> 众沿岸求桥，余独问津，乃得渡。由是知问之不可少也。
译文：众人沿岸找桥，我去问渡口才过得河，由此知道不能少了询问。

## 原文：古籍引文 {#prose44.2.p.dong}
> 燕赵古称多慷慨悲歌之士。董生举进士，连不得志于有司，怀抱利器，郁郁适兹土。吾知其必有合也。董生勉乎哉！
译文：燕赵地方旧称多豪迈悲歌之士。董生应进士举，接连不被主管官员录取，身有才干，郁郁地前往那里。我想他一定有能相合的人。董生，好自勉励吧！

## 单选：这篇序送到董生手边时，什么事已发生，什么仍是韩愈的判断？ {#prose44.2.q1}
考点：prose44.occasion
语境：prose44.2.p.dong

- [x] 考试接连失意已发生，到燕赵能遇相合的人是判断
- [ ] 燕赵已经接纳董生，他归来才获赠序
  理由：“适兹土”与送行相连，“必有合”是在预期。
- [ ] 韩愈也去燕赵应试，托董生给书作序
  理由：“举进士”承着“董生”，称呼“董生勉乎哉”的才是韩愈。

提示：把“连不得志”同“吾知其必”分开。
解析：送别发生在由失意转往燕赵之际。“必”写赠序者的口气，不能拿来当作受赠人后来的履历。

## 找原文证据：原文到哪里由交代董生的遭遇，转成韩愈本人对这趟行程的判断？ {#prose44.2.q2}
考点：prose44.turn
语境：prose44.2.p.dong

- [x] 吾知其必有合也
- [ ] 连不得志于有司
  理由：这还是董生此前的考试遭遇。
- [ ] 郁郁适兹土
  理由：这还是叙述眼前的去向和心境。

提示：找说话人亲自出面、判断以后会怎样的一句。
解析：“吾知”让赠序者的声音显出来，所说是此行可能有怎样的际遇。

## 原文：古籍引文 {#prose44.2.p.ink}
> 羲之之书晚乃善，则其所能，盖亦以精力自致者，非天成也。然后世未有能及者，岂其学不如彼耶？则学固岂可以少哉！
译文：王羲之的书法到晚年才精妙，那么他的本领大概也是靠精力与功夫自己得来的，并非天生。后世无人赶得上他，莫非是学得不如他？如此看来，学习怎能少呢！

## 单选：这段记由羲之的书法转到劝学，哪一步在中间起作用？ {#prose44.2.q3}
考点：prose44.turn
语境：prose44.2.p.ink

- [ ] 先断定后人资质太低，才免去他们的用功
  理由：“岂其学不如彼”正要人回头看学习功夫。
- [x] 把“晚乃善”解释为长期用力的结果，于是追问后人所下的功夫
- [ ] 证明池水变黑的那一天就是羲之学成的日子
  理由：这里依据“晚乃善”，没有记一个确日。

提示：先找“则”接住的事，再看“岂可以少”劝谁。
解析：由晚年进境推想到持续用力，作者才从记羲之一人转为同后人讨论治学。

## 原文：教学例句 {#prose44.2.p.gate}
> 县学西有废射圃，父老指为古讲堂。师曰：“遗址之名未可必，诸生每岁集此读书，则吾所亲见。”请余记之，以告后之来学者。
译文：县学西边有一处废射圃，父老说那是古讲堂。老师说：“遗址的名称不能确定，学生每年来这里读书，却是我亲眼所见。”请我记下来，告诉日后来学的人。
词注：射圃：练习射箭的场地。
  未可必：尚不能断定。
  诸生：这些学生。

## 单选：依老师的嘱托，这则记最后要给谁看，为谁留下什么？ {#prose44.2.q4}
考点：prose44.occasion
语境：prose44.2.p.gate

- [ ] 给县吏看，要求认定古讲堂就是这处射圃
  理由：老师明说“遗址之名未可必”。
- [ ] 给父老看，证明他们从没在这里听过讲
  理由：父老所指未经确定，并未被证明是伪造。
- [x] 给后来读书的人看，留下当下学生在此读书的确切见闻

提示：“请余记之”之后还有一层，为什么要记？
解析：请作者动笔的是老师，文字所向是“后之来学者”；能留下的实据是老师亲见学生来读书。

## 找原文证据：欲给遗址的传说加一条“尚待核实”的批语，原文哪句正是老师自己的判断？ {#prose44.2.q5}
考点：prose44.turn
语境：prose44.2.p.gate

- [ ] 父老指为古讲堂
  理由：这是转述地方说法，未给它划可信范围。
- [x] 遗址之名未可必
- [ ] 诸生每岁集此读书
  理由：这是老师亲见的另一件事。

提示：找老师怎样看待父老所指之名。
解析：老师先对传说保留判断，再交代亲见的学生。对第一件事存疑，不妨碍第二件事可记。

## 原文：教学例句 {#prose44.2.p.east}
> 吴生将赴东郡，过余庐而辞。生以道远为忧。余语以昔闻诸舟人者，书而赠之，欲其审所问，毋以传闻为亲见也。
译文：吴生将去东郡，到我家辞别。他担心路远。我把从前听船夫说的告诉他，写下来相赠，希望他细查所打听到的话，别把传闻当作亲见。

## 单选：如果把这篇赠文题作“吴生归来之后”，哪几个动作便接不上？ {#prose44.2.q6}
考点：prose44.occasion
语境：prose44.2.p.east

- [ ] “书而赠之”表明作者是序中被送走的人
  理由：“过余庐而辞”的是吴生，作者留在家中赠文。
- [ ] “昔闻”表明吴生从前已经走完这趟路
  理由：以前听舟人讲述的是作者，没交代吴生去过。
- [x] “将赴”而来辞别，作者因他的忧虑临行赠言

提示：分别给“辞”和“赠”找出动作的人。
解析：吴生将行，别作者；作者将听来之事写成临别赠文。受赠之时尚无归来可记。

## 单选：作者既讲了舟人的话，又说“毋以传闻为亲见”，是要吴生怎样使用这篇赠文？ {#prose44.2.q7}
考点：prose44.turn
语境：prose44.2.p.east

- [ ] 把每句都当成赠序作者亲自走过、亲眼所见
  理由：作者已明说“昔闻诸舟人”。
- [x] 把它当作可供打听的线索，途中仍须核实
- [ ] 认为舟人从头到尾都在撒谎，不必询问
  理由：叮嘱是“审所问”，没有判传闻必假。

提示：“吾听来”与“你途中亲见”能否相换？
解析：临行赠言的落点在如何核对消息，不在证明每处路况已由作者查过。

> 东野之役于江南也，有若不释然者，故吾道其命于天者以解之。
译文：孟东野到江南任职，好像心里有些放不下，所以我说起他遭际中取决于天命的一面，来宽解他。

## 单选：《送孟东野序》的结尾说明写作缘起。作者怎样看出有必要赠言？ {#prose44.2.q8}
考点：prose44.occasion
语境：prose44.2.p.meng

- [ ] 东野已经来信要求评论自己的文集
  理由：这里有“役于江南”，没有编辑文集或索序的事。
- [x] 东野将去江南，看起来有所郁结，作者想开解他
- [ ] 作者要授予东野江南官职，特地宣读任命
  理由：“以解之”说宽解心事，不是任命官职。

提示：把“若不释然”和“以解之”相接。
解析：受赠者心有所结，赠序者便针对那层不快说话。“有若”没有说东野把每一重顾虑都亲口讲过。
