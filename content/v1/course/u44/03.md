# 课文：对句整齐，两边各在说什么 {#prose44.3}
简介：读江淹写舟和车，再读鲍照写荒城里的井与路，把两句各自的景物、动作和所在连起来。

## 正文

“舟凝滞于水滨，车逶迟于山侧”，齐整，却没有把舟与车放在一起赛快慢。试遮住下句，上句有舟、有停滞、有水边；再遮住上句，车也有自己的所在。

辞赋里常有这样的骈句。排得整齐，并不等于发生得有先有后。作者能让离人的舟车隔地并见，也能让一眼看见的荒井、荒路彼此映衬。什么地方真要排次序，需另有“既”“乃”等字或事理可凭。

## 知识点：沿两句对称位置分别配回主语、动作、处所 {#prose44.pair}
义项：让每一半独立成句，再检查成对处
领域：篇章
要诀：给舟、车或其他主语分别补一行白话。
讲解：读“鹤立于汀，鱼潜于渚”这组对偶，鱼、鹤相对，“立”和“潜”却各有所属；换了动作，画面便不同。
例句：prose44.ex.pair

## 原文：教学例句 {#prose44.ex.pair}
> 帆映于水，雁没于云。
译文：船帆映在水面，大雁消失在云里。

## 知识点：从骈句分辨并写的场景与真正承接的行动 {#prose44.parallel}
义项：成对写出不保证按次序发生
领域：篇章
要诀：找没有时间字也能成立的空间、感受或处境。
讲解：“客宿南亭，子候北桥”先后写在纸上，不能只凭逗号推断孩子等在客人住下以后。
例句：prose44.ex.parallel

## 原文：教学例句 {#prose44.ex.parallel}
> 前溪舟泊，后岭樵归。
译文：前面的溪边泊着船，后面的山岭有人打柴归来。

## 原文：古籍引文 {#prose44.3.p.part}
> 风萧萧而异响，云漫漫而奇色。舟凝滞于水滨，车逶迟于山侧。
译文：风声萧萧，在离人耳中格外异样；云气漫漫，颜色也显得不同。船迟滞在水边，车在山旁缓缓而行。

## 单选：若把后两句画成两幅图，哪种配法两句各自都成立？ {#prose44.3.q1}
考点：prose44.pair
语境：prose44.3.p.part

- [ ] 水上行车，山中横舟
  理由：水滨接在舟句，山侧接在车句，不能交换。
- [x] 水边迟滞的舟，山旁缓行的车
- [ ] 先在水滨弃舟，换一辆车飞驰上山
  理由：两处都写迟缓，也没写同一人换乘。

提示：各读一遍“什么，在何处，怎样了”。
解析：“舟、车”对举，“水滨、山侧”各回到本句，凝滞与逶迟都写出离行之难。

## 单选：车写在舟后，能据此把它们排成同一位旅客的换乘日程吗？ {#prose44.3.q2}
考点：prose44.parallel
语境：prose44.3.p.part

- [ ] 能，“异响”就是车来接船的声音
  理由：前句明说“风萧萧”，没有交代车来接人。
- [ ] 能，凡“于水滨”之后都必须改由陆路
  理由：“于”交代地点，并未通知下一程。
- [x] 不能，这里并写水边和山侧两幅迟行景象

提示：读者看到两个画面，原文有没有让同一个人从一处走到另一处？
解析：并列的处境共同写离情；单凭文句排列建不出换乘经过。

## 找原文证据：“泽葵依井”写植物依傍建筑遗迹。下文哪四个字也由植物起头，而且写到原来的通道？ {#prose44.3.q3}
考点：prose44.pair
语境：prose44.3.p.city

- [ ] 坛罗虺蜮
  理由：这一句落在坛上的毒虫。
- [ ] 阶斗麕鼯
  理由：这一句转到阶前的动物。
- [x] 荒葛罥涂

提示：给“荒葛”的藤找它缠住的东西。
解析：“葛”与“葵”同为植物，“涂”在各自句中与“井”相应。两句各有着落。

## 单选：有人要编一张荒城年表，排作“最初荒草蔓生，第二年毒虫才出现”。这几句能作依据吗？ {#prose44.3.q4}
考点：prose44.parallel
语境：prose44.3.p.city

- [ ] 能，写在前的草木一定比后面的动物出现得早
  理由：句子按处所并置，没有说谁何时最先出现。
- [x] 不能，它按井、路、坛、阶铺开眼前景象，没有分年份
- [ ] 能，“阶”说明已经走到衰败的第二阶段
  理由：“阶”是台阶，同“坛”都是地方。

提示：先给井、涂、坛、阶标成地点或时日。
解析：荒城多处都被草木虫兽占据；把空间次序读成时代次序便添出了年份。

## 原文：教学例句 {#prose44.3.p.inn}
> 江亭夜雨。檐溜鸣阶，远钟度水；行客方收湿笠，居人已掩柴门。鸡鸣而雨歇，客乃出。
译文：江亭夜里下雨。檐水落在阶上作响，远处钟声传过水面；旅客正在收湿斗笠，住户已经掩了柴门。鸡鸣时雨停，客人才出发。
词注：檐溜：从檐口流下的雨水。
  度水：越过水面，这里说声音传来。

## 单选：“檐溜鸣阶，远钟度水”各写什么从哪里传来？ {#prose44.3.q5}
考点：prose44.pair
语境：prose44.3.p.inn

- [ ] 一个行人走过檐下又站在水面敲钟
  理由：这两句没有人赶路或敲钟的动作。
- [x] 近处檐水敲阶，远处钟声过水
- [ ] 檐水越过江面，远钟落在台阶上
  理由：两个动作各有主语，不能因成对而互换。

提示：给“鸣阶”与“度水”分别配一个发出声音的东西。
解析：檐溜、远钟两边相对；一边让人听见身边的阶，一边让人听见水外的钟。

## 单选：哪些事能够断定有先后，理由来自哪里？ {#prose44.3.q6}
考点：prose44.parallel
语境：prose44.3.p.inn

- [ ] 必须先听到钟，江亭才开始下雨
  理由：首句已经交代夜雨，并无钟声致雨之说。
- [x] 雨停后客人才出发，要紧的是“乃出”
- [ ] 旅客一定先收完笠，住户才能掩门，因为旅客写在上句
  理由：“方”与“已”并出，分别落在两个人身上。

提示：在两组景象之外另找明确的承接词。
解析：停雨、出发之间有“乃”标明先后。此前亭内亭外是并写的夜间活动。

## 原文：教学例句 {#prose44.3.p.hall}
> 修旧馆，记曰：“梁承其上，础固其下；外延四方之客，内庇无告之人。”客问：“孰先？”主人曰：“二者并行。”
译文：修复旧馆，记文说：“梁从上方承托，柱础在下方支撑；对外接待四方旅客，对内庇护无依无靠的人。”客人问：“哪一项先办？”主人说：“两项一起办。”
词注：延：迎接。
  无告：有苦难而无处告诉或求助。

## 单选：修馆后的两项用途，哪种说法给“延”“庇”都配对了对象？ {#prose44.3.q7}
考点：prose44.pair
语境：prose44.3.p.hall

- [ ] 招无告之人作客，叫四方来客充任守卫
  理由：“客”在“延”后，是受迎接的人；没有授以守卫之职。
- [ ] 馆外只许住梁木匠人，馆内只许住造础者
  理由：上下两句先写建筑，后两句已经转到待人。
- [x] 接四方之客，护无告之人

提示：分开前一对建筑构造和后一对用途。
解析：“延”同“庇”相对，却领各自的宾语。读齐整的文字，也得逐句照应。

## 找原文证据：客人把两个用途问成“孰先”，主人哪句明确纠正了这个想法？ {#prose44.3.q8}
考点：prose44.parallel
语境：prose44.3.p.hall

- [x] 二者并行
- [ ] 外延四方之客
  理由：这是列出的第一个用途，不能据此排先后。
- [ ] 梁承其上
  理由：这是馆舍的构造，并非办事先后。

提示：不要用题目中哪句写得在前来判定。
解析：“并行”点明同时办理。两个用途分排在两句中，只是便于分别说清。
