# 课文：看见别人，还是被别人看见 {#l2.12}
简介：把动作还给动手的一方，把遭受结果的人或物留下。回看“见”“于”“为……所”以及没有标记的写法。

## 正文

“客见主人”说客人见到了主人；“客见留”则可能说客人被挽留。一个“见”不能包办判读。跟在它后面的是被看见的人，还是客人所受的动作？

有时原文把动手的一方摆出来：“舟为风所退”，船往后退，是风的作用。有时只写结果：“群盗断索，索断，舟随流去。”读者顺着前因去看绳索与船的遭遇，不必给每句话硬添一个“被”。

## 知识点：见在动词前表示遭受 {#l2.skill.pass-jian}
义项：句首的人或物受到随后的动作
领域：句法
要诀：“见”后是一个人或东西，还是加在主语身上的动作？
讲解：“客见拒”写客人遭到拒绝；“客见门人”中，门人是他见到的对象。要让整句中的人各有着落。
例句：l2.ex.pass-jian

## 原文：教学例句 {#l2.ex.pass-jian}
> 童两求入，皆见拒。
译文：孩子两次请求进去，都遭到拒绝。

## 知识点：于带出动作的发出者 {#l2.skill.passive-provider}
义项：前面的人或物受到“于”后这一方的动作
领域：句法
要诀：试问谁在动手，再看“于”后是否为可动手的人。
讲解：“书藏于室”只说处所；“客见疑于众”则说众人怀疑这位客人。“疑”的两方并没有平分同一个动作。
例句：l2.ex.passive-provider

## 原文：教学例句 {#l2.ex.passive-provider}
> 新令见信于民。
译文：新来的县令受到百姓信任。

## 知识点：为……所……引出被动 {#l2.skill.pass-weisuo}
义项：“所”后说遇到的事，“为”后可点明施事
领域：句法
要诀：谁落在“为”和“所”之间，他做了什么？
讲解：“衣为童所取”是被动句，衣服被孩子拿走了。换成主动句，孩子就站到“取”前面，作拿衣的人。
例句：l2.ex.pass-weisuo

## 原文：教学例句 {#l2.ex.pass-weisuo}
> 小舟为浪所覆。
译文：小船被浪掀翻。

## 原文：古籍引文 {#l2.12.p.people}
> 百姓之不见保，为不用恩焉。
译文：百姓没有得到保护，是因为君王没有向他们施行恩惠。
词注：保：保护，这里说百姓未受到保护。
  恩：指君主对百姓的恩惠。

## 单选：“百姓之不见保”里，百姓和“保”是什么关系？ {#l2.12.q1}
考点：l2.skill.pass-jian
语境：l2.12.p.people

- [x] 百姓是未得到保护的人
- [ ] 百姓拒绝去保护君王
  理由：下文将缘由归到没有施行恩惠的一方。
- [ ] 百姓看不见正在保护别人的人
  理由：“保”是动作，这里没有一个人名接在“见”后。

提示：把“见保”暂读作“受保护”，再与后半句相接。
解析：说话人所问的是恩惠是否及于百姓。“不见保”写百姓未受保护，不是他们没有看见什么。

## 原文：教学例句 {#l2.12.p.door}
> 客见阍人，请入。阍人闭扉，客见拒于阍人，怏怏而返。
译文：客人见到守门人，请求入内。守门人关门，客人被他拒绝，闷闷地返回。
词注：阍人：守门的人。
  扉：门扇。
  怏怏：读 yàng yàng，不高兴的样子。

## 单选：两次“见”如何读，人物的行动才接得上？ {#l2.12.q2}
考点：l2.skill.pass-jian
语境：l2.12.p.door

- [ ] 两次都说客人看见守门人，没交代准不准进
  理由：“闭扉”“怏怏而返”正交代了被拒的结果。
- [ ] 先是客人看到守门人，后是守门人遭客人拒绝
  理由：关门的是守门人，最后离开的却是客人。
- [x] 先是客人见到守门人，后是客人遭到拒绝

提示：第一处“见”后是什么人，第二处“见”后是什么动作？
解析：第一处的“阍人”是所见的人。第二处“拒”落在客人身上，“于阍人”再说拒他的是谁。

## 找原文证据：谁让客人没能进去？哪几个字点出“拒”是谁做的？ {#l2.12.q3}
考点：l2.skill.passive-provider
语境：l2.12.p.door

- [ ] 客见拒
  理由：只写客人的遭遇，没有点名拒绝者。
- [x] 于阍人
- [ ] 怏怏而返
  理由：这是客人事后的反应。

提示：在“拒”后找“于”领起的那一小段。
解析：“于阍人”写施事，前面守门人闭扉的动作也和这层意思相合。

## 原文：教学例句 {#l2.12.p.cloth}
> 柳絮满庭，新布为风所卷，挂于高枝。童持竿取之。
译文：柳絮落满院子，新布被风卷起，挂在高枝上。孩子拿竹竿把它取下来。

## 单选：要改写成“谁卷起什么”，应该把哪一方移到“卷”前？ {#l2.12.q4}
考点：l2.skill.pass-weisuo
语境：l2.12.p.cloth

- [ ] 孩子，他把布挂上高枝
  理由：孩子在布已经挂住后才来取。
- [x] 风，把新布卷了起来
- [ ] 高枝，它把风卷进院里
  理由：“挂于高枝”只交代新布后来挂在哪里。

提示：把“为”和“所”中间的字单独读出来。
解析：“为风所卷”里风施力、布受力；后面的高枝是挂住的地方。

## 原文：教学例句 {#l2.12.p.rumor}
> 商失囊，疑舟子。舟子见疑于商，告于吏。吏搜舟，囊乃在商箧中。
译文：商人丢了袋子，怀疑船夫。船夫遭他怀疑，便向官吏申告。官吏搜查船只，袋子原来就在商人的箱中。
词注：告：申告，此处说船夫向官吏陈说。
  箧：读 qiè，盛放物件的箱子。

## 单选：同一个船夫“见疑于商，告于吏”。谁怀疑他，他又去找谁？ {#l2.12.q5}
考点：l2.skill.passive-provider
语境：l2.12.p.rumor

- [ ] 他先后被商人和官吏两人怀疑
  理由：“告”写舟子主动申告，吏是听他申告的那一方。
- [x] 商人怀疑他，他向官吏申告
- [ ] 官吏怀疑他，他向商人申告
  理由：上句是商先“疑舟子”。

提示：比一比“疑”和“告”，船夫在两件事里都只是承受者吗？
解析：第一处“于”引出怀疑船夫的商人；第二处引出他去告诉的官吏。

## 原文：教学例句 {#l2.12.p.boat}
> 小艇系岸，夜为浪所击，缆绝。晨，舟人循流寻艇，得于下湾。
译文：小艇系在岸边，夜里遭波浪冲击，缆绳断了。早晨船夫顺流找船，在下游河湾找到了。

## 排序：按小艇的遭遇和船夫的行动排列经过。 {#l2.12.q6}
考点：l2.skill.pass-weisuo
语境：l2.12.p.boat

- [3] 清晨船夫在下湾找到小艇
  理由：“晨”将经过推进到第二天。
- [1] 夜里浪击小艇
  理由：“为浪所击”先交代外力。
- [2] 系艇的缆绳断了
  理由：“缆绝”承接浪击。

提示：先追浪与缆的关系，再追船夫到哪里寻回东西。
解析：浪击小艇，缆断走船；早晨船夫到下游寻回。“得于下湾”的下湾是地点。

## 原文：教学例句 {#l2.12.p.teacher}
> 老医寓于东村，屡救危者，见重于乡人。乡人有疾，辄往问之。
译文：老医生住在东村，多次救回危重病人，受到乡亲敬重。乡亲有疾患，往往前去向他求教。
词注：寓：寄居。
  重：看重，这里是乡人敬重老医。
  辄：遇到这种情况总会如此。

## 单选：“于东村”和“于乡人”能都当成医生的住处吗？ {#l2.12.q7}
考点：l2.skill.passive-provider
语境：l2.12.p.teacher

- [x] 前一处是住处，后一处说谁敬重医生
- [ ] 两处都是行医的地点
  理由：“乡人”是前去求教的人，不是地名。
- [ ] 前一处是住处，后一处说医生敬重谁
  理由：“见重”的是医生，敬重他的是乡人。

提示：找“寓”和“见重”各自需要怎样的下文。
解析：“寓”要交代住在哪里；“见重”写受到敬重，可以接“于乡人”说明敬重出自谁。

## 原文：教学例句 {#l2.12.p.letter}
> 史写二牍，赤牍为吏所取，白牍留案上。暮史但见白牍。
译文：书吏写了两份文书，红牍被一名官吏拿走，白牍留在案上。傍晚书吏只见到白牍。

## 单选：要解释傍晚为什么只见一牍，须把哪项事实放在前面？ {#l2.12.q8}
考点：l2.skill.pass-weisuo
语境：l2.12.p.letter

- [x] 吏先取走红牍
- [ ] 史自己把两牍都锁进柜里
  理由：白牍还留案上。
- [ ] “所取”指一处名叫红牍的取书地点
  理由：红牍与白牍本是两份文书，“吏”才是取走的人。

提示：先辨哪一牍受到取走的动作，再看留下哪一牍。
解析：“赤牍为吏所取”说的是红牍的去向。末句的“见白牍”才真正表示亲眼看见。
