# 检查：虚词关系与段意检查 {#check.8}

## 原文：教学例句 {#check.8.p.flood}
> 农以水涨不耕，渔者以长竿探流。
译文：农人因为水涨不耕作，渔人用长竿试探水流。

## 单选：两处“以”的关系怎样分？ {#check.8.q1}
考点：l2.skill.yi-cause
语境：check.8.p.flood

- [ ] 前者引工具，后者引原因
  理由：农人是在说明动作方式还是取消缘故？
- [ ] 两处都引工具
  理由：“水涨”是一种事态，能拿在手中使用吗？
- [x] 前者引不能耕的原因，后者引探流工具

提示：分别问为什么不耕、凭什么探流。
解析：“水涨”解释不耕的原因，“长竿”说明具体凭借。

## 原文：教学例句 {#check.8.p.slope}
> 东坡陡于西坡。负薪者与其弟择西坡而下。
译文：东坡比西坡陡，背柴的人同弟弟选择西坡下来。

## 单选：选西坡与“陡于西坡”有什么关系？ {#check.8.q2}
考点：l2.skill.yu-compare
语境：check.8.p.slope

- [ ] 兄弟各走一坡
  理由：“与其弟”引共同出行的一方。
- [ ] 从西坡可以抵达东坡
  理由：“于”前是陡缓性质，未交代通向何处。
- [x] 东坡比较陡，所选的西坡较缓

提示：先按“甲比乙……”读前句。
解析：先比较坡度，使后来选择西坡的行动容易理解。

## 原文：教学例句 {#check.8.p.letter}
> 吏为病者书信，与其子议所书。信成，病者亲封之。
译文：官吏替病人写信，同病人的儿子商议信的内容。写成后，病人亲自封信。

## 单选：谁接受代写的帮助，谁与吏商议？ {#check.8.q3}
考点：l2.skill.wei-beneficiary
语境：check.8.p.letter

- [x] 病人受帮助，他的儿子同吏商议
- [ ] 病人和儿子都是受召来的官吏
  理由：“为”“与”分别引入不同关系。
- [ ] 儿子代写，吏只负责封信
  理由：“吏为病者书信”已经点出执笔者。

提示：分别读“为病者”和“与其子”。
解析：“为”引受益人，“与”引参与商议的人。

## 原文：教学例句 {#check.8.p.clay}
> 制器者示人以所制。观者取一盏，问其价。
译文：做器物的人给人看自己的作品。看的人拿起一只小盏，问它的价钱。

## 单选：“所制”和后文“盏”怎样衔接？ {#check.8.q4}
考点：l2.skill.suo-object
语境：check.8.p.clay

- [ ] 所制指工匠本人
  理由：工匠已由“制器者”点明。
- [x] 前者指制成的物件，盏是其中之一
- [ ] 盏是制作器物的场地
  理由：客人能拿起它来问价。

提示：分清“制器者”和“所制”的指向。
解析：“所制”将动词的对象提作整体，后文以盏为具体实例。

## 原文：教学例句 {#check.8.p.tower}
> 塔下有亭，守塔者居焉。闻钟则登塔。
译文：塔下有亭，守塔人住在那里，听到钟响就登塔。

## 找原文证据：哪一处建筑是“居焉”回指的住处？ {#check.8.q5}
考点：l2.skill.yan-place
语境：check.8.p.tower

- [ ] 守塔者
  理由：这是居住的人。
- [ ] 钟
  理由：这是响起的信号。
- [x] 亭

提示：分清日常住处与随后登临之处。
解析：前句给出塔下之亭，守塔人平时在那里住。

## 原文：教学例句 {#check.8.p.seal}
> 库规：印至则开。是日印暮至，门乃启。
译文：仓库的规矩是印信送到就开门。这一天印信傍晚才到，门这才打开。

## 单选：“则”和“乃”在这段中分别说明什么？ {#check.8.q6}
考点：l2.skill.nai-delay
语境：check.8.p.seal

- [ ] 前者说已经开门，后者说以后也许开门
  理由：“库规”是一般规则，“是日”才进入这天的经历。
- [ ] 两字都说明印信从未送到
  理由：句中明说“印暮至”。
- [x] 前者写开启的条件，后者写当日终于开门

提示：对照“库规”和“是日”。
解析：同是开门，一处说规则所定的条件，一处说这次何时实现。
