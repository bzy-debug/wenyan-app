# 检查：追问一个谥号，查清一封书信 {#check.8}

## 原文：古籍引文 {#check.8.p.name}
> 子贡问曰：“孔文子何以谓之‘文’也？”子曰：“敏而好学，不耻下问，是以谓之‘文’也。”
译文：子贡问：“孔文子凭什么得到‘文’这个谥号？”孔子说：“他勤敏好学，向不及自己的人请教也不以为耻，因此称他为‘文’。”
词注：文：此处指孔文子死后所得的谥号。
  敏：领会得快；下文还说他肯向人请教。
  下问：向地位或学问不及自己的人请教。
出处：《论语·公冶长》子贡问孔文子章

## 单选：这次的问句把“何”放在“以”前。若按答话来补“以”的内容，应当补哪一项？ {#check.8.q1}
考点：l2.skill.interrogative-object
语境：check.8.p.name

- [ ] 凭一份名为“文”的旧文书
  理由：答话给出人的行为，没有拿出文书。
- [ ] 凭借子贡提出问题，孔文子才得到称号
  理由：子贡是在追问得名的缘故，不是给人定谥。
- [x] 凭他勤敏好学、肯向不及自己的人请教

提示：上课时用答句换掉“谁”“何”；这回被问的是“以何”，凭什么。
解析：“何以”问所凭的理由。答话列出孔文子的几种表现，接着才说因此称“文”。

## 单选：孔子答“敏而好学”时没有再报人名。这些行事该记在谁名下？ {#check.8.q2}
考点：l2.skill.elided-speaker
语境：check.8.p.name

- [ ] 孔子
  理由：孔子作答，答的却是前一句问到的孔文子。
- [ ] 子贡
  理由：子贡的行事是发问，他问的是另一人的谥号。
- [x] 孔文子

提示：分开说话的人和两人谈论的那个人。
解析：“子曰”是孔子开口，答句承接的对象却是孔文子。若将好学误记给说话人，便解释不了所问的谥号。

## 找原文证据：答句的“是以”除了回指“敏而好学”，还指向哪项可见的做法？ {#check.8.q3}
考点：l2.skill.refer-shi
语境：check.8.p.name

- [x] 不耻下问
- [ ] 是以谓之‘文’也
  理由：这是得名的结果，而非得名的依据。
- [ ] 子贡问曰
  理由：这确实发生了，却是子贡发问，不是孔文子的做法。

提示：在“是以”前找，谁愿意向不如自己的人请教？
解析：“是”承接前面所举的表现，“以”连出得名之由。这里应选能跟好学并列的做法。

## 原文：教学例句 {#check.8.p.letter}
> 驿书失，卒见疑于吏。卒曰：“君未我问，何以知之？”吏召守门者。对曰：“昨书为风所吹，堕于井旁，非卒取也。吾拾而藏之。”出书示吏，吏乃谢卒。
译文：驿站的书信不见了，驿卒受到官吏怀疑。驿卒说：“您还没问我，凭什么知道这事？”官吏叫来守门人。他答道：“昨天信被风吹落在井边，并非驿卒取走的。是我捡起来收着了。”他拿出信给官吏看，官吏才向驿卒道歉。
词注：驿：传递公文、供使者换马休息的地方。
  堕：落下。
  谢：向受猜疑的驿卒致歉。

## 单选：卒说的“君未我问”和后面的召问是一回事吗？ {#check.8.q4}
考点：l2.skill.negative-object
语境：check.8.p.letter

- [ ] 前句是驿卒拒绝问官吏，后面却是驿卒传守门人
  理由：“君”是卒当面称吏，召人的也是吏。
- [x] 前句是官吏尚未问驿卒，后面则找守门人求证
- [ ] 两次都在问同一位守门人
  理由：卒说的“我”只指自己，守门人在后来才被召。

提示：将“未我问”换成“未问我”，再给“我”找说话人。
解析：站出来说话的是受疑的卒。“我”虽排在动词前，仍是尚未受到询问的人；后面又出现一位能谈往事的证人。

## 单选：“见疑于吏”和“堕于井旁”都用“于”。若要画出人物与书信的去向，应该怎么画？ {#check.8.q5}
考点：l2.skill.passive-provider
语境：check.8.p.letter

- [ ] 吏在井边怀疑守门人
  理由：第一处没有说怀疑发生在哪里，受疑的又是卒。
- [ ] 卒怀疑吏；信留在吏手里
  理由：初句把卒写成受怀疑的一方，井旁才是信落下的地方。
- [x] 吏怀疑卒；信落到井旁

提示：一个“于”后是能生出怀疑的人，一个后面是什么？
解析：“见疑”须有怀疑者，故“于吏”指向官吏。“堕”在此交代落点，井旁不能当成施加动作的人。

## 排序：只排书信昨日的实际遭遇及今日查清经过，不把官吏的猜疑当成事实。 {#check.8.q6}
考点：l2.skill.pass-weisuo
语境：check.8.p.letter

- [2] 守门人拾起书，收存起来
  理由：这是“吾拾而藏之”所报的下一步。
- [3] 守门人出示书信，吏向卒道歉
  理由：“示吏”到今日召问时才发生。
- [1] 风先将书吹落井旁
  理由：“书为风所吹”令书成为受力的一方。

提示：区分守门人讲述的昨日，与他眼下拿出书这一刻。
解析：先遭风吹，再被守门人拾存，今日出示原书，足以解释“非卒取也”。官吏的早先怀疑并非书信经历的一步。
