# 检查：从虚词读懂两句话怎样相接 {#check.8}

## 原文：教学例句 {#check.8.p.flood}
> 农以水涨不耕，渔者以长竿探流。
译文：农人因为水涨不耕作，渔人用长竿试探水流。

## 单选：一个“以”跟着“水涨”，另一个跟着“长竿”。两处各是什么意思？ {#check.8.q1}
考点：l2.skill.yi-cause
语境：check.8.p.flood

- [ ] 前者引工具，后者引原因
  理由：水涨了，农人才停耕；水不是他拿来耕田的工具。
- [ ] 两处都引工具
  理由：能拿来试探水流的是长竿，水涨是农人停耕的缘由。
- [x] 前者引不能耕的原因，后者引探流工具

提示：分别问为什么不耕、凭什么探流。
解析：农人是因为水涨而不耕；渔人是拿长竿来探水。同一个“以”，前一个说明缘由，后一个说明用具。

## 原文：教学例句 {#check.8.p.slope}
> 东坡陡于西坡。负薪者与其弟择西坡而下。
译文：东坡比西坡陡，背柴的人同弟弟选择西坡下来。

## 单选：选西坡与“陡于西坡”有什么关系？ {#check.8.q2}
考点：l2.skill.yu-compare
语境：check.8.p.slope

- [ ] 兄弟各走一坡
  理由：“与其弟”说明两人一道下坡。
- [ ] 从西坡可以抵达东坡
  理由：“陡于”在比两边哪边更陡，没说从一坡能不能走到另一坡。
- [x] 东坡比较陡，所选的西坡较缓

提示：“东坡陡于西坡”是说哪一边更陡？
解析：东坡比西坡陡。兄弟俩最后选的是西坡，也就是较缓的那一边。

## 原文：教学例句 {#check.8.p.letter}
> 吏为病者书信，与其子议所书。信成，病者亲封之。
译文：官吏替病人写信，同病人的儿子商议信的内容。写成后，病人亲自封信。

## 单选：官吏替谁写信，又和谁商量？ {#check.8.q3}
考点：l2.skill.wei-beneficiary
语境：check.8.p.letter

- [x] 病人受帮助，他的儿子同吏商议
- [ ] 病人和儿子都是受召来的官吏
  理由：前一句分开写了官吏、病人和病人的儿子，没有人受召来做官。
- [ ] 儿子代写，吏只负责封信
  理由：“吏为病者书信”已经点出执笔者。

提示：分别读“为病者”和“与其子”。
解析：“为病者书信”是替病人写，“与其子议”是同病人的儿子商量。最后亲手封信的又是病人。

## 原文：教学例句 {#check.8.p.clay}
> 制器者示人以所制。观者取一盏，问其价。
译文：做器物的人给人看自己的作品。看的人拿起一只小盏，问它的价钱。

## 单选：“所制”指什么？为什么下一句就说到一只盏？ {#check.8.q4}
考点：l2.skill.suo-object
语境：check.8.p.clay

- [ ] 所制指工匠本人
  理由：工匠已由“制器者”点明。
- [x] 前者指制成的物件，盏是其中之一
- [ ] 盏是制作器物的场地
  理由：客人能拿起它来问价。

提示：谁做出了器物？客人拿起的又是什么？
解析：“制器者”是做器皿的人，他给人看的是自己做的东西，盏就是其中的一件。

## 原文：教学例句 {#check.8.p.tower}
> 塔下有亭，守塔者居焉。闻钟则登塔。
译文：塔下有亭，守塔人住在那里，听到钟响就登塔。

## 找原文证据：守塔者“居焉”，住在哪里？从原文找出那座建筑。 {#check.8.q5}
考点：l2.skill.yan-place
语境：check.8.p.tower

- [ ] 守塔者
  理由：“守塔者”指人，这里问的是他住在哪儿。
- [ ] 钟
  理由：听见钟才登塔，钟并不是他的住处。
- [x] 亭

提示：听见钟声以前，那人平日住在哪里？
解析：守塔人住在塔下的亭里。听到钟响以后，他才登上塔去。

## 原文：教学例句 {#check.8.p.seal}
> 库规：印至则开。是日印暮至，门乃启。
译文：仓库的规矩是印信送到就开门。这一天印信傍晚才到，门这才打开。

## 单选：规矩怎样说？那天又实际发生了什么？ {#check.8.q6}
考点：l2.skill.nai-delay
语境：check.8.p.seal

- [ ] 前者说已经开门，后者说以后也许开门
  理由：“库规”是一般规则，“是日”才进入这天的经历。
- [ ] 两字都说明印信从未送到
  理由：句中明说“印暮至”。
- [x] 前者写开启的条件，后者写当日终于开门

提示：对照“库规”和“是日”。
解析：仓库规定，有印就开。这天却一直等到傍晚才收到印，门这才打开。读“则”要接着规矩读，读“乃”要接着当天的经过读。
