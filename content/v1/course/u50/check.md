# 检查：使者、病中的长辈与一席夜话 {#check.50}

## 原文：古籍引文 {#c50.check.p.a}
> 项羽取陵母置军中，陵使至，则东乡坐陵母，欲以招陵。
译文：项羽把王陵的母亲安置在军中。王陵的使者来了，项羽便让王陵的母亲面朝东坐，想借此招揽王陵。
词注：乡：读 xiàng，面向。
  陵使：王陵派来的使者。
出处：《史记·陈丞相世家》王陵母在楚军

## 原文：教学例句 {#c50.check.p.b}
> 客见沈子曰：“尊君安否？”对曰：“家君有疾。伯父日从东村来视之。”客曰：“然则二老可并问也。”
译文：客人见到沈生问：“你父亲安好吗？”沈生说：“我父亲病了。伯父每天从东村来探望他。”客人说：“那么可以一并问候两位老人了。”
词注：视：探望。

## 原文：教学例句 {#c50.check.p.c}
> 使者入门，称寡君之命，求故大夫遗书。主人避席对曰：“先子自号木居士，卒而谥简。凡署木居士者，皆其手书。”言已，取书授之。
译文：使者进门，传达本国国君的命令，请求已故大夫留下的书迹。主人离席作答：“我亡父自号木居士，死后谥为简。凡是署木居士的，都是他亲手写的。”说完取出书迹交给使者。
词注：故：已经去世的。
  先子：对他人称已故的父亲。

## 单选：若为王陵的使者复画当时的坐席，应让画里哪一位面向东？ {#c50.check.q1}
考点：c50.s.face
语境：c50.check.p.a

- [ ] 使者本人 {#c50.check.q1.o1}
  理由：“坐陵母”说的是使谁坐下。
- [ ] 项羽 {#c50.check.q1.o2}
  理由：项羽安排席位，没说他本人朝向。
- [x] 王陵的母亲 {#c50.check.q1.o3}

提示：“乡”管方向；再找“坐”后面的人。
解析：“东乡坐陵母”是安排陵母东向坐。礼遇让使者看见，用意正在后面的“招陵”。

## 单选：客人想问候的病者，从客人和沈生两人口中分别怎样称呼？ {#c50.check.q2}
考点：c50.s.father
语境：c50.check.p.b

- [ ] 家君、伯父 {#c50.check.q2.o1}
  理由：“家君”由儿子说，“伯父”是来探病的另一人。
- [x] 尊君、家君 {#c50.check.q2.o2}
- [ ] 尊君、伯父 {#c50.check.q2.o3}
  理由：第二个称呼会把病者错换成探病人。

提示：病者一直没换，叙说者换了。
解析：客人的“尊君”和儿子的“家君”都是沈父。两位老人里另有一人是前来相看的伯父。

## 单选：客人若在东村碰见那位伯父，应怎样向他问起病人？ {#c50.check.q3}
考点：c50.s.uncle
语境：c50.check.p.b

- [ ] “您的父亲今日可好？” {#c50.check.q3.o1}
  理由：“伯父”与病者同一代。
- [x] “您的弟弟今日可好？” {#c50.check.q3.o2}
- [ ] “您的哥哥今日可好？” {#c50.check.q3.o3}
  理由：伯父是沈生父亲的兄长。

提示：把两位老人的关系从伯父这一边说一遍。
解析：病者是伯父的弟弟。改变发问对象，长幼也就要倒过来表述。

## 单选：哪张便条能准确记下使者的身份和任务？ {#c50.check.q4}
考点：c50.s.envoy
语境：c50.check.p.c

- [x] 受本国君主差遣，向故大夫之家求书 {#c50.check.q4.o1}
- [ ] 派国君上门，亲自核验藏书 {#c50.check.q4.o2}
  理由：“称寡君之命”是传命，方向相反。
- [ ] 奉主人父亲之命来给国君送书 {#c50.check.q4.o3}
  理由：父亲已经去世，主人在接受请求。

提示：分开记下谁发命，谁进门。
解析：使者口中的“寡君”是派他的人，求书则是他来到此处所做的事。

## 单选：发现一封题署“木居士”的旧信，想辨是否为故大夫生前手书，该依据主人哪层说明？ {#c50.check.q5}
考点：c50.s.post
语境：c50.check.p.c

- [ ] 简是他自幼写信所用的本名 {#c50.check.q5.o1}
  理由：“卒而谥简”已把“简”定在身后。
- [ ] 凡写到“简”的都是他本人所写 {#c50.check.q5.o2}
  理由：身后别人称他“简”也说得通。
- [x] 木居士是他自取的号，主人认得这一署名 {#c50.check.q5.o3}

提示：注意自号与谥各落在生死的哪一边。
解析：主人以生前自号核署名，另交代身后谥号，两种记名各有用途。

## 找原文证据：主人避席后仍在场，哪句能证明他随后亲自交出了东西？ {#c50.check.q6}
考点：c50.s.rise
语境：c50.check.p.c

- [ ] 使者入门 {#c50.check.q6.o1}
  理由：使者只是登门。
- [ ] 求故大夫遗书 {#c50.check.q6.o2}
  理由：这是请求，交付尚未发生。
- [x] 取书授之 {#c50.check.q6.o3}

提示：找“言已”后面的事。
解析：起身答话以后又当面取书，正可反推“避席”是郑重应对的礼节。
