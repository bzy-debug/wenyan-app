# 课文：项王东向坐，他在席的哪一边 {#cult50.3}
简介：亲手摆一次鸿门宴的座位，再分清赴席、避席和辞归。
回读：skill.h29.1.shuo-first c50.3.p.c
  skill.h29.3.wang-full-moon c50.3.p.c

## 正文

“东向坐”的“东”是脸朝的方向。如果四人围着同一处，面朝东的一席在西边。鸿门宴上项王、项伯东向，沛公北向，张良西向侍候。先画相对位置，再去讨论席位的轻重。这场宴会的安排不能拿去替所有宴席定礼数。

有人听完责问便“避席”，还在原地开口应答；这时是离开坐席表示敬意。要判断是否真的走了，得往下找送客、出门或告归的话。另有一种情形是见到居丧者而起身。遇“齐衰（zī cuī）”先查服饰条，它是一种缉边的麻布丧服。知道这是服丧的人，便能解释接待者的举动；若要定死者与他是什么亲属，还须另外的记载。

## 知识点：以“向”认席位方向 {#c50.s.face}
义项：区分面朝某方与席设某方
领域：文化背景
要诀：画个朝向箭头，再把席放在箭尾。
讲解：鸿门宴中，东向和西向的两人迎面而处。“侍”还须另读，面向交代方位，侍从说的是身份。
例句：c50.3.p.a

## 知识点：避席应对 {#c50.s.rise}
义项：离开坐席以示敬意，是否退去另看下文
领域：文化背景
要诀：看离席后是开口答话，还是迈出门。
讲解：“避席曰”把动作连到谦敬的答话上。若读成趁机走掉，后面的问答便无从发生。
例句：c50.3.p.b

## 知识点：见丧服辨居丧，不凭一件衣服编亲属关系 {#c50.s.mourning}
义项：借服名及动作辨居丧者和接待礼节
领域：文化背景
要诀：先查服名，再看一句话有没有交代为谁服丧。
讲解：“齐衰”是丧服之一。见服丧者起身，是对对方处境表示敬重；“服除”才说明规定的服丧期已过。具体为谁服、服多久，各篇须另核。
例句：c50.3.p.d

## 原文：古籍引文 {#c50.3.p.d}
> 子见齐衰者、冕衣裳者与瞽者，见之，虽少，必作；过之，必趋。

## 原文：教学例句 {#c50.3.p.e}
> 有士衣齐衰而来。客问：“所丧何亲？”人曰：“未之闻也。”既而其弟至，始知为母。
译文：有位士人穿着齐衰来。客人问：“失去的是哪位亲属？”旁人说：“没听说。”后来他弟弟到了，才知道是为母亲服丧。
词注：衣：读 yì，穿着。

## 原文：教学例句 {#c50.3.p.c}
> 记曰：“朔，师至。望，置席堂中，西席东向，请师坐之。”生有所问，避席而请。师答，命复坐。
译文：记录说：“月初一，老师来到。到望日，在堂中设席，西边的席面向东，请老师坐。”学生有疑问，离席请教。老师回答后，让他重新坐下。
词注：置：安放。
  复：重新。

## 单选：若画鸿门宴的席位图，“项王、项伯东向坐”应怎样画？ {#c50.3.q1}
考点：c50.s.face
语境：c50.3.p.a

- [ ] 把两人放在东边，箭头朝西 {#c50.3.q1.o1}
  理由：这会把“东向”画成西向。
- [ ] 把两人放在南边，箭头朝北 {#c50.3.q1.o2}
  理由：北向的是下一句里的沛公。
- [x] 把两人放在西边，箭头朝东 {#c50.3.q1.o3}

提示：箭头表示脸朝哪边。
解析：“向”管面朝的方向，席位所在恰好在面对的一侧的对面。

## 找原文证据：老师坐下后面朝哪里？选出直接写面朝方向的两个字。 {#c50.3.q2}
考点：c50.s.face
语境：c50.3.p.c

- [ ] 西席 {#c50.3.q2.o1}
  理由：“西席”说坐席设在西边。
- [x] 东向 {#c50.3.q2.o2}
- [ ] 堂中 {#c50.3.q2.o3}
  理由：只是设席的地方，不能定人的朝向。

提示：分开看“在哪里”和“朝哪里”。
解析：“西席东向”将席位所在与面朝方向都写出来，正好可以互相核对。

## 单选：两人“避席”后，哪一个动作最能说明他们还在认真听教？ {#c50.3.q3}
考点：c50.s.rise
语境：c50.3.p.b

- [ ] 走出门外，另请人转告 {#c50.3.q3.o1}
  理由：话由二人亲口说出。
- [x] 自称鄙陋，当面表示领教 {#c50.3.q3.o2}
- [ ] 席间无人注意，他们悄悄离去 {#c50.3.q3.o3}
  理由：“曰”引出的正是正式的回答。

提示：把“避席”与紧接的“曰”连读。
解析：改容、避席、答话前后相承。他们起身改变应对的姿态，并未借机结束谈话。

## 单选：孔子见一位穿齐衰的年轻人便起身。查过“齐衰”的服名，哪一种解释最稳妥？ {#c50.3.q4}
考点：c50.s.mourning
语境：c50.3.p.d

- [x] 对方正在居丧，虽年轻也以礼相待 {#c50.3.q4.o1}
- [ ] 对方的官阶一定比孔子高，所以起身 {#c50.3.q4.o2}
  理由：“齐衰”是丧服，不能据此定官阶。
- [ ] 对方一定在为兄长服丧，孔子是其伯父 {#c50.3.q4.o3}
  理由：所服丧服不能据此确定死者是谁，文中也没写孔子和他的亲属关系。

提示：“齐衰者”与“冕衣裳者”是分别举出的人。
解析：服名说明居丧；“虽少必作”说明这份礼遇不由年龄决定。两层加起来才解释了这次起身。

## 单选：若记录客人发问的那一刻，以下哪两栏可填、哪一栏仍要空着？ {#c50.3.q5}
考点：c50.s.mourning
语境：c50.3.p.e

- [ ] 死者为母早可填，因为齐衰只为母而服 {#c50.3.q5.o1}
  理由：旁人直到“其弟至”才得知消息，齐衰也不只用于这一种关系。
- [ ] 只能填颜色，是否居丧也毫无线索 {#c50.3.q5.o2}
  理由：齐衰本就是丧服名。
- [x] 衣服名与居丧可填，死者是何亲尚未听说 {#c50.3.q5.o3}

提示：分清“知道在服丧”和“知道所丧何亲”。
解析：“齐衰”足以解释客人为什么来问亲属；答案要等到另一条消息到来，不能单靠服名推出。

## 单选：学生避席后还留在堂中，哪一对动作能作证？ {#c50.3.q6}
考点：c50.s.rise
语境：c50.3.p.c

- [ ] 老师到来，学生早已回家 {#c50.3.q6.o1}
  理由：学生当面发问，老师也答了。
- [ ] 老师入席，学生便离开书院 {#c50.3.q6.o2}
  理由：没有辞行，反有“复坐”。
- [x] 离席请教，老师让他再坐 {#c50.3.q6.o3}

提示：看老师回答后又让学生做什么。
解析：“请”是开口请教，“复坐”是再坐回去，夹在其间的姿态变化合乎师生问答。

## 单选：若只在本月第一日的格里填一件事，该填什么？ {#c50.3.q7}

## 单选：学生要赶上请老师入席的那天，半月前后来访应挑哪一个时段？ {#c50.3.q8}
考点：skill.h29.3.wang-full-moon
语境：c50.3.p.c

- [x] 月中，月将圆的时分 {#c50.3.q8.o1}
- [ ] 月初第一日 {#c50.3.q8.o2}
  理由：初一发生的是老师到来。
- [ ] 月末新旧两月交替时 {#c50.3.q8.o3}
  理由：那要找“晦”等字。
