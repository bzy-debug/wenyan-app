# 课文：生前的号，身后的谥，使者口中的国君 {#cult50.2}
简介：听子贡问一个“文”字，再看史传怎样让使者代国君传话。
回读：skill.h29.1.regnal-year c50.2.p.d

## 正文

读“孔文子”，子贡问的不是这个人怎样写文章，而是何以得到“文”这一身后称号。谥用来称述死者；“自号”则可以是本人生前自取的别号。传里一个人先后换称呼，别急着往人物表里添人。

使者在别国开口说“寡君”，是在说本国君主。“寡人”却可由君主自己说。要辨一句话是谁的主意，看“使”前是谁、受命走来的是谁。读到“某侯三年”，还须另问：第三年是按谁即位来数？

## 知识点：辨生前自号和身后之谥 {#c50.s.post}
义项：用“自号”“卒”“谥”等字判断称号来历
领域：文化背景
要诀：在称呼旁记下是谁在何时起的。
讲解：一人可以有字、号和谥，不能因为有几个称呼就算成几个人。尤其要看“自号”“谥之”的主语是不是本人。
例句：c50.2.p.a

## 知识点：从“寡君”辨传话人的来处 {#c50.s.envoy}
义项：使臣说“寡君”指自己本国的君主
领域：文化背景
要诀：把“寡君使臣”换成“我国君主派我”。
讲解：“使”之后还有奉命的人。若是国君说“寡人”，这句话的第一人称才是君主本人。
例句：c50.2.p.b

> 韩厥执絷马前，再拜稽首，奉觞加璧以进，曰：“寡君使群臣为鲁、卫请，曰：‘无令舆师陷入君地。’”

## 原文：教学例句 {#c50.2.p.c}
> 使者至，曰：“寡君闻先生自号溪叟，愿得一见。”叟辞。使者归报，其君曰：“寡人当往。”
译文：使者来了，说：“我国国君听说先生给自己取号溪叟，希望见你一面。”老者推辞。使者回去报告，国君说：“我应当亲自去。”
词注：叟：老人。

## 原文：教学例句 {#c50.2.p.d}
> 卫侯三年，有司书：“大夫某卒，谥曰恭。”其子泣曰：“先人未尝自称恭也。”
译文：卫侯在位的第三年，主管的官员记录：“某大夫去世，谥为恭。”他的儿子哭着说：“我父亲生前从来不自称恭。”
词注：有司：主管其事的官员。

## 单选：子贡追问孔文子为何称“文”，孔子回答的是哪件事？ {#c50.2.q1}
考点：c50.s.post
语境：c50.2.p.a

- [ ] 孔文子替自己写过哪些文章 {#c50.2.q1.o1}
  理由：回答举出的是好学、愿意请教。
- [ ] 孔文子出生时为何取名为文 {#c50.2.q1.o2}
  理由：孔文子名圉，问的是谥。
- [x] 哪种生前表现足以解释这个身后称号 {#c50.2.q1.o3}

提示：看回答落在“文章”还是“行事”。
解析：孔子把“不耻下问”作为称“文”的理由。一句对答正好留下“人的行为—身后称号”这一层联系。

## 单选：韩厥说“寡君使群臣”，应把命令归给谁？ {#c50.2.q2}
考点：c50.s.envoy
语境：c50.2.p.b

- [ ] 韩厥正向他陈话的人 {#c50.2.q2.o1}
  理由：韩厥接下来用“君地”指对方国土。
- [x] 派韩厥来的晋国国君 {#c50.2.q2.o2}
- [ ] 受晋人帮助的鲁卫两国 {#c50.2.q2.o3}
  理由：鲁、卫在“为”后面，是代为提出请求的一方。

提示：停在“使”字，看前面是谁。
解析：韩厥是晋臣，说“寡君”便是敬谨地称己国国君。国君发命，群臣奉命。

## 找原文证据：哪几个字直接给韩厥的话标出派遣者和受命者？ {#c50.2.q3}
考点：c50.s.envoy
语境：c50.2.p.b

- [ ] 再拜稽首 {#c50.2.q3.o1}
  理由：这是陈词前的礼节。
- [x] 寡君使群臣 {#c50.2.q3.o2}
- [ ] 为鲁、卫请 {#c50.2.q3.o3}
  理由：这说的是替谁陈请。

提示：找一个带“使”的短句。
解析：“君”指发命的人，“群臣”承受命令，韩厥借此交代来意的出处。

## 找原文证据：“溪叟”从何而来？选出能证明取号人就是先生本人的文字。 {#c50.2.q4}
考点：c50.s.post
语境：c50.2.p.c

- [x] 先生自号溪叟 {#c50.2.q4.o1}
- [ ] 寡人当往 {#c50.2.q4.o2}
  理由：这是国君听完回报才说的。
- [ ] 使者归报 {#c50.2.q4.o3}
  理由：只说使者回去报告。

提示：哪一个字能排除别人所赠？
解析：“自”把取号这件事归到先生本人，又有使者当面求见，可知先生当时在世。

## 单选：前有“寡君”，后有“寡人”。把这两句各署一个发话者，应怎样写？ {#c50.2.q5}
考点：c50.s.envoy
语境：c50.2.p.c

- [ ] 两次都是先生 {#c50.2.q5.o1}
  理由：先生只推辞求见，末句的“其君”另有其人。
- [ ] 前为国君，后为使者 {#c50.2.q5.o2}
  理由：使者已经“归报”，随后才轮到国君说话。
- [x] 前为使者，后为国君 {#c50.2.q5.o3}

提示：注意“使者至”和“其君曰”两个换人处。
解析：两句话都谈这位国君，但说话的身份变了，一为代述，一为亲口决定。

## 单选：儿子说父亲生前没这样叫过自己，这会推翻记录吗？ {#c50.2.q6}
考点：c50.s.post
语境：c50.2.p.d

- [ ] 会，谥必须由本人亲口决定 {#c50.2.q6.o1}
  理由：“卒”在“谥”之前。
- [ ] 会，儿子说先人一生从未恭敬过 {#c50.2.q6.o2}
  理由：“未尝自称”只说他不这样称自己。
- [x] 不会，“恭”是身后所得的谥 {#c50.2.q6.o3}

提示：这条记录先写了哪件事？
解析：“卒，谥曰恭”定了先后。谥和自号的来历不同，儿子所见正合这次记载。

## 单选：若给这条身后称号的记录立时间栏，“三年”应从哪件事算起？ {#c50.2.q7}
考点：skill.h29.1.regnal-year
语境：c50.2.p.d

- [ ] 大夫去世 {#c50.2.q7.o1}
  理由：死亡是这一年记录的事件。
- [x] 这位卫侯即位 {#c50.2.q7.o2}
- [ ] 儿子接到谥号 {#c50.2.q7.o3}
  理由：文章没有给儿子立年。

提示：谁的称号紧挨着“三年”？
解析：“卫侯三年”给这一段定下国君在位年次，不能据此说某大夫已经去世了三年。

## 找原文证据：把后来得到的称号写进人物小传，哪一句足以支持把“恭”列在谥号一栏？ {#c50.2.q8}
考点：c50.s.post
语境：c50.2.p.d

- [x] 谥曰恭 {#c50.2.q8.o1}
- [ ] 未尝自称恭也 {#c50.2.q8.o2}
  理由：这只能看出他生前不自称“恭”。
- [ ] 其子泣曰 {#c50.2.q8.o3}
  理由：这是答话人的动作。

提示：要找明确记下称号种类的动词。
解析：“谥”直接点明命名方式。“卒”给出时间，两个线索合看便不会误填进字或自号栏。
