# 课文：“尊君”和“家君”是两个人吗 {#cult50.1}
简介：跟着元方答客，弄清说话人称的是谁的父亲，再排出项氏三代的辈分。

## 正文

客人到陈家，开口问“尊君”，孩子答话说“家君”。称呼变了，所指的人却没换。读对话时先在心里添上领属：您家的父亲，还是我家的父亲？只写一个“君”，又可能是当面称“您”。

史传常把好几代人压在一句里。“父”前还有一个字要看清：“伯父”是父亲的哥哥，“叔父”是父亲的弟弟，“季父”在项羽这段也属父辈。兄弟排行可以补充，但先别把叔父填进亲父那一格。

## 知识点：随说话人辨“家君”“尊君” {#c50.s.father}
义项：家君称己父，尊君敬称对方的父亲
领域：文化背景
要诀：给每个“君”补一个说话场景。
讲解：“尊君在不”问的是孩子的父亲；“待君久不至”里的“君”却当面指客人。能为“谁等谁”填上人名，才算读通。
例句：c50.1.p.a

## 知识点：从“季父”“伯父”排出父辈 {#c50.s.uncle}
义项：按称谓和领属词辨父亲的兄弟
领域：文化背景
要诀：先写下“谁的”，再写“什么亲属”。
讲解：“其季父某”须接上上文人物。“某父即某”又从某的角度向上数一代。这两条连起来，比猜一个人物年纪可靠。
例句：c50.1.p.b

## 原文：古籍引文 {#c50.1.p.a}
> 客问元方：“尊君在不？”答曰：“待君久不至，已去。”友人便怒曰：“非人哉！与人期行，相委而去。”元方曰：“君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。”
译文：客人问元方：“你父亲在家吗？”元方说：“等您好久，您没来，他已经走了。”客人便生气地责骂对方丢下自己走了。元方说：“您和我父亲约在正午。正午不来，是失信；当着儿子的面骂他父亲，是失礼。”
词注：不：这里用于是非问，读 fǒu。
  期：约定。

## 原文：古籍引文 {#c50.1.p.b}
> 其季父项梁，梁父即楚将项燕，为秦将王翦所戮者也。
译文：项籍的叔父是项梁。项梁的父亲就是楚将项燕，他被秦将王翦所杀。
词注：其：承接上文的项籍（项羽）。

## 原文：教学例句 {#c50.1.p.c}
> 客问周生：“尊君尝受业于谁？”生曰：“家君少从伯父学。伯父长家君三岁。”
译文：客人问周生：“你父亲曾向谁学习？”周生说：“我父亲小时候跟我的伯父学习。伯父比我父亲大三岁。”
词注：受业：从师学习。

## 单选：客人问“尊君”，元方说“待君”，又提“家君”。若把这三处称呼都换成人，久等的是谁？ {#c50.1.q1}
考点：c50.s.father
语境：c50.1.p.a

- [ ] 客人等元方的父亲 {#c50.1.q1.o1}
  理由：“已去”的是先到、久等的人。
- [ ] 元方自己等父亲回家 {#c50.1.q1.o2}
  理由：元方是在回答父亲去了哪里。
- [x] 尊君、家君都指元方父亲，是他等来问话的客人 {#c50.1.q1.o3}

提示：把客人问的“尊君”补回“待”的前面。
解析：“尊君”是客人问的那位父亲；元方接话称客人为“君”，说父亲等了他很久。

## 找原文证据：元方用哪个称呼把父亲说成“我家的父亲”？ {#c50.1.q2}
考点：c50.s.father
语境：c50.1.p.a

- [ ] 尊君 {#c50.1.q2.o1}
  理由：这是客人对着元方说的。
- [x] 家君 {#c50.1.q2.o2}
- [ ] 友人 {#c50.1.q2.o3}
  理由：这是叙述者称呼那位迟到的客人。

提示：找孩子回应约定时说的话。
解析：“君与家君”一边是来客，一边是说话人的父亲。他们才是约定出门的两个人。

## 单选：从项籍这一辈向上看，项梁是哪位亲属？ {#c50.1.q3}
考点：c50.s.uncle
语境：c50.1.p.b

- [ ] 自己的弟弟 {#c50.1.q3.o1}
  理由：“季父”的“父”把项梁放在上一辈。
- [x] 父亲的弟弟 {#c50.1.q3.o2}
- [ ] 母亲的父亲 {#c50.1.q3.o3}
  理由：“季父”指父亲这一边的长辈。

提示：先读“其季父”，再看“梁父”。
解析：“其”领起项籍与项梁的关系；“梁父”才改从项梁的立场讲他的父亲。

## 找原文证据：想再向上查项梁的父亲，哪一处已经把姓名写明？ {#c50.1.q4}
考点：c50.s.uncle
语境：c50.1.p.b

- [x] 梁父即楚将项燕 {#c50.1.q4.o1}
- [ ] 其季父项梁 {#c50.1.q4.o2}
  理由：这里给出项籍的叔父。
- [ ] 秦将王翦 {#c50.1.q4.o3}
  理由：王翦是出手的秦将。

提示：“即”将哪两种称法接在一起？
解析：“梁父”是关系，“楚将项燕”是身份和姓名，合起来正好在家系中落一笔。

## 单选：客人与周生说到的“尊君”“家君”各是谁？ {#c50.1.q5}
考点：c50.s.father
语境：c50.1.p.c

- [ ] 前一次指客父，后一次指周父 {#c50.1.q5.o1}
  理由：发问的人敬称听话人的父亲。
- [ ] 前一次指周父，后一次指伯父 {#c50.1.q5.o2}
  理由：“家君少从伯父学”把两位长辈分开说。
- [x] 两次都指周生的父亲 {#c50.1.q5.o3}

提示：读出谁向谁发问，谁作答。
解析：周生接过关于父亲的问题说明求学经过，两种称呼是同一个人从两边听到的叫法。

## 单选：周生说“伯父长家君三岁”，怎样画两人的关系？ {#c50.1.q6}
考点：c50.s.uncle
语境：c50.1.p.c

- [ ] 父子两代，伯父年长 {#c50.1.q6.o1}
  理由：“伯父”从周生这里称父亲的兄长。
- [ ] 师生之间没有亲属关系 {#c50.1.q6.o2}
  理由：两人确实有教与学的事，也同时有兄弟关系。
- [x] 同辈兄弟，伯父年长 {#c50.1.q6.o3}

提示：别只凭“从……学”排辈。
解析：“长……三岁”交代兄弟的年差。哥哥教弟弟，并未因此成为弟弟的父辈。

## 找原文证据：哪两个字是来客开口时对周生父亲的敬称？ {#c50.1.q7}
考点：c50.s.father
语境：c50.1.p.c

- [ ] 家君少 {#c50.1.q7.o1}
  理由：这是周生开始讲父亲幼年求学。
- [x] 尊君 {#c50.1.q7.o2}
- [ ] 客问 {#c50.1.q7.o3}
  理由：这是叙述者交代谁开口。

提示：回到第一句问话。
解析：“尊”向着对方；若把问话改作第三人称，就是“客问周生之父尝受业于谁”。

## 单选：若把“伯父”改写成一句不含亲属专称的话，哪一种保住了原意？ {#c50.1.q8}
考点：c50.s.uncle
语境：c50.1.p.c

- [x] 教我父亲读书的是他哥哥 {#c50.1.q8.o1}
- [ ] 教我父亲读书的是我哥哥 {#c50.1.q8.o2}
  理由：伯父在周生父亲这一代。
- [ ] 教我父亲读书的是他儿子 {#c50.1.q8.o3}
  理由：这会把师长往下错放一代。

提示：把周生心里的“我”保留下来。
解析：“伯父”从周生称，“他哥哥”从周生的父亲称。改用不同的人作起点，才要换说法。
