# 课文：同一个“遗”，东西怎么换了主人 {#lex40.3}
简介：礼物和失物都可能过手。借动词两旁的人与物，重画它们的去向。
回读：skill.vocab.11.1 lex40.3.p2
  skill.vocab.11.2 lex40.3.p3

## 正文

“遗”读 yí，可以说人在路上丢了东西；“道不拾遗”又把人遗落的东西直接叫作“遗”。读 wèi 时，东西是特地送给别人的。试将“舟中遗一笠”与“遗舟人一笠”摆在一起：前一句只给出遗落的位置，后一句多出了一个收笠的人。

真读一段话，不一定每回都有“以某物遗某人”这样齐整的说法。有人寻找、有人归还，通常是失物；有人拜受、写信称谢，就该看看是谁送的。同一句里也可能有古今相沿的说法：和今天说“负重前行”一样，若写“负书囊而行”，书袋是实实在在背在身上的。

## 知识点：遗（yí），失落以及失落之物 {#lex.s.lose}
义项：从遗落、寻访或拾取辨认失物义
领域：实词
要诀：留意后来的人是在找、在拾，还是在收礼。
讲解：“遗钥于门”说钥匙遗落在门边；“收其所遗”中的“所遗”指遗落的那些东西。
例句：lex40.3.p1

## 原文：古籍引文 {#lex40.3.p1}
> 秦民大说，道不拾遗，山无盗贼，家给人足。
译文：秦国百姓十分高兴，道上无人拾取他人遗失的东西据为己有；山间没有盗贼，各家生活充足。
词注：说：同“悦”，高兴。

## 单选：“道不拾遗”的“遗”用白话补足，指的是什么？ {#lex40.3.q1}
考点：lex.s.lose
语境：lex40.3.p1

- [ ] 百姓接到的遗命 {#lex40.3.q1.o1}
  理由：下文写盗贼与生活，与宣读遗命无关。

- [x] 旁人失落在路上的财物 {#lex40.3.q1.o2}

- [ ] 路人送给彼此的礼物 {#lex40.3.q1.o3}
  理由：赠物当面有受者，这里写道上无人拾取失物。

提示：想一想“拾”的对象。
解析：“拾”需要一个能从路上捡起的东西；这里用“遗”称失物。

## 单选：淮南王“大喜”之后，财物发生了怎样的转移？ {#lex40.3.q2}
考点：skill.vocab.11.1
语境：lex40.3.p2

- [ ] 王得到一批珍宝才感到欢喜 {#lex40.3.q2.o1}
  理由：“大喜”已在赠礼之前，“遗”的施事也是王。

- [ ] 王在路上遗失钱财 {#lex40.3.q2.o2}
  理由：“厚”在这里写赠与之多，配合王的喜意。

- [x] 王把自己的财物厚赠给对方 {#lex40.3.q2.o3}

提示：先找“大喜”和“遗”共用的主语。
解析：“厚遗”由王发出，后面列的是赠礼。

## 原文：教学例句 {#lex40.3.p3}
> 客负书囊而行，遗印于驿，去十里始觉。驿卒拾之，以书告客，客返而取焉。
译文：客人背着书袋出发，却把印章遗落在驿站，走了十里才察觉。驿卒捡到后写信通知，客人回来取走了。
词注：驿：驿站。

## 单选：客人离站时为什么没把印带走？ {#lex40.3.q3}
考点：lex.s.lose
语境：lex40.3.p3

- [x] 不慎把印留在驿站，到路上才察觉 {#lex40.3.q3.o1}

- [ ] 作为送给驿卒的酬谢 {#lex40.3.q3.o2}
  理由：若印已赠人，专程回来取走便与下文不合。

- [ ] 交了押金，约好十里后再来 {#lex40.3.q3.o3}
  理由：文中写“始觉”，没有约定保管。

提示：看他是哪时才发现印不在身边。
解析：“始觉”配合后来的“返而取”，说明印是失落的。

## 找原文证据：画客人离驿的情形。哪几个字明确说他背着什么？ {#lex40.3.q4}
考点：skill.vocab.11.2
语境：lex40.3.p3

- [ ] 遗印于驿 {#lex40.3.q4.o1}
  理由：这是他遗漏在驿站里的东西。
- [ ] 以书告客 {#lex40.3.q4.o2}
  理由：这封信是驿卒后来写的。
- [x] 负书囊而行 {#lex40.3.q4.o3}

提示：先分清随身带走和留在驿站的东西。
解析：“负书囊”与今天的“负重”一样，写的是用背负物；“遗印”才是忘记带走的那一件。

## 原文：教学例句 {#lex40.3.p4}
> 姊以所织帛遗妹，代为裁衣。妹藏其余，曰：“此吾姊所遗也。”
译文：姐姐把自己织的帛送给妹妹，还替她裁衣。妹妹收好余料，说这是姐姐给的。
词注：帛：丝织品。

## 单选：这段话里的帛原是谁的，后来给谁？ {#lex40.3.q5}
考点：skill.vocab.11.1
语境：lex40.3.p4

- [x] 原是姐姐织的，由姐姐给妹妹 {#lex40.3.q5.o1}

- [ ] 原是妹妹的，交姐姐代卖 {#lex40.3.q5.o2}
  理由：妹妹称礼物来自姐姐，全文未说售卖。

- [ ] 是妹妹送给裁衣人的工钱 {#lex40.3.q5.o3}
  理由：裁衣是姐姐代劳，开头的“遗”已把帛交给了妹妹。

提示：先看“遗”紧接着的是哪一个人。
解析：“以所织帛遗妹”明写礼物和受礼人。

## 单选：“此吾姊所遗也”中的“此”指什么？ {#lex40.3.q6}
考点：skill.vocab.11.1
语境：lex40.3.p4

- [ ] 姐姐忘在妹妹家的裁衣刀 {#lex40.3.q6.o1}
  理由：全文没有刀，也没有姐姐寻找东西。

- [ ] 妹妹准备送还的一件成衣 {#lex40.3.q6.o2}
  理由：妹妹收的是“余”，不是另交出去的成衣。

- [x] 姐姐送来的帛中剩下的部分 {#lex40.3.q6.o3}

提示：把妹妹说的话接回她手中所藏的东西。
解析：“妹藏其余”先写妹妹收起余料，“此”承接余下的帛。

## 原文：教学例句 {#lex40.3.p5}
> 舟子遗篙于浦，童拾而归之。舟子以鱼遗童，童拜而受。
译文：船夫把篙遗落在水边，孩子捡到后归还。船夫送鱼给孩子，孩子行礼收下。
词注：浦：水边。
  篙：撑船的长竿。

## 找原文证据：把第一句的“遗”读成赠送，会与哪个动作冲突？ {#lex40.3.q7}
考点：lex.s.lose
语境：lex40.3.p5

- [x] 童拾而归之 {#lex40.3.q7.o1}

- [ ] 童拜而受 {#lex40.3.q7.o2}
  理由：孩子拜受的是后来送的鱼。

- [ ] 舟子以鱼遗童 {#lex40.3.q7.o3}
  理由：这一处才写有意送给孩子的礼物。

提示：先追篙的来去，再看鱼。
解析：孩子把捡到的篙还给失主，才引出船夫的谢礼。

## 单选：孩子最后收下的是谁给的什么？ {#lex40.3.q8}
考点：skill.vocab.11.1
语境：lex40.3.p5

- [ ] 船夫先前遗失的篙 {#lex40.3.q8.o1}
  理由：孩子已经把篙归还。

- [ ] 过路人交托给船夫的鱼 {#lex40.3.q8.o2}
  理由：赠鱼的是答谢孩子的舟子。

- [x] 船夫送的鱼 {#lex40.3.q8.o3}

提示：分清前一句的“归”与后一句的“受”。
解析：“以鱼”说物，“遗童”说给谁，随后孩子拜受。
