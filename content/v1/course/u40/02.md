# 课文：两人相得，为什么还说“恨” {#lex40.2}
简介：读一场相知恨晚的相遇。人物在惋惜什么？“恨”后面接的几个字就能回答。

## 正文

两个人相处得十分融洽，却说“恨相知晚”。若按今天最容易想到的“仇恨”读，便要追问他们恨对方什么。把“相知晚”连起来读，惋惜的原来是相识得太迟。

古今都用的字，有的改变了所指的范围。今天随处可见以“河”为名的水道，但先秦叙事里单说“河”，在相应的地理语境里往往专指黄河。也有古义反而更宽的：“臭”可以泛指气味，香、腥还得另看。再如“爪牙之士”，本可指担任护卫的勇士；若径自添上“帮凶”，人物的态度便成了译者加给他的。

## 知识点：恨，惋惜一件事 {#lex.s.regret}
义项：因事不遂意或做得太迟而遗憾
领域：实词
要诀：“恨”后面是一个仇人，还是一件未能如愿的事？
讲解：若两人相投却“恨相知晚”，他们惋惜的是相识太迟。
例句：lex40.2.p1

## 知识点：河，古地理语境里的黄河 {#lex.s.river}
义项：凭渡口、支流等地理线索认出黄河专名
领域：实词
要诀：把说到的渡口、支流放回同一张图上。
讲解：古文中的“河”有时是黄河的专称。若年代、地点都不明，仍须查地图或篇注。
例句：lex40.2.p3

## 知识点：臭，泛指气味 {#lex.s.smell}
义项：读出气味本身，再判断香、腥等性质
领域：实词
要诀：是什么的气味？原句用什么字说明好闻与否？
讲解：指气味时今常读 xiù。“其臭清芬”说闻到清香，更不能照今天常说的“臭了”来读。
例句：lex40.2.p4

## 知识点：爪牙，守卫或受倚重的武士 {#lex.s.guard}
义项：在兵卫语境中读出对勇士的称呼
领域：实词
要诀：谁这样称呼谁？紧接着安排了什么职分？
讲解：古书中“爪牙”可借猛兽赖以自卫的爪和牙说护卫、勇士。褒贬还要看说话人。
例句：lex40.2.p2

## 原文：古籍引文 {#lex40.2.p1}
> 两人相为引重，其游如父子然。相得驩甚，无厌，恨相知晚也。
译文：两人互相推重，交往亲密如父子。在一起欢洽得很，总不厌倦，只遗憾相识太晚。
词注：引重：推重，看重。
  驩：同“欢”。

## 单选：读完“恨相知晚”，可以给这两个人写下怎样的评语？ {#lex40.2.q1}
考点：lex.s.regret
语境：lex40.2.p1

- [ ] 交情已有裂痕，父子之情使他们忍耐 {#lex40.2.q1.o1}
  理由：“如父子”是说亲近，未写两人交恶。

- [x] 相处十分投契，只可惜结交得迟 {#lex40.2.q1.o2}

- [ ] 起初相投，后来因一人失约而结怨 {#lex40.2.q1.o3}
  理由：“晚”说相识晚，文中没有约会迟到。

提示：找出“恨”的究竟是哪件事。
解析：“恨”所指是“相知晚”这件事；前面的“相得驩甚”也与惋惜相合。

## 原文：古籍引文 {#lex40.2.p2}
> 予，王之爪牙。胡转予于恤，靡所止居？
译文：我是王的护卫。为什么把我调入忧患之中，使我没有可以安居的地方？
词注：予：我。
  胡：为什么。
  恤：忧患。

## 单选：这位说话人先说“予，王之爪牙”，想交代自己的什么身份？ {#lex40.2.q2}
考点：lex.s.guard
语境：lex40.2.p2

- [ ] 向王进谏的文官 {#lex40.2.q2.o1}
  理由：这里以爪牙说守卫的武力，未提进谏职分。

- [ ] 替敌人行事的奸细 {#lex40.2.q2.o2}
  理由：“王之”明说自己为王效力，后面才发出怨言。

- [x] 承担王的护卫之责的武士 {#lex40.2.q2.o3}

提示：先分清是在介绍自己，还是在骂别人。
解析：他先陈述自己的职分，再质问为何这样调动自己。

## 原文：教学例句 {#lex40.2.p3}
> 晋使至孟津，河涨不得渡。将军命爪牙之士护使者，俟水落乃济。
译文：晋国使者到了孟津，黄河水涨，不能过河。将军派勇士护送使者，等水退了才渡过去。
词注：孟津：黄河渡口。
  俟：等。

## 单选：古地图把孟津标在黄河上。本段的“河涨”该标在哪里？ {#lex40.2.q3}
考点：lex.s.river
语境：lex40.2.p3

- [x] 孟津所在的黄河河道 {#lex40.2.q3.o1}

- [ ] 使者遇到的每条支流 {#lex40.2.q3.o2}
  理由：文字只说孟津此渡，不能扩到所有支流。

- [ ] 晋国境内某条叫“涨”的河 {#lex40.2.q3.o3}
  理由：“涨”写水位上升，是不能渡的缘故。

提示：找出使者已经到达的渡口。
解析：渡水的地点在孟津，这给“河”专指哪条水道提供了依据。

## 单选：“爪牙之士”到了渡口做什么？ {#lex40.2.q4}
考点：lex.s.guard
语境：lex40.2.p3

- [ ] 替将军爪取使者财物 {#lex40.2.q4.o1}
  理由：“护”写保护，文中没有劫掠。

- [ ] 带猎兽去追踪使者 {#lex40.2.q4.o2}
  理由：“之士”明说是人。

- [x] 奉将军命保护使者 {#lex40.2.q4.o3}

提示：读“命”后面那一整件事。
解析：“命……护使者”写清所任的差事，“爪牙”在这里指可供护卫的武士。

## 原文：教学例句 {#lex40.2.p4}
> 渭水东流入河。舟载兰过其会，岸人闻其臭，曰：“清芬满舟。”
译文：渭水向东汇入黄河。有船载着兰草经过汇流处，岸边的人闻到气味，说满船清香。
词注：会：两水相会处。
  清芬：清香。

## 单选：岸边的人到底闻到了什么？ {#lex40.2.q5}
考点：lex.s.smell
语境：lex40.2.p4

- [x] 船上兰草的清香 {#lex40.2.q5.o1}

- [ ] 腐烂兰草的恶臭 {#lex40.2.q5.o2}
  理由：“清芬”与腐败的气味不合。

- [ ] 两条河汇流时的泥腥气 {#lex40.2.q5.o3}
  理由：岸人称清香满舟，所指是船上的兰草。

提示：看说话人用哪两个字描写这种气味。
解析：“臭”指气味，气味怎样须接着读“清芬”。

## 单选：若在古地图上补画开头的水势，该给“河”怎样标名、画怎样的箭头？ {#lex40.2.q6}
考点：lex.s.river
语境：lex40.2.p4

- [ ] 从黄河流出的渭水 {#lex40.2.q6.o1}
  理由：“渭水……入河”将渭水写在汇入的一方。

- [ ] 两水相会后新开的人工渠 {#lex40.2.q6.o2}
  理由：“河”在这里已有所指，文中未记开渠。

- [x] 接纳渭水的黄河 {#lex40.2.q6.o3}

提示：依“入”字画出水流的箭头。
解析：“入”写汇入的方向。渭水是支流，“河”是它流入的黄河。

## 原文：教学例句 {#lex40.2.p5}
> 病者失其嗅，兰与鲍鱼置前，皆不能辨其臭。医后至，恨未及早治之。
译文：病人失去嗅觉，兰草和咸鱼放在面前，也分辨不出它们的气味。医生到得晚，遗憾未能早点治他。
词注：鲍鱼：这里指气味浓烈的腌鱼。

## 单选：病人不能“辨其臭”，若只解释为“辨认恶臭”，漏掉了哪一边？ {#lex40.2.q7}
考点：lex.s.smell
语境：lex40.2.p5

- [x] 兰草也有香气，这里兼说两种气味 {#lex40.2.q7.o1}

- [ ] 医生也闻不到鱼腥 {#lex40.2.q7.o2}
  理由：失去嗅觉的是病人。

- [ ] 腌鱼其实没有气味 {#lex40.2.q7.o3}
  理由：把腌鱼放在兰草旁，正是为了比较。

提示：看看病人面前放了哪两样东西。
解析：“兰与鲍鱼”同作比较对象，“臭”囊括香气和腥气。

## 单选：医生所“恨”的是什么？ {#lex40.2.q8}
考点：lex.s.regret
语境：lex40.2.p5

- [ ] 病人为难自己，不肯求医 {#lex40.2.q8.o1}
  理由：没有病人拒诊的叙述。

- [ ] 别人把腌鱼带到了病室 {#lex40.2.q8.o2}
  理由：“恨”后说的是未及早治，并非气味难闻。

- [x] 没能早点给病人医治 {#lex40.2.q8.o3}

提示：先读“恨”后面的几个字。
解析：“恨”直接领起“未及早治之”，说到迟误的遗憾。
