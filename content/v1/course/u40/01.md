# 课文：缓急、参差，要不要逐字读 {#lex40.1}
简介：一封求援的信里说“有缓急”，对方该从容等候，还是马上动身？

## 正文

把“道路有缓急”放在议事的场合，可以是在分轻重缓急。换成“若有缓急，叩门呼我”，可不会有人专在事情舒缓时半夜敲门。“缓急”两字并见，这里说的却是急难。读这类偏义复词，要看看当时究竟出了什么事。

“参差”的两个字又是另一回事。“竹影参差”写竹影高低错落；单查“参”或“差”，再拼回去，很难说清眼前的景象。“参差”“踟蹰”这类联绵词，读不通时可以整词查。倒也不必把所有相邻的字都当成一词：“地／方百里”，说的还是一片土地有多大。

## 知识点：由动作判明偏义复词中着重的一边 {#lex.s.bias}
义项：两个意思并列成词，辨当下事件实际关涉的一边
领域：实词
要诀：是谁遇上了什么事？两边的意思都与这件事相合吗？
讲解：“有缓急”若引出求援，着重在急难。“缓急有序”中的轻重两头却都要考虑。
例句：lex40.1.p1

## 知识点：把联绵词合起来读 {#lex.s.linked}
义项：将描写状态的两个音节合查，读出整体意思
领域：实词
要诀：先试着说出所见的模样，再看需不需要把两字拆开。
讲解：“踟蹰”写人迟疑不前，“参差”写长短高低不齐。一个词说出一种样子。
例句：lex40.1.p3

## 原文：古籍引文 {#lex40.1.p1}
> 太仓公将行会逮，骂其女曰：“生子不生男，有缓急非有益也！”
译文：太仓公将要被押走，他责骂女儿们，说自己没有儿子，遇到急难时女儿帮不上忙。这是他被捕时说的气话。
词注：会逮：面临被捕押送。

## 单选：太仓公说“有缓急”，眼前就有什么事？ {#lex40.1.q1}
考点：lex.s.bias
语境：lex40.1.p1

- [ ] 家里有些事情从容，有些事情匆忙 {#lex40.1.q1.o1}
  理由：他说的是当下这一桩困境，未把家事分作两类。

- [x] 自己将被押走，正遇到急难 {#lex40.1.q1.o2}

- [ ] 女儿要从容商议他几时出行 {#lex40.1.q1.o3}
  理由：行程由拘捕决定，父亲并非请女儿安排日子。

提示：先看他说话前正要被怎样处置。
解析：“将行会逮”已经说到拘捕，这里的“急”有着落。

## 单选：怎样转述父亲的话，能保留“有缓急”的意思？ {#lex40.1.q2}
考点：lex.s.bias
语境：lex40.1.p1

- [x] 他以为家中遇难时女儿帮不上忙 {#lex40.1.q2.o1}

- [ ] 他说女儿平日办事总是忽快忽慢 {#lex40.1.q2.o2}
  理由：“缓急”落在家中遭遇的变故上，未说女儿动作快慢。

- [ ] 他说自己打算延期受审 {#lex40.1.q2.o3}
  理由：句里没有推迟或改期的请求。

提示：看“有缓急”是说女儿的举动，还是她们父亲的处境。
解析：父亲埋怨的是此时无人解救；这里转述他的话，也就保留了说话人的偏见。

## 原文：教学例句 {#lex40.1.p2}
> 邻翁嘱守门者：“吾若有缓急，虽夜，叩门勿拒。”后数日水入其庐，翁果夜至。
译文：邻家老翁嘱咐看门人，若遇急难，哪怕在夜里敲门也请开门。几天后家里进了水，他果然连夜来了。
词注：庐：屋舍。

## 找原文证据：在老翁后来所遇的事中，哪几个字把“急”落到了实处？ {#lex40.1.q3}
考点：lex.s.bias
语境：lex40.1.p2

- [ ] 翁果夜至 {#lex40.1.q3.o1}
  理由：这说明他依约到了，洪水才是他求援的缘故。

- [x] 水入其庐 {#lex40.1.q3.o2}

- [ ] 后数日 {#lex40.1.q3.o3}
  理由：这一处交代两件事相隔多久。

提示：找出使他非出门求助不可的变故。
解析：洪水进了屋，他需要马上求援。

## 原文：教学例句 {#lex40.1.p3}
> 庭竹参差，短者才及窗，长者已过檐。童子仰视，久之乃去。
译文：庭前的竹子高低不齐，短的才到窗前，高的已经过了屋檐。孩子抬头看了很久才走。
词注：檐：屋顶伸出墙外的部分。

## 找原文证据：若把“参”单独查作“参与”，哪处最能提醒你改读整词？ {#lex40.1.q4}
考点：lex.s.linked
语境：lex40.1.p3

- [ ] 童子仰视 {#lex40.1.q4.o1}
  理由：这是观竹人的动作，未交代有几人参与。

- [ ] 久之乃去 {#lex40.1.q4.o2}
  理由：这是孩子停留的时间。

- [x] 短者才及窗，长者已过檐 {#lex40.1.q4.o3}

提示：找说竹子高低的两句话。
解析：短竹高竹同写，正好说明“参差”的样子。

## 单选：画出“庭竹参差”，该怎样安排竹梢？ {#lex40.1.q5}
考点：lex.s.linked
语境：lex40.1.p3

- [ ] 只画三竿竹子，长短随意 {#lex40.1.q5.o1}
  理由：“参”在这里不单独记株数。

- [x] 有的只齐窗，有的高出檐口 {#lex40.1.q5.o2}

- [ ] 竹梢一律截在同一高度 {#lex40.1.q5.o3}
  理由：这与“短者”“长者”相抵触。

提示：“参差”在描摹竹子的哪一点？
解析：“参差”合在一起形容高低不齐。

## 原文：教学例句 {#lex40.1.p4}
> 行者至危桥，踟蹰桥侧。樵者已渡，回顾相招，乃举足。
译文：行人来到险桥前，在桥边迟疑着。打柴人已经过去，回头招呼，他才迈步。
词注：樵者：打柴人。

## 单选：“踟蹰桥侧”时，行人站在哪一边？ {#lex40.1.q6}
考点：lex.s.linked
语境：lex40.1.p4

- [ ] 对岸，正等打柴人赶来 {#lex40.1.q6.o1}
  理由：已经先渡过去的是樵者。

- [ ] 桥中央，正在向前疾跑 {#lex40.1.q6.o2}
  理由：人还在“桥侧”，到最后才迈步。

- [x] 原来的一边，还迟疑着没过桥 {#lex40.1.q6.o3}

提示：谁先过桥，谁到末句才迈步？
解析：“乃举足”接在别人招呼之后，“踟蹰”写迟疑不前。

## 找原文证据：查词时应先合查哪一处，才能知道行人起初怎么了？ {#lex40.1.q7}
考点：lex.s.linked
语境：lex40.1.p4

- [ ] 回顾 {#lex40.1.q7.o1}
  理由：这是打柴人已经过桥后的举动。

- [x] 踟蹰 {#lex40.1.q7.o2}

- [ ] 桥侧 {#lex40.1.q7.o3}
  理由：这两字只说明在桥边。

提示：先分清哪几个字说的是还没过桥的人。
解析：两字合写迟疑的样子，把它们硬拆成先后两个动作反会失去句意。

## 原文：教学例句 {#lex40.1.p5}
> 盗入人园圃，负其枣而出。主人见枣树摧折，告之里正。
译文：有人进别人园中偷枣，背着枣逃出。园主见枣树折损，报给里正。
词注：园：旧时可指种植果树的园地。
  圃：旧时可指种菜的园地。

## 单选：若按被盗的作物说明“入人园圃”，哪一说最稳妥？ {#lex40.1.q8}
考点：lex.s.bias
语境：lex40.1.p5

- [ ] 他先偷枣，随后又进菜地偷菜 {#lex40.1.q8.o1}
  理由：没有第二次行窃的记载。

- [ ] 他偷走的是菜苗，枣树只是路标 {#lex40.1.q8.o2}
  理由：“负其枣”写得很明白。

- [x] 他进了人家的果园偷枣 {#lex40.1.q8.o3}

提示：把“园圃”后面两次出现的作物合起来看。
解析：负去的是枣，折损的是枣树；这段的“园圃”着重在种果树的园。
