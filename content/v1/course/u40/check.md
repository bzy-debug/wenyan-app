# 检查：荒年开仓，陌上失书 {#check.40}

## 原文：教学例句 {#lex40.check.p1}
> 岁旱，乡人约曰：“有缓急者，告于仓长。”老农踟蹰门外，仓长引之入，问家尚有几日粮。
译文：年成干旱，乡人约定，遇有急难的人可以告诉仓长。一个老农在门外迟疑，仓长引他进来，问家里还剩几天的粮。
词注：岁旱：年成干旱。

## 单选：哪种人符合这里的“有缓急者”？ {#lex40.check.q1}
考点：lex.s.bias
语境：lex40.check.p1

- [ ] 从容有余粮、愿意代管粮仓的人 {#lex40.check.q1.o1}
  理由：这一约定写谁可来告急，并未招募管仓人。

- [x] 遭遇急难、眼下需要求援的人 {#lex40.check.q1.o2}

- [ ] 办事快的人和办事慢的人 {#lex40.check.q1.o3}
  理由：仓长问的是存粮，并不挑办事快慢。

提示：先看歉收的背景，再看仓长问的第一句话。
解析：遇到大旱，问话又落在家里还剩几天粮，约定为救急而立。

## 单选：老农被引进门以前是怎样的情形？ {#lex40.check.q2}
考点：lex.s.linked
语境：lex40.check.p1

- [x] 在门外犹疑着，没有立刻进去 {#lex40.check.q2.o1}

- [ ] 已坐在仓里清点粮食 {#lex40.check.q2.o2}
  理由：“门外”还在外面。

- [ ] 大声催促仓长出来 {#lex40.check.q2.o3}
  理由：“踟蹰”没有催促的意思。

提示：分清“引之入”前后的所在。
解析：“踟蹰”整词写犹疑之态；进门是仓长引他以后。

## 原文：教学例句 {#lex40.check.p2}
> 友人以桂枝来，满室闻其臭。主人念亡友昔尝植桂，叹曰：“恨昔未及同游其园。”
译文：朋友带来桂枝，满屋都能闻到桂香。主人想起亡友曾种桂树，遗憾当年没能一起游园。
词注：亡友：已去世的朋友。

## 单选：“满室闻其臭”中的“其”承接桂枝，整句是什么意思？ {#lex40.check.q3}
考点：lex.s.smell
语境：lex40.check.p2

- [ ] 亡友的花园种得不好，散发恶气 {#lex40.check.q3.o1}
  理由：花园是在主人回忆中提起，眼前的气味在室内。

- [x] 屋里都能闻见桂枝的气味 {#lex40.check.q3.o2}

- [ ] 闻到屋内某处有腐物，座客都怪罪来客 {#lex40.check.q3.o3}
  理由：只有桂枝是“其”所指，文中没有责客的话。

提示：先看是哪样东西刚刚进屋。
解析：这里说带进屋里的桂枝散发气味，没有说它坏了。

## 单选：主人叹的是什么？ {#lex40.check.q4}
考点：lex.s.regret
语境：lex40.check.p2

- [x] 自己未能趁朋友在世时和他同游 {#lex40.check.q4.o1}

- [ ] 有人折断桂枝，因此痛恨来客 {#lex40.check.q4.o2}
  理由：“恨昔未及”已明写所憾的往事。

- [ ] 他和已故朋友曾在园中争执 {#lex40.check.q4.o3}
  理由：他感叹两人未能同游，更谈不上文中记有园中争执。

提示：读出“未及”所领的动作。
解析：“恨”后是昔日未及同游，遗憾正由桂香勾起。

## 原文：教学例句 {#lex40.check.p3}
> 师遗弟子书一卷。弟子归，遗之于陌；明日访于耕者，始得其书。
译文：老师送弟子一卷书。弟子回家时把书掉在田间路上，次日向农人询问才找回来。
词注：陌：田间道路。

## 单选：第一次写“遗”时，书到了谁手中？ {#lex40.check.q5}
考点：skill.vocab.11.1
语境：lex40.check.p3

- [ ] 老师在路上遗失，弟子拾得 {#lex40.check.q5.o1}
  理由：“于陌”交代的是弟子归途所遇。

- [x] 老师把书送给了弟子 {#lex40.check.q5.o2}

- [ ] 耕者受弟子之托把书交给老师 {#lex40.check.q5.o3}
  理由：耕者第二天才出现。

提示：读完第一句就停下，看看已经出现了哪两个人。
解析：“师遗弟子书一卷”先说送、受的双方，再说所送的书。

## 单选：同一卷书为何要到第二天才重新找到？ {#lex40.check.q6}
考点：lex.s.lose
语境：lex40.check.p3

- [x] 弟子在田间路上把它遗失了 {#lex40.check.q6.o1}

- [ ] 弟子反悔，想讨回送给农人的礼物 {#lex40.check.q6.o2}
  理由：弟子只是向耕者打听，没有把书送给耕者的记载。

- [ ] 老师约好第二天才交书 {#lex40.check.q6.o3}
  理由：书在开头已经由老师交出。

提示：比较第一次“遗”后的人与第二次“遗”后的地点。
解析：第二个“遗”后跟地点，次日询访并找回书，正是寻失物的过程。
