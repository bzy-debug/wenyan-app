# 课文：从、将、率、引 {#vocab.2}
简介：分清走在前面带领的人与跟在后面的人。

## 正文

读“童从师入山”与“师率童入山”，两句都写师生同行，却从不同人起笔。前句让孩子作主语，“从师”表示跟随；后句让老师作主语，老师带领孩子。**把主语画在箭头的起点，再写“跟随谁”或“带领谁”。**“将”也能作领兵的动词，不要见到它就一律当成“快要”。

## 知识点：从 {#skill.vocab.2.1}
义项：跟随
领域：实词
要诀：看谁在前引路、谁随着对方行动。
讲解：“童从父入林”里父子同往，孩子“未敢独行”说明他跟在父亲身边。入林的人有两个，跟随的人只有孩子。
例句：p.vocab.2.1.example

## 原文：教学例句 {#p.vocab.2.1.example}
> 童从父入林，未敢独行。
译文：孩子随父亲进树林，不敢独行。

## 原文：教学例句 {#p.vocab.2.1.a}
> 门生从师行，师止，亦止。
译文：学生跟老师前行，老师停下，他也停下。

## 单选：这段话里的“从”是什么意思？ {#q.vocab.2.1}
考点：skill.vocab.2.1
语境：p.vocab.2.1.a

- [ ] 任凭 {#q.vocab.2.1.o1}
  理由：停走随着老师变化，说明两人相随。
- [ ] 来自 {#q.vocab.2.1.o2}
  理由：“师”指人，此处没有交代籍贯。
- [x] 跟随 {#q.vocab.2.1.o3}

提示：看谁在前引路、谁随着对方行动。
解析：老师停，学生也停，两人的动作构成跟随关系。

## 原文：古籍引文 {#p.vocab.2.1.b}
> 在陈绝粮，从者病，莫能兴。
译文：孔子一行在陈地断粮，随行的人都病弱了，没有人能起身。

## 单选：“从者”指哪一群人？ {#q.vocab.2.2}
考点：skill.vocab.2.1
语境：p.vocab.2.1.b

- [x] 跟着孔子出行的人 {#q.vocab.2.2.o1}
- [ ] 陈地所有百姓 {#q.vocab.2.2.o2}
  理由：“从者”按随行关系指人。
- [ ] 已经兴起的军队 {#q.vocab.2.2.o3}
  理由：“莫能兴”说的是无人能起身。

提示：看谁在前引路、谁随着对方行动。
解析：“从”在“者”前指跟从这一行动；断粮、生病的是随行者。

## 知识点：将 {#skill.vocab.2.2}
义项：率领
领域：实词
要诀：若“将”后直承人数或部队，试问谁统率谁。
讲解：“将军自将百人”有两个“将”。前者在官称中，后者接“百人”，是将军亲自率这百人的动作。
例句：p.vocab.2.2.example

## 原文：教学例句 {#p.vocab.2.2.example}
> 将军自将百人守渡。
译文：将军亲自率领一百人守渡口。

## 原文：教学例句 {#p.vocab.2.2.a}
> 令兄将乡兵，弟守仓。
译文：命令哥哥带领乡兵，弟弟看守粮仓。

## 单选：这段话里的“将”是什么意思？ {#q.vocab.2.3}
考点：skill.vocab.2.2
语境：p.vocab.2.2.a

- [ ] 快要 {#q.vocab.2.3.o1}
  理由：“乡兵”是被统领的人，不是将要发生的动作。
- [x] 率领 {#q.vocab.2.3.o2}
- [ ] 扶持 {#q.vocab.2.3.o3}
  理由：这里在分派统兵与守仓的职责。

提示：若“将”后直承人数或部队，试问谁统率谁。
解析：哥哥所领的是乡兵；“将”在此带对象，是率领。

## 原文：教学例句 {#p.vocab.2.2.e}
> 王命武将三百人先行，众皆听命于武。
译文：国君命武率三百人先行，众人都听武的指挥。

## 找原文证据：哪处说明武对这批人有指挥权？ {#q.vocab.2.4}
考点：skill.vocab.2.2
语境：p.vocab.2.2.e

- [x] 众皆听命于武 {#q.vocab.2.4.o1}
- [ ] 先行 {#q.vocab.2.4.o2}
  理由：这是出发先后。
- [ ] 三百人 {#q.vocab.2.4.o3}
  理由：人数不能单独说明谁指挥谁。

提示：若“将”后直承人数或部队，试问谁统率谁。
解析：众人服从武的命令，印证“将三百人”是率领这批人。

## 知识点：率 {#skill.vocab.2.3}
义项：带领
领域：实词
要诀：找“率”后面共同参与行动的人。
讲解：“长者率众修堤”可拆成谁领头、领着谁、做何事。领头的是长者，跟着一起修堤的是众人。
例句：p.vocab.2.3.example

## 原文：教学例句 {#p.vocab.2.3.example}
> 长者率众修堤。
译文：年长者带领大家修堤。

## 原文：教学例句 {#p.vocab.2.3.a}
> 村长率丁壮入谷，搜求失牛。
译文：村长带领壮丁进入山谷，搜寻走失的牛。

## 单选：这段话里的“率”是什么意思？ {#q.vocab.2.5}
考点：skill.vocab.2.3
语境：p.vocab.2.3.a

- [ ] 大概 {#q.vocab.2.5.o1}
  理由：“丁壮”是一群随行的人。
- [x] 带领 {#q.vocab.2.5.o2}
- [ ] 轻率 {#q.vocab.2.5.o3}
  理由：后面写的是带人入谷搜寻，没有评价态度。

提示：找“率”后面共同参与行动的人。
解析：“率丁壮”点明村长所带的人员，“入谷”写共同去向。

## 原文：教学例句 {#p.vocab.2.3.b}
> 雨坏桥，匠率其徒更架木，人乃得过。
译文：雨水冲坏了桥，工匠带徒弟重新架木，人们才得以通过。

## 单选：谁组织架木修桥？ {#q.vocab.2.6}
考点：skill.vocab.2.3
语境：p.vocab.2.3.b

- [ ] 行人带着工匠 {#q.vocab.2.6.o1}
  理由：“匠率其徒”已经写明领头者。
- [ ] 徒弟带着行人 {#q.vocab.2.6.o2}
  理由：行人是桥修好后得到方便的人。
- [x] 工匠带着徒弟 {#q.vocab.2.6.o3}

提示：找“率”后面共同参与行动的人。
解析：“率”前的工匠是带队的人；“其徒”是一起修桥的人。

## 知识点：引 {#skill.vocab.2.4}
义项：引导
领域：实词
要诀：对照领路者、跟随者与目的地。
讲解：“童引客入舍”以孩子为主语，客人才是要进屋的人。孩子领客人走进去，有一个引路、一个随行。
例句：p.vocab.2.4.example

## 原文：教学例句 {#p.vocab.2.4.example}
> 童引客入舍。
译文：孩子领客人进入屋舍。

## 原文：教学例句 {#p.vocab.2.4.a}
> 客迷于巷，里人引至县门。
译文：客人在巷中迷路，当地人领他到了县门。

## 单选：这段话里的“引”是什么意思？ {#q.vocab.2.7}
考点：skill.vocab.2.4
语境：p.vocab.2.4.a

- [ ] 援引 {#q.vocab.2.7.o1}
  理由：没有举出言论或成例。
- [x] 引导 {#q.vocab.2.7.o2}
- [ ] 延长 {#q.vocab.2.7.o3}
  理由：客人需要找路，县门是目的地。

提示：对照领路者、跟随者与目的地。
解析：开头交代迷路，结尾交代到达地点，由此可知是给人引路。

## 原文：教学例句 {#p.vocab.2.4.b}
> 寺门既启，僧引众客登楼观山。
译文：寺门打开后，僧人领众客登楼看山。

## 单选：僧人与客人怎样到楼上？ {#q.vocab.2.8}
考点：skill.vocab.2.4
语境：p.vocab.2.4.b

- [ ] 众客拖僧人上楼 {#q.vocab.2.8.o1}
  理由：“引”的前面是僧，后面是众客。
- [ ] 僧人叫客人留在门外 {#q.vocab.2.8.o2}
  理由：“登楼”已说明进入后的移动。
- [x] 僧人领客人上楼 {#q.vocab.2.8.o3}

提示：对照领路者、跟随者与目的地。
解析：句子先写领路的人，继而写所领的客人和共同目的地。
