# 检查：琴客离开山寺之后 {#check.21}

## 原文：教学例句 {#p.vocab.check.21.new1}
> 山寺雨止。琴客方出门，适闻舟人呼渡，遂从樵者登舟。
译文：山寺的雨停了。琴客刚出门，恰巧听见船夫招呼过渡，便跟着打柴人上了船。
词注：樵者：打柴的人。

## 单选：琴客是不是本来就和舟人约好了？看“适闻”应怎样回答？ {#q.vocab.check.21.new1}
考点：skill.vocab.shi-chance
语境：p.vocab.check.21.new1

- [ ] 是，听见喊声就说明琴客特意赶来 {#q.vocab.check.21.new1.o1}
  理由：赶上喊声也可能是偶然，“适”所写的正是这个巧合。
- [ ] 不是，他根本没听清叫的是什么 {#q.vocab.check.21.new1.o2}
  理由：后面真登了船；“闻”写的是听见，不是听错。
- [x] 只是恰巧听见招呼，文中没说有约 {#q.vocab.check.21.new1.o3}

提示：试把“适”放在“闻舟人呼渡”整件事前读。
解析：“方出门”碰上“呼渡”，两个原可各不相干的动作赶在了一起。

## 单选：谁跟在谁之后上了船？ {#q.vocab.check.21.new2}
考点：skill.vocab.2.1
语境：p.vocab.check.21.new1

- [x] 琴客跟着樵者 {#q.vocab.check.21.new2.o1}
- [ ] 樵者跟着琴客 {#q.vocab.check.21.new2.o2}
  理由：“从樵者”的动作仍由前句的琴客做。
- [ ] 舟人跟着琴客 {#q.vocab.check.21.new2.o3}
  理由：舟人负责在水边呼渡，没写他跟随乘客。

提示：找“遂从”的主语，再找“从”后的人。
解析：琴客一出门、二闻声、三从人登舟，三个动作都接在同一个人身上。

## 原文：教学例句 {#p.vocab.check.21.new2}
> 既渡，过漆工。工延之入，示以新琴。室暗，客就牖视其纹。
译文：渡过河以后，琴客拜访漆工。漆工请他进屋，拿新琴给他看。屋里暗，他就走到窗边看琴上的纹理。
词注：延：请进
  牖：窗。

## 找原文证据：“过漆工”是拜访，哪处能证明琴客没有只从门外路过？ {#q.vocab.check.21.new3}
考点：skill.vocab.1.4
语境：p.vocab.check.21.new2

- [ ] 室暗 {#q.vocab.check.21.new3.o1}
  理由：这是对室内光线的描写，本身没写谁与谁见面。
- [x] 工延之入 {#q.vocab.check.21.new3.o2}
- [ ] 既渡 {#q.vocab.check.21.new3.o3}
  理由：渡过河才到这里，这只交代路程。

提示：找漆工亲自对来客做的动作。
解析：漆工请他进屋，又拿琴给他看，这次“过”写的是上门相见。

## 单选：“就牖”时，是窗子发生了变化，还是人换了位置？ {#q.vocab.check.21.new4}
考点：skill.vocab.3.1
语境：p.vocab.check.21.new2

- [ ] 琴客马上把窗子关上 {#q.vocab.check.21.new4.o1}
  理由：“就”后是他靠近的地方，没有关窗动作。
- [ ] 漆工已经把窗子修好 {#q.vocab.check.21.new4.o2}
  理由：室内暗与后来“视其纹”相接，说的是借光，而非修窗。
- [x] 琴客走到窗边，好借光看琴纹 {#q.vocab.check.21.new4.o3}

提示：为什么要先交代“室暗”？
解析：室中光线不够，靠近窗子才能细看。“就”把人带到有光的地方。

## 原文：教学例句 {#p.vocab.check.21.new3}
> 日暮，客辞归。工引之出后巷，指渡口；客循旧道还寺。
译文：天晚了，客人告辞。漆工领他穿出后巷，指给他渡口。客人沿原来的路回到寺中。
词注：循：沿着。

## 单选：从后巷出去的这一段，谁给谁领路？ {#q.vocab.check.21.new5}
考点：skill.vocab.2.4
语境：p.vocab.check.21.new3

- [x] 漆工领琴客，并为他指渡口 {#q.vocab.check.21.new5.o1}
- [ ] 琴客领漆工，要陪他过河 {#q.vocab.check.21.new5.o2}
  理由：“工引之”的“之”接琴客，指路的仍是漆工。
- [ ] 两人一直同行回到寺里 {#q.vocab.check.21.new5.o3}
  理由：末句另起“客”，只说客人返回。

提示：留意“工引”到“客循”之间哪里换了主语。
解析：“引之”先领一段路，“指渡口”再告诉客人往哪儿去。漆工不必把人送到山寺。

## 单选：“客循旧道还寺”里的“还寺”，怎样接得上琴客起先从山寺出门？ {#q.vocab.check.21.new6}
考点：skill.vocab.3.4
语境：p.vocab.check.21.new3

- [x] 回到出发过的山寺，漆工只领了出后巷的那一段路 {#q.vocab.check.21.new6.o1}
- [ ] 头一次来到这座寺，因为漆工让他改去一个新住处 {#q.vocab.check.21.new6.o2}
  理由：寺在开篇已是琴客出门的地方。漆工指渡口，并没替客人换目的地。
- [ ] 重走旧路回到漆工家，当晚留宿，第二天才去山寺 {#q.vocab.check.21.new6.o3}
  理由：“寺”跟在“还”的后面，到了哪里当晚已交代清楚。

提示：把“旧道”的一头和全篇刚出发的位置连起来。
解析：“还寺”是回到山寺，走旧路是他的归途。漆工出巷指津以后，循路而还的是客人。
