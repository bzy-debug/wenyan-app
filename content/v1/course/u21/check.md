# 检查：途中遇到了谁，又往哪里去 {#check.21}

## 原文：教学例句 {#p.vocab.check.21.1}
> 商人自卫适陈。中道闻故友疾，乃过其舍。友不能起，握其手与语。明旦，商人复行。
译文：商人从卫地去陈地。半路听说老友病了，就去他的住处探望。朋友起不来，握着他的手交谈。第二天早上，商人继续赶路。

## 单选：这趟行程起初打算到哪里？ {#q.vocab.check.21.1}
考点：skill.vocab.1.1
语境：p.vocab.check.21.1

- [ ] 朋友住处 {#q.vocab.check.21.1.o1}
  理由：那是途中听到消息后才去的地方。
- [x] 陈地 {#q.vocab.check.21.1.o2}
- [ ] 卫地 {#q.vocab.check.21.1.o3}
  理由：“自卫”交代从哪里来。

提示：“自卫”与“适陈”分别放在出发、抵达的哪一头？
解析：商人从卫出发，本来要去陈。朋友的住处是他中途停下来的地方。

## 单选：哪一件事说明“过其舍”并非只经过门前？ {#q.vocab.check.21.2}
考点：skill.vocab.1.4
语境：p.vocab.check.21.1

- [x] 朋友握他的手交谈 {#q.vocab.check.21.2.o1}
- [ ] 商人从卫地来 {#q.vocab.check.21.2.o2}
  理由：这只交代出发地。
- [ ] 次日继续走 {#q.vocab.check.21.2.o3}
  理由：这是探望之后的行动。

提示：哪件事必须等两位朋友见了面才能做？
解析：朋友握着商人的手交谈。商人是进门看望病友，隔天才继续上路。

## 原文：教学例句 {#p.vocab.check.21.2}
> 吏急诣仓，僮从之。巷道甚曲，有老人引二人至仓后门。
译文：官吏急着去仓库，仆僮跟着他。巷道很曲折，有位老人把两人领到仓库后门。

## 单选：“从之”两字写的是谁跟谁？ {#q.vocab.check.21.3}
考点：skill.vocab.2.1
语境：p.vocab.check.21.2

- [x] 仆僮跟着官吏 {#q.vocab.check.21.3.o1}
- [ ] 官吏跟着仆僮 {#q.vocab.check.21.3.o2}
  理由：“僮”是“从”的主语。
- [ ] 老人跟着官吏 {#q.vocab.check.21.3.o3}
  理由：老人到下句才出现。

提示：“僮从之”的主语在“从”前，“之”承接前一个人。
解析：“之”指急着去仓的官吏。仆僮跟着他，两人后来一同由老人领路。

## 单选：谁解决了路难找的问题？ {#q.vocab.check.21.4}
考点：skill.vocab.2.4
语境：p.vocab.check.21.2

- [x] 给二人带路的老人 {#q.vocab.check.21.4.o1}
- [ ] 看守后门的人 {#q.vocab.check.21.4.o2}
  理由：后门是两人最终到达的地方。回头找带他们穿过曲巷的人。
- [ ] 独自去仓库的官吏 {#q.vocab.check.21.4.o3}
  理由：巷道曲折后写到别人带路。

提示：走过曲巷后，是谁把两人带到了仓的后门？
解析：“引二人”的是老人，仆僮与官吏都是他带路的人。

## 原文：教学例句 {#p.vocab.check.21.3}
> 桥上风烈，行人就石垣以避风。俄闻儿啼，趋至桥下，抱儿还于其母。
译文：桥上风大，行人靠近石墙避风。不久听到孩子哭，快步到桥下，抱起孩子交还母亲。

## 单选：行人如何利用石墙？ {#q.vocab.check.21.5}
考点：skill.vocab.3.1
语境：p.vocab.check.21.3

- [x] 靠近墙壁避风 {#q.vocab.check.21.5.o1}
- [ ] 动手修成墙壁 {#q.vocab.check.21.5.o2}
  理由：风大时要找遮挡，未写筑墙。
- [ ] 推倒墙壁通行 {#q.vocab.check.21.5.o3}
  理由：倒墙不能帮他挡风。

提示：把“就石垣”和后面的“以避风”连读。
解析：桥上风大。行人靠到石墙旁，借墙挡风。

## 单选：听到啼哭后，哪一处写行人加快了脚步？ {#q.vocab.check.21.6}
考点：skill.vocab.3.3
语境：p.vocab.check.21.3

- [ ] “俄”写风很猛烈 {#q.vocab.check.21.6.o1}
  理由：“俄”是从避风到听哭声相隔不久。
- [ ] “垣”写低头看路 {#q.vocab.check.21.6.o2}
  理由：垣是前面用来挡风的墙。
- [x] “趋”写快步赶去 {#q.vocab.check.21.6.o3}

提示：把从听见啼哭到桥下抱起孩子的动作连起来。
解析：“趋至桥下”写赶紧到桥下。后面的抱儿还母说明他急着去做什么。
