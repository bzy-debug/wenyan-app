# 课文：适、诣、造、过 {#vocab.1}
简介：区分目的地与沿途地点，读清谁特意去找谁。

## 正文

**先找出发点，再找目的地。** 自编例句“客适齐，过故人，明日复行”把两层行程叠在了一起。齐地是整段旅行的目的地，故人的住处是中途专程拜访之处。若下文写出“扣门”“延入”等动作，试把“造”“过”读成拜访，看看会不会比“经过门前”更能衔接。

## 知识点：适 {#skill.vocab.1.1}
义项：前往
领域：实词
要诀：看“适”后是否接地名，再核对人物是否已动身。
讲解：“商人适齐”中，齐是国名。“载布以行”写商人带着货物上路，由此可以把齐读成目的地。
例句：p.vocab.1.1.example

## 原文：教学例句 {#p.vocab.1.1.example}
> 商人适齐，载布以行。
译文：商人前往齐地，载着布匹出发。

## 原文：古籍引文 {#p.vocab.1.1.a}
> 子适卫，冉有仆。
译文：孔子前往卫国，冉有给他驾车。

## 单选：这段话里的“适”是什么意思？ {#q.vocab.1.1}
考点：skill.vocab.1.1
语境：p.vocab.1.1.a

- [ ] 适宜 {#q.vocab.1.1.o1}
  理由：冉有驾车点明孔子在出行。
- [x] 前往 {#q.vocab.1.1.o2}
- [ ] 恰好 {#q.vocab.1.1.o3}
  理由：“卫”是这趟车程所去的国家。

提示：看“适”后是否接地名，再核对人物是否已动身。
解析：卫是地名，“仆”在这里是驾车。把两句连起来，写的是前往卫国的行程。

## 原文：教学例句 {#p.vocab.1.1.b}
> 客自陈适宋，宿于道旁。
译文：旅人从陈地去宋地，中途住在路旁。

## 单选：旅人这趟行程的起点和终点分别在哪里？ {#q.vocab.1.2}
考点：skill.vocab.1.1
语境：p.vocab.1.1.b

- [ ] 从路旁前往陈地 {#q.vocab.1.2.o1}
  理由：宿于路旁只交代夜宿处。
- [ ] 从宋地前往陈地 {#q.vocab.1.2.o2}
  理由：“自”紧接陈，标出出发之处。
- [x] 从陈地前往宋地 {#q.vocab.1.2.o3}

提示：看“适”后是否接地名，再核对人物是否已动身。
解析：“自陈”标起点，“适宋”标目的地；住宿发生在途中。

## 知识点：诣 {#skill.vocab.1.2}
义项：到某人或某处去
领域：实词
要诀：留意“诣”的对象以及人物到达后做的事。
讲解：“民诣县门”先说百姓到了哪里，“请见长吏”再说求什么事。先到县门，还不等于已经见到官吏。
例句：p.vocab.1.2.example

## 原文：教学例句 {#p.vocab.1.2.example}
> 民诣县门，请见长吏。
译文：百姓来到县门，请求见长官。

## 原文：教学例句 {#p.vocab.1.2.a}
> 生有疑，抱书诣师，请辨其义。
译文：学生有疑问，抱书去找老师，请他辨析字义。

## 单选：这段话里的“诣”是什么意思？ {#q.vocab.1.3}
考点：skill.vocab.1.2
语境：p.vocab.1.2.a

- [ ] 派遣 {#q.vocab.1.3.o1}
  理由：学生自己抱着书，句中没有受派者。
- [ ] 造诣很深 {#q.vocab.1.3.o2}
  理由：疑问还要请教别人，谁正带书出行？
- [x] 到某人或某处去 {#q.vocab.1.3.o3}

提示：留意“诣”的对象以及人物到达后做的事。
解析：“抱书”是就教的准备，“请辨”说明师所在之处是他前往的目的地。

## 原文：教学例句 {#p.vocab.1.2.e}
> 翁诣县，吏延之入，问其所陈。
译文：老人到了县衙，官吏请他入内，问他要陈述什么。

## 找原文证据：哪一行动说明老人已到县衙门前？ {#q.vocab.1.4}
考点：skill.vocab.1.2
语境：p.vocab.1.2.e

- [ ] 问其所陈 {#q.vocab.1.4.o1}
  理由：这是入内后询问诉求。
- [x] 吏延之入 {#q.vocab.1.4.o2}
- [ ] 翁 {#q.vocab.1.4.o3}
  理由：这是前往县衙的人。

提示：留意“诣”的对象以及人物到达后做的事。
解析：官吏已能迎接他进门，由此印证“诣县”的去向。

## 知识点：造 {#skill.vocab.1.3}
义项：登门拜访
领域：实词
要诀：遇到“造”后接人名或称谓，寻找迎客、交谈的后文。
讲解：“客造友人”后紧接“叩其户”。叩的是朋友家的门，被拜访的是友人，两处指向同一次登门。
例句：p.vocab.1.3.example

## 原文：教学例句 {#p.vocab.1.3.example}
> 客造友人，叩其户。
译文：客人去拜访友人，敲响他的门。

## 原文：教学例句 {#p.vocab.1.3.a}
> 客造陶翁，翁出迎之，留饮。
译文：客人去拜访制陶老人，老人出门迎接，留下他喝酒。

## 单选：这段话里的“造”是什么意思？ {#q.vocab.1.5}
考点：skill.vocab.1.3
语境：p.vocab.1.3.a

- [ ] 成就 {#q.vocab.1.5.o1}
  理由：“出迎”“留饮”写的是会客过程。
- [x] 登门拜访 {#q.vocab.1.5.o2}
- [ ] 制作 {#q.vocab.1.5.o3}
  理由：老人出来迎客，“陶翁”是一个人。

提示：遇到“造”后接人名或称谓，寻找迎客、交谈的后文。
解析：“造陶翁”与老人迎接相应，“造”是登门拜访。

## 原文：教学例句 {#p.vocab.1.3.b}
> 生数造里师，未尝空手，或执枣栗。
译文：学生多次登门拜访乡里的老师，每次都带点东西，有时拿着枣栗。

## 单选：枣栗是学生什么时候拿着的？ {#q.vocab.1.6}
考点：skill.vocab.1.3
语境：p.vocab.1.3.b

- [x] 去拜访老师时 {#q.vocab.1.6.o1}
- [ ] 动手建造学舍时 {#q.vocab.1.6.o2}
  理由：文中只提拜见里师，并未营建屋舍。
- [ ] 在路上偶遇老师时 {#q.vocab.1.6.o3}
  理由：“数造”说明几次有意登门。

提示：遇到“造”后接人名或称谓，寻找迎客、交谈的后文。
解析：“数造”交代屡次拜访，所带枣栗是到老师处时拿的物品。

## 知识点：过 {#skill.vocab.1.4}
义项：拜访
领域：实词
要诀：看“过”的对象是不是人，下文有没有见面停谈。
讲解：“友过我”后两人能“与语终夕”，可见朋友专程来相见，并在我这里停留下来。
例句：p.vocab.1.4.example

## 原文：教学例句 {#p.vocab.1.4.example}
> 雨歇，友过我，与语终夕。
译文：雨停了，朋友来看我，和我谈了整夜。

## 原文：教学例句 {#p.vocab.1.4.a}
> 闻友病，遂过之，坐其榻旁。
译文：听说朋友生病，便去看望他，坐在他床边。

## 单选：这段话里的“过”是什么意思？ {#q.vocab.1.7}
考点：skill.vocab.1.4
语境：p.vocab.1.4.a

- [x] 拜访 {#q.vocab.1.7.o1}
- [ ] 超过 {#q.vocab.1.7.o2}
  理由：“之”指病友，坐在床边与竞赛无关。
- [ ] 犯错 {#q.vocab.1.7.o3}
  理由：听闻患病后采取的是探望的行动。

提示：看“过”的对象是不是人，下文有没有见面停谈。
解析：“坐其榻旁”说明已经到病友家中，“过之”是去探望他。

## 原文：教学例句 {#p.vocab.1.4.e}
> 季子过叔，叔设席延坐，问其近事。
译文：季子拜访叔父，叔父设席请他坐，问他的近况。

## 找原文证据：哪几个字最能说明叔父准备接待来人？ {#q.vocab.1.8}
考点：skill.vocab.1.4
语境：p.vocab.1.4.e

- [ ] 近事 {#q.vocab.1.8.o1}
  理由：这是随后谈论的内容。
- [x] 设席延坐 {#q.vocab.1.8.o2}
- [ ] 季子 {#q.vocab.1.8.o3}
  理由：这是来访者的称呼。

提示：看“过”的对象是不是人，下文有没有见面停谈。
解析：摆设坐席并请客人坐下，说明前面的“过叔”是登门拜访。
