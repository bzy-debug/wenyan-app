# 检查：这句话是听谁说的 {#check.11}

## 原文：古籍引文 {#p.check.11.a}
> 子夏之晋，过卫，有读史记者曰：“晋师三豕涉河。”子夏曰：“非也，是己亥也。夫己与三相近，豕与亥相似。”至于晋而问之，则曰：“晋师己亥涉河也。”
译文：子夏去晋，经过卫国，听到读史籍的人说“晋军三只猪渡河”。子夏认为应是干支纪日的“己亥”，理由是字形相近。到了晋国再询问，得到的说法果然是晋军在己亥日渡河。
出处：《吕氏春秋·察传》
作者：战国吕不韦门客集撰

## 单选：子夏到了晋国，比在卫国时多做了什么？ {#q.check.11.1}
考点：skill.l3.7.1
语境：p.check.11.a

- [x] 到事关的晋国查问记事的读法
- [ ] 在卫国增加听众却重复“三豕”
  理由：“至于晋”已换地点。
- [ ] 找来三只猪观察如何渡河
  理由：“三豕”是所争的字形读法。

提示：在卫国他是根据什么猜出读法的？到了晋国又怎样？
解析：在卫国，子夏看出两组字长得像，指出这里应当读“己亥”。到晋国后，他又向人查问了这件事。

## 单选：把在卫国听到的、到晋国问到的合起来，哪种讲法准确？ {#q.check.11.2}
考点：skill.l3.8.1
语境：p.check.11.a

- [x] 卫的读者说三豕；子夏据形近纠读，晋地问得己亥
- [ ] 晋国人先说三豕，子夏在卫替他们传话
  理由：两地的先后与发话者反了。
- [ ] 卫的读者当场承认自己故意误写
  理由：没有交代他承认或故意。

提示：标出第一、第二处“曰”分别属于谁。
解析：“三豕”是卫国读史的人念出来的。子夏说该是“己亥”，到晋国一问，得来的回答也是“己亥”。

## 原文：教学例句 {#p.check.11.b}
> 乡人失马。其弟曰：“吾得其迹矣：昨见客牵白马出东门。”邻童亦云。乡人责客，客指马曰：“子马有黑蹄，此马四蹄皆白。”客又曰：“子真善相马矣，不视蹄而识之！”乡人视之，谢而还。
译文：乡人丢马，弟弟说有了线索，昨天亲眼见一个客人牵着白马出了东门。邻家孩子也这样说。乡人责问客人，客人指出失马有黑蹄，眼前这匹四蹄全白。客人又说，您可真擅长相马，连蹄子也不看就认识它！乡人看后道歉回去。

## 单选：弟弟的“得其迹”究竟“得”了什么？ {#q.check.11.3}
考点：skill.l3.7.2
语境：p.check.11.b

- [x] 一条有人牵白马出门的线索
- [ ] 找到客人偷马的证据
  理由：所见只是牵马经过，并不能判定归属。
- [ ] 亲手抓回自己家的失马
  理由：后面还要靠蹄色辨认。

提示：“得其迹”之后，弟弟说自己亲眼见到了什么？
解析：弟弟看见客人牵白马出门，这是一条可追问的线索。他没有说已经找到了那匹丢失的马。

## 单选：邻童“亦云”，能从上文补出哪句话？ {#q.check.11.4}
考点：skill.l3.9.1
语境：p.check.11.b

- [ ] 他也断言那就是失马
  理由：弟弟只说看见一匹白马，没说看清是谁家的。
- [x] 他也说见过客人牵白马出东门
- [ ] 他也看见马有黑蹄
  理由：蹄色是客人后来提出的。

提示：只补上一个人的原话，不添加推断。
解析：弟弟说昨天见客人牵白马出东门，“亦云”就是邻童也这样说。两人都没说亲自认过马蹄。

## 单选：乡人去“责客”，能说明什么？ {#q.check.11.5}
考点：skill.l3.9.2
语境：p.check.11.b

- [ ] 客人已承认拿错失马
  理由：客人答的是两匹马的差别。
- [x] 乡人凭听来的所见怀疑客人
- [ ] 叙述者已经查明客人偷马
  理由：叙述写的是乡人去责问。

提示：乡人开口责问时，已经比过两匹马的蹄色了吗？
解析：乡人听说有人牵白马，就责问客人。直到人家指出蹄色不同，他才细看，没法凭先前的传闻认定是同一匹。

## 单选：客人为何称乡人“善相马”？ {#q.check.11.6}
考点：skill.l3.8.2
语境：p.check.11.b

- [x] 顺着乡人自以为辨认无误的态度，用没看蹄色反问其本领
- [ ] 告诉乡人四蹄皆白是良马的公认标准
  理由：这里只关乎是不是同一匹马。
- [ ] 真心认可乡人已逐一比过马蹄
  理由：乡人是听完才看蹄。

提示：把“善相马”与“不视蹄”放在一起读。
解析：嘴上说“善相马”，下半句却指出乡人连马蹄也没看。这话是在讥讽他认得太快、看得不仔细。
