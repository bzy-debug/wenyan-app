# 检查：辨别消息与本意综合检查 {#check.11}

## 原文：教学例句 {#p.story.check.11.a}
> 行旅夜闻犬声，仆曰：“盗至矣。”主人使视之，见邻儿过门，犬逐之，乃止。主人曰：“闻犬而谓有盗，过也。”
译文：旅行的人夜里听见狗叫，仆人说来了贼。主人派人察看，见是邻家孩子经过，狗追了他一阵才停。主人说听见狗就以为有贼，是错判。
词注：盗：贼，这是仆人听到狗叫时的猜测。
  逐：追赶，狗追的是门外经过的孩子。

## 单选：谁断言“盗至矣”？ {#q.story.check.11.1}
考点：skill.story.l3.7.1
语境：p.story.check.11.a

- [ ] 邻家孩子
  理由：原文没写孩子开口。
- [x] 仆人
  理由：狗叫是真的，有贼是仆人先作的判断。
- [ ] 查探的人
  理由：查探的人实际见到邻儿经过。

提示：把引号前的名字找出来。
解析：狗叫是真的，有贼是仆人先作的判断。

## 单选：“犬逐之”的“之”指谁？ {#q.story.check.11.2}
考点：skill.story.l3.7.2
语境：p.story.check.11.a

- [ ] 夜盗
  理由：查看后发现的不是盗。
- [ ] 派人察看的主人
  理由：主人没有从门前走过。
- [x] 刚刚过门的邻儿
  理由：狗追的是邻儿，查探让初始判断有了改正的根据。

提示：之前刚写谁过门？
解析：狗追的是邻儿，查探让初始判断有了改正的根据。

## 找原文证据：哪一处是事情查明后对最初说法的评价？ {#q.story.check.11.3}
考点：skill.story.l3.9.2
语境：p.story.check.11.a

- [ ] 行旅夜闻犬声
  理由：这是大家遇上的情形。
- [ ] 主人使视之
  理由：这是求证的行动。
- [x] 闻犬而谓有盗，过也
  理由：“过也”指出从狗叫推出有盗并不可靠。

提示：找批评推断失当的字。
解析：“过也”指出从狗叫推出有盗并不可靠。

## 原文：教学例句 {#p.story.check.11.b}
> 园丁以绳围新苗，书“勿近”于木。客见之，以为园有猛犬，遂绕道。友谓客曰：“使真有犬，自可避；今绳内惟苗耳，盍问园丁？”
译文：园丁用绳围住新苗，在木牌写“别靠近”。客人以为园里有猛犬，便绕道。朋友对他说，假使真有狗，当然可以避开，如今绳内只有苗，何不问问园丁？
词注：书：写，把提醒行人的字写到木牌上。
  惟：只有，朋友指出绳子里只有新苗。

## 单选：朋友说“使真有犬”该怎样理解？ {#q.story.check.11.4}
考点：skill.story.l3.8.1
语境：p.story.check.11.b

- [ ] 已经替园丁养了一条狗
  理由：“使”在此是假设。
- [x] 暂且假定有狗，再说该怎么办
  理由：前句是在设想，后句才说眼前状况。
- [ ] 亲眼见到猛犬才劝告客人
  理由：他看到的情形是绳内只有苗。

提示：与下一句的“今”比较。
解析：前句是在设想，后句才说眼前状况。

## 找原文证据：朋友真正建议客人做什么？ {#q.story.check.11.5}
考点：skill.story.l3.8.2
语境：p.story.check.11.b

- [x] 盍问园丁
  理由：朋友请客人向立标记的人核实。
- [ ] 使真有犬
  理由：这是先顺着客人的猜想说。
- [ ] 自可避
  理由：这是有狗的前提成立时才合适的做法。

提示：读问话的最后一句。
解析：朋友请客人向立标记的人核实。

## 单选：“勿近”在园丁那里与在客人那里，有何不同？ {#q.story.check.11.6}
考点：skill.story.l3.9.1
语境：p.story.check.11.b

- [x] 园丁围苗，客人却把它看成防狗的提醒
  理由：客人没看到立牌时的情形，自己给这两个字添了一层意思。
- [ ] 两人都亲见猛犬才绕路
  理由：园里只写了新苗。
- [ ] 园丁警告别采花，客人以为要付钱
  理由：两种说法均无文据。

提示：分别看开头布置和客人“以为”的事。
解析：客人没看到立牌时的情形，自己给这两个字添了一层意思。
