# 课文：智子疑邻：相同的话，不同的听法 {#l3.9}

简介：儿子和邻家老人说了同一句话，丢了东西以后，一人受夸，另一人却遭怀疑。谁亲眼看见盗贼了？

## 正文

儿子先说“不筑，必将有盗”，老人接着“亦云”。“亦云”就是也这样说，补出来应当是同一句修墙的提醒。话虽一样，说话的却是两个人。

丢钱以后，家人“智其子”，即觉得自己的儿子有见识；对邻家老人却用了一个“疑”。试把最后一句说给别人听：可以说家里丢了财物、家人疑心老人，却还说不出是谁偷的。

## 知识点：亦云 {#skill.l3.9.1}
义项：读回上一句，知道另一个人“也这样说”说的是什么
领域：句法
要诀：“也这样说”的人说了什么？回头读前面那句话。
讲解：“亦云”省得把儿子的提醒重写一遍。补话时要留下两个人：先提醒的是儿子，第二次说这番话的是邻家老人。
例句：p.l3.9.a

## 知识点：智其子 {#skill.l3.9.2}
义项：分清家人觉得谁聪明、怀疑谁，以及事情究竟查明了多少
领域：实词
要诀：谁觉得儿子聪明，又是谁在怀疑老人？
讲解：“其家”是家里人。他们用“智”夸儿子，又疑心老人。这句告诉我们家里人怎么想，还没有告诉我们盗贼是谁。
例句：p.l3.9.a

## 原文：古籍引文 {#p.l3.9.a}
> 宋有富人，天雨墙坏。其子曰：“不筑，必将有盗。”其邻人之父亦云。暮而果大亡其财。其家甚智其子，而疑邻人之父。
译文：宋国有个富人，下雨把他家的墙弄塌了。儿子说不修墙，就会招盗。邻家老人也这样说。傍晚家中果然丢失许多财物。家人觉得儿子很有见识，却怀疑邻家老人。

## 单选：邻家老人“亦云”，他也说了什么？ {#q.l3.9.1}
考点：skill.l3.9.1
语境：p.l3.9.a

- [ ] 也承认自己偷了财物
  理由：邻人是在失窃前发话。
- [ ] 也称赞富人的儿子很聪明
  理由：夸儿子聪明的是富人一家，那时财物已经丢了。
- [x] 也提醒若不筑墙将有盗

提示：把“亦”往紧邻的前一句接。
解析：老人开口是在失窃以前。他和儿子的意思一样：墙坏了不修，只怕会招来盗贼。

## 单选：“甚智其子”该怎样转述？ {#q.l3.9.2}
考点：skill.l3.9.2
语境：p.l3.9.a

- [x] 富人家觉得自己的孩子很有见识
- [ ] 叙述者断言儿子比所有邻人聪明
  理由：评价有清楚的主语“其家”。
- [ ] 家人设法使儿子变聪明
  理由：这里说事后的判断，未写教导。

提示：试读成“这一家人觉得儿子……”。
解析：“其家”开头点出了谁在说儿子聪明。儿子和老人一样提醒过修墙，可事后得到称赞的只有儿子。

## 找原文证据：原文哪几个字写家里人心里起了疑？ {#q.l3.9.3}
考点：skill.l3.9.2
语境：p.l3.9.a

- [ ] 果大亡其财
  理由：这只能说明财物丢了，没有说是谁拿的。
- [x] 疑邻人之父
- [ ] 天雨墙坏
  理由：这是被盗前的条件。

提示：找出家里人怎样看待那位老人。
解析：“疑”字能说的是家人的疑心。后面没有写查获盗贼，也没有写老人动手。

## 单选：为什么先写儿子和老人都提醒过修墙？ {#q.l3.9.4}
考点：skill.l3.9.1
语境：p.l3.9.a

- [ ] 让邻家老人取代儿子成为发话人
  理由：先是儿子开口，邻家老人随后也提醒了一遍。
- [x] 让读者比较同一警告在不同关系中得到的待遇
- [ ] 说明老人只是事发之后附和
  理由：老人说话也在失财以前。

提示：儿子说过，老人也这样说。丢了东西以后，家里分别怎么看他们？
解析：两人的话一样，后来遇到的事却不同：家里人觉得儿子聪明，却怀疑老人。读过前面的“亦云”，末句这处分别尤其明显。

## 原文：教学例句 {#p.l3.9.b}
> 库门夜不扃。少吏告守者曰：“宜闭之。”过客亦有是言。旦失一缣，守者称少吏能虑远，而指过客为盗。长者问：“见其取缣乎？”守者曰：“未也。”
译文：库门夜间未上闩。小吏提醒守库人该关门，一个过客也这样说。早晨丢了一匹细绢，守库人夸小吏考虑周到，却指过客为盗。长者问是否亲眼见他取绢，守库人说没有。

## 找原文证据：哪几个字表示过客也说了小吏说过的话？ {#q.l3.9.5}
考点：skill.l3.9.1
语境：p.l3.9.b

- [ ] 旦失一缣
  理由：这是次日的结果。
- [ ] 未也
  理由：“未也”答的是有没有亲眼看见过客拿绢。
- [x] 亦有是言

提示：找“也”和“这番话”的配合。
解析：前面小吏说“宜闭之”，后面“是言”就是“这话”。过客也主张把库门关上。

## 单选：守库人答“未也”，他承认自己没看见什么？ {#q.l3.9.6}
考点：skill.l3.9.2
语境：p.l3.9.b

- [ ] 已经证实过客绝不可能取绢
  理由：未亲见并不等于排除所有可能。
- [ ] 守者不承认库中丢绢
  理由：“未”回答的是有没有看见过客拿绢。
- [x] 守者没有亲见过客拿绢

提示：长者问的是丢没丢绢，还是亲眼看没看见过客拿绢？
解析：长者问的是“你看见他拿绢了吗”，守库人答“没看见”。丢绢是实情，谁拿了绢却还没查清。

## 单选：说“过客劝小吏闭门”，把谁弄错了？ {#q.l3.9.7}
考点：skill.l3.9.1
语境：p.l3.9.b

- [x] 过客是另一位提醒守者的人，小吏不是其听者
- [ ] 小吏从未见过库门
  理由：小吏确实提醒过关门，关键是他在提醒谁。
- [ ] 过客说话时库门已经补好
  理由：没有补门的场景。

提示：小吏先告诉守库人该关门，过客也说了同样的话。听话的是谁？
解析：建议都是说给守库人听的：先开口的是小吏，随后过客也说了同样的话。

## 单选：若把这件事讲给一个没读过的人，哪一说法有原文可据？ {#q.l3.9.8}
考点：skill.l3.9.2
语境：p.l3.9.b

- [ ] 少吏知道盗者是谁却故意隐瞒
  理由：他只提醒关门，没有指认。
- [x] 门未闩，有两人提醒，次晨失绢，守者怀疑过客但未亲见
- [ ] 守者抓住过客偷绢后当场盘问
  理由：长者问的是守者，也没有抓获经过。

提示：读到“未也”便停住：谁亲眼见到过客拿绢了？
解析：夜里门没闩，早上少了绢。守库人虽指过客为盗，却承认自己没亲眼看见。至于究竟是谁偷的，故事没说。
