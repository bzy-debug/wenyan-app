# 课文：智子疑邻：相同的话，不同的听法 {#l3.9}

简介：把人物的判断从读者可以证实的事实中剥离。

## 正文

先把两次提醒写在左右两栏。“亦云”省去了整段重复内容，可从儿子的话补足。再分别列出富家的反应：有人得到称许，有人受怀疑。同一句预警为何有不同待遇，是这段材料可讨论的问题。

“**智其子**”要译成人的评价动作。“智”在这句话里不是客观鉴定；“疑”也不是审判结论。读完故事试写一句只陈述已发生的事、不指派盗贼身份的摘要。

## 知识点：亦云 {#skill.l3.9.1}
义项：从上句补出转述时省去的相同内容
领域：句法
要诀：复原相同的警告，保留不同说者
讲解：“亦云”把前一人的话作为省写依据。补全内容时不要连身份、立场和后来处境也一起复制过去。
例句：p.l3.9.a

## 知识点：智其子 {#skill.l3.9.2}
义项：将意动评价与事实真伪分层
领域：实词
要诀：把评价改写成“某人认为……”
讲解：“智其子”是家人认为儿子聪明；“疑”也是特定人物的疑心。词语提示谁在判断，但不能替代查证。
例句：p.l3.9.a

## 原文：古籍引文 {#p.l3.9.a}
> 宋有富人，天雨墙坏。其子曰：“不筑，必将有盗。”其邻人之父亦云。暮而果大亡其财。其家甚智其子，而疑邻人之父。
译文：宋国一户富人家因下雨坏了墙。儿子说不修墙，就会招盗。邻家老人也这样说。傍晚家中果然丢失许多财物。家人觉得儿子很有见识，却怀疑邻家老人。

## 单选：若把“亦云”补齐，应补什么？ {#q.l3.9.1}
考点：skill.l3.9.1
语境：p.l3.9.a

- [ ] 也承认自己偷了财物
  理由：邻人是在失窃前发话。
- [ ] 也称赞富人的儿子很聪明
  理由：称智出自失窃后富人家。
- [x] 也提醒若不筑墙将有盗

提示：把“亦”往紧邻的前一句接。
解析：“亦云”省略的是儿子刚作的预警；发生时间在“暮而”之前。

## 单选：“甚智其子”该怎样转述？ {#q.l3.9.2}
考点：skill.l3.9.2
语境：p.l3.9.a

- [x] 富人家觉得自己的孩子很有见识
- [ ] 叙述者断言儿子比所有邻人聪明
  理由：评价有清楚的主语“其家”。
- [ ] 家人设法使儿子变聪明
  理由：这里说事后的判断，未写教导。

提示：把“其家”放到白话判断句的主语位置。
解析：家人作评价，儿子是评价对象。同样预警却只称智于儿子，体现评价的差别。

## 找原文证据：哪一段字只能证明老人受怀疑？ {#q.l3.9.3}
考点：skill.l3.9.2
语境：p.l3.9.a

- [ ] 果大亡其财
  理由：这可证失财，不能确定嫌疑人。
- [x] 疑邻人之父
- [ ] 天雨墙坏
  理由：这是被盗前的条件。

提示：留意表示判断而非定罪的动词。
解析：“疑”是富人家的态度。事后没有审讯、物证或查获经过。

## 单选：两个提醒相同，在叙事中起什么作用？ {#q.l3.9.4}
考点：skill.l3.9.1
语境：p.l3.9.a

- [ ] 让邻家老人取代儿子成为发话人
  理由：两人均分别作了提醒。
- [x] 让读者比较同一警告在不同关系中得到的待遇
- [ ] 说明老人只是事发之后附和
  理由：老人说话也在失财以前。

提示：先固定话的内容，只换发话人。
解析：末句把“智”与“疑”并排，前面的“亦云”使这组差别特别显眼。

## 原文：教学例句 {#p.l3.9.b}
> 库门夜不扃。少吏告守者曰：“宜闭之。”过客亦有是言。旦失一缣，守者称少吏能虑远，而指过客为盗。长者问：“见其取缣乎？”守者曰：“未也。”
译文：库门夜间未上闩。小吏提醒守库人该关门，一个过客也这样说。早晨丢了一匹细绢，守库人夸小吏考虑周到，却指过客为盗。长者问是否亲眼见他取绢，守库人说没有。

## 找原文证据：哪一处提示可以把小吏的建议补给第二个人？ {#q.l3.9.5}
考点：skill.l3.9.1
语境：p.l3.9.b

- [ ] 旦失一缣
  理由：这是次日的结果。
- [ ] 未也
  理由：是守库人对是否亲见的回答。
- [x] 亦有是言

提示：找“也”和“这番话”的配合。
解析：“是言”回指“宜闭之”，未再逐字重复。

## 单选：“未也”对前面“指过客为盗”形成了怎样的限制？ {#q.l3.9.6}
考点：skill.l3.9.2
语境：p.l3.9.b

- [ ] 已经证实过客绝不可能取绢
  理由：未亲见并不等于排除所有可能。
- [ ] 守者不承认库中丢绢
  理由：被否定的是“见其取”，不是失绢。
- [x] 守者没有亲见过客拿绢

提示：先还原长者问句的谓语。
解析：问的范围是亲眼所见。“未也”揭示指认缺少这项证据，并未补出真正的盗者。

## 单选：若说“过客劝小吏闭门”，哪里读错了？ {#q.l3.9.7}
考点：skill.l3.9.1
语境：p.l3.9.b

- [x] 过客是另一位提醒守者的人，小吏不是其听者
- [ ] 小吏从未见过库门
  理由：原文不能支持这个理由。
- [ ] 过客说话时库门已经补好
  理由：没有补门的场景。

提示：按两栏列出谁提醒谁。
解析：复制的是建议内容和受话者；发出第二个提醒的是过客。

## 单选：哪句话可以作为有依据的案情摘要？ {#q.l3.9.8}
考点：skill.l3.9.2
语境：p.l3.9.b

- [ ] 少吏知道盗者是谁却故意隐瞒
  理由：他只提醒关门，没有指认。
- [x] 门未闩，有两人提醒，次晨失绢，守者怀疑过客但未亲见
- [ ] 守者抓住过客偷绢后当场盘问
  理由：长者问的是守者，也没有抓获经过。

提示：摘要中把每个判断都放回作判断的人名下。
解析：房门状况、提醒、失物和对答是有文本依据的四件事，盗者身份仍未查明。
