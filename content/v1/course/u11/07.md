# 课文：从丁氏到宋君：追踪一句传闻 {#l3.7}

简介：将一句话的传播过程和它所指的事实画成两条线。

## 正文

丁家原来要派人在外汲水。故事开头这项看似琐碎的交代，是理解结尾的钥匙：“得一人”究竟多出一个活人，还是省下一个人的劳作？

先用箭头连传话的人，再单独标出求证的动作。“国人道之”只增加了说这件事的人数，不能自动增加消息的可靠性。读第二则材料时，也要区分**传到谁那里**与**向谁查问**。

## 知识点：闻之于 {#skill.l3.7.1}
义项：辨别传闻到达的人与追问的来源
领域：句法
要诀：分别标出谁转述、谁核实
讲解：同一段连续出现“闻”“问”时，不要只凭“于”字定方向。传闻到某人处，与某人派人向知情者核实，是两种信息流动。
例句：p.l3.7.a

## 知识点：得一人之使 {#skill.l3.7.2}
义项：用开头的劳役背景消解传语歧义
领域：阅读技能
要诀：让结尾的解释与先前的现实相合
讲解：听来的省略说法可能丢掉“省下劳力”等关键限定，应把当事人的解释与开头的具体条件对读。
例句：p.l3.7.a

## 原文：古籍引文 {#p.l3.7.a}
> 宋之丁氏，家无井而出溉汲，常一人居外。及其家穿井，告人曰：“吾穿井得一人。”有闻而传之者曰：“丁氏穿井得一人。”国人道之，闻之于宋君。宋君令人问之于丁氏。丁氏对曰：“得一人之使，非得一人于井中也。”
译文：宋国丁家没有井，得出门打水，经常有一个人在外。等家里挖了井，丁氏对人说挖井得了一人。有人听来便这样转述，国中人纷纷传说，消息传到了宋君那里。宋君派人向丁家询问。丁氏说，省下的是一个人的劳力，并非从井中挖出一个人。
出处：《吕氏春秋·察传》

## 排序：把消息传递与核实的顺序排出来。 {#q.l3.7.1}
考点：skill.l3.7.1
语境：p.l3.7.a

- [1] 丁氏向人说挖井得一人
  理由：这是原话的发出。
- [3] 国君派人向丁氏查问
  理由：核实才听到“一人之使”。
- [2] 国人传说，消息传到国君那里
  理由：流传发生在派人询问以前。

提示：区分“闻之”与“问之”。
解析：消息先外传后返回当事人处核实；传得广不能替代对事实的询问。

## 找原文证据：哪一句背景最能帮助理解“一人之使”？ {#q.l3.7.2}
考点：skill.l3.7.2
语境：p.l3.7.a

- [ ] 宋君令人
  理由：这是国君指派问话的人。
- [ ] 国人道之
  理由：这是传播状况，不是取水所需人手。
- [x] 常一人居外

提示：想想有井之前家庭如何安排人手。
解析：从前有一人长期在外汲水，开井之后该人的劳力可以另作他用。

## 单选：“闻之于宋君”和“问之于丁氏”各把谁放在哪个位置？ {#q.l3.7.3}
考点：skill.l3.7.1
语境：p.l3.7.a

- [x] 传闻到了宋君那里；受命者再向丁氏求证
- [ ] 国君和丁氏一起散布传闻
  理由：“令人问”表明此时在核实。
- [ ] 宋君发出传闻，丁氏派人问国君
  理由：两股信息的方向均被倒置。

提示：谁发出“令人”的命令？
解析：宋君得闻后才命人问，丁氏随后“对曰”；句间因果给出方向。

## 单选：若有人复述“丁氏说自己在井底发现了工人”，问题何在？ {#q.l3.7.4}
考点：skill.l3.7.2
语境：p.l3.7.a

- [ ] “人”在古文中只能指劳动日
  理由：句义靠具体劳作背景确定。
- [x] 将转述中的歧义当成当事人确认的事实
- [ ] 丁氏其实否认家里打过井
  理由：他否认的是井中得人，未否认穿井。

提示：读丁氏“非……”否定的究竟是什么。
解析：第一句压缩了“省出一人劳力”的信息；查问后的解释消除了另一种解读。

## 原文：教学例句 {#p.l3.7.b}
> 东村旧共一碓，三户更守。及各置小碓，一妇曰：“吾家得三日矣。”行者传曰妇人受人三日之佣。里正问诸妇，妇曰：“昔轮守废织三日，今得自织，何佣之有？”
译文：东村原来合用一台舂米的碓，三户轮流看守。后来各置小碓，一位妇人说家里得了三天。过路人传成她收到了三天工钱。里正向妇人询问，她说以前轮守要耽误三天织布，如今可以自己织，哪来的工钱呢？

## 单选：“里正问诸妇”在故事里起什么作用？ {#q.l3.7.5}
考点：skill.l3.7.1
语境：p.l3.7.b

- [ ] 向所有路人宣布付钱日期
  理由：这是询问而非开始付款。
- [ ] 把过路人叫来确认他听见了多少钱
  理由：受问的是妇人。
- [x] 回到最早说“得三日”的人那里核实

提示：看下一句由谁“曰”。
解析：妇人能说明自己说“得”的原意。她的回答与行者的加工应分开。

## 单选：“何佣之有”否定的是哪种理解？ {#q.l3.7.6}
考点：skill.l3.7.2
语境：p.l3.7.b

- [ ] 她曾经轮流看碓
  理由：她亲口说“昔轮守”。
- [ ] 她现在能利用三天织布
  理由：“今得自织”正承认这点。
- [x] 她收到过路人说的佣钱

提示：从行者的传语找被反驳的部分。
解析：“得三日”指原本耗在守碓上的时间可用于织布，不是得到对应的报酬。

## 找原文证据：哪一句能说明“得三日”的具体来源？ {#q.l3.7.7}
考点：skill.l3.7.2
语境：p.l3.7.b

- [ ] 东村旧共一碓
  理由：交代共用器具，但没有说明三天从何而来。
- [x] 昔轮守废织三日
- [ ] 行者传曰
  理由：只表明有人传播。

提示：选能直接指出耗掉哪三天的词句。
解析：轮守时耽误织布的三天，如今可以收回来自用。

## 单选：两则故事中，哪一组人物承担相近的核实功能？ {#q.l3.7.8}
考点：skill.l3.7.1
语境：p.l3.7.b

- [x] 宋君派出的询问者与东村里正
- [ ] 国人与妇人
  理由：一方传说，另一方还原自家劳作。
- [ ] 丁氏与东村行者
  理由：一人是原话来源，一人加工了传闻。

提示：找主动问到当事人那里的人。
解析：两段都用追问打断传闻的循环，核实者与最初说话者承担不同角色。
