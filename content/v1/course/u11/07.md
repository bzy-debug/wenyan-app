# 课文：从丁氏到宋君：追踪一句传闻 {#l3.7}

简介：丁家打了井，怎么就“得一人”？跟着这句话一路听到宋君那里，再回来听丁家本人的解释。

## 正文

丁家没有井时，常得留一个人在外打水。记住这点，再读“吾穿井得一人”：是井里多出个人来，还是家里省出一个人手？

当初是丁家讲给别人听，后来“国人道之”，连国君也听说了。可接下来谁去找谁，是另一回事：宋君派人回丁家问个明白。东村妇人说“得三日”，也得听她亲口解释，才知道省下的是哪三天。

## 知识点：闻之于 {#skill.l3.7.1}
义项：分清传言到了谁那里，后来又找谁问实情
领域：句法
要诀：听到了消息的是谁？回头去问的又是谁？
讲解：“闻之于宋君”是传到了宋君的耳朵里。下一句“问之于丁氏”，才是国君派人去问丁家。
例句：p.l3.7.a

## 知识点：得一人之使 {#skill.l3.7.2}
义项：从原来要派人打水，明白“得一人”省下的是人手
领域：阅读技能
要诀：想想从前是谁在外打水。
讲解：丁家有了井，原本在外汲水的那个人便可以做别的事。“一人之使”正是这么来的。
例句：p.l3.7.a

## 原文：古籍引文 {#p.l3.7.a}
> 宋之丁氏，家无井而出溉汲，常一人居外。及其家穿井，告人曰：“吾穿井得一人。”有闻而传之者曰：“丁氏穿井得一人。”国人道之，闻之于宋君。宋君令人问之于丁氏。丁氏对曰：“得一人之使，非得一人于井中也。”
译文：宋国丁家没有井，得出门打水，经常有一个人在外。等家里挖了井，丁氏对人说挖井得了一人。有人听来便这样转述，国中人纷纷传说，消息传到了宋君那里。宋君派人向丁家询问。丁家人答道：“是省出了一个人手，哪里是从井里得了一个人！”

## 排序：这句话怎样传到宋君耳中，又怎样问回丁家？按先后排一排。 {#q.l3.7.1}
考点：skill.l3.7.1
语境：p.l3.7.a

- [1] 丁氏向人说挖井得一人
  理由：最早说这句话的就是丁家人。
- [3] 国君派人向丁氏查问
  理由：核实才听到“一人之使”。
- [2] 国人传说，消息传到国君那里
  理由：流传发生在派人询问以前。

提示：区分“闻之”与“问之”。
解析：丁家先开口，旁人接着传，最后传到宋君耳中。直到国君派人去问丁家，才听到“得一人之使”的解释。

## 找原文证据：哪几个字说明丁家没井时，总要占用一个人手？ {#q.l3.7.2}
考点：skill.l3.7.2
语境：p.l3.7.a

- [ ] 宋君令人
  理由：这是国君指派问话的人。
- [ ] 国人道之
  理由：“国人道之”只说众人在传，没说过去谁打水。
- [x] 常一人居外

提示：没有井的时候，丁家得派谁出门做什么？
解析：家里没井，“常一人居外”，这个人得在外打水。有了井，省出的就是他的工夫。

## 单选：消息传到了谁那里？宋君又派人向谁打听？ {#q.l3.7.3}
考点：skill.l3.7.1
语境：p.l3.7.a

- [x] 传闻到了宋君那里；受命者再向丁氏求证
- [ ] 国君和丁氏一起散布传闻
  理由：“令人问”表明此时在核实。
- [ ] 宋君发出传闻，丁氏派人问国君
  理由：“令人”的是宋君，后面作答的是丁氏。

提示：“令人问”的是谁？“对曰”的又是谁？
解析：先是宋君听见众人的传言，后是丁氏“对曰”。派人去问的是国君，答话的是知道事情经过的丁家人。

## 单选：说“丁家人在井底发现一个工人”，错在哪里？ {#q.l3.7.4}
考点：skill.l3.7.2
语境：p.l3.7.a

- [ ] “人”在古文中只能指劳动日
  理由：丁家说的是打水的人手，“人”字本身并不是一天的工。
- [x] 将转述中的歧义当成当事人确认的事实
- [ ] 丁氏其实否认家里打过井
  理由：他否认的是井中得人，未否认穿井。

提示：读丁氏“非……”否定的究竟是什么。
解析：丁家最初只说“穿井得一人”，没说怎样“得”的。后来亲口说明省下的是一个人的劳力，还特意说了并没有从井里挖出人。

## 原文：教学例句 {#p.l3.7.b}
> 东村旧共一碓，三户更守。及各置小碓，一妇曰：“吾家得三日矣。”行者传曰妇人受人三日之佣。里正问诸妇，妇曰：“昔轮守废织三日，今得自织，何佣之有？”
译文：东村原来合用一台舂米的碓，三户轮流看守。后来各置小碓，一位妇人说家里得了三天。过路人传成她收到了三天工钱。里正向妇人询问，她说以前轮守要耽误三天织布，如今可以自己织，哪来的工钱呢？

## 单选：里正为什么要去问妇人？ {#q.l3.7.5}
考点：skill.l3.7.1
语境：p.l3.7.b

- [ ] 向所有路人宣布付钱日期
  理由：这是询问而非开始付款。
- [ ] 把过路人叫来确认他听见了多少钱
  理由：受问的是妇人。
- [x] 回到最早说“得三日”的人那里核实

提示：看下一句由谁“曰”。
解析：“得三日”出自妇人之口。过路人却说她拿了工钱，要知道那三天到底是什么，里正便去问她本人。

## 单选：“何佣之有”否定的是哪种理解？ {#q.l3.7.6}
考点：skill.l3.7.2
语境：p.l3.7.b

- [ ] 她曾经轮流看碓
  理由：她亲口说“昔轮守”。
- [ ] 她现在能利用三天织布
  理由：“今得自织”正承认这点。
- [x] 她收到过路人说的佣钱

提示：过路人多添了一样什么东西？
解析：原来轮到她守碓，就不能织布。现在能用这三天来织布了，哪里有什么工钱？

## 找原文证据：妇人从哪里省出了三天？哪句话说得最清楚？ {#q.l3.7.7}
考点：skill.l3.7.2
语境：p.l3.7.b

- [ ] 东村旧共一碓
  理由：交代共用器具，但没有说明三天从何而来。
- [x] 昔轮守废织三日
- [ ] 行者传曰
  理由：只表明有人传播。

提示：选能直接指出耗掉哪三天的词句。
解析：“废织三日”是说过去要耽误三天织布。如今不用轮守，这三天才归她自己用。

## 单选：两段故事里，谁亲自去问了最早说这句话的人？ {#q.l3.7.8}
考点：skill.l3.7.1
语境：p.l3.7.b

- [x] 宋君派出的询问者与东村里正
- [ ] 国人与妇人
  理由：国人在传别人的话，妇人是在说自己的织布工夫。
- [ ] 丁氏与东村行者
  理由：丁家是最先开口的人；东村的行者却把听来的话传成了工钱。

提示：找主动问到当事人那里的人。
解析：宋君派人问丁家，里正自己问妇人。两次都是找到亲历的人，才把旁人传的话问明白。
