# 课文：孔文举见客：隔了一层的反话 {#l3.8}

简介：听见一句好话，先问它回应的是谁刚才说的什么。

## 正文

长段中有三次听者变动：门吏听“我是李府君亲”，李元礼亲自追问，后来才到的陈韪又听宾客转述。若把三人合为一个听者，最后一句的锋芒便消失了。

“人以其**语** **语**之”可分成“把那番**话**／**告诉**他”。“了了”说小时候聪慧。陈韪把小时聪慧和长大未必优秀对举，文举随后沿用这组对举，却把它还给说话者本人。

“元礼及宾客莫不奇之”把在场的人都算进去了：“莫”是没有谁，“不奇之”是不觉得他出奇，合起来便是人人称奇。陈韪后来说“大未必佳”，“未必”只是否定“一定”：他还没有断言这个孩子长大必定不佳。

## 知识点：以其语语之 {#skill.l3.8.1}
义项：在同字作名词与动词时确定传话人和受话人
领域：实词
要诀：分别问“传的什么”和“告诉谁”
讲解：在“以其语语之”里，前一个语是话，后一个语表示告知。末尾的“之”应从新出现的听者定位。
例句：p.l3.8.a

## 知识点：承语反用 {#skill.l3.8.2}
义项：用对方刚立的判断反照其本人
领域：篇章
要诀：把末句放回上一人的话
讲解：字面像称许的回应可以借前文的条件构成讥刺。说明反用所凭的两句，不凭印象断言人物心情。
例句：p.l3.8.a

## 原文：古籍引文 {#p.l3.8.a}
> 孔文举年十岁，随父到洛。时李元礼有盛名，为司隶校尉。诣门者皆隽才清称及中表亲戚乃通。文举至门，谓吏曰：“我是李府君亲。”既通，前坐。元礼问曰：“君与仆有何亲？”对曰：“昔先君仲尼与君先人伯阳有师资之尊，是仆与君奕世为通好也。”元礼及宾客莫不奇之。太中大夫陈韪后至，人以其语语之。韪曰：“小时了了，大未必佳。”文举曰：“想君小时必当了了。”韪大踧踖。
译文：十岁的孔文举随父来到洛阳。李元礼名望很高，门上只通报俊才、有清名者或亲戚。文举自称亲属得以入内。他面对李元礼的追问，借孔子与老子的师承说自己两家世代交好，宾客都觉得惊异。陈韪晚到，别人把童子的答语告诉他。他说小时聪慧，长大未必出众。文举顺势说，想必您小时一定聪慧。陈韪十分窘迫。

## 找原文证据：哪句话表明陈韪没有亲听先前的问答？ {#q.l3.8.1}
考点：skill.l3.8.1
语境：p.l3.8.a

- [ ] 元礼问曰
  理由：这是元礼亲自发问。
- [x] 陈韪后至
- [ ] 既通，前坐
  理由：这写文举入席。

提示：比较谁已在场，谁后来才来。
解析：陈韪迟到，需要别人把先前的对话告诉他；不能把他当成发问的李元礼。

## 单选：“人以其语语之”如何分配三个角色？ {#q.l3.8.2}
考点：skill.l3.8.1
语境：p.l3.8.a

- [ ] 文举把陈韪的话重复给自己
  理由：此时陈韪还没发表“小时了了”的判断。
- [x] 在场的人把文举的话告诉陈韪
- [ ] 陈韪把元礼的话告诉门吏
  理由：陈韪是“后至”的新听者。

提示：依次标出传话者、内容、接受者。
解析：“以其语”领出所传之言，“语之”的“之”指刚出现的陈韪。

## 单选：“想君小时必当了了”为何令陈韪难堪？ {#q.l3.8.3}
考点：skill.l3.8.2
语境：p.l3.8.a

- [ ] 文举想请陈韪讲小时候的事
  理由：这句是回应评价，没有发出询问。
- [ ] 文举提出陈韪童年不识字的证据
  理由：没有童年事实作证。
- [x] 文举沿用其“小聪明未必长成佳才”的说法来映照成人的陈韪

提示：把陈韪原话接在文举答话后再读。
解析：前一句中小时聪慧并非保证长大优秀，文举把“小时了了”说给陈韪，反击由语境产生。

## 单选：文举先前自称与李府君有亲，实际怎样解释这个“亲”？ {#q.l3.8.4}
考点：skill.l3.8.2
语境：p.l3.8.a

- [ ] 列出本人与李元礼的直系亲属关系
  理由：答话讲的是仲尼和伯阳。
- [ ] 诉说陈韪与李元礼同在朝中任职
  理由：陈韪尚未出场。
- [x] 援引祖先师承而说两家世交

提示：查看被门吏传入之后的回答。
解析：从“先君”“先人”转到“通好”，是对“亲”作巧妙延伸，并未证明近亲身份。

## 原文：教学例句 {#p.l3.8.b}
> 市人夸镜曰：“明者能见人毫末。”客取之照，尘蔽其面。童笑曰：“此镜必甚明，先见君之尘矣。”有后至者，众以童言语之，方知众笑所由。
译文：卖镜人夸说明镜能照见人的毫毛。客人拿过镜子一照，尘土遮住镜面。孩子笑说这镜子想必明亮极了，先照出了您的尘土。又有人晚来，众人把孩子的话转告他，他才明白众人在笑什么。

## 单选：“众以童言语之”中的“之”指谁？ {#q.l3.8.5}
考点：skill.l3.8.1
语境：p.l3.8.b

- [ ] 说俏皮话的孩子
  理由：孩子是被转述的话的原说者。
- [x] 刚刚到场的人
- [ ] 镜中的客人
  理由：叙事把“后至者”新引入为听者。

提示：找上句中还不明白大家为什么笑的人。
解析：迟到者未见先前情形，需要听转述，所以下句写“方知”。

## 找原文证据：哪句话给孩子的“必甚明”制造了反差？ {#q.l3.8.6}
考点：skill.l3.8.2
语境：p.l3.8.b

- [ ] 有后至者
  理由：晚来的人与镜子的明暗无关。
- [ ] 客取之照
  理由：拿来照并不能证明不清楚。
- [x] 尘蔽其面

提示：找与“明亮”正面冲突的可见事实。
解析：尘土遮面与能见毫末不相称，孩子表面说镜明，其意须合前文理解。

## 单选：翻译童子的话时，哪一项保留了反用？ {#q.l3.8.7}
考点：skill.l3.8.2
语境：p.l3.8.b

- [ ] 认真鉴定镜子比所有镜子都清楚
  理由：童子没有做这样的比较。
- [x] 故意沿着“明镜”的夸口，说它先看见了尘土
- [ ] 指出来客脸上有伤
  理由：原文写尘，不写伤。

提示：保留“夸镜—照镜—童笑”的顺序。
解析：若去掉先前的夸口和实测情形，把“甚明”直读为鉴定结论，就损失了对话关系。

## 单选：晚到者“方知”的依据属于哪一类？ {#q.l3.8.8}
考点：skill.l3.8.1
语境：p.l3.8.b

- [ ] 自己擦拭镜子取得结论
  理由：没有写他动手。
- [ ] 亲耳听见市人开头夸镜
  理由：他是在童子说完后来的。
- [x] 依靠在场众人转述童言才明白

提示：“方”前紧接的动作是谁做的？
解析：“众……语之”是获得信息的方式，与前面的客人亲手取镜不同。
