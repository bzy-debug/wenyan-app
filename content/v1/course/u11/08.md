# 课文：孔文举见客：隔了一层的反话 {#l3.8}

简介：陈韪来得晚，没听见孔文举先前说的话。文举又为什么当面“夸”他小时候聪明？

## 正文

先出来听孔文举说话的是门吏，随后才是李元礼。李元礼问两家有什么亲戚关系，文举拿先辈的师生关系作答。陈韪来得更晚：他听到的是在场人转述的这番话。

“人以其语语之”里的两个“语”，读法不同。前一个是“话”（yǔ），后一个是“告诉”（yù）。合起来就是“有人把他的话告诉了陈韪”。“莫不奇之”则是没有谁不觉得孔文举出奇，即大家都称奇。

陈韪说“小时了了，大未必佳”，“未必”是“不一定”。他说聪明孩子长大了不一定出色，文举接过这句话，偏说陈韪小时候一定聪明。把两句话连起来听，才听得出最后一句的滋味。

## 知识点：以其语语之 {#skill.l3.8.1}
义项：看清谁把谁的话讲给了谁，分辨两个“语”的用法
领域：实词
要诀：两个“语”一个是“话”，一个是“告诉”。
讲解：“以其语”说转述的是什么，“语之”说讲给谁听。“之”指刚进门、没听到那番话的陈韪。
例句：p.l3.8.a

## 知识点：承语反用 {#skill.l3.8.2}
义项：借对方刚说的话回敬他本人
领域：篇章
要诀：把这句夸奖接在对方刚说的话后面听。
讲解：陈韪刚说小时聪明的人长大未必出色，孔文举马上“夸”他小时聪明。少了上一句，就听不出这句的讥讽。
例句：p.l3.8.a

## 原文：古籍引文 {#p.l3.8.a}
> 孔文举年十岁，随父到洛。时李元礼有盛名，为司隶校尉。诣门者皆隽才清称及中表亲戚乃通。文举至门，谓吏曰：“我是李府君亲。”既通，前坐。元礼问曰：“君与仆有何亲？”对曰：“昔先君仲尼与君先人伯阳有师资之尊，是仆与君奕世为通好也。”元礼及宾客莫不奇之。太中大夫陈韪后至，人以其语语之。韪曰：“小时了了，大未必佳。”文举曰：“想君小时必当了了。”韪大踧踖。
译文：十岁的孔文举随父来到洛阳。李元礼名望很高，当时任司隶校尉。上门的人，得是出众的人才、有好名声的人或亲戚，门吏才替他通报。文举自称亲属得以入内。李元礼问他是什么亲戚，他便说自己的先祖孔子同李家的先人老子有师生之谊，两家算得上世代交好。李元礼和在座宾客无不称奇。陈韪晚到，别人把童子的答语告诉他。他说小时聪慧，长大未必出众。文举顺势说，想必您小时一定聪慧。陈韪十分窘迫。

## 找原文证据：哪几个字表明陈韪没赶上孔文举和李元礼的问答？ {#q.l3.8.1}
考点：skill.l3.8.1
语境：p.l3.8.a

- [ ] 元礼问曰
  理由：这是元礼亲自发问。
- [x] 陈韪后至
- [ ] 既通，前坐
  理由：这写文举入席。

提示：比较谁已在场，谁后来才来。
解析：“后至”是说他后来才到。所以接下来才要有人转述，告诉他文举先前答了什么。

## 单选：“人以其语语之”是谁把谁的话告诉了谁？ {#q.l3.8.2}
考点：skill.l3.8.1
语境：p.l3.8.a

- [ ] 文举把陈韪的话重复给自己
  理由：此时陈韪还没发表“小时了了”的判断。
- [x] 在场的人把文举的话告诉陈韪
- [ ] 陈韪把元礼的话告诉门吏
  理由：陈韪是“后至”的新听者。

提示：“后至”的人需要别人告诉他什么？
解析：在场的人把文举的那番话告诉陈韪。“其语”的“语”指那番话，“语之”则是告诉他。

## 单选：“想君小时必当了了”为何令陈韪难堪？ {#q.l3.8.3}
考点：skill.l3.8.2
语境：p.l3.8.a

- [ ] 文举想请陈韪讲小时候的事
  理由：孔文举是在接陈韪的话，并没问他小时候的经历。
- [ ] 文举提出陈韪童年不识字的证据
  理由：没有童年事实作证。
- [x] 文举沿用其“小聪明未必长成佳才”的说法来映照成人的陈韪

提示：把陈韪原话接在文举答话后再读。
解析：陈韪刚说小时聪明不保证长大出众。文举就夸成人的陈韪“小时必当了了”，把他评别人的话送回给他自己。

## 单选：文举先前自称与李府君有亲，实际怎样解释这个“亲”？ {#q.l3.8.4}
考点：skill.l3.8.2
语境：p.l3.8.a

- [ ] 列出本人与李元礼的直系亲属关系
  理由：答话讲的是仲尼和伯阳。
- [ ] 诉说陈韪与李元礼同在朝中任职
  理由：陈韪尚未出场。
- [x] 援引祖先师承而说两家世交

提示：李元礼亲自问“有何亲”，孔文举答的是哪两位先人？
解析：文举说的是孔子与老子的师生之谊，由此把两家说成世交。他没有拿出一条能证明近亲的亲属关系。

## 原文：教学例句 {#p.l3.8.b}
> 市人夸镜曰：“明者能见人毫末。”客取之照，尘蔽其面。童笑曰：“此镜必甚明，先见君之尘矣。”有后至者，众以童言语之，方知众笑所由。
译文：卖镜人夸说明镜能照见人的毫毛。客人拿过镜子一照，尘土遮住镜面。孩子笑说这镜子想必明亮极了，先照出了您的尘土。又有人晚来，众人把孩子的话转告他，他才明白众人在笑什么。

## 单选：“众以童言语之”中的“之”指谁？ {#q.l3.8.5}
考点：skill.l3.8.1
语境：p.l3.8.b

- [ ] 说俏皮话的孩子
  理由：话是孩子说的，晚到的人才需要听别人转述。
- [x] 刚刚到场的人
- [ ] 镜中的客人
  理由：“之”接上句那个晚到的人，他才没听见孩子的原话。

提示：找上句中还不明白大家为什么笑的人。
解析：“有后至者”才引出一个晚到的人。“众……语之”，是大家把孩子的话告诉他，他这才知众人为什么笑。

## 找原文证据：卖镜人夸镜子很明亮，哪一句写出了眼前相反的情形？ {#q.l3.8.6}
考点：skill.l3.8.2
语境：p.l3.8.b

- [ ] 有后至者
  理由：晚来的人与镜子的明暗无关。
- [ ] 客取之照
  理由：拿来照并不能证明不清楚。
- [x] 尘蔽其面

提示：客人拿起镜子一照，镜面上有什么？
解析：客人一照，镜面却给尘土遮住。再听孩子说镜子“甚明”，就知道他是在接着卖镜人的夸口开玩笑。

## 单选：哪一项读出了孩子说“此镜必甚明”的笑意？ {#q.l3.8.7}
考点：skill.l3.8.2
语境：p.l3.8.b

- [ ] 认真鉴定镜子比所有镜子都清楚
  理由：童子没有做这样的比较。
- [x] 故意沿着“明镜”的夸口，说它先看见了尘土
- [ ] 指出来客脸上有伤
  理由：原文写尘，不写伤。

提示：先听卖镜人怎么夸，再听孩子说这镜子最先照见了什么。
解析：先有人夸得连细毛都照得出，客人拿来一照却满是灰。孩子故意说它先照见了尘土，正是顺着那句夸口在打趣。

## 单选：晚来的人最后是怎样明白大家为什么笑的？ {#q.l3.8.8}
考点：skill.l3.8.1
语境：p.l3.8.b

- [ ] 自己擦拭镜子取得结论
  理由：没有写他动手。
- [ ] 亲耳听见市人开头夸镜
  理由：他是在童子说完后来的。
- [x] 依靠在场众人转述童言才明白

提示：“方”前紧接的动作是谁做的？
解析：他来得晚，是在场众人把孩子的话讲给他听，他才明白。亲自拿镜子照的是先前那位客人。
