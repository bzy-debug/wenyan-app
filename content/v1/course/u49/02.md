# 课文：“欺于张仪”，是谁骗了谁 {#g49.2}
简介：先替动词找出两边的人，再辨“于”和“见”各自有没有标出那只动手的手。

## 正文

“怀王外欺于张仪”，受骗的是怀王，设法骗他的是张仪。换成“怀王见张仪于庭”，庭院只能是两人相见的地方。两句都有“于”，只看它前后站着几个字，还不能把人物分准。

有时连“于”也没有。《史记》把“屈原放逐”和“著《离骚》”前后并写。谁流放了他，这几个字里没有说；受流放的是他，写书的也是他。再听写信人问朋友“倘可见教乎”，这是请朋友教自己。要是读成“朋友受到教导”，下一句答谁、谁在求教就全掉了个头。

## 知识点：动词后的“于”可以引出施事 {#g49.s.agent}
义项：在没有“见”的句子中，从“动词＋于＋人”认出是谁把动作加在主语身上
领域：句法
要诀：将“于”后的人移到动词前，人物的遭遇还相合吗？
讲解：“欺于张仪”就是张仪欺骗怀王。遇见“问于张仪”则是向张仪发问，他又不做“问”的人了。
例句：g49.2.p.chu

## 知识点：从事件判断主语承受的动作 {#g49.s.unmarked}
义项：没有被动标记也能读出动作落在主语身上，再判断下一件事由谁做
领域：句法
要诀：主语能自己做下这件事吗？前后文写他在执行还是在承受？
讲解：“屈原放逐”接“著《离骚》”。前半说他遭流放，后半才说他动笔；复述时别平白替他添一个被他流放的人。
例句：g49.2.p.li

## 知识点：动词前的“见”可指动作及于说话人 {#g49.s.speaker}
义项：凭说话双方辨出“见教、见告”等表达中的受教者或受告者
领域：句法
要诀：当面发问或写信的人希望对方做什么？谁收下对方的话？
讲解：“愿君见告”是我请你告诉我。“客见拒”却是客人遭拒；“客见吏”后跟人名物名，说的又是见到了谁。光看“见”排在动词前，还辨不出这两种读法。
例句：g49.2.p.letter

## 单选：孟子把“治人”和“治于人”前后相对。他的话怎样安排“劳力者”？ {#g49.2.q1}
考点：g49.s.agent
语境：g49.2.p.rule

- [ ] 既出体力又治理劳心者
  理由：这把“治人”和“治于人”读成了一种关系。
- [x] 在他的说法里，劳力者是受治理的一方
- [ ] “于人”指他们劳动的地点
  理由：“人”在这里是治理他们的人，不是一处劳动地点。

提示：保持“治”的意思不变，把“于人”中的“人”放到“治”的前面试试。
解析：“劳心者治人”中，动词前的人管别人；“劳力者治于人”中，动作落到动词前的人身上。这是在辨作者所说的两方。

## 单选：这两句只写了一个人名。要把屈原的遭遇和行动分开，应当怎样说？ {#g49.2.q2}
考点：g49.s.unmarked
语境：g49.2.p.li

- [x] 屈原受人流放，自己著书
- [ ] 屈原流放别人，又替被流放者著书
  理由：原文既未另提一个被他流放的人，也未说他代人写作。
- [ ] 屈原与《离骚》的作者一起遭到流放
  理由：“著”接在后面，动作仍属屈原，没有出现第二位作者。

提示：先问“放逐”落在谁身上，再问谁执笔。两问的答案可以是同一人。
解析：“屈原”是流放这一行动所涉及的人，到了“著《离骚》”又是执笔的人。第一个动词前不用另有一个“被”，也能从遭遇读下来。

## 单选：若范景山愿意应这封信，他该做什么？ {#g49.2.q3}
考点：g49.s.speaker
语境：g49.2.p.letter

- [ ] 回信请苏轼来教自己
  理由：这样一来，写信求教的人成了老师。
- [ ] 请旁人替苏轼看看范景山的长相
  理由：“教”关乎指教，问题不是能否看见一个人。
- [x] 把自己熟悉的书或秘法告诉苏轼

提示：“乎”前是苏轼向景山提出的请求。是谁手中可能有书、有秘诀？
解析：“见教”在信中是“教我”。“我”指执笔的苏轼，景山若应允，才是出言指教的人。

## 单选：分别给“惑”和“欺”填上动手的一方，哪种写法合原文？ {#g49.2.q4}
考点：g49.s.agent
语境：g49.2.p.chu

- [ ] 怀王迷惑郑袖，张仪欺骗郑袖
  理由：两个动词共同说怀王所受的事，郑袖不是“欺”的受事。
- [x] 郑袖迷惑怀王，张仪欺骗怀王
- [ ] 郑袖迷惑张仪，怀王欺骗张仪
  理由：“故”后接着说的是怀王识人不明所受的害，不能把怀王写成设局的人。

提示：“内”和“外”两边的人不同；两件事都落在开头哪一个人身上？
解析：把“惑于郑袖”展开为“郑袖惑怀王”，把“欺于张仪”展开为“张仪欺怀王”。两句都不用再加“见”，也能看清施受。

## 原文：教学例句 {#g49.2.p.register}
> 吏以旧券三付童，命焚其二而留其一。暮，二券已焚，一券尚在匣中。
译文：小吏把三张旧券交给童子，叫他烧去两张，留下一张。傍晚，两张券已经烧掉，还有一张在匣子里。
词注：券：凭据，契券。
  匣：小盒。

## 单选：只把“二券已焚”译成“两张券已经烧了别的东西”，与前面哪层交代冲突？ {#g49.2.q5}
考点：g49.s.unmarked
语境：g49.2.p.register

- [ ] 吏当时在匣中藏了三张别人的契券
  理由：起初三券都交给了童子，没有交代另有其物。
- [ ] 天黑以后才下焚券的命令
  理由：“暮”记的是后来清点的时刻，不是下令的时刻。
- [x] 吏叫童子动手，券正是要烧掉的东西

提示：拿“命焚其二”同“二券已焚”对看，两张券先后各放在什么位置？
解析：“其二”在吩咐里是“焚”的对象；到清点时，写法换成“二券已焚”，仍是那两张券受焚。

## 原文：教学例句 {#g49.2.p.message}
> 客见吏于津，问曰：“舟何时发？愿君见告。”吏曰：“日昃乃发。”客谢之。
译文：客人在渡口见到小吏，问道：“船什么时候开？请您告诉我。”小吏说：“太阳西斜时才开。”客人向他道谢。
词注：津：渡口。
  日昃：太阳偏西。

## 单选：“客见吏于津”的“见”和“愿君见告”的“见”各怎样读？ {#g49.2.q6}
考点：g49.s.speaker
语境：g49.2.p.message

- [x] 前一句是客看见小吏，后一句是客请小吏告诉自己
- [ ] 两句都是客看见了什么：先看见吏，再看见一张告示
  理由：这里的“告”有答话承接，句中没有告示。
- [ ] 前一句客被小吏看见，后一句小吏又被客告知船期
  理由：小吏后来开口答船期，是给消息的人。

提示：把小吏说的“日昃乃发”当作回答，哪一问刚好需要这个回答？
解析：“见吏”的宾语就是吏。“君见告”则由“君”开口，我听取消息；方向要从谁问谁答来定。

## 排序：小吏交付契券后，先后能怎样登记它们的去向？ {#g49.2.q7}
考点：g49.s.unmarked
语境：g49.2.p.register

- [3] 傍晚还有一张留在匣中
  理由：余下的一券到傍晚仍可查见。
- [1] 童子接到三张旧券和处置命令
  理由：三张同交童子时，两张还没有烧去。
- [2] 其中两张依命被烧掉
  理由：“已焚”说明清点前就发生了这件事。

提示：把开头的总数和“其二”“其一”排在一起。
解析：“其二”一直是那三张券里的两张。句末虽不再写童子的名字，不能因此让券变成烧别物的那一方。

## 找原文证据：不看译文，哪句话是小吏真的把消息告诉客人的证据？ {#g49.2.q8}
考点：g49.s.speaker
语境：g49.2.p.message

- [ ] 客见吏于津
  理由：这里只写客人到了哪里、见到了谁。
- [x] 日昃乃发
- [ ] 客谢之
  理由：道谢写在答话之后，并不是船期本身。

提示：若在渡口记事簿上填“发船时刻”，你会抄哪几个字？
解析：“日昃乃发”是小吏给客人的回答。求他“见告”的人得到出发时刻，这才道谢。
