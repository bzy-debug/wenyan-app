# 检查：身分、遭遇与答话 {#check.49}

## 原文：教学例句 {#check.49.p.worker}
> 门外二人，一持规，一执甓。持规者语曰：“彼是陶师，吾木工。彼甓甚坚，吾以之为础。”陶师问：“君能举之乎？”工曰：“吾能。”请曰：“幸见助，试举其一。”工为之举，指甓曰：“以甓为础，是吾乡旧法也。”
译文：门外有两人，一人拿圆规，一人拿砖。拿圆规的说：“那位是制陶师傅，我是木匠。他的砖很坚实，我要用作础石。”陶师问：“你能举得起来吗？”木匠答：“我能。”陶师便请他：“烦请你帮我，试着举一块。”木匠替他把砖举起来，指着砖说：“拿砖作础石，这是我们乡里的老办法。”
词注：规：画圆的工具。
  甓：砖。
  础：柱子下面的石墩。

## 单选：读“彼是陶师，吾木工”，当记下哪两种身份？木工最后说“是吾乡旧法也”，又在指什么？ {#check.49.q1}
考点：g49.s.bare
语境：check.49.p.worker

- [ ] 执砖者是陶师，持规者是木工；末句把亲手举砖验分量称为老法
  理由：木工说的是“以甓为础”，没有把先试举一块砖说成乡里的旧法。
- [ ] 两人都是制砖的陶师；末句是在说用砖作础石是老法
  理由：“彼是陶师”只报另一个人的职业；“吾木工”是持规者自己报出不同的行当。
- [x] 执砖者是陶师，持规者是木工；末句称用砖作础石为乡里的老法

提示：开头把“彼”和“吾”分开。读到末句时，试试把“是”换成“这样做”。
解析：前一个“是”把“彼”与陶师的身份接起来。“吾木工”虽然没有“是”或“也”，仍在报另一人的职业。后一个“是”指木工刚说的做法，换成“这样做”便清楚了。

## 单选：从“彼甓甚坚”能给这些砖添上哪条记录？ {#check.49.q2}
考点：g49.s.quality
语境：check.49.p.worker

- [ ] 陶师把原本柔软的砖弄硬了；“甚坚”是制作工序
  理由：这句话中并没有叫砖变硬的施事，持规者说的是眼下能看到的性质。
- [ ] 木工这个人的性情坚定；砖的好坏没有说
  理由：“彼甓”是他的砖，木工准备拿砖作础正用到砖的性质。
- [x] 砖很坚实；“甚坚”写砖本身的性质

提示：“甚坚”前面，话已经落到人还是物上？
解析：“彼甓”在这里受陈述，“甚坚”可以直接回答砖怎样，所以木工打算拿来承柱。

## 单选：“请曰”前没写人名。“幸见助”是谁请谁帮忙？后来是谁动手？ {#check.49.q3}
考点：g49.s.speaker
语境：check.49.p.worker

- [ ] 木工是为了试自己的础石，陶师只请他看砖，并没有求他帮自己
  理由：陶师说的“幸见助”带着请求；“为之举”也明说木工是为了对方而动手。
- [x] 木工替陶师举砖，陶师是向他说“帮我”的人
- [ ] 木工说“吾能”之后又接着求人，砖是陶师举起来的
  理由：“请曰”前要按应答换人；随后“工为之举”把实际举砖的人点成了木工。

提示：谁开口求人？后一句由谁动手？
解析：“见助”带进说话人的一方，相当于请对方助我。“为之举”写的正是木工替陶师举砖。

## 原文：教学例句 {#check.49.p.messenger}
> 邮人至北关，守者误执之。其同行先至县，告曰：“邮人拘于关吏，所持之书尽取矣。”令问：“吏取其书乎，抑邮人自献乎？”答曰：“吏启箧取之。”
译文：送信人到了北关，守关的人错抓了他。他的同伴先来到县里，报告：“送信人被关吏扣下了，他带的信全被拿走了。”县令问：“是关吏拿走的，还是送信人主动交出的？”同伴答：“是关吏开箱拿走的。”
词注：拘：扣留。
  自献：自己主动交出。

## 单选：谁扣了谁？“书尽取”又该让谁来做“取”的动作？ {#check.49.q4}
考点：g49.s.agent
语境：check.49.p.messenger

- [ ] 关吏扣的是同伴，后来又从送信人的箱中取了信
  理由：同伴先到县里报告；在北关“误执”的是送信人。
- [ ] 关吏扣了送信人，但信是同伴取去给县令看的
  理由：同伴先到县里是为了报告。答话“吏启箧取之”明确说取信的是关吏。
- [x] 关吏扣送信人，也是关吏取走了信

提示：先听同伴报告，再拿最后一句给动手的人署名。
解析：“拘于关吏”的“于”带出施事。后面“书尽取”虽然没有“见”“为”等字，仍是信遭人取走。

## 单选：县令问“吏取其书乎，抑邮人自献乎”，只回“书已出箧”够吗？ {#check.49.q5}
考点：g49.skill.choice
语境：check.49.p.messenger

- [ ] 够；县令只想知道箱子还在不在
  理由：问句两项都在谈信离开手里的方式。
- [x] 不够；还要说是关吏取，还是邮人主动交出
- [ ] 不够；还要证明邮人本从哪座城出发
  理由：县令没有在问来路，他追问的是谁先动手交、取。

提示：两种可能都可以造成“信不在箱中”。哪个细节能把它们分开？
解析：“吏启箧取之”支持第一种。仅说书离开了箱，给不出县令所追问的主动一方。

## 原文：教学例句 {#check.49.p.shrine}
> 乡人岁祀一士。童问父曰：“谁祀此士？”父曰：“吾乡人也。昔贼欲使之卖友以求生，士不肯，遂死。乡人敬其死义，故岁祀之。”
译文：乡里人每年祭祀一名士人。孩子问父亲：“谁来祭这位士人？”父亲说：“我们乡里的人。当年贼人想让他出卖朋友以求活命，他不答应，终于丧生。乡亲敬重他为道义而死，所以年年祭祀他。”
词注：岁祀：每年祭祀。
  卖友：出卖朋友。

## 单选：孩子问“谁祀此士”，父亲报的是谁？接着说“死义”，想说明什么？ {#check.49.q6}
考点：g49.skill.whorole
语境：check.49.p.shrine

- [ ] 祭人的是乡亲；“死义”说乡亲使道义跟着士人一同消失
  理由：乡人之所以祭祀他，正是要记得他不肯出卖朋友这件事。
- [ ] 祭人的是这位士人；他后来为了不出卖朋友而死
  理由：问句里“此士”是受祭的人。“吾乡人也”答的是谁来祭他。
- [x] 祭人的是乡亲；士人自己为守住道义而死

提示：把“吾乡人”填进“谁”的位置，再看那位士人有怎样的选择。
解析：父亲报出祭者是乡人。士人宁死也不肯卖友，“义”说他为了什么而死；他的死正是乡人祭他的缘由。
