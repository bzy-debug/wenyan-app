# 课文：听两种说法，找准答话的人 {#g49.3}
简介：从别人和自己之间的动作来回读，弄清是谁问、替谁办、为何而动。

## 正文

客人问“汝求此书乎，抑友赠汝乎”，说的是同一部书。第一种设想中，得到书的人先去求；第二种设想中，送书的人先开口。“抑”在这里领出另一种可能，答“有书”还不够。

读“死国”时，先找前文怕死的是谁。一句说人为国事而死；若说成使国家覆亡，死者和缘由就颠倒了。动作后面出现一个名字，要看这个人做了什么或得到什么，并不总是承受这个动作。

## 知识点：用“抑”并列两种待定的解释 {#g49.skill.choice}
义项：两问备举时，辨出要选的是哪两种说法
领域：句法
要诀：把说者正在悬疑的两件事并排写出，哪一个回答真能帮他选？
讲解：“子自行乎，抑人召子乎”没问此人到没到，而在辨他是自己来，还是有人来召。
例句：g49.ex.choice

## 原文：教学例句 {#g49.ex.choice}
> 汝自织乎，抑母遗汝乎？
译文：你是自己织的，还是母亲送给你的？

## 知识点：动作因谁而起、为谁而做 {#g49.skill.causeperson}
义项：分清动词后面的人或事是行动的缘由、受益者，还是被改变的一方
领域：句法
要诀：先说清谁动，再问他为何这样做、替谁这样做。
讲解：“父哭其子”，流泪的是父亲，哭是为了儿子；没有使儿子哭这一层。“客为邻汲”是替邻居取水，邻居并未去打水。
例句：g49.ex.causeperson

## 原文：教学例句 {#g49.ex.causeperson}
> 人皆哀之，父独哭之。
译文：众人都为他难过，父亲独自为他哭泣。

## 知识点：疑问代词所问的施事和受事 {#g49.skill.whorole}
义项：分辨谁来问人、问的是谁
领域：句法
要诀：试填一个真实人名，填好以后他究竟开口还是受问？
讲解：“孰召汝”答的是来召你的人。“汝召谁”答的是被你召来的人；古人也可把所问的宾语放到动词前。
例句：g49.ex.whorole

## 原文：教学例句 {#g49.ex.whorole}
> 师问：“谁教汝？”徒曰：“吾父。”
译文：老师问：“是谁教你的？”徒弟回答：“是我父亲。”

## 单选：子禽已经知道孔子听得到政事。他还要子贡分清什么？ {#g49.3.q1}
考点：g49.skill.choice
语境：g49.3.p.policy

- [ ] 是孔子听到政事，还是子贡听到
  理由：问题开头已把闻政的人定为“夫子”。
- [x] 是孔子主动求问，还是别人主动相告
- [ ] 是这个国家有政事，还是那个国家有政事
  理由：“是邦”指孔子抵达的那个国家，备选的是消息怎样取得。

提示：“求”与句中表示给予的“与”，主动的一方相同吗？
解析：两个问句共说孔子能闻政，所疑的是由谁先发起。

## 找原文证据：哪半句话让子禽的问题有了第二种回答？ {#g49.3.q2}
考点：g49.skill.choice
语境：g49.3.p.policy

- [ ] 必闻其政
  理由：这是他已经认可的事实。
- [x] 抑与之与
- [ ] 子禽问于子贡曰
  理由：此处只写谁向谁发问。

提示：找一个提出另一种可能的开头。
解析：“抑”带出另一种情形：政事是人家主动告诉老师的。

## 单选：末句“死国”把“国”接在“死”后，该保留谁冒着丧命的风险？ {#g49.3.q3}
考点：g49.skill.causeperson
语境：g49.3.p.country

- [ ] 已逃走的人要把旁人处死
  理由：“亡”只是刚刚举出的一种选择，文中没有此处处死别人的行动。
- [x] 是说话的人自己为国事而死
- [ ] 是说话的人要让一个国家灭亡
  理由：前面两种选择中，说话者都在考虑自己的死。

提示：把“今亡亦死”追问的性命和末句对起来。
解析：前后没有换成国家死亡。“国”点出死是为了什么；这一段仍在商议，不能记成两人已经身死。

## 原文：教学例句 {#g49.3.p.cloth}
> 邻人丧子，妪往哭之，归为其母缝衣。孙问：“谁请大母？”妪曰：“无人请，吾自往耳。”
译文：邻居失去了儿子，老妇去为他哭泣，回来为孩子的母亲缝衣。孙子问：“是谁邀请祖母的？”老妇说：“没人邀请，是我自己去的。”
词注：妪：老妇。
  大母：祖母。

## 单选：把“哭之”和“为其母缝衣”各画一幅图，谁哭、谁缝、又是为了谁？ {#g49.3.q4}
考点：g49.skill.causeperson
语境：g49.3.p.cloth

- [ ] 老妇先把孩子弄哭，又让母亲自己缝衣
  理由：孩子已经去世，母亲也没被写作执针的人。
- [x] 老妇为死去的孩子哭，又替孩子的母亲缝衣
- [ ] 死者的母亲为老妇哭，再替她缝衣
  理由：“妪往……归……”这两个动作都接着老妇。

提示：“归”前后都是谁在行动？“之”和“其母”指同一人吗？
解析：孩子是她哀悼的人，母亲是得到帮助的人；哭与缝两件事都由老妇做。

## 单选：孙问“谁请大母”，要是确有人相邀，回答里应报谁？ {#g49.3.q5}
考点：g49.skill.whorole
语境：g49.3.p.cloth

- [ ] 受到邀请的祖母本人
  理由：祖母已在问句中明说，不必再问她是谁。
- [ ] 祖母去吊唁的死者
  理由：“请”问的是邀请的事，死者是此前所哭的人。
- [x] 开口邀祖母前来的人

提示：把名字填进“某人请大母”。
解析：答“无人请”正合所问，说明祖母并没有等别人相邀。

## 原文：教学例句 {#g49.3.p.fisher}
> 津吏问童：“谁召汝？”童曰：“渔父。”又问：“汝何求？”童曰：“求其舟，将迎吾兄。”吏曰：“其人许汝乎，抑汝自取乎？”童出渔父所付之楫。
译文：渡吏问孩子：“谁叫你来的？”孩子说：“是捕鱼老人。”又问：“你求什么？”孩子回答：“求借他的船，打算接我哥哥。”渡吏再问：“他答应给你用，还是你自己拿的？”孩子拿出了老人交给他的桨。

## 单选：渔父和船，为什么不能在这两次答话里互换？ {#g49.3.q6}
考点：g49.skill.whorole
语境：g49.3.p.fisher

- [x] 召人的应答渔父，所求的物件应答船
- [ ] 两个“求问”都要知道谁站在渡口
  理由：第二问有明确的动作“求”，答的是所求之物。
- [ ] 渔父是被孩子叫来的，船是送给哥哥的
  理由：“谁召汝”中“汝”已经是受召的人；船还只说是用去迎人。

提示：分别填“某召汝”和“汝求某”。
解析：“谁”补来召者，“何”补所求之物。两个疑问代词在句首附近，所顶替的位置却不同。

## 单选：末次问话要判哪一件事？孩子拿出船桨，是想支持哪一说？ {#g49.3.q7}
考点：g49.skill.choice
语境：g49.3.p.fisher

- [ ] 是不是渔父亲自划船；拿桨便知渔父在船上
  理由：吏问的是许可与自取，没问谁操桨。
- [x] 是否得到许可；船桨由渔父交付，支持已经许可
- [ ] 哥哥是否已经到达；船桨足以证明到岸
  理由：原文只说将迎，没说哥哥已经渡过河。

提示：把“许汝”和“自取”分开，再问“所付”是谁先递的。
解析：问句提出两种来历。老人把桨交给孩子，是可用来解释他为何有船可用的证据。

## 原文：教学例句 {#g49.3.p.boat}
> 舟人溺死，闾人哭之。舟人之父老，众为之负薪。父问：“谁负薪？”邻曰：“东舍之子。”
译文：船夫溺死了，乡邻为他哭泣。船夫的父亲年老，大伙儿替他背柴。父亲问：“谁背的柴？”邻居说：“东边那家的孩子。”

## 单选：若说“乡邻让船夫哭，又使老父背柴”，两处人事都倒在何处？ {#g49.3.q8}
考点：g49.skill.causeperson
语境：g49.3.p.boat

- [x] 乡邻自己哭；背柴的是帮老父的人
- [ ] 前一句应当改，后一句父亲确实背了柴
  理由：答“东舍之子”，点出的正是背柴的人。
- [ ] 后一句应当改，前一句船夫确实被弄哭了
  理由：“舟人溺死”之后乡里的人“哭之”，是生者吊死者。

提示：先看“闾人”做什么，再拿父亲问谁背柴的答话核实。
解析：哭是为死去的船夫，背柴是为年老的父亲；两句都不能说成让对方去做。
