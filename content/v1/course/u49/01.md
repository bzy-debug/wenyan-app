# 课文：眼前是何人，眼前的水又怎样 {#g49.1}
简介：先分清说的是身份、来历还是性质，再听“是”到底说了什么。

## 正文

读传记，遇见“荀卿，赵人”，不要等下一句给“荀卿”安排一个动作。“赵人”已经把他的籍贯交代完了。古人可以直接把一个名词接在另一个名词后面。写成“赵人也”，末尾的“也”帮助收束这一判断；没有“也”，句子也说得完整。

另有一句“此必是豫让也”。桥下藏着谁还要探问，说话人指着眼前的动静，已经有“此”字在前，“是”把他认作豫让。换成“借而不还，是失信也”，“是”才把前面的行为指回来，等于“这”。不妨再看“溪深”：溪的名字、来历都没有变，人家说的是它有多深。若下文是“溪涨”，说的又是水发生了变化。

## 知识点：两个名词直接交代身份或籍贯 {#g49.s.bare}
义项：句末没有“也”，仍能用名词性成分断定人物的身份、籍贯
领域：句法
要诀：问后半句：答的是“什么人”，还是“做了什么”？
讲解：“荀卿，赵人”可以填入籍贯一栏。若在“赵”后随意补个“去”，便把籍贯改成了目的地。
例句：g49.1.p.xun

## 知识点：“是”用来确认身份 {#g49.s.copula}
义项：辨认判断动词“是”连接的对象与身份，区别回指前文的“是”
领域：句法
要诀：若已经用“此”指出眼前的人，“是”后又说了什么？
讲解：“此是某人”把眼前人同名字相接；“是失信也”若紧接一个违约故事，才可以问“这”指哪件事。
例句：g49.1.p.rang

## 知识点：形容词直接说事物的性质 {#g49.s.quality}
义项：从形容词谓语读出事物当时的性状，区别给它命名或叙述行动
领域：句法
要诀：把句子当作回答，是在答“叫什么”，还是“什么样”？
讲解：“北溪深”告诉赶路人水深，“此北溪也”才告诉他眼前是哪一道溪。没有“是”字也能把水的深浅说清。
例句：g49.1.p.ford

## 单选：录荀卿的籍贯和游学之地，两栏怎样填？ {#g49.1.q1}
考点：g49.s.bare
语境：g49.1.p.xun

- [ ] 籍贯齐，游学赵
  理由：“于齐”紧跟“游学”，“赵人”才跟在人名后。
- [x] 籍贯赵，游学齐
- [ ] 两栏都填赵，齐只是别人的名字
  理由：“游学于齐”明说他到齐国游学。

提示：先单独读完“荀卿，赵人”，再看下句多出哪一个去处。
解析：“赵人”两字里不用另找一个“是”。籍贯交代完毕，作者才把荀卿带到齐国。

## 单选：“此必是豫让也”接在马惊之后。襄子当时作了什么判断？ {#g49.1.q2}
考点：g49.s.copula
语境：g49.1.p.rang

- [x] 认定引起马惊的那个人就是豫让
- [ ] 认定豫让这个名字取得对
  理由：他随后派人去查的是桥下人的身份，未曾品评名字。
- [ ] 先让豫让自己承认马曾受惊
  理由：他说完才“使人问之”。

提示：“此”已指向眼前的人。看看“是”后接的是动作还是姓名。
解析：这里“是”把所指之人同“豫让”这个名字连接起来。“必”是襄子猜得有把握；下面的“果”才写查得相合。

## 原文：教学例句 {#g49.1.p.ford}
> 客至北溪，水深，岸滑。问童：“此何溪也？”曰：“此北溪也，南溪浅，可涉。”客乃南行。
译文：客人到了北溪，水深，岸边又滑。他问孩子：“这是哪条溪？”孩子说：“这是北溪，南溪水浅，可以蹚过去。”客人便向南走。
词注：涉：蹚水过去。
  滑：这里说岸上不好站稳。

## 单选：地图上已经标出两条溪的名字。还要在北溪旁补上哪条有关渡水的消息？ {#g49.1.q3}
考点：g49.s.quality
语境：g49.1.p.ford

- [ ] 北溪又名“岸滑”
  理由：“岸滑”是说岸上情形，孩子答溪名时只说“北溪”。
- [ ] 北溪的水刚刚变浅
  理由：“浅”说南溪；“水深”本身也没有说水位刚变。
- [x] 目前水深，岸边还容易打滑

提示：“水深，岸滑”各先说一物，再交代它怎么样。
解析：客人先碰见深水和滑岸，随后才问溪名。“深”“滑”说的都是行路会遇到的情形。

## 原文：教学例句 {#g49.1.p.roster}
> 吏录渡者。季良，陶人；伯安，舟师。良负瓮，安执楫。
译文：小吏登记过河的人。季良是陶匠，伯安是船师。季良背着瓮，伯安拿着桨。
词注：陶人：制陶的工匠。
  楫：船桨。

## 找原文证据：只把伯安的职业抄进簿中，原文哪两字正好够用？ {#g49.1.q4}
考点：g49.s.bare
语境：g49.1.p.roster

- [ ] 渡者
  理由：这包括了过河的各色人等，不能辨明伯安的职业。
- [x] 舟师
- [ ] 执楫
  理由：这是伯安手上的动作；他的身份另有两个字写明。

提示：先将伯安的名字读完，余下哪个词直接说他是什么人？
解析：“伯安，舟师”已经是完整的介绍，句末没有“也”。后面拿船桨的动作，和这身份相合。

## 原文：教学例句 {#g49.1.p.gate}
> 暮有叩门者，儿曰：“此是吾舅。”开之，果舅也。舅出金还母，曰：“受贷必偿，是吾家之约也。”
译文：傍晚有人敲门，孩子说：“这是我舅舅。”开门一看，果然是舅舅。舅舅取出钱还给孩子的母亲，说：“借了定要还，这是我们家的约定。”
词注：贷：这里指借来的钱。
  偿：归还。

## 单选：孩子说“此是吾舅”，舅舅说“是吾家之约也”。后一个“是”能换成“这件事”，指的是什么？ {#g49.1.q5}
考点：g49.s.copula
语境：g49.1.p.gate

- [ ] 敲门的人是舅舅
  理由：这是孩子所认的人；舅舅谈家约时已经换到归还借款。
- [ ] 天黑以后才准敲门
  理由：借还钱财一事同敲门的时刻无关。
- [x] 凡向人借钱，就须偿还

提示：在后一个“是”前停下来：舅舅刚说完的是哪条规矩？
解析：孩子的话已经有“此”指人，然后用“是”认出舅舅；舅舅话里的“是”直接指回“受贷必偿”。

## 原文：教学例句 {#g49.1.p.cup}
> 客试二盏。左盏薄，右盏厚。客举右盏，问所值，未尝举左盏。
译文：客人查看两只杯子。左杯薄，右杯厚。他举起右杯问价，没有举左杯。
词注：盏：小杯。
  所值：值多少钱。

## 单选：“左盏薄”能不能记成“客人刚刚把左盏磨薄了”？ {#g49.1.q6}
考点：g49.s.quality
语境：g49.1.p.cup

- [x] 不能。只写了左杯原有的厚薄，没写磨杯的人或动作
- [ ] 能。凡事物后面跟“薄”，总要补一个使它变薄的人
  理由：“薄”能直接说明杯壁怎样，不能凭字序添工序。
- [ ] 不能，因为左盏的“薄”指价格低
  理由：所问的价钱是右盏的，左盏同右盏比较的是厚薄。

提示：左右句互相照应，哪两个字在说一种可以对看的性质？
解析：“左盏薄，右盏厚”把两个杯壁的厚薄摆在一起。等到“客举右盏”，才有客人正在做的事。

## 原文：教学例句 {#g49.1.p.quarry}
> 匠携一石至。童问其名。匠曰：“砥石。其面平。”乃濡石而磨刀。
译文：工匠带来一块石头。孩子问名字，工匠说：“是磨刀石。它的表面平整。”随即沾湿石头磨刀。
词注：砥石：磨刀石。
  濡：沾湿。

## 排序：给这块石头作记录，按工匠说和做的先后排出三条。 {#g49.1.q7}
考点：g49.s.quality
语境：g49.1.p.quarry

- [2] 形状：表面平整
  理由：“其面平”紧接石名。
- [3] 用途得到演示：沾湿后用来磨刀
  理由：“乃”把这件事放在答话之后。
- [1] 名称：磨刀石
  理由：这是工匠对“问其名”的回答。

提示：孩子先问什么？“平”字又是在说哪个部位？
解析：“砥石”答名字，“平”答石面怎么样；等石头沾上水，磨刀的动作才真正开始。

## 找原文证据：襄子认人时有个“必”，派人查问以后，哪句话才明写查得的身份？ {#g49.1.q8}
考点：g49.s.copula
语境：g49.1.p.rang

- [ ] 襄子至桥
  理由：只交代襄子到了哪里。
- [x] 果豫让也
- [ ] 使人问之
  理由：查问刚开始，这里尚未写出结果。

提示：同一个人名出现两次，哪一次在派人查问之后？
解析：前面以“是”把那人认作豫让，后面直接说“果豫让也”。判断都认的是同一个人，证实的时刻却在后。
