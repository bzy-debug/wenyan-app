# 试读：井里还有水吗 {#pilot.well}

阶段：学习前
版本：1
类型：教学自编
状态：草稿
原文权利：项目自撰教学短文
译注权利：项目自撰词注与练习
正文：二人同汲于井。甲下绠，不及水，曰：“井竭矣。”乙取小石投之，闻水声，乃续其绠，再下之，得水而归。
词注：汲：打水。绠（gěng）：打水用的绳。竭：干涸。

## 练习：甲说井干了，当时他亲自试过什么？ {#well.claim}

考点：区别所见与推断
- [ ] 把石头扔进井里，听不到水声
- [x] 把井绳放下去，够不着水
- [ ] 接长井绳，依旧打不上水
解析：“不及水”只说明绳子没够到。井底究竟有没有水，甲还没有查明。

## 练习：乙“投之”，后来又“下之”。两次说的是什么？ {#well.objects}

考点：辨清动作及其对象
- [ ] 先放下短绳，再放下长绳
- [ ] 先扔下一块石头，再扔下另一块
- [x] 先投下小石头，再放下接长的井绳
解析：“取小石投之”连着石头说。“再下之”前面多了一步“续其绠”，手里拿的已经换成井绳。

## 练习：为什么听见一声响，乙接下来就去接绳子了？ {#well.reason}

考点：用后来取得的证据检验原先的判断
- [x] 他听见的是水声，便想到井绳可能太短
- [ ] 他以为落石堵住了井口，要用绳把石头拉出来
- [ ] 他得知井水刚刚涨高，要防止绳子浸湿
解析：石头落水有声，甲对井底的猜测就站不住了。接长绳子后果然打到了水。

## 续读：次日再来 {#well.extension}

原文：明旦甲复来携长绠一汲而足
断句：明旦甲复来／携长绠／一汲而足
其他读法：明旦／甲复来／携长绠／一汲而足
参考大意：第二天早晨甲又来了，带着长绳，一回就打够了水。
说明：“明旦”交代时候，可以单独一停。“复来”“携”“汲”的人都是甲。“一”说只打了一回。
