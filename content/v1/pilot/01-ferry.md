# 试读：渡口候舟 {#pilot.ferry}

阶段：学习前
版本：1
类型：教学自编
状态：草稿
原文权利：项目自撰教学短文
译注权利：项目自撰解析与选项
正文：客至津，闻水声甚急。舟子曰：『水未平，未可渡也。』客乃坐树下。久之，水缓，舟子招客，客始登舟。
词注：津：渡口。舟子：船夫。

## 练习：客人最先是怎样察觉水流很急的？ {#ferry.sense}

考点：从对象判断动作
- [x] 听见湍急的水声
- [ ] 从船夫口中得知
- [ ] 看见船夫招手
解析：客人先“闻水声”，后来船夫才开口。发现水急时，他已经听见流水声了。

## 练习：树下等待的是谁？ {#ferry.actor}

考点：辨认动作发出者
- [ ] 船夫
- [x] 客人
- [ ] 船夫和客人
解析：“客乃坐树下”把等候的人点出来了。船夫先前在劝他等，后来又是招手让他上船的人。

## 练习：哪项变化使客人终于能够登舟？ {#ferry.turn}

考点：联系条件与后果
- [ ] 客人找到了树荫
- [ ] 客人听清了船夫的话
- [x] 水流渐缓，船夫示意可渡
解析：船夫先说“水未平”，后来“水缓”了才招客。“始”说的是到这时候，客人终于能登船。

## 续读：断句与译意 {#pilot.ferry.extension}

原文：日已暮众人渡毕舟子系舟而归
断句：日已暮／众人渡毕／舟子系舟而归
参考大意：天晚了，众人渡完了河，船夫系好船回家。
说明：从“日”读到“众人”，再读到“舟子”，每换一次主语，意思也换一层。末尾系船、回家，两件事都是船夫做的。
