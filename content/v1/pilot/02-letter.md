# 试读：没有回音的信 {#pilot.letter}

阶段：学习后
版本：1
类型：教学自编
状态：草稿
原文权利：项目自撰教学短文
译注权利：项目自撰词注与练习
正文：客寄书于友，旬日无报，意友忘己。道逢使者，问之。使者出其书曰：“河涨，未得渡。”客乃笑曰：“吾过矣。”
词注：旬日：十天。报：回复。使者：受托送信的人。

## 练习：客人先知道了什么，又猜了什么？ {#letter.claim}

考点：区别所见与推断
- [x] 等了十天没有回信，便猜朋友忘了自己
- [ ] 看见河水涨了，便猜朋友没有写信
- [ ] 看见朋友收下信，便猜送信人迷了路
解析：“旬日无报”是他等到的结果。“意”说的是他自己的猜想，朋友并没有出场说话。

## 练习：“问之”和“出其书”各写了谁在做事？ {#letter.objects}

考点：辨清动作及其对象
- [ ] 送信人发问，客人取出回信
- [ ] 客人发问，朋友拿出写好的答信
- [x] 客人问送信人，送信人拿出那封托付给他的信
解析：前一句是客人路遇使者，向他问起。下一句重新点名“使者”，信从使者手里拿了出来。

## 练习：哪件事最让客人明白自己猜错了？ {#letter.reason}

考点：用后来取得的证据检验原先的判断
- [ ] 朋友的回信已经写好，只差过河
- [x] 原信还在使者手中，朋友还没收到
- [ ] 使者也已经十天没见到客人
解析：水涨拦下了送信人。连第一封信都没送到，朋友没回信就不足以说明他忘了客人。

## 续读：水退以后 {#letter.extension}

原文：明日水退使者济以书授其友
断句：明日水退／使者济／以书授其友
其他读法：明日／水退／使者济／以书授其友
参考大意：第二天水退了，送信人过了河，把信交给了客人的朋友。
说明：“水”做“退”的主语。过河、交信这两个动作接着说使者。“以书”要和后面的“授”一起读。
