# 试读：夜行遇桥 {#pilot.lamp}

阶段：学习后
版本：1
类型：教学自编
状态：草稿
原文权利：项目自撰教学短文
译注权利：项目自撰解析与选项
正文：樵者负薪夜归，至桥，见桥上有隙，止而未进。童子闻其呼声，举灯照之。樵者见可行之处，乃过桥。
词注：樵者：打柴的人。薪：柴。隙：缺口。

## 练习：童子是怎样注意到樵者的？ {#lamp.sense}

考点：从对象判断动作
- [ ] 看见樵者举灯
- [x] 听见樵者呼喊
- [ ] 发现桥面有缺口
解析：童子听见的是樵者的喊声。前面用眼睛看见桥上缺口的人是樵者。

## 练习：是谁把灯举起来的？ {#lamp.actor}

考点：辨认动作发出者
- [ ] 樵者
- [ ] 樵者与童子一同举灯
- [x] 童子
解析：把两句话连起来：“童子闻其呼声，（童子）举灯照之。”第二句省下来的还是童子。

## 练习：樵者从停步到过桥，直接原因是什么？ {#lamp.turn}

考点：联系条件与后果
- [x] 借灯光看清能走的地方
- [ ] 桥上的缺口已被修补
- [ ] 有人替他背走了柴
解析：樵者先看清下脚的地方，“乃过桥”。使他能过桥的是灯光；缺口并没有补上，柴也没有卸下。

## 续读：断句与译意 {#pilot.lamp.extension}

原文：童子收灯樵者谢之负薪而归
断句：童子收灯／樵者谢之／负薪而归
其他读法：童子收灯／樵者谢之负薪而归
参考大意：孩子收起灯，樵夫向他道谢，背着柴回了家。
说明：收灯的是童子，道谢的是樵者。最后“负薪而归”仍说樵者；这里既可以停一停再读，也可以接在“谢之”后面一气读下去。
