# 试读：夜行遇桥 {#pilot.lamp}

阶段：学习后
版本：1
类型：教学自编
状态：草稿
原文权利：项目自撰教学短文
译注权利：项目自撰解析与选项
正文：樵者负薪夜归，至桥，见桥上有隙，止而未进。童子闻其呼声，举灯照之。樵者见可行之处，乃过桥。
词注：樵者：打柴的人。薪：柴。隙：缺口。

## 练习：童子是怎样注意到樵者的？ {#lamp.sense}

考点：从对象判断动作
- [ ] 看见樵者举灯
- [x] 听见樵者呼喊
- [ ] 发现桥面有缺口
解析：“闻其呼声”说明童子听见呼喊。“见桥上有隙”是樵者的发现。

## 练习：是谁把灯举起来的？ {#lamp.actor}

考点：辨认动作发出者
- [ ] 樵者
- [ ] 樵者与童子一同举灯
- [x] 童子
解析：“童子闻其呼声，举灯照之”前后承接，举灯沿用前一小句的主语“童子”。

## 练习：樵者从停步到过桥，直接原因是什么？ {#lamp.turn}

考点：联系条件与后果
- [x] 借灯光看清能走的地方
- [ ] 桥上的缺口已被修补
- [ ] 有人替他背走了柴
解析：“见可行之处，乃过桥”将看清落脚处与过桥连起来，文中没有修桥或卸柴的动作。

## 续读：断句与译意 {#pilot.lamp.extension}

原文：童子收灯樵者谢之负薪而归
断句：童子收灯／樵者谢之／负薪而归
参考大意：孩子收起灯，樵夫向他道谢，背着柴回家。
说明：“童子”与“樵者”分别引出动作；“负薪而归”承接樵者的动作，也可以与上一句连读。
