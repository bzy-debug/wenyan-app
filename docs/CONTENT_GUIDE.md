# 教学写作与审核

每份课稿都是可直接阅读的 Markdown 文件。用 [作者工作台](https://bzy-debug.github.io/wenyan-app/#/author) 选择一课，修改、试做并下载修改稿。编辑区的改动只保留在当前页；交付下载的 Markdown 即可。文件结构、中文字段、题型和报错示例见[作者手册](AUTHORING.md)。

## 从阅读困难写起

为每课写出一个学习者可以独立完成的动作，例如“找出离开的起点”“从上文补出省略的主语”。知识点应细化到单个意义或用法。先给必要语境，让读者比较两种读法，明确哪个词、哪个动作或哪处指代关系能排除其中一种。讲解后用新语境检验同一方法。

每道题标明考点、语境、正确选项、提示与原文依据。单选与选段逐个解释干扰项；排序要能从原文确定先后。遇到合理的第二种读法，应接受语言事实，重写问题或补充语境。单元检查使用新的文本或情境，避免复习提前重复其答案。

## 引用与权利

自造句标记为「教学例句」。古籍引文标明作品、篇章、作者或编者、所用版本或可核对的文本，摘句保留原意；节选、字形转换和标点处理应说明。改写真实故事时标明教学改写或单独写成教学例句。原文权利与现代译注权利分别记录。商业教材用于核对教学范围与编排，译文、讲解及练习由项目自撰。[教学参考与课次映射](TEACHING_REFERENCES.md)

## 交稿与发布

1. 编辑课稿并保留已有标识。在作者预览中检查讲解、所引原文、正确答案、提示与干扰项。选段用原文文字指定；重复字词用出现次数消歧，编译器负责计算位置。
2. 编辑人员把稿件放入对应单元并运行内容校验。当前 L1 每课 8 题，每单元检查 6 题；知识卡在多个语境中考查同一义项。
3. 新内容和经机器改写的内容使用草稿状态。人工复核出处、权利、义项、歧义和学习难度后记录审核人并改为已审核。发布负责人复核该内容及依赖后，方可标为已发布。
