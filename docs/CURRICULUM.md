# 从一段小事读到整篇古文

这条路径面向能读白话、想自己读通古文的成年人。L1 至 L5 依次有 4、12、9、6、6 个单元。每单元三课及一次检查。111 节课各有八题，37 次检查各有六题，共 1110 题。整条路可自由选学。下表的“能做什么”也是学习者挑选起点的依据。

| 从哪里开始 | 学完这一段，试着做件什么事 | 备课记录 |
| --- | --- | --- |
| L1 读懂单句 | 给一个没读过这则小事的人讲清楚，谁先做了什么，结果如何。读到相同的字，能在另一句话里重选合适的意思。 | [单句与短章](curriculum/L1.md) |
| L2 连句成段 | 把前后两句连成一段白话。人做了什么、让谁怎样、在何处发生，即使原文语序变化，也能说清。 | [词义和句式](curriculum/L2.md) |
| L3 读完一则故事 | 看清说话的人何时换了，插在中间的往事发生在哪一天，以及谁只是猜测。合上书，再连贯地讲一遍。 | [叙事与复句](curriculum/L3.md) |
| L4 研读散文与论说 | 分清作者、人物和评论者的口吻。从文中取出一句，说明少了这一层，论证会失去哪一步。读诗词时，说得清哪几句发生在眼前，哪几句是对远方的设想。 | [文体与论证](curriculum/L4.md) |
| L5 借辞书独立研读 | 一篇文章先读通大意。选出真妨碍理解的生字、生义或典章，查过再回读，并能交代哪处证据决定了自己的读法。 | [辞书、古注与自读](curriculum/L5.md) |

## 从同一篇文章里学几件事

词义和句法跟随阅读安排。第一课先随守桥的驿卒听水声、报信，再去读王戎和伙伴摘李子的片段。同是“走”，场景从报急换成孩子争先，读者要自己从动作的目的判断快慢。同一个故事里还可以问谁没动、什么是当场见到的、什么是人物猜出来的。隔一段时间复习时，应用按具体义项另选语境。

进入论说和史传后，读者会遇到更长的引语、旁人的看法和相互抵触的判断。词义之外，虚词、句法、篇章、阅读方法和文化背景都在课文中有着落。使用辞书的一道题可以同时练字音、词义和人物关系。文化背景跟着官职、称谓、地理等确实影响文意的地方讲。

要核对一个字学到了哪一步，可以从[王力常用词逐条索引](curriculum/WORD_INDEX.md)查条号，再看[教材与练习对照](curriculum/COVERAGE.md)。词注记录某个词在眼前一句如何解释。带考点的题目才留下独立辨义的机会。过几课再遇同一义项，课稿用旧知识点标记新的练习，复习时能从同一张卡取到不同文字。遇到一个似懂非懂的词时，可以在答后展开解析查看随文词注，也可以在知识库切到「随文词义」，用字词或释义找到它出现的原句，再回到那一课或单元检查。一个字在不同文章里的读法可以并列。复习卡仍记录独立作答的情况。

## 课怎样排，后面怎样再考

- **L2 先把一个字放回事情里。** 比如“请”后都有一个动作，读者却要分出该谁去做。一个单元可以换几篇文章，接触十来个相关义项。[人物往来](curriculum/VOCABULARY.md) · [补查的常用义](curriculum/FREQUENT_WORDS.md)
- **L3 把人和事接成一段。** “举”“拜”之间有时隔着一番辞让，把荐举直接读成就任，会弄错人的经历。议论里还要听清哪些话已有把握，哪些话只是在姑且承认一种可能。[史传用词](curriculum/HISTORY_WORDS.md) · [议论用词](curriculum/ARGUMENT_WORDS.md)
- **L4 留出几篇给旧字。** 例如读过“拜”授官义，后来在廉颇的记载里再遇一次，题目才问他因什么、受了何职。每个回读义项沿用原卡，读者在新文中的作答也能用于安排复习。[原卡与新题](curriculum/RETURN.md)
- **L5 让读者亲自找。** 给一个未注明音的字、一张按部首和部外画排的小表、几条备选释义。先用表查到字，再回到句子看哪一义说得通。古注中指音、释义、换字的线索也照此换例实践。[查字与读注](curriculum/DICTIONARY.md)

## 怎样知道自己能独立读了

十二篇独立自读在课程路径之外。短章可以从《追兵来时》入手，笔记可以试《古镜为何微凸》，整篇游记可以读姚鼐《游灵岩记》。先通读，遇到紧要的生词才打开词注或辞书。能复述之后再展开自校，用原文印证自己的解释。每篇都附有可定位的古籍底本。[自读文选](../content/v1/readings/)

两篇前后阅读自测另外留出，从未见的文字检验能否辨明事实与猜想、人物与动作，以及支持判断的证据。自读、练习得分和复习日程各有用途。是否已经能通读陌生作品，还要看读者实际怎样解释它。[试读与反馈](PILOT.md)
