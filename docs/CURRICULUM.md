# 从一段小事读到整篇古文

这条路径面向能读白话、想自己读通古文的成年人。五个等级各有四个单元，每单元三课及一次独立检查。每课八题，每次检查六题，共 60 节课、20 次检查和 600 道题。整条路可自由选学。下表的“能做什么”也是学习者挑选起点的依据。

| 从哪里开始 | 学完这一段，试着做件什么事 | 备课记录 |
| --- | --- | --- |
| L1 读懂单句 | 给一个没读过这则小事的人讲清楚，谁先做了什么，结果如何。读到相同的字，能在另一句话里重选合适的意思。 | [单句与短章](curriculum/L1.md) |
| L2 连句成段 | 把前后两句连成一段白话。人做了什么、让谁怎样、在何处发生，即使原文语序变化，也能说清。 | [词义和句式](curriculum/L2.md) |
| L3 读完一则故事 | 看清说话的人何时换了，插在中间的往事发生在哪一天，以及谁只是猜测。合上书，再连贯地讲一遍。 | [叙事与复句](curriculum/L3.md) |
| L4 研读散文与论说 | 分清作者、人物和评论者的口吻。从文中取出一句，说明少了这一层，论证会失去哪一步。 | [文体与论证](curriculum/L4.md) |
| L5 借辞书独立研读 | 一篇文章先读通大意。选出真妨碍理解的生字、生义或典章，查过再回读，并能交代哪处证据决定了自己的读法。 | [辞书、古注与自读](curriculum/L5.md) |

## 从同一篇文章里学几件事

词义和句法跟随阅读安排。第一课先随守桥的驿卒听水声、报信，再去读王戎和伙伴摘李子的片段。同是“走”，场景从报急换成孩子争先，读者要自己从动作的目的判断快慢。同一个故事里还可以问谁没动、什么是当场见到的、什么是人物猜出来的。隔一段时间复习时，应用按具体义项另选语境。

进入论说和史传后，读者会遇到更长的引语、旁人的看法和相互抵触的判断。词义之外，虚词、句法、篇章、阅读方法和文化背景都在课文中有着落。使用辞书的一道题可以同时练字音、词义和人物关系。文化背景跟着官职、称谓、地理等确实影响文意的地方讲。

课内 274 段文字中，有 115 段注明底本的古籍材料，其余是教学自编。全书另编 567 条随文词注，按字面合计 464 个不同字词，其中包括复词和固定说法。遇到一个似懂非懂的词时，可以在答后展开解析查看随文词注，也可以在知识库切到「随文词义」，用字词或释义找到它出现的原句，再回到那一课或单元检查。一个字在不同文章里的读法可以并列。复习卡仍记录独立作答的情况。

## 怎样知道自己能独立读了

十二篇独立自读在课程路径之外。短章可以从《追兵来时》入手，笔记可以试《古镜为何微凸》，整篇游记可以读姚鼐《游灵岩记》。先通读，遇到紧要的生词才打开词注或辞书。能复述之后再展开自校，用原文印证自己的解释。每篇都附有可定位的古籍底本。[自读文选](../content/v1/readings/)

两篇前后阅读自测另外留出，从未见的文字检验能否辨明事实与猜想、人物与动作，以及支持判断的证据。自读、练习得分和复习日程各有用途。是否已经能通读陌生作品，还要看读者实际怎样解释它。[试读与反馈](PILOT.md)
