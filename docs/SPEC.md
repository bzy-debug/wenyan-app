# 文言拾阶 · 产品规格
面向熟悉现代汉语、希望独立阅读古文的成年人。课程以读懂陌生文本为目标；不用背标准译文。每课约 5–8 分钟，包含用法讲解、带语境的例句和即时反馈。允许无限重试，不设生命值、付费墙和排行榜。

## 能力路径
| 等级 | 学习目标 |
| --- | --- |
| L1 | 读懂单句，辨认古今异义、常见虚词与基本句法 |
| L2 | 读懂段落，处理多义、特殊句式和词类活用 |
| L3 | 读懂短篇，恢复跨句指代、省略和叙事顺序 |
| L4 | 研读复杂散文与论说，结合历史语境分析修辞和论证 |
| L5 | 借助辞书与注释，自主研读古籍 |

知识领域分为实词、虚词、句法、篇章、阅读技能和文化背景。Skill 细化到特定意义或用法，如“之·宾语代词”和“之·结构助词”分别建模。

## L1 课程表
| 单元 | 三节课（依次） |
| --- | --- |
| U1 古今词义 | 常见动词：走、去、闻；一词多义与古今义对照；根据上下文判断词义 |
| U2 虚词入门 | 之的常见用法；其的常见用法；而的常见用法 |
| U3 句子结构 | 谓语与动作对象；主语省略与指代恢复；否定与疑问 |
| U4 短文阅读 | 人物与事件顺序；因果与转折；综合短文阅读 |

12 课各 8 道计分题，每单元另设 6 道检查题，共 120 题。M1 只开放首课，所有教学内容均为待审核草稿。路径显示已规划课程，规划项不能作答。

## 学习与判定
单选可用于词义、虚词、填空和理解；选段用于定位成分和证据；排序用于事件或语序。今后增加断句、开放式翻译和概括。提交后给出正确答案、错因和原文依据。普通课至少 6/8 题首次无关键提示答对，同时覆盖所有主要知识点，方有下一课解锁资格。单元检查门槛为 4/6。看关键提示后该题不计无提示首答。重试不能改写本轮首答，新开一轮单独统计。

## 复习与激励
知识卡绑定一个明确义项和多种语境。首次学习次日复习；到期无提示首答正确按 1、3、7、14、30、60 天进阶，否则回到 1 天。同日不能多次升级。独立调度器可替换为 FSRS。课程完成与长期熟练度分别记录。经验值与连续学习天数只用于鼓励坚持。

## 交付边界
- M0：固定 Node LTS 与 npm 锁文件，建立数据契约、校验、测试和 CI。
- M1：首页、课程路径、讲解、三种交互、反馈、会话内首答及结算。本阶段刷新会清除会话。
- M2：Dexie / IndexedDB、刷新恢复、持久化解锁和进度备份。
- M3：知识卡调度、错题纠正、复习页与知识库。
- M4：经验值、连续学习、设置、PWA、离线与移动端打磨。
- M5：完成全部 L1 正课、检查及内容审核。
- M6：实际试用，通过陌生文本阅读表现评估学习迁移。

移动优先 Web App，使用 React、TypeScript、Vite、React Router、Zod；Vitest、Testing Library 和 Playwright 用于验证。进度最终保存在浏览器本地，无需账号、服务器或 LLM API。
