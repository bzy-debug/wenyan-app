# 文言拾阶 · 产品规格
面向熟悉现代汉语、希望独立阅读古文的成年人。课程以读懂陌生文本为目标；不用背标准译文。每课约 5–8 分钟，包含用法讲解、带语境的例句和即时反馈。允许无限重试，不设生命值、付费墙和排行榜。

## 能力路径
| 等级 | 学习目标 |
| --- | --- |
| L1 | 读懂单句，辨认古今异义、常见虚词与基本句法 |
| L2 | 读懂段落，处理多义、特殊句式和词类活用 |
| L3 | 读懂短篇，恢复跨句指代、省略和叙事顺序 |
| L4 | 研读复杂散文与论说，结合历史语境分析修辞和论证 |
| L5 | 借助辞书与注释，自主研读古籍 |

知识领域分为实词、虚词、句法、篇章、阅读技能和文化背景。Skill 细化到特定意义或用法，如“之·宾语代词”和“之·结构助词”分别建模。

## 单句入门课程表
| 单元 | 三节课（依次） |
| --- | --- |
| U1 古今词义 | 常见动词：走、去、闻；一词多义与古今义对照；根据上下文判断词义 |
| U2 虚词入门 | 之的常见用法；其的常见用法；而的常见用法 |
| U3 句子结构 | 谓语与动作对象；主语省略与指代恢复；否定与疑问 |
| U4 短文阅读 | 人物与事件顺序；因果与转折；综合短文阅读 |

L1 的 12 课各 8 道练习，每单元另设 6 道检查题，合计 120 题。全书五级合计 114 节课、38 次单元检查及 8 篇独立自读文本。各级教学目的、教材依据和自读方式见[课程范围](CURRICULUM.md)。读者可按兴趣选任意课或检查，课程表给出建议顺序。在线版本为待人工审核的草稿试用版。

## 课程与练习

点进课文直接进入练习。需要示范时可主动打开本课讲解，读完回到原题。普通课允许逐题点「不知道」查看帮助并继续。单元检查是自由选择的独立练习。两类练习做完即记为完成，途中离开可在回来时接着做。其他课程始终可以进入。

单选用于词义、虚词、填空和理解。找原文证据要求读者从完整语境中辨认成分或支持判断的字词，可保留正常标点。排序用于事件或语序。试读另设断句、译意或概括。断句只给出待断的连续文字，提交后才显示参考停顿和依据。合理异读可在自评中讨论。

答对后以简短确认和继续操作为主。答错时显示正确答案，用一句具体的线索回应所选误读。原文详解及译意供主动展开。求助后可直接继续，也可重试。重复作答保留第一次作答留下的复习依据。

答后展开详解的交互参考多邻国的 Explain My Answer。项目的解析由课稿作者编写，可以随课包离线使用。[多邻国的功能说明](https://blog.duolingo.com/explain-my-answer-now-free/)

## 复习与激励
知识卡绑定一个明确义项和多个不同语境。首次接触后次日复习，间隔阶梯为 1、3、7、14、30、60 天。到期后独立首答正确可延长间隔，答错或选择「不知道」则安排次日再见。同日重练不会反复延长间隔。调度器使用本地日历日期，可替换为 FSRS。首答仅用于复习安排。经验按完成的练习类型固定发放，完成记录与连续学习天数按参与计算。

## 交付边界
- M0：固定 Node LTS 与 npm 锁文件，建立数据契约、校验、测试和 CI。
- M1：首页、课程路径、讲解、三种交互、反馈、会话内首答及结算。
- M2：Dexie / IndexedDB、刷新恢复、跨课程续学和进度备份。
- M3：知识卡调度、错题纠正、复习页与知识库。
- M4：经验值、连续学习、设置、PWA、离线与移动端打磨。
- M5：完成 L1–L5 的正式课程编排、各级练习和独立阅读材料，修订后组织人工审校。
- M6：实际试用，通过陌生文本阅读表现评估学习迁移。

移动优先 Web App，使用 Vue 3、TypeScript、Vite、Vue Router、Zod；Vitest、Testing Library 和 Playwright 用于验证。Dexie 将学习进度保存在浏览器本地，无需账号、服务器或 LLM API。

## 课程和界面的边界

课程清单声明级别、单元顺序与规模。每课的 Markdown 正文负责讲解，知识点、引文、题目、提示和错因通过中文扩展语法表达。构建端将文档编译为经校验的数据对象，Vue 组件接收这些对象渲染；同一套渲染器也用于作者校稿。领域层处理作答、完成记录与复习调度。课程生产流程见 [作者手册](AUTHORING.md)。

## 学习体验

首页优先让学习者继续手头的一课，也可进入目录自选。目录显示学习进度、已完成内容和建议顺序。每屏聚焦一个阅读判断，题内文案只说明当前要做的事。移动端保留容易触达的主要操作。正文使用现代无衬线字体，状态同时使用文字、图形与颜色表达。
