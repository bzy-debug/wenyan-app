# 高频字词的语境训练

这组课程包含 8 个单元、24 节课与 8 次单元检查。91 个不同字头分为 96 个具体义项，共 240 道计分练习。每张知识卡有两个不同的正课语境，单元检查另用短段落。L2 集中在行旅、对话、时间、数量和人情往来，L3 进入任官、史事与人物评价。

## 选词依据

王力主编《古代汉语》校订重排本（中华书局，第一册 ISBN 9787101132434）将常用词同文选、通论合编。这里采用遇词先读句、再以新材料检验义项的安排。宋绍年《古代汉语》第二单元关于古今义和引申义的编排用于设计干扰项，如“去除”与“授官”、“经过”与“拜访”。选词时另查先秦典籍中的字形出现情况，再按实际阅读任务补入任官、借贷等专题词。下列是本课程自己的选词和义项划分。王力书目提供教学编排的参照，未逐条据其常用词目录建立对应。[王力书目与简介](https://www.sanmin.com.tw/product/index/006885945) · [宋绍年书目与目录](https://www.sanmin.com.tw/product/index/003159521)

下表同时给出三个独立文本的字频供复核。取 Kanseki Repository 固定版本中《论语》20 篇、《孟子》14 卷、《韩非子》20 卷，排除卷 000、README、以 #、* 或全角空格开头的元数据和标目行。逐卷合并正文行后，除去页码标签、实体编码和半角圆括号中的注文，只取 U+3400–U+9FFF 汉字。每个字用 OpenCC t2s 简化后计次。同一字的异读、异义、人名或仍夹在正文里的书名可能都计入；例如“余”的次数含自称，“兵”的次数合计器物和军队两义。两本经书与一部子书的字频仅作取样，通行简体合并异字也会影响结果。

## 内容复核

在校对设备上，任选一张卡，先比对要诀和示范例句的具体释读，再连续试做两个不同语境。多义字可对照同字的不同卡，例如 U26 的兵器／军队、U27 的道路／述说。人工审稿还须复核古籍语境、断取边界和现代译解，并留意同义近义的干扰项能否在本句得到排除。以上内容状态均为草稿。
