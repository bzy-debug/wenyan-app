# L2 的四组常用词课

四个单元各设三节课和一次单元检查。45 个字头拆为 48 个可单独复习的义项，每卡都有示范例、两道不同语境的正课题。四次检查另写了十二段材料，每段两题。下表把每个义项追到具体题目，方便核实某种读法究竟在哪儿练过。

## 怎样取词

王力主编《古代汉语》的“常用词”逐条区分本义、引申、异读和实际用例。选词时直接核读了表中标号的条目。例如第 5 条把“请”后谁实施动作作为分义依据，第 62 条分列道歉、辞谢、告知、感谢和凋谢。这组课把其中三种容易混淆的回应分别教作赔礼、婉辞与致谢；“告知”和“凋谢”没有列作这四单元的主卡。第 193 条的两个用法则分散练习：U05 已教“适某处”，U21 用“适游赵”教巧合。教材并未给这些义项分别统计出现频率，此处按读段落时辨错后是否改变事件、人物或时间来取舍。[王力《古代汉语》](../../references/王力-古代汉语.epub) · [U05 的行旅课](../../content/v1/course/u05/02.md)

杨振中《文言文启蒙读本》补足连贯小段中的用法。第 280 篇的“过”字专讲解释了范式约定上门拜访的那句话，不能只读成经过；第 36、78 篇分别把“谢”放回失礼和认错的情境。第 282 篇以改字的先后讲“旋”，第 338 篇在庄周和监河侯的话里使借入、借出的双方先后开口。题目与解释按这里的学习任务另写；杨书中的改写与现代注释不当作所引古籍的底本。[杨振中《文言文启蒙读本》](../../references/杨振中-文言文启蒙读本.epub)

表中“王”后的数字为 EPUB“常用词”各条的连续编号，括号内是该词条的分项。“杨”后为读本篇号；有的篇目专讲该字，有的提供句中实例。条目缺少课程需要的特定义项时，表内另指篇目或辞典。王力第132条字头作“卹”，本课写“恤”；该条第（二）项释救济。引导、优待与救济义另核对《重编国语辞典修订本》资料。“贷”在不同角度可以表示借入或贷出，判题时一并看出粮、用粮、还粮的人。[引](https://www.moedict.tw/引) · [厚](https://www.moedict.tw/厚) · [恤](https://www.moedict.tw/恤)

## 逐卡核对

技能号在表中省去共同前缀 `skill.vocab.`，对应复习卡号加前缀 `card.skill.vocab.`。正课题号与检查题号均省去 `q.vocab.`。同一行的两道正课题分属两段原文，可在课稿中查到例句、首答干扰项和解析。检查栏的“—”表示本单元六题没有单独考这项；正课两题仍会计分并进入复习。
