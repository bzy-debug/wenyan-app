# 杨振中本的 340 篇练习

修订本的篇号比电子书页码稳定。这份索引逐篇读篇后的“思考与练习”，登记题目要求读者做的事，并列出各篇“文言知识”栏挑出来讲的字词和句法。同一篇可有几项。一篇中出现几个“之”，可能只问其中一个，也可能要求逐一解释。请循篇号核对具体语境。[教材版本](../TEACHING_REFERENCES.md) · [修订本原目录](../../references/杨振中-文言文启蒙读本.epub)

| 读法 | 登记范围 |
| --- | --- |
| 词义、音形 | 释词、辨同字在几处的意思，或根据字音字形分辨词。 |
| 句法、译句 | 指认成分、用法或补回省略，或用现代汉语讲出一句话。只要求翻译的题记“译句”。 |
| 篇意、取证 | 讲清人物做法、事件因果、全文意思或提出评价。明确要求回到原文摘词句的，另记“取证”。 |
| 名物、查书 | 解释与时代有关的称谓、典故、作品、制度等；题目明确要求查辞典的，另记“查书”。 |
| 延伸 | 联系现代成语、补名句、记作者作品或举课文外的例子等。有些题既问文化常识又要求背记，故可并列。 |

“篇后练习”只按题面登记。旁列的“知识栏话题”另据原书逐篇核对。337 篇有“文言知识”栏，第 73、250、316 篇未设此栏，以空线表示。例如第 197 篇知识栏讲“值”，篇后的练习另问“恒”“辄”等及两句今译。逐篇核对，266 篇的题面有“翻译：”，另有第 171 篇要求补回“以”的宾语再翻译，第 273 篇要求把“以告”补完整再译。共 268 篇明确要求今译，均记“译句”。第 88、158、195 篇原电子书用图片或拆字表示缺字，索引分别转写为“勣、蝜、鷧”。

课程如何承接这些读法，见[双教材覆盖核对](COVERAGE.md)。这里的篇号只索引教材，不能作为本站计分练习的编号。
