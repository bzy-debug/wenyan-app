# 文言文阅读主线与教材依据

## 学完以后，拿什么来检验

给读者一篇没上过课的史传、一段诸子对话或一篇唐宋以后的散文，允许用辞书查生字、生义和典故。读完以后，他应当能用自己的话说清谁对谁做了什么、事情何以走到这一步、作者据此说了什么，并指出原文依据。遇到两种讲得通的读法，能说明分歧落在哪个字或哪个句界。诗词也读到能辨基本句意、意象、对举和用典。专门的音韵学、格律学、校勘学可以在此基础上继续学。

下表划定主线的教学范围。王力本提供词条、通论和文选，宋绍年本用例句和单元练习细分语言现象，杨振中本示范从一篇短文同时追问字词、句意与人物的用心。具体读法在各领域的表中可逐行核对。课程按阅读难度编排，同一领域会在多个阶段出现。[教材版本与实读例](../TEACHING_REFERENCES.md) · [实际学习路径](../CURRICULUM.md)

## 一、实词与词汇

[逐项查教材、讲解、独立题与异篇题](evidence/实词.md)

| 应教到的颗粒 | 学生能做什么 |
| --- | --- |
| 单音词、复音词与词界 | 能区别一个词和两个相邻的词。如“地方百里”，能读出土地纵横的范围。遇到联绵词、专名或凝固的说法，也知道哪些字要合查。 |
| 古今词义的相沿、扩大、缩小和转移，词义轻重与褒贬的差异 | “再”要辨第二次、两次与后来再做；“稍”要辨逐渐与稍微。说出采用今义会把哪件事读错。 |
| 一词多义、本义与引申、近义词辨析 | 熟悉一个义项后，在新搭配里重新判断。如“谢”要会分道歉、推辞、致谢；同形的名字、地名另行辨认。选义要看句子允许什么，字形和词源可提供线索。 |
| 高频义项的范围 | 以王本十四组、1086 个编号词目作核对底册。逐义决定哪些应熟读，哪些先能借注读通。优先行动与方向、授受与取舍、言语与认知、时间与数量，以及仕宦、礼法、行旅、战争等反复见于史传和散文的词。例如“遗”写遗失和读 wèi 写赠送，须分别读出谁失去什么、谁把东西给谁。 |
| 数量、次序、时长与约数 | 数词如何计物、计动作，数量放在名词前后，分数、倍数和约数各怎么读。“十一”在征收语境可指十分之一；“一负再胜”里要数清败几回、胜几回。 |

教材定位：王本常用词（二）第 109 条、通论（二）至（四）；宋本印刷页 52–72、142–144；杨本第 56、275、286 篇。核对常用词时可利用仓库的《常用词对照》，它分别记录专卡、词注和正文同形。

## 二、虚词与固定说法

[逐项查教材、讲解、独立题与异篇题](evidence/虚词.md)

| 应教到的颗粒 | 宜放在一起比较的读法 |
| --- | --- |
| 人称、指示、疑问、无定代词 | 吾、我、尔、汝等随说话人换指；“其一”从哪个群体中数；“或”是有人还是几种可能；“莫”指无人还是表示禁止。“相”在一处可说互相，在另一处可偏指一方。 |
| 一个字的多种工作 | “之”代人或事、连接修饰语与名词、用在主谓之间使整段充当一个成分、标出提前的宾语；另辨实词“之”表示前往。“其”可领属、指示，也可传达揣测或劝告。“焉”有时兼有介词和代词的作用，有时帮助收束语气。 |
| 介词与连词 | “于”分处所、从哪里来、向谁、跟谁比以及被动句中的施事；“以”分工具、凭借、缘由以及连接目的等用法；“为”分替谁、为了什么及被动等用法。“而、则、乃、故、若、虽、苟”等放回两分句，读清并列、承接、转折、条件、假设、让步、因果。 |
| 副词、否定与语气 | 方、既、尝、未、乃如何安排时间；皆、独、唯、但等限定谁或什么；“未皆”与“皆未”；不、弗、未、非、无、毋、勿、莫各在否定什么或禁止什么。“也、矣、乎、哉、欤、耳、而已”在具体话里表示判断、变化、询问、感叹、限止。 |
| 常用结构须成组学 | “者／所”所指的人、物、事；“所从、所与、所以”中的来处、同伴、凭借或缘故；“之于／之乎”等合音在具体的“诸”字句里怎样读。“何以、何……之有、如……何、孰与、不亦……乎、无乃……乎、得无……乎”分别用来问什么、作何比较、表达怎样的语气。 |

教材定位：宋本印刷页 191–205、267–293、347–365；王本通论（九）、（十）、（十二）至（十四）；杨本第 84 篇同题比两种“于”，第 180 篇讲“相委”，第 286 篇练五处“之”，第 326、337 篇知识栏分别讲比较和揣问。

## 三、句法

[逐项查教材、讲解、独立题与异篇题](evidence/句法.md)

| 应教到的颗粒 | 阅读时实际要作的判断 |
| --- | --- |
| 句子骨架 | 找主语、谓语、宾语以及时间、处所、对象。名词或形容词也能充当谓语；遇到授受句分清所给的东西与接受者；连续几个动词时，分清是一人连做，还是前一动作的对象又去做后一件事。 |
| 判断、叙述、否定、疑问 | 读出有无“者、也”的名词判断；辨“是”指上文还是作判断；区分“非”否定判断与“不、未”否定动作；分真问、反问、选择问和婉问，以及问句在对话中起什么作用。 |
| 主动与被动 | 辨动词的施事、受事，有标志的“见……”“……于……”“见……于……”“为……所……”及依语境判断的无标志被动。“见”还可能是看见或动作偏及说话人，要从人物和搭配分辨。 |
| 词类活用 | 名词作动词、名词作状语，形容词或动词等的活用；使动看谁使谁发生变化，意动看谁怎样评价谁。遇到为某人做、为某事而动等读法，要能交代动作和对象的关系。 |
| 宾语前置 | 分疑问代词作动词或介词的宾语、否定句中的代词宾语、“唯……是／之……”等强调格式。比较“谁问我”与“我问谁”，能把答案放回原问句。 |
| 谓语后面的介词短语 | 辨地点、比较、对象、工具等。“画四龙于壁”中“四龙”回答画什么，“于壁”回答画在哪里。可认识“状语后置”这一常用教学名称，同时了解这种位置在古文中本来就很常见。 |
| 名词后的修饰语、谓语提前、数量位置 | 读“马之千里者”，能圈出是哪一类马；读“贤哉，回也”，能指出受赞的是谁。另教“马三匹”这样的数量次序。读韩愈“口衔山石细，心望海波平”，上句读出细小的山石，下句读出盼望海波平静。 |
| 省略与嵌套 | 补出省掉的主语、谓语、宾语及介词所带的对象，分别从上文、下文、对话情境找依据。动词后若接一整件事，或“者／所”结构还带有别的成分，能指出这一层到哪里结束。 |

教材定位：王本通论（七）至（十三）与（三十）；宋本印刷页 103–107、130–149、182–191、365；杨本第 5、39、132、236 篇。不同文体、时代和学者对部分句子有不同分析。能据上下文说清关系，比给有争议的例句指定一个术语更重要。

## 四、篇章与文体

[逐项查教材、讲解、独立题与异篇题](evidence/篇章.md)

- **叙事与对话。** 分清叙述人、发话人、听话人和引语中的第三人。随对话换人恢复主语，追踪同一个人物换了哪些称呼、同一件物品几次过手。复原先后、插叙、同时与结果。区分确已发生、人物打算、人物误以为发生。
- **论证与说服。** 分主张、理由、例子、类比、反例和隐含前提。问谁在劝谁，设问想让对方承认哪一步，结论能推到哪里。练习从原文支持或修正自己的推论。杨本第 228 篇问齐王为何转移话题；第 333 篇问渡河为何失败，都需要越过逐句释词。
- **文体和修辞。** 史传分开人物自述、事件记载与史家评论；表奏读出所陈、所请与分寸；书信辨称谓及言外之意；记、序、游记要跟住地点、观察次序、叙事转议论之处。诗、词、骈文和赋读基本句意，辨重章、对偶、互文、比兴、借代、用典、铺陈；读对句时检验两句的语法和意思各自怎样成立。

教材定位：王本十四单元文选、通论（二十三）至（三十二）；宋本寓言、经传、史传、论说、奏议等文选；杨本第 19、228、293、333、336 篇的篇后练习。更换文体和时代，才能检验一种读法能否带到另一篇文章。

## 五、独立研读的技能

[逐项查教材、讲解、独立题与异篇题](evidence/研读.md)

- **认字和查词。** 会用部首、读音和复词条检索。比较今字与古字、繁简、异体、通假；借字的认定须有辞书、古注或可核对的语料支持。形声偏旁提供查找方向；有异读、多音多义时，再看所读义项和句中位置。比较辞书里两个候选解释和它们的书证，把释义放回整句。
- **断句和复核。** 先认发话人、动词管到哪里、上下两句如何相对，再借语气词核验。给读者无标点的一段；如有两种切法，说出各自会让谁做哪件事。已有标点的材料也要能发现一处句读差别会怎样改变意思。
- **使用古注。** 区分原文、注、疏、校记和现代译文。认“谓”“谓之”的释义方向，“如字”的读音提示，“读若／读如”“读为／读曰”的通常用途；遇到例外结合注家实际说明。认识反切、异文和典故提示，能找到所需信息。
- **读完一篇。** 对陌生文章先作通读，标出真正阻断理解的字句，查证后能改正初读，简述事件或论点并引出一处支持它的原文。可用口头复述、标出证据、比较两种解释等方式观察；学生自己译句如何在界面呈现，另行讨论。

教材定位：王本通论（一）、（五）、（六）、（十六）至（十八）、（二十四）；宋本印刷页 17–29、90–103、398–415。王本（一）以“社稷”为例，祭祀和保全这两种语境需要选不同义项；（十七）用《氓》的“泮读为畔”示范怎样借郑笺读正文。

## 六、读文所需的文化背景

[逐项查教材、讲解、独立题与异篇题](evidence/文化.md)

- **人和制度。** 姓、名、字、号、谥与别称；亲属、辈分、自称、对称、谦敬；君臣、宾主、师友说话的身份。分清察举、征辟、科举等不同历史背景，识荐举、授官、迁调、贬谪、罢免。读《陈情表》能按先后分清地方荐举、朝廷授职和李密的请求。
- **时地和度量。** 年号、干支、朔望、旬和更，辨事件在何时、相隔多久；辨古今地名、山水阴阳、都城与边邑、行政地域；读懂常用的长度、距离、容量和比例。精确换算还要核对时代。
- **生活、礼制和典故。** 按文章学朝见、席位、避席、丧服等礼俗，以及宗庙社稷、车马、饮食、器物、赋税、封邑、交通军旅。解决具体问题，例如一个人为何离席、谁能奉诏、谁给谁缴纳什么。生僻名物能找到可靠注释，并说明它对这一段有什么影响。

教材定位：王本通论（十九）至（二十二）及《陈情表》等文选；杨本第 5、38、180、293、337 篇。常见而会反复改变理解的关系进主线，繁复的官制沿革、历谱、礼器制度和典故出处随文查考。

## 六个阶段怎样衔接

先在短句中认出动作与对象，再集中辨词，继而处理语序、省略和分句。句意读稳后，转入史传叙事、诗文论说以及凭辞书和古注自主研读。每一段仍会回读先前的材料所教过的义项，后面的文章会换。读者始终可以直接进入自己感兴趣的课。[各阶段、单元与检验方式](../CURRICULUM.md) · [课程清单](../../content/v1/course/course.md)

上古音系重建、韵部考据、全套平仄和词谱曲谱、六书逐字分类、历代注家谱系等可以开专题。主线上遇到押韵、借字、诗句语序或古注切实影响句意时，就在原句里教到读得通的深度。

## 怎样核对这份范围

以你在学习时可能碰到的定语后置为例，宋本第 365 页用“马之千里者”设问。课程请读者在马群里挑出韩愈所说的那一类，然后才读它能吃多少粮。到单元检查，园里收了一批瓜子，读者得按“子之饱满者，别封以待春”分出挑选的条件与挑好后的处置。两题的正确选项写的东西完全不同，读通它们却需要同一个判断。[教材印刷页 365](../../references/宋绍年-古代汉语.pdf#page=375) · [讲解与初测](../../content/v1/course/u38/01.md?plain=1#L6) · [换篇检查](../../content/v1/course/u38/check.md?plain=1#L10)

以“于”为例。能在“画四龙于壁”中找出作画地点，给处所用法一条证据；能在另一段分辨比较对象，再给比较用法一条。要说“于”还能引出被动句的施事，就须另找一道必须分清谁做、谁受的题。这三条证据各有用途。

每行记录一个阅读判断，列出教材位置、讲解课、独立题和较后另一篇材料中的题。后三项都可以点开看课稿原文。对生僻义和专门文化知识，记录“可凭辞书或注释读通”的任务即可。只见过词注、已独立练过、换篇再练过要分别记录。是否学会最终由读者在陌生材料中的表现来检验。

同为异篇练习，有的两端都取自古籍，有的会用教学例句安排对照，以便观察只换一个条件会有什么影响。复核时看每段的出处标记。另有十三篇独立自读和两篇阅读自测，供读者通读陌生材料，再与原文核对。[如何复查课稿](evidence/README.md) · [自读文选](../../content/v1/readings)
