# L3 条件、比较与问句

这两个单元接在 L3 的基础短篇阅读之后。学习者需要跨句核实一项前提是否实现，弄清一则判断是谁作出的，并从回应和行动辨认问话人的立场。六课各有八题，两次综合检查各有六题。所有内容均为待人工审核的教学草稿。

| 单元及课号 | 学习目标 | 换语境时需要辨认的证据 |
| --- | --- | --- |
| U31 · syntax.7 | 区分“若”“苟”提出的条件、约定的结果和已发生的事 | 守渡人许诺、水工核料、工匠治沟。清点、试掘会提供新事实，先前的承诺本身不能证明条件成立。 |
| U31 · syntax.8 | 分清承认事实与暂设有利情形，找出让步后仍成立的结论 | “虽曰未学”接过一种说法；“道虽远”确指已经走过的路；“纵明日又得十斛”只是假设明日增收。 |
| U31 · syntax.9 | 在一段话中分辨追加理由的“且”、转折的“然”、引出结果的“则”、揭示实情的“乃” | 把每一个关联字左边和右边的话分别复述一次。同字重现时，“日且暮”和“且山中多雾”不能照抄同一解释。 |
| U32 · syntax.10 | 区分“所以”指缘由或供使用的工具、手段；区分“以为”的主观判断和“以……为……”的实际任用 | 遇到“此所以……”先找“此”的指代，再看后文是否示范用途。把门板作筏、任老匠为工师都有后续行动，能与人物的暂时猜测区分。 |
| U32 · syntax.11 | 从“孰与”还原比较对象和标准；辨认“与其……孰若……”推荐的办法 | “哪口井甘”若无人尝过就没有结果；“与其各道所闻，孰若同观桥碑”有后续查碑行动，可以确认说话人推荐后者。 |
| U32 · syntax.12 | 分辨“无乃”“得无”的推测、委婉责问和求证；从“何……为”“如……何”的语境辨认反诘和真问 | 长者指出装饰井栏过早，有明确的规劝；医生问“得无苦而未饮乎”，答话却纠正了医生的猜测。水堰决口有人答出办法，路绝无舟的向导则叹息后留宿。 |

## 出处与复核

各课选用一段有底本定位的古籍文字。引文依汉籍电子文献所收《论语》CHANT 本与《孟子》TLS 本转简、节录，译文与题解由本项目编写。其余原文在课程文件中标作“教学例句”。人工审校时可逐行对照正文。

两次综合检查均使用新编、此前未教的语境。U31 检查重点是泉水是否已经找到、桥窄是否总不能过、粮仓能否立即开仓。U32 则让学习者分别解释核役簿、门板作筏、试车、查碑、迟信与排水六件事。答语涉及态度时，题目要求用后面的实际行动或对方提供的新消息加以验证。
