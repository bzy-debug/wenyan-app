# 王本常用词索引以哪一层为一项

跟随本仓库王力本 EPUB 的目录，可以找到十四组常用词。先按组、条号和词头找到条文，再找条内的“（一）”“（二）”。对应表记录 1086 个词条中的 2546 个位置。其中 277 条没有显式一级编号，以“全条”定位；另外 809 条合计有 2269 个可分别指出的小项或首段。用“顺序号＋一级小项”能唯一确定一行，再以顺序号向词头表查组别和原书条号。[小项索引](sense-sections.tsv) · [词头索引](headwords.tsv) · [教材版本](../../TEACHING_REFERENCES.md)

“全条”既可能很短，也可能同时讲到几个引申用法。一个小项内标“引申为”“又为”、更换读音、列出复词或分列 (1)、(2)，仍应连着该项读。例如 825【步】的（二）里面又有 (1)、(2)，索引只列到（二）。若课程只练了一个引申用法，教学对照应说明练到哪一层。[词汇对照与学习范围](../WORD_INDEX.md)
