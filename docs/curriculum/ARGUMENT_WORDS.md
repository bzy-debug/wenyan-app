# U37 · 听出一番话留了多少余地

L3 读短篇时，学生可能认出了每个字，却把人物的立场读反。乙说甲“爱帛”，是指责他舍不得拿出来；学生“爱其金”，说的是自己想买画又舍不得付钱。换到齐王谈牛羊，才要分辨谁认为他吝惜、谁否认。这三段分别用于认识义项、换篇重读和检查。全单元为待人工审核的课程草稿。[三课与单元检查](../../content/v1/course/u37/unit.md)

## 古籍和新材料的分工

- [第一课](../../content/v1/course/u37/01.md)引用《孟子·公孙丑上》《梁惠王上》《告子上》。齐人、民心、本性三个话题分别写当前判断、未实现的设想与原来已有的状态。验钟、旧井和问字的教学例另写，能从动作辨义。
- [第二课](../../content/v1/course/u37/02.md)引用《论语·阳货》《孟子·梁惠王上》《史记·老子韩非列传》。庄周借祭牛的结局作比，足以说明反问的方向。购画、制衣、护巢的三段另写。
- [第三课](../../content/v1/course/u37/03.md)引用《孟子·公孙丑上》《梁惠王上》《左传·宣公二年》《桓公二年》。士季所引的《诗》按《左传》当场引诗的底本核字。新写的补书、抄碑拓材料让学生看见本领的限度和“不尽”的具体意思。
- [单元检查](../../content/v1/course/u37/check.md)用两篇在常规课中未出现的材料。第一篇从《孟子·梁惠王上》取连续三段对话，保留孟子所说“以小易大”，足以让学生从百姓一方解释何以误会。第二篇是修水道图的教学短文，按老工的本领、脚病和图面取舍复原师徒怎样合作。各古籍引文均在课稿记录底本版本、固定提交与行号。
