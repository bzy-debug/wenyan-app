# 王力《古代汉语》常用词对照

教材第 62 条“谢”，课程到底考了哪几种意思？在对照表中，道歉、婉辞、致谢各有一张卡。《史记》鸿门相见的一段，以“谢项王”再考的是道歉；本题不能同时给其他两个义项多记一次。十四组的统计、每一条的课程证据、各次复现的原句可分别查阅。[分组汇总](word-index/summary.md) · [1086 条逐项对照](word-index/coverage.tsv) · [后续原句和题号](word-index/returns.tsv)

## 读表

每个编号占一行，空证据栏记作“—”。在“专卡ID及课内义项”找到知识点，即可按 ID 查其初学课、原文和题目。部分同形词分列多条，如第 165 条“仆”指人，第 923 条“仆”说向前倒。一本书收录多少编号、课内有多少具体义项、学习者本人掌握了什么，是三个不同的问题。

| 证据栏 | 怎样认定 |
| --- | --- |
| 有义项专卡 | 原书这个编号内能找到相应用法，编辑将相应小项与课程知识点配对。复习卡在初学课至少有两道题取自不同原文，目标字形在两段材料里都能核到。 |
| 有同形词注 | 尚未对上一张合格的专卡，至少有一段材料将该字本身单列为词注。可查词注例 ID 决定是否同义。“行李”的整词注不拆给“行”。 |
| 仅正文同形 | 在学习材料原文中找得到这个字，目前既无已对上的专卡，也无单列该字的词注。姓名、地名、别义、借写都可能造成命中。 |
| 未见字形 | 在这次检索所用的课程原文和可选自读正文中未命中。教材、课前导读、题干、译文、错因和试读测量卷不参与字形计数。 |

各栏计数相斥。少数课程确有专卡，但与王力编号所释的具体用法不同，另列待辨说明。如“过”有过失、拜访两张卡。过失义能对上王力第 261 条的第二项；该条另外讲经过、超出等用法，拜访义应查杨振中《范式守信》等材料。“领”作兼任官职，也不与第 378 条的统率混计。这样的课程卡仍出现在“待辨的课程卡”列。[待辨记录](word-index/unmatched.tsv) · [L2 逐卡取词依据](VOCABULARY.md) · [史传词的练习语境](HISTORY_WORDS.md)

“已核后续用例”要求另有一段新文，而且编写时已对读上下文，确认用的是同一个意思。课程先后按实际学习路径排列，单元检查位于本单元各课之后。自读篇可随时选读，不据此推定跨级。相同句子换标点或原样节引，不增加复现。一个词头重新出现也不足以认定同义，例如“子适卫”的“适”带目的地，“适闻舟人呼渡”的“适”说碰巧听见。

- **有再考题号**时，读者须在新材料上作答。带“互证/”的题另属一张阅读卡，题干仍直接要求辨这个义项。例如《颜氏家训》“求假”的题直接问“假”怎么讲，可以与 L2 的借用义互证。
- **无题号**表示新材料再次用到相同意思，只记阅读机会。如选读工之侨献琴，“抱以适市”仍是往某处去。表中收录的是已对读的证据，其他同义语境仍可增补。

这份课程编制用的对照仍是草稿，义项与书证待任课教师复核。个人答题是否正确、复习是否到期，须查应用里的学习记录。

## 词目从哪里来

随附的《王力-古代汉语.epub》在目录中列十四组“常用词”。抽取器循 EPUB 目录找到对应正文章节，读取每个带编号的【词头】，再核对各组条数和连续位置。首组 60 条，末组 82 条，共 1086 条。词头清单只摘条号和字头；分项清单按原书分段保存一级编号，另外记录没有明列编号的整条。所用 EPUB 的 SHA-256 为 0c7ce05f04da2a91859cb6dc91211b87636074c58a4f041866e77a9b27e67df1。

- 第 303 条【吏】在电子本中紧接上一条的最后一条例句，只认行首编号会漏掉它。第十一组【序】位于 784【赋】和 786【铭】之间，标题作 385。“底本号”照录 385，“顺序号”取 785。全表用组别和顺序定位。[源词头清单](word-index/headwords.tsv)
- 少数标题须结合本组提要、条内用例辨认。第 541 条题为【书】，提要写“字画”，释划分界限、绘画等义；对照时用“画”，保留原题供核。第 132 条题为【卹】并列“恤”，两形一起检索。其他未经核实的字形不会自动互换。[异体与校记](word-index/forms.tsv)
- 课内的“本”既考草木的根，也考一件事的根本。第 730 条第一义及其引申中，跟课内确切合得上的是后一项。同一字头能有不同对照结论。[义项对照](word-index/alignments.tsv)

## 重算与增补

在仓库根目录执行。正常校验只需 Node 项目依赖，不读教材文件，也无需联网。

~~~sh
npx tsx scripts/word-index/report.ts --check
npx tsx scripts/word-index/report.ts --lookup 谢
npx tsx scripts/word-index/report.ts --lookup 785
rg -n -F '{#q.return.2.2}' content/v1/course
~~~

内容编译器提供实际课序、题、知识卡、段落和自读篇。“段数”按材料 ID 计；同一段有多道题只计一个 ID。查一个词条时，命令会列出所有同形原文，供编者挑选需要进一步精读的段落。

新增专卡时，先定位原书小项，核对初学课两段题文，再将条号、知识点 ID、小项和课内义项加入 alignments.tsv。确认后课同义时，在 returns.tsv 保存一小段逐字原文，填该题 ID 或填“—”。若一题兼考另一张卡的义项，可在题号前加“互证/”，并核对题干、选项与解析。程序检查题与引文是否出自同一段、题目归属、跨课次序和文本重复；同义与否仍由审校人判断。改完再生成汇总和明细。

~~~sh
npx tsx scripts/word-index/report.ts --write
npx tsx scripts/word-index/report.ts --check
npx vitest run tests/unit/word-index.test.ts
~~~

持有对应 EPUB 的编辑还可运行以下命令，将十四组词头和各条的一级分项与教材核对。换版本时才加 --epub 文件路径 --write，并重新核查组数、错号、同形分列与既有义项映射。

~~~sh
python3 scripts/word-index/extract_headwords.py
~~~

## 决定要教到哪一步

先选实际要读的篇章，再用条号定位义项。影响人物所为、授受方向、事件先后或作者判断，且会在别篇反复遇到的用法，优先列为应熟读。已经精读原条并配对到课程主卡的义项，逐项列出初学题和回读题。遇到特定古字用法、地貌或名物，凭字条、古注或相同句型的书证就能读通本段的，可以先练查读。每个这样的决定都要落实到某个义项。一个编号可以同时有两种目标。

取舍按原书能稳定定位的单位登记。十四组 1086 条中，809 条有可辨的一级分段，共 2269 段；另 277 条没有标（一）（二），定位到整条。两者合计 2546 个位置。同一位置内还可能包含引申、读音说明或几种句法。表中“请允许我做”和“请对方做”各列一行，都指向第 5 条【请】全条。只有列明的句中义接受了相应教学，其余引申遇到时再查。电子本有三处须特别留意：333【举】两次写（二），保留重号；357【险】首段没号码、接着写（二）；813 题头作【网】，提要与例证指“纲”，仅录书中实际出现的（一）（三）。[一级定位清单](word-index/sense-sections.tsv) · [字形校记](word-index/forms.tsv)

全表可以直接按词头或顺序号筛选。[逐分项教学范围](word-index/study-scope.tsv)

在仓库根目录运行以下只读命令。第一条导出完整教学范围，同号、同一小项可列出几个不同的课内用法。第二条只看“归”。第三条列出课内原句，可用来查一个字是否另有语境。

~~~sh
npx tsx scripts/word-index/report.ts --scope > /tmp/wenyan-word-scope.tsv
npx tsx scripts/word-index/report.ts --scope 319
npx tsx scripts/word-index/report.ts --lookup 319
~~~

| 表里的记录 | 教师或编者怎样用 |
| --- | --- |
| 应熟读，有初学与另外一篇的题号 | 先做初学题，再在列出的另一篇作答。例如 390【遗】分别问 yí 的失物与 wèi 的赠物。学习者须从所送之物、受者或返身寻找的经过说明物品去向。 |
| 应熟读，只有课内题或后来碰见了同义句 | 这是已有部分证据。后课只把这个字写进原文或词注时，仍须另设要凭该义项才能做对的题。 |
| 查读已考 | 有核过的原句和题号。先遮住译意，用题内字条、古注或并列的书证挑出合适的意思，再指出哪几个字能排除另一义。问到借资料读通的能力，熟读情况另考。 |
| 随文查读 | 原文和词注可对照原书小项，本处没有专门的查读题。如《三人成虎》的“质于邯郸”需要读出到赵国做人质，“市有虎”的“市”指买卖之所；二者都能从随文词注查出。 |
| 遇到再查 | 这个原书小项目前不列作必须熟读的读法，也没有已核过的查读任务。初读时用语句中的动作、对象或地名缩小范围，选一项放回句中，再用下句验证。此处即使标有正文同形或词头另有专卡，也不算这个小项已有教学证据。 |
| 分项待核 | 词条的首段漏编号或后段重号。需要正式据此指派新练习时，先核对纸本或另一可靠版本；原有的分段痕迹仍可用于找回教材位置。 |

当前导出有 132 行应熟读、9 行查读已考、32 行随文查读、2375 行遇到再查、2 行分项待核。合计 2550 行，比 2546 个原书位置略多，因为一处能分成多项课程证据，一种读法也可能援引相邻两项。应熟读的 132 行目前都能查到初学和异篇题；同一字的其他用法照各自的行处理。作为随文查读登记的每一项，都可由表中的语境 ID 找到项目自撰词注。[随文查读用例](word-index/gloss-senses.tsv)

如查 319【归】，第二项的回家、回国与“归孔子豚”的赠送需要不同的证据。先圈出“孔子”和“豚”，对读《孟子》的“馈孔子蒸豚”，再决定阳货是回了家还是把东西送给别人；抄录时仍保留《论语》的“归”。查 63【责】第一项，可让读者自己辨“收責於薛”究竟是收债，还是向薛地的人追究责任。查 1075【畔】，在郑笺的“泮读为畔”之外，还要找“畔，涯也”，这才有把边际义带回“隰则有泮”的依据。具体题号与原句可在查读用例中逐项复核。[查读用例](word-index/lookup-senses.tsv) · [已经按义项核对的主卡](word-index/alignments.tsv)

王本之外也有应熟读的义项。比如 261【过】确能核到“过失”；“过漆工”的登门拜访义由杨本第280篇佐证，仍有专课和换篇题，可以从《实词》的四项对应找到。仅有同形又未入选的词，无须预先给它贴上冷僻标签。反过来，遇到生僻鸟名也无须强拆进王本的一条单字卡：选读《这只青鸟究竟叫什么》时，先据所见颜色质疑俗称，再用所引《说文》核对外形、颜色，用《韵集》解决读音。这是一份可以自行完成的查读任务。[实词逐项证据](evidence/实词.md) · [青鸟的原文和自校](../../content/v1/readings/09-bird.md)
