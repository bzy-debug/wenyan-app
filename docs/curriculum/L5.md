# L5 借辞书与注疏自主研读

结课时，请读者试着自己说清三件事：我怎样读这段话，哪几个字或哪条古注支持我的读法，还有什么仅凭这段文字无法决定。本级六个单元。U32、U33 的查检步骤、字形和古注对读详见[拿陌生字查书](DICTIONARY.md)。下列 U17–U20 的十二课合计 92 道单选、25 道找原文证据、3 道排序。每课有一条另行标识的教学例句、两段古籍材料、一个能够独立复习的具体知识点。检查另取十二段本单元正课未用的材料。三十六段古籍配有随文词注，本级共收八十四个不同的词头。

| --- | --- | --- |
| [1 翻到字头，还要往下找](../../content/v1/course/u17/01.md) | 王力《古代汉语》通论（一）从《康熙字典》的部首检索讲到《辞源》等书的单字、复词；通论（三）讲单音词、复音词及其关系。宋绍年《古代汉语》印刷页 17–27（PDF 27–37）比较工具书排检与释字体例，包括先音后义、词头与复词的编排。 | 给出“犹”和“犹豫”、“须”和“须臾”的候选条目。读《史记》两段，前者以“未能决”复核词义，后者以两次发话间的停顿复核时长。 |
| [2 原书的“归”，另一处为什么写“馈”？](../../content/v1/course/u17/02.md) | 王力通论（六）将古今字、异体字和简繁关系分开，通论（十六）讨论借音写词。文选《论语·阳货》的“归孔子豚”条逐字解释“归、豚、时、亡”；再读《孟子·滕文公下》所记阳货之礼。 | 对齐收礼人、礼物和赠礼动作，原样引用“归”，在旁说明为何读“馈”。第二个语境换成“蚤起”，检验“早”的意思能否接妻子起身跟随丈夫的叙事。 |
| [3 “衣帛”的“衣”，是衣裳还是穿衣？](../../content/v1/course/u17/03.md) | 杨振中《文言文启蒙读本》第 112 篇《秀才读别字》以近形、误读造成的书名笑话提醒逐字辨认；第 125 篇《卖瓜减字》另从“然之”能带什么成分辨用法。这里将字音与搭配放进同一题，不取两篇故事作古籍引文。 | 在“衣（yī）”“衣（yì）”两项间试读，用《论语》里穿不同衣服的两个人和《孟子》里的“衣帛／食肉”分别验音。 |
| [检查](../../content/v1/course/u17/check.md) | 迁移整词、借字、多音字三种查法。 | 查《史记》赋中人物如何“逡巡避席”；以听话者确定《论语》“女”所指；依“孟子见梁襄王，出，语人曰”的说话关系选读 yù。 |

## U18 古注究竟在解哪几个字

| 课次 | 教材里读了什么 | 读者实际要做的事 |
| --- | --- | --- |
| [4 古注里“谓”和“谓之”的方向](../../content/v1/course/u18/01.md) | 王力通论（十七）用《诗经·硕鼠》的经、毛传、郑笺等说明层次，又区分常用释词术语。宋绍年“古书的注解”印刷页 401、404–405（PDF 411、414–415）分别讲疏、辨集解各家、释词与疏通文意。 | 取《论语注疏》两条疏文，“终谓父母之丧”和“先人后己谓之让”。把“被解释的词”和“解释的情形”写在两栏，引用时保留是疏家所说。 |
| [5 翻到“音义”：两个反切字怎样用](../../content/v1/course/u18/02.md) | 王力通论（十八）讲读音提示、反切上下字、“如字”和别读。宋书印刷页 21（PDF 31）以《康熙字典》先列读音、再释义的体例示范如何看字条。 | 直接读“好，呼报反，下章好学同”和“近……又如字”。认目标字、上下字、适用范围，并保留原书并列的读法。此处不要求读者拿普通话生拼中古音。 |
| [6 没加标点，怎样认出一句话到哪里](../../content/v1/course/u18/03.md) | 王力通论（二十四）以《左传》等处句读讨论词组和动词所领对象。宋书“古书的标点”印刷页 411–416（PDF 421–426）先区分句读与标点，再以误断解释文意、语法和常见句式如何限制停顿，末附无标点练习。 | 将两段《论语》撤去现代标点，试读“见善如……见不善如……”与“不愤不启不悱不发”。只评价会误拆词组、误认对象的停法，不考能同时成立的逗号、分号之别。 |
| [检查](../../content/v1/course/u18/check.md) | 换到《为政》“众星共之”及《里仁》新句。 | 分读疏家称“北辰”的理由、音义所录“郑作拱”的写法与反切，再无标点读出“讷于言”与“敏于行”。 |

古注在各段的“出处”字段标明是疏还是音义。“郑作拱”是四库本《论语注疏》所录的一家写法，练习没有把它说成所有《论语》底本的文字。

## 底本与释读边界

- 引文取自 Kanseki Repository 的 CHANT《论语》、TLS《孟子》《史记》、文渊阁四库全书本《论语注疏》《柳河东集》、四部丛刊本《颜氏家训》《梦溪笔谈》。各段标明篇章、编撰者、固定提交和具体行号，供复核节取范围。褚少孙补述的西门豹故事在作者栏单列。三本现代教材用于课程设计；讲解、词注、今译、选项和错因均另写。
- 断句练习撤去整理标点。柳集两段略去夹在正文中的音注，出处有说明。四部丛刊本《梦溪笔谈》转录把“山崖之间”录作“山崔之间”；这里对勘另一转录取“崖”，与后文“石壁”相应。其余随通行简体排印，如“徧”作“遍”、“𥙷”作“补”。[《梦溪笔谈》卷二十四对勘本文字](https://zh.wikisource.org/w/index.php?oldid=7404681)
- 课程内容均为草稿。古注的解释注明是谁的意见。近古地理推断、名字来历、反切注音各按原书语境讨论，读者无需把古人所述当成现代科学结论。口头拟摘要和自行复核是读法建议，客观练习只评分原文能裁决的问题。
