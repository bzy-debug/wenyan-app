# L5 借辞书与注疏自主研读

读者先用字典提出一种可能的读法，再用语法、上下文、成书年代及注疏层次检验。课程以 12 节正课、4 次新篇检查组织 120 道题，其中单选 95 道、原文证据 22 道、排序 3 道。12 个具体知识点各有独立知识卡；每张卡从两个不同古籍语境各取两题。每课导读另设一条明确标记的教学例句。上课前可以先看例句；检查中使用本单元未练过的原文。

## 怎样使用教材与工具

- 斯坦福 Chinese Philosophical Texts 的 *How to Read Classical Chinese* 以一字多义、上下文中的语法关系、修辞结构三个层次示读，并用「方」说明查得多个释义后仍须选择。L5.1–3 将「记录候选义项、连同搭配试代、交代舍弃其他义项的依据」作为实际操作。L5.9 用重复与对举检验无标点片段。[开放课程正文](https://chinesetexts.stanford.edu/1-classical-chinese/)
- 王力主编《古代汉语》校订重排本第一、二册（中华书局）将文选、常用词和古汉语通论搭配。项目依据已核对的书目及目录安排由句内释词到整段研读的顺序；练习的具体解释回到辞书和古书文本。L5.4–6 在经、传、问答中识别时间和称谓；L5.10–12 把解决一个词的方法用于整段取证。[教材书目与查阅范围](../TEACHING_REFERENCES.md)
- 教育部《重编国语辞典修订本》（2021）按字头区分读音和义项。L5.1 查「好」「冠」，L5.2 查「女」「莫」，L5.3 查「簞」「豆」；用一组音义试读，再回看对举。「莫」的 mò 与 mù 分列，后者收日暮、时日晚之义。查询异体写形另用《异体字字典》，比较「峯／峰」。课内提供自行撰写的简释及需要时可打开的辞书入口。[好](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%A5%BD) · [冠](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E5%86%A0) · [莫](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E8%8E%AB) · [豆](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E8%B1%86) · [异体字字典](https://dict.variants.moe.edu.tw/)
- 实际检索时，可用简体课文对照繁体字头，例如「箪／簞」「辔／轡」「纩／纊」。文化、地理及器物词只释足以读通本句的意义。学习者可由同一字头继续核查其他用例。[朔](https://dict.revised.moe.edu.tw/dictView.jsp?ID=9141) · [拜](https://dict.revised.moe.edu.tw/dictView.jsp?ID=141) · [轡](https://dict.revised.moe.edu.tw/dictView.jsp?ID=669) · [諡](https://dict.revised.moe.edu.tw/dictView.jsp?ID=8799) · [篁](https://dict.revised.moe.edu.tw/dictView.jsp?ID=5247) · [纊](https://dict.revised.moe.edu.tw/dictView.jsp?ID=4709)

## 读本处理与版权

《论语》采用 CHANT 转录；《孟子》《春秋左传》《史记》采用 tls 转录。《论语注疏》《柳河东集》采用文渊阁四库全书本，《梦溪笔谈》《颜氏家训》采用四部丛刊本。均检索 Kanseki Repository 的固定提交，对照各课所列行段，去掉页码和电子行界，转成通行简体字并独立标点。常见字形转写包括「鼈／鳖」「蠒／茧」「徧／遍」「縁／缘」「晩／晚」。古籍正文、古注及其现代译解分别计权；今译、字词短释、标点、题解及教学例句由项目自撰。十二条教学设例均单独标出，所举架空的日子、校本、任命和人物不作古籍引文。

《论语注疏》引文以“注”“音义”及引号区分层次。L5.8 将“学而不思则罔”“思而不学则殆”两段被夹注分开的经文合读，省去两处注文，保留同章“罔本又作冈，殆音待，依义当作怠”的音义。U19 检查将“有朋自远方来”及包注与同章音义中的“有或作友，非”对读，省略处已标出。释“道”的音义针对本章前面的“道千乘之国”，与“使民以时”所附包注分别标明。柳集的“一云”沿用所据刻本的另读，未据此推断作者亲改。

U20 检查《梦溪笔谈》在印数与两板交替的叙述后明确以删节号跳到“昇死，其印为予群从所得”，分别考查作者怎样限制效率判断及字印去向。两处对应同一底本的第 173–176、184–185 行。史传、名物及历法的解释只覆盖所读篇段；干支日名没有被直接换算成公历日期。
