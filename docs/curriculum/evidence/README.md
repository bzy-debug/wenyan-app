# 怎样复核一条教材证据

六张表按实词、虚词、句法、篇章、研读、文化分开。每行选一个可以从答案判断的读法。先翻教材中列出的通论、例句或印刷页，再找课程里的讲解。最后读两道题：第一道必须属于讲解课，第二道在正式课序中更晚，使用另一段原文。单元检查排在本单元最后一课之后。

在 GitHub 上点击表里的课号或题号，就会跳到课稿中那一题或讲解的开头。新增行时只需写稳定 ID，改完课稿运行 `npm run evidence:links` 即可重建行号链接。

在仓库根目录运行下面的命令，就能找到“许子衣褐”那道题的课稿行号，再查哪张证据表用了它。

```sh
rg -n -F '{#q.cross.clothes}' content/v1/course
rg -n -w -F 'q.cross.clothes' docs/curriculum/evidence -g '*.md' -g '!README.md'
```

查讲解课也可用同样方法，把花括号内的 ID 换成课 ID。只知道卡 ID 时，可先按“考点”列出主考这张卡的题，再拿题 ID 查六张表。

```sh
rg -n -F '考点：s.l5.rolevoice' content/v1/course
npm run validate:coverage
```

校验会核对表格列、教材定位、引用、关卡开放状态和正式课序，并核实每张已开课的主修卡都在六表中有一道以它为主考点的独立题。编辑状态为草稿的课可以检查；编写中的课程占位不能提供证据。复现时允许同一道题考两项读法，例如既要分清谁给谁，又要认出给的东西。省去其中一步还能够排除全部干扰项时，编辑应换题或改题。

同一段原文换一个 ID、删标点、缩成短引或与另一段连续重合三十字，校验均会指出相关题号。若两段摘自同一篇的相邻问答，字面重合可能很少，编辑仍须检查其是否提供了新的情境。单元课稿里的原文、底本和题解才是判定依据，表格中的一串 ID 不能替代这一步。
