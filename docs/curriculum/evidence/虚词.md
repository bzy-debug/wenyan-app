# 虚词如何改变一句话的读法

“王”指王力主编《古代汉语》，数字为通论序号，常用词另注条号。“宋”指宋绍年《古代汉语》的印刷页（PDF页码加10）。“杨”指杨振中《文言文启蒙读本》的篇号。教学例句、译注和选项由项目撰写；古籍引文的独立底本与行号在原课相应段落。教材版本见[参考书目](../../TEACHING_REFERENCES.md)。

同一个字有时必须回到动词和前文才分得清。例如“于”在王本通论十三中把“在、从、向”的今译列入引进处所的大类；这里分开训练，是为了让人分别找出活动地点、所取来源和说话对象。有些后测同题要求解读两处，例如读钥匙一段的两“诸”。表中只列问题确实追问的读法。
