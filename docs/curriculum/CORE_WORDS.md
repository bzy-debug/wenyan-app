# 常用实词与句中辨义

U33–U38 补充了 72 个直接影响通读的义项。课程将多音、多义或容易照现代汉语误读的字放入可解释的句子。每个义项有单独的知识卡，至少在两个不同的计分语境中出现；单元检查再用新文本复用这些读法。另有[八个词义专题](VOCABULARY.md)从行旅、人事、任官、史事和评价等语境选词。

例如，读“危言危行”时，“言”“行”是发言和行事，再看与“言孙”的对举，可以理解此处的“危”形容正直。换到一座将塌的桥旁，同一个字就要联系人物担心的处境重读。知道一个字的常见古义，只是开始，能说明这个意思为什么适用于眼前这句话，才算读懂了这一处。

本表按课程顺序列出所练义项。课稿链接内可查看全部例句、出处、译意与错因。真实引文逐段注明底本，教学例句单独标识。
