# 从两部教材核对课程能教会哪些读法

想知道“会读到什么程度”，可以先看一个小例子。杨振中选《饿死狙公》，篇后要读者解释五处“之”。正课先分清捡到“它”和物主“的”东西，往后再读“之”后带目的地的句子。到了刘基的原文，读者还要回答小狙第二次发问究竟动摇了什么。前两步有具体义项和计分练习，最后一步让读者自己组织答案。这三处各能检验一件不同的事。[初读“之”](../../content/v1/course/u02/04.md) · [“之”动词用法](../../content/v1/course/u25/01.md) · [独立自读《山里的果子归谁》](../../content/v1/readings/06b-monkeys.md)

## 哪些结论还需要读者来验证

- **遇见、作答、隔篇迁移须分别记录。** 杨本第 1、262 篇的知识栏都讲“诸”。本站 U33 原文里有“諸”的随文注，说明这里可以读作“之于”；该课计分考的是“蚤／早”等字的关系。杨本第 326 篇的“孰与”，本站在相如问门客的段落确有题目要求找出比较结果，但这道题跟踪的是门客的意见。“诸”“孰与”各自的多义辨析和熟练度，仍缺直接证据。[U33 随文词注](../../content/v1/course/u33/02.md) · [q.l4.7.5](../../content/v1/course/u15/07.md) · [杨本索引](YANG_EXERCISES.md)
- **选对复述以后，再让读者自己讲一次。** 两篇自测一篇辨井水，一篇辨书信，能看谁把不同的动作误归给同一人，或把推测当作亲见。开放续读能留下读者自己的断法和句意。要比较前后学习效果，还需观察真实读者的作答、是否查注、哪些理解改过，以及两篇难度是否相近。单人的两次分数不足以说明课程造成了多少进步。[第一篇](../../content/v1/pilot/01-well.md) · [第二篇](../../content/v1/pilot/02-letter.md)
- **给够材料，也留下需要另找材料的题。** 课内的字表保留了学生亲手寻找的步骤；新注家、罕见异体、典故版本或完整历谱可能不在其中。训练能否移到一部真正陌生的书，可让读者任选一本有释义和例句的辞书，记下所查条目、采用的解释，以及原文中支持、限制这个解释的字。若是在做校点或研读多家异说，还须结合相应底本和学科审读。[U32 换检字表](../../content/v1/course/u32/check.md) · [U33 换注例](../../content/v1/course/u33/check.md)
