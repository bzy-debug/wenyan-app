# 从纪日读到任免：L3 的史传词语

U28–31 每单元三课，每课四个义项、八道练习。每卡在两段不同语境中作答，每单元检查另用六道新语境题抽查六卡。其他卡仍从两次课内作答进入复习。学生读史传时要能说出这件事是谁做的、在哪一天、到了哪一步。

## 教材与编写方法

所附王力《古代汉语》EPUB 无稳定纸页，按通论和小节定位。通论十九《古代文化常识（一）》“历法”（chapter64.html）以《左传》“五月辛丑”示范干支纪日，分别讨论君年、月内日名和时刻。通论二十《古代文化常识（二）》“地理、职官、科举”（chapter65.html）区别地方区划和官员职掌；科举节回溯察举，直接引李密的太守、刺史两句，说明荐举与入仕还要分开。二十一的姓名、二十二的车马和宫室、二十三的书说分别用来读人物开场、车辆计数及进言。

杨振中《文言文启蒙读本》以下用所附 EPUB 篇号，按标题可在目录定位。第307篇将会稽太守的地方政事与征为将作大匠相连，并专释“鄙”；第325篇用迁冀州刺史说明调任；第52篇分别解释“克城”与“城克”；第337篇对“坐盗”及因罪免职举例。另有的篇章只提供叙事场景或读法，表中标明了这一层关系。直接引文一律另核公版底本，未将读本的改写、译文或习题作古籍原文。

沿用旧版验证过的多语境题，并按新路径重新分组、命名和绑定卡片。察举、官名嵌入姓名、君年、干支、朔晦、历时与历年之别等另选史传或另拟新题。所有新写的情境都标作教学例句，全部课稿保留草稿。
