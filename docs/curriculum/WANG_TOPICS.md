# 王力本三十二篇通论怎样对到阅读课

本表按本地 EPUB 的通论序号查找。某行写“已练”时，指该行说出的具体动作。读了《诗经》、见过赋中的一句答话，都不能算作掌握一整章音韵或赋学。词义可另外按教材编号查到原文位置、出题依据和后课复现情况。[版本](../TEACHING_REFERENCES.md) · [十四组常用词](WORD_INDEX.md)

| 通论 | 从正文里辨出的阅读任务 | 课程证据和范围 |
| --- | --- | --- |
| 一 辞书 | 不知字音时按部首寻字；认得字，仍须在同一字下选整词、例句及相合的义项。 | U32 让读者拿小索引查楫、辨左右阝，再对照“行李”的意思。U17 练查复词与据搭配读音。还要凭读者在真实辞书中的查检表现确认能否独立使用。[U32](../../content/v1/course/u32/unit.md) · [U17](../../content/v1/course/u17/unit.md) |
| 二 古今词义；三 单双音与同义词；四 本义和引申义 | 两字相邻时，有时属于一个词，有时得分开读；熟悉的今义也可能遮住文中的人和事。王本据可证明的早期用例讨论本义。 | “地／方百里”和双音词的查法见 U05、U32；从草木的根读到生计之本见 U05。对“请”的两种请求方向、对“谢”的不同交往行为有独立练习。U36 继续对读“复于客曰”与“声乃复”，一次是向人回话，一次是声音恢复，U37 追问“诚”是在断定还是在设想。词义演变的年代、所有近义词的用法差别还有待逐条考察。[“本”和“道”](../../content/v1/course/u05/03.md) · [常用义项对照](VOCABULARY.md) |
| 五 字的构造；六 古今字、异体字、繁简字 | 看出字形提供了什么线索；古书的写法和今本不同时，分清一词两形、后来另造的字、借同音字记录的词。 | 部首检索、字形关系与平行材料有专练。按六书逐字分析构形、辨析各时代字体尚无系统练习。[查检与异体](DICTIONARY.md) |
| 七 判断句和“也”；八 叙述、“矣”“焉”；九 否定；十 疑问 | 同一句末的“也”“矣”可以分别说明事情怎样、新近起了什么变化；“莫”在早期文本可指没有人。读问句还须辨它在求证，还是委婉地责问。 | U08 判断与否定范围、U26 的“或／莫”“皆未／未皆”“矣／耳”、U27 的“无乃／得无”都要求按眼前语境作判断。每一类虚词还有别的义项。[U08](../../content/v1/course/u08/unit.md) · [逐项句法表](SYNTAX.md) |
| 十一 词类活用；十二 代词、“者”“所” | 用跟在谓语后的对象决定谁受影响；有“所”的结构有时还须找工具、缘由、处所。 | U06 对读使动、意动和名词写动作。U25 把介词和动作一起读，还原“所从”“所与”分别指什么。[U06](../../content/v1/course/u06/unit.md) · [“所”后所缺的成分](../../content/v1/course/u25/03.md) |
| 十三 连词介词；十四 句首句中语气词、词头词尾 | 前后分句可以转折、假设、并列；“于”“以”所带的成分有不同作用。王本还讲“且夫”“今夫”中“夫”领起议论等用法。 | U07 读缘由、工具和比较，U11–12 读人物话里的设想和理由。句首提顿、词头词尾仅零散接触，尚少专门对读。[U07](../../content/v1/course/u07/unit.md) · [U12](../../content/v1/course/u12/unit.md) |
| 十五 《诗经》用韵；十六 双声叠韵和古音通假 | 通论十五同举《硕鼠》《静女》等说明韵的位置；通论十六从音近谈字的借用。 | 《硕鼠》课练的是两章换字和说话双方；U17、U33 才要求从旁证识借字。上古韵部、双声叠韵及按音系判定通假的方法留待专项研读。[重章](../../content/v1/course/u34/01.md) · [辨“归／馈”](../../content/v1/course/u17/02.md) |
| 十七、十八 古书注解 | 先分清正在读正文、注还是疏，再辨注家此处给读音、释词义、换读一个字，还是指明典故来源。 | U18 要求人认清谁在解释谁；U33 让“读如”和“读为”的解释经得起整条注文检验。李善注所引典故的出处与传承未系统训练。[U18](../../content/v1/course/u18/unit.md) · [古注实读](DICTIONARY.md) |
| 十九 天文历法乐律；二十 地理职官科举 | “某月某干支”先给事件定日。读察举和授官时，谁被荐、是否已经任职，影响整段史事。 | U29 在编年材料里找月份、干支和朔日；U28 对读察、举、拜、除；U19 从历史地名定位。星宿、律吕、历代科举程序仍属扩展。[史传字词与纪日](HISTORY_WORDS.md) · [U19](../../content/v1/course/u19/unit.md) |
| 二十一 姓名、礼俗、宗法；二十二 宫室、车马、饮食等 | 同一人物换姓名、字或身后称号时，要能继续追踪；礼仪和实物有时也决定谁能进哪一道门、坐哪一个位置。 | 姓名与字有直接练习。[一人还是两人](../../content/v1/course/u19/02.md)。宗法制度、礼仪位次与器物用途主要靠随文解释或查书，尚无依靠多篇文本的系统检查。 |
| 二十三 文体；二十四 句读 | 读给君主的表，需要辨求什么、以什么为理由；给无标点的文字加句读，需要知道哪些成分不能拆开。 | U16、U19 比较表章中的请求、理由、对象；U18 与两篇试读给连续文字，先自主判断停顿。长篇校点与异读论证需要更多独立材料。[表与记](../../content/v1/course/u16/unit.md) · [句读](../../content/v1/course/u18/03.md) |
| 二十五、二十六 骈体文；二十七 赋；二十八 修辞 | 骈文的对偶与用典，赋的铺陈和问答，以及古文中的譬喻，都需要在文脉中读。 | U13–U14 实际辨过譬喻何处有说服力；U17 检查用赋中答语查词。骈体长段、整篇赋的铺陈、系统用典均有待补。[举例说理](../../content/v1/course/u13/unit.md) · [赋中答语](../../content/v1/course/u17/check.md) |
| 二十九、三十 诗律；三十一 词律；三十二 曲律 | 对读近体诗上下句的句法关系；遇到词、曲，先辨说话者、句式与声口，再谈词牌、曲调与格律。 | U34 用《江雪》《次北固山下》等对读景句，再读柳永、苏轼的词。格律、词谱、曲牌与散曲正文留作扩展。读者能读懂这几篇诗词，并不能由此推定会研读骈赋曲律。[唐诗](../../content/v1/course/u34/02.md) · [宋词](../../content/v1/course/u34/03.md) |
