# U35 · 在新故事里认出旧字

这三课安排在 L4 的论说与人物叙事之后。读者读过魏晋授官、古代计日和说话人的语气，这次打开《史记》中的新段落，依据原文决定“拜”“谢”“再”的意思。三课共用九张已有的知识卡。旧例句与旧题目保留，三课的作答记录直接进入原来的卡；下列题号均为学生需要亲自作答的练习。

## 选文与教法

- **廉颇怎样得到上卿之位。** 传记开头以“……者，……也”介绍人物，以“伐”交代用兵，再以“拜为”记授职。新的粮吏故事故意让受任者和出征者分属两人：只记住廉颇的故事便会把军功归错人。王力《古代汉语》通论（二十）《古代文化常识（二）》职官、通论（七）《判断句，也字》用作句式和官职背景。杨振中《文言文启蒙读本》第52篇《曹彬称病》将攻城和后来克城分开，第325篇《私交与公法》以调任冀州刺史辨任职动词。这里换用列传开场和独立编写的粮运短文。[《史记·廉颇蔺相如列传》底本第14367–14374行](https://github.com/kanripo/KR2a0001/blob/1c19dc6fa970b1c530fced9e8e3697d19163c26c/KR2a0001_500.txt#L14367-L14374)
- **两声“诺”以后。** 项伯与沛公分别作出承诺，次日才写沛公到鸿门赔罪。“与将军戮力”的共同目标要和黄河以南、以北的不同战场一并解释。邻船擦碰后上门补船的教学短文换成民间往来，仍须辨清应允、歉意和已经完成的事。王力通论（十三）《连词，介词》讨论“与”所连成分，杨振中第52篇的诸将许诺和后文实际行动给出类似的时间区分。两段鸿门原文分开摘录，读者能看见两次交涉的时间距离。[项伯夜间传约，第12283–12290行](https://github.com/kanripo/KR2a0001/blob/1c19dc6fa970b1c530fced9e8e3697d19163c26c/KR2a0001_100.txt#L12283-L12290) · [沛公次日赴会，第12304–12313行](https://github.com/kanripo/KR2a0001/blob/1c19dc6fa970b1c530fced9e8e3697d19163c26c/KR2a0001_100.txt#L12304-L12313)
- **三场赛马，一句话怎样记完。** 《孙子吴起列传》先叙田忌平日常赛，再完整讲孙膑出策、三场相较、获胜和获荐。“数”写多次却未计数；“一不胜而再胜”中两个数字则必须合足三场。“然之”记的是下注前的认可，而非事后的胜负。杨振中第125篇《卖瓜减字》直接辨“然之”的语法。王力通论（二）《古今词义的异同》供检验古今相似字面的读法，数目判断由本段三场实数印证；两里分水的练习另撰。[《史记·孙子吴起列传》底本第1143–1163行](https://github.com/kanripo/KR2a0001/blob/1c19dc6fa970b1c530fced9e8e3697d19163c26c/KR2a0001_500.txt#L1143-L1163)
