# 陌生文本试读与反馈

从设置进入「陌生文本试读与反馈」，也可打开站内 `#/pilot`。两篇短文位于 `content/v1/pilot.json`，均为专门创作的教学草稿，与课程题库分开。学习前读《渡口候舟》，完成目标课程后读《夜行遇桥》。每篇含三个选择题，分别观察动作词理解、动作发出者辨认、条件与结果联系。续文提供选做的断句、自由译意或概括，提交后可按语法线索对照自评。有合理分歧的答案保留供人工讨论。

## 学习者如何参与

1. 在同一个浏览器中自愿勾选同意。独立读学习前短文，只使用页面上的词注。提交前可修改选择。提交后首答保留，每篇只能交一次。把姓名、联系方式等个人信息留在反馈之外。
2. 在课程中学习。完成后用相同设备独立阅读学习后短文，记录哪一句需要回看、推断时用了什么线索，以及界面哪里妨碍阅读。
3. 展开“查看首答与解析”核对答案和证据。是否分享由学习者决定。“导出试读与反馈”下载到本机，学习者可先检查文件，再自行交给试用组织者。应用没有自动上传接口。可单独删除本机试读记录；已导出的文件由持有人管理。

## 组织者如何使用结果

招募已经掌握现代汉语且希望提升古文阅读能力的成年人，说明试用目的、分享方式与反馈用途，允许中止。初次见到该文本的读者才适合做首读比较。请记录参与者是否查阅外部资料、是否重复做过题、是否使用同一设备，并获得允许后再观察操作。无需收集姓名。

逐人比较两篇短文对应的三个阅读目标，同时查看其断句、译意和对证据的解释。每个目标仅有一道自动计分题，两篇文本难度也可能不同；单次分差只能产生改进假设。人工复核时注意主语归属、转折或因果依据是否来自文本，以及有无意思相当的替代读法。可在多个读者独立遇到同一困难后，具体记录对应题号、困难、原文或交互修改、修订后验证结果，再用未见过的新材料复测。请保留文本版本，避免把不同版本的成绩合并比较。

本机记录保存在单独的 IndexedDB 中。导出的 JSON 带版本、提交时间、首答选择及对错、断句位置（按字符计，从 1 开始表示该字之后）、自由回答与反馈。课程进度备份和试读导出各自独立。实际受试者观察、授权反馈和后续课程修订需要由试用组织者开展；浏览器冒烟测试只检验流程。
